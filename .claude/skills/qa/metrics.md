# metrics — 기획 모드의 약속 → 측정

> `qa` 기획 3단계에서 「활성」을 고른다. **약속 원문은 옮겨 적지 않는다** — 「근거」의 § 를 **실행 전에** 다시 읽고, DECISION_LOG 에서 폐기(~~취소선~~)됐는지도 본다(기획서는 자주 바뀌고, GAME_DESIGN 요약이 옛말을 인용하고 있기도 하다).
> **판정 기준 수치(몇 % 면 문제)는 적지 않는다** — 목표가 정해지면 CSV 키로 가고 단정으로 승격한다(SKILL.md 원칙 8).
> 실행 파라미터 · 출력 필드는 [src/dev/README.md](src/dev/README.md) 「대량 실행」 · 마지막 판정 수치는 같은 문서 「기획 모드 판정」. 회고에서 「최근」을 덮어쓰고 쓸모 있던 지표를 위로 올린다.
