# risk_map — 자주 깨지는 곳 · 못 일으킨 관찰

> `qa` 1단계 브리핑에서 위부터 읽고 이번 범위에 넣는다. **덮어쓴다** — 이력은 git 이 든다.
> 회고에서 고친다: 버그가 난 영역은 위로 · 다시 일으켰거나 [DEV_PLAN.md](docs/client/DEV_PLAN.md) §4 로 간 관찰은 지운다. §4 번호가 고쳐졌으면 그 영역을 한 번 더 찔러 회귀를 본다.

## 먼저 찌를 곳

| 영역 | 왜 위험한가 | 근거 |
|---|---|---|
| 앱 시계 · 멈춤 문턱 | 문턱을 넘는 공백에도 원정이 안 끊겼다 — 박동 · 재생기 · 끊기가 얽힌 자리 | §4 #51 (09-15) · ADR-0102 · `ui/app.js` `expTick` |
| 관전 HP 갱신 · 표시 | 마법사 HP 가 최대를 넘고 최대 표시가 한 판 안에서 흔들린다 — 최대 HP 가 열리고 닫히는 효과 주변 | §4 #50 (09-15) |
| 개발용 주소의 약속 | QA 는 README 주소표를 믿고 상태에 닿는다 — 적힌 대로 안 돌면 관점이 통째로 막힌다 | §4 #49 (`rep=1`) |
| 원정 중 편성 | 도는 원정의 인원과 `party` 가 갈린다 — 해고 · 수색 · 장착이 어느 쪽을 보나 | R92 (2026-09-14) · 미실행 |
| 제련소 (제작 · 강화 · 크래프트) | 새 기능 · 재료 경계 · 되돌리기 | R96 (2026-09-15) · 미실행 |
| 라운드 단위 진행 · 끊기 | 보상이 라운드마다 들어오고 끄면 끊긴다 | R89 (2026-09-14) · 09-15 새로고침 끊기는 이상 없음 |
| 클라우드 세이브 | 선택 창 · 기기 간 충돌 | R90~R97 묶음 커밋 · 09-15 두 탭 멈춤 창은 이상 없음 |
| 자동 그물이 없는 경로 | 골든 · 캘리브레이션이 한 번도 안 지나는 코드 — 가방 넘침 · 레벨 상한 근처 · 마스터리 랭크 · 세이브 이관 · 선술집 · 수색 | [src/dev/README.md](src/dev/README.md) 「그래도 못 잡는 것」 |
