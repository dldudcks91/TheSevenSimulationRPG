# risk_map — 자주 깨지는 곳 · 못 일으킨 관찰

> `qa-bug` 가 시작에 위부터 읽고 이번 범위에 넣는다. **덮어쓴다** — 이력은 git 이 든다.
> 회고에서 고친다: 버그가 난 영역은 위로 · 다시 일으켰거나 [DEV_PLAN.md](docs/client/DEV_PLAN.md) §4 로 간 관찰은 지운다. §4 번호가 고쳐졌으면 그 영역을 한 번 더 찔러 회귀를 본다.

## 먼저 찌를 곳

| 영역 | 왜 위험한가 | 근거 |
|---|---|---|
| 창이 떠 있는 동안 시계가 바꾸는 상태 | `render()` 에 try 가 없어 창 하나가 던지면 그 뒤 그리기가 전부 멈춘다 — 출정 창은 바퀴 넘김에 `expStage` 를 잃었다. `gone` 이 없는 창(`MODALS`)이 다음 후보 | §4 #90 (10-27 발견 · 같은 날 수정 — `wheel_depart.py` · `depart_flow.py` 로 회귀 확인) |
| 관전 재생기를 다시 세우는 순간 | `mountBattle` 이 세우는 도중 콜백(`onEnd`)이 다시 그리면 바깥 그리기가 새 상태를 덮는다 — 결과 띠가 이미 다 센 런을 되살리는 길(⏸ · 다른 탭 · 숨긴 탭 · 부대 바꾸기)이 다음 후보 | §4 #91 (10-27 발견 · 같은 날 수정 — `pause_probe.py` · `pause_band.py` 로 회귀 확인) |
| 비울 수 있는 대상(관전 장착 대상 · ADR-0849) | `h = null` 로 그리는 길이 보관 칸 · 상자 · 메뉴 · 함 넷 — 하나가 빠져 보관 줄이 사라졌다. 같은 장치를 새로 들이면 그 길 전부를 찔러 본다 | §4 #89 (10-27 수정 · 퍼저 대조군으로 회귀 확인) |
| 앱 시계 · 멈춤 문턱 | 문턱을 넘는 공백에도 원정이 안 끊겼다 — 박동 · 재생기 · 끊기가 얽힌 자리 | §4 #51 (09-15 발견 · 09-21 수정 — 회귀 확인 대기) · ADR-0102 · `ui/app.js` `expTick` |
| 관전 HP 갱신 · 표시 | 마법사 HP 가 최대를 넘고 최대 표시가 한 판 안에서 흔들렸다 — 최대 HP 가 열리고 닫히는 효과 주변 | §4 #50 (09-15 발견 · 09-21 수정 — 회귀 확인 대기) |
| 개발용 주소의 약속 | QA 는 README 주소표를 믿고 상태에 닿는다 — 적힌 대로 안 돌면 관점이 통째로 막힌다 | §4 #49 (`rep=1` · 09-15 해소 — 회귀 확인 대기) |
| 동시 원정 3부대 | 부대마다 시계 · 리포트 · 가방이 따로 돈다 — 한 부대의 조작이 다른 부대에 새나 | GAME_DESIGN §1 · R252 · 미실행 |
| 난이도 전환 | 노말 → 나이트메어 → 헬로 같은 스테이지를 다시 돈다 — 해금 · 기록 · 보상이 난이도마다 갈리나 | 09-30 난이도 바퀴 · 미실행 |
| 강화 · 넘친 드롭 | 단계마다 성공 확률 · 모루와 망치 세 번 · 넘친 드롭은 분해되어 가루로 | R253 · R255 · 미실행 |
| 자원 미니게임 | 10-16 전면 개편 | R267 · 미실행 |
| 원정 중 편성 | 도는 원정의 인원과 `party` 가 갈린다 — 해고 · 수색 · 장착이 어느 쪽을 보나 | R92 (2026-09-14) · 미실행 |
