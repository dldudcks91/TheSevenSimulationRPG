# Project instructions

For requests to create, revise, select, or apply hero or monster bust portraits in this repository, read and use [the portrait art skill](.agents/skills/seven-portrait-art/SKILL.md) before drafting a prompt or editing assets. This instruction does not apply to icons, backgrounds, buildings, or UI art.

The new northern survival idle game inspired by Melvor Idle now has its own sibling workspace, [northward-idle](../northward-idle/README.md). For work on that game, read its [AGENTS.md](../northward-idle/AGENTS.md), [current design](../northward-idle/docs/design/GAME_DESIGN.md), and [project status](../northward-idle/docs/PROJECT_STATUS.md). Save subsequent decisions and implementation in that workspace. The documents under docs/new_game in this repository are archived discussion snapshots, not the current design source. This separate project does not change TheSevenSimulationRPG's existing rules or implementation.
