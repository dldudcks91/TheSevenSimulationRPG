> **캘리브레이션 재측정 (2026-08-28 두 번째, CSV 형태 최적화 후 · 손잡이 미조정 · 같은 조건 시드 20)** — 101 100% / 9.0 라운드 / 164 s / 전투불능 0.00 / 1292 골드 · 102 **100%** / 9.0 / 289 s / 0.00 / 1593 · 103 **100%** / 9.0 / 270 s / 0.00 / 1935 · 104 **100%** / 9.0 / 229 s / 0.25 / 7525. 시간 초과 0.
> 앞선 08-28 측정(스킬 도입 직후)은 101 100% / 102 100% / 103 100% / 104 15% 였다. **수치를 움직인 것은 손잡이가 아니라 데이터 결함 수정 셋이다** — 부채 #18(보스 raw 이중 elevation) 해소로 보스 hp·attack 이 그 스테이지 일반몹 평균으로 내려갔고(예: 사탄 hp 183→60), 부채 #17 해소로 정예 `hp_mult` 3.0→2.0 이 됐다. 드롭 판정도 등급별 굴림 N회에서 **처치당 1회 × 확률 배율**로 바뀌었다(item_design §1). **104 골드 7525 는 챕터보스를 이제 실제로 잡기 때문**이다(`exp_reward × exp_mult × gold_mult × gold_rate`).
> **이제 네 스테이지가 전부 100% 로, 목표 대역(102 는 30~70% · 103/104 는 지는 게 정상)을 위로 벗어난다.** 손잡이는 하나도 돌리지 않았다 — 재보정은 스킬 예산(`skill_dps_budget_pct`)·몬스터 축·귀환 룰(부채 #14)을 함께 보는 별도 결정이다.

> **캘리브레이션 재측정 (2026-08-30, 귀환 룰 반영 후 · 손잡이 미조정 · 같은 조건 시드 20)** — 101 100% / 9.0 라운드 / 164 s / 전투불능 0.00 / 1292 골드 · 102 100% / 9.0 / 289 s / 0.00 / 1593 · 103 100% / 9.0 / 270 s / 0.00 / 1935 · 104 **75%** / 8.8 / 223 s / 0.25 / 5785. 시간 초과 0. **PASS 126/126.**
> **움직인 것은 104 하나뿐이다**(100% → 75%). 101~103 은 전투불능이 아예 안 나서 귀환 룰이 걸릴 자리가 없다 — 표가 안 바뀐 것이 정상이고, 바뀌었다면 그게 회귀였다. 104 의 `avg downed` 는 **0.25 로 직전 측정과 같다** — 전에도 같은 빈도로 쓰러졌고 그 뒤에도 계속 싸워서 이겼을 뿐이다. 즉 이 25%p 는 밸런스가 나빠진 것이 아니라 **없던 안전장치가 생긴 값**이다.
> 목표 대역(102 30~70% · 103/104 는 지는 게 정상) 은 여전히 위로 벗어나 있다 — 손잡이 재보정은 그대로 남은 별도 결정이다.
