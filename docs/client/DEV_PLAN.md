**아카이브는 평소엔 안 연다** — [DEV_LOG.md](DEV_LOG.md)(클라이언트 · 폴더 README · 스킬의 옛 이력) · [DECISION_LOG.md](../game_design/DECISION_LOG.md)(기획서의 옛 이력 · §9 에서 넘어온 행) · [SCREEN_CHANGELOG.md](SCREEN_CHANGELOG.md) · [adr/](adr/README.md). 아카이브에는 크기 상한이 없다.

**크기 상한 — 넘으면 신호다.** 작업 중에 넘은 것을 보면 **보고에 적는다.** 가르거나 덜어 내는 것은 사용자 승인 뒤다.

| 무엇 | 상한 | 왜 |
|---|---|---|
| `CLAUDE.md` | 10KB | 매 턴 통째로 로드된다 |
| 스킬 `SKILL.md` | 15KB | 스킬을 부를 때마다 통째로 읽힌다 |
| 폴더 README · 살아 있는 문서의 한 절(`##` · `###`) | 30KB | 스킬 절차가 통째로, 또는 절 단위로 연다 |
| GAME_DESIGN §9 | 30행 | 기획 작업마다 연다 — 넘치면 가장 오래된 날짜의 행을 날짜째 DECISION_LOG §1 로 옮긴다 |
