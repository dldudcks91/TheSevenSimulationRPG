## 0. 요약

- **왜** — 2024 Steam 사용자의 1차 언어는 간체 33.7% 로 영어(33.5%)보다 많다(Valve 발표). Steam 은 사용자 언어를 지원하는 게임을 더 추천하고, 매칭 기준은 최소 「Interface」 지원이다. 글이 많은 게임은 중국어가 없으면 중국 판매가 1 ~ 2%, 있으면 10 ~ 22% 다(2020 표본). 드래곤클리프는 간체 리뷰가 73.7% 다.
- **무엇이 깎이나** — 문장이 덜 매끄러운 것보다 **규칙 · 수치를 틀리게 옮긴 것**(「after 15s」 → 「每15s」), **같은 개념을 두 단어로 · 다른 개념을 한 단어로**, **번역 빠짐 · 다른 언어 노출**(한국 팀은 한국어가 새는 사고가 특히 잦다), 깨지는 글꼴, 「中文（台湾）」 같은 언어 이름이다.
- **우리 방식** — 용어집을 먼저 고정하고 → 이름은 영어 원본에서 뜻으로 옮기고 · 문장은 한국어 원문에서 옮기며 영어로 대조하고 → 기계 검사 + 문장 대조 + 화면 확인으로 검토한다. 출시 전에 원어민 한 명의 검수를 권한다(§6).
- **구조** — 지금 ko · en 이 나란히 놓인 자리(화면 사전 · CSV 열 · mock 쌍)에 zh 를 셋째로 얹는 것을 권한다. 이것은 **열을 더하는 스키마 변경**이라 사용자 확인 전에는 하지 않는다(§7 D1).

- **이름은 뜻으로 옮기는 것이 관행이다** — Chaos Orb → 混沌石 · Snecko Eye → 异蛇之眼. 소리로 옮기는 것은 인명 · 뜻 없는 고유어(룬 El → 艾尔)뿐이고, 보통명사를 소리로 옮기면 조롱받는다.
- **등급어는 장르 선례를 따른다** — 디아블로4 가 Legendary = 传奇 · Unique = 暗金 이고, 이 게임도 두 등급이 다 있어 그 짝이 맞다(PoE 는 Unique = 传奇 라 충돌).
- **판호** — 글로벌 Steam 출시에는 필요 없다. Steam China(蒸汽平台)에만 필요하다.
- **피드백 창구** — steamcommunity · Discord 는 중국 본토에서 막혀 있어 중국 유저 의견은 Steam 리뷰 · 小黑盒 · Bilibili · QQ群 으로 온다.

## 2. 번역 원칙

1. **용어집이 먼저, 정하면 안 바꾼다** — 등급 · 능력치 · 옵션 · 장비 작업 · 죄종 · 시스템 이름을 한 표로 고정하고 번역은 그 표만 쓴다. 바꿀 때는 틀린 것만(Silksong 방식 · Stardew 교훈).
2. **옮기는 원본이 둘이다** — **아이템 · 스킬 이름은 영어가 원본**(src/data/README.md 「이름은 영어가 원본」)이라 영어에서 옮긴다. **문장(화면 문구 · 도움말 · 이야기 · 스킬 설명)은 한국어가 원문**이라 한국어에서 옮기고 영어로 뜻을 대조한다.
3. **이름은 뜻으로 옮긴다(意译)** — 디아블로2 레저렉션 간체 공식명이 있으면 그것을 쓴다(Long Bow → 长弓 · Mace → 钉锤 · 전수 대조는 용어집 §3). 인명 · 지명 · 뜻 없는 고유어만 소리로 옮긴다. ⚠ 한국어의 「직역 = 음차」 규칙(모닝스타)과 방향이 다르다 — 그 규칙은 한글의 것이고, 중국어로 소리를 옮기면 莫宁斯塔 가 된다 — D2R 공식명은 流星锤 다(§7 D2).
4. **비슷한 두 개념에 같은 글자를 쓰지 않는다** — 한국어가 「범위 ↔ 사거리」 · 「강화(대장간) ↔ 강화(스킬 태그 Boost)」 · 「보호막 ↔ 배리어」처럼 가르는 것은 중국어에서도 두 단어로 가른다. 단 「데미지 · 피해」는 둘 다 伤害다 — 중국어 게임의 관례이고 1차 번역 전 덩어리가 그렇게 모였다(갈림은 화면 맥락이 든다).
5. **규칙 · 수치 문장은 조건어를 대조표로 맞춘다** — 「~마다(every) · ~뒤(after) · ~동안(for) · 최대(up to) · 이상(at least)」을 한 표로 정하고 그대로 쓴다. 자리표시자(`{n}` 등)는 원문과 같은 집합이어야 한다.
6. **문체** — 툴팁 · 옵션 줄은 평이한 현대어로 짧게(CLAUDE.md 규칙 7). 이야기 글은 현대 서면어에 문언 허사(之 · 其 · 乃 · 亦 · 犹如)를 조금만 섞는다 — 반문언은 피한다(Silksong). 과거형 소설체는 「了 · 曾 · 已」와 시간어로 내고 「了」를 문장마다 박지 않는다. 인터넷 은어 · 번체 글자 섞임 금지.
7. **부호** — 문장 안 부호는 전각(，。：；！？、). 따옴표는 대륙식 “ ” ‘ ’ — 「 」는 대만 · 홍콩 관례라 쓰지 않는다. 줄표 ——, 말줄임 …… 은 두 글자. 한자와 숫자 · 영문 사이에 공백을 넣지 않는다(브라우저가 간격을 넣는다).
8. **양사** — 한국어 「{n}마리 · 개 · 권 · 명 · 장 · 판 · 번」은 키마다 只 · 个 · 本 · 名 · 张 · 场 · 次 로 옮긴다. 영어 복수형(`{one, other}`)은 zh 에서 한 문자열이다.
9. **언어 이름은 「简体中文」** — 나라 · 지역 이름을 쓰지 않는다.
10. **빠짐 0** — 업적 · 설정 · 오류 · 알림까지 전수. zh 화면에 한글이 한 글자도 나오지 않는 것을 기계로 검사한다(§6).

## 4. 기술 방향

지금 구조는 언어 하나(`i18n.js` 의 `current`) · 고르는 헬퍼 둘(`t()` 화면 문구 · `L()` 데이터 문구)이다. zh 를 얹을 때 손볼 곳(줄 번호는 [조사 노트](../reference/zh_localization/codebase_text_survey_2026-11-16.md)):

| 곳 | 지금 | 제안 |
|---|---|---|
| 화면 사전 `i18n.js` | 키 하나에 `{ko, en}` 나란히 | `{ko, en, zh}` — 「한 키에 나란히」라 빠짐을 구조로 막는 장점이 그대로 산다 (D1) |
| CSV 표시 열 | `_kr` / `_en` 쌍 53개(41개 파일) | 같은 파일에 `_zh` 열을 더한다 · 설계자 메모 열(`description_kr` 등)은 더하지 않는다 (D1). 새 파일로 따로 두면 「로더 목록 = `src/data/*.csv` 전부」 단정과 규약에 어긋난다 |
| `mock.js` 쌍 | `{ko, en}` 219쌍 | `{ko, en, zh}` (D1) |
| 재포장 지점 | 로더 · data.js · app.js 약 70곳이 `{ko: r.x_kr, en: r.x_en}` 을 손으로 만든다 | 열 이름 하나에서 셋을 꺼내는 헬퍼 하나로 모아 zh 를 빠뜨릴 자리를 없앤다 |
| 빠졌을 때 | `v[current] ?? v.ko` — 한국어가 나온다 | zh 가 비면 **영어**를 보인다 (D4) |
| 이름 조립 `naming.js` | ko 는 받침으로 「과/와」 · en 은 형용사 `adj` | zh 규칙을 더한다(「A之 · A与B之」) — game_logic 경계라 INTERFACE.md 먼저 |
| 접사 한 줄 `mock.js` | ko 「이름 값」 · en 「값 이름」 | zh 는 「이름 값」(데미지 +10% → 伤害 +10%) |
| 세이브에 박힌 이름 | 영웅 이름 · 특성 · 아이템 이름이 `{ko, en}` 로 저장 | 불러올 때 zh 를 채운다 — 아이템은 저장된 죄종 · 단어 · 베이스로 다시 조립, 영웅은 한국어 이름으로 표를 찾는다 (D8 · INTERFACE.md 먼저) |
| 언어 버튼 | 「EN ↔ 한국어」 두 값 토글 | 세 언어를 고른다 (D7 · SCREEN_DESIGN 먼저 → `/ui`) |
| `<html lang>` · `?lang=` | 내부 코드를 그대로 단다 | `zh` → `zh-CN` 으로 달고, `?lang=zh-CN · zh-cn · zh-Hans · zh` 를 하나로 받는다 |
| 글꼴 | `Pretendard, Malgun Gothic` · 제목 Cinzel(라틴 전용) | zh 에서는 **한국어 글꼴을 스택에서 통째로 뺀다** — Pretendard 가 한자 435자와 전각 부호를 맡아 한 문장에 글꼴이 섞인다. 본문 간체 고딕 · 제목 간체 명조를 넣는다 (D6) |
| 줄바꿈 | `word-break: keep-all` 28곳 | 중국어는 띄어쓰기가 없어 이 속성이면 줄이 안 끊기고 넘친다 → 변수로 바꾸고 zh 에서 `normal` |
| 글자 크기 | 가장 작은 단계 9px | 한자는 9px 에서 못 읽는다 · Deck(×0.8 축소)도 생각해 zh 에서 작은 단계를 올린다(시작값은 노트 §3-7) |
| 숫자 · 날짜 | `toLocaleString()` 인자 없이 약 73곳 — OS 로케일을 따른다 | 언어 코드를 명시한다. 万 · 亿 압축은 하지 않는다 — 숫자가 무한히 크지 않다(무한 수직 없음) |
| 테스트 | `['ko','en']` 를 도는 단정 5곳 · 스킬 설명 자리표시자 ko ↔ en 대조 | zh 를 더하고, zh 문자열에 한글 0 · 자리표시자 일치 · 빠진 목록을 단정한다 |
| 그림 속 글자 | 로고 「THE SEVEN」 하나(라틴) | 그대로 둔다 |

- **병렬 세션 운영** — 지금도 여러 세션이 매일 문구를 더한다. 셋 다 필수로 하면 모든 세션이 중국어를 써야 하고, 아니면 zh 가 뒤처진다. 권장: **새 문구는 ko · en 만 써도 된다 · zh 빠짐은 영어로 보이고 · 빠진 목록을 기계로 뽑아 몰아서 옮긴다**(D5 — CLAUDE.md 규칙 6 「ko/en 나란히」를 고치는 일이다).
- **Steam** — 간체 언어 코드는 `schinese`. 첫 실행 언어를 Steam 언어로 고를 때 쓴다. 웹판과 데스크톱판은 저장소(localStorage)가 따로다.
