# 모바일 화면 규격

TheSevenSimulationRPG의 기존 초상·배경·스킨·죄종 색·아이콘과 게임 규칙을 유지하고, 휴대폰에서는 화면 구조를 다시 배치한다.

## 화면과 이동

- 오른쪽 위 설정 → 화면 → 화면 배치에서 자동·PC·모바일을 고른다. 기본값 자동은 좁은 창(가로 1024px 이하)과 휴대폰 가로 화면에 모바일 배치를 적용한다. PC·모바일을 직접 고르면 창 크기와 무관하게 그 배치를 유지하고 이 브라우저에 저장한다. PC를 직접 고른 세로 휴대폰에서도 회전 안내막으로 가리지 않는다.
- 모바일은 세로 회전 안내막 없이 바로 플레이한다. PC 배치는 기존 1600×800 화면과 최대화를 유지한다. 배치 변경은 진행 상태와 게임 세이브를 바꾸지 않는다.
- PC의 마우스 환경에서 모바일을 직접 선택하면 390×844 세로 미리보기를 중앙에 고정한다. 창이 넓어져도 확대하지 않고, 작으면 비율을 유지해 통째로 축소한다. 메뉴·카드·팝업과 크기별 CSS는 고정 논리 규격을 기준으로 배치한다. 설정에 미리보기 규격을 표시한다. 자동 배치와 실제 터치 모바일은 실제 화면을 사용한다(ADR-1111).
- 세로 화면은 상단 자원·우편·알림·설정, 원정 부대 상태 줄, 높이가 고정된 본문, 하단 아이콘 메뉴로 나눈다. 화면 전체와 본문은 스크롤하지 않는다. 가로 휴대폰은 아이콘 메뉴가 왼쪽의 얇은 세로 바가 되어 전장 높이를 확보한다.
- 빠른 메뉴는 원정·편성·캐릭터·건설·전체 메뉴다. 전체 메뉴에서 기존 전투·마을·기타 묶음의 모든 탭, 언어·플레이 시간·새 게임을 찾는다. 기존 잠금과 할 일 점을 그대로 표시한다. 메뉴 아이콘에는 짧은 이름과 접근성 이름이 함께 있다.
- 메뉴판은 닫기·바깥 누르기·Escape로 닫고, 키보드 포커스는 메뉴판 안에 머문 뒤 연 버튼으로 돌아온다. 메뉴를 연 채 게임이 갱신되어도 위치와 메뉴 상태를 잃지 않는다.
- 안전 영역과 브라우저 주소창 높이를 반영한다. 일반 버튼은 높이 44px를 기준으로 키우고, 전투 도구 줄과 다수의 작은 스킬·아이템 칸은 기존 정보량에 맞춰 조밀하게 배치한다.
- 높이 640px 이하의 짧은 세로 관리 화면에서는 원정 부대 상태 줄을 접어 현재 기능에 높이를 준다. 원정에서는 상태 줄을 계속 표시한다. 빈 영웅 자리는 하나의 남은 자리 수로 합치며 실제 영웅과 잠긴 자리는 유지한다.

## 밀어서 탐색하는 정보

- 관련 기능 패널과 고용·의뢰·전술·전직 카드는 본문을 좌우로 밀어서 비교한다. 선택 줄을 직접 누르거나 키보드 화살표로 이동할 수도 있다. 선택 줄 안에 양옆 정보 이름과 현재 위치를 표시한다.
- 캐릭터는 능력치로 진입한다. 상세 II–상세 I–능력치–장비–창고–가방 순서이며 능력치에서 오른쪽으로 밀면 상세 I가 들어온다. 반대 방향으로 밀면 능력치로 돌아온다. 선택은 갱신과 메뉴 이동 후 유지한다.
- 끄는 동안 본문이 따라오며 짧은 이동은 복귀한다. 세로 스크롤·다중 터치·취소는 페이지 전환을 확정하지 않는다. 첫/마지막에서 되감지 않으며 안쪽 카드 끝에서 바깥 메뉴로 넘어가지 않는다.
- 고용·강화·전직·출전 같은 실행 버튼은 눌러 확정한다. 실행 버튼 위에서 끄는 동작이 실행 클릭으로 바뀌지 않게 한다. 진형 드래그·영웅 순서 변경·아이템 조작·스킬 판·입력 필드는 기존 손동작을 유지한다.
- PC 미리보기에서도 마우스 드래그가 가능하며 축소 배율을 보정한다. 동작 감소 설정은 애니메이션을 생략하고 화면 전환은 유지한다. [조사와 계획](MOBILE_GESTURE_PLAN.md), ADR-1129를 따른다.

## 한 화면에서 결정하는 선택지

- 원정은 챕터 선택기·난이도·결과 접근과 다섯 지역을 분리한다. 다섯 행이 남은 높이를 균등하게 나눠 마지막 지역까지 휠 없이 보이고 눌린다. 작은 가로 화면은 조작부를 왼쪽에 둔다. 잠금 사유와 해당 지역의 활동 중 부대 이동은 유지한다.
- 고용 후보는 초상·이름 선택 줄에서 고른 한 명의 능력치 7개·고용·보관을 함께 보여준다. 의뢰도 선택 줄과 현재 목표·진행·보상·수락/수령/포기를 나눠 긴 카드를 쌓지 않는다.
- 수색은 도착한 영웅·빈자리·잠긴 자리를 한 줄로 두고 선택한 영웅의 전체 능력치와 고용·돌려보내기를 같은 화면에 표시한다. 아무도 고르지 않았을 때는 도착 주기·확률·남은 시간을 보여준다.
- 수색 줄에 등록한 영웅과 현재 행동도 안내 판 안에 표시한다. 짧은 가로 화면에서는 도착 상태 왼쪽·등록 영웅 오른쪽으로 나눠 등록 창 접근을 유지한다.
- 전술은 다섯 슬롯 선택과 현재 카드, 공유 보너스 화면을 분리한다. 전직은 갈래 선택과 현재 갈래의 세 스킬을 보여주며 비용과 전직 버튼은 고정한다.
- 건설은 현재 건물·다음 랭크·비용·실행을 한 판에 두고 랭크 목록을 분리한다. 연구소는 생산 줄 하나씩 영웅 칸과 연결 노드를 보여준다. 지점 상세는 연구/레벨 목록, 생산 줄 상세는 생산 현황/영웅 등록으로 나누며 시작·진행·취소는 같은 판에서 조작한다.
- 대장간 네 작업 탭은 화면 폭을 나눠 갖는다. 강화는 현재 단계·성공 확률·변화·전체 비용·실행을 한 판에 둔다. 담금질–강화–장비 옵션을 같은 작업의 연속 페이지로 배치하며 강화에서 오른쪽으로 밀면 담금질이 나온다. 담금질은 3×3 판·다섯 재료 단계·선택 재료·실행을 화면 안에 맞춘다. 짧은 가로 화면은 판 왼쪽, 재료/실행 오른쪽으로 나눈다.
- 탐험은 챕터를 고른 뒤 세 지점을 모두 표시한다. 도감·도움말·챕터처럼 긴 분류 버튼 줄은 모바일 선택기를 사용한다. 도움말 검색으로 달라지는 선택 가능 주제도 선택기에 반영한다.
- 시련의 탑·결투장 준비는 부대 선택, 두 팀/장비 탭, 고정된 전투 시작 버튼으로 구성한다. 실제 영웅 여섯 명의 초상·체력·스킬이 들어간 상태로 짧은 화면까지 맞춘다.
- 고정 개수 선택지와 주요 행동에는 페이지 스크롤을 요구하지 않는다. 가방·도감 결과·레벨 목록·긴 스킬 설명처럼 길이가 가변적인 참조 내용만 해당 영역에서 스크롤한다. 버튼을 가린 뒤 스크롤바만 숨기는 방식은 사용하지 않는다([ADR-1123](adr/1123-mobile-native-selection-and-actions.md)).
- 실행 결과 플래시는 상단 자원 줄 아래에 작게 표시해 하단 실행 버튼을 덮지 않는다. 기존 세 메시지 한도·수명·잠금 사유·클릭 통과는 유지한다.

## 전투

- 관전 진입 시 전장이 본문을 채운다. 적 위·아군 아래, 전열·후열 차이, 초상·이름·HP·행동 게이지·스킬·상태·물약·버프·남은 시간·배속·일시정지·철수·결과를 유지한다.
- 세로에서는 가로로 긴 유닛 카드를 초상 위·정보 아래로 재배치하고, 한 진영 최대 세 장이 한 줄에 선다. 가로 화면은 넓이를 활용해 초상과 정보를 나란히 둔다.
- 기존 최대화 버튼 자리는 모바일에서 전장과 가방 화면을 전환한다. 가방에서도 전장으로 돌아가는 버튼이 고정된다. 아이콘 메뉴와 부대 전환은 계속 사용할 수 있다.
- 시련의 탑·결투장 관전의 같은 버튼은 전장과 두 팀 전투 통계 화면을 전환한다. 짧은 휴대폰에서도 전장과 조작부는 한 화면 안에 맞춘다.
- 로그·누적은 세로에서 전장 아래의 접이식 영역, 가로에서 전장 오른쪽에 겹치는 영역이다. 전투 계산과 재생 위치는 화면 이동·회전으로 초기화하지 않는다.
- 종료 리포트는 원정 기록·전투 결과로 나눈다. 기록을 누르면 결과로 이동하고, 영웅별 피해·처치·쓰러짐은 두 열 카드로 읽는다. PC 표의 가로 스크롤은 쓰지 않는다. 결투 통계의 스킬별 보기 역시 영웅별 세로 목록이다.

## 모든 기능의 배치

- 관리 화면은 좌우 밀기 또는 기능 선택으로 전환하며 한 번에 한 패널만 보여준다. 영웅 선택과 기능 탭은 고정되고, 아이템·도감·능력치처럼 긴 목록 안에서만 스크롤한다. 선택한 기능·챕터·생산 줄은 같은 화면이 갱신되거나 메뉴를 오가도 유지된다.
- 캐릭터는 장비·기본·상세 1·상세 2·창고·가방, 편성은 진형·물약·전술, 건설은 부지·건물 상세, 선술집은 고용·수색·의뢰·도박장, 상점은 구매·판매·교역·상단·창고·가방으로 나눈다.
- 대장간은 작업·장비·창고·가방, 도서관은 폴더 탭(스킬북·전직) 아래 스킬북을 업그레이드·책 제작으로(고른 영웅·지금 가진 스킬은 가로 화면에서 판 왼쪽 열 · ADR-1165), 연구소는 연구판·선택한 연구, 시련의 탑과 결투장은 상대 선택·출전 준비로 나눈다. 부지·연구·상대 선택은 해당 상세 화면으로 이어진다.
- 진형의 세 칸은 터치 드래그를 유지하며 초상·HP·세 스킬까지 포함한 폭으로 판을 맞춘다. 연구소는 생산 줄 선택기로 전환하며, 스킬 트리는 각 판 내부에서 이동한다. 도감·도움말은 분류와 검색을 고정하고 선택한 목록·글만 스크롤한다.
- 가로 휴대폰에서는 영웅 선택 띠를 본문 왼쪽의 세로 목록으로 옮긴다. 전장 물약은 옆으로 세워 카드와 겹치지 않게 하고 상태 칩은 초상 옆에 둔다. 짧은 세로 전투 카드는 초상을 배경으로 두고 HP·행동·스킬을 겹쳐 표시한다.
- 탐험은 비율을 유지한 세계지도와 큰 지점 아이콘·이름 목록을 함께 보여준다. 지점 선택 시 상세가 같은 본문을 덮고 닫기는 고정된다. 수령·출발·불러들이기와 진행 표시를 유지한다.
- 실험실 레이드는 전장·설정·기록으로 나누며 세 부대는 내부 탭으로 바꿔 본다. 보스·공격 예고·출발·일시정지·배속·퇴각은 전장에 두고 편성 선택·새 팀 생성은 설정에서 조작한다. 실험실 도구 전환은 레이드 설정 또는 결투 통계 화면에서 한다.
- 채광·채집·벌목 미니게임은 팝업의 남는 높이를 플레이 영역으로 쓴다. 짧은 가로 화면은 채집 그림·게이지를 좌우로 배치하며, 세 게임의 터치 입력과 닫기를 화면 안에 둔다.
- 출정·스킬·우편·설정 등 팝업은 화면 안에 맞추고 제목·닫기·주요 행동을 고정한다. 긴 준비 항목과 스킬 판은 내부 탭으로 나눈다. 터치 설명창은 세부·범위·장착·잠금 같은 기존 행동을 유지한다.
- 새 게임·프롤로그·알림·튜토리얼도 같은 안전 영역을 따른다. 한국어·영어, 기존 스킨을 함께 점검한다.
- 모바일 글씨는 `mobile.css`의 공용 `--fs-*`와 모바일 크기 토큰으로 관리한다. 작은 전투 칩·초상 위 라벨만 8~10px를 쓰고 본문·입력·제목은 별도 단계다.
