# SCREEN_DESIGN — 화면 설계

> **무엇을 보여주고 어떤 결정을 받는가.** DOM·CSS 가 아니다 — 그건 `src/ui/` 의 구현이고 Phase 2 에서 버려진다. 여기 적힌 것은 엔진이 바뀌어도 **그대로 들고 간다.**
> 화면을 바꾸려면 **이 문서를 먼저** 고친다 (TheSevenSimulation 관례 — 씬 변경은 문서가 코드보다 앞선다).
> 폭·배율·최소 크기 같은 구현 정책은 [src/ui/README.md](../../src/ui/README.md).

관련: [ARCHITECTURE.md](ARCHITECTURE.md) · [INTERFACE.md](INTERFACE.md)(호출하는 함수의 계약) · 컨셉 락 [CLAUDE.md](../../CLAUDE.md)

## 1. 화면 지도

```
시작 ──(새 게임 / 이어하기)──▶ 게임 ── 탭 5 ──┬ 원정   : 편성 ⇄ 관전 ⇄ 리포트   ← 접속 중의 본편 (컨셉 락)
                                            ├ 캐릭터 : 장비·능력치·가방          ← "아이템 정리"
                                            ├ 스킬   : 슬롯 3 · 트리 3탭 (목업)
                                            ├ 선술집 : 고용
                                            └ 도감   : 몬스터 카드
                        (미구현 — 컨셉 락 "오프라인 = 비전투") ▶ 거점/파견 · 탐험 · 제련소 · 상단 · 연구소 · 광산
```

**전투 창구는 하나** — 원정 탭 하나가 편성·관전·리포트 세 상태를 갖는다. 탭을 늘려 전투를 복제하지 않는다 (따름정리 2).

## 2. 공통 셸

| 요소 | 내용 |
|---|---|
| 브랜드 | 상단 좌측 |
| 상단바 | 현재 위치(crumb) · 자원 3종(골드 · 가루 · 낙인) · **언어 토글**(ko/en) |
| 탭 내비 | 원정 · 캐릭터 · 스킬 · 선술집 · 도감 (게임 화면에서만) |
| 메인 | 탭 내용. **항상 전체 다시 그림** |
| 툴팁 레이어 | 아이템 비교 툴팁 (마우스 따라다님, 화면 밖 넘침 보정) |
| 플래시 | 한 번만 보이는 안내/오류 한 줄 (i18n 키 + 파라미터). 다음 렌더에 사라진다 |
| 접이식 설명 | 각 패널 하단 `note` — 기본 접힘. 규칙 설명은 여기에 두고 본문을 어지럽히지 않는다 |

**다국어** — 화면의 모든 문자열은 `t(key)`(문구) 또는 `L({ko,en})`(데이터). 렌더러에 한국어 리터럴 없음.

## 3. 시작 화면

**목적** — 새 게임의 첫 결정(시작 파티 3명)과 이어하기.

| 보여준다 | 결정 | 규칙 |
|---|---|---|
| 세이브 요약 (저장 시각 · 영웅 수 · 클리어 수 · 골드) | **이어하기** | 세이브 버전이 다르면 이어하기 대신 사유를 보여준다 (v1 은 이관 없음) |
| 후보 카드 3장 — 초상 · 이름 · 등급 · 직업 · 역할/무기군 · 죄종 · 시작 특성 · 기본 능력치 7 막대 · 최대 HP · 합계 | **리롤** (무제한, 횟수 표시) | 같은 리롤 횟수 = 같은 3명 (고정 시드) |
| | **시작** | 세이브가 있으면 **두 번 눌러야** 덮어쓴다 — 되돌릴 수 없는 행동은 오클릭 한 번으로 일어나지 않는다 |
| 안내: 각자 직업 전속 무기 1개를 쥐고 시작 | | |

호출: `hero.rollStartParty` · `game.newGame` · `game.deserialize` · `game.closeRun`

## 4. 원정 탭

세그먼트 3 — **편성 / 관전 / 리포트.** 관전은 재생 중인 전투가 있을 때만, 리포트는 마지막 리포트가 있을 때만 활성.
안내 문구: "전투 파티는 한 팀" (동시 원정 1).

### 4-1. 편성

| 영역 | 보여준다 | 결정 |
|---|---|---|
| 재접속 알림 (있을 때) | "꺼져 있던 사이 런이 마무리됨" + 스테이지 | 리포트 보기 / 닫기 |
| 파티 | 슬롯 `party_size_max` 개 — 이름 · 등급 · 직업 · 레벨 · 죄종 · 부상 남은 시간 · 리더 표시 | 행 클릭 = **파티에서 뺀다** |
| | 파티 없음 / 부상자 있음 경고 | |
| | **반복 원정 토글** (마지막 스테이지에 붙음, 런이 있을 때만) | ON/OFF |
| 대기 로스터 | 파티 밖 영웅 (n / `roster_cap`) | 행 클릭 = **파티에 넣는다** (부상자는 비활성) |
| 스테이지 | 해금된 챕터까지 전부 — 잠긴 스테이지도 보인다 ("어디까지 가야 하는지가 보여야 한다"). 죄종 · Ch-스테이지 · 이름 · 클리어 표시 · dlvl · 예상 소요(분) · 배경 | **출발** (해금된 것만) |
| | 접이식 "편성 보기": 등장 몬스터 얼굴·이름 · 보스 · 정예 라운드 · 보스 라운드 | |

호출: `game.toggleParty` · `game.stageUnlocked` · `battle.stagePool` · `game.resolveBattle`(출발) · `game.dismissNotice`
오류 → 플래시: 잠김 / 파티 없음 / 출발 불가(부상) / 파티 정원

### 4-2. 관전 (재생기)

**정산은 출발 순간 끝났다.** 이 화면은 결과를 시간에 맞춰 보여줄 뿐이다.

| 영역 | 내용 |
|---|---|
| 헤드 | 챕터 — 스테이지 이름 · 라운드 n / 총 · 라운드 종류 · 경과 시계 · **라운드 트랙**(1..9, 정예·보스 색) |
| 컨트롤 | 배속 ×1 / ×2 / ×4 · 일시정지 · **건너뛰기** |
| 아레나 | 적(위) / 파티(아래) 상하 대치 · 배경 = 스테이지 배경. 유닛 카드: 이름 · HP 바 · 행동 게이지(마지막 행동 이후 경과 ÷ 주기) · 공격 모션 · 피해/회피/치명/카드 팝업 |
| 로그 | 라운드 시작(편성) · 치명 · 반사 · 처치/전투불능 · 카드 · 종료 |
| 결과 띠 | 재생 끝 → 승/패 띠 → [리포트로]. **반복 ON + 승리면 잠깐 세고 다음 원정 자동** |

재생기가 아는 이벤트 7종과 순서 보장은 [INTERFACE.md §2-6](INTERFACE.md#2-6-battlejs--헤드리스-전투). 언어를 바꿔도 같은 타임라인을 다시 재생한다.

### 4-3. 리포트

| 영역 | 보여준다 | 결정 |
|---|---|---|
| 판정 | **클리어 / 철수(시간 초과) / 패배** · 스테이지 · 소요 · 사유 | |
| 획득 | 골드 · 가루 · XP(1인당) · 라운드 n / 9 · 전투불능 수 · 카드 수 | |
| 레벨업 | 영웅별 from→to + 오른 능력치 | |
| 카드 | 몬스터별 장수, 이번 카드로 도감 레벨이 올랐으면 ▲ | |
| 부상 | 전투불능자 이름 · 남은 치료 시간 · "귀환 시 나머지는 무료 회복" | |
| 액션 | | **다시 출발** / **편성으로** / 반복 토글 |
| 드롭 | 이름(희귀도 색) · 희귀도 · 부위 · ilvl · 비교 툴팁 · 가방 초과로 버린 수 | 행별 **분해** (아직 가방에 있을 때만) |
| 라운드 로그 | R1..9 · 종류 · 처치 목록 · 정예 죄종 | |

호출: `game.salvage` · `game.codexLevel` · `game.resolveBattle`(다시)

## 5. 공통 영웅 띠 (캐릭터 · 스킬 · 선술집 상단)

세 탭이 **같은 띠, 같은 자리, 같은 순서**로 로스터를 보여준다. 카드 = 초상(큰) + 이름 + **지금 하는 일**(치료 중(남은 시간) / 전투 파티 / 대기). 직업·레벨·죄종·등급은 툴팁. 유니크는 표시 구분. 빈 칸은 `+` 로 `roster_cap` 까지.
클릭 = 그 영웅 선택 (선술집에서는 캐릭터 탭으로 이동).
파견이 생기면 "지금 하는 일"에 파견지가 들어온다 — 이 띠가 컨셉 락의 접속/오프라인 상태를 한눈에 보여주는 자리다.

## 6. 캐릭터 탭 — "아이템 정리"

세로 3단: ① 영웅 띠 ② 장비 / 능력치 / 세부 / 현재 스킬 ③ 가방(전폭). **장착·해제·분해가 실제로 일어나는 곳.**

| 패널 | 보여준다 | 결정 |
|---|---|---|
| 장비 | **페이퍼돌** — 신체 위치대로 착용 위치 9 (부위 8, 반지 ×2). 희귀도 색 테두리 · 양손 무기면 보조 칸 잠김 표시 · 착용 n / 9 | 착용 칸 클릭 = **해제** |
| | 접사 죄종 **태그** 집계 (세트포인트 아님 — 보류) | |
| 능력치 | 기본 능력치 7 막대 (범위 표시) · 핵심 전투치 4: 공격력(타입) · 방어(→ **감쇠율 %** — 소재값만 보이면 못 읽는다) · 최대 HP · 행동 주기 | |
| 세부 | 전투 능력치 24 — 카테고리별, 값 있는 것 n / 24, 담당 기본 능력치 약어 | |
| 현재 스킬 | 액티브 슬롯 3 (§7 과 같은 패널) | → 스킬 탭 |
| 가방 | 칸 `inventory_cap` 개 · 부위 필터 · **분해 모드 토글** · 비교 툴팁(이 아이템 vs 교체될 착용품 — 반지는 빈 칸 우선) | 칸 클릭 = **장착** (분해 모드면 **분해**) |

호출: `game.equip` · `game.unequip` · `game.salvage` · `game.equipTarget` · `game.heroCombat` · `formula.mitigation` · `item.groupOf`
오류 → 플래시: `ch.err.<code>` (직업 전속 / 양손 / 가방 초과 / 없음)

**툴팁 규격** — 이름(희귀도 색) · 희귀도 · 부위 · ilvl · (무기) 무기군 + 착용 직업 + 공격력 + 타입/원소 + 주기 · Implicit · 접사 목록 · 죄종 태그 · 힌트. 비교 시 "이 아이템 / 착용 중" 두 장.
