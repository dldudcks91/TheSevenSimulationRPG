## 결정

신원은 본문 오른쪽 열이 든다 · 색은 카드 윗변  — 위칸(띠)은 완전히 폐기. 초상 오른쪽 열이 위에서부터 이름 줄 / HP / 행동 게이지 / 스킬 칸을 쌓는다 — 카드가 「초상 + 수치 열」 한 덩어리가 되고, 위칸이 쓰던 세로 자리를 본문이 받는다.

## 근거 · 맥락

> 아래는 [SCREEN_DESIGN.md](../SCREEN_DESIGN.md) §4-2 본문에서 **그대로 옮긴 것**이다 (2026-09-09 이관). **쓰인 날의 문장이라 고치지 않는다** — 뒤집히면 새 ADR 이 이것을 대체한다.

**신원은 본문 오른쪽 열이 든다 · 색은 카드 윗변** [재개정 2026-09-03 사용자 지시 — 같은 날 「띠 박스」→「선 아래 신원 줄」→**「오른쪽 열」**로 두 번 물렸다] — 위칸(띠)은 **완전히 폐기.** 초상 오른쪽 열이 위에서부터 **이름 줄 / HP / 행동 게이지 / 스킬 칸**을 쌓는다 — 카드가 「초상 + 수치 열」 한 덩어리가 되고, 위칸이 쓰던 세로 자리를 본문이 받는다.

| 규칙 | 내용 |
|---|---|
| ~~이름 + 신원 = 한 줄 · 이름은 오른쪽 끝~~ → **신원 윗줄 · 이름 아랫줄 — 두 줄 · 둘 다 오른쪽 정렬** [개정 2026-09-07 사용자 지시 — 09-03 「첫 줄 하나」 폐기 · 같은 날 「둘 다 왼쪽 정렬」 재개정] | 첫 줄 = 신원(무채색 **보조 글씨** · `Lv.n · 직업` / 정예·보스 라벨) · 둘째 줄 = 이름(**한 단 큰 본문 글씨** — 2026-09-07 사용자 지시 · 두 줄이 같은 크기면 색으로만 갈렸다 · 크기 토큰은 `style.css`) · **둘 다 오른쪽 정렬** [재개정 2026-09-07 사용자 지시 — 같은 날 아침의 「둘 다 왼쪽 정렬(오른쪽 끝은 지그재그)」을 물렸다]. 정렬은 **양 진영 같다**(아래 「열 구성은 양 진영이 같다」) — 몬스터 이름·라벨도 같은 오른쪽 변에 선다. 한 줄 합침은 좁은 열(~104px)에서 신원(고정 조각)이 줄을 먼저 먹어 **이름이 짜부라졌다** — 실기에서 겹침·잘림 관찰(사용자 지적). 이름이 전폭을 쓰면 말줄임이 드물어진다. **일반 몬스터도 윗줄 자리는 잡는다**(빈 채 — 줄 위치·카드 높이 균일 · 역할 줄 「언제나 두 줄 자리」와 같은 원칙). 넘치면 각 줄이 제 줄에서 말줄임된다 |
| **이름 줄은 HP 바 바로 위** [재개정 2026-09-04 사용자 지시 — 전날의 「초상 윗변」을 물렸다] | 열은 바닥 정렬 그대로 — 이름·HP·게이지·스킬이 **한 묶음**으로 초상 아랫변에 붙고, 남는 세로는 전부 이름 **위**에 둔다. 이름을 윗변에 떼어 두면 수치 묶음과 붕 떠서 두 덩어리로 읽혔다 — 읽는 눈이 한 곳에 모이는 쪽을 택했다 |
| **신원 = 강함의 신원** | 영웅은 `Lv.n · 직업`, 몬스터는 **정예/보스 라벨**(일반은 이름뿐 — 테두리 색이 이미 말한다). 무채색 보조 글씨라 죄종 색 폐지와 충돌하지 않는다 |
| **정예의 죄종 접두 이름은 관전에서 안 쓴다** [2026-09-03 사용자 지시] | 「나태의 고블린 전사」 대신 **「고블린 전사 + 정예 라벨」**. 정예임은 라벨·노란 테두리가 이미 말하고, 접두가 붙으면 같은 몬스터가 로그·누적 데미지에 다른 이름으로 흩어진다. ⚠ 조립 규칙(`naming.js:eliteName`)은 폐기가 아니다 — 화면이 안 부를 뿐이고, 리포트의 정예 표시는 원래부터 「몬스터 이름 + 죄종 칩」이라 안 바뀐다 |
| **열 구성은 양 진영이 같다** | 09-03 「카드 형태를 진영 무관 하나로」의 연장 — 몬스터도 같은 열에 이름을 든다. 스킬 칸이 바닥 정렬이라 아랫줄들은 어긋나지 않는다 |
| **색 선은 카드 윗변** [재개정 2026-09-03 사용자 지시] | **카드 윗변 3px** — 영웅 띠 카드·후보 카드가 쓰는 공통 문법이라, 관전 카드만 색 자리가 다르던 것이 닫힌다 |
| **색 = 등급** (죄종 아님) | 영웅은 **영웅 등급**(레어 금색 · 유니크 주황 — `mock.js:HERO_TIER`, 아이템 희귀도와 같은 계단), 몬스터는 **스폰 등급**(일반 = 진영색 · 정예 노랑 · 보스 빨강 — 카드 테두리가 이미 쓰던 그 색). 등급은 **강함의 축**이라 관전에서 읽을 값이고, 죄종은 아니다 |
| **죄종 색은 영웅에게서 걷는다** [2026-09-03 사용자 지시] | 관전만이 아니라 **게임 전체**에서다 — 후보 카드 윗변 · 영웅 띠 카드 윗변 · 능력치 막대 · 이름 줄 죄종 칩 · 스킬 창 강조색이 전부 죄종 색을 쓰고 있었다. 자리는 **등급 색**이 받는다. ⚠ **죄종 이름표는 남는다** — 걷는 것은 색뿐이다(무슨 죄종인지는 여전히 읽혀야 한다). ⚠ 챕터·몬스터·**장비 접사**의 죄종 색은 영웅의 정체성이 아니라 **다른 축**이라 그대로 둔다 |
| 긴 이름 | 제 줄에서 말줄임. 카드 폭은 안 늘린다 |
