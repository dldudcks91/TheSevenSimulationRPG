## 결정

로그와 누적 데미지는 창이 든다  — 옛 우측 열은 폐기한다. 창 규격은 §2 공통 셸의 창과 같다(어두운 판 · 가운데 · 정사각 X) — 창마다 닫는 법이 다르면 그때마다 다시 배워야 한다.

## 근거 · 맥락

> 아래는 [SCREEN_DESIGN.md](../SCREEN_DESIGN.md) §4-2 본문에서 **그대로 옮긴 것**이다 (2026-09-09 이관). **쓰인 날의 문장이라 고치지 않는다** — 뒤집히면 새 ADR 이 이것을 대체한다.

**로그와 누적 데미지는 창이 든다** [개정 2026-09-03 사용자 지시] — 옛 우측 열은 폐기한다. 창 규격은 §2 공통 셸의 창과 **같다**(어두운 판 · 가운데 · 정사각 X) — 창마다 닫는 법이 다르면 그때마다 다시 배워야 한다.

| 규칙 | 내용 |
|---|---|
| 여는 곳 | 컨트롤 줄의 **[전투 로그] · [누적 데미지]** 두 버튼. 열려 있는 판의 버튼은 눌린 표시(`on`)가 남는다 |
| 닫는 길 | **넷** — 열었던 그 버튼 다시 누르기(여는 자리 = 닫는 자리, §4-1 편성 패널과 같은 문법) · 정사각 X · 판 바깥 클릭 · `Esc` |
| 판 갈아타기 | 창이 열린 채 **다른 버튼**을 누르면 판만 바뀐다. 「두 판은 재생 중 자유롭게 오간다」(2026-08-27)를 그대로 잇는다 |
| 창 머리 | 지금 보고 있는 판의 이름(`bt.log.h` / `bt.tab.dmg` 재사용) + X. **새 문구를 만들지 않았다** |
| 재생 | 창을 열어도 **재생은 계속 돈다.** 멈추고 읽으려면 일시정지가 이미 있다 — 창이 재생을 대신 멈추지 않는다(멈춤은 컨트롤이 든다) |
| 재렌더 | 열림 여부와 어느 판인지는 재생 위치와 **같이** 실려 간다(`resume = {t, speed, running, tab, win}`) — 가방을 눌러 화면이 다시 그려져도 창은 열린 채다 |

- **창이 아레나를 덮는다** — 로그는 「방금 뭘 봤나」를 되짚는 판이라 여는 순간의 목적이 관전이 아니다. 나란히 두려면 아레나를 다시 좁혀야 하는데 그건 이번 개정이 되돌린 바로 그 배치다
