## 결정

어느 그림인가는 태어날 때 굴려 세이브에 박은 id 가 정한다  — `faces/<스타일>/hero_<직업id>_<k>.png`, 뒤 두 칸 = `hero.face`(`'<직업id>_<k>'` 문자열 · `mock.js heroFace`). 굴림은 제 직업 풀 안에서만 돈다 — 궁수 얼굴이 전사에게 가지 않는다. 풀이 0장인 직업(마법사)은 `face = null` 이라 빈 칸이다. 옛 판은 이름 해시였다(2026-08-30 ~ 09-06).

## 근거 · 맥락

> 아래는 [SCREEN_DESIGN.md](../SCREEN_DESIGN.md) §5 본문에서 **그대로 옮긴 것**이다 (2026-09-09 이관). **쓰인 날의 문장이라 고치지 않는다** — 뒤집히면 새 ADR 이 이것을 대체한다.

**어느 그림인가는 태어날 때 굴려 세이브에 박은 id 가 정한다** [개정 2026-09-06 · 직업 분류 2026-09-07 사용자 지시] — `faces/<스타일>/hero_<직업id>_<k>.png`, 뒤 두 칸 = `hero.face`(`'<직업id>_<k>'` 문자열 · `mock.js heroFace`). **굴림은 제 직업 풀 안에서만** 돈다 — 궁수 얼굴이 전사에게 가지 않는다. 풀이 0장인 직업(마법사)은 `face = null` 이라 **빈 칸**이다. 옛 판은 **이름 해시**였다(2026-08-30 ~ 09-06).
- **uid 로 고르지 않는다** — 시작 화면·선술집의 **후보는 아직 uid 가 없다**(고용할 때 발급된다). uid 로 고르면 뽑을 때 본 얼굴과 고용한 뒤의 얼굴이 갈려 「어디서나 같다」가 첫 화면에서부터 깨진다. 이름은 굴리는 순간 정해져 끝까지 안 바뀐다
- **매 렌더 굴리지 않는다** — 다시 그릴 때마다 얼굴이 바뀌면 그건 초상이 아니다. 같은 이름 = 늘 같은 그림
- **왜 저장인가** [2026-09-06] — 이름 해시는 **저장할 자리가 없어서** 쓰던 우회다. 렌더러가 화면을 매번 전부 다시 그리므로 그때그때 난수를 굴리면 얼굴이 흔들린다. 그래서 「매번 같은 답이 나오는 계산」이 필요했다. 굴린 값을 영웅에 박아 두면 그 계산이 필요 없다
- **해시가 실제로 낸 사고** [2026-09-06] — 얼굴이 8종(2의 거듭제곱)이 되자 해시의 아래 비트만 쓰여 이름 24개가 5종에 몰렸다. `hero_1`·`hero_3`·`hero_7` 은 **어떤 이름으로도 안 나왔다**. 저장형으로 바꾸면서 원인째 사라졌다 ([DEV_PLAN §4](../DEV_PLAN.md) 부채 #36)
- **장수를 늘려도 기존 영웅 얼굴이 안 바뀐다** [2026-09-06] — 해시 시절에는 장수를 바꿀 때마다 나머지가 달라져 전원 재배정이었다. 지금은 **줄일 때만** 영향이 있다(범위를 넘은 저장값은 접어서 쓴다)
- **후보도 얼굴을 들고 있다** — 굴림이 `rollStartParty` 안에 있어 시작 화면·선술집 후보에게도 그 자리에서 박힌다. 그래서 「뽑을 때 본 얼굴 = 고용한 뒤의 얼굴」이 uid 없이도 성립한다
- ~~**그 스타일에 영웅 그림이 없으면 직업 글리프로 떨어진다**~~ → **빈 칸이다** [개정 2026-09-03 사용자 지시] — 직업 글리프(⚔ ⛨ ✦ 🏹 …)를 **초상 밑에 깔던** 규칙을 폐지한다. 영웅 그림이 **배경 투명 PNG** 이고 칸을 `contain` 으로 채우므로, 그림이 **있어도** 여백 사이로 이모지가 비쳐 보였다 — 자리표시가 아니라 그림을 망치는 층이었다. `onerror` 로 img 가 빠지면 그냥 빈 칸이 남는다. **몬스터는 다르다** — 이니셜(이름 첫 글자)을 계속 깐다(글자라 그림과 안 싸우고, 도감 미수집 표시가 그 글자에 걸려 있다). 옛 문장: (몬스터 얼굴과 같은 규칙 · §10 `?face=`). 글리프 표는 한 곳(`mock.js classGlyph`)
- **장수가 로스터보다 적으면 얼굴이 겹친다** — 지금 그림은 `mock.js:HERO_FACES` 가 **직업별로** 든 장수(전사 3 · 기사 5 · 궁수 1 · 사제 1 · 마법사 0 — 배정도 그 직업 풀 안에서다 [2026-09-07])이고 로스터는 `[balance.csv:roster_cap]` 명이라 겹치는 것이 정상이다. 줄이는 방법은 **그림을 늘리는 것 하나**(그 직업의 장수를 올린다) — 겹침을 피하려고 「파티 안에서 중복 제거」를 하면 얼굴이 편성에 따라 바뀌어 「어디서나 같다」가 깨진다
- ~~⚠ **지금은 `HERO_FACE_MAX = 1` 이라 전 영웅이 같은 얼굴이다**~~ **[지난 상태 — 2026-09-04 사용자 지시]** 옛 초상 14장을 지우고 검투사 한 장만 남긴 잠정 상태였다. `% 1` 의 나머지는 늘 0 이라 이름 해시가 사실상 죽어 있었다. **지금은 10장 · 4직업 풀이다**(전사 3 · 기사 5 · 궁수 1 · 사제 1 · 마법사 0 — 2026-09-07). 그 검투사 한 장은 `hero_warrior_1.png` 으로 남아 있고 여전히 **배경이 불투명**이라 초상 칸에 네모 박스로 보인다 — 누끼 보류(`faces/example/README.md`)
