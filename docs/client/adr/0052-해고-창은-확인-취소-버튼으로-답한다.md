# ADR-0052 — 해고 창은 [확인] · [취소] 버튼으로 답한다

| | |
|---|---|
| **상태** | 확정 · 2026-09-09 (신설) |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | — |
| **대체됨** | — |

## 결정

해고 창은 **한 줄 + 버튼 줄**이다. 상태가 둘이고 버튼이 그것을 말한다.

| 상태 | 문구 | 버튼 |
|---|---|---|
| 장비를 걸치고 있다 | 「영웅을 해고하려면 모든 장비를 해제해야 합니다.」 | **[확인]** |
| 다 벗었다 | 「영웅을 해고합니다.」 | **[확인] [취소]** |

문구는 사용자가 준 그대로다. 「마지막 한 명이다」는 앞의 막힘과 같은 꼴(한 줄 + [확인])로 따라간다.

## 맥락

[ADR-0048](0048-해고는-여기서-한다-장비를-다-벗어야-열린다.md) 로 선 첫 판의 창은 이랬다.

- **막힘 상태에 버튼이 하나도 없었다.** 창을 닫는 길은 정사각 X · 판 바깥 클릭 · Esc 뿐이라, 「읽었다」를 누를 곳이 없었다. 창이 무엇을 요구하는지 말해 놓고 그것에 답할 자리를 안 준 셈이다.
- **확인 상태에 취소가 없었다.** 되돌릴 수 없는 행동([ADR-0048](0048-해고는-여기서-한다-장비를-다-벗어야-열린다.md) · §3)인데 물러설 길이 위험 색 버튼 옆에 안 보이고, X 를 찾아야 했다.
- 문구가 **규칙 설명**이었다 — 「장비를 모두 벗어야 해고할 수 있다 — 착용 {n}」 · 「{name} — 해고하면 되돌릴 수 없다」.

## 근거

**창은 묻고 사람은 버튼으로 답한다.** 닫는 길 셋(X · 바깥 · Esc)은 창 레이어의 공통 규격([SCREEN_DESIGN §2](../SCREEN_DESIGN.md))이고 그대로 남지만, 그것은 **닫는 길**이지 **답**이 아니다. 답이 버튼으로 서 있지 않으면 막힘 상태는 「고장난 창」으로 읽히고, 확인 상태는 「빠져나갈 곳이 없는 창」으로 읽힌다.

**문구에서 수치·이름을 걷는다.** 착용 수 `{n}` 은 창 뒤의 페이퍼돌이 이미 보여 주고, `{name}` 은 창을 연 그 카드가 이미 말한다([ADR-0049](0049-자리는-영웅-띠의-고른-카드-오른쪽-아래다.md) — 버튼이 카드에 붙어 있다). 창이 한 번 더 적으면 **같은 사실이 두 곳에 살아** 한쪽만 낡는다.

**되돌릴 수 없다는 경고를 문장에서 뺀 자리는 [취소] 버튼이 받는다.** 「되돌릴 수 없다」를 읽게 하는 것보다, 물러설 버튼이 확인 버튼 **옆에 실제로 서 있는 것**이 같은 일을 더 확실히 한다. 위험 색은 [확인] 쪽에 남는다 — 파괴적인 쪽이 그쪽이다.

**대안 — 막힘 상태를 창 없이 플래시로.** 안 골랐다. 벗으러 가는 곳이 창 뒤의 페이퍼돌이라 창이 떠 있는 편이 다음 행동에 가깝고, 플래시는 한 번 지나가면 다시 못 읽는다.

## 파급

- i18n — `ui.ok` · `ui.cancel` **신설**(공통 키 · 다음 창도 같은 말을 쓴다). `ch.dismiss.blocked` · `ch.dismiss.confirm` 문구 교체 및 **파라미터 삭제**(`{n}` · `{name}`)
- CSS — `.dismiss-actions` 신설(버튼 줄). 줄은 상태와 상관없이 늘 선다
- ⚠ **이 두 문구만 합니다체**다 — 지시 문구를 그대로 쓴 결과이고, 나머지 화면 문구의 평서체와 갈린다. 화면 전체의 말투를 정하는 것은 이 결정의 범위 밖이라 **열린 채 남긴다**
- ⚠ 「마지막 한 명이다」의 문구(`ch.err.last`)는 **안 건드렸다** — 플래시와 같은 키를 창 본문이 함께 쓰는 구조라, 말투를 맞추려면 플래시 쪽까지 같이 정해야 한다
