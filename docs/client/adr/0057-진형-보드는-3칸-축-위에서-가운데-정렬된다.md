# ADR-0057 — 진형 보드는 3칸 축 위에서 가운데 정렬된다 · 덩어리는 패널 가운데에 선다

## 결정

진형 영역의 배치를 셋 고친다.

| | 옛 판 | 새 판 |
|---|---|---|
| 랭크 줄 안의 칸 | 왼쪽부터 채운다 | **정원 최대(3칸) 폭의 축 위에서 가운데 정렬** (`--fm-axis`) |
| 진형 덩어리(아이콘 + 보드) | 패널 왼쪽에 붙는다 | **패널 가운데**. 머리(「진형」)도 가운데 |
| 칸 한 변 (`--fm-slot`) | 96px | **84px** |

랭크 라벨(전열/후열)은 칸 쪽으로 **오른쪽 정렬**해 붙인다.

## 맥락

띠가 탭 최상단으로 올라간 뒤([ADR-0055](0055-영웅-띠는-원정-탭-최상단에-선다.md)) 전진 패널에는 진형 보드만 남았는데, 보드가 패널 왼쪽에 붙어 있어 **오른쪽 절반이 통째로 비었다.**

그리고 칸이 왼쪽부터 채워지므로 2·1 템플릿에서 **후열 하나가 앞 칸 바로 밑(왼쪽 끝)에** 붙었다 — 진형이 아니라 「짧은 둘째 줄」로 읽혔다 (사용자 지적: 「지금 너무 구림」).

## 근거

**편성 보드와 관전 아레나가 같은 그림이어야 한다.** 관전은 이미 「수가 적은 랭크를 가운데」로 세운다([ADR-0053](0053-진형은-수가-적은-랭크를-가운데에-세운다.md)). 편성에서 왼쪽으로 붙여 놓으면 **같은 진형이 두 화면에서 다른 모양**으로 보인다 — 편성에서 만든 그림이 전투에서 그대로 나와야 편성이 결정으로 읽힌다.

**축을 정원 최대(3칸)로 못박는다.** 랭크의 칸 수만큼만 잡고 가운데 정렬하면 템플릿을 바꿀 때 축이 흔들린다. 3칸으로 고정하면 2·1 ↔ 1·2 ↔ 3 어디서도 **가운데가 같은 자리**다.

**칸을 84px 로 줄인 것은 세로 때문이다.** 「칸 크기를 키우면 보내기 버튼이 접힌다」([ADR-0044](0044-진형은-목업이다.md))의 반대 방향이다 — 보드가 두 줄이라 한 변을 12px 줄이면 세로가 24px 돌아온다. 실측(1280×700 · 뷰포트 608): 보내기 버튼 바닥 **706 → 682**(접힘 98 → **74px**). 완전히는 못 없앤다 — 그러려면 칸이 얼굴로 안 읽힐 만큼 작아져야 한다.

**대안 — 템플릿 아이콘을 보드 위로.** 안 골랐다. 아이콘 높이(46px + 여백)가 그대로 패널 세로에 더해져 보내기가 도로 접힌다(2026-09-09 실측으로 이미 한 번 물린 배치다).

## 파급

- `--fm-axis` 신설(= 칸 3개 + 간격) · `--fm-slot` 96 → 84 · `.fm-main` 이 `center` 정렬 · `.fm-cells` 가 축 폭 + `justify-content: center` · `.fm-label` 오른쪽 정렬 · `.fm-head` 가운데
- ⚠ **보내기 버튼은 여전히 접힌다**(1280×700 뷰포트 608 기준 74px) — 좁아졌을 뿐 해소는 아니다. 메인 칸이 스크롤되므로 닿기는 한다. 완전히 여는 길은 **패널 밖**(아레나 높이 · 헤드 줄 수)이라 별도 결정이다
- ⚠ 칸이 작아져 **영웅 띠 카드와 같은 크기**라는 옛 근거([ADR-0044](0044-진형은-목업이다.md))가 깨졌다 — 띠 카드 하한은 96px 다. 빈 칸이 「영웅이 들어갈 자리」로 읽히는 것은 84px 에서도 유지된다고 보고 택했다
