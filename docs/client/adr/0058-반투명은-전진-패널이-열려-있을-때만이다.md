# ADR-0058 — 파티 카드의 반투명은 전진 패널이 열려 있을 때만이다

| | |
|---|---|
| **상태** | 확정 · 2026-09-09 (신설) |
| **화면** | [SCREEN_DESIGN §4-1](../SCREEN_DESIGN.md) · [§5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | [ADR-0056](0056-편성-띠에서-파티는-테두리가-아니라-반투명으로-말한다.md) *(뜻은 그대로 두고 **조건**을 붙인다)* |
| **대체됨** | — |

## 결정

편성 띠의 파티 카드가 반투명해지는 것은 **지역을 골라 전진 패널이 열려 있는 동안뿐**이다. 같은 지역을 다시 눌러 패널을 접으면 **파티 영웅도 선명하게 돌아온다.**

띠에 `.deployed` 클래스가 붙고 빠지는 것으로 갈린다 (`state.expStage != null`).

## 맥락

[ADR-0056](0056-편성-띠에서-파티는-테두리가-아니라-반투명으로-말한다.md) 이 파란 겉 테두리를 반투명으로 바꾸면서 흐림에 **「이 영웅은 아래 진형 보드에 내려가 있다」**는 뜻을 줬다. 그런데 조건 없이 걸어 둬서, 지역을 안 골라 **보드가 화면에 없을 때도** 파티 영웅이 흐린 채였다 (사용자 지적).

## 근거

**「내려가 있다」는 내려갈 곳이 있을 때만 참이다.** 전진 패널이 접히면 진형 보드가 사라지므로 그 영웅들은 아무 데도 안 가 있다 — 흐림이 가리키는 대상이 없는데 표시만 남은 꼴이었다.

**닫힌 화면의 기본은 「전부 선명」이다.** 지역을 안 고른 상태가 이 화면의 기본이고([SCREEN_DESIGN §4-1](../SCREEN_DESIGN.md)), 기본 화면에서 로스터의 절반이 흐려 있으면 「못 쓰는 영웅」으로 읽힌다.

## 파급

- `heroStrip` 에 `deployed` 옵션 · `.hero-strip.deployed` 클래스 · CSS 선택자가 `.party-mode.deployed .hs-card.party` 로 좁아진다
- ⚠ **패널이 닫혀 있으면 파티가 누구인지 띠에서 안 보인다** — 파티는 세이브 값(`G.party`)이라 그대로 살아 있고, 지역을 누르면 그 자리에 다시 나타난다. 「누가 파티인가」를 닫힌 화면에서도 읽어야 한다는 요구가 생기면 **흐림이 아닌 다른 표시**로 새 결정을 낸다(파란 테두리는 [ADR-0056](0056-편성-띠에서-파티는-테두리가-아니라-반투명으로-말한다.md) 이 이미 걷었다)
