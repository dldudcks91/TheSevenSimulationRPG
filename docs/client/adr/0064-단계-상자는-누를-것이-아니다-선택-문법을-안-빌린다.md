# ADR-0064 — 단계 상자는 누를 것이 아니다 · 선택 문법을 안 빌린다

## 결정

**이 탭에서 클릭을 받는 것은 단 하나뿐이다** — 그래서 단만 누를 수 있어 보인다.

- 단계 상자는 `.dp-cell` 의 **선택 문법을 안 빌린다** — 왼쪽 강조선(= 열렸다)도 `--bg-tertiary`(= 골라졌다)도 안 쓴다. 대신 **파인 칸**(`--bg-input`)이라 단 안의 내용으로 읽힌다
- 단은 hover 에 **테두리까지** 밝아진다(`--border-secondary`) — 손가락 커서와 함께 「이것이 그 버튼」을 말한다
- 상자 안 글씨가 **한 단씩 올라간다** — 단계 이름 `--fs-xs` → **`--fs-md`**, 산출물 `--fs-2xs` → **`--fs-xs`**, 번호 배지 `--fs-2xs` → **`--fs-xs`**, 트랙 머리 `--fs-2xs` → **`--fs-xs`**, 단 이름 `--fs-sm` → **`--fs-md`**

## 맥락

[ADR-0061](0061-단계-7-은-줄이-아니라-상자다-단-3-이-세로를-다-쓴다.md) 로 단계 일곱이 상자가 되면서 상자가 `.dp-cell` 의 표시 둘을 그대로 물려받았다 — **왼쪽 강조선**과 **`--bg-tertiary` 배경**. 그 둘은 카드였던 시절부터 「열렸다 / 골라졌다」를 말하는 어휘라, 같은 옷을 입은 상자 일곱이 한 단 안에 서자 **각각 눌리는 칸**으로 읽혔다. 실제로 클릭을 받는 것은 단 하나뿐이었다.

글씨는 [ADR-0061](0061-단계-7-은-줄이-아니라-상자다-단-3-이-세로를-다-쓴다.md) 이 상자를 실측 78px(1440×900)까지 키우면서도 **줄이던 시절의 크기를 그대로** 뒀다 — 이름 12px · 산출물 **9px**. `--fs-2xs` 는 「칸 안 초소형 라벨 전용」인데(ui/README 글씨 크기) 그 칸이 이미 초소형이 아니게 된 뒤였다.

## 근거

**같은 옷은 같은 뜻이어야 한다.** 강조선과 `--bg-tertiary` 는 이 화면에서 이미 뜻이 배정된 어휘다. 상자를 다르게 보이게 하는 방법은 여럿이지만, **이미 쓰이는 어휘를 피하는 것**이 새 어휘를 만드는 것보다 싸다 — 파인 칸(`--bg-input`)은 화면 곳곳에서 「값이 담기는 자리」로 이미 쓰고 있다.

**곁들여 실제 버그가 하나 닫혔다** — 열린 단은 배경이 `--bg-tertiary` 인데 상자도 같은 색이라, **골라진 단에서만 상자가 테두리만 남고 사라졌다.** 파인 칸으로 바꾸면 열림 여부와 무관하게 상자가 선다.

**글씨 크기는 칸 크기를 따라간다.** 9px 라벨은 배지·약어처럼 **이미 아는 것을 확인하는** 자리에서만 성립한다. 상자의 두 줄은 처음 읽는 이름이라 본문 크기가 필요하다.

**버린 안 — 상자를 진짜 누를 수 있게 만든다.** 「눌러 보이는데 안 눌린다」를 해소하는 반대쪽 길이었다. 안 고른 이유는 **누른 뒤에 일어날 일이 없기 때문**이다 — 단계를 고르는 결정은 배치·산출 정산이 있어야 성립하고 그것은 `game_logic` 에 없다. 손잡이만 먼저 만들면 누를 수 없는 칸을 그리는 셈이고, 그 금지는 §8 의 오래된 규칙이다.

## 파급

- `.dp-tier` 배경 `--bg-tertiary` → `--bg-input` · `border-left` 강조선 삭제 · `.dp-tier.empty` 의 강조선 예외도 함께 삭제(끌 선이 없어졌다)
- `.dp-cell:hover` 에 `border-color: var(--border-secondary)` 추가 · `.dp-t-n` 에 `background: var(--bg-primary)` 추가(파인 칸 위에서 배지가 떠 보이게)
- **CSS 만 바뀐다** — 렌더러 · i18n · 데이터 무수정
- ⚠ **하한 1280×700 에서 안내 패널이 접힘 아래로 내려갔다** — 글씨가 커지며 상자 일곱의 최소 높이 합이 늘었다(실측 상자당 약 51px). 1440×900 에서는 다 선다. 안내 패널을 걷으면 하한에서도 스크롤이 사라진다 — [ADR-0061](0061-단계-7-은-줄이-아니라-상자다-단-3-이-세로를-다-쓴다.md) 이 「버린 안」으로 적어 둔 그 선택이 여기서 다시 열려 있다
