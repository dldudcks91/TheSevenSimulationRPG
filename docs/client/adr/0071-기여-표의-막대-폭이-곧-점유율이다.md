# ADR-0071 — 기여 표의 막대 폭이 곧 점유율이다 (칸 전체 = 100%)

| **화면** | [SCREEN_DESIGN §4-3](../SCREEN_DESIGN.md) |

| **대체됨** | — |

## 결정

기여 표의 막대는 **칸 전체를 100%(= 파티 합계)로 놓고 점유율만큼** 그린다. 40%면 칸의 40%다.

## 맥락

[ADR-0070](0070-기여-표는-초상을-달고-두-칸이-각자-자기-최대로-그린다.md) 은 막대를 **그 칸의 최대값** 기준으로 그렸다. 그러면 각 칸의 1등은 언제나 막대가 꽉 찬다 — 실제로 화면에는 `41%` 라고 적힌 옆에 **가득 찬 막대**가 서 있었다. 한 줄 안에서 그림과 숫자가 서로 다른 말을 했다.

## 근거

- **한 칸에 두 개의 눈금이 있을 수 없다.** 숫자가 점유율이면 막대도 점유율이어야 한다. 최대값 기준 막대는 「이 사람이 1등이다」만 말하고, 그 사실은 표가 이미 정렬로 말한다
- 0070 이 최대값 기준을 고른 이유(받은 피해 칸이 늘 비어 보인다)는 **점유율 기준에서도 풀린다** — 파티가 맞은 총량 안에서의 몫이라 0% 와 47% 가 뚜렷이 갈린다. 두 칸이 서로 다른 총량(가한 합 · 받은 합)을 100% 로 쓰므로, 「자기 칸 안에서 비교한다」는 0070 의 뜻도 그대로 산다
- 100% 는 **읽는 사람이 이미 아는 눈금**이다. 최대값은 판마다 달라서 같은 길이의 막대가 판마다 다른 뜻이 된다

## 파급

- `contribSection` 의 `cell()` 이 점유율 하나로 폭과 글자를 **같은 값에서** 만든다 — 둘이 어긋날 자리가 없어졌다
- 0070 의 나머지(초상 · 두 칸 같은 폭·같은 모양 · 막대 색 구분 · 합계 줄)는 **안 바뀐다**
