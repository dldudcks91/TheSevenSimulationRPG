# ADR-0075 — 스킬 세그먼트는 조밀 격자다 · 직업 다섯이 한 화면에 선다

| | |

| **화면** | [SCREEN_DESIGN §9-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | — *([ADR-0036](0036-묶음별로-전부-펼치는-조회-화면.md) 의 「묶음별로 전부 펼친다」와 [ADR-0066](0066-캐릭터-초상도-직업이-묶음이다.md) 의 묶는 단위는 그대로 두고, 스킬 세그먼트의 **칸 크기**만 바꾼다)* |
| **대체됨** | — |

## 결정

스킬 세그먼트의 격자는 **조밀하다** — 그림 칸이 작아지고 타일·묶음의 여백이 좁아진다. 목표는 하나다: **직업 묶음 전부가 하한 폭·세로 예산에서 한 화면에 선다.** **캐릭터 · 아이템 세그먼트는 손대지 않는다** — 초상은 크게 보는 것이 그 세그먼트의 목적이다(아래 「파급」의 ⚠).

곁딸린 규칙 하나 — **스킬 타일의 파일명은 확장자를 뗀다.**

## 맥락

스킬 세그먼트의 묶음은 직업 다섯이다. 한 화면에 든 것은 **두 묶음 반**이었고 나머지는 스크롤 아래였다 — 「어느 직업이 아직 제 그림이 없나」가 이 화면의 용도인데(빈 칸 신호는 파일명 줄 — [ADR-0036](0036-묶음별로-전부-펼치는-조회-화면.md)), 그 감사를 스크롤을 오르내리며 해야 했다.

세 세그먼트가 같은 칸 크기를 쓰는데, 스킬은 칸이 가장 많다 — 묶음마다 한 줄이 서고 그 줄이 다섯이다.

## 근거

**도감은 이미 「한 화면」 규칙을 갖고 있다** — 몬스터 세그먼트는 한 챕터가 한 화면이고([SCREEN_DESIGN §9](../SCREEN_DESIGN.md)), 원정이 그 규칙을 빌려 갔다([ADR-0067](0067-원정도-한-챕터가-한-화면이다.md)). 스킬만 스크롤을 쓰고 있었다.

**세로를 줄이는 방법이 셋 있었고, 그림을 줄이는 쪽을 골랐다.**

| 버린 안 | 왜 안 골랐나 |
|---|---|
| **직업 세그먼트를 한 겹 더 얹는다** (한 번에 한 직업) | 「묶음별로 **전부 펼친다**」([ADR-0036](0036-묶음별로-전부-펼치는-조회-화면.md))를 정면으로 뒤집는다. 세그먼트가 두 겹(자산 × 직업)이 되고, 무엇이 비었는지 보려면 직업 수만큼 눌러야 한다 — 스크롤을 클릭으로 바꾼 것뿐이다 |
| **이름 · 파일명을 걷고 그림만 남긴다** | 그림은 오히려 커지지만, 스킬의 **빈 칸 신호가 파일명 줄**이다([ADR-0036](0036-묶음별로-전부-펼치는-조회-화면.md)). 그 줄을 툴팁 뒤로 숨기면 감사하려고 타일을 하나씩 올려야 한다 — 이 화면이 걷어 낸 조건을 다시 세우는 꼴이다 |
| **그룹 머리를 격자 왼쪽에 세운다** | 세로는 묶음마다 머리 한 줄씩 줄지만 **가로를 먹는다.** 가장 큰 묶음이 하한 폭에서 한 줄에 못 서고, 접히는 순간 줄어든 세로보다 더 늘어난다 |

**확장자를 뗀 이유** — 칸이 좁아지면 가장 긴 파일명이 두 줄이 되고, 그 한 줄이 묶음마다 붙어 세로 예산을 도로 깬다. 스킬 아이콘은 전부 png 라 넉 자가 말해 주는 것이 없고, **비교 대상은 스킬 id 와 파일명의 줄기**다 — 뗀 쪽이 신호에 더 가깝다.

## 파급

- CSS 는 `.ix-body.dense` 한 갈래다 — 캐릭터 · 아이템 세그먼트의 규칙은 한 줄도 안 바뀐다. 값은 [src/ui/README.md](../../../src/ui/README.md) 가 든다(폭 · px 의 SSOT)
- 렌더는 `artTile` 의 인자 하나(`stem`)와 세그먼트에 붙는 class 하나. **묶는 문법(직업) · 타일이 든 것 · 툴팁 · 목록의 SSOT 는 그대로**다
- i18n · 세이브 · 단정 무변동
- ⚠ **한 묶음이 하한 폭에서 한 줄에 서는 칸 수를 넘으면** 격자가 두 줄이 되어 세로가 다시 넘친다. 직업 하나의 스킬이 그만큼 늘면 그때 다시 정한다 — 칸 수의 SSOT 는 `skill.csv` 다
- ⚠ **캐릭터 세그먼트는 그대로 스크롤이 남는다** — 그쪽도 직업으로 묶여 묶음 수가 같지만(ADR-0066) **초상은 크게 보는 것 자체가 이 화면의 목적**이라 같은 처방을 안 썼다. 이 결정은 스킬 하나에만 걸린다
