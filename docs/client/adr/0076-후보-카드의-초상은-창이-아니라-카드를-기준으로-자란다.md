# ADR-0076 — 후보 카드의 초상은 창이 아니라 카드를 기준으로 자란다

| | |
|---|---|
| **상태** | 확정 · 2026-09-10 |
| **화면** | [SCREEN_DESIGN §3](../SCREEN_DESIGN.md) · [§8-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | — |
| **대체됨** | — |

## 결정

`.ng-card` 를 컨테이너로 세우고(`container-type: inline-size`) 초상을 **카드 안쪽 폭의 44%** 로 잰다 — `clamp(96px, 44cqw, 152px)`. 종전의 `9.5vw`(창 폭 기준)를 대체한다. 상한 152px 은 그대로 둔다.

## 맥락

`.ng-card` 는 시작 화면(§3)과 선술집 명단(§8-1)이 함께 쓰는 한 규격이다. 2026-09-08 사용자 지시로 선술집 전용 크기값(초상 clamp · 패딩 · 이름 글씨 · 능력치 줄간격)을 **전부 지워** 카드가 시작 화면과 같은 규격을 타게 했고, 그 지시는 「후보 카드가 시작 화면과 **완전히 같은 크기**」로 기록됐다 ([src/ui/README 화면 폭 정책](../../../src/ui/README.md)).

2026-09-10 실측에서 **크기가 안 맞는 것이 드러났다**. 1440×900 기준:

| | 시작 화면 | 선술집 |
|---|---|---|
| 카드 폭 | **343px** | **378px** |
| 초상 | 137px | 137px |

카드 CSS 도 격자(`repeat(3, minmax(0,1fr))` · gap 14)도 같은데 **담는 그릇이 달랐다** — 시작 화면은 `.ng-wrap { max-width: 1060px }` 에서 잘리고 선술집은 `.panel` 전폭(1163px)을 쓴다. 그런데 초상만 `9.5vw` 로 **창**을 봐서 두 화면에서 같은 137px 이었다. 결과는 「카드는 10% 넓은데 얼굴은 그대로」 — 초상이 카드에서 차지하는 비중이 40% 대 36% 로 갈렸고, 「후보 카드의 초상은 **카드에서 가장 큰 조각**이다」([2026-08-31 사용자 지시](../SCREEN_DESIGN.md) §3)가 선술집에서만 풀려 있었다.

같은 이유로 **창을 넓히면 시작 화면 안에서도 비율이 흔들렸다** — `.ng-wrap` 이 1060px 에서 잘려 카드는 343px 에 멈추는데 초상은 `9.5vw` 로 계속 자라 1600px 창에서 152px(상한)에 닿는다. 같은 카드에서 초상만 44% → 49% 로 커진다.

## 근거

**초상의 크기를 정하는 것은 창이 아니라 카드다.** 초상은 「카드에서 가장 큰 조각」이라는 **카드 안에서의 역할**로 크기가 정해진 것이므로, 기준도 카드여야 한다. `cqw` 는 그 관계를 그대로 적는 단위다 — 카드가 넓어지면 얼굴도 넓어지고, 어느 화면에 놓이든 비율이 같다.

**버린 안 — 선술집 명단도 `max-width: 1060px` 로 자른다.** 카드가 343px 로 **완전히 같아진다**는 점에서 09-08 지시의 문자에 가장 가깝다. 안 고른 이유는 넓은 패널 안에서 명단만 가운데로 몰려 양옆에 100px 씩 빈 띠가 생기기 때문이다 — 선술집은 명단 아래에 도구 줄과 의뢰 게시판이 **전폭으로** 서 있어, 명단만 좁히면 그 셋의 폭이 어긋나 「명단이 덜 그려졌다」로 읽힌다. 시작 화면의 1060px 캡은 **읽기 폭**을 위한 것이고(그 화면엔 카드 셋 말고 아무것도 없다) 선술집엔 그 이유가 없다. 이 안은 살아 있다 — 「완전히 같은 크기」를 문자 그대로 지켜야 한다면 한 줄로 되돌릴 수 있다.

**버린 안 — 그대로 둔다.** 초상 크기가 두 화면에서 같으니 얼굴은 어차피 같게 읽힌다는 쪽. 안 고른 이유는 위의 **창 폭에 따른 비율 흔들림**이 남기 때문이다. 그건 화면 간 차이가 아니라 **한 화면 안의 버그**라 어느 쪽 선택과도 무관하게 고쳐야 했다.

**상한 152px 을 안 건드린 이유** — 초상 원본을 넘겨 확대하지 않기 위한 값이라 카드 폭과 무관한 근거를 갖는다. 넓은 창의 선술집에서는 이 상한이 먼저 걸려 비율이 다시 44% 아래로 내려가지만, 그건 「원본보다 크게 그리지 않는다」가 이긴 것이고 의도된 순서다.

## 파급

- `.ng-card` 에 `container-type: inline-size` — `contain: layout` 이 함께 걸린다. 카드 안에 **카드 밖을 기준으로 눕는 것이 없어** 안전하다: 초상 위 겹침(`.hero-face img`)은 `.hero-face` 안쪽이고, 툴팁(`#tooltip`)은 `index.html` 최상위라 카드의 자손이 아니다
- 1440×900 에서 선술집 초상 **137 → 151px**. `.ng-head` 의 높이는 옆 열(`.ng-id` — 칩 · 이름 · 직업 · 역할 · 고유 스킬 칸)이 이미 더 길어 **카드 높이는 거의 안 변한다**
- ⚠ **카드 폭 35px 차이는 그대로 남는다** — 이 결정이 맞춘 것은 크기가 아니라 **비율**이다. 「완전히 같은 크기」(2026-09-08 사용자 지시)는 위의 버린 안으로만 닿는다
