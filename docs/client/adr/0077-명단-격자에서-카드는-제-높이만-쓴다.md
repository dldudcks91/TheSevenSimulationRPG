# ADR-0077 — 명단 격자에서 카드는 제 높이만 쓴다

| | |
|---|---|
| **상태** | 확정 · 2026-09-10 |
| **화면** | [SCREEN_DESIGN §8-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | — |
| **대체됨** | — |

## 결정

선술집 명단 격자(`.tv-cands`)에 `align-items: start` 를 건다 — 후보 카드가 행 높이까지 늘어나지 않고 제 내용만큼만 선다. 늘어나야 하는 둘만 되돌린다: **빈 칸**(`.tv-empty` — 고용한 자리)과 **수색 칸의 대기·진행 상태**(`.tv-search` — 버튼이 `margin-top:auto` 로 바닥에 앉는다).

## 맥락

수색이 실동작하면서(ADR-0062 · ADR-0068) 셋째 칸이 **결과 카드**가 되는 상태가 생겼다. 결과 카드는 「수색 완료」 줄 + 만남 블록(질문 + 답 버튼들) + 영웅 카드 + 버튼 둘을 이고 있어 후보 카드보다 한참 길다.

격자가 `stretch` 라 행 높이를 제일 큰 카드가 정하는데, 1440×900 실측에서 후보 카드 둘이 고용 버튼(y 583)에서 끝나고도 테두리는 **y 805 까지** 내려왔다 — 카드 속이 **222px 비었다**. 테두리는 있는데 안에 아무것도 없어 「덜 그려졌다」로 읽힌다.

## 근거

**빈 속을 보이느니 카드를 끊는다.** 카드의 테두리는 「여기까지가 이 영웅이다」라는 선인데, 속이 없는 채로 내려오면 그 선이 거짓말을 한다. 카드를 제 높이에서 끊으면 남는 자리는 **패널 배경**이 되고, 배경은 아무것도 주장하지 않는다.

⚠ 이 결정은 시작 화면(§3)의 「**세 장은 같은 무게로 놓인다** — 하나를 크게 하면 그쪽이 정답처럼 읽힌다」를 선술집에서 뒤집는다. 뒤집는 이유는 **셋의 성격이 다르기 때문**이다. 시작 화면의 셋은 **서로 고르는 후보**라 무게가 같아야 하지만, 선술집의 셋째 칸은 후보가 아니라 **다른 활동**(수색)이고 결과 카드는 이미 만남·이야기를 이고 있어 같은 무게일 수가 없다. 시작 화면은 안 건드린다.

**버린 안 — 결과가 오면 명단을 숨기고 그 영웅만 크게 띄운다.** 1시간 기다린 결과가 사건으로 읽힌다는 장점이 있다. 안 고른 이유는 **명단 후보와 견줄 수 없게 되기 때문**이다 — 고용비가 같은 밑값(`tavern_hire_cost`)이라 「이 600골드를 어디 쓸까」가 실제 결정이고, 만남에서 값을 깎았다면 더욱 그렇다. 나란히 세워야 그 비교가 선다. 리롤하러 온 흐름을 막는다는 점도 걸렸다.

**버린 안 — 결과 카드를 격자 밖 자기 줄로 뺀다.** 「후보 카드와 다른 것이라 같은 격자에 세우면 후보로 읽힌다」는 의뢰 게시판의 논리를 그대로 쓸 수 있었다. 안 고른 이유는 수색 칸을 **명단 오른쪽 셋째 칸**에 둔 2026-09-01 사용자 지시([ADR-0011](0011-수색-칸을-그린다.md))를 뒤집기 때문이고, 위와 같은 이유로 **비교가 서는 자리**가 실제로 그 격자다.

## 파급

- `.tv-cands { align-items: start }` · `.tv-cands .tv-empty` 와 `.tv-search` 에 `align-self: stretch`
- 결과 카드는 `.ng-card.tv-search-res` 라 `.tv-search` 규칙에 안 걸린다 — **제 높이로 선다**(어차피 행에서 제일 길다)
- ⚠ **빈 칸 + 완료가 겹치면 빈 칸이 결과 카드 높이만큼 길어진다** — 고용으로 자리가 빈 채 수색이 끝난 상태다. 「빈 칸은 자리를 지킨다」가 이긴 결과이고, 드문 조합이라 그대로 둔다
- 행 높이 자체는 안 줄어든다 — 결과 카드가 여전히 정한다. **세로 예산은 이 결정으로 나아지지 않는다**([src/ui/README 화면 폭 정책](../../../src/ui/README.md) 의 선술집 예외는 그대로다)
