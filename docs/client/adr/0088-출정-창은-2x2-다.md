# ADR-0088 — 출정 창은 2×2 다 · 적 구성은 파티 오른쪽 · 진형은 파티 아래

## 결정

출정 창의 칸 넷이 **격자 하나에 2×2** 로 선다.

| | 왼쪽 열 (남는 폭) | 오른쪽 열 (적 구성 내용 폭) |
|---|---|---|
| **위 줄** | 캐릭터 선택 (띠 7장) | 적 구성 (정사각 4칸) |
| **아래 줄** | 진형 (템플릿 셋 · 보드) | 출정 방식 (버튼 둘) |

- **읽는 법** — 위 줄은 「누구를 보내나 ↔ 누구와 싸우나」가 **마주 선다**. 아래 줄은 「어떻게 세우나 → 갈까」
- **칸 넷이 격자의 직접 자식**이다 — 줄마다 감싸는 래퍼를 두지 않는다. 출정 방식 칸은 오른쪽 열의 폭을 받는다
- **가림막** — 칸마다 오른쪽 · 아래 여백을 두고, 오른쪽 열은 **왼쪽에 세로선**, 아래 줄은 **위에 가로선**을 세운다. 선은 줄 높이 전체에 서고 칸 안 내용은 위 정렬 그대로다
- **창 높이를 조금 키운다 — 칸이 아니라 간격 · 여백으로** — 줄 사이 여백 28 + 28 · 칸 이름 아래 9 → 12 · 판 여백 `16/20/20` → `22/24/26`. 칸 크기(`--fm-slot` · 띠 카드)와 창 폭(`min(1520px, 100%)`)은 그대로다

## 맥락

사용자 지시 원문 — 「적 구성을 우리 파티 7명 오른쪽으로 옮기자 · 우리 파티 아래에 진형 설정 · 탭 높이를 좀만 키워봐」.

창은 **위에 캐릭터 선택(띠) + 아래 한 줄에 「적 구성 · 진형 · 출정 방식」** 이었다(ADR-0084). 아래 줄은 왼쪽에서 오른쪽으로 「누구와 싸우나 → 어떻게 세우나 → 갈까」로 읽혔다(ADR-0078). 1600×800 에서 창 높이는 **504px** 였다(실측).

그때 창의 판 여백 `16/20/20`(`.depart-box`)은 **안 먹고 있었다** — 뒤에 선언된 창 공통 `.modal-box`(12/14/14)가 같은 명시도로 덮었다(computed `12px 14px 14px`).

## 근거

- **보낼 쪽과 맞설 쪽이 같은 줄에 마주 선다** — 띠와 적 구성이 한 줄이면 둘을 한 눈에 견준다
- **진형이 띠 바로 아래다** — 띠 카드를 보드로 끌어내리는 거리가 짧다
- **한 격자라 구분선이 두 줄을 관통한다** — 줄마다 격자를 따로 두면 두 줄의 열 폭이 따로 잡혀 세로선이 이어지지 않는다
- **높이는 칸이 아니라 간격으로 키웠다** — 칸을 키우면 적 구성 넷과 진형 축 셋이 같이 넓어져 가로가 같이 커진다
- **판 여백은 이 창에서만 명시도를 한 단 올려 먹게 한다**(`.modal-box.depart-box`) — 창 공통 `.modal-box` 를 고치면 스킬 창 · 해고 창의 여백까지 같이 바뀐다

⚠ **ADR-0078 의 읽는 순서(「맨 왼쪽 — 누구와 싸우나 → 어떻게 세우나 → 갈까」)를 뒤집는다** — 경고한 뒤 사용자 지시를 따랐다.

## 파급

- CSS — `.dw-body` 가 flex → 격자(`minmax(0, 1fr) auto`) · `.dw-body > *` · `.dw-c2` · `.dw-r2` 신설 · `.fp-row` · `.dw-body .fp-row` 삭제 · `.foe-box` · `.fm-box` 의 옛 세로 가림막 삭제 · `.foe-h, .fm-h, .dw-h` 아래 여백 12 · `.depart-box` → **`.modal-box.depart-box`**(`.modal-box` 자체는 그대로)

- 실측 1600×800 — 창 높이 **504 → 548px**(+44 · ko / en / Ch7-4 / 파티 없음 같다) · 열 950 / 520 · 띠 7장 · 적 4칸이 각각 한 줄 · 가로 스크롤 없음
