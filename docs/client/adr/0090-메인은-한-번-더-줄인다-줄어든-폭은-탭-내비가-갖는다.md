# ADR-0090 — 메인은 한 번 더 줄인다 · 줄어든 폭은 탭 내비가 갖는다

## 결정

메인(탭 내용)은 한 장 안에서 **한 번 더 통째로 줄인다**. 메인을 크게 그리고 줄여서 상단바 아래 세로에 맞춘다 — **모든 탭이 같은 비율**이고 배치는 그대로다. 줄어든 폭은 **탭 내비가 가져간다**.

- **줄이는 것** — `.main` 하나. 재생기 안의 로그 · 누적 창도 메인 안이라 같이 준다
- **안 줄이는 것** — 브랜드 · 상단바 · 탭 내비 · 툴팁(`#tooltip`) · 창 레이어(`#modal` — 스킬 트리 · 출정 창 · 해고) · 내비가 없는 화면(`#app.pregame` — 시작 · 프롤로그)
- 그날의 값 — 탭 내비 **330px** · 메인 **`zoom: .9`** (값의 SSOT 는 [src/ui/README.md](../../../src/ui/README.md) 크기 정책)

## 맥락

1600×800 실측(그날) — 캐릭터 탭의 `.main` 이 **82px** 스크롤했다. 세 단이 영웅 띠 144 · 네 칸 430(하한 · [ADR-0009](0009-세-가지-막대-정렬-칸-높이-세로-예산.md)) · 가방 192 에 간격 둘이라, **가방 아래 줄이 탭 내비의 「새 게임」 줄보다 아래로 내려갔다**. 같은 날 선술집 65 · 탐험 50 · 자원 25 · 관전(넓게) 129px 도 넘쳤다 — ADR-0087 파급이 「열린 것」으로 남긴 목록이다.

사용자 지시는 **「왼쪽 탭 넓이를 오른쪽으로 늘리고, 비율적으로 오른쪽 내용물이 줄어들게」** 였고, 확인 질문에 **「캐릭터 탭을 맞춰 줄이는 만큼 다른 탭들도 같은 비율로 줄어드는 것」** 으로 답했다.

## 근거

- **폭만 줄여서는 안 준다** — DOM 은 좁아지면 옆으로 눌리지 크기가 줄지 않는다. 세 단의 높이는 폭과 무관하다. 실측: 내비 260px → 79px · 340px → 81px 스크롤(그대로)
- **배율은 세로가 정한다** — 캐릭터 탭의 설계 세로 834 를 메인 칸 752 에 넣는 배율은 ≈ .9017 이고, 반올림한 **.9** 에서 설계 세로가 836(여유 2px)이다. **내비 폭은 따로 고르는 값**이다 — 메인의 설계 폭을 줄이기 전(1412)과 같게 두는 **330** 을 골랐다(1270 ÷ .9 = 1411). 그래야 배치가 지금 비율 그대로 준다
- **전 탭이 한 번에 닫힌다** — 실측 1600×800 · ko/en: 캐릭터 · 선술집 · 탐험 · 자원 **0** · 원정 · 강화 · 상점 · 연구 · 도감은 0 그대로 · 관전(넓게) 129 → 45
- **`transform` 이 아니라 `zoom`** — `transform` 은 레이아웃에 안 걸려서 메인에 고정 설계 크기와 그것을 감싸는 칸이 따로 든다. `zoom` 은 칸 폭 1270 안에서 내용을 1411 로 레이아웃한다. ADR-0087 이 한 장에 `zoom` 을 버린 사유(좌표 보정)는 **메인 안에 해당하는 코드가 없어** 안 걸린다 — 마우스 좌표를 쓰는 곳은 툴팁(`tip.js:stagePoint` · 한 장 직속)과 진형 드래그(`app.js:bindFormDrag` · 출정 창 = `#modal`)뿐이다

**버린 안**

1. **왼쪽 탭만 넓힌다** — 위 실측대로 넘침이 안 닫힌다
2. **세로를 깎는다**(네 칸 하한 430 해제 + 띠 · 가방 여백 압축) — 글자 100% 를 지키지만 캐릭터 탭 하나만 닫히고, ADR-0009 의 하한(2026-09-08 사용자 지시)을 되돌린다. 하한만 걷으면 52px 가 남는다(실측)
3. **캐릭터 탭만 줄인다** — 탭마다 글자 크기가 달라진다
4. **내비 188 유지 · 메인만 .9** — 넘침은 같이 닫히지만 메인 설계 폭이 1569 로 넓어져 배치가 바뀐다. 사용자 지시는 왼쪽을 넓히는 쪽이었다

## 파급

- `style.css` 셸 절 — `#app` 첫 열 188 → 330 · `#app:not(.pregame) > .main { zoom: .9 }` 신설
- [src/ui/README.md](../../../src/ui/README.md) 크기 정책 — 「메인은 한 번 더 줄인다」 줄 · 선술집 · 탐험 · 관전 실측
- SCREEN_DESIGN §2 「탭 내비」 「메인」 · §8 자원 · §8-1 선술집 · §8-4 탐험의 스크롤 문장
- JS · i18n · 세이브 · 단정 무변동
- ⚠ **열린 것**
  - **글자가 한 번 더 준다** — 가장 작은 글자(`--fs-2xs` 9px)가 1600×800 에서 8.1px · 1366×768 에서 약 6.5px. ADR-0087 의 「최소 배율이 없다」와 겹친다
  - **탭 내비에 빈 폭이 크다** — 메뉴 글자만 선다
  - **창 레이어(100%)와 탭(90%)의 글자 크기가 갈린다**
  - **관전(넓게)은 45px 이 남는다** — 아레나가 메인 전폭의 화면비라 설계 세로가 늘어난 만큼만 준다
  - **여유 2px** — 캐릭터 탭의 세 단이 더 자라면 다시 스크롤한다
