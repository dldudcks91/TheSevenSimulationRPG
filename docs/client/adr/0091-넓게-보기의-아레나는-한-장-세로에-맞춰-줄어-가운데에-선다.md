# ADR-0091 — 넓게 보기의 아레나는 한 장 세로에 맞춰 줄어 가운데에 선다 · 비는 2.33 그대로

| | |
|---|---|
| **상태** | 확정 · 2026-09-11 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (제안 후 확정) |
| **대체** | [ADR-0018](0018-아레나가-메인-칸을-꽉-채운다-높이는-420-고정.md) 중 **폭**만 (메인 칸 전폭 → 한 장 세로에 맞춘 고정 폭 · 가운데). 「높이 = 폭 ÷ 2.33」은 그대로 산다 |
| **대체됨** | [0095](0095-넓게-보기의-아레나는-판-전폭이다-가방은-새-게임-줄에-붙는다.md) — 넓게 보기의 아레나가 **판 전폭 · 남는 세로**가 됐다(비를 안 지킨다) — 2026-09-11 |

## 결정

넓게 보기의 아레나는 메인 칸을 꽉 채우지 않는다. **화면비 2.33 : 1 을 지킨 채 통째로 줄여 판 가운데에** 세운다 — 한 장 세로(아래 가방까지)에 들어가는 높이에서 폭이 나온다. 좌우에 남는 자리는 전투 판의 바탕이다.

- 카드 크기 · 진형 · 헤드 · 나눔 보기는 그대로다
- 그날의 값 — 폭 **1184px** · 높이 **508**(설계 크기). 값의 SSOT 는 [src/ui/README.md](../../../src/ui/README.md) 크기 정책

## 맥락

[ADR-0090](0090-메인은-한-번-더-줄인다-줄어든-폭은-탭-내비가-갖는다.md)(메인 90%) 뒤 1600×800 실측(그날) — 원정 전투(넓게 보기)의 `.main` 이 **45px** 스크롤했다. 세로는 헤드 34 · **아레나 1320×567** · 가방 190 에 여백이었다. 아레나 안에서 카드 두 줄과 VS 가 차지하는 높이는 **325** 이고 위아래 약 107px 씩이 배경이었다. 나눔 보기는 스크롤이 없었다.

사용자 지시 — **「탭은 내비두고 전투화면 크기를 좀 줄이면서 올려야」**. 두 안(위아래만 깎기 · 통째로 줄이기)을 스크린샷으로 놓고 **통째로 줄이기**를 골랐다.

## 근거

- **닫는 데 필요한 것은 아레나 높이 45px 이다** — 카드는 아레나 안에서 세로 가운데 정렬이라 높이를 줄여도 VS 를 축으로 한 카드 자리가 안 흔들린다
- **비를 지킨다** — 2.33 : 1 은 2026-09-03 사용자 지시(ADR-0018)로 나눔 보기가 실제로 서는 비를 넓게에도 옮긴 값이다
- **508 은 한 장 세로 예산에서 나온다** — 메인 설계 세로 836 − (메인 여백 40 · 판 여백 21 · 헤드 34 + 10 · 단 사이 14 · 가방 190) = **527** 이 상한이고 여유 17px 을 두었다. 폭 = 508 × 2.33 ≈ 1184
- **진형 봉투 안이다** — ADR-0083 의 `여백 + step ≤ 59.5` 는 아레나 높이 430 에서 잰 식이라 508 에서는 여유가 더 있다

**버린 안**

1. **위아래만 깎는다**(폭은 판 전부 · 비 2.6 : 1 · 1337×514) — 좌우 빈 여백이 안 생기지만 09-03 에 정한 비를 바꾼다
2. **메인 배율을 더 줄인다** — 모든 탭의 글자가 같이 준다(ADR-0090 이 이미 90%)
3. **헤드 · 가방 여백만 압축한다** — 걷을 수 있는 여백이 45px 에 못 미친다

- [src/ui/README.md](../../../src/ui/README.md) 크기 정책 「관전 아레나」 줄 · SCREEN_DESIGN §4-2 「아레나」

- ⚠ **열린 것**

  - **배경 그림이 전보다 작게 보인다** — 카드는 그대로라 카드가 차지하는 비중이 커진다
