## 결정

ADR-0092 가 넓게 보기에 붙였던 모양 — **아레나 왼쪽(로그 열을 뺀 폭 · 비 2.33) + 오른쪽 로그 열** — 을 **나눔 보기**로 옮긴다. **넓게 보기는 ADR-0091 로 되돌린다** — 아레나 1184×508 판 가운데 · 로그 / 누적은 창.

- 나눔 보기의 카드 · 진형 간격은 **넓게 보기와 같다**(카드 226 · 초상 101 · step 21 · VS 여백 38). 옛 축소 규칙을 걷는다
- 넓게 보기에 로그 창 · 창 열림 상태(`win`) · `Esc` 가 돌아온다 — ADR-0019 가 다시 선다
- 그날의 값 — 나눔 보기 아레나 **989×424** · 열 **334×424** · 넓게 보기 아레나 **1184×508**(설계 크기). 값의 SSOT 는 [src/ui/README.md](../../../src/ui/README.md) 크기 정책

## 맥락

ADR-0092 를 적용한 화면을 본 사용자 지시 — **「지금 뷰를 split view 로 사용하고 기존 와이드뷰는 롤백」**. ADR-0092 는 커밋되기 전에 거둬졌다.

## 근거

- **두 보기가 서로 다른 일을 한다** — 넓게 = 전투를 크게 본다(로그는 필요할 때 창) · 나눔 = 전투와 로그를 나란히 본다. ADR-0092 로는 둘 다 로그 열을 가져 차이가 아레나 · 카드 크기뿐이었다
- **옛 나눔 보기의 축소는 아레나 높이 304 가 강제한 것이었다** — 카드를 200/76 으로 줄이고 진형 간격을 좁혀도 창 뱃지가 아레나 밖으로 나가던 자리였다(style.css 주석의 「선행 버그」). 424 에서는 넓게 보기와 같은 규격이 들어간다

**버린 안**

1. **ADR-0092 를 유지한다** — 넓게 보기가 로그 창을 잃는다
2. **나눔 보기를 옛 크기로 둔다** — 사용자가 이 모양을 나눔 보기로 쓰겠다고 했다

## 파급

- `battle.js` — 로그 창 마크업 · `state.win` · `Esc` · 배치별 버튼 뜻(넓게 = 창 여닫기 · 나눔 = 판 고르기) · 판 DOM 을 창 ↔ 열로 옮기는 `paintLayout` 을 ADR-0092 이전으로 되돌린다
- `app.js` — `resume` 의 `win` 세 곳 복원
- `style.css` — `.battle-body.split` 격자 · `.arena` 폭 1184 · 가운데 복원 · `.battle-body.split .arena` 는 폭만 격자 칸에 맡긴다(비 2.33 유지) · 나눔 전용 카드 · 진형 간격 규칙 삭제 · `.bw-box` · `.battle-side[hidden]` 복원
- SCREEN_DESIGN §2 「창 레이어」 · §4-2 「로그 / 누적」 · §10 은 ADR-0092 이전 문장으로 · §4-2 「아레나」 는 나눔 배치 설명만 새로
- ADR-0019 · ADR-0091 의 「대체됨」 칸을 비웠다(ADR-0092 가 철회돼 다시 선다)
- **i18n · 세이브 · 단정 무변동**
- ⚠ **열린 것**
  - **나눔 보기에서 가방 아래 약 100px 이 빈다**
  - **보기를 바꾸면 가방이 84px 위아래로 움직인다**(넓게 508 · 나눔 424)
  - **진형 봉투** — ADR-0083 의 `여백 + step ≤ 59.5` 는 아레나 430 기준이라 나눔 보기 424 에서는 최악의 경우 뱃지 줄이 약 2.5px 넘친다
