# ADR-0112 — 로그인하면 세이브가 Google 계정을 따라간다 · 클라우드는 통째로 올리고 갈리면 고른다

## 결정

Google 로그인(Firebase Authentication)을 붙이고, 로그인한 사람의 세이브는 Firestore `saves/<계정 id>` 문서 하나에 **통째로** 사본을 둔다. 로그인하지 않으면 지금처럼 브라우저에만 저장된다. 로컬 저장 시점은 그대로(상태가 바뀔 때마다)이고, 클라우드는 **일정 간격 · 브라우저 탭을 숨기거나 닫을 때 · 「지금 올리기」** 로만 올린다. 이 브라우저와 클라우드가 서로 모르는 진행을 들고 있으면 **고르게 한다**(두 번 눌러 확정) — 합치지 않는다. 같은 브라우저의 **다른 탭이 세이브를 쓰면 이 탭은 멈춘다**(닫는 길이 없는 창 · 새로고침으로 이어한다). 계정 버튼은 상단바의 언어 토글 앞에 선다 — 시작 화면과 게임 화면이 같은 자리다.

## 맥락

그날 세이브는 브라우저 localStorage 키 하나였고(GAME_DESIGN §8 「서버 없음 · 세이브 LocalStorage」), 게임은 GitHub Pages 로 공개돼 테스터들이 하고 있었다. 테스터의 진행은 각자의 브라우저에만 남아 개발자가 볼 수 없었고, PC 나 브라우저를 옮기면 처음부터였다. 같은 브라우저에서 탭 두 개를 열면 둘이 번갈아 세이브 전체를 덮어써 한쪽 진행이 사라졌다 — 다른 탭의 저장을 알아채는 코드가 없었다.

## 근거

- **목적은 세이브 이어하기 하나다** — 치트 방지 · 랭킹 · 거래가 아니다. 그래서 서버가 판정을 갖는 구조(서버 권위)가 아니라 **문자열 보관함**이면 된다. 서버 · DB 를 직접 운영하지 않는다 — Firebase 무료 등급(Spark)은 결제 수단이 없어 한도를 넘으면 청구가 아니라 멈춤이다
- **Drive 앱 폴더를 안 고른 이유** — 세이브가 플레이어 Drive 에 있어 개발자가 못 보고, 토큰이 1시간마다 만료돼 다시 허락을 구해야 한다. 테스터 세이브를 콘솔에서 보는 것이 이 실험의 값이다
- **GitHub 에 저장하지 않는다** — Pages 는 읽기 전용이고, API 로 쓰려면 쓰기 토큰을 공개 코드에 넣어야 한다
- **통째로 · 병합 없음** — 세이브는 서로 물린 한 덩어리다(영웅 ↔ 착용 아이템 ↔ 번호표). 일부만 올리면 받은 쪽에서 앞뒤가 안 맞고, 필드별로 합치면 아이템 복제가 열린다. 리포트는 뺄 수 있었지만 루팅 리포트 확인이 코어 루프라 넣었다 — 크기 손잡이는 이미 `report_keep` 이 있다. Firestore 는 배열 안 배열(`formation.ranks`)을 못 담아 JSON 문자열 하나로 넣는다
- **로컬은 바뀔 때마다 · 클라우드는 모아서** — localStorage 쓰기는 비용이 없고 브라우저는 「닫을 때 저장」을 믿을 수 없어(강제 종료 · 크래시 · 절전) 로컬은 그대로 둔다. 클라우드 무료 한도는 쓰기 **횟수**(하루 2만)라, 원정 중 라운드마다 올리면 테스터 몇 명으로 한도에 닿는다. 간격은 게임 수치가 아니라 저장소 사정이라 CSV 가 아니다(ADR-0102 의 멈춤 문턱과 같은 선례) — 그날 1분
- **순서는 시각이 아니라 저장 번호(rev)** — 기기마다 시계가 다르다. 올릴 때 클라우드 번호가 이 브라우저가 마지막으로 맞춘 번호와 다르면 덮어쓰지 않는다(트랜잭션)
- **고르게 한다 · 두 번 누른다** — 한쪽을 고르면 다른 쪽이 덮인다. 되돌릴 수 없는 행동은 두 번 누른다(§3 새 게임 덮어쓰기와 같은 규칙). 창을 닫으면 고르지 않은 것이다 — 올리기가 멈춘 채 계정 버튼이 「세이브 선택」을 든다. 닫는 것을 로그아웃으로 치는 안은 버렸다 — 창 닫기가 결정을 만들면 창 레이어의 「닫기 = 아무 일도 안 일어난다」가 깨진다
- **이 브라우저가 마지막으로 맞춘 뒤 안 바뀌었으면 묻지 않고 받는다** — 다른 기기에서 진행한 것을 가져오는 가장 흔한 경우라, 거기서 창이 뜨면 잡음이다
- **받으면 새로고침한다** — 도는 원정 · 재생기 · 화면 상태를 새 세이브에 맞추는 가장 짧은 길은 켜는 길을 한 번 더 타는 것이다. 받은 세이브에 돌던 원정은 끊긴다 — 게임을 끄면 원정이 끊기는 규칙(GAME_DESIGN §9 09-14)과 같은 길이다
- **다른 탭은 멈춘다 · 그 창은 닫히지 않는다** — 창 레이어 「닫는 길 셋」(§2)의 **의도된 예외**다. 닫을 수 있으면 멈춘 탭이 다시 저장해 다른 탭의 진행을 덮는다. 멈추는 신호는 **다른 탭이 세이브를 쓴 순간**이다 — 열기만 한 탭은 아무것도 안 쓰므로, 두 탭 중 먼저 쓰는 쪽이 남고 다른 쪽이 멈춘다
- **SDK 는 로그인한 브라우저에서만 불러온다** — 로그인하지 않은 사람에게는 네트워크 의존이 늘지 않는다. 전에 로그인한 브라우저는 켤 때 계정 복원과 받기를 기다린다 — 기다림에 상한을 두고, 넘으면 이 브라우저 세이브로 켠 뒤 다음 눈금에 다시 붙는다(늦게 온 결과는 버린다 — 이미 연 세이브 위에 받은 사본을 쓰면 옛 상태가 클라우드를 덮는다)
