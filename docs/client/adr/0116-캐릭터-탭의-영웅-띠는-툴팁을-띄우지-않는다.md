# ADR-0116 — 캐릭터 탭의 영웅 띠는 툴팁을 띄우지 않는다

## 결정

캐릭터 탭 상단 영웅 띠의 카드에 마우스를 올려도 **유닛 툴팁이 뜨지 않는다**. 출정 창의 띠와 관전 유닛 카드는 그대로 뜬다. 띠는 한 함수이므로 부르는 쪽이 옵션 하나(`heroStrip(…, { tip: false })`)로 끈다.

## 맥락

ADR-0114 는 영웅 띠 두 자리(캐릭터 탭 상단 · 출정 창)에 같은 유닛 툴팁을 걸었다. 캐릭터 탭은 띠 바로 아래 네 칸이 고른 영웅의 기본 옵션 · 세부 옵션을 이미 찍는다. 띠 카드는 클릭하면 그 영웅을 고르는 자리다.

## 근거

- **같은 값이 두 번 선다** — 고른 영웅이면 툴팁이 아래 칸과 같은 값을 다시 찍는다. 다른 영웅이면 클릭 한 번으로 아래 칸이 그 영웅으로 바뀐다. 이 탭에서는 고르는 것과 올려 보는 것의 비용이 거의 같다
- **띠는 탭 맨 위다** — 뜬 카드가 아래 네 칸을 덮는다. 캐릭터 탭은 장착 · 비교를 하는 화면이라 가려지는 값이 보려던 값이다
- **출정 창은 남긴다** — 편성 띠의 클릭은 파티 넣고 빼기라 영웅을 「고르는」 동작이 없다. 거기서 영웅 값을 보는 길은 올려 보기뿐이다
- **버린 안** — 띠 전부에서 끄기: 출정 창에서 영웅 값을 보려면 창을 떠나야 한다

## 파급

- `app.js:heroStrip` 에 옵션 `tip`(기본 켜짐) · 캐릭터 탭 호출이 `tip: false`
- §2 유닛 툴팁의 서는 자리 · §5 툴팁 행
- i18n · CSS 변경 없음
