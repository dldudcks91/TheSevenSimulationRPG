# ADR-0118 — 스킬 설명창은 능력치 칩을 달고 고정 설명을 뗀다

| **대체** | — |
| **대체됨** | — |

## 결정

스킬 설명창(`tip.js:skillTipCard`)의 칩 줄에 **능력치 칩**을 더하고, 바닥의 **고정 설명**(`skill.csv:desc_*`) 줄을 뗀다.

- 능력치 칩 = 그 스킬의 스케일링 슬롯(`def.scales`)이 가리키는 능력치. 슬롯 순서 · 같은 능력치는 한 번 · 라벨은 `hero_attribute.csv:abbr`(ko/en 같다) · **계수 0 이어도 찍는다** · 숫자는 안 든다
- 순서는 출처 칩 → 태그 칩 → 능력치 칩. 능력치 칩은 태그와 섞여 읽히지 않게 색을 따로 든다
- 설명창은 문장(과 추가 피해 문장)에서 끝난다 — 그 아래는 「Alt 계산식」 각주뿐이다

## 맥락

설명창의 칩 줄은 출처(영웅 · 무기 · 전직)와 태그(`skill_tag.csv` — 오오라 · 함성 …)를 들었다. 어느 능력치가 스킬을 미는지는 **Alt 를 누르는 동안의 괄호 식**(ADR-0089)에만 있어서, 누르지 않으면 안 보였다.

바닥에는 `skill.csv:desc_*` 한 문장이 섰는데, 위의 문장이 같은 내용을 값까지 넣어 이미 말하고 있었다 — 사용자가 든 예는 배틀오더스의 「양 옆 아군의 최대 체력을 한동안 올린다」다.

## 근거

- **칩은 「무엇이」, 괄호 식은 「얼마나」** — 칩은 이름만 들어 기본 상태에서도 한눈에 읽힌다. 얼마나는 여전히 Alt 괄호 식이 숫자 옆에서 말한다
- **ADR-0089 버린 안 ①(별도 능력치 줄)을 되살리는 것이 아니다** — 그 안은 「힘 STR 42 · 피해 +84」처럼 **숫자를 든 줄**이라 ①어느 숫자의 풀이인지 다시 짝지어야 했고 ②슬롯이 여럿이면 줄이 늘었고 ③설명창이 늘 길어졌다. 칩은 숫자를 안 들어 ①이 없고, 이미 있는 칩 줄에 흘러 들어가 ②③이 없다
- **계수 0 도 찍는다** — 괄호 식의 「계수 0 인 항도 찍는다」와 같은 규칙이다. 축은 정해졌고 크기만 밸런스 몫이라, 계수로 거르면 계수가 전부 0 인 동안 칩이 하나도 안 선다
- **라벨은 약어다** — 괄호 식이 약어를 쓴다(ADR-0089). 칩이 이름(힘 · 민첩)을 들면 칩과 식이 다른 말로 같은 것을 가리켜 짝이 안 읽힌다
- **고정 설명을 뗀 이유** — 같은 말을 두 번 한다. 문장이 값까지 든 더 정확한 쪽이다. 스킬 창 액티브 줄은 2026-09-08 에 같은 이유로 고정 설명을 뺐고(ADR-0042 근거 「같은 말을 두 번 했다」), 그때 「고정 설명은 툴팁만 든다」로 남겨 둔 것을 이번에 설명창에서도 뗐다

## 파급

- CSS — `.tip-chip.attr` 신설 · `.tip-desc` 삭제(스킬 설명창 말고 쓰는 곳이 없었다)
- i18n 키 변화 없음 — 약어는 CSV 가 든다
- 개발용 URL — `?dev=tip&t=skill`(캐릭터 탭 액티브 카드의 설명창 · [src/dev/README.md](../../../src/dev/README.md))
- ⚠ 이날로 `skill.csv:desc_kr` · `desc_en` 을 읽는 화면이 없어졌다 — 컬럼과 `skill.js` 의 「비었나」 검사는 그대로 뒀다(데이터 정리는 `/client` · 기획 몫)
