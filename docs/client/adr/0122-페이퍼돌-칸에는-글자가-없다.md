## 결정

캐릭터 탭 장비 칸(페이퍼돌)의 착용 칸 8 에서 **부위 이름 글자**를 걷는다. 빈 칸은 부위 실루엣(그림이 없는 부위는 이모지) 하나, 찬 칸은 아이템 그림 하나다. 부위 이름은 빈 칸의 `title` 이 든다.

## 맥락

칸마다 아래에 `투구` · `무기` · `반지` 같은 부위 이름이 작은 글씨(`--fs-2xs`)로 섰다. 빈 칸은 ADR-0025 로 부위 실루엣을 깔고 있었고, 실루엣은 글씨와 안 겹치게 칸 위쪽 영역에 갇혀 있었다.

사용자 지시: 「장비창에서 글씨 다 빼」.

## 근거

- **부위는 그림이 이미 말한다** — 빈 칸은 실루엣(ADR-0025), 찬 칸은 아이템 그림과 툴팁. 배치도 신체 위치 그대로(투구 위 · 신발 아래)라 칸 자리 자체가 부위다
- **스킬 칸과 같은 문법** — 캐릭터 탭 액티브 칸도 칸 안은 그림 하나다(ADR-0040)
- **그림이 칸 가운데로 온다** — 글자 자리(아래 14px)를 비워 두던 실루엣이 칸 가운데에 서고, 찬 칸 그림과 빈 칸 실루엣을 **같은 크기**로 맞춘다
- **`title` 은 빈 칸만** — 찬 칸에는 아이템 툴팁이 뜨므로 `title` 을 달면 브라우저 기본 툴팁이 겹친다(관전 유닛 카드에서 `title` 을 걷은 것과 같은 이유)
- ⚠ 투구 · 목걸이는 실루엣 그림이 없어 **흐린 이모지** 하나로 남는다 — 그림이 들어오면 해소된다

## 파급

- CSS — `.pd-label` 삭제 · `.pd-cell.art` 의 아래 여백과 끝 정렬 삭제 · 찬 칸 그림 크기를 실루엣과 맞춘다
- `src/ui/README.md` 의 `--fs-2xs` 쓰임 목록에서 페이퍼돌 라벨이 빠진다
- 패널 제목 「장비」와 「접사 죄종」 소제목 · 칩은 그대로다
