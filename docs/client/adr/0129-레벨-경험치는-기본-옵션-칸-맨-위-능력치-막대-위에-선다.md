# ADR-0129 — 레벨 · 경험치는 기본 옵션 칸 맨 위, 능력치 막대 위에 선다

## 결정

캐릭터 탭 「기본 옵션」 칸의 **맨 위**(제목 바로 아래 · 능력치 7 막대 위)에 레벨 · 경험치 한 벌을 둔다 — 한 줄(왼쪽 `Lv.n` · 오른쪽 `경험치 현재 / 필요`) + 그 아래 **칸 폭 전부를 쓰는 얇은 막대**. 능력치 막대와는 선 없이 간격으로만 가른다. **만렙이면 숫자 자리에 `MAX` 를 찍고 막대를 가득 채운다** — 줄은 사라지지 않는다. 액티브 스킬 블록은 그만큼 내려간다.

## 맥락

그날 캐릭터 탭은 고른 영웅의 레벨을 어디에도 찍지 않았다. 영웅 띠 카드의 위칸은 하는 일 · 이름뿐이고(§5), 레벨이 든 유닛 툴팁은 캐릭터 탭 띠에서 뜨지 않는다([ADR-0116](0116-캐릭터-탭의-영웅-띠는-툴팁을-띄우지-않는다.md)). 경험치 막대의 흔적(`app.js:xpNext` · `style.css:.bar.xp`)은 부르는 곳 없이 남아 있었다. 사용자가 「액티브 스킬을 좀 내리고 레벨 · 경험치를 넣자 — 기본 옵션 위냐 아래냐」를 물었다.

## 근거

- **유닛 툴팁과 같은 순서다** — 툴팁은 이름 · 소속(레벨이 여기 든다) → 기본 옵션 막대 → 대표값 순이고, 툴팁은 캐릭터 탭 표기를 따른다([ADR-0114](0114-유닛-툴팁은-캐릭터-탭-표기를-따른다-Alt-를-누르면-세부-옵션이-선다.md)). 캐릭터 탭만 레벨을 막대 아래에 두면 같은 영웅을 두 자리에서 거꾸로 읽는다
- **버린 안 — 막대 아래(액티브 스킬 위)** — 막대와 액티브 스킬 사이의 선은 하나(소제목 윗선)라는 규격이 있다. 그 사이에 끼우면 선을 하나 더 긋거나, 선 없이 막대에 붙어 **경험치 막대가 여덟째 능력치로 읽힌다**
- **성질이 다르다** — 능력치 7종은 타고난 값이라 장비로도(`attr_equip_bonus` = 0) 레벨로도(R83) 안 변한다. 이 칸에서 시간이 가며 바뀌는 값은 레벨 · 경험치뿐이라 머리에 선다
- **버린 안 — 영웅 띠 카드에 얹기** — 위칸은 한 줄 고정이고 좁으면 「하는 일」부터 말줄임된다(§5). 레벨을 더 얹을 자리가 없다
- **만렙에 줄을 걷지 않는다** — 걷으면 만렙 영웅을 고를 때만 막대 · 스킬 블록이 한 줄 올라가, 영웅을 바꿀 때마다 칸이 흔들린다

## 파급

- i18n `ch.lv` · `ch.xp` · `ch.xp.max` · CSS `.ch-xp` · `.ch-xp-line` · `.ch-lv` · `.ch-xp-n` · `app.js:xpBlock` — 부르는 곳이 없던 `xpNext` · `.bar.xp` 를 다시 쓴다
- 경험치 막대는 능력치 막대와 **시작 x · 두께**로 갈린다(칸 폭 전부 · 더 얇다) — 약어 배지도 안 단다
