## 결정

영웅 · 몬스터 유닛 툴팁에서 **이름 줄과 소속 줄**(영웅 = 직업 · 레벨 · 죄종 · 등급 / 몬스터 = 직업 · 등급)을 뺀다. 카드는 「기본 옵션」 열 머리부터 시작한다. 무엇의 툴팁인지는 **윗변 색**과 **붙은 자리**([ADR-0120](0120-유닛-툴팁은-커서가-아니라-올린-카드-옆에-선다.md) — 올린 카드 바로 옆)가 말한다.

## 맥락

사용자가 원정의 유닛 툴팁이 너무 크다며 크기 · 글씨를 줄이고 이름 · 소속을 빼라고 지시했다 — 「어차피 캐릭터 머리에 써 있다」. 이날 관전 카드의 이름 줄은 영웅 = 이름 + `Lv.n · 직업`, 몬스터 = 이름 + 정예 · 보스 라벨(일반은 이름뿐)이었고, 출정 창 띠 카드의 위칸은 하는 일 + 이름이었다. 툴팁은 ADR-0120 으로 이미 그 카드 바로 옆에 붙어 떴다.

## 근거

- **같은 글자가 한 뼘 안에 두 번 선다** — 툴팁이 카드 옆에 붙어 뜨므로 이름은 바로 옆 카드에 있다
- **카드가 두 줄만큼 낮아진다** — 크기를 줄이라는 요청의 한 몫이다
- **ADR-0115 의 근거가 무너진다** — 그 결정은 「머리글(「영웅」 · 「몬스터」)은 이름 색과 소속 줄이 대신한다」였다. 머리글 없음은 그대로 두고, 대신하던 줄까지 걷는다

## 파급

- ⚠ **잃는 것** — 영웅의 **죄종**과 **등급 이름**은 관전 화면에서 글자로 안 남는다(등급은 윗변 색만) · 출정 창 띠에서는 **직업 · 레벨**도 안 보인다(띠 카드는 하는 일 + 이름) · 몬스터의 **「일반」** 표기
- `tip.js` — `heroTipCard` · `monsterTipCard` 의 머리 · `classOf` · `GRADE_KEY` 삭제 · i18n `tip.hero.lv` 삭제 · CSS `.tip-unit-head` 삭제
- 같은 요청으로 유닛 툴팁 카드에 배율을 건다 — 값은 [src/ui/README.md](../../../src/ui/README.md) 크기 정책
