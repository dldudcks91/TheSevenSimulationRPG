# ADR-0142 — 제련소는 제작 · 강화 · 크래프트를 위쪽 탭으로 가른다

## 결정

제련소(강화 탭)의 세 작업을 **한 화면에 나란히 두지 않는다.** 패널 머리와 배치 줄 아래에 **위쪽 탭**(제작 · 강화 · 크래프트)을 세우고 **고른 작업 하나만** 박스 끝까지 편다. 기본은 제작이고, `?tab=forge&fg=make|up|craft` 로 그 탭을 고른 채 연다.

## 맥락

2026-09-15 기획이 물약을 확정했다(GAME_DESIGN §9 09-15 · item_design §7-4 · battle_design §7-1) — 물약은 제련소의 **제작** 안에서 만든다. 그래서 제작 칸이 장비 제작(부위 · 레벨대 · 재료 세 줄)에 더해 **물약 단계 목록**까지 들게 됐다.

그날 화면은 ADR-0124 대로 세 칸이 좌우로 나란히 서서 칸마다 폭이 박스의 1/3 이었고, 강화 칸은 「목록 | 작업 패널」 2단을 세로로 접은 채였다. ADR-0124 는 「제작 칸이 실제 목록을 받는 날 폭이 모자라면 이 결정을 다시 연다」고 열어 두었다.

## 근거

- **폭을 되찾는다** — 제작이 장비 · 물약 두 갈래를 들고 강화가 「목록 | 작업 패널」을 펴려면 1/3 폭으로는 못 선다. 다시 여는 조건(0124 파급의 ⚠)이 그대로 성립했다
- **사용자 지시가 결정의 본체다** — 「같은 화면에 넣지 말고」
- **0124 가 세그먼트를 버린 근거가 무너졌다** — 「셋 중 둘이 미착수라 세그먼트를 넘기면 대부분 빈 화면」이었는데, 제작이 실물 둘을 들면서 빈 칸은 크래프트 하나만 남았다
- **세 칸을 두고 제작 칸 안에서 다시 접는 안**은 같은 폭 문제를 한 단 더 깊은 곳으로 미룰 뿐이다 — 장비와 물약이 1/6 폭씩 갖게 된다

## 파급

- CSS — `.fg-split` 이 탭 본문 한 칸이 된다 · `.fg-box .fg-work` 세로 접기와 `.fg-box .fg-list` 높이 제한을 걷는다 · `.fg-tabs` 신설
- app.js — 화면 상태 `forgeTab` 신설 · 미착수 칸 헬퍼(`todoBox`)가 크래프트 탭의 안내 한 줄로 줄었다
- i18n — 탭 이름은 기존 `fg.seg.make` · `fg.seg.up` · `fg.seg.craft` 를 그대로 쓴다(새 키 없음)
- 개발용 URL `&fg=` 신설 — 탭은 클릭으로만 바뀌어 헤드리스가 못 닿는다 (SCREEN_DESIGN §10)
- ⚠ 크래프트 탭은 여전히 「미착수」 배지 + 안내 한 줄이다 (R97)
