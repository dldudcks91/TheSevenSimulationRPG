# ADR-0146 — 연구의 가지는 카드 하나다 · 카드 머리에 건물 그림이 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-15 |
| **화면** | [SCREEN_DESIGN §13-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「아래로 같은 카드안에 들어있거나 하는식으로 해야할것같은데? 맨위에다가 해당 건물 그림간단하게 넣고」 |
| **대체** | — *(ADR-0145 를 뒤집지 않는다 — 가지 8 · 가지끼리 선 없음은 그대로이고 열을 카드로 감싼다)* |
| **대체됨** | — |

## 결정

연구의 가지 하나를 **카드 하나**로 감싼다 — 카드 머리에 **건물 그림**, 그 아래 가지 이름 · 완료 수, 그 아래 노드가 위에서 아래로 든다. 건물 그림은 가지마다 한 장인 **단색 실루엣(SVG) 목업**이다 — 원정 성문 · 탐험 언덕 위 망루 · 제련소 굴뚝 작업장 · 선술집 간판 단 집 · 상단 짐마차 · 자원 갱도 입구 · 도감 기둥 선 서고 · 파티 전술 작전 천막.

## 맥락

ADR-0145 대로 그린 첫 화면은 가지 8 이 테두리 없는 열이었고, 노드 카드만 떠 있어 어느 노드가 어느 가지에 속하는지를 열 머리의 밑줄 하나가 들었다. 그날 저장소에는 가지에 붙일 건물 아트가 없었다 — 건물이 그려진 그림은 한 장 뒤에 깔리는 배경(`backgrounds/town.webp`) 하나였다.

## 근거

- **사용자 지시가 결정의 본체다**
- **카드가 소속을 든다** — 열 머리의 밑줄 하나로는 노드가 가지에 묶여 보이지 않았다. 카드 테두리 안에 들면 「이 노드들이 한 가지다」가 설명 없이 읽히고, 카드 사이의 빈틈이 「가지끼리 안 잠근다」를 그대로 보인다
- **그림은 단색 실루엣으로 둔다** — 대안은 셋이었다. ①**이모지**(그림 없는 투구 · 목걸이가 떨어지는 폴백 — SCREEN_DESIGN §2 「아이템 그림」)는 기기마다 색 그림이라 화면 톤과 어긋난다. ②**배경 그림을 잘라 쓰기**는 8 가지 중 도감 · 파티 전술 · 자원에 해당하는 건물이 그림에 없다. ③**아트 발주**는 「간단하게」의 범위를 넘는다. 단색 실루엣은 글자색을 따라 테마를 타고 그래픽 최소화 계약(GAME_DESIGN §8)과 맞는다

## 파급

- CSS — `.rs-branch` 가 카드(배경 · 테두리 · 안쪽 여백)가 됐다 · `.rs-art` 신설
- mock.js — `RS_ART`(가지 id → SVG 문자열) · 가지마다 `art`
- app.js — `researchBody` 가 카드 머리에 그림을 붙인다
- ⚠ 그림은 목업이다 — 아트가 오면 `RS_ART` 만 이미지로 갈아 끼운다
