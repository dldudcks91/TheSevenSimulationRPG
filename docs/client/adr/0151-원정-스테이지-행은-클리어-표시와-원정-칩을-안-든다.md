# ADR-0151 — 원정 스테이지 행은 클리어 표시와 「원정」 칩을 안 든다

| | |
|---|---|
| **상태** | 확정 · 2026-09-15 |
| **화면** | [SCREEN_DESIGN §4-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「클리어 글씨 삭제」 · 「오른쪽 끝에 원정 글씨 삭제 — 이전 스테이지 클리어 필요는 삭제하지 말고」) |
| **대체** | — *(클리어 표시 · 「원정」 칩은 ADR 없이 §4-1 행 규격에만 있었다)* |
| **대체됨** | — |

## 결정

- **스테이지 행은 클리어 표시를 안 든다** — 제목 줄은 죄종 칩 · `Ch-스테이지 이름` 까지다
- **오른쪽 끝의 「원정」 칩을 걷는다** — 오른쪽 끝에는 **잠긴 행에만** 「이전 스테이지 클리어 필요」가 선다. 고른 행의 표시는 **테두리**(`.zone.on`)가 혼자 든다
- **부제 줄(위험도 · 예상 소요 · 원소)은 그대로 산다** · 행 높이 · 챕터 세그먼트도 그대로다

## 맥락

그날 스테이지 행은 제목 줄(죄종 칩 · 이름 · 깬 스테이지면 잔글씨 「클리어」) + 부제 줄(위험도 · 약 N분 · 원소)이었고, 오른쪽 끝에 풀린 행이면 「원정」 칩(고른 행은 밝아진다) · 잠긴 행이면 「이전 스테이지 클리어 필요」가 섰다. 「원정」 칩은 행 클릭이 「고른다」였던 시절(2026-08-27)의 표시였고, 행 클릭이 창을 여는 동사가 된 뒤(ADR-0084)에도 남아 있었다.

## 근거

- **「원정」 칩을 걷어도 누를 곳이 안 흐려진다** — 풀린 행은 행 전체가 눌리는 자리이고(커서 · 호버 테두리), 잠긴 행은 오른쪽 안내가 따로 말한다. 오른쪽 끝의 글자가 「잠겼다」 하나의 뜻만 갖게 된다
- **잠긴 행 안내를 남기는 이유** — 잠긴 스테이지를 그리는 근거가 「어디까지 가야 하는지가 보여야 한다」이고, 왜 못 누르는지를 말하는 자리가 이것 하나다

**버린 안** — 셋 다 같은 날 화면에 넣었다가 사용자 지시로 되돌렸다

1. **부제 줄(위험도 · 약 N분 · 원소)도 걷는다** — 올려 둔 스테이지의 강조색([ADR-0104](0104-위험도-조절은-출정-방식-칸에-선다.md))도 이 줄에 산다
2. **잠긴 행 안내도 같이 걷는다** — 사용자가 남기라고 했다
3. **챕터 세그먼트를 큰 박스로 · 목록 전폭을 채운다** — 칸을 똑같이 나누면 영어 `Ch5 Caverns of the Abyss` 가 1600 에서 말줄임으로 잘려, 이름이 긴 칸만 넓히는 격자(`minmax(max-content, 1fr)`)까지 갔다가 옛 크기(`.btn.sm`)로 되돌렸다

## 파급

- `app.js` — `renderExpIdle` 행에서 클리어 표시 · `.zone-pick` 칩을 뺐다(풀린 행의 오른쪽 칸은 빈다)
- `style.css` — `.zone-pick` · `.zone.on .zone-pick` 삭제
- `i18n.js` — 쓰는 곳이 없어진 `exp.cleared` · `exp.pick` 삭제
- ⚠ **열린 것** — **어느 스테이지를 깼는지가 목록에서 직접 안 보인다.** 다음 스테이지가 풀렸는지로만 읽힌다
