# ADR-0155 — 후보 카드의 죄종 칩은 그 죄종 색을 입는다

| | |
|---|---|
| **상태** | 확정 · 2026-09-18 |
| **화면** | [SCREEN_DESIGN §3](../SCREEN_DESIGN.md) · [§8-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「선술집에 나오는 영웅 카드에 폭식과 나태 같은 게 하얀색인데 → 각 죄종에 맞는 색으로」) |
| **대체** | [ADR-0023](0023-영웅에게-죄종-색을-주지-않는다.md) 중 **후보 카드 이름 줄의 죄종 칩**만 (「색을 잃고 글자만 남는다」 → **그 죄종 색**). 카드 윗변 · 능력치 막대가 등급 색이라는 것과 영웅 띠 · 관전 카드 · 스킬 창의 등급 색은 그대로 산다 |
| **대체됨** | — |

## 결정

후보 카드(`app.js:candidateCard` — 시작 화면 · 선술집 명단 · 수색 결과가 같은 카드다)의 칩 줄에서 **죄종 칩의 글자와 테두리를 그 죄종 색**(`mock.js:SINS` 의 `color`)으로 칠한다. 등급 칩이 등급 색인 것과 같은 문법이다. 카드의 다른 자리 — 윗변 · 능력치 막대 — 는 등급 색 그대로다.

## 맥락

2026-09-03(ADR-0023)부터 영웅의 정체성 색은 등급이었고, 이름 줄의 죄종 칩은 무채색(`--text-secondary`) 글자와 테두리였다. 후보 카드의 칩 줄에는 등급 칩(등급 색)과 죄종 칩(흰 글자)이 나란히 섰다. 선술집 탭에서는 같은 화면의 수색 칸 소문 칩 · 대기 영웅 칩도 무채색 죄종 칩이었다.

## 근거

사용자 지시다. ADR-0023 이 걷은 까닭(죄종 색 일곱이 화면마다 다른 뜻으로 읽힌다)이 있는 자리라는 점을 알린 뒤 지시를 따랐다.

- **칩 하나만 칠하는 이유** — 윗변 · 막대까지 죄종 색으로 돌리면 ADR-0023 이 등급에 준 자리(영웅의 정체성 색)를 통째로 뒤집는다. 칩은 글자가 이미 죄종을 말하는 자리라, 색을 입혀도 「이 영웅은 어느 죄종인가」 이상의 뜻을 싣지 않는다
- **후보 카드만인 이유** — 지시가 가리킨 것이 선술집의 영웅 카드다. 그 카드가 시작 화면 · 수색 결과와 **한 벌**이라(§3 「선술집 명단도 같은 카드다」) 세 자리가 함께 바뀐다. 한 벌을 가르는 쪽이 새 규칙을 만든다

## 파급

- `app.js:candidateCard` 의 죄종 칩에 인라인 색(`sinColor`) — 챕터 줄 · 리포트 정예 칩이 쓰던 방식 그대로. `style.css .sin-chip` 의 무채색 기본은 그대로다
- ⚠ 같은 탭의 **수색 칸 소문 칩 · 대기 영웅 칩**, 영웅 띠 · 관전 카드의 죄종 표기는 이 결정 밖이다 — 무채색으로 남는다
