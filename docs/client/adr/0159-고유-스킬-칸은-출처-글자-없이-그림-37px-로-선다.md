## 결정

후보 카드(시작 화면 · 선술집 명단 · 수색 결과)의 고유 스킬 칸에서 **출처 글자(「영웅」 / `Hero`)를 지운다** — 칸은 그림 + 이름 + 쿨 두 줄이다. 칸은 **위 여백 없이** 서고 그림은 **44px → 37px** 이다. 영어의 역할 줄 두 줄 자리는 걷는다. 스킬 설명창에도 출처 칩을 달지 않는다 — 카드 어디에도 출처가 안 선다.

## 맥락

같은 날 ADR-0156 으로 스킬 그림 아랫변을 초상 아랫변에 맞췄다. 한국어는 맞았고, 영어는 역할 줄이 두 줄로 접히는 직업(다섯 중 셋)이 있어 역할 줄이 늘 두 줄 자리를 잡았고 스킬 그림이 초상 아랫변보다 약 12px(보이는 크기) 아래였다.

스킬 칸은 그림(44px) 옆에 글 세 줄(출처 태그 · 이름 · 쿨)이 서고, 위 여백이 6px 였다. 1600×800 시작 화면 영어에서 잰 값 — 출처 글자만 지우면 12.1 → **11.2px**(칸 높이를 그림이 정해 글 한 줄이 빠져도 칸이 안 낮아진다). 위 여백 0 + 그림 37px 이면 영어 두 줄 직업도 **0** 이었다(한국어는 그대로 0). 그림만 31px 로 줄이는 안도 0 이었다.

ADR-0121 은 「출처 칩은 출처가 화면에 글자로 안 선 자리에서만 단다」였고, 후보 카드는 고유 태그가 글자로 서 있어 칩을 뗀 자리였다.

## 근거

사용자에게 셋을 보였다 — ① 위 여백 0 + 그림 37px(0) ② 그림만 31px(0) ③ 글자만 지우고 약 11px 어긋남을 둔다. 사용자가 ①을 골랐다.

- **그림을 31px 까지 줄이지 않은 이유** — 44px 는 「그림이 들어와도 읽히는 크기」(2026-09-03 사용자 지시)였다. 여백 6px 를 먼저 내면 그림은 16% 만 준다(31px 는 30%)
- **글자만 지우는 안을 버린 이유** — 목표(영어 두 줄까지 초상 안에)를 못 이룬다. 칸 높이는 그림이 정한다
- **출처를 툴팁에도 안 다는 이유** — 사용자 판단: 후보 카드에 서는 스킬은 고유 하나뿐이라 영웅 스킬로 읽힌다. ADR-0015 가 태그를 둔 까닭(「3칸 중 하나만 보이므로 왜 하나인지가 칸 안에서 답해져야 한다」)을 알린 뒤의 결정이다. 그래서 ADR-0121 의 한 줄 규칙에서 후보 카드는 **예외**가 된다 — 글자도 칩도 없다
