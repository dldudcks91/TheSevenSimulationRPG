# ADR-0160 — 스킬 그림은 두 줄 이름 높이(49px) · 영어는 윗줄 간격을 좁힌다

## 결정

후보 카드 고유 스킬 칸의 그림을 **37px → 49px** 로 키운다 — 스킬 이름이 두 줄로 접혔을 때 글(이름 두 줄 + 쿨) 높이와 같다. 한국어는 그 밖에 바꾸는 것이 없다(역할 줄과 스킬 칸 사이의 빈 자리가 줄어든다). **영어만** 이름 · 직업 · 역할 줄의 줄 간격을 좁혀(`line-height` 이름 1.3 → 1.1 · 직업 → 1.2 · 역할 1.35 → 1.2) 역할이 두 줄인 카드도 오른쪽 열이 초상 높이 안에 들게 한다. 칩 줄과 이름 사이 4px 띄움은 두 언어 모두 그대로다.

## 맥락

같은 날 ADR-0159 로 그림이 37px 가 됐다. 그날 본편 다섯 직업의 스킬 37개 중 이름이 두 줄로 접히는 것은 프레이어 오브 리제너레이션(`pri_regen`) 하나였고, 그때 글 높이는 약 48.7px 로 그림(37px)보다 컸다 — 글이 그림 위로 삐져나와 보였고, 영어 사제(역할도 두 줄)에 이 스킬이 붙으면 스킬 그림이 초상 아랫변보다 약 11px 아래였다.

1600×800 에서 잰 값 — 그림만 49px 로 키우면 한국어는 모든 카드에서 맞고(역할 줄과 스킬 칸 사이에 약 17px 빈 자리가 있었다), 영어는 역할이 두 줄인 카드에서 약 12px 어긋났다. 영어에서 이름 · 직업 · 역할 줄 간격을 위 값으로 좁히면 **37개 스킬 × 5개 역할 × 시작 화면 · 선술집 × 한국어 · 영어 모두** 스킬 그림 아랫변이 초상 아랫변과 같았다(차이 0).

## 근거

사용자에게 둘을 보였다 — ① 그림만 49px(영어 약 12px 어긋남 복귀) ② 그림 49px + 영어에서 칩 줄 · 이름 사이 띄움을 없애고 줄 간격을 좁힌다. 사용자는 「위 글씨와의 간격을 줄여서」 그림을 키우자고 했다.

- **칩 줄 · 이름 사이 4px 를 남긴 이유** — 2026-09-08 사용자 지시(「두 층이 한 덩어리로 읽힌다」)의 자리다. 이름 · 직업 · 역할 줄 간격만 좁혀도 12px 가 나와 이 띄움을 건드릴 필요가 없었다
- **영어만 좁히는 이유** — 한국어는 그림을 키워도 빈 자리가 남아 좁힐 까닭이 없다. 두 언어를 같이 좁히면 한국어 카드의 모양이 까닭 없이 바뀐다
- **49px 인 이유** — 지시가 「두 줄 이름이 나왔을 때와 높이를 맞춘다」였다. 그보다 작으면 두 줄 이름에서 글이 그림보다 커 보인다

## 파급

- `style.css` — `.ng-skill .ico` 49px · `html[lang="en"]` 에서 `.ng-name` · `.ng-cls` · `.ng-role` 의 `line-height`
- [src/ui/README.md](../../../src/ui/README.md) 스킬 아이콘 칸 크기 목록의 `.ng-skill .ico` 37 → 49
- ⚠ 스킬 이름이 세 줄로 접히거나 영어 역할이 세 줄로 접히는 것이 생기면 열이 초상보다 길어진다 — 그날 37개 스킬 · 다섯 직업에는 없었다
