# ADR-0169 — 페이퍼돌 착용 칸도 강화 단계를 든다

| | |
|---|---|

| **대체됨** | — |

## 결정

캐릭터 탭 페이퍼돌의 착용 칸도 **오른쪽 위에 강화 단계 `+n`** 을 단다 — 가방 칸과 같은 자리 · 같은 모양이고, 강화하지 않은 물건(0)에는 안 선다. 그래서 착용 칸의 글자는 **가방 칸과 같은 모서리 배지 둘**(위 `+n` · 아래 `Lv.n`)이 된다.

## 맥락

ADR-0168 로 착용 칸 오른쪽 아래에 아이템 레벨이 섰다. 강화 `+n` 은 가방 칸 · 리포트 드롭 칸에만 있었고 착용 칸에는 없었다 — ADR-0122 가 착용 칸의 글자를 전부 걷은 뒤로 강화 표시도 따라 빠진 채였다.

사용자 지시: 「강화 수치가 착용한 아이템에는 안 보여」.

## 근거

- **강화는 착용한 물건에 쌓인다** — 제련소는 착용품도 강화 대상에 넣는다(§8-2). 가장 많이 강화되는 것이 끼고 있는 물건인데 그 칸만 단계를 안 들면, 강화한 결과를 보러 갈 자리가 툴팁 하나뿐이다
- **가방 칸과 같은 문법** — 같은 물건이 가방에서는 `+3`, 끼면 사라지는 것은 「장착하면 강화가 풀린다」로 읽힐 수 있다. 자리 · 모양을 가방 칸과 똑같이 둔다
- ADR-0122 가 걷은 것은 칸 자리가 이미 말하는 **부위 이름**이었다. 강화 단계는 레벨과 같이 **개체값**이라 그림도 자리도 대신 말해 주지 못한다(ADR-0168 과 같은 근거)

## 파급

- CSS — `.pd-up` 을 `.inv-up` 과 한 규칙에 묶는다(자리 · 크기 · 색이 같다)
- i18n 키는 없다 — `+n` 은 가방 칸처럼 기호와 숫자뿐이다
