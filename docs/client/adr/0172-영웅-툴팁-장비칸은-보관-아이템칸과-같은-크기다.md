# ADR-0172 — 영웅 툴팁 장비 칸은 보관 아이템 칸과 같은 크기다

## 결정

영웅 툴팁의 장비 칸은 아래 보관(Stash · Inventory)의 아이템 칸과 **화면에서 같은 크기**로 보인다. 보관은 메인 배율 `.9`, 유닛 툴팁은 배율 `.85`를 따로 받으므로 툴팁 장비 칸의 설계값은 53px로 둔다. 1600×800 브라우저 실측은 보관 45.03px · 툴팁 45.05px다.

칸 사이 간격은 보관과 같은 4px다. 장비 첫 열은 `3칸 + 틈 2개` 너비만 들고, 기존 유닛 옵션 열의 278px 하한 때문에 생기던 좌우 빈 폭을 걷는다. Alt 세부 옵션 열은 기존 폭을 유지한다.

## 맥락

ADR-0171로 영웅 툴팁 첫 장을 페이퍼돌로 바꿨지만 캐릭터 탭의 60px 착용 칸을 그대로 가져왔다. 툴팁 배율을 적용해도 아래 보관 아이템 칸보다 크게 보였고, 3×3 장비 주위에는 기본 옵션 열의 폭이 남아 장비판이 게임의 조밀한 보관 UI보다 넓게 떠 보였다.

사용자 지시: 「장비창 좌우를 좀 줄여 게임에 맞추고, 툴팁 장비 칸 하나하나를 아래 아이템 칸과 똑같이」.

## 근거

- **같은 아이템 칸은 같은 크기다** — 착용 여부만 다르고 아이템을 빠르게 훑는 단위는 같다
- **배율 차이를 보정한다** — 같은 CSS px가 아니라 최종 화면에서 같은 크기여야 한다
- **세부 옵션 폭은 건드리지 않는다** — 긴 영문 능력치 이름과 값이 들어가는 열까지 줄이면 읽기 문제가 다시 생긴다

## 파급

- 툴팁 페이퍼돌만 53px · 4px를 쓰고 캐릭터 탭 페이퍼돌 60px · 8px는 그대로다
- 채운 칸 그림과 빈 칸 실루엣도 보관 그림의 보이는 크기에 맞춰 함께 줄인다
