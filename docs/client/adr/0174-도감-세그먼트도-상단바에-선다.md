## 결정

도감의 몬스터 · 캐릭터 · 아이템 · 스킬 세그먼트를 패널 안에서 빼고, 원정 세그먼트와 같은 **상단바의 crumb 바로 오른쪽**에 둔다. 패널 안에서 세그먼트와 짝을 이루던 「도감」 제목 줄은 통째로 걷는다.

## 맥락

사용자 지시 — 「codex의 monster, characters 얘네도 탭 위치를 expedition처럼 위로 올려줄 수 있나」. 도감의 네 버튼은 한 화면 전환 묶음이므로 몬스터 · 캐릭터만 떼지 않고 아이템 · 스킬까지 같은 자리로 옮긴다.

## 근거

- **같은 깊이의 전환은 같은 자리에 선다** — 원정 안의 편성 · 관전 · 리포트와 도감 안의 네 화면은 모두 왼쪽 주 탭 아래의 화면 전환이다
- **버튼 묶음을 나누지 않는다** — 몬스터 · 캐릭터만 상단으로 올리고 아이템 · 스킬을 패널에 남기면 같은 형제 화면의 조작 위치가 둘이 된다
- **패널 제목은 중복이다** — 상단바 crumb 가 이미 「도감」을 말한다. 버튼이 빠진 뒤 패널에 「도감」만 남기면 정보 없이 세로 한 줄을 쓴다

## 파급

- `app.js:renderCodex` 가 `.tab-seg`를 채우고, 패널의 `.panel-nav`를 만들지 않는다
- `.panel-nav`는 마지막 사용처가 사라져 CSS 규칙도 걷는다
- 도감 세그먼트 상태 · `?cx=` 개발 경로 · i18n · 세이브는 바뀌지 않는다
