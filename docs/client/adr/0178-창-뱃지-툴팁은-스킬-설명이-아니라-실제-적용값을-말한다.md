# ADR-0178 — 창 뱃지 툴팁은 스킬 설명이 아니라 실제 적용값을 말한다

## 결정

창 뱃지의 툴팁은 그 스킬의 시전 대상·쿨·일반 설명을 되풀이하지 않는다. 현재 유닛에게 실제로 적용된 효과만 짧게 말한다.

- 예: 스킬 설명이 「모든 아군의 공격력을 25% 증가시킨다」여도 창 툴팁의 효과 줄은 **「공격력 25% 증가」**다.
- 수치는 `skill.csv`의 원문이나 원값이 아니라 전투 타임라인 `buff` 이벤트의 `stat`·`v`를 쓴다. 능력치 계수로 효과값이 바뀌면 바뀐 값이 보인다.
- 증가·감소의 방향도 실제 효과를 따른다. `period_pct` 양수는 「행동 주기 감소」, `dr_pct` 양수는 「받는 피해 감소」다.
- 숫자가 없는 표식도 실제 상태만 말한다. 도발은 공격 대상 고정, 결투는 시전자만 공격, 경직은 행동 게이지 정지다.
- 툴팁의 머리에는 창을 만든 스킬 이름과 아이콘이 남고, 아래에는 이 효과 줄과 남은 시간(오오라는 「상시」)이 선다.

## 이유

스킬 설명창은 「무엇을 시전하는가」를 설명하고, 창 뱃지 툴팁은 「이 유닛에게 지금 무엇이 걸려 있는가」를 확인하는 자리다. 같은 긴 문장을 두 곳에 복사하면 대상·쿨 같은 이미 끝난 정보가 현재 상태보다 앞선다. 전투가 확정한 실효값을 직접 읽어야 화면과 계산도 어긋나지 않는다.

## 구현

- `battle.js:effectSummaryText` — `buff.stat`·`buff.v`를 상태 한 줄로 변환
- `battle.js:effectTipCard` — 이름 / 실제 적용 효과 / 남은 시간
- `i18n.js:bt.effect.*` — 효과 종류별 짧은 한국어·영어 문장
