## 결정

아이템 도감의 방어구 탭에서 **빈 칸 실루엣 묶음을 제거**한다. 방어구 탭에는 투구 · 갑옷 · 장갑 · 신발 · 목걸이 · 반지의 실제 아이템 베이스 묶음만 편다.

## 맥락

빈 칸 실루엣은 장비가 없는 착용 칸의 부위를 알아보게 하는 화면 자산이다. 아이템 베이스를 분류해 보는 도감에서는 실제 아이템 묶음과 나란히 놓여 별도 재고처럼 보였다. 사용자 지시 — 「empty slot silhouettes는 없어도 될 것 같다」.

## 근거

- 아이템 도감은 실제 무기 · 방어구 베이스를 확인하는 화면이다
- 빈 칸 실루엣은 착용 화면에서 이미 실제 용도로 확인할 수 있다
- 도감에서만 걷고 `slotArt`와 빈 착용 칸 표시는 유지한다

## 파급

- 방어구 탭의 마지막 「빈 칸 실루엣」 묶음과 전용 i18n 문구를 제거한다
- `mock.js:SLOT_ART_PARTS`와 실제 착용 칸의 빈 슬롯 그림은 바뀌지 않는다
