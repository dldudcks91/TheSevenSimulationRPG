# ADR-0182 — 영웅 툴팁은 장비 200 · 세부 옵션 220이고 장비 hover가 옵션을 연다

## 결정

영웅 툴팁의 열 폭을 **장비 200px · 세부 옵션 1 220px · 세부 옵션 2 220px**로 줄인다. 장비 칸 자체는 53px · 간격 4px를 유지하고 3×3을 200px 열 가운데에 둔다.

첫 장 높이는 계속 세부 옵션 1과 같다. 다만 세부 옵션 열의 새 폭이 220px이므로, 기본 상태의 보이지 않는 높이 기준도 **220px 폭**으로 잰다.

Alt를 누른 채 찬 장비 칸에 커서를 올리면 기존 §6 「착용 중」 아이템 카드를 별도 설명창으로 띄운다. 이름 · 아이템 레벨/무기군 · 밑수 · 접사 · 담은 스킬은 기존 아이템 카드와 완전히 같은 렌더러를 쓰며 비교 카드는 붙이지 않는다. 빈 칸은 설명창을 열지 않고, 칸에서 나가거나 Alt를 떼면 장비 설명창을 닫는다. 장착·해제 클릭은 만들지 않는다.

## 근거

- 278px 세 열은 한 번에 펼쳤을 때 가로를 과하게 썼다. 장비는 3×3이 드는 최소 여유를 남기고, 글줄이 있는 세부 옵션은 그보다 20px 넓힌다
- 장비 그림만으로는 개체의 밑수와 접사를 확인할 수 없다. 이미 캐릭터 탭에서 쓰는 「착용 중」 아이템 카드를 재사용해야 두 화면의 표기가 갈리지 않는다
- 장비 설명창은 영웅 툴팁과 별도 위치에 떠야, 설명창이 추가될 때 기존 장비 칸이 움직여 hover가 끊기는 왕복 깜빡임이 없다

## 파급

- Basic Stats 렌더링 코드는 계속 남고 영웅 툴팁에서는 숨는다
- 몬스터 · 일반 아이템 · 스킬 툴팁 크기는 바뀌지 않는다
- Alt를 누르지 않은 상태의 전역 툴팁은 계속 `pointer-events:none`이라 진형 드래그를 가리지 않는다
