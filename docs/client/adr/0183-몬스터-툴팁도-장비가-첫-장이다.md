# ADR-0183 — 몬스터 툴팁도 착용 장비가 첫 장이다 — 영웅과 같은 카드다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) 「유닛 툴팁 규격」 · [§4-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | 0114 의 **몬스터 첫 장**(기본 옵션 막대 + 대표값 3줄) 조항 |
| **대체됨** | — |

## 결정

관전 카드의 몬스터에 올리면 뜨는 유닛 툴팁을 **영웅 툴팁과 같은 카드**로 만든다 — 첫 장은 **착용 장비 3×3**, Alt 를 누르는 동안 바깥쪽에 세부 옵션 1 · 2 두 열, Alt 동안 카드 밖으로 나가도 유지되고 찬 장비 칸에 올리면 「착용 중」 아이템 카드가 옆에 뜬다. 몬스터의 한 벌은 그 몬스터가 **실제로 입고 있는 장비**이고(`round` 이벤트의 `gear`), 안 입는 부위는 영웅과 같은 빈 칸 실루엣이다. 몬스터 전용이던 **기본 옵션 막대 열과 대표값 3줄은 첫 장에서 걷는다** — 영웅이 ADR-0171 에서 걷은 것과 같은 자리다.

## 맥락

ADR-0171 이 영웅 툴팁의 첫 장을 착용 장비로 바꾼 뒤, 같은 아레나의 카드 두 종이 서로 다른 물건을 냈다 — 영웅은 장비 3×3, 몬스터는 기본 옵션 막대 일곱 줄 + 대표값 3줄. 몬스터도 2026-09-11(R79)부터 `rollGear` 로 **한 벌을 입고** 있고 처치 드롭이 그중 하나로 나가는데, 그 한 벌을 화면에서 볼 자리가 없었다. 값은 `makeEnemy` 안에만 있었고 `round` 이벤트의 적 항목(`enemyView`)이 싣지 않아 재생기에 닿지도 않았다.

## 근거

- **한 아레나의 카드는 한 문법이어야 한다.** 영웅 카드와 몬스터 카드는 같은 크기 · 같은 윗변 문법 · 같은 스킬 칸 줄을 쓴다(§4-2). 툴팁만 진영마다 다른 물건을 내면 「올리면 무엇이 나오는가」를 두 번 배워야 한다.
- **몬스터의 장비는 드롭의 원인이다.** 「무엇을 떨구는가」가 「무엇을 입고 있는가」인 구조(R79)에서, 입은 한 벌을 보여주는 것은 인과를 읽히게 하는 일이다(기획 조언 원칙 2 통제성).
- 버린 안 ① **장비 열을 기본 옵션 옆에 붙인다** — 열이 셋(장비 + 기본 옵션 + Alt 두 열)이 되어 카드가 아레나를 가로로 덮는다. ADR-0115 가 세부 옵션을 두 열로 가른 이유와 같은 벽이다.
- 버린 안 ② **몬스터만 기본 옵션을 남긴다** — 「영웅이랑 똑같이」라는 요청과 정면으로 어긋난다. 몬스터의 기본 능력치는 Alt 세부 옵션이 파생값으로 이미 들고 있다.
- `Basic Stats` 조립(`attrRowsHtml` · `unitCard` 의 막대 열)은 **지우지 않는다** — 캐릭터 탭 기본 옵션이 같은 함수를 부르고, 첫 장을 되살릴 여지도 남긴다(ADR-0171 과 같은 처리).

## 파급

- `game_logic/battle.js:enemyView` 가 **`gear` 를 싣는다**(얕은 복사 · 표시값 · rng 0) — `round` · `call` 이벤트가 같은 모양이라 둘 다. **타임라인 안이라 골든 지문(`tl`)이 갈린다** → 재촬영(DEV_PLAN R119). [INTERFACE §2-6](../INTERFACE.md)
- `tip.js` — `equipmentHtml` 이 「위치 → 아이템」 한 벌을 받는 모양이 됐다. 영웅은 `equipped`(위치 → uid), 몬스터는 `gear`(**부위** 배열)에서 같은 모양으로 온다. 부위가 위치 둘인 반지는 **앞 칸부터** 앉힌다.
- `itemCardOf` 의 인자가 **uid → 아이템 개체**로 바뀌었다 — 몬스터 장비는 세이브에 없어 uid 가 없다(`uid: null`). 부르는 자리 셋(`app.js` 둘 · `ui/battle.js` 하나)이 같이 바뀌었다.
- 몬스터 카드의 `bindTipNode` 가 `holdOnAlt: true` 를 받는다 — 장비 칸 hover 가 Alt 동안만 열리는 규칙(ADR-0176 · ADR-0182)이 그대로 적용된다.
- 새 i18n 키는 없다 — 머리글 `ch.gear.h` · 아이템 카드 머리글 `tip.equipped` 를 그대로 쓴다.
- ⚠ 몬스터 장비의 아이템 카드가 쓰는 스킬 문장 숫자는 **그 몬스터 기준**이다(`noStatMult: true` — 몬스터 능력치 계수 보류 · ADR-0164 · GAME_DESIGN §10).
- ⚠ 열린 채 남은 것 — 몬스터가 **안 입는 부위**가 빈 칸으로 서므로, 부위를 적게 입는 초반 몬스터의 첫 장은 칸이 많이 빈다. 「입는 부위만 칸을 세운다」는 안은 칸 격자가 카드마다 달라져 안 골랐다(§4-1 「물리 스테이지도 원소 칸을 찍는다」와 같은 규칙).
