# ADR-0184 — 분해는 골라서 버튼으로 한다 · 분해 모드 토글을 버린다

| **대체** | — |

## 결정

분해 모드 토글을 버리고 **고르고 나서 실행하는 방식**으로 바꾼다.

도구 줄의 **[분해]** 를 누르면 보관 두 칸이 **고르는 중**이 되고, 그 줄이 **[분해하기] · [잠그기] · [취소]** 로 갈린다. 고르는 중의 칸 클릭은 **왼쪽 위 체크를 토글할 뿐**이고, 실제 분해는 [분해하기] 한 번이 한다. 실행 버튼은 체크가 하나도 없으면 꺼진다.

## 맥락

그날 분해는 **가방 상단의 「분해 모드」 토글**을 켜고 칸을 클릭하는 방식이었다. 리포트 「획득 장비」 칸에는 **독립된 토글이 하나 더** 있었는데, 한쪽을 켜 둔 채 다른 화면에서 오클릭하는 사고를 막으려고 일부러 따로 둔 것이었다(`state.salvageMode` · `state.repSalvage`).

같은 날 끝난 교차 조사([salvage_interaction_survey.md](../../reference/salvage_interaction_survey.md))가 40여 종의 분해 조작을 일곱 갈래로 정리했는데, **「모드를 먼저 켜고 그 상태에서 클릭」은 표본이 없었다.** 가장 가까운 Melvor 의 Toggle Sell Mode 도 다중 선택을 위한 모드였다. 반면 **체크 후 버튼**은 표본이 있다(Torchlight Infinite · ESO · Idle Heroes).

## 근거

- **토글은 자리마다 복제된다** — 그날 이미 둘이었고, 위험을 화면 분리로 막고 있었다. 장비가 들어오는 자리가 늘면 토글도 는다
- **§3 「되돌릴 수 없는 행동은 두 번 누르게 한다」가 첫 클릭에만 성립했다** — 토글을 한 번 켜면 그 뒤의 클릭은 몇 번이든 무확인 파괴였다. 체크 + 실행 버튼은 **모든 아이템에** 두 번을 건다
- **모드 상태가 위험을 만들지 않는다** — 고르는 중에 잘못 눌러도 체크가 붙을 뿐 아무것도 사라지지 않는다. 토글을 둘로 쪼개 막던 사고가 원인째 없어진다
- **일괄이 공짜로 따라온다** — 조사에서 「개별만 두면 일괄을 달라는 요청이 반드시 나온다」가 양 극단으로 실증됐다(§2-2). 고르는 방식은 한 개도 여러 개도 같은 손짓이다
- **자동 분해가 들어와도 비용이 안 는다** — 조건 저장형 자동 분해(GAME_DESIGN §10 「자동 분해의 선」)가 서면 개별 분해는 「자동이 못 거른 애매한 것」만 남아 드물어진다. N+1 클릭이 방치형에 과하다는 조사 평(§4 D안)은 그 층이 깔린 뒤엔 걸리지 않는다

**버린 안**

1. **우클릭 = 즉시 분해** — 개당 1클릭으로 가장 싸고 우클릭 자리가 비어 있었다(전역 브라우저 메뉴를 막아 뒀고 마스터리 트리의 「망각」이 이미 파괴하는 동사로 쓴다). 버린 이유는 **확인이 0 이고 잠금을 걸 자리가 남지 않아서**다 — `Ctrl`(창고 이동 · [ADR-0103](0103-보관은-두-칸이다-왼쪽-창고-오른쪽-인벤토리-ctrl-클릭으로-오간다.md)) · `Alt`(툴팁) · 드래그(자리 옮기기)가 이미 찼다
2. **우클릭 → 컨텍스트 메뉴 [분해 / 잠금]** — [ADR-0026](0026-강화는-이-탭에-없다.md) 이 「가방에서 바로 강화하는 길은 우클릭 메뉴가 후보」로 예약해 둔 자리와 같다. 버린 이유는 **사용자가 체크 방식을 골라서**다. 우클릭 자리는 여전히 비어 있어 강화가 나중에 그리로 갈 수 있다
3. **리포트에 「이 런에서 얻은 것 일괄」** — 조건 저장형 자동 분해가 서면 리포트에 뜨기 전에 이미 걸러지므로 할 일이 없다 (리포트는 [ADR-0186](0186-리포트는-보기-전용이다.md) 으로 보기 전용이 됐다)
4. **제련소로 옮긴다** — 접속 층이 두꺼워져 「가장 얇은 층」(GAME_DESIGN §3-1)과 부딪힌다

## 파급

- `state.salvageMode` 삭제 · **`state.bagSel`**(고른 uid 집합) · **`state.bagSelMode`**(고르는 중인가) 신설
- `state.repSalvage` 삭제 — 리포트 쪽은 [ADR-0186](0186-리포트는-보기-전용이다.md)
- i18n — `ch.salvageMode` · `ch.salvageHint` · `rep.salvage` 삭제 · `ch.sel.start` · `ch.sel.salvage` · `ch.sel.lock` · `ch.sel.cancel` · `ch.salvagedN` · `ch.skipLocked` 신설
- `style.css` — `.inv-cells.salvage` 가 고르는 중 표시로 바뀌고 `.inv-check` 신설
- **탭을 떠나면 고르는 중이 풀린다** — 모드 상태가 화면 밖으로 새지 않는다
- ⚠ **열린 것** — 조건 저장형 자동 분해(「알아서 분해」)는 이 결정 밖이다. 같은 날 논의에서 **일괄과 자동을 하나로 합쳐 「규칙 한 벌 + 신규 유입에 계속 적용 + 지금 가진 것에도 적용 버튼」** 으로 가기로 했으나 아직 그리지 않았다
