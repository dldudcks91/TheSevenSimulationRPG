# ADR-0190 — 제련소는 탭 이름이 장소다 · 작업 탭은 상단바에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §8-2](../SCREEN_DESIGN.md) (§2 상단바) |
| **정한 사람** | 사용자 지시 — 「강화라는 이름을 → 제련소로 수정」 · 「제작, 강화, 크래프트탭을 위로 올리고」(상단바로 확인) · 제목 줄은 「상단바에 모두 표기하잖아」 |
| **대체** | [ADR-0142](0142-제련소는-제작-강화-크래프트를-위쪽-탭으로-가른다.md) 의 **탭이 서는 자리**(패널 안 배치 줄 아래 → 상단바) — 「고른 하나만 편다」는 산다 |
| **대체됨** | [ADR-0281](0281-제련소의-작업-탭은-패널-박스-바로-위에-선다.md) 이 **작업 탭의 자리**를 대체(상단바 → 패널 박스 바로 위) · 2026-09-21 — 탭 이름 「제련소」는 산다 |

## 결정

1. **탭 이름을 `강화` → `제련소`** 로 바꾼다 (`nav.forge` — en `Upgrade` → `Smeltery` · 패널 머리이던 `dp.post.forge` 와 같은 말).
2. **작업 탭(제작 · 강화 · 크래프트)을 상단바의 탭 세그먼트 자리**(crumb 바로 오른쪽)에 세운다 — 원정 · 도감이 쓰는 자리다. 고른 하나만 박스 끝까지 편다는 [ADR-0142](0142-제련소는-제작-강화-크래프트를-위쪽-탭으로-가른다.md) 의 결정은 그대로다.
3. **패널 안의 「제련소」 제목 줄을 걷는다.**

## 맥락

그날 강화 탭은 위에서부터 **패널 제목 「제련소」 → 배치 줄 → 작업 탭 → 고른 작업의 박스**였다. 탭 이름은 「강화」(활동), 패널 머리는 「제련소」(장소)라 상단바 crumb 는 「강화」, 패널 제목은 「제련소」 — 같은 곳을 두 이름으로 불렀다. 「강화」는 작업 탭 하나의 이름이기도 해서 crumb 「강화」 아래에 작업 탭 「강화」가 또 섰다.

「탭은 활동 · 패널 머리는 장소」 갈림은 09-03 탭 분리 때 「시설 어휘를 바꾸는 결정은 기획 소관이라 화면이 앞서가지 않는다」는 이유로 세운 것이고, 상점(탭 「상점」 · 패널 머리 「상단」)도 같은 갈림이었다. 상단바의 탭 세그먼트 자리는 원정([ADR-0094](0094-원정-세그먼트는-상단바에-선다.md))과 도감([ADR-0174](0174-도감-세그먼트도-상단바에-선다.md))이 쓰고 있었다.

## 근거

- **한 곳은 한 이름으로 부른다** — crumb 와 패널 제목이 다른 말로 같은 곳을 가리켰고, 탭과 작업이 「강화」라는 이름을 나눠 가졌다. 탭 이름이 장소가 되면 「제련소 › 강화」로 층이 갈린다
- **탭 안의 화면 전환은 상단바가 든다** — 원정 · 도감이 이미 그 자리를 쓴다. 제련소만 패널 안에 두면 전환 버튼이 어디 있는지를 탭마다 다시 찾아야 한다
- **제목 줄은 crumb 를 되풀이한다** — 탭 이름이 곧 「제련소」다. 도감이 같은 이유로 제목 줄을 안 둔다(§9) · 원정 · 캐릭터 패널도 탭 이름을 제목으로 되풀이하지 않는다
- 09-03 의 「시설 어휘는 기획 소관」은 사용자가 이름을 직접 정하면서 풀렸다

**버린 안**

1. **패널 안에서 작업 탭을 배치 줄 위로만 올린다** — 전환 버튼의 자리가 탭마다 갈리는 문제가 남는다
2. **상점도 함께 장소 이름(「상단」)으로 바꾼다** — 지시 범위 밖이다. 상점은 「상점」/「상단」 갈림 그대로 둔다
