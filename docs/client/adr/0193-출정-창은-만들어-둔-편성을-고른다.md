# ADR-0193 — 출정 창은 만들어 둔 편성을 고른다 · 고르개는 고른 편성의 영웅 셋을 초상으로 든다

## 결정

출정 창의 2×2 는 그대로 두고 **왼쪽 열의 두 칸만** 갈아 끼운다.

- **위 줄 왼쪽 = 편성** — 편성 버튼이 **세로로** 서고, 그 오른쪽에 **고른 편성의 영웅 셋이 초상으로** 선다. 초상은 **읽기 전용**이다(클릭 없음). 자리는 파티가 덜 차도 **셋만큼 잡는다**
- **아래 줄 왼쪽 = 출정 방식 단독** — 위험도 · 반복 · 보내기. 보내기는 **고른 편성으로** 나간다

## 맥락

그날 출정 창은 2×2 였다 — 위 줄 캐릭터 선택(로스터 띠) · 적 구성 / 아래 줄 진형 + 출정 방식 · 이야기(ADR-0088 · 0105). 창 안에서 파티를 짜고 진형을 세웠다. 같은 날 편성 탭이 서며(ADR-0192) 파티 · 진형이 그리로 갔다.

## 근거

- **2×2 를 유지한다** — ADR-0088 · 0105 가 세운 **「창 크기가 상태에 안 흔들린다」**(2026-08-28 사용자 지시)와 「보낼 쪽과 맞설 쪽이 같은 줄에 마주 선다」가 그대로 선다. 위 줄은 여전히 「누가 가나 ↔ 누구와 싸우나」다
- **초상 셋만 — 진형 · 물약은 안 그린다** — 사용자가 「어떤 애가 나가는지 정도만」이라 했다. 창은 **고르는 자리**이고 고치는 자리는 편성 탭이다
- **읽기 전용** — 초상을 누르면 무엇을 하나(빼기? 편성 탭 열기?)가 새로 생긴다. 클릭이 없으면 그 물음이 없다
- **셋 자리를 늘 잡는다** — 편성마다 인원이 달라도 창이 흔들리지 않는다. 적 구성이 챕터보스 스테이지에서도 넷 자리를 잡는 것과 같은 규칙이다(ADR-0098)
- **버튼은 세로** — 가로면 버튼과 초상이 한 줄에 서서 어느 버튼의 초상인지가 흐려진다. 세로면 「왼쪽에서 고르고 오른쪽에서 본다」
- **버린 안** — ① 창에 「편성 고치기」 버튼: 사용자가 「정도만」이라 했다 ② 편성마다 초상 셋을 전부 늘어놓는다: 아홉 장이 위 줄을 채워 적 구성과 마주 서는 읽기가 깨진다

## 파급

- app.js — `departBody` 에서 로스터 띠 · 진형 보드가 빠지고 편성 고르개 + 초상 셋 · `?dev=form` 은 그대로
- CSS — 왼쪽 열이 띠 일곱 장에서 버튼 + 초상 셋으로 줄었다 — **창 폭은 크기 정책에서 다시 잰다**
- i18n — 편성 칸 이름 · 경고(편성이 비었다)
- ⚠ **창을 닫고 편성 탭으로 가야 고친다는 거리가 남는다** — 사용자가 수정 요청으로 정한다
