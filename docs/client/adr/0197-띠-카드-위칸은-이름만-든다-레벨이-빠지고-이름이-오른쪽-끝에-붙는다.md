# ADR-0197 — 띠 카드 위칸은 이름만 든다 — 레벨이 빠지고 이름이 오른쪽 끝에 붙는다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「위에 나오는 캐릭터 UI 에서 레벨을 빼고 이름을 오른쪽 정렬로」) |
| **대체** | [ADR-0165](0165-띠-카드-위칸은-이름-뒤에-레벨을-든다.md) (위칸 오른쪽 = 이름 + `Lv.n` → **이름 하나**) |
| **대체됨** | — |

## 결정

영웅 띠 카드 위칸은 왼쪽 「지금 하는 일」 · 오른쪽 **이름** 둘만 든다. `Lv.n` 이 빠지고 이름이 **카드 오른쪽 끝**에 붙는다. 띠는 한 벌이라 두 자리(편성 탭 · 캐릭터 탭) 다 그렇다. 줄어드는 쪽이 「하는 일」 하나인 규칙은 그대로다.

## 맥락

2026-09-18 부터 위칸 오른쪽이 이름 뒤에 `Lv.n` 을 붙여 들었다(ADR-0165). 이름에 `margin-left:auto` 가 걸려 **이름 + 레벨 한 덩어리**가 오른쪽에 붙었으므로, 이름 자체는 오른쪽 끝이 아니라 레벨 폭만큼 안쪽에 섰다. 같은 날 편성 진형 보드의 초상 카드는 위칸에 이름 하나만 오른쪽 끝에 들고 있었다.

## 근거

사용자 지시다.

- **레벨을 어디로 옮길지는 이 결정에 없다** — 지시가 「빼고 · 어디에 넣을지는 고민하자」였다. 자리가 정해지면 그 결정이 따로 선다. 그날 레벨을 읽는 자리는 캐릭터 탭 기본 옵션 칸 맨 위(고른 영웅 한 명 · [ADR-0129](0129-레벨-경험치는-기본-옵션-칸-맨-위-능력치-막대-위에-선다.md))뿐이었다 — 유닛 툴팁은 이름 · 소속 줄을 안 든다([ADR-0134](0134-유닛-툴팁은-이름-소속-줄을-안-든다.md))
- **두 띠 다인 이유** — ADR-0165 가 두 띠를 묶은 근거(「두 자리가 같은 띠」 — 한쪽만 가르면 같은 카드가 자리마다 달라진다)가 빼는 쪽에도 그대로 선다
- **이름은 따로 정렬을 고치지 않는다** — 이름에 이미 `margin-left:auto` 가 걸려 있어, 뒤의 레벨이 빠지면 이름이 오른쪽 끝에 붙는다

## 파급

- `app.js:heroStrip` 위칸의 `.hs-lv` 조각 삭제 · `style.css .hs-lv` 삭제
- i18n `ch.lv` 는 **남는다** — 기본 옵션 칸의 레벨 줄이 부른다
- ⚠ 편성 탭에서는 영웅 레벨을 읽는 자리가 없어졌다 — 레벨의 새 자리가 이 공백을 받는다
