# ADR-0199 — 영웅 띠 카드의 레벨은 오른쪽 아래에 서고 해고 버튼이 덮는다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §5](../SCREEN_DESIGN.md) |
| **정한 사람** | 제안 후 승인(「오른쪽 아래로 넣자 · 해고 버튼이 그냥 레벨을 덮는 걸로」) |
| **대체** | — |
| **대체됨** | [ADR-0202](0202-영웅-띠-카드의-레벨은-왼쪽-아래-리더-표시는-오른쪽-아래다.md) — 레벨은 왼쪽 아래 · 리더 표시는 오른쪽 아래 — 2026-09-21 |

## 결정

영웅 띠 카드는 초상 **오른쪽 아래**에 `Lv.n` 을 단다 — 모든 카드 · 두 띠(편성 탭 · 캐릭터 탭) 다. 모양은 아이템 칸의 오른쪽 아래 `Lv.n`([ADR-0168](0168-아이템-칸-오른쪽-아래에-아이템-레벨이-선다.md))과 같은 문법 — 판 없이 검은 테두리를 두른 글자다. 캐릭터 탭에서 고른 카드에 **해고 버튼이 뜨면 그 버튼이 레벨 위를 덮는다**.

## 맥락

같은 날 [ADR-0197](0197-띠-카드-위칸은-이름만-든다-레벨이-빠지고-이름이-오른쪽-끝에-붙는다.md) 이 위칸에서 레벨을 걷고 자리를 미정으로 남겼다. 그 뒤 영웅 레벨을 읽는 자리는 캐릭터 탭 기본 옵션 칸 맨 위(고른 영웅 한 명 · [ADR-0129](0129-레벨-경험치는-기본-옵션-칸-맨-위-능력치-막대-위에-선다.md))뿐이었고, 편성 탭에는 없었다.

카드의 모서리는 위칸이 위쪽 전체, 리더 뱃지가 왼쪽 아래(편성 띠 · 파티 첫 칸만), 해고 버튼이 오른쪽 아래(캐릭터 탭 · 고른 카드만 · [ADR-0049](0049-자리는-영웅-띠의-고른-카드-오른쪽-아래다.md))를 썼다.

## 근거

안 넷을 놓고 골랐다 — 오른쪽 아래 배지 · 왼쪽 아래 배지 · 위칸 왼쪽(「하는 일」 자리) · 띠에 안 둔다.

- **오른쪽 아래인 이유** — 아이템 칸이 이미 오른쪽 아래에 `Lv.n` 을 찍는다. 「오른쪽 아래 숫자 = 레벨」이 영웅과 아이템에 한 규칙으로 읽힌다. 일곱 카드의 레벨을 커서 없이 한 번에 견준다
- **해고 버튼이 덮어도 되는 이유** — 해고 버튼은 **클릭해서 고른 카드 한 장에만** 뜬다. 그 영웅의 레벨은 바로 아래 기본 옵션 칸 맨 위에 있어 가려도 잃는 것이 없다
- **버린 안 — 해고 버튼을 배지 위에 쌓는다**: 모든 카드에 레벨이 남지만 고른 카드 구석이 두 단으로 커진다. 덮는 쪽이 더 단순하다
- **버린 안 — 해고 버튼을 왼쪽 아래로 옮긴다**: 캐릭터 탭 띠엔 리더 뱃지가 없어 빈 자리지만, ADR-0049 를 뒤집는 일이 따로 선다
- **버린 안 — 왼쪽 아래**: 편성 띠에서 리더 뱃지와 겹치고, 아이템 칸과 방향이 반대다
- **버린 안 — 위칸 왼쪽**: 「지금 하는 일」을 다른 표시로 옮겨야 해서 판이 커진다
- **버린 안 — 띠에 안 둔다**: 누구를 데려갈지 고를 때 레벨을 견주려면 카드마다 툴팁을 열어야 한다
- **글씨 크기는 아이템 칸보다 한 단 크다** — 띠 카드가 아이템 칸의 두 배쯤이라 같은 크기면 구석에서 안 읽힌다

## 파급

- `app.js:heroStrip` — 초상 뒤에 `.hs-lv` 한 조각 · `style.css .hs-lv`(절대 배치 · `z-index:1` — 해고 버튼 `z-index:2` 가 그 위에 선다). 해고 버튼 배경이 반투명이라 덮기만 하면 밑의 글자가 비쳐, **버튼이 선 카드에서는 레벨을 감춘다**(`.hs-card:has(.hs-dismiss) .hs-lv`)
- **새 i18n 키가 없다** — 기본 옵션 칸이 쓰던 `ch.lv`(`Lv.{n}`)를 그대로 부른다. 아이템 레벨 `ch.itemLv` 와 글자는 같아도 가리키는 것이 달라 키를 합치지 않는다(ADR-0168)
