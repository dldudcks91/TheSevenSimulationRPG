# ADR-0200 — 도감 몬스터 카드는 장수를 안 든다 · 스테이지 행이 박스 아래까지 선다

## 결정

도감 몬스터 세그먼트의 카드는 오른쪽 위의 **카드 수(`0장` / `0 cards`)를 안 든다** — 이름이 윗줄을 통째로 쓴다. 그리고 한 챕터의 스테이지 행들이 **본문 높이를 똑같이 나눠 갖고 박스 맨 아래까지** 선다. 늘어난 세로는 카드가 받고, 카드 높이 = 초상 지름이므로 **초상이 커진다**(원형 그대로).

## 맥락

2026-08-30 부터 카드는 초상 72px 고정이었고 카드 높이를 초상이 정했다. 한 챕터가 한 화면이라는 제약이 초상의 상한이었는데, 그날 1600×800 에서 다섯 행(스테이지 1~4 + 챕터보스 단독 5)을 쌓으면 박스 아래에 한 행 가까운 빈 띠가 남았다. 카드 윗줄은 왼쪽 이름 · 오른쪽 장수(`--fs-lg` 로 가장 큰 글자)였고, 영어에서 장수가 이름과 폭을 다투면 **이름이 말줄임**되는 규칙이 걸려 있었다.

## 근거

사용자 지시다.

- **늘어난 세로는 초상이 먹는다** — 행만 늘리고 초상을 72px 에 두면 카드 안에 빈 세로가 생기고 「카드 높이 = 초상 높이」(§9 · §5 · §4-2 공통 규칙)가 깨진다. 08-30 규칙이 이미 「화면 제약이 초상 크기의 상한」이라고 적었으므로, 화면을 채우는 순간 초상이 그 상한까지 가는 것이 같은 규칙의 끝이다
- **고정 px 로 키우지 않는다** — 행이 본문을 flex 로 나눠 갖고 초상 지름이 카드 높이를 따라간다(`aspect-ratio`). 챕터마다 스테이지 수 · 머리 줄 높이가 달라져도 바닥에 맞는다. 72px 은 하한으로 남긴다
- **장수 대신 이름이 넓어진다** — 장수가 빠지면 윗줄에서 폭을 다툴 것이 없어 말줄임 규칙이 이름 하나의 넘침 처리만 남는다

## 파급

- `app.js:monsterCard` 의 `.mon-top` 줄과 `.mon-kills` 조각 삭제 — 이름(`.mon-name`)이 `.mon-body` 의 첫 줄로 선다. 장수 칸에 걸려 있던 레벨 툴팁(`cx.lvTitle`)도 같이 빠졌다(핍이 제 레벨 툴팁을 든다)
- `app.js:codexMonster` 본문에 `.cx-mon` · `style.css` 의 `.cx-mon` 신설 · `.mon-top` `.mon-kills` 삭제 · `.mon-card .face` 가 고정 72px → 카드 높이를 따르는 원
- i18n `cx.cards` 는 **남는다** — 핍 툴팁 · 리포트의 카드 줄이 부른다
- ⚠ **도감 화면에서 지금 가진 카드 수를 숫자로 읽는 자리가 없어졌다** — 레벨 핍 · 「다음 N장」(다음 레벨 누적 문턱) · 진행 막대가 남는다
- ⚠ `docs/reference/portrait_art_style_study.md` 의 「도감 카드 72px」 표는 그날의 조사 기록이라 안 고쳤다
