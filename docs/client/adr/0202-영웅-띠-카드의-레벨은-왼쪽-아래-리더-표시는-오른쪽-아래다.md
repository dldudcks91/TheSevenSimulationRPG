# ADR-0202 — 영웅 띠 카드의 레벨은 왼쪽 아래 · 리더 표시는 오른쪽 아래다

## 결정

영웅 띠 카드의 `Lv.n` 은 초상 **왼쪽 아래**에 선다 — 모든 카드 · 두 띠 다. 편성 띠의 **리더 표시는 오른쪽 아래**로 옮긴다. 오른쪽 아래는 해고 버튼(캐릭터 탭 띠)과 리더 표시(편성 띠)가 나눠 쓰고, 둘은 서로 다른 띠에만 서서 한 카드에서 만나지 않는다. 레벨은 어느 카드에서도 가려지지 않는다.

## 맥락

같은 날 ADR-0199 가 레벨을 오른쪽 아래에 두고 캐릭터 탭에서 고른 카드는 해고 버튼이 덮게 했다. 사용자가 왼쪽 아래를 나란히 비교해 보자고 해서 CSS 만 옮겨 두 벌을 찍었다. 왼쪽 아래 판에서는 편성 띠의 리더 카드만 레벨이 리더 표시 위로 한 단 올라서, 줄을 훑을 때 한 장이 어긋났다. 그 비교를 보고 리더 표시를 오른쪽 아래로 보내라는 지시가 나왔다.

## 근거

사용자 지시다.

- **왼쪽 아래인 이유** — 고른 카드에서도 레벨이 보인다. 오른쪽 아래 판은 해고 버튼이 선 한 장만 레벨이 빠졌다
- **리더를 오른쪽으로 보낸 이유** — 왼쪽 아래에 레벨과 리더가 같이 서면 리더 카드만 레벨 높이가 달라진다. 리더와 해고는 띠가 갈려(리더 = 편성 띠 · 해고 = 캐릭터 탭 띠) 같은 구석을 나눠 써도 부딪히지 않는다
- **남는 흠 — 아이템 칸과 방향이 반대다** — 아이템 칸은 오른쪽 아래가 `Lv.n` 이다(ADR-0168). 글자 문법(판 없이 검은 테두리)은 그대로 맞췄다
- **진형 보드 칸의 리더 표시는 안 옮겼다** — 지시가 가리킨 것은 띠 카드다. 보드 칸엔 레벨이 없어 왼쪽 아래가 비어 있다

## 파급

- `style.css .hs-lv` — `right` → `left` · ADR-0199 의 `.hs-card:has(.hs-dismiss) .hs-lv { visibility:hidden }` 삭제(덮을 것이 없다)
- `style.css .hs-card .hs-leader` — 띠 카드에서만 오른쪽 아래로 뒤집는다(테두리도 왼쪽으로). 기본 `.hs-leader`(왼쪽 아래)는 진형 보드 칸(`.fm-cell`)이 그대로 쓴다
- SCREEN_DESIGN §5 에 「리더 표시」 행을 세웠다 — 자리가 어디에도 안 적혀 있었다
