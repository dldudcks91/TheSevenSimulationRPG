# ADR-0205 — 라운드 줄은 종류를 글 왼쪽의 칩으로 단다 · 첫 라운드는 고정 줄에만 선다

## 결정

로그의 라운드 줄 — 머리 줄 아래 고정 줄과 목록 안 라운드 줄 둘 다 — 은 **종류(일반 · 정예 · 보스)를 괄호가 아니라 글 왼쪽의 칩**으로 단다: `[정예] 라운드 3 — 편성`. 칩은 리더 뱃지와 같은 작은 테두리 박스이고, 색은 관전 헤드의 라운드 트랙과 같다(정예 · 보스). **첫 라운드는 목록에 줄을 쌓지 않고 고정 줄에만 선다** — 목록의 라운드 줄은 2라운드부터 경계로 선다.

## 맥락

같은 날 머리 줄 아래에 지금 라운드 줄을 고정했고, 목록 안의 라운드 시작 줄도 그대로 두었다(ADR-0204). 원정이 막 시작하면 목록이 비어 있어 **고정 줄 바로 밑에 같은 글의 첫 라운드 줄이 붙어 두 줄로 섰다.** 라운드 줄의 종류는 `라운드 3 (정예)` 처럼 괄호였다.

## 근거

- **첫 라운드만 뺀다** — 두 줄이 겹치는 것은 목록이 빈 채 시작할 때뿐이다. 2라운드부터는 목록 줄이 지난 줄을 거슬러 읽을 때의 경계라 남긴다. 판단은 「목록이 비어 있는가」로 한다 — 되감기 · 재렌더도 빈 목록에서 이벤트를 다시 밟으므로 같은 결과다
- **칩은 리더 뱃지와 같은 모양** — 사용자가 가리킨 박스다. 괄호보다 종류가 먼저 눈에 걸리고, 글 왼쪽이라 줄마다 같은 자리에 선다
- **색은 라운드 트랙과 같다** — 같은 화면에서 정예 · 보스를 이미 그 색으로 칠한다. 같은 뜻을 두 색으로 두지 않는다(일반은 무채색)
- **칩은 렌더러가 붙인다** — 문구(`log.roundStart`)에서 종류를 빼고 렌더러가 `kind.*` 문구로 칩을 앞에 단다. 칩은 마크업이라 ko/en 문장 안에 둘 수 없다

**버린 안**

1. **목록 안 라운드 줄을 모두 뺀다** — 거슬러 읽을 때 경계가 없어진다(ADR-0204 와 같은 이유)
2. **고정 줄을 첫 라운드 동안 숨긴다** — 사용자가 고정 줄을 요청했다 · 남는 것은 목록 쪽 한 줄이면 된다

## 파급

- i18n `log.roundStart` 에서 `({kind})` 삭제 — 종류는 `kind.normal` · `kind.elite` · `kind.boss` 를 같이 쓴다
- `battle.js` — `round` 이벤트가 칩(`span.lg-kind.{종류}`)을 앞에 단 글을 고정 줄에 건다 · 목록이 비어 있으면 목록에는 안 쌓는다
- CSS `.lg-kind` · `.lg-kind.elite` · `.lg-kind.boss`
- `game_logic` · 세이브 · 단정 무관
