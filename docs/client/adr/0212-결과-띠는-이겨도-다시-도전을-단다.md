# ADR-0212 — 결과 띠는 이겨도 [다시 도전]을 단다 · 띠는 불투명하다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) 「결과 띠」 |
| **정한 사람** | 사용자 지시 (「승리했어도 다시 도전하기 버튼 추가」 · 「전투 끝나고 나오는 새로운 탭이 스킬보다 위에서 덮도록」) |
| **대체** | [ADR-0138](0138-패배한-결과-띠는-다시-도전을-단다.md) 의 **「승리 띠에는 달지 않는다」** — 버튼의 동작(같은 스테이지 · 지금 파티 · 한 번에 눌린다 · 반복 설정은 그대로)은 그대로 산다 |
| **대체됨** | — |

## 결정

1. 원정 관전의 결과 띠는 **이겨도** [다시 도전]을 단다. 버튼 순서는 [리포트 보기] · [다음 스테이지] · [다시 도전]이다. **반복이 세는 띠에는 달지 않는다** — [다음 스테이지]를 그 띠에 안 다는 것(ADR-0141)과 같은 규칙이다
2. 띠는 **불투명 바닥**을 깐다(툴팁과 같은 `--bg-secondary`). 아레나 위에 겹쳐 뜨는 판이라 아래에 무엇이 오든 덮는다

## 맥락

- 이날 결과 띠는 패배일 때만 [다시 도전]을 달았다. 이기면 [리포트 보기] · [다음 스테이지]뿐이었다. 같은 날 리포트의 [같은 곳으로 다시]가 빠지면서([ADR-0210](0210-리포트에는-버튼이-없다.md)) 반복 없이 이긴 곳을 다시 치는 길은 출정 창 하나만 남았다
- 띠의 바닥색은 `rgba(surface-0, --panel-alpha-soft)` 였고 그 알파가 0 이라 **완전 투명**이었다. 층은 띠가 위(z 3 · 파티 쪽 z 1)였다. 하지만 **2·1 진형에서 뒷줄 영웅 카드 아래의 창 뱃지(스킬 아이콘)**가 띠 자리까지 내려와(실측 1600×800 — 뱃지 줄 y 512~536 · 띠 y 519~561) 띠 글자와 뱃지가 한 자리에 겹쳐 보였다

## 근거

- **이긴 뒤에도 같은 곳을 다시 치는 일이 있다** — 반복을 켜지 않은 채 한 번 더 돌리려면 출정 창까지 가야 했다. ADR-0138 은 「그 길은 반복 원정이 든다」며 승리 띠에서 뺐지만, 반복은 켜 두고 잊는 설정이라 한 번 더 돌리는 결정과 무게가 다르다
- **반복이 세는 띠는 예외다** — 몇 초 뒤 같은 곳으로 저절로 나가므로 [다시 도전]이 할 일이 없다. 세는 동안 버튼을 늘리지 않는다는 ADR-0141 의 규칙을 그대로 따른다
- **겹침은 층이 아니라 바닥 문제다** — 층 순서는 이미 띠가 위였다(그 자리의 최상단 요소 = 띠). 바닥이 투명하면 층과 무관하게 아래가 비친다. 띠를 옮기는 것보다 덮는 쪽이 진형 · 배치마다 자리를 따지지 않아도 된다

**버린 안**

1. **띠를 뱃지 줄과 안 겹치는 자리로 옮긴다** — 뒷줄의 유무 · 진형 · 넓게/나눔 배치마다 아레나 안 빈자리가 달라져 한 자리를 못박을 수 없다
2. **`--panel-alpha-soft` 를 올린다** — 이 토큰은 자원 줄 판 등이 같이 쓰는 배경 투명도 손잡이다. 띠 하나를 위해 올리면 다른 판도 같이 어두워진다
