# ADR-0228 — 자원 단의 단계 트랙은 머리 줄 없이 상자만 선다

| | |
|---|---|

| **대체됨** | — |

## 결정

자원 탭 파견처 단 3의 단계 트랙에서 **머리 줄 「단계 N」을 지운다**. 이름 줄(이름 + 담당 능력치) 아래 구분선 바로 밑이 단계 상자 일곱이다.

## 맥락

같은 날 ADR-0220 · 0222 · 0224 로 단의 머리가 「이름 + 능력치」 한 줄로 줄었다. 그 아래 트랙 머리에 「단계 7」이 서 있었고, 사용자가 이것도 지우라고 했다.

## 근거

**개수는 상자가 이미 말한다.** 상자마다 순서 번호(1 ~ N)가 붙어 있어 마지막 상자의 번호가 곧 단계 수다. 머리 줄은 같은 수를 한 번 더 적는 자리였다.

**상자 개수는 여전히 CSV 가 정한다.** 머리 줄이 `D.mineNodes.length` 를 찍던 것이 빠질 뿐, 상자 수를 정하는 규칙(코드에도 CSS 에도 개수를 박지 않는다)은 그대로다.

## 파급

- `app.js:tierTrack` 이 머리 줄을 안 만든다 · `style.css` 의 `.dp-tier-h` 규칙 삭제
- i18n `dp.tier` 삭제 — 참조가 그 한 줄뿐이었다
- 빠진 줄의 세로는 상자 일곱이 나눠 갖는다 (`grid-auto-rows: 1fr`)
