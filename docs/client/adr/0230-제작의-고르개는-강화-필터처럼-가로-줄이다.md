# ADR-0230 — 제작의 고르개는 강화 필터처럼 가로 줄이다 · 세로 탭을 되돌린다

| | |

| **화면** | [SCREEN_DESIGN §8-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「다시 강화처럼 가로로 나오도록」 |

## 결정

제련소 제작의 고르개(부위 실루엣 칸 전부 + 끝의 물약 칸)를 **제작 칸 위의 가로 줄**로 세운다 — 강화 목록 머리의 부위 필터와 같은 모양(같은 버튼 · 같은 그림 크기)이다. 고른 칸 하나만 그 아래에 편다. 물약 칸 · 병 실루엣 · 고른 하나만 편다는 ADR-0219 그대로다.

## 맥락

같은 날 ADR-0226 으로 고르개를 제작 칸 왼쪽의 세로 탭으로 세웠다 — 고른 탭이 오른쪽 판과 이어지는 폴더 탭 모양이었다. 사용자가 그 화면을 보고(「한번 확인해보게」로 시험한 모양) 가로로 되돌리라고 지시했다.

## 근거

- **강화 필터와 같은 모양이 된다** — 제련소의 두 작업이 「부위를 고르는 칸 줄」을 같은 자리 · 같은 모양으로 든다. 세로 탭이면 같은 그림 칸이 작업마다 다른 방향으로 선다
- **버린 안 — 왼쪽 세로 탭**(ADR-0226): 부위 · 물약 고르기와 레벨대 고르기의 급이 모양으로 갈리는 값은 있었으나, 사용자가 시험해 보고 가로로 정했다. 같은 제안을 다시 올리지 않는다

## 파급

- CSS — `.fg-vtabs` · `.fg-mpane` 삭제 · `.fg-make` 는 다시 세로로 쌓는 한 칸(고르개 줄 · 레벨대 줄 · 재료 블록). 새 i18n 키 없음
