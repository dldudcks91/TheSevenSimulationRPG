## 결정

도감 몬스터 툴팁은 **카드 두 장이 나란히** 선다.

- **왼쪽 = 기본 옵션** — 캐릭터 탭의 기본 옵션 칸을 그대로 쓴다: 제목(`기본 옵션`) + 챕터 죄종 칩 · 능력치 7 막대(같은 줄 조립 함수 `attrRowsHtml`) · 액티브 스킬 소제목 + 스킬 칸. 값은 `monster.csv` 의 기본 능력치 7 이다(레벨과 무관). 레벨 · 경험치 줄은 없다
- **스킬 칸은 지금 고유 1칸만** — 정예의 무기 칸 · 보스의 셋째 칸은 판마다 굴려 정해져 도감이 못 박는다. **보스는 나중에 전직 칸까지 그린다**(사용자 예고)
- **칸 아래 글자가 스킬 이름이다** — 캐릭터 탭은 출처 이름(`고유`)을 적지만, 툴팁 안의 그림에는 올려도 설명이 안 뜬다(툴팁이 닫힌다)
- **오른쪽 = 이야기 · 단계** — 종전 한 장 그대로(이름 · 직업 · 초상 + 이야기 · 단계 목록)

## 맥락

도감 툴팁은 이야기와 도감 단계만 들었다. 몬스터마다 기본 능력치 7 과 고유 스킬이 `monster.csv` 에 있는데(영웅과 같은 모양 · monster_design §5-1) 그것을 읽을 화면이 관전의 유닛 툴팁뿐이었고, 그마저 첫 장이 장비라(ADR-0183) 능력치 막대가 안 섰다.

## 근거

사용자 지시다. 선택지 둘(스킬 칸 · 스킬 이름 자리)은 사용자가 골랐다.

- **새로 그리지 않고 가져온다** — 막대 줄은 캐릭터 탭 · 유닛 툴팁과 같은 함수가 조립한다(ADR-0114 · 두 자리가 따로 짜면 한쪽만 고쳐진다). 스킬 칸도 같은 클래스다
- **막대 색은 관전 몬스터 툴팁과 같은 등급 색** — 보스는 보스 선 색, 아니면 일반 / 정예 고르개를 따른다. 어두운 색은 막대만 밝힌다(유닛 툴팁과 같다)
- **버린 안 — 무기 · 셋째 칸을 「판마다 다름」 빈 칸으로 세운다** — 사용자가 「일단 고유 1칸만」을 골랐다
- **버린 안 — Alt 로 툴팁을 붙잡고 그림에 올려 설명창을 본다** — 도감에는 레벨 · 장비가 없어 설명창의 데미지 숫자가 비어 나온다. 사용자가 이름 쪽을 골랐다
- ⚠ **몬스터의 능력치 계수는 보류다**(GAME_DESIGN §10 「몬스터의 능력치 계수」 · `battle.makeEnemy` ④) — 힘 · 지능이 몬스터의 데미지를 지금은 안 키운다. 막대는 데이터를 그대로 읽을 뿐이다
