# ADR-0234 — 진형 보드도 관전과 같은 한 줄이다 · 뒤 랭크는 한 단만 내려간다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §15](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「영웅들 배치를 바꿀때마다 지금은 완전하게 위아래로 구분되는데 이거를 실제 인게임처럼 조금만 차이나게 수정해볼래?」 |
| **대체** | 편성 탭 진형 보드의 **줄 배치**(랭크마다 제 줄 · 줄 높이 한 칸 · 줄 사이 7px)를 걷는다. [ADR-0053](0053-진형은-수가-적은-랭크를-가운데에-세운다.md) · [ADR-0045](0045-진형이-파티-카드를-위아래로-민다.md) 를 **뒤집지 않는다 — 관전의 규칙을 보드가 따라간다** |
| **대체됨** | — |

## 결정

**보드는 칸 하나 높이의 한 줄이다.** 랭크는 줄이 아니라 **한 단 어긋남**이 말한다 — 관전 아레나와 같은 그림이다.

- **가로 차례는 관전과 같은 식**으로 나온다 — k 칸짜리 랭크의 i 번째가 `x = (i + 0.5) / k`, 전원을 그 x 로 줄 세운다(x 가 같으면 앞 랭크가 먼저 · `ui/battle.js:layoutRanks` 와 같은 규칙 · ADR-0053). 2·1 이면 **앞 · 뒤 · 앞** 차례라 뒤 칸이 저절로 가운데다
- **뒤 랭크는 `--fm-step` 만큼 내려간다** — 칸 한 변의 0.22 배로, 관전의 `--form-step`(21px)이 유닛 카드에서 차지하는 비율과 같다. 랭크가 하나뿐인 템플릿(일자)은 아무도 안 내려간다
- **칸끼리는 안 겹친다** — 가로 차례가 자리를 갈라 놓으므로 어긋남이 작아도 초상이 다 보인다. 끌어다 놓는 자리라 가림이 없어야 한다
- **전열 · 후열 라벨은 남는다** — 왼쪽에 두 줄로 서되 **제 랭크의 단과 같은 높이**에 붙는다(후열 라벨이 `--fm-step` 만큼 내려간다). 관전에는 없는 글자지만 여기는 **고치는 화면**이라 어느 단이 앞인지 글자로도 말한다
- 보드 높이는 `칸 + 단` 하나로 못박혀 템플릿을 바꿔도 안 흔들린다(옛 값은 칸 둘 + 7px)

## 맥락

2026-09-09 진형이 실물이 되면서 보드는 **랭크마다 제 줄**로 그려졌다(칸 높이 118 + 줄 사이 7 = 243). 관전 아레나는 같은 날 반대로 갔다 — 카드가 **진영마다 한 줄**에 서고 랭크는 세로 어긋남(21px)으로만 말한다([ADR-0045](0045-진형이-파티-카드를-위아래로-민다.md)). 1280 에서 두 줄은 세로가 모자랐기 때문이다.

그래서 같은 편성이 **두 화면에서 다른 그림**으로 보였다 — 편성 탭에서는 위아래로 완전히 갈린 두 덩어리, 관전에서는 살짝 어긋난 한 줄.

## 근거

- **편성은 전투의 예고편이다** — 보드가 관전과 같은 그림이면 「이 편성이 저렇게 선다」가 그대로 읽힌다. 다른 그림이면 플레이어가 두 번 배운다
- **어긋남이 작아도 뜻은 전해진다** — 관전이 이미 21px 로 그 일을 하고 있고, 앞뒤의 뜻은 **자리보다 규칙**(앞부터 맞는다 · battle_design §3-1)이 든다. 라벨이 그 규칙을 글자로 받친다
- **세로가 100px 가까이 준다** — 편성 탭은 띠 · 진형 · 물약 · 전술이 한 화면을 나눠 쓰는 자리다(ADR-0221)
- **버린 안** — ① 두 줄을 그대로 두고 줄 사이만 좁히는 안: 2·1 은 뒤 칸이 앞 두 칸 사이에 서 있어 줄이 겹치면 **초상이 서로 가린다** ② 라벨을 걷고 어긋남만 남기는 안(관전과 완전히 같게): 고치는 화면에서 앞뒤를 글자로 확인할 길이 사라진다

## 파급

- `app.js:formBox` — 랭크마다의 `.fm-row` · `.fm-cells` 가 `.fm-line` 하나로 합쳐진다. 칸의 `data-rank` · `data-idx` 는 그대로라 **드래그 · 클릭 계약이 안 바뀐다**
- `style.css` — `--fm-step` 신설 · `--fm-board-h` 가 `칸 + 단` · `.fm-row` · `.fm-cells` 삭제 · `.fm-line` · 라벨은 절대 자리
- i18n 키 · 조작 · 로직은 하나도 안 바뀐다 (`exp.form.front` · `exp.form.back` 그대로)
