# ADR-0253 — 연구 탭은 「건설」이 되어 캐릭터 바로 아래에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §1](../SCREEN_DESIGN.md) · §2 박스 규격 · §10 · §12 · §13 |
| **정한 사람** | 사용자 지시 — 「연구를 건설로 바꾸고 Character 아래로 탭 옮겨줘봐」 |
| **대체** | — |
| **대체됨** | — |

## 결정

연구 탭의 화면 이름을 **「건설」**(en **Construction**)로 바꾸고, 탭 내비에서 **캐릭터 바로 아래**로 옮긴다. 탭 순서는 원정 · 편성 · 캐릭터 · **건설** · 제련소 · 선술집 · 상점 · 자원 · 탐험 · 도감 · 도움말이 된다. 노드의 실행 버튼도 「연구」에서 **「건설」**(en **Build**)이 된다. 도움말 섹션도 탭 순서를 따라 캐릭터 · 스킬 뒤로 온다.

바뀌는 것은 **보이는 이름과 자리뿐**이다 — 탭 id `research`(`?tab=research`) · i18n 키(`nav.research` · `rs.*`) · 목업 데이터 `mock.js:RESEARCH` · 상태 필드(`researchLayout` · `researchPick`)는 옛 이름 그대로 둔다.

## 맥락

그날 연구 탭은 **가지 8** 을 카드로 세운 화면 하나였다(ADR-0145 의 가지 8 열 · ADR-0192 로 위쪽 탭을 걷은 뒤). 가지는 **시설 이름**(원정 · 탐험 · 제련소 · 선술집 · 상단 · 자원 · 도감 · 파티 전술)이었고, 카드 머리에 **건물 그림**이 섰다(ADR-0146). 노드의 내용 · 비용 · 여는 조건은 기획이 안 정해 전부 목업이었다.

탭은 **탐험 뒤 · 도감 앞**에 섰다 — 「맡기고 나가는 둘(자원 · 탐험)의 산출을 먹는 연구가 이어진다」는 09-03 순서의 근거였다.

기획서(GAME_DESIGN §9 09-14 · 09-21 · tactic_card_design · base_expedition_design)는 이 시스템을 「연구」라 불렀다.

## 근거

- **이름이 화면과 맞는다** — 가지가 시설이고 카드 머리가 건물 그림이다. 노드를 찍는 일이 「시설을 짓는다」로 읽힌다
- **캐릭터 바로 아래** — 사용자 지시. 원정 · 편성 · 캐릭터 · 건설이 앞 넷에 모여, 영구히 여는 성장(건설)이 영웅 성장(캐릭터) 바로 옆에 선다. 09-03 순서의 「산출을 먹는 쪽이 뒤」라는 근거는 이 탭에 대해선 이로써 버려진다
- **id · 키는 바꾸지 않는다** — `research` 는 `?tab=` 라우트 · 상태 필드 · 도움말 · 목업 데이터가 같이 든 이름이라 리네임은 파급만 크고 화면에 보이는 것이 없다. 채광의 장소 id `mine`(화면 라벨만 활동 이름) · 탐험의 `dp.*` 어휘와 같은 처리다
- **en 은 탭이 Construction · 버튼이 Build** — 탭은 시스템의 이름(명사)이고 버튼은 동작(동사)이다. 한글은 둘 다 「건설」이다
- **도움말 섹션은 탭 순서를 따른다**(§12) — 스킬은 캐릭터 탭 안의 창이라 캐릭터에 붙어 있고, 건설은 그 뒤에 선다

## 파급

- i18n — `nav.research` · `rs.research.h` 값이 「건설 / Construction」, `rs.rs.go` 가 「건설 / Build」. `rs.research.note`(도움말 본문)는 옛 위쪽 탭 설명(ADR-0192 로 걷힌 것)이 남아 있어 **현재 화면 기준으로 다시 썼다**
- `app.js:TABS` 순서 · `helpSections()` 순서 · `i18n.js` 의 `nav.*` 나열 순서(탭 바 순서와 맞춘다)
- SCREEN_DESIGN §2 박스 규격의 이 탭 줄 — 걷힌 위쪽 탭 · 전술 칸 격자가 적혀 있던 것을 §13 기준으로 바로잡았다
- ⚠ **기획서는 여전히 「연구」다** — 시스템 이름을 기획 쪽에서도 「건설」로 맞출지는 기획 결정이다(`/game-design`). 그 전까지 SCREEN_DESIGN §13 이 「기획서의 연구 = 이 탭」을 적어 둔다
