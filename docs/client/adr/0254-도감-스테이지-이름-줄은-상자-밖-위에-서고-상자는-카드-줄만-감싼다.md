# ADR-0254 — 도감 스테이지 이름 줄은 상자 밖 위에 서고 상자는 카드 줄만 감싼다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §9](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「카드를 몬스터까지만 포함하고 카드 위에 이름을 올려볼 수 있나」 → 시험 화면을 보고 「이 느낌으로 가자」) |
| **대체** | — *(옛 모양 — 스테이지 행 상자 하나가 이름 줄과 카드 줄을 같이 감쌌다 — 은 ADR 이 아니라 SCREEN_DESIGN §9 · `style.css .codex-stage` 에 있었다)* |
| **대체됨** | — |

## 결정

도감 몬스터 세그먼트의 스테이지 행에서 **이름 줄(번호 · 이름 · 스테이지 보정)은 상자 밖 위에 서고, 상자(배경 · 테두리)는 몬스터 카드 줄만 감싼다**. 행 사이 간격은 이름 줄이 앞 상자에 붙어 보이지 않게 넓힌다(5 → 10px).

## 맥락

그날 스테이지 행은 상자 하나 안에 이름 줄과 카드 줄이 함께 들어 있었다. 같은 날 번호가 로마 숫자가 되며(`I 파멸의 진영`) 이름 줄이 제목 역할을 하게 됐고, 사용자가 이름을 상자 위로 올린 모양을 시험 화면으로 보고 정했다.

## 근거

사용자 지시다.

- **제목과 내용이 갈린다** — 상자 안의 이름 줄은 카드와 같은 층의 정보로 읽혔다. 상자 밖으로 나오면 「이 스테이지의 몬스터들」이라는 묶음의 제목이 된다
- **바뀌는 것은 상자의 범위뿐이다** — 행이 본문 높이를 똑같이 나눠 갖고 늘어난 세로를 초상이 먹는 규칙(ADR-0200)은 그대로다

## 파급

- `style.css` — 배경 · 테두리 · 안 여백이 `.codex-stage` 에서 `.mon-strip` 으로 옮겼다 · `.cs-head` 는 상자 밖 이름 줄
- 마크업(`app.js:codexStageRow`)은 그대로다
