## 결정

진형 칸 왼쪽의 모양 고르개는 **세로로 쌓인 버튼 셋**이고, 버튼마다 **그 모양의 이름을 글로** 적는다 — 이름은 `formation_template.csv` 의 `name_kr` · `name_en`(「모두 앞」 · 「둘 앞 하나 뒤」 · 「하나 앞 둘 뒤」)이다. 점 그림은 걷는다. 고른 버튼은 강조색 · 순서는 표의 행 순서(첫 행이 새 편성의 기본값)는 그대로다. 버튼 폭은 셋 중 가장 긴 이름에 맞춰 같다.

## 맥락

그날 모양 고르개는 정사각 아이콘 셋이 가로로 선 줄이었다 — 정원 배열을 점으로 찍어(●●● / ●● · ● / ● · ●●) 글자가 없었다. 가로 배치는 2026-09-09 의 사용자 지시였고(세로 기둥을 걷었다), 그때 이 상자는 **출정 창** 안에서 세로가 빠듯했다. 같은 날(09-21) 진형은 편성 탭의 왼쪽 열로 옮겨 왔고(ADR-0260), 이름 밑줄 아래 여백이 늘었다.

## 근거

- **점은 읽는 법을 배워야 한다** — 점 줄 둘이 「앞 · 뒤」라는 것은 보드를 한 번 보고 나서야 풀린다. 이름은 처음 보는 사람에게도 그대로 읽힌다
- **이름은 이미 표에 있다** — `formation_template.csv` 가 진형 확정(2026-09-09) 때부터 ko/en 이름을 들고 있었다. 새 문구 · 새 i18n 키 없이 데이터를 그대로 부른다(다국어 규약 — 데이터 문자열은 `L()`)
- **세로 비용이 이제 감당된다** — 가로를 택한 이유는 출정 창의 세로였다. 편성 탭 왼쪽 열은 진형 아래가 물약뿐이고 박스 아래가 남는다. 버튼 셋의 높이는 보드(칸 + 한 단) 안에 든다
- **버린 안** — 점 아이콘 옆에 이름 붙이기: 같은 뜻을 두 번 적어 버튼이 넓어지고, 보드 옆 폭을 먹는다

## 파급

- `app.js:formBox` — 버튼 글자가 `L(D.formationTemplates[id])` · 점 그리기(`shapes`) 삭제
- `style.css` — `.fm-tpls` 세로 · `.fm-tpl` 이 글자 버튼(폭 같게) · 점 규칙(`i` · `b`) 삭제
- SCREEN_DESIGN §15 진형 행(왼쪽 = 버튼 셋 · 결정 칸의 「템플릿 아이콘 클릭」)
- `game.formationState` 의 `shapes` 는 화면이 더 안 읽는다 — 계약은 그대로 둔다(INTERFACE 무변경)
