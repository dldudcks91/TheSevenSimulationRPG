# ADR-0268 — 도감 바닥 줄은 마우스 올림 안내다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §9](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「이 설명 말고 마우스를 올리면 세부 정보를 볼 수 있다로 수정」) |
| **대체** | [ADR-0266](0266-도감-몬스터-바닥에-설명-한-줄이-선다.md) 일부 — 바닥 줄의 문구(`cx.sub` · 레벨별 누적 처치 문턱) |
| **대체됨** | [ADR-0273](0273-도감-세그먼트는-패널-위에-서고-바닥-줄은-없다.md) — 바닥 줄 삭제 |

## 결정

도감 몬스터 세그먼트의 바닥 줄은 **「마우스를 올리면 세부 정보를 볼 수 있다」** 한 줄이다(`cx.hoverHint` · en 「Hover to see details」). 자리 · 높이 · §12 예외라는 점은 ADR-0266 그대로다.

## 맥락

같은 날 ADR-0266 으로 바닥 줄은 도움말의 `cx.sub`(누적 처치 100 · 1,000 · 10,000 · 100,000 마리에서 레벨이 오른다 — 스테이지 계열 스탯이 오른다)였다. 카드에 올리면 두 장짜리 몬스터 툴팁(선술집 후보 카드 · 스토리 · 보너스 효과 — ADR-0233 · 0244)이 뜨지만, 화면에는 그 사실을 알리는 것이 없었다.

## 근거

사용자 지시다.

- **규칙을 적지 않고 입구를 알린다** — 문턱 · 효과 같은 규칙은 툴팁의 단계 목록과 도움말이 든다. 바닥 줄은 「더 볼 것이 있다」만 말한다 — §12 의 예외를 가장 좁게 쓴다
- **새 키다** — 도움말 `cx.note` 안에 같은 뜻의 문장(「카드에 마우스를 올리면 그 몬스터의 이야기와 처치 단계가 뜬다」)이 있지만 여러 문장이 한 키로 묶여 있어 떼어 쓸 수 없다
- ⚠ ADR-0266 의 근거 「문턱이 화면에서 빠진 자리를 메운다」는 무너졌다 — 레벨별 문턱은 다시 레벨 핍의 작은 툴팁과 도움말에만 있다

## 파급

- i18n `cx.hoverHint` 신설 · `app.js:codexMonster` 바닥 줄이 그 키를 부른다 · `cx.sub` 는 도움말만 쓴다
