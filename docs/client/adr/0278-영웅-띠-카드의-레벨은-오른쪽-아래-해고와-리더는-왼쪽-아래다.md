# ADR-0278 — 영웅 띠 카드의 레벨은 오른쪽 아래 · 해고와 리더는 왼쪽 아래다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「레벨 위치를 오른쪽 아래로 바꾸고 해고랑 Leader 표시를 왼쪽으로 — 오른쪽 아래로 통일하는 게 좋을 것 같다」) |

## 결정

영웅 띠 카드의 `Lv.n` 은 초상 **오른쪽 아래**에 선다 — 모든 카드 · 두 띠 다. 캐릭터 탭 띠의 **해고 버튼**과 편성 띠의 **리더 표시**는 **왼쪽 아래**로 간다. 레벨은 여전히 어느 카드에서도 가려지지 않는다 — 해고 · 리더와 구석이 갈린다.

## 맥락

같은 날 ADR-0202 가 레벨을 왼쪽 아래, 해고 · 리더를 오른쪽 아래에 두었다. 그 ADR 은 「아이템 칸과 방향이 반대다」를 남는 흠으로 적었다 — 아이템 칸은 오른쪽 아래가 `Lv.n` 이다(ADR-0168). 사용자가 레벨을 오른쪽 아래로 통일하자고 했다.

## 근거

사용자 지시다.

- **오른쪽 아래인 이유** — 레벨이 아이템 칸의 `Lv.n` 과 같은 구석에 선다. 「레벨은 오른쪽 아래」가 게임 전체에서 한 규칙이 된다 — ADR-0202 의 남는 흠이 없어진다
- **ADR-0202 의 근거는 살아 있다** — 그 ADR 이 레벨을 왼쪽으로 보낸 이유는 오른쪽 아래의 해고 버튼이 고른 카드의 레벨을 덮는 것이었다(ADR-0199). 해고가 왼쪽으로 가서 레벨은 이번에도 안 가려진다. 구석을 맞바꿨을 뿐 「레벨과 버튼 · 뱃지는 다른 구석」이라는 규칙은 그대로다
- **리더도 왼쪽인 이유** — ADR-0202 가 밝혔듯 레벨과 리더가 한 구석에 서면 리더 카드만 레벨 높이가 달라진다. 해고와 리더는 띠가 갈려(리더 = 편성 띠 · 해고 = 캐릭터 탭 띠) 같은 구석을 나눠 써도 부딪히지 않는다
- **덤 — 리더 표시가 어디서나 같은 구석이다** — 진형 보드 칸 · 출정 창 초상의 리더 표시는 원래 왼쪽 아래였다. 띠 카드만 오른쪽으로 뒤집혀 있던 것이 풀렸다

## 파급

- `style.css .hs-lv` — `left` → `right`
- `style.css .hs-dismiss` — `right: 0` → `left: 0`
- `style.css .hs-card .hs-leader` 삭제 — 띠 카드만 오른쪽으로 뒤집던 규칙이다. 띠 카드도 기본 `.hs-leader`(왼쪽 아래)를 쓴다
- SCREEN_DESIGN §5 의 레벨 · 리더 표시 · 해고 버튼 행
