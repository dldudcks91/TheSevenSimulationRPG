# ADR-0280 — 진형 보드 칸은 띠 카드와 같은 위칸과 레벨을 단다

## 결정

편성 탭 진형 보드의 영웅 칸은 **영웅 띠 카드와 같은 얼굴**을 한다 — 초상 위 **위칸**(왼쪽 지금 하는 일 · 오른쪽 이름)과 초상 **오른쪽 아래 레벨**(`Lv.n`)이다. 리더 표시는 그대로 왼쪽 아래다. 조각은 띠 카드의 것(`.hs-band` · `.hs-doing` · `.hs-name` · `.hs-lv`)을 그대로 쓰고, 이름 하나만 들던 보드 전용 띠(`.fm-nm`)는 걷는다.

## 맥락

그날 보드 칸은 초상 위에 **이름 하나뿐인 반투명 띠**를 얹고 왼쪽 아래에 리더 태그를 달았다. 같은 화면 바로 위의 띠 카드는 위칸에 「하는 일」과 이름을, 오른쪽 아래에 레벨을 들었다(ADR-0278). 칸은 띠 카드와 같은 크기라서, 같은 영웅이 띠에서는 레벨과 상태를 보이고 보드로 내려가면 이름만 남았다. [ADR-0202](0202-영웅-띠-카드의-레벨은-왼쪽-아래-리더-표시는-오른쪽-아래다.md) 는 「보드 칸엔 레벨이 없다」를 그날의 사실로 적었다.

## 근거

사용자 지시다.

- **띠 카드 조각을 그대로 쓰는 이유** — 칸은 띠 카드와 같은 크기이고 드래그로 서로 오간다. 같은 영웅은 어느 자리에서든 같은 얼굴로 읽혀야 한다. 따로 만든 띠(`.fm-nm`)를 넓히면 글꼴 · 여백 · 말줄임 규칙이 두 벌로 갈린다
- **구석이 부딪히지 않는다** — ADR-0278 로 레벨은 오른쪽 아래, 리더는 왼쪽 아래다. 보드 칸도 같은 구석을 쓰므로 리더 칸의 레벨이 가려지지 않는다
- **「하는 일」은 편성 탭에서도 뜻이 있다** — 원정이 도는 동안에도 편성을 바꾼다(R92). 보드에 앉은 영웅이 지금 싸우는 중인지(원정 중) 아닌지(대기)를 칸에서 바로 읽는다. 값은 띠 카드와 같은 함수(`app.js:heroDoing`)가 낸다
- **버린 안** — 레벨만 달고 이름 띠는 그대로 두기. 지시가 둘 다를 요구했고, 반쪽만 맞추면 띠 카드와 여전히 다른 얼굴이다

## 파급

- `app.js:formBox` — 칸 안을 띠 카드와 같은 위칸 + `Lv.n` 으로
- `style.css .fm-nm` 삭제
- SCREEN_DESIGN §15 진형 행의 「칸은 정사각(…)」
- ⚠ 출정 창의 편성 초상(§4-1)은 **위칸이 없는 그대로**다 — 지시가 가리킨 것은 편성 탭 보드다
