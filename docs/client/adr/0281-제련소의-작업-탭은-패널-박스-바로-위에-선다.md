# ADR-0281 — 제련소의 작업 탭은 패널 박스 바로 위에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-21 |
| **화면** | [SCREEN_DESIGN §8-2](../SCREEN_DESIGN.md) (§2 상단바) |

| **대체됨** | — |

## 결정

제련소의 작업 탭(`제작` · `강화` · `크래프트`)을 상단바에서 **패널 박스 바로 위**(카드 밖)로 내린다. 도감의 세그먼트(ADR-0273)와 같은 자리 · 같은 모양(한 CSS 규칙 — `.cx-tabs, .fg-tabs`)이다. 패널 안의 제목(고른 작업 이름 · 크래프트면 「미착수」 배지)은 그대로 둔다.

## 맥락

그날의 제련소는 상단바 crumb 「제련소」 오른쪽에 작업 탭 셋이 서고(ADR-0190), 패널 머리에는 고른 작업 이름(「제작」)이 제목으로 섰다. 같은 날 도감의 세그먼트가 상단바를 떠나 패널 박스 바로 위로 내려갔고(ADR-0273), 사용자가 제련소 탭도 내리라고 지시했다. 첫 구현은 탭을 **카드 안 머리 줄**에 넣고 제목을 걷었는데, 사용자가 「카드 밖으로 · 제목은 그대로」로 바로잡았다.

## 근거

- **박스 위 전환 줄은 도감과 한 문법이다** — 탭 안의 화면을 가르는 줄이 같은 자리 · 같은 모양이면 탭마다 다시 찾지 않는다. 규칙을 한 벌로 묶어 둘이 갈라지지 않게 한다
- **카드 안의 제목은 카드가 무엇인지를 말한다** — 탭은 카드 밖의 고르개이고, 카드 머리의 제목은 다른 탭의 패널 제목과 같은 문법이다. 둘은 자리가 달라 「같은 말을 두 번」으로 읽히지 않는다
- **ADR-0190 의 근거 「탭 안의 화면 전환은 상단바가 든다」가 약해졌다** — 그날 도감이 상단바를 떠나 상단바를 쓰는 탭은 원정 하나였다

**버린 안**

1. **탭을 카드 안 머리 줄에 두고 제목을 걷는다** — 첫 구현이었다. 사용자가 되돌렸다 — 탭은 카드 밖, 제목은 카드 안
2. **탭을 아이콘 줄과 같은 칸 폭으로 맞춘다** — 영어 라벨(`Upgrade`)이 아이콘 칸 폭을 넘는다

## 파급

- 렌더러 — `renderForge` 가 `.tab-seg` 를 안 채운다 · 세그먼트를 `main` 에 패널보다 먼저 붙인다(`.fg-tabs`)
- CSS — `.cx-tabs` 두 규칙에 `.fg-tabs` 를 더했다(자리 · 배율 · 고른 칸 강조)
- 새 i18n 키 없음 · `?tab=forge&fg=make|up|craft` 는 그대로다
- ⚠ 상단바 탭 세그먼트를 쓰는 탭이 원정 하나가 됐다 — 원정만 상단바에서 화면을 가른다
