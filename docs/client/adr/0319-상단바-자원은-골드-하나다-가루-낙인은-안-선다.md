# ADR-0319 — 상단바 자원은 골드 하나다 · 가루 · 낙인은 안 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-24 |
| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) 공통 셸 「상단바」 |
| **정한 사람** | 사용자 지시(「위에 나오는 분해 가루 0, 낙인 0 삭제」) |
| **대체** | — *(상단바의 「자원 3종」은 ADR 이 아니라 SCREEN_DESIGN §2 한 줄이었다)* |
| **대체됨** | — |

## 결정

상단바의 자원 칸은 **골드 하나**다. 분해 가루 · 낙인은 상단바에 서지 않는다.

## 맥락

상단바는 골드 · 분해 가루 · 낙인 세 숫자를 늘 세웠다. 새 게임에서 가루 · 낙인은 둘 다 0 으로 서 있었고, 사용자가 둘을 걷기를 원했다.

## 근거

사용자 지시다.

- **가루는 쓰는 자리에서 읽힌다** — 제련소 제작의 재료 칸이 `보유/필요` 를 찍는다. 분해 결과는 플래시가 든다
- ⚠ **낙인은 보유량을 읽을 자리가 없어진다** — 비용 표기(`costText`)는 필요량만 찍고 모자라면 색으로 말한다. 낙인이 몇 개 있는지는 이 날 기준 상단바 말고는 서는 자리가 없었다. 낙인을 쓰는 화면이 보유량을 들지, 자원 탭 등에 세울지는 열린 채 남는다
- **버린 안** — 0 일 때만 숨기기: 지시는 두 칸을 지우라는 것이었고, 값에 따라 칸이 생기고 사라지면 상단바 폭이 흔들린다

## 파급

- `app.js` 상단바 자원 띠 · 관전 중 자원 숫자 갈아 끼우기(`refreshBattleSide`)가 골드 하나만 본다
- i18n `res.dust` · `res.stigma` 는 남는다 — 비용 표기 · 제련소 재료 칸이 쓴다
- ⚠ 낙인 보유량 표시 자리 — 열림
