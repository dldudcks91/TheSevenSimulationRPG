# ADR-0320 — 자원 단 이름은 소제목 모양이고 밑줄이 단계와 가른다

## 결정

자원 탭 단 셋의 이름 줄(채광 · 채집 · 벌목 + 담당 능력치)은 **소제목 모양**이다 — 패널 제목 · 소제목과 같은 규칙 하나(`.panel > h2, .sub-h` · [ADR-0241](0241-패널-제목과-소제목은-한-모양이다-선은-글씨-아래다.md))를 쓴다: 같은 글씨 크기 · 굵게 · 밝은 글씨색 · **글씨 아래 밝은 선 하나**. 그 밑줄이 이름 줄과 단계 상자를 가른다 — 단계 트랙 위에 있던 어두운 구분선은 걷는다. 담당 능력치는 이름보다 **한 단 작게** · 굵지 않게 · 흐린 글씨색으로 이름 줄에 남는다. 미착수 흐림(불투명도)은 **단계 상자에만** 걸린다 — 이름 줄은 다른 소제목과 같은 색으로 선다.

## 맥락

이름 줄은 `--fs-lg` 보통 굵기였고, 카드 전체에 걸린 미착수 흐림(0.72) 때문에 회색으로 보였다. 이름 줄 아래에는 단계 트랙의 어두운 윗선(`--border-dark`)이 있어 거의 안 보였다. 바로 아래 안내 패널의 제목(「채광」)은 소제목 모양이라 같은 이름이 두 모양으로 서 있었다.

## 근거

사용자 지시다.

- **밑줄을 새로 긋지 않고 트랙 윗선을 걷는 이유** — 둘 다 두면 이름 아래에 선이 두 줄 선다. 선은 하나 — 소제목의 밑줄이다(캐릭터 탭 액티브 스킬 절과 같은 판단)
- **능력치를 한 단 내리는 이유** — ADR-0222 의 「같은 크기면 「채광 STR」이 한 이름으로 읽힌다」가 그대로 산다. 이름이 `--fs-md` 로 내려왔으니 능력치는 `--fs-sm` 이다
- **흐림을 상자로 옮기는 이유** — 카드 전체가 흐리면 이름이 소제목 색이 될 수 없다. 「미착수」는 단 아래 안내 패널이 말하고, 흐림은 「아직 고를 수 없는 단계」를 가리키는 표시로 상자에 남는다
