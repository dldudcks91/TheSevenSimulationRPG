# ADR-0327 — 건설 상세 왼쪽은 「다음 랭크」 가 위다

| | |
|---|---|
| **상태** | 확정 · 2026-09-24 |
| **화면** | [SCREEN_DESIGN §13-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 「다음 랭크와 현재 가능한 기능 위치를 바꿔 줘 봐」 |
| **대체** | [ADR-0326](0326-건설-부지는-한-줄에-셋이고-상세는-반으로-갈린다.md) 의 왼쪽 위아래(현재 가능한 기능 위 · 다음 랭크 아래) — 부지 3열 · 상세 반 가르기는 산다 |
| **대체됨** | — |

## 결정

건설 상세 왼쪽 반은 **「다음 랭크」 가 위, 「현재 가능한 기능」 이 아래**다.

## 맥락

ADR-0326(같은 날)은 「지금 → 다음 → 전체」 읽는 순서를 따라 현재 가능한 기능을 위에 두었다. 그러면 [건설] 버튼이 현재 기능의 길이만큼 아래로 밀려, 다 지은 것이 많은 건물일수록 버튼 자리가 건물마다 달랐다.

## 근거

- **행동이 위에 선다** — 이 화면에서 누를 수 있는 것은 [건설] 하나다. 「다음 랭크」 가 위면 부지를 바꿔 골라도 [건설]이 같은 높이 근처에 선다
- 현재 가능한 기능은 참고로 읽는 목록이라 아래에서 길어져도 된다(왼쪽 반이 제 안에서 스크롤한다)

## 파급

- `app.js` — `buildingSide` 가 왼쪽에 `nextRankBox` → `nowBox` 순으로 넣는다
- `style.css` — 두 절 사이 여백이 `.cn-next` 아래로 옮겼다
