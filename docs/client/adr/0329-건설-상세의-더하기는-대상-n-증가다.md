# ADR-0329 — 건설 상세의 더하기는 「대상 +n 증가」 다

| | |

## 결정

건설 상세(「다음 랭크」 · 「현재 가능한 기능」 · 랭크 목록)에서 **상한 · 칸 · 단계를 더하는 것**은 문장이 아니라 **「대상 +n 증가」** 한 토막으로 쓴다 — 「파티 전술 칸 +1 증가」 · 「로스터 +5 증가」 · 「강화 상한 +2 증가」. 영어는 「Party tactic slots +1」. 기능을 여는 것(「선술집 명단에서 영웅을 고용한다」)은 설명 문장 그대로다. 키는 그대로 `cn.t.<대상>` 하나다.

## 맥락

ADR-0325(같은 날)은 여는 것 전부를 설명 문장으로 썼다 — 더하기도 「파티 전술 칸이 {n} 늘어난다」 · 「보유할 수 있는 영웅이 {n}명 늘어난다」 같은 서술형이었다. 사용자는 더하기를 「대상 +n 증가」 로 줄이라고 했다.

## 근거

- **더하기는 무엇이 얼마나 느나가 전부다** — 대상 이름과 숫자면 다 읽힌다. 서술형은 같은 뜻에 글자만 늘려, 숫자가 문장 가운데 묻혔다
- **기능을 여는 문장은 남긴다** — 그쪽은 이름만으로 안 읽혀서 문장이 됐다(ADR-0325). 더하기의 대상 이름은 이미 게임 안에서 쓰는 말(로스터 · 가방 칸 · 강화 상한)이라 그 이유가 없다
- **영어는 「증가」 에 해당하는 말을 안 붙인다** — 「+n」 이 이미 증가를 말한다. 「Increases X by n」 은 서술형 그대로였다

## 파급

- `i18n.js` — `cn.t.<대상>` 중 더하기 대상의 값이 「대상 +{n} 증가」 · 「Target +{n}」
- `app.js` · `style.css` — 바뀌지 않는다(한 줄에 한 토막 · 같은 `.cn-desc`)
