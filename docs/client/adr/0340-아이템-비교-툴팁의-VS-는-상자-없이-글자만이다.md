# ADR-0340 — 아이템 비교 툴팁의 VS 는 상자 없이 글자만이다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 「비교 툴팁 규격」 |

| **대체** | [ADR-0339](0339-아이템-비교-툴팁의-틈은-좁고-VS-는-두-장의-가장자리를-덮고-위에-선다.md) 의 **딱지**(배경 · 테두리가 있는 불투명 네모) — 글자만 남긴다. 「좁은 틈」 · 「두 장의 가장자리 위에 겹친다」 · 「카드 안 여백까지만 걸친다」는 산다 |

## 결정

`VS` 는 **글자만** 선다 — 배경 · 테두리 네모가 없다. 자리는 그대로 좁은 틈 위, 두 장의 가장자리에 겹친 가운데 높이다. 글자 뒤에는 카드 바탕색의 **번짐 그림자**만 둔다 — 겹친 두 카드의 테두리 선이 글자를 가로질러 보이지 않게 한다.

## 맥락

ADR-0339 를 화면에 올린 직후 사용자 — 「네모난 딱지를 왜 넣어, 그냥 글씨만 넣어」. 겹쳐 올리라는 지시를 읽을 거리로 만들려고 딱지를 씌웠는데, 원정 관전의 VS(글자뿐)와 모양이 갈렸다.

## 근거

- **원정의 VS 가 글자뿐이다** — ADR-0337 이 빌린 것은 그 글자다. 네모를 씌우면 새 부품이 된다
- **번짐 그림자는 상자가 아니다** — 가장자리가 없어 네모로 읽히지 않고, 글자 밑을 지나는 두 테두리 선만 지운다

## 파급

- `style.css` 의 `.tip-vs span` 한 곳 — 배경 · 테두리 · 안쪽 여백을 걷고 `text-shadow` 를 둔다. DOM · i18n · 세이브 · 단정 무변동
