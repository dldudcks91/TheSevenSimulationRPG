## 결정

상세 머리 오른쪽 끝의 건설 인력은 **칸 하나만** 선다 — 제목 「건설 인력」 · 미착수 배지 · 그 사이 세로 가림선을 걷는다. 빈 칸은 브라우저 기본 툴팁(`title`)으로 「건설 인력」 을 든다 — 페이퍼돌 빈 칸이 부위 이름을 `title` 로 드는 것(ADR-0122)과 같은 자리 · 같은 방식이다. 찬 칸은 영웅 얼굴이 말한다.

## 맥락

그날 ADR-0343 으로 건설 인력은 상세 머리 오른쪽 끝에 「제목(건설 인력 + 미착수 배지) | 칸 하나」 로 섰다. 배지는 인력이 목업(짓기에 영향 없음)이라는 표시였다. 사용자 지시 — 「오른쪽 탭에 건설 인력 미착수 이거 다 지우고 세로선도 제거」.

## 근거

- **머리는 그림 · 이름 · 칸 셋이면 읽힌다** — 제목과 가림선이 칸보다 넓은 자리를 먹어 이름 칸을 좁혔다(en 긴 이름이 두 줄로 접혔다)
- **이름은 빈 칸의 `title` 이 든다** — 글자를 걷어도 「이 칸이 무엇인가」 는 올려 보면 나온다. 페이퍼돌 빈 칸과 같은 문법이라 새 규칙이 아니다. 찬 칸에는 안 단다 — 얼굴이 이미 말하고, 띠 카드와 같은 얼굴 위에 브라우저 툴팁이 겹칠 까닭이 없다
- ⚠ **목업 표시가 화면에서 사라진다** — 인력이 짓기에 영향이 없다는 것은 이제 문서(§13-1 · §11)만 말한다. 사용자가 걷기로 한 것이고, 기획이 인력의 효과를 정하면 이 문제는 없어진다

## 파급

- `app.js:crewSlot` 의 `.cn-crew-h` 줄을 뺐다 · 빈 칸에 `title` · `aria-label` = `cn.crew.h` · CSS `.cn-crew-h` 규칙 삭제
- `todo.badge` 는 다른 미착수 자리(제련소 크래프트 · 상단 · 의뢰 · 훈련장)가 계속 쓴다
