## 결정

「{건물} 랭크」 목록의 묶음은 **「랭크 I」 · 여는 것 문장 · 오른쪽 끝 상태 글자**만 든다 — 조건 아랫줄을 걷는다. 안 지은 랭크(준비 중 제외)에 마우스를 올리면 툴팁에 그 랭크의 **조건 전부**가 한 줄에 하나씩 뜬다 — 「다음 랭크」 절과 같은 문법(선 것 초록 ✓ · 모자란 것 경고색 ✗ · 같은 문장). 그 뒤 랭크는 줄째 흐리다(조건의 주황을 살리려고 조건만 빼고 흐리던 규칙은 조건이 빠져 쓸모가 없다).

## 맥락

그날 랭크 목록은 묶음마다 윗줄 여는 것 문장 · 아랫줄 조건(주황 글씨 · ADR-0328)이었고, 왼쪽 「다음 랭크」 절이 다음 랭크의 조건을 ✓ / ✗ 로 전부 찍고 있었다. 사용자 지시 — 「오른쪽 탭의 각 랭크별로 필요한 옵션은 hover 를 했을 때 뜨도록 만들고 어떤 효과를 얻는지만 나오도록 수정해 줘 · 어차피 왼쪽 탭에 다음 랭크에 필요한 옵션이 있으니까」.

## 근거

- **다음 랭크의 조건은 왼쪽이 이미 든다** — 목록의 조건은 그 절과 같은 값을 두 번 찍었다. 그 뒤 랭크의 조건은 지금 짓는 결정에 쓰이지 않고 「앞으로 무엇이 필요한가」를 궁금할 때만 본다 — 올려서 보는 자리가 맞다
- **툴팁은 「다음 랭크」 의 조건 표기를 그대로 쓴다** — ✓ / ✗ 가 붙으면 그 뒤 랭크의 조건 중 이미 선 것도 읽힌다(주황 한 색으로는 선 것 · 모자란 것이 안 갈렸다). 같은 정보가 두 화면에서 같은 모양이다
- **툴팁은 조건만 든다** — 제목 · 설명 문장 없이 조건 줄뿐이다(CLAUDE.md 규칙 7 「툴팁은 짧다」). 어느 랭크인지는 올린 줄이 이미 말한다
- **지은 랭크 · 준비 중 랭크에는 툴팁이 없다** — 지은 랭크는 조건이 끝났고, 준비 중은 조건이 있어도 지을 수 없다(construction_draft §11-5)
- **버린 안** — 조건을 목록에 흐린 글씨로 남기기: 사용자가 「효과만」 을 지시했다 · 브라우저 기본 툴팁(`title`): 줄바꿈 · 색이 안 되어 ✓ / ✗ 가 안 선다
