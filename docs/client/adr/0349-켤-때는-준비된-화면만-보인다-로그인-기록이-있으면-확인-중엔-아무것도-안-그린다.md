## 결정

켤 때 **준비가 안 된 화면을 그리지 않는다.** 셋이다.

1. **한 장은 맞춘 뒤에 보인다** — `#stage` 는 CSS 에서 숨긴 채 서고(`#stage:not(.fit)`), `app.js:fitStage` 가 처음 맞출 때 `.fit` 을 건다
2. **첫 그리기 전의 셸은 로그인 관문 상태로 선다** — `index.html` 의 `#app` 이 `login-gate` 를 들고 시작한다(`authenticated` 의 첫 값이 거짓이다). 브랜드 · 상단바 · 탭 내비가 빈 채로 비치지 않는다
3. **켤 때 계정을 복원하는 동안, 이 브라우저에 로그인 기록(`storage.js:loadCloudLink`)이 있으면 로그인 화면을 그리지 않는다** — 바닥색만 보이다가 확인이 끝나면 게임이 곧장 선다. 실패(상한 `app.js:CLOUD_BOOT_WAIT_MS` 포함) · 세션 없음이면 그때 로그인 화면이 선다. **기록이 없으면** 로그인 화면이 곧장 서고 버튼이 「확인 중」을 든다 — 어차피 로그인해야 해서 바뀔 화면이 없다

## 맥락

- 2026-09-24 사용자 보고 — 새로고침하면 `THE SEVEN` 이 크게 떴다가 줄어들며 게임 화면이 켜진다
- 켜는 순서가 화면을 네 번 갈아 끼웠다 ① `app.js` 는 module 이라 첫 그리기 **뒤에** 돈다 — 그 사이 한 장이 원배율(1600×800)로 왼쪽 위에 섰다(창이 한 장보다 작으면 크게) ② `fitStage` 뒤 CSV 를 받는 동안은 정적 셸(왼쪽 위 브랜드 · 빈 상단바 · 빈 내비)이 비쳤다 ③ `cloudResume` 이 `setCloud('checking')` 을 부르면 `authenticated` 가 거짓이라 `render()` 가 **로그인 화면**(정중앙 38px 로고 + 「확인 중」 버튼)을 그렸다 — Firebase SDK 를 CDN 에서 받고 · 세션을 복원하고 · 클라우드 사본을 받는 동안 남았다 ④ 그다음 게임
- 사용자가 본 「크게 떴다가 줄어든다」는 ③ 의 로고가 ④ 의 왼쪽 위 브랜드로 바뀌는 자리다(① 도 창이 한 장보다 작으면 같은 인상이다)

## 근거

- **보이는 화면은 약속이다** — 로그인한 사람에게 로그인 화면을 1~2초 보여 주면 「로그아웃됐나」로 읽힌다. 곧 사라질 화면이라면 안 그리는 쪽이 정직하다
- **판정은 이미 있는 값 하나다** — 로그인 기록은 클라우드와 맞출 때 쓰고 로그아웃 · 세션 만료에 지운다. 「곧 자동으로 들어간다」의 가장 가까운 대리값이고 새 상태를 늘리지 않는다
- **맞추기는 공식 한 벌을 지킨다** — 숨기는 것은 CSS 한 줄 · 드러내는 것은 `fitStage` 안이라 배율 공식을 `index.html` 에 옮겨 적지 않는다

**버린 안**

1. **확인 중엔 항상 빈 화면** — 분기가 하나 준다. 버린 이유 — 처음 온 사람(기록 없음)도 로그인 화면 전에 SDK 를 받는 동안 빈 화면을 본다. 그 사람에겐 로그인 화면이 바로 목적지라 기다릴 까닭이 없다
2. **빈 화면에 「확인 중」 한 줄** — 느린 네트워크에서 멈춘 것처럼 안 보인다. 버린 이유 — 요소 하나 · i18n 키 하나가 는다. 기다림에는 이미 상한(8초)이 있고, 넘으면 로그인 화면이 사유를 든다
3. **`index.html` 에 배율을 거는 인라인 스크립트** — module 을 기다리지 않고 첫 그리기 전에 맞춘다. 버린 이유 — `fitStage` 공식(눕힘 · 보이는 창 포함)이 두 벌이 된다 · `tip.js:stagePoint` 가 뒤집는 행렬의 출처도 둘이 된다

## 파급

- `style.css` `#stage:not(.fit)` · `app.js:fitStage`(`.fit`) · `index.html` `#app.login-gate` · `app.js:renderLogin`(복원 중이고 기록이 있으면 빈다) · `app.js:cloud.resuming`
- i18n 무변동 · 한국어 문구 없음
- ⚠ **열린 것** — ① 기록이 있는데 네트워크가 느리면 상한까지 빈 화면이다(버린 안 2 가 푸는 자리) ② module 을 못 불러오면(문법 오류 · 파일 누락) 한 장이 끝까지 숨는다 — 이날 전에는 빈 셸이 원배율로 섰다. 어느 쪽이든 게임은 안 켜지고, 원인은 콘솔이 든다 ③ 기록 없이 세션만 살아 있는 브라우저(연결 기록을 지운 채)는 여전히 로그인 화면이 잠깐 선다
