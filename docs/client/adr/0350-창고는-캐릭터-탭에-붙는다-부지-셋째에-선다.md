# ADR-0350 — 창고는 캐릭터 탭에 붙는다 · 부지 셋째에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-24 |
| **화면** | [SCREEN_DESIGN §13-1](../SCREEN_DESIGN.md) 부지 순서 · §1 흐린 탭 |
| **정한 사람** | 사용자 지시 — 「창고 → 캐릭터창에 디벨롭되는 느낌으로 하게 창고를 3번째로 옮기자」 |
| **대체** | — *(ADR 이 아니던 표 값 — `building.csv:tab` 의 창고 `-`)* |
| **대체됨** | — |

## 결정

창고(`storage`)의 붙는 탭을 `-`(없음)에서 **`character`** 로 바꾼다(`building.csv:tab`). 부지는 「부지 순서 = 왼쪽 탭 바 순서」(§13-1)대로 **원정 · 지휘 천막 다음 셋째**에 선다. 창고가 여는 것은 그대로다.

## 맥락

그날 창고는 탭이 없는 유일한 건물이라 부지 격자 맨 끝(열째)에 섰다. 창고의 랭크는 가방 · 창고 사용(r1 · 시작부터 지어짐) · 물약 칸 + · 장비 세트 저장 · 장비 세트 + 를 연다([construction_draft.md §2](../../game_design/construction_draft.md)). 가방 · 창고 · 장비는 캐릭터 탭에서 쓴다. 같은 날 탭 바가 원정 · 편성 · 캐릭터 · 건설 · 선술집 · 상점 · 제련소 · 훈련장 … 으로 바뀌었다(ADR-0348).

## 근거

- **창고는 캐릭터 탭을 키우는 건물로 읽혀야 한다**(사용자) — 지휘 천막이 편성 탭에 붙어 둘째에 서는 것과 같은 짜임이다
- **부지 자리를 화면에서 따로 정하지 않고 표의 `tab` 을 고친다** — 부지 순서는 이미 `tab` 을 읽는다. 화면에 예외 한 줄을 두면 표와 화면이 건물 · 탭 짝을 따로 든다
- **버린 안 — `sort_order` 만 당긴다** — `sort_order` 는 같은 탭끼리의 순서라 탭 없는 창고는 여전히 맨 뒤다

## 파급

- `building.csv` 창고 행 `tab` = `character` · 코드 변경 없음(`construction.tabs` · 부지 정렬이 표를 읽는다)
- **캐릭터 탭이 흐린 탭 규칙(§1)에 들어간다** — 창고가 안 지어졌으면 캐릭터 탭이 흐리고 안 들어가진다. 창고는 `start_rank` 1 이라 지금은 일어나지 않는다
- ⚠ 창고의 `start_rank` 를 0 으로 내리면 새 게임에서 캐릭터 탭이 잠긴다 — 그때는 이 짝을 다시 본다
- 물약 칸 + (창고 r2 · r5)는 편성 탭에서 쓰지만 창고는 탭 하나에만 붙는다 — 캐릭터로 둔 것은 가방 · 창고 · 장비 세트가 다수라서다
