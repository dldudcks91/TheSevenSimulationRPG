# ADR-0351 — 건설 상세의 더하기는 「대상 +n」 이다 · 「증가」 를 안 붙인다

## 결정

건설 상세(「다음 랭크」 · 「현재 가능한 기능」 · 랭크 목록)의 더하기는 **「대상 +n」** 으로 쓴다 — 「파티 전술 칸 +1」 · 「로스터 +3」 · 「강화 상한 +2」. 한국어도 영어(「Party tactic slots +1」)와 같은 모양이다. 기능을 여는 설명 문장과 장의 누적 문장(「n장까지 연다」)은 그대로다.

## 맥락

그날 아침 ADR-0329 가 더하기를 서술형 문장에서 「대상 +n 증가」 로 줄였다. 영어는 그때부터 「+n」 만 썼다. 건설 상세의 랭크 목록에는 「로스터 +1 증가」 가 랭크마다 되풀이됐다.

## 근거

- **「+」 가 이미 증가를 말한다** — ADR-0329 가 영어에서 「증가」 를 뺀 이유가 한국어에도 똑같이 선다. 「+1 증가」 는 같은 뜻을 두 번 적었다
- **목록에서 되풀이되는 꼬리가 눈에 걸렸다**(사용자) — 랭크마다 같은 두 글자가 붙어 대상 이름 · 숫자보다 먼저 읽혔다

## 파급

- `i18n.js` — `cn.t.<대상>` 중 더하기 대상의 ko 값이 「대상 +{n}」 (en 은 그대로)
- 다른 화면의 「증가」 문장(관전 창 뱃지 「공격력 25% 증가」 · 마스터리 효과 「공격 속도가 5% 증가한다」)은 이 결정 밖이다 — 「+n」 모양이 아니다
