# ADR-0356 — 상단바 ⚙ 왼쪽에 플레이 시간을 단다 · 게임 화면이 보이는 동안만 센다

## 결정

상단바 오른쪽 **⚙ 바로 왼쪽**에 **플레이 시간**을 단다 — 이 세이브를 실제로 플레이한 누적 시간이고 `H:MM:SS` 로 찍는다(시가 24를 넘어도 일로 접지 않는다). 라벨은 골드와 같은 모양(흐린 라벨 + 굵은 값)이다.

- **세는 동안** = 게임 화면(`state.screen === 'game'`)이 떠 있고 · 로그인돼 있고 · 브라우저 탭이 보이고 · 이 탭이 멈춤(다른 탭이 세이브를 씀)이 아닐 때. 꺼 둔 시간 · 숨긴 탭 · PC 절전 · 시작 화면 · 프롤로그는 안 센다
- 누적 값은 **세이브에 든다**(`playMs` · INTERFACE §4) — 새로고침 · 다른 기기(클라우드 사본)에서도 이어진다
- 숫자는 앱 시계 눈금마다 **글자만** 바꾼다(전체 다시 그림이 아니다 · 골드 숫자 `refreshGold` 와 같은 길)

## 맥락

그날 상단바 오른쪽은 골드 · 계정 · 언어 · Admin · Card · ⚙ 였다. 게임 안의 시각은 「게임을 만든 시각」(`createdAt`) 하나뿐이었고 그것은 오프라인에도 흐른다(특수상단 방문 주기의 시계 · §8-3). 플레이한 시간을 재는 값은 세이브에 없었다.

## 근거

- **「정말 플레이한 시간」** (사용자) — `createdAt` 부터 흐른 시간은 꺼 둔 시간까지 든다. 방치형이라 그 차이가 크다. 그래서 새 누적 값을 세이브에 두고 **보이는 동안만** 더한다
- **숨긴 탭은 안 센다** — 원정은 숨긴 탭에서도 앱 시계가 민다(ADR-0102). 하지만 그 시간은 보고 있지 않은 시간이라 「플레이」가 아니다. 브라우저가 숨긴 탭의 눈금을 1분까지 늦추므로 셀 정확도도 안 나온다
- **절전 공백은 안 센다** — 앱 시계의 멈춤 문턱(`FROZEN_GAP_MS`)을 넘은 공백은 더하지 않는다. 멈춤 판정과 같은 문턱이라 「껐다 켠 것과 같이 본다」(ADR-0102)와 같은 답이다
- **세이브 버전은 안 올린다** — 필드가 없으면 `0` 부터 센다. 흘러간 플레이 시간은 어디에도 없어 되살릴 판단이 없다(INTERFACE §4 의 「판단이 없으면 절을 안 쓴다」)
- **플레이 시간만의 저장은 없다** — 누적 값은 다른 저장(라운드 정산 · 조작)에 실려 간다. 세이브를 따로 한 번 더 쓰면 **같은 게임을 연 다른 탭이 멈춘다**(다른 탭이 세이브를 쓰면 멈춤 창 · §2-1 · ADR-0112) — 그래서 마지막 저장 뒤의 몫은 버린다

**버린 안**

1. **`createdAt` 부터 흐른 시간** — 저장이 필요 없지만 꺼 둔 시간까지 든다(사용자가 원한 것이 아니다)
2. **이번 접속의 시간** — 새로고침하면 0 이 된다
3. **숨긴 탭도 센다** — 켜 놓고 다른 일을 한 시간까지 플레이로 친다
4. **매 초 저장** — 원정이 없어도 세이브와 클라우드 올리기가 쉬지 않고 돈다 · 아래 5 와 같은 이유로 다른 탭을 멈춘다
5. **닫힐 때(`pagehide`) 저장** — 한 번 넣었다가 같은 날 걷었다. 탭 A 에서 게임하다 새 탭 B 를 열고 A 를 닫으면, A 의 마지막 저장이 B 를 **멈춤 창에 세웠다**(헤드리스 두 창 재현 — 원본은 B 가 그대로 돈다). 숨길 때(`visibilitychange`) 저장도 같다 — 탭을 오갈 때마다 떠나는 탭이 써서 돌아온 탭이 멈춘다

## 파급

- 세이브 `playMs` · `game.addPlayTime(state, ms)` 신설(INTERFACE §2-7 · §4) · `dev/test.js` 단정
- `app.js` — `renderShell` 이 ⚙ 앞에 칸을 세운다 · `expTick` 이 `playTick` 을 부른다 · **저장 시점은 안 바뀐다**(다른 탭 멈춤 규칙이 그대로다)
- i18n `ui.playTime` · `style.css .play-time`
- §10-2 카드 전/후 버튼은 이제 플레이 시간 왼쪽이다
- ⚠ 마지막 저장 뒤의 몫은 끄면 빠진다 — 원정이 돌면 라운드마다 저장하므로 대개 그 간격 안쪽이지만, 원정 없이 조작도 없이 보고만 있던 시간은 통째로 빠질 수 있다. 채우려면 멈춤 규칙이 안 보는 **별도 저장소 키**에 적어 두고 다음 부팅에 합치는 길이 있다(미착수)
- ⚠ 화면을 켜 두고 자리를 비운 시간은 센다 — 입력이 없는 시간을 빼는 규칙은 없다
