# ADR-0358 — 인게임의 속도 이름은 「공격 속도」 하나다 · 「행동 주기」를 화면에서 걷는다

| | |
|---|---|
| **상태** | 확정 · 2026-09-25 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) · §7 · §4-2 · §12 |
| **정한 사람** | 사용자 지시 — 「인게임에서 행동주기라는 이름을 모두 삭제하고 그냥 공격속도로 통일해」 |
| **대체** | [ADR-0357](0357-무기-툴팁의-속도-줄은-행동-주기-초다-초당-공격속도를-걷는다.md) 의 **이름 하나**(「속도 줄의 이름은 행동 주기다」) — 값이 초 / 1회라는 것은 산다 |
| **대체됨** | — |

## 결정

화면에 찍히는 속도 축의 이름을 전부 **「공격 속도 / Attack Speed」**로 바꾼다. 값은 그대로 **초 / 1회**(`1.60초`)다. 바뀌는 자리:

- `combat_stat.csv:action_period` 의 이름 — 세부 옵션 머리 행 · 무기 툴팁 속도 줄 · 유닛 툴팁이 여기서 읽는다
- 스킬 창의 속도 줄(`sk.cycle`) · 관전 행동 게이지의 title(`bt.actTitle`)
- 버프 효과 구절 — `sk.eff.period_pct` · `.neg` · `bt.effect.period.up` · `.down` — **부호를 뒤집는다**: 주기를 줄이는 창은 「공격 속도 +」, 늘리는 창은 「공격 속도 −」
- 도움말(`sk.slots.note`) — 「행동 주기가 오면」 → 「차례가 오면」 · 「쿨이 행동 주기의 정수배」 → 「쿨이 공격 속도(초)의 정수배」
- `skill.csv` 헤이스트 · 바인드의 `desc_kr`

기획 용어 「행동 주기」와 축 id `action_period` 는 그대로다 — 문서 · 코드의 이름이지 화면의 이름이 아니다.

## 맥락

같은 날 ADR-0357 이 무기 툴팁의 속도 줄을 초로 바꾸면서 이름을 「행동 주기」로 맞췄다(그날 초 값은 다섯 자리에서 행동 주기로 불렸다). 그것을 본 사용자가 인게임에서는 「행동 주기」를 쓰지 말고 「공격 속도」 하나로 하자고 했다. 옵션 · 마스터리 · 방어구 갈래의 변화량은 이미 「공격 속도 +%」였다.

## 근거

- **플레이어가 아는 말은 공격 속도다** — 옵션 「공격 속도 +5%」와 그 옵션이 움직이는 값이 한 이름을 갖는다. 밑수와 변화량이 같은 이름의 두 층인 것은 물리 방어(implicit ↔ `def_flat`)와 같은 모양이다
- **버프 구절의 부호를 뒤집는다** — 이름만 갈면 「행동 주기 −20%」(빨라진다)가 「공격 속도 −20%」(느려진다)로 읽힌다. 창의 식은 `주기 × (1 − 값)` 이고 옵션 `aspd_pct` 도 같은 식이라, 「공격 속도 +20%」는 옵션과 **같은 뜻 · 같은 수**다
- **도움말의 「행동 주기가 오면」은 「차례가 오면」** — 그 문장은 속도가 아니라 차례를 말한다. 「공격 속도가 오면」은 말이 안 된다
- ⚠ **ADR-0081 이 버린 안을 다시 쓴다** — 그 ADR 은 「라벨만 공격속도, 값은 주기」를 「이름과 방향이 반대라 틀린 것을 크게 찍는다」며 버렸다. 이번 값은 **단위 「초」를 달고** 선다 — 맨 숫자 1.30 이 아니라 「1.30초」라 무엇을 재는지는 읽힌다. 다만 **숫자가 클수록 느리다**는 방향 반전은 남는다(공격 속도 옵션을 올리면 이 숫자가 내려간다). 경고한 뒤 사용자 판단을 따랐다(기획 조언 원칙 4)

**버린 안**

1. **「행동 주기」 유지**(ADR-0357) — 사용자가 인게임 이름으로 거절했다
2. **「공격 간격」** — 숫자와 방향이 맞는 이름이지만, 사용자가 「공격 속도」 하나를 골랐다
3. **이름은 공격 속도, 값은 회/초로 되돌린다** — 방향은 맞지만 같은 날의 「공격에 걸리는 시간으로 통일」(ADR-0357)을 뒤집는다

## 파급

- i18n 8키의 문구 — 키 이름은 그대로다. `bt.effect.period.up` 은 **주기**가 느는 쪽이라 문구는 「공격 속도 감소」다
- `combat_stat.csv:action_period` 의 `stat_kr` · `stat_en` · `skill.csv` 두 줄의 `desc_kr`
- 영어 이름도 하나가 된다 — 그날의 `Action Period` · `Action Cycle` 이 둘 다 `Attack Speed`
- ⚠ 무기 툴팁 한 장 안에 같은 이름이 두 층으로 선다 — 메인 옵션 「공격 속도 1.60초」(밑수)와 옵션 줄 「공격 속도 +5%」(변화량). 의도된 모양이다
- ⚠ 기획 문서(game_design)와 코드 주석은 「행동 주기」를 축 이름으로 계속 쓴다 — 화면 이름과 기획 용어가 갈린다
