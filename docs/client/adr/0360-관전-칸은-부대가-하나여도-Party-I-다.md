## 결정

상단바 원정 세그먼트의 관전 칸은 **부대 수가 몇이든 부대마다 한 칸이고 글자는 부대 이름**(「Party I」 …)이다. 부대가 하나뿐인 판도 「Party I」 칸 하나가 선다. 상태(없음 · 도는 중 · 끝남)는 **색만** 든다 — 회색 · 파랑 · 빨강(ADR-0147 의 색 그대로).

## 맥락

2026-09-25 에 편성이 원정 랭크로 열리게 되면서(R156) 새 게임은 편성 1 · 부대 1 로 시작한다. ADR-0316 은 「부대가 하나면 옛 칸 하나(글자가 상태를 따른다)」라서, 새 게임에서는 세그먼트에 「전투 관전」 · 「전투 중」 · 「전투 종료」가 섰다. 관리자 모드(모든 건물 최대 랭크 · SCREEN_DESIGN §10-3)를 켜면 편성이 셋으로 열려 「Party I」 · 「Party II」 · 「Party III」 가 섰다 — 같은 화면이 관리자 모드를 켜고 끄는 것만으로 모양이 바뀌었다.

## 근거

- **부대는 이제 자라는 것이다.** 편성(= 부대)이 원정 r3 · r6 으로 늘어나므로 새 게임의 한 칸은 「부대가 하나뿐인 판」이 아니라 「Party I 하나가 열린 판」이다. 처음부터 같은 이름으로 서 있어야 r3 을 지었을 때 옆에 「Party II」가 붙는 것으로 읽힌다 — 한 칸의 글자가 「전투 중」에서 「Party I」로 바뀌며 칸이 느는 것보다 인과가 곧다(통제성)
- **편성 탭 · 출정 창과 같은 이름이다.** 편성은 하나여도 「Party I」로 선다(§15). 세그먼트만 다른 이름을 쓰면 같은 대상이 두 이름을 갖는다
- **ADR-0316 이 버린 근거 — 「1부대는 뜻 없는 번호」.** 부대 수가 고정이던 때의 판단이다. 부대가 건물로 늘어나는 뒤로는 번호가 「다음 부대가 올 자리」를 말한다
- **잃는 것 — 한 칸일 때 상태를 글자로 읽던 것.** 상태는 여러 칸일 때와 같이 색이 든다. 색만으로 못 읽는 끝남(빨강)은 관전 화면의 결과 띠가 글자로 말한다

## 파급

- i18n `exp.seg.live` · `exp.seg.over` 삭제 — `exp.seg.battle`(「전투 관전」)은 도움말 제목으로만 산다
- `app.js:expNavBox` 의 한 칸 분기(`id: 'battle'`) 삭제 — 칸 id 는 늘 `battle{n}` 이고 누르면 `watchBattle(n)`
- ⚠ 색만으로 상태를 읽어야 해서 색을 구분하기 어려운 유저에게는 한 칸일 때도 상태 글자가 없다 — 여러 칸일 때와 같은 한계
