# ADR-0363 — 제련소 탭 맨 위에 영웅 띠가 선다

| **대체** | — |
| **대체됨** | — |

## 결정

제련소 탭 맨 위에 **상점 탭과 같은 영웅 띠**(§5)가 선다 — 그 아래 작업 탭(패널 박스 바로 위 · ADR-0281)과 패널이 그대로 선다. 띠는 박스의 머리라 스크롤해도 서 있다. **카드 누르기 = 영웅 고르기**이고 캐릭터 · 상점 탭과 **같은 「고른 영웅」**(파란 겉 테두리)이다. 카드에 올리면 영웅 유닛 툴팁이 뜬다. **해고 · 순서 바꾸기는 없다.**

## 맥락

그날 제련소 탭은 작업 탭(제작 · 강화 · 크래프트) 아래 패널 하나였고 영웅이 서는 자리가 없었다 — 배치 줄도 걷혀 있었다(ADR-0191). 영웅 띠는 편성 · 캐릭터 · 상점 세 자리에 섰다(ADR-0359).

## 근거

- **장비를 만들고 올리는 자리에서도 「누구의 장비인가」가 보여야 한다** — 상점에 띠를 세운 근거(ADR-0359)와 같다. 띠 없이는 영웅이 무엇을 끼고 있는지 보려고 캐릭터 탭을 오가야 했다 — 카드 툴팁이 착용 장비 3×3 을 든다
- **상점과 같은 띠 · 같은 옵션이다** — 새 모양을 만들지 않는다. 고른 영웅이 캐릭터 · 상점 탭과 하나인 이유, 툴팁을 켜는 이유(아래에 같은 값을 든 칸이 없다 · ADR-0116 의 이유가 성립하지 않는다), 해고 · 순서 바꾸기를 안 다는 이유도 ADR-0359 그대로다
- ⚠ **ADR-0359 가 경계한 「눌러도 변화가 없는 띠」에 걸린다** — 상점은 고른 영웅이 상단 장비 툴팁의 비교 상대지만, 제련소 안에는 고른 영웅이 바꾸는 것이 아직 없다(보이는 것은 파란 테두리뿐). 사용자 지시가 띠만이라 비교 · 필터(강화 목록을 그 영웅의 착용품으로 좁히기 · 제작 줄의 비교 카드 등)는 이 결정에 넣지 않았다

## 파급

- §5 띠의 자리가 넷(편성 · 캐릭터 · 상점 · 제련소) · 「골랐다」 표시와 툴팁 행에 제련소 띠 · §2 유닛 툴팁의 서는 자리 여섯 · §2 박스 규격 · §1 지도의 제련소 줄
- 제련소 박스의 세로를 띠가 먹는다 — 제작 종류 목록은 줄 높이를 남는 세로에 맞춰 나누므로(§8-2) 줄이 그만큼 낮아진다
- i18n 새 키 없음 — 띠는 캐릭터 · 상점 탭의 것 그대로다
- ⚠ 고른 영웅을 제련소에서 무엇에 쓸지는 열려 있다
