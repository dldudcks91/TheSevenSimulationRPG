# ADR-0364 — 강화는 고른 영웅의 장비칸과 아이템창에서 대상을 고른다

| | |
|---|---|
| **상태** | 확정 · 2026-09-27 |
| **화면** | [SCREEN_DESIGN §8-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 「부위별 강화방식을 수정 · 클릭된 영웅의 장비가 왼쪽에 · 아래에 아이템창을 캐릭터처럼」 · 해석(부위 필터 목록을 걷는다)과 도구 줄 포함은 질문 후 사용자 선택 |

## 결정

제련소 강화 탭의 **부위 필터 + 세로 목록**(착용 + 인벤토리 + 창고 전부)을 걷는다. 대신 **왼쪽에 띠에서 고른 영웅의 장비칸**(캐릭터 탭 페이퍼돌과 같은 칸), **오른쪽에 작업 패널**(그대로), **패널 아래에 캐릭터 탭과 같은 아이템창**(창고 | 인벤토리 · 도구 줄까지 그대로)이 선다. 장비칸 · 아이템창의 칸 클릭은 **강화 대상 고르기**다 — 벗기거나 장착하지 않는다. 고른 칸은 강조 테두리를 두른다.

## 맥락

그날 강화 탭은 「목록 | 작업 패널」 2단이었다 — 목록 머리의 부위 필터(`전체` + 부위 실루엣)로 좁히고, 줄마다 이름 · 부위 · ilvl · 착용/가방 · `+n` 을 찍었다. 누가 끼고 있는지는 줄의 「착용 중」 태그가 전부였다. 바로 앞의 ADR-0363 이 제련소 맨 위에 영웅 띠를 세웠지만 고른 영웅이 제련소 안에서 바꾸는 것은 없었다.

## 근거

- **장비는 영웅 단위로 생각한다** — 「누구의 무엇을 올릴까」가 강화의 질문이다. 캐릭터 탭과 같은 장비칸 · 아이템창이면 같은 눈으로 읽힌다 — 새 목록 모양을 배우지 않는다
- **ADR-0363 의 「눌러도 변화가 없는 띠」가 풀린다** — 띠에서 고른 영웅이 곧 왼쪽 장비칸이다
- **부위 필터는 할 일이 없어진다** — 장비칸은 부위 자리대로 서 있고 아이템창은 [정렬](부위순)이 있다
- **클릭 = 고르기** — 벗기기 · 장착을 여기서도 하면 강화하려고 누른 칸이 벗겨지는 사고가 난다. 같은 칸 모양이 탭마다 다른 일을 하는 비용은 받아들였다 — 캐릭터 탭은 장비를 바꾸는 곳, 제련소는 고르는 곳이다
- **도구 줄은 캐릭터 탭 그대로** — 「칸만」(파괴 버튼을 섞지 않는다)도 제시했으나 사용자는 도구 줄까지를 골랐다. 고르는 중 · 잠그는 중이면 칸 클릭이 캐릭터 탭과 같은 일을 한다 — 파선 테두리가 모드를 말한다(ADR-0207)

## 파급

- `storagePanel` · `itemsPanel` · `paperdoll` 이 **고르기 콜백**을 받는다 — 없으면 캐릭터 탭 동작 그대로
- `state.forgeFilter` · i18n `fg.count` · `fg.empty` 삭제 · `fg.pick` 문구 「장비를 고른다」(「왼쪽에서」를 뺐다 — 아래에서도 고른다)
- 제련소 박스의 세로를 아이템창이 먹는다 — 캐릭터 탭과 같은 배분(아이템창이 제 높이 · 모자라면 칸이 스크롤)
- 목걸이 · 반지는 고를 수 있고 작업 패널이 `강화 없음` 으로 선다 (ADR-0125 의 뜻)
