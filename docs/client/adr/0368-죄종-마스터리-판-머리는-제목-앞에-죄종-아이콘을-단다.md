# ADR-0368 — 죄종 마스터리 판 머리는 제목 앞에 죄종 아이콘을 단다

| | |
|---|---|
| **상태** | 확정 · 2026-09-27 |
| **화면** | [SCREEN_DESIGN §7](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | — |
| **대체됨** | ADR-0375 — 「직업 판에는 아이콘이 없다」만(직업 판도 직업 아이콘을 단다) |

## 결정

마스터리 창의 죄종 판 머리에서 제목 앞에 그 죄종의 아이콘을 둔다. 그림은 `assets/art/icons/sins/<죄종>.png` 7장이고 경로는 `mock.js:sinIcon` 이 든다. 그림은 스킬 아이콘과 같은 규격의 회색 단색 실루엣이며, 화면은 이것을 CSS 마스크로 쓰고 판 색(`--mastery-color`)으로 칠한다. 적용 범위는 **마스터리 죄종 판 하나**다. 판 머리를 공유하는 도감 마스터리 세그먼트의 죄종 판에도 같이 뜬다.

## 맥락

죄종 판은 태그(「죄종」)·제목(「분노 마스터리」)·판 테두리 색으로만 어느 죄종인지 알렸다. 죄종은 화면 여러 곳(영웅 카드 · 툴팁 · 챕터 줄 · 도감)에서 색 글자 칩(`sin-chip`)으로만 나온다. 죄종 아이콘 7종은 이날 스킬 아이콘 선 굵기(512px 에서 실선 21 · 파낸 선 15)와 긴 변 0.88 에 맞춰 새로 그렸다.

## 근거

- **마스터리 판만** — 사용자가 「일단」 한 곳에 적용해 보자고 골랐다. `sin-chip` 전체에 아이콘을 붙이는 안(한 곳을 고치면 모든 죄종 표시가 바뀐다)은 적용 범위가 넓어 뒤로 미뤘다
- **파일은 회색 한 벌, 색은 화면이 칠한다** — 죄종색으로 구운 PNG 를 7장 더 두면 `mock.js:SINS` 의 색과 그림 색이 두 군데서 관리된다. 마스크로 칠하면 판 색이 바뀌어도 그림을 다시 뽑지 않는다
- **직업 판에는 아이콘이 없다** — 직업 아이콘이 아직 없다. 두 판의 머리 모양이 달라지는 것을 받아들였다. 머리 높이(`.sk-box-head` 최소 높이)는 그대로라 첫 줄 정렬은 깨지지 않는다

## 파급

- `mock.js:SIN_ICON_DIR` · `sinIcon` 신설 · `app.js:masteryBox` 머리 · `style.css:.sk-sin-icon`
- 그림 원본 `assets/art/icons/sins/source.html`(SVG — 다시 뽑을 때 이것을 512 로 렌더한다)
- ⚠ 열린 채 남은 것 — `sin-chip` 에 아이콘을 붙일지 · 직업 판 아이콘
