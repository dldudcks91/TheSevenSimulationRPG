# ADR-0374 — 손가락 입력은 길게 눌러 툴팁을 열고 · Alt 와 우클릭은 툴팁 아래 버튼이 든다

## 결정

**입력마다** 가른다 — 마지막 포인터 입력(`pointerdown` · `pointermove` 의 `pointerType`)이 `touch` 면 손가락 방식, 아니면 지금 방식이다. 가르는 곳은 `tip.js` 하나다.

- **길게 누르기(약 0.45초) = 툴팁** — `[data-tip]` 칸을 누르고 있으면 그 칸의 툴팁이 선다. 손을 떼도 남고, 그 누르기의 클릭은 삼킨다. 손가락이 드래그 임계(4px)만큼 움직이거나 브라우저가 스크롤로 가져가면(`pointercancel`) 취소한다
- **툴팁 밖을 탭하면 닫힌다** — 그 탭은 삼키지 않는다(제 할 일도 한다)
- **손가락이 연 툴팁 아래 버튼 줄** — **[세부]** 는 Alt 상태를 켜고 끈다(툴팁이 닫히면 꺼진다 · `data-alt` 칸이 있을 때만) · 칸이 준 **행동**(`bindTipNode` 의 `actions` — 스킬 창 칸의 [되돌리기])
- **손가락이 낸 가짜 마우스 이벤트는 툴팁이 무시한다** — 브라우저는 탭마다 `mouseenter` 를 흉내 내 쏜다. 그대로 두면 탭 = 툴팁 + 클릭이 겹친다
- 손가락으로 연 툴팁은 **포인터를 받는다**(`.interactive`) — 버튼을 눌러야 하고, Alt 동안의 장비 칸 탭(ADR-0176)도 이 길로 된다

## 맥락

- ADR-0371 로 폰에서 가로 한 장이 서게 됐고, 사용자가 「모바일에선 방식이 다르게」 조작이 되길 원했다
- 코드에서 마우스 · 키보드 전용이던 것은 셋이었다 — hover 툴팁(`bindTipNode` · 호출 25곳) · Alt 세부 옵션 · 계산식(`setAlt`) · 마스터리 칸 우클릭 되돌리기. 클릭 · 진형 드래그(포인터 이벤트 · `touch-action: none`) · 스크롤은 손가락으로도 됐다
- 아이폰 사파리는 길게 눌러도 `contextmenu` 를 안 쏜다 — 우클릭 되돌리기에 닿을 길이 없었다

## 근거

- **기기가 아니라 입력으로 가른다** — `pointer: coarse` 는 기기 성질이라 터치 노트북에서 마우스를 쓰는 사람도 손가락 방식이 된다. 마지막 입력을 보면 둘 다 제대로 된다
- **길게 누르기** — 모바일 게임의 관례다. 「첫 탭 = 툴팁 · 두 번째 탭 = 실행」은 모든 조작이 두 번이 되고, 되돌릴 수 없는 행동의 「두 번 누르기」(§3)와 겹쳐 뜻이 흐려진다
- **Alt 는 토글 버튼** — 손가락에는 「누르는 동안」을 유지하며 다른 곳을 볼 손이 없다. 툴팁이 닫히면 꺼지므로 ADR-0089 가 걱정한 「켜 둔 걸 잊는다」가 툴팁 한 장을 넘지 않는다
- **되돌리기는 툴팁 안** — 길게 누르기를 툴팁이 가져가서 되돌리기의 자리가 따로 필요하다. 칸이 보여 주는 설명 바로 아래라 무엇을 되돌리는지가 보인다
- **바깥 탭은 삼키지 않는다** — 삼키면 툴팁을 읽고 장착하는 흐름이 탭 두 번이 된다

**버린 안**

1. **첫 탭 툴팁 · 두 번째 탭 실행** — 위 근거
2. **기기 판정(`pointer: coarse`)으로 방식을 통째로 바꾸기** — 터치 노트북에서 마우스가 죽는다
3. **Alt 를 화면 고정 버튼으로** — 툴팁 밖에 늘 선 버튼이 한 장을 덮고, 켜 둔 것을 잊는다

## 파급

- `tip.js` — `bindTipNode({ actions })` · 길게 누르기 · 바깥 탭 · 가짜 마우스 무시 · 버튼 줄 · `isTouchInput` · `moveTip` 이 버튼 줄 높이를 잰다
- `app.js:masteryBox` — 칸에 [되돌리기] 행동 · 손가락이 낸 `contextmenu`(안드로이드 길게 누르기)는 되돌리지 않는다
- i18n `tip.touch.alt` · `sk.unlearn` · style.css `.tip-touch`
- ⚠ **열린 것** — 손가락으로 연 툴팁이 떠 있는 동안 앱 시계의 다시 그리기가 미뤄진다(`handBusy` — 마우스 hover 와 같은 규칙이나, 손가락은 바깥을 탭해야 풀린다) · 실기기 확인 전이다 · 배율 약 0.49 인 폰 가로에서 글자 크기는 이 결정 밖이다
