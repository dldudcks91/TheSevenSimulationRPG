# ADR-0378 — 죄종 마스터리 칸 그림은 한 틀 메달이고 판 색으로 칠한다

|---|---|

| **화면** | [SCREEN_DESIGN §7](../SCREEN_DESIGN.md) |

| **대체** | — |
| **대체됨** | ADR-0380 — 틀만(원판을 통째로 칠하는 메달 → 고리와 기호 선만 칠함). 기호 · 한 벌 파일 · 판 색 마스크는 유지 |

## 결정

죄종 마스터리 칸 24개(공통 3 + 죄종 고유 21)의 그림을 **한 틀 메달**로 바꾼다 — 바깥 고리 · 틈 · 안쪽 원판에 가운데 기호를 파낸 모양이고, 틀은 24장이 픽셀까지 같다. 기호는 정면 · 정지이고 노드의 테마 이름을 그린다(격분 = 불꽃 · 미다스의 손 = 동전 쥔 손 …). 파일은 회색 한 벌(`icons/mastery/sin/<node_id>.png`)이고 칸과 툴팁이 **판 색 마스크**로 칠한다 — 죄종별 변형 PNG 를 읽지 않는다.

## 맥락

옛 칸 그림은 코드가 그린 원형 봉인 문양(`generate.ps1`)이었고 죄종별로 색을 구운 변형 PNG(`nodes/variants/<죄종>/`)를 따로 두었다. 같은 날 스킬 · 직업 아이콘이 Gemini 단색 실루엣 그림체로 정리되면서 마스터리만 그림체가 달랐다. 같은 날 죄종 마스터리 이름이 T1 = 능력치 이름 · T2 = 테마 이름으로 바뀌었다(GAME_DESIGN §9 09-27).

## 근거

- **마스터리끼리 한 가족 · 스킬과는 모양으로 갈린다** — 사용자 요구. 틀을 공유하면 기호만 바뀌어 가족으로 읽히고, 스킬 아이콘은 물건 모양 실루엣이라 둥근 메달과 모양만으로 갈린다
- **C 를 고른 이유** — 네 시안 중 B(고리 + 양각 기호)는 방패 스킬(`kni_defiance`)과 같은 모양이라 섞으면 안 갈렸다. A(꽉 찬 음각 메달) · D(팔각 판)도 가족 느낌은 같았고 D 가 스킬과 가장 멀었지만 사용자가 C 를 골랐다
- **틀은 코드가 한 벌 찍는다** — 이미지 생성기에 틀까지 그리게 하면 장마다 고리 굵기 · 장식이 갈려 가족 느낌이 깨진다
- **정면 · 정지** — 대각선 · 움직임은 스킬 그림의 문법이다
- **색은 화면이 칠한다** — 판 색(`mock.js:SINS`)과 그림 색을 두 곳에서 관리하지 않는다. 죄종 판 머리 아이콘(ADR-0368)과 같은 방식이다

## 파급

- `app.js:masteryIconPath`(죄종 판 → `icons/mastery/sin/`) · `masteryIconHtml` 신설(칸 · 툴팁 공통) · `style.css:.sk-icon-mask`
- 원본은 코드로 그린 SVG — 임시 그림이 아니라 설치본이지만, 기호는 이미지 생성기로 다시 뽑아 같은 틀에 합성할 수 있다
- ⚠ 열린 채 남은 것 — 직업 판 칸은 옛 봉인 문양 그대로(색 구운 PNG) · 옛 죄종 변형 PNG(`nodes/variants/<죄종>/` · `nodes/sin_*`)는 안 읽히지만 지우지 않았다
