# ADR-0380 — 죄종 마스터리 칸 그림은 직업 판과 같이 고리와 기호 선만 칠한다

## 결정

죄종 마스터리 칸 24개의 그림을 **원 고리 + 양각 기호**로 바꾼다 — 고리와 기호만 판 색으로 칠하고 안쪽은 칸 바탕 그대로 비운다. 직업 판 봉인 문양과 같은 칠이다. 기호(테마 이름 그림 — 격분 = 불꽃 등) · 회색 한 벌 파일(`icons/mastery/sin/<node_id>.png`) · 판 색 마스크 · 칸 안 크기(직업 문양과 같은 칸의 75.5%)는 ADR-0378 그대로다.

## 맥락

ADR-0378 은 같은 날 원판을 통째로 칠하는 메달(시안 C)을 설치했다. 직업 판은 옛 봉인 문양(고리 + 기호 선)이라 한 창 안에서 죄종 판만 색 면이 크고 강했다. 비교 시안(원형 고리 · 팔각 테두리 · 둘 다 선만 칠함)을 궁수 판 옆에 놓고 사용자가 원형을 골랐다.

## 근거

- **직업 판과 같은 칠** — 한 창에 두 판이 나란히 선다. 칠 방식이 다르면 한쪽이 튄다
- **원형 · 팔각 중 원형** — 팔각은 죄종 판과 직업 판을 모양으로 가르지만, 사용자는 마스터리 전체의 통일을 택했다. 판 종류는 판 색과 판 머리 아이콘(ADR-0368 · ADR-0375)이 가른다
- **스킬과의 구분** — 비교 시안에서 원 고리 + 양각 기호(B)는 방패 스킬(`kni_defiance`)과 모양이 겹쳤다. 마스터리는 판 색 · 칸 안 크기 · 랭크 숫자로 갈린다 — 스킬 아이콘은 판 색을 안 쓴다

## 파급

- 그림 24장 교체 · `style.css:.sk-icon-mask` 칸 안 여백(고리가 파일에서 차지하는 비율이 달라졌다)
- 「살의」 단검을 굵게 다시 그렸다(선만 칠하면 가늘어 안 읽혔다)
