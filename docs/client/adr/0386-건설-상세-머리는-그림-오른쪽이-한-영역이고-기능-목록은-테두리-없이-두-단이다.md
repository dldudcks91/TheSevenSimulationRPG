# ADR-0386 — 건설 상세 머리는 그림 오른쪽이 한 영역이고 기능 목록은 테두리 없이 두 단이다

## 결정

건설 상세 머리에서 그림(+ 아래 눈금) 오른쪽을 **한 영역**으로 쓴다. 맨 위 줄에 **건물 이름과 상태**가 나란히 서고, 그 아래에 지은 랭크까지 연 기능이 **테두리 · 바탕 없이 두 단**으로 흐른다. 넘치면 영역 안에서 스크롤한다.

## 맥락

ADR-0383 로 기능 목록이 이름 오른쪽의 테두리 칸에 섰다. 같은 날 사용자가 「UI 가 좀 보기 불편한데 오른쪽 위에 교통정리 좀 해 줄래 · 박스가 구분되게 그릴 필요는 없을 것 같다」 라고 했다. 그날 화면에서 이름 · 상태는 그림과 칸 사이의 좁은 열에 끼었고, 칸 테두리가 머리를 두 덩어리로 갈랐으며, 기능 글은 넓은 칸의 왼쪽 위 구석에 몰렸다.

## 근거

- **열 셋 → 둘** — 그림 | 글. 이름 · 상태와 기능이 같은 글 영역에 위아래로 서서 읽는 순서가 하나다(무엇인가 → 무엇을 여나)
- **테두리 없음** — 머리 안의 구분은 자리와 글자 크기가 한다. 상세 전체가 「상자 없이 글」(ADR-0324)이라 문법도 맞는다
- **두 단** — 기능 줄이 짧은 토막(「장비 강화」 · 「편성 +2」)이라 한 단이면 높이를 넘고 오른쪽이 빈다. 두 단이면 머리 높이 안에 든다
- 버린 안 — 이름 아래 한 단(넘치면 스크롤이 잦다) · ADR-0383 의 따로 선 칸(사용자가 불편하다고 했다)

## 파급

- `app.js:buildingSide` 가 이름 줄과 기능 목록을 한 영역(`.cn-head-info`)으로 묶는다 · CSS `.cn-cur` 테두리 · 바탕 삭제, `columns: 2`
- 눈금이 그림 아래인 것(ADR-0383)은 그대로다
