# ADR-0387 — 재료 탭은 일곱 단계를 전부 세운다

## 결정

인벤토리 재료 탭은 채광 · 채집 · 벌목 줄마다 **표의 단계 전부(1 ~ 7)** 를 세운다. 진행 챕터는 보지 않는다. 0 개인 칸은 흐리게 서고, 안 열린 단계라고 따로 표시하지 않는다.

## 맥락

ADR-0379 는 같은 날 「진행 챕터까지만 세우고, 그 위 단계는 가진 것만 세운다」로 정했다. 그러면 챕터 1 에서는 줄마다 한 칸만 선다. 사용자는 이 범위를 7단계 전부로 넓히라고 지시했다.

## 근거

- **「고정」이 챕터를 넘어 고정된다** — 진행에 따라 칸이 늘어나면 칸 자리가 챕터마다 바뀐다. 일곱 칸이 늘 서 있으면 「몇 단계에 무엇이 있나」가 처음부터 한눈에 읽힌다
- **칸 수가 격자 안에 든다** — 줄 머리 1 + 7단계 = 8칸이라 장비 격자 한 줄(12칸)에 들어간다. 패널 크기는 그대로다
- ADR-0379 가 이 안(「7단계 전부 고정」)을 버린 근거는 「초반 화면 대부분이 흐린 칸」이었다. 사용자는 그것을 알고서 전부 보이는 쪽을 골랐다. 안 열린 단계를 따로 흐리게 하는 표시는 넣지 않는다 — 0 개 칸이 이미 흐리다

## 파급

- `game.materialsState` — 걸러내는 단계와 `chapter` 필드를 걷는다(INTERFACE §2-7) · 단정 `materials:` 개정
- 렌더러 · CSS 는 그대로다 — 서는 칸이 늘 뿐이다
