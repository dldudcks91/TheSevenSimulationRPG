# ADR-0391 — 「다음 랭크」 의 재료 칸과 [건설]은 여는 것 · 조건 글 오른쪽에 선다

## 결정

건설 상세 「다음 랭크」 는 **두 열**이다 — 왼쪽에 「랭크 n」 · 여는 것 문장 · 조건 줄, **오른쪽에 재료 칸과 [건설]**(한 줄 · [건설]이 오른쪽 끝). 다 지었거나 준비 중이면 오른쪽이 없다.

## 맥락

같은 날 상세가 한 열이 되며(ADR-0388) 「다음 랭크」 는 글 아래에 재료 칸 줄이 따로 서서 세로를 먹었고, 그 아래 랭크 목록이 1600×800 에서 네다섯 칸만 보였다. 사용자가 「재료와 건설 버튼을 필요 · 적용 글 오른쪽으로」 라고 지시했다.

## 근거

- **세로를 아낀다** — 한 열이 되며 넓어진 폭의 오른쪽이 비어 있었다. 재료 칸 줄을 옆으로 올리면 「다음 랭크」 높이가 글 높이로 줄고 랭크 목록이 그만큼 더 보인다
- **읽는 순서** — 무엇을 여나 · 무엇이 필요하나(왼쪽) → 무엇을 내나 · 짓는다(오른쪽). 결정 버튼이 오른쪽 끝인 것(ADR-0388)은 그대로다
