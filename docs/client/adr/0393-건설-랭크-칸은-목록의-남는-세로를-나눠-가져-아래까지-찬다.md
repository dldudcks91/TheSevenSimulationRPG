# ADR-0393 — 건설 랭크 칸은 목록의 남는 세로를 나눠 가져 아래까지 찬다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §13-1](../SCREEN_DESIGN.md) |

| **대체** | — *(ADR-0392 의 두 줄 최소는 그대로 · 그 위에 더한다)* |
| **대체됨** | — |

## 결정

건설 상세 랭크 목록의 칸은 **최소 글 두 줄**(ADR-0392) 위에 **목록의 남는 세로를 똑같이 나눠 가진다** — 목록이 상세 아래 끝까지 찬다. 글이 긴 칸은 제 높이에 같은 몫을 더 받는다. 칸 수가 적은 건물은 칸이 그만큼 높아진다.

## 맥락

두 줄 기준으로 모든 랭크가 한 화면에 들자 목록 아래에 빈 세로가 남았다(7랭크 건물 · 「다음 랭크」 가 짧은 판에서 더 크다). 사용자가 「약간만 더 크게 · 아래까지 꽉 차게 잘 나눠 써 봐」 → 「2.5 줄로 키울 필요까지는 없고 그냥 아래에 남는 칸을 모두 쓰라고」 라고 지시했다.

## 근거

- **최소는 두고 남는 것만 나눈다** — 고정 줄 수를 키우면(2.5 줄 안) 「다음 랭크」 가 긴 판에서 7랭크가 넘친다. 남는 세로를 나누면 어느 판에서도 넘치지 않으면서 아래가 빈다는 문제가 사라진다
- 버린 안 — 칸 높이를 목록의 1/7 로 두고 최소 두 줄(칸이 적은 건물은 아래가 빈다 — 사용자가 「남는 칸을 모두」 라고 했다)
