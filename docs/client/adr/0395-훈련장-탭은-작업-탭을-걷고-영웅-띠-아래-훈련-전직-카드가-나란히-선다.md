# ADR-0395 — 훈련장 탭은 작업 탭을 걷고 영웅 띠 아래 훈련 · 전직 카드가 나란히 선다

## 결정

훈련장 탭의 작업 탭 둘(훈련 · 전직)을 걷는다. 탭 맨 위에 **캐릭터 탭과 같은 영웅 띠**(§5)가 서고, 그 아래 **훈련 · 전직 패널 두 장이 나란히**(반반) 선다. 띠의 카드 누르기는 캐릭터 탭 · 상점 · 제련소와 **같은 「고른 영웅」**이다. 두 카드의 속(건물 줄 · 훈련 칸 · 안내)은 탭 시절 그대로다. `&tr=` 딥링크는 고를 탭이 없어 걷는다.

## 맥락

그날 훈련장은 **통째로 목업**이었다(훈련 · 전직 둘 다 `game_logic` 에 없다 · DEV_PLAN R16). 작업 탭은 제련소 문법(ADR-0142 · ADR-0281)을 빌려 고른 하나만 폈고, 전직 탭은 건물 줄 한 줄 + 안내만 들어 거의 비어 있었다. 같은 날 기획이 **전직 = 훈련장 작업**으로 정해졌다 — 갈래 3 중 1 · 되돌릴 수 없다 · 전직 스킬 3 중 1 만 배우고 그것은 자유롭게 되돌린다(GAME_DESIGN §9 09-27).

## 근거

- **두 작업 모두 「영웅을 골라 넣는」 일이다** — 훈련도 전직도 대상이 영웅 하나라, 누구에게 할지가 보이는 띠가 맨 위에 있어야 한다. 상점(ADR-0359)과 제련소가 이미 같은 짜임(띠 + 가운데 단)이라 새 모양을 만들지 않는다
- **탭으로 가르면 한 장이 거의 빈다** — 전직 탭은 한 줄뿐이었다. 나란히 세우면 두 작업의 여는 랭크가 한눈에 보이고 탭을 오가지 않는다
- **고른 영웅은 하나다** — 훈련장에서 고른 영웅이 캐릭터 탭에서도 이어진다(ADR-0359 「고른 영웅은 캐릭터 탭과 하나다」와 같은 이유)

- `state.trainingTab` 삭제 · `.tr-tabs` CSS 삭제 · 새 클래스 `.c-train-band` · i18n 새 키 없음(카드 제목은 `tr.seg.train` · `tr.seg.adv` 그대로)
- ⚠ 띠를 골라도 두 카드는 아직 바뀌지 않는다 — 훈련 · 전직 로직이 없다. 전직 카드의 속(고른 영웅 직업의 갈래 셋 · 스킬 셋 · 확정 두 번 누름)은 R16 과 함께 선다
