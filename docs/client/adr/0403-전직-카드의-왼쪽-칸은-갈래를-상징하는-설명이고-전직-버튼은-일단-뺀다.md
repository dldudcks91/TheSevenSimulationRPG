# ADR-0403 — 전직 카드의 왼쪽 칸은 갈래를 상징하는 설명이고 전직 버튼은 일단 뺀다

| | |
|---|---|
| **상태** | 확정 · 2026-09-28 |
| **화면** | [SCREEN_DESIGN §16](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 「전직 버튼 일단 다 빼고 스킬들 오른쪽으로 민 다음에 각 전직을 상징하는 설명이 좀 들어가야 할 것 같은데」 · 설명 문장은 제안 |
| **대체** | ADR-0402 의 왼쪽 칸(갈래 이름 + [전직]) · ADR-0399 의 [전직] 버튼 |

## 결정

전직 카드의 갈래 카드에서 **[전직] 버튼을 뺀다.** 왼쪽 칸은 **갈래 이름 + 그 갈래를 상징하는 설명 한 줄**(`advance.csv:desc_kr` · `desc_en`)이고, 스킬 셋은 오른쪽으로 밀린다(왼쪽 칸이 설명만큼 넓다). 버튼과 함께 「왜 못 하나」 사유 줄도 걷는다. 전직 후의 [배우기] · [되돌리기]는 그대로다.

## 맥락

그날 갈래 카드는 왼쪽 칸에 갈래 이름과 [전직]만 있고 오른쪽에 스킬 셋이 설명과 함께 섰다(ADR-0402). 갈래의 성격(예: 스나이퍼 = 화력을 스킬에 싣는다)은 기획서(skill_design §4-1)에만 있고 화면에는 이름뿐이라, 스킬 셋을 읽고 짐작해야 했다.

## 근거

- **갈래는 되돌릴 수 없는 선택이라 「이 갈래가 무엇인가」가 먼저 읽혀야 한다** — 기획의 갈래 축(skill_design §4-1 — 직업마다 다르다)을 한 줄로 옮긴다. 스킬 설명은 개별 효과, 갈래 설명은 셋을 묶는 성격이다
- **설명은 표(`advance.csv`)가 든다** — 화면에 새 문구를 박지 않는다(다국어 ko/en 나란히 · SSOT)
- **버튼은 사용자가 「일단」 뺐다** — 되살릴 때는 두 번 누름(§3)을 그대로 따른다

## 파급

- `advance.csv` 에 `desc_kr` · `desc_en` 열 · `game.advanceState` 의 갈래가 `desc` 를 든다(INTERFACE §2-7) · 비면 로드가 멈춘다
- ⚠ **전직을 시작하는 자리가 화면에 없다** — 로직(`game.advanceStart`)은 그대로 살아 있다. 개발용으로는 단정 · 콘솔로만 닿는다
- 안 쓰게 된 i18n `tr.adv.go` · `tr.adv.confirm` · `tr.adv.started` 와 화면 상태 `advArm` 은 버튼을 되살릴 때를 위해 남긴다 — 결정이 서면 걷거나 쓴다
