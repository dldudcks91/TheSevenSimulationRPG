# ADR-0404 — 훈련장 카드는 건물 줄을 안 든다 · 안 열린 카드는 잠김 베일로 덮는다

| | |
|---|---|
| **상태** | 확정 · 2026-09-28 |
| **화면** | [SCREEN_DESIGN §16](../SCREEN_DESIGN.md) · §13-1 |
| **정한 사람** | 사용자 지시 「훈련장에서 훈련장 1랭크. 훈련장 3랭크 이렇게 적힌 거 모두 제거」 · 베일은 기존 규칙(§13-1 「덮는 표시는 잠김 베일 하나」) |
| **대체** | ADR-0310 의 「전직 줄은 『훈련장 n랭크』다」(건물 줄) |
| **대체됨** | — |

## 결정

훈련 · 전직 카드 맨 위의 **건물 줄**(「훈련장 n랭크」 + 완료 / 준비 중 / 모자란 조건 / 비용 + [건설에서 짓기])을 걷는다. 그 작업이 **안 열렸으면 카드 본문을 잠김 베일로 덮는다** — 자물쇠 + 「훈련장 n랭크 필요」(`lockVeil` · 몇 랭크인지는 `game.needOf`). 열렸나는 `game.hasFeature` 하나다.

## 맥락

그날 두 카드는 맨 위에 그 작업을 여는 랭크의 줄을 들었다 — 지은 뒤에도 「훈련장 1랭크 완료」 · 「훈련장 3랭크 완료」가 늘 서 있었다(ADR-0310 · R137). 짓기 상태는 건설 탭(§13)이 같은 판정으로 이미 보여 준다.

## 근거

- **지은 뒤의 「완료」 줄은 할 일이 없는 정보다** — 카드의 첫 줄을 늘 차지하면서 누를 것도 바뀔 것도 없다
- **안 열린 상태는 베일이 말한다** — 잠긴 칸을 덮는 표시는 베일 하나로 통일돼 있다(§13-1 · 2026-09-27 사용자 지시). 짓는 길은 건설 탭이 든다
- 베일의 한 줄(「훈련장 n랭크 필요」)은 **안 열렸을 때만** 선다 — 사용자가 걷으라고 한 것은 늘 서 있던 건물 줄이다

## 파급

- `app.js:trainingBuilding` 삭제 · i18n `tr.bld.go` 삭제 · CSS `.tr-bld` 삭제
- ⚠ 훈련장 탭에서 건설 탭으로 바로 가는 버튼이 사라졌다 — 짓는 길은 왼쪽 메뉴의 건설 탭이다
