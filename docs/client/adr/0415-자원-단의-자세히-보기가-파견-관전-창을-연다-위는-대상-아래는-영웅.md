## 결정

자원 탭 각 단의 이름 줄 오른쪽 끝에 **[자세히 보기]** 가 선다(그 단에 앉은 영웅이 없으면 흐리고 안 눌린다). 누르면 창(`#modal`)이 뜬다. 머리는 **앉은 자리마다 탭 하나**(세 파견처를 통틀어 · 첫 탭은 누른 단의 가장 앞 자리)이고, 속은 원정 관전과 같은 **상하 대치** — 위 = 대상 카드(산출물 아이콘 · 단계 이름 · 바 = 다음 1개까지 남은 양) · 아래 = 영웅 카드(얼굴 · 이름 · 레벨 · 담당 능력치 · 산출 속도). 박자마다 영웅이 찌르고 대상이 흔들리며 깎인 % 가 떠오르고, 바가 다 깎이면 「+1 산출물」이 떨어진다. **보기 전용** — 산출 · 세이브 · CSV 를 안 바꾼다.

## 맥락

자원 파견은 단계 상자의 자리 칸에 얼굴과 얇은 게이지 하나로만 보였다. 사용자가 접속 중에 할 일이 부족하다며, 파견을 전투처럼 볼 수 있는 창을 요청했다. 표식(보고 있을 때 손대는 요소)은 기획이 아직 안 섰다(PLAN_dispatch_watch Q1 ~ Q3) — 이번엔 창만 세운다.

## 근거

- **바 = `dispatchProgress.frac` 을 뒤집은 것** — 버린 안: 대상에 체력 수치를 새로 둔다. 새 수치가 생기면 산출 공식과 따로 놀아 창을 연 사람과 안 연 사람의 산출이 갈릴 수 있다. 뒤집기만 하면 바가 한 바퀴 도는 순간이 정산의 1개 틱과 같다
- **여는 자리는 단 이름 줄** — 버린 안: 자리 칸의 선택 창 안에 둔다. 선택 창은 앉히고 빼는 곳이라 보기와 섞이고, 칸 클릭이 이미 선택 창을 연다
- **탭은 앉은 자리 전부** — 버린 안: 파견처마다 창을 따로 연다. 여러 자리를 보낸 사람은 창을 닫았다 열어야 해서, 원정 관전이 부대를 탭으로 바꿔 보는 모양을 따랐다
- **타격은 CSS 모션** — 버린 안: 관전 이펙트(`fx.js`)를 빌린다. `fx.js` 는 재생기 상태를 읽고 설정의 피격 반응 스위치에 묶여 있다
- **대상 그림은 산출물 아이콘** — 활동별 그림이 아직 없다. 없는 그림 자리를 비우는 것보다 이미 있는 재료 그림이 「무엇을 캐나」를 말한다
- **떠오르는 숫자는 %** — 초 단위면 박자마다 늘 같은 값이 떠 정보가 없다. % 는 담당 능력치 · 단계에 따라 달라 속도가 읽힌다
