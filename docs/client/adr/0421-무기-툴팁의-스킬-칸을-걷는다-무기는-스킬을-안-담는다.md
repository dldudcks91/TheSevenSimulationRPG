# ADR-0421 — 무기 툴팁의 스킬 칸을 걷는다 · 무기는 스킬을 안 담는다

| | |
|---|---|
| **상태** | 확정 · 2026-09-29 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 「비교 툴팁 규격」 · §2 「스킬 설명창 규격」 |
| **정한 사람** | 사용자 지시(skill_design §2-1 · PLAN_player_experience §9-7 「칸을 없앤다」) |
| **대체** | ADR-0139 · ADR-0081 의 스킬 블록 · ADR-0051 |
| **대체됨** | — |

## 결정

아이템 비교 툴팁의 **스킬 줄을 없앤다** — 툴팁은 여섯 줄(머리글 · 이름 · 이름 아래 정보 · 메인 옵션 · 옵션 · 힌트)이다. 「스킬 없음」도 안 찍는다. 유닛 툴팁의 장비 hover 카드도 같은 카드라 같이 빠진다.

## 맥락

2026-09-28 기획이 무기가 스킬을 담는 구조를 걷었다(스킬북 · skill_design §2-1). 그날까지 무기 카드 바닥에는 그 무기가 담은 스킬의 설명창 몸통이 섰고, 「이 아이템」 카드의 숫자는 장착 대상 영웅이 그 무기를 낀 값으로 따로 계산했다(`game.heroCombatIf`).

## 근거

- 무기 개체에 스킬이 없으니 칸이 들 것이 없다. 「스킬 없음」을 모든 무기에 찍으면 정보가 아니다(§4-3 「언제나 0 인 칸은 정보가 아니다」와 같은 판단)
- 칸이 빠지면서 「이 아이템」 카드가 스킬 맥락으로 `heroCombatIf` 를 부를 까닭도 사라졌다

## 파급

- `app.js:tipCard` 의 스킬 칸 · `tip.noSkill` 키 삭제 · 가방 칸의 `heroCombatIf` 호출 삭제
- `tip.js:skillTipSection` 은 부르는 곳이 없으면 걷는다
