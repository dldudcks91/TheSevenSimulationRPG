## 결정

캐릭터 탭 액티브 둘째 칸(책)을 눌러 뜨던 스킬북 창을 걷는다. 칸은 누를 수 없고 보기만 한다(찬 칸은 툴팁 · 빈 칸은 `title` 사유 · 잠긴 칸은 자물쇠 — ADR-0425). 책을 배우고 만드는 자리는 서고 탭(§17) 하나다. 창이 들던 줄 규격(머리 줄 · 가진 책 · 기본 책 만들기)은 §17 로 옮겼다.

## 맥락

같은 날 ADR-0420 이 둘째 칸을 누르면 뜨는 창을 세웠고, 뒤이어 서고 탭이 서면서(ADR-0422) 같은 속이 두 자리에 섰다. 「일단」 — 시험 삼아 한 자리로 줄인다.

## 근거

- **사용자 지시**
- **한 자리** — 같은 일을 두 곳에서 하면 어느 쪽이 정본인지가 흐려진다. 영웅을 고르는 띠가 서고 탭에도 있어 ADR-0420 의 「영웅을 두 번 고른다」 걱정은 이미 풀렸다
- 버린 안 — 칸을 누르면 서고 탭으로 옮겨 가기(지시가 「클릭 같은 거 할 수 없게」다)

## 파급

- app.js `MODALS.book` · `bookBody` · 칸의 `clickable` 걷음 · `?dev=book` 은 기본이 서고 탭(`&lib=1` 은 기본과 같아 읽지 않는다 · `&mat=1` 은 그대로)
- i18n `bk.h`(창 제목) 삭제 · CSS `.bk-modal` · `.sk-card.clickable` 삭제
- 창에서 쓰던 `bookLearnInto` · `bookCraftInto` 는 서고 탭이 그대로 쓴다
