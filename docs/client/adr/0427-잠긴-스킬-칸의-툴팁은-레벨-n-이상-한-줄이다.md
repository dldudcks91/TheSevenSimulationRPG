# ADR-0427 — 잠긴 스킬 칸의 툴팁은 「레벨 n 이상」 한 줄이다

| | |
|---|---|
| **상태** | 확정 · 2026-09-29 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「hover하면 레벨10이상, 레벨30이상 문구만 탭으로 간단하게 나오도록」 |
| **대체** | — (잠긴 칸의 사유가 `title` 이던 것을 툴팁 카드 한 줄로 바꾼다 · 잠기지 않은 빈 칸은 `title` 그대로) |
| **대체됨** | 문구 언어 · 툴팁 폭 — [ADR-0428](0428-잠긴-스킬-칸-툴팁은-영어-한-줄이고-폭은-글자만큼이다.md) 가 대체 2026-09-29 (한 줄 · 값은 그대로) |

## 결정

캐릭터 탭 액티브 칸 중 자물쇠가 선 칸(ADR-0425)에 올리면 툴팁 카드가 뜨고, 그 안은 **「레벨 n 이상」 한 줄**뿐이다. n 은 책 칸 = `skillbook_learn_level`, 전직 칸 = `advance_unlock_level` 이다. 다른 설명은 붙이지 않는다.

## 맥락

잠긴 칸의 사유는 브라우저 `title` 이었다 — 늦게 뜨고 모양이 게임 툴팁과 다르며, 문구도 「Lv.n 부터」 · 「전직 전」으로 칸마다 달랐다.

## 근거

- **사용자 지시** — 문구와 모양(간단한 툴팁)을 정했다
- **효과만 적는다는 규칙(CLAUDE.md 규칙 7)과 맞는다** — 열리는 조건 한 줄이지 규칙 설명이 아니다
- **전직 칸은 레벨만 말한다** — 전직은 레벨 말고도 훈련장 랭크 · 전직 시간이 걸리지만, 사용자가 문구를 「레벨 30 이상」으로 정했다

## 파급

- i18n `sk.lockLv` · app.js `slotLockLevel` · 툴팁은 기존 `.tip-card` · `.tip-name`
