# ADR-0428 — 잠긴 스킬 칸 툴팁은 영어 한 줄이고 폭은 글자만큼이다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) |

| **대체** | [ADR-0427](0427-잠긴-스킬-칸의-툴팁은-레벨-n-이상-한-줄이다.md) 의 문구 언어(한국어 「레벨 n 이상」)와 툴팁 폭(다른 툴팁과 같은 304px) |

## 결정

잠긴 액티브 칸의 툴팁 한 줄은 **한국어 화면에서도 영어** 「Level n+」다. 툴팁 카드는 `.tip-mini` 로 **폭이 글자만큼**이고 안쪽 여백도 줄인다.

## 맥락

ADR-0427 은 같은 날 한 줄 툴팁을 세웠는데, 카드가 다른 툴팁과 같은 304px 폭이라 짧은 한 줄 옆이 크게 비었다.

## 근거

- **사용자 지시**
- **예외를 i18n 키 안에 둔다** — 렌더러에 영어 리터럴을 박지 않고 `sk.lockLv` 의 ko 값도 영어로 적는다. 언어 전환 구조(CLAUDE.md 규칙 6)는 그대로이고, 되돌릴 때 ko 값 하나만 고친다
- **폭은 이 카드에만** — 다른 툴팁(아이템 · 스킬 · 유닛)은 줄이 많아 고정 폭이 줄을 맞춘다

## 파급

- i18n `sk.lockLv` ko 값 · CSS `.tip-card.tip-mini`
