# ADR-0434 — 전술 「관계」 조건 문구는 「이 파티로 스테이지 n회 이상 클리어」다

## 결정

전술 「관계」 조건은 **「이 파티로 스테이지 {n}회 이상 클리어」**(en 「{n}+ stage clears as this party」)로 적는다. 옆의 카운터(`12 / 100`)는 그대로다 — 세는 것이 **같이 깬 칸 수**(칸을 이길 때마다 +1)로 바뀌었을 뿐이다.

## 맥락

관계 수(`bonds`)는 출발할 때 +1 이었다. 출정 → 철수를 연타하면 한 판도 안 싸우고 문턱(30 · 100)에 닿았다. 사용자가 「한 스테이지를 완료할 때마다 +1」로 정했고(tactic_card_design §5-8 · DEV_PLAN R184), 옛 문구 「출정」은 이제 세지 않는 것을 가리키게 됐다.

## 근거

- **글자가 세는 것을 말한다** — 「출정」이라고 적힌 채 출정해도 안 오르면 조건을 못 읽는다(tactic_card_design §4 「화면 요구」 — 조건은 화면에서 세어 볼 수 있어야 한다)
- **「스테이지」 · 「클리어」는 이미 화면의 말이다** — 칸은 스테이지 목록 · 출정 창에서 스테이지로 불리고 이긴 칸의 리포트 판정이 「클리어」다

## 파급

- i18n `rs.cond.together` 개정 · 로직은 `state.settleRound`(DEV_PLAN R184)
