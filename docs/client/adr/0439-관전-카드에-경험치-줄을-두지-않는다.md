# ADR-0439 — 관전 카드에 경험치 줄을 두지 않는다

## 결정

관전 영웅 카드의 초상 아랫변에 겹쳐 두었던 **경험치 줄(보라색 선)을 걷는다.** 관전 카드에는 경험치 표시가 없다 — 경험치는 리포트와 캐릭터 탭이 든다. ADR-0435 의 나머지 — 레벨이 오르면 카드에 「레벨 업」 글자(언더레벨이면 적중 변화 한 줄) · 로그 `▲ Lv.n` · 레벨업을 카드가 그린 레벨과 대조해 잡는 방식 — 은 그대로 산다.

## 맥락

같은 날 ADR-0435 로 영웅 카드 초상 아랫변에 두께 4px 의 경험치 줄(`--xp-fill` 보라)이 섰다. 스크린샷으로 확인한 사용자가 그 선을 필요 없다고 했다.

## 근거

- 사용자 지시다
- 레벨업의 순간은 글자 팝업 · 체력이 가득 차는 막대 · 로그 한 줄이 이미 든다. 줄은 「다음 레벨까지 얼마」를 보여 줬을 뿐 그 순간을 만들지는 않았다

## 파급

- CSS `.xp-line` · 재생기 `xpPct` 삭제 · §4-2 호출 줄의 `hero.xpNeeded` 삭제
- 걷은 뒤의 규격은 ADR-0435 이전과 같다 — 「XP 바는 두지 않는다」
