# ADR-0440 — 본 적 없는 레벨업은 관전 카드의 레벨이 누를 때까지 반짝인다

| | |
|---|---|
| **상태** | 확정 · 2026-09-29 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「레벨업하면 왼쪽 위의 레벨이 반짝반짝거리도록 · 걔를 클릭할 때까지」) · 세부 셋은 제안 후 사용자 선택(1 기억 = 게임이 켜져 있는 동안만 · 2 자리 = 관전 카드만 · 3 누르면 = 반짝임만 꺼진다) |
| **대체** | — |
| **대체됨** | [ADR-0463](0463-반짝이는-레벨은-그-영웅-카드-어디를-눌러도-걷힌다.md) 이 **누르는 자리(그 글자)** 를 카드 전체로 넓혔다 — 반짝임 · 본 레벨의 기억은 그대로 산다 |

## 결정

영웅이 레벨업했는데 플레이어가 아직 확인하지 않았으면, 관전 영웅 카드 **띠 왼쪽 위의 `Lv.n` 이 반짝인다**(금색 · 부드러운 깜빡임). **그 글자를 누를 때까지** 이어지고, 누르면 반짝임만 꺼진다 — 글자가 카드 안에 있어 카드 클릭(장착 대상 고르기 · ADR-0137)도 함께 일어난다. 「확인한 레벨(본 레벨)」은 영웅마다 **앱의 화면 상태**가 기억한다 — 세이브에 넣지 않아 새로고침하면 걷힌다. 다른 화면(영웅 띠 등)의 `Lv` 는 반짝이지 않는다.

## 맥락

같은 날 ADR-0435 로 레벨업하는 순간 카드에 「레벨 업」 글자가 1.6초 뜨게 됐다. 원정은 다른 탭 · 숨긴 탭에서도 앱 시계가 밀어 계속 돈다(ADR-0300) — 관전을 안 보는 동안 오른 레벨업은 그 글자도 없이 지나갔다. 원정은 게임을 끄면 멈춘다(PLAN_stage_segments D7) — 레벨업은 늘 게임이 켜져 있는 동안 일어난다.

## 근거

- **「본 레벨」을 재생기가 아니라 앱이 드는 이유** — 재생기는 관전을 볼 때만 살아 있고 런마다 새로 선다. 레벨업을 재생 사건으로 잡으면 안 본 동안의 레벨업은 영영 안 잡힌다. 앱이 영웅마다 본 레벨을 들고 지금 레벨과 대조하면 어느 화면에서 올랐든 카드가 서는 순간 잡힌다. 처음 보는 영웅은 지금 레벨을 본 것으로 친다 — 영웅은 고용 · 편성(클릭 → 그리기)을 거쳐야 파티에 들므로 첫 레벨업 전에 적힌다
- **세이브에 안 넣는 이유(사용자 선택 1)** — 레벨업은 게임이 켜져 있을 때만 일어나 화면 상태로 대부분 잡힌다. 세이브에 칸을 더하면 형식이 바뀐다. 버린 안: 세이브에 남긴다(새로고침에도 남는다)
- **관전 카드에만 두는 이유(사용자 선택 2)** — 사용자가 짚은 자리다. 버린 안: 다른 탭의 영웅 띠(초상 오른쪽 아래 `Lv.n`)도 반짝인다 — 건설 탭에 있어도 누가 올랐는지 보이지만 띠가 서는 화면이 여럿이라 범위가 커진다
- **누르면 반짝임만 꺼지는 이유(사용자 선택 3)** — 버린 안: 누르면 그 영웅의 마스터리 화면이 열린다(레벨업이 포인트 1점을 주므로 「찍으러 가기」) — 관전을 떠나게 된다
- **글자를 눌러도 카드 클릭이 일어나는 것을 받아들이는 이유** — 레벨이 오른 영웅을 보러 누른 것이라 장착 대상이 그 영웅으로 바뀌어도 해가 없다. 막으면 같은 카드 안에서 누르는 자리마다 뜻이 갈린다

## 파급

- 앱 화면 상태 `state.lvSeen` · `lvSeenOf` · `lvUnseen` · `lvSee` · 재생기 옵션 `lvUnseen` · `onLvSeen` · 신원의 레벨 칸 `.unit-lv` · CSS `.unit-lv.lv-new` · `@keyframes lv-blink`
- ⚠ 새로고침하면 확인 안 한 반짝임이 사라진다(사용자 선택)
