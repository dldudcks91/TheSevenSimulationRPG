# ADR-0447 — 수동 분해의 일괄 체크는 [분해하기] 바로 위로 올라오는 메뉴가 든다 · 등급 · 레벨 두 줄

## 결정

[분해]를 누르면 고르는 중이 되고 도구 줄은 [분해하기] · [취소]만 든다. 동시에 **[분해하기] 바로 위로 고르기 메뉴**가 올라온다(왼쪽 끝 = [분해하기] 왼쪽 끝). 메뉴는 두 줄 **[등급 ▸] · [레벨 ▸]** 이고, 누른 줄의 선택지가 **오른쪽으로 미끄러져 나온다**(한 번에 한 줄).

- 등급 선택지 — 일반 · 매직 · 레어 · 크래프트 · 유니크(`mock.js:RARITY` 순서 · 글자 = 등급 색)
- 레벨 선택지 — 아이템 레벨 구간. 폭은 `balance.csv:weapon_atk_band_levels`(아이템 구간 폭)이고 `hero_level_cap` 까지 자른 뒤 그 위를 하나로 묶는다
- 선택지 버튼의 체크 규칙은 ADR-0444 그대로다. 등급과 레벨은 **체크를 더한다**(교집합이 아니다)

## 맥락

ADR-0444 는 등급 버튼 다섯을 도구 줄에 늘어놓았다. 영어에서 줄이 끝까지 차서 칸 수 글자가 말줄임으로 사라졌고, 레벨 기준까지 더할 자리가 없었다. 사용자가 「위로 올라와서 오른쪽으로 펼쳐지는」 메뉴로 바꾸고 기준을 등급 · 레벨 둘로 나누라고 지시했다.

## 근거

- **도구 줄을 비운다** — 선택지가 메뉴로 올라가 도구 줄은 [분해하기] · [취소] · 칸 수로 돌아온다. 보관 도구 줄은 한 줄을 지킨다(ADR-0247)
- **펼침은 정렬과 같은 문법이다** — 누르면 오른쪽으로 미끄러져 나오는 움직임은 [정렬](ADR-0247)이 이미 쓴다. 한 번에 한 줄이라 메뉴가 두 줄 폭 이상으로 커지지 않는다
- **위로 뜬다** — 보관 칸은 화면 맨 아래라 아래로 펼 자리가 없다. 메뉴는 위 패널을 잠깐 덮고, 칸 격자는 가리지 않는다. 그래서 메뉴를 띄운 채 칸을 눌러 체크를 고칠 수 있다
- **[분해하기] 바로 위다** — 방금 누른 [분해] 자리에서 손을 떼지 않고 이어 누른다. 영어에서 레벨 줄(여덟 칸)이 그 자리에서 시작해도 인벤토리 칸 안에 들도록 선택지를 촘촘하게 둔다(공용 여백이면 화면 오른쪽 끝을 넘었다 — 실측 1619 > 1600)
- **레벨은 구간 버튼이다** — 버튼 하나가 한 묶음이라 등급 버튼과 같은 토글 규칙이 그대로 선다. 구간 폭은 아이템 성능 구간(무기 피해 · 방어구 방어력이 레벨 구간마다 오른다)과 같다
- **체크를 더한다** — 버튼마다 뜻이 하나라 결과가 읽힌다. 교집합은 버튼 상태가 서로 얽히고, 칸을 직접 눌러 붙인 체크와도 부딪힌다

**버린 안**

1. **도구 줄에 늘어놓기(ADR-0444)** — 레벨까지 서면 줄이 넘친다
2. **레벨 = 「Lv.n 미만」 값 조절 + [선택]** — 자동 분해 창과 같은 모양이지만 버튼이 하나 더 들고, 등급 버튼과 누르는 규칙이 갈린다
3. **등급 × 레벨 교집합** — 위 「체크를 더한다」의 반대편
4. **메뉴를 도구 줄 왼쪽 끝에 세운다** — 영어 넘침을 피하려고 한때 그렇게 그렸다. 누른 버튼과 메뉴가 떨어져 사용자가 되돌렸다

## 파급

- `app.js` — `bagGradeBar` 를 걷고 고르기 메뉴(`bagPickMenu`)를 단다 · 화면 상태 `bagPickFold`(펼친 줄) · `bagPickAnim`(올라오는 움직임 한 번) · `bagFoldAnim`(펼치는 움직임 한 번) — 세이브 아님 · 체크 집합은 기존 `state.bagSel`
- i18n — `ch.sel.byRarity` · `ch.sel.byLevel` 신설. 등급 이름은 `mock.js:RARITY` 를 `L()` 로 푼다 · 레벨 버튼은 숫자만이라 키가 없다
- `style.css` — `.sel-grades` 를 걷고 `.sel-anchor`([분해하기] · [취소] 묶음 — 메뉴의 기준 자리) · `.sel-pop` · `.sel-fold`(선택지 여백 3 · 간격 2)를 단다
- 세이브 · `game_logic` 은 바뀌지 않는다
