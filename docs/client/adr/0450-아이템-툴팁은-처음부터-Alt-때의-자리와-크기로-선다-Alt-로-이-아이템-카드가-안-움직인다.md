# ADR-0450 — 아이템 툴팁은 처음부터 Alt 때의 자리와 크기로 선다 · Alt 로 「이 아이템」 카드가 안 움직인다

## 결정

비교 상대가 있는 아이템 툴팁은 **기본 상태에도 Alt 때의 모양을 통째로 깔고** 선다. 착용품 카드 · VS 는 자리만 잡고 보이지 않으며(`visibility: hidden`), 툴팁의 폭 · 높이 · 커서 왼쪽으로 접히는지가 Alt 때와 같다. Alt 를 누르면 숨은 것이 보일 뿐이라 **「이 아이템」 카드는 한 픽셀도 안 움직인다.**

- 카드 바닥은 **바꿔 끼우는 칸 하나**다 — 기본 = 각주 「Alt 비교」 · Alt 동안 = 「반지 n번 칸에 낀다」 · 「착용 중 없음」. 둘이 같은 칸에 겹쳐 서서 높이는 둘 중 큰 쪽이다 — 줄이 바뀌어도 카드 키가 안 변한다
- 「끼우면 전술이 꺼진다」 줄은 두 상태 모두 보인다(ADR-0448)
- 손가락 툴팁의 버튼 줄은 **「이 아이템」 카드 아래**에 선다 — 접힌 툴팁이면 오른쪽 끝에 맞춘다(왼쪽 끝은 숨은 착용품 카드 자리다)

## 맥락

ADR-0448 로 기본은 한 장(304px) · Alt 동안 두 장(616px)이 됐다. 폭이 두 배로 늘면서 커서 오른쪽에 있던 카드가 Alt 순간 **커서 왼쪽으로 뛰었다**(가방은 화면 오른쪽 절반이라 거의 매번 · 2026-09-29 실측 x 1025 → 689). 카드 바닥 줄도 바뀌어 화면 아래에 붙은 툴팁은 위아래로 12px 흔들렸다. 사용자가 Alt 때를 기준으로 뜨게 하라고 지시했다.

## 근거

- **읽던 카드가 제자리에 있어야 비교가 된다** — Alt 는 「옆에 하나 더」여야 한다. 읽던 카드가 뛰면 눈이 다시 찾아야 한다
- **숨겨서 자리를 잡는다** — 두 장을 짓고 하나를 안 보이게 두면 접힘 판정(`tip.js:moveTip`)이 두 상태에서 같은 폭을 잰다. 자리 계산을 따로 짜지 않는다 — 유닛 툴팁이 기본 상태에 숨은 세부 옵션 1 로 높이를 잡는 것(ADR-0176)과 같은 수다
- 버린 안: **Alt 때만 자리를 다시 계산해 「이 아이템」 카드 자리를 고정** — 한 장일 때와 두 장일 때 접힘 판정이 달라 좌표를 따로 맞춰야 하고, 화면 끝에서 두 장이 못 들어가면 결국 움직인다
- 대가: 기본 상태에서도 툴팁이 두 장 폭 기준으로 접혀, 화면 가운데쯤의 칸도 카드가 커서 왼쪽에 선다

## 파급

- `app.js:bindTip` — 착용품 카드 · VS 는 두 상태 모두 짓고 `alt-only` 로 숨긴다 · 바닥 칸 `.tip-swap`
- `style.css` — `.tip-compare:not(.alt) .alt-only` · `.tip-compare.alt .base-only` 숨김 · `.tip-swap` 겹침 격자 · 접힌 비교 툴팁의 `.tip-touch` 오른쪽 맞춤
