# ADR-0451 — 보관 칸 우클릭은 [착용] · [잠금] 버튼을 띄운다 · 클릭은 그대로 장착이다

## 결정

보관 칸(창고 · 인벤토리)의 장비를 **우클릭하면 커서 자리에 버튼 두 개**가 뜬다 — **[착용]** · **[잠금]**(잠긴 것이면 **[잠금 해제]**). [착용]은 칸 클릭과 같은 장착이고, [잠금]은 잠그는 중에 칸을 누른 것과 같은 자물쇠 토글이다. **칸 클릭은 그대로 장착**이다.

- 닫힘 — 버튼을 누르거나 · 바깥을 클릭 · 우클릭하거나 · `Esc` · 탭을 옮기면. 바깥 클릭은 닫기만 한다(그 자리의 칸을 누르지 않는다)
- 고르는 중 · 잠그는 중에는 안 뜬다 — 그 동안 칸 누르기는 체크 · 자물쇠다
- 손가락은 우클릭이 없다 — **길게 눌러 연 툴팁 아래 버튼 줄**에 같은 둘이 선다(ADR-0374 「우클릭은 툴팁 아래 버튼이 든다」)

## 맥락

칸 클릭은 곧바로 장착이고, 잠금은 도구 줄 [잠금] → 칸 → [완료] 세 번이었다. 사용자가 「클릭하면 [착용] · [잠금] 버튼」을 제안했고, 비교(장착이 두 번으로 는다 · 장착은 되돌릴 수 있어 두 번 누르게 할 대상이 아니다 · 제련소처럼 클릭 뜻이 다른 자리와 갈린다)를 본 뒤 **클릭은 두고 우클릭에 버튼을 띄우는 쪽**을 골랐다.

## 근거

- **가장 잦은 손짓을 안 늘린다** — 리포트를 보고 장비를 재배분하는 것이 코어 루프라 장착은 한 번에 끝나야 한다
- **한 개 잠그기가 두 번이 된다** — 우클릭 → [잠금]. 여러 개는 여전히 잠그는 중이 빠르다
- **우클릭 = 그 칸만의 행동**은 선례가 있다 — 스킬 창 칸의 우클릭(되돌리기 · §7)과 그 손가락 짝(ADR-0374)
- **창의 틀은 자원 자리의 선택 창(ADR-0373)** — 상태(`state.itemMenu`)가 들고 그리기마다 다시 서며, 한 장 바로 아래에 붙고 깔개가 바깥 클릭을 받는다
- 버린 안: **우클릭 = 곧바로 잠금 토글**(메뉴 없음) — 사용자가 버튼이 뜨는 쪽을 골랐다

## 파급

- i18n `ch.menu.equip` · `ch.menu.lock` · `ch.menu.unlock` 신설 · 도움말 `ch.equip.hint` 에 우클릭 한 마디
- `app.js` — `state.itemMenu` · `itemMenuPanel` · 칸 클릭의 장착 · 자물쇠를 함수(`equipFromStorage` · `toggleItemLock`)로 뽑아 메뉴 · 손가락 버튼 줄이 같이 부른다
- ⚠ [창고로] · [분해] 같은 다른 버튼은 안 넣었다 — 지시가 둘이었다
