# ADR-0456 — Alt 각주는 Alt 를 누르는 동안에도 걷지 않는다

## 결정

툴팁 바닥의 Alt 각주 — 유닛 툴팁의 「Alt 세부 옵션」 · 「Alt 장비 · 세부 옵션」, 아이템 비교 툴팁의 「Alt 비교」 — 는 **Alt 를 누르는 동안에도 그 자리에 그대로 선다.** 문구도 자리도 두 상태에서 같다. 아이템 툴팁의 Alt 줄(반지 n번 칸 · 착용 중 없음)은 각주와 겹치지 않고 **각주 바로 위**에 따로 서며, 기본 상태엔 ADR-0450 대로 보이지 않게 자리만 잡는다 — 각주가 맨 바닥이다.

## 맥락

세 카드 모두 Alt 를 누르면 각주를 지웠다. 유닛 카드 · 편성/원정 영웅 카드는 Alt 상태에서 각주 줄을 아예 짓지 않았고, 아이템 비교 툴팁은 각주와 Alt 줄을 한 칸에 겹쳐 두고 Alt 동안 각주를 숨겼다(ADR-0450). 누를 때마다 바닥 한 줄이 사라지는 것을 사용자가 지적했다.

## 근거

- **각주는 「Alt 가 무엇을 여나」의 이름표다** — 연 뒤에도 남아 있어야 지금 보는 것이 Alt 가 연 모양이라는 것이 읽힌다. 지우면 누를 때마다 바닥이 깜빡인다
- **두 상태에서 같은 줄이 같은 자리에 서는 편이 ADR-0450 의 취지(Alt 로 카드가 안 움직인다)와도 맞는다** — 겹친 칸을 바꿔 끼우던 것보다 바뀌는 것이 적다
- 버린 안 — **Alt 동안 각주 문구를 바꾼다**(「Alt 떼면 닫힘」 따위): 규칙 설명이라 툴팁의 몫이 아니다(CLAUDE.md 규칙 7) · **아이템 Alt 줄을 각주 아래에 둔다**: 각주가 바닥이 아니게 되고 기본 상태엔 각주 밑에 빈 자리가 남는다

## 파급

- `tip.js:unitCard` · `statsFirstCard` — 각주를 두 상태 모두 짓는다
- `app.js:bindTip` — `.tip-swap` 겹침을 걷고 [Alt 줄(`alt-only`) · 각주] 순으로 쌓는다 · `base-only` 는 쓰는 곳이 없어져 CSS 와 함께 걷는다
- ⚠ 아이템 툴팁에 Alt 줄이 있는 자리(반지 칸 · 빈 부위)는 기본 상태에 각주 위로 빈 줄이 한 줄 남는다 — Alt 로 카드가 안 움직이는 대가다(ADR-0450)
