# ADR-0457 — 배치 버튼을 걷는다 — 로그 · 누적 버튼이 오른쪽 열을 바로 연다

## 결정

관전 컨트롤의 **[배치](나눠 보기 / 넓게 보기) 버튼을 걷는다.** 배치는 **[전투 로그] [누적 데미지] 두 버튼이 정한다** — 두 버튼은 늘 눌린다.

- **열이 닫혀 있을 때(넓게)** — 누르면 그 판을 든 오른쪽 열이 선다(나눔)
- **열이 열려 있을 때(나눔)** — **켜진 버튼을 다시 누르면 열이 닫힌다**(넓게) · 다른 버튼은 열의 판만 바꾼다
- 열 · 판의 모양은 그대로다 — 아레나 오른쪽 딜미터 열(ADR-0093) · 아레나를 덮는 창은 돌아오지 않는다(ADR-0130 이 걷은 그대로)
- 열이 열려 있는지는 그날처럼 **취향**이라 화면 상태(`state.btLayout`)가 들고 다음 원정에도 남는다

## 맥락

그날 로그 · 누적을 보려면 두 번 눌러야 했다 — [나눠 보기]로 열을 세운 뒤 [전투 로그] / [누적 데미지]로 판을 고른다. 넓게 보기에서 두 버튼은 흐린 채 안 눌렸다(ADR-0130). [배치] 버튼은 헤드 오른쪽 끝, 철수 뒤 구분선 다음에 섰고 글자는 바꿀 배치의 이름(「나눠 보기」 / 「넓게 보기」)이었다.

## 근거

- **한 번에 닿는다** — 보려는 것은 로그나 누적이지 배치가 아니다. 배치는 「그 판을 보고 있나」의 결과로 따라온다
- **ADR-0130 이 이 안을 버린 이유가 없어진다** — 그날 버린 안 2(「넓게 보기에서 버튼을 누르면 나눔 보기로 바꿔 준다」)의 근거는 **[배치] 버튼과 같은 일을 두 곳이 하게 된다**였다. [배치] 버튼이 사라지면 배치를 바꾸는 곳은 두 버튼 하나뿐이다
- **닫는 길은 켜진 버튼이다** — 넓게 보기로 돌아갈 길이 따로 없으면 한 번 연 열이 안 닫힌다. 켜진 판 버튼을 다시 누르면 닫히는 것은 탭 · 토글의 흔한 문법이고 새 버튼을 안 늘린다
- **창이 아니라 열이다** — 아레나를 덮는 창은 ADR-0130 에서 「크게 본다」를 깬다는 이유로 걷혔다. 열은 아레나를 옆으로 밀 뿐 덮지 않는다

**버린 안**

1. **아레나 위에 뜨는 창으로 되돌린다(ADR-0019)** — ADR-0130 이 걷은 이유(아레나를 덮는다 · 재생기 안의 창 레이어 · `Esc` 리스너)가 그대로 산다. 열 안의 판 규격(ADR-0189 · 0196 · 0201 · 0204 · 0208 · 0211 · 0252 · 0258)도 전부 열을 전제로 섰다
2. **열에 닫기(X) 버튼을 단다** — 여닫는 길이 둘이 되고 열의 머리에 칸이 하나 는다. 켜진 버튼이 이미 「지금 열린 판」을 가리킨다
