# ADR-0463 — 반짝이는 레벨은 그 영웅 카드 어디를 눌러도 걷힌다

| | |
|---|---|
| **상태** | 확정 · 2026-09-30 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「그 숫자를 클릭하는 게 아니라 그냥 영웅만 클릭해도 깜빡이 없어지도록」) |
| **대체** | [ADR-0440](0440-본-적-없는-레벨업은-관전-카드의-레벨이-누를-때까지-반짝인다.md) 의 **누르는 자리(그 글자)** — 반짝임 · 본 레벨의 기억(화면 상태 · 세이브 밖) · 관전 카드에만 두는 것은 그대로 산다 |
| **대체됨** | — |

## 결정

본 적 없는 레벨업으로 `Lv.n` 이 반짝이는 영웅은 **그 영웅의 관전 카드 어디를 눌러도** 반짝임이 걷힌다. 글자를 정확히 맞혀 누르지 않아도 된다. 카드 클릭이 하던 일(장착 대상 고르기 · ADR-0137)은 그대로 함께 일어난다.

## 맥락

전날 ADR-0440 은 「그 글자를 누를 때까지」 반짝이게 했다. 글자는 카드 띠 왼쪽 위의 작은 `Lv.n` 하나였고, 카드의 나머지 자리를 누르면 장착 대상만 바뀌고 반짝임은 남았다.

## 근거

- **사용자 지시다** — 작은 글자를 맞혀 눌러야 하는 것을 걷어 달라는 요청이었다
- **ADR-0440 이 이미 「글자를 눌러도 카드 클릭이 일어난다」를 받아들였다** — 같은 카드 안에서 누르는 자리마다 뜻이 갈리지 않게 하려는 근거였다. 카드 전체가 걷는 자리가 되면 그 근거가 양쪽으로 다 선다
- 버린 안: 글자만 누르는 자리로 둔다(ADR-0440) — 「확인했다」를 또렷이 가르지만 표적이 작다

## 파급

- 재생기(`battle.js`)의 걷는 클릭이 글자에서 카드로 옮겨 갔다 · 장착 대상 고르기보다 먼저 건다
- ⚠ 장비를 옮기려고 카드를 누른 것도 「확인했다」로 친다 — 레벨을 안 보고 걷힐 수 있다
