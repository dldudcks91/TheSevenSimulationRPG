# ADR-0464 — 편성 탭 진형 · 물약 소제목 옆 물음표에 올리면 설명 툴팁이 선다

| | |
|---|---|
| **상태** | 확정 · 2026-09-30 |
| **화면** | [SCREEN_DESIGN §15](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「편성에서 진형과 물약 오른쪽에 물음표 버튼 만들어서 … 간단한 설명 나오도록」 → 「클릭 말고 hover 하면 대충 설명 나오는 걸로」) |
| **대체** | — |
| **대체됨** | — |

## 결정

편성 탭의 소제목 「진형」 · 「물약」 글씨 바로 오른쪽에 작은 `?` 표시를 하나씩 단다. **올리면 설명 툴팁**이 선다 — 물약 카드와 같은 모양으로 첫 줄은 그 칸 이름, 선 아래는 한두 문장이다. 진형은 「적은 전열부터 공격한다 · 전열이 모두 쓰러져야 후열이 공격받는다」, 물약은 「HP 가 정해진 비율 아래로 떨어진 영웅이 자동으로 마신다」 한 문장이다. 누르는 자리가 아니다. 자세한 규칙은 여기 적지 않는다.

## 맥락

편성 탭의 진형 · 물약 칸은 손(클릭 · 드래그)만 있고 그 칸이 전투에서 무엇을 하는지는 화면 어디에도 없었다. 도움말 탭에도 진형 · 물약 설명이 없었다. 「설명 문구는 도움말 탭 전용」(2026-08-26 지시)이 서 있어 패널 안에 글을 깔 수는 없었다.

## 근거

- **사용자 지시다** — 그 칸 옆에서 바로 읽히는 간단한 설명을 원했다
- **올려야만 뜬다** — 패널에는 글이 한 줄도 안 깔린다. 「인게임 패널에는 설명 문장을 안 둔다」는 그대로 선다
- 버린 안: **누르면 뜨는 설명 창**(창 레이어) — 같은 날 먼저 지어 봤고 사용자가 hover 로 바꿨다. 한두 문장을 읽자고 화면을 덮고 닫기까지 시키는 것이 무거웠다
- **카드는 있던 툴팁 모양을 쓴다** — 이름 / 선 / 한 줄짜리 물약 카드의 클래스 그대로라 새 모양이 없다
- **물약은 한 문장이다** [사용자 지시 「…정도로만 써 · 세부적인 건 도움말에 쓰고 자세한 건 나중에」] — 앞 칸부터 마신다 · 쿨타임 · 스테이지마다 다시 채운다는 뺐다. 진형도 도발 · 지목 예외를 뺐다
- 「파티 전술」에는 안 단다 — 지시가 진형 · 물약 둘이었다

## 파급

- i18n 키 둘(`pt.help.form` · `pt.help.potion`) · CSS `.q-btn` · `.q-tip` · `app.js:subHelp`
- 출정 창의 「물약」 소제목에는 안 단다 — 편성 탭만이다
- ⚠ 도움말 탭에 진형 · 물약의 자세한 규칙을 적는 일은 열린 채 남았다
- ⚠ 손가락에서는 다른 툴팁과 같은 길(길게 누르기)로 선다 — 따로 재지 않았다
