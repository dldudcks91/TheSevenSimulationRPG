# ADR-0466 — 잠긴 스킬 칸 툴팁은 칸마다의 문장이다 · 책은 서고에서 · 전직은 전직 후

| | |
|---|---|
| **상태** | 확정 · 2026-09-30 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「책 스킬창에 hover 하면 나오는 설명에 Lv10이 되면 서고에서 스킬을 배울 수 있습니다. 전직에서는 Lv30이 되면 전직 후 스킬을 배울 수 있습니다로 수정」) |
| **대체** | [ADR-0428](0428-잠긴-스킬-칸-툴팁은-영어-한-줄이고-폭은-글자만큼이다.md) 의 **문구**(두 칸 공통 「Level n+」 · 두 언어 다 영어) — 폭이 글자만큼인 것은 그대로 산다 |
| **대체됨** | — |

## 결정

캐릭터 탭 액티브 스킬의 잠긴 칸에 올리면 뜨는 한 줄을 **칸마다의 문장**으로 바꾼다. 책 칸은 「Lv n 이 되면 서고에서 스킬을 배울 수 있습니다.」, 전직 칸은 「Lv n 이 되면 전직 후 스킬을 배울 수 있습니다.」다. n 은 표의 값이다(책 `skillbook_learn_level` · 전직 `advance_unlock_level`). 한국어는 한국어로, 영어는 영어로 찍는다.

## 맥락

전날 ADR-0427 · 0428 로 잠긴 칸의 툴팁은 두 칸이 같은 「Level n+」 한 줄이었고 한국어에서도 영어였다. 레벨만 말하고 **그 레벨에 어디서 무엇을 하는지**(서고 · 전직)는 말하지 않았다.

## 근거

- **사용자 지시다** — 문장을 그대로 받았다
- 칸이 둘이고 여는 길이 다르다 — 책은 서고에서 배우고 전직 칸은 전직해야 찬다. 한 문구로는 그 차이가 안 읽혔다
- ⚠ 「hover 설명은 효과만 적는다 · 조건 설명을 늘어놓지 않는다」(2026-09-24 · CLAUDE.md 규칙 7)와 닿는 자리다 — 빈 칸이라 적을 효과가 없고, 한 줄이라 그대로 두었다
- 버린 안: 「Level n+」 그대로(ADR-0428) — 짧지만 다음 할 일을 안 말한다

## 파급

- i18n — `sk.lockLv` 삭제 · `sk.lock.book` · `sk.lock.advance` 신설 · 렌더러는 칸의 출처로 키를 고른다
- 툴팁 모양(`.tip-mini` · 폭은 글자만큼)은 안 바뀌었다 — 문장이 길어진 만큼 넓어진다
- ⚠ 전직 칸은 레벨이 차도 전직 전이면 잠긴 채라 같은 문장이 계속 뜬다
