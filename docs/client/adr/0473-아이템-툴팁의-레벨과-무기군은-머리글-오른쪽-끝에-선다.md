## 결정

아이템 툴팁의 아이템 레벨과 무기군은 **머리글 줄의 오른쪽 끝**에 선다 — 왼쪽 「이 아이템」 · 「착용 중」, 오른쪽 `둔기  Lv.12`(무기가 아니면 `Lv.12` 만). 레벨 표기는 `ilvl n` 이 아니라 가방 칸 배지와 같은 `Lv.n`(`ch.itemLv`)이다. 이름 아래 줄은 없어진다.

## 맥락

이름 아래 한 줄에 `ilvl 12 · 둔기` 가 이름과 메인 옵션 사이를 갈라 서 있었다. `ilvl` 은 렌더러에 박힌 영어 약어였고, 같은 값이 가방 칸 · 페이퍼돌 배지에서는 `Lv.12` 로 찍혀 같은 값이 두 이름을 갖고 있었다.

## 근거

- **레벨은 「어느 칸의 값인가」를 대조하는 값이다** — Alt 비교 두 장에서 오른쪽 위 모서리라는 같은 자리에 서면 눈이 한 번에 견준다. 가방 칸도 레벨을 모서리 배지로 든다(ADR-0168)
- **이름이 메인 옵션 바로 위에 붙는다** — 카드가 한 줄 줄고, 이름(무엇인가) → 메인 옵션(얼마나 센가)이 끊기지 않는다
- **무기군은 분류 태그라 머리글의 결이다** — 이름 줄 오른쪽은 이름이 길면(「격노와 찬탈의 퀼티드 아머」) 부딪힌다. 머리글은 짧은 말 하나라 자리가 남는다
- 버린 안 — **무기군을 메인 옵션 블록 머리로**: 줄이 다시 하나 생긴다. **레벨을 카드 바닥으로**(PoE 식): Alt 각주 · 힌트와 섞이고 대조 자리에서 멀다

## 파급

- `ilvl` 렌더러 리터럴이 걷힌다 — 제련소 강화 칸 머리의 메타 줄도 `Lv.n` 으로 맞춘다
- CSS — `.tip-head-row` · `.tip-meta` (머리글 양 끝 정렬)
