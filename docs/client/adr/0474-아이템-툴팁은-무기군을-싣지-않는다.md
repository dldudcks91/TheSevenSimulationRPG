## 결정

아이템 툴팁은 무기군(둔기 · 도끼 · 활 …)을 찍지 않는다. 머리글 오른쪽 끝에는 `Lv.n` 하나만 서고, 그 글씨는 머리글보다 한 치수(1px) 작다.

## 맥락

같은 날 ADR-0473 이 무기군과 레벨을 머리글 오른쪽 끝(`둔기  Lv.12`)으로 옮겼다. 사용자는 무기군 표시를 지우고 레벨 글씨를 한 치수 줄이라고 지시했다.

## 근거

- 무기군의 쓸모는 메인 옵션이 이미 든다 — 공격력의 이름(물리 · 마법)과 공격 속도 초가 무기군에서 나온다. 베이스 이름(모닝스타 · 토마호크)도 종류를 말한다
- 머리글 오른쪽에 하나만 남으면 레벨이 비교 두 장의 같은 모서리에서 홀로 읽힌다

## 파급

- `tipCard` 가 `item.groupOf` 를 메인 옵션 계산에만 쓴다 — 머리글에는 안 쓴다
- CSS — `.tip-meta` 의 글씨 = `calc(var(--fs-xs) - 1px)` (확대 배율의 `--fs-xs` 재정의도 따라간다)
- ⚠ 무기군이 화면에서 직접 읽히는 자리가 툴팁에서 사라졌다 — 직업 전속 거절은 플래시(`ch.err.class`)가 든다
