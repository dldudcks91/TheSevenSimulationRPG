# ADR-0476 — 행동 게이지 색은 무기 종류다 · 물리 주황 · 마법 파랑

## 결정

관전 카드의 행동 게이지는 그 유닛이 든 무기의 종류로 칠한다. 물리 무기(평타를 친다)는 주황 `--dt-physical`, 마법 무기(평타가 없다 · `noBasic`)는 파랑 `--color-info` 이고 **양 진영이 같다.** 갈아입어 무기 종류가 바뀌면 다음 카드부터 색이 바뀐다. 파견 창의 행동 게이지(채굴 타격)는 전투가 아니라서 노랑 그대로다.

## 맥락

같은 날 R198 로 마법 무기는 평타를 안 친다 — 행동 게이지가 차도 준비된 스킬이 없으면 **가득 찬 채** 기다렸다가 시전 순간 비운다. 그날 게이지는 영웅 노랑(`--color-warning`) · 적 갈색(`--enemy-fill`)으로 진영만 갈랐다. 그래서 「찼는데 안 비는 게이지」가 멈춤인지 기다림인지 카드에서 읽히지 않았다.

## 근거

- **색이 리듬의 차이를 말한다** — 주황 게이지는 찰 때마다 친다. 파랑 게이지는 찬 채로 스킬을 기다린다. 같은 노랑이면 두 리듬이 같은 물건으로 읽힌다
- **색은 새로 만들지 않았다** — 누적 피해 판의 막대가 이미 물리 = `--dt-physical`, 마법 = `--color-info` 로 칠한다(ADR-0252). 같은 두 색을 쓰면 한 화면 안의 「물리 · 마법」이 한 벌이 된다. 클래스 이름도 막대와 같은 `k-phys` · `k-magic` 이다
- **진영 색을 버렸다** — 적 갈색은 물리 주황과 붙어 구분이 안 된다. 진영은 카드의 자리(위 · 아래)와 띠가 이미 든다. 몬스터도 같은 규칙(R198 — 마법 무기 몬스터는 평타가 없다)이라 색도 같은 규칙을 따른다
- **값은 시뮬이 싣는다** — 재생기가 영웅의 무기 · 몬스터의 장비에서 종류를 다시 읽으면, 갈아입기가 걸리는 시각(보스 라운드 거절 · 라운드 도중)과 어긋날 수 있다. 그래서 시뮬이 쓴 `noBasic` 을 결과 · 이벤트가 싣는다(INTERFACE §2-6)

## 파급

- INTERFACE §2-6 — `result.party[]` · `round`·`call` 의 적 항목 · `refit` 에 `noBasic` 이 붙는다. 적 항목 · `refit` 은 타임라인 안이라 골든 `tl` 이 갈린다(§5-5 재촬영 대기에 합류)
- CSS — `.act-fill.k-phys` · `.act-fill.k-magic`. `.unit.enemy .act-fill`(진영 색)과 `--enemy-fill` 토큰은 걷었다. 기본 `.act-fill` 은 노랑 그대로라 파견 창이 그것을 쓴다
