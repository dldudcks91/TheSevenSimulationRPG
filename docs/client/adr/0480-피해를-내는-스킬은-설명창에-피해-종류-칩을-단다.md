## 결정

피해를 내는 스킬의 설명창 칩 줄에 **종류 칩**을 단다 — 물리면 「물리」, 원소면 원소 이름(`st.atkType.*` — 「불」 · 「냉기」 · 「전기」 · 「독」). 자리는 **태그 칩 뒤 · 능력치 칩 앞**이고(배시 = 「단일 · 물리 · STR」) 모양은 태그 칩과 같다. 하는 일 줄마다 종류를 보되 같은 종류는 한 번만 단다. 종류는 문장과 같은 판정이다 — 타격 · 고정은 원소 태그, 없으면 쓰는 이의 공격 타입(언제나 물리) · 평타 부여(`onhit_element`)는 얹는 원소. 피해가 없는 스킬(버프 · 회복 · 소환 · 평타 퍼뜨리기)은 칩이 없다.

## 맥락

ADR-0477 이 문장마다 피해 종류를 넣은 날, 종류 칩은 「문장과 칩이 같은 말을 두 번 한다」는 이유로 버렸다. 칩 줄에는 출처 · 태그(단일 · 광역 · 다단히트 · 함성 …) · 능력치가 섰고, 태그는 `skill_tag.csv` 의 파생 · 저작 태그뿐이라 종류가 없었다.

## 근거

- 칩은 **훑어 읽는 줄**이다 — 문장을 읽기 전에 「단일 · 물리 · STR」만 보고 어느 방어를 상대하는지 · 어느 능력치가 미는지를 고른다. 같은 말을 두 번 하는 값보다 한눈에 갈리는 값이 크다(사용자 판단)
- `skill_tag.csv` 의 파생 태그로 넣지 않았다 — 태그는 `game_logic` 이 검증 · 집계하는 어휘이고(`MAX_TAGS` · 파생 규칙), 종류는 이미 `skill_effect.csv:element` · `skill_status.csv:element` 가 든 값이다. 같은 값을 두 번 저장하지 않고 이름도 화면의 원소 이름(`st.atkType.*`) 하나를 쓴다

## 파급

- `tip.js:damageTypeOf` — 문장(`amountPhrase`)과 칩이 같은 판정을 부른다 · 칩 클래스 `tip-chip dmg`(모양은 태그 칩 그대로 — 새 CSS 없음)
- ⚠ 자폭은 「물리」 칩이 선다 — ADR-0477 의 열린 질문(방어 · 저항을 안 받는 비직격)과 같다
