# ADR-0484 — 둘째 스킬 칸의 출처 글자는 「습득」이다

| | |
|---|---|
| **상태** | 확정 · 2026-10-02 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 캐릭터 탭 액티브 칸 · §2 스킬 툴팁 출처 칩 · 도움말 |
| **정한 사람** | 사용자 지시 「Book 이라고 되어 있는 걸 … 습득으로 수정해 보자」 (메인 스킬 · 비기 · 전수 · 무기 후보 중) |
| **대체** | ADR-0420 의 출처 글자 「책」(칸의 뜻 — 책으로 배운 스킬 — 은 그대로) |
| **대체됨** | — |

## 결정

액티브 둘째 칸의 출처 글자를 「책 / Book」에서 **「습득 / Learned」**로 바꾼다(`i18n.js:sk.src.book`). 칸 셋이 **영웅 · 습득 · 전직**으로 읽힌다. 캐릭터 탭 칸 아래 글자 · 관전 스킬 칸 툴팁의 출처 칩 · 도움말의 칸 이름이 같은 말을 쓴다. 키 이름(`sk.src.book`)과 데이터의 출처 값(`source = book`)은 그대로다. 리포트 획득 격자의 「책」 배지(`rep.book`)는 실제 스킬북 아이템이라 그대로다.

## 맥락

그날 칸 글자는 「영웅 · 책 · 전직」이었다(ADR-0420 — 2026-09-29 「무기」를 대체). 「책」은 칸이 아니라 그 칸을 채우는 아이템의 이름이라, 같은 화면의 스킬북 아이템 · 서고 탭과 칸이 같은 말로 읽혔다. 같은 날 R197 로 무기를 요구하는 칸이 이 칸 하나가 됐다.

## 근거

- **출처 축을 지킨다** — 영웅 · 전직은 스킬이 어디서 왔나를 말한다. 「습득」도 그렇다. 빈 칸 문구 「배운 스킬 없음」 · 서고의 「배운 스킬」과 같은 말이다
- **버린 안** — 「메인 스킬」: 역할(중요도)을 말해 나머지 두 칸과 축이 섞이고, 첫 칸(영웅)보다 위로 읽힌다. 「비기」: 희귀하고 센 기술로 들려 전직 노드의 필살기와 겹친다. 「전수」: 낯설다. 「무기」: 09-29 에 버린 이름이고 스킬은 무기가 아니라 책에서 온다. 「수련」: 훈련장 탭과 겹친다. 「직업」: 다른 직업의 책도 배워 「내 직업 스킬」로 잘못 읽힌다

## 파급

- i18n — `sk.src.book` 값 · 도움말 스킬 절의 칸 이름(ko 「책 칸」 → 「습득 칸」 · en 「book slot」 → 「learned slot」)
- ⚠ 기획 문서 · 코드 주석의 「배운 칸」 · 「책 칸」은 그대로다 — 화면 글자만 바꿨다
