# ADR-0499 — 스킬 설명창은 「Alt 계산식」 각주를 안 단다

| | |
|---|---|
| **상태** | 확정 · 2026-10-03 |
| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) 스킬 설명창 규격 |
| **정한 사람** | 사용자 지시 「스킬툴팁 아래에 Alt 계산식 이거 문구 모두 삭제해」 |
| **대체** | ADR-0089 의 기본 설명창 바닥 「Alt 계산식」 각주 |
| **대체됨** | — |

## 결정

스킬 설명창 바닥의 「Alt 계산식」 각주 줄을 걷는다. Alt 를 누르는 동안 숫자 뒤에 괄호 식이 서는 규칙(ADR-0089)은 그대로 산다.

## 맥락

그날 스킬 설명창은 기본 상태에서 괄호가 붙을 숫자가 하나라도 있으면 바닥에 「Alt 계산식」 한 줄을 세웠다.

## 근거

사용자 지시. 툴팁은 효과만 짧게 적는다(CLAUDE.md 규칙 7) — 조작 안내는 툴팁의 몫이 아니다.

## 파급

- `tip.js:skillBodyHtml` 의 각주 줄 · i18n `sk.altHint` 를 걷었다. `R.fx` 표지는 남는다(식 자리 판정)
- 단정 「숫자 자리 셋」은 기본 상태에 각주가 **없음**을 본다
