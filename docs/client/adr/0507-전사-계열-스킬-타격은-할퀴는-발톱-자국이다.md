## 결정

**전사 계열**(직업 전사의 스킬 + 그 전직 갈래 — 광전사 · 바바리안 · 선봉장 — 의 스킬)의 스킬 타격은 피해 종류 모양 대신 **할퀴는 발톱 자국**이 선다. 하늘빛 흰 긴 사선 넷(치명 다섯)이 나란히, 엇갈린 박자(줄마다 조금 늦게)로 왼쪽 위에서 오른쪽 아래로 그어진다. 줄마다 길이 · 굵기(바깥 줄이 가늘다) · 시작점 · 각도가 조금씩 달라 깔끔한 베기가 아니라 긁힌 자국으로 읽히고, 줄의 결은 고르지 않은 농담이다. 뒤에 옅은 바람 띠(반투명 납작한 타원) 하나가 떴다 사라진다. 섬광 원판은 없다. 줄은 카드 밖까지 뻗는다. 피해 숫자는 그대로 피해 종류 색이다.

계열은 표에서 읽는다 — 직업 스킬은 `skill.csv:owner_id`, 전직 스킬은 `advance.csv:class_id`(`data.js:skillLine`). 계열 모양이 없는 계열은 피해 종류 모양 그대로다.

## 맥락

그날까지 스킬 이펙트는 **피해 종류**(물리 · 화염 · 냉기 · 전기 · 독 · 종류 없음)로만 모양이 갈렸고(ADR-0412 · ADR-0506), 「화려한 그림은 나중에 전직 스킬에만」(ADR-0412)이 남아 있었다. 사용자가 전사 스킬을 바람의 나라 「백호참」 같은 스타일로 해 달라며 스크린샷을 줬다 — 하늘빛이 도는 흰 긴 사선 서넛이 대상을 가로질러 나란히 그어진 모양이다. Claude 는 직업별 연출이 새 축이고 ADR-0412 와 부딪힌다고 알렸고, 사용자는 참고 그림을 주며 진행했다.

## 근거

- **참고 그림의 요점은 「나란한 긴 사선 여럿 · 하늘빛 흰색 · 고르지 않음」이다** — 줄 수 · 각도 · 색을 그림에서 땄고, 사용자가 말한 「할퀴는 듯한」을 줄마다 다른 길이 · 굵기 · 시작점 · 엇갈린 박자로 냈다
- **피해 종류 대신 계열 모양** — 전사 스킬은 전부 물리라 피해 종류 모양(물리 베기)으로는 다른 물리 스킬 · 평타(ADR-0505 — 같은 베기 줄)와 갈리지 않는다. 피해 숫자의 색은 그대로라 「무슨 피해인가」는 숫자가 든다
- **섬광 원판을 빼다** — 참고 그림에 없고, 원판이 있으면 발톱 자국이 가운데 덩어리에 묻힌다
- **색은 계열 색이다** — 하늘빛 흰색은 피해 종류 색이 아니다(ADR-0406 의 색 규칙은 피해 종류 모양에 선다). 채도는 낮고 번짐 빛은 없다 — 바람 띠는 평평한 반투명 타원이다
- **전직 갈래도 같다** — 「전사 스킬」이 전직 뒤에 바뀌면 같은 직업의 연출이 갈린다. 전직 스킬의 그림(ADR-0412)은 나중에 그 위에 얹는 일이다
