## 맥락

사용자는 코드로 구현된 전사 기본 스킬을 하나씩 확인하고 게임에 맞는 이미지로 구현하도록 요청했다. 현재 스킬별 모양은 `skill_looks.js`의 조각 조합이고, 전사 기본 스킬은 여덟 종이다.

## 결정

- 전사 기본 스킬 여덟 종의 타격·강화 연출을 스킬별 투명 이미지로 표시한다. ADR-0412의 이미지 제한을 이 범위에서 대체한다.
- 기존 모양을 따른다: 배시 사선 셋 · 더블스윙 X · 어스스플릿 지면 균열 · 리프 어택 내리꽂힘과 착지 파문 · 타운트 붉은 고리 · 워 크라이 금빛 음파 · 배틀오더스 상승 꺾쇠 · 아이언 스킨 강철 막.
- 그림은 굵은 암색 외곽선과 평면 색을 쓰고, 초상 둘레 안에서 짧게 움직인다. 버프 그림의 중앙은 비워 초상을 보여 준다.
- `skill_art.js`가 스킬·사건별 그림과 움직임을 든다. 로딩 중이거나 그림을 읽지 못하면 기존 코드 조각을 표시한다.
- 관전과 도감 이펙트 탭은 같은 표시 함수를 사용한다. 배속·켜고 끄기·되감기·조각 정리는 기존 규칙을 따른다.
- 스킬 아이콘, 타임라인, 수치, 게임 로직은 이 변경의 대상이 아니다.

## 파급

- `src/assets/art/fx/skills/<skill_id>.webp`: 게임용 투명 WebP.
- `src/assets/art/fx_source/warrior_basic_20261005/`: 생성 원본·프롬프트·측정·비교 이미지.
- `src/ui/skill_art.js`, `fx.js`, `style.css`: 스킬별 이미지와 움직임.
- `src/ui/app.js`: 도감 이펙트 탭에서도 그림을 미리 읽는다.
