# ADR-0516 — 마스터리 칸은 조건이 꺼져도 켜진 칸과 같은 모양이다

| | |
|---|---|
| **상태** | 확정 · 2026-10-06 |
| **화면** | [SCREEN_DESIGN §7](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「마스터리 조건 달성여부에 따라 색깔이 지금 다르게 적용되는데 모두 똑같이 적용되도록 수정」) |
| **대체** | ADR-0385 의 「꺼진 칸은 흐리게만 한다」 |
| **대체됨** | — |

## 결정

낀 장비가 켜는 마스터리 칸(직업 판 아랫줄 — 든 무기 · 입은 갑옷 · 죄종 판 가운뎃줄 첫 칸 — 그 죄종 장비 수)이 지금 장비로 꺼져 있어도 **그림을 흐리게 하지 않는다.** 조건을 채운 칸과 못 채운 칸이 같은 판 색 · 같은 밝기로 선다. 툴팁의 장비 조건 줄은 그대로 둔다.

## 맥락

ADR-0385 이후 꺼진 칸은 `.sk-cell.icon-only.off` 가 그림을 `opacity .4` 로 흐렸다. 2026-10-05 죄종 판 가운뎃줄 첫 칸이 「그 죄종 장비 n개 이상」 조건을 얻으면서 같은 흐림을 받았고, 판 색 마스크 그림이 조건 달성 여부에 따라 두 가지 색으로 보였다.

## 근거

- **사용자 지시** — 조건 달성 여부로 칸 색이 갈리지 않게 한다
- 조건은 툴팁의 장비 조건 줄이 든다 — 죄종 장비 칸은 지금 낀 수(「(2/3)」)까지 함께 든다

## 파급

- `style.css:.sk-cell.icon-only.off .sk-icon-art` 삭제 · `app.js:masteryCell` 이 `off` 클래스를 안 붙인다
- ⚠ 칸만 보고는 지금 꺼졌는지 모른다 — 무기 · 갑옷 칸은 툴팁에도 지금 맞는지가 안 선다(어느 무기군 · 갑옷군이 켜는지만 적는다)
