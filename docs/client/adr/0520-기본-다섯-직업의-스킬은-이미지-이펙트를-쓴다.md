## 결정

- 기존 전사 8종에 기사 9 · 마법사 8 · 궁수 6 · 사제 8을 더한다. 추가된 31개 스킬은 32장이다. 결투의 적 지목과 시전자 보호는 서로 다른 그림이다.
- 실제 스킬 데이터를 따른다. 스마이트는 방패의 물리 충돌, 인챈트는 화염 강화, 프로즌 월은 불러낸 얼음 벽의 등장, 힐링 라이트와 힐은 회복, 페니턴스와 바인드는 적 약화다.
- 굵은 암색 외곽선 · 평면 색 · 투명 배경을 사용한다. 강화와 보호는 중앙을 비우고, 모든 기본 스킬은 초상 둘레 안에서 짧게 움직인다.
- `skill_art.js`가 사건별 그림과 움직임을 정한다. 타격 · 강화 · 약화 · 회복 · 불러내기 모두 이미지가 준비됐으면 먼저 표시한다. 로딩 중이나 읽기 실패 시 기존 코드 연출을 사용한다.
- 결투의 `stat: duel`은 양수 값이어도 적에게 건 지목이다. 적에게 지목 그림, 시전자에게 보호 그림을 띄운다.
- 기사 오오라 셋은 전투 중 상시 연출을 띄우지 않는 기존 규칙을 유지한다. 도감 이펙트 탭에서만 새 그림을 미리 볼 수 있다.
- 전직 스킬은 이번 범위에 포함하지 않는다. 수치와 게임 로직은 그대로다.

## 파일

- `src/assets/art/fx/skills/<skill_id>.webp`: 게임용 384×384 투명 WebP. 결투 보호는 `kni_duel_guard.webp`.
- `src/assets/art/fx_source/party_basic_20261006/`: 생성 원본 · 최종 프롬프트 · 측정 · 직업별 비교 시트 · 검증 기록.
- `scripts/build_party_skill_fx.py`: 원본 알파와 색을 유지하면서 여백 · 크기 · 인코딩을 맞춘다.
- [발주와 적용 기록](../../reference/party_basic_fx_art.md).
