## 맥락

91px 흉상 위에서 머리를 감싸는 고리는 투구·화관·헤드폰으로 읽혔다. 아래 변과 양옆에 놓은 그림도 알파 bbox로 잘라 중앙에 맞추면 그 자리를 잃는다. 사용자는 업데이트된 [시트 프롬프트](../../reference/basic_skill_fx_sheet_prompts.md)로 생성한 전사·기사 중 전사만 적용하고 기존 그림은 보관하도록 요청했다.

## 결정

- 전사 기본 스킬 8종을 새 전사 시트로 교체한다. 배시 사선 셋 · 더블스윙 X · 어스스플릿 밝은 균열과 바위 · 리프 어택 세 줄 내리꽂힘과 먼지 폭발 · 타운트 아래 변 붉은 가시 부채 · 워 크라이 바깥 함성 줄 · 배틀오더스 양옆 꺾쇠 탑 · 아이언 스킨 아래 양 귀퉁이 강철판이다.
- 타격은 가운데를 치고 강화는 얼굴을 비운 채 아래 변·양옆·귀퉁이에 놓는다. 모든 모양은 굵은 외곽선·평면 음영·밝은 속을 가진다.
- 시트의 검정 격자를 제외한 칸 전체를 자르고 자홍색을 투명하게 처리해 384×384 WebP q90으로 줄인다. 알파 bbox를 잘라 다시 중앙에 맞추지 않는다.
- 전사 `SKILL_ART.fit = 'portrait'`는 실제 초상 폭에 시트 틀을 맞춘다. `size: 101`은 초상 치수를 읽을 수 없을 때의 기본값이다. 강화 동작은 가장자리 자리를 유지하며 아래에서 솟거나 바깥으로 퍼지거나 짧게 오른다.
- 아이언 스킨은 강철판 안을 설치한다. 귀퉁이 번쩍임 안은 원본·후보로 보관한다.
- 기존 전사 WebP 8장과 표시 설정은 `fx_source/warrior_sheet_20261006/previous/`에 복사하고 SHA-256으로 보존을 확인한다. 기존 생성 원본도 남긴다.
- 기사·궁수·마법사·사제의 설치 이미지와 표시 정의는 유지한다. 관전·도감의 공통 표시 함수, 배속, 설정, 되감기와 정리 규칙을 따른다.
