## 결정

- 전사 기본 이펙트 8장을 새 시트 적용 직전 백업으로 복원한다. 전사별 표시 크기·움직임·시간·흔들림 설정도 당시 `SKILL_ART` 값으로 복원한다.
- 현재 모양은 [ADR-0515](0515-전사-기본-스킬은-이미지-이펙트를-쓴다.md)의 배시 사선 셋 · 더블스윙 X · 어스스플릿 균열 · 리프 어택 착지 파문 · 타운트 붉은 고리 · 워 크라이 금빛 음파 · 배틀오더스 상승 꺾쇠 · 아이언 스킨 강철 막이다.
- 새 시트·프롬프트·절단 이미지·후보·적용 검증은 그대로 보관한다. 교체된 새 설치 이미지와 표시 설정도 `fx_source/warrior_sheet_20261006/restored_legacy_20261006/replaced/`에 보관한다.
- 다른 직업의 그림과 표시 정의는 유지한다. 복원한 8장의 SHA-256이 적용 직전 백업과 일치하는지 확인한다.

## 파급

- `scripts/restore_warrior_skill_fx.py`: 백업에서 전사 8장과 해당 표시 정의만 복원한다.
- `scripts/verify_warrior_skill_fx.py --legacy`: 복원 이미지·크기·움직임·도감 재생을 검사하고 복원 폴더에 결과를 남긴다.
- 현재 전사 발주 기록은 [warrior_basic_fx_art.md](../../reference/warrior_basic_fx_art.md), 보관한 새 시트 기록은 [warrior_sheet_fx_art.md](../../reference/warrior_sheet_fx_art.md)다.
