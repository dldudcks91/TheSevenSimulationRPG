# ADR-0530 — 리포트 획득 격자에 처치 재료가 책 뒤에 선다 · 재료 하나가 칸 하나다

## 결정

처치에서 나온 재료(광석 · 목재 · 약초 — item_design §1 「처치 재료」)를 리포트의 **획득 격자**에 세운다. 자리는 **스킬북 칸 뒤**이고, **재료 하나가 칸 하나**다 — 같은 재료가 여러 번 나오면 한 칸에 모으고 오른쪽 아래 숫자가 그 런이 준 개수다. 칸 순서는 광석 → 목재 → 약초. 그림 · 숫자 자리는 창고 재료 탭(§6)의 칸과 같고, 올리면 재료 이름과 획득 수가 뜬다. 흐려지지 않는다 — 재료는 가방 칸을 안 먹고 전부 재고에 든다. 머리 줄의 개수(장비 + 책)에는 넣지 않는다.

## 맥락

같은 날 기획이 처치에서 파견 재료가 약간 나오게 바꿨다(GAME_DESIGN §9 10-06). 리포트 `report.materials` 가 `{산출물 id: 개수}` 로 그 런의 재료를 싣는다(INTERFACE §2-7). 그 전까지 획득 격자는 장비 칸과 스킬북 칸(ADR-0420)만 받았다. 재료는 런 하나에 같은 종류가 여러 개 나오는 것이 보통이다(챕터 1 의 한 칸에 0 ~ 몇 개).

## 근거

- **재료 하나가 칸 하나** — 장비 · 책처럼 개체마다 칸을 세우면 같은 그림이 줄지어 서서 한 줄 높이로 못박은 격자(ADR-0086)를 금방 넘친다. 재료는 개체 차이가 없어 개수만 읽히면 된다 — 재료 탭(§6)이 이미 「그림 + 오른쪽 아래 수량」으로 읽힌다.
- **책 뒤** — 격자의 순서가 「처치당 1개」의 몫(장비 → 책)을 먼저 보이고, 그와 따로 굴리는 재료를 끝에 둔다. 사용자에게 제안한 자리 그대로다.
- **머리 줄 개수에서 뺀다** — 머리 줄의 n 개는 「처치당 1개」로 떨어진 물건의 수다. 재료를 더하면 칸 수와도 개수 합과도 안 맞는 숫자가 된다 — 재료 칸은 제 숫자를 단다.
- 버린 안 — 별도 줄(「획득 재료」 머리 줄을 하나 더): 리포트 상세의 자리가 내용에 흔들리지 않아야 한다는 규칙(ADR-0086)과 부딪히고 줄 하나를 위해 높이를 잡아먹는다.

## 파급

- i18n `rep.matGot`(툴팁 아래 줄 「획득 n」) 신설 · 칸 클래스는 재료 탭의 `mat-cell` · `res-<종류>` 를 그대로 쓴다(새 CSS 없음)
- 옛 리포트(`materials` 없음)는 재료 칸이 없다 · 재료만 있고 장비 · 책이 없는 런도 「없음」 대신 재료 칸이 선다
- ⚠ 런 목록(왼쪽 열)의 「n개」는 장비 수 그대로다 — 재료는 상세에서만 보인다
