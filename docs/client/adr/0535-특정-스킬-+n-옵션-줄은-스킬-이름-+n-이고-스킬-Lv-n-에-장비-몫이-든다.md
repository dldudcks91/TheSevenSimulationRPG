# ADR-0535 — 특정 스킬 +n 옵션 줄은 「스킬 이름 +n」이고 스킬 `Lv.n` 에 장비 몫이 든다

## 결정

- **아이템 툴팁 옵션 줄** — 특정 스킬 +n(`skill_plus`)은 다른 옵션처럼 출처 태그 뒤에 **「파이어볼 +1」**(스킬 이름 + 단계)로 선다. 스킬이 없으면(옛 데이터) 「—」 다
- **스킬 이름 뒤 `Lv.n`** — 고유 · 배운 칸은 **장비 몫까지 더한 레벨**이다(같은 책 업그레이드 + 낀 장비의 그 스킬 +n). 설명창 문장의 숫자도 그 레벨로 낸다. 장비 몫을 따로 떼어 적지 않는다

## 맥락

10-07 에 무기 · 갑옷 오만 줄에 「특정 스킬 +n」이 섰다(기본 스킬 하나 · 그 스킬이 없는 영웅엔 효과 없음 · 책 업그레이드 상한을 넘는다). 전투는 그 단계를 스킬 레벨에 더하므로(`skill.activesFor` 의 `ctx.skillPlus` · INTERFACE §2-8) 화면의 `Lv.n` 이 장비를 빼고 찍으면 관전과 숫자가 어긋난다.

## 근거

- **옵션 줄은 이름 + 값만**(§2 · 도움말 원칙) — 「책 상한을 넘는다」 · 「없는 영웅엔 효과 없음」 같은 규칙은 줄에 안 붙인다. 이름이 곧 스킬 이름이라 「스킬 레벨」 같은 앞말도 안 붙인다(D2 의 「+1 파이어볼」 표기와 같은 모양)
- **`Lv.n` 은 하나의 숫자** — 전투가 쓰는 레벨과 같은 숫자를 한 번만 찍는다. 출처별로 나누는 표기(예: `Lv.5 (+1)`)는 버렸다 — 옵션 툴팁에서 장비 몫이 이미 보인다
