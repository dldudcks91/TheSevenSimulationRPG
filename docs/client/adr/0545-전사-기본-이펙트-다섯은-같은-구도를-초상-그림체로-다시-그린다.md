## 결정

- 전사 기본 이펙트 다섯 장을 **같은 구도 그대로 초상 그림체로** 다시 그린 그림으로 바꾼다. 배시 사선 셋 · 더블스윙 X · 어스스플릿 균열과 바위 · 리프 어택 내리꽂힘과 착지 파문 · 아이언 스킨 양옆 강철 판이다.
- 그림체는 [ADR-0541](0541-마법사-라이트닝-아이스-블라스트는-초상-바깥-위에서-떨어진다.md)과 같다 — 살짝 거친 굵은 먹선, 채도를 뺀 중간 명도, 이 빠지고 찢긴 투박한 모양. 배시 · 더블스윙은 거친 B안(찢긴 자국 · 튄 조각), 나머지 셋은 구도에 충실한 A안이다.
- 배시 · 더블스윙의 자국은 회백색 속에 바랜 강철빛 테두리다. 흰 속 + 하늘빛 띠보다 채도가 낮다.
- 표시 크기 · 움직임 · 시간 · 땅 울림은 그대로다. 함성 셋(타운트 · 워 크라이 · 배틀오더스)은 이 결정에 들지 않는다 — 함성끼리 한 모양으로 통일하는 안을 따로 정한다.

## 맥락

같은 날 마법사 두 스킬을 초상 그림체로 바꾼 뒤(ADR-0541) 사용자가 전사 전체도 같은 스타일로 바꿀 수 있는지 물었다. 전사 그림은 10-06에 새 구도(초상 가장자리)로 바꿨다가 사용자 지시로 예전 그림으로 되돌린 적이 있다(ADR-0527 → 0528). 그래서 이번 후보는 구도를 그대로 두고 그림체만 바꿨고, 스킬마다 충실한 A안과 거친 B안을 지금 그림과 나란히 움직여 보였다.

## 근거

- **구도는 그대로** — 사용자가 되돌린 것은 구도(가장자리 배치)였다. 그림체만 바꾸면 스킬을 알아보는 모양은 지키면서 매끈한 클립아트 결을 걷는다.
- **함성은 뺀다** — 사용자가 「함성 느낌이 나도록 함성 전체를 통일」을 원했다. 타운트 · 워 크라이 · 배틀오더스의 A안은 지금 모양(고리 · 음파 · 꺾쇠)을 따로 옮긴 것이라 통일안이 정해질 때까지 바꾸지 않는다.
