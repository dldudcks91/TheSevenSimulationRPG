# ADR-0546 — 전사 함성 셋은 같은 집중선이고 색만 다르다

| | |
|---|---|
| **상태** | 확정 · 2026-10-08 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) 「연출」 · §9-1 「이펙트 탭」 |
| **정한 사람** | 사용자 지시 — 「함성 느낌이 나도록 함성 전체를 통일」 · 함성 표현 여덟 가지 중 집중선 선택 · 굵은 F2안 선택 |
| **대체** | [ADR-0528](0528-전사-기본-이펙트를-기존-그림으로-복원한다.md)의 타운트 · 워 크라이 · 배틀오더스 그림과 움직임(붉은 고리 · 조여듦 / 금빛 음파 / 상승 꺾쇠 · 솟아오름) |
| **대체됨** | — |

## 결정

- 기본 직업의 함성 셋 — 타운트 · 워 크라이 · 배틀오더스(`skill.csv:tags`에 `shout`) — 은 **같은 그림 틀**을 쓴다. 굵고 끝이 갈라진 먹선 열두 줄 남짓이 초상 네 가장자리에서 얼굴 쪽으로 몰려드는 **집중선**이고, 가운데는 비운다.
- 스킬은 **색으로만** 갈린다. 타운트는 핏빛 · 워 크라이는 바랜 금빛 · 배틀오더스는 녹청 청동이다.
- 움직임도 하나다. 셋 모두 작게 시작해 퍼지는 `wave` · 크기 90 · 580ms다. 타운트의 조여듦과 배틀오더스의 솟아오름은 걷는다.
- 그림체는 [ADR-0545](0545-전사-기본-이펙트-다섯은-같은-구도를-초상-그림체로-다시-그린다.md)와 같은 초상 그림체다.
- 전직 스킬의 함성(사자후 · 호령 · 일갈)은 이 결정에 들지 않는다.

## 맥락

전사 이펙트를 초상 그림체로 바꾸며(ADR-0545) 함성 셋은 따로 두었다. 사용자가 「함성 느낌이 나도록 함성 전체를 통일」을 원했기 때문이다. 처음 시안 둘(양옆 음파 호를 색만 바꾼 안 · 음파 틀 아래 상징을 단 안)은 마음에 드는 것이 없다고 했다. 그래서 워 크라이 하나로 함성 표현 여덟 가지(집중선 · 뾰족 말풍선 · 떨림 표시 · 충격파 · 입김 · 갈라진 공기 · 포효 부채 · 북소리 꺾쇠)를 그려 보였고, 사용자가 집중선을 골랐다. 그 틀로 셋을 촘촘한 안과 굵은 안으로 그렸고, 굵은 안을 골랐다.

## 근거

- **집중선은 외치는 얼굴의 약속된 기호다** — 만화에서 소리치는 얼굴 둘레에 긋는 선이라, 고리나 음파처럼 머리에 쓴 물건(투구 · 헤드폰)으로 읽히지 않으면서 「소리친다」로 바로 읽힌다.
- **모양 하나 · 색 셋** — 「통일」의 뜻대로 함성이면 같은 모양이고, 어떤 함성인지는 색이 가른다. 상징을 다는 안은 가슴 위에 물건(방패 등)이 얹혀 버렸다.
- **움직임도 하나** — 모양이 같은데 하나는 조여들고 하나는 솟으면 같은 가족으로 안 읽힌다.
