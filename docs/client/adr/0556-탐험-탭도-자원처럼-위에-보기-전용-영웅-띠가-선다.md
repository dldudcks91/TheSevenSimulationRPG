## 결정

탐험 탭 맨 위에 공통 영웅 띠(§5)가 선다. 자원 탭(ADR-0369)과 **같은 보기 전용 띠**다. 카드 위칸 「지금 하는 일」로 누가 탐험에 나가 있고(「탐험 중」) 누가 놀고 있나(「대기」)를 보여 줄 뿐이고, 클릭을 받지 않는다(툴팁은 뜬다). 보낼 영웅은 지금처럼 아래 지점 패널의 칩이 고른다. 띠 아래로 지도(남는 세로) → 지점 패널(제 높이) 순서는 그대로다.

## 맥락

2026-10-09 탐험 탭은 지도 + 지점 패널 두 덩어리였다(ADR-0553). 같은 날 사용자가 「탐험도 자원처럼 위에 영웅들이 쫙 나오도록」을 지시했다. 자원 탭은 2026-09-27 부터 같은 자리에 보기 전용 띠를 두고 있었다.

## 근거

- **두 탭은 같은 종류다** — 둘 다 「보내 놓고 기다리는」 탭이라, 누가 어디에 나가 있나가 먼저 읽혀야 한다. 같은 띠 · 같은 자리면 두 탭을 오갈 때 로스터가 같은 곳에 선다(§5 「어느 탭에서든 로스터가 같은 자리」)
- **띠를 고르개로 쓰는 안은 버렸다** — 카드를 눌러 보낼 영웅을 넣고 빼면 칩 줄이 필요 없어진다. 하지만 자원 탭 띠와 같은 띠가 탭마다 다른 동작을 하게 되고(자원은 아무것도 안 함), 원정 · 수색 · 전직 중인 영웅을 띠에서 어떻게 막아 보일지가 새로 생긴다. 사용자 지시는 「자원처럼」이었다
- **지도 크기를 내준다** — 띠 높이만큼 지도가 줄어, 1600×800 한 장에서 지도가 칸을 가로로 가득 채우지 못하고 좌우가 빈다(ADR-0540 의 「가로로 가득」이 이 화면에서는 무너진다). 지도 비(2.15:1)는 바꾸지 않았다 — 그림을 다시 자르면 마스크 · 좌표를 전부 다시 잡아야 한다

## 파급

- `app.js:renderExplore` — 쌓인 판 맨 위에 `heroStrip(() => {}, { view: true })`(자원 탭과 같은 호출)
- `style.css` — 띠와 지도 칸 사이 간격 한 줄
- i18n 키 추가 없음 — 띠의 「탐험 중」은 `hs.doing.explore`(ADR-0553 때 이미 섰다)
- ⚠ 열린 것 — 지도가 좁아져 아이콘도 같이 작아진다(지도 폭의 %) · 띠를 고르개로 쓰는 안은 필요하면 다시 연다
