# ADR-0562 — 스킬 이펙트 투명도는 설정 탭에서 네 단계로 고른다

## 결정

- 설정 탭에 **이펙트 투명도** 줄이 선다 — `0%` · `25%` · `50%` · `75%`(기본 **0%** = 그대로). 자리는 **이펙트 그림체 줄 바로 아래**이고 스킬 이펙트가 `Off` 면 흐려져 안 눌린다(값은 남는다).
- **스킬 이펙트만** 옅어진다 — 스킬이 그리는 그림 · 코드 조각 · 카드 훑음. 기본 공격 이펙트 · 피격 반응(번쩍임 · 흔들림 · 쓰러짐 막) · 피해 숫자는 그대로다.
- 누른 순간부터 다음 사건에 먹는다 · 이 브라우저에만 남는다. **도감 이펙트 세그먼트에도 먹는다** — 관전에서 보일 모습을 그대로 본다.

## 맥락

같은 날 관전의 스킬 이펙트 그림체를 설정 탭에서 고르게 됐다(ADR-0561 — 깔끔한 그림 · 수묵 · 초상 그림체 · 코드 모양). 그림이 초상 · 피해 숫자를 가린다는 문제는 이전부터 크기 · 길이 · 그림체로만 다뤄 왔고(ADR-0549 · 0551), 사용자가 진하기를 직접 고르게 하자고 했다.

## 근거

- **네 단계 · 100% 없음** — 다른 연출 줄(피격 시 흔들림 0~3)과 같은 버튼 줄이다. 완전히 투명하면 끈 것과 같으므로 `Off` 가 이미 그 일을 한다
- **값은 투명도(%)** — 사용자의 말이 「투명도」였다. 0% 가 그대로라 기본값이 「아무것도 안 했다」로 읽힌다
- **스킬만** — 기본 공격 · 피격 반응은 이미 따로 켜고 끄는 줄이 있고, 투명도를 묶으면 어느 줄이 무엇을 바꾸는지 흐려진다
- **도감에도 먹는다** — 켜고 끄기는 도감에서 무시하지만(보려고 연 화면 — ADR-0513), 투명도는 생김새라 그림체 탭처럼 「관전에서 이렇게 보인다」를 보여 줘야 고를 수 있다
- **조각마다 `filter: opacity()`** — 조각의 애니메이션이 `opacity` 를 쓰고 있어 같은 속성을 덮으면 나타나고 사라짐이 깨진다. 필터로 곱하면 둘이 겹친다
