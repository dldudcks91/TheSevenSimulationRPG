# ADR-0565 — 탐험 지점 창 머리는 지점 이름만 쓰고 땅 이름을 안 붙인다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §8-4](../SCREEN_DESIGN.md) |

| **대체** | [ADR-0563](0563-탐험-지점은-장마다-이름과-한-줄-이야기를-갖는다.md) 의 「창 머리 = 지점 이름 · 땅 이름」 |
| **대체됨** | — |

## 결정

탐험 지점 창 머리는 지점 이름 하나만 쓴다(「피난민 동굴 · 불타는 전장」 → 「피난민 동굴」). 아이콘의 접근성 라벨도 지점 이름 하나다.

## 맥락

ADR-0563 으로 지점마다 장 고유의 이름이 생겼다. 그 뒤로도 머리는 옛 「동굴 · 땅 이름」 틀을 그대로 이어 「피난민 동굴 · 불타는 전장」처럼 땅 이름을 덧붙였다.

## 근거

- **어느 땅인지는 이미 보인다** — 창은 고른 아이콘 바로 옆에 뜨고, 아이콘 테두리가 그 땅의 색이며, 지도 위 자리가 곧 그 땅이다
- **지점 이름이 이제 땅마다 다르다** — 「동굴」 하나로 부르던 때는 땅 이름이 있어야 어느 동굴인지 갈렸지만, 「까마귀 동굴」은 그 자체로 하나뿐이다
- 이야기 줄이 땅의 사연을 함께 든다

## 파급

- `app.js` — 머리 · 아이콘 라벨이 `exSpotName` 하나를 쓴다
- i18n — `ex.where` 를 지운다(부르는 곳이 없다)
