# ADR-0566 — 관전 카드는 개편판으로 고정한다 · 전/후 비교 버튼을 걷는다

## 결정

`⚙` 판 설정 탭의 개발용 줄 `Card [Before | After]` 를 걷는다. 관전 유닛 카드는 **어느 브라우저에서나 개편판**(ADR-0262 이름 띠와 뒤따르는 카드 개편 전부)이다 — 전에 `Before` 를 골라 둔 브라우저도 개편판으로 선다(저장된 선택을 더는 읽지 않는다). 개편 전 모양으로 돌리는 길은 코드의 `battle.js:CARD_V2` 한 줄만 남는다. 같은 판의 `Focus` 줄은 그대로다.

## 맥락

전/후 버튼은 2026-09-21 카드 개편을 들이며 「빠르게 롤백이 가능해야」 한다는 지시로 상단바에 달았고, 2026-10-01 설정 탭 끝으로 옮겼다. 그 뒤 개편판은 띠 내용 · 카드 폭 · 칸 크기를 여러 번 고쳤고(ADR-0265 · 0270 · 0274 · 0275) 기본값은 줄곧 개편판이었다.

## 근거

- **비교가 끝났다** — 버튼은 「개편이 정해지면 걷는다」는 임시 장치였다(SCREEN_DESIGN §10-2). 사용자가 개편판을 골랐다
- **저장된 선택을 안 읽는다** — 버튼만 걷고 저장값을 계속 읽으면, 예전에 `Before` 를 고른 브라우저는 고칠 길 없이 개편 전 카드에 갇힌다
- **코드 스위치는 남긴다** — 개편 전 모양의 코드는 스위치 하나 아래에 모여 있어 남겨 둬도 화면에 안 나온다. 걷는 것은 따로 할 수 있는 정리다
- **버린 안** — 개편 전 코드(`.unit.v2` 밖 분기 · 옛 신원 줄)까지 한 번에 걷기: 이번 지시는 비교 버튼을 없애는 것이고, CSS 규칙을 합치는 일은 화면 회귀를 따로 봐야 한다

## 파급

- `src/ui/devcompare.js` — `mountCardCompare` · 저장값(`devCard`) 되살리기를 걷는다. `Focus` 만 남는다
- `src/ui/app.js` — 설정 탭이 `mountCardCompare` 를 안 부른다
- `src/ui/battle.js` — 카드 모양은 `CARD_V2` 만 본다(`<html data-card>` 를 안 읽는다)
