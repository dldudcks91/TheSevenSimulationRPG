# ADR-0574 — 선술집 가입 희망 칸은 수색 오른쪽 세로 초상 줄이고 누르면 후보 카드 창이 뜬다

## 결정

선술집 명단 줄의 맨 오른쪽에 **「가입 희망」 세로 한 줄**을 세운다. 작은 제목 아래 초상 칸(`tavern_join_slots` 개)이 위에서 아래로 서고, 찬 칸은 초상 + 아래 띠의 **남은 시간**, 빈 칸은 점선이다. 초상을 누르면 **가입 희망 창**이 떠서 명단과 같은 후보 카드 + 남은 시간 + **[고용]**을 보인다. 수색이 끝나 여백 칸(이야기 · 만남 · ADR-0144)이 서면 그 칸은 가입 희망 줄의 왼쪽에 선다.

## 맥락

기획이 탐험 마차(보호)의 보상으로 「이긴 적 영웅의 가입 희망」을 확정하고, 그 영웅이 선술집으로 찾아오게 했다(창구는 선술집 하나 · base_expedition §2-4). 사용자가 자리(수색 오른쪽 · 세로 넷 안팎) · 고르는 법(클릭해서 고용) · 남은 시간 표시를 지시했다. 명단 격자 오른쪽에는 수색이 끝났을 때만 쓰던 여백이 있었다.

## 근거

- **초상만 세우고 고르는 일은 창이 든다** — 오른쪽 남는 폭은 후보 카드 한 장보다 좁아 카드를 넷 세울 수 없다. 초상과 남은 시간만 세우고, 누르면 명단과 같은 카드를 띄워 같은 판단 재료(능력치 · 고유 스킬 · 등급)로 고른다. 클릭 한 번에 곧장 골드가 나가면 초상을 잘못 눌러도 고용된다
- **남은 시간을 늘 보인다** — 떠나는 것이 규칙이므로 숨기면 사라진 영웅이 버그로 읽힌다
- **빈 칸도 선다** — 명단의 빈 칸과 같은 이유. 칸이 없으면 「없는 기능」으로 읽힌다
- **여백 칸은 왼쪽으로 비킨다** — 가입 희망 줄은 늘 서고 여백 칸은 수색이 끝났을 때만 선다. 늘 선 것이 끝자리를 지켜야 줄이 흔들리지 않는다
- **버린 안** — ① 초상 클릭 즉시 고용: 비용이 보이지 않는 자리에서 골드가 나간다 ② 초상에 마우스를 올리면 영웅 툴팁: 툴팁은 효과만 적는 자리(CLAUDE.md 규칙 7)라 후보를 고르는 재료를 다 못 든다
