# ADR-0574 — 탐험 지점 창은 지도의 빈 자리를 눌러도 닫힌다

## 결정

탐험 지점 창은 머리의 ✕ 말고도 **지도 칸의 빈 자리**(창 · 지점 아이콘 밖 — 잠긴 구간 막 · 자물쇠 · 지도 둘레의 빈 칸 포함)를 누르면 닫힌다. **누른 자리와 뗀 자리가 둘 다 바깥**이어야 닫힌다. **위 영웅 띠는 안 닫는다** — 창이 열린 동안 보낼 영웅을 고르는 자리다. 지점 아이콘은 지금처럼 그 지점을 고르고 창을 연다. 닫힌 것은 세이브가 아니다.

## 맥락

같은 날 지도 아래 패널을 걷고 아이콘 옆에 뜨는 지점 창이 섰다(ADR-0558). 창은 지도 일부를 가려서 머리에 ✕ 가 섰고 닫는 길은 그것 하나였다. 다른 창(창 레이어 §2)은 닫기 버튼 · 판 바깥 클릭 · `Esc` 셋으로 닫힌다.

## 근거

- 지도 위에 뜬 창은 손이 이미 지도에 가 있다 — 작은 ✕ 를 찾아가는 것보다 빈 땅을 누르는 쪽이 짧고, 다른 창에서 배운 손짓(바깥 클릭)과 같다
- 영웅 띠는 「바깥」으로 치지 않는다 — 대기 지점에서 띠 카드를 누르는 것이 보낼 영웅을 넣고 빼는 손짓이라, 띠가 창을 닫으면 고르는 순간 창이 사라진다
- 누른 자리와 뗀 자리를 둘 다 보는 것은 창 레이어와 같은 이유다 — 창 안에서 시작한 드래그(글줄 긁기 등)가 바깥에서 끝나도 창이 안 닫힌다
- 버린 안 — **`Esc` 도 같이 단다**: 사용자는 바깥 클릭만 말했고, 이 창은 창 레이어(`openModal`)가 아니라 지도 안의 칸이라 `bindEsc` 에 걸리지 않는다. 필요해지면 따로 단다
