# ADR-0576 — 스킬 레벨 `Lv.n` 은 그림 오른쪽 아래에 선다 · 아이템 칸과 같은 글이다

## 결정

스킬 레벨 `Lv.n` 은 **그 스킬 그림의 오른쪽 아래**에 선다 — 아이템 칸의 `Lv.n`(ADR-0168)과 **같은 글**(판 없이 검은 테두리를 두른 작은 글자 · 같은 크기 · 같은 색 · 같은 구석). 그림이 있는 모든 스킬 레벨 자리가 그렇다 — 스킬 설명창 이름 줄의 아이콘 · 스킬 창 액티브 줄의 아이콘 · 스킬 창 전직 판의 배운 스킬 칸 · 서고 배우기 머리 줄(지금 가진 스킬)의 그림 · 서고 전직 패널의 배운 스킬 줄 그림(줄 끝 글은 「배움」만 남는다). 이름 뒤의 `Lv.n` 은 걷는다.

## 맥락

그날까지 스킬 레벨은 이름 바로 뒤의 글이었다(ADR-0529) — 설명창 · 액티브 줄 · 서고 머리 줄. 전직 판의 배운 칸만 그림 오른쪽 아래였고, 그것도 마스터리 칸 랭크 꼬리표(`.sk-icon-rank` — 바탕을 깐 판)의 모양이었다. 서고 전직 패널의 배운 줄은 끝에 「배움 · Lv.n」을 썼다. 아이템 레벨은 처음부터 칸 오른쪽 아래의 판 없는 글이었다(ADR-0168).

## 근거

- **레벨은 그림에 붙은 값으로 읽힌다** — 아이템 칸 · 영웅 카드(ADR-0278)가 이미 「오른쪽 아래 = 레벨」이다. 스킬만 이름 뒤에 두면 같은 `Lv.n` 이 화면마다 다른 자리에서 찾아진다
- **글은 아이템 칸과 한 규칙을 쓴다**(`.inv-lv` 와 같은 선택자) — 따로 두면 크기 · 색이 갈라진다. 전직 판 칸의 판 깐 꼬리표도 그래서 바꾼다. 마스터리 칸의 `랭크/상한` 은 레벨이 아니라 그대로 둔다
- 버린 안 — **이름 뒤에 두고 그림에도 단다**: 같은 값을 한 줄에 두 번 찍는다

## 파급

- CSS — `.sk-lv` 가 `.inv-lv` · `.pd-lv` 규칙에 든다 · 그림 칸(`.tip-card.skill .tip-sk-ico` · `.act-slot .ico` · `.bk-ico` · `.tr-adv-ico`)이 `position: relative` · `.tip-name-lv` · `.act-slot .nm .lv` · `.bk-cur-sk .bk-lv` 퇴역
- i18n — `tr.adv.learnedLv` 퇴역 · 배운 줄 끝은 `tr.adv.learned` · `sk.lvTag` 글은 그대로
- ⚠ 서고 가진 책의 읽기 줄(ADR-0573)은 그림이 없고 칸 오른쪽 아래는 권수 `×n` 이 쓴다 — 그 줄의 `Lv.n` 은 이 결정의 범위 밖이다
- ⚠ 캐릭터 탭 스킬 칸은 레벨을 안 든다(ADR-0040 · ADR-0529 의 버린 안) — 이 결정이 거기까지 넓히지 않는다
