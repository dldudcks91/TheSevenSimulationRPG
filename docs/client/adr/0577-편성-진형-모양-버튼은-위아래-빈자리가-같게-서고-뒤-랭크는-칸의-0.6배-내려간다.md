# ADR-0577 — 편성 진형의 모양 버튼은 위아래 빈자리가 같게 서고 · 뒤 랭크는 칸의 0.6배 내려간다

## 결정

편성 탭 진형 상자에서 두 가지를 바꾼다.

1. **모양 버튼 열**(`formation_template.csv` 행마다 하나 · 그날 넷)은 **위아래 빈자리가 같게** 선다 — 「진형」 밑줄에서 첫 버튼까지와 끝 버튼에서 「물약」 이름까지가 같다. 보드 높이가 고정이라 템플릿을 바꿔도 버튼 열이 안 움직인다.
2. 뒤 랭크가 내려가는 단(`--fm-step`)을 **칸 한 변의 0.6배**로 키운다(0.35배에서).

## 맥락

버튼 열은 보드 위쪽에 붙어 섰다(위 정렬). 이 정렬은 진형 상자가 출정 창 안에서 옆 칸 「출정 방식」과 이름 줄을 맞추던 시절의 것인데, 상자가 편성 탭으로 옮겨 온 뒤에도 남아 있었다. 그 결과 「진형」 밑줄 아래 빈자리는 좁고(밑줄 아래 여백 28px) 버튼 아래 빈자리는 넓었다(보드의 남는 높이 + 물약까지 36px). 단은 ADR-0491 로 0.22 → 0.35배가 됐지만 1600×800 한 장에서 전열과 후열이 여전히 크게 갈려 보이지 않았다(118px 칸에서 약 41px).

## 근거

- **버튼 열의 가운데 정렬은 보드 기준이 아니라 눈에 보이는 빈자리 기준이다** — 보드 세로 가운데에만 세우면 위(밑줄 아래 28px)와 아래(물약까지 36px)의 여백 차만큼 아래가 넓다. 그 차를 위에 얹어 「밑줄 ↔ 첫 버튼 = 끝 버튼 ↔ 물약」으로 맞춘다. 두 여백 값은 CSS 변수 하나씩(`--fm-head-gap` · `--pt-left-gap`)이라 어느 쪽을 고쳐도 맞춤이 따라온다
- **단을 키워도 보드 높이는 고정이다** — 높이가 `칸 + 단 + 라벨` 로 늘 랭크 최대 기준이라 템플릿을 바꿔도 물약 칸이 안 흔들린다(ADR-0234 의 약속). 단이 커진 만큼 진형 상자가 한 번 길어질 뿐이고, 왼쪽 열 아래가 비어 있어 세로 예산이 있다
- **버린 안** — 버튼을 보드 세로 가운데에만 세우는 안: 사용자가 본 것은 밑줄과 물약 사이의 빈자리라 8px 이 어긋난다. 버튼 사이 간격을 벌려 열을 보드 높이에 채우는 안: 지시가 「내려 달라」였고 버튼이 흩어져 한 묶음으로 안 읽힌다
- **관전은 그대로다** — ADR-0491 과 같은 이유(지시가 편성 화면 · 관전 아레나 세로 예산)

## 파급

- `style.css` — `--fm-step` 0.35 → 0.6배(보드가 약 30px 길어진다) · `.fm-side` 가 `align-self: center` + 여백 차만큼 `margin-top` · `.pt-left` 가 `--pt-left-gap`(36px) · `--fm-head-gap`(28px) 를 든다
- 로직 · i18n · 조작은 안 바뀐다
