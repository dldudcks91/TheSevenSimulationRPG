# ADR-0578 — 서고 「지금 가진 스킬」은 캐릭터 탭 액티브 카드 셋이다

## 결정

서고 배우기 카드 머리의 「지금 가진 스킬」은 캐릭터 탭 「액티브 스킬」(§6)과 **같은 카드 셋**이다 — 같은 함수(`app.js:skillCardGrid`)가 그린다. 고유 · 습득 · 전직 칸이 **늘 셋** 서고(빈 칸은 점선 · 잠긴 칸은 자물쇠), 칸 아래에 출처 글자, 무기가 안 맞는 칸은 흑백이다. 서고에서만 찬 칸 그림 오른쪽 아래에 `Lv.n` 을 단다(ADR-0576).

## 맥락

같은 날 서고 머리는 액티브 칸 중 **찬 것만** 한 줄로 늘어놓았다(그림 · 이름 — ADR-0567 · 레벨 자리는 ADR-0576). 그래서 빈 칸이 안 보였고, 캐릭터 탭의 같은 정보와 모양이 달랐다.

## 근거

- 「3가지가 나열되는 형태」 — 칸이 셋 다 서야 책을 읽으면 **어느 칸**이 차거나 바뀌는지(습득 칸)가 보인다. 찬 칸만 늘어놓으면 빈 습득 칸이 안 보인다
- 같은 함수를 쓰면 캐릭터 탭이 바뀔 때 서고도 같이 바뀐다 — 두 모양이 갈리지 않는다
- `Lv.n` 은 서고에서만 — 같은 날 ADR-0576 이 서고 머리의 그림에 레벨을 두었다. 캐릭터 탭 카드는 「찬 칸은 그림 하나뿐」(§6)이라 그대로 둔다
- 버린 안 — **스킬 창 액티브 줄(§7 — 출처 · 그림 · 이름 · 쿨 · 문장 세 줄)**: 서고 왼쪽 위 카드 높이에 세 줄이 안 들어간다

## 파급

- `app.js` — `skillCards` 의 카드 줄을 `skillCardGrid(h, tipCtx, { lv })` 로 떼어 냈다(캐릭터 탭은 그대로 그린다) · 서고 머리의 찬 칸 줄(`.bk-cur`)과 「없음」 줄을 걷었다
- CSS — `.bk-cur*` 삭제 · `.sk-cards.lv .sk-card` 에 `position: relative`(레벨 글자 자리)
