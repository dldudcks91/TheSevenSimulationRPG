# ADR-0581 — 능력치 줄에 올리면 이름과 효과 카드가 선다

## 결정

능력치 줄에 마우스를 올리면 **이름 / 가는 선 아래 효과** 카드가 선다. 효과가 여럿이면 **한 줄에 하나**다. 물약 카드 · 창 뱃지 툴팁과 같은 클래스(`.tip-effect-head` · `.tip-effect-summary`)다. 서는 자리는 캐릭터 탭 기본 옵션의 능력치 막대 줄 · 세부 옵션 1 · 2 의 모든 줄 · 후보 카드(시작 화면 · 선술집)의 능력치 줄이다. 유닛 툴팁 · 도감 몬스터 툴팁 **안의** 같은 줄에는 안 선다. 문구는 i18n `st.desc.<줄 id>` 한 곳에 둔다.

## 맥락

그날 캐릭터 탭의 능력치 줄은 이름과 값만 찍었고 올려도 아무것도 안 떴다. 능력치가 무엇을 바꾸는지는 도움말 탭의 문단(`ch.attr.note` · `ch.detail.note`)이 묶어서 말할 뿐 줄마다의 설명이 없었다. 기본 능력치 일곱은 09-10 이후 스킬 계수 · 파견 산출로 뜻이 바뀌어 이름만으로는 읽히지 않았다(힘 = 평타 · 물리 스킬 · 채광 등).

## 근거

- **물약 카드와 같은 모양** — 「이름 / 선 아래 효과」는 이미 물약 · 창 뱃지가 쓰는 툴팁 문법이다. 새 카드 모양을 만들지 않는다
- **효과가 여럿이면 한 줄에 하나** — 처음엔 `·` 로 이었는데 영어에서 카드 폭을 넘겨 접히자 `· Faster mining` 처럼 가운뎃점이 줄 머리에 걸렸다(헤드리스 실측). 기본 능력치 일곱 중 여섯이 효과가 둘 이상이다
- **값은 카드에 안 넣는다** — 올린 줄이 이미 값을 든다. 카드가 같은 수를 다시 찍으면 같은 말을 두 번 한다
- **효과만 적는다** (CLAUDE.md 규칙 7) — 공식(곡선 · 상한 · 체감) · 파티 합산 · 어느 장비가 주나는 규칙이라 도움말의 몫이다
- **값이 `—` 인 줄도 선다** — 비어 있는 축이 다음 장비의 자리(§6)라, 무엇을 하는 축인지 알아야 장비를 고른다
- **후보 카드도 같은 줄 조립을 쓴다** — 고용 · 시작 영웅을 고를 때가 능력치의 뜻이 가장 필요한 순간이다. 후보 카드가 따로 짜던 막대 줄을 `tip.js:attrRowsHtml` 로 바꿔 두 자리가 한 표기다
- **툴팁 속 줄은 안 선다** — `#tooltip` 은 한 자리라 카드 위에 카드를 띄우면 원래 카드가 사라진다
- 버린 안 — **CSV 에 `desc_kr`/`desc_en` 열**(`hero_tier.csv` · `skill.csv` 의 선례): 세부 옵션 중 옵션이 여는 줄(`fx_*` · `tip.js:FX_ROWS`)은 CSV 행이 없어 문구가 두 곳으로 갈린다. 기존 `description_kr` 은 기획 메모(취소선 · 날짜 · 키)라 화면에 그대로 못 쓴다
- 버린 안 — **브라우저 `title` 속성**: 뜨는 데 지연이 있고 모양 · 위치가 게임 툴팁과 달라 한 장 배율(ADR-0087)도 안 탄다

## 파급

- i18n — `st.desc.<id>` 40키(기본 능력치 7 · 세부 옵션 줄 33) ko · en
- `tip.js` — 줄에 `data-stat` 를 단다(`attrRowsHtml` 은 이름 · 막대 · 값 세 칸 · `sheetRowsHtml` · `fxRowHtml` 은 줄) · `bindStatTips(root)` 신설
- `app.js` — `attrPanel` · `detailPanels` · `candidateCard` 가 `bindStatTips` 를 부른다 · `candidateCard` 의 막대 줄 조립을 `attrRowsHtml` 로 바꿨다
- CSS — `.tip-card.stat-tip`(폭은 글자만큼 · 효과 줄은 낱말 단위로 접힌다)
- 단정 — 줄 id 전부에 `st.desc.*` 가 있고 영어 문구에 한글이 없는지
