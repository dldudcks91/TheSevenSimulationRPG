# ADR-0598 — 도서관 스킬 업그레이드와 스킬 북 제작 카드는 높이가 같다

## 결정

도서관 탭 오른쪽 열의 두 카드 — 스킬 업그레이드(위) · 스킬 북 제작(아래) — 는 **띠 아래 남는 세로를 반씩 나눈다.** 내용이 카드보다 길면 그 카드 본문이 스크롤한다.

## 맥락

ADR-0573 은 책 만들기 카드를 제 내용 높이로 두고 배우기(지금 스킬 업그레이드) 카드가 남는 세로를 받게 했다 — 그날 배우기 카드는 머리 스킬 카드 셋 · 가진 책 칸까지 들어 길었다. 같은 날 ADR-0595 가 스킬 카드 셋을 전직 패널로 보내 위 카드가 짧아졌고, 위 카드 아래에 빈 자리가 크게 남았다. 사용자가 두 카드의 높이를 같게 하라고 했다.

## 근거

- **위 카드가 짧아져 「남는 세로」를 받을 이유가 사라졌다** — 위 카드에 남은 것은 읽기 줄과 가진 책 칸뿐이다
- **반반이 두 카드를 같은 무게로 읽게 한다** — 오른쪽 열이 같은 크기의 상자 둘로 선다

## 파급

- CSS `.lib-col > .panel:last-child { flex: 0 1 auto }` 를 걷는다 — 두 카드가 `.lib-col > .panel { flex: 1 1 0 }` 하나를 받는다
