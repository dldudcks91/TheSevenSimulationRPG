# ADR-0603 — 스킬 업그레이드 카드 제목 옆에도 물음표가 선다

| | |
|---|---|
| **상태** | 확정 · 2026-10-12 |
| **화면** | [SCREEN_DESIGN §17](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「스킬 업그레이드 오른쪽에 ?를 넣고 보유한 스킬북을 통해 스킬 레벨을 업그레이드 할 수 있습니다 << 이렇게 수정」) |
| **대체** | — (ADR-0600 이 스킬 북 제작 카드에 단 `?` 를 위 카드에도 단다) |
| **대체됨** | — |

## 결정

도서관 **스킬 업그레이드** 카드 제목 바로 오른쪽에 `?` 표시가 선다 — 스킬 북 제작 카드의 `?`(ADR-0600) · 편성 탭 소제목의 `?`(ADR-0464)와 같은 원 · 같은 툴팁 카드다. 올리면 카드 이름 아래에 사용자가 정한 문장 「보유한 스킬북을 통해 스킬 레벨을 업그레이드 할 수 있습니다.」가 뜬다. 같은 문장이 도움말 도서관 섹션에도 선다.

## 맥락

같은 날 ADR-0600 이 스킬 북 제작 카드 제목 옆에 `?` 를 달았다. 사용자가 위 카드에도 같은 표시를 달고 문장을 정해 주었다.

## 근거

- **두 카드가 같은 모양이어야 한다** — 오른쪽 열의 두 카드는 높이(ADR-0598)도 제목 줄 모양도 같다
- **문장은 사용자 원문 그대로다** — 영어는 같은 뜻의 직역이다
- ⚠ ADR-0600 과 같은 예외 — 규칙 문장(CLAUDE.md 규칙 7 · §12)이 `?` 를 올릴 때만 뜨고 카드 본문에는 없다
