## 결정

무덤 명패의 비석은 **그림 한 장**(`src/assets/art/grave/tombstone.webp`)이다 — 아치 위에 뿔 달린 악마 해골을 인 돌 비석 · 앞면 가운데가 빈 판 · 발치에 흙 둔덕. 일곱 챕터보스가 **같은 한 장**을 쓴다. 보스 이름과 남은 시간은 그림에 없고 화면이 **빈 앞면 위에** 얹는다. 그림은 초상 자리(관전 카드 · 출정 창 적 칸) 세로를 거의 채운다.

## 맥락

ADR-0590 은 「비석 하나에 아트 발주를 걸지 않는다 · 그림이 생기면 같은 자리에 갈아 끼운다」며 명패를 CSS 그라디언트 돌판(위가 둥근 사각)으로 칠했다. 같은 자리의 다른 그림(보스 초상 · 신단 카드의 신단 그림)은 굵은 외곽선 카툰인데 명패만 납작한 UI 조각이라 「보스가 죽어 있다」보다 「빈 칸」으로 읽혔다. 사용자가 Codex 로 그려 넣으라고 지시했다.

## 근거

- **글자는 그림에 안 굽는다** — 이름은 ko/en 이 다르고(CLAUDE.md 규칙 6) 남은 시간은 매초 간다. 그래서 발주는 「앞면을 비워라 · 룬도 금도 앞면을 지나지 않는다」였고, 화면이 그 빈 판 자리에 글자를 얹는다.
- **보스마다 다른 비석을 안 그린다** — 명패는 1분 남짓 서는 대기 표시이고 이름이 누구인지를 든다. 일곱 장은 그래픽 최소화(GAME_DESIGN §1)를 넘는다.
- **장식은 뿔 해골** — 후보 셋(뿔 해골 · 부러진 왕관 · 녹슨 사슬과 칼)을 같은 지시문으로 뽑았다. 챕터보스가 모두 악마 군주라 뿔 해골이 맞고, 좌우 대칭이라 초상 크기(약 100px)에서도 덩어리가 또렷하다. 사슬과 칼은 한쪽으로 치우쳐 빈 판이 가운데에서 밀려 보였다. 나머지 둘은 원본 폴더에 남긴다.
- **그림체는 보스 초상 · 신단 그림에 맞춘다** — 챕터보스 초상(`faces/gemini/monster/1900`)과 신단 그림(`shrines/wrath`)을 참조로 붙였다(굵은 외곽선 · 평면 색 + 그림자 한 단 · 채도 낮은 회색 돌).

## 파급

- CSS `.grave-plaque` — 그라디언트 · 테두리 · 둥근 모서리를 걷고 그림을 깐다 · 글자 자리 `.grave-face`(그림의 빈 앞면 사각) · `battle.js:gravePlaque` 가 이름 · 남은 시간을 그 안에 싼다
- 그림 · 발주 · 설치 — `src/assets/art/grave/`(README 「grave/」) · 지시문은 `grave/source/run_codex.py` · 앞면 자리는 `install.py` 가 잰다(그림을 바꾸면 CSS 의 글자 자리도 다시 잡는다)
- ⚠ 이름이 긴 보스는 빈 판 폭에서 두 줄로 접힌다(넘치면 줄임) — 관전 카드의 이름 줄 · 출정 창 칸의 이름 띠가 같은 이름을 든다
