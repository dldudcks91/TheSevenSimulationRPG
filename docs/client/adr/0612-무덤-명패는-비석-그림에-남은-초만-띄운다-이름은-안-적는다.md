## 결정

무덤 명패는 비석 그림과 **남은 초 하나**뿐이다. 초는 그림의 빈 앞면 한가운데에 `time.s` 글(「53초」 · 「53s」)로 선다. 보스 이름은 명패에 안 적는다 — 화면이 읽는 이름(`aria-label`)에만 남는다.

## 맥락

ADR-0611 은 같은 날 비석 그림의 빈 앞면에 이름(위)과 남은 시간 `m:ss`(아래)를 얹었다. 이름이 긴 보스(아스모데우스 · `Asmodeus`)는 판 폭에서 두 줄로 접혀, 글자 상자를 판 바깥 돌 테두리까지 넓히고 줄 간격 · 자간을 줄여야 겨우 들었다. 사용자는 비석 그림만 보이고 그 위에 초만 띄우라고 했다.

## 근거

- **이름은 바로 옆에 이미 있다** — 관전 카드는 오른쪽 열 이름 줄, 출정 창 적 칸은 칸 위 이름 띠가 같은 이름을 든다. 명패의 이름은 같은 칸 안의 두 번째 이름이었다.
- **명패가 말할 것은 「죽어 있다」와 「언제 돌아온다」 둘이다** — 앞은 그림이, 뒤는 초가 든다. 글자가 하나라 앞면 한가운데에 크게 서고 판을 가리지 않는다.
- **`m:ss` 대신 초** — 사용자 말 그대로다. 대기가 `[balance.csv:boss_respawn_sec]` 하나라 분 자리가 늘 0 이었고, 결과 띠의 세기 글(`bt.respawnWait` — 「보스 재등장까지 n초」)과 단위가 같아진다.

## 파급

- `battle.js:graveLeftText` → `time.s` · `gravePlaque` 가 이름 칸(`.grave-name`) · 글자 상자(`.grave-face`)를 걷는다 — 앱 시계(`app.js:respawnTick`) · 결과 띠의 세기는 같은 함수를 불러 그대로 간다
- CSS `.grave-left` — 앞면 한가운데 · 한 단 큰 굵은 글씨
- ⚠ 대기를 몇 분으로 늘리면 초가 세 자리가 된다(「125초」) — 그때 `time.ms` 로 갈지 다시 본다
