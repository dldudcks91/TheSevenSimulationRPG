# ADR-0632 — GPT 아트 선택은 초상과 스테이지 배경을 함께 바꾼다

| | |
|---|---|
| 상태 | 확정 · 2026-10-15 |
| 화면 | SCREEN_DESIGN §2-2 · §10 |
| 정한 사람 | 사용자 — 챕터 1~3 배경도 다시 만들고 몬스터처럼 GPT를 누르면 GPT 배경으로 바꾸도록 요청 |
| 관계 | ADR-0152의 스타일별 폴더·도트 비교 방식은 유지하고 선택 방법을 확장한다 |

## 결정

설정과 도감의 기존 `gemini / gpt` 버튼 하나로 영웅·몬스터 초상과 스테이지 배경을 함께 고른다. `gpt`는 `faces/gpt/`·`backgrounds/gpt/`, `gemini`는 `faces/gemini/`·기존 `backgrounds/illustrate/`를 읽는다. 기본값은 Gemini다.

GPT 배경은 챕터 1~3의 새 그림 15장과 앞서 생성한 챕터 4~5의 10장으로 총 25장이다. 기존 일러스트와 원본은 보존한다. 원본은 `backgrounds/source/gpt/`, 설치본은 `backgrounds/gpt/`이며 1376×615 WebP다. 아이콘·거점·로그인·탐험 지도는 이 선택의 대상이 아니다.

버튼은 두 선택값을 저장하고 전체 화면을 다시 그린다. `?face=gpt`·`?face=gemini`도 같은 묶음을 고르며, 이전에 저장된 GPT 초상 선택도 GPT 배경을 불러온다. 명시적인 `?bg=illustrate|gpt|pixel`은 처음 열 때의 비교용 재정의다. 저장된 도트 비교 선택은 유지하되, 아트 버튼을 누르면 선택한 묶음의 배경으로 바뀐다.

## 근거와 검증

초상과 배경에 별도 버튼을 추가하면 사용자가 같은 제작자의 아트를 보려 두 번 선택해야 한다. 기존 아트 선택 지점인 `mock.js:setFaceStyle`에서 배경도 바꾸면 설정·도감·URL이 같은 규칙을 쓴다. 전투 재생과 장소 목록은 기존 `stageBgOf` 경로를 그대로 사용한다.

검증은 격리된 브라우저에서 버튼 전환·새로고침·전투 배경·URL 우선순위를 확인하고, 활성 스테이지 25개에 GPT 파일이 모두 있는지 검사한다.
