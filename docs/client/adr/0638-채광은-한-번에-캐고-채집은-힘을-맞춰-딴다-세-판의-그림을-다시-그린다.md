## 결정

채광 「찰나의 광맥」은 4×3 지점에 잠깐 뜨는 일반·희귀 광맥을 한 번 누르면 캔다. 등장 간격과 노출 시간이 판 후반에 짧아진다. 위험 바위나 빈 지점을 누르면 즉시 끝나며 이미 캔 재료는 받는다. 놓친 광맥은 콤보만 끊는다.

채집 「약초의 숨결」은 한 포기씩 살펴본다. 약초를 누르고 있으면 당기는 힘이 오르고, 초록 구간에서 놓으면 수확한다. 가운데 밝은 구간은 기본 수확량 +1 뒤 콤보 배수를 적용한다. 너무 일찍·늦게 놓거나 독초를 건드리면 목숨 하나를 잃는다. 독초는 기다려 넘긴다. 마우스·터치와 스페이스/Enter 입력이 같은 판정을 쓴다.

벌목 「숲의 박자」는 가지를 피해 좌우에서 베는 규칙을 유지하고 나무·가지·나무꾼과 조작 버튼을 다시 그린다. 세 판은 새 광산·약초 정원·노을 숲 배경과 같은 색 체계의 HUD·시작·결과 화면을 쓴다. 준비 시간은 판 시간에서 뺀다.

## 근거와 파급

- 채광은 반응 속도와 대상을 가리는 판단, 채집은 누르고 놓는 힘 조절, 벌목은 좌우 박자를 각각 맡는다.
- 원본 미니게임 그림은 제거한다. 배경은 `assets/art/minigames/`, 새 벡터 오브젝트는 `ui/minigame_art.js`가 소유한다. 실제 재료 아이콘은 수확량·단계 표시에 사용한다.
- 채광·채집 길이는 현재 30초다. 수치·성공 구간은 `balance.csv`에 둔다. 최종 경제 밸런스 수치는 조정 대상이다.
- 영웅과 독립적인 직접 수확·무제한 재도전·점수 내림 보상·판 번호 재현·한 번만 수령하는 기존 계약은 유지한다.
- 숨긴 탭에서는 시계를 멈추고 누르는 상태를 취소한다. ×·바깥·Esc로 나가면 완료된 수확을 받는다.
