## 결정

메인 왼쪽 위(안쪽 여백 자리)에 **[뒤로가기]** 를 둔다 — 왼쪽 화살표 아이콘 + 글, 상자 없는 글 버튼이고 올리면 상자가 비친다. 누르면 메뉴([ADR-0641](0641-켜면-메뉴가-선다-새-게임-위-불러오기-아래-저장-칸은-하나다.md))로 간다. 제목 「첫 파티」는 걷는다 — 화면 이름은 상단바 crumb(「새 게임」)이 든다. 카드 줄은 제목이 있던 때와 같은 높이에 선다.

## 맥락

ADR-0641 의 메뉴가 서면서 시작 파티 고르기에서 메뉴로 돌아가는 길이 필요해졌다. 첫 시험판은 아래 버튼 줄(굴림 수 · 다시 굴리기 · 시작)의 맨 왼쪽에 상자 버튼 [뒤로]를 두었다. 카드 줄 위에는 가운데 정렬 제목 「첫 파티」가 있었다.

## 근거

- **버튼 줄에서 뺐다** — 세이브가 있으면 같은 줄의 시작 버튼이 되돌릴 수 없는 [세이브를 지우고 이 셋으로 시작]이라 오클릭 자리였다. 왼쪽 위는 「뒤로」의 익숙한 자리다
- **상자 없는 글 버튼** — 되돌릴 수 있는 이동이라 결정 버튼(다시 굴리기 · 시작)과 무게를 가른다
- **제목을 걷고 카드를 끌어올린 판은 버렸다** — 아래가 140px 쯤 비었고 사용자가 원래 자리로 돌렸다

## 파급

- `app.js:renderStart` · `backIcon`(자물쇠 `lockIcon` 과 같은 인라인 그림 · 색은 글자색) · CSS `.ng-back` · `#app.pregame > .main { position: relative }` · `.ng-wrap` 위 여백(옛 여백 + 걷은 제목의 높이)
- i18n `ng.back` 신설 · `ng.title` 은 도움말 「새 게임」 절의 머리가 계속 쓴다
