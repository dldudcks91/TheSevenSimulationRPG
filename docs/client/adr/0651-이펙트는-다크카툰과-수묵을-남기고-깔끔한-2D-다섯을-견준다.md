# ADR-0651 — 이펙트는 다크 카툰·수묵을 남기고 깔끔한 2D 시안을 견준다

| | |
|---|---|
| **상태** | 확정 · 2026-10-17 |
| **화면** | [설정 · 관전 · 도감 이펙트](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 — 「스킬 이펙트 한 4~5가지 버전으로 다시」 · 「다크카툰 및 수묵 빼고 이미지 모두 삭제」 · 비슷한 2D와 도깨비처럼 깔끔한 스타일 |
| **대체** | ADR-0584·0594·0599의 비교 그림체 구성과 보관 이미지 정책 |

## 결정

다크 카툰과 수묵은 원본·설치본을 보존한다. 그 밖의 기존 스킬 이펙트 이미지는 설치본과 보관 시안·비교 이미지까지 삭제한다. 전투 배경·영웅·몬스터 초상은 이 삭제 범위에 포함하지 않는다.

깔끔한 2D 시안은 셀 애니메이션, 플랫 코믹, 클린 모바일, 도깨비불 2D, 클린 도트 방향으로 새로 생성한다. 각 방향은 `skill_art.js:SKILL_ART`가 현재 읽는 파일 전부를 갖춘다. 그림체 이름·순서는 `skill_art.js:ART_STYLES`가 기준이다. 코드 모양은 이미지가 없으므로 유지한다.

도감과 관전에서 같은 스킬을 비교할 때 위치·크기·움직임·재생 시간은 공통이다. 회복·강화는 얼굴 가운데를 비운다. 새 그림은 실제 투명 배경으로 생성하고, 원본 시트와 최종 프롬프트는 `fx_source/clean_20261017/`에 둔다.

기본 그림체는 ADR-0621의 다크 카툰을 유지한다. 없어진 그림체가 브라우저에 저장돼 있으면 기존 검증 규칙에 따라 기본값으로 연다.

## 근거

질감이 강한 시안보다 윤곽과 색 덩어리가 정돈된 방향에서 선택지를 찾으려는 요청이다. 기존 질감의 색만 바꾸지 않고 외곽선·명암·곡선·픽셀 처리의 차이를 비교한다. 언급된 게임은 카카오게임즈의 [도깨비의세계](https://dokkaebi.kakaogames.com/)로 해석했다. 이 게임의 2D 도트 감각은 참고 방향이며, 기존 그림을 게임에 복사하지 않는다.
