## 결정

클린 도트(`pixel2d`)·다크 카툰(`darktoon`)·수묵(`ink`)의 원본 그림·프롬프트·설치 그림을 보존한다. 그 외 스킬 이펙트의 설치 그림과 폐기 시안·생성 프롬프트·관련 보관 데이터를 삭제한다. 영웅·몬스터 초상, 스킬 아이콘과 배경은 이 삭제 범위에 포함하지 않는다.

새 그림체는 **종이 콜라주(`papercut`)·오일 파스텔(`pastel`)·금속박(`foil`)·리소 인쇄(`riso`)·클레이(`clay`)**다. 동일한 스킬의 주요 형태·방향·구도를 유지하면서 종이의 겹, 거친 왁스 획, 반사와 눌린 금속 면, 인쇄 망점, 둥근 점토의 부피로 표현 기법을 바꾼다. 색만 다른 버전이 아니다. 각 그림체는 현재 `SKILL_ART`가 읽는 88장을 모두 갖춘다.

선택 목록은 보존 셋과 새 다섯, 총 여덟 그림체다. 코드 모양은 비교 탭에서 걷는다. 그림이 없는 스킬의 기존 코드 조각 대체 연출은 유지한다. 기본값은 다크 카툰이며, 삭제된 그림체 환경설정은 기존 검증 규칙으로 기본값을 따른다.

도감과 관전은 같은 파일·크기·위치·동작·재생 시간을 사용한다. 새 그림은 내장 imagegen으로 투명 배경에 생성하고, 클린 도트 원본은 형태 대응 참조로 쓴다. 새 스타일의 첫 시트는 후속 시트의 재료 표현 참조다. 원본 15장·최종 프롬프트·대응표·비교표는 `src/assets/art/fx_source/material_20261017/`, 설치본은 `src/assets/art/fx/skills/<file>_<style>.webp`에 둔다.

## 검증

보존 파일의 SHA-256, 새 440장의 투명 알파·셀 경계·파일 대응, 한국어·영어 탭, 전체 재생과 설정 저장을 검사한다. 기록은 새 원본 폴더에 저장한다.
