# ADR-0657 — 피해 숫자는 한 단 더 크다

| | |
|---|---|
| **상태** | 확정 · 2026-10-18 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) 「아레나」 팝업 |
| **정한 사람** | 사용자 지시 「피격 데미지 폰트 크기를 더 키워보자」 |
| **대체** | [ADR-0407](0407-피해-숫자는-한-단-크다.md) 의 보통 크기(15px) |
| **대체됨** | — |

## 결정

관전 카드의 피해 숫자를 크기 토큰 한 단 더 키운다 — `--fs-md` 15 → **`--fs-lg` 18px**. 스킬 · 평타 · 치명이 같은 크기인 것([ADR-0471](0471-피해-숫자는-한-크기다-동시에-뜬-팝업은-위아래로-쌓인다.md))은 그대로다. 글자 팝업(빗나감 · 반격 · 처치 · 회복 · 레벨업)은 손대지 않는다.

## 맥락

그날 피해 숫자는 15px(ADR-0407)이었고, 관전 카드 초상(101px) 옆 검은 여백에서 떠올랐다(ADR-0470). 사용자가 더 크게를 요청했다.

## 근거

- **한 단 = 토큰 한 칸** — 크기 토큰의 다음 칸(`--fs-lg`)으로 올린다. 토큰 밖 임의 px 를 만들지 않는다. 그다음 칸(`--fs-xl` 24px)은 초상 높이의 4분의 1에 가까워 줄 넷이 쌓이면 얼굴 옆 여백을 넘친다
- **줄 간격(18px)은 그대로** — 숫자는 글자 높이의 약 0.7배라 18px 글씨도 18px 간격 줄에서 위아래가 안 겹친다 · 줄 넷(`POP_ROWS`)이 초상 높이 안에 그대로 든다
- **레벨업 글자와 같은 크기는 아니다** — 레벨업은 `--fs-md` 굵은 금색이라, 피해 숫자가 한 단 크게 되어도 색 · 굵기 · 자리(초상 위)로 갈린다

## 파급

- `style.css` — `.pop.dmg` 의 `font-size`
- ⚠ 회복 숫자 · 빗나감 글자는 `.pop` 기본(`--fs-sm` 13px)이라 피해 숫자와의 차이가 13 : 15 → 13 : 18 로 벌어졌다
