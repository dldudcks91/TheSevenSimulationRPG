## 결정

비교 상대가 있는 자리에 올리면 **처음부터 「이 아이템」 · VS · 착용품 카드 두 장**이 선다(교체될 자리가 비면 한 장 + 「착용 중 없음」). 「반지 n번 칸에 낀다」 · 「착용 중 없음」은 기본 상태의 줄이다. **착용 델타**(「{영웅} 착용 시」 블록 — ADR-0618 · ADR-0639)는 **Alt 를 누르는 동안만** 「이 아이템」 카드의 옵션 아래에 선다 — 기본 상태엔 자리도 안 잡는다. 바닥 각주는 「Alt 변화 · Shift 범위」. 두 장은 늘 같은 키(긴 쪽)이고, Alt 동안엔 「이 아이템」 카드의 아랫변만 델타만큼 내려간다. **Alt 로 툴팁은 안 움직인다** — 아래 넘침 보정이 처음부터 Alt 때의 키까지 잰다(Alt 때 모양의 「이 아이템」 카드를 숨은 사본 `.tip-ghost` 로 툴팁 줄 밖에 세워 둔다).

## 맥락

그날 가방 칸 툴팁은 기본 「이 아이템」 한 장 + 옵션 아래 착용 델타였고(ADR-0618 — 「기본 상태에도 선다」), Alt 동안 착용품 카드가 VS 를 사이에 두고 붙었다(ADR-0448). 착용품 카드는 기본 상태에도 보이지 않게 자리만 잡았다(ADR-0450). 사용자가 둘을 맞바꾸라고 지시했다 — 기본은 착용품과의 비교, Alt 는 변화량.

## 근거

- **Alt = 더 보기 문법은 그대로다**(ADR-0448 근거 1) — 무엇이 기본이고 무엇이 「더」인지만 바뀐다. 두 장 대조가 기본이라는 것은 사용자 판단이다. ADR-0618 의 「가장 중요한 답이 키 뒤로 숨는다」는 이 결정이 받아들인 대가다
- **델타는 기본 상태에 자리를 안 잡는다** — 자리만 잡으면 옵션과 각주 사이가 빈다. 보이는 상자 안의 빈 칸은 고장으로 읽힌다(ADR-0465 · ADR-0482 와 같은 판단)
- **대신 넘침 보정이 Alt 때 키를 미리 잰다** — 가방은 화면 아래쪽이라 툴팁이 거의 늘 아래 넘침 보정(`tip.js:moveTip`)을 받는다. 안 재면 Alt 순간 툴팁이 델타 키만큼 위로 뛴다. ADR-0450 의 「Alt 로 읽던 카드가 안 움직인다」는 이렇게 산다
- **사본은 툴팁 줄에 안 낀다**(`position: absolute`) — 줄에 끼면 두 장이 사본 키로 늘어 기본 상태에 바닥이 빈다
- 버린 안: **델타를 기본 상태에 `visibility: hidden` 으로 자리만** — 위 빈 칸 · **Alt 동안 델타를 셋째 카드로** — 폭이 세 장이 돼 접힘이 바뀌고 카드가 커서 반대쪽으로 뛴다(ADR-0450 의 맥락) · **넘침 보정을 안 고치고 위로 뛰게 둔다** — ADR-0450 의 사용자 지시 「지금처럼 바뀌면 곤란해」와 부딪힌다

## 파급

- i18n `tip.item.altHint`(Alt 비교 → **Alt 변화** / Alt: changes) · `tip.item.keysHint`(Alt 변화 · Shift 범위)
- `app.js:bindTip` — 두 장 · VS 를 기본으로 짓는다 · `altHints` → `compareHints`(기본 줄) · 델타는 `isAltHeld()` 일 때만 · 델타가 서는 자리만 `data-alt` 와 `.tip-ghost`
- `tip.js:moveTip` — 아래 넘침 보정의 키 = 툴팁 · `.tip-ghost` 중 큰 쪽
- `style.css` — `.alt-only` 세 규칙(숨김 · 줄 숨김 · 위쪽 정렬)을 걷었다 · `.tip-ghost`
- ⚠ 기본 상태 폭이 두 장(304px × 2 + 틈)이라 가방을 훑을 때 툴팁이 크다 — ADR-0448 이 풀려던 맥락이 돌아왔다
- ⚠ 손가락 버튼 줄은 툴팁의 실제 아래에 매달려, [세부]로 델타가 서면 그만큼 내려간다
- 도움말 `eq.inv.note`(「착용 중인 장비와 나란히 비교」)는 이 결정과 맞는다 — 고칠 것 없음
