## 결정

원정 세 화면에 가는 길을 화면마다 하나로 둔다.

- **스테이지 = 원정 탭 버튼** — 누르면 언제나 스테이지 목록이 선다. 관전 · 리포트를 보고 있었어도, 이미 원정 탭이어도 같다
- **관전 = 상단바의 부대 칸**(`Party I` …) — 모든 탭에 선다(ADR-0353 그대로)
- **리포트 = 스테이지 화면 오른쪽 위의 [Report]** — 난이도 탭 줄의 오른쪽 끝 · 끝난 리포트가 있을 때만 활성이고 없으면 꺼진 채 자리를 잡는다

상단바의 `Stages` · `Report` 칸은 걷는다.

## 맥락

그날 상단바의 원정 세그먼트는 `Stages` · `Party I` … · `Report` 였고 모든 탭에 섰다(ADR-0353). 원정 탭 버튼은 마지막에 보던 원정 화면을 다시 열었다 — 관전을 보다 다른 탭에 갔다 돌아오면 관전이, 리포트를 보다 오면 리포트가 섰다(ADR-0140). 그래서 원정 탭 버튼과 `Stages` 칸이 같은 자리로 가는 두 길이었고, 탭 버튼은 누를 때마다 다른 화면을 열었다. 같은 날 탐험이 원정 바로 아래로 왔다(ADR-0660).

## 근거

- **탭 버튼이 무엇을 여는지가 늘 같다** — 탭 버튼을 눌렀는데 지난번 화면이 서면 「스테이지로 가려면 무엇을 누르나」가 한 번 더 남는다. 원정 탭의 첫 화면은 「어디를 갈지 먼저」(§4-1)의 스테이지 목록이다
- **같은 곳으로 가는 길 둘은 하나를 걷는다** — 탭 버튼이 스테이지를 열면 `Stages` 칸은 같은 일을 하는 둘째 버튼이다
- **리포트는 스테이지 화면에서 연다** — 사용자 지시. 리포트는 끝난 원정의 확인이라(§4-3) 원정 탭 안의 자리면 된다
- ⚠ **잃는 것 — 다른 탭에서 「끝난 리포트가 있다」가 안 보인다.** ADR-0353 의 「다른 거 하다가도 알 수 있게」 중 리포트 칸의 몫이다. 부대 칸의 색(부대 상태)은 그대로 모든 탭에 선다. 다시 필요해지면 탭 할 일 점(§1 · ADR-0637)의 원정 줄로 여는 것이 먼저다
- **버린 안 — 리포트를 상단바 오른쪽 끝으로 옮긴다** — 상단바 오른쪽은 자원 · 언어 · 시간 · ⚙ 자리이고, 사용자는 「스테이지 누르면 오른쪽 위」로 스테이지 화면을 짚었다
