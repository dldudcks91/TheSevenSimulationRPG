## 결정

「착용 중」 머리글은 **죄종 칩(`.sin-chip`)과 같은 결의 테두리 칩**이다 — 1px 테두리(글자색) · 모서리 2px · 바탕 없음 · 글씨는 가장 밝은 색(`--text-primary`) 굵게. 「이 아이템」은 그대로 흐린 맨글자다. 테두리는 안쪽 그림자(`inset`)로 그려 머리글 줄 높이가 「이 아이템」과 같다.

## 맥락

ADR-0659 로 같은 날 「착용 중」이 밝은 바탕 · 어두운 굵은 글씨의 배지가 됐다. 화면의 다른 칩(죄종 칩 · 희귀도 배지 · 옵션 줄의 `[고정]` · `[랜덤]` 출처 태그)은 모두 테두리만 있고 바탕이 비어 있었다. 사용자가 그 배지가 UI 와 어울리는지 물었다.

## 근거

- **칩의 문법은 테두리다** — 바탕이 꽉 찬 밝은 덩어리는 화면 어디에도 없어 그 배지만 다른 UI 의 것처럼 읽혔다
- **표지가 내용보다 밝으면 안 된다** — 반전 배지는 툴팁에서 가장 밝은 면이라 아이템 이름(희귀도 색) · 데미지 값보다 먼저 눈에 걸렸다. 테두리 칩은 「이 아이템」(흐린 맨글자)과는 확실히 갈리고 이름 · 값보다는 낮다
- **테두리를 `border` 가 아니라 안쪽 그림자로 긋는다** — 머리글 줄은 flex 라 칸에 테두리를 주면 착용품 카드만 2px 높아져 두 장의 이름 · 메인 옵션 줄이 어긋난다
- 버린 안: **옅은 바탕(흰 8%)을 더한 칩** — 테두리 칩만으로 갈려 필요 없다. 약하다는 판단이 서면 그때 더한다

## 파급

- `style.css` `.tip-card .tip-head .tip-worn` — 바탕을 걷고 안쪽 그림자 테두리 · `--text-primary`
- `app.js:tipCard` 는 그대로(머리글이 「착용 중」이면 `tip-worn`)
