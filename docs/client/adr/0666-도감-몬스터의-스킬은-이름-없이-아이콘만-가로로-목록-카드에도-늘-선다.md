# ADR-0666 — 도감 몬스터의 스킬은 이름 없이 아이콘만 가로로 — 목록 카드에도 늘 선다

## 결정

도감 몬스터의 스킬은 **그림만 가로 한 줄**로 선다 — 이름을 적지 않는다. 내용은 그 몬스터의 정해진 칸(고유 → 나이트메어 2칸)이고, 나이트메어부터 서는 칸은 **아이콘 오른쪽 위 모서리 표시**로 가른다. 같은 줄이 두 자리에 선다: ① **목록의 몬스터 카드** — 이름 줄 오른쪽 끝에 **늘** 선다(올리지 않아도 보인다 · 이름은 남는 폭에서 말줄임) · 아이콘에 올리면 이름(· 여는 단) ② **몬스터 툴팁 왼쪽 장** — 무기군 줄 아래의 「그림 + 이름」 줄들을 대신한다. 칸과 여는 단은 `battle.monsterSkillSlots` 를 단마다 물어 얻는다.

## 맥락

같은 날 몬스터가 나이트메어에서 2칸을 들게 되어(ADR-0664 · DEV_PLAN R269) 툴팁 왼쪽 장이 「고유 그림 + 이름」 아래 「2칸 그림 + 이름 + 단 이름」 줄을 하나 더 얹었다. 카드가 길어졌고, 도감 목록에서는 몬스터가 무슨 스킬을 쓰는지가 **카드에 올려야만** 보였다 — 장소마다 셋 · 넷이 늘어선 목록을 훑으며 「어느 몬스터가 이 스킬을 드나」를 찾으려면 카드마다 올려 봐야 했다.

## 근거

- **그림이 이미 이름을 대신한다** — 스킬 그림은 출정 창 칸 줄 · 관전 쿨 칸 · 도감 스킬 탭에서 같은 그림으로 읽힌다. 이름을 빼면 줄 하나에 칸 여럿이 서고 카드가 짧아진다. 이름이 필요한 사람은 아이콘에 올리면 된다(목록 카드) — 툴팁 안에서는 올릴 수 없지만 왼쪽 장 옆의 획득처 · 스킬 탭이 같은 그림을 이름과 함께 든다.
- **목록 카드의 이름 줄 오른쪽이 비어 있었다** — 직업은 윗줄 오른쪽(ADR-0615) · 추가옵션은 핍 줄 오른쪽(ADR-0588)이고 이름 줄만 오른쪽이 비었다. 카드 높이(= 초상 지름)를 안 늘리고 들어간다.
- **나이트메어 칸은 글자 대신 모서리** — 이름을 뺀 줄에 단 이름 글자를 남기면 좁은 카드에서 끊긴다(그날 툴팁에서 「나이트메\n어」로 끊겼다). 모서리 표시는 칸 크기를 안 바꾸고, 고유와 2칸을 섞어 「노말에서도 쓴다」로 읽히는 것을 막는다(통제성 — ADR-0664 와 같은 이유).
- **칸 규칙은 로직이 답한다** — 화면이 `monster.csv` 의 두 칸을 직접 읽고 「2칸은 몇 번째 단부터」를 계산하면 규칙의 사본이 된다. 단마다 `monsterSkillSlots` 를 물어 처음 선 단을 붙인다 — 헬 셋째 칸이 서면 그대로 따라온다.
- 버린 안 — **아이콘마다 스킬 카드 툴팁**: 카드 전체가 이미 몬스터 툴팁을 거는 자리라(ADR-0206) 안쪽에 툴팁을 하나 더 걸면 두 툴팁이 겹친다 — 아이콘은 이름 한 줄(`title`)만 든다. **보스의 판마다 굴리는 칸(「?」)도 카드에**: 도감은 몬스터를 소개하는 자리이고 굴림 칸은 그 몬스터의 스킬이 아니다 — 출정 창(ADR-0664)과 스킬 탭 획득처가 든다.

## 파급

- `tip.js` 새 `monsterSkillIcons`(목록 카드 · 툴팁이 같이 부른다) · `codexCandCard` 의 스킬 줄 · `app.js:monsterCard` 의 이름 줄
- CSS `.mon-name-row` · `.mon-sk` · `.sk-ico.late` (모서리 표시) · ADR-0664 가 더한 `.cx-cand .ng-skill .sk-diff` 는 걷는다
- i18n 키는 새로 안 든다 — 이름 · 단 이름은 데이터
- ⚠ 툴팁 안의 아이콘은 이름을 못 보인다(올릴 수 없다) — 이름이 필요하면 목록 카드의 아이콘 · 스킬 탭
