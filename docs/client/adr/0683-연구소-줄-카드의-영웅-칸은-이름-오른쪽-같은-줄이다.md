# ADR-0683 — 연구소 줄 카드의 영웅 칸은 이름 오른쪽 같은 줄이다

| | |
|---|---|
| **상태** | 확정 · 2026-10-21 |
| **화면** | [SCREEN_DESIGN §8](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「영웅 +넣는거를 아래가 아니라 오른쪽으로 넘겨도되잖아」 |
| **대체** | ADR-0681 의 「줄 카드 아래 = 영웅 칸」 |
| **대체됨** | — |

## 결정

줄 카드가 **한 줄**이 된다 — 왼쪽부터 줄 그림 · 줄 이름(찾아온 영웅은 이름 뒤 `Lv n` / 「닫힘」) · 그리고 카드 오른쪽 끝에 **영웅 칸**(등록한 영웅의 작은 얼굴 + 빈 칸 `+`)이 붙는다. 얼굴이 많아 자리가 모자라면 이름이 먼저 말줄임되고, 그래도 넘치면 영웅 칸이 오른쪽에서 줄을 바꾼다. 누르는 동작(얼굴 · `+` = 그 줄의 등록 창 · 나머지 = 그 줄 고르기)은 그대로다.

## 맥락

같은 날 줄 카드는 위에 줄 그림 · 이름, 아래에 영웅 칸이 서는 두 줄 상자였다(ADR-0681). 행이 일곱 줄 높이로 줄며(ADR-0682) 카드도 두 줄을 겨우 담았다. 사용자가 영웅 칸을 아래가 아니라 오른쪽으로 두라고 지시했다.

## 근거

- **카드 폭이 남는다** — 줄 이름은 짧고(채광 · Mining) 카드 열은 210px 이상이라 이름 오른쪽이 비어 있었다. 한 줄이면 카드 높이가 행의 절반 안쪽이라 일곱 줄 높이에서도 여유가 있다
- **얼굴이 이름보다 먼저 지켜진다** — 등록한 영웅은 숨기면 안 되는 값이고 이름은 줄 그림 · 행 자리가 같이 말한다 — 그래서 좁으면 이름이 먼저 줄어든다(§5 띠 위칸의 「하는 일이 먼저 줄어든다」와 같은 생각)

## 파급

- `app.js:dpTreeLine` — 영웅 칸(`dpRegRow`)을 카드 머리 줄 안에 붙인다
- CSS — `.dp-card` 한 줄 · `.dp-card-n` 이 줄어드는 쪽 · `.dp-reg-row` 오른쪽 끝 정렬
