# ADR-0686 — 게임 화면의 상단바엔 탭 이름이 없다 · 부대 칸이 왼쪽 끝에 붙는다

## 결정

게임 화면(탭 내비가 서는 화면)에서는 상단바 왼쪽의 현재 위치(crumb — 고른 탭 이름)를 **세우지 않는다.** 그 자리를 비워 두지 않고, 원정 부대 칸이 **상단바 왼쪽 끝**으로 붙는다. 게임 밖 화면(메뉴 · 시작 파티 고르기 · 프롤로그)의 crumb 은 그대로다 — 「새 게임」 · 「프롤로그」 · 메뉴는 빈칸.

## 맥락

crumb 은 고른 탭 이름을 흰 글씨 · 굵게 세웠고(2026-09-21), 부대 칸이 모든 탭에 서면서 탭을 옮겨도 부대 칸이 안 움직이게 가장 긴 탭 이름만큼 폭을 늘 잡았다(ADR-0353). 지금 탭은 왼쪽 탭 내비의 고른 칸(강조색)이 이미 들고 있었다 — 같은 이름이 화면에 두 번 섰다.

게임 밖 화면에는 탭 내비가 없다. 시작 파티 고르기는 제목을 걷으면서 화면 이름을 crumb 「새 게임」에 맡겼다(ADR-0643).

## 근거

- **같은 정보가 두 번 선다** — 탭 내비의 고른 칸이 지금 탭을 말한다. crumb 은 그 이름을 한 번 더 적을 뿐이다
- **빈자리를 안 남긴다**(사용자 선택) — 글자만 지우고 폭을 그대로 두면 상단바 왼쪽에 이유 없는 빈칸이 선다. 글자가 없으면 탭을 옮겨도 밀 것이 없어 ADR-0353 의 「폭 고정」 근거도 함께 사라진다 — 부대 칸은 어느 탭에서나 왼쪽 끝 한 자리다
- **게임 밖 화면은 그대로**(사용자 선택) — 그 화면들엔 탭 내비가 없어 화면 이름을 대신 들 곳이 없고, 시작 파티 고르기는 제목을 이미 crumb 에 넘겼다(ADR-0643)

**버린 안**

1. **글자만 지우고 자리는 비워 둔다** — 사용자가 「왼쪽으로 붙여」를 골랐다
2. **게임 밖 화면 이름도 지운다** — 사용자가 「내버려둬」를 골랐다 · 시작 파티 고르기가 이름을 잃는다

## 파급

- `app.js:renderShell` — 게임 화면이면 crumb 을 비운다 · 게임 밖은 그대로
- `style.css` — 빈 crumb 은 자리를 안 잡는다(`.crumb:empty`) · 탭 이름을 겹쳐 두던 규칙(`.crumb > span` · `.ghost`) 삭제 · 자원 줄은 앞의 칸이 다 비어도 오른쪽 끝에 남는다(`margin-left: auto` — 메뉴 화면)
- **i18n · 세이브 · 게임 로직 · 단정 무변동** — `nav.*` 는 탭 내비가 그대로 쓴다
- ⚠ 패널 안 제목 줄을 걷으며 「탭 이름은 crumb 이 든다」를 근거로 삼은 탭(제련소 ADR-0190 · 도감 ADR-0174)은 이제 탭 이름을 탭 내비의 고른 칸에서만 읽는다
