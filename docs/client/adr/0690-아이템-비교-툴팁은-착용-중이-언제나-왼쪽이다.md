# ADR-0690 — 아이템 비교 툴팁은 「착용 중」이 언제나 왼쪽이다

| | |
|---|---|
| **상태** | 확정 · 2026-10-21 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 「비교 툴팁 규격」 — 「두 장의 자리」 |
| **정한 사람** | 사용자 지시 — 「장비 UI에서 인벤토리에 있는 아이템은 착용중이 무조건 왼쪽으로 나오도록 통일해봐」 |
| **대체** | [ADR-0337](0337-아이템-비교-툴팁은-이-아이템이-커서-쪽이고-두-장-사이에-VS-가-선다.md) 의 **두 장의 좌우**(「이 아이템」이 커서 쪽 · 접히면 순서가 뒤집힌다) — 따로 선 두 상자 · 사이의 `VS` 는 산다 |
| **대체됨** | — |

## 결정

비교 두 장은 툴팁이 커서 오른쪽에 서든 화면 끝에서 커서 왼쪽으로 접히든 **언제나 `착용 중 | VS | 이 아이템`** 이다. 비교 툴팁을 쓰는 자리(가방 · 창고 · 관전 보관 칸 · 제련소 아이템창 · 상점 상단 장비 칸)가 한 규칙을 쓴다. 손가락 버튼 줄은 「이 아이템」 카드 아래 — 언제나 오른쪽 끝이다.

## 맥락

그날까지 두 장은 ADR-0337 대로 「이 아이템」이 커서 쪽이었다 — 툴팁이 커서 오른쪽이면 `이 아이템 | VS | 착용 중`, 접히면 `착용 중 | VS | 이 아이템`(`tip.js:moveTip` 의 `at-left` 를 CSS 가 보고 줄 순서를 뒤집었다). 같은 가방 안에서도 칸이 화면 오른쪽에 가까우냐에 따라 착용품 카드가 왼쪽에도 오른쪽에도 섰다.

## 근거

- **자리가 고정돼야 눈이 먼저 간다**(사용자 「통일」) — 착용품이 늘 같은 쪽이면 머리글을 읽기 전에 어느 카드가 무엇인지 안다. ADR-0337 은 「무엇이 착용 중인지는 머리글이 든다」로 좌우 고정을 버렸는데, 그 머리글을 매번 읽게 하는 비용이 남았다
- **왼쪽 = 지금 가진 것 · 오른쪽 = 바꿀 후보** — 왼쪽에서 오른쪽으로 읽는 순서가 「지금 → 바꾼 뒤」와 같다. 착용 델타의 `지금 → 낀 뒤` 화살표(ADR-0618)와 같은 방향이다
- **커서와의 거리는 감수한다** — 툴팁이 커서 오른쪽에 서면 「이 아이템」 카드가 커서에서 한 장 떨어진다. ADR-0337 이 지키던 「시선은 커서에 있다」를 이 결정이 내려놓는다(사용자 판단)

**버린 안**

1. **ADR-0337 그대로(커서 쪽이 「이 아이템」)** — 칸 위치에 따라 좌우가 바뀌어 통일이 안 된다(사용자)
2. **가방만 고정 · 다른 비교 자리는 그대로** — 같은 툴팁이 자리마다 좌우가 달라진다. §6 「비교 상대가 있는 자리 전부 같다」와 부딪힌다

## 파급

- `app.js:bindTip` 이 `[착용 중, VS, 이 아이템]` 순서로 짓는다 · CSS 의 접힘 뒤집기(`.tooltip.at-left … row-reverse`) 걷음 · 손가락 버튼 줄은 접힘과 무관하게 오른쪽 끝 · `tip.js:moveTip` 의 `at-left` 표시는 읽는 곳이 없어져 걷었다
- 숨은 사본(`.tip-ghost` — Alt 때 키 재기)은 줄 밖이라 순서와 무관하다 · 착용 중 없음(한 장)은 그대로
- i18n · 세이브 · 단정 무변동
