# ADR-0693 — 인벤토리 칸의 툴팁은 커서 왼쪽에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-10-21 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 「비교 툴팁 규격」 — 「툴팁이 서는 쪽」 |
| **정한 사람** | 사용자 지시 — 「마우스가 중간보다 왼쪽으로 가면 hover UI가 오른쪽으로 나와 이것도 왼쪽으로 보내야해」 |
| **대체** | — *(툴팁은 커서 오른쪽 · 넘치면 왼쪽으로 접는다는 기본은 그대로 · 인벤토리 칸만 먼저 쪽이 왼쪽이다)* |
| **대체됨** | — |

## 결정

인벤토리(가방) 칸에 올린 툴팁은 **커서 왼쪽이 먼저**다 — 커서 왼쪽에 다 안 들어갈 때만 오른쪽으로 접는다. 다른 칸(창고 · 페이퍼돌 · 상점 · 관전 등)은 그대로 커서 오른쪽이 먼저고, 넘치면 왼쪽으로 접는다.

## 맥락

같은 날 ADR-0690 이 비교 두 장의 좌우를 `착용 중 | VS | 이 아이템` 으로 고정했다. 툴팁 자체가 서는 쪽은 그대로 「커서 오른쪽 · 한 장 밖으로 넘치면 커서 왼쪽」(`tip.js:moveTip`)이었다. 인벤토리는 캐릭터 탭 오른쪽 절반에 있어, 같은 인벤토리 안에서도 왼쪽 열에 올리면 툴팁이 커서 오른쪽(인벤토리 위)에, 오른쪽 열에 올리면 커서 왼쪽에 섰다.

## 근거

- **한 칸 안에서 툴팁의 쪽이 갈리지 않는다**(사용자) — 같은 인벤토리에서 칸마다 툴팁이 다른 쪽으로 튀면 읽기 시작점이 흔들린다. ADR-0690 의 「통일」과 같은 이유다
- **인벤토리는 화면 오른쪽 절반이다** — 커서 왼쪽에는 비교 두 장이 늘 들어갈 자리가 있다. 툴팁이 인벤토리를 덮지 않고 세부 옵션 쪽에 선다
- **기본은 안 바꾼다** — 창고는 화면 왼쪽 절반이라 커서 오른쪽이 늘 들어간다(이미 한쪽으로 고정이다). 모든 툴팁을 왼쪽 먼저로 바꾸면 화면 왼쪽 칸들이 반대로 갈린다

**버린 안**

1. **모든 툴팁을 커서 왼쪽 먼저** — 화면 왼쪽 절반의 칸(창고 · 페이퍼돌 · 영웅 띠)에서 접힘이 생겨 같은 문제가 그쪽으로 옮겨 간다
2. **칸의 자리로 정한다(화면 가운데보다 오른쪽이면 왼쪽)** — 칸마다 다시 갈릴 수 있고, 사용자가 짚은 것은 인벤토리다

## 파급

- `tip.js:bindTipNode` 에 `side`(`'left'` 면 커서 왼쪽이 먼저)를 더했다 · `openTip` 이 노드의 쪽을 기억하고 `moveTip` 이 그 쪽부터 놓는다 · `app.js:bindTip` 이 그대로 넘기고 `storagePanel` 의 인벤토리 칸만 `'left'` 를 준다
- 같은 보관 줄(`itemsPanel` — 창고 | 인벤토리)을 쓰는 화면(관전 아래 가방 · 제련소 아이템창 · 상점 아이템창)의 인벤토리 칸도 같이 왼쪽이다
- i18n · 세이브 · 단정 무변동
