# ADR-0696 — 연구소 트리 노드는 그림 하나다 · 아래 글을 걷고 레벨은 오른쪽 아래 · 줄 카드는 행을 채운다

## 결정

연구소 트리의 지점 노드는 **지점 그림 원 하나**다. 원 아래 글(지금 값 · 잠긴 노드의 「n랭크」 · 「닫힘」)을 걷는다. 레벨은 원 위 `Lv n/최대` 대신 **원 오른쪽 아래 `Lv.n`** — 스킬 · 아이템 칸의 레벨 배지(ADR-0576 · ADR-0168)와 같은 글 · 같은 모양이고 레벨 1 이상일 때만 선다. 연구 중인 노드는 주황 테두리 + 원 아래 진행 막대 그대로다. 지금 값 · 무엇이 여는지는 노드 `title` 과 고른 지점이 든다. **지점 원은 34 → 44** 로 키운다(그림은 원을 따라 커진다). **줄 카드는 행 높이에서 위아래 6 씩만 뺀 높이다** — 행 간격(격자의 1/7 · ADR-0682)은 그대로다.

## 맥락

그날 노드는 위 `Lv 3 / 10` · 원 · 아래 값(`×1.3` · `1단계` · `+6%`)의 세 층이었고, 잠긴 노드는 아래에 「7랭크」 · 「닫힘」을 적었다(ADR-0684). 줄 카드는 한 줄 높이(그림 26 · 영웅 칸 24)라 행(일곱 줄 몫 · 1600×800 에서 70px 남짓) 안에서 가는 띠로 떠 있었다. 사용자 지시 — 「아이콘아래에 있는 글씨 삭제」 · 「채광, 채집, 벌목등 각 집단의 높이 상승」 · 「레벨 표시도 다른것들 처럼 아이콘의 오른쪽아래에 나오도록」. 카드가 행을 꽉 채운 판(72px)을 본 뒤 같은 날 「네모박스 약간씩만 줄이고 아이콘 크기를 좀 더 키워봐」. 같은 날 고른 지점에 레벨 목록이 섰다(ADR-0694) — 레벨마다의 값 · 최대 레벨은 그쪽이 든다.

## 근거

- **레벨 배지 = 다른 칸과 같은 글 · 같은 자리** — 스킬 그림 · 아이템 칸이 이미 「그림 오른쪽 아래 `Lv.n`」이다. 같은 문법이면 연구소 노드를 따로 익힐 것이 없다. 레벨 0 은 배지가 없다 — 배우지 않은 스킬 칸과 같고, 「아직 안 올렸다」가 배지의 유무로 읽힌다. `/최대` 는 다른 배지에 없어 뺐다 — 고른 지점의 눈금 · 레벨 목록이 든다
- **값을 노드 아래에서 걷는다** — 사용자 지시. 값의 비교는 노드 `title` · 고른 지점(지금 → 올린 뒤 · 레벨 목록)이 든다 — ⚠ ADR-0678 · 0684 의 「트리 한 장에서 모든 지점의 지금 값을 비교한다」는 이 결정으로 레벨 비교만 남는다
- **원 44** — 노드가 그림 하나가 되어 그림이 읽혀야 한다(사용자 「아이콘 크기를 좀 더 키워봐」). 행(70px 남짓) 안에 원과 아래 막대가 함께 든다. 배지는 원 모서리에 걸쳐 원 밖으로 조금 나온다(원 안 오른쪽 아래에 두면 그림을 가린다)
- **카드는 행보다 조금 작다 · 행 간격은 그대로** — 「집단의 높이」를 올리되 일곱 줄 몫 행(ADR-0682 — 사용자 「연구 아이콘이 7개정도 들어갈 수 있도록」)을 지키면 카드만 키우면 된다. 행을 꽉 채운 판은 「약간씩만 줄이고」로 위아래 6 씩 뺐다. 행을 1/6 로 키우는 안은 일곱째 줄이 서는 날 다시 줄여야 해서 버렸다
