# ADR-0702 — 연구소 영웅 칸은 늘 최대 칸 수만큼 서고 안 열린 칸은 자물쇠다

## 결정

연구소 줄 카드의 영웅 칸과 고른 줄의 「등록 효과」 영웅 자리는 **늘 「등록 칸」 지점의 최대 칸 수만큼** 선다(그날 표에서 셋). 열린 칸은 등록한 영웅 얼굴 · 빈 칸 `+` 그대로이고, **아직 안 열린 칸은 자물쇠**(흐린 점선 칸 + 자물쇠 그림 · `title` = 「등록 칸 Lv.n」 — 그 칸을 여는 지점 레벨)다. 자물쇠 칸을 누르면 그 줄의 「등록 칸」 지점이 고른 지점이 된다(비용 · 시간 · [연구]가 바로 보인다). 줄 카드의 영웅 얼굴은 24 → 44(카드 높이 안 끝)로 키우고, 카드 열은 그만큼 넓힌다.

## 맥락

그날 영웅 칸은 「등록 칸」 지점의 지금 값만큼만 섰다 — 처음엔 한 칸이라 「등록 칸」 지점을 올리면 칸이 늘어난다는 것이 화면에 안 보였다(ADR-0684 · ADR-0700). 사용자 지시 — 「거기에 나오는 영웅 초상화 크기도 좀 크게하고 기본적으로 3칸 열고 자물쇠로 잠궈」. 칸 수의 끝은 `lab_node.csv` 의 「등록 칸」 지점 최대 레벨 값이고 그날 모든 줄에서 셋이었다.

## 근거

- **최대만큼 그리고 잠근다** — 마스터리 빈 프레임(§7) · 연구소 잠긴 노드(ADR-0684)와 같은 이유다 — 어디까지 열리는지가 보여야 한다. 자물쇠는 화면 전체가 「잠긴 자리」에 쓰는 표시다
- **칸 수는 표가 정한다** — 「3」은 코드에 없다. 「등록 칸」 지점의 레벨별 값(`labState` 의 `levels`)의 끝이 칸 수이고, 각 자물쇠 칸이 몇 레벨에 열리는지도 같은 목록에서 읽는다 — 표가 바뀌면 칸 수가 따라간다
- **자물쇠 칸 클릭 = 「등록 칸」 지점** — 잠긴 칸 앞에서 할 수 있는 일은 그 지점을 연구하는 것 하나다. 툴팁은 짧게(CLAUDE.md 규칙 7) 「등록 칸 Lv.n」 한 토막
- **얼굴 44 · 카드 열을 넓힌다** — 사용자 「좀 크게」 → 32 를 본 뒤 「더키워봐」 — 카드 높이(61) 안에서 가장 크게. 칸이 셋으로 고정되며 영웅 칸 폭이 늘 최대라 영어 이름(`Visiting Heroes` · `Gathering` + 단계 글자)이 말줄임 없이 들도록 카드 열을 격자 폭의 40% 로 넓혔다(ko/en 실측 — 지점 노드 다섯 칸은 그대로 든다)
