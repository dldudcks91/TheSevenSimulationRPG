# ADR-0718 — 레벨업 글자 아래에 적중 변화 줄을 두지 않는다

| | |
|---|---|

| **대체됨** | — |

## 결정

관전 영웅 카드에 레벨이 오를 때 「레벨 업」 글자 아래에 서던 작은 줄 **「적중 a% → b%」를 걷는다.** 레벨업은 「레벨 업」 글자 · 체력 막대가 가득 차는 것 · 로그 `▲ Lv.n` 만 든다. 레벨업을 카드가 그린 레벨과 대조해 잡는 방식 · 본 적 없는 레벨업의 `Lv.n` 반짝임(ADR-0440)은 그대로다.

## 맥락

ADR-0435 로 영웅 레벨이 그 라운드 적 가운데 가장 높은 레벨보다 낮으면 「레벨 업」 글자 아래에 `formula.hitChance` 로 잰 레벨업 전 · 뒤 적중률이 섰다(마법 무기 영웅 · 적중이 안 바뀌는 칸은 줄이 없었다). 관전을 보던 사용자가 그 줄을 안 뜨게 하라고 했다.

## 근거

- 사용자 지시다
- 레벨업의 순간은 글자 · 가득 차는 체력 막대 · 로그 한 줄이 이미 든다. 적중 변화는 그 순간에 덧붙인 계산 결과였다

## 파급

- i18n `pop.lvupHit` · CSS `.pop.lvup small` 삭제 · 재생기 `levelCheck` 가 적중을 재지 않는다(관전 화면이 `formula.hitChance` 를 안 부른다)
- 레벨 차가 명중에 주는 영향은 리포트의 「레벨 차 → 명중 −p%」(SCREEN_DESIGN §4-3)가 든다
