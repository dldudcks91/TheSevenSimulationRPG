## 결정

캐릭터 탭의 [자동 장착]을 장비 칸 제목 줄에서 빼서 **인벤토리 도구 줄의 [분해] 바로 왼쪽**에 둔다 — `인벤토리 [Party I][Party II][Party III] ─ [자동 장착] [분해] [자동 분해] [정렬]`. 하는 일은 그대로다 — 영웅 띠에서 고른 영웅에게 보고 있는 인벤토리의 장비를 `game.autoEquip` 으로 낀다. **캐릭터 탭에서만** 선다 — 상점 · 제련소 · 원정의 같은 인벤토리 도구 줄엔 안 선다. 분해함이 떠 있는 동안은 [자동 분해]처럼 안 선다. 장비 칸 제목은 다시 이름뿐이다([ADR-0041](0041-집계-줄-폐기-네-칸의-제목은-이름뿐이다.md)).

## 맥락

같은 날 ADR-0712 가 [자동 장착]을 장비 칸 제목 오른쪽 끝에 두었다. 사용자가 그 버튼을 못 찾았다(「아예 버튼이없음」 — 헤드리스로 재면 창 폭 1920 ~ 900 모두 그 자리에 보였다). 사용자가 자리를 인벤토리 도구 줄 [분해] 왼쪽으로 정했다.

## 근거

- **장비를 다루는 버튼이 모인 줄이다** — [분해] · [자동 분해] · [정렬]이 서는 줄이고, 사용자가 버튼을 찾은 곳이 거기였다
- **꺼내는 인벤토리가 같은 줄에서 읽힌다** — 부대 버튼(어느 인벤토리를 보나)과 [자동 장착](그 인벤토리에서 낀다)이 한 줄에 선다
- ⚠ **ADR-0712 가 이 자리를 버린 근거** — 「이 인벤토리의 것을 누구에게?」로 읽혀 대상 영웅이 흐리다 · 도구 줄이 영어에서 길어진다 — 를 사용자에게 알리고 사용자 판단을 따랐다. 대상은 같은 화면 영웅 띠의 고른 카드다
- **캐릭터 탭에서만** — 옮기는 것은 자리뿐이다. 상점 · 제련소 · 원정 화면의 인벤토리 도구 줄은 ADR-0712 때처럼 버튼이 없다
- **분해함이 떠 있는 동안 안 선다** — 그동안 칸 누르기는 함에 올리기이고 줄엔 [분해] 하나만 선다([ADR-0673](0673-분해는-화면-가운데-4x4-분해함에-올려서-한다-필터는-등급-레벨-고정-세-열이고-열끼리는-그리고다.md))

## 파급

- 문구는 그대로 — `ch.autoEq` · `ch.autoEq.done` · `ch.autoEq.none`
- CSS `.btn.sm.pd-auto`(제목 줄을 안 키우던 규칙)를 걷는다 — 도구 줄의 다른 버튼과 같은 `btn sm`
- 장비 칸 제목은 이름뿐 — ADR-0041 의 「네 칸의 제목은 이름뿐」이 장비 칸에서 다시 선다
