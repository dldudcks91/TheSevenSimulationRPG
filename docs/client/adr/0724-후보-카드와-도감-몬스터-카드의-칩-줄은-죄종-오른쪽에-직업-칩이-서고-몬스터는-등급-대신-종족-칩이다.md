# ADR-0724 — 후보 카드와 도감 몬스터 카드의 칩 줄은 죄종 오른쪽에 직업 칩이 서고 몬스터는 등급 대신 종족 칩이다

## 결정

`.ng-card` 의 칩 줄(초상 옆 윗줄)이 **셋**이 된다 — 영웅 후보 카드(새 게임 · 선술집 · 찾아온 영웅)는 `등급 → 죄종 → 직업`, 도감 몬스터 툴팁 왼쪽 장은 `종족 → 죄종 → 직업`. 직업 칩은 죄종 칩과 같은 규격이고 글자 · 테두리가 **그 직업 색**(`class.csv:color`)이다. 직업이 칩 줄로 올라가 이름 아래 직업 줄은 영웅은 `Lv.n` 만 남고 몬스터는 걷힌다. 몬스터의 종족 칩은 `monster.csv:monster_type` 의 이름(`SYS.commission.races` — 관전 신원의 종족과 같은 말)이고, 글자 · 테두리는 **등급 색**(일반 / 정예 고르개 · 보스) 그대로다.

## 맥락

그날 칩 줄은 둘(영웅 = 등급 · 죄종 / 몬스터 = 등급 `일반` · `정예` · `보스` + 챕터 죄종)이었고 직업은 이름 아래 제 줄에 맨 글자로 섰다. 몬스터 카드의 등급 칩은 고르개(일반 / 정예)가 정한 초상 등급을 되읊을 뿐이라 그 몬스터에 대해 새로 말하는 것이 없었다. 같은 날 도감 보너스 효과의 Lv1 · Lv2 가 종족 단위로 개편됐지만(ADR-0715) 카드에는 종족이 안 보였다.

## 근거

- 직업을 칩으로 올리면 카드의 「무엇인가」(등급 · 죄종 · 직업)가 한 줄에 모이고 이름 줄은 「누구인가」만 든다 — 칩 줄 · 이름 줄을 가른 09-08 문법(§3 · 칩 줄 위 · 이름 아래)과 같은 방향이다
- 몬스터의 등급은 윗변 · 막대 색이 이미 든다 — 칩 글자가 같은 말을 되풀이하던 자리를 종족에 준다. 칩 색은 등급 색으로 남겨 정예 고르개를 누르면 칩도 노랗게 바뀐다
- 대안 — 관전 카드(§4-2)의 이름 줄에 직업을 붙이는 안은 안 골랐다: 관전 카드는 띠(신원)가 이미 `Lv.n · 직업 · 종족` 을 들고, 일반 몬스터는 죄종 칩이 없어 「죄종 오른쪽」이 성립하지 않는다
- 사용자가 「어떻게 보이나 보게」로 시험 삼아 요청했다 — 보고 되돌리면 이 ADR 을 새 ADR 이 대체한다

## 파급

- `app.js:candidateCard` 칩 줄 · `tip.js:codexCandCard` 칩 줄 · CSS `.cls-chip` 신설 · i18n 키 추가 없음(직업 · 종족 이름은 데이터)
- 새 게임 카드는 연장 칸(ADR-0675)에도 직업 칩이 있어 한 카드에 직업 칩이 두 번 선다
- ⚠ 「일반」이 종족 이름(`monster_type.csv:Normal`)과 등급 이름(`kind.normal`) 둘에 쓰인다 — 정예 고르개 「일반」을 누르면 언데드 카드도 칩은 「언데드」다
