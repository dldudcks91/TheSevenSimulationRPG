# ADR-0726 — 적이 쓰러질 땐 글자 팝업이 없다 — 쓰러짐은 카드가 보인다

## 결정

관전 카드에서 **적이 쓰러질 때 「처치」 글자 팝업을 띄우지 않는다.** 쓰러진 것은 카드가 보인다 — 붉은 막 · 가라앉음(피격 반응 · `fxDown`)과 한 박자 뒤의 흐려짐(`.unit.dead`). **전투 로그의 처치 줄은 그대로다**(격자 값 「처치」 · 문장 「{a} 처치」). 영웅이 쓰러질 때의 「전투 불능」 글자도 그대로다.

## 맥락

적이 쓰러질 때마다 그 카드의 초상 오른쪽 위에 「처치」 가 떴다(ADR-0470 의 글자 팝업 · ADR-0500 의 쓰러진 표시). 한 라운드에 몬스터가 여럿 쓰러지니 그만큼 떴다.

## 근거

- **쓰러짐은 글자 없이 읽힌다** — 붉은 막이 덮이고 카드가 가라앉은 뒤 흐려진다. 글자는 같은 사실을 한 번 더 말했다
- **로그 줄은 남긴다** — 사용자가 「로그 말고」 로 범위를 정했다. 로그는 지나간 일을 읽는 자리라 무엇이 언제 쓰러졌는지 한 줄이 든다
- **「전투 불능」 글자는 이 결정 밖이다** — 요청은 「처치」 한 단어였다

## 파급

- `battle.js` 의 `down` 이벤트 — 적이면 팝업을 안 부른다
- `i18n.js` 의 `pop.slain` 삭제 — 쓰는 곳이 없다
- SCREEN_DESIGN §4-2 — 쓰러진 표시에서 「처치」 를 빼고 팝업 줄에 한 마디
- ⚠ 결투장도 같다 — 같은 재생기라 상대 영웅이 쓰러질 때도 글자가 없다
- ⚠ 전투 화면 밖의 「처치」(리포트 기여 표 칸 · 도감 · 의뢰 종류 · 옵션 이름 「처치 시 체력 회복」)는 이 결정 밖이다
