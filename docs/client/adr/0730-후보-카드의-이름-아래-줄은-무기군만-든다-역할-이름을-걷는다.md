# ADR-0730 — 후보 카드의 이름 아래 줄은 무기군만 든다 · 역할 이름을 걷는다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §3](../SCREEN_DESIGN.md) · [§8-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「역할을 삭제하고 무기군만 넣자(어차피 이제 새게임 툴팁에 설명 나오잖아)」) |

| **대체됨** | — |

## 결정

영웅 후보 카드(`.ng-card` — 새 게임 · 선술집 명단 · 찾아온 영웅 카드)의 이름 아래 회색 줄이 **그 직업의 무기군만** 든다(「도끼 / 둔기」 · `Greatsword / Spear`). 역할 이름(「근접 물리」 · 「탱커 · 수호」)은 카드 머리에서 걷는다. 도감 몬스터 툴팁 왼쪽 장의 역할 줄(역할 + 그 몬스터의 무기군)은 그대로다.

## 맥락

그날 이 줄은 `역할 · 무기군`(`app.js:classLine`)이었고, 영어에서 다섯 직업 중 셋이 오른쪽 열 폭(보이는 폭 146px)을 넘어 두 줄로 접혔다 — 기사 `Tank · Guardian · Greatsword / Spear` 177px · 궁수 166px · 사제 161px. 높이는 초상 안에 들었지만(ADR-0160) 줄 끝이 카드마다 들쭉날쭉했다. 직업은 전날부터 칩 줄의 직업 칩이 들었고(ADR-0724), 새 게임 카드는 아래 연장 칸이 직업의 역할을 한 문장으로 들었다(ADR-0675).

## 근거

- 직업은 칩이, 하는 일은 새 게임 연장 칸 문장이 든다 — 역할 이름은 카드 안에서 세 번째로 같은 것을 말하는 자리였다
- 무기군만 남기면 가장 긴 줄이 `Greatsword / Spear` 94px 로 두 언어 모두 한 줄에 선다
- 대안 — 역할 / 무기군을 늘 두 줄로 나누는 안 · 영어 역할 이름(`class.csv:role_en`)을 줄이는 안 · 무기군을 빼는 안을 같이 냈고 사용자가 이 안을 골랐다. 선술집 카드엔 연장 칸이 없어 역할 이름이 화면에서 빠진다 — 사용자가 알고 골랐다

## 파급

- `app.js:candidateCard` 의 줄이 `classLine` 대신 무기군(`classWeapons`) — 직업이 없으면 `class.unassigned` · `classLine` 은 부르는 곳이 없어 지운다 · CSS 클래스 `.ng-role` 은 이름 그대로 둔다 · i18n 키 추가 없음
- SCREEN_DESIGN §3 연장 칸 규칙의 「역할 줄은 카드 머리가 이미 들어 안 되풀이한다」가 무너졌다 — 연장 칸 문장이 역할을 든다로 고친다
