# ADR-0733 — 첫 클리어 상자는 칸 클릭으로 안 열린다 · 우클릭 메뉴의 [사용]으로 연다

| **대체됨** | — |

## 결정

상자 칸을 **그냥 클릭하면 아무 일도 없다.** 여는 길은 **우클릭 메뉴의 [사용]** 하나다(손가락은 길게 눌러 연 툴팁 아래 버튼 줄의 [사용]). [사용]을 누르면 ADR-0731 그대로 그 칸이 무기로 바뀌고 플래시가 무기 이름을 등급 색으로 띄운다. `Ctrl`+클릭 · 끌어 놓기(창고로)는 그대로다. 상자 그림 · 툴팁 · 등급 숨김 · 우편함은 ADR-0731 · 0732 그대로다.

## 맥락

ADR-0731 은 상자 칸 클릭을 열기로 정했다 — 다른 보관 칸의 클릭(= 장착)과 손이 같다는 이유였다. 같은 날 사용자가 클릭 한 번에 바로 열리지 않고 우클릭 → [사용]을 거치도록 바꿨다.

## 근거

- **실수로 안 연다** — 인벤토리 칸을 훑으며 장비를 끼는 클릭이 상자를 건드려도 상자가 그대로 남는다. 여는 것은 고른 행동이다
- **버튼 이름은 「사용」** — 사용자가 부른 말 그대로다. 상자 칸에만 서는 버튼이라 [착용] · [잠금]과 섞이지 않는다
- 거른 안 — **클릭 = 고르기 · 고른 칸 옆에 [사용] 버튼**: 보관 칸에 「고른 상태」가 없다(분해함 모드만 칸을 올린다) — 우클릭 메뉴가 이미 그 칸만의 버튼 자리다

## 파급

- i18n `ch.menu.open` 의 글자가 「사용 / Use」 · ADR-0731 의 「대체됨」 칸
- 상자 칸 클릭은 툴팁만 닫는다
