# ADR-0735 — 후보 카드의 이름과 무기군은 칩 줄과 스킬 칸 사이 가운데에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-10-23 |
| **화면** | [SCREEN_DESIGN §3](../SCREEN_DESIGN.md) · [§8-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「이름을 좀 더 아래로 내려도될거같에 불안해보임 너무 높아서」) |
| **대체** | [ADR-0015](0015-고유-스킬-칸.md) 일부 — 칩 줄과 이름 사이를 「살짝」(4px) 띄운다 |
| **대체됨** | — |

## 결정

영웅 후보 카드(새 게임 · 선술집 명단 · 찾아온 영웅)의 오른쪽 열에서 **이름 줄 + 무기군 줄 덩어리가 칩 줄과 고유 스킬 칸 사이 남는 자리의 세로 가운데**에 선다. 칩 줄은 맨 위, 스킬 그림 아랫변은 초상 아랫변 그대로다(ADR-0156). 칩 줄과 이름 사이는 4px 를 최소로 지킨다. 도감 몬스터 툴팁 왼쪽 장은 그대로(칩 줄 바로 아래 4px)다.

## 맥락

그날 같은 날 이름 아래 `Lv.n` 줄이 이름 오른쪽으로 가고(ADR-0727) 역할 이름이 걷혀(ADR-0730) 오른쪽 열이 칩 · 이름 · 무기군 · 스킬 넷이 됐다. 이름 덩어리는 칩 줄 4px 아래에 붙고 스킬 칸은 열 바닥에 붙어, 그 사이가 통째로 비어 이름이 위로 몰려 보였다.

## 근거

- 고정 px 로 내리지 않고 가운데로 둔다 — 남는 자리는 초상 크기 · 칩 줄 줄 수가 정하는데, 가운데면 그 값이 바뀌어도 위아래 빈 자리가 늘 같다
- 칩 줄 · 이름을 「무엇인가 / 누구인가」로 가르는 09-08 의 뜻(ADR-0015)은 남는다 — 띄움이 커질 뿐 순서와 층은 같다
- 도감 몬스터 장은 역할 줄이 남아 있고 영어에서 칩 줄이 접힐 수 있어 열에 남는 자리가 카드마다 다르다 — 이 요청의 범위 밖이라 안 바꿨다

## 파급

- CSS `.ng-name` 의 위 여백이 `auto`(+ 최소 4px)이고 스킬 칸의 `margin-top: auto` 와 남는 자리를 반씩 나눈다 · `.cx-cand .ng-name` 은 종전 4px 로 되돌린다 · i18n 키 추가 없음
