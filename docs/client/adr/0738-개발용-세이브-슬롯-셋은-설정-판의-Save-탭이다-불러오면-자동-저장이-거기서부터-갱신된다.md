## 결정

1. `⚙` 판의 탭에 **Save** 가 설정 · Palette 다음에 선다. 개발 장치라 글은 영어다(Palette 와 같다).
2. 슬롯은 셋 — 한 줄에 `Slot n` · 저장 시각 · 요약(영웅 수 · 클리어 칸 수 · 골드 — 메뉴의 세이브 요약과 같은 셋) · `[Save]` `[Load]` `[Clear]`.
3. **[Save]** = 지금 판을 그 슬롯에 복사한다. **[Load]** = 그 슬롯으로 지금 판을 바꾸고, 자동 저장을 그 내용으로 덮어 **거기서부터 자동 저장이 다시 갱신된다** — 슬롯은 저장한 그대로 남는다. 메뉴의 [불러오기]는 지금처럼 자동 저장을 연다.
4. 불러오기는 메뉴의 이어 하기와 **같은 길**이다 — 저장한 뒤 흐른 시간은 꺼져 있던 동안처럼 세고, 저장할 때 돌던 원정은 마무리된다.
5. 찬 슬롯의 [Save](덮어쓰기) · [Load] · [Clear] 는 **두 번 눌러야** 일어난다. 빈 슬롯의 [Save] 는 한 번이다.
6. 판이 없으면(메뉴 · 시작 화면에서 판을 아직 안 열었으면) [Save] 가 흐리다 · 빈 슬롯과 못 여는 옛 세이브의 [Load] 도 흐리다.
7. 배포 주소에서도 선다 — `Admin` · Palette 와 같다.

## 맥락

세이브는 자동 저장 하나뿐이었다. 특정 구간의 판을 남겨 두고 다시 열어 데이터를 확인할 길이 없었다.

## 근거

- `⚙` 판은 이미 개발 장치(Palette)가 탭으로 서는 자리다 — 상단바에 버튼을 더 세우지 않는다
- 불러오기를 이어 하기와 같은 길로 두면 판을 갈아타는 처리(부대 핸들 정리 · 런 마무리)가 하나다
- 버린 안 — **저장한 순간에서 시간을 멈춰 불러오기**: 세이브 안의 시각 값을 전부 당기는 함수를 게임 로직에 새로 내야 한다 · 영웅 · 장비 · 진행 칸은 시간이 흘러도 그대로라 확인 용도엔 이어 하기 길로 족하다(사용자가 추천안을 받았다)
- 버린 안 — **슬롯 메모 칸 · JSON 파일 내려받기 · 올리기**: 이번엔 안 넣는다

## 파급

- `ui/storage.js` — 슬롯 읽기 · 쓰기 · 지우기(키 `thesevensim.slot.<n>`) · 자동 저장 키와 따로라 다른 탭의 멈춤 신호를 안 건드린다
- `ui/devsave.js` 신설 — Save 탭의 속 · `ui/devpalette.js` 가 덧붙는 탭을 받는다 · `app.js` 가 판 복사 · 불러오기를 넘긴다
- 세이브 형식은 그대로다(INTERFACE §4)
- 배포 주소에서 옛 슬롯을 불러오면 진행이 뒤로 간 세이브가 플레이 기록으로 올라간다(개발 환경은 안 올린다 · SCREEN_DESIGN §2-1)
