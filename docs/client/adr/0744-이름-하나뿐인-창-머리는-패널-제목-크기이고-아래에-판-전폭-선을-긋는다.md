# ADR-0744 — 이름 하나뿐인 창 머리는 패널 제목 크기이고 아래에 판 전폭 선을 긋는다

## 결정

창 머리가 **이름 하나**인 창(i18n 키 하나가 머리 — 우편함 · 도박장 · 친선전 · 스킬 트리 · 해고 · 멈춤 창)은 이름 글씨가 **패널 제목(`.panel > h2`)과 같은 크기**이고, 머리 아래에 **판 전폭 선**(패널 제목 밑줄과 같은 색 · 닫기 X 까지 머리 한 줄 전체를 받친다)이 선다. 머리를 통째로 갈아 끼우는 창(출정 · 자동 분해 · 미니게임 · 연구소 등록)은 제 규칙 그대로다.

## 맥락

이름 하나뿐인 창의 머리는 브라우저 기본 `h2` 크기였다 — 속 줄보다 두 단 넘게 컸다. 자동 분해 창은 이미 패널 제목 크기로 줄였고(2026-09-21), 출정 창은 머리 아래에 판 전폭 선을 그었다(ADR-0288). 사용자가 우편함 창을 보고 같은 처리를 지시했다.

## 근거

- **창 하나가 아니라 같은 모양의 창 모두** — 「우편함같은」 창 — 머리가 이름 하나인 창은 같은 함수(`renderModal`)가 같은 `h2` 를 그린다. 우편함만 바꾸면 창마다 머리 크기가 달라진다
- **크기 = 패널 제목** — 탭 안의 패널 제목과 같은 위계다. 이미 자동 분해 창이 이 크기라 새 단계를 만들지 않는다
- **선 = 출정 창의 머리 선과 같다** — 머리와 속이 갈리는 자리를 한 가지 선이 말한다
- 거른 안 — **우편함 창만**: 같은 모양의 창끼리 머리가 갈린다

## 파급

- CSS `.modal-head.plain` · `app.js:renderModal` 이 이름 머리에 `plain` 을 단다
- ⚠ 머리를 갈아 끼우는 창의 머리 크기 · 선은 창마다 다르다 — 맞출지는 따로 본다
