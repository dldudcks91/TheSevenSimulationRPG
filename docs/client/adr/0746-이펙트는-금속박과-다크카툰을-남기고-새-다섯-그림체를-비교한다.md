금속박과 다크 카툰의 설치본·원본을 보존하고 나머지 전투 이펙트의 설치본·원본·비교 이미지는 삭제한다. 보존 파일은 SHA-256으로 변경 여부를 확인하고 삭제 목록을 남긴다.

같은 스킬을 수채화·스테인드글라스·네온 플라즈마·로우폴리·자수로 새로 생성한다. 재질과 획의 차이를 비교하기 위해 스킬 대응·자리·크기·움직임·시간은 공통으로 쓴다. 활성 목록의 소환 역오각별도 새 그림체마다 갖춘다. 그림체와 경로의 기준은 `src/ui/skill_art.js:ART_STYLES`와 `artFile`이다.

내장 imagegen이 실제 투명 원본을 생성한다. 내보내기는 알파를 유지해 자르고 줄여 WebP로 저장한다. 생성 프롬프트·대응표·원본·비교표·검사 결과는 `src/assets/art/fx_source/revision_20261024/`에 둔다.

설정·도감은 같은 그림체 목록을 읽는다. 기본값은 다크 카툰이며 삭제된 선택값은 기존 기본값 처리로 돌아간다. 스테이지 띠는 UI 마스크로 이번 전투 이펙트 정리 대상에서 제외한다.
