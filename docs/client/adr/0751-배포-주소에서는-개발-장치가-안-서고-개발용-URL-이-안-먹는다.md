## 결정

개발 환경과 배포판을 **주소 하나로** 가른다 — 개발 환경 = 이 PC 의 로컬 서버로 연 주소(`localhost` · `127.0.0.1` · `[::1]`), 그 밖은 전부 배포판이다. 판정은 `ui/env.js:DEV_HOST` 한 곳이고 플레이 기록(§2-1)의 「개발 환경은 안 올린다」도 같은 값을 읽는다. 배포판에서는 ① 개발 장치가 안 선다 — 상단바 `Admin`(§10-3) · `⚙` 판의 Palette · Save 탭(§10-1 · §10-4) · 실험실 탭(§18) ② 이 브라우저에 남은 개발 장치의 저장값(Unlock `devAdmin` · 색 `devPalette`)도 안 먹는다 ③ 개발용 URL(§10 표)을 전부 무시한다 — 아무것도 없는 주소와 같다. 보기 설정 `?lang` · `?face` · `?bg` 와 `?focus`(§10-2 — 그 줄과 함께 걷는다)는 그대로 먹는다. 겸해서 사전에 없는 키를 받은 `t()` 는 키를 HTML 이스케이프해서 돌려준다.

## 맥락

2026-10-24 코드 리뷰(`output/2026-10-24_code_review/REPORT.md` D1 ~ D4)에서 개발 장치가 배포판 플레이어에게 그대로 열려 있는 것이 드러났다. ① `?flash=<키>` 는 모르는 키를 그대로 플래시의 `innerHTML` 로 넣어 주소 하나로 임의 스크립트가 돌았다(헤드리스에서 실행 확인) — 같은 origin 에 관리자 Google 로그인을 쓰는 `dev/funnel.html` 이 있다 ② `Admin` 이 누구에게나 서서 골드 · 재료 · 도안 · 영웅 넣기와 Unlock 이 됐고, 플레이 기록 요약에는 그 표시가 없어 퍼널을 믿을 수 없었다 ③ `?cn=max` · `?diff=` 를 `?dev=` 없이 주면 메뉴 상태(판 없음)에서 새 게임이 서며 자동 저장이 지워졌다. §10-4 는 「배포 주소에서도 선다 — Admin · Palette 와 같다」로 적고 있었다(ADR-0738 7번).

## 근거

- **판정을 주소로 한다** — 배포판은 `?dev` 같은 플래그를 지우는 것만으로 열리면 안 된다. 주소는 플레이어가 바꿀 수 없다. 반대로 「배포 주소 목록」(`*.github.io`)을 적는 안은 배포처를 옮기면 소리 없이 다시 열리므로 거른다 — 모르는 주소는 배포판으로 친다.
- **판정이 `app.js:isDevHost` 와 같아야 한다** — 플레이 기록이 이미 그 셋으로 「개발 환경은 안 올린다」를 가르고 있었다. 둘이 다르면 「장치는 서는데 기록은 올라가는」 주소가 생긴다. 그래서 정의를 `env.js` 로 옮기고 둘이 같은 값을 읽는다. ⚠ 같은 와이파이의 폰으로 PC 의 IP(`192.168.x.x`)를 열면 배포판으로 친다 — 기록도 올라가던 그대로다.
- **개발용 URL 을 표 단위로 고르지 않고 통째로 끈다** — §10 의 길들은 세이브를 직접 고치거나(`devBuild` · `?cxlv`) 새 게임을 세운다. 하나씩 안전한지 가르는 것보다 통째로 끄는 쪽이 새 길이 생겨도 기본이 닫혀 있다. 플레이어의 보기 설정인 `?lang` · `?face` · `?bg` 만 남긴다(루트 `index.html` 이 이 셋을 넘겨주는 공유 주소다).
- **저장값도 끈다** — 버튼만 숨기면 전에 Unlock 을 켜 둔 브라우저는 배포판에서도 전부 열린 채 돈다.
- **`t()` 이스케이프는 `?flash` 를 막은 뒤에도 둔다** — 모르는 키를 화면 글로 내는 길은 `?flash` 말고도 `` flash(`${pre}.err.${err}`) `` 같은 조립 키다. 정상 키(`ch.err.bagFull`)에는 이스케이프할 글자가 없어 화면이 안 바뀐다.

## 파급

- `ui/env.js` 신설 · `app.js`(`NAV_GROUPS` 의 `lab` · `mountAdmin` · `mountDevPalette` 인자 · `boot` 의 개발 경로 앞 출구 · `TRACK_ON`) · `devadmin.js`(Unlock 저장값) · `devpalette.js`(Palette 탭 선택지) · `i18n.js`(`t()`) — i18n 키 · CSS 클래스는 그대로
- 개발 장치 파일 자체는 배포판에도 실려 간다(정적 import) — 동적 import 로 떼는 것은 별건이다
- ⚠ `?focus`(§10-2)와 배속 ×16 은 「나중에 배포판에서 지운다」(2026-10-24 사용자) — 이번엔 안 건드렸다
