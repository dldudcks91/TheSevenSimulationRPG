## 결정

결투 배경을 **탭마다 한 장**으로 가른다. 콜로세움 탭은 ADR-0749 의 로마 콜로세움(`illustrate/background_colosseum.webp`)이고, 결투장 탭은 같은 그림체로 새로 그린 **요새 지하의 고딕 결투 홀**(`illustrate/background_arena.webp`)이다. 결투 홀에는 둥근 돌 결투 바닥 · 쇠사슬 기둥 · 늑골 천장 아래 빈 발코니 · 큰 문 양옆의 쇠 화로 · 문 위 벽감의 무기를 든 일곱 챔피언 석상이 있다. 그 탭의 판과 관전이 같은 그림이다. 경로는 탭 id 를 키로 한 `mock.js:ARENA_BG` 하나가 든다.

## 맥락

같은 날 ADR-0749 로 두 탭이 콜로세움 한 장을 같이 깔았다. 그림을 거친 그림체로 다시 뽑은 뒤 사용자가 콜로세움은 그대로 두고 결투장에 따로 한 장을 만들라고 했다.

## 근거

- **두 탭이 갈린다** — 콜로세움(오프라인 층 사다리)과 결투장(온라인 레이팅)은 판 · 관전이 같아도 탭이 다르다. ADR-0749 는 「그림을 둘로 가를 근거가 없다」고 봤는데, 들어가는 탭마다 장소가 달라 보이는 것이 사용자가 원한 쪽이다
- **결투장 = 실내 지하 홀** — 콜로세움이 하늘이 트인 바깥 원형 경기장이라, 같은 그림체에서 가장 멀리 갈리는 짝이 천장이 덮인 실내다. 문 위 챔피언 석상은 레이팅 리그(지난 승자의 자리)를 장소로 말한다
- **그림체는 콜로세움을 따른다** — 콜로세움 원본과 `201` 을 붙여 같은 STYLE 블록으로 뽑았다
- **거른 안 — 한 장을 두 탭이 다른 색으로 쓴다** — 색 필터로 가르면 같은 장소로 읽힌다

## 파급

- `mock.js:ARENA_BG` = `{ colosseum, arena }` · `app.js:arenaWatchPage` 가 배경을 받고 `arenaStage` 가 `o.bg` 를 깐다
- 콜로세움 그림의 파일명이 `background_arena` → `background_colosseum` 으로 바뀌었다(원본 · 지시문 같이). 결투 홀이 `background_arena` 다 — 파일명 = 탭 id
