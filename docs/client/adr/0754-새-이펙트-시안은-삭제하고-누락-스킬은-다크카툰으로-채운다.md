# ADR-0754 — 새 이펙트 시안은 삭제하고 누락 스킬은 다크 카툰으로 채운다

| | |

| **화면** | [SCREEN_DESIGN §9-1](../SCREEN_DESIGN.md) · §2-2 · §4-2 |
| **정한 사람** | 사용자 「새로 그린거 모두 삭제하고 다크카툰에 그려지지않았던애들을 다크카툰스타일로 모두 다시 그려봐」 |
| **대체** | [ADR-0746](0746-이펙트는-금속박과-다크카툰을-남기고-새-다섯-그림체를-비교한다.md)의 새 다섯 시안과 선택 목록 |
| **대체됨** | — |

수채화·스테인드글라스·네온 플라즈마·로우폴리·자수의 설치본·원본·프롬프트·비교 이미지와 전용 작업 스크립트를 삭제한다. 기존 금속박·다크 카툰의 그림 파일은 보존한다.

현재 `skill.csv`와 `skill_art.js:SKILL_ART`를 대조해 그림이 없는 스킬을 찾고 모두 다크 카툰으로 새로 그린다. 기존 다크 카툰의 굵은 검은 윤곽선·각진 실루엣·두 단계 명암·절제된 강조색을 참조하며 각 스킬의 효과와 사건에 맞춰 구도를 정한다. 회복·강화·약화는 얼굴 가운데를 비운다. 오오라는 기존처럼 도감에서 미리 본다.

새 파일은 다크 카툰에만 있다. 정의의 `styles`가 가용 그림체를 나타내고 `artFile`이 없는 조합을 null로 돌려 금속박에서는 파일 요청 없이 코드 조합을 쓴다. 새 스킬의 코드 대체 연출도 같은 의미와 색을 갖춘다. 관전·도감의 표시 함수와 사건·크기·움직임 계약은 공통이다.

생성 방식은 내장 imagegen이며 원본·프롬프트·셀 대응표·삭제 목록·보존 해시·검사 기록은 `src/assets/art/fx_source/darktoon_completion_20261024/`에 둔다. 그림체 목록과 파일 대응은 `ART_STYLES`와 `artFile`이 기준이다.
