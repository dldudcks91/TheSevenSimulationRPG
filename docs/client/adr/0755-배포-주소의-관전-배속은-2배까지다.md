# ADR-0755 — 배포 주소의 관전 배속은 ×2 까지다

| | |
|---|---|
| **상태** | 확정 · 2026-10-24 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) · [§10 머리](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「배포판에서는 최대2배까지 적용되도록 넣어봐」) |
| **대체** | — |
| **대체됨** | — |

## 결정

관전 헤드의 배속 버튼은 **배포 주소에서 `×1` · `×2` 둘**이다. 개발 환경(ADR-0751 의 판정 — `ui/env.js:DEV_HOST`)은 그대로 `×1` · `×2` · `×4` · `×16` 넷이다. 목록은 `ui/battle.js:speedsFor` 한 곳이 낸다.

## 맥락

2026-10-24 코드 리뷰에서 「배속이 원정의 실제 빠르기 = 시간당 보상을 바꾼다」가 드러났다 — 시각은 실제로 흐른 시간 × 배속이라(§4) 보는 부대를 `×16` 에 두면 원정이 16배로 돈다(안 보는 부대는 `×1`). `×16` 은 2026-10-05 사용자 지시로 들어온 버튼이었다. 같은 날 사용자는 「배속 ×16 은 나중에 배포판에서 지운다」고 정했고, 이어서 배포판의 상한을 `×2` 로 정했다.

## 근거

- **버튼 목록을 줄인다** — 배속은 화면 상태에만 산다(세이브 · 저장소에 안 든다). 그 값을 바꾸는 길이 버튼 하나뿐이라 목록만 줄이면 배포판에서 `×2` 를 넘는 값이 생길 자리가 없다. 정산 쪽에 상한을 따로 거는 안은 같은 값을 두 곳이 지키게 되어 거른다.
- **개발 환경은 넷을 둔다** — 헤드리스 검증 · 연출 확인이 `×16` 을 쓴다(성능 점검 · 대량 관전).
- **`×2` 의 연출 박자(`fx.js:SPEED_K`)는 그대로다** — 값 목록에서 빠지는 것뿐이라 `×2` 의 모양은 안 바뀐다.

## 파급

- `ui/battle.js` 의 배속 목록 · SCREEN_DESIGN §4-2 컨트롤 줄 · §10 머리(배포판에서 빠지는 것) · 상단바 원정 시간 줄의 예시
- ⚠ 시간당 보상이 배속을 탄다는 규칙 자체(§4 「시각은 실제로 흐른 시간 × 배속」)는 그대로다 — 배포판에서는 그 폭이 `×2` 로 좁아질 뿐이다. Focus(§10-2)도 이번엔 안 건드렸다
