## 결정

두 탭의 **화면 이름을 맞바꾼다.** 다른 사람의 팀과 레이팅으로 겨루는 온라인 ELO 탭이 **콜로세움**(Colosseum)이고, 층마다 정해진 AI 팀을 오르는 오프라인 사다리가 **결투장**(Arena)이다. 탭 머리 그림도 이름을 따라 맞바꾼다 — 콜로세움 = 콜로세움 건물(`icons/arena/colosseum`) · 결투장 = 칼(`duel`). 결투 배경도 이름을 따른다(로마 콜로세움 그림은 콜로세움 탭 · ADR-0761). 내비 자리는 그대로라 기타 묶음이 「결투장 · 콜로세움 · 도감 …」 순이 된다.

**탭 id · 세이브 키 · 문구 키 · 개발 URL 은 옛 이름 그대로다** — `colosseum` 탭(`renderColosseum` · `G.colosseum` · `cs.*` · `?dev=colosseum`) = 화면 「결투장」, `arena` 탭(`renderArena` · `G.arena` · `ar.*` · `?dev=arena`) = 화면 「콜로세움」.

## 맥락

2026-10-18(ADR-0670) 에 탭을 둘로 가르며 오프라인 층 사다리를 콜로세움, 온라인 ELO 를 결투장이라 불렀다. 사용자가 「지금 다른 사람이랑 싸우는 게 뭐냐」를 묻고 결투장이라는 답을 들은 뒤, 남과 겨루는 쪽이 콜로세움인 편이 멋지다고 했다. 서버가 없어 그날 남의 팀과 붙는 길은 결투장 탭의 친선전 하나였다.

## 근거

- **콜로세움은 「관중 앞에서 남과 겨룬다」로 읽힌다** — 레이팅을 걸고 다른 플레이어와 겨루는 자리가 그 이름값을 한다. 정해진 AI 층을 하나씩 오르는 자리엔 과하다. 결투장은 이름이 수수해 수련 · 사다리 쪽에 맞는다
- **탭 id 는 안 바꾼다** — id 를 바꾸면 세이브 키(`G.colosseum` · `G.arena` — 세이브 버전 · 이주) · 개발 URL · 단정 · 문구 키 접두가 다 움직이는데, 화면에서 얻는 것은 같다. 대신 id 와 이름이 엇갈린다는 것을 내비 정의(`app.js:NAV_GROUPS`) · i18n 머리 · 규격 §1 · arena_design §0 에 적는다
- **「결투장」은 두 뜻으로 남는다** — 기획 문서에서는 영웅 팀 대 영웅 팀 전체(밸런스 기준 「PvP(결투장)」 · GAME_DESIGN §10 「결투장」 행)를 가리킨다. 이 뜻은 두 탭 모두에 맞아 고치지 않고 arena_design §0 에 「두 뜻」 한 줄을 둔다
- **거른 안 — 탭 id 까지 바꾼다** — 위 이주 비용 · 병렬 세션이 같은 파일을 고치는 중이라 충돌 위험

## 파급

- i18n `nav.colosseum` = 결투장 / Arena · `nav.arena` = 콜로세움 / Colosseum · `cs.back` · `ar.back` · `cs.help` · `ar.help.rating` · `ar.help` 의 이름
- `app.js:arenaShell` 머리 그림 인자 맞바꿈 · 탭을 이름으로 가리키던 주석에 id 를 붙였다
- 기획 — arena_design §0 · §5 · §7 · §8 · GAME_DESIGN §9 · §10 「결투장」 행 · 문서 표
- ⚠ 코드 주석 · INTERFACE 의 옛 이름(「콜로세움 층」 · 「결투장 리그」)은 id 의 뜻으로 읽힌다 — 화면 이름이 아니다
