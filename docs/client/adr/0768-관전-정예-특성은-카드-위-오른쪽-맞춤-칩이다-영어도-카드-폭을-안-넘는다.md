## 결정

관전 정예 카드의 특성은 **카드 위에 뜬 칩 줄**이다 — 카드 밖이라 카드 크기 · 띠(신원)를 안 건드린다 · **오른쪽 맞춤** · 칸마다 칩 하나. 칩은 죄종 칩 모양(글자색 1px 테두리)에 카드 바탕을 깔고, 색은 ADR-0765 그대로(죄종 칸 죄종 색 · 능력치 칸 본문 색 · 방어 칸 피해 종류 색). **영어의 가장 긴 조합도 카드 폭을 넘지 않는다** — 그렇게 되도록 능력치 칸 통솔의 이름을 「Commanding 지휘하는」에서 **「Leading 이끄는」** 으로 바꿨다. 그래도 넘치면 칩 줄은 왼쪽부터 잘린다. 개발용 `&traits=max` 는 칸마다 가장 긴 이름을 세워 이 약속을 눈으로 보는 자리다.

## 맥락

ADR-0765 로 특성을 띠 오른쪽 글자로 적자 실제 화면에서 왼쪽 신원이 줄었다 — 헬 영어는 「Lv.1…」까지 줄어 레벨도 잘렸다(사용자 「너무 가리네」). 그날 비교한 자리(전부 실제 관전 스크린샷 위 목업 · 1600 × 800):

- 카드 위 한 줄 글자(어두운 바닥) — 사용자 「구려보인다」
- 카드 윗변 테두리에 걸친 칩 · 카드 아래 창 뱃지 줄 맨 앞 칩 — 뱃지 줄은 영어 헬에서 칩만으로 카드 폭을 넘어 버프 그림이 밀려 잘렸다
- 걸치지 않고 위로 올린 칩(오른쪽 · 왼쪽 맞춤) — 채택

카드 위 공간: 아레나 윗변에서 적 전열 카드 윗변까지 실측 60px · 후열(진형 한 칸 21px 위)이라도 39px — 칩 한 줄(16px + 띄움 6px)이 든다.

## 근거

- **카드 밖 · 위** — 띠 안에서는 신원과 자리를 나눠 어느 한쪽이 잘린다. 위는 비어 있고, 칩을 테두리에 걸치지 않아 카드 테두리 · 띠가 그대로다(사용자)
- **칩** — 맨 글자는 배경 그림 위에서 붙여 놓은 것처럼 보였다. 이미 쓰는 칩 문법(죄종 칩 · 등급 칩)이라 카드에 딸린 것으로 읽힌다
- **오른쪽 맞춤** — 사용자 선택. 칸이 하나 · 둘일 때 카드 오른쪽 위 구석에 모인다
- **카드 폭이 상한** — 이웃 카드 위로 넘어가면 어느 카드의 특성인지 흐려진다(사용자 「절대 카드크기를 넘기면 안 돼」). CSS 로 자르는 것은 안전망이고, 약속은 이름이 진다
- **잰 값**(Pretendard · `--fs-xs` · 칩 좌우 여백 5 + 테두리 1 · 칩 틈 3 · 카드 바깥 폭 252) — 칩 셋이 쓸 수 있는 폭 246:
  - 영어 최장 = 죄종 Appraiser's Eye 94.6 + 능력치 **Commanding 83.6** + 방어 Venomproof 77.9 = 256.1 → **넘친다**
  - 능력치 이름 중 Commanding 만 튀었다(다음이 Intelligent 64.4) — 이 하나만 바꾸면 최장 = 94.6 + 64.4 + 77.9 = **236.9**(여유 9) · 마스터리 이름(영웅 화면과 같은 SSOT)은 건드리지 않는다
  - 후보 — **Leading 이끄는** 54.8 · Rallying 규합하는 53.5 · Inspiring 고무하는 57.6 → 하는 일을 그대로 말하는 Leading(담백한 이름 · 영어 원본 · 한글 직역)
  - 한국어 최장 = 감정사의 눈 66.9 + 매력적인 53.5 + 독이 듣지 않는 80.3 = 200.7 — 여유 넉넉
