## 결정

정예 특성 칩은 **카드 맨 위 띠의 오른쪽 끝에 가로 한 줄 · 오른쪽 맞춤**으로 선다(왼쪽부터 죄종 → 능력치 → 방어). 칩 모양 · 색 · 글씨 크기는 ADR-0768 그대로다. 띠가 모자라면 **왼쪽 신원(`Lv.n · 직업 · 종족`)이 먼저 말줄임으로 줄어들고** 칩은 띠 폭까지만 선다 — 글씨가 카드 밖으로 나가지 않는다.

## 맥락

같은 날 칩을 초상 왼쪽 아래에 세로로 쌓았다(ADR-0774) — 사용자가 초상 위가 아닌 카드 오른쪽 위를 지시했다. 이 자리는 ADR-0765(띠 오른쪽 글자)와 같은 자리이고, 그때 헬 영어에서 신원이 「Lv.1…」까지 줄었다.

## 근거

- **띠 오른쪽 · 오른쪽 맞춤** — 사용자 지시. 칸이 하나 · 둘일 때 카드 오른쪽 위 구석에 모인다
- **신원이 먼저 줄어든다** — ADR-0765 와 같은 순서(칩이 이 카드의 정예 정보를 혼자 든다 · 신원은 다른 화면에도 있다)
- ⚠ 헬 영어의 긴 조합에서는 신원이 거의 다 잘린다 — 사용자가 「일단」으로 둔 자리라 실제 화면으로 다시 본다. 다시 정할 때의 후보: 단어 줄이기(능력치 약어 · 원소 이름 — ADR-0765 에서 본 B 안) · 초상 아래(ADR-0774)

## 파급

- `battle.js` — 칩 줄(`traitsHtml`)이 본문에서 띠(`.unit-top`) 오른쪽으로
- CSS — `.unit.v2 > .unit-top .unit-traits`(줄지 않고 띠 폭까지만 · 오른쪽 맞춤 · 넘치면 왼쪽부터 잘림) · 초상 기준 규칙(`.unit.v2 .unit-body` position)을 걷는다
- 칩 하나 = 초상 폭이던 약속(ADR-0774)은 「칩 줄이 띠 폭 안 · 넘치면 신원이 먼저 준다」로 바뀐다
