# ADR-0781 — HP 소모는 그 카드에 작고 흐린 숫자로만 뜬다

| | |
|---|---|
| **상태** | 확정 · 2026-10-24 |

| **정한 사람** | 제안 후 승인(사용자 지시 「차지는 현재 체력의 10%를 사용하고」의 화면 몫) |
| **대체** | — |

## 결정

스킬을 쓰며 낸 HP(`pay` 사건 — 같은 날 기사 차지가 지금 HP 의 일부를 내게 됐다 · DEV_PLAN R355)는 **그 카드에 작고 흐린 `-낸 양`** 으로 피해 숫자 자리에 뜨고 체력 막대가 그만큼 준다. 로그 줄과 피격 반응(흔들림 · 번쩍임)은 없다. 설명창 문장은 새 자리 `{p}`(지금 HP 의 비율 · 원값)로 낸 양을 말한다 — 「현재 HP 의 10%를 써서 …」.

## 맥락

재생기는 HP 를 사건의 `dhp` 로만 맞춘다(계산하지 않는다). HP 소모를 사건 없이 두면 체력 막대가 다음에 맞을 때까지 안 줄어 숫자와 막대가 어긋난다. 그래서 로직이 `pay` 사건을 내고, 화면은 그것을 어떻게 보일지 정해야 했다.

## 근거

- **피해와 갈려야 한다** — 피해 숫자는 크고(ADR-0657) 피해 종류 색이다(ADR-0408). 같은 모양이면 「차지가 자기를 때렸다」 · 「적이 때렸다」로 읽힌다. 작고 흐린 글자는 회복 · 물약 팝업과 같은 자리 규칙(초상 오른쪽 위에서 떠오른다)을 따르면서 크기 · 색으로 갈린다.
- **로그 줄을 안 둔다** — 로그는 타격 · 회복 · 상태를 적는 자리이고(ADR-0189) 소모는 시전의 일부라 바로 앞 「차지」 시전 줄이 이미 말한다. 줄을 더하면 차지마다 줄이 둘이 된다.
- **피격 반응을 안 둔다** — 피해가 아니다(배리어 · 피해 감소를 안 지난다 · INTERFACE §2-6 `pay`). 카드가 흔들리면 맞은 것으로 읽힌다.
- 거른 안 — 소모를 표시하지 않고 막대만 줄이기: 왜 줄었는지 읽을 길이 없다(통제성 — 인과가 읽혀야 한다).

## 파급

- `ui/battle.js` — `pay` 사건: `dhp` 로 HP 를 맞추고 `popup(… 'pay')`
- `style.css` — `.pop.pay`(흐린 글자색 · 작은 글자)
- `tip.js:descSlots` — 자리 `{p}` · `skill.js` 로드가 그 스킬에 소모가 없으면 `{p}` 를 막는다
- ⚠ 리포트 · 딜미터는 소모를 안 센다 — 받은 피해가 아니다
