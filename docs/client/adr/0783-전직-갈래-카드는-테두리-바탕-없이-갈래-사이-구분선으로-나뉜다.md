# ADR-0783 — 전직 갈래 카드는 테두리 · 바탕 없이 갈래 사이 구분선으로 나뉜다

## 결정

도서관 전직 패널의 갈래 셋은 **테두리도 바탕도 없이** 서고, **갈래와 갈래 사이에 가로 구분선 하나**가 그어진다 — 패널 제목 밑줄과 같은 선(`--border-primary`)이다. 셋 사이의 빈 간격은 없앤다(선이 나눈다). 셋이 남는 세로를 똑같이 나눠 채우는 것 · 안의 배치 · 누르면 고르는 것은 그대로고, **고른 갈래의 파란 안쪽 테두리 · 전직한 갈래의 주황 안쪽 테두리**도 그대로 그 갈래에만 선다. 올리면(고를 수 있을 때) 그 갈래의 바탕이 조금 밝아진다.

## 맥락

같은 날 갈래 셋은 저마다 회색 테두리 · 카드 바탕을 두른 상자였고 상자 사이가 10px 띄어 있었다. 패널 자체가 테두리를 둘렀고 그 안의 「지금 가진 스킬」 칸도 테두리를 둘러, 패널 안에 상자가 겹겹이 서 있었다. 사용자가 상자를 걷고 사이 구분선으로 정리하자고 했다.

## 근거

- **패널 안 상자가 한 겹 준다** — 패널 테두리 · 갈래 테두리 · 스킬 그림 칸 테두리가 겹치던 것에서 갈래 테두리가 빠진다. 셋을 가르는 일은 선 하나로 충분하다
- **고른 표시는 남긴다** — 평소에 상자가 없으니 고른 · 전직한 갈래에만 서는 안쪽 테두리가 오히려 더 또렷하다. 바탕 칠로 고른 것을 말하는 안은 올리기(hover) 표시와 겹쳐 거른다
- **선은 패널 제목 밑줄과 같다** — 새 색을 만들지 않는다. 툴팁 안의 절 구분선(`--border-dark`)보다 한 단계 밝아 큰 패널에서도 읽힌다

## 파급

- CSS `.tr-adv-branch` — 테두리 · 바탕을 걷고 `+ .tr-adv-branch` 위에 구분선 · `.tr-adv-row` 의 `gap` 을 걷는다 · `.can-pick:hover` 는 테두리 색 대신 바탕
- `app.js:advancePanel` 은 그대로다(클래스 이름이 같다)
