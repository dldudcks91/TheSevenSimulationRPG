# ADR-0784 — 전직 첫 갈래 위에도 구분선이 선다

## 결정

도서관 전직 패널의 갈래 구분선은 **갈래마다 그 위에** 그어진다 — 둘째 · 셋째 갈래 위만이 아니라 **첫 갈래 위**(지금 가진 스킬 카드 셋과 갈래 셋 사이)에도 같은 선이 선다. 마지막 갈래 아래에는 선이 없다(패널 테두리가 닫는다).

## 맥락

같은 날 갈래 셋의 상자를 걷고 갈래 사이에만 선을 그었다(ADR-0783). 첫 갈래(광전사 등) 위는 선 없이 「지금 가진 스킬」 칸 아래로 이어져, 갈래 자리가 어디서 시작하는지가 흐렸다. 사용자가 광전사 위에도 선 하나를 그어 보자고 했다.

## 근거

- **갈래 자리의 시작이 읽힌다** — 위 영웅 줄 · 스킬 칸(베일 밖 · ADR-0595)과 아래 갈래 셋(베일이 덮는 자리)이 선 하나로 갈린다
- **새 선을 만들지 않는다** — 갈래 사이 선과 같은 선을 갈래마다 위에 두면 규칙이 하나다(「첫 갈래만 다른 선」이 생기지 않는다)

## 파급

- CSS `.tr-adv-branch` — 구분선이 `+ .tr-adv-branch` 에서 모든 갈래의 위(`border-top`)로 옮겨 간다
