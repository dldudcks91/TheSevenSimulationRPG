## 결정

`D2 Min` 에서 게임 화면의 메인(`#app:not(.pregame) > .main`)은 **위 · 왼쪽 여백이 4px** 다 — 패널 돌 테두리가 바깥으로 나가는 양과 같아, 첫 판의 테두리 바깥 끝이 메인 칸 끝에 닿는다. 상단바 · 브랜드 · 탭 열의 틀이 그리드 칸 경계에서 맞붙는 것과 같은 모양이라, 첫 판과 탭 열 · 상단바 사이 틈이 상단바 줄(브랜드 ↔ 상단바)의 틈과 같다. 오른쪽 · 아래 여백은 그대로다. `Now` 와 게임 밖 화면(메뉴 · 새 게임)은 안 바뀐다.

## 맥락

같은 날 ADR-0791 로 `D2 Min` 을 붙였다. 상단바 · 브랜드 · 탭 열은 그리드 칸을 꽉 채운 판이라 돌 테두리끼리 맞붙어, 1600×800 에서 보이는 틈이 브랜드 ↔ 상단바 4px · 브랜드 ↔ 탭 열 5px 였다. 메인 안의 판은 메인 여백(20px · 메인 배율 .9 → 18px) 만큼 떨어져, 첫 판과 탭 열 · 상단바 사이 틈이 18px 였다(8비트 회색값 실측). 셸 판 넷이 붙어 있는데 본문 판만 떠 보였다.

## 근거

- **4px 인 이유** — 판의 돌 테두리는 바깥으로 4px 나간다(ADR-0791). 여백이 그 양이면 테두리 바깥 끝 = 메인 칸 끝이라, 셸 판끼리 맞붙는 것과 같은 자리에 선다. 실측 — 첫 판 ↔ 탭 열 4px · 첫 판 ↔ 상단바 5px 로 상단바 줄의 두 틈과 픽셀까지 같다. 더 줄이면 메인(`overflow` 가 걸린 칸)이 테두리를 자른다
- **위 · 왼쪽만인 이유** — 요청이 왼쪽 위 끝점이었다. 오른쪽 · 아래는 손대지 않았다
- **게임 밖 화면을 빼는 이유** — 메뉴 · 새 게임은 탭 열이 없고 내용이 가운데 선다. 맞붙을 틀이 없다
- **ADR-0791 의 「여백을 안 바꾼다」를 거스르는 것** — 그 근거는 `Now` 와 견줄 때 배치 차이가 섞이지 않게 하려는 것이었다. 사용자가 이 시안의 배치를 직접 고쳤다 — 이제 두 모양은 메인 내용 칸 크기(가로 · 세로 16px 씩)도 다르다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 패널 규칙 아래 한 줄(`:where(:root[data-skin="d2min"]) #app:not(.pregame) > .main`)
- i18n 키 변화 없음
- ⚠ 오른쪽 · 아래는 첫 판 ↔ 한 장 끝 틈이 상단바 · 탭 열보다 넓은 채다 — 맞출지는 열려 있다
- ⚠ 메인 첫 요소가 패널이 아닌 탭(원정 장소 목록 — 난이도 줄이 맨 위)은 그 요소가 메인 칸 끝에서 4px 에 선다
