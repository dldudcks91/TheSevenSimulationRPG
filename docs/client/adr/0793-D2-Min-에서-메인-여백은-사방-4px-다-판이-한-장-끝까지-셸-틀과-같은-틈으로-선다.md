# ADR-0793 — `D2 Min` 에서 메인 여백은 사방 4px 다 · 판이 한 장 끝까지 셸 틀과 같은 틈으로 선다

## 결정

`D2 Min` 에서 게임 화면의 메인(`#app:not(.pregame) > .main`)은 **오른쪽 · 아래 여백도 4px** 다 — 사방이 패널 돌 테두리가 바깥으로 나가는 양과 같다. 판의 오른쪽 끝은 상단바 틀의 오른쪽 끝과, 박스의 아랫변은 탭 열 틀의 아랫변과 같은 자리에서 끝난다. `Now` 와 게임 밖 화면은 안 바뀐다.

## 맥락

같은 날 ADR-0792 로 위 · 왼쪽 여백을 4px 로 줄여 첫 판이 상단바 · 탭 열 틀에 맞붙었다. 오른쪽 · 아래는 그대로라 판 ↔ 한 장 끝 틈이 상단바 · 탭 열보다 넓었다(오른쪽 여백 20px · 아래 12 / .9 — 박스 아랫변 = 탭 열 「새 게임」 아랫변 788). 이것도 맞출지 묻자 사용자가 채우라고 했다.

## 근거

- **4px 인 이유** — ADR-0792 와 같다. 테두리 바깥 끝 = 메인 칸 끝이라 상단바 · 탭 열 틀이 한 장 끝에 닿는 것과 같은 자리다. 1600×800 실측 — 판의 오른쪽 끝 어두운 줄(1598 · 1599)이 상단바 줄과 같고, 박스 아래 밝은 줄(792) · 어두운 줄(797~799)이 탭 열과 같다
- **박스 아랫변이 「새 게임」을 안 따르는 이유** — 그 맞춤은 테두리 없는 `Now` 에서 박스 아랫변을 탭 열 안의 마지막 줄과 잇는 규칙이다. `D2 Min` 에서는 탭 열도 틀을 두른 판이라, 틀 아랫변끼리 맞는 것이 상단바 줄과 같은 모양이다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 메인 규칙이 `padding: 4px` 한 줄
- i18n 키 변화 없음
- `Now` 와 견주면 메인 내용 칸이 가로 32px · 세로 약 24px 넓다
- ⚠ 도움말 탭처럼 폭이 정해진 판은 오른쪽이 빈 채다 — 판 폭은 손대지 않았다
