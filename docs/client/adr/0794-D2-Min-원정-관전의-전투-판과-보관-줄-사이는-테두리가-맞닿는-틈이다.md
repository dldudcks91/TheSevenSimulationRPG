# ADR-0794 — `D2 Min` 원정 관전의 전투 판과 보관 줄 사이는 테두리가 맞닿는 틈이다

| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |

| **대체** | — |
| **대체됨** | [ADR-0795](0795-D2-Min-에서-모든-판-사이-틈은-테두리가-맞닿는-8px-다.md) — **「원정 관전의 위아래 한 곳만 · 결투 관전은 그대로」**(→ 모든 판 사이 8px). 8px 값 · 보관 줄이 제자리인 것은 산다 — 2026-10-26 |

## 결정

`D2 Min` 에서 원정 관전 탭(`.bt-page`)의 전투 판 ↔ 보관 줄(창고 · 인벤토리) 사이 간격은 **8px** 다 — 두 판의 돌 테두리가 바깥으로 4px 씩 나가 테두리끼리 맞닿는다. 보이는 틈이 셸 판끼리(브랜드 ↔ 탭 열)의 틈과 같다. 보관 줄은 제자리이고 전투 판이 그만큼 길어진다. 결투 관전(`.arena-watch`)과 `Now` 는 안 바뀐다.

## 맥락

같은 날 ADR-0793 으로 메인 여백을 사방 4px 로 줄여 판이 셸 틀과 같은 틈으로 섰다. 원정 관전 안의 두 판 사이는 `gap` 14px(메인 배율 .9 → 12.6px)이라 테두리 바깥 끝 사이가 약 6px 떴고, 보이는 틈이 셸 틈보다 넓었다. 1600×800 실측 — 셸(x=200)은 밝은 줄 → 어두운 줄 5 → 밝은 줄이고, 고친 뒤 전투 판 ↔ 창고도 같은 모양이다.

## 근거

- **8px 인 이유** — 판마다 테두리가 4px 나간다(ADR-0791). 둘을 더한 값이면 테두리 바깥 끝끼리 닿아, 셸 판이 그리드 칸 경계에서 맞붙는 것과 같은 모양이다
- **보관 줄이 아니라 전투 판이 늘어나는 이유** — 관전 박스는 전투 판이 남는 세로를 먹는다(`.bt-page > .battle-panel` · flex 1). 보관 줄의 칸 크기 · 자리를 그대로 두는 쪽이 비교에 섞이는 것이 적다
- **결투 관전을 빼는 이유** — 요청이 원정이었다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 한 줄(`.bt-page:not(.arena-watch)`)
- i18n 키 변화 없음
- ⚠ 창고 ↔ 인벤토리 가로 틈(`.bag-row` gap 14px)은 그대로다 — 맞출지는 열려 있다
- ⚠ 캐릭터 · 대장간 탭처럼 판이 위아래로 쌓인 다른 탭의 판 사이 틈도 그대로다
