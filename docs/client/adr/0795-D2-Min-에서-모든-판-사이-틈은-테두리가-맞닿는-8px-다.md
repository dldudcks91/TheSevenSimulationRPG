## 결정

`D2 Min` 에서 게임 화면의 **판과 판 사이는 모두 8px** 다 — 위아래(쌓인 판의 간격 · 위 마진)와 좌우(나란한 판의 간격)가 같다. 두 판의 돌 테두리가 바깥으로 4px 씩 나가 테두리끼리 맞닿고, 보이는 틈이 셸 판끼리(브랜드 ↔ 상단바 · 탭 열)의 틈과 같다. 돌 테두리가 없는 탐험 지도는 위 영웅 띠와 5px — 보이는 어두운 줄 수가 판 사이와 같은 값이다. 나란히 서서 위 마진이 0 인 판(선술집 도박장 · 연구소 옆 칸)은 그대로 0 이다. `Now` 와 판 안쪽의 간격은 안 바뀐다.

## 맥락

같은 날 ADR-0794 로 원정 관전의 전투 판 ↔ 보관 줄만 8px 로 줄였다. 나머지 판 사이는 기본값 14px(메인 배율 .9 → 12.6px) 그대로라, 1600×800 에서 판이 둘 이상인 화면(원정 관전 · 편성 · 캐릭터 · 선술집 · 상단 · 대장간 · 도서관 · 연구소 · 리포트 · 결투 관전)을 재면 판 사이가 7.2px 와 12.6px 두 값으로 섞여 있었다. 14px 는 토큰이 아니라 판을 담는 자리마다(간격 여덟 곳 · 위 마진 셋) 따로 적혀 있었다.

## 근거

- **8px 인 이유** — ADR-0794 와 같다. 판마다 테두리가 4px 나가 둘을 더하면 테두리끼리 닿는다
- **판을 담는 자리를 하나씩 고치는 이유** — 14px 가 토큰이 아니다. 토큰을 새로 세우면 기본 규칙 열한 줄을 고쳐야 해 비교 장치가 본 규칙 쪽으로 번진다. 시안 절 안에서 같은 자리를 덮으면 걷을 때 절 하나만 지우면 된다(ADR-0791). `.cols` 는 판 안에서도 쓰여 판 밖의 것만 고른다
- **나란한 판의 위 마진 0 을 다시 거는 이유** — 그 0 은 기본 규칙에서 `.panel + .panel` 과 같은 강도라, 파일 끝의 시안 줄이 덮어 옆 판이 8px 내려앉았다(실측). 같은 0 을 시안 절에서 다시 건다
- **탐험 지도가 5px 인 이유** — 지도는 판이 아니라 테두리가 바깥으로 안 나가고 제 1px 테두리가 어둡다. 판 사이는 어두운 줄 다섯이고, 지도는 5px 에서 같은 다섯 줄이 된다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절: 간격 8px(`.bt-page` · `.char-stack` · 판 밖 `.cols` · `.bag-row` · `.tdm` · `.lib-col` · `.dp-wrap` · `.tv-low`) · 위 마진 8px(`.panel + .panel` · `.hs-panel + .dp-wrap` · `.tv-low`) · 위 마진 0 다시 걸기(`.dp-side` · `.tv-gb`) · 탐험 지도 위 마진 5px
- i18n 키 변화 없음
- 판 사이가 좁아진 만큼 판이 넓어진다 — 보관 칸(정사각 · 열 폭 1fr)은 `Now` 45.1px → 46.5px 로 커졌다(ADR-0793 의 여백과 합친 값)
- ⚠ 창 · 판 안쪽의 간격(전투 판 안 나눔 배치의 로그 열 등)은 판 사이가 아니라 손대지 않았다
