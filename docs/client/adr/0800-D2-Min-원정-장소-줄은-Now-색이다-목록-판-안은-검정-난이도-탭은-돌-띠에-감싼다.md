## 결정

`D2 Min` 원정 탭에서

- **장소 줄(`.zone`)의 색은 `Now` 그대로다** — 줄 바탕 · 그림 앞 그라데이션 · 고른 줄 바탕 · 왼쪽 띠 · 올린 줄 테두리가 쓰는 토큰을 줄 안에서만 `Now` 값으로 되돌린다
- **목록 판(`.diff-panel`) 안쪽 바탕은 `Now` 처럼 검정이다** — 돌 테두리는 그대로
- **난이도 탭 줄(`.diff-tabs`)은 도감 탭 줄과 같은 모양이다** — 줄째 돌 테두리 띠로 감싸고, 탭은 버튼처럼 밝은 돌 + 턱, 고른 탭은 턱 대신 강조색 테두리 한 바퀴. 띠와 목록 판 사이는 판 사이 8px
- 장소 줄 사이 간격(8px)은 `Now` 와 같아 손대지 않는다

## 맥락

`D2 Min`(ADR-0791)은 바탕 토큰을 한 단 밝히고 중립 회색 선 토큰을 홈 색으로 바꿨다. 장소 줄은 바탕 · 그림 앞 그라데이션(app.js 인라인)이 `--bg-tertiary` 를 써서 1600×800 에서 `rgb(4,4,4)` → `rgb(22,22,22)` 회색이 됐다. 잠긴 줄은 줄째 반투명(45%)이라 아래 돌 바탕이 비쳐 더 회색이었고, 왼쪽 띠(`--border-secondary`)는 홈 색이 되어 사라졌다. 줄 사이 간격은 두 겹 모두 8px(화면 7.2px)로 같았다. 다만 회색 줄과 어두운 돌 바탕 사이 대비가 없어 틈이 묻혀 좁아 보였다. 난이도 탭은 ADR-0799 에서 돌 탭으로만 바꿔 판 테두리 위에 얹혀 있었다.

## 근거

- **줄에서만 토큰을 되돌리는 이유** — 토큰째 되돌리면 다른 탭의 판 · 카드도 같이 어두워져 시안이 무너진다. 줄은 그림이 깔린 띠라 판 바탕과 따로 논다
- **판 안을 검정으로 두는 이유** — 잠긴 줄의 반투명은 줄째 거는 것이라 줄 바탕만 검게 해도 판 바탕이 비친다. `Now` 판은 투명이라 비치는 것이 검정이다. 판 안을 검정으로 두면 잠긴 줄 · 줄 사이 틈이 `Now` 와 같은 밝기다(실측 — 잠긴 줄 2 대 `Now` 2~3 · 틈 0 대 2)
- **간격을 안 늘리는 이유** — 간격은 이미 `Now` 와 같은 8px 였다. 좁아 보인 것은 색 탓이었고, 색을 되돌리자 틈이 다시 보인다
- **난이도 탭을 띠에 감싸는 이유** — 사용자가 감싸서 테두리를 넣으라고 했다. 같은 시안 안의 판 밖 탭 줄(도감 · 실험실 · 대장간)이 이미 돌 띠 안의 버튼 줄이라(ADR-0799) 같은 말투로 맞춘다. 폴더 탭(고른 탭의 윗변 2px · 솟음 · 판과 이어짐)은 띠 안에서 뜻이 없어 걷는다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절: `.zone` 토큰 넷 · `.panel.diff-panel` 바탕 · 위 여백 8px · `.diff-tabs` 띠 · `.diff-tab` 턱 · 고른 탭
- i18n 키 변화 없음
- ⚠ 줄의 `Now` 회색 값(`#4e4e4e` · `#707070`)은 맨 위 `:root` 의 값을 옮겨 적었다 — `Now` 토큰이 바뀌면 같이 고친다
