## 결정

`D2 Min` 원정 목록 판은 ADR-0802 이전처럼 **내용 높이(챕터 줄 + 장소 줄 다섯)에서 끝나고**, 장소 줄은 `Now` 와 같은 높이(1600×800 에서 98px)다. 챕터 폴더 탭의 생김새(ADR-0802)는 그대로다.

## 맥락

같은 날 ADR-0802 로 목록 판을 박스 아랫변까지 늘리고 장소 줄을 120px 로 키웠다. 사용자가 보고 원래 크기로 되돌리라고 했다.

## 근거

- **크기만 되돌리는 이유** — 같은 요청에 묶였던 둘째 일(챕터 탭 생김새)은 크기와 따로 논다. 되돌림은 크기를 바꾼 묶음(판 세로 흐름 · 줄 나눠 갖기 · 마지막 줄 아래 여백)만 걷는다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 목록 판 묶음(`.main:has(> .diff-panel)` · `.diff-panel` 세로 흐름 · `.zone` 나눠 갖기)을 걷었다
- 판 아래 빈 바탕(약 100px)이 다시 선다
