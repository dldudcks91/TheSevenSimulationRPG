## 결정

`⚙` 설정 탭 `Skin` 줄의 부품 시트 스킨을 **스물(21 ~ 40)** 로 바꾼다 — 버튼 글은 번호이고 이름은 hover 다(`21 Bronze` … `40 Stash`). 부품 시트는 **컨셉 그림 없이 글 지시문만으로** 그린다: 공통 본문(어둡고 깔끔한 디아블로 2 · 장식은 모서리에만 작게) + 스킨마다 한 줄(재질 · 색 · 가르는 법). 한 장에 패널 · 버튼 · 칸 · 면 둘을 같이 그려 부품끼리 결이 맞는다.

[ADR-0797](0797-겉모양-비교에-부품-시트-스킨-넷을-더한다-D2-Min-규칙을-타고-부품과-토큰만-바꾼다.md) 의 나머지는 그대로 산다 — 스물은 `D2 Min` 의 규칙을 그대로 타고(`<html data-skin="d2min" data-skin-parts="<번호>">`) 부품 다섯 장과 토큰만 바꾼다 · 부품 픽셀 모양은 D2 Min 과 같다 · 모서리 장식은 모서리 칸에 들어가는 크기로 줄인다.

## 맥락

- ADR-0797 의 넷은 그날 뽑은 컨셉 스무 장(21 ~ 40 · 캐릭터 탭 페인트오버) 중 넷을 참조로 붙여 시트를 그렸다. 사용자가 넷과 컨셉 스무 장을 모두 지우고(`D2 Min` 만 남긴다) 같은 방식으로 스물을 다시 만들라고 했다
- 컨셉이 없어졌으므로 시트의 기준은 글 지시문뿐이다. 스물의 방향은 컨셉 스무 장에 쓴 「이 장의 변주」 한 줄 그대로다

## 근거

- **번호를 버튼 글로 쓰는 이유** — 버튼 스물둘이 이름으로 서면 설정 판에서 열 줄 넘게 접힌다. 번호는 짧고, 이름은 hover 와 이 ADR 의 표가 든다
- **스킨별 토큰을 스크립트가 찍는 이유** — 스물의 바탕 색 · 턱 줄 색을 손으로 고르면 시트와 어긋난다. 바탕 = 어두운 면 평균을 더 누른 색 · 턱 줄 = 테두리 띠의 밝은 쪽 색 · 밝은 면이 짙은 색(채도 차 40 넘음)이면 상단바 · 버튼을 어두운 면으로 — `cut_skin_parts.py --css`
- **모서리 덩어리를 눈으로 잰 이유** — 판 가운데 색에서 벗어난 깊이로 자동으로 재 봤더니 그늘 · 결까지 잡혀 스물 중 대부분이 상한에 닿았다. 시트 모서리를 4배로 키워 8px 눈금으로 잰 값을 스크립트에 적는다
- **버린 안 — 컨셉을 다시 뽑아 참조로 붙인다** — 사용자가 컨셉 단계를 지웠다. 시트 한 장이 부품끼리의 결을 맞춘다
