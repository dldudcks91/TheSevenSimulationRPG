## 결정

`D2 Min` 원정 챕터 폴더 탭의 글씨는 **`--fs-md`(15px)** 다 — ADR-0807 의 18px 에서 한 단 내린다. 같은 폭 나누기 · 폴더 탭 모양은 그대로다.

## 맥락

같은 날 ADR-0807 로 챕터 탭을 같은 폭으로 나누고 글씨를 18px 로 키웠다. 사용자가 보고 글씨를 줄이라고 했다.

## 근거

- **한 단 내리는 이유** — 글씨 단계 토큰의 바로 아래 단이다. 1600×800 실측 — 한국어 일곱 칸 모두 173px 그대로 · 영어는 「Ch5 Caverns of the Abyss」 한 칸만 177px 이고 나머지는 172px 로, 18px 때보다 같은 폭에 더 가깝다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 원정 챕터 `.btn` 글씨 한 값
- 탭 높이가 그만큼 낮아져 아래 장소 줄이 3px 올라선다
