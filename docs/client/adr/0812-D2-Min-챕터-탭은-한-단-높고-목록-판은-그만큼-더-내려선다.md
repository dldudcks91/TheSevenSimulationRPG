## 결정

`D2 Min` 원정 챕터 탭은 고른 것 · 안 고른 것 모두 **위아래 안쪽 여백을 3px 씩 더 둔다** — 탭 줄 34 → 40. 목록 판 위 여백은 **58** = 난이도 띠 테두리 4 + **틈 10** + 탭 줄 40 + 판 테두리 4 — 판이 탭이 커진 만큼에 더해 6px 더 내려선다. 1600×800 에서 안 고른 탭 25 → 30.5px · 고른 탭 29.6 → 35px · 판 윗변 139 → 149.8 · 위 난이도 띠와 고른 탭 사이 틈 4 → 10px.

## 맥락

같은 날 ADR-0809 · 0811 로 탭 줄을 판 바깥 윗변에 얹고 고른 탭이 위로만 커지게 했다. 사용자가 판을 조금 더 내리고 탭 높이를 조금 더 키우라고 했다.

## 근거

- **위아래를 같이 늘리는 이유** — 글자가 탭 가운데를 지키고, 고른 탭과 안 고른 탭의 아래 여백이 같아 글자 높이가 같다(ADR-0811)
- **틈을 넓히는 이유** — 판이 탭과 붙어 있어 판을 내리면 탭도 내려간다. 「판을 더 내린다」는 위 난이도 띠와 탭 줄 사이가 벌어지는 것으로 읽힌다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 챕터 탭 안쪽 여백 두 줄 · 판 위 여백
- 장소 줄이 그만큼 내려선다(판 아래 빈 바탕이 준다)
