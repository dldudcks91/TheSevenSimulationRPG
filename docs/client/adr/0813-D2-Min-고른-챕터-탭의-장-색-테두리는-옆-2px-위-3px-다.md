## 결정

`D2 Min` 원정 챕터 폴더 탭에서 **고른 장의 장 색 테두리는 옆 2px · 위 3px**(밑변은 그대로 없음)다 — 옆 1 · 위 2 에서 한 단 굵다. 위로 굵어진 1px 만큼 위 안쪽 여백을 줄여 고른 탭 높이가 그대로이고, 일곱 칸 같은 폭도 그대로다(1600×800 한국어 모두 175px).

## 맥락

고른 탭의 표시는 장 색 테두리(렌더러 인라인 · ADR-0801) · 밝은 돌 · 솟음(ADR-0811 · 0812)이다. 사용자가 클릭했을 때 나오는 선을 조금 더 굵게 하라고 했다.

## 근거

- **색은 그대로 두고 두께만** — 테두리 색은 렌더러가 인라인으로 넣는 장 색이다. 두께는 CSS 가 정하므로 색 · 장마다의 차이는 그대로 산다
- **높이를 지키는 이유** — 탭 줄 높이(40)가 목록 판 위 여백(ADR-0812)을 정한다. 높이가 바뀌면 판이 따라 움직인다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 고른 챕터 탭 한 줄(`border-width` · 위 여백)
