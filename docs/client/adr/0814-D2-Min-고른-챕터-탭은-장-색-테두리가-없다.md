## 결정

`D2 Min` 원정 챕터 폴더 탭에서 **고른 장의 탭은 장 색 테두리가 없다.** 고른 표시는 솟음 · 밝은 돌 · 안쪽 턱 줄(세 변) · 장 색 글자가 든다. 걷은 테두리 두께만큼 안쪽 여백을 늘려 고른 탭 높이와 일곱 칸 같은 폭(1600×800 한국어 175px)이 그대로다. `Now` 의 챕터 세그먼트는 그대로 고른 칸에 장 색 테두리가 선다.

## 맥락

고른 탭에는 렌더러가 장 색 테두리를 인라인으로 넣는다(`segmented` · 2026-09-09 「고른 칸은 테두리까지 그 색」). 같은 날 ADR-0813 으로 그 테두리를 옆 2 · 위 3px 로 굵혔다가, 사용자가 폴더 탭의 그 선 자체를 없애라고 했다.

## 근거

- **두께로 걷는 이유** — 색은 인라인이라 CSS 로 덮으려면 `!important` 가 든다. 두께를 0 으로 하면 색은 그대로 남되 그려지지 않는다
- **고른 표시가 남는 이유** — 폴더 탭은 솟음 자체가 고른 표시다. 밝은 돌 · 안쪽 턱 줄이 위 난이도 줄의 고른 버튼과 같은 말투로 남는다. 장 색은 글자가 든다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 고른 챕터 탭 한 줄(`border-width: 0` · 안쪽 여백)
- 렌더러 · i18n 변화 없음 — 인라인 테두리 색은 그대로 들어오고 그려지지만 않는다
