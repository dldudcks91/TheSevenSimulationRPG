## 결정

`D2 Min`(과 그 규칙을 타는 부품 시트 스킨 — ADR-0797)에서 편성 탭의 박스(`.pt-body`)는 판을 걷고, 안의 셋이 **각자 돌 테두리 판**이 된다 — 진형 · 물약(왼쪽 열 위아래) · 파티 전술(오른쪽 열). 맨 위 편성 고르개는 판 밖 탭 줄(ADR-0799)처럼 **돌 테두리 띠** 안에 선다. 판 사이는 모두 8px(ADR-0795)이고 두 열 사이 세로 가림선은 없다. 소제목 띠는 패널 제목처럼 테두리 안쪽 끝까지 넓다. 물약 판이 왼쪽 열의 남는 세로를 받아 아랫변이 파티 전술 판과 맞는다. 판 바깥 끝은 옛 박스의 테두리 바깥 끝과 같다.

## 맥락

§15 의 편성 박스는 판 하나 안에 편성 고르개 · 진형 · 물약 · 파티 전술이 있고, 두 열 사이를 회색 세로 가림선 하나가 가른다(ADR-0260). `D2 Min` 은 중립 회색 선을 토큰째 홈 색으로 바꿔(ADR-0791) 그 선이 `#0a0a0a` 가 됐는데, 판 바탕 돌 결도 그만큼 어두워 1600×800 에서 선이 사실상 안 보였다. 넷이 한 돌판 위에서 제목 띠로만 갈렸다. 같은 화면에 CSS 만 넣은 시안 둘(A 판 나누기 · B 판은 하나로 두고 셋을 판에 파인 홈으로)을 찍어 견줬고 사용자가 A 를 골랐다.

## 근거

- **판으로 가르는 이유** — 이 시안의 말투가 「선 대신 면」이고, 판 사이 8px · 판 밖 탭 줄 = 돌 띠가 이미 서 있다. 같은 부품 · 같은 틈으로 가르면 새 모양이 안 는다
- **버린 안 — 홈 파기(B)** — 판은 하나로 두고 셋을 전장처럼 판에 파인 홈으로 만든다. 갈림은 생기지만 A 보다 약했다
- **물약 판이 남는 세로를 받는 이유** — 두 열의 아랫변을 맞춰 판 셋이 한 장 끝까지 선다(ADR-0793). 물약 판 안 아래가 비는 것은 받아들였다
- **진형 모양 버튼 열의 위아래 빈자리(ADR-0577)** — 기준이 「끝 버튼 ↔ 물약 이름」이었는데 물약이 다른 판으로 나가, 「끝 버튼 ↔ 진형 판 안쪽 아랫변」으로 맞춘다
- **§15 를 대체하지 않는다** — 비교 시안이라 규격(박스 하나 · 세로 가림선 · ADR-0260)을 뒤집지 않는다(ADR-0791 과 같다). 채택하면 그때 0260 을 대체할지 정한다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 편성 탭 묶음(`.pt-body` 판 걷기 · `.pt-pick` 띠 · `.fm-box` · `.pt-potion` · `.pt-tactics` 판 · 간격 · 소제목 띠 · `--pt-left-gap`)
- i18n 키 · 렌더러 변화 없음
- 판 안쪽 여백만큼 칸이 줄어 파티 전술 판의 행 폭이 조금 좁다
