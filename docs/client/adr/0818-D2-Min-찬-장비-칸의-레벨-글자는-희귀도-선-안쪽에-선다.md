# ADR-0818 — `D2 Min` 찬 장비 칸의 레벨 글자는 희귀도 선 안쪽에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「각 아이템에 들어가있는 레벨 위치가 지금 너무 바깥으로 나와있거든? 등급선안쪽으로 들어가도록 위치 조절」) |
| **대체** | ADR-0816 파급의 「구석 글자는 칸 끝 쪽으로 1px 옮겨 선다」 중 레벨 글자 |
| **대체됨** | — |

## 결정

`D2 Min` 에서 아이템이 든 장비 칸(ADR-0816 과 같은 칸 — 가방 · 창고 · 페이퍼돌 · 분해함 · 상점 · 드롭 · 실험실 기록)의 **레벨 글자(`Lv.n`)는 희귀도 선 안쪽**에 선다 — 선의 안쪽 끝에서 기본 여백(오른쪽 3px · 아래 2px)만큼 떨어진다. 강화 글자(`+n`) · 재료 · 스킬북 칸의 개수 글자는 그대로다.

## 맥락

ADR-0816 이 희귀도 선을 칸 바깥 끝에 붙이며 칸 테두리 두께를 0 으로 했다. 레벨 글자는 칸 안쪽 끝에서 오른쪽 3px · 아래 2px 자리라, 칸 안쪽이 칸 끝까지 넓어지자 글자가 바깥으로 1px 나와 선(굵기 약 2px)에 걸쳤다.

## 근거

- **기본 여백을 선 기준으로 옮긴다** — `Now` 에서 레벨 글자는 칸 테두리 안쪽 끝에서 오른쪽 3px · 아래 2px 였다. 같은 여백을 이제 테두리 대신 선 안쪽 끝에서 잰다 — 새 값을 고르지 않는다
- **선 굵기만큼 비율로 들인다** — 선 굵기는 칸의 1.92/47 이라(ADR-0816) 칸 크기가 달라도 글자가 늘 선 안쪽이다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 한 규칙(`.inv-lv` · `.pd-lv` 의 `right` · `bottom`) · 렌더러 · i18n 변화 없음
- 측정(1600×800 · 배율 1) — 칸 끝에서 글자 상자까지 페이퍼돌 칸 오른쪽 4.9 · 아래 4.0px · 가방 칸 4.6 · 3.7px(선 굵기 2.2 · 1.9px)
- 강화 글자(`+n` · 오른쪽 위)는 아직 선에 걸칠 수 있다
