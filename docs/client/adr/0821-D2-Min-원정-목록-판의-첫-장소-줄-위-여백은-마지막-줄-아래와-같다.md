# ADR-0821 — `D2 Min` 원정 목록 판의 첫 장소 줄 위 여백은 마지막 줄 아래와 같다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「그아래 박스의 맨 위 스테이지와 박스상단의 거리가 너무 가까움 거리좀 넓혀봐」) |
| **대체** | — |
| **대체됨** | — |

## 결정

`D2 Min` 원정 목록 판(`.diff-panel`)의 **위 안쪽 여백은 19px** 다 — 아래(마지막 장소 줄 마진 8 + 판 아래 여백 11)와 같다. 1600×800 에서 돌 테두리 안쪽 끝 ↔ 첫 장소 줄 11.8px · 마지막 줄 ↔ 테두리 안쪽 끝 11.8px 로 위아래가 같다(전에는 위 3.7px).

## 맥락

같은 날 ADR-0809 로 챕터 탭 줄을 판 밖으로 옮겨 판 안 맨 위가 첫 장소 줄이 됐다. 판 위 안쪽 여백은 패널 기본값(10px)이라 돌 테두리 띠(안으로 7px)를 빼면 첫 줄이 테두리에 붙어 보였다. 사용자가 맨 위 스테이지와 박스 위 사이를 넓히라고 했다.

## 근거

- **아래와 같게 하는 이유** — 판 안의 위아래 숨이 같아야 줄 다섯이 판 가운데에 선다. 아래는 이미 마지막 줄 마진과 판 여백이 만든 값이라 그것에 맞춘다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 `.panel.diff-panel` 위 안쪽 여백
- 목록 판이 9px 길어진다(판 아래 빈 바탕이 준다)
