## 결정

`D2 Min` 원정 난이도 탭 줄(노말 · 나이트메어 · 헬)에서 **고른 탭은 빨간(강조색) 테두리가 없다.** 고른 표시는 흰 글씨 · 안쪽 턱 줄(밝은 돌)이 든다 — 안 고른 탭은 회색 글씨 · 버튼 턱이다. 테두리 자리 1px 는 투명으로 남아 탭 크기가 그대로다. `Now` 의 폴더 탭은 그대로 윗변 강조색이다.

## 맥락

같은 날 ADR-0800 으로 난이도 탭 줄을 도감 탭 줄과 같은 돌 띠로 감싸며 고른 탭을 강조색 테두리 한 바퀴로 표시했다. 바로 아래 챕터 탭은 ADR-0814 · 0817 로 장 색 테두리를 걷고 솟음으로만 고른 표시를 하게 됐다. 사용자가 위 난이도 탭도 고를 때의 빨간 선을 없애라고 했다.

## 근거

- **흰 글씨 · 안쪽 턱 줄로 남기는 이유** — 난이도 탭은 띠 안의 버튼 줄이라 솟을 자리가 없다. 기본 규칙의 고른 글씨(흰색)와 시안의 고른 버튼 안쪽 턱 줄이 이미 있어 그 둘이 표시를 든다
- **테두리 자리를 투명으로 두는 이유** — 1px 를 걷으면 고를 때마다 탭 크기가 바뀐다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 `.diff-tab.on` 한 값(테두리 색)
- ⚠ 시안의 다른 고른 버튼(도감 · 실험실 · 대장간 탭 줄 · 세그먼트)은 그대로 강조색 테두리다 — 맞출지는 열려 있다
