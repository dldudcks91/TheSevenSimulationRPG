# ADR-0825 — `D2 Min` 원정 챕터 탭 글씨는 14px 다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「폴더 글씨를 조금씩 줄여봐 2px씩만」 → 13px 를 보고 「14px로 다시」) |
| **대체** | [ADR-0808](0808-D2-Min-원정-챕터-탭-글씨는-fs-md-다.md) — 글씨 `--fs-md`(15px) |
| **대체됨** | — |

## 결정

`D2 Min` 원정 챕터 폴더 탭의 글씨는 **14px** · 굵게다 — 15px 에서 1px 내린다. 글씨 단계 토큰(`--fs-sm` 13 · `--fs-md` 15) 사이라 값을 바로 적는다. 탭 모양 · 같은 폭 · 솟음 · 판 위 여백은 그대로다. 1600×800 에서 안 고른 탭 30.5 → 29.5px · 고른 탭 41.3 → 40.3px · 일곱 칸은 한국어 · 영어 모두 175px 로 같은 폭이다(영어 「Ch5 Caverns of the Abyss」 도 같은 폭에 든다).

## 맥락

같은 날 ADR-0808 로 챕터 탭 글씨를 15px 로 정했다. 사용자가 2px 줄이라고 해 13px 로 보였더니, 14px 로 다시 하라고 했다.

## 근거

- **토큰 밖 값을 쓰는 이유** — 사용자가 고른 크기가 토큰 두 단 사이다. 비교 시안 절 안의 값이라 토큰을 새로 세우지 않는다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 챕터 탭 글씨 한 값
- 탭이 1px 낮아져 위 난이도 띠와 고른 탭 사이 틈이 1px 넓어진다(판 위 여백 64 는 그대로)
