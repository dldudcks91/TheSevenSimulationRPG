# ADR-0826 — `D2 Min` 고른 챕터 탭은 10px 솟는다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「선택된 폴더 올라가는거 약간만 줄여줘 높이」) |
| **대체** | [ADR-0819](0819-D2-Min-고른-챕터-탭은-12px-솟는다-목록-판은-그만큼-더-내려선다.md) 일부 — 「12px 솟는다 · 글자 6px 오른다」. 판 위 여백 64 는 산다 |
| **대체됨** | — |

## 결정

`D2 Min` 원정 챕터 폴더 탭에서 고른 장의 탭은 안 고른 탭보다 **10px 높다**(위아래 안쪽 여백을 5px 씩 더 둔다 · 글자는 가운데를 따라 5px 오른다). 같은 모양 · 같은 폭 · 아랫변 선반 · 목록 판 위치(판 위 여백 64)는 그대로이고, 줄어든 높이만큼 위 난이도 띠와의 틈이 넓어진다. 1600×800 · 글씨 14px(ADR-0825)에서 안 고른 탭 29.5px · 고른 탭 38.5px(차이 10.8 → 9px).

## 맥락

같은 날 ADR-0819 로 고른 탭의 솟음을 6 → 12px 로 키웠다. 사용자가 올라가는 높이를 조금만 줄이라고 했다.

## 근거

- **10 인 이유** — 「약간」 — 솟음 하나가 고른 표시라(ADR-0817) 한눈에 읽히는 차이는 남기고 한 단만 내린다
- **판을 안 움직이는 이유** — 요청이 탭 높이 하나였다. 판 위치는 ADR-0812 · 0819 에서 사용자가 정한 자리다
