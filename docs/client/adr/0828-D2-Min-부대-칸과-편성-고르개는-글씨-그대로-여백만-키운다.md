# ADR-0828 — `D2 Min` 부대 칸과 편성 고르개는 글씨 그대로 · 여백만 키운다

## 결정

`D2 Min`(과 그 규칙을 타는 부품 시트 스킨 — ADR-0797)에서 상단바 부대 칸과 편성 탭의 편성 고르개는 **글씨를 작은 버튼 그대로**(`--fs-sm` · 보통 굵기) 두고 **여백만** 키운다 — 부대 칸은 위아래 6px · 좌우 18px, 편성 고르개는 위아래 9px · 좌우 24px.

## 맥락

ADR-0824 는 두 버튼을 키우며 글씨도 한 단 키우고 굵게 했다(부대 칸 높이 23 → 28px · 편성 고르개 21 → 32px). 사용자가 글씨 크기는 그대로 두라고 했다 — 요청은 버튼 크기였다.

## 근거

- **버튼 크기는 여백으로 낸다** — 글씨가 그대로여도 높이는 0824 와 거의 같다(1600×800 에서 부대 칸 29px — 상단바 틀 안쪽 30px 안 · 편성 고르개 32px)
- **굵기도 되돌린다** — 굵게는 요청에 없던 글씨 변경이다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 두 줄(`.tab-seg .btn.sm.seg-party` · `.pt-body > .pt-pick .btn.sm`)에서 글씨 크기 · 굵기를 걷고 여백만 남긴다
- i18n 키 · 렌더러 변화 없음
