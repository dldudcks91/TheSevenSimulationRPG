# ADR-0831 — `D2 Min` 게임 화면 상단바 줄은 62px 다 · 탐험 지도 판의 위아래 여백이 좌우와 같다

## 결정

`D2 Min`(과 그 규칙을 타는 부품 시트 스킨 — ADR-0797)에서 게임 화면의 **상단바 줄(브랜드 · 상단바)을 48px 에서 62px 로** 높인다. 높인 만큼 메인이 짧아지고, 그 세로는 **남는 세로를 받는 판**(가운데 줄 · 관전 전장 · 탐험 지도 판 · 박스)이 나눠 낸다. 영웅 띠 · 창고 · 인벤토리 줄은 내용 높이라 그대로다. 게임 밖 화면(메뉴 · 새 게임 · 프롤로그)은 48px 그대로다.

## 맥락

탐험 지도는 비율이 정해진 그림이라 지도 판(ADR-0799) 안에서 폭에 맞춰 서고, 남는 세로가 위아래 여백이 된다. 1600×800 에서 좌우 여백은 7.3px, 위아래는 14.2px 였다. 사용자가 상단바를 그 차이만큼만 높이라고 했다. 같은 날 상단바 부대 칸을 29px 로 키웠다(ADR-0824 · 0828).

## 근거

- **62px 인 이유** — 위아래 여백의 남는 몫이 (14.2 − 7.3) × 2 ≈ 14px 다. 상단바는 메인 배율(.9) 밖이라 화면 px 그대로 더한다. 62px 에서 지도 판 여백은 좌우 7.5 · 위아래 7.3px 이다
- **따로 줄이는 자리를 안 만드는 이유** — 사용자 조건이 「아이템 · 창고 · 캐릭터 라인 그대로 · 다른 곳에서 약간씩」이었다. 화면 짜임이 이미 그렇다 — 영웅 띠(129px)와 창고 · 인벤토리 줄(196.5px)은 내용 높이고 그 사이 판이 `1fr` · `fill` 이라 저절로 14px 씩 준다(캐릭터 · 상점 · 대장간 가운데 줄 405 → 391px · 관전 전장 480.6 → 466.6px · 도서관 · 리포트 판도 같은 몫). 화면 열여덟을 열어 재니 새로 넘치거나 스크롤이 생긴 판이 없었다
- **게임 밖 화면을 빼는 이유** — 그 화면의 자리는 그대로 둔다(ADR-0793 · 새 게임 카드 자리 — ADR-0799)

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 한 줄(`#app:not(.pregame)` 의 `grid-template-rows`)
- i18n 키 · 렌더러 변화 없음
- 왼쪽 탭 열도 14px 짧다(맨 아래 「새 게임」까지 든다)
- ⚠ 게임 밖 화면과 게임 화면의 상단바 높이가 다르다 — 메뉴에서 게임으로 넘어가면 상단바가 14px 커진다
