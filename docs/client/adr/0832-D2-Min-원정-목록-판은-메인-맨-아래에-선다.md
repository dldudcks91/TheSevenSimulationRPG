## 결정

`D2 Min` 원정 탭에서 **목록 판(`.diff-panel` · 위에 얹힌 챕터 탭째)은 메인의 맨 아래에 선다** — 판 돌 테두리의 아랫변이 다른 탭의 맨 아래 판(탐험 지도 판 등)과 같은 줄이다. 판 높이는 내용 그대로(ADR-0803)이고 옮기기만 한다. 난이도 탭 줄은 메인 맨 위에 남고, 남는 세로는 **난이도 줄과 챕터 탭 사이 틈**이 받는다. 판 위 여백 64 는 그 틈의 최소다 — 내용이 메인보다 길면 틈은 64 로 줄고 메인이 그대로 스크롤된다. 1600×900 판에서 판 아랫변이 탐험 지도 판 아랫변과 같은 자리(1600×800 화면 796.4)다.

## 맥락

같은 날 ADR-0830 으로 난이도 줄의 띠를 걷자 줄과 판이 띠 높이만큼 올라서, 판 아래에 빈 바탕이 더 넓어졌다. 판을 박스 아랫변까지 늘리는 안은 ADR-0802 에서 해 보고 ADR-0803 으로 되돌렸다. 사용자가 이번엔 늘리지 말고 옮겨서 아랫변을 맨 아래에 맞추라고 했다.

## 근거

- **옮기기만 하는 이유** — 사용자가 「이동시켜서」라고 했다. 판 높이 · 장소 줄 높이는 ADR-0803 이 되돌린 값이다
- **챕터 탭째 옮기는 이유** — 챕터 탭은 판 바깥 윗변에 얹힌 판의 일부다(ADR-0809). 판만 내리면 탭과 판이 떨어진다
- **난이도 줄은 위에 두는 이유** — 요청은 챕터 박스였다. 난이도 줄을 같이 내릴지는 열려 있다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 — 목록 판이 선 메인을 세로 flex 로 · 난이도 줄 아래 여백 `auto`
- 1600×900 판에서 난이도 줄 ↔ 챕터 탭 틈이 약 100px 로 넓어진다
