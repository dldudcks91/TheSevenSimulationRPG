## 결정

`D2 Min` 원정 목록 판(`.diff-panel` · 위에 얹힌 챕터 탭째)은 메인 맨 아래로 가지 않고 **난이도 줄 아래 제자리에 선다.** 판 위 여백은 **64 → 88** — 띠를 걷은 뒤 자리보다 판째 24 내려선다. 판 높이 · 챕터 탭 · 난이도 줄은 그대로이고, 늘어난 24 는 난이도 줄과 챕터 탭 사이 틈이 받는다. 1600×800 화면에서 판 윗변 157 → 176.2 · 판 아랫변 731.6(맨 아래 796.4 까지 64.8 남는다).

## 맥락

같은 날 ADR-0832 로 목록 판을 메인 맨 아래로 옮기자 판이 약 105(화면 84px) 내려가 난이도 줄과 챕터 탭 사이가 그만큼 벌었다. 사용자가 다시 올리되 약간만 내리고 맨 아래까지는 내리지 말라고 했다.

## 근거

- **24 인 이유** — 「약간」 — 맨 아래까지 내려갔던 거리(약 105)의 1/4 쯤이다
- **판 위 여백으로 내리는 이유** — 판 위 여백이 이미 난이도 줄 ↔ 판 사이를 정하는 값이다(ADR-0812 · 0819). 맨 아래 정렬(세로 flex)은 걷는다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 `.panel.diff-panel` 위 여백 한 값 · ADR-0832 의 세로 flex 두 줄 삭제
- 판 아래 빈 바탕이 맨 아래 정렬 전보다 24 준다
