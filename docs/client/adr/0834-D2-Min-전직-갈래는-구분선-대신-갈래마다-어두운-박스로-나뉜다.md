# ADR-0834 — `D2 Min` 전직 갈래는 구분선 대신 갈래마다 어두운 박스로 나뉜다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) · §17 |
| **정한 사람** | 사용자 지시 (「d2 min 전직칸에서 각 전직 사이를 선으로 구분하지말고 각전직 뒤에 어두운 네모박스를 넣어서 구분하는걸로해볼까?」) |
| **대체** | — |
| **대체됨** | — |

## 결정

`D2 Min`(과 그 규칙을 타는 부품 시트 스킨 — ADR-0797)에서 도서관 전직 패널의 갈래 셋(`.tr-adv-branch`)은 위 구분선을 걷고 **갈래마다 어두운 네모 박스**를 깐다 — 판보다 어두운 바탕 · 안쪽 그늘 · 아래 밝은 한 줄(판에 파인 홈)이다. 박스 사이는 8px 다. 고른 갈래(파랑) · 전직한 갈래(주황)의 안쪽 테두리는 그대로 박스 위에 선다. 고를 수 있는 갈래에 올리면 박스가 한 단 덜 어둡다.

## 맥락

`Now` 의 갈래는 테두리 · 바탕 없이 갈래마다 위에 가로 구분선 하나로 나뉜다(ADR-0783 · 0784). `D2 Min` 은 그 선이 홈 색이 되어(ADR-0791) 돌 결 위의 가는 어두운 줄로 남았다. 사용자가 이 시안에서는 선 대신 박스로 가르자고 했다.

## 근거

- **박스 모양** — 이 시안은 「선 대신 면」이고, 판 안에서 칸을 가르는 면은 「판에 파인 홈」(전장 · ADR-0791)이 이미 쓰는 말투다. 돌 테두리 판을 판 안에 또 두르면 패널과 같은 무게가 돼 겹겹이 무거워진다
- **사이 8px** — 판 사이와 같은 값이다(ADR-0795). 박스 셋이 남는 세로를 나눠 갖는 짜임(ADR-0607)은 그대로라 갈래 카드가 1600×800 에서 145 → 140px 로 줄 뿐 넘치지 않는다
- **올린 바탕을 따로 거는 이유** — `Now` 의 올린 바탕(`--surface-5`)은 박스 바탕과 거의 같은 검정이라 올려도 안 갈렸다
- **§17 을 대체하지 않는다** — 비교 시안이라 `Now` 의 구분선(ADR-0783)을 뒤집지 않는다(ADR-0791 과 같다). 채택하면 그때 0783 을 대체할지 정한다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 전직 갈래 묶음(`.tr-adv-row` 사이 · `.tr-adv-branch` 박스 · 올린 바탕)
- i18n 키 · 렌더러 변화 없음
