# ADR-0836 — `D2 Min` 왼쪽 탭 열은 탭 사이 구분선이 없다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「d2-min에서 왼쪽 메뉴탭 사이사이 검정색선으로 구분해놓은거 없애봐 모두」) |
| **대체** | ADR-0791 의 「탭 열 — 탭마다 아래 홈 줄」 |
| **대체됨** | — |

## 결정

`D2 Min` 의 왼쪽 탭 열에서 **탭 사이를 가르는 선을 모두 걷는다** — 탭마다 아래에 그은 홈 줄(검은 줄 1px + 그 아래 옅은 밝은 줄)과 「새 게임」 위의 검은 줄. 탭 자리 · 간격 · 묶음 머리(전투 · 마을 · 기타)와 그 윗여백, 고른 탭의 밝은 돌판 + 턱 + 왼쪽 빨간 띠, 탭 열의 두 겹 돌 테두리는 그대로다.

## 맥락

ADR-0791 은 탭 열을 어두운 돌 결로 칠하고 탭마다 아래에 홈 줄을 그어 탭을 갈랐다. 「새 게임」 위의 줄은 기본 규칙(`.nav .b-newgame` 윗변)이 `D2 Min` 의 홈 색 토큰(`--border-dark`)을 타서 검은 줄로 보였다.

## 근거

- **「모두」** — 요청이 탭 사이의 검은 구분선 전부였다. 「새 게임」 위 줄도 같은 모양의 검은 줄이라 함께 걷는다. 고른 탭의 판 테두리는 고른 표시라 구분선이 아니다
- **묶음은 여백이 가른다** — 탭 묶음 사이는 원래 묶음 머리와 그 윗여백이 가른다(ADR-0554). 탭 하나하나는 줄 없이도 글자 줄로 읽힌다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 탭 규칙(`box-shadow` 를 걷는다) · 「새 게임」 윗변을 투명하게(두께 1px 는 남아 자리가 그대로) · `Now` 와 스킨 키트 아닌 화면은 그대로 · 렌더러 · i18n 변화 없음
- 스킨 키트(`data-skin-parts`)도 `D2 Min` 의 탭 규칙을 타므로 같이 줄이 없어진다
