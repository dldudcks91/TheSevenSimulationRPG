## 결정

`D2 Min` 원정 난이도 줄은 **「노말 › 나이트메어 › 헬」 글자만 선 단계 화살표**다.

- 탭은 바탕 · 턱 · 테두리 없이 글자만 선다
- **고른 단은 20px 밝은 흰 글씨**, 나머지는 **14px 어두운 회색 글씨**다. 잠긴 단은 자물쇠 + 흐림(기본 규칙 그대로)
- 탭 사이 틈이 **화살표 `›`**(어두운 회색)를 든다
- 마우스를 올리면 안 고른 단의 글씨가 밝아진다
- 다음 단 조건 글자 · `Report` 자리는 그대로다
- 줄 높이는 옛 버튼 줄 높이(35)를 지켜 아래 목록 판 위치(ADR-0833)가 그대로다

## 맥락

같은 날 ADR-0830 으로 난이도 줄의 띠를 걷고, 줄을 어떻게 보일지 시안 셋(1 단계 화살표 · 2 큰 이름 + ▾ · 3 해골 개수)을 화면에 얹어 보였다. 버튼 셋은 장 · 칸 · 레벨을 다 정하는 단을 아래 챕터 탭보다 작게 보이고, 차례로 여는 단계를 대등한 필터처럼 보였다. 사용자가 1번을 골랐다.

## 근거

- **글자만 두는 이유** — 지금 단 · 순서 · 다음 잠금과 그 조건이 한 줄 글로 읽힌다
- **고른 단을 20px 로 키우는 이유** — 단이 챕터(14px)보다 큰 단위라 더 크게 보인다
- **줄 높이를 지키는 이유** — 판 위치는 바로 앞에 사용자가 정한 자리다(ADR-0833)

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 `.diff-tab` · `.diff-tab.on` · 탭 사이 틈 화살표 · 줄 최소 높이
- 부품 시트 스킨(D2 Min 규칙을 탄다 · ADR-0820)도 같은 모양이 된다
- i18n 키 변화 없음 — 화살표는 CSS 글자다
