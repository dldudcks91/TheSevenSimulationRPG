# ADR-0840 — `D2 Min` 스킬이 든 액티브 스킬 칸은 칸 그림의 회색 네모를 지운다

## 결정

`D2 Min` 에서 **스킬 그림이 든 액티브 스킬 칸**(`.sk-card` — 캐릭터 탭 「액티브 스킬」 · 도서관 「지금 가진 스킬」)은 빈 칸 그림을 걷어 **회색 네모가 안 보인다** — 바탕은 그림 안쪽과 같은 어두운 한 색. 무기가 안 맞아 흑백으로 꺼진 칸도 그림이 든 칸이라 같다. 빈 칸 · 자물쇠 칸은 회색 네모 그대로다. 관전 카드의 스킬 칸(`.cd-slot`) · 창고 스킬북 탭 칸은 그대로다.

## 맥락

ADR-0810 이 아이템이 든 장비 칸에서 회색 네모를 지웠다. 액티브 스킬 칸도 같은 빈 칸 그림을 깔아(ADR-0791) 그림이 든 칸에서 아이콘 둘레로 회색 네모가 보였다.

## 근거

- **아이템 칸과 같은 문법** — 그림이 든 칸은 네모가 없고, 빈 칸은 네모가 「여기 들어간다」를 말한다. 스킬 칸은 희귀도가 없어 그 자리에 다른 선을 두지 않는다
- **요청 범위** — 「스킬창」은 캐릭터 탭 액티브 스킬 칸(같은 칸을 쓰는 도서관 목록 포함)으로 읽었다. 관전 카드 스킬 칸 · 창고 스킬북 칸은 같은 회색 네모를 갖지만 요청 밖이라 그대로 둔다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 한 규칙(`.sk-card:not(.vacant)` 의 칸 그림을 걷는다) · 렌더러 · i18n 변화 없음
- 칸 가장자리의 1px 테두리는 홈 색(`--border-dark` — 바탕과 거의 같은 검정)이라 안 보인다
- 스킨 키트도 `D2 Min` 규칙을 타 같은 칸에서 칸 그림이 걷힌다
