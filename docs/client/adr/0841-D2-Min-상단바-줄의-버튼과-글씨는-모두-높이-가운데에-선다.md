# ADR-0841 — `D2 Min` 상단바 줄의 버튼과 글씨는 모두 높이 가운데에 선다

## 결정

`D2 Min`(과 그 규칙을 타는 부품 시트 스킨 — ADR-0797)의 게임 화면에서 상단바 줄(브랜드 · 상단바)의 버튼 · 글씨는 모두 **줄의 높이 가운데**에 선다 — 부대 칸 · 우편 · 언어 · Admin · 설정 버튼, 「골드」 · 「원정 플레이 시간」 글씨, 브랜드 워드마크. 버튼 높이는 그대로다.

## 맥락

상단바를 62px 로 높인 뒤(ADR-0831) 1600×800 에서 재면 「골드 600」 · 「원정 플레이 시간」 글씨가 줄 가운데보다 6px 위에 떠 있었다. 오른쪽 자원 줄이 버튼(30px)에 맞춰 늘어나고 글씨 칸은 그 위쪽에 붙어 섰기 때문이다. 버튼은 0.5px 위였다 — 상단바 아래 테두리 1px 만큼 내용 칸이 위로 치우쳤다. 브랜드 워드마크는 대문자뿐인 장르 글꼴이라 글자 칸 가운데보다 글자가 2.5px 위로 보였다.

## 근거

- **자원 줄 글씨 칸만 가운데로 세우는 이유** — 줄째 가운데로 세우면 늘어나 있던 언어 · 설정 버튼이 제 높이(23 · 25px)로 줄어든다. 글씨 칸만 세우고 줄 높이를 버튼 글씨와 같게 두면 글씨가 버튼 안 글씨와 같은 줄에 선다
- **위 여백 1px** — 아래 테두리 1px 와 맞서 내용 칸 가운데가 돌 틀 가운데와 같아진다
- **브랜드 위 여백 5px** — 대문자 글자가 실제로 보이는 높이의 가운데를 줄 가운데에 맞춘다(글자 칸 기준이 아니다)
- **게임 밖 화면을 빼는 이유** — 그 화면은 상단바 높이 48px 그대로다(ADR-0831)

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 상단바 줄 묶음 세 줄(상단바 위 여백 · 자원 줄 글씨 칸 · 브랜드 위 여백)
- i18n 키 · 렌더러 변화 없음
- 측정(1600×800) — 버튼 · 글씨 칸의 가운데가 줄 가운데와 0px 차이 · 보이는 글자는 0.5px 안
