# ADR-0844 — `D2 Min` 스킬 그림 칸의 그림 크기는 `Now` 와 같다 · 회색 네모만 없다

| | |
|---|---|
| **상태** | 확정 · 2026-10-26 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「지금 now랑 똑같은크기로 나오도록 약간만 작게해줄수있나? 스킬 아이콘을」) |
| **대체** | ADR-0843 의 「그림이 칸을 꽉 채운다(여백 · 테두리 0)」 |
| **대체됨** | — |

## 결정

`D2 Min` 에서 스킬 그림이 든 칸 셋(액티브 스킬 — 캐릭터 탭 · 도서관 / 관전 카드 스킬 / 창고 스킬북)의 **그림 크기는 `Now` 와 같다** — 칸 안쪽 여백 · 테두리 · 그림 칸 크기를 `Now` 값 그대로 둔다. **회색 네모(빈 칸 그림)는 없는 채**다(ADR-0840 · 0843).

## 맥락

ADR-0843 이 세 칸의 여백 · 테두리를 0 으로 해 그림이 칸을 꽉 채웠다(1600×800 배율 적용 전 — 액티브 52 · 관전 40 · 스킬북 52px). `Now` 는 액티브 44 · 관전 38 · 스킬북 40px 이다.

## 근거

- **`Now` 값으로 되돌린다** — 「`Now` 랑 똑같은 크기」가 기준이라 새 크기를 고르지 않고 여백 · 테두리 · 그림 칸을 `Now` 규칙 그대로 둔다
- **테두리가 돌아와도 줄로 안 보인다** — `D2 Min` 에서 칸 테두리는 홈 색(`--border-dark` — 바탕과 거의 같은 검정)이라 회색 네모를 지운 것은 그대로 읽힌다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 스킬 칸 규칙에서 여백 · 테두리 0 과 스킬북 그림 칸 100% 를 걷는다(칸 그림을 걷는 줄만 남는다) · 렌더러 · i18n 변화 없음
- 관전 칸의 발동 · 정신 집중 때 그림이 1px 안으로 드는 일(ADR-0843)도 없어진다 — 테두리 두께가 늘 같다
