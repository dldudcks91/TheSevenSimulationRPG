## 결정

`⚙` 설정 탭 `Skin` 줄은 **`Now` · `D2 Min` 둘**로 돌아간다. D2 Min 위에 부품만 갈아 끼우던 스킨 키트(ADR-0797 · 0805 · 0820 · 0829 · 0835 의 갈래)를 모두 걷는다 — 키트 부품 · 키트 시트 · 자르는 스크립트(`cut_skin_kits.py`) · style.css 「스킨 키트」 절 · devcompare.js 의 키트 목록 · `data-skin-parts`. `D2 Min`(ADR-0791 과 그 뒤 D2 Min 결정들)은 그대로다.

## 맥락

- 그날 같은 자리에서 다섯 판을 만들고 지웠다 — 컨셉에서 자른 넷(ADR-0797) · 글 지시문 스물(0805) · 키트마다 제 모양 스물(0820) · D2 Min 결을 더 검게 · 붉게 열(0829) · 주제 한 줄로 지어낸 스물(0835). 사용자가 마지막 판까지 지우고 D2 Min 만 남기라고 했다

## 근거

- **틀을 남기지 않는 이유** — 키트가 하나도 없는데 `data-skin-parts` 분기 · 키트 절 · 자르는 스크립트를 두면 읽히지 않는 코드다. 다시 만들 때는 이 ADR 들(특히 0820 의 배율 0.5 · 부품 여섯 장 · 밝기 상한)과 git 이력에서 되살린다
- 다른 세션의 D2 Min 규칙이 `:not([data-skin-parts])` 로 키트를 빼던 자리는 그대로 둔다 — 속성이 없으면 늘 참이라 D2 Min 동작이 같다

## 파급

- `src/ui/style.css` — 맨 끝 「겉모양 비교 — 스킨 키트」 절을 걷었다
