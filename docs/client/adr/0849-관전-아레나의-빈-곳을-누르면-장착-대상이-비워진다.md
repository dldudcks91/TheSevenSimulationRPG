# ADR-0849 — 관전 아레나의 빈 곳을 누르면 장착 대상이 비워진다

## 결정

원정 관전에서 **아레나의 빈 곳**(카드 · 버튼 · 물약 칸 · 결과 띠 밖)을 누르면 **장착 대상이 비워진다** — 고른 영웅 카드의 파란 겉 테두리가 걷히고, 영웅 카드를 다시 누를 때까지 아래 보관 칸은 아무 영웅도 향하지 않는다.

- 칸 클릭 = 아무 일도 없다(장착 안 함) · `Ctrl`+클릭 · 끌어 놓기(반대편으로 옮기기)는 그대로다
- 칸 툴팁 = 비교 · 착용 델타 없이 그 아이템 카드 한 장 · 요구 레벨 미달 빨간 배지 없음
- 우클릭 메뉴 = [잠금] 하나 · 상자 칸은 메뉴가 안 선다(상자는 보고 있는 영웅에게 맞춰 까진다 · ADR-0742)
- [자동 장착] = 꺼진 버튼
- 비운 상태는 **관전 화면에 있는 동안만** 간다 — 다른 탭 · 리포트로 나가면 풀려 돌아오면 전처럼 고른 영웅(`state.heroUid` — 캐릭터 탭과 같은 선택)이 대상이다. 다음 런으로 이어져도 관전에 머무는 동안은 비운 채다
- 캐릭터 탭의 고른 영웅은 안 바뀐다 — 비우는 것은 관전 화면의 상태다

## 맥락

ADR-0137 로 관전의 영웅 카드를 누르면 그 영웅이 장착 대상이 되고 파란 겉 테두리를 든다. 대상을 비우는 길은 없어서 한 번 누르면 테두리가 늘 남았다. 사용자가 바탕을 누르면 테두리가 없어지게 할 수 있냐고 물었고, 두 안 — A 테두리만 숨김(보관은 그 영웅을 계속 향한다) · B 대상 비움 — 중 B 를 골랐다.

## 근거

- **대상째 비우는 이유** — 테두리만 숨기면 보이지 않는 영웅에게 장비가 끼워진다. 통제성(누구에게 들어가나가 읽혀야 한다)이 먼저다
- **빈 곳을 아레나로 좁히는 이유** — 보관 칸 · 도구 줄을 누르는 손짓이 대상을 풀면 정리하다 대상이 사라진다. 카드 · 버튼 · 물약 칸 · 결과 띠는 제 할 일이 있다
- **관전에 있는 동안만인 이유** — 다시 들어오면 고른 영웅이 대상인 지금 모습(ADR-0137)을 지킨다. 캐릭터 탭 선택을 건드리지 않는다

## 파급

- 재생기 — battle.js `mountBattle` 에 `onPickNone()`(아레나 빈 곳 클릭) 하나
- 렌더러 — app.js 관전 화면 상태 `state.btNoPick` · 보관 칸이 향하는 영웅 `bagHero()` · 보관 칸 · 상자 칸 · 우클릭 메뉴 · [자동 장착] 이 대상 없음을 받는다
- 세이브 · i18n 변화 없음
