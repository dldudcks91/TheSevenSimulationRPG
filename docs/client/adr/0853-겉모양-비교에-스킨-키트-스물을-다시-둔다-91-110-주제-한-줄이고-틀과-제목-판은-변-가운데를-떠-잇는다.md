## 결정

`⚙` 설정 탭 `Skin` 줄에 **스킨 키트 스물(91 ~ 110)** 을 다시 둔다 — `Now` · `D2 Min` 뒤 · 버튼 글은 번호 · 이름은 hover. 길은 걷기 전의 마지막 판 그대로다:

- **키트 지시문은 주제 한 줄**([ADR-0835](0835-스킨-키트를-주제-한-줄로-Codex-가-지어낸-스물로-바꾼다.md)) — 재질 · 색 · 테두리 단면 · 모서리 · 제목 판 끝 · 버튼 · 칸은 Codex 가 지어낸다. 지시문이 거는 것은 자르는 규칙(마젠타 바탕 · 다섯 조각의 자리와 크기 · 테두리 띠 8 ~ 22px · 장식은 띠 안)과 「글자가 얹히는 면은 어둡게」뿐이다
- **배치 · 부품 · 배율 · 밝기는 [ADR-0820](0820-부품-시트-스킨을-스킨-키트-스물로-바꾼다-스킨마다-제-테두리-제목-판-버튼-칸-모양이고-배치는-D2-Min-그대로다.md) 그대로** — `<html data-skin="d2min" data-skin-parts="<번호>">` 로 D2 Min 의 배치를 타고 부품 여섯 장(테두리 · 버튼 턱 · 칸 · 제목 판 · 판 속 면 · 밝은 면)과 토큰만 키트 것 · 모든 조각 0.5 · 글자가 얹히는 면(판 속 면 · 밝은 면 · 제목 판 · 칸)은 밝기 상한까지 누른다

자르기에서 둘을 더한다:

- **테두리 틀은 변 가운데를 떠 잇는다** — 9-slice 그림을 판째 쓰지 않고, 네 모서리(11px)는 판 모서리 그대로 · 네 변은 판 변 **가운데의 민 띠**만 떠 다시 짠다. 모서리 장식이 띠보다 커도 그 끝이 변을 따라 되풀이되지 않는다(장식은 모서리 칸 크기로 잘린다)
- **제목 판의 끝 폭은 키트마다 잰다** — 양 끝에서 들어가며 세로 한 줄이 판 가운데와 같아지는 자리까지가 끝 모양이다. 판도 끝 + 가운데 민 조각 + 끝으로 다시 짜고, 화면은 끝을 띠 높이에 맞춘 비율로 그린다(토큰 `--sk-title-cap` · `--sk-title-capw`)

## 맥락

- ADR-0848 이 키트 스물(71 ~ 90)과 그 틀을 모두 걷었다 — 「다시 만들 때는 이 ADR 들(특히 0820 의 배율 0.5 · 부품 여섯 장 · 밝기 상한)과 git 이력에서 되살린다」. 걷기 전의 시트 · 자르는 스크립트는 커밋되지 않아 git 이력에 없었다 — ADR 의 문장으로 다시 짰다
- 사용자가 「정리된 로직대로」 스물을 더 주문했다. 주제는 지시가 없었다

## 근거

- **주제를 이렇게 고른 이유** — 일곱 죄종(91 ~ 97)은 이 게임의 주제라 화면 말투로 가장 먼저 견줄 만하다. 나머지 열셋은 지운 스물(71 ~ 90)과 안 겹치는 재질로 고르고 게임의 자리(결투장 · 연구소 · 원정 · 탐험 대상 · 선술집 용병)를 닮은 것을 먼저 골랐다
- **번호를 91 부터 매긴 이유** — 지운 21 ~ 90 과 겹치면 이력(ADR-0805 · 0820 · 0829 · 0835)의 번호가 다른 키트를 가리킨다(ADR-0829 와 같은 근거)
- **틀을 다시 짜는 이유** — 시험 넷(91 ~ 94) 중 94 는 모서리 블록이 시트에서 약 55px(화면 27px)로 띠 상한을 넘었다. 판째 9-slice 로 쓰면 변 조각 양 끝에 블록 끝이 들어가 `round` 되풀이마다 변 가운데에 서는 일이 ADR-0805 의 ⚠(37 Frost)와 같다. 지시문만으로는 Codex 가 장식을 띠 안에 가두지 않는다 — 자르기가 막는다
- **제목 판 끝을 재는 이유** — ADR-0820 의 「양 끝 12px」은 시트의 끝 모양이 24px 안이라는 가정이었다. 시험 넷의 끝은 화면 27 ~ 33px 이라 12px 로 자르면 끝 모양의 남은 몫이 가운데로 늘어난다. 키트마다 잰 폭을 토큰으로 넘긴다
- **버린 안 — 키트마다 테두리 slice 를 CSS 에서 따로** — ADR-0820 의 「버린 안」과 같은 이유(D2 Min 절이 slice 11 을 숫자로 들고 있다 · 그 절은 다른 세션이 계속 고친다)
- **버린 안 — 화면 전체 페인트오버 컨셉을 스무 장 더 뽑는다(ADR-0791 의 길)** — 「정리된 로직」은 걷기 직전까지 다듬어 ADR-0848 이 되살림 방법으로 적어 둔 키트의 길이다. 컨셉은 고른 뒤 다시 잘라야 화면에서 견줄 수 있다

## 파급

- `src/ui/devcompare.js` — `KIT_SKINS` 스물 · `data-skin-parts` · `?skin=<번호>`
- `src/ui/style.css` — 맨 끝 「겉모양 비교 — 스킨 키트 91 ~ 110」 절(키트마다 토큰 한 덩어리 — 스크립트가 찍은 것 · 상단바 · 버튼 바탕 · 제목 판 규칙)
- `src/assets/art/skins/k91_*` ~ `k110_*`(여섯 장씩) · 시트 `skins/source/kit_<번호>_<id>.png`(+ 지시문) · 발주 `skins/source/run_skin_kits.py`(주제 표 `KITS`) · 자르기 `skins/source/cut_skin_kits.py`
- D2 Min 의 희귀도 선 규칙이 `:not([data-skin-parts])` 로 키트를 빼던 자리(ADR-0848 이 남겨 둔 것)가 다시 먹는다 — 키트는 칸 가장자리 그대로다
- ⚠ D2 Min 과 같은 빈자리 — 판 안에 따로 검은 바탕을 둔 상자에는 키트 면이 없다
- ⚠ 모서리 장식이 띠보다 큰 키트는 장식이 모서리 칸(11px)에서 잘린다
