# ADR-0863 — `D2 Min` 원정 난이도 단 글씨는 모두 17px 다 · 고른 단은 색으로만 갈린다

## 결정

`D2 Min` 원정 탭 난이도 줄(「노말 › 나이트메어 › 헬」)의 단 글씨는 **모두 17px** 다. 고른 단은 밝은 흰 글씨 · 나머지는 어두운 회색(올리면 밝아진다)이라 고른 단은 **색으로만** 갈린다. 화살표 · 잠긴 단(자물쇠 + 흐림) · 줄 자리는 그대로다.

## 맥락

- 그날 고른 단은 20px · 나머지는 17px 이었다(ADR-0837 · 0854). 0854 는 「20 에 가까울수록 고른 단을 크기가 못 든다(색 차이만 남는다)」며 한 단 차이를 남겼다
- 사용자가 크기를 안 고른 단 크기로 모두 맞추라고 했다

## 근거

- **색 차이로 충분하다** — 고른 단 #f2ece2 · 나머지 #7d776e 로 밝기가 크게 갈린다. 0854 가 남긴 크기 차이는 사용자가 걷었다
- **17 에 맞춘다** — 지시가 「선택되지 않은 글씨 크기로」다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 고른 단(`.diff-tab.on`) 글씨 크기 · 렌더러 · i18n 변화 없음
- 글자 줄 높이가 고른 단만큼 줄어 줄 가운데 정렬이라 글자가 위아래로 1~2px 씩 안쪽에 선다 — 위아래 틈이 같다(ADR-0862)는 그대로다
