# ADR-0864 — `D2 Min` 원정 난이도 줄의 리포트 버튼은 한 단 큰 버튼이다

| **정한 사람** | 사용자 지시 (「오른쪽에 리포트 버튼 크기좀 키우고」) |
| **대체** | — |

## 결정

`D2 Min` 원정 탭 난이도 줄 오른쪽 끝의 리포트 버튼(`.dt-report`)은 **한 단 큰 버튼**이다 — 글씨 15(`--fs-md`) · 여백 6 · 18. 자리(줄 오른쪽 끝) · 문구 · 누르면 하는 일은 그대로다.

## 맥락

- 그날 리포트 버튼은 작은 버튼(`.btn.sm` — 글씨 13 · 여백 3 · 8)이었다. 같은 날 왼쪽 난이도 글씨가 17px 로 커지고(ADR-0854 · 0863) 줄이 위아래 틈이 같은 자리로 내려섰다(ADR-0862)
- 사용자가 버튼을 키우라고 했다

## 근거

- **여백은 상단바 부대 칸과 같다(6 · 18)** — `D2 Min` 에서 「여백을 키운 큰 버튼」으로 이미 쓰는 값이다(ADR-0824 · 0828). 글씨는 한 단(13 → 15) 올려 옆 난이도 글씨(17)와 크기 차이를 줄인다
- **줄 높이 안에 든다** — 버튼 높이(글씨 줄 + 위아래 여백 12 + 테두리)가 난이도 줄 최소 높이 35 안이라 줄 · 아래 목록 판이 안 움직인다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절의 `.diff-tabs .dt-report` · 렌더러 · i18n 변화 없음
