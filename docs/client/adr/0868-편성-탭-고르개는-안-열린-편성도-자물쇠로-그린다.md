## 결정

편성 탭 박스 맨 위의 편성 고르개는 **다 열렸을 때의 편성 수**(`presetFull` — 건물을 다 지은 판의 `limitsOf.presets`)만큼 칸이 늘 선다. 아직 안 열린 편성(`limitsOf(G).presets` 너머)은 **자물쇠 + 회색 · 이름만**(`Party II` …)이고 안 눌린다. 무엇이 여는지는 안 적는다. 열린 칸은 그대로다.

## 맥락

- 그날 편성 탭 고르개는 열린 편성만 그렸다 — 새 게임은 `Party I` 하나뿐이었다
- 상단바 부대 칸은 이미 안 열린 부대도 자물쇠 + 회색으로 세운다(ADR-0691). 편성 = 부대라 같은 이름(`Party I` …)이다

## 근거

- **상단바 부대 칸과 같은 말투** — 같은 이름의 같은 것(부대 = 편성)이 한 화면 위아래에서 다르게 보이지 않게 칸 · 자물쇠 · 회색 · 무엇이 여는지 안 적는 것까지 ADR-0691 을 따른다(`seg-lock`)
- **칸 수 = 다 열렸을 때의 편성 수** — 렌더러가 기본값 + 더하기를 따로 셈하지 않고 출정 창 편성 버튼이 쓰는 `presetFull()` 을 그대로 쓴다(§4-1 · ADR-0442)
- **편성 탭만** — 결투장 판도 같은 고르개를 쓰지만 요청은 편성 탭이었다. 결투장은 그대로다

## 파급

- `src/ui/app.js` — `presetSeg` 에 잠긴 칸 손잡이(`{ locked }`) · `renderParty` 가 켠다 · i18n 키 변화 없음(`pt.preset`)
- CSS 변화 없음 — 잠긴 칸은 기존 `.btn.seg-lock` · `disabled` 모양
