# ADR-0877 — `D2 Min` 건설 재료 칸의 재화 그림은 한 단 작다

| | |
|---|---|
| **상태** | 확정 · 2026-10-27 (임시 비교 장치) |
| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) · §13-1 |
| **정한 사람** | 사용자 지시 (「이렇게 넣을거면 안에들어가는 아이콘 크기를 살짝 줄여야해」) |
| **대체** | — |
| **대체됨** | — |

## 결정

`D2 Min`(과 스킨 키트)에서 건설 「다음 랭크」 재료 칸의 재화 그림을 한 단 줄인다 — 그림 34 → 28px · 임시 실루엣(낙인) 32 → 26px. 칸 크기(52) · 수량 글자 자리 · 그림 아래 여백은 그대로다.

## 맥락

ADR-0875 가 재료 칸에 빈 칸 그림을 깔았다. 그림은 `Now` 의 검은 칸 크기 그대로(34)라, 칸 그림의 안쪽 회색 네모(칸 끝에서 약 3px)에 위아래가 거의 닿고 오른쪽 아래 수량 글자(`6,000` · `0/60`)와 겹쳤다.

## 근거

- 칸 그림을 깔면 그림이 앉을 자리는 칸 전체가 아니라 회색 네모 안이다. 28 이면 그림 위 · 양옆에 회색 네모까지 5px 남짓이 비고 아래는 수량 글자 줄이 남는다
- 칸을 키우지 않은 이유 — 재료 칸 줄은 [건설]과 한 줄이고 「다음 랭크」 높이는 고정(§13-1)이라 칸이 크면 그 줄이 밀린다
- `Now` 는 그대로다 — 회색 네모가 없는 검은 칸이라 34 가 맞다
