# ADR-0882 — `D2 Min` 액티브 스킬 칸은 도서관도 회색 네모 위에 앉고 그림이 네모 안으로 살짝 작다

| **화면** | [SCREEN_DESIGN §10-5](../SCREEN_DESIGN.md) |

## 결정

`D2 Min` 에서 **액티브 스킬 칸**(캐릭터 탭 「액티브 스킬」 · 도서관 「지금 가진 스킬」 — 같은 카드 셋)은 스킬이 든 칸도 **회색 네모(빈 칸 그림) 위에 앉고**, 그림이 **네모 안쪽으로 살짝 작다** — 칸 안쪽 여백 3 → 6px. 빈 칸 · 자물쇠 칸은 그대로다. 관전 카드 스킬 칸 · 창고 스킬북 칸은 회색 네모가 없고 그림 크기 `Now` 그대로다(ADR-0843 · 0844).

## 맥락

ADR-0870 이 캐릭터 탭 액티브 칸에 회색 네모를 되돌렸을 때 그림 크기는 `Now` 그대로(여백 3 + 테두리 1)였다. 칸 그림의 회색 선은 칸 폭의 3/47 자리(안쪽 끝 4/47)라 그림이 회색 선에 바로 닿았다. 도서관 칸은 회색 네모가 없는 채였다.

## 근거

- **그림은 네모 안에 든다** — 회색 네모가 칸의 끝을 말할 때 그림이 그 선에 닿으면 선이 그림 테처럼 묻힌다. 여백을 선 안쪽 끝보다 몇 px 깊게 두어 그림과 선 사이에 틈을 둔다
- **여백으로 줄인다** — 그림 비율(`%`)을 새로 두지 않고 칸 여백 하나만 바꾼다. 그림은 `object-fit: contain` 이라 칸 크기를 따라가고, 구석 `Lv.n` 은 칸 기준이라 자리가 그대로다
- **같은 카드는 같은 모양** — 도서관 「지금 가진 스킬」은 캐릭터 탭과 같은 함수(`skillCardGrid`)가 그린다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절: 회색 네모를 걷는 규칙에서 액티브 칸을 빼고, 찬 액티브 칸(`.sk-card:not(.vacant)`) 여백 6px 한 줄 · 렌더러 · i18n 변화 없음
- 스킨 키트도 `D2 Min` 규칙을 타 같다 — 키트마다 칸 그림의 선 자리가 달라 틈의 폭은 키트마다 조금씩 다르다
