## 결정

`D2 Min`(과 스킨 키트)에서 **안 지은 부지**(파인 홈 — ADR-0875)와 **안 지은 건물의 상세 그림**은 그림이 홈 테 안쪽으로 들어간다 — 그림 끝 = 칸 끝 + 10(테 6 + 어두운 틈 4). 테의 회색 선(칸 끝 + 3)과 그림 사이는 칸 그림 안쪽과 같은 어두운 색이다. 이름 · 눈금 띠도 그림 안에 선다. 칸 크기 · 자리는 그대로다(부지 네모 · 상세 그림 둘 다). 고른 부지(붉은 테 2px)도 그림 끝이 같다. 초록 점은 그림 모서리를 따라 같이 들어간다. 지은 부지(솟은 판)는 그대로 칸을 꽉 채운다.

## 맥락

ADR-0875 는 안 지은 부지에 빈 칸 그림의 테(9-slice 6px)만 얹고 그림은 칸 끝까지 깔았다. 테의 회색 선이 그림 위에 바로 앉아 그림 결과 섞여 잘 안 보였다.

## 근거

- 선이 또렷하려면 선 양쪽이 다른 색이어야 한다 — 바깥은 테의 어두운 돌, 안쪽은 칸 그림 안쪽과 같은 어두운 틈이어야 회색 선 한 줄이 빈 칸 그림처럼 선다
- 그림을 줄이는 것이 선을 밝히는 것보다 낫다 — 선 색을 올리면 빈 부지 · 다른 칸 그림과 말투가 달라진다
- 지은 부지는 들이지 않는다 — 「솟은 판 = 꽉 찬 그림 / 파인 홈 = 들어간 그림」으로 지었나가 한 겹 더 읽힌다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 건설 묶음(안 지은 부지 · 상세 그림의 안쪽 여백 · `background-origin/clip: content-box` · 틈을 칠하는 안쪽 그림자 · 고른 부지 여백 · 초록 점 자리)
- i18n 키 · 렌더러 변화 없음
