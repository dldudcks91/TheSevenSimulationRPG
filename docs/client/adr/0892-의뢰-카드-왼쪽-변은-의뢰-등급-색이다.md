# ADR-0892 — 의뢰 카드 왼쪽 변은 의뢰 등급 색이다

| | |
|---|---|
| **상태** | 확정 · 2026-10-27 |
| **화면** | [SCREEN_DESIGN §14](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「Commissions에서 왼쪽에 나오는 색깔띠가 초록색과 흰색이 있는데 뭔차이?」 → 「그냥 레어같은 난이도색으로 수정해봐」) |
| **대체** | — (§14 「왼쪽 굵은 변이 종류 둘을 가른다」를 고친다 — ADR 로 정한 적이 없는 문장이다) |
| **대체됨** | — |

## 결정

의뢰 게시판 카드의 왼쪽 굵은 변(3px)은 **그 카드의 의뢰 등급 색**이다 — 일반 · 매직 · 레어가 아이템 희귀도 색(`--rarity-normal` · `-magic` · `-rare`)으로, 종류 배지 옆 등급 칩과 같은 색이다. 종류(처치 · 수집)는 변이 아니라 카드 맨 위 종류 배지 글자가 든다.

## 맥락

- 그날 왼쪽 변은 종류를 갈랐다 — 처치 = 초록(`--color-success`) · 수집 = 밝은 회색(`--border-highlight`)
- 사용자가 초록과 흰색의 차이를 물었다 — 색만으로는 뜻이 안 읽혔다. 초록은 다른 곳에서 「성공 · 완료」 색이라 처치 의뢰가 끝난 것처럼 보일 수 있었다
- 종류는 카드 맨 위 첫 글자(「처치」 · 「수집」)로 이미 보였다

## 근거

- **등급 색** — 카드에 이미 등급 칩(아이템 희귀도 색)이 있다. 변이 같은 색이면 한 카드의 색이 하나라 뜻이 하나다. 희귀도 색은 화면 전체에서 「얼마나 귀한가」로 읽히는 색이다
- **종류는 글자가 든다** — 같은 뜻을 색으로 한 번 더 들던 것을 걷는다
- **렌더러를 안 고친다** — 변 색은 카드 안 등급 칩의 등급(`g-<grade>`)을 CSS 가 보고 정한다

## 파급

- CSS — `.cm-card.k-kill` · `.cm-card.k-collect` 의 변 색을 걷고 등급 칩을 보고 변 색을 정한다 · 렌더러 · i18n 변화 없음 · 클래스 `k-<kind>` 는 그대로 달린다
- §14 「종류가 카드의 첫인상이다」의 「왼쪽 굵은 변이 둘을 가른다」를 고친다
