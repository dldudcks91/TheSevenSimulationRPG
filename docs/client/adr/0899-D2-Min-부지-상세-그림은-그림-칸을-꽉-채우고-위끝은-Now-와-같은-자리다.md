# ADR-0899 — `D2 Min` 부지 · 상세 그림은 그림 칸을 꽉 채우고 위끝은 `Now` 와 같은 자리다

## 결정

`D2 Min` 건설 탭의 부지 · 상세 그림은 그림 칸(칸 끝에서 위 8 · 아래 6 · 좌우는 회색 선 사이 가운데 — ADR-0894 · 0898)을 **꽉 채운다**. 가로는 그림 전부가 보인다. 그림 칸이 테 없던 칸보다 가로로 조금 길어 위아래가 조금 더 잘리는데, **위끝은 `Now` 와 같은 자리**에서 자르고(지붕 · 깃발 · 연기가 `Now` 와 같다) 더 잘리는 몫은 아래 — 이름 띠 밑 — 가 받는다. 그래서 회색 선 → 그림 거리가 네 변 모두 약 4px(1600×800 화면)이다.

## 맥락

ADR-0896 은 테 없던 칸의 그림을 통째로 줄여 그림 칸 가로 가운데에 앉혔다. 그림 비율이 테 없던 칸 비율(1.66 : 1)에 묶여 그림 칸(1.72 : 1)의 양옆에 약 3.5px 씩 검은 띠가 남았다 — 선 → 그림 거리가 위아래 약 4 · 양옆 약 8 이 되어 양옆이 검정에 잘려 보였다.

거슬러 보면 ADR-0896 을 부른 「자르지 말라」는 지적은 그때의 구현 고장 — 안 지은 부지의 그림이 칸 안 전체 크기로 깔리고 틈 색 띠가 가장자리를 덮던 것(ADR-0898 맥락) — 이 크게 잘라 보인 탓이 컸다. 고장을 고친 뒤에는 `cover` 의 위아래 차가 깃발 끝 몇 px 뿐이다.

## 근거

- 네 변의 검정이 같아야 그림이 테 안에 「들어간」 것으로 읽힌다 — 양옆 띠는 덮개로 읽혔다
- 위아래 더 잘리는 몫(그림 높이의 약 1%)을 아래로 몰면 사용자가 본 잘림(깃발 · 지붕)이 없다. 아래는 이름 · 눈금 띠가 어둡게 덮는 자리라 안 읽힌다
- 거른 안 — 가로로 3.6% 늘려 채우기(그림이 일그러진다) · 그림을 위아래로 키우기(선 → 그림 거리가 위아래 1px 로 붙는다)

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 건설 묶음: `background-size: cover` · 세로 자리 `--cn-pic-y`(부지 34% · 상세 31% — `Now` 의 칸 · 그림 크기로 위끝을 맞춘 값 · 칸 크기가 바뀌면 다시 잰다) · 초록 점 자리
- i18n 키 · 렌더러 변화 없음
