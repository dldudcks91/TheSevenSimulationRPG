# ADR-0909 — 건설 조건에 「챕터 n 클리어」 · 「노말 클리어」 문장이 선다

| | |
|---|---|
| **상태** | 확정 · 2026-10-27 |
| **화면** | [SCREEN_DESIGN §13](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「조건: 스테이지 1-5 클리어 -> 챕터 1 클리어」 · 「조건: 노말 클리어」 · 「조건: 나이트메어 클리어」) |
| **대체** | — |
| **대체됨** | — |

## 결정

건설 「다음 랭크」 와 랭크 툴팁의 조건 줄에 두 문장이 더 선다 — **「챕터 n 클리어」**(노말에서 그 장의 보스 칸을 깼다) · **「{난이도} 클리어」**(그 난이도에서 다음 난이도가 열리는 칸 — 5장 보스 — 를 깼다 · 「노말 클리어」 · 「나이트메어 클리어」). 표기는 다른 조건과 같다(선 것 초록 ✓ · 모자란 것 경고색 ✗). 스테이지 조건 「스테이지 1-5 클리어」는 그대로 남는다 — 지금은 탐험 건물만 새 조건을 쓴다.

## 맥락

탐험 건물을 다시 짜며 사용자가 랭크 I 의 조건을 「스테이지 1-5 클리어」에서 「챕터 1 클리어」로 바꾸고 랭크 IV · V 를 노말 · 나이트메어 클리어로 정했다. 건설 조건 종류는 스테이지 · 합산 레벨 · 영웅 레벨 · 다른 건물 넷뿐이었고, 스테이지 조건은 노말 기록만 본다.

## 근거

- **지시 그대로** — 장 보스 칸을 「스테이지 1-5」로 적으면 그 칸이 장의 끝이라는 것이 안 읽힌다. 사용자가 고른 문장이 「챕터 1 클리어」다
- **난이도 클리어는 스테이지 문장으로 못 쓴다** — 같은 5-5 칸도 난이도마다 기록이 따로라 「스테이지 5-5 클리어」로는 어느 난이도인지 안 읽힌다
- **다른 건물은 안 건드린다** — 사용자 요청이 탐험 건물이었다(대장간 랭크 II 등의 「스테이지 n-5 클리어」는 그대로)
