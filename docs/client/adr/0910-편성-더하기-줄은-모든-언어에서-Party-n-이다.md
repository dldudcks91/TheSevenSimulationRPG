# ADR-0910 — 편성 더하기 줄은 모든 언어에서 「Party +n」 이다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §13](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「모든 언어에서 Party는 그냥 Party로 나오도록 수정」) |
| **대체** | — |
| **대체됨** | — |

## 결정

건설 화면에서 편성 수를 늘리는 줄(여는 것 문장 · 기능 목록의 합)은 **ko · en 모두 「Party +n」** 이다. 다른 더하기 줄처럼 언어마다 옮기지 않는다. 편성 탭 · 출정 창 등 다른 자리의 「편성」은 그대로다.

## 맥락

편성 더하기 줄은 ko 「편성 +n」 · en 「Party presets +n」이었다. 탐험 건물 랭크 IV · V 를 「Party+1」로 다시 짜며 사용자가 이 줄을 모든 언어에서 「Party」로 적으라고 했다.

## 근거

- **지시 그대로** — 「모든 언어에서」라 한국어도 옮기지 않는다
- **범위는 그 줄 하나** — 지시가 건물 랭크 목록의 「Party+1」에 붙어 있었다. 편성 탭 이름까지 바꾸라는 말은 없었다

## 파급

- i18n — `cn.t.presets` 의 ko · en 둘 다 `Party +{n}`
- 렌더러 · 로직 변화 없음
