# ADR-0913 — 영웅 띠는 다 지은 칸 수만큼 서고 안 열린 칸은 자물쇠다

| | |
|---|---|
| **상태** | 확정 · 2026-10-27 |
| **화면** | [SCREEN_DESIGN §5](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「기본 영웅 칸을 지금 5칸에서 6칸으로 일단 올리자, 그리고 박스를 미리 다 그려두고 잠금처리」) |
| **대체** | §5 의 「빈 칸은 `+` 로 `roster_cap` 까지」 |

## 결정

공통 영웅 띠(일곱 탭)는 **선술집을 다 지었을 때의 영웅 칸 수**까지 칸을 그린다. 영웅 뒤의 빈 칸은 지금 상한까지 `+`, 그 뒤는 **잠긴 칸** — 흐린 점선 칸 안에 회색 닫힌 자물쇠 · 올리면 그 칸을 여는 건물 랭크 한 줄(「선술집 4랭크」). 잠긴 칸은 클릭도 끌어 놓기도 없다.

## 맥락

선술집 개편(DEV_PLAN R363)으로 영웅 칸 기본값이 오르고 늘어나는 칸이 선술집 뒤 랭크(나이트메어 장 클리어)로 모였다. 띠는 지금 상한까지만 `+` 를 그려 칸이 더 늘어난다는 것도, 무엇을 지어야 느는지도 안 보였다.

## 근거

- **물약 칸(ADR-0716)과 같은 문법이다.** 다 지은 수만큼 서고 잠긴 칸은 자물쇠 · 올리면 「창고 2랭크」 — 칸이 건물 랭크로 늘어나는 자리는 같은 그림으로 읽힌다
- **얼마나 남았는지가 띠에서 보인다.** 회색 탭(construction_draft §4)과 같은 생각이다 — 무엇을 향해 가는지가 보이면 짓는 이유가 선다
- **잠긴 칸의 한 줄은 건물 · 랭크만 말한다.** 랭크의 문턱(나이트메어 n장 클리어)은 건설 탭이 말한다 — 툴팁은 짧다(CLAUDE.md 규칙 7)

## 파급

- `app.js:heroStrip` — `+` 칸 뒤에 잠긴 칸 · 칸 수는 `balance.csv:roster_cap` 위로 `game.needOf('roster', n)` 이 닿는 데까지
- `app.js:rosterLockCard` — 칸 클래스는 연구소 영웅 칸의 잠긴 칸(ADR-0702)과 같은 `hs-card empty lock` · style.css 의 그 규칙을 `.hero-strip` 에도 건다
- 영웅이 상한보다 많은 옛 세이브는 잠긴 칸이 영웅 뒤에서 시작한다
