# ADR-0914 — 연구소 랭크 I 은 「연구소 개방」 이다

| | |

## 결정

건설 상세에서 연구소 **랭크 I** 의 여는 것 설명은 **「연구소 개방」**(en 「Laboratory Opens」)이다. 랭크 II ~ VII 은 「연구소 n랭크 지점 해금 · 자동 생산」 그대로다. 「지금 열린 것」 칸도 연구소가 랭크 I 이면 같은 문장이다.

## 맥락

같은 날 연구소가 처음부터 랭크 I 로 지어진 채 시작하게 됐고(ADR-0911 · DEV_PLAN R361), 이어서 랭크 I 이 **줄을 하나도 안 열게** 됐다 — 연구소 탭은 들어가지지만 줄은 다 닫혀 있다. 줄은 관련 건물이 연다(자원 = 창고 r1 · 도박장 = 선술집 r4 · 나머지 줄의 짝은 사용자가 정한다). 그런데 랭크 I 의 설명은 다른 랭크와 같은 「연구소 1랭크 지점 해금 · 자동 생산」이라 열리는 것이 있는 것처럼 읽혔다.

## 근거

- **지시 그대로** — 사용자가 랭크 I 의 문장을 「연구소 개방」으로 정했다
- **랭크 I 의 더하기 줄은 남긴다** — 연구소 랭크를 세는 것이 그 더하기(`resource_tier`)라 표에서 걷을 수 없다. 화면이 누적 1 일 때 다른 키를 고른다(`app.js:effectText` → `cn.t.lab_open`)
- **버린 안 — 랭크 I 을 빈 줄로 둔다** — 지은 랭크에 아무 글도 없으면 무엇을 지었는지 안 읽힌다

## 파급

- i18n `cn.t.lab_open` 하나 · 렌더러는 키 고르기 한 줄 · 표 · 로직 변화 없음
