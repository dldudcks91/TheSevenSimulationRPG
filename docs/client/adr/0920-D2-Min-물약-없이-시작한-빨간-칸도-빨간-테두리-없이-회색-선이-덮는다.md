# ADR-0920 — `D2 Min` 물약 없이 시작한 빨간 칸도 빨간 테두리 없이 회색 선이 덮는다

## 결정

`D2 Min` 관전 물약 띠에서 **라운드를 물약 없이 시작한 칸**(빨간 반투명 · `.p-slot.none`)은 제 빨간 점선 테두리를 걷는다. 빨간 바닥은 그대로이고, 그 위를 찬 칸과 같은 빈 칸 그림 테두리(회색 선 · ADR-0915)가 덮는다 — 물약 그림이 든 칸과 같은 모양에 속만 빨갛다. `Now` 는 그대로다.

## 맥락

같은 날 열린 칸 전부에 빈 칸 그림 테두리를 물약 위로 겹쳤다(ADR-0915). 빨간 칸은 제 빨간 점선이 그 바깥에 남아, 빨간 점선 → 검은 띠 → 회색 선 → 빨간 속의 두 겹 테두리로 섰다. 찬 칸은 제 테두리를 걷어 회색 선 하나였다.

## 근거

- **물약이 든 칸과 같은 틀.** 빨간 칸도 「이 칸에 들 것이 없었다」를 속의 색으로 말한다 — 틀까지 다르면 칸 크기가 다른 것처럼 읽힌다
- **빨간 것은 속 하나로 충분하다.** 칸 그림 테두리의 바깥 6px 는 불투명이라 빨간 바닥은 회색 선 안쪽에서만 보인다 — 바깥 점선이 없어도 빨간 칸은 갈린다

## 파급

- CSS — style.css 「겉모양 비교 — D2 Min」 절 물약 띠 줄(`.b-belt .p-slot.none` — 테두리 1px 은 찬 칸 바닥과 같은 어두운 색 · 빨간 바닥은 그 안쪽만. 테두리만 투명하게 하면 빨간 바닥이 그 1px 에 비쳐 얇은 빨간 테두리가 남았다 · 실측)
- 같은 띠를 쓰는 결투 관전도 같다 · 편성 탭 · 출정 창의 물약 칸은 그대로
