# ADR-0921 — 고른 표시의 겉 테두리는 3px 이다 · 연구소 줄 카드와 지점이 원정과 같아진다

## 결정

무엇을 골랐는지 보여 주는 **겉 테두리(아웃라인)의 굵기는 3px** 로 고정한다. 기준은 원정 관전의 장착 대상 카드(`.unit.on` — 같은 날 2px → 3px)다. 이 결정으로 **연구소의 고른 줄 카드(`.dp-card.pick`)와 고른 지점(`.dp-tree-cell.on`)** 이 2px → 3px 이 된다. 색 · 띄움(카드 1px · 지점 2px)은 그대로다. 앞으로 새로 만드는 고른 표시도 3px 로 선다.

## 맥락

같은 날 관전 장착 대상 테두리를 「약간만 더 두껍게」로 2px → 3px 올렸다. 연구소는 줄 카드 · 지점을 고르면 같은 파란 겉 테두리(ADR-0700 「노드 고르기와 같은 파란 겉 테두리」)가 서는데 2px 그대로였다. 사용자가 연구소도 원정처럼 3px 로 하고, 고른 표시는 앞으로 전부 3px 로 고정하자고 했다.

## 근거

- **같은 「골랐다」는 같은 굵기** — 화면마다 굵기가 다르면 같은 표시가 다른 뜻처럼 읽힌다
- **기준을 원정에 둔다** — 사용자가 직접 굵기를 보고 고른 자리가 원정이다

## 파급

- CSS — `.dp-card.pick` · `.dp-tree-cell.on .dp-tree-orb` 의 `outline` 2px → 3px
- 연구소 두 표시는 ADR-0700 대로 서로 같은 굵기를 유지한다
- ⚠ 이 날 2px 로 남은 고른 표시 — 영웅 띠의 고른 카드(`.hs-card.on` · 연구소 등록 창도 이 모양) · 도서관 전직 갈래(`.tr-adv-branch.pick`) · 아이템창 고른 칸(`.inv-cell.td-picked`) · 장비 · 가방 고른 칸(`.pd-cell.sel` · `.inv-cell.sel` — 빨강) · 결투장 고른 층(`.cs-floor.on` — 흰색). 기존 자리를 함께 올릴지는 사용자 확인 대기다. 영웅 띠를 올리면 §4-2 「띠보다 한 단 굵다」가 사라진다
