# ADR-0923 — 건설 띠 아래 틈은 22 고 상세 소제목은 띠와 같은 크기다

## 결정

- **제목 띠 아래 틈 = 22** — 부지 둘레(칸 사이 · 줄 사이 · 판 여백 — ADR-0747)와 같은 값. 두 판에 같이 걸려 상세 그림 윗변 = 부지 첫 줄 윗변 · 두 소제목 = 부지 둘째 줄 맞춤은 그대로다
- **상세 소제목(「다음 랭크」 · 「{건물} 랭크」) = 제목 띠와 같은 글자 크기** — 상세 판의 한 벌 +2 를 안 탄다

## 맥락

ADR-0919 로 두 판 맨 위에 제목 띠가 섰고 띠 아래 틈은 판 제목의 보통 틈(8)이었다. 사용자가 부지가 띠에 너무 붙었다며 조금 더 내리라고 했고, 상세의 두 소제목이 맨 위 제목보다 커 보인다며 같은 크기로 줄이라고 했다.

## 근거

- **22 는 이 판이 이미 쓰는 값이다** — 부지의 다른 세 변 여백 · 칸 사이가 22 라 띠 아래도 22 면 격자가 사방 같은 틈에 선다(새 값을 만들지 않는다)
- **두 판에 같이** — 왼쪽만 내리면 그림 · 소제목이 부지 줄과 어긋난다(9-24 · 10-24 사용자 맞춤)
- **제목이 소제목보다 작으면 위계가 뒤집힌다** — 소제목을 띠 크기로 맞춰 같은 층으로 읽힌다
