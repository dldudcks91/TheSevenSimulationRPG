# ADR-0925 — 잠금 표시는 어디서나 회색이다 — 자물쇠와 여는 조건 글자 둘 다

| | |

| **화면** | [SCREEN_DESIGN §13-1](../SCREEN_DESIGN.md) 잠긴 자리의 한 줄 · 잠김 베일 — 그것을 쓰는 모든 자리 · §15 전술 잠긴 행 |
| **정한 사람** | 사용자 지시 — 「우리게임에 있는 모든 잠금 표시를 회색 으로 수정해봐」 |
| **대체** | — (베일 · 전술 잠긴 행 · 탐험 지도 자물쇠의 경고색은 2026-09-27 규격 문장이 들었다 · ADR 없음) |

## 결정

1. **자물쇠 그림(`lockIcon` 닫힘)은 어디서나 흐린 글자색(회색 `--text-muted`)이다** — 둘레 글자색을 안 따른다. 챕터 탭의 죄종 색 · 출발 칸 버튼 · 막힘 줄의 빨강 · 플래시의 경고색 안에서도 자물쇠는 회색이다.
2. **여는 조건 글자도 회색이다** — 잠김 베일 · 탐험 지도 잠긴 구간 · 전술 잠긴 행(경고색이었다) · 글 줄 안의 잠김 한 줄(`lockLine` — 도서관 스킬 업그레이드 「Lv.10 달성」 · 출정 창 「영웅 편성」 · 방출 막힘 「원정 철수」처럼 빨간 막힘 줄 안에 서던 것)이 모두 회색이다.
3. **플래시는 자물쇠만 회색**이다 — 글은 플래시 카드 색(경고색) 그대로. 플래시는 잠긴 자리가 아니라 누른 뒤의 알림 카드다.
4. **유저가 거는 잠금은 대상이 아니다** — 파티 전술 잠금 토글(`.rs-pin` — 잠근 칸은 강조색)과 아이템 잠금 🔒 은 「안 열림」이 아니라 유저가 건 상태 표시라 지금 색 그대로다.

## 맥락

자물쇠 색이 자리마다 갈려 있었다 — 흐린 탭 · 장소 줄 · 난이도 탭 · 스킬 카드 · 연구소 · 관전 물약 칸(ADR-0716) · 도감 단계 줄(ADR-0922)은 회색, 잠김 베일 · 탐험 지도 · 전술 잠긴 행은 경고색, 막힘 줄에 선 잠김 한 줄은 빨강, 챕터 탭은 죄종 색. 사용자가 10-22(물약 칸) · 10-27(도감 단계 줄)에 자리별로 회색을 지시한 끝에 전부를 회색으로 모았다.

## 근거

- **지시 그대로** — 「모든 잠금 표시」
- **「잠금 표시」는 자물쇠 + 여는 조건 한 토막으로 읽었다** — 잠긴 자리의 한 줄은 둘이 한 덩어리다(ADR-0699). ADR-0922 도 자물쇠와 글자를 같이 회색으로 했다
- **유저가 거는 잠금은 뺐다** — 전술 잠금 토글은 잠근 칸이 강조색이어야 「이 칸은 리롤에서 빠진다」가 읽힌다(§15). 아이템 잠금은 이모지라 색을 안 탄다

## 파급

- style.css — `.rs-pin-ico` 에 회색 · `.rs-pin .rs-pin-ico` 는 버튼 색 · `.lock-line` 회색(플래시 `.toast .lock-line` 은 카드 색) · `.lock-veil` · `.ex-lock` · `.rs-lock` 글자색 회색
- app.js — `lockLine` 이 한 줄을 `.lock-line` 으로 감싼다
- 새 i18n 키 없음
