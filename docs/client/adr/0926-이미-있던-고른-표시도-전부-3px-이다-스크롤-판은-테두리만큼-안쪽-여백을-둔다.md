# ADR-0926 — 이미 있던 고른 표시도 전부 3px 이다 · 스크롤 판은 테두리만큼 안쪽 여백을 둔다

| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) 「고른 표시」 · [§4-2](../SCREEN_DESIGN.md) · [§8](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 (「모두 3px로 올려봐 이상하면 내가 다시 내려달라고할게 · 줄카드 잘리는것도 당연히 고쳐야지」) |

## 결정

ADR-0921 이 연구소만 3px 로 올리고 2px 로 남겨 둔 고른 표시를 **전부 3px** 로 올린다 — 영웅 띠의 고른 카드(`.hs-card.on` · 연구소 등록 창도 같은 모양) · 도서관 전직 갈래(`.tr-adv-branch.pick`) · 상점 · 도서관 책 칸의 고른 칸(`.inv-cell.td-picked`) · 대장간 강화의 고른 장비(`.pd-cell.sel` · `.inv-cell.sel` — 빨강) · 결투장 고른 층(`.cs-floor.on` — 흰색). 색은 그대로다. 띄움도 그대로고, 전직 갈래만 테두리가 카드 안쪽에 서도록 안쪽 띄움을 굵기만큼(-3px) 늘린다.

**스크롤 판 가장자리의 고른 표시가 잘리지 않게** 판 안쪽에 「굵기 + 띄움」만큼 여백을 둔다 — 연구소 트리 판(`.dp-tree-grid`)에 4px(줄 카드 테두리의 왼쪽 · 위가 잘렸다) · 책 칸 격자(`.bk-grid`) 3px → 4px.

## 맥락

ADR-0921 에서 연구소 줄 카드 · 지점을 3px 로 올리고, 남은 2px 자리를 올릴지 사용자에게 물었다. 같은 날 측정에서 연구소 줄 카드의 파란 선이 **왼쪽(모든 줄) · 위(`D2 Min` 첫 줄)가 잘려** 오른쪽 · 아래만 보였다 — 트리 판이 `overflow-y: auto` 라 판 밖으로 나간 겉 테두리를 자른다. 2px 일 때부터 같았다. 책 칸 격자는 같은 문제를 2026-10-09 에 판 여백(2px + 1px = 3px)으로 고쳐 둔 선례가 있다.

## 근거

- **같은 「골랐다」는 같은 굵기** — ADR-0921 과 같다. 사용자가 전부 올려 보고 이상하면 다시 내리겠다고 했다
- **원정이 「띠보다 한 단 굵다」던 구분은 사라진다** — 관전 장착 대상과 띠가 같은 굵기다
- **전직 갈래는 안쪽 테두리를 지킨다** — 2px 를 -2px 안쪽에 그리던 자리라, 3px 를 -2px 에 그리면 1px 가 카드 밖으로 나간다
- **잘림은 여백으로 고친다** — 안쪽 띄움(음수)으로 바꾸면 「겉 테두리」가 아니게 된다 · 책 칸 격자의 선례와 같은 손이다

## 파급

- CSS — 위 다섯 규칙의 `outline` 2px → 3px · `.tr-adv-branch.pick` 의 `outline-offset` -2px → -3px · `.dp-tree-grid` 에 `padding: 4px` · `.bk-grid` 의 `padding` 3px → 4px
- 연구소 트리 판의 내용이 사방 4px 안쪽으로 든다
- ⚠ 테두리(`border`)로 그리는 고른 표시는 이 결정 밖이다 — 건설 부지(`.cn-lot.pick`) · 선술집 찾아온 영웅 칸(`.tv-join-slot.on`)
