# ADR-0928 — 스킬 업그레이드 카드도 책 배우기가 안 열렸으면 잠김 베일로 덮는다

## 결정

도서관 탭 오른쪽 위 **스킬 업그레이드** 카드는 책 배우기(`skillbook`)가 안 열렸으면 **카드 몸을 잠김 베일로 덮는다** — 스킬 북 제작 카드(ADR-0635)와 같은 `lockVeil('skillbook')`(검은 막 · 가운데 자물쇠 + 「도서관 2랭크」 · 몇 랭크인지는 표가 정한다 `game.needOf`). 제목 줄과 `?` 는 베일 밖이다. 베일이 말하는 막힘이라 카드 맨 위 막힘 한 줄에서 「도서관 n랭크」는 빠지고, 레벨 미달(「Lv.n 달성」)만 한 줄로 남는다.

## 맥락

같은 날 기획(R364)이 책 배우기를 도서관 r1 에서 r2 로 옮겨 책 제작과 같은 랭크가 됐다. 표만 바뀌고 화면은 그대로라, 도서관 r1 에서 제작 카드는 베일로 덮이는데 업그레이드 카드는 맨 위 한 줄 「도서관 2랭크」만 서고 책 칸이 그대로 보였다 — 같은 랭크에 잠긴 두 카드가 다르게 보였다.

## 근거

- **통째로 안 열린 자리는 잠김 베일 하나로 덮는다**(§13-1) — 전직 갈래 자리 · 스킬 북 제작 카드와 같은 표시다.
- **레벨 미달은 베일이 아니다** — 영웅마다 다른 막힘이라 띠에서 영웅을 바꾸면 풀린다. 기능이 닫힌 것과 갈린다.

## 파급

- `app.js:renderLibrary` — 업그레이드 카드의 `card` 에 대상 `'skillbook'`
- `app.js:bookLearnInto` — 막힘 한 줄에서 `unbuilt` 를 뺀다(베일 아래 반투명으로 비치던 같은 말)
- 캐릭터 탭 책 칸의 빈 칸 사유(`emptySlotText` — 「도서관 2랭크」)는 그대로다
