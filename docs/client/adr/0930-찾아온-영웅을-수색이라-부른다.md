## 결정

연구소 줄 · 선술집 칸 · 플래시 · 건설 효과 줄이 쓰던 이름 **「찾아온 영웅」을 「수색」** 으로 바꾼다. 영어는 **`Search`** 다(10-19 전 수색과 같은 영어). 바뀌는 것은 이름뿐이다 — 시간마다 한 명이 칸에 저절로 오고 영웅을 보내지 않는 규칙 · 칸 · 화면 배치는 그대로다. i18n 키 · 코드 식별자(`tv.visit.h` · `dp.post.visit` · `visit` · `joins` · `?dev=visit`)도 그대로다.

## 맥락

2026-10-19 에 영웅을 보내 데려오던 「수색」을 걷고, 시간으로 영웅이 오는 「찾아온 영웅」으로 바꿨다(ADR-0671). 그 뒤 연구소 줄 이름 · 선술집 칸 이름 모두 「찾아온 영웅」(`Visiting Heroes`)이었다. 사용자가 이 이름을 전부 「수색」으로 바꾸라고 했다.

## 근거

- **사용자 지시** — 이름은 기획 결정이고 사용자가 정했다
- **영어는 옛 수색의 영어를 잇는다** — 한국어가 옛 이름으로 돌아가므로 영어도 그때의 `Search` 다. 직역 규칙(한글 ↔ 영어 짝)에도 맞는다
- **식별자는 안 바꾼다** — 이름만 바뀌는 일에 세이브 · 키 · 개발 URL 을 흔들 까닭이 없다

## 파급

- i18n — `tv.visit.h` · `dp.post.visit` = 「수색」 / `Search` · `tv.kept` · `tv.err.joinFull` · `cn.t.recruit_quality` · 연구소 안내 줄의 이름
- 지금 상태를 적는 문서(SCREEN_DESIGN · INTERFACE · 기획서 · README) · 코드 주석 · CSV 설명 칸의 「찾아온 영웅」 → 「수색」. 결정 기록(ADR · 이력 · 결정 로그 · R 대장)과 「수색 → 찾아온 영웅」 같은 이력 메모는 그날 이름 그대로 둔다
- `D2 Min` 연구소 카드 열 폭(40% 하한 · 내용 폭까지)은 `Visiting Heroes` 길이로 쟀었다 — 영어 이름이 짧아져 열이 하한 쪽으로 준다(깨지지 않는다)
