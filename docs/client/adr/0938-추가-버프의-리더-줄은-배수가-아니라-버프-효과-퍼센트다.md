# ADR-0938 — 「추가 버프」의 리더 줄은 배수가 아니라 「버프 효과 ±n%」다

## 결정

편성 탭 「추가 버프」 툴팁의 리더 줄은 **「리더 통솔 7 — 버프 효과 −17%」** 다. 리더 배수(`tacticState.leader.curve`)를 그대로 적지 않고 **1 에서 늘고 준 양을 정수 퍼센트**로 적는다 — 0.83 이면 −17% · 1.12 면 +12% · 1 이면 ±0%. 부호는 레이팅 변화와 같은 `signed`(`+` · `−` · `±0`)다.

## 맥락

ADR-0758 은 리더 줄을 「전술 ×0.83」으로 적었다. 같은 행의 「추가 버프」 열은 리더 보너스를 능력치 값(늘어난 양)으로 적고, 0758 도 새 출처는 「n%」로 적기로 했다 — 리더 줄만 배수였다.

## 근거

- **배수는 늘었나 줄었나를 한 번 더 셈해야 읽힌다** — ×0.83 은 「17% 줄었다」로 바꿔 읽어야 하고, 퍼센트는 그대로 읽힌다
- **「전술」 → 「버프 효과」** — 줄어드는 것은 전술 칸이 아니라 칸이 주는 버프의 크기다. 열 이름 「버프」(ADR-0764)와 같은 말이 된다
- 정수로 자른다 — 소수 둘째 자리 배수(0.83)가 이미 1% 단위라 잃는 자리가 없다

## 파급

- i18n `rs.buff.lead` — `{m}`(배수) → `{p}`(부호 붙은 정수)
- 도움말 「파티 전술」 묶음 `rs.note.lead` 의 「×{lo} · ×{hi}」는 이번에 안 건드렸다 — 곡선의 끝값 설명이다
