# ADR-0943 — 시작 화면은 첫 카드 왼쪽에 능력치가 하는 일을 능력치 줄 높이로 적는다

## 결정

시작 파티 고르기 화면의 **첫 카드 왼쪽 빈자리**에 능력치 범례를 한 번 적는다 — 머리 「능력치가 하는 일」 아래 일곱 줄, 줄마다 능력치 이름(흰 글씨) + 하는 일(회색 짧은 명사구 · 대표 효과만). **줄마다 카드의 능력치 막대 줄과 같은 높이**에 서서 옆으로 눈만 옮기면 어느 줄의 설명인지 맞는다. 범례 줄에 올리면 카드의 능력치 줄과 같은 능력치 설명 카드가 선다. 새 게임 화면에만 있다.

## 맥락

후보 카드의 능력치 일곱 줄은 이름 · 약어 · 막대 · 값만 들었고, 무엇을 하는 능력치인지는 줄에 **올려야** 서는 설명 카드(ADR-0581)에만 있었다. 처음 하는 사람은 올려 볼 줄을 몰라 「힘 · 통솔 · 매력이 뭘 하는지」를 화면만으로 알 수 없었다. 이 화면은 카드 세 장이 가운데 서고 양옆이 비어 있었다(1600 한 장에서 카드 줄 왼쪽 약 320px).

## 근거

시안 셋을 실제 화면에 얹어 찍어 비교했다.

- **① 첫 카드 왼쪽 · 줄 높이 맞춤 (골랐다)** — 세 장 공용으로 한 번만 적고 카드는 안 건드린다. 줄 높이가 막대 줄과 같아 표처럼 가로로 읽힌다. 비어 있던 자리를 쓴다
- **② 버튼 아래 2줄 × 4칸 범례 (버렸다)** — 카드 줄과 떨어져 있어 위아래로 오가며 짝지어야 한다. ADR-0675 가 걷은 「카드 아래 안내 띠」와 같은 모양이다
- **③ 카드 줄마다 꼬리표(「물리 피해」) (버렸다)** — 같은 단어가 세 장에 반복되고, 막대가 짧아져 카드가 빽빽해진다
- **줄 높이는 재지 않는다** — 범례가 첫 카드 능력치 목록 안에 절대 위치로 서서 그 목록의 높이를 일곱 등분한다(목록의 줄은 모양이 같아 높이가 같다). 렌더 뒤에 좌표를 재 맞추면 배율 · 언어 · 스킨마다 어긋날 자리가 생긴다
- **문구는 대표 효과만** — 능력치 하나가 효과를 여럿 갖는데 다 적으면 줄이 넘쳐 높이 맞춤이 깨진다. 전부는 올리면 서는 설명 카드가 든다
- **「설명 문구는 도움말 탭 전용」(§12)의 예외** — 카드 연장 칸(ADR-0675)과 같은 결로, 첫 결정을 내리는 이 화면에서만 연다
- **선술집 · 수색은 안 넓힌다** — 첫 결정 이후의 자리이고, 선술집 판에는 범례가 설 빈자리가 없다

## 파급

- `app.js:renderStart` 가 첫 카드의 `.attr-list` 에 `.ng-legend` 를 붙인다 · `bindStatTips` 로 줄에 설명 카드
- i18n `ng.attrHead` · `ng.attr.<능력치 id>` 일곱 (ko/en)
- CSS `.ng-legend` · `.ng-lg-h` · `.ng-lg-r` · `.ng-card .attr-list { position: relative }`
- SCREEN_DESIGN §2 「능력치 설명 툴팁 규격」 서는 자리에 범례 줄이 더해졌다
- `D2 Min`(§10-5)은 새 게임 카드 줄을 돌 판이 두르고 판 안 옆 여백이 좁아 범례가 테두리를 가로질렀다 — 그 겉모양에선 범례가 **판 밖**에 선다(뒤로가기와 같다). 그 자리 폭에 맞춰 영어는 더 짧게 쓴다(「Physical damage」)
