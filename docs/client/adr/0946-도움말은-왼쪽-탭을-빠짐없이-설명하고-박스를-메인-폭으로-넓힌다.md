# ADR-0946 — 도움말은 왼쪽 탭을 빠짐없이 설명하고 박스를 메인 폭으로 넓힌다

| | |
|---|---|
| **상태** | 확정 · 2026-10-29 |
| **화면** | [SCREEN_DESIGN §12](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 왼쪽 각 탭의 설명을 모두 정리하고 잘리는 박스를 가로로 넓힙니다 |
| **대체** | §12의 읽기 폭 상한, 상점·대장간 섹션 생략, 기존 문구만 재사용하는 제한 |
| **대체됨** | — |

## 결정

도움말 목차와 본문 섹션은 왼쪽 메뉴의 순서를 따르며 모든 탭을 설명합니다. 스킬은 캐릭터에, 새 게임은 도움말에 포함합니다. 개발 전용 실험실 설명은 해당 탭과 함께 개발 환경에서만 표시합니다. 잠긴 탭의 사용법도 미리 읽을 수 있습니다.

본문에는 현재 구현을 기준으로 조작 방법, 조건, 결과를 한/영으로 작성합니다. 예전의 단일 파티·영웅 파견·스킬 미구현 등 현재 기능과 맞지 않는 문장은 사용하지 않습니다. 값이 필요한 곳은 코드·CSV에서 같은 값을 조회해 치환합니다.

860px 상한을 없애 박스가 메인 가용 폭을 채우게 합니다. 제목·목차는 고정하고 본문만 세로 스크롤합니다. 목차와 문장은 줄바꿈하고 본문 끝까지 박스 안에서 확인할 수 있게 합니다. 목차는 현재 읽는 섹션을 표시하며 클릭은 본문만 움직입니다.

## 근거

상점과 대장간이 목차에서 빠져 있었고, 기능이 바뀌어도 과거 패널에서 옮겨 온 안내는 그대로 남았습니다. 기존 문구의 재사용만으로는 현재 동작을 설명할 수 없었습니다. 도움말 박스의 가로 상한은 오른쪽 공간을 남겨 긴 설명을 좁은 칸에 몰았습니다.
