# ADR-0947 — 도움말은 검색으로 찾고 기획의 핵심을 짧은 문단과 예시로 읽는다

| | |
|---|---|
| **상태** | 확정 · 2026-10-29 |
| **화면** | [SCREEN_DESIGN §12](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 전체 기획을 확인하면서 꼼꼼하고 쉽게 도움말을 계속 수정·보완합니다 |
| **대체** | — |
| **대체됨** | — |

## 결정

각 기능의 목적과 성장 흐름, 조작, 결과, 선택 예시를 설명합니다. 기획의 과거 논의와 개발 파일명은 본문에 넣지 않습니다. 기획이 확정되어 있어도 아직 쓸 수 없는 기능은 현재 기능처럼 설명하지 않습니다. 효과가 다른 전투 규칙, 영웅·장비의 등급과 레벨, 무기 착용과 스킬 무기 조건처럼 혼동하기 쉬운 개념은 구별해 적습니다.

긴 본문은 짧은 문단과 기능별 소제목으로 나누며, 필요한 곳에 간단한 예시를 둡니다. 왼쪽 메뉴와 같은 섹션 순서 및 ADR-0946의 전폭 박스·고정 목차를 유지합니다.

제목 아래에 도움말 검색을 둡니다. 현재 언어의 섹션 이름·소제목·본문에서 단어를 찾으며, 여러 단어는 모두 포함된 설명을 표시합니다. 대소문자와 연속 공백은 결과에 영향을 주지 않습니다. 결과 수를 표시하고, 맞는 설명이 없는 목차는 비활성화합니다. 검색을 지우면 전체 본문을 복구합니다. 검색어는 화면 상태이며 세이브에 넣지 않습니다. 검색 중 게임 상태가 갱신되어도 입력과 커서를 유지합니다.

## 근거

버튼을 누르는 방법만으로는 왜 그 기능을 쓰는지와 막혔을 때 바꿀 대상을 알기 어렵습니다. 또 설명이 많아질수록 필요한 규칙을 찾기 위해 긴 본문을 훑어야 합니다. 개념과 예시를 보완하고 주제 단위 검색으로 접근할 수 있게 합니다.
