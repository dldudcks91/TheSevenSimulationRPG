# ADR-0949 — 새 라운드의 적은 제자리에서 작게 생겨 커진다 · 위에서 내려오지 않는다

## 결정

원정의 새 라운드 적 카드는 **제자리에서** 0.58배 · 어둡게(밝기 0.45) · 투명하게 생겨 0.82초에 걸쳐 제 크기로 커진다(불투명은 0.46초) — 위아래로 움직이지 않는다. 카드 사이 0.11초 차례 · 라운드 사이 빈 줄(0.95초 숨)은 ADR-0948 그대로다.

## 맥락

ADR-0948 을 본게임에 넣은 날, 사용자가 「처음 만들어 준 건 위에서 내려오는 느낌이 아니라 제자리에서 슉하고 생기는 거였다」고 짚었다. 출발 자리(위 120px · 0.58배 · 어둡게)는 처음 시안부터 같았다 — 처음 시안은 같은 순간에 배경이 앞으로 당겨졌고(배경 당김 · 누적 당김) 0.68초로 더 빨라 같은 움직임이 「깊이에서 다가옴」으로 읽혔다. 배경이 멈춘 등장만 다가옴에서는 「위에서 내려옴」으로 읽혔다.

## 근거

사용자가 바란 모양은 「제자리에서 생김」이다 — 위아래 이동을 걷고 크기 · 밝기 · 투명만 남겼다. 시안이 아레나 밖을 잘라 둔 차이(본게임 아레나는 안 자른다)도 따져 봤으나 출발 순간 아레나 밖으로 나가는 몫이 거의 투명한 짧은 순간뿐이라 원인이 아니었다.

## 파급

- `fx.js:ARRIVE.from` 에서 `translate` 를 걷었다 — `scale` · `opacity` · `filter` 만
- ⚠ 카드마다 제 가운데에서 커져 붙어 선 이웃 쪽으로 가장자리가 밀고 들어가 보이는 것(ADR-0948 「충돌」)은 그대로다
