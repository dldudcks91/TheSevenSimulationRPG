# ADR-0959 — 연구소의 잠긴 줄은 「닫힘」 대신 자물쇠와 여는 조건을 쓴다

## 결정

연구소의 잠긴 줄은 줄 카드의 이름 오른쪽에 **자물쇠 + 여는 조건**(`lockLine` — 「창고 건설」 · 「선술집 2랭크」 · 「연구소 2랭크」 · 「선술집 3랭크」)을 쓴다. 글은 잠긴 지점이 쓰는 것(`dpNeedFull` — 그 줄의 첫 지점)과 같다. 고른 줄의 머리에는 상태 글이 없다 — 잠겼으면 그 아래 자물쇠 + 여는 조건 한 줄이 이미 말한다. 수색 줄이 열렸는데 「간격」을 아직 안 올렸으면 「이 줄」에 자물쇠 + 「간격 Lv 1」을 쓴다. 「닫힘」(`dp.visit.closed`)은 걷는다.

## 맥락

- 그날 줄 카드는 잠긴 줄 넷에 똑같이 「닫힘」을 썼다 — 무엇을 지어야 열리는지는 지점을 하나씩 눌러야 보였다
- 같은 날 수색 줄이 선술집 r2 로 옮겨 가(ADR-0955) 줄마다 여는 건물이 달라졌다 — 자원 = 창고 · 수색 = 선술집 r2 · 훈련 = 연구소 r2 · 도박장 = 선술집 r3

## 근거

- **잠긴 자리는 자물쇠 + 여는 조건 한 토막이다**(§13-1 · ADR-0699) — 연구소 머리 · 잠긴 지점 · 선술집 수색 칸이 이미 이 말투를 쓴다. 줄 카드만 「닫힘」이면 잠김이 두 말투로 읽힌다

## 파급

- `app.js` — `dpTreeLine` · `dpLineSide` · `dpSideLine` · 선술집 `visitCell` 의 잠긴 줄도 연구소가 섰으면 「선술집 2랭크」(옛 「연구소 1랭크」)
- `i18n.js` — `dp.visit.closed` 삭제
