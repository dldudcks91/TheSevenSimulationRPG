# ADR-0962 — 대장간 탭 버튼은 언제나 강화 작업 탭을 연다

| | |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | [SCREEN_DESIGN §8-2](../SCREEN_DESIGN.md) 「작업 탭」 |
| **정한 사람** | 사용자 지시 (「대장칸 딱 누르면 처음에 나오는게 강화로 나오도록 수정해줘봐」) |
| **대체** | [ADR-0142](0142-제련소는-제작-강화-크래프트를-위쪽-탭으로-가른다.md) 의 **「기본은 제작」** — 작업 탭으로 가르고 고른 하나만 펴는 것은 산다 |
| **대체됨** | — |

## 결정

왼쪽 탭 줄의 **대장간 버튼을 누르면 언제나 `강화` 작업 탭이 선다** — 제작 · 합성을 보다 다른 탭에 갔다 와도, 이미 대장간이어도 같다. 처음 여는 기본값도 강화다. 작업 탭의 순서(`제작` · `강화` · `합성` · `크래프트`)는 그대로다. `?tab=forge&fg=…` 는 그 작업 탭을 고른 채 연다(§10 그대로).

## 맥락

그날 대장간은 처음 열면 제작이 섰고(ADR-0142 「기본은 제작」), 그 뒤로는 마지막에 고른 작업 탭을 기억해 다시 열었다. 장비 · 아이템창의 칸을 누르면 강화 탭으로 넘어가는 길(ADR-0364 · ADR-0366)은 이미 있었다.

## 근거

- **사용자 지시** — 대장간을 누르면 처음 나오는 것이 강화
- **기본값만 바꾸지 않고 누를 때마다 강화로 연다** — 기본값만 바꾸면 제작을 한 번 본 뒤에는 다시 제작이 선다. 탭 버튼이 무엇을 여는지가 늘 같은 것은 원정 탭 버튼(ADR-0661)과 같은 규칙이다
- **버린 안 — 강화를 작업 탭 맨 앞으로 옮긴다** — 지시는 처음 서는 화면이었고 순서가 아니었다
- ⚠ **잃는 것 — 고른 작업 탭을 기억하지 않는다.** 제작을 하다 다른 탭에 갔다 오면 [제작]을 한 번 더 누른다

## 파급

- app.js — `state.forgeTab` 기본 `'up'` · 탭 버튼이 대장간이면 `forgeTab = 'up'` · `renderForge` 의 되돌림 값 `'up'`
- §8-2 「작업 탭」 줄의 「기본은 제작」 → 「대장간 탭 버튼은 언제나 강화」
