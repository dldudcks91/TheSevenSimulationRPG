# ADR-0963 — 대장간 작업 탭은 패널 윗변에 붙은 폴더 탭이고 강화가 맨 왼쪽이다

## 결정

대장간 작업 탭은 **작업 패널 윗변에 붙은 폴더 탭**이다. 순서는 `강화` · `제작` · `합성` · `크래프트`.

- **`Now`** — 원정 난이도 탭(ADR-0596)과 같은 길. 탭 줄이 패널의 윗선을 긋고(첫 틈 = 패널 가로 여백 · 탭 사이 틈 · 남은 자리 · 안 고른 탭의 아랫변이 한 선) **고른 탭 자리에서만 선이 끊겨** 탭 안과 패널 안이 이어진다. 고른 탭은 윗변이 강조색이고 한 단 높다. 패널은 윗변이 없다
- **`D2 Min`** — 편성 고르개(ADR-0847 · 0872 · 0876)와 같은 폴더 탭. 띠 없이 작업 판의 돌 테두리 바깥 끝(선반)에 앉는다 · 어두운 돌 + 버튼 턱(밑변 없음) · 넷이 같은 폭(가장 넓은 탭) · 고른 탭은 같은 모양이 위로 솟고 글씨가 밝다

고른 탭은 눌러도 아무 일이 없다. 패널 제목(고른 작업 이름)은 그대로 선다.

## 맥락

그날 작업 탭은 패널 위에 떨어진 세그먼트 버튼 줄이었다(도감 세그먼트와 같은 모양 · `.cx-tabs, .fg-tabs` 한 규칙 · 메인 배율을 되돌린 크기). `D2 Min` 에서는 상단바처럼 돌 테두리 띠 안에 섰다(ADR-0799). 고른 칸은 강조색 테두리 하나로만 갈렸다. 같은 날 대장간 탭 버튼이 언제나 강화를 열게 됐다(ADR-0962) — 처음 서는 탭이 줄의 두 번째 칸이었다.

## 근거

- **사용자 지시** — 폴더에서 고르듯이 · 강화를 맨 왼쪽
- **새 부품을 만들지 않는다** — 폴더 탭은 이미 두 겉모양에 하나씩 있다(`Now` 원정 난이도 · `D2 Min` 편성 고르개 · 도감 판 위 고르개). 같은 말을 쓰면 「탭 = 그 아래 판을 바꾼다」가 화면마다 같다
- **강화가 맨 왼쪽** — 탭 버튼이 언제나 여는 탭(ADR-0962)이 줄의 첫 칸이다
- **버린 안 — 도감 세그먼트(`.cx-tabs`)도 같이 폴더 탭으로 바꾼다** — 지시는 대장간이었다. 도감 · 실험실 줄은 그대로 둔다(박스 위 전환 줄이 두 모양이 된다 — ⚠ 아래)

## 파급

- app.js `renderForge` — 탭 줄을 `segmented` 대신 직접 세운다(틈 `.fg-gap` · 탭 `.fg-tab` · 남은 자리) · 패널에 `.fg-panel`
- style.css — `.cx-tabs, .fg-tabs` 한 규칙에서 `.fg-tabs` 를 뗐다 · `Now` 폴더 탭 묶음 · `D2 Min` 판 밖 띠 규칙에서 `.fg-tabs` 를 떼고 폴더 탭 묶음
- ⚠ 박스 위 전환 줄이 두 모양이다 — 도감 · 실험실은 세그먼트, 대장간은 폴더 탭. 하나로 맞추면 도감 쪽을 폴더 탭으로 옮기는 것이 먼저다
