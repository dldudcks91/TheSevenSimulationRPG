# ADR-0964 — 도움말 주제는 독립된 폴더이고 고른 폴더 내용만 스크롤한다

## 결정

왼쪽 메뉴의 각 주제를 독립된 도움말 폴더로 둡니다. 제목과 전체 검색 아래에 본문 윗변과 붙은 폴더 탭을 두고, 고른 폴더의 내용 하나만 펼칩니다. 본문을 끝까지 내려도 다른 폴더로 넘어가지 않습니다. 폴더별 스크롤 위치와 선택은 화면 상태에 보관해 폴더 전환·화면 갱신·다른 게임 탭에서 돌아왔을 때 복구하며 세이브에는 넣지 않습니다.

기존 도움말의 한/영 설명 범위와 메뉴 순서를 유지합니다. 검색은 모든 폴더의 이름·소제목·본문에서 여러 단어를 모두 포함한 설명을 찾습니다. 결과 없는 폴더는 비활성화하고, 고른 폴더에 결과가 없으면 첫 결과 폴더를 엽니다. 전체 결과가 없으면 본문 자리에 결과 없음 상태를 표시합니다. 검색을 지우면 모든 설명을 복구합니다. 폴더 탭은 좌우 방향키·Home·End로도 선택할 수 있습니다.

## 맥락

도움말은 모든 탭의 설명을 하나의 긴 본문에 붙이고 목차 버튼으로 해당 제목까지 스크롤하는 방식이었습니다. 읽는 섹션을 표시해도 다음 주제가 계속 이어져 각 주제가 별도 문서처럼 갈리지 않았습니다.

## 근거

사용자는 각 주제를 폴더처럼 독립시키고 그 안의 내용만 내리도록 요청했습니다. 폴더를 고르면 본문 하나가 교체되는 방식으로 주제의 경계를 분명히 합니다. 폴더별로 읽던 위치를 보관하면 긴 설명을 오가며 다시 찾을 수 있습니다. 전체 검색을 유지해 폴더를 하나씩 열지 않고도 필요한 설명을 찾습니다.

## 파급

- `renderHelp`의 목차 점프·연속 본문을 폴더 선택과 독립 스크롤로 변경합니다.
- 도움말의 폴더·검색 안내 한/영 문구와 SCREEN_DESIGN §12·§2 박스 표를 맞춥니다.
- 게임 규칙과 저장 형식은 바뀌지 않습니다.
