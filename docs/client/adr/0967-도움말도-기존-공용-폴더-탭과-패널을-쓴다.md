## 결정

도움말 주제는 대장간의 공용 폴더 탭(`.fg-tabs` · `.fg-tab` · 틈과 남은 자리)과 패널(`.fg-panel`)로 표시한다. 탭은 패널 밖 윗변에 붙이고, 고른 주제를 공용 패널 제목으로 쓴다. 제목 아래 전체 검색을 고정하고 그 아래에서 고른 주제의 본문만 스크롤한다.

기본 스킨은 고른 탭 자리에서 패널 윗선이 끊긴다. D2 Min은 대장간·편성에서 쓰는 돌 폴더 탭과 같은 모양이며 고른 탭이 위로 솟는다. 주제 줄이 길면 메인 폭 안에서 가로로 이동하며, 화면 갱신 뒤 가로 위치를 복구한다. 도움말만의 탭 색·테두리·글자 크기를 따로 만들지 않는다.

## 근거

사용자는 새로 만든 도움말 폴더의 모양을 게임의 기존 화면과 맞추도록 지시했다. 이미 쓰는 폴더 탭과 패널을 재사용하면 두 스킨 모두 같은 선택 방식과 외형을 유지한다.

## 파급

- 주제 순서·전체 검색·키보드 선택·폴더별 스크롤 기억을 유지한다.
- 본문 제목의 중복을 걷고 공용 패널 제목으로 고른 주제를 표시한다.
- 게임 규칙·저장 형식·한/영 설명 범위는 바뀌지 않는다.
