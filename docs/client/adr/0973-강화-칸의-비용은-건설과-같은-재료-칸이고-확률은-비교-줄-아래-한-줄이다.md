## 결정

강화 작업 칸 아래쪽 둘을 고친다.

1. **비용 = 건설 · 연구소와 같은 재료 칸**(`matTile` · `.cn-mats`) — 골드 · 부위 재료 · 가루가 한 줄의 칸이다(그림 · 골드는 필요 수 · 재료는 보유/필요 · 모자라면 붉은 테와 수 · 칸 아래 이름). **칸 줄 오른쪽 끝에 [강화]** — 연구소 상세의 재료 칸 + 버튼 줄과 같은 꼴 · 한 줄에 안 들면(영어 재료 이름) 칸 줄은 그대로 두고 버튼이 다음 줄 오른쪽 끝으로 내려간다 · 이름은 칸 아래 두 줄까지 접힌다 · 작업 칸은 36 → 40%(옵션 칸이 그만큼 준다)
2. **성공 확률은 칩이 아니라 비교 줄 아래 한 줄** — `성공 확률` · `n%`(비교 줄과 같은 이름 · 값 꼴 · 두 줄을 위아래 가름선 한 쌍이 묶는다)

상한이면 확률 줄과 재료 칸이 빠지고 버튼 자리에 `fg.upMax` 가 선다(그대로).

## 맥락

그날 작업 칸 아래는 재료가 글자 줄(`1 최하급 철광석 · 1 최하급 가루`)이고 골드는 그림 칩, 확률은 같은 모양의 칩이라 `[성공 100%] [600] [강화]` 셋이 다 버튼처럼 읽혔다. 같은 「무엇이 얼마나 드나」를 건설 상세 · 연구소 상세는 재료 칸(그림 · 보유/필요)으로 보였다. 같은 날 패널 제목을 걷고 안쪽 상자를 걷는 안도 함께 넣었다가 사용자가 되돌렸다(아래 버린 안).

## 근거

- **같은 말은 같은 모양** — 비용은 건설 · 연구소에서 이미 재료 칸이다. 대장간만 글자 줄 + 칩이면 「모자란가」를 읽는 법이 화면마다 갈린다. 재료 칸은 보유 수까지 보인다(옛 글자 줄은 필요 수만)
- **누를 수 있는 것만 버튼 꼴** — 확률은 읽는 값이라 비교 줄과 같은 「이름 · 값」 줄이 맞다
- **버린 안 — 재료 칸과 버튼을 늘 두 줄로 나눈다** — 작업 칸 세로가 모자라 아래 줄이 스크롤로 밀린다. 연구소 상세가 이미 한 줄이다
- **버린 안 — 패널 제목 · 안쪽 상자를 걷고 도움말 `?` 를 고른 폴더 탭 안으로 옮긴다** — 같은 날 넣었다가 사용자 지시로 되돌렸다(「비용이랑 성공확률 빼고 롤백」). 폴더 탭 아래 같은 글자의 제목이 한 번 더 서는 것은 그대로다

## 파급

- app.js `forgeUpgrade` — ③ 확률 한 줄(`.fg-up-rows` 안 `.fg-up-cmp`) · ④ `.cn-mats`(`matTile`) + [강화]
- i18n — `fg.chanceLab`(성공 확률 / Success chance) 신설 · `fg.chance` 삭제
- style.css — 옛 칩(`.fg-up-chance` · `.fg-up-cost` · `.fg-up-mats`) 걷음 · `.fg-up` 작업 칸 40% · ADR-0737 뒤 남아 있던 강화 연출 규칙(`.fg-anim` 묶음) 걷음
