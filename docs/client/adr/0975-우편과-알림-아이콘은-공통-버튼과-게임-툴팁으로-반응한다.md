## 결정

상단바 우편함·알림 아이콘은 공통 `btn sm` 버튼을 쓴다. 버튼 크기와 그림 여백만 아이콘 자리의 규격으로 정하고 바탕·테두리·마우스를 올렸을 때의 반응은 기존 버튼 규칙을 받는다. `D2 Min`의 돌 버튼과 밝기 반응도 같은 규칙에서 나온다.

마우스를 올리면 `bindTipNode`가 기존 `#tooltip` 자리에 `tip-mini` 카드를 띄운다. 내용은 해당 언어의 「우편함」·「알림」 이름 한 줄이다. 커서 이동·나가기·손가락 길게 누르기는 기존 툴팁 장치를 따른다. 버튼을 누르거나 알림 버튼이 새로 그려지면 해당 툴팁을 정리한다.

편지 그림은 백색 봉투로 다시 그려 기존 PNG 원본과 WebP 설치본을 교체한다. 우편함과 알림 목록의 처리 방식은 ADR-0969를 따른다.

## 근거

- 별도 버튼 스타일로 만든 아이콘은 게임 스킨의 공통 반응을 받지 않아 같은 상단바의 다른 버튼과 다르게 보였다.
- 이름 한 줄은 기존 짧은 툴팁으로 읽을 수 있다. 같은 표시 장치를 쓰면 위치 보정·마우스 이동·터치 동작이 함께 유지된다.

## 파급

- `app.js`·`notifications.js`의 아이콘 버튼에 공통 클래스와 짧은 이름 툴팁을 연결한다.
- `style.css`의 아이콘 전용 규칙은 크기·그림·배지만 맡는다.
- `icons_source/mail/mail.png`와 `icons/mail/mail.webp`를 새 그림으로 교체한다. 종 그림과 게임 저장 형식은 그대로다.
