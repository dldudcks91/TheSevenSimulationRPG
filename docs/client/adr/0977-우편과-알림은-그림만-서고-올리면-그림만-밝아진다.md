## 결정

상단바의 편지봉투와 종은 배경·테두리·프레임 없이 백색 그림만 선다. 마우스를 올리면 아이콘 그림만 살짝 밝아진다. 알림 판을 연 상태에도 버튼 바탕은 투명하다. 키보드로 이동했을 때는 포커스 외곽선을 보여준다.

이름 한 줄을 보여주는 기존 `bindTipNode`·`tip-mini` 툴팁과 아이콘의 클릭·개수 배지는 유지한다. 편지 그림 재제작은 ADR-0975의 결정을 따른다.

## 근거

- 사용자가 아이콘의 마우스 반응을 그림의 밝기 변화로 구체화했다.
- 상단 아이콘의 모양과 기존 게임 툴팁의 표시 방식을 각각 유지할 수 있다.

## 파급

- `app.js`·`notifications.js`의 아이콘에서 공통 버튼 외형 클래스를 걷는다.
- `style.css`는 아이콘 바탕을 투명하게 고정하고 그림에만 밝기 반응을 준다.
- 우편 수령·알림 이동·대기 건수·저장 형식은 그대로다.
