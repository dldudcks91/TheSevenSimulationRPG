## 결정

종 아래의 작은 판 안에 「알림 · 미션 · 업적」 폴더 탭을 둔다. 모양은 기존 대장간 작업 폴더 탭을 따른다.

- **알림**은 처리 대기 중인 의뢰 목표 달성·탐험 완료·가입 희망 영웅과 해당 화면으로 가는 버튼을 보여준다.
- **미션**은 기존 초보자의 다음 할 일 한 개와 이동 버튼을 보여준다. 안내 접기는 유지하고, 첫 의뢰 보상을 받아 안내가 끝나면 빈 상태를 보여준다.
- **업적**은 회색의 꺼진 탭이다. 기존 게임의 닫힌 자물쇠 그림을 쓰며 누를 수 없다. 내용·보상·해금 조건은 정하지 않는다.

처음 고르는 폴더는 초보 안내가 있으면 미션, 없으면 알림이다. 같은 페이지에서 같은 게임을 보는 동안 열기·닫기와 다시 그리기를 거쳐도 고른 폴더·폴더별 스크롤을 유지한다. 다시 그리거나 폴더를 오갈 때 해당 컨트롤의 키보드 포커스도 보존한다. 새 게임이나 다른 세이브를 열면 초기화한다. 이 상태를 게임 저장에 넣지 않는다.

## 근거

처리 대기 결과와 초보 진행 안내를 각각의 폴더에서 확인할 수 있다. 업적은 화면의 잠긴 자리만 확보하며 별도 게임 규칙을 만들지 않는다.

## 파급

- `notifications.js`가 폴더 선택·스크롤·포커스를 관리하고 `style.css`는 기존 작업 폴더 탭의 모양을 재사용한다.
- `i18n.js`에 폴더 이름과 미션 빈 상태를 한영으로 둔다. 닫힌 자물쇠는 기존 공용 그림을 받는다.
- `game.notificationState`의 목표·목록·개수, 아이콘·배지·완료 말풍선·우편 수령 동작은 유지한다.
