# ADR-0981 — 수색 안내 칸도 수색 패널에 선다 · 영웅 고용은 후보 카드 둘이다

## 결정

선술집 윗줄의 **영웅 고용 패널은 후보 카드 둘 + 도구 줄**이다. 옛 명단 셋째 칸(수색 안내 · 얼굴을 누르면 그 영웅의 카드)은 **수색 패널의 첫 칸**이 된다 — 패널 머리(「수색」 + `?`) 아래 왼쪽에 후보 카드와 같은 크기의 그 칸 · 오른쪽에 얼굴 칸 묶음(두 칸씩). 안내 칸의 제목 「수색」은 패널 머리와 겹쳐 걷는다(사양 · 레어 확률 · 상태 줄은 그대로). 카드 폭과 칸 크기(= 초상)는 윗줄 폭에서 같은 식으로 푼다 — 윗줄 = 카드 셋 + 칸 둘 + 틈 · 패널 여백.

## 맥락

- 그날 수색 칸은 영웅 고용 옆 제 패널이었지만(ADR-0978), 수색 안내와 고른 영웅 카드는 영웅 고용 패널의 셋째 칸에 남아 있었다 — 얼굴을 누르면 다른 패널의 칸이 바뀌었다

## 근거

- **한 일은 한 패널** — 안내(다음 도착 · 레어 확률 · 칸 수)와 고른 영웅 카드는 수색의 것이다. 얼굴과 그 카드가 같은 패널에 서야 「누르면 옆에 선다」가 한눈에 읽힌다
- **크기는 그대로** — 카드 셋 · 칸 둘이 같은 윗줄을 나누는 것은 같아 카드 · 초상 크기가 바뀌지 않는다(1600×800 · 명단 상한보다 조금 좁은 것도 같다)
- **안내 칸 제목 걷음** — 같은 패널 머리에 「수색」이 이미 있다

## 파급

- `app.js:renderTavern` — 안내 칸 · 고른 영웅 카드가 수색 패널 본문(`.tv-search-row`)으로 · `visitCell` 제목 걷음
- `style.css` — `--tv-c`(카드 폭) · 명단 격자 둘 · 수색 패널 폭 = 카드 + 칸 둘 · `.tv-cands` 에 걸던 카드 바닥 줄 규칙을 수색 칸 카드에도
