## 결정

재료 칸의 단계 표식은 **칸 왼쪽 위 로마 숫자 `I` ~ `V`** 다(최하급 `I` → 최상급 `V`). **최하급도 `I` 을 단다.** 글씨는 표시 글꼴(Cinzel · `--font-display`) 굵게 · 청동 금색(`--bronze-fg`) · 검은 테두리 그림자(칸의 `+n` · `Lv.n` 배지와 같은 문법). 재료 칸을 쓰는 자리(창고 재료 탭 · 대장간 합성 사다리 · 건설 · 연구소 · 강화의 비용 칸)가 모두 같다.

## 맥락

그날 재료는 줄 넷 × 단계 다섯이었고 위 단계는 제 그림이 없어 최하급 그림을 빌렸다. 단계는 왼쪽 위 노란 마름모 점(`◆` 하급 하나 ~ 최상급 넷)으로 읽었는데, 사용자가 싸구려처럼 보인다고 했다. 옛 단계 그림(`icons/materials/*_t1` ~ `_t7`)은 서로 다른 재료라 단계 그림으로 못 쓴다(ADR-0857).

## 근거

- **로마 숫자** — 같은 자리 · 같은 크기로 단계가 바로 읽힌다. 표시 글꼴이 이미 게임 제목 · 머리 글자의 글꼴이라 분위기가 맞는다. 최하급에도 `I` 을 달아 「표식 없음 = 최하급」 규칙을 외울 필요가 없다.
- 거른 안 (시안 비교 · 2026-10-30):
  - **테두리 색**(회색 → 흰 → 파랑 → 노랑 → 주황) — 장비 희귀도 색과 겹쳐 「파란 테두리 = 매직」으로 읽힌다(ADR-0857 이 이미 거른 이유).
  - **밑변 눈금**(다섯 칸 막대) — 오른쪽 아래 보유 수량과 부딪힌다.
  - **그림 뒤 빛**(단계가 오를수록 진하게) — 이웃 단계(II · III)가 구분이 안 된다.
  - **단계마다 새 그림** — 근본 해결이지만 16장 발주가 든다. 그림이 오면 숫자를 걷을지는 그때 정한다.

## 파급

- `app.js:matPips` — 마름모 반복 → 단계 숫자 · CSS `.mat-tier` 의 글꼴 · 색
- 첫 칸(최하급)도 표식을 달아 「표식 없는 첫 칸이 묶음의 시작」(ADR-0982 근거)이 「`I` 칸이 묶음의 시작」으로 바뀐다
- ⚠ 단계마다 제 그림 발주는 열린 채다(`/icon-prompt`)
