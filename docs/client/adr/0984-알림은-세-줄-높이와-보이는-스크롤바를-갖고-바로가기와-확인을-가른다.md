## 결정

종 판의 본문은 알림 카드 약 세 개가 보이는 고정 높이다. 항목이 없거나 하나·여러 개일 때와 모든 폴더에서 같은 높이를 쓴다. 오른쪽 세로 스크롤바를 표시한다. 스크롤바 표시 예외는 이 본문에만 적용한다. 「확인할 일」 소제목은 걷는다.

각 알림 항목에는 왼쪽 [바로가기]와 오른쪽 [확인]을 둔다. 바로가기는 해당 기능 화면으로 이동하며 알림을 남긴다. 확인은 알림만 지운다. 확인으로 보상을 받거나 영웅을 고용하거나 다른 화면으로 이동하지 않는다. 미션 안내에는 기존 이동 버튼만 둔다. 업적은 잠긴 폴더로 유지한다.

확인한 알림은 안정적인 항목 ID로 기억한다. 기록은 브라우저 저장 어댑터를 통해 게임의 `seed:createdAt`별로 나누며 게임 세이브에는 넣지 않는다. 새로고침이나 같은 게임을 다시 불러와도 확인한 항목은 목록·배지·새 알림 연출에서 제외한다. 실제 게임에서 보상 수령이나 해당 처리가 끝나도 원본 대기 항목은 자연스럽게 사라진다. 탭의 기존 할 일 점은 실제 게임 상태를 계속 따른다.

배지는 아직 확인하지 않은 알림 수다. 초보 안내는 세지 않는다. 판을 열거나 바로가기를 누른 것만으로는 배지를 줄이지 않는다.

## 근거

본문의 크기를 일정하게 유지해 항목 수와 폴더에 따라 판이 늘거나 줄지 않게 한다. 실제 게임 활동으로 가는 행동과 알림을 정리하는 행동을 구분한다.

## 파급

- `notifications.js`가 확인 기록을 읽어 원본 대기 목록을 걸러 표시하고 항목의 두 버튼을 연결한다.
- `storage.js`가 브라우저의 게임별 확인 기록을 보관한다. 게임 저장 형식·보상·진행 판정은 바꾸지 않는다.
- `style.css`가 본문 높이를 고정하고 해당 본문의 세로 스크롤바만 복원한다.
- 아이콘 크기·마우스 반응·폴더 선택·처음 열기·완료 말풍선 규격은 유지한다.
