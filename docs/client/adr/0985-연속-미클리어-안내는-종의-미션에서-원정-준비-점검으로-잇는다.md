## 결정

현재 원정 중이거나 재출정을 기다리는 부대가 같은 난이도·칸에서 `balance.csv:expedition_retry_guide_runs` 이상 연속 미클리어하면 종의 미션에 준비 점검 안내를 보여준다. 최신 완료 기록의 전멸·시간 초과를 세고, 승리·직접 철수·꺼져 중단·다른 칸·다른 난이도는 연속을 끊는다. 진행 중 기록과 다른 부대 기록은 제외한다. 저장된 최근 기록 안에서만 세며 누적 실패 횟수는 저장하지 않는다.

첫 건설·첫 의뢰 수락 같은 구체적인 초보 행동은 우선한다. 원정으로 자금 마련·첫 의뢰 진행 같은 일반적인 안내와 안내가 없는 상태에는 준비 점검을 보여준다. 첫 의뢰 보상을 받은 뒤에도 이 안내는 가능하다. 배지의 처리 대기 건수에는 포함하지 않는다.

이동은 실제 출정 인원 중 첫 영웅과 해당 부대 인벤토리를 캐릭터 탭에 선택한다. 장비·마스터리·물약 점검과 이전 구간 파밍을 제안한다. 이동 직전 원정 문맥을 다시 확인하며 출발·철수·반복 설정을 조작하지 않는다. 진행 중 새 재도전 안내가 나타나면 기존 종 말풍선을 한 번 사용하고 같은 문맥의 횟수가 늘 때마다 반복하지 않는다. 처음 불러온 기록은 말풍선으로 재생하지 않는다.

## 근거

신규 진행 QA에서 같은 칸 재도전이 수백 번 이어졌다. 이전 구간 파밍 대조군은 같은 시작 조건의 노말 진행 시간을 줄였다. 특정 실패 원인을 추정해 전투를 바꾸기보다 플레이어가 준비 상태를 점검할 경로를 제공한다. 시간 초과는 철수로 표기되므로 안내는 패배 대신 미클리어라고 부른다.

리포트는 사실만 보여주고 버튼을 두지 않는 기존 결정(ADR-0210·0623)을 유지한다. 자동 파밍 전환은 원정 목적지와 반복 동작을 바꾸므로 이 개선에 포함하지 않는다.
