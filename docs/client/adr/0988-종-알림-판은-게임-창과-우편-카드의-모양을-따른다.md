# ADR-0988 — 종 알림 판은 게임 창과 우편 카드의 모양을 따른다

| **정한 사람** | 사용자 지시 — 「초인종 알림 우리 UI에 맞춰서 눌렀을 때 나오는 거 수정」 |
| **대체** | — |

## 결정

종을 눌러 여는 알림 판의 **겉모양을 게임 창과 같게** 한다. 동작(폴더 · 배지 · 바로가기 · 확인 · 말풍선 수명 · 고정 높이 · 보이는 스크롤바)은 그대로다.

- **껍데기** = 창(`.modal-box`)과 같은 바탕 · 테두리 · 여백 · 그림자. 겉모양 `D2 Min`이면 탐험 지점 창 · 분해함처럼 돌판 + 돌 테두리.
- **머리** = 창 머리(`.modal-head.plain` — 이름 + 아래 전폭 선)와 정사각 닫기 `.modal-x`.
- **폴더 탭** = 대장간 작업 탭과 같은 틈 · 남은 자리(`.fg-gap` · `.fg-fill`)를 갖춰, 탭 줄이 아래 본문 판의 윗변이 된다. `D2 Min`에서는 세 탭이 판 폭을 똑같이 나눠 갖는다.
- **항목** = 우편 카드(`.mail-card`)와 같은 카드 — 인벤토리 칸 바탕 · 왼쪽 굵은 경고색 띠 · 카드 사이 틈. 이름은 굵게, 세부는 작은 흐린 글씨.
- **빈 자리** = 카드가 세 장보다 적으면 남은 자리에 흐린 종을 든 점선 빈 칸이 깔린다(우편함의 흐린 편지봉투와 같은 규칙). 빈 폴더는 글 없이 빈 칸 셋이다. 빈 칸은 남은 높이를 나눠 가져 두 줄 카드가 서도 본문이 스크롤하지 않는다.
- **말풍선** = `D2 Min`에서 판과 같은 돌판 + 돌 테두리.

## 맥락

알림 판은 상단바에 붙어 뜨는 작은 판으로 따로 만들어져, 평평한 검은 바탕 · 작은 닫기 버튼 · 밑줄로만 가른 항목 줄 · 가운데 글 한 줄의 빈 상태를 썼다. 바로 옆 편지봉투가 여는 우편함 창은 게임 창 껍데기와 카드 · 흐린 빈 칸을 쓰고 있어, 나란히 선 두 버튼이 여는 판의 모양이 달랐다. `D2 Min`에서는 우편함 창이 돌판으로 입혀지는데 알림 판만 평평하게 남았다. 미션 폴더의 안내 카드는 마지막 항목의 밑줄 지우기 규칙에 걸려 아랫변이 빠져 보였다.

## 근거

- 편지봉투와 종은 같은 자리 · 같은 모양의 두 버튼이라, 여는 판도 같은 부품으로 읽혀야 한다. 새 모양을 만들지 않고 이미 있는 창 · 우편 카드 · 폴더 탭 규칙을 그대로 쓴다 — 겉모양을 바꾸면 알림 판도 같이 바뀐다.
- 빈 상태를 글 한 줄 대신 빈 칸으로 둔 것은 우편함과 같은 읽기(「여기에 들어온다」)이고, 폴더마다 · 개수마다 본문 모양이 같아진다(고정 높이 — ADR-0984). 빈 상태 글은 화면 읽기 프로그램용 이름으로만 남는다.
- 거른 안 — 판을 진짜 창(가운데 · 어두운 막)으로 띄우기: 알림은 하던 화면을 덮지 않고 종 아래에서 잠깐 보는 판이다(ADR-0969). 자리와 여닫는 길은 그대로 두고 겉만 맞춘다.

## 파급

- `notifications.js` — 머리 · 닫기 클래스, 폴더 탭 틈 · 남은 자리, 빈 칸(`SLOTS`) · 빈 폴더 이름(`nt.empty` · `nt.missionsEmpty`를 빈 칸의 이름으로).
- `style.css` — 알림 판 절을 창 · 우편 카드 규칙으로 다시 쓰고, 「겉모양 비교 — D2 Min」 절의 작은 창 돌판 줄에 판 · 말풍선을 더하고 폴더 탭 폭을 나눈다. 판 폭은 영어 폴더 이름이 들도록 넓혔다.
- 게임 로직 · 저장 형식 · 문구 키는 바뀌지 않는다.
