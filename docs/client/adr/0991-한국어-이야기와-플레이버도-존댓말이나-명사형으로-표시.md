# ADR-0991 — 한국어 이야기와 플레이버도 존댓말이나 명사형으로 표시

| | |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 모든 한국어 반말을 존댓말 또는 단순 어휘로 수정 |
| **대체** | [ADR-0725](0725-화면-한국어-문구는-한-줄이면-명사형-문장이면-합니다체다-이야기는-서술체-그대로다.md)의 이야기·플레이버 서술체 예외 |
| **대체됨** | — |

화면에 표시하는 한국어는 이야기와 대사를 포함해 존댓말 또는 자연스러운 명사형을 사용한다. 짧은 효과·상태 설명은 명사형으로, 안내 문단과 서사는 합니다체로 정리한다. 원고의 사건과 설정, 수치, 영어 문구는 유지한다.
