# ADR-0993 — 장신구 베이스와 연구소 도서관의 확정 기획을 화면에 연결한다

| | |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | [SCREEN_DESIGN](../SCREEN_DESIGN.md) §6·§8·§17 |
| **정한 사람** | 사용자 「구현해야할 기획 모두 구현해줘」 · DEV_PLAN R309·R321·R389·R399 |
| **대체** | ADR-0213의 새 목걸이 발동 줄 |
| **대체됨** | — |

확정된 장신구 베이스가 생성·전투·설명창에 반영되지 않았고 연구소의 도서관 줄은 데이터·정산·화면이 없었다. 최근 재료 비용 개편에는 분해 산출과 전직 골드 표시도 빠져 있었다.

반지의 베이스는 태그·효과·값 한 줄, 목걸이는 특정 기본 스킬 +n 한 줄로 표시한다. 기존 장비는 보존하며 새 장비부터 적용한다. 값이 없는 목걸이 베이스 줄은 생략한다. Shift 범위는 기존 옵션과 같은 API에서 읽는다.

연구소 도서관은 기존 줄 카드·지점·영웅 등록 조작을 재사용한다. 고른 줄에는 등록 영웅별 도안 생산량·후보 스킬·다음 한 장의 진행도를 보여 준다. 잠금은 책 제작을 여는 도서관 랭크를 읽는다.

전직 비용에는 골드 재료 칸을 쓰고, 분해 전후에는 가루와 부위 재료를 함께 보여 준다. 출정 창에는 선택 난이도의 몬스터 체력·데미지 배율을 표시한다. 수치는 로직과 CSV에서 읽는다.
