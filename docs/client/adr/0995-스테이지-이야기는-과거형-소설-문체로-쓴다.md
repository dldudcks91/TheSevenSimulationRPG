# ADR-0995 — 스테이지 이야기는 과거형 소설 문체로 쓴다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §2 · §4-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 스테이지 스토리 모두를 소설에 쓰이는 문체로 다시 수정 |
| **대체** | [ADR-0991](0991-한국어-이야기와-플레이버도-존댓말이나-명사형으로-표시.md) 중 스테이지 이야기의 합니다체 규칙 |
| **대체됨** | — |

출정 창의 스테이지 이야기는 과거형 소설 서술체(「~했다 · ~었다」)로 쓴다. 인물의 대사는 관계와 상황에 맞추며, 이름·행동으로 말하는 주체를 드러낸다. 장소와 몬스터를 나열하거나 죄종의 의미를 해설하기보다, 눈앞의 움직임과 바알의 반응이 이어지는 한 장면으로 구성한다.

이번 개정 범위는 플레이 가능한 1~5장의 장소 전체다. 한국어 원고와 영어를 함께 다듬고, 같은 장소의 칸 I~III은 하나의 이야기를 공유한다. 6·7장은 제외라는 기존 기획을 따른다. 바알은 용병들을 지휘하며, 입장 이야기는 전투 전의 대면까지 담는다.

나머지 화면의 말투는 각 규격을 따른다. 프롤로그·몬스터·탐험 이야기를 이 결정으로 함께 개정하지 않는다. 원고의 SSOT는 `src/data/stage.csv:story_kr/story_en`이다.
