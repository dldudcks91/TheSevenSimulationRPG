# ADR-0996 — 레벨업 후 마스터리 배분을 종 알림으로 안내한다

## 결정

종의 알림 폴더에 마스터리 포인트를 사용할 수 있는 영웅을 안내한다. 영웅별로 한 항목에 이름·레벨·남은 포인트를 표시하고, 바로가기는 해당 영웅을 선택한 캐릭터 탭의 스킬 창을 연다. 포인트를 모두 쓰거나 지금 배울 수 있는 마스터리 칸이 없으면 항목을 제외한다. 확인은 기존 알림과 같이 알림만 정리한다. 영웅과 레벨로 항목 ID를 정해 확인 후에도 다음 레벨업에서는 새 알림이 뜨며, 일부 포인트를 배분하면 같은 항목의 잔여 포인트만 갱신한다.

## 맥락

레벨업은 마스터리 포인트를 지급했지만 종 알림에는 의뢰·탐험·가입 희망 영웅만 표시됐다. 포인트를 쓰려면 캐릭터 탭에서 스킬 창을 직접 찾아야 했다.

## 근거

마스터리 배분도 처리할 수 있는 성장 행동이므로 기존 알림 폴더와 배지로 안내한다. 영웅마다 한 항목만 두어 여러 번 레벨업한 포인트를 합쳐 보여주고, 잠긴 칸·상한만 남아 실제로 배분할 수 없을 때는 행동을 권하지 않는다. 확인 기록을 영웅 ID만으로 묶으면 이후 레벨업까지 알림이 가려지므로 레벨도 포함한다.

## 파급

- `notificationState`가 기존 마스터리 학습 판정을 읽어 항목을 만든다. 게임 저장 형식은 늘리지 않는다.
- 알림 문구는 한영으로 제공하고 바로가기 직전에도 사용 가능한 항목인지 재확인한다.
- 기존 미션 우선순위와 알림 확인 동작을 유지한다.
