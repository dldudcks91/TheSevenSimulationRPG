## 결정

종의 숫자 배지는 미확인 알림 수와 현재 미션 수를 합한다. 미션 안내가 있으면 한 건이며, 초보 안내와 원정 준비 점검 모두 같은 규칙이다. 미션만 있어도 점 대신 숫자 1을 표시한다. 알림 폴더에는 미확인 알림 수, 미션 폴더에는 현재 미션 수를 각각 표시한다. 없는 항목의 폴더 배지는 비운다.

미션은 조건을 달성하거나 안내 조건이 사라질 때 개수에서 빠진다. 종을 열거나 미션을 접거나 바로가기로 이동해도 줄지 않는다. 알림의 [확인]은 해당 알림만 지우며 현재 미션은 그대로 센다.

## 맥락

미션 폴더에 다음 행동이 남아 있어도 종은 숫자 없이 점만 표시했다. 알림의 숫자와 미션의 점이 달라 사용자가 종에서 확인할 수 있는 전체 항목 수를 알기 어려웠다.

## 근거

종이 모으는 두 폴더를 합계에 반영하고 각 폴더에 개수를 두면 숫자가 어디에서 왔는지 알 수 있다. 미션의 존재와 접기·열기 상태를 분리해 안내를 다시 찾을 수 있게 한다.

## 파급

- `notificationState.count`는 원본 처리 대기 수 + 미션 수다. `items`는 기존 처리 대기 목록을 유지한다.
- `notifications.js`는 브라우저 확인 기록을 적용한 알림 수 + 미션 수로 표시 개수를 계산한다.
- 종 버튼의 한영 접근성 이름도 알림과 미션을 함께 센다는 뜻으로 맞춘다.
- 초반 튜토리얼의 구체적인 안내 방식은 별도 미확정 초안에서 검토한다.
