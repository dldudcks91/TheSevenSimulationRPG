# ADR-0999 — 레이드는 실험실 아이템 생성기 오른쪽 도구 탭이다

## 결정

실험실의 도구 탭은 **아이템 생성기 | 레이드** 순서다. 왼쪽 메뉴의 독립 레이드 항목은 걷고, 레이드 전장은 실험실에서 고른 도구의 본문에 표시한다. 세 편성과 전방 공동 보스의 배치·전투·조작·결과는 ADR-0997을 따른다.

선택한 도구는 `state.lab.tool`의 `item` 또는 `raid`로 유지한다. 다른 도구나 화면으로 이동해도 생성기의 조건·기록과 레이드의 준비·진행·결과 상태는 남는다. 레이드가 화면에 없거나 문서가 숨겨진 동안에는 연습 시계를 멈춘다. 다른 게임을 불러오거나 새로고침하면 연습은 초기화된다.

`?tab=lab&lab=raid`는 레이드 도구를 직접 연다. 기존 `?dev=raid`의 체험용 판 준비는 유지하면서 진입점을 실험실 레이드로 바꾼다. 옛 `?tab=raid`도 같은 도구로 연결한다. 실험실과 이 경로들은 개발 환경에서만 제공한다.

도움말은 별도 레이드 폴더 없이 **실험실** 폴더 안에 레이드의 흐름·명령·패턴·연습 조건 네 주제를 둔다. 전장의 `?` 버튼은 그중 첫 레이드 주제로 연결한다.

## 맥락

첫 시제품은 전투 메뉴의 독립 탭으로 구현했다. 사용자는 아이템 생성기 오른쪽에 레이드 탭을 두어 실험실에서 시험하기를 요청했다. 보상과 정식 반복이 미정인 연습의 현재 범위도 개발 도구와 맞는다.

## 근거

기존 실험실 도구 탭에 레이드를 추가하면 생성기로 아이템을 확인하는 흐름과 공동 보스 전투를 시험하는 흐름을 같은 곳에서 찾을 수 있다. 도구 왕복이 판을 버리지 않고, 화면 밖에서는 연습 시계를 멈추면 돌아와서 같은 상황을 검토할 수 있다. 기존 개발 주소는 같은 도구로 이어 검증과 체험 경로를 유지한다.

## 파급

- 앱의 도구 선택·화면 이동·URL·도움말 경로와 한영 문구를 맞춘다.
- 일반 메뉴의 레이드 항목과 도움말의 독립 레이드 폴더는 제거한다.
- 전투 로직·보스 표·해금·보상 없는 연습 범위는 유지한다. 정식 레이드의 최종 메뉴 위치는 이번 개발 도구 배치로 결정하지 않는다.
