# ADR-1000 — 도서관 전직 비용과 버튼은 스킬과 같은 줄 오른쪽에 선다

| | |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | [SCREEN_DESIGN §17](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 「도서관에서 전직에 필요한 골드 위치를 스킬과 동일한 높이로 옮기고 오른쪽끝으로 보내서 그 오른쪾에 전직버튼 만들어줘」 |
| **대체** | [ADR-0539](0539-전직-버튼은-패널-제목-오른쪽이고-이름-줄-아래-지금-가진-스킬이-선다.md)의 전직 버튼 자리 |
| **대체됨** | — |

고른 영웅 줄 바로 아래를 한 가로줄로 쓴다. 왼쪽에는 지금 가진 스킬 카드 셋, 오른쪽에는 전직 골드 비용, 그 바로 오른쪽 끝에는 [전직] 버튼을 둔다. 골드는 기존 재료 칸의 그림과 필요량 표시를 재사용한다.

갈래를 골라야 버튼이 켜지고, 전직 기능이 잠겨 있으면 버튼을 숨긴다. 전직 중·후에는 비용과 버튼을 표시하지 않는다. 현재 스킬과 갈래 선택, 비용 판정, 전직 시작 동작은 그대로 유지한다.

골드가 스킬 위의 별도 줄을 차지하고 버튼은 패널 제목에 떨어져 있어 비용과 실행 자리가 멀었다. 같은 높이의 오른쪽에 비용과 버튼을 붙여 전직 비용을 읽고 바로 실행할 수 있게 한다.
