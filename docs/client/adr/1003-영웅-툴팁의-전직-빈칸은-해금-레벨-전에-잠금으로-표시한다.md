# ADR-1003 — 영웅 툴팁의 전직 빈칸은 해금 레벨 전에 잠금으로 표시한다

## 결정

영웅 호버 툴팁의 전직 스킬이 비어 있고 영웅 레벨이 전직 해금 레벨보다 낮으면, 셋째 칸 가운데에 캐릭터창과 같은 회색 자물쇠를 표시한다. 해금 레벨은 `balance.csv:advance_unlock_level`을 읽는다. 해금 뒤 아직 배우지 않은 전직 스킬은 빈칸이며 이미 배운 스킬은 그대로 표시한다.

## 맥락

장비 오른쪽의 스킬 세 칸을 확인할 때, 전직을 배울 수 없는 영웅과 아직 배우지 않은 영웅이 모두 같은 빈칸으로 보였다. 사용자는 해금 레벨 전임을 잠금 표시로 구분하도록 요청했다.

## 근거

캐릭터창의 회색 잠금 SVG와 크기 규칙을 공유하면 같은 스킬 칸으로 읽힌다. 빈칸에만 표시하여 이미 배운 스킬의 아이콘과 레벨을 가리지 않는다.

## 파급

- 관전 · 편성 · 출정 창 등 영웅 툴팁을 공유하는 모든 자리에서 같은 규칙을 적용한다.
- 장비와 스킬의 배치, 칸 크기, Alt 장비 hover는 유지한다. 몬스터에는 적용하지 않는다.
- 자물쇠 SVG는 `mock.js:lockIcon`을 앱과 툴팁이 공유하며 크기 규격은 [src/ui/README.md](../../../src/ui/README.md)를 따른다.
