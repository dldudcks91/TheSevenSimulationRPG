# ADR-1004 — 초반 안내는 실제 기능 옆에서 다섯 가지만 알린다

## 결정

첫 원정, 장비 비교, 마스터리 배분, 물약, 건설의 다섯 가지를 실제 기능 가까이에 작은 안내 카드로 표시한다. 카드 하나와 대상 강조만 두고, 해당 화면에서 행동할 수 있을 때 안내한다. 인물이나 화면을 가리는 배경, 자동 화면 전환과 자원 사용은 없다. 안내 중에도 전투와 일반 조작은 계속된다.

확인한 안내는 게임별 브라우저 기록에 남긴다. 새 게임에서 자동 시작하고 기존 진행 세이브에는 자동으로 시작하지 않는다. 설정의 초반 안내 [다시 보기]로 현재 게임의 기록을 초기화해 현재 가능한 안내를 다시 볼 수 있다. 확인 직후 같은 화면의 다른 안내를 연달아 표시하지 않는다.

## 맥락

초보 미션은 다음 할 일을 종에서 찾을 수 있게 했지만, 장비 비교나 마스터리처럼 기능을 실제로 사용하는 방법은 별도 학습이 필요했다. 사용자는 화면이 따라가는 완전한 튜토리얼과 단순 추천 알림 사이에서 가볍게 설명하는 방식을 선택하고, 안내 인물의 등장을 원하지 않았다.

## 근거

실제 기능을 보는 순간 그 위치에서 짧게 설명하면 조작과 설명이 이어진다. 화면을 바꾸거나 클릭을 강제하지 않아 자동 원정과 플레이어의 선택을 유지한다. 다섯 가지로 범위를 제한하고 확인 후 다음 상황을 기다려 초반에 설명이 몰리지 않게 한다.

## 파급

- `tutorial.js`와 `tutorial.css`가 카드·대상 강조·위치를 관리하며 앱이 화면과 상태에 맞는 후보를 제공한다.
- `storage.js`의 `thesevensim.tutorialSeen`은 `seed:createdAt`별 확인 기록을 게임 세이브와 분리한다.
- 한영 안내 문구와 설정의 [다시 보기]를 제공한다. 게임의 보상·난수·저장 형식은 바꾸지 않는다.
- 안내 카드는 종 배지 개수에 추가하지 않으며 확인해도 기존 미션과 알림의 처리 상태는 그대로다.
- 상세 규격은 [초반 안내](../../game_design/tutorial_draft.md)를 따른다.
