# ADR-1005 — 적용된 장비 발동 접사는 미적용 표지를 떼고 옛 목걸이 발동은 남긴다

| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 아이템 툴팁 |
| **정한 사람** | 사용자 「타격 시 스킬붙는거말고 다른것들도 모두 적용해줄래? 아물렛 반지 모두」 |
| **대체** | ADR-0213의 발동 접사 미적용 표지 범위를 실행 상태에 맞춰 갱신 |

## 결정

타격 · 시전 · 피격 발동 접사는 착용 부위와 관계없이 전투에 적용되므로 옵션 줄의 「(미적용)」 표지를 없앤다. 반지 · 목걸이의 접사도 같은 규칙이다. 발동 조건 · 확률 · 스킬 이름을 적는 기존 문장은 유지한다.

퇴역한 옛 목걸이의 독립 `item.proc`은 전투에서 읽지 않으므로 해당 줄에는 「(미적용)」을 남긴다. 새 목걸이의 특정 스킬 +n과 반지의 태그 효과 표기는 기존 규칙을 따른다.

## 맥락과 근거

시전 · 피격 발동이 작동한 뒤에도 상태 표지가 남으면 실제 장비 효과를 잘못 안내한다. 표지는 전투가 읽는 접사와 실행하지 않는 옛 저장 필드를 구분해야 한다.

## 파급

- 캐릭터 · 가방 · 드롭 · 비교 카드가 공유하는 옵션 사전의 `inert` 판정으로 표시한다.
- 발동 시전은 관전의 액티브 쿨 칸 · 행동 게이지를 바꾸지 않는다. 실행 계약은 [INTERFACE §2-6](../INTERFACE.md)이 정한다.
