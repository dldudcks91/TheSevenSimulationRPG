# ADR-1006 — 프롤로그는 과거형 소설 문체로 쓴다

| | |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | [SCREEN_DESIGN §2 · §3-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 프롤로그의 존댓말을 소설 형태의 글귀로 다시 수정 |
| **대체** | [ADR-0991](0991-한국어-이야기와-플레이버도-존댓말이나-명사형으로-표시.md) 중 프롤로그의 합니다체 규칙 |
| **대체됨** | — |

프롤로그 다섯 씬은 과거형 소설 서술체(「~했다 · ~었다」)로 쓴다. 명사 나열과 해설을 장면의 흐름으로 잇고, 바알의 속마음과 명령은 냉혹한 지휘관이라는 인물의 성격에 맞춘다. 화면 안내문의 존댓말 규칙을 프롤로그 서사에 적용해 분위기를 잃었던 문제를 바로잡는다.

사건과 설정은 유지한다. 일곱 칼은 왜곡된 기억이며, 바알은 추락 후 직접 싸우지 못하고 용병들을 지휘한다. 원고 `docs/game_design/story/prologue.md`와 화면 문구 `src/ui/i18n.js:pro.*`를 일치시키고, 영어도 같은 내용과 과거형 시제로 다듬는다.
