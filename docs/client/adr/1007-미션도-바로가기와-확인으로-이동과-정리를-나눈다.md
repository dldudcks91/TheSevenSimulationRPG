## 결정

상단 건설 미션 제목을 「상단을 건설하세요」로 표시한다. 모든 미션 카드에는 알림과 같은 순서로 [바로가기]와 [확인]을 둔다. 바로가기는 해당 기능으로 이동하고, 확인은 현재 미션만 목록과 표시 개수에서 지운다. 확인해도 건설·원정·보상·게임 진행 상태는 바뀌지 않는다.

확인 기록은 기존 알림 확인 저장소에 게임별로 남긴다. 미션 종류와 건물·의뢰·원정 부대·난이도·스테이지의 문맥으로 식별하며, 다음 단계나 다른 대상의 미션은 새로 표시한다. 같은 원정 준비 점검의 연속 미클리어 횟수가 늘거나 대상 영웅이 바뀌는 것만으로는 확인한 안내를 다시 띄우지 않는다.

## 맥락

알림 카드에는 이동과 확인을 분리한 버튼이 있었지만 미션에는 바로가기만 있었다. 사용자가 내용을 읽은 뒤 미션 표시를 정리할 수 없었고, 상단 건설 제목도 행동과 해금 효과를 함께 적었다.

## 근거

같은 종 안의 카드가 같은 방식으로 반응하게 한다. 미션 확인과 실제 목표 달성을 분리해 화면 정리 때문에 자원을 쓰거나 다음 단계가 자동 완료되는 일을 막는다.

## 파급

- `notifications.js`가 미확인 알림과 미확인 미션을 걸러 목록·종 합계·폴더 배지에 반영한다.
- `notificationState`는 실제 게임 상태의 원본 안내와 개수를 그대로 제공한다.
- 미션 제목은 한영으로 맞추고 기존 게임별 확인 저장소를 재사용한다. 게임 저장 형식은 바꾸지 않는다.
