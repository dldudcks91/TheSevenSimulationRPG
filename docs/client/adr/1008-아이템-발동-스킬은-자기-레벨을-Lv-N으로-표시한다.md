# ADR-1008 — 아이템 발동 스킬은 자기 레벨을 Lv.N으로 표시한다

## 결정

아이템 발동 옵션의 스킬 이름 앞에 실제 레벨을 붙여 「Lv.1 파이어볼」로 표시한다. 영어도 「Lv.1 Fireball」이다. 기존 발동 조건 · 확률 문장 안에서 이 이름을 사용한다.

새 발동 접사는 모두 Lv.1로 생성한다. 레벨이 없거나 잘못된 옛 값은 Lv.1로 표시한다. 퇴역한 옛 목걸이 발동 줄도 같은 이름 표기를 쓰되 「(미적용)」은 유지한다.

목걸이 베이스의 특정 스킬 +n은 영웅이 가진 스킬을 올리는 옵션이므로 기존 「파이어볼 +1」 표기를 쓴다.

## 맥락과 근거

아이템에 박힌 발동 스킬은 자체 레벨을 저장하고 그 레벨로 실행한다. 레벨을 이름 옆에 적으면 캐릭터가 책으로 올린 스킬 레벨과 장비 발동의 실제 레벨을 확인할 수 있다.

## 파급

- 반지 · 목걸이를 포함한 모든 부위의 발동 옵션에서 같은 표기를 사용한다.
- 카드 · 비교 · 드롭 · 강화의 공유 옵션 문장이 같은 레벨 기본값을 읽는다.
- 레벨 저장과 실행 계약은 [INTERFACE §2-5 · §2-6](../INTERFACE.md)이 정한다.
