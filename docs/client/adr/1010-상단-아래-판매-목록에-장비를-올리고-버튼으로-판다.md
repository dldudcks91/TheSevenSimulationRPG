# ADR-1010 — 상단 아래 판매 목록에 장비를 올리고 버튼으로 판다

| 항목 | 내용 |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | §8-3 상점 |
| **대체** | ADR-0365의 상점 클릭 장착 · ADR-0367의 상단 높이 |
| **대체됨** | ADR-1011(구매·판매 배치) |
| **근거** | 사용자 「상단의 아래에 판매기능」 · 「인벤토리를 클릭하면 아이템이 장착되는게 아니라 … 판매에 올라가도록」 · 「레벨 등급에 따라 상점 판매가의 1/3가격」 |

## 결정

상단 구매 패널 아래에 판매 패널을 둔다. 상점 화면의 창고 · 인벤토리에서 장비를 누르면 판매 목록에 올리고 다시 누르면 뺀다. 목록의 장비를 누르는 것도 선택 해제다. 실제 처리는 [판매]가 맡는다.

판매가는 아이템 레벨 · 등급으로 구하는 상점 장비 가격에 `balance.csv:shop_sell_divisor`를 적용하고 장비마다 소수점을 버린다. 부위 · 옵션 · 강화는 판매가를 바꾸지 않는다.

## 맥락과 근거

잉여 장비를 골드로 바꾸는 창구를 상단에 더한다. 장비를 선택하자마자 없애지 않고 목록과 합계를 먼저 보여 주면 여러 장비의 거래를 확인한 뒤 실행할 수 있다. 분해는 재료, 판매는 골드를 얻는 선택으로 남는다.

## 파급

- 캐릭터 · 원정 등 다른 화면의 클릭 장착은 유지한다.
- 잠긴 장비 · 착용 중인 장비 · 상자는 판매 대상에서 뺀다.
- 상점의 오른쪽 교역소 · 특수상단은 위아래 배치를 유지한다.
