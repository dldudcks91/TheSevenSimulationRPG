# ADR-1011 — 상점은 장비창을 빼고 구매와 판매를 좌우로 둔다

| 항목 | 내용 |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | §8-3 상점 |
| **대체** | ADR-0365의 영웅 장비 패널 · ADR-0367의 열 너비 · ADR-1010의 구매·판매 배치 · 구매 패널 제목 |
| **대체됨** | — |
| **근거** | 사용자 「상점에서는 장비창을 빼버리고 구매와 판매로 좌우로 나눠보자」 |

## 결정

상점 본문의 영웅 장비 패널을 없애고 구매와 판매를 같은 높이로 나란히 둔다. 왼쪽이 구매, 가운데가 판매이며 오른쪽 보조 열은 위 교역소·아래 특수상단으로 유지한다. 본문의 세 열은 폭이 같다. 일반 상단의 구매 패널 제목은 「구매」다.

맨 위 영웅 띠와 맨 아래 창고·인벤토리는 유지한다. 영웅 띠는 비교 대상과 상품 교체 레벨을 고른다. 착용 장비는 영웅 툴팁과 상품 비교 카드에서 확인한다.

## 맥락과 근거

판매할 장비를 고르는 동안 구매 목록과 판매 목록을 함께 볼 수 있도록 거래 창구에 본문 높이를 배분한다.

## 파급

- 판매 선택·해제·실행과 레벨·등급별 상점 기준가의 판매 비율은 유지한다.
- 캐릭터와 대장간의 영웅 장비 패널은 각 화면 규격을 따른다.
- 교역소와 특수상단은 별도 패널이며 보조 열의 높이를 반씩 나눈다.
