# ADR-1012 — 첫 레벨 보상은 바로 배우는 스킬북이다

| 항목 | 내용 |
|---|---|
| 상태 | 확정 · 2026-10-30 |
| 화면 | §4-3 원정 리포트 · §17 도서관 |
| 대체 | ADR-0680의 리포트에는 도안만 표시하는 범위 |
| 근거 | 사용자 「도안으로 주지말고 그냥 스킬북으로 줘라 … 처음에 약초없어가지고」 |

첫 책 사용 레벨 보상은 재고에 들어가는 완성된 스킬북 한 권이다. 제작 재료가 없는 초반에도 도서관에서 바로 배울 수 있어야 한다. 영웅별 한 번·해당 직업 1티어·고유 제외·무작위 선택은 유지한다.

원정 획득 격자는 이 책을 장비 뒤에 표시하며 「스킬북 / Book」 배지로 도안과 구분한다. 기존 도안·재료는 그 뒤에 놓고 획득 칸 수에도 책을 포함한다. 도서관은 기존 가진 책 선택·배우기 조작을 사용한다.

옛 원정 레벨 보상 기록과 미사용 도안이 남아 있으면 로드에서 같은 책으로 한 번 교환한다. 기록이나 도안이 없으면 추측해 재지급하지 않는다.
