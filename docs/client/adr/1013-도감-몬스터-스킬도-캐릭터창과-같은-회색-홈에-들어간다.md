# ADR-1013 — 도감 몬스터 스킬도 캐릭터창과 같은 회색 홈에 들어간다

## 결정

도감 몬스터 목록 카드와 상세 툴팁의 스킬 칸에 캐릭터창 · 영웅 툴팁과 같은 회색 홈 테두리를 적용한다. d2min 스킨의 기존 `--sk-slot` 배경과 그림 안쪽 여백을 공유한다.

## 근거

[ADR-1002](1002-영웅-툴팁-스킬은-캐릭터창과-같은-회색-홈에-들어간다.md)의 스킬 칸 외형을 도감에도 이어 적용해 같은 스킬 표시를 통일한다. 목록과 상세 툴팁 모두에 적용하며, 칸 크기와 레벨 표시 · 스킬 설명창 동작은 유지한다.
