# ADR-1014 — 도감 스킬 칸을 키우고 왼쪽 경험치 바를 줄인다

| | |
|---|---|

| **대체** | ADR-1013의 목록 스킬 칸 크기 유지 |
| **대체됨** | — |

## 결정

도감 몬스터 목록의 스킬 칸을 키운다. 오른쪽 스킬이 늘어난 폭은 왼쪽 이름 · 경험치 바 영역에서 확보한다. 회색 홈과 그림 여백은 유지한다.

## 근거

회색 홈의 안쪽 여백을 적용하면서 스킬 그림이 작아졌다. 칸 자체를 키우면 테두리를 유지하면서 그림을 읽기 쉽게 되돌릴 수 있다. 상세 툴팁의 배치는 유지한다.
