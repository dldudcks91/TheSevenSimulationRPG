# ADR-1015 — 몬스터 호버도 영웅과 같은 장비 · 스킬 배치다

| | |
|---|---|
| **상태** | 확정 · 2026-10-30 |
| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 「영웅 hover하면 나오는거 몬스터에도 똑같이나오도록맞춰줘」 |
| **대체** | ADR-1001의 몬스터는 장비만 가운데 표시하는 부분 |
| **대체됨** | — |

## 결정

몬스터 호버 툴팁도 영웅처럼 기본 옵션 아래 왼쪽에 장비, 오른쪽에 세로 스킬 칸을 표시한다. 칸 크기 · 간격 · 회색 홈 테두리 · 그림 여백은 영웅과 공유한다. 스킬과 레벨은 관전 재생기가 받은 실제 값을 사용하고 순서는 관전 카드와 맞춘다. 남는 칸은 잠금 없이 비우며 툴팁 안의 스킬은 아이콘과 `Lv.n`만 표시한다. Alt 세부 옵션과 장비 hover는 기존 동작을 따른다.

## 근거

영웅과 몬스터가 같은 정보를 같은 자리에서 보여 주도록 공통 툴팁 조립과 스타일을 사용한다. 몬스터에게 영웅의 전직 해금 조건은 적용하지 않는다.
