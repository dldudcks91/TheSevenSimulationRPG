# ADR-1018 — 연구소도 줄·등록·연구를 실제 위치에서 안내한다

| | |
|---|---|
| **상태** | 확정 · 2026-10-31 |

| **정한 사람** | 사용자 — 「연구소 튜토리얼을 꼭넣어야해」 |
| **대체** | ADR-1004의 안내 대상을 다섯 가지로 제한한 부분 |
| **대체됨** | — |

## 결정

초반 안내에 연구소를 포함한다. 연구소의 줄 목록에서 생산·수색과 해금 조건을 설명하고, 열린 줄을 고르면 영웅 등록 효과를, 열린 지점을 직접 고르면 비용·시간·연구 방법을 설명한다. 등록 창을 먼저 열어도 영웅 카드에서 등록·이동·해제를 안내한다.

기존 카드 하나·대상 강조·게임별 확인 기록·설정의 다시 보기를 사용한다. 연구소의 고른 줄·지점이 바뀌면 다음 상황으로 보되 확인 직후 연속 표시는 하지 않는다. 모든 줄이 잠긴 첫 진입도 줄 목록의 설명을 받을 수 있다. 연구 안내는 실제 연구 버튼이나 진행 중 연구가 있는 열린 지점에만 붙인다.

## 근거

연구소의 줄 이름과 지점 그림은 서로 다른 내용을 열고, 영웅 등록은 원정과 함께 할 수 있어 화면만으로 처음 이해하기 어렵다. 기능이 열리는 조건과 실제 조작 위치를 함께 설명해야 연구소를 사용할 수 있다.

## 파급

- 한영 안내에 줄 목록·등록·연구 세 항목을 추가한다.
- 진행 중인 옛 게임은 설정의 초반 안내 [다시 보기]로 시작하는 규칙을 유지한다.
- 게임 세이브·보상·난수·해금·비용 판정에는 변경이 없다.
- 상세 규격은 [초반 안내](../../game_design/tutorial_draft.md)를 따른다.
