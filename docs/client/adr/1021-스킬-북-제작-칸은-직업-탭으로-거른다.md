# ADR-1021 — 스킬 북 제작 칸은 직업 탭으로 거른다

| | |
|---|---|

| **대체** | — |
| **대체됨** | — |

## 결정

스킬 북 제작 카드의 만들기 줄과 도안 칸 사이에 직업 탭을 둔다. 「전체」가 처음이고 뒤에 `class.csv` 행 순서의 직업이 선다. 정식 직업은 늘 서고, 그 직업 도안이 없으면 흐려 못 누른다. 전직 스킬은 갈래의 직업 탭에 든다. 고른 탭은 세이브하지 않는다.

## 근거

도안이 쌓이면 스킬 그림만으로 어느 직업의 책인지 찾기 어렵다. 탭 자리가 도안 유무로 움직이지 않아야 같은 자리를 다시 누를 수 있어, 도안이 없는 직업도 지우지 않고 흐리게 둔다. 고른 책이 없는 탭에서는 만들기 줄을 비운다 — 안 보이는 칸의 책을 만들지 않게 한다.

거른 안 — 영웅의 직업을 처음 탭으로(다른 직업 책도 읽을 수 있어 고른 영웅과 제작은 묶이지 않는다).

## 파급

- 직업은 `skill.defs[id].classId` 를 읽는다. 로직 · 세이브 변경 없음. 스킬 업그레이드 카드(가진 책)에는 탭을 두지 않는다.
- 개발 URL `?dev=book&bkcls=<class_id>` 로 탭에 닿는다.
