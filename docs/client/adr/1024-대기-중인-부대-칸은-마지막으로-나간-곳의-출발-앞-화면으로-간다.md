# ADR-1024 — 대기 중인 부대 칸은 마지막으로 나간 곳의 출발 앞 화면으로 간다

| | |
|---|---|
| **상태** | 확정 · 2026-11-02 |
| **화면** | [SCREEN_DESIGN §4](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「대기중인 파티를 클릭하면 해당 파티가 마지막으로 돌았던 원정화면이나 탐험화면 앞으로 이동시켜줘」 · 「앞」을 출발 직전 창으로 읽은 것과 기록이 없을 때의 처리는 제안 |
| **대체** | 원정이 없는 열린 부대 칸은 안 눌린다(ADR-0912 까지의 동작 · 칸이 말하는 글자와 색은 그대로다) |
| **대체됨** | — |

## 결정

원정이 없는 열린 부대 칸을 누르면 그 편성을 고르고 마지막으로 나간 곳으로 간다. 원정이면 원정 탭의 그 칸 · 그 단의 출정 창(반복은 꺼진 채)이고, 탐험이면 탐험 탭의 그 지점 창이다. 기록이 없으면 원정 스테이지 화면이다. 단이 잠겼거나 칸이 없어졌으면 창 없이 지금 단의 스테이지 화면이다. 나가 있는 탐험도 같은 길로 그 지점 창에 닿는다.

## 근거

대기 중인 부대는 같은 곳에 다시 보내는 일이 가장 잦다. 출발 직전 창에 세우면 [보내기] 한 번이면 되고, 잘못 눌러도 아직 아무 일도 안 일어난다. 탐험은 수령하면 기록이 걷히므로 편성마다 `lastGo` 를 따로 적는다. 옛 세이브는 그 부대의 최신 리포트로 원정만 찾는다.

거른 안 — 곧바로 다시 출격(눌렀다는 것만으로 부대가 나가면 되돌리기 어렵다) · 스테이지 목록까지만(한 번 더 찾아 눌러야 한다).

## 파급

- `presets[].lastGo` 선택 필드 · `game.lastGoOf`. 세이브 버전 무변경.
- 칸의 글자 · 색은 그대로다. 탐험 중인 부대도 「대기 중」으로 읽힌다.
