## 결정

원정 · 편성 · 건설 · 선술집 · 상점 · 대장간 · 도서관 · 콜로세움 · 도감 · 실험실 **열 탭의 아이콘을 굵은 도형 실루엣(Codex판)으로 바꾼다.** 탐험 · 도움말은 game-icons 그림 그대로다. 결투장 · 캐릭터 · 연구소도 그날은 game-icons 그대로 두고 새 그림을 다시 발주했다(고르면 그 그림으로 바뀐다).

| 탭 | 새 그림 |
|---|---|
| 원정 | 교차한 칼 |
| 편성 | 가운데가 앞에 선 셋 |
| 건설 | 망치 |
| 선술집 | 거품 오른 맥주잔 |
| 상점 | 차양 친 가게 |
| 대장간 | 모루 |
| 도서관 | 선반 위의 책 넷 |
| 콜로세움 | 우승컵 |
| 도감 | 눈 장식의 책 |
| 실험실 | 톱니 |

칠하는 법 · 크기 · 흐린 탭 · 고른 탭 규칙은 ADR-1028 그대로다.

## 맥락

ADR-1028 로 15장이 game-icons 그림으로 섰다. 사용자가 더 단순한 느낌을 물었고, 굵은 도형 몇 개로 직접 그린 단순판(24 격자 SVG)과 그 단순판 시트를 Codex 이미지 생성에 붙여 다시 그린 Codex판을 실제 탭 열에 입혀 비교했다. game-icons 그림은 20px 에서 안쪽 잔선이 뭉개졌다(지도 · 월계관 · 펼친 책). 단순판과 Codex판은 20px 에서 거의 같았다 — 참조를 붙이고 「같은 물건 · 세부 추가 금지」로 시켰기 때문이다.

## 근거

- **20px 에서 읽히는 쪽** — 굵은 면 · 큰 구멍만 있는 그림이 칸 크기에서 모양이 바로 잡힌다. 상단바 편지봉투 · 종의 단순 실루엣과도 결이 같다
- **Codex판을 쓴 이유** — 단순판과 같은 그림에 곡선 · 비례가 다듬어졌다(칼 손잡이 · 가게 틀 · 모루 뿔). 버린 안 — 단순판 SVG(한 장 고치기는 쉽지만 손으로 그린 도형이라 선이 거칠다)
- **탐험 · 도움말은 남긴다** — 사용자가 지금 그림을 골랐다. 그래서 game-icons 출처 표기는 남는다

## 파급

- 아트 — `icons_source/nav/<탭 id>.png` 열 장 교체 · 설치본 `icons/nav/` · Codex 시트와 지시문은 `icons_source/nav/source/codex/` · [assets/art/README.md](../../../src/assets/art/README.md) `icons/nav/` 절이 탭마다 출처를 든다
- i18n — `help.help.credits.body` 「왼쪽 탭의 아이콘」 → 「왼쪽 탭 아이콘 일부」
- 코드 · 화면 규칙은 안 바뀐다(`mock.js:NAV_ICON` 경로 그대로)
- ⚠ 결투장 · 캐릭터 · 연구소는 새 그림 후보를 고르는 중이다
