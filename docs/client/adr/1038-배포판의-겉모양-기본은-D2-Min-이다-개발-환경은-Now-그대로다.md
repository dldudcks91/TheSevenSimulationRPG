## 결정

`⚙` 설정 탭 `Skin` 줄을 **한 번도 누른 적이 없는 브라우저**(localStorage `devSkin` 없음)는 배포판에서 **`D2 Min`** 으로 연다. 개발 환경(이 PC 의 로컬 서버)은 `Now` 그대로다. 고른 적이 있으면 그 값이 먼저고, `?skin=` 개발용 URL 은 여전히 그 로드에서만 저장값보다 먼저다.

## 맥락

- 배포판 = GitHub Pages(`.github/workflows/pages.yml`) — 피드백용 웹판을 여는 사람은 설정 탭 마지막 줄까지 안 내려가 `Now` 만 본다
- 개발 환경 / 배포판 가름은 이미 `src/ui/env.js:DEV_HOST` 하나다(ADR-0751 — 모르는 주소는 배포판)

## 근거

- **주소를 `github.io` 로 안 박은 이유** — 개발 장치 · 플레이 기록이 같은 `DEV_HOST` 를 읽는다. 따로 판정하면 배포처를 옮길 때 둘이 갈린다
- **개발 환경을 안 바꾼 이유** — 요청이 「github 에서 켤 때」다 · 헤드리스 검증과 로컬 플레이의 기본 화면이 그대로다
- **줄을 배포판에서 안 숨긴 이유** — 배포판 사람도 `Now` 로 되돌려 견줄 수 있어야 비교 장치다

## 파급

- `src/ui/devcompare.js` — `SKIN_DEFAULT` 한 줄 · 되살림 블록이 저장값 없을 때 그 값을 건다 · `env.js` import
