# ADR-1047 — 원정 관전 아레나 오른쪽 위에 스테이지 남은 시간이 숫자로만 선다

| | |
|---|---|
| **상태** | 확정 · 2026-11-11 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) 「남은 시간」 |
| **정한 사람** | 사용자 지시 — 「스테이지별 남은시간을 오른쪽 위에 적어 줄 수 있을까?」 · 「그냥 시간만 넣어 남은시간이딴거넣지말고 알아서 이해하겠지」 |
| **대체** | — |
| **대체됨** | — |

## 결정

원정 관전의 아레나 **오른쪽 위 구석**에 그 스테이지의 남은 제한 시간을 **`9:41` 처럼 숫자만** 띄운다 — 「남은 시간」 같은 라벨은 안 붙인다. 값은 `[balance.csv:battle_timeout_sec]` 에서 재생 시각을 뺀 것(초 올림)이고, 재생 시각을 따라 줄어든다. 결투 관전에는 없다.

## 맥락

전투에는 제한 시간이 걸려 있었다 — 스테이지를 열 때 0 에서 출발해 라운드를 넘어 이어 세는 시계가 `battle_timeout_sec` 에 닿으면 런이 `timeout` 으로 끝난다(진 것과 같이 그 라운드 몫이 없고 같은 칸을 다시 돈다). 관전 화면에는 그 시계가 어디에도 없었다 — 헤드의 경과 시계는 2026-09-04 에 줄을 깎으며 지웠고([ADR-0032](0032-전투-헤드는-한-줄이다.md)), 경과 시각은 로그 줄 머리의 타임스탬프만 들고 있었다. 사용자가 「지금 시간 적용되고 있는 것 같은데」라며 남은 시간을 물었다.

## 근거

- **아레나 덮개라 세로를 안 먹는다** — ADR-0032 가 헤드에서 시계를 뺀 이유(가방이 화면 아래로 잘림)를 되살리지 않는다. 헤드는 그대로 한 줄이다
- **오른쪽 위** — 왼쪽 위는 버프 아이콘(신단 · 전술 · 도감) · 왼쪽 아래는 물약 칸 · 아래 가운데는 결과 띠가 쓰고, 오른쪽 위가 비어 있었다. 사용자가 고른 자리다
- **숫자만** — 사용자 지시. 줄어드는 `m:ss` 는 그 자체로 남은 시간으로 읽힌다 · 언어 문구가 없어 영어 길이 문제도 없다
- **경과가 아니라 남은 시간** — 묻는 것은 「언제 끊기나」다. 경과는 로그 타임스탬프가 이미 든다
- **경고 색은 안 단다** — 문턱을 정하는 CSV 키가 없다(SCREEN_DESIGN 원칙 「경고는 문턱 키가 있을 때만」)
- 거른 안: 헤드에 다시 넣기 — 줄 하나가 다시 생기거나 이름 말줄임이 더 깎인다. 라운드마다의 시계 — 제한은 스테이지 하나에 걸린다

## 파급

- `battle.js` — 아레나에 `.stage-clock`(원정만 · `stageId` 가 있을 때) · `paintClock` 이 걸음마다 글자가 바뀔 때만 갈아 끼운다 · 첫 프레임 · 되감은 자리에서도 한 번
- CSS — `.arena > .stage-clock` (버프 아이콘과 같은 바탕 · 테두리 · 높이)
- i18n — 새 키 없음(숫자뿐)
- 라운드 사이 숨 · 일시정지 동안은 시뮬 시각이 안 가서 숫자도 선다
