# ADR-1050 — 설정 탭을 게임 · 화면 · 연출 하위 탭 셋으로 나눈다

| | |
|---|---|

| **화면** | [SCREEN_DESIGN §2-2](../SCREEN_DESIGN.md) |

| **대체** | — |

## 결정

`⚙` 판의 설정 탭 맨 위에 하위 탭 한 줄 — `게임` · `화면` · `연출` — 을 세우고, 고른 하위 탭의 줄만 편다. **게임** = 초반 안내 · 닉네임. **화면** = 아트 스타일(초상 스타일이 둘 이상일 때만) · 아이템 그림 · 로그 · Skin. **연출** = 스킬 이펙트 · 이펙트 그림체 · 이펙트 투명도 · 기본 공격 이펙트 · 피격 반응 · 피격 시 흔들림 · 공격 시 흔들림 · Focus. 열면 `게임` 이고, 페이지를 연 동안은 마지막에 고른 하위 탭으로 연다(판의 탭 셋과 같은 규칙 — 세이브 · 브라우저 저장과 무관).

## 맥락

그날 설정 탭은 한 장에 초반 안내 · 스킬 이펙트 · 이펙트 그림체 · 이펙트 투명도 · 기본 공격 이펙트 · 피격 반응 · 피격 시 흔들림 · 공격 시 흔들림 · 로그 · 닉네임 · Focus · Skin 이 차례로 쌓여 있었다(아트 스타일은 초상 스타일이 하나라 안 섰다). 아이템 그림 묶음(Gemini · Codex)을 고르는 줄이 하나 더 필요해졌다(ADR-1051).

## 근거

- **줄이 무엇을 바꾸나로 가른다** — 관전에서 사건마다 먹는 연출(이펙트 · 흔들림 · Focus)은 `연출`, 그림 · 겉모양 · 로그 찍는 방식처럼 보이는 모양을 바꾸는 것은 `화면`, 계정과 안내처럼 게임 진행에 붙은 것은 `게임`
- **하위 탭은 설정 탭 안에 둔다** — 판의 탭 셋(설정 · Palette · Save)은 그대로다. 판 탭을 늘리면 개발 장치 탭(Palette · Save)과 플레이어 탭이 한 줄에 섞인다
- **열면 `게임`** — 처음 여는 사람에게 닉네임(콜로세움의 이름 — ADR-1042)이 먼저 보인다

**버린 안**

1. **판의 탭을 셋으로 늘린다**(설정 탭 대신 게임 · 화면 · 연출을 판 탭으로) — 배포 주소에서는 판 탭이 설정 하나뿐인데(ADR-0751) 개발 환경에서는 Palette · Save 와 다섯이 한 줄에 서서 좁은 판을 넘는다
2. **줄 사이에 머리글만 넣는다** — 줄 수가 그대로라 판이 길고, 사용자가 「나누고」라고 했다
