# ADR-1052 — 무기군 특성은 무기 툴팁의 [베이스] 줄로 선다

| | |
|---|---|
| **상태** | 확정 · 2026-11-12 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 아이템 툴팁 「옵션」 행 |
| **정한 사람** | 특성 한 줄을 툴팁에 세우는 것은 기획(weapon_group_draft §1 · DEV_PLAN R443 「툴팁 · 정보 판에 특성 한 줄」) / 자리 · 문구는 제안 |
| **대체** | — |
| **대체됨** | — |

## 결정

무기 툴팁의 옵션 목록에서 베이스 옵션 「무기 데미지 +n%」 바로 다음에 **그 무기군의 특성을 `[베이스]` 줄로** 세운다 — 도끼 「치명타 확률 +10%」 · 둔기 「강타 +1%」 · 석궁 「방어 무시 +20%」 · 성경 「버프 · 디버프 효과 수치 +20%」(한 줄). 값은 무기군이 든 값 그대로(`weapon_group.csv:trait_*` · 굴림 없음)이고 Shift 범위를 달지 않는다. 특성이 없는 무기군(양손검 · 창 · 활 · 오브 · 스태프 · 십자가)은 줄이 안 선다.

## 맥락

2026-11-11 다섯 직업 두 무기가 정해지며(weapon_group_draft §5 ~ §8) 무기군 넷에 특성이 생겼다 — 전사는 둔기 · 도끼의 기본 성능이 같아 **특성만이 두 무기를 가른다**. 특성은 아이템이 든 줄이 아니라 무기군이 든 값이다(굴림 없음 · 전투 합산이 든 무기의 무기군에서 바로 읽는다 — `hero.weaponTrait`).

## 근거

- **갑옷군 특성과 같은 자리 · 같은 태그**(ADR-0685) — 「그 부위 · 그 갈래면 무조건 붙는 것」이 `[베이스]` 의 뜻이다. 플레이어가 무기를 고를 때 보는 곳이 툴팁이라 특성이 안 보이면 전사의 두 무기가 같은 무기로 읽힌다
- **성경은 한 줄** — 태그 다섯(강화 · 축복 · 함성 · 오오라 · 저주)에 같은 값이 붙어 반지 줄 꼴(「[강화] 효과 수치 +20%」)로 다섯 줄을 세우면 옵션 목록이 특성으로 덮인다
- **Shift 범위가 없다** — 굴리지 않는 값이라 범위가 곧 값이다

**버린 안**

1. **무기 이름 아래 메인 옵션 행(공격력 · 공격 속도 옆)에 세운다** — 메인 옵션 행은 두 카드의 같은 x 에 값이 서는 비교 칸이고 특성은 무기군마다 있거나 없어 칸이 어긋난다
2. **성경을 태그마다 다섯 줄** — 위 근거
