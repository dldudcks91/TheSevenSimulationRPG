# ADR-1053 — 연구소 영웅 칸은 등록 칸 수만큼 서고 자물쇠 칸이 없다

| **화면** | [SCREEN_DESIGN §8](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | 0702 |
| **대체됨** | — |

## 결정

연구소 줄 카드의 영웅 칸과 고른 줄의 「등록 효과」 영웅 카드는 **등록 칸 수(`[balance.csv:lab_seats]`)만큼만** 선다 — 등록한 영웅의 얼굴 + 남은 칸 `+`. **안 열린 칸(자물쇠)은 없다.** 자물쇠를 누르면 「등록 칸」 지점을 고르던 조작도 없다.

## 맥락

2026-11-12 사용자 「3명으로하고 칸늘리는 연구를 없애봐」 · 「3칸을 기본으로 하도록 수정해봐」 — 연구소의 「등록 칸」 지점(줄마다 칸을 연구로 늘린다)이 지워지고 등록 칸은 다섯 줄 모두 고정 값이 됐다(GAME_DESIGN §9 11-12 · base_expedition_design.md §2-1 · DEV_PLAN R454). ADR-0702 의 자물쇠 칸은 「그 지점의 최대 칸 수까지 칸을 세우고 아직 안 연 칸은 자물쇠 — 누르면 그 지점」이었다. 열 지점이 없어져 자물쇠가 가리킬 곳이 없다.

## 근거

- 자물쇠는 「무엇을 하면 열린다」를 보여 주는 자리다(§2 「잠긴 자리의 한 줄」). 여는 길이 없는 칸에 자물쇠를 세우면 거짓 약속이다.
- 칸 수가 고정이라 「어디까지 열리는지」를 미리 보일 이유도 없다 — 서 있는 칸이 전부다.
- 거른 안 — 칸 수를 고정 값보다 크게 세우고 넘는 칸을 흐리게 둔다: 열 방법이 없는 칸이라 자물쇠와 같은 거짓이다.

## 파급

- `app.js` — `dpSeatSlots` 와 두 자리(줄 카드 영웅 칸 · 「등록 효과」)의 자물쇠 칸 반복을 걷는다 · 「등록 칸」 지점 값 표기(`dp.val.seats`)와 지점 이름(`dp.node.seats`)은 쓰는 곳이 없어 지운다
- 도움말 「연구소」 · 「등록」 문단에서 「등록 칸」을 연구 항목으로 적은 문장을 고친다
- 지점 그림 `icons/lab/node/seats` 는 파일만 남는다(쓰는 곳 없음)
