# ADR-1057 — 갑옷 갈래 특성은 아이템이 든 굴린 [베이스] 줄이다

| | |
|---|---|
| **상태** | 확정 · 2026-11-12 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 아이템 툴팁 「옵션」 행 |

| **대체** | [ADR-0685](0685-갑옷군-특성은-아이템-툴팁의-고정-줄로-선다.md) |
| **대체됨** | — |

## 결정

갑옷 툴팁에서 **갈래가 든 고정값 줄**(ADR-0685 — `armor_group.csv` 의 `aspd_pct` · `cdr_pct` 를 렌더러가 끼워 넣던 `[베이스]` 줄)을 걷는다. 갑옷 갈래 특성(경갑 공격 속도 · 로브 쿨타임 감소)은 투구 · 장갑 · 신발과 같이 **아이템이 든 굴린 `[베이스]` 줄** 하나로만 선다 — 다른 접사와 같이 서고 Shift 범위가 붙는다. 중갑은 특성이 없다.

## 맥락

2026-11-11 갑옷 갈래 개정(DEV_PLAN R446)으로 중갑 공속 손해가 지워지고 경갑 공속 · 로브 쿨감이 굴리는 특성 줄로 옮겨 갔다. 고정값 칸은 세 갑옷 모두 0 이 되어 ADR-0685 의 줄은 더는 서지 않았다. 2026-11-12 사용자가 빈 칸 삭제를 정해 칸 자체가 없어졌다 — 끼워 넣을 값이 없다.

## 근거

- **한 특성에 한 줄** — 고정값 줄과 굴린 줄이 같이 살면 같은 「공격 속도」가 두 번 설 수 있다. 네 부위가 같은 규칙(굴린 줄)이면 툴팁 읽는 법이 하나다
- **`[베이스]` 태그의 뜻은 그대로다**(ADR-0100 · 0714) — 그 갈래면 반드시 붙는 줄이다. 값이 아이템마다 다를 뿐이다

**버린 안**

1. **칸을 0 으로 남겨 두고 렌더러 길도 남긴다** — 읽히지 않는 칸 · 죽은 길이 남는다(데이터 형태 원칙 — 불필요한 칸을 두지 않는다)

## 파급

- 렌더러 `app.js:itemBodyHtml` — 갈래 고정값 줄 끼우기를 걷고 무기군 특성 줄(ADR-1052)만 끼운다
- 로직 `hero.computeCombat` 의 갈래 공속 · 쿨감 합산 · `data.js` 의 `aspdPct` · `cdrPct` 를 걷는다 — 계약은 INTERFACE §1 `armorGroups`
- 그 전에 얻은 경갑 · 로브는 특성 줄이 없다 — 소급하지 않는다(2026-11-12 사용자)
