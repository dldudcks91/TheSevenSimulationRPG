# ADR-1058 — 페이퍼돌 왼쪽 위는 잠긴 「죄종 인장」 칸이다

| | |
|---|---|
| **상태** | 확정 · 2026-11-12 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 — 「레이드보상으로 만들거임 일단 칸열어놓고 잠궈놔」 · 「화면에 그냥 칸만들고 거기 잠금처리해놓으면 되잖아」 |
| **대체** | — (§6 장비 패널의 「잠기는 칸은 없다」에 잠긴 인장 칸 하나를 더한다 · 착용 칸이 잠기지 않는다는 규칙은 그대로) |
| **대체됨** | — |

## 결정

캐릭터 탭 장비 패널의 페이퍼돌 3 × 3 에서 **비어 있던 왼쪽 위 자리**에 아홉째 칸 「죄종 인장」을 그린다. 칸은 **늘 잠겨 있다** — 가운데 닫힌 자물쇠 · 올리면 툴팁 카드 한 줄(「죄종 인장은 레이드에서 얻을 수 있습니다.」) · 누를 수 없다. **화면에만 있는 칸이다** — 착용 위치(`equip_slot.csv`)는 8 그대로이고 게임 로직 · 세이브 · 결투장 · 유닛 툴팁의 장비 3 × 3 은 바뀌지 않는다.

## 맥락

같은 날 죄종 마스터리 T2 를 「내 장비 중 그 죄종 수의 단 셋(3 · 6 · 9)」으로 바꾸면서, 착용 칸이 8 이라 9 단은 특수한 경로로만 닿게 했다(PLAN_mastery_tiers §0-1). 사용자가 그 경로를 **레이드 보상인 아홉째 칸**으로 정했고, 인장 아이템과 레이드 보상은 아직 데이터가 없다. 페이퍼돌 왼쪽 위는 2026-09-01 보조 슬롯 폐지(4행 → 3행) 뒤로 빈자리(`pd-gap`)였다.

## 근거

- **화면만 먼저 연다** — 로직 칸(`equip_slot.csv` 에 줄을 더한다)을 함께 열면 세이브 구조 · 자동 장착 · 결투장 장비 굴림 순서(같은 시드의 결과 — 골든) · 드롭 부위 목록이 같이 바뀌는데, 인장 데이터가 없어 아무것도 낄 수 없다. 사용자가 화면 칸만 고르고 로직 칸은 인장 데이터를 만들 때 함께 연다
- **자리는 빈자리 그대로** — 3 × 3 의 유일한 빈 칸이라 다른 칸을 옮기지 않는다
- **잠긴 칸의 문법은 액티브 칸과 같다** — 가운데 자물쇠(ADR-0425) · 툴팁 카드 한 줄(ADR-0427 · 0466 의 문장형). 열리는 길 한 줄이지 규칙 설명이 아니다(CLAUDE.md 규칙 7)
- **유닛 툴팁의 장비 3 × 3 에는 안 그린다** — 몬스터는 인장이 없고, 영웅 툴팁에서 잠긴 칸은 읽을 거리가 아니다
