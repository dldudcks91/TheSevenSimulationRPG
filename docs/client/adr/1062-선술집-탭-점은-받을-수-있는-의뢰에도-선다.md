# ADR-1062 — 선술집 탭 점은 받을 수 있는 의뢰에도 선다

| | |
|---|---|
| **상태** | 확정 · 2026-11-12 |
| **화면** | [SCREEN_DESIGN §1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 「선술집에 진행가능한 의뢰가 있거나 완료된 의뢰가 있으면 초록색 점 나오도록」 |
| **대체** | — *(ADR-0637 의 선술집 줄에 조건 하나를 더한다 · 0637 의 나머지는 그대로)* |
| **대체됨** | — |

## 결정

선술집 탭의 할 일 점(ADR-0637)이 서는 때에 **받을 수 있는 의뢰가 있다**를 더한다 — 의뢰 게시판이 열렸고, 받아 둔 의뢰 수가 동시에 받아 둘 수 있는 수(`[balance.csv:commission_slots]`)보다 적을 때. 기존 두 조건(수색 칸에 누가 기다린다 · 다 채운 의뢰가 [수령]을 기다린다)은 그대로다. 판정은 `game.navTodo` 한 곳이다.

## 맥락

이날 선술집 점은 수색 칸 · 다 채운 의뢰에만 섰다. 의뢰를 하나도 안 받아 둔 동안에는 게시판에 [받기]가 눌리는 카드가 서 있어도 탭 바에는 아무 표시가 없었다. 게시판은 선술집 탭을 그릴 때 빈 자리를 굴려 채운다(`commissionFill`) — 게시판이 막 열린 판은 탭을 한 번 열기 전까지 카드가 0장이다.

## 근거

- **하면 꺼지는 일이다** — 의뢰를 받아 자리를 다 채우면 꺼진다. ADR-0637 이 뺀 영입 후보(늘 있다 · 고용해도 안 꺼진다)와 갈린다.
- **판정은 카드가 아니라 남은 자리로 한다** — 「[받기]가 눌리는 카드가 있다」로 재면 게시판이 막 열린 판에서 탭을 열기 전까지 점이 안 선다. 게시판 자리 수가 동시에 받는 수보다 많아 자리가 남았으면 [받기]가 눌리는 카드가 늘 서므로, 남은 자리로 재는 것과 탭 안에서 보이는 것이 같다.
- ⚠ 받아 둔 의뢰가 없는 동안은 늘 켜진다 — 0637 이 경계한 「늘 켜진 점」에 가깝지만, 꺼지는 길(의뢰 받기)이 탭 안 한 번 누름이다.

## 파급

- `game.navTodo` 의 `tavern` 판정에 조건 하나(INTERFACE §2) · 단정 `navTodo` 갱신
- 문구 · i18n 키 · CSS 없음 — 점은 0637 그대로
- 상단 종 알림(`notificationState`)은 바꾸지 않았다 — 받을 수 있는 의뢰는 알림 항목이 아니다
