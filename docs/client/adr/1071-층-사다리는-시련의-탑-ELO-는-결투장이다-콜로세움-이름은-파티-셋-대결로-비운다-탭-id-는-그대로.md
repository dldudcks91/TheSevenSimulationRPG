## 결정

층마다 정해진 AI 팀을 한 층씩 오르는 오프라인 사다리(탭 id `colosseum`)가 **시련의 탑**(Tower of Trials)이고, 다른 플레이어의 방어 편성과 레이팅으로 겨루는 ELO 탭(탭 id `arena`)이 **결투장**(Arena)이다. **콜로세움**(Colosseum)이라는 이름은 파티 셋이 모두 나가는 새 대결(arena_design §10 · 초안 — 아직 화면이 없다)의 몫으로 비운다. 내비 자리는 그대로라 기타 묶음이 「시련의 탑 · 결투장 · 도감 …」 순이다.

**탭 id · 세이브 키 · 문구 키 · 개발 URL 은 그대로다** — `colosseum` 탭(`renderColosseum` · `G.colosseum` · `cs.*` · `?dev=colosseum`) = 화면 「시련의 탑」, `arena` 탭(`renderArena` · `G.arena` · `ar.*` · `?dev=arena`) = 화면 「결투장」.

**그림은 탭 id 를 따른 채 둔다** — 시련의 탑 = 칼(`duel`) 머리 그림 · 등급마다 배경, 결투장 = 콜로세움 건물(`icons/arena/colosseum`) 머리 그림 · 로마 콜로세움 배경. 콜로세움 화면이 설 때 그 건물 그림 · 배경을 어디에 둘지 정한다.

## 맥락

2026-10-24(ADR-0760) 에 ELO 가 콜로세움, 층 사다리가 결투장이 됐다. 사용자가 두 이름이 헷갈리고 AI 와 싸운다는 것이 이름에서 안 읽힌다고 했다. 같은 자리에서 「모든 파티가 참여하는 대결」을 새로 만들어 콜로세움이라 부르기로 했다(번호끼리 세 판 · 2선승 · 승자 잔류는 보류 — arena_design §10).

## 근거

- **시련의 탑은 「정해진 상대를 한 층씩 오른다」가 이름에서 읽힌다** — 층 · 승급전 · 등급마다 허름한 곳에서 정상으로 가는 배경이 탑을 오르는 모양과 같다
- **결투장은 「남과 한 판 붙는다」** — 레이팅 결투 · 친선전에 맞는다. 기획 문서의 넓은 뜻(영웅 팀 대 영웅 팀 전체 · 밸런스 기준 「PvP(결투장)」)도 이제 같은 쪽을 가리킨다
- **탭 id 는 안 바꾼다** — ADR-0760 근거 그대로(세이브 키 · 개발 URL · 단정 · 문구 키가 다 움직인다)
- **그림을 안 옮긴다** — 탑 그림이 아직 없고, 콜로세움 건물 · 배경은 곧 설 새 콜로세움의 몫이라 지금 옮기면 두 번 옮긴다

**버린 안**

1. **탭 id 까지 바꾼다** — 위 이주 비용 · `colosseum` id 를 새 콜로세움에 주려면 세이브 이주가 붙는다
