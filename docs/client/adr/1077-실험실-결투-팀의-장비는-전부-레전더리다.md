# ADR-1077 — 실험실 결투 팀의 장비는 전부 레전더리다

## 결정

실험실 결투의 두 팀은 장비를 **전부 레전더리**로 굴린다 — `arena.rollTierOpponent('champion', rng, taken, { floorRules: true, rarityWeights: { legendary: 1 } })`. 아이템 레벨 · 강화 · 책 · 전직 · 마스터리 · 짜기([ADR-1074](1074-실험실-결투-팀은-시련의-탑-층-AI-팀과-같은-짜기다.md)) · 물약은 그대로다.

## 맥락

직업별 세기를 장비 희귀도의 운 없이 보려는 요청이다. 챔피언 차림의 희귀도는 레어 · 매직 가중치라 같은 직업도 장비 줄 수가 판마다 다르다.

## 근거

- **장비를 맨 위로 맞추면 차이는 직업 · 스킬 · 옵션 굴림에서만 난다** — 만렙 끝의 결투를 보는 자리다
- 차림 표(`arena_tier.csv`)는 레전더리 칸이 없다 — 게임의 차림은 그대로 두고 등급 굴림이 가중치를 옵션으로 받는다

**버린 안**

1. **차림 표에 레전더리 칸을 더한다** — 게임의 결투 상대까지 바뀐다. 요청은 실험실과 측정이다
