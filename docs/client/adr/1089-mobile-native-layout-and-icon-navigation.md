# ADR-1089 — 모바일은 실제 화면 크기와 아이콘 메뉴를 사용한다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |
| **화면** | [SCREEN_DESIGN §1](../SCREEN_DESIGN.md) · §2 · §4 · [모바일](../MOBILE_UI.md) |
| **정한 사람** | 사용자 지시 / 세부 배치는 구현자 위임 |
| **대체** | 모바일의 고정 한 장 축소 · 세로 회전 안내막 · 최대화 시 내비 숨김 |
| **대체됨** | — |

## 문제

1600×800 한 장을 휴대폰에 통째로 축소하면 버튼과 글씨가 작아지고 세로 화면은 회전 안내막에 막힌다. 기존 최대화는 전장을 키우지만 메뉴를 숨기므로 사용자가 요구한 전투와 관리 화면의 왕복에 맞지 않는다.

## 결정

좁은 화면에서는 실제 뷰포트 크기로 배치하고, 세로 하단·가로 왼쪽에 원정·편성·캐릭터·건설·전체 메뉴 아이콘을 둔다. 모든 기존 탭은 전체 메뉴에 그대로 남으며 잠금·할 일 점·언어·새 게임도 유지한다. 관전은 기본으로 본문 전체를 쓰고 가방을 펼치는 보기를 별도로 제공한다.

관리 패널은 세로로 쌓고, 공간 관계가 필요한 판과 긴 표는 내부에서 스크롤한다. 툴팁의 길게 누르기·세부·범위·행동을 유지하면서 화면 안에서 읽게 한다. 기존 초상·아이콘·스킨·색 토큰을 사용한다. 참고작과 세부 규격은 [MOBILE_UI.md](../MOBILE_UI.md)에 둔다.

## 범위

모바일에 한해 기존 한 장 축소·세로 회전 안내막·최대화 시 메뉴 숨김을 대체한다. 넓은 데스크톱 창의 배치와 최대화는 유지한다. 내비게이션은 기존 버튼 행동을 호출하며 게임 규칙·저장 형식·전투 시계를 새로 만들지 않는다.

## 검증

`scripts/verify_mobile_ui.py`가 화면 크기·언어·스킨별 실제 터치 이동, 팝업, 장비 설명, 메뉴 접근성, 데스크톱 복귀와 기존 회귀 검사를 수행한다. 별도 실시간 장시간 검사는 전투 중 메뉴 왕복·회전·재접속을 반복한다. 브라우저 에뮬레이션은 실제 기기 검사와 구분한다.
