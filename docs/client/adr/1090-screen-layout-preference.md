## 결정

오른쪽 위 설정의 화면 탭에서 자동·PC·모바일을 고른다. 자동은 기존 화면 크기 판정을 쓰고, 수동 선택은 그 판정보다 우선한다. 선택은 즉시 반영하고 브라우저에 저장한다. 게임 세이브와 분리하며 새 게임·이어하기에서도 선택을 유지한다. 저장이 제한된 환경에서는 현재 실행 동안 선택을 유지한다.

세로 휴대폰에서 직접 PC를 고르면 회전 안내막을 표시하지 않는다. 사용자가 선택한 배치를 막지 않고 같은 설정에서 모바일·자동으로 돌아갈 수 있게 한다.
