# ADR-1102 — 도감 캐릭터 묶음 제목엔 도움말 물음표를 안 단다

## 결정

도감 › 캐릭터 세그먼트의 직업 묶음 제목(「전사」 · 「기사」 …) 옆에 **도움말 `?` 표시를 안 단다**. 머리는 직업 이름 + 오른쪽 끝까지 가는 선뿐이다. 다른 세그먼트(아이템 · 스킬)의 묶음 제목은 그대로 `?` 를 단다.

## 맥락

그날 도감 묶음 제목(`.ix-title`)은 전부 `app.js:bindSectionHelp` 가 제목 글씨 바로 뒤에 도감 도움말(`hint.codex`) `?` 를 달았다. 같은 날 캐릭터 묶음 머리가 직업 이름 + 선으로 바뀌고([ADR-1091](1091-도감-캐릭터는-직업-묶음-둘이-한-줄이고-머리는-직업-이름과-선이다.md)) 장수가 빠져([ADR-1100](1100-도감-캐릭터-묶음-머리는-장수를-안-적는다.md)) 다섯 머리에 같은 `?` 다섯 개만 남았다.

## 근거

- **사용자 지시.** 머리가 왼쪽 메뉴 묶음 제목(「전투 ───」)과 같은 꼴이 되려면 이름과 선만 서야 한다
- 같은 도움말이 한 화면에 다섯 번 서서 더하는 정보가 없다. 도감 도움말은 다른 세그먼트 제목과 도움말 탭(§12)에 남는다

## 파급

- 렌더러 — `app.js:bindSectionHelp` 가 `.ix-chars` 안의 `.ix-title` 을 건너뛴다
