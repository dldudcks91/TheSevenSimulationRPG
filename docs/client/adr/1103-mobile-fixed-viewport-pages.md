## 결정

기존 UI의 색감·장식·초상·아이콘만 유지하고 모바일 화면 구조는 다시 구성한다. 화면 전체를 세로로 스크롤하지 않는다. 상단 상태와 메뉴를 고정하고 관리 기능은 탭으로 나누어 한 패널씩 보여준다. 목록·설명·공간형 트리만 해당 영역 안에서 스크롤한다. 전장은 작은 세로 화면과 가로 화면에서도 조작부까지 한 화면 안에 맞추며, 가방과 통계는 전장을 늘리지 않고 다른 화면으로 전환한다.

선택과 행동은 기존 DOM 이벤트와 게임 함수를 유지한다. 모바일 탭 상태는 UI 모듈에만 두고 세이브·전투 시계·게임 규칙은 바꾸지 않는다. 설정의 자동·PC·모바일 선택은 유지한다.
