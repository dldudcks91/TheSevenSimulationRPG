## 결정

1. 스킬 창 포인트 칸 — 스킬 포인트 「남은 / 전체」 **오른쪽에 전직 포인트 「남은 / 전체」**를 같은 모양으로 세운다. 전직 포인트는 전직 스킬 배우기 몫이다(갈래가 서면 하나 · 배우면 쓴다). 전직하기 전 영웅은 안 세운다. 값은 `advanceState.hero.learnPts` 가 낸다.
2. `D2 Min` 전직 판 머리 아래에도 죄종 · 직업 판과 같은 2px 줄을 `Tier I` 높이 띠 바로 위에 긋는다 — 색은 **전직 색 주황**(`--color-chosen` · 도서관의 전직한 갈래 테두리). 전직한 판만이다(잠긴 판은 안 긋는다).
3. **마스터리 판 제목**(스킬 창 판 셋 · 도감 마스터리 판)에는 제목 도움말 `?` 를 달지 않는다.
4. 줄 머리 띠의 「쓴 / 상한」 숫자는 `Tier` 글보다 살짝 작다.

## 맥락

전직 포인트(R471 · 11-13)가 다시 생겼지만 화면 어디에도 남은 수가 없었다 — 11-01 에 걷은 「전직 전용 둘째 줄」은 그때 전직 트리가 공용 스킬 포인트만 쓰게 되어 걷은 것이다. 판 제목의 `?` 는 제목 도움말(§2)이 `.sk-title` 에 자동으로 달던 것이다.

## 근거

- **옆에 같은 모양** — 아래 둘째 줄은 왼쪽 칸 높이를 늘려 창이 커진다 · 같은 「남은 / 전체」 모양이라 읽는 법이 하나다
- **주황** — 전직에 따로 정한 색이 없다 · 도서관에서 「전직한 갈래」가 이미 이 색이다
- **`?` 삭제를 도감 판까지** — 같은 판 머리가 두 자리에 서고(§9-1) 같은 문구(`hint.skill_tree`)를 읽었다

## 파급

- `state.js:advanceState` `hero.learnPts`(INTERFACE §2-7) · `app.js` 포인트 칸 · `bindSectionHelp` 의 `.sk-title` 줄 · i18n `sk.points.adv` 추가 · `hint.skill_tree` 삭제 · `style.css` `.sk-pts-row` · `.adv-board > .sk-box-head::after` · `.sk-row-cap > span:last-child`
- 스킬 포인트 · 액티브 패널 · 창 제목의 `?` 는 그대로다
