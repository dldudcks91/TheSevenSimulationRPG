# ADR-1110 — 선술집 후보 교체는 30분마다 한다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |

| **정한 사람** | 사용자 지시(「선술집 후보 교체 텀을 30분으로」 2026-11-14) |
| **대체** | [ADR-1016](1016-선술집과-구매-교체는-무료로만-한-시간마다-한다.md) 의 **선술집 쪽 「한 시간」** — 구매 목록 교체 간격은 그대로 |
| **대체됨** | — |

## 결정

선술집 후보 교체의 쿨다운은 30분이다(`balance.csv:tavern_refresh_hours` = 0.5). 항상 무료 · 대기 중 버튼 비활성 · 옆에 남은 시간 · 오프라인에도 흐름 · 자동 갱신 없음은 ADR-1016 그대로다. 도움말은 이 간격을 **분**으로 적는다(`help.tavern.reroll.body` 의 `{refresh}` = 키 × 60).

## 맥락

ADR-1016 은 선술집과 구매 목록 교체를 둘 다 한 시간으로 묶었다. 사용자가 선술집 쪽만 30분으로 줄였다.

## 근거

- **키는 시간 단위 그대로** — 이름 바꾸기(`_minutes`) 대신 0.5 로 둔다. 도움말만 분으로 찍어 「0.5시간」이 안 서게 한다

## 파급

- `balance.csv:tavern_refresh_hours` · `app.js` 도움말 인자 · i18n `help.tavern.reroll.body` 두 줄 · `dev/test.js` 선술집 쿨다운 단정 둘(한 시간 고정 → 키에서 읽는다)
- 남은 시간 「교체까지 hh:mm:ss」는 밀리초로 세서 그대로다
