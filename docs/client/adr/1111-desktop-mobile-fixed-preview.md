# ADR-1111 — PC 모바일 미리보기는 고정 세로 규격이다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |
| **화면** | [모바일 규격](../MOBILE_UI.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | ADR-1090의 PC에서 수동 모바일 선택 시 실제 창 크기 사용 |
| **대체됨** | — |

PC의 마우스 환경에서 화면 배치를 모바일로 선택하면 390×844 세로 규격으로 고정한다. 큰 창에서는 확대하지 않고 중앙에 놓으며, 작은 창에서는 비율을 유지해 통째로 축소한다. 본문·팝업·메뉴·크기별 CSS는 같은 논리 규격을 사용한다. 화면 전환은 현재 게임 인스턴스와 진행 상태를 유지한다. 자동 배치와 실제 터치 모바일은 기존 반응형 화면을 사용한다.
