## 결정

수색 줄은 연구소와 선술집 영웅 고용이 서면 열리고, 열린 첫 정산에 도착 시계가 선다. 「간격」 지점은 레벨 0 이 기준이고 레벨마다 도착을 빠르게 할 뿐이다.

- 연구소 「고른 줄」의 수색은 열리면 늘 도착 간격 · 레어 확률 · 대기 칸을 쓴다 — 자물쇠 + 「간격 Lv 1」 줄을 걷는다
- 선술집 수색 안내 칸의 「연구소에서 열림」(`tv.visit.closed`)을 걷는다 — 줄이 닫혔으면 지을 것 한 줄(연구소 · 선술집 랭크)만 남는다
- 도움말 두 곳(`help.tavern.visitors.body` · `help.resource.jobs.body`)에서 「첫 연구를 끝내야 시작」을 걷는다

## 맥락

사용자가 선술집을 지은 뒤 수색 칸이 늘 비어 있는 것을 봤다. 줄은 열려 있었지만 「간격」 첫 연구 전이라 시계가 서지 않았고, 화면은 그 사실을 선술집 칸의 「연구소에서 열림」 한 줄로만 알렸다.

## 근거

- **인과가 읽히게** — 「열린 줄인데 아무 일도 안 일어난다」는 상태를 없앤다. 자원 · 도박장 줄처럼 열리면 기본 속도로 돈다
- **「간격」 값은 다른 지점과 같은 식** — 레벨 0 = 기본 간격 · 레벨마다 `per_lv` 만큼 빨라진다

## 파급

- `state.js` `visitSettle`(열린 줄의 첫 정산이 시계를 세운다) · `visitState`(`open` = `labOpen`) · `labState`(수색 `active` = 열림) · `nodeValue`(수색 「간격」의 레벨 1 기준 삭제) · 로드
- `app.js` `dpSideLine` · `visitCell` · `?dev=visit` · i18n `tv.visit.closed` 삭제 · 도움말 두 키
