# ADR-1116 — 도감 마스터리 판은 스킬 창 판과 똑같이 그리고 한 줄에 네 판이다

## 결정

도감 › 마스터리의 판은 **스킬 창(§7)의 판과 똑같이 그린다** — 머리 = 제목 앞 아이콘 + 「<이름> 마스터리」(전직 판은 전직 아이콘 · 전직 색) · 층 태그 · 부제 없음 · 줄 위 띠 = `Tier I` ~ `IV`(전직 판은 「전직 스킬」 · 「전직 스킬 강화」 · 「공통 마스터리」) · 구분선 · 「0 / 상한」 · `D2 Min` 머리 띠 · 판 색 줄(`Tier I` 바로 위) · 칸 그림 · 전직 스킬 칸 회색 네모가 스킬 창과 같은 규칙을 읽는다. 판은 **한 줄에 넷**이다.

## 맥락

ADR-1095(같은 날)가 판 · 칸 크기를 스킬 창과 맞췄지만, 머리(층 태그 · 부제) · 띠 · `D2 Min` 머리 띠 폭 · 판 색 줄 자리는 도감 규칙이 따로 남아 스킬 창과 다르게 보였다. 판 셋이 가운데 모여 양옆이 비었다.

## 근거

- **같은 규칙을 읽는다** — 도감 판을 스킬 창 판의 사본으로 두면 스킬 창이 바뀔 때 같이 바뀐다 · CSS 선택자를 `.c-skill` · `.codex-mastery-grid` 로 나란히 건다
- **층 태그 · 부제 걷음** — 안쪽 탭(죄종 · 직업 · 전직)이 이미 층을 말한다 · 전직 판의 직업 부제는 판 순서(직업마다 한 줄 셋)가 든다
- **넷** — 판 폭 256 × 4 + 사이가 도감 박스 안에 든다 · 셋이면 양옆이 판 하나만큼 비었다

## 파급

- `app.js:masteryBox`(`bands` 인자) · `codexMastery` · `codexAdvanceBoard`(머리 · 띠) · 전직 머리 공용 `advHeadHtml` · `style.css` `.codex-mastery-grid` 열 넷 · `.c-skill` 규칙에 `.codex-mastery-grid` 를 나란히
- ⚠ 전직 판은 직업 부제가 없어 「어느 직업의 갈래인가」는 순서와 머리 아이콘(전직 아이콘 그림 전엔 직업 아이콘)이 든다
