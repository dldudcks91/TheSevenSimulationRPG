# ADR-1122 — 스킬 창 빈 전직 칸은 자물쇠와 전직 안내 문장을 든다

|---|---|

## 결정

스킬 창 액티브 패널의 **빈 전직 칸**은 — 전직 전이면 **자물쇠 + 「Lv.30이 되면 도서관에서 전직이 가능합니다」**(숫자 = `balance.csv:advance_unlock_level` · 영웅 레벨이 넘었으면 「도서관에서 전직이 가능합니다」), 전직했지만 전직 스킬을 안 배웠으면 「배운 전직 스킬 없음」(습득 칸의 「배운 스킬 없음」과 같은 꼴 · 자물쇠 없음). 세 칸의 출처 글(영웅 · 습득 · 전직)은 한 단 크게(`--fs-sm`).

## 맥락

빈 전직 칸은 늘 「전직 전」이었다 — 전직하고 스킬만 안 배운 영웅에게도 같은 글이 서 틀렸고, 무엇을 하면 열리는지 말하지 않았다. 습득 칸은 이미 자물쇠 + 「Lv.10 달성」을 든다(ADR-0699).

## 근거

- **문장** — 사용자 지시 문구 그대로다. ⚠ §2 「잠긴 자리의 한 줄」(ADR-0699 — 자물쇠 + 조건 한 토막 · 문장으로 풀지 않는다)과 다르다 — 이 자리는 「어디서」(도서관)까지 말해야 해 한 토막으로 안 접혔다. 다른 잠긴 자리에 번지지 않는다
- **레벨이 넘은 뒤** — 「Lv.30이 되면」은 이미 된 영웅에게 틀린 말이다

## 파급
