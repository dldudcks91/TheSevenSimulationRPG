# ADR-1123 — 모바일의 선택지와 행동은 한 화면 안에서 결정한다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |
| **화면** | [모바일 규격](../MOBILE_UI.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | ADR-1103의 원정 목록 스크롤과 긴 관리 카드의 단순 세로 적재 |
| **대체됨** | — |

PC 패널의 최소 높이와 긴 버튼 줄을 모바일에 그대로 두지 않는다. 원정 다섯 지역은 한 화면에 모두 보이고, 챕터·난이도·결과 접근도 휠 없이 가능해야 한다. 후보·전술·전직처럼 개수가 정해진 선택지는 선택부와 현재 상세로 나누며 행동 버튼을 고정한다. 길이가 가변적인 아이템 목록·본문 설명은 필요한 영역 안에서만 스크롤한다.

기존 게임 판단과 실행 함수를 사용하되, 모바일의 정보 우선순위와 조작 배치는 별도로 구성한다. 단순히 스크롤바를 감추거나 화면 전체를 축소해서 통과시키지 않는다. 마지막 선택지의 전체 경계, 버튼 터치 가능 여부, 휠 전후 위치, 갱신 후 선택과 실제 실행까지 검사한다. PC 고정 모바일 미리보기(ADR-1111)는 유지한다.

고용·수색은 현재 영웅의 전체 능력치와 행동, 의뢰는 현재 목표·진행·보상과 행동을 함께 표시한다. 건설·연구의 전체 랭크/레벨 목록은 별도 탭으로 둔다. 연구 진행·취소·영웅 등록과 출전 준비의 실제 여섯 영웅 상태까지 검사한다. 결과 플래시는 상단 자원 줄 아래의 작은 카드로 표시해 하단 행동을 덮지 않으며 기존 세 메시지 한도와 수명을 유지한다.

대장간은 네 작업 탭이 폭을 나눠 갖고, 강화 결정과 장비의 전체 옵션 설명을 분리한다. 현재 장비를 선택한 상태에서 단계·성공 확률·현재/다음 수치·모든 재료·강화 실행이 휠 없이 보여야 한다.
