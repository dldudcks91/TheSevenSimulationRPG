# ADR-1126 — 스킬 창 액티브 빈 줄도 세 칸이고 그림 칸은 회색 네모다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |
| **화면** | [SCREEN_DESIGN §7](../SCREEN_DESIGN.md) 액티브 3 · §10-5 |
| **정한 사람** | 사용자 지시(「자물쇠 위치를 다른 스킬과 똑같이 넣어주고」 · 「스킬들 테두리도 넣어주고 위의 스킬창과 같은 곳에서 전직 관련 문구 나오고 글씨크기도 똑같이 맞춰」 2026-11-14) / 그림 칸 틀 = 빈 칸 그림은 제안 |

## 결정

스킬 창 액티브 패널의 **빈 줄도 채워진 줄과 같은 세 칸**이다 — 출처 · **그림 칸**(잠겼으면 칸 가운데 회색 자물쇠 · 아니면 빈 칸) · **사유**(스킬 이름 자리 · 이름과 같은 글씨 `--fs-sm` · 회색). `D2 Min` 에서 그림 칸은 **빈 칸 그림(회색 네모) 위**이고 그림은 칸 안쪽으로 작다 — 마스터리 칸과 같은 틀이다.

## 맥락

빈 줄은 「출처 | 자물쇠 + 사유」 두 칸이라 자물쇠 · 글이 위 스킬 줄의 그림 칸 · 이름과 다른 x 에서 시작했다(ADR-1122 같은 날). `D2 Min` 의 그림 칸은 어두운 바탕에 어두운 테두리라 틀이 안 보였다.

## 근거

- 세 줄이 같은 세 칸이면 자물쇠는 그림 자리, 사유는 이름 자리라 「여기 스킬이 설 자리가 잠겼다」로 읽힌다
- 그림 칸 틀은 판 셋의 칸 틀(빈 칸 그림)과 같은 것을 쓴다 — 새 틀을 만들지 않는다
