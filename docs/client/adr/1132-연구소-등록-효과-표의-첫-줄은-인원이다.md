# ADR-1132 — 연구소 등록 효과 표의 첫 줄은 인원이다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |
| **화면** | [SCREEN_DESIGN §8](../SCREEN_DESIGN.md) |
| **정한 사람** | 제안 후 승인 (기획 — 사용자 지시) |
| **대체** | — |
| **대체됨** | — |

## 결정

고른 줄의 **등록 효과 표**에서 자원 · 도박장 줄은 첫 줄이 「인원 | n명 | +값」이다(값 = `labState` 의 `effects.heads` — 등록 영웅 하나마다 한 몫). 그 아래 속도 줄(생산량 · 도착 속도 · 골드)은 **힘 덤만**(`effects.strBonus`) 적는다. 수색 · 훈련 · 도서관은 인원 줄이 없고(수색은 같은 날 영웅마다 시계 — R492) 속도 줄이 힘 덤이다. 영웅이 없어도 인원 줄은 선다(「0명 · +0%」 흐림 — 표의 「0 이어도 다 선다」 그대로).

## 맥락

같은 날 기획이 등록 효과를 「인원 + 능력치」로 바꿨다(GAME_DESIGN §9 11-14 — 영웅 하나 = 기본 한 몫 · 능력치는 덤). 표는 속도 줄 하나에 `speed − 1` 을 적고 미는 능력치를 「힘」으로 달았는데, 그대로 두면 인원 몫(+100% · +200% · +300%)이 「힘」 칸의 값으로 보인다.

## 근거

- 규칙이 「몇 명 + 힘 덤」이라 표도 두 줄로 가른다 — 한 줄에 합치면 힘을 바꿔도 값이 거의 안 움직여 보이고, 사람을 빼면 왜 크게 떨어지는지 안 읽힌다
- 가운데 칸이 능력치 이름이던 자리에 「n명」 — 같은 표 문법(이름 | 미는 것 | 값) 그대로다
- 버린 안: 인원을 표 머리(「등록 효과 · 3명」)에만 적기 — 값이 안 보인다

## 파급

- i18n `dp.fx.heads` · `dp.fx.headsN` · `app.js:dpFxBox`
- `labEffects` 의 `heads` 는 인원 몫이 없는 줄에서 `null`(INTERFACE §2 `labState` · §5-3 `LAB_HEAD_LINES`)
