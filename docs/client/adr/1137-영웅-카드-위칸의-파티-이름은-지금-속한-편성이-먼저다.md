# ADR-1137 — 영웅 카드 위칸의 파티 이름은 지금 속한 편성이 먼저다

| | |

| **대체됨** | — |

## 결정

영웅 카드 위칸 왼쪽의 파티 이름(연구소 밖 모든 영웅 카드 · ADR-0956)은 **지금 든 편성**(`G.presets[].party`)이 먼저다. 어느 편성에도 없을 때만 아직 싸우는 부대(`game.runOf`)를 적는다. 색은 그대로 「영웅이 지금 무언가 하는 중인가」(`game.heroBusy` — 주황 / 회색)다.

## 맥락

그날 위칸은 나가 있는 부대를 먼저 읽었다(ADR-0907 — 「원정 도중 편성에서 뺀 영웅은 그 원정이 끝날 때까지 그 부대에서 싸운다」). 원정 중인 Party I 에서 Party II 로 옮긴 영웅은 Party II 진형 칸에 서 있으면서 위칸에 「Party I」이 찍혔다 — 편성 탭에서 보는 칸과 위칸 이름이 엇갈렸다.

## 근거

- **편성 탭 · 진형 칸이 묻는 것은 「어느 편성 사람인가」다** — 옮긴 순간부터 그 영웅은 새 편성의 다음 출발에 나간다. 옛 런에 남은 것은 끝나면 풀리는 잔여다
- **싸우는 중이라는 것은 색이 이미 말한다** — 주황(무언가 하는 중)은 그대로 남는다
- **버린 안** — 부대 먼저(ADR-0907): 위 맥락의 엇갈림

## 파급

- `app.js:partyDoing` — 든 편성 → `runOf` 순 · 색 판정 그대로
