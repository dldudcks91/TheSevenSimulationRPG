# ADR-1140 — 강화 칸은 같은 폭의 판 셋이고 판마다 위에 제목 띠가 선다

## 결정

강화 칸의 세 자리를 **같은 폭의 판 셋**(셋이 1/3씩 · 판 사이 8px)으로 가른다. 판은 스킬 창의 마스터리 판(§7)과 같은 돌판이고, 판마다 위에 **제목 띠**가 선다 — `장비` · `담금질` · `강화`. 왼쪽 판은 옵션 나열(툴팁 꼴 · 글씨는 툴팁과 같고 폭은 판 폭 · 길면 판만 스크롤하고 띠는 서 있다) · 가운데 판은 담금질(담금질을 못 하면 띠만 선 빈 판) · 오른쪽 판은 작업. 모바일은 판 대신 밀어서 보기 페이지로 갈리고 띠는 안 선다.

## 맥락

강화 칸은 세 자리가 가름선 하나로만 갈렸고 폭이 제각각이었다 — 왼쪽은 툴팁 카드 폭(ADR-0979), 오른쪽 작업 칸은 40%(재료 칸 줄과 [강화]가 한 줄에 서게 · ADR-0973), 가운데 담금질은 남는 폭이고 머리 `담금질` 을 칸 안에 들었다(ADR-1134). 1600 화면에서 칸 폭이 대략 300 · 220 · 360 으로 갈렸다.

## 근거

- **자리마다 무엇을 하는 곳인지 제목이 말한다** — 「장비를 보고 → 담금질하고 → 강화한다」가 판 셋으로 읽힌다. 마스터리 판 셋과 같은 모양이라 새 모양을 배우지 않는다
- **같은 폭이 깔끔하다**(사용자) — 1600 화면에서 판 하나가 툴팁 폭과 거의 같아 왼쪽 옵션 나열이 거의 안 접힌다
- 대가 — 오른쪽 판이 40% 보다 좁아 재료 칸 셋과 [강화]가 한 줄에 안 들 수 있다(특히 영어). 그때는 버튼이 다음 줄 오른쪽 끝에 선다(ADR-0973 의 접힘 규칙 그대로)
- 탭 패널 제목도 `강화` 라 오른쪽 판 제목과 같은 글자가 위아래로 선다 — 패널 제목은 탭(작업)을, 판 제목은 자리를 말한다

## 파급

- i18n — `fg.board.gear` · `fg.board.up` 신설 · 담금질 띠는 `fg.temper` · 도움말 `hint.temper` 그대로
- CSS — `.fg-board` · `.fg-board-hd`(돌판 · 제목 띠 — 스킨이 있으면 마스터리 판과 같은 돌 틀 · 띠) · `.fg-up` 격자 = 같은 폭 셋 · 판마다 안쪽 여백 `--bp-x` · `--bp-y` · `.fg-tp-hd` 삭제
- 모바일 — 띠 · 돌판 모양을 걷는다 · 담금질을 못 하는 빈 가운데 판은 안 선다
