# ADR-1145 — 수색 얼굴 칸 위에 「대기소」 이름이 서고 · 칸 사이는 위아래 · 양옆이 같다

## 결정

수색 패널의 얼굴 칸 열은 안내 칸과 같은 높이로 선다. **위에 「대기소」 이름**(en 「Waiting Room」 · `tv.visit.lounge` · 작은 글씨 · 남는 세로를 받는다)이 서고, **아래에 칸 묶음이 바닥에 붙는다** — 끝 줄 아랫변이 안내 칸 아랫변에 맞고, **칸 사이는 위아래 · 양옆 모두 8px** 이다.

## 맥락

같은 날 ADR-1144 로 칸을 초상의 92% 로 줄이고 줄을 위아래로 벌려 묶음의 위아래 변을 안내 칸에 맞췄다. 줄 사이(약 19px)가 칸 사이(8px)보다 넓어 고르지 않았다.

## 근거

- **틈을 고르게 하려면 남는 세로를 칸 밖에서 받아야 한다** — 칸 크기는 카드 폭 식에서 오고 안내 칸 높이는 내용이 정해 둘을 CSS 식으로 맞출 수 없다. 남는 세로를 이름 줄이 받으면 칸 사이는 늘 8px 이다
- **이름은 칸 묶음이 무엇인지 말한다** — 열린 칸 · 안 열린 칸 · 출처 띠만 있던 자리라 「여기 온 사람이 기다린다」가 글자로 서지 않았다. 사용자가 「대기소」를 골랐다
- **아래에 붙인다** — 끝 줄 아랫변이 안내 칸 아랫변과 같은 선이어야 「아래가 튀어나온다」(ADR-1144 의 출발점)가 다시 안 생긴다

## 파급

- i18n — `tv.visit.lounge` 신설(ko 「대기소」 · en 「Waiting Room」)
- CSS — `.tv-join-h` 신설 · `.tv-join-grid` 는 `space-between` 을 걷고 늘이지 않는다
- 렌더러 — `joinColumn` 이 칸 묶음 위에 이름 한 줄을 단다
