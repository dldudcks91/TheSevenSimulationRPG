## 결정

담금질로 오른 몫이 있을 때 작업 판의 성공 확률 줄을 **`본 확률 + 오른 몫`**(예 `90% + 10%`)으로 찍는다. 합한 값은 찍지 않는다. 오른 몫은 찍힌 두 정수 % 의 차(`chance` − `baseChance`)라 100% 에 잘리면 잘린 만큼(`95% + 5%`)이고, 0 이면(본 확률이 이미 100%) 흐리게 선다. 오른 몫은 초록.

## 맥락

ADR-1134 · 1138 이 같은 날 확률 줄을 위 비교 줄(공격력 `지금 › 다음`)과 같은 꼴 `본 › 오른`(`90% › 100%`)으로 세웠다. 사용자가 그 화면을 보고 `90% + 10%` 여야 하지 않느냐고 했다.

## 근거

- **담금질은 확률에 몫을 더하는 장치다** — `›` 는 위 비교 줄에서 「강화하면 이 값이 된다」(다음 단계)로 읽혀, 담금질 몫이 강화 뒤의 값처럼 섞여 읽혔다. `+` 는 「본 확률에 담금질이 이만큼 얹혔다」를 그대로 보인다
- **오른 몫은 잘린 값으로 적는다** — 결과표의 몫(`temper_roll.csv`)을 그대로 적으면 `95% + 10%` 가 100% 를 넘는 합으로 읽힌다. 실제로 오른 만큼만 적어 두 수의 합이 실제 확률과 같게 한다

## 파급

- `app.js` 확률 줄만 — i18n · CSS 무변경(`.fg-up-cmp` 의 `i` · `.nx` · `.nx.same` 를 그대로 쓴다)
- ⚠ 본 확률이 이미 100% 일 때 담금질을 막을지는 열려 있다(지금은 돌릴 수 있고 `+ 0%` 가 흐리게 선다)
