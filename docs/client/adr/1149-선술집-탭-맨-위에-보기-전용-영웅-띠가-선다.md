# ADR-1149 — 선술집 탭 맨 위에 보기 전용 영웅 띠가 선다

## 결정

선술집 탭 맨 위에 **캐릭터 탭과 같은 영웅 띠**(§5)가 선다 — 그 아래가 윗줄(영웅 고용 | 수색) · 아랫줄(의뢰 | 도박장)이다. 띠는 **보기 전용**(탐험 · 연구소 탭 띠와 같다 — 클릭 · 고른 표시가 없고 영웅 유닛 툴팁만 뜬다). 띠가 먹는 세로는 **아랫줄이 낮아져** 낸다 — 아랫줄은 남는 세로만 받는다.

## 맥락

같은 날 「수색이 와닿으려면 찾아온 영웅이 좋은지 읽혀야 한다」를 논의하며 선술집에 영웅 띠를 얹는 안이 나왔다. 그날 1600×800 에서 띠를 그대로 얹으면 약 142px 가 모자랐고, 같은 날 후보 교체 줄을 제목 줄로 올리고(ADR-1131) 후보 카드의 최대 HP · 능력치 합 줄을 걷어(ADR-1135) 일부를 되찾았다. 의뢰 줄은 `flex: 1 0 auto`(줄지 않는다)였다.

## 근거

- **고용하는 자리에서 내 로스터가 보여야 한다** — 누가 있고 몇 자리가 비었나(빈 칸 `+`)를 보려고 캐릭터 탭을 오가지 않는다. 상점 띠(ADR-0359)와 같은 이유다
- **보기 전용으로 둔다** — 고르기가 하는 일(후보 카드와 견주기 · 해고)이 아직 정해지지 않았다. 눌러도 아무 변화가 없는 고르기는 두지 않는다(ADR-0359 근거 · ADR-0046). 고르기를 붙일 때는 상점처럼 캐릭터 탭과 같은 「고른 영웅」을 쓴다
- **아랫줄이 낸다** — 사용자 지시. 의뢰 카드의 빈 가운데가 먼저 줄고, 그래도 모자란 만큼은 명성 줄을 제목 줄로 올려(ADR-1150) 낸다

## 파급

- 렌더러 — `renderTavern` 이 맨 위에 `heroStrip(() => {}, { view: true })`
- CSS — `.c-tavern > .hs-panel + .tv-top` 14px(D2 Min 8px) · `.c-tavern > .tv-low` 가 `flex: 1 1 0` · 명단 줄(`.tv-row`)의 아래 여백 10px 를 걷는다(후보 교체가 제목 줄로 올라간 뒤 쓸모가 없었다)
- §5 띠의 자리가 여덟이 되고 보기 전용 띠가 셋(탐험 · 연구소 · 선술집)이 된다
- ⚠ 열린 것 — 띠의 고르기를 후보 카드 비교에 쓸지 · 선술집 띠에 해고를 달지
