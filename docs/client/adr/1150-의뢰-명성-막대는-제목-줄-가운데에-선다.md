## 결정

의뢰 패널의 명성(「명성 Lv n」 + 막대 + 가운데 「센 수 / 드는 수」)은 **제목 줄 가운데**에 선다 — 제목(「의뢰」 + `?`)과 「받음 n / m」 사이의 남는 폭을 막대가 받는다. 카드는 제목 바로 아래에서 서고, 옆 도박장 칸도 제목 바로 아래에서 서서 **두 윗변이 그대로 같다.** 게시판이 안 열렸으면(잠김 베일) 명성은 안 선다 — 제목 줄은 베일 밖이다.

## 맥락

같은 날 선술집 맨 위에 영웅 띠를 세우며(ADR-1149) 아랫줄이 띠만큼 낮아졌다. 의뢰 카드의 빈 가운데가 줄어든 뒤에도 약 30px 가 모자라 [수락] 버튼이 1600×800 바닥 밖으로 잘렸다. 그날 명성은 제목 밑줄과 카드 사이의 따로 선 한 줄이었고, 도박장 칸은 그 줄만큼 내려서 의뢰 카드 윗변에 맞췄다.

## 근거

- **한 줄을 통째로 되찾는다** — 카드 여백 · 버튼 키(2026-10-12 사용자 「수락버튼 높이를 좀 더 키우고」)를 깎는 것보다 크고, 카드 · 버튼 모양이 그대로다
- **명성은 게시판 전체의 값이라 머리가 제자리다** — 제목 줄은 이미 「받음 n / m」(게시판 전체의 값)을 들고 있었다. ADR-0945 가 한때 제목 줄에 명성을 글자로 적었던 것과 같은 자리다 — 이번엔 막대째 올린다
- **도박장 칸 맞춤이 저절로 된다** — 두 패널 모두 제목 바로 아래에서 서면 따로 내려설 몫이 없다

## 파급

- 렌더러 — `renderTavern` 이 명성 줄을 의뢰 제목(`h2`)의 「받음」 앞에 끼운다 · 게시판이 닫혔으면 안 넣는다
- CSS — `.panel > h2 > .cm-fame`(남는 폭 · 굵기 안 탐) · `.cm-fame` 의 위아래 마진을 걷는다 · `.gb-cell` 의 내려서는 마진을 0 으로
- `--cm-fame-pad` 는 쓰는 곳이 없어진다
