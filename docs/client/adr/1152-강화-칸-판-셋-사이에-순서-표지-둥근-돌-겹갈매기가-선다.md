## 결정

강화 칸의 판 셋(`장비` · `담금질` · `강화`) 사이 두 경계에 **순서 표지**를 하나씩 띄운다 — 둥근 돌(어두운 돌 결 · 주황 테두리) 안에 주황 겹갈매기 `»`. 경계 한가운데 · 세로 가운데에 떠서 양쪽 판 테두리를 덮고, 판 폭은 그대로다. 누를 수 없다. 스킨이 있으면 돌 결은 판 머리의 돌 띠 그림을 쓴다. 모바일은 판이 밀어서 보기 페이지로 갈려 안 선다.

## 맥락

ADR-1140 이 같은 날 강화 칸을 같은 폭의 판 셋(사이 8px)으로 갈랐고, 판마다 주황 테두리 · 윗변 3px 의 카드 꼴을 입었다. 셋이 나란히 서기만 해서 장비를 고르고 → 담금질하고 → 강화한다는 순서가 화면에서 읽히지 않았다.

## 근거

- **갈매기 아이콘 + 돌 = 사용자가 낸 두 안을 한 칸에** — 아이콘만 두면 얇은 선이 판 테두리 주황에 묻히고, 돌만 두면 방향이 안 읽힌다. 둥근 돌이 판 경계를 덮어 「이음새」로 보이고 안의 `»` 가 방향을 든다
- **사이에 칸을 따로 두지 않고 떠 있게** — 판 사이 8px 에 화살표 칸을 끼우면 판 폭이 줄고 셋이 같은 폭(ADR-1140)이 깨진다. 경계 위에 떠 있으면 폭은 그대로다
- **세로 가운데** — 제목 머리 높이에 두면 `장비 › 담금질 › 강화` 빵부스러기처럼 읽히지만 머리 밑줄 · 도움말 `?` 와 겹친다. 판 가운데는 왼쪽 판 툴팁 값 · 가운데 릴과 떨어져 있다

## 파급

- CSS — `.fg-up` 에 `position: relative` · `.fg-up-flow`(`.c2` · `.c3` = 그 칸을 담는 틀 · `::after` = 겹갈매기 마스크) · 모바일 `display: none`
- `app.js:forgeUpgrade` — 판 셋 뒤에 표지 둘(`aria-hidden`) · i18n 무변경
- ⚠ 가운데 판이 빈 판(상한 · 목걸이 · 반지)이어도 표지는 선다
