# ADR-1153 — 의뢰 카드 골드는 첫 줄 오른쪽 끝이고 · 바닥 보상 줄을 걷는다

## 결정

의뢰 카드의 골드(`n G` · 금색)는 **첫 줄 오른쪽 끝**에 선다 — 죄종 칩 · 등급 칩과 같은 줄이고 남는 폭을 밀어낸다. 카드 바닥의 보상 줄(위 가는 선 + 골드)은 걷는다. 카드는 위에서부터 **첫 줄(칩 · 골드) → 목표 문장 → (진행 중이면 진행 막대) → 버튼**이고, 진행 막대 · 버튼은 카드 바닥에 붙는다.

## 맥락

같은 날 선술집 맨 위에 영웅 띠가 서며(ADR-1149) 의뢰 줄이 낮아졌다. 그날 카드는 첫 줄(칩) · 목표 · 진행 막대 · 바닥 보상 줄(가는 선 위 골드) · 버튼이었고, 옆 도박장 칸의 「한 판 n G부터」 줄이 그 보상 줄과 같은 자리 · 같은 말투로 맞춰져 있었다(ADR-0601).

## 근거

- **보상 줄 한 줄을 통째로 아낀다** — 골드는 숫자 하나라 첫 줄의 칩 옆 빈 폭에 든다
- **카드를 고르는 순서와 맞는다** — 죄종(어느 도감 칸) · 등급(얼마나 어렵나) · 골드(얼마 받나)가 한 줄에서 먼저 읽히고, 무엇을 하나(목표)가 그 아래다
- **도박장 칸은 그대로 둔다** — 「한 판 n G부터」는 그 칸의 유일한 값이고 [입장] 바로 위가 자리다. 의뢰 쪽 짝이 없어졌을 뿐 줄 모양(위 가는 선 · 골드 금색)은 산다

## 파급

- 렌더러 — `commissionCard` 의 첫 줄에 `.cm-gold` · `.cm-rew` 줄을 걷는다
- CSS — `.cm-rew` 를 걷고 `.cm-kind > .cm-gold`(오른쪽 끝) · `.cm-card > .cm-go` / `.cm-prog` 가 바닥으로(`margin-top: auto`)
- 모바일 가로 CSS 의 `.tv-cm .cm-rew` 자리 규칙은 걸 줄이 없어진다
