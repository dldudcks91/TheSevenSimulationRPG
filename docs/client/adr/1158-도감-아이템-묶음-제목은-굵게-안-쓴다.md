# ADR-1158 — 도감 아이템 묶음 제목은 굵게 안 쓴다

| | |
|---|---|
| **상태** | 확정 · 2026-11-14 |
| **화면** | [SCREEN_DESIGN §9-1](../SCREEN_DESIGN.md) 아이템 세그먼트 「그룹 머리」 |
| **정한 사람** | 사용자 지시(「그리고 제목 볼드처리뺴봐」 2026-11-14) |
| **대체** | [ADR-1155](1155-도감-아이템-묶음-머리는-이름-하나만-든-제목-띠다.md) 의 **글은 굵은 제목** |
| **대체됨** | — |

## 결정

도감 아이템 세그먼트(무기 · 방어구 · 물약)의 묶음 제목 띠 글자는 **보통 굵기**다. 글 크기 · 색 · 왼쪽 정렬 · 띠(`D2 Min` 돌 띠 · `Now` 바탕 띠)는 ADR-1155 그대로다.

## 맥락

ADR-1155 로 묶음 머리가 판 폭 제목 띠가 되면서 글이 굵은 큰 제목이 됐다. 같은 날 사용자가 굵기를 빼 보라고 지시했다.

## 근거

- **띠가 이미 경계를 긋는다** — 묶음 경계는 판 폭 띠가 맡는다. 글까지 굵으면 칸 그림보다 제목이 먼저 눈에 걸린다
- 크기는 남긴다 — 지시는 굵기만이다

## 파급

- CSS — `.ix-items .ix-title` 의 `font-weight: bold` 를 뺀다
- 캐릭터 세그먼트 머리(`.ix-chars .ix-title` 굵게)는 그대로다
