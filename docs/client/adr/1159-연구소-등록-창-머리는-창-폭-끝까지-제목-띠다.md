# ADR-1159 — 연구소 등록 창 머리는 창 폭 끝까지 제목 띠다

## 결정

연구소 등록 창의 머리 「{줄} — 영웅 등록」은 **창 폭 끝까지 깔린 제목 띠**다. 글자는 패널 제목 크기(`--fs-md`)이고, 닫기 X 도 띠 안에 선다. `Now` 는 바탕 띠(한 단 밝은 면 + 아랫선)이고, `D2 Min` 은 패널 제목과 같은 밝은 돌 띠(돌 테두리 안쪽 끝까지)다. 띠는 창 안쪽 여백만큼 음의 여백을 두고 같은 양의 안쪽 여백을 줘, 제목 글자가 속 카드와 한 세로줄에 선다.

## 맥락

등록 창은 머리를 갈아 끼우는 창(`head` · 도움말 `?` 가 붙은 제목)이라 이름 하나뿐인 창의 머리 규칙(ADR-0744 — 패널 제목 크기 + 아랫선)을 안 받았다. 그래서 창 제목이 큰 글씨(`h2` 기본)로 띠 없이 떠 있었다. 같은 날 등록 창 속을 [적용] 방식으로 바꾼 뒤(ADR-1154) 사용자가 「제목 크기 줄이고 제목처리해야되니까 띠 그려줘」라고 지시했다.

## 근거

- **크기** — 다른 창 머리 · 패널 제목과 같은 크기라 창마다 제목 무게가 같다(ADR-0744 와 같은 말)
- **띠** — 선 하나(ADR-0744)가 아니라 면을 깐 이유는 사용자 지시(「제목처리」)다. 모양은 이미 있는 띠를 따른다 — `D2 Min` 패널 제목 띠 · 대장간 판 띠(`.fg-board-hd`)와 같은 돌 띠라 새 생김새를 만들지 않는다

## 파급

- CSS `.modal-box.lr-modal > .modal-head` · `D2 Min` 덮개 한 줄
- ⚠ 다른 창(이름 하나뿐인 창 — ADR-0744)은 선 머리 그대로다. 띠를 창 공통으로 넓힐지는 열려 있다
