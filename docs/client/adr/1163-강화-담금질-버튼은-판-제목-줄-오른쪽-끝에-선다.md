## 결정

**[담금질]** 은 `담금질` 판의, **[강화]** 는 `강화` 판의 **제목 줄 오른쪽 끝**에 선다. 제목 글씨와 같은 크기 · 보통 굵기 · 줄 높이를 키우지 않는 낮은 버튼이다. 재료 칸 줄은 재료 칸만 남는다. 상한이면 [강화] 글이 `fg.upMax` 로 바뀌어 같은 자리에 잠긴다. 모바일은 제목 줄이 안 서므로(ADR-1140) 버튼은 전처럼 판 아래(담금질 판 맨 아래 · 재료 칸 아래)에 선다.

## 맥락

ADR-1140 이 같은 날 강화 칸을 제목 머리를 단 판 셋으로 갈랐다. [강화] 는 재료 칸 줄 오른쪽 끝(ADR-0973), [담금질] 은 담금질 판 맨 아래(ADR-1134)에 있어 두 판의 누르는 자리가 높이가 달랐다. 사용자가 둘을 제목 오른쪽 끝으로 보내자고 했다.

## 근거

- **누르는 자리를 한 줄에** — 두 판의 버튼이 같은 높이(제목 줄)에 서서 「담금질 → 강화」 를 같은 눈높이에서 누른다
- **모바일은 그대로** — 모바일은 판이 밀어서 보기 페이지라 제목 줄이 없다(페이지 이름이 제목). 버튼은 렌더러가 두 자리에 그리고 CSS 가 화면에 맞는 하나만 보인다 — 렌더러는 모바일인지 모른다

## 파급

- `app.js:forgeTemper` · `forgeUpgrade` — 버튼을 `mkGo` 로 둘 만든다(제목 줄 `.fg-board-go` · 판 아래 `.fg-go-foot`)
- CSS — `.fg-board-hd > .fg-board-go` · 데스크톱 `.fg-go-foot` 숨김 · 모바일 규칙(`.fg-tp > .btn` · `.fg-up-act > .btn`)은 그대로 판 아래 버튼에 걸린다
