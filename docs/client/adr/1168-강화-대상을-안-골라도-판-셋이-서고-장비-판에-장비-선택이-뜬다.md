## 결정

강화 대상을 고르기 전에도 판 셋(`장비` · `담금질` · `강화` — 제목 머리 · 판 테두리 · 순서 표지)을 그대로 세운다. 왼쪽 장비 판 가운데에 `장비 선택`(`fg.pick`)이 서고, 담금질 · 강화 판은 제목만 선 빈 판이다(버튼 없음). 모바일은 제목 줄이 없고 강화 페이지가 먼저 서므로 강화 판에도 같은 글이 선다.

## 맥락

ADR-1140 이 강화 칸을 같은 폭의 판 셋으로 갈랐으나, 고르기 전에는 판 대신 패널 전체를 덮는 한 칸에 `장비 선택`만 섰다. 고르는 순간 판 셋이 나타나 화면 꼴이 바뀌었다.

## 근거

- **꼴이 고르기 전후로 같다** — 판 셋이 먼저 서 있으면 「장비를 고르면 이 판들이 찬다」 가 고르기 전부터 읽힌다. 글은 장비를 놓을 판(왼쪽)에 선다
- **빈 판에 버튼을 두지 않는다** — 고를 것이 없는 담금질 · 강화 판에 잠긴 버튼을 세우면 누를 수 없는 것이 늘 서 있다

## 파급

- `app.js:forgeUpgrade` — 대상이 없을 때 판 셋을 그린다 · 순서 표지는 `fgFlows` 로 뺐다
- CSS — `.fg-up-empty` 삭제 · `.fg-up-pick`(장비 판 · 모바일 강화 판) · 데스크톱은 강화 판의 `.fg-up-pick` 을 숨긴다
