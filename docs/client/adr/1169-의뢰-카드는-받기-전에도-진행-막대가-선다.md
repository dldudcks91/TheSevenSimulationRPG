## 결정

의뢰 카드의 **진행 막대 + 「센 수 / 목표 수」는 받기 전에도 선다** — 받기 전에는 「0 / 목표 수」 빈 막대다. 받으면 같은 막대가 차오른다. 카드 위 안쪽 여백을 조금 넓혀(칩 줄이 윗변에 안 붙게) 첫 줄을 내리고, 목표 문장도 칩 줄에서 조금 더 띄운다.

## 맥락

같은 날 의뢰 카드에서 등급 칩 · 바닥 보상 줄을 걷고 카드를 낮췄다(ADR-1153 · ADR-1161). 받기 전 카드는 첫 줄 · 목표 · 버튼뿐이라 목표와 버튼 사이가 비었고, 칩 줄은 카드 윗변에 붙어 보였다.

## 근거

- **모든 카드가 같은 줄 구성이 된다** — 받기 전 · 진행 중 · 다 채움이 같은 자리에 같은 막대를 들어, 받는 순간 카드 모양이 바뀌지 않고 막대만 찬다
- **목표 수가 숫자로 한 번 더 읽힌다** — 목표 문장의 수(「30마리」)와 막대의 「0 / 30」이 같은 값을 두 자리에서 말하지만, 막대 쪽은 받은 뒤 진행을 읽는 자리라 받기 전부터 같은 자리에 있는 편이 낫다(사용자 판단)
- **빈 세로를 쓴다** — 진행 중 카드가 들던 높이를 모든 카드가 쓰므로 1600×800 높이는 늘지 않는다

## 파급

- 렌더러 — `commissionCard` 가 진행 줄을 늘 붙인다(받기 전 센 수 = 0)
- CSS — 카드 위 안쪽 여백 8px · 칩 줄 ↔ 목표 5px
