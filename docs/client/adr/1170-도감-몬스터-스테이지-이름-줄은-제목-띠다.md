# ADR-1170 — 도감 몬스터 스테이지 이름 줄은 제목 띠다

| | |
|---|---|
| **상태** | 확정 · 2026-11-15 |
| **화면** | [SCREEN_DESIGN §9](../SCREEN_DESIGN.md) 몬스터 세그먼트 「스테이지 행」 |
| **정한 사람** | 사용자 지시(「몬스터 도감 제목도 혹시 띠로 바꿔줘볼래? 지금은 라인으로 되있는데」 2026-11-15) |
| **대체** | — *(§9 「스테이지 행」의 **이름 줄 아래 가로선 하나**(2026-09-21 · ADR 없음 · 시험 중)를 대체)* |
| **대체됨** | — |

## 결정

도감 몬스터 세그먼트의 스테이지 이름 줄(로마 숫자 번호 · 이름)은 아래에 가로선을 긋는 글줄이 아니라 **제목 띠**다. 도감 아이템 묶음 머리(ADR-1155 · 글 굵기 ADR-1158)와 같은 띠다 — `D2 Min` 은 돌 띠(`--sk-chrome`), `Now` 는 바탕 띠이고 글은 보통 굵기 · 왼쪽 정렬. 띠는 그 행의 폭 끝까지 선다 — 마지막 행은 챕터보스 · `???` 자리가 제 폭만큼 따로 단다. 스테이지를 감싸는 상자가 없는 것(2026-09-21)은 그대로다.

## 맥락

이름 줄은 2026-09-21 상자를 걷은 시험 이후 「이름 + 아래 가로선 하나」였다. 2026-11-14 같은 도감의 아이템 세그먼트 묶음 머리가 판 폭 제목 띠가 됐다(ADR-1155).

## 근거

- **한 도감 안의 머리 문법을 맞춘다** — 아이템 탭은 띠, 몬스터 탭은 선이면 같은 화면의 두 탭이 다른 말을 한다
- **띠가 행 경계를 긋는다** — 상자 없는 행이 다섯 줄 쌓이는 화면이라, 선보다 면이 어디서 다음 스테이지가 시작하는지 먼저 읽힌다
- **이미 있는 띠** — 아이템 묶음 머리 · 마스터리 판 머리 · 대장간 판 띠가 쓰는 결이다. 새 그림을 만들지 않는다

## 파급

- CSS — `.cs-head`(바탕 · 높이 · 안쪽 여백 · 가운데 정렬) · `D2 Min` 겉모양 `.cs-head` 돌 띠
- 띠가 이름 줄보다 조금 높아 행의 카드 줄 세로가 그만큼 준다(행은 본문 높이를 나눠 갖는다)
