## 결정

강화 대상을 고르기 전에는 왼쪽 장비 판의 **제목이 `장비 선택`**(`fg.pick`)이고 판 안은 빈다. 고르면 제목이 `장비` 로 돌아온다. 모바일은 제목 줄이 없으므로 전처럼 판 안(강화 · 장비 페이지)에 `장비 선택` 이 선다.

## 맥락

ADR-1168 이 같은 날 고르기 전에도 판 셋을 세우고 장비 판 가운데에 `장비 선택` 을 띄웠다. 사용자가 판 안 글을 걷고 제목을 `장비 선택` 으로 바꾸자고 했다.

## 근거

- **할 일이 제목 자리에** — 판 셋의 제목 줄이 한 줄로 읽히므로 `장비 선택 › 담금질 › 강화` 가 순서 그대로 선다. 판 가운데 글은 빈 판 셋 사이에서 따로 떠 보였다

## 파급

- `app.js:forgeUpgrade` — 대상이 없을 때 장비 판 제목 = `fg.pick` · i18n 무변경
- CSS — 데스크톱은 `.fg-up-pick` 을 전부 숨긴다(모바일만)
