# ADR-1172 — 도감 캐릭터 직업 제목은 아이템과 같은 띠다

| | |

| **대체됨** | — |

## 결정

캐릭터 도감의 모든 직업 묶음 제목을 아이템 도감과 같은 제목 띠로 표시한다. 띠는 묶음 상자의 폭을 채우며 배경 · 높이 · 여백 · 글자 크기를 아이템 제목과 공유한다. 글자는 보통 굵기이며 왼쪽 정렬이다. 직업 이름 옆 가로선은 제거한다.

직업 묶음 둘이 한 줄인 배치와 초상 목록은 유지한다. CSS의 아이템 제목 띠 규칙을 캐릭터에도 함께 적용해 모양을 맞춘다.
