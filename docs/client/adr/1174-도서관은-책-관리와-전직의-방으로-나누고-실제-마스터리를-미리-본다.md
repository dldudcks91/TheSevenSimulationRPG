# ADR-1174 — 도서관은 책 관리와 전직의 방으로 나누고 실제 마스터리를 미리 본다

| | |
|---|---|
| 상태 | 확정 · 2026-11-15 |
| 화면 | SCREEN_DESIGN §17 · §7 |
| 정한 사람 | 사용자 승인: 전직의 방 + 갈래 설명 + 실제 마스터리 미리보기 + 완료 후 마스터리 연결을 모두 적용 |
| 대체 | ADR-1165의 스킬북·전직 폴더 탭, ADR-1167의 전직 갈래 배치, ADR-0592의 완료 후 세 갈래 조회 배치, ADR-1000의 전직 버튼 자리 |

## 결정과 근거

도서관 기본 화면은 현재 스킬·책 배우기·책 제작이다. 반복하는 책 관리에 공간을 쓰고, 전직은 항상 보이는 [전직의 방]에서 연다. 입구에 선택 영웅의 전직 가능 여부·해금 조건·완료 상태를 표시한다.

방은 별도 모달 한 장이다. 왼쪽에는 세 갈래의 이름·역할 설명, 오른쪽에는 고른 갈래의 실제 전직 마스터리를 표시한다. 도감 미리보기와 같은 데이터·그림·효과를 쓰며 스킬을 선택하면 강화 줄도 바뀐다. 비교는 포인트·재화를 쓰지 않는다. 설명·스킬·마스터리를 별도 탭으로 나누지 않는다.

아래에는 선택한 갈래·레벨/건물 조건·비용·소요 시간과 [전직]을 표시한다. 갈래 선택과 전직 실행을 분리하고 갈래를 되돌릴 수 없음을 실행 전에 알린다. 완료 후에는 완료한 갈래와 [마스터리 열기]를 표시한다. 미리보기는 자동으로 스킬을 배우지 않는다.

모바일 세로에서는 세 갈래 선택지를 위에 함께 놓고 선택한 설명·미리보기를 아래에서 읽는다. 실행 영역은 고정하고 본문만 스크롤한다. 작은 가로 화면도 선택지와 본문이 잘리지 않게 한다. 영웅 변경 시 이전 영웅의 갈래 선택을 적용하지 않는다. 기존 개발 URL `&lib=adv`는 전직의 방을 연다.
