# ADR-1175 — 교역소 재료 수량도 보유/필요 순서로 표시한다

| | |
|---|---|
| **상태** | 확정 · 2026-11-15 |
| **화면** | [SCREEN_DESIGN §8-3](../SCREEN_DESIGN.md) |
| **계기** | 사용자 「필요한 자원/보유자원 … 분수형태로 나올때 왜 반대로 되있는거같지? 확인좀」 |
| **대체 범위** | ADR-1017 교역소의 재료 수량 표기 순서 |

## 결정

교역소 지불 재료의 수량을 **보유량 / 필요량**으로 표시한다. 건설·연구소·대장간의 재료 수량과 같은 순서다. 한영 툴팁도 보유량을 먼저 명시한다. 골드는 기존처럼 가격 G를 표시한다.

## 근거

교역소만 필요량 / 보유량으로 표시하여 같은 수량이 화면마다 반대 뜻으로 읽혔다. 보유량이 6이고 필요량이 3이면 `6 / 3`, 부족하여 보유량이 2이면 `2 / 3`으로 읽힌다. 부족 색상과 구매 가능 여부는 기존 판정을 사용한다.
