# ADR-1176 — 비용의 자원 수량은 필요량/보유량 순서다

| **정한 사람** | 사용자 정정 — 자원 비용은 필요량/보유량 순서 |
| **대체 범위** | ADR-0397 등 비용 칸의 보유/필요 순서 · ADR-1175 |

## 결정

비용을 분수 형태로 표시할 때는 **필요량 / 보유량** 순서로 표시한다. 건설·연구소·장비 제작·강화·담금질·교역소가 같은 순서를 사용한다. 예를 들어 필요량이 3이고 보유량이 6이면 `3 / 6`이다. 한영 툴팁도 같은 순서다.

골드 가격만 표시하던 곳은 가격만 표시한다. 부족 색상과 실행 가능 여부의 기준은 보유량이 필요량보다 적은지로 판정한다. 레벨 조건·마스터리·의뢰 등의 진행 수치는 비용이 아니므로 이 결정의 대상이 아니다.
