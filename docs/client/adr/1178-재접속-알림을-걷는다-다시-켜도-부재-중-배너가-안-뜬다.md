# ADR-1178 — 재접속 알림을 걷는다 · 다시 켜도 「부재 중」 배너가 안 뜬다

| **대체** | ADR-0881 (재접속 알림이 원정 탭 맨 위에 떠서 선다 — 알림 자체가 걷힌다) |

## 결정

게임을 껐다 켜거나 JS 가 멈췄던 공백에서 깨어나 원정이 끊겨도 **원정 탭에 「부재 중」 알림을 띄우지 않는다.** 알림 판(`app.js:noticeBanner` · `.notice-box` · `.notice-float`)과 그 문구 키(`exp.notice.runClosed.h` · `.body` · `exp.notice.report` · `exp.notice.dismiss`)를 지운다. 원정이 끊기는 규칙(`game.closeRun` — 진행 중 라운드는 사라지고 이어 가기가 멈춘다)은 그대로고, 결과는 마지막 리포트가 든다. 알림을 가리키던 도움말 두 곳(`help.expedition.offline.body` · `help.help.away.body`)은 「알림과 마지막 리포트를 확인하고」에서 알림을 뺀다.

## 맥락

- 그날 끊긴 원정이 있으면 `G.notice` 가 서고(`game.closeRun`), 원정 탭 맨 위에 「부재 중 — 원정은 게임이 켜져 있을 때만 돕니다 — {칸} 원정이 멈췄습니다 …」 판이 [리포트 보기] · [확인]과 함께 떠서 닫을 때까지 섰다(ADR-0881)
- 같은 규칙은 도움말 「게임을 닫았을 때」 · 「자리를 비울 때」와 반복 원정 도움말(`exp.repeat.sub`)이 이미 적고 있었다

## 근거

- **지시가 「안 나오게」다** — 판을 다른 자리로 옮기거나(플래시) 문구만 줄이는 안은 지시와 다르다
- **규칙 문장은 도움말의 몫이다** — 인게임 판은 숫자 · 상태 · 버튼만 둔다(SCREEN_DESIGN §12 · 설명 문구는 도움말 탭 전용). 알림 본문의 앞 절이 규칙 설명이었고, 같은 말이 도움말에 이미 있다
- **`G.notice` 는 남긴다** — 세이브 · `game.closeRun` · 단정이 이 칸을 쓴다. 화면만 안 읽으면 되는 일이라 `game_logic` · 세이브 스키마를 건드리지 않는다

## 파급

- i18n — `exp.notice.runClosed.h` · `exp.notice.runClosed.body` · `exp.notice.report` · `exp.notice.dismiss` 삭제 · `help.expedition.offline.body` · `help.help.away.body` ko/en 에서 알림을 뺐다
- CSS — `.notice-box` · `.notice-float` (D2 Min 덮어쓰기 포함) 삭제
- `?dev=offline` 은 원정이 멈춘 채 서는 화면을 본다
- ⚠ `G.notice` 는 `game.closeRun` 이 계속 채우고 아무도 안 읽는다 — 걷으려면 `game_logic` · 세이브 스키마 일(→ `/client`)
