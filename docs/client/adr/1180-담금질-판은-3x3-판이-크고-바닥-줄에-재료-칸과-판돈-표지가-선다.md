## 결정

데스크톱 담금질 판은 칸 셋이다 — 머리 / **3×3 판**(남는 높이 가운데 · 한 칸 54px로 크게) / **바닥 줄**(왼쪽 = 고른 판돈 단계의 재료 칸 · 오른쪽 = 판돈 표지 다섯 · `판돈` 이름 없음). 강화 판의 위 내용(단계 눈금 · 비교 · 확률 줄)은 머리와 재료 칸 사이 세로 가운데에 서고, `+n / 상한` 은 굵게 하지 않는다. 대장간 재료 칸은 **그림 칸만** — 칸 아래 이름 글씨를 안 단다(모바일은 이름을 둔다).

## 맥락

ADR-1177 이 같은 날 두 판을 위에서부터 쌓고 담금질에 판돈 줄(이름 · 가름선)을 세웠다. 판돈 줄 · 재료 칸 이름이 높이를 먹어 3×3 판이 한 칸 38px 로 줄었고, 강화 판은 단계 눈금이 머리 바로 아래에 붙었다. 사용자가 룰렛을 크게 · 강화 단계를 덜 위로 · 굵기와 재료 이름을 빼라고 했다.

## 근거

- **담금질은 돌아가는 판이 주인공** — 판돈 고르기와 재료는 한 줄로 바닥에 모으고 남는 높이를 3×3 판에 준다
- **재료는 그림이 말한다** — 재료 칸 그림 · 단계 표지(`I`)가 무엇인지 말해 이름 글씨가 겹말이었다. 이름 두 줄(영어)이 판 높이를 먹던 것도 사라진다
- **강화 판은 가운데** — 위 내용이 짧아 머리에 붙이면 아래가 비어 보였다. 재료 칸은 바닥에 두고 위 내용만 남는 높이 가운데에 세운다

## 파급

- `app.js:forgeTemper` — 판돈 줄 이름(`gb.stake`) 삭제
- CSS — 데스크톱 `.fg-tp` = 그리드 칸 셋 · 3×3 판 한 칸 54px · 판돈 줄 가름선 삭제 · 대장간 재료 칸 이름 숨김 · `.fg-up-th b` 보통 굵기 · 강화 판 위 내용 세로 가운데
- ⚠ 재료 칸에 이름이 없어 그림을 모르면 읽을 길이 없다 — 재료 칸 hover 이름은 아직 없다
