# ADR-1184 — 강화 작업 판 위 줄은 남은 횟수 숫자이고 눈금은 강화 단계다

## 결정

강화 작업 판 맨 위 줄은 `남은 횟수` · `남은 / 전체` **숫자만**이다. 그 아래 눈금은 **강화 단계 눈금**(ADR-0968 — `slots` 칸 · 찬 칸 = 지금 단계 · 다음 칸 테두리 · 지금 상한 너머 잠긴 칸 · 잠긴 칸 툴팁 ADR-1181) 그대로다. 남은 횟수가 0 이면 다음 칸 테두리도 밝히지 않는다.

## 맥락

ADR-1183 이 같은 날 눈금을 남은 횟수 칸(10칸)으로 바꿨다. 사용자가 남은 횟수는 숫자로만 보이고 눈금은 강화 정도라 그대로 두라고 했다.

## 근거

- **눈금 = 얼마나 올랐나 · 숫자 = 몇 번 남았나** — 두 값을 각자 자리에 둔다. 단계 눈금은 지금 상한 · 잠긴 칸(여는 랭크)까지 읽혀 강화 정도를 한 줄로 보인다
- 남은 횟수는 한 숫자로 충분하다 — 칸으로 그리면 단계 눈금과 같은 꼴의 칸 줄이 둘이 된다
