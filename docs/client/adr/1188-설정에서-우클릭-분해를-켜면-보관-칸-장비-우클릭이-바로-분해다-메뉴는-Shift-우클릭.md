# ADR-1188 — 설정에서 우클릭 분해를 켜면 보관 칸 장비 우클릭이 바로 분해다 · 메뉴는 Shift+우클릭

## 결정

`⚙` 판 설정 탭 `게임` 하위 탭에 **우클릭 분해** `Off` · `On` 줄을 둔다(기본 **Off** · 이 브라우저에만 남는다). `On` 이면 보관 칸(창고 · 인벤토리)의 장비를 우클릭하면 메뉴를 띄우지 않고 **그 자리에서 분해**한다 — 확인이 없고, 결과는 분해함 [분해하기]와 같은 플래시다. 우클릭 메뉴([착용] · [잠금])는 **`Shift`+우클릭**이 띄운다. **잠긴 장비 · 상자 칸 · 상점의 보관 칸**은 `On` 이어도 메뉴가 그대로 뜬다. 손가락 조작(길게 누르기 툴팁 버튼 줄)은 바뀌지 않는다.

## 맥락

분해는 분해함(ADR-0673)에 올려 [분해하기]를 누르는 두 단계였고, 우클릭은 [착용] · [잠금] 메뉴(ADR-0451)였다. 한 개씩 정리할 때도 [분해] → 칸 누르기 → [분해하기] 세 번을 눌러야 했다.

## 근거

- **켜는 사람이 고른 손짓** — §3 「되돌릴 수 없는 행동은 두 번 누르게 한다」와 부딪힌다. 그래서 기본은 `Off` 고, 켠 사람만 한 번 누름으로 분해한다. 켜는 행동이 첫째 확인을 대신한다.
- **잠금이 안전장치로 남는다** — 잠긴 장비는 우클릭해도 분해되지 않고 메뉴가 떠 [잠금 해제]가 거기 있다. 아끼는 것은 잠그면 된다.
- **메뉴를 잃지 않는다** — 잠금은 우클릭 메뉴로만 켠다(ADR-0454). 우클릭을 분해에 주면 마우스로 잠글 길이 사라지므로 `Shift`+우클릭이 메뉴를 띄운다.
- **상점은 판매 목록** — 상점 칸의 우클릭은 판매 목록 고르기(ADR-1010)라 분해와 섞지 않는다. 상자 칸은 분해되지 않는다(R328).
- **거른 안** — ① 우클릭 메뉴 맨 앞에 [분해] 버튼 더하기: 여전히 두 번 누른다 — 「바로」가 아니다. ② `Shift`+우클릭을 분해로: 요청이 「우클릭」이다. ③ 잠긴 것은 거절 플래시: 잠금을 풀 길이 메뉴뿐이라 메뉴를 띄우는 편이 낫다.
