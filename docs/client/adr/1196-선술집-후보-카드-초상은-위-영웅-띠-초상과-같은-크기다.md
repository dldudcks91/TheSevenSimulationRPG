# ADR-1196 — 선술집 후보 카드 초상은 위 영웅 띠 초상과 같은 크기다

| | |
|---|---|
| **상태** | 확정 · 2026-11-15 |
| **화면** | [SCREEN_DESIGN §8-1](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「선술집에 나오는 초상화가 위의 상태창 초상화보다 큰가」 → 「선술집 후보카드 초상 크기를 살짝만 줄여서 맞춰볼까? 지금 너무 큰듯?」) |
| **대체** | [ADR-0734](0734-후보-카드의-칩-줄은-영어에서도-한-줄이다-칩-여백-4px-초상-41.md) 일부 — 선술집 명단의 초상 = 카드 안쪽 폭의 **41%** (시작 화면 · 도감은 그대로) |
| **대체됨** | — |

## 결정

선술집 영웅 고용 패널의 후보 카드 초상은 **탭 맨 위 영웅 띠 카드의 초상과 같은 크기**로 선다. 선술집 초상 비율 손잡이 `--tv-k`(`style.css` `.c-tavern > .tv-top`)를 **.41 → .38** 로 내린다 — 카드 폭이 상한(시작 화면 카드 줄과 같은 (1060 − 28) / 3)에 닿은 자리에서 초상 = .38 × (344 − 34) ≈ 118px 이고, 영웅 띠 초상도 카드 상한 120px − 테두리 2px = 118px 이다. 수색 얼굴 칸은 「초상의 90%」([ADR-1144](1144-수색-얼굴-칸은-초상보다-작고-묶음이-안내-칸과-같은-높이로-선다.md)) 그대로라 같이 준다. 시작 화면 후보 카드는 41% 그대로다.

## 맥락

2026-11-14 에 선술집 탭 맨 위에 보기 전용 영웅 띠가 섰다([ADR-1149](1149-선술집-탭-맨-위에-보기-전용-영웅-띠가-선다.md)). 그 뒤로 같은 얼굴 그림이 한 화면에 위아래로 선다. 이날 실측(D2 Min · 보이는 크기): 1600×900 에서 영웅 띠 초상 106px · 후보 카드 초상 114px · 1920×1080 에서 127 · 137 — 창 크기 다섯(1280 ~ 1920)에서 모두 후보 카드가 **1.08배** 컸다. 화면 전체가 한 배율로 커지고 줄어 비율은 창과 무관했다.

## 근거

- **한 화면에서 같은 그림이 두 크기면 어긋남으로 읽힌다** — 차이가 8% 라 「일부러 다르다」로 읽히기엔 작고, 「덜 맞췄다」로 읽히기엔 충분하다. 맞추면 한 규격으로 읽힌다.
- **아래를 줄인다 · 위를 키우지 않는다** — 영웅 띠는 원정 편성 · 캐릭터 · 스킬 탭과 같은 조각이라 상한(`--hs-card-max`)을 올리면 다른 탭까지 커진다. 사용자도 「후보카드를 줄여서」로 방향을 정했다.
- **고정 px 대신 비율을 바꾼다** — 카드 폭 식(`--tv-c`)이 초상 비율(`--tv-k`)로 수색 칸 폭을 풀어내므로, 영웅 띠 값을 직접 끌어오면 그 식을 다시 세워야 한다. 비율 하나만 바꾸면 식이 그대로 선다.
- **시작 화면은 안 건드린다** — 시작 화면엔 영웅 띠가 없어 맞출 대상이 없고, 「시작 화면과 보이는 크기도 같다」는 [ADR-0978](0978-선술집-수색은-영웅-고용-옆-제-패널이고-잠긴-칸은-자물쇠만-든다.md) 이 이미 걷었다.

## 파급

- `style.css` `--tv-k` 한 값 · 같은 블록 주석. 후보 카드 머리 높이(= 초상)가 줄어 카드가 그만큼 낮아지고, 수색 얼굴 칸 · 수색 패널 폭이 같이 준다
- 초상이 작아져 오른쪽 열(칩 줄 · 이름 · 고유 스킬)이 넓어진다 — ADR-0734 의 「영어 칩 줄 한 줄」은 더 여유롭다
- ⚠ 두 값은 **묶여 있지 않다** — 영웅 띠 카드 상한 · 후보 카드 여백 · 명단 상한 폭 중 하나가 바뀌면 이 비율을 다시 맞춘다
