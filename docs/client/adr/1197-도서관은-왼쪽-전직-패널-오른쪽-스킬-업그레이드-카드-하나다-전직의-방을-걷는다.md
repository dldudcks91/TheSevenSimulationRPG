## 결정

도서관 탭은 영웅 띠 아래 **두 열**이다 — 2026-11-13(커밋 `c21fac53`)의 짜임에서 **스킬 북 제작 카드만 빠진 모양**.

```
┌ 영웅 띠 ───────────────────────────────────────────────────────────────┐
├ 전직 (폭 = 띠 카드 7칸) ───────────────────────┬ 스킬 업그레이드 ───────┤
│ 이름  Lv.n / 전직 레벨          스킬 포인트 n/n │ 고른 책 · [배우기]     │
│ [고유][습득][전직]          (골드) [전직]       │ ▢▢▢▢ 가진 책 칸        │
│ ─ 갈래 1 · 설명   │ 스킬 셋 한 줄씩 (1 : 4)    │                         │
│ ─ 갈래 2 · 설명   │ …                          │   (열 전체 높이)        │
│ ─ 갈래 3 · 설명   │ …                          │                         │
└─────────────────────────────────────────────────┴─────────────────────────┘
```

- **왼쪽 = 전직 패널** — 폭은 위 영웅 띠 카드 7칸(ADR-0852 되살림) · 머리 = 고른 영웅 줄(이름 · `Lv.n / 전직 레벨` · 전직했으면 공용 스킬 포인트) · 그 아래 지금 가진 스킬 카드 셋 + 같은 줄 오른쪽 골드 비용 · [전직](ADR-1000 되살림) · 그 아래 갈래 셋이 세로로 쌓인다(왼쪽 칸 1 : 오른쪽 스킬 줄 4 · ADR-0852) · 고른 갈래는 파란 테두리 · 전직 중은 막대 · 전직 뒤는 전직한 갈래가 주황 테두리(ADR-0592) · 전직이 안 열렸으면 갈래 자리만 잠김 베일(ADR-0595 · ADR-0404)
- **오른쪽 = 스킬 업그레이드 카드 하나가 열 전체 높이**를 받는다
- **[전직] 은 갈래를 골라야 켜진다** — 처음엔 아무 갈래도 안 골라져 있다 · 「고르고 누른다」(§3 두 번 누름 · ADR-0536 되살림)
- **걷는 것** — 스킬정보 패널 · 전직의 방 칸 · 전직의 방 창 · 창 옆 마스터리 판 카드 · 계기판 · `&lib=adv` · 맨 위 갈래 자동 선택
- **그대로 사는 것** — 전직 스킬은 그림에 `Lv.n` 을 안 단다(ADR-1190) · 겉모양 `D2 Min` 의 갈래 홈 박스 · 덮어쓰기 확인 창(ADR-1020)

## 맥락

도서관은 11-14 ~ 11-15 사이에 네 번 짜임이 바뀌었다 — 스킬북 · 전직 폴더 탭(ADR-1165) → 책 관리 + 전직의 방 창(ADR-1174) → 윗줄 「스킬정보 | 전직의 방 칸」 + 창(ADR-1179 · 1186 · 1187 · 1189). 같은 날 스킬 도안과 책 제작이 걷혀(PLAN_skillbook_no_blueprint D1 · D2) 오른쪽 아래 「스킬 북 제작」 카드가 할 일이 없어졌다.

## 근거

- **전직은 패널로 나와 있어야 견준다** — 영웅마다 한 번 하는 일이지만, 띠에서 영웅을 바꿔 가며 갈래 셋을 바로 읽는 것은 패널이어야 된다. 창은 열 때마다 한 단계를 더한다. 사용자가 고른 「예전 스타일」이 이 패널이다.
- **실제 마스터리 판은 도서관에 다시 안 세운다** — 같은 판이 도감(§9-1)과 스킬 창(§7)에 있다. 패널 7칸 폭 안에 판을 하나 더 세우면 갈래 줄의 한 줄 설명(ADR-0852)이 접힌다.
- **맨 위 갈래 자동 선택 · 한 번 누름(ADR-1189)은 창을 위한 예외였다** — 창이 열자마자 완성된 화면이어야 한다는 이유였는데 창이 없어졌다. 갈래는 되돌릴 수 없으니 §3 「되돌릴 수 없는 행동은 두 번 누르게 한다」로 돌아간다.
- **오른쪽은 카드 하나가 열을 다 받는다** — 제작 카드 자리를 비워 두면 「아직 안 연 기능」으로 읽힌다.
- **즉시 끝나는 전직은 「완료」로 말한다** — 걸리는 시간이 0 이면 [전직] 한 번에 끝난다. 「전직 시작」 플래시는 그때 거짓이라 완료 문장(`tr.adv.done`)을 따로 둔다.
- 버린 안 — **윗줄 「스킬정보 | 전직의 방 칸」은 남기고 아랫줄만 스킬 업그레이드 하나로**: 전직이 창 안에 남는다 — 사용자가 밖으로 빼라고 한 그것이다.
