# ADR-1219 — 영웅 띠의 카드 사이는 4px이다

| | |
|---|---|
| **상태** | 확정 · 2026-11-16 |
| **화면** | [SCREEN_DESIGN §5](../SCREEN_DESIGN.md) (공통 영웅 띠) |
| **정한 사람** | 사용자 지시 — 「일단 영웅들 사이에 거리가 너무 멀어보이는데 이것좀 줄여볼래?」 |
| **대체** | 영웅 띠의 카드 사이 8px(`--hs-gap` 의 옛 값 — 규격에 적힌 적은 없다) |
| **대체됨** | — |

## 결정

공통 영웅 띠의 카드 사이를 **4px** 로 줄인다(`--hs-gap`). 카드 폭 규칙(하한 · 상한 · 띠 폭을 나눠 늘어나기)은 그대로라 줄어든 간격만큼 카드가 조금 넓어진다(12칸 기준 105 → 108px).

## 맥락

로스터가 12칸으로 늘며(ADR-1216) 띠에 칸이 빽빽해졌고, 사용자가 카드 사이가 멀어 보인다고 했다.

## 근거

- **값 하나를 줄인다.** 간격은 변수 하나가 들고 있고, 띠 칸에 끝을 맞추는 판(도서관 전직 패널 ADR-0852 · 연구소 등록 창 칸 · 캐릭터 탭 훈련 띠 폭)이 같은 변수를 읽어 따로 고칠 곳이 없다

## 파급

- `style.css` `--hs-gap` 8 → 4px

---
*이 파일은 고치지 않는다. 결정이 뒤집히면 새 ADR 이 이것을 대체하고, 여기엔 「대체됨」 한 줄만 붙는다.*
