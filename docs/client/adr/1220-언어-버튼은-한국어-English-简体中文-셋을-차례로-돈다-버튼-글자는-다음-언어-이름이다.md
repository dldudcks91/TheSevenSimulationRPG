# ADR-1220 — 언어 버튼은 한국어 · English · 简体中文 셋을 차례로 돈다 · 버튼 글자는 다음 언어 이름이다

| | |
|---|---|
| **상태** | 확정 · 2026-11-16 |
| **화면** | [SCREEN_DESIGN §2](../SCREEN_DESIGN.md) (상단바) |
| **정한 사람** | 제안 후 승인 — [LOCALIZATION_ZH.md](../LOCALIZATION_ZH.md) D7 · 사용자 「ㄱㄱ진행해줘」 |
| **대체** | 상단바 언어 토글(ko ↔ en 두 값 — 규격에 「언어 토글(ko/en)」로만 적혀 있었다) |
| **대체됨** | — |

## 결정

상단바의 언어 버튼은 누를 때마다 **한국어 → English → 简体中文 → 한국어** 순서로 바뀐다. 버튼 글자는 **누르면 바뀔 다음 언어의 이름**이다(한국어 화면 「EN」 · 영어 화면 「简体中文」 · 간체 화면 「한국어」). 간체의 이름은 「简体中文」으로 적고 나라 · 지역 이름을 붙이지 않는다.

## 맥락

간체 중국어를 셋째 언어로 넣기로 했다(LOCALIZATION_ZH D1 ~ D10). 지금 버튼은 두 값을 뒤집는 토글이라 셋째 언어로 갈 길이 없다.

## 근거

- **버튼 하나 · 칸 하나 그대로** — 상단바에 고르는 목록(펼침)을 새로 세우지 않는다. 세 언어면 많아야 두 번 누른다.
- **글자는 다음 언어** — 지금 토글도 「다른 쪽 언어」를 적었다(한국어 화면 「EN」). 같은 읽기를 셋으로 늘렸다.
- **「简体中文」** — 「中文（台湾）」 같은 지역 표기가 중국 유저의 비추천을 부른 사례가 있다(Vampire Survivors · [조사 노트](../../reference/zh_localization/comparable_games.md) §0).
- 버린 안 — **고르는 목록**(언어가 넷 이상이면 이쪽이 맞다 · 지금은 버튼 하나가 단순하다).
