# ADR-1227 — 고른 작은 버튼은 강조색 테두리 · 흰 글씨이고 바탕은 깔지 않는다

## 결정

고른 · 켜진 작은 버튼(공용 `.btn.sm.on`) = **강조색(빨강) 테두리 · 흰 글씨**. 바탕은 공용 고른 칸의 바탕 그대로(한 단 밝은 무채색)이고 강조색을 깔지 않는다. 바탕이 같으니 챕터 세그먼트에 따로 둔 예외는 없다 — 챕터 세그먼트는 글자 · 테두리가 죄종 색이라 그 색이 강조색을 덮는다.

## 맥락

같은 날 ADR-1226 이 시안 B(테두리 · 글씨 + 옅은 강조색 바탕)를 반영했다. 그때 단점으로 적은 것이 「주 행동 버튼(어두운 빨강 바탕)과 같은 계열」이었고, 사용자가 화면을 본 뒤 바탕을 뺀 A 로 바꿨다.

## 근거

- **주 행동 버튼과 겹치지 않는다** — 빨강 바탕은 주 행동 버튼(`.btn.primary`)의 몫으로 남는다. 고른 칸은 테두리 · 글씨로만 갈린다
- **도감 세그먼트(2026-09-21)와 정확히 같은 모양** — 그때 사용자가 고른 표시가 이 모양이었다

## 파급

- style.css `.btn.sm.on` 바탕을 무채색으로 · `.btn.sm.on.own-color` 삭제
- `app.js` `segmented` 의 `own-color` 클래스 삭제
