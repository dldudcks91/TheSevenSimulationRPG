# ADR-1231 — 출정 창 머리에 난이도 배수(몬스터 체력 · 데미지 ×) 줄을 안 적는다

| | |
|---|---|
| **상태** | 확정 · 2026-11-17 |
| **화면** | [SCREEN_DESIGN §4-1](../SCREEN_DESIGN.md) 「출정 창」 머리 |
| **정한 사람** | 사용자 지시 — 「스테이지 원정 갈 때 위에 몬스터 체력 x0.8 이런 거 나오는 거 삭제 좀」 |
| **대체** | — (2026-10-30 확정 미반영 일괄 연결 때 코드에만 들어온 줄 · 규격 · ADR 에는 없었다) |
| **대체됨** | — |

## 결정

출정 창 머리는 규격대로 **죄종 칩 · 칸 이름 · 「레벨 n」 · (있으면) 장 디버프 한 줄**이다. 그 오른쪽에 붙던 잔글씨 **「몬스터 체력 ×{hp} · 데미지 ×{dmg}」**(`exp.diff.stats` · 고른 난이도의 `difficulty_tier.csv` 배수)를 걷는다. 다른 자리에 옮겨 세우지 않는다.

## 맥락

2026-10-30 확정 미반영 기획 일괄 연결(R401 무렵) 때 출정 창 머리에 난이도 배수가 잔글씨로 붙었다. §4-1 머리 규격에는 없었다.

## 근거

- **사용자 지시**
- **배수는 레벨과 겹친다** — 머리의 「레벨 n」이 이미 고른 난이도의 몬스터 레벨이다. 배수 줄은 노말에서도 「×0.8」처럼 서서 무엇이 약해졌다는 것인지가 안 읽혔다
- 난이도가 몬스터를 얼마나 세게 하는지는 도움말의 몫이다(§12 — 패널에 규칙 · 수치 설명을 세우지 않는다)

## 파급

- `app.js` `departHead` 의 한 줄 · i18n `exp.diff.stats` 삭제
- 출정 창이 떴는지를 `.dw-difficulty` 로 기다리던 검증 스크립트 둘(`scripts/verify_confirmed_implementation.py` · `scripts/verify_stage_seed_sweep.py`)은 창 머리 `.dw-title` 을 기다린다
