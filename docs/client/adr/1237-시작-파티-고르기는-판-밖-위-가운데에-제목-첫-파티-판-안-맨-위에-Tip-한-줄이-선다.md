## 결정

시작 파티 고르기 화면의 판(`D2 Min` 의 돌 판 · `Now` 는 판 없이 카드 줄) **밖 위 가운데**에 제목 「첫 파티」(`ng.title` · 부제 없음)를 세운다. 제목은 판 위 여백(뒤로가기와 판 사이 — ADR-0643 이 걷은 제목의 높이를 남겨 둔 자리)에 들어 판이 내려가지 않는다. 판 **안 맨 위**(카드 줄 위 · 카드 줄 왼쪽 변)에 「Tip.」(강조색) + 한 문장의 Tip 줄을 둔다. 팁은 한 번에 하나이고 [다시 굴리기]를 누를 때마다 목록의 다음 것으로 넘어간다(굴림 횟수 차례 · 난수 없음). 첫 목록은 한 문장 — 「영웅은 나중에 선술집에서 더 고용할 수 있습니다」.

## 맥락

2026-10-16 사용자가 「첫 파티라는 글씨가 좀 거슬리는데 아예 없애봐」로 제목을 걷었고(ADR-0643), 화면 이름은 상단바 crumb 「새 게임」이 들었다. 그때 걷은 제목은 카드 줄 위 가운데 정렬 「첫 파티」 + 부제 한 줄이었다. 이날 사용자가 제목이 필요하다며 다시 세우게 했다. 시안은 「첫 파티 고르기」 · 「함께 시작할 영웅 셋」 · 「첫 파티」 셋이었고 사용자가 옛 제목과 같은 「첫 파티」를 골랐다.

## 근거

- **판 밖 위** — 사용자가 자리를 「카드 밖 가운데 위」로 정했다. 판 위 여백은 ADR-0643 이 카드를 제자리에 두려고 남긴 옛 제목 높이라 제목이 들어가도 판 · 카드 줄의 시작 높이가 그대로다(제목을 걷고 카드를 끌어올린 판은 그때 버려졌다)
- **부제를 다시 안 둔다** — 옛 부제(「이 n명이 그대로 시작 영웅 로스터가 됩니다 — 마음에 들 때까지 다시 굴려도 됩니다」)의 몫은 Tip 줄과 도움말 「새 게임」 절이 든다
- **Tip 은 하나씩 · 굴릴 때마다 다음** — 여러 줄을 한꺼번에 세우면 판이 그만큼 길어지고 카드 줄을 민다. 넘김을 굴림 횟수에 묶으면 화면이 난수 · 시계 없이 돈다(렌더러는 난수를 안 쓴다)
- **팁 문장은 초반에 쓸모 있는 것** — 사용자 「초반에 좋은 팁이 나오면 좋지」. 같이 낸 후보(다시 굴리기 무제한 · 카드 윗변 색 = 등급 · 올리면 설명 · 맨 왼쪽 영웅이 리더 · 직업 무기를 들고 시작)는 고르지 않았다
- **§12 의 의도된 예외** — 게임 화면에 들어가는 설명 문장이다. 이 화면에는 이미 같은 결의 예외(카드 연장 칸 · 능력치 범례)가 있다

## 파급

- `app.js:renderStart` — 제목 `.ng-title`(판 `.ng-wrap` 앞) · Tip 줄 `.ng-tip`(판 안 카드 줄 앞) · 목록 `NG_TIPS`
- CSS — `.ng-wrap` 위 여백을 제목 높이만큼 덜고 그 높이를 `.ng-title` 이 갖는다(`Now` · `D2 Min` 둘 다) · `.ng-tip` 신설
- i18n `ng.tipLabel` · `ng.tip.tavern` 신설 · `ng.title` 은 화면 제목과 도움말 「새 게임」 절 머리가 같이 쓴다
- ⚠ 팁 목록에 문장을 더하는 것은 이 결정 안이다(새 ADR 이 아니다)
