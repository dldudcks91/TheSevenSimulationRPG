# ADR-1240 — 선술집 윗줄의 남는 폭은 수색 패널이 받고 영웅 고용 패널은 카드 둘 만큼이다

## 결정

- **「영웅 고용」 패널 폭 = 후보 카드 둘 + 카드 사이 틈 + 좌우 패널 여백.** 그래서 패널 오른쪽 여백이 왼쪽 여백과 같다.
- **윗줄에 남는 폭은 수색 패널이 받는다.** 수색 패널 안에서는 왼쪽 안내 칸(이야기 · 고른 영웅의 카드)이 그만큼 넓어진다. 높이는 후보 카드와 같다(숨긴 후보 카드가 높이를 잡는 것은 그대로 — ADR-0981). 얼굴 칸 열은 폭이 그대로다.

## 맥락

윗줄 카드 폭(`--tv-c`)은 윗줄 폭으로 풀되 상한이 있다. 상한에 걸리는 화면에서는 윗줄에 남는 폭이 생겼고, 그 폭을 「영웅 고용」 패널(`flex: 1`)이 받아 두 번째 후보 카드 오른쪽 여백이 왼쪽보다 넓어졌다.

## 근거

사용자 지시다.

- **여백은 좌우가 같아야 한다** — 영웅 고용 패널은 카드 둘을 담는 틀이라 카드 폭에 맞춘다.
- **남는 폭은 글이 쓰는 자리로** — 수색 안내 칸은 이야기 줄이 칸 폭에서 말줄임으로 잘리는 자리라 넓어지면 덜 잘린다.
- **버려진 안 — 남는 폭을 두 패널 사이 틈이나 양끝에 나눠 둔다**: 빈 자리만 늘고 쓰는 곳이 없다.

## 파급

- `style.css` — `.tv-hire` = 카드 둘 폭(고정) · `.tv-search` = 남는 폭(최소 = 지금 폭) · `.tv-search-cell` = 남는 폭(최소 = 카드 폭)
- ⚠ 고른 얼굴의 카드(`joinCardBox` · `heldCardBox`)도 안내 칸 폭을 따라 명단 카드보다 넓을 수 있다
