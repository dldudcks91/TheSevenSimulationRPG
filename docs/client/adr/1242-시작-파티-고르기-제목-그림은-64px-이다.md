## 결정

판 밖 위 가운데 제목 그림 「FIRST PARTY」(`assets/art/logo/first_party.webp`)의 화면 높이를 48px 에서 **64px** 로 키운다. 제목 칸 높이(97px)와 판의 시작 높이는 그대로다.

## 맥락

같은 날 ADR-1241 이 제목을 워드마크 결의 그림으로 바꾸며 높이를 48px(게임 안 브랜드 칸 40px 보다 한 단 큰 값)로 두었다. 기준 한 장(1600×800)에서 그림은 폭 약 200px 이었고, 사용자가 더 키우라고 했다.

## 근거

- **64px** — 97px 제목 칸 안에 위아래 여백을 남기고 드는 둥근 값이다. 그림 폭은 약 270px 이 되고, 단검 머리 끝이 뒤로가기 줄 높이쯤에 닿는다. 그림과 판 윗변 사이는 약 17px 이다
- **판을 더 내리지 않았다** — 사용자는 크기만 말했다. 칸 안에 들어가므로 카드 줄 자리가 바뀌지 않는다

## 파급

- CSS `.ng-title img { height: 64px }`
- 설치본(1010×240)은 64px 에서도 3.75배라 다시 뽑지 않는다
