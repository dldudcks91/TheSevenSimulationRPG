## 결정

제목 그림 「FIRST PARTY」(64px — ADR-1242)를 제목 칸(97px)의 세로 가운데보다 **8px 위**에 세운다 — 그림 아래 여백 16px(`.ng-title img { margin-bottom: 16px }`). 칸 높이와 판의 시작 높이는 그대로다.

## 맥락

ADR-1242 로 그림을 64px 로 키운 뒤 그림은 칸 가운데에 서서 판 윗변과 약 17px 떨어져 있었다. 사용자가 위치를 살짝 올리라고 했다.

## 근거

- **8px** — 「살짝」. 그림과 판 윗변 사이가 약 25px 로 벌어져 제목이 판에 붙어 보이지 않고, 단검 머리 끝은 뒤로가기 글자 줄 높이에 온다
- **칸을 줄이지 않았다** — 칸을 줄이면 판이 같이 올라간다. 판 자리는 ADR-1241 에서 사용자가 내리라고 한 자리다

## 파급

- CSS `.ng-title img` 아래 여백 16px
