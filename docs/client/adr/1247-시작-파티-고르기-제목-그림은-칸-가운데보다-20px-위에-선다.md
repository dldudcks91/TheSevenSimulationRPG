# ADR-1247 — 시작 파티 고르기 제목 그림은 칸 가운데보다 20px 위에 선다

| **대체됨** | — |

## 결정

제목 그림 「FIRST PARTY」(64px)를 제목 칸(97px)의 세로 가운데보다 **20px 위**에 세운다 — 그림 아래 여백 40px. 그림 윗변이 칸 위로 4px 넘쳐 메인 위 여백(20px)에 든다. 칸 높이와 판의 시작 높이는 그대로다.

## 맥락

ADR-1244 로 8px 올렸을 때 그림과 판 윗변 사이는 약 25px 이었고, 사용자가 더 올리라고 했다.

## 근거

- **20px** — 그림 글자 줄이 뒤로가기 글자 줄 높이에 와서 화면 맨 윗줄 하나로 읽힌다. 그림과 판 윗변 사이는 약 37px 이다
- **칸 위로 넘치게 둔다** — 칸을 줄이면 판이 같이 올라간다. 넘친 4px 는 메인 위 여백 안이라 상단바를 침범하지 않는다

## 파급

- CSS `.ng-title img` 아래 여백 40px
