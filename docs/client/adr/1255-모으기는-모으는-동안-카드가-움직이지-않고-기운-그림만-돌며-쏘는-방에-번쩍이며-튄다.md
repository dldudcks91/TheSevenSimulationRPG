## 결정

모으기(`cast = channel_charge`)가 열려 있는 동안 카드는 **다른 정신 집중처럼 나간 채 서 있기만 한다** — 물러나지도 줄지도 않는다. 「모으는 중」은 초상 둘레의 기운 그림(ADR-1252 · 모일수록 진해진다)이 혼자 맡는다. **쏘는 방**에서 기운이 걷히고 초상이 한 번 번쩍하며 카드가 상대 쪽으로 **튀었다가 나간 자리로 돌아온다**(크기는 안 바뀐다). 튐 · 번쩍은 「공격 시 흔들림」, 기운 그림은 「스킬 이펙트」 · 투명도 · 그림체를 따른다.

## 맥락

같은 날 ADR-1253 으로 카드 크기 변화를 걷고 뒤로 물러남(최대 9px)만 남겼다. 사용자가 「그러면 기 모으는 걸 그냥 이미지로 만들어서 하는 걸로 해?」라고 물었고, 모으는 동안은 그림만 · 쏘는 순간은 번쩍 + 튐(가)과 번쩍만(나)을 놓고 가를 골랐다.

## 근거

- **「모으는 중」을 읽히게 하는 건 거의 기운 그림이었다** — 9px 물러남은 작아 잘 안 보이고, 나간 카드(14px)가 반쯤 돌아와 내려오는 것처럼 보일 수 있었다
- **정신 집중의 카드 모양이 하나로 모인다** — 끊어 치기 · 계속 닳기도 카드는 나간 채 서 있다. 모으기는 그림 하나로 갈린다
- **쏘는 순간의 튐은 남긴다** — 걸렸던 것은 카드 크기였고, 모은 끝에 터지는 맛은 튐이 준다
- 거른 안 — **번쩍만**: 카드가 끝까지 안 움직여 모은 한 방이 보통 타격과 같은 무게로 보인다

## 파급

- `fx.js:fxCharge` 는 기운 그림만 다룬다(카드에 `charging` 클래스 · `--charge` 를 안 건다) · `fxChargeShot` 의 튐은 나간 자리에서 시작한다
- CSS — `.unit.charging` 을 걷고 `@keyframes fx-charge-shot` 이 0 → 앞으로 12px → 0 이다
