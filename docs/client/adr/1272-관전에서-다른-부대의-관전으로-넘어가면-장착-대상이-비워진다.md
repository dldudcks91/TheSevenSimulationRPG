# ADR-1272 — 관전에서 다른 부대의 관전으로 넘어가면 장착 대상이 비워진다

| | |
|---|---|
| **상태** | 확정 · 2026-11-18 |
| **화면** | [SCREEN_DESIGN §4-2](../SCREEN_DESIGN.md) 「아레나」 · 「보관」 |
| **정한 사람** | 사용자 지시(「Party2 에서 영웅이 선택되어 있어도 Party1 화면으로 넘어가면 클릭된 거 취소」) |
| **대체** | — |
| **대체됨** | — |

## 결정

- 관전을 보다가 상단바 부대 칸으로 **다른 부대의 관전**으로 넘어가면 장착 대상이 비워진다 — 아레나 빈 곳을 누른 것과 같은 상태다([ADR-0849](0849-관전-아레나의-빈-곳을-누르면-장착-대상이-비워진다.md)). 영웅 카드를 다시 누를 때까지 보관 칸은 아무 영웅도 향하지 않는다
- 비우는 것은 **관전 화면에서 넘어갈 때만**이다 — 다른 탭 · 스테이지 화면에서 부대 칸이나 ▶ 부대 버튼으로 관전에 들어오는 길은 ADR-0849 그대로(고른 영웅이 대상)
- 캐릭터 탭의 고른 영웅은 안 바뀐다(ADR-0849 그대로)

## 맥락

장착 대상은 화면 상태 하나(고른 영웅)라 부대를 바꿔 봐도 남았다. Party II 관전에서 영웅을 눌러 두고 Party I 관전으로 넘어가면, 고른 영웅은 Party I 판에 없어 테두리가 어느 카드에도 서지 않는데 보관 칸의 장착 · 비교 · [자동 장착]은 여전히 그 영웅을 향했다.

## 근거

- **넘어간 판에 고른 카드가 없다** — 테두리가 안 보이는 대상에게 장비가 들어가는 것은 「본 것과 일어나는 일」이 어긋난다. 비워 두면 보관 칸 클릭이 아무 일도 안 해 잘못 끼우는 사고가 없다
- **넘어간 부대의 첫 영웅으로 바꾸는 안**은 안 골랐다 — 누르지 않은 영웅이 대상이 되는 것도 같은 어긋남이고, 요청은 「취소」다
