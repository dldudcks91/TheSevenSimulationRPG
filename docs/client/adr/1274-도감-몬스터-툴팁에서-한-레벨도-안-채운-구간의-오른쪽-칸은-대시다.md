# ADR-1274 — 도감 몬스터 툴팁에서 한 레벨도 안 채운 구간의 오른쪽 칸은 대시다

## 결정

- **한 레벨도 안 채운 구간의 오른쪽 칸 = `—`** — `+0%` 를 쓰지 않는다
- 한 레벨이라도 채운 구간은 지금 받는 값(`+0.2%`) · 잠긴 줄 · 효과가 없는 줄은 빈 칸 — ADR-1271 그대로

## 맥락

ADR-1271 은 지금 받는 값을 그대로 적어 안 채운 구간에 `+0%` 가 섰다.

## 근거

- **기호는 `—`** — 같은 툴팁에서 효과가 없는 줄의 가운데 칸이 이미 `—` 다. 하이픈 `-` 은 값 칸에서 음수 부호로 읽힌다
