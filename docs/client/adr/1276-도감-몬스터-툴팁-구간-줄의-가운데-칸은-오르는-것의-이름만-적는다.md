# ADR-1276 — 도감 몬스터 툴팁 구간 줄의 가운데 칸은 오르는 것의 이름만 적는다

| | |
|---|---|
| **상태** | 확정 · 2026-11-18 |
| **화면** | [SCREEN_DESIGN §9](../SCREEN_DESIGN.md) 「몬스터 툴팁」 |
| **정한 사람** | 사용자 지시(「가운데 글귀에는 +n% 가 필요 없겠지」 → 「빼」) |
| **대체** | [ADR-1268](1268-도감-몬스터-툴팁의-보너스-효과-글은-레벨당-값이다.md) — 효과 글 = 레벨당 값 · 줄 앞 「레벨당」 |
| **대체됨** | — |

## 결정

- **가운데 칸 = 무엇이 오르나만** — 값도 「레벨당」도 없다: `데몬 드롭 확률` · `데몬 상대 공격 · 캐스팅 속도` · `치명타 확률`
- **숫자는 오른쪽 칸 하나가 든다** — 지금 받는 값(ADR-1271) · 안 채운 구간 `—`(ADR-1274)
- 효과가 없는 줄 `—` · 잠긴 줄 · 구간 칸 · 머리글 `Lv.n` 은 그대로

## 맥락

ADR-1271 이 오른쪽 칸에 지금 받는 값을 넣자, 가운데의 `레벨당 … +0.1%` 와 오른쪽 `+0.2%` 가 한 줄에 숫자 둘로 섰다.

## 근거

- **숫자는 한 자리** — 줄마다 읽을 숫자는 지금 받는 값 하나다. 안 채운 구간이 얼마를 줄지는 한 레벨을 채우면 오른쪽에 선다
