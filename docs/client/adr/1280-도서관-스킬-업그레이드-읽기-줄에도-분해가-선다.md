## 결정

도서관 아랫줄 왼쪽 「스킬 업그레이드」의 **읽기 줄**에 **[분해]** 를 더한다 — 자리는 줄 끝 읽기 버튼([배우기] · [덮어쓰기] · [업그레이드] · 「최대」) **바로 왼쪽** · 보통 버튼 색. 하는 일은 창고 스킬북 탭 [분해]와 같다(`game.salvageBook` — 고른 책 1권 → 스킬 조각 `[balance.csv:book_salvage_shard]` · 확인 창 없음 · 한 번에 1권 · 플래시 `bk.salvaged`). 고른 책이 없으면 꺼진다. **영웅과 무관하다** — 레벨 미달 막힘 · 상한(「최대」)이어도 선다. 남아 있으면 고른 채 · 다 쓰면 칸이 빠져 저절로 풀린다. 창고 스킬북 탭 [분해]는 그대로 남는다.

```
├ 스킬 업그레이드 ? ─────────────────────────────────────┤
│ [전체][전사][기사][궁수][마법사][사제]                   │
│ ▢×3 이름 / Lv.2 → Lv.3 · 책 3권 필요   [분해][업그레이드] │
│ ▢▢▢▢▢▢▢▢▢▢                                            │
└────────────────────────────────────────────────────────┘
```

## 맥락

2026-11-18 R540 · [ADR-1262](1262-도서관에-전직의-방이-돌아오고-아랫줄은-스킬-업그레이드와-스킬-조각으로-만드는-스킬-북-제작이다.md) 로 책 분해가 스킬 조각을 내게 됐고, 조각을 쓰는 스킬 북 제작은 도서관 아랫줄 오른쪽 반에 섰다. 분해 버튼은 창고 스킬북 탭 도구 줄에만 있어, 남는 책을 조각으로 바꿔 책을 만들려면 창고와 도서관을 오가야 했다.

## 근거

- **읽기 줄이 「가진 책 하나를 고른 자리」다** — 분해의 대상도 가진 책 하나라 고르기를 새로 만들 필요가 없다. 스킬 북 제작 쪽 칸은 **만들 수 있는 책**(재고와 무관)이라 거기서 고르면 「가진 것을 부순다」와 어긋난다.
- **읽기 버튼의 오른쪽 끝 자리를 안 옮긴다** — 주 행동(배우기 · 업그레이드)은 늘 줄 끝 같은 자리에 선다. [분해]는 그 왼쪽에 보통 색으로 선다.
- **확인 창을 안 둔다** — 창고 [분해]와 같은 행동이라 같은 규칙(고르고 누른다 · [ADR-1199](1199-창고-스킬북-탭에서-책을-골라-분해하면-최하급-가루가-된다.md))이다. 한 화면에서만 확인을 묻는 갈림을 만들지 않는다.
- 거른 안 — **스킬 북 제작 구역에 분해 모드**: 제작 칸은 가진 책을 안 보이므로 분해 대상을 따로 띄워야 한다. **창고 [분해]를 걷고 도서관으로 옮기기**: 사용자 요청은 「추가」라 창고 것은 남긴다.

## 파급

- 새 i18n 키 없음 — `bk.salvage` · `bk.salvaged` 를 같이 쓴다
- CSS — 버튼 둘이 서는 모바일 줄에서 오른쪽으로 미는 여백은 첫 버튼만 진다(`mobile.css`)
- 조각 수는 오른쪽 스킬 북 제작 만들기 줄이 바로 다시 그린다(`스킬 조각 n` · `가진/필요`)
