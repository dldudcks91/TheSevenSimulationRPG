# ADR-1283 — 창고 스킬북 탭 격자는 3줄에서 멈추고 넘친 줄은 안에서 내리며 아래에 더 있으면 주황 `»` 가 선다

## 결정

- **격자 높이는 3줄(`app.js:BAG_ROWS`)에서 멈춘다** — 책 종류가 창고 칸 수보다 많아 넷째 줄이 생기면, 넘친 줄은 격자 안에서 아래로 내려 본다(휠 · 마우스로 끌기 · 손가락). 아이템창이 위로 커지지 않는다
- **아래에 칸이 더 있으면 격자 아랫변 가운데에 아래를 향한 주황 `»`** 가 선다(`--color-more`) — 맨 아래까지 내리면 사라진다 · 포인터를 안 받는다(밑의 칸을 그대로 누른다)
- **다시 그려도 내린 자리는 남는다** — 화면 전체 다시 그림(`data-keep`)과 관전 보관 칸 갈아 끼우기(`refreshBattleBag`) 둘 다

## 맥락

창고 스킬북 탭은 가진 책만 칸으로 세우고, 책 종류가 창고 칸 수보다 많으면 넘친 책도 칸으로 그렸다(ADR-0616). 격자는 창고 장비 격자와 같은 3줄이었는데 넘친 칸이 넷째 줄을 만들면 그만큼 아이템창이 높아졌고, 아이템창이 화면 아래 끝에 붙어 있어 위로 올라왔다. 스크롤바는 화면 전체에서 숨긴다(ADR-0097).

## 근거

- **3줄 = 장비 탭과 같은 높이** — 탭을 바꿔도 창고 · 인벤토리 크기가 안 변한다는 규칙(ADR-0379 · 0616)을 넘친 책에도 지킨다. 격자 밖으로 늘리지 않고 안에서 내린다
- **화살표는 스크롤바 대신** — 스크롤바를 숨기는 화면이라 넷째 줄이 있다는 신호가 따로 있어야 한다. 끝까지 내리면 더 볼 것이 없으므로 화살표도 걷는다
- **고른 칸의 파란 겉 테두리(3px · ADR-0926)는 안 잘린다** — 스크롤 판에 테두리만큼 여백을 두고 같은 폭만큼 바깥으로 물려(음수 마진) 칸 크기 · 패널 높이는 장비 탭과 같다

## 파급

- 코드 — `app.js:bookStashGrid`(스크롤 판 · 화살표 · 끌기) · `refreshBattleBag`(`data-keep` 스크롤 위치 이월) · `style.css`(`.bk-scroll-wrap` · `.bk-scroll` · `.more-down` · `--color-more`)
- i18n 없음 — 화살표는 기호 하나
- ⚠ 장비 · 재료 탭의 넘침(상한이 줄어든 옛 세이브)은 그대로 격자가 늘어난다 — 이 결정의 범위 밖
