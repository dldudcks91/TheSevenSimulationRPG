# ADR-1288 — 전체 버프 창의 묶음 머리는 제목 띠다

| | |

| **정한 사람** | 사용자 지시(「좀 구분되게 사이사이에 제목 띠 좀 넣어」) — 띠 모양 · 띠 위 간격 · `Now` 띠 색은 제안 |
| **대체** | — |

## 결정

- **묶음 머리 셋(파밍 · 전투 · 옵션 · 파티 전원) = 제목 띠** — 도감 스테이지 이름 줄 · 아이템 묶음 머리와 같은 띠: `D2 Min` 돌 띠 · 글은 보통 굵기 · 한 단 큰 글자 · 구간 `Lv.1 ~ 20` 은 흐린 글
- `Now` 띠는 `--bg-tertiary` — 창 바탕이 `--bg-secondary` 라 다른 화면의 바탕 띠 색이면 안 보인다
- 띠 위는 10 띄운다 · 첫 띠(파밍)는 종족 머리 줄에 붙는다 · 옵션 띠는 목록을 내려도 위에 붙어 있다

## 맥락

ADR-1279 의 창은 묶음 머리가 굵은 글자 한 줄이라, 파밍 다섯 줄 · 전투 열다섯 줄이 한 표로 이어져 경계가 안 읽혔다.

## 근거

- **화면에 이미 있는 띠** — 도감의 묶음 경계는 어디서나 이 띠가 긋는다(ADR-1155 · ADR-1170). 새 모양을 만들지 않는다
