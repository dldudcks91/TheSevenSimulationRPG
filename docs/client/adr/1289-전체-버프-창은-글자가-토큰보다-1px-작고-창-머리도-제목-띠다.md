# ADR-1289 — 전체 버프 창은 글자가 토큰보다 1px 작고 창 머리도 제목 띠다

| | |
|---|---|
| **상태** | 확정 · 2026-11-18 |
| **화면** | [SCREEN_DESIGN §9](../SCREEN_DESIGN.md) 「몬스터 세그먼트」 [전체 버프] |
| **정한 사람** | 사용자 지시(「글씨 크기를 다 한 픽셀씩 내려 주고 위에 전체 버프에도 띠 둘러」) — 띠 모양은 제안 |
| **대체** | — |
| **대체됨** | — |

## 결정

- **창 안 글자 전부 = 쓰던 토큰보다 1px 작다** — 창 제목 · 묶음 띠 = `--fs-md` − 1 · 표 · 목록 = `--fs-sm` − 1
- **창 머리 「전체 버프」 = 제목 띠** — 연구소 등록 창 머리 띠와 같다(`Now` 바탕 띠 · `D2 Min` 돌 띠 · 창 테두리 안쪽 끝까지 · 닫기 X 는 띠 오른쪽 끝)

## 맥락

ADR-1288 로 묶음 머리가 띠가 되자, 창 머리만 선 하나로 남아 띠가 아닌 줄이 맨 위에 섰다.

## 근거

- **머리 띠는 이미 있는 모양** — 연구소 등록 창이 같은 띠를 쓴다. 새 모양을 만들지 않는다
