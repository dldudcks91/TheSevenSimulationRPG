# ADR-1298 — 자원 비상 보급은 부족한 재료를 더 빨리 채운다

2026-11-20

자원 줄의 다섯 번째 연구는 비상 보급이다. 최하급 철광석·약초·목재 중 가장 적게 가진 재료를 찾는다. 최저 보유량이 동률이면 그 재료들이 함께 가속한다. 세 재료의 보유량이 같으면 각 재료는 평소 속도로 생산한다.

최다 보유량 대비 부족한 비율에 최대 가속률을 곱한다. 최대 가속률은 레벨당 10%p이며 5레벨에서 50%다. 연구소 2랭크에서 시작한다. 실제 재료가 들어올 때마다 비율을 갱신해 접속 중과 오프라인에 같은 규칙을 적용한다.
