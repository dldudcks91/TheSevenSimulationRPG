# ADR-1301 — 인챈트는 옵션 판에 현재 옵션과 새 옵션을 표시한다

| | |
|---|---|
| **상태** | 확정 · 2026-11-20 |
| **화면** | [SCREEN_DESIGN §8-2](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시 |
| **대체** | [ADR-1299](1299-대장간-현재-옵션-아래에-새-옵션을-둔다.md)의 판 제목 |
| **대체됨** | — |

## 결정

가운데 판의 제목은 **옵션**이다. 비교할 때 위 카드에는 **현재 옵션**, 아래 카드에는 **새 옵션**을 같은 스타일로 표시한다. 판 제목은 두 옵션을 아우르고, 카드 제목은 어느 옵션을 유지하거나 적용하는지 알려준다.
