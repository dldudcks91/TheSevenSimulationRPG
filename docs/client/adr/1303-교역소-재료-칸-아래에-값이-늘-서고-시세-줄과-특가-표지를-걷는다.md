# ADR-1303 — 교역소 재료 칸 아래에 값이 늘 서고 시세 줄과 특가 표지를 걷는다

## 결정

교역소 재료 칸 아래에 **한 번 구매의 값**을 늘 찍는다 — `n개 · n G`(다른 재료 수 · 골드). 고르기 전부터 서고, 상단 구매 칸 아래 가격과 같은 글자다. 재료 넷은 패널 폭을 고르게 나눠 선다. 그 회차의 싼 재료는 칸 아래 값과 고른 뒤 지불 칸 값이 **초록 + ▼** 다. 고른 재료 이름 × 받는 수(옛 본문의 받는 줄)는 제목 줄 오른쪽으로 올린다. 제목 줄 시세(지금 · 다음 특가 · 남은 시간), 칸의 `특가` 표지, 받는 줄의 `특가`, 지불 칸의 줄 그은 평소 값을 걷는다. 특수상단 카드의 상인 이름은 한 명(`mock.js:TRADE.special.who`)으로 돌아간다. 받을 재료를 고른 뒤 지불 칸의 [구매]를 누르는 흐름(ADR-1017 · 1019)은 그대로다.

## 맥락

2026-11-23 기획이 교역소를 가격표로 바꿨다(base_expedition §2-6 · GAME_DESIGN §9 11-23 · R557). 값은 받을 재료마다 하나이고, 특수상단 방문 회차마다 무작위 재료 하나가 싸진다(사다리 순서 회전은 걷었다). 약초는 재료로도 골드로도 비싸다. 그날 교역소는 칸을 눌러야 값이 보였고, 고르기 전에는 특가 표지와 보유량만 보였다.

## 근거

- **값이 고르기 전에 보여야 한다** — 사용자가 원한 것은 「각자 몇 개가 필요한지」다. 칸을 하나씩 눌러 지불 줄을 열어 봐야 값이 보이면 가격표가 아니다. 상단 구매 칸이 칸 아래에 가격을 두는 것과 같은 자리다.
- **두 값을 한 줄에 둔다** — 재료 값은 어느 재료로 내든 같아서, 받을 재료마다 재료 수 하나와 골드 하나면 다 읽힌다. 지불 재료 셋을 칸마다 늘어놓을 까닭이 없다.
- **싼 것은 색과 ▼ 하나로 보인다** — 사용자가 원한 것은 「어? 뭐가 좀 싼데」다. 거래 게임들(Bannerlord · No Man's Sky)은 평소 대비 싼 값을 숫자의 초록으로 보인다. 「특가」 글자 · 다음 특가 · 남은 시간은 그 느낌에 더하는 것 없이 반 칸 패널을 채웠다. ▼ 는 색을 못 가리는 사람에게도 읽히게 붙인다. 평소보다 비싸지는 때가 없어 빨강 ▲ 는 안 쓴다.
- **칸 아래 값에 부족 빨강을 안 쓴다** — 칸 아래 값은 무엇으로 낼지 정하기 전의 값이다. 부족 판정은 지불 칸이 이미 한다.
- **넷이 패널 폭을 나눈다** — 50px 칸 폭에 `n개 · n G` 를 가두면 영어에서 잘린다. 칸 크기는 50px 를 유지한다.
- **받는 줄을 제목 줄로 올린다** — 패널이 높이 반 칸(ADR-0960)이라 값 줄을 더하자 지불 칸의 [구매]가 패널 아래로 반쯤 잘렸다(2026-11-23 실측). 시세 줄이 비운 제목 줄 오른쪽(구매 머리의 [교체]와 같은 짜임)에 두면 본문 높이가 그대로다.
- **상인 이름을 하나로 되돌린다** — 회차마다 이름이 바뀐 것은 교역소 특가 재료를 가리키기 위해서였다. 특가가 없으면 재료별 상인 넷(셋은 임시 이름)이 가리킬 것이 없다.
- 거른 안: 싼 재료 없이 고정 가격표(늘 같은 값이면 「싸다」를 느낄 기준이 없다 — 같은 날 사용자가 되돌렸다) · 싼 재료에 줄 그은 평소 값을 함께(칸 폭이 좁아 `~~3~~ 2개 · ~~100~~ 70 G` 가 영어에서 넘친다 — 얼마나 싼지는 도움말의 % 몫) · 칸 아래에 재료 값만(골드 값을 보려면 다시 눌러야 한다).

## 파급

- i18n `td.trade.deal` · `td.trade.next` 삭제 · `td.trade.price` 추가 · 도움말 `help.shop.trade.body` 의 특가 단락을 싼 재료 단락(무작위 · 초록 ▼ · 평소의 n%)으로 개정
- CSS `.td-trade-market` · `.td-deal-tag` · `.td-deal-cell` · `.td-base` 삭제 · `.td-trade-col` · `.td-trade-price` 추가 · `.td-price.deal`(초록) 에 `::before` ▼
- 개발 URL `&tdc=n` 삭제(`&trd=<재료>` 는 남는다) — src/dev/README
- `mock.js:TRADE.merchants` → `TRADE.special.who`
- 앱 시계(`shopTick`)는 회차가 바뀌는 순간 다시 그린다(특수상단과 같은 순간 — 싼 재료도 그때 바뀐다) · 교역소 남은 시간 글자는 없다
