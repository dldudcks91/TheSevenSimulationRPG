# ADR-1311 — 교역소 재료 칸은 0개여도 흐리지 않는다

| | |
|---|---|
| **상태** | 확정 · 2026-11-23 |
| **화면** | [SCREEN_DESIGN §8-3](../SCREEN_DESIGN.md) |
| **정한 사람** | 제안 후 승인 — 화면 점검에서 「철광석 · 가루 아이콘이 어두운 회색이라 바탕에 묻힌다」를 짚음 → 사용자 「ㅇㅇ모두 수정해봐」 → 원인이 0개 흐림임을 실측으로 확인 |
| **대체** | — |
| **대체됨** | — |

## 결정

교역소의 받을 재료 칸(`matCell` · `.td-trade-item`)은 보유가 0개여도 아이콘을 흐리지 않는다. 보유 수는 칸 오른쪽 아래 숫자(`0`)가 그대로 말한다. 창고 재료 탭의 「0개 칸은 흐리게」(ADR-0379)는 그대로다.

## 맥락

2026-11-23 화면 점검에서 교역소의 철광석 · 가루 칸이 바탕에 묻혀 보였다. 같은 날 실측하니, 보유가 0개인 칸은 재료 탭 규칙(`.mat-cell.zero .inv-icon` 흐림)으로 아이콘이 옅어져 있었다. 보유가 생기면 두 아이콘이 또렷했다. 약초 · 목재는 색이 있어 흐려도 보였고, 회색인 철광석 · 가루만 사라졌다. 철광석 아이콘은 같은 날 다른 작업(PLAN_lab_panel_material_icons C4 — 철광석 · 약초 · 목재를 갈아 끼운다 · 후보 고르기 대기)이 교체를 앞두고 있다.

## 근거

- **교역소 칸은 사는 물건이다** — 재료 탭의 흐림은 「가진 것이 없다」를 칸 전체로 말하는 장치다. 교역소에서는 없는 재료를 사러 오므로 0개가 평소 상태이고, 흐리면 상품 진열이 빈 선반처럼 읽힌다. 상단 구매 칸도 가진 수와 무관하게 또렷하다.
- **원인을 고친다** — 아이콘을 밝게 다시 그려도 0개 흐림이 남으면 회색 계열 재료는 다시 묻힌다. 그림은 C4 의 몫으로 두고 겹치지 않는다.
- 거른 안: 철광석 · 가루 아이콘을 밝게 다시 그린다(원인이 흐림이라 다른 화면에서는 이미 또렷하다 · C4 와 겹친다) · 재료 탭 흐림을 모든 곳에서 걷는다(재료 탭에서는 0개 칸이 자리만 지키는 것이 맞다 — ADR-0379).
