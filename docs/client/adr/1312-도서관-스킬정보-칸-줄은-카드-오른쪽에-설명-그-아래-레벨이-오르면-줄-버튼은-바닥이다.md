## 결정

스킬정보 칸 줄(고유 · 습득 · 전직)이 위아래로 선다 — **카드 오른쪽 = 이름 + 설명**, **그 아래 = 「레벨이 오르면」 줄**, **바닥 = 레벨 · 책 글 + 버튼**.

```
┌────────────────────────────────────┐
│ [▣]  배시                            │
│ 영웅  15.0초마다 무기를 높이 들어 적   │
│       하나를 내리찍어 48~64 의 물리   │
│       피해를 입힙니다                 │
│ 레벨이 오르면  피해 배율 150% → 180%   │
│ ────────────────────────────────── │
│ Lv.1 → Lv.2 · 책 1/1    [업그레이드] │
└────────────────────────────────────┘
```

- **설명** = 그 칸 스킬의 효과 문장 — 카드 설명창 · 캐릭터 탭 액티브 줄과 같은 함수(`tip.js:skillLineHtml`) · 그 영웅 기준 숫자 · 지금 레벨(낀 장비의 스킬 +n 포함 — 카드의 `Lv.n` 과 같은 레벨).
- **「레벨이 오르면」 줄** = 그 스킬의 레벨 칸(`skill_effect.csv:level_field` · `level_field2`)마다 `이름 지금 → 다음` — 이름 · 값은 도감 스킬 툴팁 레벨별 옵션과 같은 것(`tip.js:skillLevelSteps`) · 한 단계에서 안 바뀌는 칸(타수 소수 단계)은 빠진다 · 바뀌는 칸이 없거나 최대 레벨이면 `—`.
- **바닥** = 왼쪽 `Lv.a → Lv.b · 책 가진/드는`(막힘 · 최대 레벨 글은 ADR-1308 그대로) · 오른쪽 끝 버튼.
- **습득 줄이 새 책을 받으면** 이름 줄 = `앞 스킬 Lv.n → 새 책` · 설명 · 레벨 줄은 새 책(Lv.1) 것 · 바닥 = `책 가진/드는` + [배우기] · [덮어쓰기].
- **전직 줄 · 책이 안 되는 고유** = 이름 + 설명만(레벨 줄 · 바닥 없음 — 전직 스킬은 레벨이 없다 · ADR-1190). 빈 칸은 이름 자리 `—`.

## 맥락

[ADR-1308](1308-도서관-스킬-업그레이드는-스킬정보-칸마다-선다-스킬-업그레이드-패널을-걷는다.md)(같은 날)로 업그레이드가 스킬정보 칸 줄에 섰다. 줄은 카드 · 글 두 줄(이름 / `Lv.a → Lv.b · 책`) · 오른쪽 끝 버튼이라, 무엇이 오르는지는 카드에 마우스를 올려야 알았고 올려도 지금 레벨의 문장만 보였다. 사용자가 설명과 오르는 능력치를 칸 줄에 적고 버튼을 아래로 내리자고 했다.

## 근거

- **업그레이드를 누르기 전에 얻는 것이 보인다** — 책을 쓰는 결정의 값어치(`피해 배율 150% → 180%`)가 버튼 바로 위에 선다. 도감 스킬 툴팁에는 레벨별 옵션이 있었지만 도서관에서는 안 보였다.
- **같은 글을 새로 만들지 않는다** — 설명은 설명창과 같은 함수, 레벨 줄은 도감 레벨별 옵션과 같은 이름 · 값을 다시 쓴다. 규칙 문장이 아니라 그 스킬의 효과 · 수치라 「패널에 규칙 문장 없음」(CLAUDE.md 규칙 7)과 안 부딪힌다 — 전직의 방 창이 전직 스킬 효과 한 줄을 적는 것과 같다(ADR-0852).
- **버튼이 바닥에 서면 세 줄의 버튼이 한 높이에 선다** — 줄마다 설명 길이가 달라도 바닥이 맞는다.
- 거른 안 — **레벨 줄을 `Lv.n 마다 +x` 로**: 「지금 → 다음」이 바닥의 `Lv.a → Lv.b` 와 짝이 맞고 도감 레벨별 옵션(레벨마다의 값)과도 같은 표기다. **바닥을 버튼 하나(칸 폭)로**: 책 가진/드는 수가 버튼과 떨어진다.

## 파급

- 렌더러 — `libSlotRow` 가 위(카드 + 이름 · 설명) · 레벨 줄 · 바닥 셋을 쌓는다 · 메인미션 손가락 선택자 `.lib-info .lib-slot .btn.primary` 는 그대로 닿는다
- `tip.js` — `skillLevelSteps(id, up)` export(도감 레벨별 옵션의 이름 · 값 함수를 빌린다)
- CSS — `.lib-slot` 세로 짜임 · `.lib-slot-top` · `.lib-slot-desc` · `.lib-slot-lv` · `.lib-slot-foot`
- i18n — `bk.lvGain`(「레벨이 오르면」)
- 스킬정보 패널이 높아지는 만큼 아랫줄(보유 스킬북 · 스킬 북 제작)이 낮아진다
