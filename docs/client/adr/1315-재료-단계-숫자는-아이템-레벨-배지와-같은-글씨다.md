# ADR-1315 — 재료 단계 숫자는 아이템 레벨 배지와 같은 글씨다

| | |
|---|---|
| **상태** | 확정 · 2026-11-23 |
| **화면** | [SCREEN_DESIGN §6](../SCREEN_DESIGN.md) 「창고 — 재료 탭」 |
| **정한 사람** | 사용자 지시(「왼쪽위에 나오는 1~5까지 로마자가 좀 우리게임에 안어울리는 글씨체」 → 「맞춰 아이템 글씨체로」) |
| **대체** | [ADR-0983](0983-재료-단계는-칸-왼쪽-위-로마-숫자다.md) — **글씨만**(표시 글꼴 · 굵게 · 청동 금색). 자리(칸 왼쪽 위) · 로마 숫자 `I` ~ `V` · 최하급도 다는 것 · 검은 테두리는 그대로 산다 |
| **대체됨** | — |

## 결정

재료 칸 왼쪽 위 단계 숫자 `I` ~ `V`(`.mat-tier`)의 글씨는 아이템 칸 오른쪽 아래 레벨 배지 `Lv.n`(`.inv-lv`)과 **같다** — 본문 글꼴(`--font-main`) · 보통 굵기 · 같은 크기(`--fs-2xs` + 1px) · 같은 색(`--text-secondary`) · 같은 검은 테두리 그림자. 재료 칸을 쓰는 자리(창고 재료 탭 · 대장간 합성 · 건설 · 연구소 · 강화 비용 칸)가 모두 같다.

## 맥락

ADR-0983 은 단계 숫자를 표시 글꼴(Cinzel) 굵게 · 청동 금색으로 그렸다. 11-23 그 글씨가 게임 안 다른 글자와 어울리지 않는다는 지적이 나왔다. 그날 Cinzel(`--font-display`)은 워드마크 · 메뉴 글자 말고는 게임 화면 안에서 이 단계 숫자만 썼고, 같은 칸의 보유 수량 · 아이템 칸의 `+n` · `Lv.n` 은 본문 글꼴이었다.

## 근거

- **칸 모서리 글자는 한 벌** — 같은 칸 오른쪽 아래 보유 수량과 아이템 칸의 `Lv.n` 이 본문 글꼴이다. 모서리 넷 중 하나만 장식 글꼴이면 그 글자만 튄다.
- 거른 안 — **글꼴만 바꾸고 굵게 · 청동 금색은 남긴다**: 사용자가 「아이템 글씨체로」 맞추라 했고, 바꿀 범위를 글씨체 · 굵기 · 색으로 밝힌 뒤 받은 답이다.

## 파급

- CSS `.mat-tier` 한 규칙 · SCREEN_DESIGN §6 재료 탭 줄
- ⚠ 단계 숫자와 보유 수량이 같은 회색이 된다 — 위치(왼쪽 위 · 오른쪽 아래)와 글자 꼴(로마 숫자 · 아라비아 숫자)이 둘을 가른다
