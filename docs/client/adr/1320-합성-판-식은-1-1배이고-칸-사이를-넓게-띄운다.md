# ADR-1320 — 합성 판 식은 1.1배이고 칸 사이를 넓게 띄운다

## 결정

합성 판 가운데 식(낼 재료 칸 `+` 골드 칸 `›` 만들 재료 칸)은 칸 · 글자를 **1.1배**로 그리고, 칸과 기호 사이를 **넓게** 띄운다(`.fg-sy-recipe` 의 `gap`). 크기를 키워 보이게 하지 않고 사이를 벌려 보이게 한다.

## 맥락

ADR-1318 은 「잘 보이게」를 식 1.25배 + 조금 넓힌 사이로 풀었다. 그날 사용자가 크기는 1.1배 안팎으로 줄이고 사이를 띄우라고 했다.

## 근거

- 사용자 지시. 칸이 커지면 왼쪽 재료 판 칸(같은 재료 칸)과 크기가 어긋나 한 화면 안에서 같은 칸이 두 크기로 보인다 — 1.1배는 그 차이가 작다.
- 사이를 띄우면 「낼 것 + 낼 것 › 나올 것」이 덩어리로 갈려 읽힌다.

## 파급

- CSS `.fg-sy-recipe` 의 `zoom` · `gap` 한 줄
- 이름이 칸 아래에 떠 있는 규칙(칸 폭을 안 넓힌다)은 그대로 — 사이가 넓어도 영어 이름이 판 안에 든다(2026-11-23 실측 · 한국어 · 영어)
