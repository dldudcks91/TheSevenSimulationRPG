## 결정

스킬정보 칸 줄 셋(고유 · 습득 · 전직)마다 **맨 위에 제목 띠**가 선다 — 그 칸의 출처 이름(「영웅」 · 「습득」 · 「전직」 — 카드 아래 글자와 같은 `sk.innate` · `sk.src.*`)을 제목처럼 굵게 적는다. **카드 아래 출처 글자는 걷는다**(띠가 말한다).

```
┌──────────────────────────────┐
│ 영웅                          │  ← 제목 띠 — 줄 폭 전체 · 어두운 반투명 바탕 · 아래 가는 선
├──────────────────────────────┤
│ [카드]  배시           도끼 · 둔기 │
│         15초마다 …               │
│ Lv.1 → Lv.2  피해 배율 300% → 330% │
│ 책 100/1              [업그레이드] │
└──────────────────────────────┘
```

- 띠는 줄 테두리 안쪽 끝까지 닿는다(줄 안쪽 여백을 넘어 선다) · 고른 책이 걸린 줄의 파란 테두리는 띠까지 두른다.
- 띠 모양 = 영웅 띠 카드 위칸(`.hs-band`)과 같은 어두운 반투명 바탕 + 아래 가는 선 · 글씨는 패널 소제목처럼 굵다.
- 캐릭터 탭 「액티브 스킬」 카드 · 편성 진형 칸은 그대로다(`skillCardGrid` 의 `caption` 만 끈다).

## 맥락

2026-11-23 스킬정보 칸 줄은 카드(+ 칸 아래 출처 글자 · ADR-0578) | 이름 · 설명 / 레벨 줄 / 바닥(ADR-1312 · 1317)이었고, 같은 날 윗줄 전폭이 됐다(ADR-1327). 출처 글자는 카드 아래 작은 회색 글이라 줄이 무엇의 칸인지(영웅 고유 · 책으로 배운 습득 · 전직) 줄 머리에서 안 읽혔다.

## 근거

- **줄마다 무엇의 칸인지가 맨 위에서 읽힌다** — 셋이 같은 꼴의 줄이라 머리 이름이 줄을 가른다.
- **한 곳만 말한다** — 띠와 카드 아래 글자가 같은 말을 두 번 하지 않는다.
- **이미 있는 띠 문법** — 영웅 띠 카드 위칸과 같은 바탕 · 선이라 새 겉모양이 아니다.
- 거른 안 — **띠에 필요 무기 칩도 올리기**: 칩은 스킬 이름 줄의 것이라(설명창과 같은 자리) 이름과 떨어진다.

## 파급

- 렌더러 — `libInfoPanel` 이 `skillCardGrid(h, ctx, { caption: false })` · `libSlotRow` 맨 앞에 `.lib-slot-band`(`sourceName(i)`)
- CSS — `.lib-slot-band`(줄 안쪽 여백만큼 음의 여백 · 바탕 · 아래 선) · 스킬정보 패널이 띠만큼 높아지고 아랫줄이 그만큼 낮아진다
- i18n 변화 없음
