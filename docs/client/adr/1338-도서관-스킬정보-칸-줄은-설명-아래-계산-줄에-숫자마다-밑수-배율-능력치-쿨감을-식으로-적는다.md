## 결정

```
┌ 영웅 ─────────────────────────────┐
│ [카드] 배시                  도끼 · 둔기 │
│        15초마다 … 40~64 의 물리 피해 …   │
│ - - - - - - - - - - - - - - - - - - - - │
│ 피해 40~64 = 데미지 10~16 × 300% × STR 13(×1.33) │
│ 쿨타임 15.0초 = 15초 − 쿨감 0%            │
│ Lv.1 → Lv.2  피해 배율 300% → 330%       │
│ 책 1/1                      [업그레이드] │
└─────────────────────────────────────┘
```

- 스킬정보 칸 줄(고유 · 습득 · 전직)마다 카드 · 설명 아래 **계산 줄**이 선다 — 설명의 숫자마다 한 줄 `이름 값 = 식`.
  - **피해 · 회복 · HP** = `밑수 이름 a~b × 배율% × 능력치 약어 값(×계수)` — 밑수는 데미지 · 마법 공격력 · 최대 HP(설명창 Alt 식과 같은 이름) · 반지 · 전직 태그 몫이 있으면 `× 태그 ×n`.
  - **쿨타임** = `실제 쿨 = 표기 쿨 − 쿨감 n%`(실제로 깎인 비율 — Alt 식과 같은 항).
  - 걸린 효과에 태그 몫이 있으면 `태그 지속 +n% · 효과 +n%`.
- 계수가 0 인 슬롯(지속 · 값 · 타수 …)은 값을 안 바꾸므로 줄이 없다. 낼 줄이 없는 칸(빈 칸)에는 계산 줄이 안 선다.
- **값과 중간 값은 `skill.previewOf` 가 낸다** — `parts.amount` 에 `base`(밑수 양끝) · `tagMult` · `statMult` · `attrs`(`[{attr, v, mult}]`)를, 최상위에 `tags`(`{duration, value}`)를 더했다. 화면은 곱하지 않고 찍기만 한다.

## 맥락

2026-11-24 스킬정보 칸 줄은 설명 문장(그 영웅 기준 숫자) · 레벨 줄(책 레벨 하나 오를 때 바뀌는 값)만 들었다. 숫자가 어디서 나왔는지는 스킬 설명창에서 Alt 를 누를 때만 `40~64 (데미지 × 300% × STR)` 처럼 식의 **모양**이 섰고, 데미지 범위 · 능력치 값 · 계수는 어디에도 안 보였다.

## 근거

- **식의 모양이 아니라 숫자** — 「어떤 스탯이 얼마나」를 보려면 능력치 값과 그 계수(`×1.33`)가 같이 서야 한다. Alt 식은 모양만 있어 사용자가 물은 「영향 미치는 스탯」에 못 답한다.
- **줄마다 `이름 값 = 식`** — 설명의 숫자(40~64 · 15초)가 줄 머리에 다시 서서 어느 숫자의 식인지 바로 짝지어진다. 계산이 맞는지 눈으로 확인된다(10~16 × 300% × 1.33 = 40~64).
- **`previewOf` 가 중간 값을 낸다** — 렌더러는 계산하지 않는다(DEV_PLAN 부채 #3). 태그 몫은 `(1 + 데미지% + 태그) / (1 + 데미지%)` 라 화면이 다시 적으면 전투와 갈린다.
- **계수 0 슬롯을 안 적는다** — 지속 · 값 슬롯은 `skill_effect.csv` 에서 계수가 전부 0 이라 `+ VIT × 0` 은 잡음이다(Alt 식의 거름과 같다). 밸런스가 계수를 채우면 그때 줄을 더한다.
- **규칙 문장이 아니다** — 줄은 이름 · 숫자 · 연산 기호뿐이다. 「능력치 계수는 …」 같은 설명은 도움말의 몫이다(CLAUDE.md 규칙 7 · ui 원칙 4).
- 거른 안 — **설명 문장 안에 Alt 식을 늘 세우기**: 값이 없고 모양뿐이라 질문에 못 답한다. **올리면 뜨는 툴팁**: 「다 보여줘」가 늘 보이는 것을 원했다. **데미지 범위를 무기 · 데미지 % 까지 풀기**: 데미지는 세부 옵션의 한 줄(캐릭터 탭)이라 여기선 그 값에서 멈춘다.
