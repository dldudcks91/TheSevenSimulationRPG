# ADR-1344 — 보관 칸을 끄는 동안 들어갈 칸은 칸 테두리 자체가 하늘색 3px 로 바뀐다

## 결정

보관 칸을 끄는 동안 아이템이 들어갈 칸(ADR-1340)은 **칸의 회색 테두리 자리 그 자체가 하늘색 3px 테두리**(`--color-info`)로 바뀐다. 칸 크기는 그대로다(테두리는 칸 안으로 먹는다). 어느 칸을 두르는지 · 창고가 재료 · 스킬북 탭일 때 패널을 두르는 것은 ADR-1340 그대로다.

## 맥락

ADR-1340 은 칸 안쪽에 2px 선(outline)을 그렸다. 보관 칸은 한 장 배율 아래서 작게 서서, 2px 선이 화면에서 1px 남짓으로 보였고 빈 칸의 회색 테두리(1px)와 굵기 차이가 없었다. 사용자가 너무 얇다 · 회색 테두리 자리를 차지해야 한다고 했다.

## 근거

- **테두리 자체를 바꾼다** — 칸 바깥 틀(회색 선)이 하늘색으로 바뀌어야 「이 칸」으로 읽힌다. 안쪽에 덧그린 선은 회색 틀 안에 갇혀 보인다.
- **3px** — 고른 칸 표시(`.pick` · 3px)와 같은 굵기다. 등급 테두리(찬 칸 2px)보다 한 단 굵어 겹치는 상자 칸에서도 읽힌다.
- **칸 크기 그대로** — 칸이 `border-box` 라 테두리가 굵어지면 안으로 먹는다. 끄는 동안 격자가 흔들리지 않는다.
- 거른 안 — **진형 칸처럼 칸 바깥에 띄워 두르기**(`outline-offset` 양수): 칸 사이 4px 에 옆 칸 테두리와 붙어 어느 칸인지 흐려진다.

## 파급

- CSS — `.inv-cell.drop-on` = `border: 3px solid var(--color-info)` · 빈 칸의 안쪽 그림자 끔 · `.panel.bag.drop-on`(패널 경우)은 2px 안쪽 선 그대로
- 렌더러 · 로직 · i18n 변화 없음
