## 결정

캐릭터 탭 ② 「기본 옵션」 칸의 제목 아래 첫 줄(ADR-1345 의 칩 줄)이 **신원 한 줄**이 된다 — 왼쪽 = 고른 영웅 **이름**(굵게) · 오른쪽 끝 = 죄종 → 직업 칩(경험치 숫자 바로 위 · 자리 그대로). 칸이 모자라면 칩 묶음이 이름 아래 줄로 접힌다. 도서관 기본 옵션의 신원 줄([ADR-1332](1332-도서관-기본-옵션-제목-아래-이름-죄종-직업-한-줄이-서고-아랫줄은-탭-패널-전직의-방-2-1-이다.md))과 같은 줄이다.

## 맥락

같은 날 ADR-1345 로 칩을 제목 줄에서 제목 아래 첫 줄 오른쪽 끝으로 내렸고, 그 줄의 왼쪽은 비어 있었다. 이름은 영웅 띠 카드(§5)에만 있었다. 도서관 기본 옵션은 같은 자리에 이름 + 칩 한 줄을 이미 두고 있었다.

## 근거

사용자 지시다.

- **도서관과 같은 줄인 이유** — 두 탭의 기본 옵션이 같은 영웅의 같은 시트를 그린다. 신원 줄의 모양(이름 굵게 왼쪽 · 칩 오른쪽 끝 · 모자라면 칩이 접힘)이 갈리면 같은 값을 두 문법으로 읽게 된다 — 이름 · 칩 CSS 규칙을 두 줄이 같이 쓴다
- **칩 묶음이 접히는 이유** — 네 칸이 같은 폭이라 영어 긴 이름 + 칩 셋(성장 등급이면)이 한 줄을 넘을 수 있다. 이름을 자르면 신원을 못 읽으므로 칩 쪽이 내려간다(도서관과 같은 판단)

## 파급

- `app.js:attrPanel` — 칩 줄이 `div.ch-ids` 안의 `b.ch-ids-nm`(`L(h.name)`) + `span.attr-ids` 가 된다
- `style.css` — `.ch-ids` 가 접히는 flex 줄이 되고, 이름 · 칩 규칙은 도서관 `.lib-stat-nm` · `.lib-stat-id > .attr-ids` 와 선택자를 같이 쓴다
- **새 i18n 키가 없다** — 이름은 영웅 데이터의 `{ko, en}` 을 `L()` 이 푼다
