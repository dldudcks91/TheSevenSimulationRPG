# ADR-1350 — 연구소 잠긴 지점도 머리에 Lv 눈금이 선다

| | |
|---|---|
| **상태** | 확정 · 2026-11-24 |
| **화면** | [SCREEN_DESIGN §8](../SCREEN_DESIGN.md) |
| **정한 사람** | 사용자 지시(「모두 채광처럼 레벨 이랑 오른쪾에 레벨칸나오도록수정」) |
| **대체** | 1343 의 「잠긴 지점은 눈금이 안 보이되 자리는 남는다」 |
| **대체됨** | — |

## 결정

연구소 고른 지점의 머리는 **잠긴 지점도 열린 지점과 같은 `Lv n / 최대` + 눈금 줄**을 세운다 — 잠긴 지점은 `Lv 0 / 최대` 와 빈 칸(최대 레벨 수만큼)이다. 그림 원의 흐림 · 「다음 레벨」 칸의 자물쇠 + 여는 조건은 그대로다.

## 맥락

같은 날 ADR-1343 은 머리 높이를 고정하려고 잠긴 지점의 눈금 줄을 안 보이게 두고 자리만 남겼다 — 잠긴 지점은 이름과 설명 사이가 한 줄 비었다. 사용자는 열린 지점(채광)처럼 모든 지점에 레벨과 그 오른쪽 칸이 서기를 바랐다.

## 근거

- **같은 자리에 같은 것** — 지점을 바꿔 눌러도 머리의 모양이 같다. 잠긴 지점에서도 「끝까지 몇 레벨인가」가 머리에서 읽힌다(레벨 목록과 같은 정보를 한 줄로).
- **잠김은 이미 다른 곳이 말한다** — 흐린 그림 원 · 「다음 레벨」 칸의 자물쇠 + 「연구소 n랭크」 · 「창고 건설」. 눈금을 숨겨 잠김을 한 번 더 말할 까닭이 없다.
- 높이는 그대로다 — 안 보이던 자리에 보이는 줄이 서므로 머리 높이 · 레벨 목록 자리(ADR-1341)는 바뀌지 않는다.
