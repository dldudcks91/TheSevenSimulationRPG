## 결정

편성 탭 가진 물약 줄의 칸은 **개수와 상관없이 그 물약 그림 그대로**다. 0 개는 칸 오른쪽 아래 `×0` 만 흐린 글씨로 말한다.

## 맥락

같은 날 ADR-1348 이 0 개인 물약을 그 물약 그림의 회색 실루엣으로 칠했다(`brightness(0) invert(.5)` · 흐림).

## 근거

- **그림이 어느 물약인지를 말한다** — 사용자 지시. 실루엣은 다섯 병의 색을 지워 단계를 모양으로만 가르게 했다. 없다는 것은 `×0` 이 이미 말한다
- 거른 안 — 0 개 칸 전체를 흐리게(그림이 다시 덜 읽힌다 · 사용자는 「그냥 보여줘」)

## 파급

- CSS — `.pt-inv.sil` 걷음 · `.pt-inv.zero .p-cnt`(흐린 개수)
