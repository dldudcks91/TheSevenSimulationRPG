## 결정

연구소 고른 지점의 **「다음 레벨」 칸(예약 높이 — ADR-1341)** 안은 위에서부터 **값 변화 줄**(지금 값 보통 글 → 올린 뒤 굵은 초록) · (다른 연구가 돌면) 「연구 중 {줄} · {지점}」 — 그리고 **칸 바닥에 붙은 줄** = 비용 칸(왼쪽) · **걸리는 시간 + [연구]**(오른쪽 끝, 시간이 버튼 바로 왼쪽)다. 연구 중이면 바닥 줄이 진행 막대 · 남은 시간 + [그만두기]다. 예약 높이의 빈 자리는 값 변화 줄과 바닥 줄 사이로 간다.

**재료 칸(`matTile` — 그림 칸 오른쪽 아래 필요 수 · 필요/보유)의 수량 글씨는 어디서나 보통 굵기다** — 건설 · 연구소 · 대장간(강화 · 인챈트 · 합성 · 손질).

## 맥락

그날 「다음 레벨」 칸은 위에서부터 값 변화 줄(오른쪽 끝에 「27분 걸림」) → 비용 칸 + [연구] → (다른 연구 중이면) 안내 줄이었고, 예약 높이 때문에 비용 칸 · [연구] 아래가 비었다. 걸리는 시간은 ADR-0694 가 「비용 칸 줄에 끼우면 재료 칸이 세로로 접힌다」며 값 변화 줄 끝에 올린 자리였다 — 값 변화와 시간이 한 줄에 양끝으로 떨어져 무엇의 시간인지 안 붙어 보였다. 재료 칸 수량 글씨는 대장간 판만 보통 굵기였다(ADR-1322).

## 근거

- **누르는 것 곁에 그 값** — 걸리는 시간은 비용처럼 [연구]를 누르면 치르는 것이다. 버튼 바로 왼쪽이면 「이 버튼 = 이 비용 · 이 시간」이 한 덩어리로 읽힌다.
- **접힘 걱정이 풀렸다** — 고른 지점 열이 넓어져(두 패널 줄의 33%) 비용 칸 둘 + 「1시간 30분 걸림」 + [연구](98px)가 한 줄에 든다(1600×800 · 한영 · 두 스킨 실측 — 비용 칸 줄 높이 52 그대로).
- **바닥에 붙인다** — 빈 자리가 버튼 아래(레벨 목록 소제목 바로 위)에 서면 버튼이 허공에 뜬다. 바닥에 붙이면 「다음 레벨」 칸이 아래 레벨 목록과 이어지고 버튼 자리가 상태와 무관하게 같다.
- **값 변화는 올린 뒤가 주인공** — 지금 값까지 굵으면 두 숫자가 같은 무게로 겨룬다.
- **수량 글씨** — 사용자 지시. 굵은 숫자가 칸 그림을 덮는 문제(ADR-1322 의 근거)는 대장간만의 것이 아니었다.

## 파급

- `app.js` — `dpSide` 비용 갈래: 값 변화 줄에서 시간을 걷고 · 안내 줄이 비용 칸 줄 위로 · `.dp-side-go-w`(걸리는 시간 + [연구])
- `style.css` — `.dp-side-act` · `.dp-side-res` 가 `margin-top: auto` · `.dp-side-go-w` · `.dp-side-rate > b:first-child` 보통 글 · `.dp-side-time` 의 `margin-left: auto` 걷음 · `.cn-mat-n` 보통 굵기(`.fg-up .cn-mat-n` 의 작은 글씨는 그대로)
- ⚠ 비용 칸이 셋 이상이 되거나 시간 글이 길어지면 비용 칸 줄이 접힐 수 있다 — 그때 다시 잰다
