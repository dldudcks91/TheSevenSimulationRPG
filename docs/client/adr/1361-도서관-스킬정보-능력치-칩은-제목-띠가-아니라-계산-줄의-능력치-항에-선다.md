# ADR-1361 — 도서관 스킬정보 능력치 칩은 제목 띠가 아니라 계산 줄의 능력치 항에 선다

## 결정

- **제목 띠 칩 = 태그 → 종류**(능력치는 뺀다).
- **계산 줄의 능력치 항 = 능력치 칩 + 값 + 계수** — `피해 40~64 = 데미지 10~16 × 300% × [STR] 13(×1.33)`. 칩은 스킬 설명창의 능력치 칩과 같다(청동색 · 각진 모서리). 계산 줄 높이를 안 늘린다.
- 그래서 도서관에 서는 능력치는 **지금 숫자를 실제로 바꾸는 것**(계수가 곱해지는 `mult_pct` 슬롯)뿐이다. 계수 0 인 슬롯의 능력치는 설명창에만 선다.

## 맥락

2026-11-24 띠 오른쪽에 태그 · 종류 · 능력치 칩이 섰고(ADR-1360), 계산 줄에도 같은 능력치가 약어 글자로 한 번 더 섰다(`STR 13(×1.33)` · ADR-1338). 띠의 능력치 칩은 계수 0 인 것도 찍어 숫자를 안 바꾸는 능력치가 섞였다(라그나로크 STR · VIT).

## 근거

- **한 번만 · 값 옆에** — 같은 능력치가 띠와 계산 줄에 두 번 섰다. 계수가 서는 자리에 칩을 두면 「어느 능력치가 · 얼마나」가 한 자리에서 읽힌다.
- **계수 0 이 빠진다** — 띠의 능력치 칩은 숫자를 안 바꾸는 능력치까지 찍었다. 계산 줄은 곱해지는 항만 내므로 칩이 곧 「영향 미치는 스탯」이다(사용자의 처음 질문).
- 거른 안 — **띠에도 남기기**: 두 번 선다.

## 파급

- 렌더러 — `tip.js:skillChipsHtml` = 태그 · 종류 · `skillCalcLines` 능력치 항 = `.tip-chip.attr` + 값 + 계수
- CSS — `.lib-slot-calc .tip-chip` 줄 높이를 계산 줄에 맞춘다
- 설명창(`skillBodyHtml`)은 그대로 — 이름 뒤 능력치 칩(계수 0 도)
