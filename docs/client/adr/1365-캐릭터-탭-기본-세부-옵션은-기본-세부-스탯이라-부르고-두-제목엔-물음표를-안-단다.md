# ADR-1365 — 캐릭터 탭 기본 · 세부 옵션은 기본 · 세부 스탯이라 부르고 두 제목엔 물음표를 안 단다

## 결정

캐릭터 탭 네 칸 가운데 **「기본 옵션」 · 「세부 옵션 1 · 2」를 「기본 스탯」 · 「세부 스탯 1 · 2」로 부른다** — 같은 이름을 쓰는 자리(유닛 툴팁 열 이름 · Alt 각주 · 도서관 기본 스탯 · 도움말 본문)가 다 따라 바뀐다(`ch.attr.h` · `ch.detail.h` · `ch.detail.hn` · `tip.unit.altHint*` — 영어 · 중국어는 이미 Stats · 属性 라 그대로). **기본 스탯 · 세부 스탯 1 · 2 제목엔 도움말 `?` 를 안 단다** — 네 칸 가운데 `?` 는 장비만 남는다. 장비의 `?` 문장은 「선택한 영웅이 착용한 장비입니다. 장비에 마우스를 올리면 옵션을 확인할 수 있습니다.」(`hint.equipment`)로 줄인다.

## 맥락

그날 캐릭터 탭 네 칸 제목은 모두 이름 + `?` 였다. 기본 옵션의 `?` 는 「영웅 생성 시 각 기본 능력치는 최대 n까지 붙습니다…」(`hint.attributes`), 세부 옵션 1 · 2 의 `?` 는 「장비와 스킬 효과가 반영된 전투 수치입니다. 수치 이름에 마우스를 올리면 설명을 볼 수 있습니다.」(`hint.combat_stats`)였다. 두 칸의 줄은 줄마다 올리면 설명 카드가 이미 떴다(§2 「능력치 설명 툴팁 규격」). 「옵션」은 아이템 옵션 줄과 같은 말이었다.

## 근거

- **사용자 지시**
- 두 칸은 줄마다 설명 카드가 있어 제목의 `?` 가 더하는 정보가 적다
- 도서관 기본 스탯 제목의 `?`(`hint.attributes`)는 이 지시의 범위(캐릭터창) 밖이라 그대로 둔다

## 파급

- 렌더러 — `app.js:attrPanel` · `detailPanels` 제목을 `helpHeading` 에서 `el('h2')` 로 · i18n `hint.combat_stats` 삭제(읽는 자리가 없다) · `hint.equipment` 문장 교체 · `hint.attributes` 는 도서관 · 영웅 생성이 계속 읽는다
- 규격 — SCREEN_DESIGN 의 「기본 옵션」 · 「세부 옵션」을 전부 「기본 스탯」 · 「세부 스탯」으로 · §2 「제목 도움말」 예외에 한 문장
- ⚠ 기획서(docs/game_design) · 코드 주석은 옛 이름 그대로다
