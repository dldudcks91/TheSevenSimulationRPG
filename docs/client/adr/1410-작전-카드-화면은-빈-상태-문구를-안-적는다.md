## 결정

편성 탭 파티 전술과 가방 창에서 「~ 없음」 빈 상태 문구를 걷는다.

- 편성 탭 빈 칸 카드 — 칸 이름 · 「가방 n」 만(「카드 없음」 없음 · 점선 테두리 그대로)
- 가방 창 「장착 중」 줄 — 칸이 비었으면 줄째 안 선다(잠긴 칸의 여는 랭크 줄은 그대로)
- 가방 창 두 덩어리 — 칸이 없으면 머리(「사용한 카드」 · 보관 n / 칸 수 · 「새 카드」)만 선다
- 맨 아래 고른 카드 줄 — 고른 카드가 있을 때만 선다

## 맥락

ADR-1399(2026-11-26)의 가방 창은 비어 있는 자리마다 「~ 없음」 문구를 달았다(고른 카드 · 등급 탭으로 걸러 빈 칸 · 사용한 카드 · 새 카드). 편성 탭 빈 칸 카드와 「장착 중」 줄도 「카드 없음」 을 적었다.

## 근거

- 사용자가 빈 상태를 글로 설명하지 말라고 했다 — 칸이 비어 있으면 빈 것이 보인다
- 고른 카드 줄은 고르면 그때 선다 — 고르기 전에는 [장착] · [분해] 할 대상이 없다
- 잠긴 칸의 「지휘 천막 n랭크」 는 빈 상태가 아니라 여는 곳이라 남긴다

## 파급

- JS — `app.js:tacticRow`(빈 칸) · `tacticBagBody`(장착 중 줄 · 격자 · 고른 카드 줄)
- i18n — 걷음 `rs.card.none` · `rs.bag.empty` · `rs.bag.usedEmpty` · `rs.bag.gradeEmpty` · `rs.bag.pickNone`
- CSS — 걷음 `.tcb-empty` · `.tc-none`
- ⚠ 같은 종류가 남은 곳 — 결투장 판의 「작전 카드 없음」(`ar.noTactic`)은 이 결정 밖이다
