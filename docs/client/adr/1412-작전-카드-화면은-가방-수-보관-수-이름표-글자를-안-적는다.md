## 결정

편성 탭 파티 전술과 가방 창에서 개수 글자와 이름표 글자를 걷는다.

- 편성 탭 빈 칸 · 잠긴 칸 카드 — 「가방 n」 을 안 적는다. 빈 칸은 칸 이름만 · 잠긴 칸은 칸 이름 + 자물쇠 + 여는 지휘 천막 랭크
- 가방 창 맨 위 줄 — 「장착 중」 이름표 없이 든 카드(그림 · 이름 · 등급 칩)만 · 잠긴 칸이면 여는 랭크 한 줄
- 가방 창 사용한 카드 머리 — 「보관 n / 칸 수」 · 「보관 칸 가득 참」 을 안 적는다. 가득 차면 새 카드의 [장착] 이 꺼질 뿐이다
- 맨 아래 고른 카드 줄 — 사용한 카드여도 「사용한 카드」 표를 안 단다

## 맥락

ADR-1410(2026-11-26)이 「~ 없음」 문구를 걷은 뒤에도 편성 탭 빈 칸 카드에 「가방 n」 이 남았다. Admin 의 Tactic Cards 줄로 카드를 채우면 「가방 200」 처럼 큰 수가 섰다. 가방 창에도 「장착 중」 · 「보관 5 / 10」 · 「사용한 카드」 같은 덧붙은 글자가 있었다.

## 근거

- 사용자가 화면에 글을 넣지 말라고 했다 — 가방에 무엇이 몇 장 있는지는 창을 열면 칸과 「×n」 으로 보인다
- 남기는 글자 — 칸 이름 · 창 제목 · 등급 탭 · 두 덩어리 머리 · 카드 조각 · 버튼 · 잠긴 칸의 여는 랭크 · 나가 있는 편성의 자물쇠 줄

## 파급

- JS — `app.js:tacticRow`(빈 칸 · 잠긴 칸) · `tacticBagBody`(맨 위 줄 · 사용한 카드 머리 · 고른 카드 줄). 행 카드의 `.bag` 클래스는 길 안내 고르개라 남는다
- i18n — 걷음 `rs.bag.n` · `rs.bag.cur` · `rs.bag.store` · `rs.bag.full` · `rs.bag.usedTag`
- CSS — 걷음 `.tc-foot` · `.tc-bag` · `.tcb-cur-h` · `.tcb-store` · `.tcb-used-tag`
- ⚠ 보관 칸 수(`tactic_used_cap`)가 화면에 안 보인다 — 가득 찬 때는 꺼진 [장착] 으로만 드러난다. 규칙은 도움말(§12)이 적는다
