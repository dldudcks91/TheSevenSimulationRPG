# ADR-1419 — 능력치 칩은 캐릭터 탭 기본 옵션의 약어 칸과 같은 모양이다

## 결정

능력치 칩(`.tip-chip.attr` — 스킬 설명창 이름 뒤 · 도서관 계산 줄의 능력치 항)을 캐릭터 탭 기본 옵션 줄의 약어 칸(`.cs-a` — 「힘 [STR]」의 [STR])과 같은 모양으로 그린다 — 한 단 작은 글자(`--fs-2xs`) · 흐린 글자 · 어두운 선 한 줄 · 바탕 없음 · 각진 모서리 · 보통 굵기. 자리 · 내용(약어 · 계수 0 도 · 숫자 없음 · 도서관은 `STR 13`)은 그대로다.

## 맥락

같은 날 능력치 칩을 청동 바탕 · 양끝 깎은 표식으로 바꿨다(ADR-1414). 사용자가 「다시 우리게임에 맞는걸로」를 요청했고, 남아 있던 능력치 실루엣 그림(`icons/battle_buffs/elite_<능력치>`)을 쓴 넷(그림 칸 · 그림 + 약어 · 그림 + 이름 · 그림만)을 목업으로 냈다. 사용자는 그림 안을 거르고 능력치 약어를 이미 쓰는 캐릭터 탭의 모양으로 정했다.

## 근거

- **게임 안에 이미 있는 능력치 표기** — 캐릭터 탭 기본 옵션 일곱 줄이 같은 약어를 이 칸으로 찍는다. 같은 약어가 두 화면에서 같은 모양이면 따로 꾸민 장식이 없다
- 거른 안 — **청동 표식**(ADR-1414): 게임에 없는 장식이다 · **능력치 실루엣 그림**: 사용자가 걸렀다
- ⚠ 이 모양은 설명창의 태그 · 종류 칩(흐린 글자 · 어두운 선)과 크기 · 여백만 다르다 — 「다른 칩과 갈려야 한다」(ADR-1414 맥락)는 자리(이름 바로 뒤 vs 이름 아래 줄)가 맡는다. 사용자가 「일단」으로 정했다

## 파급

- CSS — `.tip-chip.attr` 의 값을 `.cs-a` 와 맞춘다 · 1414 가 더한 `--bronze-ink` · `--attr-cut` · 도서관 여백 줄을 걷는다
- 렌더러 · i18n 은 안 바뀐다
