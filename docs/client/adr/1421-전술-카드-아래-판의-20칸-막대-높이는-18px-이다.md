## 결정

편성 탭 파티 전술 카드 아래 판(리더 통솔 · 죄종 일곱)의 20칸 막대 높이를 **18px** 로 한다. 줄 가운데에 서는 것 · 칸 = SVG 사각형 · 칸 사이 틈이 고른 것은 ADR-1416 그대로다.

## 맥락

ADR-1416(2026-11-26)이 줄 높이를 다 쓰던 막대(기준 한 장에서 칸 높이 약 26px)를 12px 로 낮췄다.

## 근거

- 사용자가 12px 는 너무 낮고 18px 정도라고 했다

## 파급

- CSS — `.rs-bd-bar` 높이
