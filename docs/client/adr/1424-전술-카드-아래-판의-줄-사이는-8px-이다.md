# ADR-1424 — 전술 카드 아래 판의 줄 사이는 8px 이다

| **대체됨** | — |

## 결정

편성 탭 파티 전술 카드 아래 판(리더 통솔 · 죄종 일곱)의 줄 사이를 **8px** 로 한다 · 판 위아래 안쪽 여백도 8px. 판이 제 높이만 쓰고 남는 세로를 카드 행이 받는 것 · 막대 높이 20px 는 ADR-1423 그대로다.

## 맥락

ADR-1423(2026-11-26)이 판을 제 높이로 줄이며 줄 사이를 4px 로 붙였다.

## 근거

- 사용자가 4px 는 너무 붙었다고 했다

## 파급

- CSS — `:root:not([data-mobile]) .pt-tactics > .rs-board` 의 `row-gap` · `padding`
