# ADR-1426 — 편성 탭 진형 칸은 위 영웅 띠 카드와 같은 크기다

| | |
|---|---|
| **상태** | 확정 · 2026-11-26 |
| **화면** | [SCREEN_DESIGN §15](../SCREEN_DESIGN.md) 「진형」 |
| **정한 사람** | 사용자 지시 「진형칸의 초상화 크기를 위 영웅들 칸이랑 똑같이 맞춰볼래?」 |
| **대체** | 편성 탭 진형 칸 한 변 = `--fm-slot`(1600×800 한 장 고정 118px — 출정 창 적 구성 칸과 같은 값) |
| **대체됨** | — |

## 결정

편성 탭 진형 보드의 칸(초상 칸 · 빈 칸)은 **같은 화면 위 영웅 띠 카드와 같은 폭 · 같은 높이**다. 테두리(윗변 3px · 나머지 1px)도 같아 안의 초상이 띠 초상과 같은 크기 · 같은 정사각으로 그려진다.

- 띠 카드 폭은 띠 폭을 칸 수로 나눈 몫(flex · 96 ~ 120px)이라 고정값이 아니다 — 편성 탭을 그린 뒤 띠 카드의 폭 · 높이를 재서 진형 칸에 건다(`--fm-slot` · `--fm-cell-h` · `.pt-left` 에만)
- 스킬 열(칸 셋)은 진형 칸 높이를 나눠 갖는다 · 보드 높이 · 진형 축 폭도 칸을 따라 줄어든다 · 뒤 랭크가 내려가는 한 단(`--fm-step`)은 그대로
- 출정 창의 적 구성 칸 · 폰 화면은 안 바뀐다

## 맥락

진형 칸은 `--fm-slot`(118px — 적 구성 칸과 같은 값) 정사각이었다. 1600×800 한 장에서 진형 초상은 약 104 × 103px, 위 띠 초상은 약 96 × 96px 로 진형이 약 9% 컸다. 진형 칸은 테두리 포함 정사각이라 윗변이 굵은 만큼 초상이 세로로 1px 짧았다.

## 근거

- 사용자가 진형 초상을 위 띠 초상과 똑같이 맞추자고 했다 — 같은 영웅이 같은 화면 두 곳에서 다른 크기로 서지 않는다
- **재서 건다** — 띠 카드 폭은 띠 칸 수에 따라 바뀐다. 고정값으로 맞추면 칸 수가 바뀔 때 다시 어긋난다
- 거른 안 — 띠 쪽을 진형 크기로 키우기(띠는 캐릭터 탭 · 출정 창과 같은 공통 카드다 · §5)

## 파급

- JS — `app.js:renderParty`(그린 뒤 띠 카드 `getComputedStyle` 폭 · 높이 → `.pt-left` 의 `--fm-slot` · `--fm-cell-h` · 폰은 안 건다)
- CSS — `.fm-cell` 높이 · `.fm-box` 의 `--fm-sk` · `--fm-board-h` 가 `--fm-cell-h`(없으면 `--fm-slot`)를 읽는다
