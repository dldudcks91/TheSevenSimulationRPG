## 결정

- **덩어리마다 판 하나** — 사용 중인 카드 · 사용한 카드 · 새 카드가 각각 테두리 · 둥근 모서리 · 카드 바탕의 판이다. 편성 탭 전술 행(`.tc-row`)과 같은 모양이다(D2 Min 스킨은 같은 돌 바탕 + 턱). 머리는 판 안 맨 위. 등급 탭은 사용 중인 카드 판과 사용한 카드 판 사이에 그대로
- **사용 중인 카드 = 편성마다 한 열** — 다 열렸을 때의 편성 수만큼(편성 고르개와 같다) 「Party n」 이름 + 그 편성의 이 갈래 칸에 든 카드 한 칸
  - 고른 편성(가방 창이 장착하는 편성)은 이름이 밝다
  - 칸이 비었으면 빈 그림 칸 · 안 열린 편성은 흐린 자물쇠 칸(올리면 그 편성을 여는 진행 문턱 한 줄 — 편성 고르개와 같은 줄)
  - 올리면 카드 툴팁 + 옵션 줄 둘(그 편성 파티로 잰 적용 값) · 고르지 않는다
  - 열 폭 = 아래 격자의 칸 폭 — 세 판의 칸이 같은 세로줄에 선다
- 고른 편성이 나가 있으면 사용 중인 카드 판 아래에 자물쇠 한 줄(그대로)

## 맥락

ADR-1428(2026-11-26)이 가방 창 맨 위에 사용 중인 카드 덩어리를 세웠다 — 고른 편성의 카드 한 장. 덩어리 사이는 가는 선 한 줄이라 경계가 약했다.

## 근거

- 사용자가 덩어리를 기존 UI 에 맞게 구분하고 사용 중인 카드를 편성별로 보이자고 했다
- 같은 갈래 카드가 편성마다 따로 든다 — 다른 편성에 무엇을 끼웠는지 보면서 어느 카드를 끼울지 고른다
- 판 모양은 바로 아래 편성 탭 전술 행과 같아야 같은 화면 부품으로 읽힌다
