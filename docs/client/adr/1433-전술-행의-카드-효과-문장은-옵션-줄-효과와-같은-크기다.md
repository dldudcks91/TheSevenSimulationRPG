# ADR-1433 — 전술 행의 카드 효과 문장은 옵션 줄 효과와 같은 크기다

## 결정

- 편성 탭 전술 행의 카드 효과 문장은 **바로 아래 옵션 줄의 효과 글씨와 같은 크기**다(`.tc-line > .rs-eff` 와 같은 값)
- 색(흐린 글씨) · 자리 · 폭 · 줄바꿈 · 카드가 든 칸만 서는 것은 ADR-1431 그대로

## 맥락

ADR-1431(2026-11-26)이 옵션 줄 위에 카드 효과 한 문장을 세우면서 글씨를 옵션 줄보다 한 단 작게 잡았다.

## 근거

- 사용자가 이 문장이 행의 본체(카드 규칙)인데 덧붙는 옵션 줄보다 작다고 했다
- 같은 행 안에서 본체가 덧붙는 몫보다 작으면 읽는 순서가 뒤집힌다

## 파급

- CSS — `.tc-desc` 글씨 크기
- 세 행이 모두 두 줄 문장인 경우 줄 칸 최소 높이를 다시 재서 한 장(1600×800)에서 판이 안 밀리게 맞춘다
