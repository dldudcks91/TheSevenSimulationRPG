## 사용법

1. 위 단계부터, **선행 칸이 전부 ✅ 인 과제**만 집는다. 같은 단계 안에서는 병렬 가능
2. 착수 전 해당 문서의 mtime 을 보고 다시 읽는다 — 다른 세션이 같은 시간대에 고친다
3. 확정하면 ① GAME_DESIGN §9 에 한 줄 ② §10 에서 삭제 ③ "적는 곳" 문서에 세부 ④ 이 표의 상태를 ✅ 로. 경계(export · rng 순서 · 스키마)가 바뀌면 [INTERFACE.md](../client/INTERFACE.md) 먼저
4. 수치는 전부 CSV 키로 — 이 문서에도 절대 수치를 적지 않는다
