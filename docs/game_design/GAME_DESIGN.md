> 7대 죄악 테마의 **Lootun형 방치 파밍 RPG**.
> **방향성 문서** — 확정된 방향만 적는다. 세부는 각 문서로, 미확정은 §10 으로, 수치는 전부 CSV(SSOT).

## 1. 게임 정의

> **"디아블로식 아이템 게임을, 경영 시뮬레이션처럼 운영한다"**
>
> **좋은 영웅과 좋은 아이템을 얻고, 파티 운영으로 챕터를 진행한다.**

- **수집 대상은 둘 — 영웅과 아이템, 대등하다.** 아이템은 원정에서 **줍고**, 영웅은 선술집에서 **고용한다**
- **행위는 빌드 · 편성 · 배분** — 조작이 아니라 의사결정이 본체
- **목표는 챕터 진행** — 방치형이므로 **성장할 때마다 기능이 하나씩 열린다**. 해금 게이트는 챕터 클리어
- 재료는 **다양한 경로**로 얻고, 그 재료로 **다방면의 아이템 획득·업그레이드**를 한다
- 수치 가드 — **장비 0 이면 능력치도 0**(battle_design.md §8) · **레벨 = 진입 자격 / 장비 = 세기**(§9-4)
- **게임에 끝은 없다** — 챕터 7 뒤 **난이도 티어**를 올려 다시 돌고(티어 ↑ = 더 나은 드롭), 그 뒤 **무한모드**

### 1-1. 동시 원정은 1개다

**1 원정 = 1 팀 = 1 관전.** 전투 창구가 하나여야 관전이 성립한다.

- 로스터 전원을 굴리는 압력은 **비전투(파견·탐험)로 푼다** — 전투를 복제해서 풀지 않는다
- 관전을 죽이는 제안(동시 원정 확대 등)은 이 조항과 먼저 대조한다

### 1-2. 층 배분

| 층 | 문법 | 비중 |
|---|---|---|
| 아이템 · **영웅** · 전투 · 빌드 · 파밍 | 완전 RPG (디아블로 언어) | **본편** |
| 거점 · 파견 | 시뮬레이션 감각 | 지류 (상한 있음) |

- **영웅 고용은 본편이다** — 선술집은 거점 안에 있지만 지류가 아니다. 아이템 드롭의 영웅판
- 비전투 활동은 콘텐츠가 아니라 **파이프** — 파밍 루프에 재료를 공급한다. 유저가 "파견이 본편"이라고 느끼면 잘못된 신호
- 사기·관계·폭주 미탑재 — 방치형 계약("자리 비워도 안전") 준수

## 2. 타겟 유저

> **아이템과 영웅 관리를 좋아하는 유저에게, 다양한 형태의 성장 발판을 제공한다.**

발판이 여럿이라는 것이 이 게임의 약속이다 — 드롭 · 제작 · 강화 · 레벨 · 스킬 · 영웅 고용 · 파견 산출. 한 축이 막혀도 다른 축이 돈다.

### 설계 검증 기준

모든 시스템 결정은 이 5개로 검증한다.

1. **드롭의 유의미함** — 접사 풀 희석 금지
2. **숫자로 읽히는 최적화** — 변경 효과가 수치로 보일 것
3. **병렬 가동** — 모든 영웅이 항상 뭔가를 하고 있을 것
4. **긴 체이스** — 유니크 수집·빌드 완성이라는 장기 목표
5. **순환 구조** — 비전투도 결국 전투 파밍을 가속할 것

## 3. 코어 루프 — 시간축이 활동을 가른다

가르는 것은 유저가 보고 있느냐가 아니라 **게임이 켜져 있느냐**다.

| | **게임 켜짐** | **게임 꺼짐** |
|---|---|---|
| 인원 | 원정 파티 `[balance.csv:party_size_max]`인 | 나머지 (로스터 `[balance.csv:roster_cap]` − 파티) |
| 활동 | **원정 = 전투** (관전 · 자리 비워도 계속) | **파견** — 거점 · 탐험 |
| 산출 | **장비 드롭** | 재료 · 재화 · 해금 |

> **켜 두면 장비가 떨어지고, 꺼 두면 재료가 쌓인다.**

- 원정은 유저가 보는 상황에서 시작한다. 반복 원정을 켜 두면 **게임이 켜져 있는 동안은 자리를 비워도 계속 진행**된다
- **게임이 꺼지면** 진행 중이던 전투(해당 몬스터)까지만 정산하고 런을 마무리한다 — 오프라인에 다음 라운드·다음 런은 돌지 않는다. 리포트는 다음 접속 때
- **전투는 실시간 독점** — 뒤집으면 **전투가 아닌 것은 오프라인에 돈다.** 탐험이 원정 문법(편성 → 출발 → 리포트)을 빌려도 전투가 아니므로 오프라인 쪽이다
- 장비는 원정 독점이 **아니다** — 크래프트로 제작할 수 있다. 다만 파견 산출(재료)은 접속해서 제련소에서 써야 장비가 되므로 파견은 여전히 **본편의 연료**다 (검증 기준 5). 원정 없이 제작이 성립하는지의 가드는 §10

```
게임 켜짐 → 원정 → 장비 드롭 ─┐
                               ├→ 거점: 분해 → 재료 → 제작·강화(낙인) → 더 깊은 원정
게임 꺼짐 → 파견 → 재료·재화 ─┘
```

## 4. 영웅

상세: [hero_design.md](hero_design.md)

- **2층 구조** — 유니크 15명(수작업 · **고유 스킬** 1 · 로스터 1명 제한) / 레어 무한 생성(전부 굴림 · 죄종×직업 35칸 커버리지 전담). 아이템 희귀도 계단의 영웅판
- **획득 창구는 선술집 하나** — 명단(리롤 쿨다운)과 수색(대기 영웅 1명) 둘 다 선술집 안. **수색은 파견이 아니다.** 유니크는 어느 쪽에서도 **지정 불가 · 확률만**
- **직업 7종** — 본편 5(전사/기사/마법사/궁수/사제) + 확장 2(암살자/네크로맨서)
- **능력치 두 층** — 기본 7종(영웅 고유 · 장비 불변) / 전투 24종(장비·스킬 파생). 게이트 없음
- **스킬** [08-27 개정 · 08-28 보강] — **액티브 / 패시브 2층**. 액티브 3 = 고유 / 무기군 / 전직 (「슬롯」 개념 폐기). 마스터리 노드는 **수치 · 반응 · 변형(태그를 바꿀다)** 셋. 마스터리 2(직업 · 죄종) — 죄종은 **T1 공통 3종(쏠림 방지) + T2 정체성(레벨10) + T3 반응형**(skill_design.md §3-1~§3-3) · **롤백 무료**
- **스킬 태그 13종** [08-28] — 4 대분류(피해 방식 / 버프 / 디버프 / 기타). 전술카드 조건 · 변형 노드 · 화면이 이걸 읽는다 (skill_design.md §11)
- **전직은 직업마다 3갈래** [08-27 · 갈래 확정 08-28 · **1택 확정 08-28**] — 셋 중 하나를 고르고, 고른 전직이 액티브 **3개**를 준다. **그중 1개를 찍고, 찍은 그 스킬만 전용 트리가 열린다.** 본편 5 × 3 = 15 전직 · 액티브 45 · 화면에 오르는 것 1. 갈래를 가르는 축은 **직업마다 다르다**
- **액티브를 주는 층은 전직뿐** [08-28] — 죄종·직업 두 마스터리는 **전부 패시브**다. 액티브 3칸은 **영웅 고유 / 무기군 / 전직**이고, 그중 **트리를 갖는 것은 전직 칸 하나**다
  - 마법사 = 원소 3종 · 전사 = 무엇으로 싸우는가 · 기사 = 지킨 것을 어떻게 쓰는가 · 궁수 = 타격의 리듬 · **사제 = 죄를 어떻게 대하는가**(사제 · 검은사제 · 몽크) — **본편 5직업 15갈래 전부 확정** [08-30] (skill_design.md §4-1)

## 5. 아이템

상세: [item_design.md](item_design.md)

- 슬롯 **9개 / 부위 8종**(반지 ×2) · 희귀도 4단계(매직→레어→크래프트→유니크) · 죄종 접사 매트릭스 · 무기군 Implicit · 낙인 크래프팅
- **세트효과 폐기 → 전술카드 이관** [08-26] — 접사가 자동으로 세트포인트가 되는 구조를 닫았다. 죄종 접사를 **세는 것은 전술카드**다 ([tactic_card_design.md](tactic_card_design.md))
- **자원** [08-26] — 골드(강화) · 광석(크래프트 제작) · 낙인(죄종 지정 · 전술카드) · 몬스터 카드(도감). 크래프트는 드롭 등급이 아니라 **제작의 결과** — 옵션을 고정해서 만든다 (item_design.md §5)
- **드롭 파이프라인** [08-27] — **처치당 최대 1개.** 레벨은 **대역(ilvl)** 만, 희귀도는 **몬스터 등급 + 매직찬스**가 정한다. 둘을 떼어 놔야 저레벨 스테이지가 두 겹으로 죽지 않는다. **지역 죄종 드롭 편향 폐기** (item_design.md §1)
- **아이템 가치 = 지표 둘** [08-27] — **ilvl**(대역) + **점수**(옵션별 구간 점수의 합, 절대값). 구간 폭이 곧 옵션의 가치 계수다. **획득 자리엔 점수 · 착용 자리엔 전투 수치 델타** (item_design.md §6)
- 변경: 코스트 폐지 · 유틸 접사 축 신설 · 쿨감 옵션 신설 · 기본 능력치 접사 폐지

## 6. 죄종 — 하나의 축, 네 개의 일

| 층 | 죄종의 역할 |
|---|---|
| 스킬 | **죄종 마스터리** — T1 공통(쏠림 방지) · T2 부터 색깔 · T3 반응형(물리 계열 진행 중) (skill_design.md §3-1~§3-3) |

| 파견 | 죄종별 비전투 적성 |

> 죄종이 붙는 자리는 다섯이다 — 챕터 · 상태이상 · 접사 · 영웅(마스터리) · 파견. 다섯의 관계를 정하는 `sin_mapping.md` 가 첫 SSOT 과제.

## 7. 거점 · 파견

상세: [base_expedition_design.md](base_expedition_design.md)

- **파견처 다섯** — 선술집 · 상단 · 연구소 · 제련소 · 광산(⚠ 제안). **짓거나 올리는 개념은 없다**
- **손잡이는 둘** — 파견처의 **가짓수 = 챕터 해금** / 파견처의 **세기 = 배치된 영웅**
- **능력치 ↔ 파견처 1:1** — 매력=선술집·상단(유일한 예외, 둘) / 지능=연구소 / 운=제련소 / 힘=광산(⚠ 제안)
- **탐험** — 파티 단위 "제2의 원정". 1인 배치가 아니라 파티를 꾸려 보낸다
- 상점 없음 · 공방 없음(제작은 제련소) · 합성은 스킬 카드 개념(후속)
- **방치형 계약 (불변)** — ①자리 비워도 로스터 파괴 없음 ②오프라인 진행 지원(파견·탐험·치료 타이머) ③모든 사건은 리포트로, 실시간 개입 요구 금지

| **광전사의 역할 분리** | 태세 셋이 전부 자기 강화라 「역할로 갈려야 한다」를 15 갈래 중 유일하게 어긴다. 셋을 다 주거나 하나를 딜로 바꾼다 (skill_design.md §10-2 · §10-6) |
| **고정 피해 채널 · 스턴** | 광전사 「투기 태세」와 바바리안 「지진」이 요구한다. 고정 피해는 무기 공격력에 안 곱해져 후반에 무의미해지고, 스턴은 **몬스터가 영웅에게 거는가**가 방치형 계약과 직결된다 (skill_design.md §7 · battle_design.md §9-7) |
| **몬스터에 회복을 줄 것인가** | 화염의 「치유 감소」가 대상을 갖는지가 여기 달렸다. 주면 화염이 **타겟팅 없이 몬스터 힐러를 무력화**하는 수단이 되어 전술카드를 안 열고도 풀린다. 안 주면 치유 감소는 반쪽 축 (battle_design.md §2-2) |
| **도트(독 · 화상) 도입 여부** | 독은 궁수(수렵꾼)로 확정됐지만(08-28) **도트 규칙이 없으면 그 갈래를 못 짠다.** 도트는 매 틱마다 피해 이벤트라 관전 타임라인과 rng 소비 수열이 늘어난다 (skill_design.md §7 · INTERFACE.md rng 순서 계약) |
| **전기의 분산을 몬스터에도 줄 것인가** | 몬스터의 분산은 플레이어가 고른 게 아니라 당하는 것이라 운에 의한 전멸을 만든다 — 회피를 폐지한 이유와 같은 구조. 후보 ①영웅만 ②폭을 작게 ③분산을 피해량이 아니라 **대상 수**에 (battle_design.md §2-2) |
| **화상(도트) 도입 여부** | 파이어월이 광역 도트다. 결빙 하나만 열기로 했는데 둘이 된다. 도트는 매 틱 피해 이벤트라 관전 타임라인과 rng 소비 수열이 늘어난다 |
| **전술카드 세부** | 도입·이관만 확정. 슬롯 수·소유자(리더) · 조건/효과 언어 · 획득 경로 · 카드 테이블 전부 미정 — tactic_card_design.md §4 |
| **"카드" 어휘 충돌** | 전술카드 · 도감 몬스터 카드 · 스킬 카드 합성 셋이 같은 단어를 쓴다 |
| **리더 도입 여부** | 전술카드 슬롯의 소유자 후보. 도입 시 통솔의 자리와 한 묶음 |
| 스킬 카드 정의 · 합성 | skill_design.md §5 후속 |
| **수색 조건 지정** | 지금은 무지정 전용. 후보 — 완료 스테이지를 골라 그 구역 수색 |
| **수색 판정에 장비·스킬이 기여하는가** | 보류. `attr_equip_bonus = 0` 불변식과의 관계를 함께 정한다 |
| **드롭 부위 편향의 단위** | 몬스터의 `monster_base`(종족) 인가 `role`(전투 역할) 인가. `role` 은 이미 방어 감쇠를 정하고 있어 겸직 주의 (item_design.md §1) |
| **매직찬스가 별개 스탯인가** | 드랍률과 나누면 유틸 접사가 3종이 된다. §5 는 유틸 축을 둘로 적어 뒀고 D2 는 MF 하나가 개수·등급을 함께 민다. 접사 풀 희석(검증 기준 1) 직결 |
| **타겟 파밍 축** | 죄종 편향 폐기(08-27)로 **부위 하나만 남았다.** 스테이지 선택의 근거가 얇아 "갈 수 있는 가장 높은 곳"으로 수렴할 위험 — 무엇으로 채울지 미정 |
| **접사 정의를 CSV 로 내리기** | `ui/mock.js AFFIX_DEFS` 가 이식 차단 항목(INTERFACE.md §7). **아이템 점수의 구간 폭 컬럼이 여기 붙어야 해서** 선행 조건이 됐다 |
| **자동 분해의 선** | 「저품질 자동 분해」는 이름만 있다. ilvl 하한인지 점수 하한인지, 죄종 태그를 어떻게 보호할지 미작성 (item_design.md §6-4) |
| **`drop_roll` 컬럼의 처리** | 처치당 최대 1개 확정으로 `spawn_grade.csv:drop_roll` 이 할 일을 잃었다. 확률로 옮기든 폐기하든 정리 필요 |

|---|---|
| 성장곡선 숫자 | 50 무릎 이후 곡선 · 몬스터 XP · 레벨당 시간 — **다른 수치 확정 뒤** 캘리브레이션 |

| 보스 행의 HP 이중 elevation | 보스가 일반몹 평균의 1.70배 HP 를 들고 `spawn_grade.hp_mult` 를 또 받는다 |

| **영웅 리롤 루프** | 레어가 무한 생성인데 리롤에 목표가 없다. 성립 조건 셋은 hero_design.md §4-1-1 |

| 기사 주력 축 | 건강 ⚠ |

| 사이즈 특효 축의 존치 | 사이즈는 대상마다 갈려 인과를 읽기 어렵다. 퇴역 검토 |
| 매혹(charm) 재정의 | `status_effect.csv` 정의가 "명중률 대폭 감소"인데 명중 축이 사라졌다 |
