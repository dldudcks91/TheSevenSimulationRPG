# TheSevenSimulationRPG — 게임 디자인

> 7대 죄악 테마의 **Lootun형 방치 파밍 RPG**. 확정 사항만 기재 — 수치는 전부 CSV(SSOT).

---

## 1. 게임 정의

> **"디아블로식 아이템 게임을, 경영 시뮬레이션처럼 운영한다"**

파티를 편성해 자동전투 원정을 보내고, 루팅 리포트를 확인하고, 빌드(스킬/장비)를 재구성한다.
그래픽 최소화 — 텍스트/UI 중심. 조작이 아니라 **빌드·편성·배분 의사결정**이 본체. **장비가 주인공** (A안).

- **장르**: 방치형 파밍 RPG + 로스터 운영
- **참고작**: Lootun(게임 형태·거점) · Diablo 2(아이템 철학·스킬트리) · Melvor Idle(방치 숙련)
- **계보**: TheSevenRPG(아이템·몬스터·스토리 계승) + TheSevenSimulation(영웅 프레임 계승)

| 층 | 문법 | 비중 |
|---|---|---|
| 아이템 · 전투 · 빌드 · 파밍 | 완전 RPG (디아블로 언어) | **본편** |
| 거점 · 파견 | 시뮬레이션 감각 | 지류 (상한 있음) |

- 비전투 활동은 콘텐츠가 아니라 **파이프** — 파밍 루프에 재료를 공급한다
- 유저가 "파견이 본편"이라고 느끼면 잘못된 신호
- 사기·관계·폭주 미탑재 — 방치형 계약("자리 비워도 안전") 준수

## 2. 타겟 유저 니즈 (설계 검증 기준)

모든 시스템 결정은 이 5개로 검증한다.

1. **드롭의 유의미함** — 접사 풀 희석 금지
2. **숫자로 읽히는 최적화** — 변경 효과가 수치로 보일 것
3. **병렬 가동** — 모든 영웅이 항상 뭔가를 하고 있을 것
4. **긴 체이스** — 유니크 수집·빌드 완성이라는 장기 목표 (세트 완성은 세트효과 보류 중 — item_design.md §4)
5. **순환 구조** — 비전투도 결국 전투 파밍을 가속할 것

## 3. 코어 루프 — 접속 층과 방치 층

| | **접속 중** | **자리 비움** |
|---|---|---|
| 인원 | 파티 `[balance.csv:party_size_max]`인 | 나머지 (로스터 `[balance.csv:roster_cap]` − 파티) |
| 활동 | **원정 = 전투** (관전) | **파견** (거점 시설) |
| 산출 | **장비 드롭** | 재료 · 재화 · 해금 |

> **보고 있을 때는 드롭이 떨어지고, 안 볼 때는 재료가 쌓인다.**

- 원정은 유저가 보는 상황에서 시작한다. **[2026-08-25 확정]** 반복 원정을 켜 두면 **게임이 켜져 있는 동안은 자리를 비워도 계속 진행** · **게임이 꺼지면 진행 중이던 전투(해당 몬스터)까지만 정산하고 런을 마무리** — 오프라인에 다음 라운드·다음 런은 돌지 않는다. 리포트는 다음 접속 때
- **장비 드롭은 원정 독점.** 파견 산출(재료)은 접속해서 거점에서 써야 장비가 되므로, 파견은 본편을 대체하지 않고 **본편의 연료**가 된다 (니즈 5)

```
접속 → 원정 → 장비 드롭 ─┐
                          ├→ 거점: 분해 → 재료 → 제작·강화(낙인) → 더 깊은 원정
방치 → 파견 → 재료·재화 ─┘
```

## 4. 영웅 — 요약

상세: [hero_design.md](hero_design.md)

- **2층 구조**: 유니크 영웅 15명(수작업·고유 패시브 1·로스터 1명 제한) / 레어 영웅 무한 생성(전부 굴림·죄종×직업 35칸 커버리지 전담). 아이템 희귀도 계단의 영웅판
- **유니크 획득 = 선술집 희귀 등장** — 매력 영웅 배치로 등장 확률·품질 상승
- **직업 7종**: 본편 5(전사/기사/마법사/궁수/사제) + 확장 2(암살자/네크로맨서)
- **능력치 두 층**: 기본 능력치 7종(영웅 고유, 장비 불변) / 전투 능력치 24종(장비·스킬 파생). 게이트 없음
- **스킬**: 독립 트리 3탭(죄종/마스터리/전직) + 액티브 슬롯 3 — **출처 고정**(죄종 / 전직 / 무기군). 무기군 스킬은 무기군에 붙고 개체에 붙지 않는다

## 6. 죄종 — 하나의 축, 네 개의 일

7대 죄악이 게임 전 층을 관통하는 단일 축. 축은 하나, 일은 넷.

| 층 | 죄종의 역할 |
|---|---|
| 스킬 | 탭1 죄종 트리 (고유 메커니즘) |
| 아이템 | 접사 카테고리 · 낙인 · 지역 드롭 편향 (세트 — 보류) |
| 영웅 | 정체성 + 장비 궁합 (메인 죄종 +1 은 세트효과와 함께 보류) |
| 파견 | 죄종별 비전투 적성 |

> 통일 매핑 테이블 `sin_mapping.md` 가 첫 SSOT 과제 — 두 원작의 매핑이 서로 다르다.

## 7. 거점 · 파견 — 요약

상세: [base_expedition_design.md](base_expedition_design.md)

- **시설이 곧 파견지** — 시설은 플레이어가 굴리고, 배치된 영웅이 효율을 결정한다. 매력=선술집·상단(교역 — 매력만 둘) / 지능=연구소 / 감각=제련소(공방 없음) / 힘=광산(⚠)
- **탐험** — 파티 단위 "제2의 원정". 시설이 아니라 원정 문법을 비전투에서 반복. 민첩·건강·통솔의 파견 역할 후보
- 상점 없음 · 합성은 스킬 카드 개념(후속) — 시설 아님
- **방치형 계약 (불변)**: ①자리 비워도 로스터 파괴 없음 ②오프라인 진행 지원 ③모든 사건은 리포트로 — 실시간 개입 요구 금지
