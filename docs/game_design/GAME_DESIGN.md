# TheSevenSimulationRPG — 게임 디자인

> 7대 죄악 테마의 **Lootun형 방치 파밍 RPG**.
> **방향성 문서** — 확정된 방향만 적는다. 세부는 각 문서로, 미확정은 §10 으로, 수치는 전부 CSV(SSOT).

## 1. 게임 정의

> **"디아블로식 아이템 게임을, 경영 시뮬레이션처럼 운영한다"**
>
> **좋은 영웅과 좋은 아이템을 얻고, 파티 운영으로 챕터를 진행한다.**

- **수집 대상은 둘 — 영웅과 아이템, 대등하다.** 아이템은 원정에서 **줍고**, 영웅은 선술집에서 **고용한다**
- **행위는 빌드 · 편성 · 배분** — 조작이 아니라 의사결정이 본체
- **목표는 챕터 진행** — 방치형이므로 **성장할 때마다 기능이 하나씩 열린다**. 해금 게이트는 챕터 클리어
- 재료는 **다양한 경로**로 얻고, 그 재료로 **다방면의 아이템 획득·업그레이드**를 한다
- 수치 가드 — **장비 0 이면 능력치도 0**(battle_design.md §8) · **레벨 = 진입 자격 / 장비 = 세기**(§9-4)
- **게임에 끝은 없다** — 챕터 7 뒤 **난이도 티어**를 올려 다시 돌고(티어 ↑ = 더 나은 드롭), 그 뒤 **무한모드**

### 1-1. 동시 원정은 1개다

**1 원정 = 1 팀 = 1 관전.** 전투 창구가 하나여야 관전이 성립한다.

- 로스터 전원을 굴리는 압력은 **비전투(파견·탐험)로 푼다** — 전투를 복제해서 풀지 않는다
- 관전을 죽이는 제안(동시 원정 확대 등)은 이 조항과 먼저 대조한다

### 1-2. 층 배분

| 층 | 문법 | 비중 |
|---|---|---|
| 아이템 · **영웅** · 전투 · 빌드 · 파밍 | 완전 RPG (디아블로 언어) | **본편** |
| 거점 · 파견 | 시뮬레이션 감각 | 지류 (상한 있음) |

- **영웅 고용은 본편이다** — 선술집은 거점 안에 있지만 지류가 아니다. 아이템 드롭의 영웅판
- 비전투 활동은 콘텐츠가 아니라 **파이프** — 파밍 루프에 재료를 공급한다. 유저가 "파견이 본편"이라고 느끼면 잘못된 신호
- 사기·관계·폭주 미탑재 — 방치형 계약("자리 비워도 안전") 준수
- **계보**: TheSevenRPG(아이템·몬스터·스토리 계승) + TheSevenSimulation(영웅 프레임 계승)

## 2. 타겟 유저

> **아이템과 영웅 관리를 좋아하는 유저에게, 다양한 형태의 성장 발판을 제공한다.**

발판이 여럿이라는 것이 이 게임의 약속이다 — 드롭 · 제작 · 강화 · 레벨 · 스킬 · 영웅 고용 · 파견 산출. 한 축이 막혀도 다른 축이 돈다.

### 설계 검증 기준

모든 시스템 결정은 이 5개로 검증한다.

1. **드롭의 유의미함** — 접사 풀 희석 금지
2. **숫자로 읽히는 최적화** — 변경 효과가 수치로 보일 것
3. **병렬 가동** — 모든 영웅이 항상 뭔가를 하고 있을 것
4. **긴 체이스** — 유니크 수집·빌드 완성이라는 장기 목표
5. **순환 구조** — 비전투도 결국 전투 파밍을 가속할 것

## 3. 코어 루프 — 시간축이 활동을 가른다

가르는 것은 유저가 보고 있느냐가 아니라 **게임이 켜져 있느냐**다.

| | **게임 켜짐** | **게임 꺼짐** |
|---|---|---|
| 인원 | 원정 파티 `[balance.csv:party_size_max]`인 | 나머지 (로스터 `[balance.csv:roster_cap]` − 파티) |
| 활동 | **원정 = 전투** (관전 · 자리 비워도 계속) | **파견** — 거점 · 탐험 |
| 산출 | **장비 드롭** | 재료 · 재화 · 해금 |

> **켜 두면 장비가 떨어지고, 꺼 두면 재료가 쌓인다.**

- 원정은 유저가 보는 상황에서 시작한다. 반복 원정을 켜 두면 **게임이 켜져 있는 동안은 자리를 비워도 계속 진행**된다
- **게임이 꺼지면** 진행 중이던 전투(해당 몬스터)까지만 정산하고 런을 마무리한다 — 오프라인에 다음 라운드·다음 런은 돌지 않는다. 리포트는 다음 접속 때
- **전투는 실시간 독점** — 뒤집으면 **전투가 아닌 것은 오프라인에 돈다.** 탐험이 원정 문법(편성 → 출발 → 리포트)을 빌려도 전투가 아니므로 오프라인 쪽이다
- 장비는 원정 독점이 **아니다** — 크래프트로 제작할 수 있다. 다만 파견 산출(재료)은 접속해서 제련소에서 써야 장비가 되므로 파견은 여전히 **본편의 연료**다 (검증 기준 5). 원정 없이 제작이 성립하는지의 가드는 §10

```
게임 켜짐 → 원정 → 장비 드롭 ─┐
                               ├→ 거점: 분해 → 재료 → 제작·강화(낙인) → 더 깊은 원정
게임 꺼짐 → 파견 → 재료·재화 ─┘
```

## 4. 영웅

상세: [hero_design.md](hero_design.md)

- **2층 구조** — 유니크 15명(수작업 · **고유 스킬** 1 · 로스터 1명 제한) / 레어 무한 생성(전부 굴림 · 죄종×직업 35칸 커버리지 전담). 아이템 희귀도 계단의 영웅판
- **획득 창구는 선술집 하나** — 명단(리롤 쿨다운)과 수색(대기 영웅 1명) 둘 다 선술집 안. **수색은 파견이 아니다.** 유니크는 어느 쪽에서도 **지정 불가 · 확률만**
- **직업 7종** — 본편 5(전사/기사/마법사/궁수/사제) + 확장 2(암살자/네크로맨서)
- **능력치 두 층** — 기본 7종(영웅 고유 · 장비 불변) / 전투 24종(장비·스킬 파생). 게이트 없음
- **스킬** [08-26 전면 개정] — **마스터리 2**(직업 = 내 숫자 / 죄종 = 그 숫자가 닿는 방식) + **전직 특화**(전직이 준 액티브 3개 각각이 트리의 뿌리). **액티브 3 = 고유 / 무기군 / 전직** — 「슬롯」 개념 폐기 · **롤백 무료**

## 7. 거점 · 파견

상세: [base_expedition_design.md](base_expedition_design.md)

- **파견처 다섯** — 선술집 · 상단 · 연구소 · 제련소 · 광산(⚠ 제안). **짓거나 올리는 개념은 없다**
- **손잡이는 둘** — 파견처의 **가짓수 = 챕터 해금** / 파견처의 **세기 = 배치된 영웅**
- **능력치 ↔ 파견처 1:1** — 매력=선술집·상단(유일한 예외, 둘) / 지능=연구소 / 운=제련소 / 힘=광산(⚠ 제안)
- **탐험** — 파티 단위 "제2의 원정". 1인 배치가 아니라 파티를 꾸려 보낸다
- 상점 없음 · 공방 없음(제작은 제련소) · 합성은 스킬 카드 개념(후속)
- **방치형 계약 (불변)** — ①자리 비워도 로스터 파괴 없음 ②오프라인 진행 지원(파견·탐험·치료 타이머) ③모든 사건은 리포트로, 실시간 개입 요구 금지

### 큰 틀

| 과제 | 상태 |
|---|---|

| **오만 마스터리의 축** | 죄종 7 중 유일한 공백. 후보 ①버프 지속·강화 ②`fhr`. 세트효과 시절에도 비어 있던 **알려진 구조적 공백** — skill_design.md §7 |
| **무기 숙련의 귀속** | 직업 마스터리 vs 무기군 트리. 무기군 귀속이면 사제·마법사 중복이 사라지지만 직업 마스터리 탭이 소멸한다 — skill_design.md §7 |
| **기능 해금 사다리** | 게이트는 챕터 클리어로 확정. 무엇을 여는가 · 첫 파견처 시점 · 반복 원정 잠금 여부 |
| **데모 범위** | 기준은 컨셉 한 바퀴(루프 + 해금 1회 + 껐다 켜기 1회)가 들어가는 최소 조각 |
| **무한모드의 형태** | 티어가 끝없이 오르는 것이 곧 무한인가 / 유한 티어 뒤 별도 무한 던전인가. 단순화 원칙은 전자 |
| **무한모드의 레벨 축** | 몬스터 레벨이 무한히 오르면 "레벨 = 자격"이 깨진다. 후보: 레벨 고정 · HP/공격력만 스케일 |
| **레이드** | **예정 — 개발 미정.** 원정의 **상위 호환**으로 별개 운영. 5인 구상 · 해금 시점 미정 |
| 유니크의 자리 | 유니크는 챕터·티어에, 무한모드는 굴림(레어·크래프트)만 — 후보 |
| **XP 출처** | 전투만인가 파견도 주나. 신규 영웅 캐치업(티어 3 에서 얻은 레벨 1 유니크)과 맞물린다 |
| 동시 원정 1 의 영구 여부 | §1-1 의 강도를 정한다 |

### 시스템

| 과제 | 상태 |
|---|---|
| 진형 · 타겟팅 | 미작성. 무기군 Implicit 은 이것이 확정될 때까지 보류 |
| 신규 무기군 베이스 데이터 | 구조는 `weapon_group.csv` 발행. 베이스 · Implicit 수치는 미작성 |
| **크래프트 가드** | 원정 없이 제작이 성립하는가. **지금 입력은 광석(파견)+낙인(보스)뿐이라 성립해 버린다.** 몬스터별 재료를 채택하면 그것이 원정 쪽 입력이 되어 구조에서 풀린다 (item_design.md §5-3) |
| **몬스터별 재료** | 만들지 여부부터 미정. 단위 후보는 **몬스터 베이스**(이름 단위는 재료 창고에서 니즈 1 재발). 채택하면 **몬스터 카드와 통합할지**가 딸려온다 (item_design.md §5-3) |
| **가루의 정체** | 정의 없이 처치·분해 두 경로로 쌓이는데 소모처가 0 이다. 몬스터 재료 결정에 물려 있다 — 채택하면 분해 전용으로 축소 |
| **지정재가 두 일을 겸한다** | 낙인이 죄종 지정과 옵션 고정을 함께 맡으면 "통제권이 오를수록 비용이 오른다"는 희귀도 계단이 한 칸에서 접힌다. 지정재를 둘로 나눌지 — 전술카드 쪽과 함께 본다 |
| **해고 규칙** | 반환물 유무 — 고용→해고 루프로 재료를 짜는 구멍 주의 |
| **골드의 싱크** | 골드가 갈 곳은 **강화**(08-26 자원 확정) + **고용** 둘. 상점 없음 · 건설비 폐지(08-26)로 더 늘지 않는데 충분한가. 후보: 리롤 비용 · 재고용 · 교역 |
| **파견 종류 어휘** | 탐험 · 채집 · 여행 — 각각의 정체와 구분을 한 표로. **수색은 제외**(선술집 하위 기능) |
| 탐험 상세 | 인원 · 산출 · 판정 (base_expedition_design.md §3-1) |
| 광산 / 힘 | 채광이 들어간다는 것만 확정. 힘 배정 · 파견처 이름 · 산출은 제안 |
| 민첩 · 건강 · 통솔의 파견 역할 | 후보: 탐험 판정 |
| **전술카드 세부** | 도입·이관만 확정. 슬롯 수·소유자(리더) · 조건/효과 언어 · 획득 경로 · 카드 테이블 전부 미정 — tactic_card_design.md §4 |
| **"카드" 어휘 충돌** | 전술카드 · 도감 몬스터 카드 · 스킬 카드 합성 셋이 같은 단어를 쓴다 |
| **리더 도입 여부** | 전술카드 슬롯의 소유자 후보. 도입 시 통솔의 자리와 한 묶음 |
| 스킬 카드 정의 · 합성 | skill_design.md §5 후속 |
| **수색 조건 지정** | 지금은 무지정 전용. 후보 — 완료 스테이지를 골라 그 구역 수색 |
