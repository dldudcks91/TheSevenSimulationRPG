## 1. 구조 [초안 2026-11-13]

| 줄 | 고르는 법 | 5랭크를 다 찍으면 |
|---|---|---|
| 전직 스킬 | 전직 레벨 `[balance.csv:advance_unlock_level]` 에 **전직 포인트**로 갈래의 셋 중 하나 | — |
| 공통 줄 | 가로 셋 · 합 5 · 자유 분배(3/1/1 · 5/0/0 …) — 갈래 전체(내 다른 스킬 포함)에 닿는 칸 | 그 칸 효과 두 배 |
| 스킬 줄 | **크기**(옛 스킬 레벨 자리) · **변형 1** · **변형 2** — 합 5 · 자유 분배 | **칸마다 다른 덤**(모양이 바뀐다) |
| 순서 | T4 · 전직 줄 모두 열려 있고 공용 포인트(포인트 = 레벨)로 알아서 찍는다 | — |

- 공통 줄 칸 순서 — **1 · 2 = 단순한 수치, 3 = 갈래 고유 효과**
- 변형을 찍으면 스킬은 크기 1랭크에 머문다 — 변형 하나가 「크기 몇 랭크 몫」과 맞먹게 값을 잡는다(결투 하네스로 셋이 골라지는 비율을 잰다)
- 데미지를 안 주는 스킬의 「크기」는 그 스킬의 크기다 — 보호막 수치 · 최대 HP 증가량 · 쿨타임 감소 · 반사 % 등
- **레벨(크기)은 효과 크기를 올린다 · 지속 시간을 올리지 않는다** — 자동 · 창 스킬이 쿨을 덮어 늘 켜지는 것을 막는다(§2-3 규칙 ③ 과 같은 이유) · 예외 — 히드라 크기 = 지속(사용자 「그대로」)

**같이** — 전직 포인트로 메인 하나 · 공통 줄 + 스킬 줄 두 줄 · 가로 셋 합 5 자유 분배(사용자 「3/1/1로 찍어도되고 대신에 5레벨에 더 좋아지게」) · 스킬 줄 첫 칸 = 크기(「첫꼬리는 무조건 데미지 올리는걸로」) · 스킬 줄 5랭크 덤은 칸마다 다르게(「스킬마다 다르게 줘도될거같긴해」) · 다 열고 순서 자유(「그냥 다 열리고 알아서 찍게」) · 공통 줄 1 · 2 = 수치 · 3 = 고유(순서 교체 지시)
**혼자** — 공통 줄 5랭크 덤 = 「효과 두 배」 한 규칙 · 「레벨은 지속을 올리지 않는다」를 전직 전체에 건 것

## 2. 전투 규칙 — 이 트리가 기대는 것 [초안 2026-11-13]

| 규칙 | 내용 |
|---|---|
| 냉기 = 결빙 | **냉기 피해 스킬은 전부 결빙을 건다** — battle_design §2-5 「원소가 같아도 저절로 붙지 않는다」의 냉기 예외 · 영웅 · 몬스터 같은 규칙 |
| 결빙 겹침 | 걸린 것마다 제 시간이 흐르고 **가장 센 하나만** 적용(화상 · 중독과 같은 규칙) — battle_design §2-4 「결빙은 하나 · 시간만 새로」 대체 |
| 스턴 | **한 번 시전에 같은 대상에게 한 번** — 다단히트(첫 방 ~ 마지막 방) · 구름(깔린 동안) · 늘 켜진 타격(떨어지는 한 번 · 「한 번 더」 포함) |
| 화상 | **받는 회복 감소만 · 고정 값** — 받는 피해 증가는 빠진다 |
| 이그나이트 | 창 동안 내 화염 스킬이 화상을 건다 + **화상 걸린 적에게 주는 데미지 증가**(레벨마다 오른다) |
| 원소 역할 | 화염 = 화력 + 회복 막기 · 냉기 = 제어 · 번개 = 운에 기대는 딜(터짐) · 물리 = 경직 — 다른 원소의 몫(공속 감소 = 냉기 등)을 전직 칸에 넣지 않는다 |

**같이** — 넷 다(사용자 「모든 아이스스킬은 결빙을걸어」 · 「가장센하나만 적용으로수정」 · 「규칙넣어봐」 · 「화상은 받는회복감소로 하자」 · 「회복감소는 50%로 고정」 · 이그나이트 「10%에서부터 +1%씩」) · 번개 스턴은 낮은 확률로 남긴다(「스턴이 저기에서도 나오면 좋지 뭐」)
**혼자** — 원소 역할 한 줄 정리(사용자가 「극명했으면」을 말했고 Claude 가 문장으로 묶음)
