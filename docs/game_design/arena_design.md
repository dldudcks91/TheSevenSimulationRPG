# 결투장 설계

> 상위: [GAME_DESIGN.md](GAME_DESIGN.md) §8 · §9 · SSOT: **미발행** (결투장 전용 키 없음 — 적법성 검사는 기존 CSV 의 범위를 읽는다)
> 수치는 전부 CSV — 본 문서에 절대값을 기재하지 않는다

## 0. 확정 [확정 2026-10-03 · 골격만]

- **본편은 오프라인으로 낸다** — 세이브는 로컬, 진행은 접속 없이 돈다 (Steam 판매형)
- **결투장만 온라인이다** — 내 팀 스냅샷을 올리고, **남이 올린 스냅샷(고스트)과 싸운다.** 상대는 그 자리에 없다 · 전투는 원정과 같은 자동전투
- **곁가지 콘텐츠다** — §1 게임 정의 · 타겟 니즈(GAME_DESIGN §2)는 안 바뀐다
- **결투장 보상은 PvE 힘으로 흐르지 않는다** — 칭호 · 꾸밈만

세부(서버 · 매칭 · 보상 목록 · 인증 리그)는 §6 → GAME_DESIGN §10 「결투장」.

## 1. 왜 본편을 오프라인으로 두나

- **출시 구조가 판매형이다** — Steam · 1~5장 · DLC(story_chapter_design.md §2). 싱글 콘텐츠의 상시 접속은 리뷰 리스크 · 서버 운영 부담
- **방치형 계약과 방향이 같다** — 기획은 접속 압박을 지운다(GAME_DESIGN §3-1 · base_expedition_design.md §4). PvP 메인의 동력(시즌 · 순위 하락)은 정반대
- **PvP 밸런스는 PvE 다양성을 깎는다** — 최종목표가 「다양한 스킬트리와 파티 조합」이다(§1)
- 검토한 대안 — 상시 온라인(D3 · D4식) · 오프라인/온라인 캐릭터 분리(D2 · Last Epoch식). 둘 다 서버 비용이 같고, 분리는 진행 이전 불가 · 두 갈래 유지가 붙는다

## 2. 치팅 — 없애지 않고 묶는다

본편이 오프라인이라 세이브는 조작할 수 있다. 그래서 **업로드 시 적법성 검사**로 거른다 — 범위 밖이면 업로드를 거부한다.

- 접사 수치가 CSV 범위 안인가 (`affix.csv` 외 아이템 테이블)
- 아이템 레벨 ≤ 도달한 난이도 · 챕터
- 영웅 레벨 ≤ `[balance.csv:hero_level_cap]`
- 스킬 · 마스터리 포인트 합 ≤ 레벨이 주는 예산
- 착용 요구를 만족하는가

**상한 논리** — 성장 원칙(§1 — 수직 유한 · 무한 수직 스케일링 금지) 덕에 치터가 올릴 수 있는 최강 팀은 **합법 만렙 + 최상옵 장비**에서 멈춘다. 오래 한 정직한 유저도 닿는 자리다. 치팅으로 얻는 것은 「불가능한 힘」이 아니라 **「파밍 생략」**이다.

검사기는 `game_logic/` 의 **순수 함수** — CSV 만 읽는다. 클라이언트(업로드 전 경고)와 서버(최종 판정)가 같은 코드를 쓴다.

## 3. 남는 피해를 줄이는 장치

| 장치 | 효과 |
|---|---|
| **전력 구간 매칭** — 팀 점수가 비슷한 고스트와만 | 치터는 최상위 구간에 모이고, 일반 유저는 거의 안 마주친다 |
| **보상 = 칭호 · 꾸밈만** | 조작이 본편 경제로 안 번진다 |
| **순위표는 가볍게** — 구간 리그 · 개인 기록 | 전체 1위 경쟁을 앞세우지 않아 오염이 덜 아프다 |

## 4. 나중에 — 인증 리그 [초안 2026-10-03]

최상위 순위표의 신뢰가 필요해질 때만 얹는다. 세이브는 여전히 로컬이다.

1. 온라인 접속 중 원정 전투의 시드를 **서버가 발급**한다 — 발급하는 순간 서버 카운터를 소모(결과를 숨기고 다시 받기 차단) · 발급 속도는 실제 전투 시간으로 제한
2. 클라이언트는 그 시드로 연출하고, 라운드가 끝나면 「파티 스냅샷 + 시드」를 올린다
3. 서버가 같은 `game_logic` 으로 재현해 승패 · 드랍을 확인하고 **드랍에 서명**한다
4. 인증 리그는 **서명된 아이템 · 영웅만** 출전한다. 서명 뒤 오프라인에서 고치면(강화 등) 서명이 깨진다

정할 것 — ①온라인 전투에 서명 없는 장비를 들고 가도 되나(허용 = 파밍 가속뿐 · 추천 / 금지 = 사실상 명단 분리) ②레벨 · 강화를 결투장에서 고정값으로 맞춰 인증 범위를 **아이템 굴림 · 영웅 정체**로 줄이나.

## 5. 지금 코드와의 거리

- 지금 결투장은 **AI 상대 연습전**이다 — 저장된 편성을 스냅샷으로 떠서(`arena.js` `snapshotTeam`) 생성된 상대(`rollOpponent`)와 싸운다 (SCREEN_DESIGN · ADR-0490)
- 고스트 = `rollOpponent` 자리에 서버에서 받은 스냅샷을 넣는다
- 인증 리그는 전투 시드를 바깥에서 받는 입구 하나 · 아이템 서명 칸(세이브 스키마 — INTERFACE.md 먼저)이 필요하다. `game_logic` 이 시드 주입 · 시간 주입이라 재현은 지금 구조로 된다
- **지금부터 지킬 것** — 결투장 보상이 PvE 힘으로 흐르는 설계를 만들지 않는다 · 아이템 고유 ID 를 유지한다

## 6. 미확정
