# 자동장착 초안 — 남은 것

> 상위: [GAME_DESIGN.md](GAME_DESIGN.md) §9 2026-10-22 (섰다) · §10 「자동장착의 남은 칸」 · 근거: [item_design.md](item_design.md) §6-3 · 화면: [SCREEN_DESIGN](../client/SCREEN_DESIGN.md) §6 · ADR-0712 · 코드: `game.autoEquip` · `item.fitsClass` (R307)
> **초안 [2026-10-21 · 2026-10-22 개정]** — 기준 · 버튼은 섰고, 아래 §2 가 남은 칸이다. 여기 적힌 후보를 근거로 다른 결정을 쌓지 않는다(⚠).
> 수치는 전부 CSV — 본 문서에 절대값을 기재하지 않는다.

## 1. 섰다 [2026-10-22]

| | |
|---|---|
| **언제** | 버튼을 누를 때만 — 캐릭터 탭 장비 칸 제목 오른쪽 끝 [자동 장착] |
| **누구에게 · 어디서** | 고른 영웅 하나 · 보고 있는 인벤토리만 |
| **거르기** | 요구 레벨 + 직업 어울림(무기군 · 갈래의 `classes`) |
| **고르기** | 무기 = 끼면 초당 피해 · 갑옷 · 투구 · 장갑 · 신발 = 끼면 방어력 — 오를 때만 바꾼다(강화 포함) · 빈 칸이면 가장 높은 것 |
| **반지 · 목걸이** | 빈 칸만 — 아이템 레벨 → 등급 순 |
| **점수를 안 쓰는 이유** | 아직 없다 · 굴림의 운을 재지 세기를 재지 않는다(§6-1 · §6-2) · 랜덤 줄을 안 보니 빌드의 판단은 손에 남고, 그래서 상시가 아니라 버튼이다 |

## 2. 남은 것

| # | 질문 | 지금(임시) | 후보 · ⚠제안 | 걸리는 것 |
|---|---|---|---|---|
| ① | **투구 · 장갑 · 신발 갈래의 직업 어울림 값** | 아래 표를 `armor_group.csv:classes` 에 넣어 두었다 ⚠임시 | 이대로 확정 / 고친다 | 장갑 · 신발의 가죽을 궁수와 캐스터가 같이 쓴다 · 직업 어울림은 자동 장착의 거르기에만 쓰인다(손으로 끼는 것은 안 막는다) |
| ② | **끼면 꺼지는 전술** | 안 본다 — 바꾼 뒤 원정 교체 플래시로만 알린다 | 그 교체를 건너뛴다 / 지금대로 끼고 알린다 | 판정 재료(`runTacticsIf`)는 이미 있다 · 건너뛰면 「왜 안 바꿨나」가 안 보인다 |
| ③ | **범위** | 고른 영웅 하나 · 보고 있는 인벤토리 | 창고까지 · 부대 전원(가장 많이 오르는 영웅에게 — 장비 봇 방식) · 다른 영웅이 낀 것 · 잠근 장비는 안 벗긴다 | 창고는 「남긴다」는 뜻의 칸(item_design §6-5) · 잠금은 지금 분해 보호 하나 — 뜻이 넓어진다 |
| ④ | **할 일 점과 같은 판정** | 별개 — 점 조건 미정(DEV_PLAN §4 #81) | ⚠제안 같이 쓴다 — 「자동 장착이 바꿀 게 있다」 = 캐릭터 탭 점 | 점이 늘 켜져 있으면 무시된다 |
| ⑤ | **점수가 서면** | 없음 | 바탕 수치가 같을 때 가르는 줄로 붙인다 | 선행 — 옵션 정의 CSV 이관 → 구간 폭 값(GAME_DESIGN §10 「아이템 점수의 구간 폭」) |
| ⑥ | **반지 · 목걸이를 빈 칸 너머로** | 빈 칸만 | 반지 고정 옵션(스킬 태그)이 서면 그 태그로 어울림을 준다 | [ring_fixed_draft.md](ring_fixed_draft.md) 가 먼저 서야 한다 |

① 의 지금 값:

| 부위 | 전사 · 기사 | 궁수 | 마법사 · 사제 |
|---|---|---|---|
| 투구 | 플레이트(최대 체력) | 가죽(명중률) | 티아라(쿨타임 감소) |
| 장갑 | 건틀릿(피해 감소) | 가죽(공격 · 캐스팅 속도) | 가죽 |
| 신발 | 그리브스(절대값 피해 감소) | 가죽(전투 시작 시 행동 게이지) | 가죽 |
