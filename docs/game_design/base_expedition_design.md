## 1. 원정 (전투 — 본편)

- **원정 단위 = 스테이지 런** — 던전 1회 입장 → 클리어 또는 귀환 → 런 단위 루팅 리포트
- **유저가 보는 상황에서 시작**하고, **로그아웃해도 끝까지 진행**된다 (클리어 또는 전멸). 리포트는 다음 접속 때
- 지역 = 챕터 구조 (story_chapter_design.md). 지역 선택 = 타겟 파밍 결정
- 파티 `[balance.csv:party_size_max]`인 · 동시 원정 `[balance.csv:concurrent_expedition_parties]`개 · 로스터 `[balance.csv:roster_cap]`

### 1-1. 부상/치료 모델

전투의 비용은 "부상" 하나로 수렴한다 — 피로도 등 별도 게이지 없음.

| 규칙 | 내용 |
|---|---|
| 런 내 소모 | 라운드를 거치며 HP 소모. **라운드 간 자동 회복 없음** — 흡혈/재생 장비가 런 깊이 담당 |
| 마을 회복 | 귀환 시 깎인 HP는 **무료·즉시 회복** |
| 부상(전투불능) | 런 중 쓰러진 영웅만 **치료 타이머** (방치·오프라인 중에도 진행) |
| 부상 중 제한 | **파견 불가** — 치료가 끝나야 복귀 |
| 귀환 룰 | 전투불능자 발생 시 파티 귀환 (연쇄 전멸 방지) |
| 제한시간 룰 | 전투가 제한시간 초과 시 귀환 — 교착 방지. 힐러·흡혈·재생 비특이적 |

- 용어는 "사망"이 아니라 **부상/전투불능** — 방치형 계약의 언어

### 1-2. 스테이지 구조

```
챕터 = 4스테이지         [balance.csv:stages_per_chapter]
스테이지 = 9라운드        [balance.csv:rounds_per_stage]
├ 라운드 3 / 6      : 정예 (정예 1 + 일반 0~2)
├ 라운드 9          : 보스 (스테이지 1~3: 보스+호위 / 스테이지 4: 챕터보스 단독)
└ 나머지            : 일반 (몬스터 1~3)
```

- **구조 고정 · 내용물 시드 랜덤** — 리듬은 익히되 런은 매번 다르다 (몬스터 조합·정예 특성 랜덤, monster_design.md §4·§6)
- **중도 귀환 = 루팅 전량 보존** — 비용은 부상 치료 + 미클리어뿐. 부분 진입도 성장 사다리
- 편성 상한·목표 전투시간: `round_budget.csv`

## 2. 거점 — 시설이 곧 파견지

> **시설은 플레이어가 굴린다. 배치된 영웅은 그 시설의 효율을 결정한다.**

제작 버튼은 플레이어가 누르고, 배치된 영웅은 성공률·품질을 민다. 이 문법 하나로 모든 시설이 굴러간다.

### 2-1. 시설 = 파견 슬롯

**건물을 지으면 그 건물이 파견 슬롯이 된다.** 파견 유형과 건물 목록은 같은 것이다.

- **지은 시설 수가 곧 동시 파견 상한** — 숫자 캡이 아니라 구조로 거는 상한
- 업그레이드 = 산출 상한 · 갱신 주기 · 배치 인원의 개선
- 시설 유형 둘: **생산형**(영웅이 물어온다 — 산출량 = 능력치) / **효율형**(플레이어가 굴리는 것의 효율을 민다)
- 둘 다 **배치 후 방치** — 방치형 계약 준수

### 2-2. 시설 ↔ 담당 능력치

시설마다 담당 능력치 하나. **매력만 예외로 둘(선술집 · 상단)을 맡는다.** **통화 비중복**이 배치 규칙 — 겹치면 하나는 반드시 열등해진다.

**비전투 활동 [확정 2026-08-25]** — 시설 5종(영입 · 교역 · 연구 · 제련 · 채광) + **탐험**(파티 단위, 시설 아님 — §3-1). 상점은 없다 — 교역이 그 자리를 대신한다. **공방은 없다** — 제작 계열은 전부 제련소. 합성은 시설이 아니다(스킬 카드 합성 — skill_design.md §5, 후속).

| 능력치 | 시설 | 활동 | 유형 | 산출 (통화) |
|---|---|---|---|---|
| **매력** | **선술집** | 영입 | 효율형 | 영웅 명단 주기 갱신 · **등장 품질** (유니크 등장 확률 포함) · 고용 비용 |
| **매력** | **상단** | 교역 | 효율형 | 재료 ↔ 재화 교환 **환율** |
| **지능** | **연구소** | 연구 | 효율형 | 기술 · 레시피 **해금** |
| **감각** | **제련소** | 제련 | 효율형 | 장비 제작·강화 **성공률/품질** — 공방 기능 흡수 |
| 힘 ⚠ | 광산 | 채광 | 생산형 | 기본 재료(광석) |
| 민첩 · 건강 · 통솔 | 시설 없음 | — | — | 파견 역할 미정 — 후보: 탐험 판정 (§3-1) |

- **[2026-08-25 확정]** 매력이 선술집과 상단 둘 다 민다 — 08-23의 매력=선술집 유지, 교역이 추가됨. 같은 날 잠시 검토한 "통솔=선술집"은 철회
- 매력 영웅 하나가 두 시설을 동시에 못 돌린다 — "선술집이냐 상단이냐"가 배치 결정. 통화가 다르므로(영웅 품질 vs 환율) 비중복 규칙은 유지된다
- ⚠ 광산은 채광이 들어간다는 것만 확정 — 힘 배정·시설명·산출은 제안
- **파견 인원(로스터 − 파티) < 시설 수** — "이번엔 어느 시설을 돌릴까"가 결정으로 남는다
- **교역 = 재료·재화 교환** — 장비를 사고파는 창구가 아니다. 상점 폐지와 같은 결정

### 2-3. 배치 슬롯이 없는 기능

| 기능 | 내용 |
|---|---|
| 분해 | 잉여 장비 → 재료. 저품질 자동 분해 업그레이드 (Lootun Scrapper) |
| 건설·업그레이드 | 재료/재화로 시설을 짓고 올린다 → 파견 슬롯과 산출 상한 확장 |

## 3. 파견 (비전투 — 지류)

- **역할**: 원정에 나가지 않는 영웅이 시설을 돌리거나 탐험을 나가 **본편 파밍의 연료**를 댄다
- **장비 드롭은 원정 독점** — 파견 산출은 재료·재화·해금·시간
- **파견 영웅도 그냥 영웅** — 같은 8부위, 전투/파견 로테이션 자유. 좋은 장비를 딜러에게 줄지 파견 영웅에게 줄지가 결정이 된다
- 티어 사다리 없음 · 배치 후 방치 · 관리 요구 없음

### 3-1. 탐험 — 파티 단위 "제2의 원정" [확정 2026-08-25 · 골격만]

시설 파견(영웅 1명 배치)이 아니라 **파티를 꾸려 보내는** 활동. 원정의 문법 — 편성 → 출발 → 리포트 — 을 비전투에서 반복한다.

| 항목 | 상태 |
|---|---|
| 형태 | **파티 단위** · 원정과 같은 보내기/리포트 구조 — 확정 |
| 전투 | 비전투 활동으로 분류. **장비 드롭 없음** (§3 원정 독점 유지) |
| 산출 | 미정 — 후보: 희귀 재료 · 해금 (Dragon Cliff Pier 패턴 — 전투 밖 축이 성장 병목을 쥔다) |
| 판정 | 미정 — 후보: **민첩 · 건강 · 통솔**의 파견 역할을 여기 둔다 (파티 합산) → 능력치 7종 전부가 비전투 판정을 갖는다 |
| 인원 · 동시 운용 | 미정 — 로스터 `[balance.csv:roster_cap]` − 원정 파티 `[balance.csv:party_size_max]` 안에서 시설 파견과 인원을 나눠 쓴다 |

- **탐험 ≠ 원정** — UI 용어 분리 (원정 Expedition / 탐험 Exploration)
- 원정 파티 + 탐험 파티 + 시설 5를 로스터로 한꺼번에 다 돌릴 수 없다 — §2-2 "파견 인원 < 시설 수"와 같은 결정 압박

### 판정 4축

| 축 | 만드는 결정 |
|---|---|
| **담당 기본 능력치** (주) | 배치 — 어느 영웅이 그 시설에 맞나 |
| **죄종 궁합** | 로스터 구성 (sin_mapping.md에서 확정) |
| **파견 숙련** | 지속 — 유형별 독립, 하면서 자람 (Melvor 방식) |
| **유틸 접사** | 장비 배분 — 장비 결정이 파견에 닿는 지점 |

### 파견 리포트

결과 수치 + 죄종/특성 사건 텍스트 (시뮬 느낌의 전달 수단). 사건은 리포트 안에서 완결 — 로스터 파괴 없음.

## 4. 방치형 계약 (불변 원칙)

1. **자리 비워도 안전** — 오프라인/방치 중 로스터가 파괴되는 사건은 없다
2. 오프라인 진행 지원
3. 모든 사건은 리포트로 읽는다 — 실시간 개입 요구 금지

## 5. 스코프 가드

- 파견·탐험·건물 확장 요구가 나올 때마다 재확인: **"유저가 파견이 본편이라고 느끼면 잘못된 신호"**
- **상점 없음** — 교역은 시설(파견 활동)로만 존재하고 장비를 사고파는 창구가 아니다. 파견·건물이 늘어도 장비의 출처는 원정 하나
