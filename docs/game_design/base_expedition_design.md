## 1. 원정 (전투 — 본편)

- **원정 단위 = 스테이지 런** — 던전 1회 입장 → 클리어 또는 귀환 → 런 단위 루팅 리포트
- **유저가 보는 상황에서 시작**한다. **[2026-08-25 확정] 반복 원정**을 켜 두면 **게임이 켜져 있는 동안은 자리를 비워도 계속 진행** · **게임이 꺼지면 진행 중이던 전투(해당 몬스터)까지만 정산하고 런을 마무리** — 오프라인에 다음 라운드·다음 런은 돌지 않는다. 리포트는 다음 접속 때
  - 오프라인 산출은 파견(§3)과 치료 타이머(§1-1)뿐 — "게임이 켜져 있을 때 드롭, 꺼져 있을 때 재료"
- 지역 = 챕터 구조 (story_chapter_design.md). 지역 선택 = 타겟 파밍 결정
- 파티 `[balance.csv:party_size_max]`인 · 동시 원정 `[balance.csv:concurrent_expedition_parties]`개 · 로스터 `[balance.csv:roster_cap]`

### 1-1. 부상/치료 모델

전투의 비용은 "부상" 하나로 수렴한다 — 피로도 등 별도 게이지 없음.

| 규칙 | 내용 |
|---|---|
| 런 내 소모 | 라운드를 거치며 HP 소모. **라운드 간 자동 회복 없음** — 흡혈/재생 장비가 런 깊이 담당 |
| 마을 회복 | 귀환 시 깎인 HP는 **무료·즉시 회복** |
| 부상(전투불능) | 런 중 쓰러진 영웅만 **치료 타이머** (방치·오프라인 중에도 진행) |
| 부상 중 제한 | **파견 불가** — 치료가 끝나야 복귀 |
| 귀환 룰 | 전투불능자 발생 시 파티 귀환 (연쇄 전멸 방지) |
| 제한시간 룰 | 전투가 제한시간 초과 시 귀환 — 교착 방지. 힐러·흡혈·재생 비특이적 |

- 용어는 "사망"이 아니라 **부상/전투불능** — 방치형 계약의 언어

### 1-3. 의뢰 [신설 2026-08-31 · 재작성 2026-09-01 — 그릇 · 여분 회차 · 명성]

**의뢰는 활동 이름이 아니라 형식 이름이다** [2026-09-01 사용자 확정]. 그릇이고, 안에 여러 종류가 들어간다.

**의뢰의 정체 = 기존 활동의 여분 회차** [확정 2026-09-01] — 새 활동을 만드는 것이 아니라 **이미 있는 활동을 한 번 더** 돌릴 기회로 뜬다. *수색은 그냥도 보낼 수 있고, 의뢰에 뜨면 또 보낼 수 있다.* 그래서 종류가 늘어도 신규 활동이 늘지 않는다.

**분류는 두 축** [확정 2026-09-01] — ① **파티 / 개인** ② **실시간 / 위임**(시간 단위로 맡기고 결과·사건을 나중에 확인).

| | **파티** | **개인** |
|---|---|---|
| **실시간** (관전) | 보스/던전 지목 · **약탈** | — |
| **위임** (오프라인) | 탐험 의뢰 · **보호** | 파견 의뢰 · 수색 의뢰 |

- 온·오프 배치는 컨셉 락 따름정리 1 이 가른다 — **기준은 문법이 아니라 전투 여부**. 탐험이 원정 문법을 빌려도 비전투라 오프라인인 것과 같다(§3-1)
- **「아르바이트」는 폐기됐다** — 1회성 비전투 활동의 자리를 의뢰가 흡수한다 (GAME_DESIGN.md §9 09-01)
- 미정 — 종류 목록의 마감(개인 × 실시간 칸이 비어 있다) · 유한성(수락하면 소진되는가) · 동시에 도는 실시간 의뢰 수 · 첫 해금 시점 (GAME_DESIGN.md §10 「의뢰 세부」)

#### 의뢰 파티 — 원정과 무관하다 [확정 2026-09-01]

**의뢰는 원정에 나가 있지 않은 영웅이 간다.** 원정 파티와 인원이 겹치지 않고(08-31 「파티 완전 분리」), 그래서 **의뢰의 성패가 원정을 막지 않는다** — 의뢰 파티가 전원 부상당해도 원정은 그대로 돈다.

#### 명성 — 의뢰의 등급 사다리 [신설 2026-09-01]

| 규칙 | 내용 |
|---|---|
| 단위 | **전체 명성 하나** — 의뢰 종류마다 따로 두지 않는다 |
| 오르면 | 더 어려운 의뢰를 받는다 → **보상이 나아진다** |
| 패배하면 | **명성이 떨어지고 파티 전원이 부상**한다 (치료 타이머 · §1-1) |

- 수치는 전부 미발행 — 상승·하락 폭 · 등급 구간 · 명성이 여는 것 · 첫 해금은 GAME_DESIGN.md §10
- **위임형 의뢰에 패배가 있는지는 미정** — 수색은 「실패는 없다」가 확정이다(§2-4). 보호가 실패할 수 있으면 **오프라인에 손실이 나는 첫 사례**가 되어 방치형 계약(§4)과 대조가 필요하다

#### 약탈 · 보호 — 적이 영웅 파티다 [신설 2026-09-01]

| 종류 | 축 | 형태 |
|---|---|---|
| **약탈** | 파티 × 실시간 | 그 자리에서 바로 전장이 열린다 |
| **보호** | 파티 × 위임 | **표국** — 의뢰인의 상단을 호위해 시간 단위로 다녀온다 |

- **적은 몬스터가 아니라 영웅 파티다** — 인간형 몬스터 행을 세우는 것이 아니라 **진짜 영웅을 적으로 굴린다.** 보스/던전 의뢰와 갈리는 지점이 여기다
- **지키는 대상은 의뢰인의 것**이다 — 플레이어의 재화·거점을 잃는 구조가 아니므로 방치형 계약(§4)과 무관하다
- ⚠ **미해결 — 보호는 위임인데 전투를 한다.** 컨셉 락 따름정리 1 「전투는 실시간 독점 · 오프라인에 전투는 돌지 않는다」와 정면으로 부딪힌다. 후보 ①전투를 판정으로 추상화(탐험 판정 4축, §3-1) ②리포트에서 전투를 재생 ③보호를 실시간으로 올린다 (GAME_DESIGN.md §10)
- 적 영웅 파티를 무엇으로 만드는가(생성 · 장비 · 드롭 · 전술카드 사용 여부)는 GAME_DESIGN.md §10 「의뢰 — 적 영웅 파티」

#### 보스/던전 지목 [확정 2026-08-31]

특정 보스/던전을 지목하면 그 전장이 즉시 열리고 파티를 편성하는 방식.

| 규칙 | 내용 |
|---|---|
| 형태 | 특정 보스/던전 지정 → 즉시 전장 오픈 → 파티 편성 |
| 동시성 | 원정과 **동시에** 실시간으로 돈다 — 별도 탭(의뢰 탭)에서 진행 |
| 관전 | 유저가 지금 보고 있는 탭이 관전 대상을 정한다(원정 탭 / 의뢰 탭) |
| 파티 | 원정 파티와 **완전히 분리된 인원** — 겹칠 수 없다 |
| 쿨다운 | 시간이 지나야 다시 초기화된다. 값 미정 |
| 드랍 | 원정과 같은 급의 전투이므로 드롭 파이프라인을 그대로 탄다(item_design.md §1) — 재사용 여부는 세부 미정 |

- **컨셉락 "전투 창구는 하나"(CLAUDE.md 따름정리 2)는 이 결정으로 개정됐다** — 전투 채널은 이제 원정·의뢰 둘이고, **파티 완전 분리 + 탭 기반 관전**이 Lootun과의 차이를 대신 지킨다(따름정리 3)
- **실시간 의뢰는 파견이 아니다** — 전투이므로 §2·§3의 파견처·파견 목록에 들지 않는다. **위임형 의뢰는 반대로 파견 쪽**이다(위 표)

## 2. 거점 — 파견처

> **파견처의 가짓수는 챕터가 정하고, 세기는 배치된 영웅이 정한다.** [확정 2026-08-26]

제작 버튼은 플레이어가 누르고, 배치된 영웅은 성공률·품질을 민다. 이 문법 하나로 모든 파견처가 굴러간다.

### 2-1. 파견처 = 파견 슬롯

**챕터를 깨면 파견처가 열리고, 열린 파견처가 곧 파견 슬롯이다.** 파견 유형과 파견처 목록은 같은 것이다. **짓거나 올리는 개념은 없다.**

- **열린 파견처 수가 곧 동시 파견 상한** — 숫자 캡이 아니라 구조로 거는 상한
- **레벨업 없음** — 세기를 미는 축은 배치된 영웅 하나다. 파견처에 레벨을 두면 같은 결과를 미는 축이 둘이 되어 "배치가 효율을 정한다"가 흐려진다
- 파견처 유형 둘: **생산형**(영웅이 물어온다 — 산출량 = 능력치) / **효율형**(플레이어가 굴리는 것의 효율을 민다)
- 둘 다 **배치 후 방치** — 방치형 계약 준수

### 2-2. 파견처 ↔ 담당 능력치

파견처마다 담당 능력치 하나. **매력만 예외로 둘(선술집 · 상단)을 맡는다.** **통화 비중복**이 배치 규칙 — 겹치면 하나는 반드시 열등해진다.

**비전투 활동 [개정 2026-08-31]** — 파견처 5종(영입 · 교역 · 제련 · 채광 · 채집) + **탐험**(파티 단위, 파견처 아님 — §3-1). 상점은 없다 — 교역이 그 자리를 대신한다. **공방은 없다** — 제작 계열은 전부 제련소. 합성은 파견처가 아니다(스킬 카드 합성 — skill_design.md §5, 후속). **연구는 파견처가 아니다** — 영웅 파견 없이 진행하는 별도 시스템(연구 탭, GAME_DESIGN.md §9 08-31)이다.

| 능력치 | 파견처 | 활동 | 유형 | 산출 (통화) |
|---|---|---|---|---|
| **매력** | **선술집** | 영입 · **수색** | 효율형 | 명단 **등장 품질** · **유니크 등장 확률** · 고용 비용 · 수색 결과 품질 (상세 §2-4) |
| **매력** | **상단** | 교역 | 효율형 | 재료 ↔ 재화 교환 **환율** |
| **운** | **제련소** | 제련 | 효율형 | 장비 제작·강화 **성공률/품질** — 공방 기능 흡수 |
| 힘 ⚠ | 광산 | 채광 | 생산형 | 기본 재료(광석) — **크래프트 제작의 바탕** (item_design.md §5) |
| ⚠ 미정 | **채집** | 채집 | 생산형 | 신규 재료(⚠ 이름 미정) — **연구**(연구 탭 신설 섹션)가 소모 |
| 지능 · 민첩 · 건강 · 통솔 | 파견처 없음 | — | — | 파견 역할 미정 — **지능은 2026-08-31 연구소 삭제로 미배정 전환.** 민첩·건강·통솔은 후보: 탐험 판정 (§3-1) |

- **[2026-08-31 개정] 연구소 삭제** — 스킬 노드·레시피 해금은 영웅 파견 없이 진행하는 별도 "연구" 시스템(연구 탭 = "연구" + "파티전술" 두 섹션)이 담당한다. 지능은 파견처 배정을 잃는다
- **[2026-08-31 신설] 채집** — 생산형 1인 배치. 담당 능력치 미정(민첩·건강 후보). 물어온 재료는 연구가 소모한다 — 크래프트가 아니므로 §10 "크래프트 가드"를 악화시키지 않는다
- **[2026-08-26 개정]** 감각 → **운**. 명중·회피 폐지로 전투 역할이 빈 자리를 재정의했다 — 제련소가 맡은 것이 "제작·강화 **성공률**/품질"이라 배정 근거가 오히려 강해진다. 운은 전투 계산 밖이고 드랍률·골드 획득 계수를 담당한다 (hero_design.md §4-1)
- **[2026-08-25 확정]** 매력이 선술집과 상단 둘 다 민다 — 08-23의 매력=선술집 유지, 교역이 추가됨. 같은 날 잠시 검토한 "통솔=선술집"은 철회
- 매력 영웅 하나가 두 파견처를 동시에 못 돌린다 — "선술집이냐 상단이냐"가 배치 결정. 통화가 다르므로(영웅 품질 vs 환율) 비중복 규칙은 유지된다
- ⚠ 광산은 채광이 들어간다는 것만 확정 — 힘 배정·파견처 이름·산출은 제안
- **파견 인원(로스터 − 파티) < 파견처 수** — "이번엔 어느 파견처를 돌릴까"가 결정으로 남는다
- **교역 = 재료·재화 교환** — 장비를 사고파는 창구가 아니다. 상점 폐지와 같은 결정

### 2-3. 배치 슬롯이 없는 기능

| 기능 | 내용 |

### 2-4. 선술집 — 명단 · 수색 [확정 2026-08-26]

> **영웅 획득 창구는 선술집 하나다.** 명단과 수색 **둘 다 선술집 안**에 있고, **수색은 파견 슬롯을 먹지 않는다** — §3 파견의 한 종류가 아니다.

| 쿨다운 | 리롤 후 `[balance.csv:tavern_refresh_hours]` · **오프라인에도 진행** |
| 즉시 리롤 | 쿨다운 중에는 `[balance.csv:tavern_reroll_cost]` 골드 |
| 고용한 칸 | **빈 채로 남고 다음 리롤에 채워진다** — 고용이 무료 리롤 우회로가 되지 않게 |

- **자동 갱신을 쓰지 않는 이유** — 시계가 명단을 덮어쓰면 자리를 비운 사이 등장이 사라지고 "주기마다 확인해야 안 놓친다"는 접속 압박이 생긴다. 방치형 계약(§4)과 충돌한다. 쿨다운은 **플레이어 행동에 걸리므로** 명단이 저절로 사라지지 않는다
- 그래서 찜(hold)·무료 갱신권 누적 같은 보상 장치가 **필요 없다** — 잃는 것이 없으므로

#### 수색 — 능동 경로

명단이 흐름이라면 수색은 통제다. 대기 영웅 하나를 내보내 **추가 후보 1명**을 물어온다.

| 규칙 | 내용 |
|---|---|
| 인원 | 대기 영웅 1명 (원정 파티 · 치료 중 제외) |
| 동시 | `[balance.csv:tavern_search_slots]` — **1 고정** |
| 소요 | `[balance.csv:tavern_search_hours]` · **오프라인에도 진행** |
| 실패 | **없다** — 매력이 미는 것은 성공 여부가 아니라 결과의 품질 |
| 결과 | 명단 밖 **별도 칸**. 리롤에 쓸려나가지 않고 **수령(고용)할 때까지 남는다** |
| 고용 비용 | 명단과 동일 `[balance.csv:tavern_hire_cost]` |

| 판정 입력 | 미는 것 |
|---|---|
| **매력** | 결과 품질 · **유니크 등장 확률** |
| **수색 숙련** | 소요 시간 · 결과 하한 — 영웅별·행동별 누적 (hero_design.md §5) |
| 장비 · 스킬 | **보류** — 기여 여부를 정하지 않았다 |

- **유니크는 지정할 수 없다. 확률만 오른다** — 명단·수색 어느 쪽에서도 특정 유니크를 지목하는 경로는 없다. 08-24 "유니크 = 선술집 희귀 등장"은 유지되고, 수색이 그 확률을 미는 두 번째 손잡이가 된다
- **숙련은 파워가 아니라 속도 쪽에 둔다** — 숙련이 세면 영웅이 그 자리에 못박혀 §3 "전투/파견 로테이션 자유"가 죽는다
- 수색 나간 영웅이 그동안 선술집 상주 효과를 잃는지는 **거점 배치 슬롯이 확정된 뒤** 정한다

#### 미정 — 훅만 남긴 것

| 항목 | 상태 |
|---|---|
| **수색 조건 지정** | `target` 자리만 비워 둔다 (현재 무지정 전용). 후보 — **완료한 스테이지를 골라 그 구역을 수색**. 유니크의 챕터는 지역 죄종 편향에서 규칙으로 도출하고 정확한 스테이지는 단서로 좁힌다(숨김 테이블을 쓰지 않는다). 유니크 15명·스테이지 데이터가 생긴 뒤 확정 |
| 선술집 배치 슬롯 | 거점 파견처 시스템 확정 후 통합 |
| 조건별 소요 시간 계단 | 조건 지정이 확정된 뒤 키 발행 |

## 3. 파견 (비전투 — 지류)

- **역할**: 원정에 나가지 않는 영웅이 파견처를 돌리거나 탐험 등을 나가 **본편 파밍의 연료**를 댄다 — 파견 종류는 여러 개를 기획 중(08-26), 어휘 정리는 GAME_DESIGN.md §10
- **수색은 파견이 아니다** — 선술집 하위 기능이고 파견 슬롯을 먹지 않는다 (§2-4, 확정 2026-08-26)
- **실시간 의뢰는 파견이 아니다** — 전투이므로 비전투 파견 목록에 안 든다. **위임형 의뢰는 오프라인이라 파견 취급**이다 — 파견 슬롯을 먹는지는 종류 목록과 함께 정한다 (§1-3, 개정 2026-09-01)
- 파견 산출은 재료·재화·해금·시간 — **[2026-08-26 개정] "장비 드롭은 원정 독점"(08-24) 삭제.** 재료는 제련소에서 크래프트 제작에 쓴다. 원정 없이 제작이 성립하는지의 가드는 미정 (GAME_DESIGN.md §10)
- **파견 영웅도 그냥 영웅** — 같은 8부위, 전투/파견 로테이션 자유. 좋은 장비를 딜러에게 줄지 파견 영웅에게 줄지가 결정이 된다
- 티어 사다리 없음 · 배치 후 방치 · 관리 요구 없음

### 3-2. 중도 회수 — 언제든 부를 수 있다 [확정 2026-08-31]

**보낸 영웅은 잠기지 않는다.** 접속 중에 필요해지면 불러들이고, **흐른 시간만큼 비례해 받는다**(끝까지 두면 전부).

- **회수에 벌을 붙이지 않는다** — 「일찍 부르면 절반」 같은 감산을 넣으면 다시 「그동안 못 쓴다」가 되어 통제성이 깨진다. 잃는 것은 **아직 안 흐른 시간**뿐이다
- **왜 필요한가** — 파견 타이머는 **접속 중에도 흐른다**(GAME_DESIGN.md §3-1 ③). 회수가 없으면 파견을 보낼수록 접속 중 만질 수 있는 영웅이 줄어, 이미 가장 얇은 접속 층이 더 얇아진다. 「못 쓴다」를 「덜 받는다」로 바꾸는 것이 이 규칙의 요점이다
- 부수 효과 — **파견 시간이 곧 오프라인 상한**이 된다. 오래 안 켜도 그 파견 하나치가 최대다
- ⚠ **산출이 시간에 비례해야 성립한다** — 「N시간 뒤 리포트 하나」 형태면 비례 지급이 안 된다. 결과 수치는 비례가 되지만 **리포트의 사건 텍스트**를 부분 지급에서 어떻게 다룰지는 미정
- 부상 치료 타이머는 별개다 — 「부상 중 파견 불가」(§1-1)가 그대로 유지된다

### 3-1. 탐험 — 파티 단위 "제2의 원정" [확정 2026-08-25 · 골격만]

1인 배치(파견처에 영웅 하나)가 아니라 **파티를 꾸려 보내는** 활동. 원정의 문법 — 편성 → 출발 → 리포트 — 을 비전투에서 반복한다.

| 항목 | 상태 |
|---|---|
| 형태 | **파티 단위** · 원정과 같은 보내기/리포트 구조 — 확정 |
| 전투 | 비전투 활동으로 분류. **장비 드롭 없음** — 드롭은 전투(원정)의 산출 (CLAUDE.md 컨셉 락) |
| 오프라인 | **진행한다** — 확정 2026-08-26. 가르는 기준은 문법이 아니라 **전투 여부**다. 원정의 문법을 빌리되 오프라인 취급은 파견 쪽 (CLAUDE.md 컨셉 락 따름정리 1) |
| 산출 | 미정 — 후보: 희귀 재료 · 해금 (Dragon Cliff Pier 패턴 — 전투 밖 축이 성장 병목을 쥔다) |
| 판정 | 미정 — 후보: **민첩 · 건강 · 통솔**의 파견 역할을 여기 둔다 (파티 합산) → 능력치 7종 전부가 비전투 판정을 갖는다 |
| 인원 · 동시 운용 | 미정 — 로스터 `[balance.csv:roster_cap]` − 원정 파티 `[balance.csv:party_size_max]` 안에서 파견처 배치와 인원을 나눠 쓴다 |

- **탐험 ≠ 원정** — UI 용어 분리 (원정 Expedition / 탐험 Exploration)
- 원정 파티 + 탐험 파티 + 파견처 5를 로스터로 한꺼번에 다 돌릴 수 없다 — §2-2 "파견 인원 < 파견처 수"와 같은 결정 압박

### 판정 4축

| 축 | 만드는 결정 |
|---|---|
| **담당 기본 능력치** (주) | 배치 — 어느 영웅이 그 파견처에 맞나 |
| **죄종 궁합** | 로스터 구성 (sin_mapping.md에서 확정) |
| **파견 숙련** | 지속 — 유형별 독립, 하면서 자람 (Melvor 방식) |
| **유틸 접사** | 장비 배분 — 장비 결정이 파견에 닿는 지점 |

### 파견 리포트

결과 수치 + 죄종/특성 사건 텍스트 (시뮬 느낌의 전달 수단). 사건은 리포트 안에서 완결 — 로스터 파괴 없음.

## 4. 방치형 계약 (불변 원칙)

1. **자리 비워도 안전** — 오프라인/방치 중 로스터가 파괴되는 사건은 없다
2. 오프라인 진행 지원 — 파견·**탐험**(§3-1)·치료 타이머. 원정은 오프라인에 진행하지 않는다 (§1)
3. 모든 사건은 리포트로 읽는다 — 실시간 개입 요구 금지

## 5. 스코프 가드

- 파견·탐험 확장 요구가 나올 때마다 재확인: **"유저가 파견이 본편이라고 느끼면 잘못된 신호"**
- **상점 없음** — 교역은 파견처(파견 활동)로만 존재하고 장비를 사고파는 창구가 아니다. 파견처가 늘어도 장비의 출처는 원정 하나
