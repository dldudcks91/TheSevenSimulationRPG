## 0. 어휘 [초안 2026-09-22]

- **건설** = 건물을 짓고 랭크를 올리는 일. **r1 = 짓기**, r2 부터 = 랭크 올리기
- **랭크** = 건물이 **여는 것**(기능 · 선택지 · 칸 · 콘텐츠)의 단계
- **연구** = 건물 **아래** 노드 — **효율 %** 를 올린다
- 화면 탭 이름은 이미 「건설」이다([ADR-0253](../client/adr/0253-연구-탭은-건설이-되어-캐릭터-바로-아래에-선다.md)). 기획서는 이 시스템 전체를 여전히 「연구」라 부른다 — 이 초안은 **건설(랭크 = 연다)** 과 **연구(노드 = %)** 를 가른다

## 1. 합의된 원칙 [초안 2026-09-22]

1. **건물 랭크는 열기만 한다 — 효율 % 는 건물 아래 연구가 올린다** (사용자 결정)
2. **연구 % 의 범위** — 경제 · 파견만 다루는 안을 권장 · 곱으로 건다 · 연구 상한을 건물 랭크가 연다. **전투 % 를 넣을지는 미정**(사용자 — 「천천히 정한다」)
3. **문턱은 두 축**
   - 세계 · 콘텐츠를 여는 랭크는 **챕터**(스테이지 단위까지)
   - 로스터를 다루는 랭크는 **로스터 합산 레벨** — 도달한 최고치 기준(내려가도 닫히지 않는다)
4. **문턱을 넘은 뒤 순서는 비용**(재료 + 골드)이 정한다 — 챕터 보스 시점에 여러 랭크가 몰리면 플레이어가 고른다
5. **실패 없음 · 되돌림 없음 · 건설 타이머 없음**
6. **건물 밖 축은 그대로** — 전직 · 마스터리(영웅 레벨) · 난이도 단(챕터 보스) · 도감 레벨(처치 수) · 베이스 티어(아이템 레벨)
7. **아직 설계 안 된 시스템은 건물로 미리 올리지 않는다** — 시스템이 설계될 때 새 건물로 붙인다. 여는 내용이 없는 건물은 빈 칸만 늘린다 (사용자 동의 · Lootun 방식 — 부록 A)
8. **새 시스템은 새 건물로, 깊이는 기존 건물의 새 랭크로** 넣는다 (부록 A 패턴 2)

## 2. 건물 표 [초안 2026-09-22]

## 4. 시작 상태 [초안 2026-09-22]

- **지어진 채 시작** — 원정 · 제련소 · 창고 · 도감 · 선술집 r1
- **처음 보이는 탭** — 원정 · 편성 · 캐릭터 · 건설 · 제련소 · 선술집 · 도감 · 도움말. 자원 · 상점 · 탐험은 **지으면 나타난다**
- 지금 코드는 탭을 전부 처음부터 연다(`ui/app.js` TABS 에 잠금 없음) — 탭 잠금은 새로 생기는 화면 규칙이다

## 6. 비용 [초안 2026-09-22]

- **건설** = 골드 + 문턱 챕터 티어의 광석 · 목재 · 가루
- **연구** = 약초 + 골드 (09-10 유지)
- 후보 — 챕터 보스가 문턱인 랭크는 **그 챕터의 낙인**을 열쇠로 요구한다
- ⚠ **파견 미구현** — 광석 · 목재 · 약초 공급이 코드에 없다. 그 전까지 1장 랭크는 **골드 · 가루만으로** 지을 수 있게 한다
- Lootun 은 새 세대 콘텐츠를 열 때마다 **이전 구간 건설비를 깎았다**(부록 A 패턴 4) — 비용 곡선은 나중에 내릴 수 있게 CSV 로 둔다

## 부록 A. Lootun 은 건물을 어떻게 키웠나 [조사 2026-09-22]

> 근거 — Steam 공식 뉴스 68건 · 얼리 액세스 이전 itch.io 개발 로그(0.5.1 ~ 0.5.14) 원문. 건물별 랭크 내용은 [lootun/03_buildings.md](../reference/lootun/03_buildings.md). 「Fixed a bug where …」 문장은 거꾸로 읽는다(그 반대가 의도).

| 시기 | 새 건물 | 기존 건물에 붙은 랭크 · 변화 |
|---|---|---|
| **0.5** (2022-05 ~ 06, 얼리 액세스 전) | 공식 설명에 나온 것은 **8종** — Scrapper · Blacksmith · Barracks(자동화) · Profession Hall · Mine · Forest · Farm · Community Project. 전부 **그때 이미 있던 기능의 집** | Barracks 전 랭크 비용 인하(자동화를 빨리 쓰게) · Alchemist's Hut r7(플라스크 자동 보충) |
| **0.6** (2022-08, 얼리 액세스 출시) | **Bounty Board** 신설. Paragon(Keep 추정) · Nemesis 제작(Castle)이 이름 없이 들어옴 | Artisan's Hall 에 속성 변환 랭크 |
| **0.7 ~ 0.8** (2022-11 ~ 2023-05) | **Domain of Agony**(맵 수식어) · **War Camp**(팩션, 추정) · **Fortress** | Blacksmith r4 · r5 전설 · 신화 제작 · Mine · Forest · Farm r6 일꾼 칸 · Artisan's Hall r6 각인 · Community Project r4 자동 기부. **Blacksmith Fragment · 고급 재료 비용 대폭 인하** |
| **0.9** (2023-09 ~ 12) | **Expedition**(레이드 입구 — 원문이 「new Expedition Building」) · **Item Vault**(Gemcutter 의 보석 보관 탭을 떼어 독립) | Item Vault r2 · r3 · Bounty 보관 칸 증가 |
| **1.0** (2024-03) | **Pinnacle** — 얼리 액세스 전부터 있던 무한 모드(Endless Spires)를 재설계해 건물 뒤로 옮김 | Armoury 랭크당 로드아웃 증가 |
| **1.1 ~ 1.3** (2024-10 ~ 2026-04) | **Grand Expedition**(상위 레이드 — 도입 버전 불명) | Barracks 스킬별 자동 시전 랭크 조건 확정(1.2) · Domain of Agony r4 교체 · Item Vault r4 아이템 연구(1.3). **Domain of Agony 이전 건물 재료비 전체 인하** |

개발 패턴

1. **있는 기능의 집 8개로 시작했다** — 나머지 18개는 콘텐츠가 늘 때마다 붙었다. 이 초안이 「지금 있는 기능만」인 것은 Lootun 0.5 와 같은 출발점이다
2. **새 시스템은 새 건물로, 깊이는 기존 건물의 새 랭크로** — 현상금 · 맵 수식어 · 팩션 · 레이드 · 보관소 · 무한 모드는 새 건물, 전설 제작 · 일꾼 칸 · 각인 · 아이템 연구는 기존 건물의 새 랭크
3. **이미 있던 기능을 건물 뒤로 옮기기도 했다** — 무한 모드 → Pinnacle · 보석 보관 탭 → Item Vault · 자동 시전 → Barracks 랭크
4. **새 세대 콘텐츠 직전마다 이전 구간 건설비를 깎았다** — 0.5.3 · 0.8 · 1.2 세 번
5. **후반 건물일수록 전용 재화가 하나씩 늘었다** — Favour → Obsidian → Soul Cloth → Overload Core

확인 못 한 것 — Watchtower · Keep · War Camp · Map Room 은 공식 원문에 이름이 0건(언어 파일 · 커뮤니티로만 확인) · Grand Expedition · Hidden Vault 의 도입 버전 · 0.5 이전 원문 없음.
