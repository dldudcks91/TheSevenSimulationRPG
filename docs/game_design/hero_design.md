# 영웅 시스템 설계

> 상태: **2층 구조 확정 (2026-08-21)** — 유니크 영웅 / 레어 영웅. 영웅 목록·고유 패시브 내용물 미착수
> 상위 문서: [GAME_DESIGN.md](GAME_DESIGN.md) §4

---

## 1. 개요

영웅은 유저의 **빌드 프로젝트**다. 유저 시간의 대부분은 영웅의 스킬 배분과 장비 세팅에 들어간다.
로스터는 소수 정예 — **[확정 2026-08-21]** 원정 파티 `[balance.csv:party_size_max]`인 + 휴식/파견 인원, 보유 상한 `[balance.csv:roster_cap]`. 다인 레이드는 추후 콘텐츠 예정.

## 2. 영웅 2층 구조 — 아이템 희귀도 계단의 영웅판

아이템이 **레어(절차 생성·무한) / 유니크(수작업·유한)**로 나뉘듯, 영웅도 같은 계단을 쓴다. 새 축이 아니라 기존 축의 재사용.

| | **유니크 영웅** | **레어 영웅** |
|---|---|---|
| 규모 | **본편 15명** (직업별 3) / 확장 포함 21명 | **무한** — 명단이 아니라 생성기 |
| 이름 | 고정 (과거의 유명 영웅) | 이름 풀에서 조합 생성 |
| 직업 | 영웅에 고정 | **굴림** |
| 죄종 | 영웅에 고정 | **굴림** (7택1) |
| 시작특성 | 미확정 (§6) | **굴림** |
| 고유 패시브 | **1개 보유** | 없음 |
| 중복 보유 | 로스터에 **1명만** — "그 영웅은 세상에 하나" | 제한 없음 (로스터 상한 내) |
| 죄종×직업 커버리지 | 담당하지 않음 | **7×5 = 35칸 전부 담당** |
| 획득 | 미확정 (§9 — 다음 논의) | 선술집 영입 / 탐색 발견 |
| 콘텐츠 비용 | 영웅당 수작업 (상한 15로 고정) | 이름 생성기 1개뿐 |

- 고용 비용은 매력 스탯으로 할인 (키: balance.csv 예정) — 양쪽 공통
- **레어 층이 커버리지를 전담**하는 것이 이 구조의 핵심. "분노 사제"가 필요하면 굴려서 얻는다. 그래서 유니크 영웅은 빈칸을 메울 의무가 없고, 오직 **"이 영웅은 남들과 다르게 싸운다"**는 특이함만 담당한다
- 대응 관계: 레어 영웅 = 매직/레어 아이템(굴림으로 강해짐), 유니크 영웅 = 유니크 아이템(고정 효과, 유한, 이름이 있음)

### 갈림길 해소 경위 (2026-08-21)

이전 초안은 죄종 부여 방식을 A1(굴림) / A2(영웅에 고정) / B(영웅 주인공 전환) 중 택일로 놓았으나, **A1과 A2를 층으로 분리**해 해소했다.

- A1 단독: 영웅마다 정답 죄종이 생기면 희귀 등장의 6/7이 잔존 가치 0인 꽝이 됨
- A2 단독: 커버리지를 위해 죄종×직업 35칸을 채워야 해 고유 패시브 수작업 비용이 폭발
- B: 계승 아이템 코어가 조연으로 강등 — **불채택** (A안 "장비가 주인공" 유지)
- → 굴림은 레어 층이(A1), 고정은 유니크 층이(A2) 각각 담당. 콘텐츠 비용은 유니크 15명으로 상한이 걸린다

## 3. 유니크 영웅

### 규모

```
본편 = 5직업 × 3명 = 15명        (전사/기사/마법사/궁수/사제)
확장 = + 2직업 × 3명 = 21명      (암살자/네크로맨서)
```

- **상한을 먼저 박는다** — 늘리기는 쉽고 줄이기는 불가능하므로 낮게 시작
- 근거: 로스터 상한 `[balance.csv:roster_cap]` 기준 한 회차에 4~5명 획득 → 못 얻은 나머지가 다음 회차 체이스로 남는다. 25명 이상이면 만드는 비용은 다 내고 플레이어가 만나는 비율이 급락
- 직업별 3명 = "내 기사 자리를 누구로 채울까"라는 선택이 성립하는 최소 규모

### 고유 패시브 (영웅 Implicit)

- **그릇**: 항시 발동. 스킬 포인트 불요, 전용 트리 없음 — 무기군 Implicit과 동일 포지션. [skill_design.md](skill_design.md)의 3탭 구조 불변
- "개성은 배분" 원칙과의 관계: **정체성은 출고(Implicit), 빌드는 3탭 배분** — 충돌 없음

**작성 규칙**

1. **파워 예산** — 고유 패시브는 "이 영웅이 **어떻게** 싸우는가"를 정한다. "**얼마나** 강한가"는 장비가 정한다 (A안 수호). 위반 시 영웅 티어리스트가 장비 파밍을 대체한다
2. **고정 죄종과의 시너지 허용** — 죄종이 영웅에 박혀 있으므로 "정답 죄종" 이진화가 발생하지 않는다. 수치형 궁합 패시브도 가능 (이전 초안의 "수치 스케일링 금지" 규칙은 굴림 전제였으므로 해제)
3. **레어 영웅을 죽이지 않을 것** — 유니크가 명백히 우월하면 레어 층 전체가 초반 소모품으로 전락한다. 목표는 D2의 "잘 굴린 레어가 유니크보다 나을 수 있다" 관계

## 4. 레어 영웅

```
레어 영웅 = 직업(굴림) + 죄종(7택1 굴림) + 시작특성(굴림) + 히든 성장률(굴림)
```

- **선술집 리롤 = 아이템 파밍의 영웅판** — 굴림 루프는 이 층에 산다
- 이름은 이름 풀에서 조합 생성 (D2 레어 아이템 명명과 동일한 취급). 생성 규칙 미확정 (§9)
- 죄종×직업 35칸을 굴림으로 전부 공급 — 유저가 원하는 조합은 여기서 나온다
- 콘텐츠 비용이 0에 수렴하므로 **영웅 다양성의 본체**는 이 층이다

## 5. 정체성 요소의 역할 분담

| 축 | 담당 | 담당하지 않는 것 |
|---|---|---|
| **고유 패시브** (유니크 전용) | 전투 방식의 특이성 | 파워 총량 (장비 담당) |
| **직업** | 스킬 탭2(마스터리)·탭3(전직) + 무기군 + 전투 역할 | 아이템 죄종 축, 파견 |
| **죄종** (7택1) | 스킬 탭1 + 죄종 접사/세트 궁합 + 파견 적성 + 리포트 성격 | 직업/무기 |
| **시작특성** (1개) | 전투/파견/유틸 소소한 다축 보정 + 리포트 사건 변주 | 핵심 파워 (양념) |

### 직업 7종 (확정 2026-08-21) — 본편 5 + 확장 2 (D2 LoD 방식 스테이징)

| 직업 | 아키타입 | 무기군 (초안) | 출시 |
|---|---|---|---|
| **전사** | 근접 물리 딜러 | 도끼 / 양손검 / 둔기 (계승) | 본편 |
| **기사** | 탱커/수호 | 한손검+방패 / 창 (계승) | 본편 |
| **마법사** | 마법 딜러 | 지팡이 (신규) | 본편 |
| **궁수** | 원거리 물리 딜러 | 활 (신규) | 본편 |
| **사제** | 지원/회복 | 둔기+방패 (계승 재활용) | 본편 |
| **암살자** | 치명/속도 근접 딜러 | 단검 (신규) | **확장** |
| **네크로맨서** | 소환 | 낫(신규) 또는 지팡이 공유 — 미정 | **확장** (펫 전투 서브시스템 필요 — 구현 최후순위) |

- **사제 서약**: 사제 없이도 최전선이 성립해야 한다 — 사제는 부상 빈도·안정성을 사는 선택지, 통행증 아님. 교착 방지는 전투 제한시간 룰이 담당 (힐러 비특이적 — 흡혈/재생 장비도 같은 그물에 걸림)
- **가드레일: 직업 ↔ 죄종 1:1 매핑 금지** — 죄종은 어느 직업과도 자유 조합되어야 한다. 7직업×7죄종 숫자 일치는 상징으로만
- 전직(탭3)의 정체는 **추후 결정** — 직업당 전직 트리 1개라는 구조만 확정
- 직업당 무기군 복수 허용 원칙: 같은 직업 안에서도 무기 선택이 갈리게 (마스터리 탭의 무기 숙련과 연동)
- **본편 유니크 영웅 풀은 본편 5직업으로만 구성**, 확장 직업의 유니크 영웅은 확장에서 추가

## 6. 능력치 — 두 층 (확정 2026-08-22 · 게이트 폐지 2026-08-23)

영웅의 수치는 **기본 능력치**와 **전투 능력치**로 완전히 갈린다. 두 층을 섞으면 개체차와 파견 배치 결정이 동시에 죽는다.

```
기본 능력치 (7종)   영웅 고유값. 성장으로만 오른다. 장비 기여 = 0
       │
       ├─ 계수     : 대응하는 전투 능력치에 곱해진다 (소폭)
       └─ 파견     : 비전투 판정의 주 축
                     ↓
전투 능력치 (파생)  장비 + 스킬 + 위 보정의 합산. 영웅이 직접 보유하지 않는다
```

**기본 능력치가 하는 일은 둘뿐이다 — 전투 계수와 파견 판정.** 무엇을 낄 수 있는지, 무엇을 배울 수 있는지는 **결정하지 않는다** (§6-2).

### 6-1. 기본 능력치 7종 — SSOT: `hero_attribute.csv`

| 능력치 | 전투 계수 | 파견 |
|---|---|---|
| **힘** | 물리 공격력 | TBD (채광장 후보) |
| **민첩** | 공격속도 · 캐스팅 속도 (= 행동 주기, 같은 축) | TBD (채집지 후보) |
| **지능** | 마법 공격력 | **연구소** — 기술·레시피 해금 |
| **건강** | 타격 회복 속도 · 상태이상 저항 | TBD (치료소 후보) |
| **감각** | 명중 · 회피 | **제련소** — 제작·강화 성공률/품질 |
| **통솔** | 파티 관련 스킬 (회복 · 파티 버프) | TBD (훈련장 후보) |
| **매력** | **없음** | **선술집** — 영웅 등장 품질 · 고용 비용 · 상점 가격 |

- 범위 `[balance.csv:hero_attr_min]` ~ `[balance.csv:hero_attr_max]` — 7종 공통
- 계수 폭 `[balance.csv:attr_bonus_per_point]` — 만점이어도 장비 총량에 비하면 소폭. 계산 위치는 battle_design.md §8-1
- **최대 HP는 어떤 능력치도 담당하지 않는다** — 전 영웅 공통 `[balance.csv:hero_hp_base]`에서 출발해 레벨·장비로만 자란다 (§6-4)
- **치명타도 능력치 담당이 없다** — 장비·스킬 전담. 감각은 명중과 회피만 민다
- 건강은 HP가 아니라 **피격 방해를 털어내는 축**(타격 회복 속도 · 상태이상 저항)이다
- **파견은 능력치 하나당 시설 하나** — 거점 시설이 곧 파견지다 (base_expedition_design.md §2-3). 3종 확정, 4종 후보
- **통솔 = 지원 축** — §9의 "사제 힐 파워 출처 미배정" 항목이 여기서 닫힌다 (`combat_stat.csv:heal_power`)
- **매력의 전투 기여 0은 버그가 아니라 기능이다** — "전투는 별론데 파견은 최고"인 영웅이 로스터에 남을 이유를 만드는 유일한 장치

### 6-2. 게이트 폐지 (2026-08-23)

**기본 능력치는 장비 착용도, 스킬 습득도 막지 않는다.** 요구 능력치(착용 게이트)와 요구 능력치 노드(스킬 게이트)를 기획에서 **전면 삭제**했다.

| 폐지 이유 | 내용 |
|---|---|
| **통제 밖의 차단** | 능력치는 자동 성장 + 히든 상한선이라 플레이어가 못 고른다. 거기에 게이트를 걸면 **플레이어가 통제할 수 없는 이유로 빌드가 막힌다** — 방치형에서 리롤 강요가 된다 |
| **게이트끼리 충돌** | 중갑 = 힘 / 경장 = 민첩인데 건강이 "방어구 전반"이라 같은 슬롯을 셋이 게이트했다. 나눌수록 복잡해지고 합칠수록 무의미해진다 |
| **배분 자유 원칙과 마찰** | 스킬 게이트는 "요구치는 배타적 선택이 아니라 적성"이라고 정리했지만, 결국 **영웅에 따라 못 배우는 노드가 생긴다.** 포인트 배분 완전 자유(skill_design.md §1)가 영웅마다 다른 모양이 된다 |
| **단순화** | 게이트를 빼면 능력치의 일이 둘로 줄고, 능력치 값 하나가 어디에 쓰이는지 한 줄로 설명된다 |

- 남는 착용 제약은 **요구 레벨뿐**이다 (코스트는 이미 폐지 — item_design.md §3)
- 직업이 무기군을 정하므로, "누가 무엇을 드나"는 **직업이 이미 담당**하고 있다. 능력치 게이트는 그 위에 얹힌 이중 제약이었다

### 6-3. 불변식 — 장비는 기본 능력치를 주지 않는다

> **`[balance.csv:attr_equip_bonus]` = 0**

기본 능력치가 `1~20` 범위인데 장비가 +n을 주기 시작하면, **잘 굴려진 영웅(힘 16)과 아닌 영웅(힘 8)의 차이를 장갑 한 짝이 덮는다.**

| 무너지는 것 | 내용 |
|---|---|
| **개체차** | 히든 성장률·상한선으로 얻은 굴림 결과를 장비가 덮는다 → 레어 영웅 리롤 루프의 근거가 사라진다 |
| **파견 배치 결정** | "매력이 높게 굴려진 영웅 → 선술집"이 성립하려면, 아무 영웅에게 +매력을 입혀 만들 수 없어야 한다 |

> 게이트 폐지로 근거 하나(요구치 자기순환)가 사라졌지만 **불변식은 그대로다.** 오히려 게이트가 없어져 능력치의 일이 전투 보정과 파견뿐이 된 지금, 장비가 능력치를 주면 **파견 배치 결정이 통째로 증발**한다 — 근거가 줄어든 게 아니라 남은 근거의 무게가 커졌다.

**크게 주면 개체차가 죽고, 작게 주면(+1~3) 접사 한 칸을 먹으면서 "떴다!"가 없는 밋밋한 옵션이 된다.** 어느 쪽으로도 이득이 없어 폐지했다.

- 예외를 둔다면 **유니크 아이템 전용**만 — 유한하고 수작업이라 통제된다. 절차 생성 접사 풀에는 넣지 않는다
- 데이터 조치: `equipment_option_override.csv` — 계승 `str`/`dex` 공통옵션 10행 제외, `all_stats` 접사 4행 치환 (item_design.md §3)

### 6-4. 원칙

- **[확정 2026-08-23] 최대 HP 시작값은 전 영웅 공통 고정** — `[balance.csv:hero_hp_base]`. 능력치 굴림이 생존력 격차를 만들지 않으므로 리롤 스트레스가 한 겹 더 줄고, **몬스터 수치 절대 앵커링의 기준점**이 된다 (monster_design.md §8)
- **수동 분배 없음** — 자동 성장 (D2 교훈: 스탯 찍기는 정답이 정해진 가짜 선택)
- **히든 파라미터**: 능력치별 성장률·상한선(비공개) — 같은 [죄종]×[직업] 굴림 사이의 개체차
- **개체차 = 파워 격차가 아니라 역할 적성 차이** — 게이트가 없으니 못 굴린 영웅도 모든 장비를 끼고 모든 스킬을 배운다. 남는 차이는 **소폭의 전투 보정**과 **파견 적성**뿐이다. 그래서 못 굴린 영웅은 "못 쓰는 영웅"이 아니라 **다른 자리(파견)가 어울리는 영웅**이 된다 — 방치형에서 리롤 스트레스를 최소화하는 형태
- **보정은 소, 파워는 장비** — 파워의 원천은 장비+스킬
- 영웅은 전투 능력치를 직접 보유하지 않는다 — 매 전투 계산 시 합산 (battle_design.md §8)

## 7. 성장

- **레벨 + XP**: 전투 원정으로 획득. 레벨업 시 스킬 포인트 지급 + 스탯 자동 성장
- **전직 해금**: `[balance.csv:advance_unlock_level]` 도달 시 탭3 개방 — 방치형 마일스톤
- **파견 숙련**: 파견 유형별 독립 숙련, 하면서 자람 (Melvor 방식) — 벤치 영웅의 성장 축
- 스킬 상세: [skill_design.md](skill_design.md)

## 8. 시작특성

- TheSevenSimulation의 21종에서 선별/재정의 예정 (목록 미정)
- 원칙: RimWorld Trait식 다축 영향 — 단 "양념" 포지션. 핵심 파워를 담지 않는다
- 레어 영웅에서는 같은 [죄종]×[직업] 굴림 사이의 **개체차 축** — 히든 성장률과 함께 리롤 깊이 담당
- 예시 방향: 호전적=물리뎀 소폭, 수집광=채집 파견 보너스, 행운아=드랍률 미세 보정, 낙천적=? (사기 시스템이 없으므로 재정의 필요)
