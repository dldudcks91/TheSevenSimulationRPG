# 영웅 시스템 설계

> 상태: 뼈대 확정 (2026-08-21) — 세부 수치/목록 미정
> 상위 문서: [GAME_DESIGN.md](GAME_DESIGN.md) §4

---

## 1. 개요

영웅은 유저의 **빌드 프로젝트**다. 유저 시간의 대부분은 영웅의 스킬 배분과 장비 세팅에 들어간다.
로스터는 소수 정예 — 파티 1~2개 + 벤치 규모 (상한: balance.csv 예정).

## 2. 획득 — 영웅도 굴림의 대상

- **선술집 영입** / **탐색 발견** (TheSevenSimulation 계승)
- 등장 시 3요소가 랜덤 조합으로 굴려져 나타남 → 선술집 리롤 = 아이템 파밍의 영웅판

```
영웅 = 죄종(7택1) + 직업(3택1) + 시작특성(1개)   ← 등장 시 확정, 영구 불변
```

- 고용 비용은 매력 스탯으로 할인 (키: balance.csv 예정)
- 이름은 별도 이름 풀에서 부여 (죄종/직업과 무관 — 처리 방식 미정)

## 3. 정체성 3요소의 역할 분담

| 축 | 담당 | 담당하지 않는 것 |
|---|---|---|
| **죄종** (7택1) | 스킬 탭1 + 죄종 접사/세트 궁합 + 파견 적성 + 리포트 성격 | 직업/무기 |
| **직업** (3택1) | 스킬 탭2(마스터리)·탭3(전직) + 무기군 + 전투 역할 | 아이템 죄종 축, 파견 |
| **시작특성** (1개) | 전투/파견/유틸 소소한 다축 보정 + 리포트 사건 변주 | 핵심 파워 (양념) |

### 직업 3종 (확정)

| 직업 | 전투 역할 (초안) | 무기군 (초안 — 미확정) |
|---|---|---|
| **전사** | 물리 딜러 | 도끼 / 양손검 / 둔기 |
| **기사** | 탱커/수호 | 한손검+방패 / 창 |
| **마법사** | 마법 딜러 | 지팡이 (신규 무기군 — TheSevenRPG에 없음, 추가 필요) |

- 전직(탭3)의 정체는 **추후 결정** — 직업당 전직 트리 1개라는 구조만 확정
- 직업당 무기군 복수 허용 원칙: 같은 직업 안에서도 무기 선택이 갈리게 (마스터리 탭의 무기 숙련과 연동)

## 4. 기본 스탯 7개 (TheSevenSimulation 계승 + 전투 역할 배정)

| 스탯 | 담당 |
|---|---|
| 힘 | 물리 데미지, 중갑/힘 무기 요구치 |
| 민첩 | 공속/회피, 원거리·경무기 요구치 |
| 지능 | 마법 데미지, 지팡이 요구치 |
| 건강 | HP/회복 |
| 감각 | 치명타/명중 |
| 통솔 | 파티 시너지 (리더 지정 시 통솔 비례 파티 버프 — 세부 미정) |
| 매력 | **비전투 전용** — 고용 비용 할인, 상점 가격, 파견 보너스 |

### 원칙

- **수동 스탯 분배 없음** — 자동 성장 (D2 교훈: 스탯 찍기는 정답이 정해진 가짜 선택)
- **스탯 기여 소, 장비 기여 대** — 감각(치명)·통솔(버프)처럼 장비 접사와 출처가 겹치는 축은 장비가 주도. 파워의 원천은 장비+스킬, 스탯은 원천/게이트
- 영웅은 파생 전투 수치(공격력/치명타%)를 직접 보유하지 않음 — 전투 수치 체계는 TheSevenRPG 계승 (item_design.md 참조)
- **히든 파라미터**: 스탯별 성장률·상한선 (비공개) — 같은 조합 영웅도 개체차 존재

## 5. 성장

- **레벨 + XP**: 전투 원정으로 획득. 레벨업 시 스킬 포인트 지급 + 스탯 자동 성장
- **전직 해금**: `[balance.csv:advance_unlock_level]` 도달 시 탭3 개방 — 방치형 마일스톤
- **파견 숙련**: 파견 유형별 독립 숙련, 하면서 자람 (Melvor 방식) — 벤치 영웅의 성장 축
- 스킬 상세: [skill_design.md](skill_design.md)

## 6. 시작특성

- TheSevenSimulation의 21종에서 선별/재정의 예정 (목록 미정)
- 원칙: RimWorld Trait식 다축 영향 — 단 "양념" 포지션. 핵심 파워를 담지 않는다
- 예시 방향: 호전적=물리뎀 소폭, 수집광=채집 파견 보너스, 행운아=드랍률 미세 보정, 낙천적=? (사기 시스템이 없으므로 재정의 필요)

## 7. 미탑재 (TheSevenSimulation에서 가져오지 않는 것)

- 사기(Morale)/폭주/구원, bonds(관계), 낮/밤·Stamina, 행동별 스탯 매핑(행동력 11종)
- 이유: 경영 시뮬 전제의 장치. 방치형 계약("자리 비워도 안전") 위반 리스크
