> 상태: 구조 확정 (2026-08-21) — **TheSevenRPG 아이템 코어를 통째로 계승**, 본 문서는 계승 범위와 변경점을 정의

> 상위 문서: [GAME_DESIGN.md](GAME_DESIGN.md) §5

## 1. 계승 원칙

TheSevenRPG의 아이템 시스템을 **기본값으로 계승**한다. 본 문서에 "변경"으로 명시되지 않은 것은 원본 설계를 따른다.
데이터(CSV)는 원본 meta_data를 복사 후 본 프로젝트 `src/data/`에서 독자 관리 (fork 후 분기).

## 2. 계승하는 구조 (원본 그대로)

### 슬롯/베이스
- **[변경 2026-08-21] 슬롯 8부위**: 무기 / 보조 / 투구 / 갑옷 / 장갑 / 신발 / 목걸이 / 반지
  - 원본은 5부위(무기/갑옷/투구/장갑/신발, `equipment_base.csv`) — **보조·목걸이·반지 3부위는 신규**
  - 양손 무기(양손검 등) 착용 시 **보조 슬롯 잠김** — 무기군 선택이 부위 하나를 거는 트레이드오프가 됨
  - ⚠ 파급: 접사 매트릭스가 7죄종 × **5**부위(prefix 35 / suffix 35)라 **신규 3부위는 죄종 접사가 없다.**
    공통 접사(`equipment_common_option.csv`)도 weapon/armor/helmet/gloves/boots 로만 태깅됨.
    → 세트포인트 최대치도 5 → 8로 바뀜 → **브레이크포인트 3/6/9로 확정** (§2 세트포인트 참조)
- **베이스 스탯 고정, 장비 레벨은 %옵션 롤 범위만 결정** — "레벨업이 아니라 굴림으로 강해진다" (D2 철학)
- 무기군 Implicit: 수치가 아니라 전투 규칙을 바꿈 (한손검=치명, 양손검=방무, 도끼=무Implicit 고데미지, 창=선제타, 둔기=경직)

### 희귀도 4단계 = 통제 가능성의 계단
```
매직(완전 RNG) → 레어(옵션 수↑) → 크래프트(낙인으로 죄종 지정) → 유니크(고정 효과)
```
- 일반(Normal) 등급 없음 — 필드 드롭 전부가 유의미
- 통제권이 올라갈수록 비용이 올라가는 일관 곡선

### 접사 시스템
- **7죄종 × 5부위 접사 매트릭스** (prefix/suffix, `equipment_prefix/suffix.csv`) — 신규 3부위는 미작성
- 지역(챕터) 죄종 접사 가중 편향 → 타겟 파밍 ("어느 지역을 도느냐 = 어떤 접사를 노리느냐")
- 죄종 성격의 메커니즘 번역 유지: 나태만 페널티 내장 접사, 폭식은 고수치, 오만은 최고 희소
- 한 장비에 같은 죄종 중복 금지 (장비당 죄종 최대 1포인트)

### 세트포인트
- 접사 1개 = 해당 죄종 1포인트, 브레이크포인트 **[변경 2026-08-21] 3/6/9** (3=상태이상, 6=조건부 패시브, 9=각성)
  - 근거: 8부위 확장으로 한 죄종 상한이 6→9 (장비 8 + 메인 죄종 1). 3/6/9 = 상한의 33/67/100% — 원작 2/4/6(상한 6)의 기하 보존
  - 각성(9) = 전 슬롯 올인 — 유니크(접사 0) 1개만 껴도 각성 포기 → "유니크 확실성 vs 각성 폭발력" 양자택일 축. 확정 달성 경로는 낙인 크래프팅
  - 이중 각성 구조적 불가 (9+9 > 총 공급 16 = 8부위×레어 접사 2) — 원작의 "각성은 하나" 불변식 유지
  - 값은 계승 CSV(`equipment_set_bonus.csv`) 무수정 — **신규 세트 테이블로 오버라이드** (무변환 원칙, G4 빈칸 작성과 통합)
- **[확정 2026-08-21] 양손 무기의 죄종 접사 = 2포인트** — 보조 슬롯 잠금 보상. 미보상 시 양손 영웅은 각성 도달 불가(7+1=8<9) → 무기 선택이 죄종 축을 침범
- 폭식 = 역방향 페널티 세트 ("과식하면 체한다") — **문턱 2→3 이동** (접사 공급 10→16 확대에 비례). 오만 = 9세트 각성만 (올 오어 낫씽)
- **[확정 2026-08-21]** 원본의 "베이직 죄종 선택 +1" 자리를 **영웅 메인 죄종 = 해당 죄종 세트포인트 +1**로 대체 → 영웅-아이템 궁합 축. 9세트 도달의 필수 경로

### 낙인(stigma)
- 챕터 보스 드롭 재료. 크래프팅 시 접사의 죄종 카테고리를 플레이어가 지정 — "통제권에 대한 프리미엄"

### 드롭 파이프라인
- 스폰 등급별 드롭롤 횟수 (일반 < 정예 < 스테이지보스 < 챕터보스)
- 카테고리 롤(Nodrop/골드/장비/기타) → 등급 판정(몬스터 레벨 선형) → 부위(몬스터 베이스별 편향) → 베이스 → 접사(지역 편향) → 수치 롤
- 유니크는 챕터 보스 전용 추가 판정
- 강화: 골드 소모로 접사 수치 증폭 (골드의 최종 소모처)

## 3. 변경점 (신규 프로젝트 결정)

| 항목 | 원본 | 변경 | 이유 |
|---|---|---|---|
| **코스트(장비 용량)** | 코스트 = 수평 제약, 전 슬롯 유니크 구조적 불가 | **폐지** | 복잡도 대비 효용 부족. 유니크 희소성은 드롭률이, 트레이드오프는 "유니크 = 접사 없음 → 세트포인트 0"이 대체. 전 슬롯 유니크는 막을 문제가 아니라 엔드게임 목표 |
| **착용 제약** | 요구 레벨 + 코스트 | **요구 스탯/레벨 게이트만** | 7스탯(힘/민첩/지능)이 무기·방어구 게이트 담당 |
| **유틸리티 접사** | 탐욕 접사(골드/드랍)만 | **유틸 축 확장** — 드랍률/골드/파견 시간 단축 등 소수 정예 | Lootun(Luck/Fortune/Wealth/Fate)·D2 MF 계보. "전투력 vs 파밍 효율" 스왑 결정 생성 |
| **무기군** | 5종 (한손검/양손검/도끼/창/둔기) | **지팡이·활 추가**(본편) + 단검·낫?(확장) + 직업별 무기군 배정 | 직업 7종 체계 — 본편 5+확장 2 (hero_design.md §4) |
| **접사 풀 순도** | — | 시뮬형 행동 보정(채집 효율 등)은 접사 풀에 **넣지 않음** | 접사 풀 희석 방지 (니즈 1) |
| **쿨타임 감소** | 없음 (원작에 스킬 체계 자체가 없음) | **신규 옵션 축 도입** | 스킬 쿨과 행동 주기의 **정렬 최적화 손잡이** ([battle_design.md](battle_design.md) §6). 정렬 재미가 장비 파밍으로 돌아옴 |

## 4. 스킬/영웅 시스템과의 접점 (신규)

- 죄종 트리(스킬 탭1)에 죄종 접사/세트 시너지 노드 배치 — 스킬과 아이템이 같은 죄종 축에서 만남
- 마스터리 트리(탭2)의 무기 숙련 ↔ 무기군 Implicit 연동
- **[확정 2026-08-21] 기본 공격은 무기군이 결정한다** — 액티브 스킬이 준비되지 않은 차례를 메우는 공격의 정체가 무기에서 나온다. 무기군 Implicit(창=선제타, 둔기=경직)이 전투에 직접 닿는 지점
- **[확정 2026-08-21] 지팡이의 기본 공격 = 마법 공격 수치 체계가 들어앉을 자리** — 계승 갭 G3(마법 공격 부재)의 해결 그릇
- **쿨감 옵션은 폭주하지 않는다** — 순차 발동이라 "한 차례에 스킬 하나"가 구조적 천장이고, 쿨감 이득이 그 지점에서 자연 체감한다. 숫자 캡 관리 불필요
- 영웅 파생 전투 수치는 전부 장비+스킬 출처 (스탯은 게이트/원천만) — 세부 전투 스탯 목록은 TheSevenRPG 축 계승 (명중/회피/공속/치명/방무/저항 등, 목록 확정 미정)
