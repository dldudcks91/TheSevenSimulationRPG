## 1. 계승하는 구조

### 슬롯 — 8부위 (원본 5부위에서 확장)

무기 / 보조 / 투구 / 갑옷 / 장갑 / 신발 / 목걸이 / 반지

- **양손 무기 착용 시 보조 슬롯 잠김** — 무기군 선택이 부위 하나를 거는 트레이드오프
- 베이스 스탯 고정, 장비 레벨은 %옵션 롤 범위만 결정 — "레벨업이 아니라 굴림으로 강해진다"
- 무기군 Implicit: 수치가 아니라 전투 규칙을 바꾼다 (한손검=치명, 양손검=방무, 도끼=고데미지, 창=선제타). 계승의 **둔기=경직은 무효** — 피격 경직 폐지 (battle_design.md §2, 08-25)

### 희귀도 4단계 = 통제 가능성의 계단

```
매직(완전 RNG) → 레어(옵션 수↑) → 크래프트(낙인으로 죄종 지정) → 유니크(고정 효과)
```

- 일반(Normal) 등급 없음 — 필드 드롭 전부가 유의미
- 통제권이 올라갈수록 비용이 올라가는 일관 곡선

### 접사

- 7죄종 × 부위 접사 매트릭스 (prefix/suffix)
- 지역(챕터) 죄종 드롭 편향 → 타겟 파밍
- 한 장비에 같은 죄종 중복 금지 (장비당 죄종 최대 1포인트)
- **접사는 기본 능력치를 주지 않는다** — 장비가 주는 것은 전투 능력치(`combat_stat.csv`)뿐 (§2)

### 세트포인트 — **보류** [2026-08-25]

"장비에 붙은 죄종 접사가 자동으로 세트포인트가 되어 세트효과를 낸다"는 구조는 **통째로 보류**한다. 접사의 죄종은 당분간 **접사 카테고리 · 지역 드롭 편향 · 낙인 지정의 축**으로만 쓴다. 설계해 둔 안은 §4에 보존 — 폐기가 아니다.

### 낙인(stigma)

챕터 보스 드롭 재료. 크래프팅 시 접사의 죄종을 플레이어가 지정 — "통제권에 대한 프리미엄".

### 드롭 파이프라인

스폰 등급별 드롭롤 횟수 (일반 < 정예 < 스테이지보스 < 챕터보스) → 카테고리 롤 → 등급 판정 → 부위 → 베이스 → 접사(지역 편향) → 수치 롤. 유니크는 챕터 보스 전용 추가 판정. 강화 = 골드 소모로 접사 증폭 (골드의 최종 소모처).

### 계승 CSV 조치 — `equipment_option_override.csv`

계승분은 읽기 전용이므로 오버라이드 테이블로 덮는다.

- `exclude` — 기본 능력치 접사(`str`/`dex`) · 코스트 감소 접사
- `replace_provisional` — 오만 `all_stats` → 잠정값 (장갑=치명타 피해, 신발=**상태이상 회복 속도** `fhr` — 상태이상 저항이 08-25 삭제되어 08-26 치환). sin_mapping.md 에서 정식 교체

## 3. 스킬/영웅 시스템과의 접점

- 죄종 트리(탭1)에 죄종 접사 시너지 노드 — 스킬과 아이템이 같은 죄종 축에서 만난다 (세트 시너지 노드는 §4와 함께 보류)
- 마스터리 트리(탭2)의 무기 숙련 ↔ 무기군 Implicit 연동
- **기본 공격은 무기군이 결정** — 무기군 Implicit이 전투에 직접 닿는 지점
- **무기군 = 액티브 슬롯 한 칸** — 착용 무기군이 스킬 종류를 준다 (skill_design.md §3). 무기 **개체**는 기본 공격에 기여하는 접사만큼만 스킬에 기여하고, 스킬 전용 파워 축을 갖지 않는다. 예외 후보는 유니크 무기뿐이며 "유니크 ≤ 잘 굴린 레어" 가드레일이 먼저다
- 장비가 기여하는 것은 **전투 능력치**(24종)뿐. 방향은 한쪽: 기본 능력치 → (계수) → 전투 능력치 (battle_design.md §8)
- 쿨감 옵션은 폭주하지 않는다 — 순차 발동이 구조적 천장이라 자연 체감

## 4. 보류 — 죄종 세트효과 (설계안 보존)

**[2026-08-25 보류]** 아래는 확정이 아니라 **보류된 설계안**이다. 다시 열 때 이 중에서 고르거나 새로 짠다. 보류 중에는 다른 문서가 세트포인트를 전제로 규칙을 세우지 않는다.

### 4-1. 공통 골격 (두 안 공통)

- 접사 1개 = 해당 죄종 1포인트 · 한 장비에 같은 죄종 중복 금지 (장비당 1포인트 — 양손 무기만 예외)
- 브레이크포인트 **3(상태이상 부여) / 6(조건부 패시브) / 9(각성)**
- **영웅 메인 죄종 = +1포인트** — 영웅-아이템 궁합 축, 9 도달의 필수 경로
- **양손 무기의 죄종 접사 = 2포인트** — 보조 슬롯 잠금 보상
- 폭식 = 역세트(문턱 3) · 오만 = 각성만 (올 오어 낫씽) → 오만은 3포인트 상태이상(심판)이 없어 "상태이상 7종 가위바위보"가 실제로는 6종이 되는 문제가 남아 있었다
- 값은 계승 CSV 무수정 — 신규 세트 테이블로 오버라이드
- 낙인(§1)으로 죄종을 지정하는 크래프트가 세트 완성의 통제 경로

### 4-2. 안 A — 슬롯 8 · 상한 9 [08-21]

- 상한 9 = 장비 8 + 메인 죄종 1
- 각성(9) = 전 슬롯 올인 — 유니크(접사 0) 1개만 껴도 각성 포기 → **"유니크 확실성 vs 각성 폭발력" 양자택일**. 이중 각성 구조적 불가

### 4-3. 안 B — 슬롯 9(반지 ×2) · 상한 10 [08-25]

- 상한 10 = 장비 9 + 메인 죄종 1 (양손: 8슬롯 × 1 + 무기 2 + 1 = 10 — 한손/양손 상한 동일)
- 각성(9) 뒤 **자유 슬롯 1** → **유니크 1개와 각성이 양립**. 트레이드오프가 "유니크 vs 각성"에서 "유니크는 최대 1개"로 이동
- 열린 질문: 각성 빌드가 "최고 유니크 1 + 죄종 8"로 정답 수렴하지 않는가
