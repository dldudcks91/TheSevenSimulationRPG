## 1. 계승하는 구조

### 슬롯 — 부위 8종 · 착용 위치 9개 (원본 5부위에서 확장) [확정 2026-08-25]

주무기 / 보조무기 / 투구 / 갑옷 / 장갑 / 신발 / 목걸이 / **반지 ×2**

- **드롭은 부위 단위** — 반지는 착용 **위치**가 둘일 뿐 부위는 하나다. 착용 위치 9 는 세트포인트 상한 논쟁(§4-2)에서 나왔지만 **그와 독립으로 확정**이고 세트 폐기에 딸려 가지 않는다
- **양손 무기 착용 시 보조 슬롯 잠김** — 무기군 선택이 부위 하나를 거는 트레이드오프
- 베이스 스탯 고정, 장비 레벨은 %옵션 롤 범위만 결정 — "레벨업이 아니라 굴림으로 강해진다"
- 무기군 Implicit: 수치가 아니라 전투 규칙을 바꾼다 (한손검=치명, 양손검=방무, 도끼=고데미지, 창=선제타). 계승의 **둔기=경직은 무효** — 피격 경직 폐지 (battle_design.md §2, 08-25)

### 희귀도 4단계 = 통제 가능성의 계단

```
매직(완전 RNG) → 레어(옵션 수↑) → 크래프트(옵션을 고정해서 제작) → 유니크(고정 효과)
```

- 일반(Normal) 등급 없음 — 필드 드롭 전부가 유의미
- 통제권이 올라갈수록 비용이 올라가는 일관 곡선
- **크래프트는 드롭 등급이 아니라 제작의 결과다** [확정 2026-08-26] — 필드 굴림은 매직·레어까지고, 크래프트는 제련소에서 **특정 옵션을 고정해서** 만든다. 그중 죄종을 지정하는 수단이 낙인. 재료는 §5
- ⚠ **"옵션이 아니라 스킬을 고정한다"는 안은 미확정** — §3 의 "무기 개체는 스킬 전용 파워 축을 갖지 않는다(예외 후보는 유니크 무기뿐)"와 정면으로 부딪힌다. 열려면 그 가드레일부터 다시 연다

### 접사

- 7죄종 × 부위 접사 매트릭스 (prefix/suffix)
- 지역(챕터) 죄종 드롭 편향 → 타겟 파밍
- 한 장비에 같은 죄종 중복 금지 — **장비당 같은 죄종 최대 1개**. 세트 폐기로 "포인트"라는 통화는 소멸했고(§4-1), 중복 금지만 접사 규칙으로 존치한다
- **접사는 기본 능력치를 주지 않는다** — 장비가 주는 것은 전투 능력치(`combat_stat.csv`)뿐 (§2)

### 세트포인트 — **폐기** [2026-08-26]

"장비에 붙은 죄종 접사가 자동으로 세트포인트가 되어 세트효과를 낸다"는 구조를 **닫는다**. 08-25 보류를 해제하지 않고 폐기한 것이다 — 자동 발현은 장비 한 칸을 바꿀 때마다 9슬롯 전체를 재계산하게 만들어 **복잡도가 디폴트**가 된다. 접사의 죄종이 하는 일은 **접사 카테고리 · 지역 드롭 편향 · 낙인 지정** 셋 그대로다.

**그 자리는 전술카드가 가져간다** — 조건 → 효과 카드 한 장이 접사 죄종을 **센다**. 복잡도가 플레이어의 선택(카드를 꽂는다)이 되고, 안 꽂으면 장비 선택은 순수 스탯 비교로 남는다. 설계 자산은 §4에 보존 — 이관이지 내용물 폐기가 아니다. → [tactic_card_design.md](tactic_card_design.md)

### 낙인(stigma)

챕터 보스 드롭 재료. 크래프팅 시 접사의 죄종을 플레이어가 지정 — "통제권에 대한 프리미엄".

- **소모처는 둘** [2026-08-26] — 크래프트(죄종 지정) · **전술카드**. 공급은 챕터 보스 하나뿐이라 **공급량은 아이템 쪽에서 잠그고 전술카드는 그 예산을 나눠 쓴다** (§5-1)

### 드롭 파이프라인

스폰 등급별 드롭롤 횟수 (일반 < 정예 < 스테이지보스 < 챕터보스) → 카테고리 롤 → 등급 판정 → 부위 → 베이스 → 접사(지역 편향) → 수치 롤. 유니크는 챕터 보스 전용 추가 판정. 강화 = 골드 소모로 접사 증폭 (골드의 최종 소모처). 제작·강화가 먹는 자원 전체는 **§5**.

### 2-1. 접사의 ilvl 스케일링 [개정 2026-08-26 — 수치 대역 재설계]

접사가 ilvl 로 어떻게 커지는지는 **접사마다 다르다.** battle_design.md §9-0 의 세 분류를 그대로 따른다.

| 분류 | 스케일링 | 해당 접사 |
|---|---|---|
| **성장 축** | 굴림 × `[balance.csv:power_growth_per_level]` ^ (ilvl − 1) | 공격력 flat · HP flat |
| **비율 축** | 굴림 + ilvl × 완만한 계수 | 물리 방어 flat |
| **곡선 밖** | **ilvl 과 무관** — 굴림 범위 그대로 | 모든 % 접사 · 치명 확률/피해 · 공속 · 흡혈 · 방어 무시 · 저항 · 유틸 |

- **% 접사에서 ilvl 가산(`perIlvl`)을 전부 제거했다** — 밑수가 이미 기하로 자라는데 % 까지 ilvl 로 커지면 곱셈층이 두 번 자라 후반이 폭주한다. % 는 "이 챕터 안에서 얼마나 더 센가"만 표현한다
- **저항 접사는 곡선 밖 + 직접 %** — `res_all` 과 원소별 4종. 상한이 목표라 값이 자랄 이유가 없다 (battle_design.md §9-5)
- **무기 공격력·방어구 고유값은 접사가 아니라 개체 굴림** — 드롭 시 편차 폭으로 한 번 굴려 개체에 박힌다 (§2 표)

## 3. 스킬/영웅 시스템과의 접점

- **죄종 마스터리**에 죄종 접사 시너지 노드 — 스킬과 아이템이 같은 죄종 축에서 만난다. 세트포인트 기반 노드는 세트효과 폐기와 함께 소멸했고, 스킬이 **전술카드 조건을 미는** 방향으로 재정의된다 (tactic_card_design.md §3)
- **직업 마스터리**의 무기 숙련 ↔ 무기군 Implicit 연동 (무기 숙련의 귀속은 미결 — skill_design.md §7)
- **기본 공격은 무기군이 결정** — 무기군 Implicit이 전투에 직접 닿는 지점
- **무기군 = 액티브 3 중 한 칸** — 착용 무기군이 스킬 종류를 준다 (skill_design.md §2). 「슬롯」 개념은 08-26 폐기. 무기 **개체**는 기본 공격에 기여하는 접사만큼만 스킬에 기여하고, 스킬 전용 파워 축을 갖지 않는다. 예외 후보는 유니크 무기뿐이며 "유니크 ≤ 잘 굴린 레어" 가드레일이 먼저다
- 장비가 기여하는 것은 **전투 능력치**뿐. 방향은 한쪽: 기본 능력치 → (계수) → 전투 능력치 (battle_design.md §8)
- 쿨감 옵션은 폭주하지 않는다 — 순차 발동이 구조적 천장이라 자연 체감

## 4. 이관 — 죄종 세트효과 → 전술카드 (설계 자산 보존)

**[2026-08-26 이관]** 08-25 에 보류했던 죄종 세트효과를 **전술카드로 옮긴다**. 폐기한 것은 **자동 발현 구조**(접사 = 세트포인트)이고, 아래 설계 자산은 카드 인스턴스의 재료로 남는다. 결정의 근거·원칙은 [tactic_card_design.md](tactic_card_design.md), 여기는 **아이템 쪽에서 무엇이 어떻게 됐는지**만.

### 4-1. 공통 골격 — 무엇이 살고 무엇이 죽나

| 규칙 | 상태 |
|---|---|
| 브레이크포인트 **3 / 6 / 9** | **산다** — 카드 조건의 계단 재료. 단 이진 문턱은 "9개에서 멈춘" 구간이 길어 계단형으로 (tactic_card_design.md §3) |
| 죄종별 성격 (폭식 = 역세트 · 오만 = 올 오어 낫씽) | **산다** — 개별 카드의 성격으로. 카드는 7×3 매트릭스를 채울 의무가 없어 오만의 3포인트 공백 문제가 소멸 |
| **영웅 메인 죄종 = +1포인트** | **죽는다 → 조건으로** 부활. 포인트 우회 없이 "메인 죄종이 분노인 영웅이 분노 접사 N개를 들면" |
| 접사 1개 = 1포인트 · 한 장비에 같은 죄종 중복 금지 | 중복 금지는 **접사 규칙으로 존치**(§1). "포인트"라는 통화는 소멸 — 카드는 접사 개수를 직접 센다 |
| **양손 무기의 죄종 접사 = 2포인트** | **죽는다** — 보조 슬롯 잠금 보상은 무기군 3축(피해 편차 · 행동 주기 · 한손/양손)이 담당 |
| 값은 계승 CSV 무수정 — 신규 세트 테이블로 오버라이드 | **신규 카드 테이블**로 대체. 계승 `equipment_set_bonus.csv` 는 안 건드린다 (CLAUDE.md 규칙 3) |
| 낙인(§1)으로 죄종을 지정하는 크래프트 = 완성 경로 | **산다** — 카드 조건을 채우는 통제 경로가 그대로 낙인이다 |

### 4-2. 소멸한 논쟁 — 안 A / 안 B (기록)

세트포인트 상한 논쟁(안 A: 슬롯 8·상한 9 / 안 B: 슬롯 9·상한 10)은 **포인트가 장비 슬롯 수에 묶여 있어서** 생긴 문제였다. 카드 조건은 접사를 직접 세므로 슬롯 수와 독립이고, 선택 자체가 사라진다.

- 안 B 의 열린 질문("각성 빌드가 최고 유니크 1 + 죄종 8 로 정답 수렴하지 않는가")도 함께 소멸 — 카드 여러 장이 서로 다른 조건으로 경쟁하면 단일 정답이 안 선다
- **다만 잃은 것 하나** — 안 A 의 **"유니크 확실성 vs 각성 폭발력" 양자택일**은 세트가 슬롯을 먹어서 성립했던 좋은 긴장이었다. 카드는 슬롯을 안 먹으므로 **약해진다**(접사 칸 압력은 남으므로 소멸은 아니다). 대체 손잡이는 카드 슬롯 수 — tactic_card_design.md §3-1

### 4-3. 세트에 걸려 있던 다른 규칙 — 이관 결과

| 규칙 | 원래 위치 | 이관 후 |
|---|---|---|
| 세트 3포인트 = 상태이상 부여 (영웅→몬스터 경로) | story_chapter_design.md §3 | **카드 효과로** — 영웅 측 부여 경로가 여기서 살아난다 (효과 정의는 미확정) |
| 죄종 트리의 세트 시너지 노드 ("세트포인트당 …") | skill_design.md §2 | **소멸** — 스킬이 카드 조건을 미는 방향으로 재정의 |
| 메인 죄종 +1 (영웅-아이템 궁합) | hero_design.md §3 · GAME_DESIGN.md §6 | **카드 조건으로** (§4-1) |
| 코스트 폐지 근거의 "접사 없음 → 세트포인트 0" | §2 | 근거만 제거 — 코스트 폐지 자체는 유지 |

### 4-4. 아이템 쪽에 남는 숙제

- **죄종 접사를 읽는 카드는 초반에 확보 가능해야 한다** — 세트는 장비 교체만으로 자동으로 켜졌지만, 카드는 없으면 접사 죄종이 다시 카테고리 라벨로만 남는다. 해금 시점이 늦으면 게임의 3/4 동안 죄종 접사가 죽어 있다
- **접사 죄종 카운터를 화면이 세줘야 한다** — 안 보이면 조건이 함정이 된다 (SCREEN_DESIGN.md §6 캐릭터 탭 · 편성 화면 양쪽)
- **유니크 vs 레어 긴장** — 세트효과 보류로 드롭률 하나뿐이던 상태가 이관으로 해소되지 않았다. 카드가 접사 카운트를 조건으로 쓰면 접사 0 인 유니크가 다시 불리해질 수 있어, 카드 조건 언어를 정할 때 함께 본다 (skill_design.md §3 의 유니크 무기 예외 가드레일과 한 묶음)

## 5. 자원 — 아이템 층이 먹는 것 [2026-08-26]

> 아이템이 무엇으로 만들어지고 무엇으로 강해지는가. 공급처의 상세는 [base_expedition_design.md](base_expedition_design.md), 여기는 **아이템 쪽 소모처** 기준으로 적는다.

### 5-1. 확정된 자원

| 자원 | 층 | 출처 | 아이템 쪽 소모처 |
|---|---|---|---|
| **골드** | 증폭 | 원정 정산 | **강화** — 접사 증폭 (골드의 최종 소모처, §1) |
| **광석** | 틀·양 | 파견(광산) | **크래프트 제작**의 바탕 |
| **낙인** | 지정 | 챕터 보스 | **크래프트**(죄종 지정) · **전술카드** |
| **몬스터 카드** | 기록 | 원정(처치) | 없음 — 도감 전용이고 소모하지 않는다 (monster_design.md §8) |

- **광석이 파견에서만 온다는 것이 컨셉 락과 정렬한다** — 꺼 두면 재료가 쌓이고, 켜서 제련소에서 써야 장비가 된다. 크래프트 처리량을 쥐는 것은 광산에 **배치된 영웅**이다 — 파견처에 레벨이 없으므로 세기를 미는 축은 배치 하나다 (base_expedition_design.md §2-1)
- **낙인 공급량은 아이템 쪽에서 잠근다** — 챕터 보스 = 유한 공급인데 소모처가 둘이다. 전술카드는 이 예산을 **나눠 쓰는 쪽**이고 자기 공급원을 따로 갖지 않는다 (§1 낙인)

### 5-2. 규칙 — 소모처 없는 자원은 만들지 않는다

새 컨텐츠가 생기면 **기존 자원으로 표현되는지 먼저 검증**하고, 안 될 때만 자원을 판다. 자원을 정의하는 것은 공급이 아니라 **소모처**다 (CLAUDE.md 철학 3 — 단순화가 정답).

> 반례가 이미 하나 있다 — **가루**는 이 규칙 없이 생겨서, 정예·보스 처치와 분해 두 경로로 쌓이는데 **소모처가 0**이고 기획서에 정의도 없다 (`balance.csv` 의 `dust_*` · `salvage_dust_*` 전부 ⚠제안값). §5-3 에서 함께 푼다

### 5-3. 미확정

| 항목 | 상태 |
|---|---|
| **몬스터별 재료** | 만들지 여부부터 미정. 단위 후보는 **몬스터 베이스**(`monster.csv` 의 이름 단위는 재료 창고에서 니즈 1 이 재발한다 — 베이스 단위는 챕터를 넘어 재등장하므로 초반 재료가 안 죽는다). 채택하면 **몬스터 카드와 통합할지**가 딸려 온다 — monster_design.md §8 이 "카드의 소모처는 후속"으로 훅을 남겨 뒀다 |
| **가루의 정체** | 몬스터 재료 결정에 물려 있다. 채택하면 가루는 **분해 전용**으로 축소되고, 안 하면 가루가 처치 재료 자리를 계속 든다. 어느 쪽이든 「아이템 정리」(분해 UI)와 함께 확정한다 |
| **크래프트 가드** — 원정 없이 제작이 성립하는가 | **미해결.** 지금 크래프트 입력은 광석(파견) + 낙인(보스)뿐이라 **원정 없이 성립해 버린다.** 몬스터 재료를 채택하면 그것이 원정 쪽 입력이 되어 별도 규칙 없이 구조에서 풀린다 (GAME_DESIGN.md §10) |
| **지정재가 두 일을 겸한다** | 낙인이 죄종 지정과 옵션 고정을 함께 맡으면 "통제권이 오를수록 비용이 오른다"(§1)는 곡선이 한 칸에서 접힌다. 지정재를 둘로 나눌지는 전술카드 쪽과 함께 본다 |
