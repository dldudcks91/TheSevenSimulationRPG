## 1. 계승하는 구조

### 슬롯 — 8부위 (원본 5부위에서 확장)

무기 / 보조 / 투구 / 갑옷 / 장갑 / 신발 / 목걸이 / 반지

- **양손 무기 착용 시 보조 슬롯 잠김** — 무기군 선택이 부위 하나를 거는 트레이드오프
- 베이스 스탯 고정, 장비 레벨은 %옵션 롤 범위만 결정 — "레벨업이 아니라 굴림으로 강해진다"
- 무기군 Implicit: 수치가 아니라 전투 규칙을 바꾼다 (한손검=치명, 양손검=방무, 도끼=고데미지, 창=선제타, 둔기=경직)

### 희귀도 4단계 = 통제 가능성의 계단

```
매직(완전 RNG) → 레어(옵션 수↑) → 크래프트(낙인으로 죄종 지정) → 유니크(고정 효과)
```

- 일반(Normal) 등급 없음 — 필드 드롭 전부가 유의미
- 통제권이 올라갈수록 비용이 올라가는 일관 곡선

### 접사

- 7죄종 × 부위 접사 매트릭스 (prefix/suffix)
- 지역(챕터) 죄종 드롭 편향 → 타겟 파밍
- 한 장비에 같은 죄종 중복 금지 (장비당 죄종 최대 1포인트)
- **접사는 기본 능력치를 주지 않는다** — 장비가 주는 것은 전투 능력치(`combat_stat.csv`)뿐 (§2)

### 세트포인트 — 3/6/9

- 접사 1개 = 해당 죄종 1포인트. 브레이크포인트 **3(상태이상) / 6(조건부 패시브) / 9(각성)**
- 상한 9 = 장비 8 + **영웅 메인 죄종 +1** (영웅-아이템 궁합 축, 9세트 도달의 필수 경로)
- **양손 무기의 죄종 접사 = 2포인트** — 보조 슬롯 잠금 보상
- 각성(9) = 전 슬롯 올인 — 유니크(접사 0) 1개만 껴도 각성 포기 → "유니크 확실성 vs 각성 폭발력" 양자택일. 이중 각성은 구조적 불가
- 폭식 = 역세트(문턱 3), 오만 = 각성만 (올 오어 낫씽)
- 값은 계승 CSV 무수정 — 신규 세트 테이블로 오버라이드

### 낙인(stigma)

챕터 보스 드롭 재료. 크래프팅 시 접사의 죄종을 플레이어가 지정 — "통제권에 대한 프리미엄".

### 드롭 파이프라인

스폰 등급별 드롭롤 횟수 (일반 < 정예 < 스테이지보스 < 챕터보스) → 카테고리 롤 → 등급 판정 → 부위 → 베이스 → 접사(지역 편향) → 수치 롤. 유니크는 챕터 보스 전용 추가 판정. 강화 = 골드 소모로 접사 증폭 (골드의 최종 소모처).

## 2. 변경점

| 항목 | 원본 | 변경 | 이유 |
|---|---|---|---|
| **코스트(장비 용량)** | 수평 제약 | **폐지** | 유니크 희소성은 드롭률이, 트레이드오프는 "접사 없음 → 세트포인트 0"이 대체 |
| **착용 제약** | 요구 레벨 + 코스트 | **요구 레벨만** | 요구 능력치 게이트도 폐지 — 무기군 선택은 직업이 담당 (hero_design.md §4) |
| **기본 능력치 접사** | `str`/`dex` 공통옵션 + `all_stats` | **전면 폐지** | 장비가 능력치를 주면 개체차·파견 배치 결정이 붕괴 (hero_design.md §4-2) |
| **유틸리티 접사** | 탐욕 접사만 | **유틸 축 확장** — 드랍률/골드/파견 시간 단축 | "전투력 vs 파밍 효율" 스왑 결정 생성 (Lootun·D2 MF 계보) |
| **무기군** | 5종 (전부 물리 근접) | **지팡이·활 추가**(본편) + 단검(확장) | 직업 7종 체계. 지팡이 = 마법 공격 체계의 그릇 |
| **쿨타임 감소** | 없음 | **신규 옵션 축** | 스킬 쿨과 행동 주기의 정렬 최적화 손잡이 (battle_design.md §6) |
| **접사 풀 순도** | — | 시뮬형 행동 보정(채집 효율 등)은 접사 풀에 **넣지 않음** | 접사 풀 희석 방지 (니즈 1) |

### 계승 CSV 조치 — `equipment_option_override.csv`

계승분은 읽기 전용이므로 오버라이드 테이블로 덮는다.

- `exclude` — 기본 능력치 접사(`str`/`dex`) · 코스트 감소 접사
- `replace_provisional` — 오만 `all_stats` → 잠정값 (장갑=치명타 피해, 신발=상태이상 저항). sin_mapping.md 에서 정식 교체

## 3. 스킬/영웅 시스템과의 접점

- 죄종 트리(탭1)에 죄종 접사/세트 시너지 노드 — 스킬과 아이템이 같은 죄종 축에서 만난다
- 마스터리 트리(탭2)의 무기 숙련 ↔ 무기군 Implicit 연동
- **기본 공격은 무기군이 결정** — 무기군 Implicit이 전투에 직접 닿는 지점
- 장비가 기여하는 것은 **전투 능력치**(27종)뿐. 방향은 한쪽: 기본 능력치 → (계수) → 전투 능력치 (battle_design.md §8)
- 쿨감 옵션은 폭주하지 않는다 — 순차 발동이 구조적 천장이라 자연 체감
