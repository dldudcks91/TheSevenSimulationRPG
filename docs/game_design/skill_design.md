## 0. 확정 [2026-08-26 — 전면 개정]

**"3탭 트리 + 액티브 슬롯 3" 구조를 닫고, 마스터리 2층 + 전직 특화로 재편한다.**

| 폐기 | 대체 |
|---|---|
| **슬롯**이라는 개념 | **액티브 3** — 출처가 셋이고 각 출처가 하나씩 준다. 편성할 게 없으므로 시스템 이름을 지운다 (§2) |
| 액티브 첫 칸 = **죄종** | 첫 칸 = **영웅 고유 스킬** (hero_design.md §1). 레어 영웅도 공용 풀에서 1개 배정받는다 |
| 트리 안의 **액티브 킷** | 액티브는 **트리 밖**에서 온다 — 고유 · 무기군 · 전직. 트리는 강화·숙련·시너지만 (§3) |
| "3택1 같은 선택 없음 — 개성은 배분" | **자유 롤백** 도입으로 폐기. 개성의 출처는 **굴림 + 장비 + 고유 스킬** (§5) |
| "배분(트리)과 편성(슬롯)의 분리" | 자유 롤백이면 배분 = 편성이다. 두 개념이 합쳐진다 (§5) |
| 탭1 = 죄종 **트리**(고유 메커니즘) | 탭1 = 죄종 **마스터리** — 액티브 없음. 축은 §3-1 |

### 왜 — 슬롯이 하던 일이 사라졌다

슬롯의 존재 근거는 하나였다: **상한이 없으면 트리 배분이 "다 찍기"로 수렴한다.** 액티브를 트리 밖으로 빼면 트리에 액티브 노드가 없으므로 그 수렴이 원천에서 사라진다. 출처가 고정이고 각 출처가 하나씩 주면 편성할 것도 남지 않는다.

남는 것은 **동시 준비 시 우선순위**뿐인데, 그건 발동 규칙의 동률 결정자(battle_design.md §3)이지 슬롯이 아니다.

| §4 전직 = **사건 하나** · 「3택1이 아니다」 | **전직 3갈래 신설** — 직업마다 셋 중 하나를 고른다. 3택1의 대상이 액티브가 아니라 **전직**이 된다 (§4) |

## 1. 액티브와 패시브 [신설 2026-08-27 — 층 분리]

### 1-1. 무엇으로 가르는가 — 기준 셋

| 기준 | **액티브** | **패시브** |
|---|---|---|
| **행동 주기를 먹는가** | **먹는다** — 비용은 행동 1회 (battle_design.md §3) | 안 먹는다 |
| **화면에 사건으로 보이는가** | **보인다** — 로그 · 이펙트 · 쿨 게이지 | 안 보인다 (반응 패시브는 발동 순간만) |
| **파워 예산을 재는 자** | `(배율 − 1) ÷ N` — §9-1 규칙 1 | 공식의 덧셈 항에 얹힌다 |

> **액티브 = 무엇을 하는가** (때린다 · 회복한다 · 건다)
> **패시브 = 어떻게 되어 있는가** (숫자가 얼마다 · 무슨 일이 저절로 일어난다)

두 번째 기준이 이 게임에서 특히 무겁다 — **조작이 없으므로 플레이어가 인과를 읽는 창구는 관전 화면뿐**이다(CLAUDE.md 철학 2). 화면에 사건으로 나타나지 않는 것은 패시브다.

### 1-2. 패시브는 둘이다

| | **수치 패시브** | **반응 패시브** |
|---|---|---|
| 형태 | 상시 — 항상 켜져 있다 | **「~하면 ~한다」** — 사건에 반응한다 |
| 예 | 상시 피해 % · 최대 HP · 저항 · 행동 주기 | 처치 시 쿨 초기화 · 명중 시 창 · 저체력 시 강화 · 타격마다 누적 · 흡혈 · 반사 |
| 공식에서 | 항에 **더한다** (`combat_stat.csv`) | 항에 안 들어간다 — **이벤트에 붙는다** |
| 화면 | 안 보인다 | **발동 순간 보인다** |
| 예산 | 덧셈이라 재기 쉽다 | **재기 어렵다** — 발동 빈도에 종속 |

**흩어져 있던 것이 전부 반응 패시브였다** — 액티브 라이더(참수의 쿨 초기화 · 응징의 자기 창) · 정예 특성(격분 · 탐식 · 도박) · 죄종 「라인 밖」(흡혈 · 반사 · 재생) · 장비 접사(`crushing_blow` · `counter_dmg`). 네 군데에 다른 이름으로 있던 것이 하나의 개념이다.

### 1-3. 반응 패시브의 자리 — 마스터리 트리의 깊은 노드 [확정 2026-08-27]

**얕은 노드 = 수치 패시브 / 깊은 노드 = 반응 패시브.**

- **새 층을 만들지 않는다** — 별도 패시브 슬롯을 세우면 §0 이 방금 지운 「슬롯」 개념이 되살아난다. 단순화 원칙(CLAUDE.md 철학 3)
- **트리에 목표가 생긴다** — 「다 찍기」가 아니라 **「어디까지 파는가」**가 된다. 자유 롤백(§5)으로 배분이 개성을 잃은 자리를, 깊이가 대신 메운다
- **굴림·장비로도 온다** — 고를 수 없는 반응 패시브는 장비 접사 · 영웅 고유 · 몬스터 정예 특성에 딸려 온다. 고르는 것(트리)과 굴리는 것(장비)이 나뉜다
- ⚠ **예산 자가 아직 없다** — 반응 패시브는 발동 빈도에 파워가 종속되어 `skill_dps_budget_pct` 로 못 잰다. 자를 세우는 것은 §7

### 1-4. 전체 구조

```
[분노][마법사] 영웅:

액티브 3  ── 고유 · 무기군 · 전직          (§2)  ※ 행동 1회를 먹는다

패시브
  마스터리 (1레벨~)   ├── 직업 마스터리 — 마법사   : 내 숫자를 키운다
                      └── 죄종 마스터리 — 분노     : 그 숫자가 닿는 방식을 바꾼다
                           ※ 포인트 풀 공유 · 액티브 없음
                           ※ 얕은 노드 = 수치 / 깊은 노드 = 반응 (§1-3)

  전직     (전직~)    └── 3갈래 중 택1 — 고른 전직의 액티브 각각이 트리의 뿌리
                           ※ 전용 포인트 (§4)

  굴림     └── 장비 접사 · 영웅 고유 — 고를 수 없다
```

- 마스터리 둘은 **영웅 생성 시 확정**된다 — 직업도 죄종도 굴림/고정이고 바꿀 수 없다. 플레이어의 결정은 **어디에 몰았나**뿐
- 전직 해금: `[balance.csv:advance_unlock_level]`

## 2. 액티브 3 — 출처 고정, 각 출처가 하나

**슬롯이 아니다.** 배운 것 중 셋을 고르는 게 아니라, 출처가 셋이고 각각이 하나씩 준다.

| 칸 | 출처 | 바뀌는 조건 |
|---|---|---|
| **고유** | 영웅 자신 (hero_design.md §1) | 안 바뀐다 — 영웅에 박혀 있다 |
| **무기군** | 착용 무기군 (`weapon_group.csv`) | **무기를 바꾸면 바뀐다** |
| **전직** | 전직이 준 3개 중 주력 | 배분으로 정해지고, 롤백으로 바꾼다 (§4) |

- **전투에서 결정을 내리는 칸은 전직 하나다.** 고유는 박혀 있고 무기군은 장비가 정한다. 결정을 흩뿌리지 않고 한 곳에 모은 것이 이 구조의 의도
- 전직 해금 전엔 **고유 + 무기군 2칸**으로 돈다. 그 구간의 재미는 스킬이 아니라 **장비 파밍 + 챕터 해금**이 담당한다 (기능 해금 게이트 = 챕터 클리어 — GAME_DESIGN.md §10)
- 우선순위(동시 준비 시 어느 것 먼저)는 플레이어가 정한다 — 무료 · 수시. 발동 규칙은 battle_design.md §3
- 쿨 설계 지침: 하한은 `행동 주기 × 3` 근처 (battle_design.md §6)
- **몬스터는 2칸이다** [초안 2026-08-27] — 무기군도 전직도 없으므로 **고유 + 직업** 둘. 억지로 맞춘 게 아니라 출처 구조에서 떨어진다. 영웅보다 하나 적은 것은 **개체 수**(`round_budget.csv` 편성 1~3)로 갚는다. 몬스터 쪽 정의는 [monster_design.md](monster_design.md) 소관이고 미확정분은 §7

### 2-1. 무기군 스킬 — 무기군에 붙고, 개체에 붙지 않는다

- **무기군이 스킬의 종류를 정하고, 세기는 정하지 않는다.** 흰 도끼든 레어 도끼든 도끼 스킬은 같다. 세기 = 마스터리 배분 + 전투 능력치. 무기 개체의 접사는 기본 공격에 기여하는 만큼만 스킬에 기여하고, **스킬 전용 파워 축을 갖지 않는다**
- 왜: "운 좋게 먹은 무기 하나"가 스킬을 주는 일이 없어야 한다. 무기군은 직업 전속 범위 안의 **선택**이지 드롭 운이 아니다
- **"옵션 vs 스킬" 결정이 성립하려면 조건이 하나 붙는다** [08-26] — 같은 직업 안에서 **무기군 간 DPS 가 균형**이어야 한다. 무기가 밑수(battle_design.md §9-1)라 공격력 격차가 스킬 차이를 압도하면, 무기군 스킬은 결정이 아니라 장비 선택의 종속 결과가 된다. hero_design.md §2 의 "무기군은 피해 편차 · 행동 주기 · 한손/양손 3축으로 차별화"가 이 조건과 같은 말이다. 무기군 베이스 데이터가 아직 0행이라 **미검증**
- 비교 UI 필요 — 실효 쿨(battle_design.md §6)에 더해 **무기군 스킬 비교**가 화면에 있어야 결정이 성립한다 (SCREEN_DESIGN.md)
- 예외 후보는 **유니크 무기**뿐(스킬 교체/변형). 허용하려면 "유니크 ≤ 잘 굴린 레어" 가드레일을 아이템 쪽에 먼저 세운다 (item_design.md §4-4)
- 규칙형(선제타 등)은 무기군 Implicit과 같은 이유로 진형·타겟팅 확정 전엔 못 짠다 — 수치형(다단타·피해 편차·행동 주기 활용)부터

## 3. 마스터리 — 축 분담은 피해 공식에서 나온다

두 탭이 왜 둘인가에 대한 답. 성격이 아니라 **공식의 자리**로 가른다.

```
[1] 기본 공격력 = 능력치계수 × 무기 공격력 × ( 1 + Σ 상시 % )      ← 직업
[2] 타격 피해   = [1] × 스킬 배율 × 치명 배수 × ( 1 + Σ 조건부 % )  ← 죄종
[3] 최종 피해   = [2] × ( 1 − 감소 ) × Π ( 1 − 피해 감소 )
                         ↑ 내 방어 = 직업 / 적의 방어를 깎는 것 = 죄종
    라인 밖      흡혈 · 반사 · 재생 · 상태이상 · 드롭 · 골드         ← 죄종
```

> **직업은 내 숫자를 키우고, 죄종은 그 숫자가 상대에게 닿는 방식을 바꾼다.**

| 탭 | 담당 | 얕은 노드 (수치 패시브) | 깊은 노드 (반응 패시브) |
|---|---|---|---|
| **직업 마스터리** | [1] 과 [3] 의 내 쪽 | 무기군 숙련 · 방어구 숙련 · 상시 피해 % · 최대 HP · 물리 방어 · 원소 저항 · 행동 주기 | 「피격하면 ~」 · 「처치하면 ~」 계열 |
| **죄종 마스터리** | [2] · [3] 의 적 쪽 · 라인 밖 | 조건부 % · 방어 무시 · 저항 감소 · 흡혈 · 반사 · 재생 · 드랍률 · 골드 | 죄종의 성격을 사건으로 표현한 것 (§3-1) |

- **깊은 노드가 반응 패시브다** [2026-08-27] — 얕은 곳은 숫자를 올리고, 깊은 곳은 **사건에 반응하는 규칙**을 준다 (§1-3). 트리의 목표가 「다 찍기」가 아니라 「어디까지 파는가」가 되는 자리
- **곱의 항은 마스터리가 뿌리지 않는다** [2026-08-27] — 위 표에서 **치명 배수가 빠졌다**. `[2]` 에서 치명 배수는 **곱**이라 다른 모든 것과 곱해진다. 덧셈 항(상시 % · 조건부 %)은 여러 출처에서 풀어도 합이 완만하지만, 곱은 하나만 풀려도 전체가 튄다. 그래서 **치명 배수의 출처는 아낀다** — 후보는 유니크 아이템 · 낙인 크래프트(item_design.md §3). 치명 **확률**은 배수가 잠겨 있으면 기대값이 선형이라 상대적으로 풀어도 안전하다(자리는 §7). D2 가 Deadly Strike 의 배수를 고정하고 확률만 쌓게 한 것과 같은 처리
- **새 괄호·새 곱셈 층을 만들지 않는다** — 노드는 전부 `combat_stat.csv` 의 기존 수치에 더한다 (battle_design.md §9-2 "괄호는 둘뿐")
- **전술카드와 겹치지 않는다** — 카드는 파티 단위 「조건 → 효과」이고 접사를 **센다**(tactic_card_design.md §1). 마스터리는 개인 단위이고 접사를 세지 않는다
- 죄종 트리가 카드 조건을 미는 방향(tactic_card_design.md §3)은 **조건 언어가 확정된 뒤** 얹는다. 지금 전제로 삼지 않는다

### 3-1. 죄종 7종 — 몬스터 죄종의 거울 [초안 2026-08-26 · 분노 개정 2026-08-27]

죄종 어휘는 이미 몬스터 정예 특성에 7개가 다 있다(monster_design.md §6). **영웅 죄종은 같은 성격을 아군 입장에서 뒤집은 것**이라 새로 발명하지 않는다.

| 죄종 | 몬스터 특성 (적) | 영웅 마스터리 축 | 공식의 자리 |
|---|---|---|---|
| **분노** | 격분 — 저체력 시 폭주 | **저체력 강화** — HP 가 낮을수록 세진다. 안정성을 안 산다 | [2] 조건부 괄호 · **반응 패시브** |
| **시기** | 박탈 — 치명 무효화 | **방어 무시 · 저항 감소** — 남의 방어를 박탈한다 | [3] 적의 감소를 깎는다 |
| **탐욕** | 도박 — 피해 랜덤 + 드롭 보너스 | **드랍률 · 골드** — 파밍 전담 | 라인 밖 (utility) |
| **나태** | 태만 — 느리지만 한 방 | **반사 피해 · HP 재생** — 안 때려도 얻고, 맞으면 갚는다 | 라인 밖 (비직격 §9-6) |
| **폭식** | 탐식 — 타격마다 공격력 누적 | **흡혈** — 때려서 얻는다 | 라인 밖 (sustain) |
| **색욕** | 유혹 — 공격력 흡수 스택 | **상태이상 활용** — 지속 연장 + 상태이상 대상 조건부 % | [2] 조건부 괄호 |
| **오만** | 불가침 — 상태이상 면역 | **미결** — §7 | — |

- **분노가 치명 배수를 잃었다** [개정 2026-08-27] — 마스터리 탭 하나가 통째로 치명 배수면 분노를 굴린 영웅 전원이 곱의 항을 공짜로 얻는다(§3 「곱의 항은 마스터리가 뿌리지 않는다」). 대신 계승 특성 **격분**을 그대로 가져와 「저체력일수록 세진다」로 둔다. 셋이 동시에 맞는다 — ① [2] 조건부 괄호라 곱을 안 건드린다 ② 몬스터 격분과 **어휘가 붙는다**(거울이 아니라 같은 말이 된다) ③ 자동전투라 저체력을 노려서 유지할 수 없으므로 「켜는 버프」가 아니라 **패배 직전의 역전 가능성**이 된다 — 관전 화면에서 가장 극적인 자리
- **분노는 반응 패시브의 첫 사례다** — 「HP 가 임계 밑이면 강화」는 상시 수치가 아니라 사건 반응이다(§1-2). 죄종 마스터리의 깊은 노드가 무엇인지 보여주는 본보기
- **폭식 ↔ 나태의 대비가 축을 가른다** — 흡혈(때려서 얻는다) vs 반사·재생(안 때려도 얻는다). 둘 다 sustain 이지만 반대 방향이라 겹치지 않는다
- **색욕은 상태이상을 "부여"하지 않는다** — 영웅 측 상태이상 **부여** 경로는 전술카드가 가져갔다(tactic_card_design.md §3). 색욕 마스터리는 **이미 걸린 상태이상을 활용**하는 쪽(지속 연장 · 상태이상 대상 조건부 피해)을 담당해 이중화를 피한다. 이 분담은 카드 효과 언어 확정 시 재검토
- 색욕은 **매혹(charm) 재정의**(GAME_DESIGN.md §10)의 자리 후보다 — 계승 정의가 "명중률 대폭 감소"인데 명중 축이 폐지됐다
- **"공격력 +x%" 노드가 하나도 없다** — 그게 이 축 분담의 목적이다. 죄종을 수치로 구분하려 하면 7개 중 절반이 상시 피해 % 로 수렴하고, 그건 직업 마스터리의 자리다
- 오만은 §7 미결. 채워지기 전까지 **오만 영웅은 죄종 마스터리가 비어 있는 상태**이므로 밸런스 검증에 넣지 않는다

## 4. 전직 — 직업마다 3갈래 [개정 2026-08-27 — 전직 종류 신설]

**직업마다 전직이 3갈래 있고, 그중 하나를 고른다.** 고른 전직이 **액티브 2~3개**를 주고, 각 액티브가 세부 트리의 뿌리가 된다.

```
직업 (5)  →  전직 3갈래  →  전직당 액티브 2~3 + 전용 트리
                            본편 = 5 × 3 = 15 전직
```

- **08-26 판에서 바뀐 것** — 종전엔 「전직 = 사건 하나 · 액티브 3개를 셋 다 보유 · 3택1이 아니다」였다. 전직이 갈래를 가지면서 **「3택1이 아니다」가 폐기**된다. 대신 3택1의 대상이 액티브가 아니라 **전직**이다
- **살아남는 것** — 「포인트를 넣은 것에만 세부 트리가 열린다」 · 두 액티브에 나눠 넣는 **몰빵 vs 분산** · **전용 포인트**(마스터리와 풀을 나눈다 — 공유하면 전직 레벨까지 안 찍고 모으는 게 최적이 되어 초반이 통째로 무력해진다)
- 전직은 **그 게임 처음의 스킬 결정**이다 — 그 앞 구간에 액티브 결정이 없으므로(§2) 여기에 무게가 실린다
- 해금: `[balance.csv:advance_unlock_level]`

### 4-2. 액티브 칸 · 전직 액티브의 선택 [⚠제안 2026-08-27 · 세 안 정리 2026-08-28]

전직이 액티브를 **3개** 주는데 §2 의 전직 칸은 하나다. 그대로면 만든 것 중 **화면에 나오는 건 하나**뿐이고, 관전이 본편인 이 게임에서 화면에 안 나오는 스킬은 값을 못 한다(§1-1 기준 2).

| 안 | 내용 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A. 1개 고정** | 전직이 액티브 하나를 정해서 준다 | 전직 액티브 15개로 끝 · 밸런스가 쉽다 · 전직 이름 ↔ 화면이 1:1 | 전직 후 스킬 결정이 0 — 전직이 「그 게임 처음의 스킬 결정」(§4)인데 고르는 순간 끝난다 |
| **B. 3개 중 1개** | 3개를 주고 그중 하나를 칸에 올린다 | **앞 2칸(고유 · 무기군)의 구멍을 메우는 결정**이 된다. 답이 영웅마다 달라서 **무료 롤백이 있어도 「최적 하나」로 안 굳는다** | 45개를 만들어 15개만 쓴다 · 셋 중 하나만 세게 나오면 나머지 둘이 죽어 결과가 A 와 같아진다 |
| **C. 전부 지급** | 전직당 2개를 만들고 둘 다 칸에 올린다 (칸 3 → 4) | 만든 것이 전부 화면에 나온다 · 고르는 것이 **두 뿌리의 포인트 배분**으로 내려간다 | 파워가 계단으로 뛴다(몬스터 전역 스케일 재보정) · §2 「액티브 3 — 출처 고정」이 깨진다 |

**B 가 성립하는 조건 하나 [2026-08-28]** — 셋이 **「센 순서」가 아니라 「역할」로 갈려야 한다.**

```
O  단일 딜 / 광역 딜 / 버프        → 앞 2칸을 보고 고른다
X  강한 딜 / 중간 딜 / 약한 딜      → 무조건 강한 것
```

이 조건은 갈래를 짤 때마다 검사한다 — 검사 결과는 §10-6.

**⚠ B 는 캘리브레이션에 가장 민감한 결정이다** — 셋의 파워 예산이 같아야(§9-1 규칙 1) 역할로 고를 수 있고, 어긋나는 순간 역할 판단이 무의미해진다. 자동전투라 플레이어 실력이 그 어긋남을 못 덮는다.

**미확정 — §7.** 다만 **지금은 전직당 3개씩 짠다** — 3 → 1 은 나머지 둘을 세부 트리 노드로 내리면 되지만(§1-3), 1 → 3 은 30개를 새로 짜야 한다. 되돌리기 쉬운 방향으로 가둔다.

## 5. 롤백 — 언제든 되돌린다 [확정 2026-08-26]

| 층 | 롤백 | 근거 |
|---|---|---|
| 마스터리 | **무료 · 수시** | 상시 수치라 최적해가 대체로 하나. 비용을 매겨도 결정이 아니라 통행세다 |
| 전직 특화 | **무료 · 수시** | 빌드 실험 자체를 재미 축으로 둔다 |

- **되돌릴 수 있다는 게 이 게임의 연구다** — 잘못 찍어 영웅 하나를 버리는 일이 없어야 한다. 방치형의 통제성(CLAUDE.md 철학 2)과 같은 계열
- **대가로 두 문장이 폐기됐다** (§0) — "개성은 배분에서 나온다" · "배분과 편성의 분리". 자유 롤백이면 배분은 개성이 아니고, 배분 = 편성이다
- **스킬은 파밍 루프 밖에 남는다** — 롤백에 재화를 안 걸었으므로 스킬이 원정→드롭→재배분 루프에 붙는 접점이 없다. 그 자리의 후보는 **연구소**(파견처)다 — 스킬 노드·특화 해금을 연구가 담당하면 접점이 생기고 롤백은 무료로 남는다. GAME_DESIGN.md §10 「스킬의 자리」

## 6. 콘텐츠 수량

```
트리 수      죄종 마스터리 7 + 직업 마스터리 N + 전직 뿌리 9N      (본편 N=5 → 57)
액티브 수    고유(유니크 15 + 레어 공용 풀) + 무기군 9 + 전직 9N   (본편 9N=45)
```

- **트리 안에 액티브 킷이 없어졌다** — 개정 전엔 "각 출처에 액티브 2개 이상"(구 §3)이라 트리 밖 정의까지 38개 이상이 필요했다. 지금은 무기군 7 + 전직 15 = 22 + 고유 풀
- 직업 1개 추가 비용 = 트리 2개(직업 마스터리 + 전직 특화) + 액티브 3개 — 선형
- **사제·마법사가 완드/스태프 숙련을 각자 트리에 두 번 짜는 중복이 남아 있다** — 무기 숙련을 직업이 아니라 무기군에 귀속시키면 사라지지만, 그러면 트리 축이 죄종/무기군/전직이 되어 직업 마스터리가 소멸한다. 미결(§7)
- **패시브가 셈에서 빠져 있었다** [2026-08-27] — 위 두 줄은 액티브만 센다. 실제 총량에는 **수치 패시브 노드 + 반응 패시브 노드**(§1-3, 트리 17개분)가 더 붙는다. 노드 규모(§7)가 정해지기 전에는 셀 수 없다
- **몬스터가 같은 풀을 쓰면 셈이 바뀐다** [2026-08-27] — 몬스터 액티브 2칸(§2)을 따로 만들면 총량이 늘지만, 직업 스킬 풀을 **영웅과 공유**하면 늘지 않는다. 어느 쪽인지가 부채 규모를 정한다 (§7 「몬스터 스킬 풀」)
- **08-27 개정으로 셈이 세 배가 됐다** [2026-08-28] — 종전 「전직 3N = 15」는 전직이 사건 하나이던 시절의 수다. 전직이 3갈래가 되고 갈래마다 액티브 3이면 **45**다. §4-2 의 A안(1개 고정)을 받으면 15로 돌아간다
- **무기군은 7이 아니라 9다** [2026-08-28] — `weapon_group.csv` 본편 9행(한손검 · 양손검 · 도끼 · 둔기 · 창 · 스태프 · 완드 · 활 · 석궁) · hero_design.md §2 「무기군 9종」. 종전 7은 낡은 수다
- **⚠ 전직 뿌리 45개는 트리를 못 짠다** [2026-08-28] — 액티브마다 세부 트리가 하나면(§4) 전직 뿌리만 45다. 죄종 7 + 직업 5 를 더하면 57. 노드 규모(§7)를 정하기 전에 **뿌리 수를 먼저 줄일지**를 §4-2 와 함께 판단한다

## 8. 보류 — 스킬 카드 합성

**[2026-08-25]** 비전투 활동 논의에서 나온 "합성"은 파견처 활동이 아니라 **스킬 카드 합성**이라는 별개 개념이다. 후속 과제 — 스킬 카드가 무엇인지(마스터리 2 + 특화 1 · 액티브 3 과의 관계)부터 정의한다. 넣을 때 별도 파견처(공방)를 세우지 않고 **제련소 기능**으로 들어간다. 정의 전까지 다른 문서에서 참조하지 않는다.

**불채택 기록** — "액티브 셋째 칸 = 스킬 카드(몬스터 카드 제작)" 안: 새 시스템 4~5종 · 드롭 운 · 카드는 낡지 않아 몰빵이 영구화 · 초반 빈칸. 카드의 가치(파밍 동기·제련소·수집)는 액티브 칸과 무관한 별개 결정.

## 9. 직업 액티브 15 — 프로토타입 초안 [2026-08-26 · 재작성 2026-08-27 — 15개 전량 교체]

> SSOT: **`src/data/skill.csv` 발행** (15행 · 값은 전부 ⚠제안) · 파워 예산 손잡이 `[balance.csv:skill_dps_budget_pct]`

§4 의 **전직 특화 액티브 3** 을 본편 5직업분 채운 것이다. 「스킬 테이블 미발행」(§0 머리말)이 여기서 풀린다 — 구조만 있고 내용물이 0이던 상태의 첫 실물.

### 9-0. 프로토타입 한정 — 셋을 시작부터 다 켠다

정상 구조에서 액티브 3칸의 출처는 **고유 · 무기군 · 전직**이고, 전직이 준 셋 중 칸에 오르는 것은 하나다(§2). 프로토타입은 **고유 스킬 풀도 무기군 액티브 7종도 미작성**이라 두 칸이 비어 있다 — 그 빈 두 칸을 같은 직업의 나머지 둘로 임시로 채운다.

- 목적은 **발동 규칙을 실제로 시험하는 것**이다 — "가장 오래 기다린 것 → 우선순위 → 기본 공격"(battle_design.md §3)은 액티브가 하나뿐이면 검증되지 않는다. 실효 쿨 정렬(§6)·버프 창 정렬(battle_design.md §7)도 같다
- 고유·무기군이 채워지면 **데이터를 그대로 두고 배정 규칙만 바꾸면 정상 구조로 돌아온다** — 직업 셋 중 하나만 칸에 남고 둘은 교체용이 된다
- ⚠ **캘리브레이션이 따라와야 한다** — 셋이 동시에 도는 동안 파티 화력이 기본 공격만 돌 때보다 크게 오른다. `round_budget.csv:time_target_sec` 이 깨지므로 몬스터 전역 스케일 재보정 전까지 라운드 소요를 신뢰하면 안 된다

### 9-1. 짜는 규칙 여섯 [개정 2026-08-27 — 규칙 4·5 폐기 · 6 신설]

**1. 파워 예산은 DPS 기여 하나로 잰다.** 마나가 없고 비용이 행동 1회뿐이라(battle_design.md §3) 잴 것이 셋밖에 없다.

```
N            = ceil( 표기 쿨 ÷ 행동 주기 )        한 사이클의 차례 수 (실효 쿨 = N × 행동 주기)
DPS 기여     = ( 스킬 배율 − 1 ) ÷ N              기본 공격 = 배율 1
목표         = [balance.csv:skill_dps_budget_pct]
```

**2. 버프는 가동률로 잰다.** 창이 열려 있는 비율에서 자기 행동 1회를 뺀다.

```
순 기여 = ( 지속 ÷ 실효 쿨 ) × 효과% − 1 ÷ N
```

파티 창은 **개인 스킬 하나를 파티 인원으로 나눈 값**이 기준이다. 인원수만큼 곱하면 파티 버퍼가 통행증이 된다 — hero_design.md §2 「사제 서약」과 같은 계열의 가드다.

⚠ **이 자에는 대상 수 K 가 없다** [2026-08-27] — 광역 스킬은 `(배율 × K − 1) ÷ N` 이라야 맞는데 K 항이 없어서, 문서의 자만으로는 광역이 예산에 맞는지 검증되지 않는다. 그리고 K 는 라운드 타입마다 흔들린다(`round_budget.csv` — 일반 1~3 · **챕터보스 단독 1**). K 를 명시하는 것은 §7.

**3. 직업 축만 준다 — 죄종 축은 액티브가 주지 않는다.** 15개 중 치명 배수 · 방어 무시 · 저항 감소 · 흡혈 · 반사 · 재생 · 드랍을 주는 것은 하나도 없다. 전부 [1] 상시 피해 % 와 [3] 내 쪽 방어에 얹힌다 (§3 축 분담의 직업 자리).

- **확정 치명이 액티브에서 빠졌다** [2026-08-27] — 저격의 `always_crit` 폐기. 치명은 액티브가 아니라 **마스터리**가 담당한다(§3 · 자리는 §7). 액티브가 치명에 닿는 것이 이제 하나도 없다
- 왜 — 축 분담이 마스터리에서만 지켜지고 액티브에서 새면 죄종 마스터리가 "액티브가 이미 주는 것을 조금 더 주는 탭"이 된다

**4. 상태이상을 연다** [개정 2026-08-27] — 종전 「상태이상 0」 폐기. 액티브가 상태이상을 **부여**할 수 있다(마법사 아이스 블라스트 = 결빙). 여는 순간 따라오는 것 둘: ① 「부여는 전술카드 전담」 분담(§3-1 색욕)이 재작성된다 ② 본작 `status_effect.csv` 신설이 필요하다. **세부는 §7** — 결빙의 정의 · 오만 정예(상태이상 면역)와의 대조 · `fhr` 와의 관계.

**5. 진형은 없고, 타겟팅은 있다** [개정 2026-08-27] — 종전 「진형·타겟팅에 기대지 않는다」 폐기. **위치(전열/후열)는 두지 않는다** — 이동 · 사거리 · 장판 계열이 전부 탈락한다. 대신 **대상 선택 규칙(타겟팅)은 확정 대상**이다. 도발(「그 창 동안 모든 적의 대상이 기사로 고정」)은 위치가 아니라 대상 선택 규칙만 요구하므로 진형 없이 성립한다.

- 진형을 두지 않기로 하면 함께 풀리는 것 넷 — 무기군 Implicit 보류 해제 · **다중타격 분배**(거리 감쇠가 없다) · `crushing_blow` · `counter_dmg` 등재 (battle_design.md §9-9 · 계승 접사)
- 대가 — 몬스터가 회복·대상 제어를 들면 플레이어가 「뒤를 지키는 놈」을 못 뚫는다. 그 대응은 타겟팅 우선순위이고, 자리는 **전술카드**다 (tactic_card_design.md §3). §7

**6. 라이더는 액티브가 아니라 반응 패시브다** [신설 2026-08-27] — 「처치 시 쿨 초기화」 · 「명중 시 자기 창」 같은 것은 행동을 따로 먹지 않으므로 §1-2 의 **반응 패시브**다. 위 1번 자로 재지 않는다. 액티브에 라이더를 붙이면 그만큼 **예산 밖으로 새므로**, 붙일 때는 그 사실을 명시한다.

### 9-2. 5직업 × 3 — 갈래가 갈리는 축 [재작성 2026-08-27 — 15개 전량 교체]

| 직업 | ① | ② | ③ | 셋을 가르는 것 |
|---|---|---|---|---|
| **전사** | **배쉬** — 단일 강타 | **함성** — 파티 공격력 창 | ⚠ **미정** — 단일 (§7) | 단일 폭발 / 파티 창 / 미정 |
| **기사** | **질** — 타수 고정 · 대상 순환 | **수호의 방벽** — 파티 배리어 | **도발** — 대상 고정 | 딜 / 파티 방어 / 대상 제어 |
| **마법사** | **파이어볼** — 단일 강타 | **연쇄 번개** — 광역 · 감쇠 | **아이스 블라스트** — 단일 + 결빙 | **원소 3종** |
| **궁수** | **저격** — 단일 강타 | **연사** — 단일 다단 | **멀티플** — 광역 | 한 방 / 여러 방 / 다수 |
| **사제** | **치유의 빛** — 파티 회복 | **심판** — 단일 딜 | **신속** — 파티 행동 주기 창 | 회복 / 딜 / 파티 창 |

- **파티 창이 공격·방어·속도로 갈렸다** — 함성(전사·공격력) · 방벽(기사·배리어) · 신속(사제·행동 주기). 세 직업이 하나씩 들고 겹치지 않는다. 종전 「**파티 창은 기사 전속**」은 폐기
- **전사** — ③ 이 비어 있다. 광역(휠윈드)은 **보류**하고 세부 트리 상위 노드로 예약했으므로 ③ 은 **단일**이어야 하는데, 배쉬와 축이 겹치면 안 된다. 후보는 §7
- **기사** — **질**은 타수를 고정하고 생존 대상에게 순환 분배한다. 대상이 하나면 그 하나에 타수가 몰리므로 **보스 단독전에서도 온전히 들어간다** — 광역이 K=1 에서 죽는 문제(§9-1 규칙 1 ⚠)를 이 형태만은 안 겪는다. 다른 광역 스킬의 모범 후보
- **기사 — 배리어는 새 개념이다** [2026-08-27] `damage_reduction`(비율 · 곱의 한 항)과 다른 점은 **총량 상한이 있다**는 것이고, 대가로 유닛 상태에 흡수 풀이 하나 생긴다. 그럼에도 배리어를 고른 이유는 **게이지로 보인다**는 것 — dr 은 파티에 걸리면 화면에 안 나타나고, 관전이 본편인 게임에서 그 차이가 작지 않다(§1-1 기준 2)
- **기사 — 도발은 타겟팅 확정을 요구한다.** 기본 대상 선택 규칙이 없으면 그 예외인 도발도 정의되지 않는다(§9-1 규칙 5). 그리고 **런 깊이의 결정자가 sustain 에서 기사 HP 로 옮겨간다** — 라운드 간 자동 회복이 없으므로(battle_design.md §1) 기사만 계속 맞으면 기사가 먼저 바닥나고 그게 원정 종료가 된다. 지속을 짧게 잡거나 배리어와 창을 물려 두지 않으면 「기사 HP = 클리어 여부」라는 단일 축이 생긴다. 대안은 **엄호**(아군이 받을 피해를 대신 받는다) — 적 AI 를 안 건드려 타겟팅 확정 전에도 짤 수 있다. §7
- **마법사** — 세 갈래가 곧 **원소 3종**이다. 무기 개체가 굴린 원소는 기본 공격이 쓰고 스킬은 자기 태그를 쓰므로(battle_design.md §9-5), "이 챕터는 화염 저항이 높으니 냉기 주력"이 **스킬 배분으로** 성립한다. 독은 도트라 미구현 — 네 번째 자리로 비워 둔다
- **마법사 — 연쇄 번개는 감쇠한다** [개정 2026-08-27] 종전 「다수 대상 = 전원에게 각각 독립 직격 · 감쇠 없음」에서 이 스킬만 예외로 뺀다. 진형이 없어도 **타격 순서**만 있으면 정의되므로 위치를 요구하지 않는다. ⚠ 순서가 정해지면 rng 소비 수열이 그만큼 늘어난다 (INTERFACE.md rng 순서 계약)
- **궁수 — 확정 치명이 빠졌다** [개정 2026-08-27] 저격의 `always_crit` 폐기. 그 결과 저격의 특이성이 **배율 크기 하나**만 남았고, 「장쿨 단일 강타」가 배쉬 · 파이어볼 · 저격 · 심판 **넷**이 됐다. 형태 중복은 인정된 상태 — 궁수의 개성은 마스터리(치명)에서 나온다는 전제다. 넷을 갈라야 한다면 §7
- **사제** — 치유의 빛이 단일에서 **파티 회복**으로 바뀌고 성역(광역 회복)은 소멸했다. 셋 중 하나가 딜인 것은 「사제 서약」(hero_design.md §2 — 사제 없이도 최전선이 성립해야 한다) 때문이다. 심판의 언데드 조건부는 **제거** — 조건부 % 는 [2] 죄종 자리라 액티브가 주면 규칙 3 위반이다
- **사제 — 신속은 스킬 비중을 낮춘다** [2026-08-27] `N = ceil(쿨 ÷ 행동 주기)` 이므로 행동 주기가 줄면 N 이 커지고 스킬 DPS 기여 `(배율−1)÷N` 이 **작아진다**. 즉 신속은 기본 공격을 키우고 스킬을 상대적으로 죽인다 — §9-4 파생 관측 2(「느린 무기가 스킬을 더 잘 쓴다」)의 정확한 역방향이다. 버그가 아니라 성질이고, 캘리브레이션에 이 항이 들어가야 한다

### 9-4. 파생 관측 넷 [2026-08-27 — 0번 추가]

0. **액티브/패시브 분리가 예산 누수의 정체를 밝혔다** [2026-08-27] — §9-1 규칙 1 의 자로 못 재던 것들(참수의 쿨 초기화 · 저격의 확정 치명 · 응징의 자기 창)이 전부 **반응 패시브**였다. 액티브에 얹혀 있어서 예산 밖으로 샜던 것이지 자가 틀린 게 아니었다 (§1-2 · §9-1 규칙 6)
1. **오만 마스터리의 축(§7)에 실체가 생겼다** — 15개 중 셋이 버프 창이고(함성 · 방벽 · 신속) 5직업 중 셋이 하나씩 갖는다. 후보 ①「버프 지속·강화」가 더 이상 대상 없는 축이 아니다. 확정은 하지 않는다
2. **느린 무기가 스킬을 더 잘 쓴다** — 쿨은 실시간이고 배율은 %라, 행동 주기가 길수록 N 이 줄어 스킬 비중이 커진다. 양손 무기가 자동으로 스킬 성향을 갖는 셈이라 §2-1 「무기군 간 DPS 균형」 검증에 이 항이 들어가야 한다
3. **스킬은 무기 개체 격차를 줄이지 않는다** — 배율은 밑수에 곱하므로 잘 뜬 무기의 우위가 그대로 곱해진다. §2-1 「옵션 vs 스킬」 결정 조건은 여전히 무기군 간 균형에 달려 있다

### 10-1. 마법사 — 원소 3종이 전직 3종이다 [확정 2026-08-27]

원소 정의는 battle_design.md §2-1 이 SSOT 다. 갈래는 그 정의를 그대로 따른다.

| 전직 | 원소 정의 | ① 단일 | ② 광역 | ③ |
|---|---|---|---|---|
| **화염술사** | 강력한 피해 + **치유 감소** | **메테오** | **파이어월** — 광역 도트 | **히드라** — 지속 포화 창 |
| **빙결술사** | **상태이상 순환** (부여 → 소비) | **프로즌 오브** — 단일 + 결빙 | **블리자드** — 광역 + 둔화 | **빙결 폭발** — 결빙을 소비하고 터뜨린다 |
| **뇌전술사** | 매우 강력한 피해 + **큰 분산** | **라이트닝** | **노바** | **정전장** — 현재 HP 비율 |

- **역할 배치를 3×3 으로 맞추지 않았다** — 원소 정의가 셋 다 다른 종류(피해+디버프 / 상태이상 / 피해+분포)인데 역할까지 격자로 맞추면 정의가 죽는다. 빙결술사는 유틸 없이 딜 셋이고 그게 「부여 → 소비」를 닫는 값이다
- **프로즌 아머 폐기** — 「파티 얼음 방어막」은 기사 **수호의 방벽**(파티 배리어)과 같은 것이라 기사의 정체성을 깎는다. 그 자리를 빙결 폭발이 받았다
- **히드라는 소환이 아니다** — 유닛을 추가하면 타겟팅 확정이 선행이고 파워 예산도 못 잰다(행동 1회로 여러 턴 딜). **창 동안 주기적 화염 타격이 자동으로 나가는** 형태로 두면 유닛 없이 체감이 같다
- **정전장이 마법사만의 해답이다** — 광역인데 **현재 HP 비율**이라 보스 단독전에 강하다. 「광역이 K=1 에서 기여를 잃는다」(§7)를 자기 갈래로 푸는 유일한 형태
- **화염이 몬스터 힐러 문제를 푼다** — 타겟팅이 자동이라 「힐러부터 잡아라」를 실행할 수단이 없는데, 화염 광역은 대상을 지목하지 않고 **적 전원의 치유를 깎는다**. 몬스터에 회복을 주기로 하면 전술카드를 안 열고도 대응이 생긴다. ⚠ 반대로 몬스터에 회복이 없으면 치유 감소는 사제·물약·흡혈에만 걸리는 반쪽 축이다 (§7)

**딸려오는 결정 둘**

| 항목 | 내용 |
|---|---|

### 10-2. 전사 — 무엇으로 싸우는가 [확정 2026-08-28]

| 전직 | 성격 | (1) | (2) | (3) |
|---|---|---|---|---|
| **광전사** | 극딜 · 평타 — **몸**으로 싸운다 | **광폭 태세** — 공격 옵션 극대 | **전투 태세** — 공격 + 방어 균형 증가 | **투기 태세** — 창 동안 공격할 때마다 고정 피해 추가 |
| **바바리안** | 균형 — **무기**로 싸운다 | **휠윈드** — 다수 × 다단 | **고대인의 망치** — 단일 강타 | **지진** — 광역 피해 + 스턴 |
| **선봉장** | 파티 — **목소리**로 싸운다 | **사자후** — 다수 피해 | **호령** — 아군 최종 피해 증가 창 | **일갈** — 적 전원 공격력 감소 창 |

- **⚠ 광전사는 태세 셋이 전부 자기 강화다** — §4-2 B안의 「역할로 갈려야 한다」 조건을 **유일하게 어기는 갈래**다(§10-6). 3개 중 1개를 고르는 구조로 가면 여기만 「구멍 메우기」가 성립하지 않고 「제일 센 태세」로 수렴한다. 태세 형태를 유지하려면 셋을 다 주거나, 하나를 딜로 바꾼다 — §7
- **바바리안이 라운드 타입에 반응한다** — 챕터보스는 단독 1(`round_budget.csv`)이라 휠윈드가 기여를 잃는 자리를 고대인의 망치가 받는다. 「잡몹전 = 휠윈드 / 보스전 = 망치」
- **선봉장 셋은 전부 소리인데 하는 일이 다르다** — 때린다 / 아군을 키운다 / 적을 깎는다. §9-2 의 「파티 창이 공격·방어·속도로 갈렸다」에서 전사 몫이 여기로 자란다
- **무기군은 갈래 축이 아니다**(§4-1) — 도끼·둔기·창은 자유 조합이고, 궁합은 `action_period` 에서 자연히 생긴다
- **새 규칙 둘** — 고정 피해 채널(투기 태세) · 스턴(지진). 둘 다 §7

### 10-3. 기사 — 지킨 것을 어떻게 쓰는가 [확정 2026-08-28]

| 전직 | 성격 | (1) | (2) | (3) |
|---|---|---|---|---|
| **가디언** | 자기가 다 받아낸다 | **엄호** — 창 동안 아군이 받을 피해를 대신 받는다 | **철벽** — 창 동안 받는 피해 대폭 감소 | **방패 강타** — 단일 피해 + 짧은 행동 지연 |
| **팔라딘** | 파티에 걸어준다 | **불굴의 맹세** — 창 동안 파티가 치명적 일격 1회 무효 | **정화** — 파티 상태이상 해제 + 짧은 면역 | **서약** — 파티 최대 HP 창 + 그만큼 회복 |
| **크루세이더** | 순수 딜러 | **성화** — 화염 속성 피해 | **단죄** — 단일 강타, 적 HP 낮을수록 배율 급증 | **결투** — 창 동안 지정한 적 1체에게 피해 대폭 증가, 다른 적에겐 감소 |

- **기사의 딜은 전사와 다른 자리에서 나온다** — 전사는 때려서, 기사는 **일대일로 물고 늘어져서** 딜한다. 결투가 그 정체이고 챕터보스 단독 1 에 정확히 걸린다. 잡몹 라운드는 기본 액티브 「질」(타수 고정 · 대상 순환)이 받으므로 크루세이더가 광역을 안 들어도 구멍이 안 생긴다
- **성화가 기사의 물리 우회로다** — 기사 무기군은 둘 다 `physical`(`weapon_group.csv`)이라 물리 방어가 높은 적 앞에 답이 없다. 마법사가 **원소끼리** 고르는 것과 달리 크루세이더는 **물리 밖으로 나가는 창구 하나**를 얻는 것이라 마법사 축의 복제가 아니다. ⚠ 화염 태그를 달면 **치유 감소**(battle_design.md §2-2)가 따라와서 「화염이 몬스터 힐러 문제를 푼다」(§10-1)가 마법사 전용이 아니게 된다 — 규모로 갈린다(갈래 전체 vs 스킬 하나)
- **도발을 전직에서 뺐다** — 기본 액티브에 이미 있고(§9-2) 기본 타겟팅 규칙이 미결이라(§7), 전직 셋 중 하나를 거기 걸면 갈래가 통째로 막힌다. 대신 **엄호**를 가디언 (1) 로 올렸다 — 적 AI 를 안 건드려서 타겟팅 확정 전에도 짜인다
- **성전이 자리를 잃었다** [2026-08-28] — 크루세이더가 순수 딜러로 가면서 「남은 배리어를 피해로 전환해 광역 폭발」이 빠졌다. 구판 §10-2 가 **「트리끼리 잇는 첫 사례」**로 꼽던 것이라(다른 뿌리인 방벽의 파라미터를 먹는다), 살리려면 **팔라딘** 쪽으로 옮긴다
- ⚠ **정화가 사제와 겹친다** — §10-5 예언자 (1) 과 같은 것이다. 귀속은 §7

### 10-4. 궁수 — 타격의 리듬 [확정 2026-08-28]

**진형이 없어서 「원거리」가 기계적으로 표현되지 않는다**(§9-1 규칙 5 — 사거리 · 위치 없음). 그래서 축은 거리가 아니라 **타격을 어떻게 쪼개는가**다. 기본 3(저격 · 연사 · 멀티플)이 이미 그 축이다.

| 전직 | 성격 | (1) | (2) | (3) |
|---|---|---|---|---|
| **저격수** | 느리고 무겁게 | **정조준** — 창 동안 피해 대폭 증가 + 자기 행동 주기 증가 | **사냥 표식** — 지정 대상에게 파티 전체 피해 증가 창 | **일격** — 단일 초대형 강타 |
| **질풍궁수** | 빠르고 잘게 | **속사** — 창 동안 자기 행동 주기 급감 | **난사** — 단일 다단, 타수 대폭 | **탄막** — 다수 × 다단 |
| **수렵꾼** | 독과 구속 | **독화살** — 독 속성 + 도트 | **맹독** — 독에 걸린 대상에게 추가 피해 | **족쇄 화살** — 단일 + 행동 지연 |

- **저격수 ↔ 질풍궁수가 같은 손잡이를 반대로 돌린다** — `N = ceil(쿨 ÷ 행동 주기)` 이라 행동 주기를 **늘리면** N 이 줄어 스킬 한 방이 무거워지고, **줄이면** N 이 커져 평타가 본체가 된다(§9-2 사제 항 · §9-4 관측 2). 두 갈래가 수치가 아니라 **전투의 리듬**으로 갈려서 관전 화면에서 바로 구분된다
- **치명은 액티브에 안 넣었다** — §7 이 「치명 확률의 자리 = 궁수 **직업 마스터리**」를 후보로 두고 있어서, 저격수의 개성을 치명이 아니라 행동 주기로 잡았다. §9-1 규칙 3 과도 정합
- **독이 궁수로 정해진다** — §10-1 의 「독은 네크로맨서 또는 궁수」가 여기서 닫힌다. ⚠ 다만 **수렵꾼이 통째로 도트에 걸려 있다** — §7 「화상(도트) 도입 여부」가 안 열리면 이 갈래는 못 짠다. 도트는 매 틱마다 피해 이벤트라 관전 타임라인과 rng 소비 수열이 늘어난다(INTERFACE.md rng 순서 계약)
- **활 ↔ 석궁 차별화는 여전히 미정**(hero_design.md §2). `weapon_group.csv` 가 활(주기 1.4 · 편차 14) / 석궁(주기 1.8 · 편차 20)으로 이미 갈라 놔서 석궁이 저격수에 활이 질풍궁수에 자연히 붙지만, **갈래 축으로 박지는 않았다** — 전사에서 무기군 축을 버린 것과 같은 이유(§4-1)

### 10-7. 뿌리로서의 적합성 — 노드를 걸 자리가 있는가 [2026-08-27 · 갱신 2026-08-28]

액티브는 **트리의 뿌리**다(§4). 그러므로 고르는 기준은 「이 스킬이 재밌나」가 아니라 **「여기서 가지가 몇 개 뻗나」**이고, 뻗을 가지는 그 스킬이 가진 **파라미터의 수**로 정해진다.

| 파라미터 | 가진 스킬 | 뻗는 가지 |
|---|---|---|
| 타수 | 질 · 연사 · 난사 · 휠윈드 · 탄막 | 타수 +1 / 타격마다 ~ |
| 대상 수 | 휠윈드 · 멀티플 · 노바 · 사자후 · 지진 · 탄막 · 천벌 | 대상 +1 / 대상 수만큼 ~ |
| 감쇠율 | 연쇄 번개 | 감쇠 완화 / 마지막 대상에게 ~ |
| 지속 | 함성 · 방벽 · 신속 · 히드라 · 태세 3 · 호령 · 일갈 · 엄호 · 철벽 · 결투 · 정조준 · 속사 · 사냥 표식 · 가호 | 지속 연장 / 창 중 ~ |
| 총량 | 배리어 · 서약 | 총량 증가 / 남은 만큼 ~ / 깨질 때 ~ |
| 조건 임계 | 단죄 | 임계 완화 / 조건 충족 시 ~ |
| 상태이상 | 아이스 블라스트 · 프로즌 오브 · 블리자드 · 지진 · 방패 강타 · 독화살 · 족쇄 화살 · 속박 | 지속 연장 / 걸린 대상에게 ~ |
| 비율 | 정전장 | 비율 상향 / 상한 완화 |
| 대가 | 투기 태세(고정 피해) · 정조준(느려짐) | 대가 완화 / 대가만큼 ~ |

- **밋밋한 뿌리 넷** — 배쉬 · 파이어볼 · 저격 · 심판은 가진 파라미터가 **배율 하나**뿐이라 뻗을 가지가 「배율 +x%」밖에 없다. 형태 중복(§7)일 뿐 아니라 **트리가 안 자란다**
- 다만 넷이 전부 **기본** 쪽에 몰려 있는 건 오히려 맞다 — 기본은 평범하고 전직이 성격을 준다. 밋밋함이 결함이 아니라 계단이 된다. D2 의 Bash → Concentrate → Berserk 계보와 같은 모양
- **빙결 폭발은 원래 깊은 노드 후보였다** — 「결빙된 적을 때리면 터진다」는 반응 패시브(§1-3)에 딱 맞는 형태다. 액티브로 올린 지금도 **트리 깊은 곳에 반응 패시브판을 따로 둘 여지**가 남아 있다
