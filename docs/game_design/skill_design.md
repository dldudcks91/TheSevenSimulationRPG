## 0. 확정 [2026-08-26 — 전면 개정]

**"3탭 트리 + 액티브 슬롯 3" 구조를 닫고, 마스터리 2층 + 전직 특화로 재편한다.**

| 폐기 | 대체 |
|---|---|
| **슬롯**이라는 개념 | **액티브 3** — 출처가 셋이고 각 출처가 하나씩 준다. 편성할 게 없으므로 시스템 이름을 지운다 (§2) |
| 액티브 첫 칸 = **죄종** | 첫 칸 = **영웅 고유 스킬** (hero_design.md §1). 레어 영웅도 공용 풀에서 1개 배정받는다 |
| 트리 안의 **액티브 킷** | 액티브는 **트리 밖**에서 온다 — 고유 · 무기군 · 전직. 트리는 강화·숙련·시너지만 (§3) |
| "3택1 같은 선택 없음 — 개성은 배분" | **자유 롤백** 도입으로 폐기. 개성의 출처는 **굴림 + 장비 + 고유 스킬** (§5) |
| "배분(트리)과 편성(슬롯)의 분리" | 자유 롤백이면 배분 = 편성이다. 두 개념이 합쳐진다 (§5) |
| 탭1 = 죄종 **트리**(고유 메커니즘) | 탭1 = 죄종 **마스터리** — 액티브 없음. 축은 §3-1 |

### 왜 — 슬롯이 하던 일이 사라졌다

슬롯의 존재 근거는 하나였다: **상한이 없으면 트리 배분이 "다 찍기"로 수렴한다.** 액티브를 트리 밖으로 빼면 트리에 액티브 노드가 없으므로 그 수렴이 원천에서 사라진다. 출처가 고정이고 각 출처가 하나씩 주면 편성할 것도 남지 않는다.

남는 것은 **동시 준비 시 우선순위**뿐인데, 그건 발동 규칙의 동률 결정자(battle_design.md §3)이지 슬롯이 아니다.

## 1. 액티브와 패시브 [신설 2026-08-27 — 층 분리]

### 1-1. 무엇으로 가르는가 — 기준 셋

| 기준 | **액티브** | **패시브** |
|---|---|---|
| **행동 주기를 먹는가** | **먹는다** — 비용은 행동 1회 (battle_design.md §3) | 안 먹는다 |
| **화면에 사건으로 보이는가** | **보인다** — 로그 · 이펙트 · 쿨 게이지 | 안 보인다 (반응 패시브는 발동 순간만) |
| **파워 예산을 재는 자** | `(배율 − 1) ÷ N` — §9-1 규칙 1 | 공식의 덧셈 항에 얹힌다 |

> **액티브 = 무엇을 하는가** (때린다 · 회복한다 · 건다)
> **패시브 = 어떻게 되어 있는가** (숫자가 얼마다 · 무슨 일이 저절로 일어난다)

두 번째 기준이 이 게임에서 특히 무겁다 — **조작이 없으므로 플레이어가 인과를 읽는 창구는 관전 화면뿐**이다(CLAUDE.md 철학 2). 화면에 사건으로 나타나지 않는 것은 패시브다.

### 1-2. 패시브는 둘이다

| | **수치 패시브** | **반응 패시브** |
|---|---|---|
| 형태 | 상시 — 항상 켜져 있다 | **「~하면 ~한다」** — 사건에 반응한다 |
| 예 | 상시 피해 % · 최대 HP · 저항 · 행동 주기 | 처치 시 쿨 초기화 · 명중 시 창 · 저체력 시 강화 · 타격마다 누적 · 흡혈 · 반사 |
| 공식에서 | 항에 **더한다** (`combat_stat.csv`) | 항에 안 들어간다 — **이벤트에 붙는다** |
| 화면 | 안 보인다 | **발동 순간 보인다** |
| 예산 | 덧셈이라 재기 쉽다 | **재기 어렵다** — 발동 빈도에 종속 |

**흩어져 있던 것이 전부 반응 패시브였다** — 액티브 라이더(참수의 쿨 초기화 · 응징의 자기 창) · 정예 특성(격분 · 탐식 · 도박) · 죄종 「라인 밖」(흡혈 · 반사 · 재생) · 장비 접사(`crushing_blow` · `counter_dmg`). 네 군데에 다른 이름으로 있던 것이 하나의 개념이다.

### 1-3. 노드 종류 셋 — 수치 · 반응 · 변형 [확정 2026-08-27 · 변형 추가 2026-08-28]

| 노드 | 하는 일 | 예 |
|---|---|---|
| **수치** (얕은 노드) | 숫자를 올린다 | 배쉬 배율 +x% · 최대 HP · 저항 |
| **반응** (깊은 노드) | 사건에 규칙을 붙인다 — 「~하면 ~한다」 | 처치하면 쿨 초기화 · 피격하면 반격 |
| **변형** (깊은 노드) | **스킬의 태그를 바꾼다** (§11) | **배쉬가 `단일` → `광역` 이 된다** |

- **새 층을 만들지 않는다** — 별도 패시브 슬롯을 세우면 §0 이 방금 지운 「슬롯」 개념이 되살아난다. 단순화 원칙(CLAUDE.md 철학 3)
- **트리에 목표가 생긴다** — 「다 찍기」가 아니라 **「어디까지 파는가」**가 된다. 자유 롤백(§5)으로 배분이 개성을 잃은 자리를, 깊이가 대신 메운다
- **굴림·장비로도 온다** — 고를 수 없는 반응 패시브는 장비 접사 · 영웅 고유 · 몬스터 정예 특성에 딸려 온다. 고르는 것(트리)과 굴리는 것(장비)이 나뉜다
- ⚠ **예산 자가 아직 없다** — 반응 패시브는 발동 빈도에 파워가 종속되어 `skill_dps_budget_pct` 로 못 잰다. 자를 세우는 것은 §7

**변형 노드가 여는 것** [2026-08-28]

- **밋밋한 뿌리가 정당해진다** — 배쉬·파이어볼·저격·심판은 가진 파라미터가 배율 하나뿐이라 트리가 안 자란다(§10-7). 변형 노드가 있으면 **뿌리는 평범해도 되고 트리 끝에서 성질이 바뀐다.**

  ⚠ **D2 인용 정정** [2026-08-28 — [diablo2/00_overview.md §3](../reference/diablo2/00_overview.md) 전수 조사] — 종전에 「D2 의 Bash → Concentrate → Berserk 계보가 그 형태다」라고 적었으나 **두 군데가 틀렸다.** ①실제 사슬은 **Bash → Stun → Concentrate → Berserk**(Lv 1→12→18→30)로 **Stun 이 빠져 있었다** ②더 중요한 것 — **D2 는 스킬이 변형되지 않는다.** 넷은 각각 따로 존재하는 액티브고 넷 다 항상 쓸 수 있다. **「선행 스킬 사슬」이지 「변형」이 아니다** — 즉 **변형 노드의 D2 선례는 없다.** 변형 노드는 여전히 유효한 설계지만 **선례 없는 신규 구조**로 취급한다
  대신 Stun 을 되살리니 세 전환이 **각각 다른 종류**임이 드러났고, 그건 변형 노드가 무엇을 바꿀 수 있는지의 목록이 된다 — **CC 타입 교체**(넉백→스턴) · **생존 트레이드오프**(Stun→Concentrate) · **피해 타입 전환**(Concentrate→Berserk, 물리→마법)
- **무료 롤백이 살아난다** — 롤백이 무료라 배분이 개성을 못 만든다는 게 §5 의 대가였는데, 변형 노드는 **스테이지마다 갈아 끼울 진짜 이유**가 된다 (「이 챕터는 잡몹이 많으니 배쉬를 광역으로」)
- **전술카드와 물린다** — 카드가 태그를 세므로(§11) 조건을 맞추려고 태그를 바꾸게 된다. §3 이 적어 둔 「스킬 트리가 카드 조건을 미는 방향」이 실물을 갖는다
- **정의 상한 2 의 예외** — 태그는 스킬 정의에서 최대 2 인데, **세 번째 태그는 변형 노드가 준다.** 늘리려면 포인트를 낸다
- ⚠ **바뀌는 것은 태그가 아니라 컬럼이다** — `광역`·`단일`·`다단히트` 는 `target`·`hits` 에서 파생되므로(§11), 노드는 **컬럼을 바꾸고 태그는 따라간다.** 둘 다 바꾸면 두 곳 관리라 반드시 어긋난다. 플레이어에겐 「태그가 바뀐다」로 보이면 된다

### 1-4. 전체 구조

```
[분노][마법사] 영웅:

액티브 3  ── 고유 · 무기군 · 전직          (§2)  ※ 행동 1회를 먹는다

패시브
  마스터리 (1레벨~)   ├── 직업 마스터리 — 마법사
                      └── 죄종 마스터리 — 분노     : T1 은 행동 주기 감소(§3-1)
                           ※ 포인트 풀 공유 · 액티브 없음
                           ※ 얕은 노드 = 수치 / 깊은 노드 = 반응 (§1-3)

  전직     (전직~)    └── 3갈래 중 택1 → 그 전직의 액티브 3 중 **1개를 찍는다**
                           ※ 찍은 그 스킬 하나만 트리의 뿌리 · 전용 포인트 (§4-2 B안)

  굴림     └── 장비 접사 · 영웅 고유 — 고를 수 없다
```

- 마스터리 둘은 **영웅 생성 시 확정**된다 — 직업도 죄종도 굴림/고정이고 바꿀 수 없다. 플레이어의 결정은 **어디에 몰았나**뿐
- 전직 해금: `[balance.csv:advance_unlock_level]`

### 1-5. 전달 형태 — 함성과 오오라 [신설 2026-09-08 — 사용자 확정]

버프가 **어떻게 걸리는가**로 둘이 갈린다. §1-1 의 기준 셋으로 재면 **오오라는 액티브도 패시브도 아니다** — 행동을 안 먹는데(패시브 쪽) 화면에 사건으로 보이고 플레이어가 고른다(액티브 쪽).

| | **함성** | **오오라** |
|---|---|---|
| 지속 | 시전하면 정해진 시간 동안 (`skill.csv:duration_sec`) | **쿨타임 없이 계속** — 패시브처럼 켜져 있다 |
| 동시 적용 | **중첩된다** — 여러 함성이 같이 걸리고 효과가 합쳐진다 | **하나만** — 켠 오오라 1개만 적용된다 |
| 행동 주기 | 먹는다 — 시전이 행동 1회 (battle_design.md §7) | **안 먹는다** |
| 결정의 자리 | **언제 · 얼마나 자주** — 창을 물리는 정렬 | **무엇을 켜는가** — 택일 |
| 드는 직업 | 전사 | 기사 |

- **전사와 기사가 이 축으로 갈린다** — 전사는 시전형이라 창의 정렬이 최적화가 되고, 기사는 상시형이라 **켜는 것 자체가 유일한 결정**이다. 조작이 없는 게임에서 후자는 편성 화면에서 끝나는 결정이라 통제성이 높다 (CLAUDE.md 철학 2)
- ~~「버프 창은 **중첩 없음** · 재시전은 갱신」~~ **폐기 2026-09-08** — 겹치는 것이 함성이라는 형태의 정의가 됐다 (§9-3 · battle_design.md §7)
- **오오라는 예산 자가 다르다** — §9-1 규칙 1·2 의 자는 「비용 = 행동 1회」를 전제하는데 오오라는 그 비용이 **0** 이다. 대신 **「하나만 켠다」가 비용**이라 기회비용이 자가 된다. 새 자가 필요하다 — §7
- ⚠ **오오라가 액티브 3칸을 먹는지 미정** — 먹으면 딜 스킬 하나를 포기하는 것이 추가 비용이고, 안 먹으면 칸 밖의 새 층이 하나 선다(§1-3 「새 층을 만들지 않는다」와 부딪힌다). §7

## 2. 액티브 3 — 출처 고정, 각 출처가 하나

**슬롯이 아니다.** 배운 것 중 셋을 고르는 게 아니라, 출처가 셋이고 각각이 하나씩 준다.

| 칸 | 출처 | 바뀌는 조건 |
|---|---|---|
| **고유** | 영웅 자신 (hero_design.md §1) — **프로토타입 배정 [2026-09-01]**: 생성 시 `skill.csv` 에 발행된 행 전부(14)에서 **균등 1개**를 굴려 박는다(직업 비종속 · §9-0) | 안 바뀐다 — 영웅에 박혀 있다 |

## 3. 마스터리 — 축 분담은 피해 공식에서 나온다

두 탭이 왜 둘인가에 대한 답. 성격이 아니라 **공식의 자리**로 가른다.

```
[1] 기본 공격력 = 능력치계수 × 무기 공격력 × ( 1 + Σ 상시 % )      ← 직업
[2] 타격 피해   = [1] × 스킬 배율 × 치명 배수 × ( 1 + Σ 조건부 % )  ← 죄종
[3] 최종 피해   = [2] × ( 1 − 감소 ) × Π ( 1 − 피해 감소 )
                         ↑ 내 방어 = 직업 / 적의 방어를 깎는 것 = 죄종
    라인 밖      흡혈 · 반사 · 재생 · 상태이상 · 드롭 · 골드         ← 죄종
```

⚠ **자리 분리 원칙(「직업 = 내 숫자 · 죄종 = 닿는 방식」) 폐기** [2026-08-28 — 사용자 확정] — 아래 담당 열은 더 이상 배타적 파티션이 아니다. 실제 T1 배정은 §3-1

| 탭 | 담당(참고) | 얕은 노드 (수치 패시브) | 깊은 노드 (반응 패시브) |
|---|---|---|---|
| **직업 마스터리** | [1] 과 [3] 의 내 쪽 | 무기군 숙련 · 방어구 숙련 · 상시 피해 % · 최대 HP · 물리 방어 · 원소 저항 · 행동 주기 | 「피격하면 ~」 · 「처치하면 ~」 계열 |
| **죄종 마스터리** | [2] · [3] 의 적 쪽 · 라인 밖 | 조건부 % · 방어 무시 · 저항 감소 · 흡혈 · 반사 · 재생 · 드랍률 · 골드 | 죄종의 성격을 사건으로 표현한 것 (§3-1) |

- **깊은 노드가 반응 패시브다** [2026-08-27] — 얕은 곳은 숫자를 올리고, 깊은 곳은 **사건에 반응하는 규칙**을 준다 (§1-3). 트리의 목표가 「다 찍기」가 아니라 「어디까지 파는가」가 되는 자리
- **곱의 항은 마스터리가 뿌리지 않는다** [2026-08-27] — 위 표에서 **치명 배수가 빠졌다**. `[2]` 에서 치명 배수는 **곱**이라 다른 모든 것과 곱해진다. 덧셈 항(상시 % · 조건부 %)은 여러 출처에서 풀어도 합이 완만하지만, 곱은 하나만 풀려도 전체가 튄다. 그래서 **치명 배수의 출처는 아낀다** — 후보는 유니크 아이템 · 낙인 크래프트(item_design.md §3). ⚠ **2026-08-28 예외 둘** — 분노 · 오만 마스터리 T2 에 한해 낮은 계수로 치명 배수를 준다(§3-2). 더는 늘리지 않는다. 치명 **확률**은 배수가 잠겨 있으면 기대값이 선형이라 상대적으로 풀어도 안전하고, 분노·색욕 T2 에서 실제로 쓰인다(§3-2). ⚠ 「D2 가 Deadly Strike 의 배수를 고정하고 확률만 쌓게 한 것과 같은 처리」라고 적어 뒀으나 **미검증**이다 — Deadly Strike 는 아이템 접사라 [diablo2/00_overview.md](../reference/diablo2/00_overview.md) 의 클래스 스킬 전수 조사 범위 밖이었다. 원칙 자체는 공식에서 나오므로 유효하지만, **D2 선례로 인용하려면 별도 확인이 필요하다**
- **새 괄호·새 곱셈 층을 만들지 않는다** — 노드는 전부 `combat_stat.csv` 의 기존 수치에 더한다 (battle_design.md §9-2 "괄호는 둘뿐")
- **전술카드와 겹치지 않는다** — 카드는 파티 단위 「조건 → 효과」이고 접사를 **센다**(tactic_card_design.md §1). 마스터리는 개인 단위이고 접사를 세지 않는다
- 죄종 트리가 카드 조건을 미는 방향(tactic_card_design.md §3)은 **조건 언어가 확정된 뒤** 얹는다. 지금 전제로 삼지 않는다

**이 재편으로 닫히는 것 셋**

| 닫힌 것 | 왜 |
|---|---|
| **서브트리 10장이 필요 없다** | 노드가 둘이다. 09-01 무기 재편과 09-07 사제 무기 신설로 본편 무기군이 10 이 되면서 서브트리안은 10장을 짜야 했다 |
| **D2 함정을 구조적으로 피한다** | 아래 인용한 「같은 효과 N장 복제 = 세금」은 서브트리가 여러 장이어야 성립한다. 노드가 둘뿐이고 **서로 반대 축**이라 복제가 생길 수 없다 |
| ~~**장착형 vs 누적형**~~ (§7) | **소멸.** 노드는 캐릭터에 쌓이고 **켜지는 것은 든 무기가 정한다.** 무기를 바꿔도 롤백할 것이 없고, 「포인트를 다 채우고 무기만 바꿔 스위칭」도 성립하지 않는다 — 어느 쪽을 들든 노드 하나는 논다 |

- **조건부가 아니다** — 「그 무기를 들었을 때」는 전투 중 발동이 아니라 **편성 시점에 확정**되므로 「T1·T2 는 단순 수치형」 규칙에 안 걸린다
- ⚠ **「최소 데미지」는 신규 전투 스탯이다** — `weapon_group.csv:variance_pct` 는 무기 데이터 컬럼이고, 영웅 쪽에서 하한을 미는 스탯이 `combat_stat.csv` 에 없다. 발행이 선행 (§7)
- ⚠ **공속이 겹겹이 쌓인다** — 죄종 T1(공통) · 마법사 T1-3 · 여기 T2-2 · 중갑 마스터리(§3-6). **느린 무기를 든 중갑 전사**는 셋에서 받는다
- **직업 T2 가 직업을 안 가른다** — T2-1·T2-2 는 5직업 동일이고 T2-3 하나만 갈린다. 죄종이 T1 공통 → T2 에서 갈리는 것과 반대 모양인데, 직업 개성은 T1 이 이미 졌으므로 구조상 문제가 아니다

**옛 근거는 그대로 유효하다 — D2 무기 마스터리 실패** ([diablo2/00_overview.md §1-1](../reference/diablo2/00_overview.md))

- D2 바바리안 무기 마스터리 6종은 **피해 %와 치명 %가 여섯 다 동일**한 「같은 효과의 6장 복제」였고, 그 결과 마스터리가 결정이 아니라 **세금**이 됐다. 무기 선택은 마스터리가 아니라 룬워드·아이템 개체가 갈랐다 — **인과가 뒤집혔다**
- **20년 뒤 예외가 딱 하나 생겼다** — D2R 2.4 에서 **투척 마스터리만** 다른 축(관통 · 소모 미차감 · 치명 시 보충)을 받았고 개발자가 밝힌 이유는 「투척만 무기가 너무 빨리 떨어진다」였다. **유일하게 다른 축을 받은 무기가, 유일하게 구조적 제약을 가진 무기다**
- **반대 사례** — 소서리스 원소 마스터리는 **콜드만 「적 저항 감소」(적 쪽)** 이고 나머지 둘은 「내 피해 배율」(내 쪽)이라 축이 갈렸고, 그래서 **최적 투자량까지 달라졌다.** T2-3 마법사 칸이 이 형태를 그대로 쓴다
- 요약 — **마스터리가 같은 축이면 세금이 되고, 다른 축이면 결정이 된다**

**폐기된 서브트리안의 기록** [2026-09-07] — 전사(둔기 / 도끼) · 기사(창 / 양손검) 로 갈라 「약점을 줄여준다」를 각각 짜려 했으나, 10 무기군의 약점이 **「한 방이 약하다 · 뜸하다 · 운에 휘둘린다」 셋으로 뭉쳐** 복제를 피할 방법이 없었다. 게다가 「운에 휘둘린다」를 처방하려면 변동을 미는 신규 스탯이 필요해 결국 T2-1 의 「최소 데미지」로 수렴한다.

### 3-6. 갑옷 마스터리 [신설 2026-09-07 — 사용자 확정]

**갑옷 한 칸에만 적용한다.** 투구·장갑·신발은 갑옷군을 갖지 않는다 — 「방어구 4부위 전체」안은 폐기 ([item_design.md](item_design.md) §1).

| **경갑** | 방어력 중간 + 공격속도 | **체력** | 궁수 |

- **셋 다 자기 갑옷군이 안 주는 축을 준다** — §3-5 무기 마스터리와 같은 「약점을 줄여준다」 형태다. item_design.md §1 의 「갑옷군이 이미 쓰는 축을 숙련이 또 주면 격차가 곱으로 벌어진다」도 셋 다 통과한다
- **직업 관점** — 전사·기사(중갑)는 느리고 무거운 대신 속도를 얻고, 궁수(경갑)는 물러서 약한 대신 체력을 얻고, 마법사·사제(로브)는 가장 얇은 대신 방어력을 얻는다
- **하드 게이트는 여전히 없다** — 마법사가 중갑을 입어도 되고 로브 마스터리 보너스만 못 받는다. 09-01 이 소프트로 둔 근거(도발을 뽑은 마법사의 탱커 빌드)는 그대로 산다
- ⚠ **경갑이 궁수 혼자다** — 중갑 2직업 · 로브 2직업 · 경갑 1직업이라 경갑 드롭이 상대적으로 남는다. 확장(암살자)이 오면 풀린다
- ⚠ **로브 마스터리가 갈래 정의를 흐린다** — 09-01 의 핵심은 「**갑옷 = 방어력의 주 출처**이고 갈래가 방어력 크기를 정한다 — 그래야 3택에 무게가 실린다」였다. 값을 작게 잡아 「로브 입은 마법사 < 중갑 입은 전사」가 유지돼야 한다
- ⚠ **결정이 얇다** — 직업마다 갑옷군이 고정이고 갑옷이 한 칸이라 「자기 군을 낀다」가 언제나 정답이다. 남는 결정은 **자기 군이 안 떴을 때 다른 군의 좋은 개체를 낄지** 하나뿐이고, 소프트 게이트로 둔 값이 거기서 나온다
- ⚠ **티어 자리 미정** — T2 는 세 칸(무기 2 + 직업별 1)이 찼다. T2 를 네 칸으로 늘릴지 T3 로 내릴지 미정이고, T3 는 조건부(반응 패시브) 층이라 단순 수치형인 갑옷 마스터리와 성격이 안 맞는다 (§7)

## 4. 전직 — 직업마다 3갈래 [개정 2026-08-27 — 전직 종류 신설]

**직업마다 전직이 3갈래 있고, 그중 하나를 고른다.** 고른 전직이 **액티브 3개**를 주고, **그중 1개를 찍는다.** 찍은 그 스킬 하나가 세부 트리의 뿌리가 된다 (§4-2 B안 확정 2026-08-28).

```
직업 (5)  →  전직 3갈래  →  전직당 액티브 3 → 그중 1개 선택 → 그 스킬의 전용 트리
                            본편 = 5 × 3 = 15 전직 · 액티브 45 · 화면에 오르는 것 1
```

**액티브가 나오는 층은 전직 하나다** [2026-08-28] — 죄종·직업 두 마스터리는 **전부 패시브**이고 액티브를 주지 않는다(§1-4). 액티브 3칸의 출처는 §2 대로 **영웅 고유 · 무기군 · 전직**이며, 그중 **트리를 갖는 것은 전직 칸뿐**이다.

- **08-26 판에서 바뀐 것** — 종전엔 「전직 = 사건 하나 · 액티브 3개를 셋 다 보유 · 3택1이 아니다」였다. 전직이 갈래를 가지면서 **「3택1이 아니다」가 폐기**된다. 대신 3택1의 대상이 액티브가 아니라 **전직**이다
- **살아남는 것** — 「포인트를 넣은 것에만 세부 트리가 열린다」 · **전용 포인트**(마스터리와 풀을 나눈다 — 공유하면 전직 레벨까지 안 찍고 모으는 게 최적이 되어 초반이 통째로 무력해진다)
- **함께 폐기된 것** [2026-08-28] — ~~두 액티브에 나눠 넣는 **몰빵 vs 분산**~~. 찍는 액티브가 하나로 확정되면서(§4-2 B) 배분할 뿌리가 둘 이상이 아니게 됐다. **전직 포인트의 결정은 「어느 스킬을 찍나」 한 번**이고, 그 뒤는 그 트리를 얼마나 파느냐(§1-3 깊이)다
- 전직은 **그 게임 처음의 스킬 결정**이다 — 그 앞 구간에 액티브 결정이 없으므로(§2) 여기에 무게가 실린다
- 해금: `[balance.csv:advance_unlock_level]`

### 4-2. 액티브 칸 · 전직 액티브의 선택 — **B안 확정** [⚠제안 2026-08-27 · 세 안 정리 2026-08-28 · **B 확정 2026-08-28**]

전직이 액티브를 **3개** 주는데 §2 의 전직 칸은 하나다. 그대로면 만든 것 중 **화면에 나오는 건 하나**뿐이고, 관전이 본편인 이 게임에서 화면에 안 나오는 스킬은 값을 못 한다(§1-1 기준 2).

| 안 | 내용 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| **A. 1개 고정** | 전직이 액티브 하나를 정해서 준다 | 전직 액티브 15개로 끝 · 밸런스가 쉽다 · 전직 이름 ↔ 화면이 1:1 | 전직 후 스킬 결정이 0 — 전직이 「그 게임 처음의 스킬 결정」(§4)인데 고르는 순간 끝난다 |
| **B. 3개 중 1개** ✅ | 3개를 주고 그중 **하나를 찍는다** — 찍은 것만 칸에 오르고 **찍은 것만 트리가 열린다** | **앞 2칸(고유 · 무기군)의 구멍을 메우는 결정**이 된다. 답이 영웅마다 다르다. ~~무료 롤백이 있어도 「최적 하나」로 안 굳는다~~ ⚠**반증됨** — 아래 | 45개를 만들어 15개만 쓴다 · 셋 중 하나만 세게 나오면 나머지 둘이 죽어 결과가 A 와 같아진다 |
| **C. 전부 지급** | 전직당 2개를 만들고 둘 다 칸에 올린다 (칸 3 → 4) | 만든 것이 전부 화면에 나온다 · 고르는 것이 **두 뿌리의 포인트 배분**으로 내려간다 | 파워가 계단으로 뛴다(몬스터 전역 스케일 재보정) · §2 「액티브 3 — 출처 고정」이 깨진다 |

**B 가 성립하는 조건 하나 [2026-08-28]** — 셋이 **「센 순서」가 아니라 「역할」로 갈려야 한다.**

```
O  단일 딜 / 광역 딜 / 버프        → 앞 2칸을 보고 고른다
X  강한 딜 / 중간 딜 / 약한 딜      → 무조건 강한 것
```

이 조건은 갈래를 짤 때마다 검사한다 — 검사 결과는 §10-6.

**B 확정 [2026-08-28]** — 액티브 칸 수는 **3 그대로**(§2 영웅 고유 · 무기군 · 전직)이고, 전직 칸에는 **찍은 하나**가 오른다. 확정으로 따라오는 것 넷:

| | 내용 |
|---|---|
| **트리는 찍은 하나에만 열린다** | 「포인트를 넣은 것에만 세부 트리가 열린다」(§4)의 대상이 **정확히 1개**로 좁혀졌다. 두 뿌리에 나눠 넣는 몰빵/분산은 폐기(§4) |
| **A · C 폐기** | A(1개 고정)는 전직 후 결정이 0이라 탈락 · C(전부 지급)는 칸 3을 깨고 파워가 계단으로 뛰어 탈락 |
| **⚠ 뿌리 45개가 확정됐다** | 어느 것을 찍든 트리가 있어야 하므로 **B 는 뿌리 수를 안 줄인다.** §6 이 「§4-2 와 함께 판단한다」고 미뤄 둔 감축 판단이 **「줄이지 않는다」로 닫힌다** — 대신 트리 **형태**(깊은 트리 vs 얕은 티어)가 총량을 정한다. 미확정(§7) |
| **⚠ 캘리브레이션 민감도는 그대로** | 셋의 파워 예산이 같아야(§9-1 규칙 1) 역할로 고를 수 있다. 자동전투라 플레이어 실력이 어긋남을 못 덮는다 |

**⚠ 「무료 롤백이면 안 굳는다」가 반증됐다** [2026-08-28 — [diablo2/00_overview.md §2-1](../reference/diablo2/00_overview.md)]

D2 팔라딘의 **오라**가 정확히 그 조건이다 — 교체가 **무료·즉시**인데도 실시간 선택이 되지 못했고, 빌드마다 한 번 정하고 안 바꾸는 **장기 선택으로 굳었다.** 컨빅션·퍼내티시즘·컨센트레이션 소수만 반복 채택되고 나머지 다수는 **시너지 재료로만** 남았다.

- **B안은 유지한다** — 사용자 확정이고, 반증된 것은 **근거 하나**지 결론이 아니다
- **굳는 것을 막는 것은 롤백 비용이 아니라 위의 「역할로 갈려야 한다」 조건 하나뿐**이다. 그 조건 검사(§10-6)의 무게가 그만큼 커졌다
- **죽은 선택지가 시너지 재료로 흡수된 것**은 본작에도 대응이 있다 — 찍히지 않은 전직 액티브 2개를 세부 트리 노드로 내리는 처리(위 「미확정」 항). D2 는 그게 **자연히 일어났다**

## 5. 롤백 — 언제든 되돌린다 [확정 2026-08-26]

| 층 | 롤백 | 근거 |
|---|---|---|
| 마스터리 | **무료 · 수시** | 상시 수치라 최적해가 대체로 하나. 비용을 매겨도 결정이 아니라 통행세다 |
| 전직 특화 | **무료 · 수시** | 빌드 실험 자체를 재미 축으로 둔다 |

**롤백의 대상이 둘로 갈렸다** [2026-08-28] — §4-2 B안 확정으로 전직 층에 되돌릴 것이 두 겹이 됐다.

| 되돌리는 것 | 상태 |
|---|---|
| **찍은 액티브를 바꾼다** (3 중 다른 하나로) | 이 표대로 **무료 · 수시**. 트리 포인트가 새 뿌리로 옮겨간다 |
| **갈래 자체를 바꾼다** (광전사 → 바바리안) | **미확정** — §7 「전직의 롤백」 |

- ⚠ **무료면 「스테이지마다 갈아 끼운다」가 최적이 된다** — §4-2 B 의 「답이 영웅마다 달라서 최적 하나로 안 굳는다」는 **영웅 간** 차이를 말한 것인데, 롤백이 무료면 같은 영웅 안에서도 **스테이지마다 갈아 끼우는 게 최적**이다. §7 「전직의 롤백」이 갈래에 대해 지적한 「무료면 결정이 아니라 상황별 스위치」와 **같은 구조**가 액티브 층에도 생겼다
- **그 자체는 §1-3 이 이미 기능으로 받아들인 것이다** — 변형 노드가 「스테이지마다 갈아 끼울 진짜 이유」로 적혀 있다. 즉 **갈아 끼우기를 결함으로 볼지 재미로 볼지가 이미 갈려 있고**, 액티브 1택도 같은 자리에 놓인다. 갈래 롤백을 정할 때 셋을 한 번에 본다

- **되돌릴 수 있다는 게 이 게임의 연구다** — 잘못 찍어 영웅 하나를 버리는 일이 없어야 한다. 방치형의 통제성(CLAUDE.md 철학 2)과 같은 계열
- **대가로 두 문장이 폐기됐다** (§0) — "개성은 배분에서 나온다" · "배분과 편성의 분리". 자유 롤백이면 배분은 개성이 아니고, 배분 = 편성이다
- **스킬은 파밍 루프 밖에 남는다** — 롤백에 재화를 안 걸었으므로 스킬이 원정→드롭→재배분 루프에 붙는 접점이 없다. 그 자리의 후보는 **연구**(연구 탭 신설 섹션, 영웅 파견 없이 진행)다 — 스킬 노드·특화 해금을 연구가 담당하면 접점이 생기고 롤백은 무료로 남는다. [2026-08-31] 연구소(파견처)는 삭제됐다 — 연구는 파견처가 아니다. GAME_DESIGN.md §10 「스킬의 자리」

## 6. 콘텐츠 수량

```
트리 수      죄종 마스터리 7 + 직업 마스터리 N + 전직 뿌리 9N      (본편 N=5 → 57)
액티브 수    고유(유니크 15 + 레어 공용 풀) + 무기군 10 + 전직 9N  (본편 9N=45)
```

- **트리 안에 액티브 킷이 없어졌다** — 개정 전엔 "각 출처에 액티브 2개 이상"(구 §3)이라 트리 밖 정의까지 38개 이상이 필요했다. 지금은 무기군 7 + 전직 15 = 22 + 고유 풀
- 직업 1개 추가 비용 = 트리 2개(직업 마스터리 + 전직 특화) + 액티브 3개 — 선형
- ~~사제·마법사가 완드/스태프 숙련을 각자 트리에 두 번 짜는 중복이 남아 있다~~ — **2026-08-31 감수로 확정**(§3-4) — 무기 숙련은 무기군이 아니라 **직업 마스터리**에 귀속된다. 중복 제거보다 트리 축(죄종/직업/전직 셋)을 안 늘리는 쪽을 택했다 — 사제·마법사 T2 를 짤 때 이 중복을 실제로 마주친다
- **패시브가 셈에서 빠져 있었다** [2026-08-27] — 위 두 줄은 액티브만 센다. 실제 총량에는 **수치 패시브 노드 + 반응 패시브 노드**(§1-3, 트리 17개분)가 더 붙는다. 노드 규모(§7)가 정해지기 전에는 셀 수 없다
- **몬스터가 같은 풀을 쓰면 셈이 바뀐다** [2026-08-27] — 몬스터 액티브 2칸(§2)을 따로 만들면 총량이 늘지만, 직업 스킬 풀을 **영웅과 공유**하면 늘지 않는다. 어느 쪽인지가 부채 규모를 정한다 (§7 「몬스터 스킬 풀」)
- **08-27 개정으로 셈이 세 배가 됐다** [2026-08-28] — 종전 「전직 3N = 15」는 전직이 사건 하나이던 시절의 수다. 전직이 3갈래가 되고 갈래마다 액티브 3이면 **45**다. §4-2 의 A안(1개 고정)을 받으면 15로 돌아간다
- **무기군은 본편 10이다** [2026-08-28 「9」 · 2026-09-01 재편으로 8 · **2026-09-07 사제 전용 2종 신설로 10**] — `weapon_group.csv` 본편 10행(양손검 · 도끼 · 둔기 · 창 · 스태프 · 오브 · 활 · 석궁 + **성경 · 십자가**) · hero_design.md §2. **스태프·오브는 마법사 전용이 됐다** — 사제가 공유를 그만두면서 §6 이 09-01 에 감수하기로 한 「사제·마법사 숙련 중복」이 소멸했다. 종전 7·8·9 는 낡은 수다
- **⚠ 전직 뿌리 45개로 확정됐다** [2026-08-28 갱신] — 액티브마다 세부 트리가 하나면(§4) 전직 뿌리만 45다. 죄종 7 + 직업 5 를 더하면 57. ~~뿌리 수를 먼저 줄일지를 §4-2 와 함께 판단한다~~ → **§4-2 B안 확정으로 감축 경로가 닫혔다.** 3 중 1을 찍는 구조라 **어느 것을 찍든 트리가 있어야 하므로 45개가 전부 필요**하다. 총량을 정하는 손잡이는 이제 수가 아니라 **형태** — 깊은 트리면 45개를 못 짜고, **얕은 티어(선형 3~5단)면 감당된다.** 형태 미확정(§7)
- 본 프로젝트 최대의 콘텐츠 부채 — 노드 규모를 정할 때 총량 감각을 먼저 잡을 것

## 8. 보류 — 스킬 카드 합성

**[2026-08-25]** 비전투 활동 논의에서 나온 "합성"은 파견처 활동이 아니라 **스킬 카드 합성**이라는 별개 개념이다. 후속 과제 — 스킬 카드가 무엇인지(마스터리 2 + 특화 1 · 액티브 3 과의 관계)부터 정의한다. 넣을 때 별도 파견처(공방)를 세우지 않고 **제련소 기능**으로 들어간다. 정의 전까지 다른 문서에서 참조하지 않는다.

**불채택 기록** — "액티브 셋째 칸 = 스킬 카드(몬스터 카드 제작)" 안: 새 시스템 4~5종 · 드롭 운 · 카드는 낡지 않아 몰빵이 영구화 · 초반 빈칸. 카드의 가치(파밍 동기·제련소·수집)는 액티브 칸과 무관한 별개 결정.

### 9-1. 짜는 규칙 여섯 [개정 2026-08-27 — 규칙 4·5 폐기 · 6 신설]

**1. 파워 예산은 DPS 기여 하나로 잰다.** 마나가 없고 비용이 행동 1회뿐이라(battle_design.md §3) 잴 것이 셋밖에 없다.

```
N            = ceil( 표기 쿨 ÷ 행동 주기 )        한 사이클의 차례 수 (실효 쿨 = N × 행동 주기)
DPS 기여     = ( 스킬 배율 − 1 ) ÷ N              기본 공격 = 배율 1
목표         = [balance.csv:skill_dps_budget_pct]
```

**2. 버프는 가동률로 잰다.** 창이 열려 있는 비율에서 자기 행동 1회를 뺀다.

```
순 기여 = ( 지속 ÷ 실효 쿨 ) × 효과% − 1 ÷ N
```

파티 창은 **개인 스킬 하나를 파티 인원으로 나눈 값**이 기준이다. 인원수만큼 곱하면 파티 버퍼가 통행증이 된다 — hero_design.md §2 「사제 서약」과 같은 계열의 가드다.

⚠ **이 자에는 대상 수 K 가 없다** [2026-08-27] — 광역 스킬은 `(배율 × K − 1) ÷ N` 이라야 맞는데 K 항이 없어서, 문서의 자만으로는 광역이 예산에 맞는지 검증되지 않는다. 그리고 K 는 라운드 타입마다 흔들린다(`round_budget.csv` — 일반 1~3 · **챕터보스 단독 1**). K 를 명시하는 것은 §7.

**3. 직업 축만 준다 — 죄종 축은 액티브가 주지 않는다.** 15개 중 치명 배수 · 방어 무시 · 저항 감소 · 흡혈 · 반사 · 재생 · 드랍을 주는 것은 하나도 없다. 전부 [1] 상시 피해 % 와 [3] 내 쪽 방어에 얹힌다 (§3 축 분담의 직업 자리).

- **확정 치명이 액티브에서 빠졌다** [2026-08-27] — 저격의 `always_crit` 폐기. 치명은 액티브가 아니라 **마스터리**가 담당한다(§3 · 자리는 §7). 액티브가 치명에 닿는 것이 이제 하나도 없다
- 왜 — 축 분담이 마스터리에서만 지켜지고 액티브에서 새면 죄종 마스터리가 "액티브가 이미 주는 것을 조금 더 주는 탭"이 된다

**4. 상태이상을 연다** [개정 2026-08-27] — 종전 「상태이상 0」 폐기. 액티브가 상태이상을 **부여**할 수 있다(마법사 아이스 블라스트 = 결빙). 여는 순간 따라오는 것 둘: ① 「부여는 전술카드 전담」 분담(§3-1 색욕)이 재작성된다 ② 본작 `status_effect.csv` 신설이 필요하다. **세부는 §7** — 결빙의 정의 · 오만 정예(상태이상 면역)와의 대조 · `fhr` 와의 관계.

**5. 진형은 없고, 타겟팅은 있다** [개정 2026-08-27 · **타겟팅 확정 2026-09-08**] — 종전 「진형·타겟팅에 기대지 않는다」 폐기. **위치(전열/후열)는 두지 않는다** — 이동 · 사거리 · 장판 계열이 전부 탈락한다. 대신 **대상 선택 규칙(타겟팅)은 확정 대상**이다. 도발(「그 창 동안 모든 적의 대상이 기사로 고정」)은 위치가 아니라 대상 선택 규칙만 요구하므로 진형 없이 성립한다. **[확정 2026-09-08] 그 대상 선택 규칙이 정해졌다 — 영웅·몬스터 양쪽 다 생존 대상 중 균등 무작위이고 예외는 도발 하나다** (battle_design.md §3-1 · GAME_DESIGN.md §9 09-08).

- 진형을 두지 않기로 하면 함께 풀리는 것 넷 — 무기군 Implicit 보류 해제 · **다중타격 분배**(거리 감쇠가 없다) · `crushing_blow` · `counter_dmg` 등재 (battle_design.md §9-9)
- 대가 — 몬스터가 회복·대상 제어를 들면 플레이어가 「뒤를 지키는 놈」을 못 뚫는다. 그 대응은 타겟팅 우선순위이고, 자리는 **전술카드**다 (tactic_card_design.md §3). §7

**6. 라이더는 액티브가 아니라 반응 패시브다** [신설 2026-08-27] — 「처치 시 쿨 초기화」 · 「명중 시 자기 창」 같은 것은 행동을 따로 먹지 않으므로 §1-2 의 **반응 패시브**다. 위 1번 자로 재지 않는다. 액티브에 라이더를 붙이면 그만큼 **예산 밖으로 새므로**, 붙일 때는 그 사실을 명시한다.

- **마법사 — 연쇄 번개는 감쇠한다** [개정 2026-08-27] 종전 「다수 대상 = 전원에게 각각 독립 직격 · 감쇠 없음」에서 이 스킬만 예외로 뺀다. 진형이 없어도 **타격 순서**만 있으면 정의되므로 위치를 요구하지 않는다. ⚠ 순서가 정해지면 rng 소비 수열이 그만큼 늘어난다 (INTERFACE.md rng 순서 계약)
- **궁수 — 확정 치명이 빠졌다** [개정 2026-08-27] 저격의 `always_crit` 폐기. 그 결과 저격의 특이성이 **배율 크기 하나**만 남았고, 「장쿨 단일 강타」가 배쉬 · 파이어볼 · 저격 · 심판 **넷**이 됐다. 형태 중복은 인정된 상태 — 궁수의 개성은 마스터리(치명)에서 나온다는 전제다. 넷을 갈라야 한다면 §7
- **사제** — 치유의 빛이 단일에서 **파티 회복**으로 바뀌고 성역(광역 회복)은 소멸했다. 셋 중 하나가 딜인 것은 「사제 서약」(hero_design.md §2 — 사제 없이도 최전선이 성립해야 한다) 때문이다. 심판의 언데드 조건부는 **제거** — 조건부 % 는 [2] 죄종 자리라 액티브가 주면 규칙 3 위반이다
- **사제 — 신속은 스킬 비중을 낮춘다** [2026-08-27] `N = ceil(쿨 ÷ 행동 주기)` 이므로 행동 주기가 줄면 N 이 커지고 스킬 DPS 기여 `(배율−1)÷N` 이 **작아진다**. 즉 신속은 기본 공격을 키우고 스킬을 상대적으로 죽인다 — §9-4 파생 관측 2(「느린 무기가 스킬을 더 잘 쓴다」)의 정확한 역방향이다. 버그가 아니라 성질이고, 캘리브레이션에 이 항이 들어가야 한다

- **역할 배치를 3×3 으로 맞추지 않았다** — 원소 정의가 셋 다 다른 종류(피해+디버프 / 상태이상 / 피해+분포)인데 역할까지 격자로 맞추면 정의가 죽는다. 빙결술사는 유틸 없이 딜 셋이고 그게 「부여 → 소비」를 닫는 값이다
- **프로즌 아머 폐기** — 「파티 얼음 방어막」은 기사 **수호의 방벽**(파티 배리어)과 같은 것이라 기사의 정체성을 깎는다. 그 자리를 빙결 폭발이 받았다
- **히드라는 소환이 아니다** — ⚠ **논거는 09-09 에 뒤집혔다**(§12-6 프로즌월이 「소환」 을 열었다). 히드라를 소환으로 되돌릴지는 별건이고, **아래 논거 자체는 소환의 비용을 재는 근거로 계속 유효하다.** ~~타겟팅 확정이 선행~~(**해소 09-08**)이지만 **유닛을 추가하면 적의 무작위 대상 풀이 늘어 파티의 실효 피격이 희석**되고 파워 예산도 못 잰다(행동 1회로 여러 턴 딜). **창 동안 주기적 화염 타격이 자동으로 나가는** 형태로 두면 유닛 없이 체감이 같다
- **정전장이 마법사만의 해답이다** — 광역인데 **현재 HP 비율**이라 보스 단독전에 강하다. 「광역이 K=1 에서 기여를 잃는다」(§7)를 자기 갈래로 푸는 유일한 형태
- **화염이 몬스터 힐러 문제를 푼다** — 타겟팅이 자동이라 「힐러부터 잡아라」를 실행할 수단이 없는데, 화염 광역은 대상을 지목하지 않고 **적 전원의 치유를 깎는다**. 몬스터에 회복을 주기로 하면 전술카드를 안 열고도 대응이 생긴다. ⚠ 반대로 몬스터에 회복이 없으면 치유 감소는 사제·물약·흡혈에만 걸리는 반쪽 축이다 (§7)

- **분노 죄종과 설계된 시너지가 생긴다** — 분노는 **저체력이면 세지고**(수동 · §3-1), 광전사는 **태워서 세진다**(능동). 축이 달라 중복이 아니고, 태우면 저체력이 되므로 **「분노 광전사」가 겹쳐서 배가된다.** 죄종×직업 35칸에 처음 생기는 의도된 조합
- **고정 피해 채널 미결을 안 연다** — 폐기된 투기 태세가 「창 동안 타격마다 **고정 피해** 추가」라 §7 「고정 피해 채널」을 강제로 열었다. 버서크의 피해 추가는 **`%` 가산**이라 공식 [1] 상시 괄호에 덧셈으로 들어가고 새 채널이 0 이다. 고정값으로 두면 그 문이 다시 열린다
- ⚠ **역할 판정은 아직 `△` 다** — ③이 딜이라 「자기 창 3개」는 벗어났지만 ①②가 둘 다 자기 창이다. 「안전(라그나로크) ↔ 화력(버서크)」으로 갈리긴 하는데 단일/광역/생존 같은 배타적 역할은 아니다 (§10-6)
- ⚠ **태우기만 하고 회수가 없다** — ②③이 둘 다 HP 를 소모하는데 갈래 안에 되찾을 수단이 없고, 라운드 간 자동 회복도 없다(battle_design.md §1). 회수 경로가 전부 갈래 밖이다 — **흡혈(폭식 죄종·장비 접사) · HP 재생(나태) · 사제 · 물약.** 즉 **광전사는 흡혈 전제 갈래**가 되는데, 그게 의도된 커플링인지 함정인지가 미결이다(§7). ①에 회복·소모 무효를 얹으면 「태우는 창 ↔ 버티는 창」으로 순환이 닫힌다
- ⚠ **광전사에 광역이 0 이다** — 셋이 자기 창·자기 창·단일이라 다수전 수단이 없다. **전사 기본 ③(§7)이 광역이어야** 9라운드가 성립한다
- **바바리안이 라운드 타입에 반응한다** — 챕터보스는 단독 1(`round_budget.csv`)이라 휠윈드가 기여를 잃는 자리를 고대인의 망치가 받는다. 「잡몹전 = 휠윈드 / 보스전 = 망치」
- **선봉장 셋은 전부 소리인데 하는 일이 다르다** — 때린다 / 아군을 키운다 / 적을 깎는다. §9-2 의 「파티 창이 공격·방어·속도로 갈렸다」에서 전사 몫이 여기로 자란다
- **무기군은 갈래 축이 아니다**(§4-1) — 도끼·둔기·창은 자유 조합이고, 궁합은 `action_period` 에서 자연히 생긴다
- **새 규칙 둘** — **HP 소모 비용**(버서크·동귀어진 — 「소모 HP 당 피해 계수」 손잡이가 필요하다) · 스턴(지진). 둘 다 §7. ~~고정 피해 채널~~ 은 투기 태세 폐기로 **요구가 사라졌다**

### 10-4. 궁수 — 타격의 리듬 [확정 2026-08-28]

**진형이 없어서 「원거리」가 기계적으로 표현되지 않는다**(§9-1 규칙 5 — 사거리 · 위치 없음). 그래서 축은 거리가 아니라 **타격을 어떻게 쪼개는가**다. 기본 3(저격 · 연사 · 멀티플)이 이미 그 축이다.

| 전직 | 성격 | (1) | (2) | (3) |
|---|---|---|---|---|
| **저격수** | 느리고 무겁게 | **정조준** — 창 동안 피해 대폭 증가 + 자기 행동 주기 증가 | **사냥 표식** — 지정 대상에게 파티 전체 피해 증가 창 | **일격** — 단일 초대형 강타 |
| **보우마스터** | 빠르고 잘게 | **속사** — 창 동안 자기 행동 주기 급감 | **난사** — 단일 다단, 타수 대폭 | **탄막** — 다수 × 다단 |
| **레인저** | 독과 구속 | **독화살** — 독 속성 + 도트 | **맹독** — 독에 걸린 대상에게 추가 피해 | **족쇄 화살** — 단일 + 행동 지연 |

- **저격수 ↔ 보우마스터가 같은 손잡이를 반대로 돌린다** — `N = ceil(쿨 ÷ 행동 주기)` 이라 행동 주기를 **늘리면** N 이 줄어 스킬 한 방이 무거워지고, **줄이면** N 이 커져 평타가 본체가 된다(§9-2 사제 항 · §9-4 관측 2). 두 갈래가 수치가 아니라 **전투의 리듬**으로 갈려서 관전 화면에서 바로 구분된다
- **치명은 액티브에 안 넣었다** — §7 이 「치명 확률의 자리 = 궁수 **직업 마스터리**」를 후보로 두고 있어서, 저격수의 개성을 치명이 아니라 행동 주기로 잡았다. §9-1 규칙 3 과도 정합
- **독이 궁수로 정해진다** — §10-1 의 「독은 네크로맨서 또는 궁수」가 여기서 닫힌다. ⚠ 다만 **레인저가 통째로 도트에 걸려 있다** — §7 「화상(도트) 도입 여부」가 안 열리면 이 갈래는 못 짠다. 도트는 매 틱마다 피해 이벤트라 관전 타임라인과 rng 소비 수열이 늘어난다(INTERFACE.md rng 순서 계약)
- **활 ↔ 석궁 차별화는 여전히 미정**(hero_design.md §2). `weapon_group.csv` 가 활(주기 1.4 · 편차 14) / 석궁(주기 1.8 · 편차 20)으로 이미 갈라 놔서 석궁이 저격수에 활이 보우마스터에 자연히 붙지만, **갈래 축으로 박지는 않았다** — 전사에서 무기군 축을 버린 것과 같은 이유(§4-1)

|---|---|---|---|---|---|

**몽크가 사제의 구조적 구멍을 메운다** — `weapon_group.csv` 상 사제 무기는 오브·스태프 둘뿐이고 **둘 다 `damage_kind=magic`** 이라 **마법 저항이 높은 적 앞에 답이 없었다.** 기사 크루세이더의 **정확한 거울**이다(§10-3 — 기사는 무기군이 둘 다 `physical` 이라 화염 태그 「성화」로 물리를 우회했다). **무기군은 늘리지 않는다** — 몽크는 스태프(봉술)를 그대로 들고 **액티브만 물리 태그**를 갖는다. `weapon_group.csv` 에서 `staff` 의 `action_period` 가 무기군 중 가장 느려 「한 방이 무겁다」와도 붙는다.

**사제 서약이 강도 조정이 아니라 구조로 지켜진다** — 셋 중 둘(검은사제 · 몽크)이 딜이라 「사제를 뽑았는데 힐을 안 한다」가 성립한다. hero_design.md §2 「사제 없이도 최전선이 성립해야 한다」가 **전직 구성만으로** 충족되므로, 종전의 보류 사유(서약과의 강도 조정)는 해소됐다.

**검은사제와 몽크가 둘 다 딜이지만 겹치지 않는다** — 검은사제는 **상태이상을 매개로** 하고 몽크는 **상태이상과 무관**하다. 상태이상이 잘 걸리는 구간엔 검은사제, 안 걸리거나 마법 저항이 높은 구간엔 몽크다. 그래서 **몽크 3 만 상태이상 기계와 무관하게 먼저 짤 수 있다.**

### 10-7. 뿌리로서의 적합성 — 노드를 걸 자리가 있는가 [2026-08-27 · 갱신 2026-08-28]

액티브는 **트리의 뿌리**다(§4). 그러므로 고르는 기준은 「이 스킬이 재밌나」가 아니라 **「여기서 가지가 몇 개 뻗나」**이고, 뻗을 가지는 그 스킬이 가진 **파라미터의 수**로 정해진다.

| 파라미터 | 가진 스킬 | 뻗는 가지 |
|---|---|---|
| 타수 | 질 · 연사 · 난사 · 휠윈드 · 탄막 | 타수 +1 / 타격마다 ~ |
| 대상 수 | 휠윈드 · 멀티플 · 노바 · 사자후 · 지진 · 탄막 · 천벌 | 대상 +1 / 대상 수만큼 ~ |
| 감쇠율 | 연쇄 번개 | 감쇠 완화 / 마지막 대상에게 ~ |
| 지속 | 함성 · 방벽 · 신속 · 히드라 · 라그나로크 · 버서크 · 호령 · 일갈 · 엄호 · 철벽 · 결투 · 정조준 · 속사 · 사냥 표식 · 가호 | 지속 연장 / 창 중 ~ |
| 총량 | 배리어 · 서약 | 총량 증가 / 남은 만큼 ~ / 깨질 때 ~ |
| 조건 임계 | 단죄 | 임계 완화 / 조건 충족 시 ~ |
| 상태이상 | 아이스 블라스트 · 프로즌 오브 · 블리자드 · 지진 · 방패 강타 · 독화살 · 족쇄 화살 · 속박 | 지속 연장 / 걸린 대상에게 ~ |
| 비율 | 정전장 | 비율 상향 / 상한 완화 |
| 대가 | **버서크 · 동귀어진**(HP 소모) · 정조준(느려짐) | 소모량 감소 / 소모한 만큼 ~ |

- **밋밋한 뿌리 넷** — 배쉬 · 파이어볼 · 저격 · 심판은 가진 파라미터가 **배율 하나**뿐이라 뻗을 가지가 「배율 +x%」밖에 없다. 형태 중복(§7)일 뿐 아니라 **트리가 안 자란다**
- 다만 넷이 전부 **기본** 쪽에 몰려 있는 건 오히려 맞다 — 기본은 평범하고 전직이 성격을 준다. 밋밋함이 결함이 아니라 계단이 된다. ~~D2 의 Bash → Concentrate → Berserk 계보와 같은 모양~~ → **인용 정정 2026-08-28**, §1-3 참조
- **빙결 폭발은 원래 깊은 노드 후보였다** — 「결빙된 적을 때리면 터진다」는 반응 패시브(§1-3)에 딱 맞는 형태다. 액티브로 올린 지금도 **트리 깊은 곳에 반응 패시브판을 따로 둘 여지**가 남아 있다

- **`restore`·`boost` 는 `heal`·`buff` 를 피한 이름**이다 — 그 둘은 `kind` 컬럼이 이미 쓰고 있어서, 같은 파일 안에 한 단어가 두 뜻을 갖게 된다

### 11-1. 갈리는 기준

| | 아군·자기 | 적 |
|---|---|---|
| **파티** | `함성` `축복` `회복` | `저주` `제어` |
| **자기** | `강화` | — |

> `함성`·`축복` 은 **창**(지속이 있다) · `회복` 은 **즉시**(되돌린 HP 는 창이 끝나도 안 사라진다)
> `저주` 는 **수치**를 깎고 · `제어` 는 **행동**을 막는다
> **배리어**(수호의 방벽)는 HP 밖의 흡수 풀이라 `회복` 이 아니라 `축복`
> `희생` 은 효과가 아니라 **비용**이라 기타 — 마나가 없는 이 게임(battle_design.md §3)의 **유일한 제2 비용 축**

### 11-2. 규칙 넷

1. **`tags` 컬럼은 최대 2** · `|` 구분 · 없으면 `-`
2. **파생 태그 셋(`광역`·`단일`·`다단히트`)은 `tags` 칸을 안 먹는다** — `target`·`hits` 에서 읽는다. 파생 가능한 것을 컬럼에 또 적으면 두 곳 관리가 되어 반드시 어긋난다
3. **`enemy_rotate`(질)는 광역으로 세지 않는다** — 타수만큼만 닿는다
4. **정의는 2 까지, 세 번째 태그는 변형 노드가 준다** (§1-3)

- **값은 영문 id** · 표시 이름 ko/en 은 `skill_tag.csv` — `src/data/README.md` 공통 규약(기계가 읽는 컬럼은 전부 영문)
- **구분자는 `\|`** — 프로젝트 공통 규약(2026-08-28 확정 · `classes`·`combat_stat`·`dispatch` 가 이미 쓴다). `csv.js` 가 `line.split(',')` 한 줄이라 **셀 안의 쉼표는 그 자리에서 컬럼을 늘린다** — `[a,b]` 형태는 쓸 수 없다
- `element` 를 태그로 중복하지 않는다 — `element` 컬럼이 이미 갖는다
- 2칸을 다 쓰는 예 — 버서크 `강화\|희생` · 블리자드 `저주\|제어` · 서약 `축복\|회복`
- 휠윈드는 `광역`+`다단히트` 둘 다 갖지만 **파생이라 `tags` 는 비어 있다**

### 11-3. 전술카드가 셀 때 [2026-08-28]

- **편성 시점에 확정된다 — 조건으로 적법하다.** 기본(직업이 정한다) · 무기군(장비가 정한다) · 전직(배분이 정한다) 셋 다 출발 전에 정해지므로 tactic_card_design.md §2-1 의 「편성 화면에서 켜짐/꺼짐이 확정되는 것만 참조」를 통과한다
- ⚠ **`단일`·`광역` 은 조건으로 쓸모가 없다** — 거의 모든 스킬에 걸려서 어떤 편성이든 만족한다. 카드는 **희소 태그**(`제어` · `회복` · `희생` · `저주` · `도트`)를 세는 게 원칙이다
- ⚠ **이중 보상 주의** — 접사 카운트 조건에 붙어 있던 경고(tactic_card_design.md §4)가 스킬 태그에는 더 세게 걸린다. 접사는 스탯만 주지만 **스킬은 전투에서 실제로 일을 한다.** 「`저주` 3개 이상이면 피해 증가」면 이미 적을 약화시켜 놓고 보상을 또 받는 것이라, **세는 방향과 보상 방향을 다르게** 둔다

### 11-4. 미배정 — 태그가 없는 스킬

`정화`(상태이상 해제 — HP 를 안 준다) · `정전장`(비율 피해) · `단죄`(처형). 셋뿐이다. 카드가 이들을 세야 하는 순간이 오면 `피해 방식` 에 `비율`·`처형` 을, `버프` 에 `해제` 를 추가한다 — **지금 미리 만들지 않는다.**

## 12. 직업 스킬 풀 — 1스킬 = 1직업 [신설 2026-09-08 — 사용자 확정]

> SSOT: **`skill.csv` 재작성 예정** — 아래 목록은 확정이고 CSV 반영은 `/client` 몫이다. 값(배율 · 타수 · 쿨 · 지속)은 **전부 미발행**

**스킬은 직업에 귀속된다.** 한 스킬은 한 직업에만 있고 직업 사이에 겹치지 않는다. §9 의 프로토타입 15개와 무기군 고정 배정이 여기서 대체된다.

### 12-1. 확정 규칙 넷

1. **1스킬 = 1직업** — ~~고유 풀 = 직업 비종속 · 균등~~(09-01 §9-0) **폐기**. 마법사가 배쉬를 드는 일은 없다
2. **무기군 고정 폐기** — ~~무기군이 스킬의 종류를 정한다~~(§2-1) **폐기**. 스킬은 무기군이 아니라 **직업**에 붙으므로 **전사 스킬이면 전사가 든 무기 아무거나** 담을 수 있다
3. **두 출처가 같은 풀에서 가져간다** — 영웅(고유 칸)도 무기(무기 칸)도 **그 직업 풀**에서 하나씩 온다 (§2)
4. **형태로 분류한다** — §12-2 의 어휘

### 12-2. 형태 어휘 [확장 2026-09-09 — 디버프 · 소환 추가]

| 형태 | 뜻 | 주로 드는 직업 |
|---|---|---|
| **단일** | 적 하나를 때린다 — 타수는 형태를 가르지 않는다(두 번 때려도 단일) | 전부 |
| **광역** | 적 여럿을 때린다 | 전부 |
| **함성** | 시전형 창 · **중첩된다** (§1-5) | 전사 |
| **오오라** | 쿨 없이 상시 · **한 번에 하나만** (§1-5) | 기사 |
| **버프** | 시전형 창 — 자신이나 아군에게 얹는다 | 궁수 · 마법사 · 기사 |
| **디버프** | 시전형 창 — 적에게 건다 | 기사 · 전사 |

- ⚠ **어휘가 두 축을 한 칸에 섞고 있다** — **전달 방식**(단일 · 광역 · 함성 · 오오라 · 소환)과 **효과 방향**(버프 · 디버프)이 같은 열에 들어 있어서, 전사 도발(`함성 · 디버프`)처럼 둘이 붙기도 하고 기사 인챈트(`버프`)처럼 하나만 서기도 한다. 두 축으로 쪼개는 정리는 §7

### 12-3. 전사 7 [확정 2026-09-08]

| 스킬 | 형태 | 설명 |
|---|---|---|
| 배쉬 | 단일 | 적을 강하게 내리쳐 피해를 입힌다 |

| 배틀오더스 | 함성 · 버프 | 양 옆의 아군의 최대 체력을 증가시킨다 |

- **전사는 함성 직업이다** — 셋이 전부 시전형 창이고 **중첩**으로 돈다. 최적화가 「창을 어떻게 물리는가」에 걸린다
- **도발이 기사에서 전사로 넘어왔다** — §7 「도발 vs 엄호」 가 「파티 탱킹은 도발·엄호가 전담」으로 정리해 둔 것 중 **도발 쪽이 전사 몫**이 된다. 전사는 **적 전원을 짧게** 끌어오고, 기사는 결투 선언으로 **하나를 끝까지** 문다(§12-4) — 폭과 길이가 반대라 둘 다 필요하다
- **광역 둘로 §7 「전사 ③ 의 형태」 와 §10-2 「광전사에 광역이 0」 이 함께 풀린다**
- ⚠ **「양 옆의 아군」이 위치를 요구한다** — §9-1 규칙 5(위치 없음)와 부딪힌다. §7

### 12-4. 기사 8 [확정 2026-09-08 · 개정 2026-09-09]

| 스킬 | 형태 | 설명 |
|---|---|---|
| 스마이트 | 단일 | 방패로 적을 후려쳐 피해를 입힌다 |
| 차지 | 단일 | 적에게 돌진해 부딪히며 피해를 입힌다 |
| 질 | 광역 | 적들 사이를 돌며 정해진 타수를 나눠 꽂는다 |
| 결투 선언 | 디버프 | 적 하나를 지목한다. 지목된 적은 **라운드가 끝날 때까지** 기사만을 노린다 |
| 인챈트 | 버프 | 일정 시간 동안 무기에 화염 데미지를 추가한다 |

- **기사는 오오라 직업이다** — 전사(시전형 창)와 정확히 대칭이고, 결정이 「언제 거는가」가 아니라 **「무엇을 켜는가」** 하나로 모인다 (§1-5). 오오라 셋이 **공격 · 속도 · 방어** 삼각이라 「하나만 켠다」가 여기서 처음 실제 결정이 된다
- **디파이언스는 방어력이 아니라 피해 감소다** [09-09] — 전사 외침이 방어력·저항(감소 전 단계)을 주므로 채널을 갈랐다. 피해 감소는 **원천별 곱**의 한 원천이다 (battle_design.md §9-3)
- **결투 선언 ↔ 크루세이더 결투** — 기본에서 지목하고 전직에서 그 지목을 피해로 바꾸는 **계보**다 (§10-3)
- **광역이 질 하나뿐인 것은 문제가 아니다** — §10-3 이 「잡몹 라운드는 기본 액티브 질(타수 고정 · 대상 순환)이 받는다」로 이미 적어 뒀고, 질은 K 무관이라 보스 단독전에서도 안 죽는다
- **인챈트가 기사의 물리 우회로다** — 기사 무기군은 둘 다 `physical` 이라 물리 방어가 높은 적 앞에 답이 없었다. ⚠ 전직 크루세이더의 **성화**와 같은 일을 하므로 둘 중 하나를 나중에 조정한다
- ⚠ **「라운드가 끝날 때까지」는 새 지속 형태다** — 지금 창은 전부 실시간 초(`skill.csv:duration_sec`)다. 지목한 적이 먼저 죽으면 다시 걸 수 있는지 · 가동률이 사실상 100% 라 §9-1 규칙 2 의 버프 자로 못 잰다. §7
- ⚠ **결투 선언은 rng 를 소비할 수 있다** — §7 「도발 세부」 가 **rng 소비 0 유지**를 조건으로 걸어 뒀는데, 「적 하나를 지목」이 무작위면 한 번 먹는다. 결정론적 기준(가장 HP 가 높은 적 등)으로 고르면 0 을 지킨다 (INTERFACE.md rng 순서 계약)
- **못 쓴 D2 팔라딘 오오라** — 컨빅션(적 저항 감소)·블레스드 에임(치명)은 §9-1 규칙 3(액티브는 죄종 축을 안 준다) 위반 · 쏜즈(반사)는 기사 마스터리 T2-3 과 중복 · 메디테이션은 마나가 없어 탈락

### 12-5. 궁수 6 [확정 2026-09-09]

**컨셉 — 빠른 공격 속도로 계속 공격한다** [사용자 지시]. 버프 둘이 전부 **평타에 얹히는** 것이라 「스킬을 쏘는 직업」이 아니라 「계속 쏘면서 평타를 강화하는 직업」이 된다.

| 스킬 | 형태 | 설명 |
|---|---|---|
| 저격 | 단일 | 한 대상을 노려 크게 쏜다 |
| 연사 | 단일 | 한 대상에게 화살을 연달아 박는다 |
| 가이드에로우 | 단일 | **가장 방어력이 높은 적**을 여러 번 공격한다 (공격할 때마다 방어력 감소) |
| 멀티플 샷 | 광역 | 화살을 흩뿌려 적 전원을 맞힌다 |
| 관통 사격 | 버프 | 일정 시간 동안 모든 공격에 관통 데미지를 추가한다 (**단일 → 광역**) |
| 독화살 | 버프 | 일정 시간 동안 화살에 독 데미지를 추가한다 |

- **빠른 무기가 유리한 유일한 직업이 된다** — §9-4 파생 관측 2(「느린 무기가 스킬을 더 잘 쓴다」)의 정확한 반대편이다. 평타에 얹는 버프라 **주기가 짧을수록 이득**이고, 사제 신속(공속 창)과 시너지가 붙는다. 활(주기 1.4) ↔ 석궁(1.8) 의 차별화 축(hero_design.md §2 미정)이 여기서 처음 방향을 얻는다
- ⚠ **독화살이 전직과 정면 충돌한다** — §10-4 레인저 ① 이 **「독화살 — 독 속성 + 도트」**로 확정돼 있다. 이름도 효과도 같아서, 기본 층으로 내리면 **레인저 갈래를 다시 짜야 한다**
- ⚠ **독은 아직 없는 채널이다** — §9-2 가 마법사 원소 4종 중 독만 「도트라 미구현 — 네 번째 자리로 비워 둔다」로 확정했고, §7 「화상(도트) 도입 여부」 가 미결이다. 도트는 **매 틱마다 피해 이벤트**라 관전 타임라인과 rng 소비 수열이 늘어난다 (INTERFACE.md rng 순서 계약)
- ⚠ **가이드에로우가 타겟팅 예외 둘째가 된다** — 09-08 확정의 딸림 조항이 「**대상 선택을 바꾸는 경로를 늘리지 않는다**」 였다(battle_design.md §3-1). 그리고 방어력 감소는 09-01 무기 통합옵션(「공격 시 n초간 대상 방어력 감소」)과 같은 채널이라 이중 축 확인이 필요하다
- ⚠ **관통 사격의 「단일 → 광역」은 §1-3 변형 노드가 하던 일이다** — 예시가 정확히 「배쉬가 단일 → 광역이 된다」 였고, §7 「변형 노드의 예산 자」 가 **대상 수 K 종속**으로 미결이다. 구현도 `target` 컬럼을 창 동안 바꾸는 것이라 단순 스탯 버프와 다르다

### 12-6. 마법사 8 [확정 2026-09-09]

**3원소 × (단일 · 광역) 격자 + 자기 버프 + 소환.** §9-2 가 원했던 「이 챕터는 화염 저항이 높으니 **냉기 주력**」 이 **전직 없이 기본 층에서** 성립한다.

| 스킬 | 형태 | 설명 |
|---|---|---|
| 파이어볼 | 단일 · 화염 | 불덩이를 던져 한 대상을 태운다 |
| 인페르노 | 광역 · 화염 | 불길을 쏟아내 적 전원을 태운다 |
| 아이스 블라스트 | 단일 · 냉기 | 한 대상을 얼려 붙인다 |
| 프로스트 노바 | 광역 · 냉기 | 냉기가 사방으로 퍼져 적 전원을 얼린다 |
| 라이트닝 | 단일 · 번개 | 번개를 내리꽂아 한 대상을 지진다 |
| 연쇄 번개 | 광역 · 번개 | 번개가 적을 타고 옮겨 가며 순서마다 약해진다 |
| 마력 집중 | 버프 | 일정 시간 동안 자신의 마법 피해를 올린다 |
| 프로즌월 | 소환 | 얼음으로 된 벽을 소환해 적의 공격을 막는다 (**체력을 갖는다**) |

- **원소마다 성격이 갈렸다** — 화염은 순수 피해, 번개는 단일·광역 딜, **냉기는 유틸**(결빙 · 벽). 셋이 같은 격자를 채우면서도 쓰임이 다르다
- **비전 파동이 빠졌다** — 무속성 광역이었으나 스태프 무기군 전용이라 무기군 고정 폐기(§12-1)로 자리를 잃었다. 결과로 **마법사의 모든 피해 스킬이 원소 태그**가 되고, 원소는 방어가 아니라 저항으로 막히므로 마법사는 **물리 방어를 늘 우회하는 대신 저항 높은 적에게 약하다**. 이건 구멍이 아니라 설계대로다 — §3-5 가 마법사 T2-3 을 **적 저항 감소**로 확정해 둔 것이 그 처방이다
- ⚠ **「라이트닝」이 뇌전술사 전직 ① 과 이름이 완전히 같다** — 같은 이름 · 같은 형태 · 같은 원소라 계보가 아니라 중복이다. **전직 쪽을 바꾼다**(후보: 썬더 스트라이크 · 라이트닝 스피어) — §10-1
- ⚠ **「프로스트 노바」가 뇌전술사 「노바」 와 가깝다** — 원소가 달라 계보로도 안 읽히므로 헷갈릴 소지가 있다
- ⚠ **결빙이 아직 없는 채널이다** — 아이스 블라스트가 `status` 에 결빙을 적어 뒀지만 `status_effect.csv` 미발행이라 코드가 안 읽는다. 프로스트 노바까지 얼리면 §7 「상태이상 세부」 에 두 스킬이 걸린다

**프로즌월 — 「소환」 을 여는 결정이다** [09-09 사용자 확정]

- ~~「히드라는 소환이 아니다」~~(§10-1) 의 논거가 여기서 **의도적으로 뒤집힌다.** 그 논거는 「유닛을 추가하면 적의 무작위 대상 풀이 늘어 파티의 실효 피격이 희석된다」 였는데, 프로즌월은 **그 희석이 목적**인 스킬이다. 09-08 타겟팅 확정(적은 생존 대상 중 균등 무작위)과 맞물려, 파티 `[balance.csv:party_size_max]` 에 벽 하나가 서면 각자 피격 확률이 그만큼 내려간다
- **파워가 「HP ÷ 파티 인원」 으로 환산된다** — 벽 HP 가 파티 총 HP 의 몇 할이냐가 곧 이 스킬의 세기다. §9-1 의 자로는 못 잰다. §7
- **펫 서브시스템을 여는 것이 아니다** — 벽은 **행동하지 않는 유닛**이라 행동 주기도 AI 도 대상 선택도 없다. HP 와 **대상 풀 참여**만 있으면 된다. 네크로맨서 펫(hero_design.md §2 — 「최후순위」)과는 다른 물건이고, 「소환을 열었으니 펫도」 로 번지지 않게 이 구분을 여기 못박는다
- ⚠ **기사 정체성 조항이 다시 걸린다** — §10-1 이 프로즌 아머를 폐기한 이유가 「파티 얼음 방어막은 기사 수호의 방벽과 같은 것이라 기사 정체성을 깎는다」 였다. 프로즌월은 형태가 달라(유닛 vs 배리어) 그 논거를 피하지만 **기능은 같다 — 파티가 덜 맞는다.** 형태로 갈렸다고 볼지 같은 것의 재발로 볼지는 §7
- ⚠ **대상 선택 rng 의 범위가 바뀐다** — 벽이 대상 풀에 들어가면 굴림의 모집단이 달라진다 (INTERFACE.md rng 순서 계약). 관전 화면에 유닛이 하나 더 그려지는 것은 SCREEN_DESIGN.md 몫
