## 0. 확정 [2026-08-26 — 전면 개정]

**"3탭 트리 + 액티브 슬롯 3" 구조를 닫고, 마스터리 2층 + 전직 특화로 재편한다.**

| 폐기 | 대체 |
|---|---|
| **슬롯**이라는 개념 | **액티브 3** — 출처가 셋이고 각 출처가 하나씩 준다. 편성할 게 없으므로 시스템 이름을 지운다 (§2) |
| 액티브 첫 칸 = **죄종** | 첫 칸 = **영웅 고유 스킬** (hero_design.md §1). 레어 영웅도 공용 풀에서 1개 배정받는다 |
| 트리 안의 **액티브 킷** | 액티브는 **트리 밖**에서 온다 — 고유 · 무기군 · 전직. 트리는 강화·숙련·시너지만 (§3) |
| "3택1 같은 선택 없음 — 개성은 배분" | **자유 롤백** 도입으로 폐기. 개성의 출처는 **굴림 + 장비 + 고유 스킬** (§5) |
| "배분(트리)과 편성(슬롯)의 분리" | 자유 롤백이면 배분 = 편성이다. 두 개념이 합쳐진다 (§5) |
| 탭1 = 죄종 **트리**(고유 메커니즘) | 탭1 = 죄종 **마스터리** — 액티브 없음. 축은 §3-1 |

### 왜 — 슬롯이 하던 일이 사라졌다

슬롯의 존재 근거는 하나였다: **상한이 없으면 트리 배분이 "다 찍기"로 수렴한다.** 액티브를 트리 밖으로 빼면 트리에 액티브 노드가 없으므로 그 수렴이 원천에서 사라진다. 출처가 고정이고 각 출처가 하나씩 주면 편성할 것도 남지 않는다.

남는 것은 **동시 준비 시 우선순위**뿐인데, 그건 발동 규칙의 동률 결정자(battle_design.md §3)이지 슬롯이 아니다.

## 1. 구조 — 마스터리 2 + 특화 1

```
[분노][마법사] 영웅:

마스터리 (1레벨~)   ├── 직업 마스터리 — 마법사   : 내 숫자를 키운다
                    └── 죄종 마스터리 — 분노     : 그 숫자가 닿는 방식을 바꾼다
                         ※ 포인트 풀 공유 · 액티브 없음

특화     (전직~)    └── 전직 특화 — 전직이 준 액티브 3개 각각이 트리의 뿌리
                         ※ 전용 포인트 (§4)
```

- 마스터리 둘은 **영웅 생성 시 확정**된다 — 직업도 죄종도 굴림/고정이고 바꿀 수 없다. 플레이어의 결정은 **어디에 몰았나**뿐
- 전직 해금: `[balance.csv:advance_unlock_level]`

## 2. 액티브 3 — 출처 고정, 각 출처가 하나

**슬롯이 아니다.** 배운 것 중 셋을 고르는 게 아니라, 출처가 셋이고 각각이 하나씩 준다.

| 칸 | 출처 | 바뀌는 조건 |
|---|---|---|
| **고유** | 영웅 자신 (hero_design.md §1) | 안 바뀐다 — 영웅에 박혀 있다 |
| **무기군** | 착용 무기군 (`weapon_group.csv`) | **무기를 바꾸면 바뀐다** |
| **전직** | 전직이 준 3개 중 주력 | 배분으로 정해지고, 롤백으로 바꾼다 (§4) |

- **전투에서 결정을 내리는 칸은 전직 하나다.** 고유는 박혀 있고 무기군은 장비가 정한다. 결정을 흩뿌리지 않고 한 곳에 모은 것이 이 구조의 의도
- 전직 해금 전엔 **고유 + 무기군 2칸**으로 돈다. 그 구간의 재미는 스킬이 아니라 **장비 파밍 + 챕터 해금**이 담당한다 (기능 해금 게이트 = 챕터 클리어 — GAME_DESIGN.md §10)
- 우선순위(동시 준비 시 어느 것 먼저)는 플레이어가 정한다 — 무료 · 수시. 발동 규칙은 battle_design.md §3
- 쿨 설계 지침: 하한은 `행동 주기 × 3` 근처 (battle_design.md §6)

### 2-1. 무기군 스킬 — 무기군에 붙고, 개체에 붙지 않는다

- **무기군이 스킬의 종류를 정하고, 세기는 정하지 않는다.** 흰 도끼든 레어 도끼든 도끼 스킬은 같다. 세기 = 마스터리 배분 + 전투 능력치. 무기 개체의 접사는 기본 공격에 기여하는 만큼만 스킬에 기여하고, **스킬 전용 파워 축을 갖지 않는다**
- 왜: "운 좋게 먹은 무기 하나"가 스킬을 주는 일이 없어야 한다. 무기군은 직업 전속 범위 안의 **선택**이지 드롭 운이 아니다
- **"옵션 vs 스킬" 결정이 성립하려면 조건이 하나 붙는다** [08-26] — 같은 직업 안에서 **무기군 간 DPS 가 균형**이어야 한다. 무기가 밑수(battle_design.md §9-1)라 공격력 격차가 스킬 차이를 압도하면, 무기군 스킬은 결정이 아니라 장비 선택의 종속 결과가 된다. hero_design.md §2 의 "무기군은 피해 편차 · 행동 주기 · 한손/양손 3축으로 차별화"가 이 조건과 같은 말이다. 무기군 베이스 데이터가 아직 0행이라 **미검증**
- 비교 UI 필요 — 실효 쿨(battle_design.md §6)에 더해 **무기군 스킬 비교**가 화면에 있어야 결정이 성립한다 (SCREEN_DESIGN.md)
- 예외 후보는 **유니크 무기**뿐(스킬 교체/변형). 허용하려면 "유니크 ≤ 잘 굴린 레어" 가드레일을 아이템 쪽에 먼저 세운다 (item_design.md §4-4)
- 규칙형(선제타 등)은 무기군 Implicit과 같은 이유로 진형·타겟팅 확정 전엔 못 짠다 — 수치형(다단타·피해 편차·행동 주기 활용)부터

## 3. 마스터리 — 축 분담은 피해 공식에서 나온다

두 탭이 왜 둘인가에 대한 답. 성격이 아니라 **공식의 자리**로 가른다.

```
[1] 기본 공격력 = 능력치계수 × 무기 공격력 × ( 1 + Σ 상시 % )      ← 직업
[2] 타격 피해   = [1] × 스킬 배율 × 치명 배수 × ( 1 + Σ 조건부 % )  ← 죄종
[3] 최종 피해   = [2] × ( 1 − 감소 ) × Π ( 1 − 피해 감소 )
                         ↑ 내 방어 = 직업 / 적의 방어를 깎는 것 = 죄종
    라인 밖      흡혈 · 반사 · 재생 · 상태이상 · 드롭 · 골드         ← 죄종
```

> **직업은 내 숫자를 키우고, 죄종은 그 숫자가 상대에게 닿는 방식을 바꾼다.**

| 탭 | 담당 | 대표 노드 |
|---|---|---|
| **직업 마스터리** | [1] 과 [3] 의 내 쪽 | 무기군 숙련 · 방어구 숙련 · 상시 피해 % · 최대 HP · 물리 방어 · 원소 저항 · 행동 주기 |
| **죄종 마스터리** | [2] · [3] 의 적 쪽 · 라인 밖 | 치명 배수 · 조건부 % · 방어 무시 · 저항 감소 · 흡혈 · 반사 · 재생 · 상태이상 · 드랍률 · 골드 |

- **새 괄호·새 곱셈 층을 만들지 않는다** — 노드는 전부 `combat_stat.csv` 의 기존 수치에 더한다 (battle_design.md §9-2 "괄호는 둘뿐")
- **전술카드와 겹치지 않는다** — 카드는 파티 단위 「조건 → 효과」이고 접사를 **센다**(tactic_card_design.md §1). 마스터리는 개인 단위이고 접사를 세지 않는다
- 죄종 트리가 카드 조건을 미는 방향(tactic_card_design.md §3)은 **조건 언어가 확정된 뒤** 얹는다. 지금 전제로 삼지 않는다

### 3-1. 죄종 7종 — 몬스터 죄종의 거울 [초안 2026-08-26]

죄종 어휘는 이미 몬스터 정예 특성에 7개가 다 있다(monster_design.md §6). **영웅 죄종은 같은 성격을 아군 입장에서 뒤집은 것**이라 새로 발명하지 않는다.

| 죄종 | 몬스터 특성 (적) | 영웅 마스터리 축 | 공식의 자리 |
|---|---|---|---|
| **분노** | 격분 — 저체력 시 폭주 | **치명 배수** — 치명타 피해에 몰빵. 안정성을 안 산다 | [2] 치명 배수 |
| **시기** | 박탈 — 치명 무효화 | **방어 무시 · 저항 감소** — 남의 방어를 박탈한다 | [3] 적의 감소를 깎는다 |
| **탐욕** | 도박 — 피해 랜덤 + 드롭 보너스 | **드랍률 · 골드** — 파밍 전담 | 라인 밖 (utility) |
| **나태** | 태만 — 느리지만 한 방 | **반사 피해 · HP 재생** — 안 때려도 얻고, 맞으면 갚는다 | 라인 밖 (비직격 §9-6) |
| **폭식** | 탐식 — 타격마다 공격력 누적 | **흡혈** — 때려서 얻는다 | 라인 밖 (sustain) |
| **색욕** | 유혹 — 공격력 흡수 스택 | **상태이상 활용** — 지속 연장 + 상태이상 대상 조건부 % | [2] 조건부 괄호 |
| **오만** | 불가침 — 상태이상 면역 | **미결** — §7 | — |

- **폭식 ↔ 나태의 대비가 축을 가른다** — 흡혈(때려서 얻는다) vs 반사·재생(안 때려도 얻는다). 둘 다 sustain 이지만 반대 방향이라 겹치지 않는다
- **색욕은 상태이상을 "부여"하지 않는다** — 영웅 측 상태이상 **부여** 경로는 전술카드가 가져갔다(tactic_card_design.md §3). 색욕 마스터리는 **이미 걸린 상태이상을 활용**하는 쪽(지속 연장 · 상태이상 대상 조건부 피해)을 담당해 이중화를 피한다. 이 분담은 카드 효과 언어 확정 시 재검토
- 색욕은 **매혹(charm) 재정의**(GAME_DESIGN.md §10)의 자리 후보다 — 계승 정의가 "명중률 대폭 감소"인데 명중 축이 폐지됐다
- **"공격력 +x%" 노드가 하나도 없다** — 그게 이 축 분담의 목적이다. 죄종을 수치로 구분하려 하면 7개 중 절반이 상시 피해 % 로 수렴하고, 그건 직업 마스터리의 자리다
- 오만은 §7 미결. 채워지기 전까지 **오만 영웅은 죄종 마스터리가 비어 있는 상태**이므로 밸런스 검증에 넣지 않는다

## 4. 전직 특화 — 액티브 3개가 트리의 뿌리다

**전직 시 액티브 3개를 지급한다.** 셋 다 보유하고, **포인트를 넣은 것에만 세부 트리가 열린다.**

- **3택1이 아니다** — 셋을 다 갖는다. 액티브 칸이 하나라 주력이 하나 정해질 뿐이고, **어디에 몰았나가 주력을 정한다**. 안 찍은 둘은 세부 트리 없이 기본 성능으로 남아 교체용으로 살아 있다
- 두 갈래에 나눠 넣는 하이브리드가 자동으로 성립한다 — D2 의 몰빵 vs 분산이 여기서 재현된다
- **전용 포인트** — 마스터리와 풀을 나눈다. 공유하면 전직 레벨까지 안 찍고 모으는 게 최적이 되어 초반이 통째로 무력해진다(D2 포인트 세이빙). 나누면 세이빙 유인이 사라지고 전직 순간의 체감도 산다
- 전직은 **그 게임 처음의 스킬 결정**이다 — 그 앞 구간에 액티브 결정이 없으므로(§2) 여기에 무게가 실린다

## 5. 롤백 — 언제든 되돌린다 [확정 2026-08-26]

| 층 | 롤백 | 근거 |
|---|---|---|
| 마스터리 | **무료 · 수시** | 상시 수치라 최적해가 대체로 하나. 비용을 매겨도 결정이 아니라 통행세다 |
| 전직 특화 | **무료 · 수시** | 빌드 실험 자체를 재미 축으로 둔다 |

- **되돌릴 수 있다는 게 이 게임의 연구다** — 잘못 찍어 영웅 하나를 버리는 일이 없어야 한다. 방치형의 통제성(CLAUDE.md 철학 2)과 같은 계열
- **대가로 두 문장이 폐기됐다** (§0) — "개성은 배분에서 나온다" · "배분과 편성의 분리". 자유 롤백이면 배분은 개성이 아니고, 배분 = 편성이다
- **스킬은 파밍 루프 밖에 남는다** — 롤백에 재화를 안 걸었으므로 스킬이 원정→드롭→재배분 루프에 붙는 접점이 없다. 그 자리의 후보는 **연구소**(파견처)다 — 스킬 노드·특화 해금을 연구가 담당하면 접점이 생기고 롤백은 무료로 남는다. GAME_DESIGN.md §10 「스킬의 자리」

## 6. 콘텐츠 수량

```
트리 수      죄종 마스터리 7 + 직업 마스터리 N + 전직 특화 N       (본편 N=5 → 17)
액티브 수    고유(유니크 15 + 레어 공용 풀) + 무기군 7 + 전직 3N   (본편 3N=15)
```

- **트리 안에 액티브 킷이 없어졌다** — 개정 전엔 "각 출처에 액티브 2개 이상"(구 §3)이라 트리 밖 정의까지 38개 이상이 필요했다. 지금은 무기군 7 + 전직 15 = 22 + 고유 풀
- 직업 1개 추가 비용 = 트리 2개(직업 마스터리 + 전직 특화) + 액티브 3개 — 선형
- **사제·마법사가 완드/스태프 숙련을 각자 트리에 두 번 짜는 중복이 남아 있다** — 무기 숙련을 직업이 아니라 무기군에 귀속시키면 사라지지만, 그러면 트리 축이 죄종/무기군/전직이 되어 직업 마스터리가 소멸한다. 미결(§7)
- 본 프로젝트 최대의 콘텐츠 부채 — 노드 규모를 정할 때 총량 감각을 먼저 잡을 것

## 8. 보류 — 스킬 카드 합성

**[2026-08-25]** 비전투 활동 논의에서 나온 "합성"은 파견처 활동이 아니라 **스킬 카드 합성**이라는 별개 개념이다. 후속 과제 — 스킬 카드가 무엇인지(마스터리 2 + 특화 1 · 액티브 3 과의 관계)부터 정의한다. 넣을 때 별도 파견처(공방)를 세우지 않고 **제련소 기능**으로 들어간다. 정의 전까지 다른 문서에서 참조하지 않는다.

**불채택 기록** — "액티브 셋째 칸 = 스킬 카드(몬스터 카드 제작)" 안: 새 시스템 4~5종 · 드롭 운 · 카드는 낡지 않아 몰빵이 영구화 · 초반 빈칸. 카드의 가치(파밍 동기·제련소·수집)는 액티브 칸과 무관한 별개 결정.

## 9. 직업 액티브 15 — 프로토타입 초안 [2026-08-26]

> SSOT: **`src/data/skill.csv` 발행** (15행 · 값은 전부 ⚠제안) · 파워 예산 손잡이 `[balance.csv:skill_dps_budget_pct]`

§4 의 **전직 특화 액티브 3** 을 본편 5직업분 채운 것이다. 「스킬 테이블 미발행」(§0 머리말)이 여기서 풀린다 — 구조만 있고 내용물이 0이던 상태의 첫 실물.

### 9-0. 프로토타입 한정 — 셋을 시작부터 다 켠다

정상 구조에서 액티브 3칸의 출처는 **고유 · 무기군 · 전직**이고, 전직이 준 셋 중 칸에 오르는 것은 하나다(§2). 프로토타입은 **고유 스킬 풀도 무기군 액티브 7종도 미작성**이라 두 칸이 비어 있다 — 그 빈 두 칸을 같은 직업의 나머지 둘로 임시로 채운다.

- 목적은 **발동 규칙을 실제로 시험하는 것**이다 — "가장 오래 기다린 것 → 우선순위 → 기본 공격"(battle_design.md §3)은 액티브가 하나뿐이면 검증되지 않는다. 실효 쿨 정렬(§6)·버프 창 정렬(battle_design.md §7)도 같다
- 고유·무기군이 채워지면 **데이터를 그대로 두고 배정 규칙만 바꾸면 정상 구조로 돌아온다** — 직업 셋 중 하나만 칸에 남고 둘은 교체용이 된다
- ⚠ **캘리브레이션이 따라와야 한다** — 셋이 동시에 도는 동안 파티 화력이 기본 공격만 돌 때보다 크게 오른다. `round_budget.csv:time_target_sec` 이 깨지므로 몬스터 전역 스케일 재보정 전까지 라운드 소요를 신뢰하면 안 된다

### 9-1. 짜는 규칙 다섯

**1. 파워 예산은 DPS 기여 하나로 잰다.** 마나가 없고 비용이 행동 1회뿐이라(battle_design.md §3) 잴 것이 셋밖에 없다.

```
N            = ceil( 표기 쿨 ÷ 행동 주기 )        한 사이클의 차례 수 (실효 쿨 = N × 행동 주기)
DPS 기여     = ( 스킬 배율 − 1 ) ÷ N              기본 공격 = 배율 1
목표         = [balance.csv:skill_dps_budget_pct]
```

**2. 버프는 가동률로 잰다.** 창이 열려 있는 비율에서 자기 행동 1회를 뺀다.

```
순 기여 = ( 지속 ÷ 실효 쿨 ) × 효과% − 1 ÷ N
```

파티 창은 **개인 스킬 하나를 파티 인원으로 나눈 값**이 기준이다. 인원수만큼 곱하면 파티 버퍼가 통행증이 된다 — hero_design.md §2 「사제 서약」과 같은 계열의 가드다.

**3. 직업 축만 준다 — 죄종 축은 액티브가 주지 않는다.** 15개 중 치명 배수 · 방어 무시 · 저항 감소 · 흡혈 · 반사 · 재생 · 드랍을 주는 것은 하나도 없다. 전부 [1] 상시 피해 % 와 [3] 내 쪽 방어에 얹힌다 (§3 축 분담의 직업 자리).

- 궁수 저격만 치명에 닿는데, 닿는 곳이 **치명 확률**(확정 치명)이라 분노의 **치명 배수**와 갈린다. `combat_stat.csv` 가 이미 치명 확률을 장비·스킬 전담으로 두고 있어 새 규정이 아니다
- 왜 — 축 분담이 마스터리에서만 지켜지고 액티브에서 새면 죄종 마스터리가 "액티브가 이미 주는 것을 조금 더 주는 탭"이 된다

**4. 상태이상 0.** 부여 경로는 전술카드가 가져갔고(§3-1) `status_effect.csv` 도 없다. **도트·둔화·스턴 없이 15개가 짜이는지**를 시험했고, 짜인다.

**5. 진형·타겟팅에 기대지 않는다.** 도발 · 엄호 · 후열 지정 없음. 기사의 탱킹은 위치가 아니라 **파티 창**으로 표현했다. 진형이 확정되면 그때 얹는다.

### 9-2. 5직업 × 3 — 갈래가 갈리는 축

| 직업 | ① | ② | ③ | 셋을 가르는 것 |
|---|---|---|---|---|
| **전사** | 광폭화 — 자기 상시 % 창 | 참수 — 장쿨 단일 · 처치 시 쿨 초기화 | 회전 베기 — 단쿨 광역 | 창 / 단일 폭발 / 다수 정리 |
| **기사** | 수호의 방벽 — 파티 피해 감소 창 | 전열 지휘 — 파티 상시 % 창 | 응징의 강타 — 중쿨 단일 + 자기 창 | 파티 방어 / 파티 공격 / 자기 딜 |
| **마법사** | 화염 작렬 — 장쿨 단일 | 연쇄 번개 — 중쿨 광역 | 서릿발 화살 — 단쿨 단일 | **원소 3종 × 템포 3단** |
| **궁수** | 저격 — 장쿨 · 확정 치명 | 관통 사격 — 중쿨 광역 | 연사 — 단쿨 다단 | 치명 / 광역 / 다단 |
| **사제** | 성역 — 파티 회복 | 치유의 빛 — 단일 회복 | 심판 — 중쿨 딜 · 언데드 조건부 | 광역 회복 / 집중 회복 / 딜 |

- **전사** — [1] 밑수와 상시 % 만 쓴다. 유일한 라이더인 「처치 시 쿨 초기화」가 라운드 정리에 가속을 붙인다
- **기사** — **파티 창은 기사 전속**이다. 사제가 HP 를, 기사가 창을 맡아 지원 축이 둘로 갈린다. 타겟팅 미확정으로 도발을 못 쓰는 자리를 여기로 메웠다. 셋 중 하나가 자기 딜이라 「딜기사」 배분이 성립한다 (§4 몰빵 vs 분산)
- **마법사** — 세 갈래가 곧 **원소 3종**이다. 무기 개체가 굴린 원소는 기본 공격이 쓰고 스킬은 자기 태그를 쓰므로(battle_design.md §9-5), "이 챕터는 화염 저항이 높으니 냉기 주력"이 **스킬 배분으로** 성립한다. 저항이 상한형이라 스테이지마다 답이 바뀌어 굳지 않는다. 독은 도트라 미구현 — 네 번째 자리로 비워 둔다
- **궁수** — 저격의 확정 치명은 세기를 **치명타 피해**가 정한다. 「스킬은 어떻게 싸우는가를 정하고 세기는 장비가 정한다」(hero_design.md §1)의 직접 표현
- **사제** — 셋 중 하나가 딜인 것은 사제 서약 때문이다. 심판의 조건부는 **언데드 한정** — 데몬까지 넣으면 계승 몬스터 구성상 대다수에 걸려 조건부가 아니라 상시가 된다

### 9-3. 이 15개가 요구하는 규칙 — 미결을 여는 제안

| 규칙 | 쓰는 스킬 | 현재 | 제안 |
|---|---|---|---|
| **다단타** | 연사 | battle_design.md §9-9 미결 | 타격마다 적중·치명을 **따로** 굴린다 · 흡혈·반사도 타격마다 유발 |
| **다수 대상** | 회전 베기 · 연쇄 번개 · 관통 사격 · 성역 | 같은 미결 | 생존 대상 **전원**에게 각각 독립 직격. 진형이 없으므로 거리·분배 감쇠 없음 |
| **버프 창** | 광폭화 · 방벽 · 지휘 · 응징 | battle_design.md §7 확정 · 구현 없음 | 실시간 초 · **중첩 없음**(재시전은 갱신) · 접사와 같은 괄호에 덧셈 |
| **회복** | 치유의 빛 · 성역 | 확정 (마법 공격력 비례) | 대상 규칙만 신설 — HP **비율** 최저 1인 / 전원 |
| 원소 태그 | 마법사 3종 | battle_design.md §9-5 확정 | 새 규칙 아님 |
| **확정 치명** | 저격 | 신설 | ⚠ 치명 굴림을 건너뛰면 **rng 소비 수열이 달라진다** — 굴리되 결과를 덮어쓰는 쪽을 권한다 (INTERFACE.md rng 순서 계약) |
| **처치 시 쿨 초기화** | 참수 | 신설 | 스킬 1개 전용 라이더 |
| **발동 조건** | 회복 2 · 버프 4 | **없다 — 필요하다** | 만피에 회복이 나가고 켜진 창 위에 창이 덮이면 행동 1회를 버린다. battle_design.md §3 에 「가치가 없으면 준비된 것으로 치지 않는다」가 붙어야 한다 (`skill.csv:cast_condition`) |

### 9-4. 파생 관측 셋

1. **오만 마스터리의 축(§7)에 실체가 생겼다** — 15개 중 넷이 버프 창이고 5직업 중 셋이 창을 갖는다. 후보 ①「버프 지속·강화」가 더 이상 대상 없는 축이 아니다. 확정은 하지 않는다
2. **느린 무기가 스킬을 더 잘 쓴다** — 쿨은 실시간이고 배율은 %라, 행동 주기가 길수록 N 이 줄어 스킬 비중이 커진다. 양손 무기가 자동으로 스킬 성향을 갖는 셈이라 §2-1 「무기군 간 DPS 균형」 검증에 이 항이 들어가야 한다
3. **스킬은 무기 개체 격차를 줄이지 않는다** — 배율은 밑수에 곱하므로 잘 뜬 무기의 우위가 그대로 곱해진다. §2-1 「옵션 vs 스킬」 결정 조건은 여전히 무기군 간 균형에 달려 있다

### 9-5. 남는 것

- **무기군 액티브 7 · 고유 스킬 풀** — 미작성. 15개는 전직 몫만 채웠다
- **세부 트리** — 각 액티브가 뿌리인 트리(§4)의 노드는 미작성
- 우선순위 기본값은 `skill.csv:priority` — 창 → 장쿨 → 단쿨 순. 플레이어 변경 UI 는 SCREEN_DESIGN.md 몫
- 값은 전부 ⚠제안 — 캘리브레이션은 9-0 의 화력 급증 보정과 한 묶음이다
