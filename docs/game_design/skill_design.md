## 1. 구조 — 독립 트리 3탭 (D2 방식)

영웅은 스킬 탭 3개를 갖는다. 포인트 풀은 공유, 배분은 완전 자유.

```
[분노][마법사] 영웅의 스킬 탭:
├── 탭1: 분노 트리          — 죄종에서 옴 (모든 분노 영웅 공유)
├── 탭2: 마법사 마스터리 트리 — 직업에서 옴 (기초 골격)
└── 탭3: 마법사 전직 트리    — 직업 심화 (레벨 해금)
```

**탭 밖 — 고유 패시브**: 영웅마다 1개씩 갖는 항시 발동 패시브는 **탭에 들어가지 않는다** (스킬 포인트 불요, 전용 트리 없음). 무기군 Implicit과 같은 포지션이므로 아래 3탭 구조와 포인트 경제는 그대로다. [hero_design.md](hero_design.md) §2 참조.

### 핵심 원칙

- **3택1 같은 선택 없음** — 개성은 "선택"이 아니라 **"배분"**에서 나온다. 같은 [분노][마법사]라도 죄종 몰빵 / 전직 몰빵 / 밸런스형이 다른 영웅
- 포인트는 레벨업으로 지급 (키: balance.csv 예정)
- 전직 탭 해금: `[balance.csv:advance_unlock_level]` (초안 값은 결정 로그 참조) — "전직까지 N레벨"이 방치형 접속 동기

## 2. 탭별 성격

| 탭 | 성격 | 내용물 방향 |
|---|---|---|
| **[죄종]** | 정체성 + 아이템 연결 | 죄종 고유 메커니즘 — 분노=치명·잃은체력비례, 색욕=흡혈, 시기=방무·디버프, 나태=저속·한방·반격, 폭식=체력·흡수, 오만=증폭·면역, 탐욕=골드·드랍 유틸. **죄종 접사/세트와 시너지 노드 포함** (예: "분노 세트포인트당 치명타 보정") |
| **[직업 마스터리]** | 기초 골격 | 무기 숙련 패시브(직업별 무기군), 방어구 숙련, 기본 액티브 소수 — D2 바바리안 마스터리 탭 포지션 |
| **[전직]** | 빌드의 본체 | 직업 심화 액티브 킷 — 전직의 정체는 추후 결정 |

## 3. 액티브 슬롯 (확정 2026-08-21)

트리에서 배우는 것과 전투에 들고 나가는 것은 다르다.

- **액티브 슬롯 3개** — 배운 액티브 중 셋을 골라 장착. 순서 변경 무료
- **슬롯 순서 = 동시 준비 시 우선순위** (발동 규칙 전체는 [battle_design.md](battle_design.md) §3)
- 발동은 **한 차례에 하나**. 스킬은 그 차례의 공격을 대체하고, 마나는 없다 — 행동 1회가 유일한 비용
- 패시브 노드는 슬롯을 먹지 않는다. 고유 패시브(유니크 영웅)도 슬롯 밖

**왜 상한을 두나**: 무제한이면 배운 액티브를 다 넣는 게 정답이라 밸런싱이 불가능해진다. 3개로 묶으면 "어느 셋을 들고 갈까"가 결정이 되고, **배분(트리)과 편성(슬롯)이 분리**된다.

**실제 빌드 결정은 슬롯 수가 아니라 포인트 배분에서 나온다** — 1개에 몰빵하면 그 스킬이 세지고 슬롯을 덜 쓰게 되며, 분산하면 셋을 채운다. D2의 시너지 대 분산 구조 그대로다.

> 쿨 설계 지침: 스킬 쿨의 하한은 대략 `행동 주기 × 슬롯 수`. 그보다 짧으면 슬롯끼리 발동 기회를 나눠 갖느라 표기 쿨이 거짓말이 된다 (battle_design.md §6)

## 4. 콘텐츠 수량

```
트리 수 = 죄종 7 + 마스터리 N + 전직 N = 7 + 2N   (덧셈 구조)
          본편 N=5 → 17개 / 확장 2직업 포함 N=7 → 21개
```

- 직업 1개 추가 비용 = 트리 2개(마스터리+전직) — 선형 확장
- 조합 다양성 = 7죄종 × 직업 수 × 배분 자유도 (곱셈은 유저 쪽에서 발생)
- **[갱신 2026-08-21]** 직업 3종 → 7종 확정으로 트리 총량이 13 → 17(본편)로 증가. 본 프로젝트 최대의 콘텐츠 부채이므로 §5의 노드 규모를 정할 때 총 노드 수 감각을 먼저 잡을 것
