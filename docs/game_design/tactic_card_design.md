## 0. 확정 [2026-08-26]

**죄종 세트효과(세트포인트) 구조를 폐기하고, 그 자리를 전술카드가 가져간다.**

- **폐기** — "장비에 붙은 죄종 접사가 자동으로 세트포인트가 되어 세트효과를 낸다"는 구조. 08-25 보류를 해제하지 않고 **닫는다**. 안 A/B(슬롯 8 상한 9 / 슬롯 9 상한 10) 선택도 함께 소멸
- **존치** — 설계 자산(문턱 3/6/9 · 죄종별 성격 · 효과 후보)은 카드 인스턴스로 재활용한다. 폐기한 것은 **자동 발현 구조**이지 내용물이 아니다 (§3)
- 접사의 죄종은 **접사 카테고리 · 지역 드롭 편향 · 낙인 지정** 세 축을 그대로 유지하고, 여기에 **카드 조건이 세는 대상**이 더해진다

### 왜 — 복잡도를 디폴트에서 옵트인으로 옮긴다

```
세트   항상 켜진 전역 제약     장비 한 칸을 바꿀 때마다 9슬롯 전체를 다시 계산해야 한다
카드   플레이어가 켜는 국소 조건  안 꽂으면 스탯 비교, 꽂으면 그 카드에 적힌 조건 하나만
```

1. **아이템 정리는 접속 중 활동의 절반이다**(컨셉 락). 그 절반이 매번 암산이면 세션이 피곤해진다. 세트는 부속 규칙(한 장비에 같은 죄종 중복 금지 · 양손 2포인트 · 메인 죄종 +1)까지 끌고 와서 장갑 한 짝 교체에 산수가 붙었다
2. **켠 상태의 인지 부하도 카드가 낮다** — 세트는 7죄종 × 3문턱 매트릭스를 계속 추적해야 하지만, 카드는 지금 꽂은 몇 장의 조건만 보면 되고 그 조건이 카드에 문장으로 적혀 있다
3. **매트릭스 대칭 의무가 사라진다** — 세트는 7×3 을 다 채워야 해서 빈칸이 곧 결함이었다(오만이 3포인트 상태이상을 못 가져 "상태이상 7종 가위바위보"가 6종이 되던 문제). 카드는 유한 인스턴스라 죄종마다 장수가 달라도 된다
4. **슬롯 수와 독립한다** — 세트포인트 상한 논쟁은 포인트가 장비 슬롯에 묶여 있어서 생겼다. 카드 조건은 접사를 그냥 세므로 슬롯 구성이 바뀌어도 규칙이 안 흔들린다
5. CLAUDE.md 철학 3(단순화가 정답)과 정렬 — 세트는 축을 얹고 **끌 수 없고**, 카드는 얹되 **끌 수 있다**

## 1. 정의

**전술카드 = 「조건 → 효과」 한 장.** 조건이 참이면 효과가 파티에 적용된다.

```
조건        효과
[분노 접사 10개 이상]  →  …
[파티에 마법사가 1명뿐]  →  …
```

- **편성 단계에서 붙는다** — 전투 중에 내지 않는다. [battle_design.md](battle_design.md) §1 "유저 조작 없음"을 깨지 않는다
- **파티 단위** — 영웅 개인이 아니라 편성 전체에 걸린다. 개인 단위 강화는 장비·스킬이 이미 담당한다
- 프레임: **파티 단위 접사**. 개인 접사와 문법이 같고 대상만 파티다 — 파워 예산 기준(§2-2)이 여기서 나온다

### 1-1. 인접 개념과의 구분

| | 무엇 | 상태 |
|---|---|---|
| **전술카드** | 편성 조건 → 파티 효과 | 이 문서 (도입 확정 · 세부 미확정) |
| 도감 몬스터 카드 | 처치 시 드롭 → 도감 레벨 재화 | 확정 (monster_design.md §8) |
| 스킬 카드 합성 | 정의 자체가 미작성 | 보류 (skill_design.md §5) |
| 진형 · 타겟팅 | 파티가 누구를 때리나 | 미작성 (GAME_DESIGN.md §10) |

⚠ **"카드" 어휘가 셋이 됐다.** 셋 다 다른 뜻이라 문서가 오래 못 버틴다 — 어휘 정리는 미확정 과제(§4).

## 2. 확정 원칙

### 2-1. 조건은 편성 화면에서 켜짐/꺼짐이 확정되는 것만 참조한다

편성 · 장비 · 접사 카운트 · 죄종 · 직업 · 무기군 — 전부 가능. **전투 중에 변하는 값(현재 HP · 남은 적 수 · 라운드 · 생존자 수)은 참조하지 않는다.**

- 결정론이 깨져서가 아니다 — 안 깨진다. **출발 버튼을 누를 때 이게 켜질지 알 수 없으면 편성이 결정이 아니라 도박**이 되기 때문
- 부수 효과로 "동료가 죽어서 내가 세졌다" 같은 인과 붕괴가 구조적으로 막힌다. 방치형의 통제성(CLAUDE.md 철학 2)이 근거
- 판정은 **출발 시 1회 고정** — 전투 중 재판정 없음

### 2-2. 카드를 안 꽂아도 게임이 성립해야 한다

**§0 의 "복잡도는 옵트인"은 이 조건이 없으면 성립하지 않는다.** 카드가 세면 "안 꽂기"는 선택지가 아니게 되고, 복잡도는 이름만 옵트인이고 실질은 강제로 돌아온다.

- 파워 예산 대역 = **개인 접사 한두 개 값** (파티 단위 × 파티원 수가 아니다)
- 이 대역이어야 "안 꽂아도 돌아가는데 꽂으면 더 좋다"가 성립한다
- [hero_design.md](hero_design.md) §2 **사제 서약**과 같은 계열의 약속이다

### 2-3. 효과는 결핍을 메우지 않는다

**결핍 보정 금지** — "전원 마법사 → 방어 +n%" 형태는 직업 시스템을 우회하는 치트키가 된다. 탱커가 없어서 생긴 문제를 카드가 메워주면 기사가 존재할 이유가 약해지고, 사제 서약("사제 없이도 최전선이 성립한다 — 사제는 안정성을 사는 선택지")과 정반대 방향이 된다.

- 허용되는 방향은 **특화 심화** — 약점은 약점으로 남긴다
- 방치형은 최적해를 찾으면 굳는다. 동질 보너스가 있으면 최적해가 단일 구성으로 수렴하고 **편성 결정이 한 번 풀리고 끝난다**

### 2-4. 수치는 기존 공식의 항으로 들어간다

새 괄호 · 새 곱셈 층을 만들지 않는다 ([battle_design.md](battle_design.md) §9-2 "괄호는 둘뿐").

| 카드가 주는 것 | 들어가는 자리 |
|---|---|
| 피해 % | §9-1 상시 피해 % 괄호 또는 §9-2 조건부 % 괄호에 **덧셈 항** |
| 방어 | §9-3 방어값 (피해 감소 쪽이 아니다 — 원천별 곱은 개수에 지수로 자란다) |
| 원소 저항 | §9-5 저항 합 |

## 3. 이관 — 세트효과에서 넘어온 것

| 세트에 있던 것 | 카드에서 |
|---|---|
| 문턱 3 / 6 / 9 | **계단형 조건**의 재료. 이진 문턱은 "9개에서 멈춰 있는" 구간이 길어 방치형에 안 맞다 |
| 3포인트 = 상태이상 부여 (영웅→몬스터) | 카드 효과로 직접 부여 — 영웅 측 상태이상 경로가 여기서 살아난다 ([story_chapter_design.md](story_chapter_design.md) §3). ⚠ **「부여는 카드 전담」이 08-27 에 깨졌다** — 액티브도 상태이상을 부여한다(냉기 = 결빙 · [skill_design.md](skill_design.md) §9-1 규칙 4 · [battle_design.md](battle_design.md) §2-2). 카드가 부여를 **독점**하던 근거는 재작성 대상이고, 카드는 부여 경로의 **하나**가 된다 |
| 메인 죄종 +1 (영웅-아이템 궁합) | 포인트 우회 없이 **조건에 직접** — "메인 죄종이 분노인 영웅이 분노 접사 N개를 들면" |
| 죄종 트리의 세트 시너지 노드 | 스킬 트리가 카드 조건을 미는 방향으로 재정의 ([skill_design.md](skill_design.md) §2) |
| 폭식 = 역세트 · 오만 = 올 오어 낫씽 | 개별 카드의 성격으로 흡수. 대칭 의무가 없어 그대로 써도 된다 |
| 계승 `equipment_set_bonus.csv` 오버라이드 계획 | **신규 카드 테이블**로 대체. 계승 CSV 는 안 건드린다 (CLAUDE.md 규칙 3) |

### 3-1. 이관으로 잃는 것 — 기록

1. **자동 발현이 사라진다** — 세트는 장비 교체만으로 켜지고 꺼졌다. 카드로 옮기면 **그걸 읽는 카드가 없는 동안 죄종 접사는 카테고리 라벨로 남는다**
   → 대응: **죄종 접사를 읽는 카드는 초반에 확보 가능해야 한다.** 후반 해금물로 두면 게임의 3/4 동안 죄종 접사가 죽어 있다
2. **"유니크 확실성 vs 각성 폭발력" 양자택일이 약해진다** — 세트가 슬롯을 먹어서 성립했던 긴장이다. 카드는 슬롯을 안 먹는다. 다만 조건이 접사 카운트면 접사 칸 압력은 남으므로 **없어지지 않고 약해진다**
   → 카드 슬롯 수를 빡빡하게 잡으면 다른 형태의 긴장으로 대체 가능 (§4)
3. **디폴트 상태의 장비 선택이 순수 스탯 비교로 남는다** — 스탯 비교는 "숫자 큰 쪽"으로 수렴해 결정이 아니라 계산이 될 위험
   → **이미 커버돼 있다**: §9-2 상시/조건부 두 괄호("이 스테이지는 데몬이니 데몬 무기로")와 §9-5 원소 저항 상한("새 챕터 들어가면 그 원소부터 채운다"). 둘 다 스테이지에 따라 정답이 바뀌므로 계산으로 안 무너진다

## 4. 미확정

> **도입과 이관만 확정이다. 아래는 전부 미정** — 정해지기 전까지 다른 문서가 전술카드를 전제로 규칙을 세우지 않는다.

| 과제 | 상태 |
|---|---|
| **카드 슬롯의 수와 소유자** | 파티 전체에 n장인가 / 리더 영웅이 여는가. **리더 도입 자체가 미확정** — 도입 시 통솔의 자리(GAME_DESIGN §10) 후보가 된다 |
| **조건 언어의 목록** | §2-1 이 경계만 정했다. 실제 어휘(접사 카운트 · 죄종 · 직업 · 무기군 · 능력치 모양 · **스킬 태그**)의 채택 범위는 미정 |
| **스킬 태그를 세는 조건** [2026-08-28] | **13 태그 사전이 확정됐다** ([skill_design.md](skill_design.md) §11 — 피해 방식 / 버프 / 디버프 / 기타). 스킬은 편성 시점에 확정되므로(기본=직업 · 무기군=장비 · 전직=배분) §2-1 을 통과한다. **두 제약**: ① `단일`·`광역` 은 거의 모든 스킬에 걸려 조건으로 쓸모가 없다 — **희소 태그**(`제어`·`회복`·`희생`·`저주`·`도트`)를 센다 ② **이중 보상**이 접사보다 세게 걸린다. 접사는 스탯만 주지만 **스킬은 전투에서 실제로 일을 하므로**, 세는 방향과 보상 방향을 다르게 둔다 |
| **효과 언어의 성격** | 수치 %인가 방향 전환("분노 접사가 저항 감소로도 계산된다")인가. 접사 카운트 조건은 조건 자체가 이미 스탯을 주므로 **이중 보상** 주의 |
| **카드 획득 경로** | 유한 수작업 해금물이 방향(무한 절차 생성이면 정답 카드 몇 장만 살고 나머지가 죽는다). 무엇이 여는가는 미정 — 3번째 파밍 축을 만들지 않는 것이 제약 |
| **문턱의 계단 값** | 3/6/9 를 그대로 쓸지, 접사 카운트 기준으로 다시 잡을지 |
| **"카드" 어휘 충돌** | 전술카드 · 도감 몬스터 카드 · 스킬 카드 합성 셋이 같은 단어를 쓴다 (§1-1) |
| **화면 요구** | 조건 카운터(접사 몇 개인지)를 세어 보여줘야 한다 — 안 보이면 함정. 편성 화면 · 캐릭터 탭 양쪽 (SCREEN_DESIGN.md §6) |
| **SSOT 테이블** | 카드 테이블 미발행. `balance.csv` 키 없음 |
