# 초반 안내

2026-10-30 · 확정 규격. 인물 없이 실제 기능 가까이에 짧은 설명을 표시하는 가벼운 튜토리얼입니다. 대상은 첫 원정, 장비 비교, 마스터리 배분, 물약, 건설의 다섯 가지입니다.

## 표시와 진행

안내는 해당 화면에 대상이 실제로 있고 지금 배울 수 있는 상태일 때 표시합니다. 한 번에 작은 카드 하나만 보여주며 제목·짧은 설명·[확인]을 둡니다. 카드 옆의 대상에는 강조를 붙입니다. 정해진 순서를 끝내야 다음 기능을 쓰는 구조가 아니며, 플레이어가 실제로 찾아간 화면과 가능한 행동을 따릅니다.

전투·입력·화면 이동은 계속 가능합니다. 화면을 가리는 배경이나 인물, 자동 화면 전환, 강제 스크롤, 자원 사용은 없습니다. 안내가 다른 창 뒤의 대상을 가리키지 않도록 관련 없는 창이 열렸으면 감춥니다. 스킬 창에서는 배울 수 있는 마스터리 칸을 직접 가리킬 수 있습니다.

[확인]한 뒤 같은 화면에서 다른 안내를 연달아 표시하지 않습니다. 다른 화면 진입이나 다음 상황을 기다립니다. 대상을 떠나 카드가 사라진 것만으로 본 것으로 기록하지 않습니다.

## 다섯 가지 안내

| ID | 표시할 상황과 대상 | 알려주는 내용 |
|---|---|---|
| `expedition` | 첫 원정 전, 원정 화면의 열린 장소 줄 | 장소를 선택하면 출정할 수 있습니다. 전투와 다음 구간 진행은 자동이며 게임이 켜져 있는 동안 이어집니다. |
| `loot` | 선택한 영웅이 있고 실제 인벤토리에 일반 장비가 있을 때, 해당 장비나 인벤토리 | 영웅을 먼저 고르고 장비에 마우스를 올려 착용품과 비교합니다. 장비를 클릭하면 선택한 영웅이 착용합니다. 터치에서는 장비를 길게 눌러 비교하고 상세 정보의 [착용]을 사용합니다. |
| `mastery` | 포인트가 남고 배울 수 있는 칸이 있는 영웅의 마스터리 버튼, 또는 스킬 창의 배울 수 있는 칸 | 레벨업으로 받은 포인트를 배분하고 무료로 초기화할 수 있습니다. |
| `potions` | 편성의 물약 영역 또는 구매 기능이 열린 상단의 물약 영역 | 설정한 체력 기준에 따라 자동 사용합니다. 마실 때마다 재고가 줄며 상단에서 보충할 수 있습니다. |
| `construction` | 건설 화면에서 건설 버튼이 있는 다음 랭크 영역. 최대 랭크·준비 중으로 버튼이 없는 대상은 제외합니다. | 조건과 비용을 확인해 건물을 지으면 새 기능이 열립니다. |

장비를 얻었다고 더 강하다고 단정하거나 장착을 강제하지 않습니다. 시작 무기보다 첫 드롭이 약할 수도 있으므로 비교 방법을 가르칩니다. 상자는 일반 장비 비교 안내의 대상에서 제외합니다.

물약은 마셨을 때 재고가 줄고, 다음 라운드에 재고에서 다시 채웁니다. 매 라운드에 무조건 소비되는 것으로 설명하지 않습니다. 마스터리는 남은 포인트만 확인하지 않고 실제로 배울 수 있는 칸도 확인합니다. 건설 조건과 비용은 기존 판정을 따르며 안내를 위해 해금하거나 비용을 지급하지 않습니다.

## 시작과 다시 보기

새 게임에서 자동 시작합니다. 기존 진행 세이브에는 자동으로 시작하지 않습니다. 설정의 **초반 안내 → [다시 보기]**를 누르면 현재 게임의 확인 기록을 초기화하고 현재 가능한 안내부터 다시 볼 수 있습니다. 이미 지나간 화면을 자동으로 열지는 않습니다.

확인 기록은 브라우저 저장 어댑터의 `thesevensim.tutorialSeen`에 게임의 `seed:createdAt`별로 구분해 둡니다. 새로고침과 같은 게임 불러오기 뒤에도 유지하며 다른 게임의 기록과 섞지 않습니다. 게임 세이브, 보상, 포인트, 난수 상태에는 영향을 주지 않습니다.

## 알림과의 관계

초반 안내는 실제 위치에서 사용법을 설명합니다. 종의 미션과 처리 대기 알림은 기존 상태 판정을 계속 따릅니다. 초반 안내 카드를 종의 개수에 추가하지 않으며, 카드를 확인해도 실제 미션이나 처리 대기 알림은 지우지 않습니다. 배운 기능의 반복 사용은 기존 알림과 도움말로 이어집니다.
