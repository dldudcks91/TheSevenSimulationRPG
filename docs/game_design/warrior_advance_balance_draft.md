## 3. 측정

기사가 앞, 전사가 뒤인 AI 팀 · 전직 스킬을 맨 앞 칸에 둔 판 · 시드 짝 200판. 차이는 전직 스킬이 없을 때와 견준 (우리 팀 평균 HP 비율 − 적 팀 평균 HP 비율)의 변화이고, 표준오차는 약 .03 ~ .04 다. 긴 전투는 모든 유닛의 HP 를 3배로 한 대용 판이다. 값은 Lv35 / 45 / 50 순서다.

공격 전직의 기준 범위는 결투 +.20 ~ .27, 긴 전투 +.15 ~ .24 다.

| 스킬 | 판 | 결과 |
|---|---|---|
| 라그나로크 | 결투 | +.21 / +.20 / +.19 |
| 라그나로크 | 긴 전투 | +.40 / +.30 / +.29 |
| 버서크 | 배시 · 더블스윙 칸 결투 | +.15 / +.13 / +.12 · 승률 77 / 78 / 75%(스킬 없음 67 / 68 / 68%) |
| 버서크 | 배시 · 더블스윙 칸 긴 전투 | +.14 / +.18 / +.18 |
| 버서크 | AI 가 굴린 칸 결투 | +.07 / +.06 / +.04 · 승률 56 / 54 / 52% |
| 동귀어진 | 결투 | +.20 / +.27 / +.22 |
| 동귀어진 | 긴 전투 | +.26 / +.25 / +.26 |
| 동귀어진 | 만피 상대 즉사 | 한 방의 26 / 25 / 29% |

- **역할 나뉨** — 배시 · 더블스윙 칸에서 라그나로크는 −.02 / −.10 / −.10 이고, AI 가 굴린 칸에서는 라그나로크가 버서크보다 앞선다. 스킬을 미는 버서크와 스킬을 내려놓는 라그나로크가 갈린다.
- **긴 전투의 치우침** — HP×3 판은 자기 · 상대 최대 HP 에 비례하는 효과를 부풀릴 수 있다.
