상위: [skill_design.md](skill_design.md) §10-2 · 측정 원본: [REPORT.md](../../output/2026-11-01_warrior_advance/REPORT.md)

> 사용자가 하나씩 확정한 값을 CSV · 코드 · 기획서에 반영하기 전까지 모아 두는 문서다. 아직 CSV 에 없는 값이라 수치를 직접 적는다. 반영하면 값은 CSV 로 옮기고 이 문서의 해당 줄을 지운다.

**범위** — 각 스킬의 기본 값만 다룬다. 노드(꼬리)는 따로 정한다.

| 전직 | 스킬 | 상태 |
|---|---|---|
| 광전사 | 라그나로크 | 확정 |
| 광전사 | 버서크 | 확정 |
| 광전사 | 동귀어진 | 일단 확정(「ㅇㅇ그렇게해보자 일단」) |
| 바바리안 | 휠윈드 · 토르의 분노 · 쇼크웨이브 | 미정 |
| 선봉장 | 사자후 · 호령 · 일갈 | 미정 |

## 1. 광전사 확정 값 [2026-11-02]

| 항목 | 라그나로크 | 버서크 | 동귀어진 |
|---|---|---|---|
| **발동** | 차례에 시전 | 전투 시작과 함께 자동 · 이후 20초마다 · 차례를 먹지 않음 · 시전 뒤 기본 공격 없음 | 차례에 시전 |
| **쿨** | 25초 | 20초(자동 발동 주기) | 16초 |
| **지속** | 15초 | 12초 | — |
| **효과** | 데미지 +150% · 공격 속도 +150% · 다른 액티브 봉인 · 방어력 변화 없음 | 다른 액티브 스킬 데미지 +100% | 기본 5배 + 상대 최대 HP 10% |
| **대가** | — | 타격마다 현재 HP 3% | 시전 때 현재 HP 30% |
| **스킬 레벨** | 지속 +1초 | 지속 +0.8초 | 배율 +0.5배 |

- **라그나로크** — 「건 차례부터 빨라지는」 규칙은 넣지 않는다. 봉인 중에도 장비의 타격 · 피격 발동은 나간다(측정 판에서 확인).
- **동귀어진** — 상대 최대 HP 10% 는 강타처럼 방어 · 저항 · 치명을 받지 않고, 레벨로 오르지 않는다. 보스 예외는 없다.

## 2. 파생 태그 「자동 / Auto」 [2026-11-02]

**확정** — 버서크처럼 스스로 발동하는 스킬에 붙는 파생 태그. 표시 이름 「자동 / Auto」 · id `auto` · 시전 방식 `cast` 에서 파생한다.

**제안(사용자 확정 전)**

| 항목 | 제안 |
|---|---|
| 대분류 | 기타 |
| 쿨 감소 | 적용 |
| 스킬 우선순위 창 | 제외 |
| 스턴 중 | 발동 |
| 라운드 사이 타이머 | 유지(미측정) |

## 3. 측정

기사가 앞, 전사가 뒤인 AI 팀 · 전직 스킬을 맨 앞 칸에 둔 판 · 시드 짝 200판. 차이는 전직 스킬이 없을 때와 견준 (우리 팀 평균 HP 비율 − 적 팀 평균 HP 비율)의 변화이고, 표준오차는 약 .03 ~ .04 다. 긴 전투는 모든 유닛의 HP 를 3배로 한 대용 판이다. 값은 Lv35 / 45 / 50 순서다.

공격 전직의 기준 범위는 결투 +.20 ~ .27, 긴 전투 +.15 ~ .24 다.

| 스킬 | 판 | 결과 |
|---|---|---|
| 라그나로크 | 결투 | +.21 / +.20 / +.19 |
| 라그나로크 | 긴 전투 | +.40 / +.30 / +.29 |
| 버서크 | 배시 · 더블스윙 칸 결투 | +.15 / +.13 / +.12 · 승률 77 / 78 / 75%(스킬 없음 67 / 68 / 68%) |
| 버서크 | 배시 · 더블스윙 칸 긴 전투 | +.14 / +.18 / +.18 |
| 버서크 | AI 가 굴린 칸 결투 | +.07 / +.06 / +.04 · 승률 56 / 54 / 52% |
| 동귀어진 | 결투 | +.20 / +.27 / +.22 |
| 동귀어진 | 긴 전투 | +.26 / +.25 / +.26 |
| 동귀어진 | 만피 상대 즉사 | 한 방의 26 / 25 / 29% |

- **역할 나뉨** — 배시 · 더블스윙 칸에서 라그나로크는 −.02 / −.10 / −.10 이고, AI 가 굴린 칸에서는 라그나로크가 버서크보다 앞선다. 스킬을 미는 버서크와 스킬을 내려놓는 라그나로크가 갈린다.
- **긴 전투의 치우침** — HP×3 판은 자기 · 상대 최대 HP 에 비례하는 효과를 부풀릴 수 있다.
