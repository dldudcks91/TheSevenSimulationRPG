## 0. 조사 방법과 신뢰도

00_overview.md §0 의 원칙(AFK Journey 오염 배제, `afk-arena.fandom.com` WebFetch 402 차단)을 그대로 이어받는다. 이번 심화 조사에서도 위키 직접 크롤은 전부 막혔다 — `?action=raw` 우회, MediaWiki API(`api.php?action=parse`) 우회를 모두 시도했으나 **둘 다 동일하게 402**를 반환했다(신규 확인 — 우회 경로 자체가 막혀 있다는 뜻). 따라서 이 문서의 근거는 **WebSearch 스니펫 종합**과 **2차 가이드 WebFetch 전문**의 조합이며, 아래처럼 세분화해 표기한다.

| 표기 | 소스 | 신뢰도 |
|---|---|---|
| **[가이드-원문]** | 2차 가이드 사이트를 WebFetch로 전문 확보(요약 모델을 거치지만 원문 페이지 자체는 열람) | ★★★ (수치가 두 페이지 이상에서 겹치면 [교차] 추가) |
| **[가이드-검색]** | WebSearch 스니펫 종합(여러 가이드 사이트가 검색 결과에 잡히지만 개별 원문은 미확보) | ★★ |
| **[위키]** | AFK Arena Wiki(Fandom) — 검색 스니펫 경유만(402 차단, API 우회도 402) | ★★☆ (문장 단위 신뢰, 표 전체 미확보) |

이번 조사에서 **WebSearch 15회 + WebFetch 13회**(총 28회)를 사용했다. 열람 시도한 위키 페이지: `Gear` `Gear_Resonance` `Rarity` `Mythic_Upgrade_Stones` `Signature_Items` `Signature_Item_Bonuses` `Faction_Emblems` `Epic_Faction_Emblem` `Factions` `Team_Composition_Strategies` `Artifacts` `Oak_Inn_Furniture` `Hero_Furniture_Abilities` `Rare_Enhancement_Tokens` `Common_Enhancement_Tokens` `Towers_of_Esperia_Rewards` `Hero_Classes` `Hero_Types` — 전부 스니펫 경유.

## 1. Gear — 등급 사슬 13단과 강화 비용

### 1-1. 13단 전체 명칭 재확인

```
Crude → Common → Rare → Rare+ → Elite → Elite+ → Legendary → Legendary+ → Mythic → Mythic T1 → T2 → T3 → T4
```

([가이드-원문]★★★ [교차] 2곳) — **"+" 표기는 "다음 단계 직전의 중간 등급"**이다(Rare+ 는 Rare~Elite 사이, Elite+ 는 Elite~Legendary 사이, Legendary+ 는 Legendary~Mythic 사이) [가이드-검색]★★. 강화로 별을 채워서 다음 등급으로 승급하는 구조이지, "+"가 강화 결과물의 명칭인 것은 아니다.

⚠ **혼동 주의 — 이 사슬은 "영웅 등급 사슬"과 이름이 겹치지만 별개다.** 영웅(히어로) 자체의 승급 사슬도 `Rare → Rare+ → Elite → Elite+ → Legendary → Legendary+ → Mythic → Mythic+ → Ascended` 로 거의 동일한 이름을 쓴다([가이드-검색]★★) — 다만 영웅 쪽은 **Mythic+ 다음이 Ascended 하나**로 끝나고, 장비 쪽은 **Mythic 다음이 T1~T4 숫자 승급**으로 갈린다. 두 사슬이 이름이 같아 검색 스니펫에서 자주 섞였다 — 이 문서는 **장비 사슬만** 다룬다.

### 1-2. 강화 포인트 표 — 단일 출처, 양 끝만 교차확인

| 등급 | 강화 단계별 필요 포인트(누적 아님, 단계당) |
|---|---|
| Rare | 60 → 120 → 180 |
| Rare+ | 200 → 400 → 600 |
| Elite | 500 → 1,000 → 1,500 → 1,800 |
| Legendary | 2,000 → 4,000 → 6,000 → 10,000 → 13,500 |
| Mythic / T1 / T2 | 8,000 → 16,000 → 24,000 → 40,000 → **72,000** |

([가이드-원문]★★, 단일 페이지) — ⚠ **표 전체는 단일 소스**(theriagames WebFetch 1회)이고 요약 모델을 거쳤으므로 중간값은 반올림·누락 가능성이 있다. 다만 **양 끝(Rare 최초 60 / Mythic 최상단 72,000)은 00_overview.md 작성 시 이미 별도 [가이드] 출처로 확인된 값과 일치**해 [교차] 신뢰도를 준다. **초반(Rare 60)과 후반(72,000) 사이 격차가 1,200배**라는 00_overview.md의 결론이 이번 표로 더 구체화됐다 — 후반 3단(Elite→Legendary→Mythic)이 격차의 대부분을 차지한다.

- **강화 불가 구간 재확인**: Crude·Common(강화 축 자체가 없음), **Mythic T3·T4**(★★★ [교차] — "Mythic Tier 3·4 도 강화 불가, 5성 Mythic T2 의 옵션이 그대로 승계된다"는 서술을 이번에 재확인)
- **골드 비용**: "강화 포인트 1당 골드 비용이 100씩 증가한다"는 서술을 찾았으나 기준점·상한 등 정확한 공식은 확인 못함(N/F)

### 1-3. 강화 재료 — 다른 장비 vs Enhancement Token

| 재료 | 포인트 | 비고 |
|---|---|---|
| **다른 장비를 먹임(feed)** | 그 장비 자체의 등급·강화도에 비례(정확한 환산식 N/F) | 가장 흔한 방법 — 하위 장비를 상위 장비에 "먹인다" |
| **Common Enhancement Token** | **10 포인트/개** | 일일·주간 퀘스트, King's Tower(Towers of Esperia) 보상. **판매·교환 불가**(귀속) [가이드-원문]★★ |
| **Rare Enhancement Token** | **1,000 포인트/개** | Peaks of Time · Voyage of Wonders · 상점(다이아) · 이벤트·퀘스트 [가이드-원문]★★ |

([가이드-원문] `Rare_Enhancement_Tokens` · `Common_Enhancement_Tokens` 페이지 요약, ★★) — **Rare 토큰 1개(1,000P)가 Common 토큰 100개와 같은 포인트다.** 즉 AFK Arena는 "강화 재료"를 **필드 드롭(장비 자체)** 과 **정제된 화폐형 재료(토큰)** 둘로 나누고, 토큰 쪽은 다시 등급별로 환전비가 고정된 계단형 재화다 — item_design.md 의 "골드 하나가 유일한 강화 소재"인 본작과 대비되는 지점(§9-1).

### 1-4. Mythic 승급(T1→T2→T3→T4)

- **Mythic Upgrade Stone을 등급 승급마다 1개씩 소모**한다 — T1 스톤이 Mythic→T1, T2 스톤이 T1→T2, T3 스톤이 T2→T3, T4 스톤이 T3→T4 를 승급시킨다. **스톤은 티어마다 별도 아이템**이다([가이드-검색]★★, [위키]★★☆ 교차)
- **T3 스톤 획득처**: AFK Reward(챕터 30 이후) · 챕터 보상(30+) · **길드 상점(월 최대 2개)** [가이드-원문]★★ — 월 2개 상한이 T3 승급 속도의 실질 병목
- T2 단계 우선순위: **별(★) 강화 우선 vs 스톤(승급) 우선**이 갈리는데, 가이드는 "3성까지 별강화가 가장 이득이 크고, 4→5성 마지막 2강화가 최대 1,000만 골드까지 든다"고 명시한다([가이드-원문]★★★) — 강화 곡선의 후반 폭주가 실전 가이드에서도 체감되는 수준

### 1-5. 실제 장비 예시 — 등급 불명확 다수, 부위·수치는 확보

⚠ 아래 예시들은 개별 가이드 페이지에서 발췌했으나 **정확한 등급(Elite+/Legendary/Mythic 등) 표기가 원문에 없거나 요약 과정에서 유실**됐다. 수치 규모로 등급을 **추정**만 하고 N/F로 명시한다 — 추측을 확정처럼 쓰지 않는다.

| 아이템 | 부위 | 기본 옵션 | 강화 시 추가 옵션 | 추정 등급(N/F) |
|---|---|---|---|---|
| **Vanguard Axe** | 무기 | ATK+40, DEF+6, ACC+8 | ATK+52, DEF+7.8, ACC+10.4 | Legendary [가이드-원문]★★ |
| **Conjurer's Boots** | 부츠 | HP+500, ATK+20, DODGE+8 | HP+650, ATK+26, DODGE+10.4 | Legendary [가이드-원문]★★ |
| **Filthmonger's Stompers** | 부츠 | HP+225,000, ATK+2,700, DODGE+378, HASTE+19.8 | +HP 2.3%, +ATK 2.0%, +DEF 1.5%, +CRIT 2.0% | Elite+ 표기됐으나 수치 규모상 재검토 필요 — **등급 N/F** [가이드-원문]★★ |
| **Wraith's Cuirass** | 갑옷 | HP+126,000, DEF+7,200, PR+19,800 | +HP 4.6%, +ATK 1.5%, +DEF 4.3% | 수치 규모(10만 단위 HP)로 볼 때 Mythic 이상 추정 — **등급 N/F** [가이드-원문]★★ |
| **Wraith's Sabatons** | 부츠 | HP+288,000, ACC+180, HASTE+14.4k, PR+9% | +HP 3.8%, +DEF 3.0%, +CRIT 1.5%, +MR 2.3% | 위와 동일 — **등급 N/F** [가이드-원문]★★ |

**관찰 — 같은 부위(부츠)라도 옵션 조합이 아이템마다 완전히 다르다**(Conjurer's Boots=HP/ATK/DODGE, Filthmonger's Stompers=HP/ATK/DODGE/HASTE, Wraith's Sabatons=HP/ACC/HASTE/PR%). D2 처럼 "이 슬롯은 이 스탯 그룹만 뜬다"는 엄격한 접사 그룹 제한이 아니라, **슬롯은 헐거운 경향만 가질 뿐 실제로는 아이템 개체별로 옵션 조합이 자유롭다**는 정황이다(§2 참조).

## 2. Gear — 슬롯 6종·계급(Class) 게이팅

### 2-1. 슬롯은 6종, 클래스별로 이름이 갈리지 않는다

**Weapon · Gloves · Ring · Helmet · Armor(Chest) · Boots** 6슬롯은 **모든 계급(Strength/Agility/Intelligence)에 공통**이다([가이드-원문]★★★ [교차] 2곳) — "계급마다 슬롯 이름 자체가 다르다"는 취지의 초기 검색 결과가 있었으나, 재검증 결과 이는 **요약 과정의 오류로 판단해 채택하지 않는다**(예: "민첩 계급은 Blades/Cuirass/Treads로 슬롯명이 바뀐다"는 서술 — 다른 가이드·위키 어디에도 대응 근거가 없어 폐기).

### 2-2. 슬롯별 스탯 경향 — 느슨한 경향만 확인, 고정 규칙 아님

| 슬롯 | 관찰된 경향 | 확실성 |
|---|---|---|
| Weapon | **ATK가 주 옵션으로 가장 자주 등장** | ★★ [가이드-검색] |
| Boots | **Dodge·Haste·이동속도 계열이 자주 붙음** | ★★ [가이드-검색] |
| Armor(Chest) | **DEF·HP 계열 위주** | ★★ [가이드-검색] |
| Helmet / Gloves / Ring | 개체마다 조합이 갈려 뚜렷한 경향 확인 못함 | N/F |

- ⚠ **§1-5 예시가 보여주듯 "이 슬롯 = 이 스탯 고정"은 성립하지 않는다.** 강화 우선순위 가이드가 "부츠부터 강화하라"고 권하는 것도 스탯표가 고정이라서가 아니라 **부츠가 HP·방어 관통(PR)·회피 등 생존 스탯이 몰리는 경향이 있어 효율이 좋다**는 경험칙에 가깝다(§1-2 T2/T3 우선순위표 참조)

### 2-3. Strength/Agility/Intelligence ↔ Tank/Warrior/Ranger/Mage/Support — 느슨한 상관, 고정 게이트 아님

이번 조사의 핵심 성과 — 00_overview.md §6-2 가 "미확인"으로 남겨 둔 이 대응표를 **"고정 게이트가 아니라 느슨한 상관관계"** 라는 형태로 확인했다.

- **계급(Strength/Agility/Intelligence)과 역할(Class: Tank/Warrior/Ranger/Mage/Support)은 서로 다른 축이고, 완전히 1:1로 묶이지 않는다** — 공식 가이드 표현을 그대로 인용하면: *"Strength 계급은 보통 Warrior 나 Tank 클래스이지만 항상 그런 것은 아니다"*, *"Intelligence 계급은 보통 Support 나 Mage 이지만 다른 클래스로 빠지는 경우도 있다"* ([가이드-검색]★★, 복수 소스 동일 표현) — **"usually, but not always"** 가 공식 톤이다
- Agility 계급은 Ranger·Assassin 계열에 가장 많이 대응된다는 정황은 있으나 이 역시 예외가 있다는 서술과 함께 나온다
- **Mythic 미만 영웅은 정식 Class 가 없다**(01_skills.md 참조)는 사실과 겹쳐 보면, "계급→역할" 대응 자체가 **낮은 등급에서는 느슨하게 시작해서 성장(승급)에 따라 더 구체화**되는 것으로 보인다 — 다만 이 인과관계까지 원문으로 확인하지는 못했다(N/F, 추정)

> **00_overview.md §6-2 정정** — 기존 문서는 이 대응표를 "정확한 원문 확인 못함"으로 남겼는데, 이번 조사로 **"대응표 자체가 존재하지 않는다(고정 게이트가 아니다)"** 는 더 강한 결론에 도달했다. 즉 미확인이 아니라 **"확인해보니 느슨한 상관관계였다"**는 것이 정확한 답이다.

## 3. 진영(Faction) 정렬 3장치 심화

### 3-1. ① 개별 장비 진영 정렬 — 확률·물음표(?) 장비

- **Rare+ 이상만** 진영 정렬을 가질 수 있다(§1) — 정확한 발생 **확률 %는 이번에도 확인 못함**(N/F). 다만 새로 확인한 보조 장치가 있다:
- **길드 상점의 "?" 표기 장비** — 아무 진영이든(진영 없음 포함) 나올 수 있는 **미확정 진영 슬롯**을 가진 장비다. **"Field of Stars"라는 업그레이드**를 거치면 이 "?" 가 **반드시 진영이 있는 것으로 확정**된다([위키]★★☆, [가이드-검색]★★) — 이는 "확률로 뜨는 것을 나중에 재화로 확정시킨다"는 **절차형 통제권 판매**의 실례다(§9-2에서 본작 낙인과 대조)
- Mythic T3·T4 는 진영 정렬이 **기본 스탯에 흡수**된다(00_overview.md §2-2 재확인, 변경 없음)

### 3-2. ② 파티 편성 진영 조합 버프 — 정확한 4단 표 확보

| 같은 진영 인원수 | ATK / HP 버프 |
|---|---|
| 3 | **+10%** |
| 3 + 2(서로 다른 두 진영) | **+15%** |
| 4 | **+18%** |
| 5(단일 진영 올진영) | **+22%** |

([가이드-검색]★★, 다수 소스 수렴 — 00_overview.md 의 "3 Mauler+2 Lightbearer=+15%" 단일 예시를 **4단 전체 표**로 확장 확인) — **인원수가 늘수록 버프가 체증하지만 등차가 아니다**(10→15→18→22, 증분이 5→3→4로 불규칙) — "5인 올진영"이 반드시 "3+2 조합"의 강한 상위호환은 아니고, 진영 상성(§3-3)까지 고려하면 3+2 로 상성 두 개를 걸치는 편이 나을 수도 있는 구조다.

### 3-3. ③ 진영 상성 — 6진영 전체 순환 구조 확인

```
Lightbearer → Mauler → Wilder → Graveborn → (다시 Lightbearer)
```

- **4대 진영은 순환 상성**이다 — Lightbearer 는 Mauler 에게 강하고 Graveborn 에게 약하다(그 반대는 각 화살표 방향대로 한 칸씩) [가이드-검색]★★, [교차] 2곳
- **가해 측 피해 +25% 고정**(00_overview.md 재확인, 변경 없음)
- **Celestial·Hypogean은 4대 진영 순환 밖의 독립 쌍** — 서로가 서로에게 상성 우위 **및** 상성 열세를 **동시에** 가진다(상호 25% 가해 증가, 상호 25% 피해 증가로 추정되나 "동시에 강하고 동시에 약하다"는 서술만 확인, 정확한 수치 대칭 여부는 N/F) [가이드-검색]★★

> **관찰** — 4대 진영은 "가위바위보"가 아니라 **단방향 순환**(A>B>C>D>A)이다. 즉 어느 진영도 절대 우위가 없고, 파티 구성이 상대 파티의 진영에 따라 최적해가 바뀐다. Celestial/Hypogean 은 이 순환에 들어가지 않는 **별도 축**(엔드게임 진영으로 후첨된 것으로 추정, N/F)이다.

- **Furniture Wishlist** 기능이 뽑기 확률에 관여(가중치 상향으로 추정)한다는 서술은 확인했으나 정확한 가중치 수치는 N/F

### 7-4. 3피스/9피스 능력 — 메커니즘 재확인

**3피스 배치 = 1차 고유 능력 언락, 9피스(풀세트) 배치 = 강화된 2차 능력**(00_overview.md 재확인, 변경 없음). 실명 예시로 **Eironn**이 반복 거론됐으나(가구 3/9피스로 그의 패시브 확정 발동) **정확한 능력 텍스트는 확보하지 못했다**(N/F) — 원문이 "각 영웅 초상화 안에 있다"는 게임 내 UI 서술만 확인됨.

## 8. 재련 — 강화 소재와 "없는" 분해 시스템

### 8-1. 강화 소재 정리(§1-3 요약)

강화 소재는 **① 다른 장비를 직접 먹인다 ② Enhancement Token(Common=10P/Rare=1,000P, 등급별 고정 환전비)** 둘뿐이다. 두 경로 모두 최종 산출물은 동일한 "Enhancement Point" 하나로 합쳐진다 — **재료의 출처(파밍이냐 토큰 구매냐)가 다를 뿐, 강화 그 자체는 단일 포인트 게이지 하나로 처리**된다.

### 8-2. 분해(Salvage) 시스템 — 존재하지 않는다(신규 확인)

이번 조사에서 명시적으로 확인한 것 — **AFK Arena(원작)에는 "장비를 분해해서 별도 재화로 바꾸는" 전용 시스템이 없다.** 검색 중 "Forge Stone으로 분해"라는 시스템이 걸렸으나 **그건 AFK Journey(후속작)의 것**이었다([위키/가이드 혼입, §0 경고대로 배제]) — 원작은 **하위 장비를 상위 장비 강화 게이지에 그대로 먹이는 것 자체가 "분해"를 겸한다.** 별도의 "분해 버튼 → 재화 획득" 단계가 없다는 뜻이다.

> **이것이 이번 조사에서 가장 명확한 구조적 대조점이다** — D2(§8-4, socket_layer)도 룬워드 등에서 "회수 불가"가 원칙이지만 호라딕 큐브 레시피라는 별도 가공 경로가 있고, 본작(item_design.md §5-2)은 "가루"라는 분해 산출 재화를 이미 갖고 있으면서도 **소모처가 0인 상태**로 방치돼 있다. AFK Arena는 반대로 **분해라는 단계 자체를 걷어내고, 남는 장비를 직접 다음 장비의 재료로 흡수**시켜 이 문제를 원천 차단했다 — "분해 재화를 어떻게 쓸까"를 고민할 필요가 없는 설계다(§9-5에서 상술).

## 9. 본작 시사점

> 본작(TheSevenSimulationRPG)은 파티 3인 자동전투 방치형 파밍 RPG. 아이템은 희귀도 4단(매직→레어→크래프트→유니크)의 "통제 가능성 계단"이고, 골드가 강화(접사 증폭)의 유일한 소모처다(item_design.md §1). 낙인(스티그마)은 소모처가 둘(크래프트·전술카드)이라 공급이 아이템 쪽에서 잠겨 있다(§5-1). 가루는 소모처가 0인 채 방치돼 있다(§5-2). 이 절은 00_overview.md §5 표에 **없던** 새 통찰 위주로 적는다.

1. **강화 재료가 "필드 드롭"과 "화폐형 토큰" 이중 트랙이고, 토큰은 등급별 고정 환전비를 가진다**(§1-3, Common=10P/Rare=1,000P) — 본작은 강화 소재가 **골드 하나**뿐이다(item_design.md §1 "강화 = 골드 소모로 접사 증폭"). AFK Arena 식 이중 트랙은 "파밍(장비를 직접 먹임)"과 "과금/이벤트(토큰 구매)"라는 **서로 다른 압력을 분리해서 강화 게이지 하나로 합류**시키는 모델이다 — 본작이 §5-3의 "가루" 처리를 확정할 때, **가루를 강화의 보조 재료(골드의 대체·가속 수단)로 붙이는 안**을 검토한다면 이 이중 트랙 모델이 참고가 된다. 단, 본작은 아직 과금 설계가 밖에 있어 직접 적용 근거는 약하다.
2. **분해 시스템 자체가 없다 — 남는 장비를 그대로 다음 장비의 재료로 흡수한다**(§8-2). 본작은 이미 "가루"(분해 산출 재화)를 갖고 있는데 **소모처가 0**이라는 문제를 안고 있다(item_design.md §5-2 "반례"). AFK Arena 는 애초에 **분해라는 중간 단계 자체를 걷어내서 이 문제를 만들지 않았다** — "소모처 없는 자원은 만들지 않는다"(item_design.md §5-2 원칙)를 극단까지 밀면, **분해 재화(가루)를 아예 신설하지 않고 장비를 강화 게이지에 직접 먹이는 쪽**이 원칙에 더 부합하는 대안일 수 있다. 이는 가루의 정체를 확정할 때(§5-3 미확정) 검토할 가치가 있는 세 번째 선택지다(기존 안 = "가루를 몬스터 재료와 통합" vs "가루를 분해 전용으로 축소" 둘뿐이었는데, "가루 자체를 없애고 장비를 직접 강화에 먹인다"는 안이 추가된다).
3. **"?" 장비 + Field of Stars — 확률로 뜬 것을 재화로 나중에 확정시키는 절차**(§3-1)는 본작 낙인의 "통제권에 대한 프리미엄"(item_design.md §1 낙인)과 **정확히 같은 문제의식을 다른 시점에 적용**한 사례다. 본작 낙인은 **제작 시점**에 죄종을 지정해 통제권을 사는 반면, AFK Arena "Field of Stars"는 **이미 드롭된 장비의 사후 확정**에 재화를 쓴다 — "언제 통제권을 파는가"(제작 전 vs 드롭 후)의 축이 하나 더 있다는 것을 보여주는 사례. 본작이 §5-3의 "지정재가 두 일을 겸한다" 문제를 풀 때, **사후 확정형 소모처를 낙인과 분리해서 신설하는 안**의 참고가 된다.
4. **계급(Str/Agi/Int) ↔ 역할(5종)이 고정 게이트가 아니라 "느슨한 상관관계"임을 실제 라이브 서비스가 증명한다**(§2-3). 본작은 착용 제약을 "요구 레벨만"으로 이미 극단적으로 단순화했다(item_design.md §2 "착용 제약" 변경점, 능력치 게이트 폐지). AFK Arena 의 사례는 **그 반대편 극단(계급-역할 대응이 있는 듯하지만 실은 느슨한 디자인)이 실전에서 플레이어에게 오히려 "예외가 있다"는 피로감·불확실성으로 읽힌다**는 것을 보여준다 — 본작이 요구 레벨만 남긴 단순화가 **AFK Arena가 자연스럽게 도달하지 못한 명료성**이라는 것을 재확인하는 대조 자료다.
5. **Artifact 의 5역할 분류(Mage/Tank/Warrior/Ranger/Support)가 Elder Tree 의 5갈래(Sorcery/Fortitude/Might/Celerity/Sustenance)와 완전히 동일한 5분류를 공유한다**(§6-2) — AFK Arena는 "역할 5종"이라는 축 하나를 **스킬 성장(Elder Tree)과 아이템(Class Artifact) 양쪽에서 재사용**한다. 본작은 직업(7종, hero_design.md)과 죄종(7종)이라는 두 축을 이미 갖고 있는데, 새 시스템(예: 향후 유물형 아이템을 검토한다면)을 설계할 때 **기존 7분류를 재사용할지, AFK Arena처럼 소수(5 이하)의 "역할" 축을 별도로 신설할지**의 갈림길이 있다는 것을 보여주는 선례다. 본작이 아직 열지 않은 손잡이지만, "축을 늘리지 않고 재사용한다"는 원칙(CLAUDE.md 철학 3 "단순화가 정답")과 정확히 같은 방향의 실례라는 점은 기록해 둘 가치가 있다.
6. **Gear Resonance가 "장비 단위로 옵트인/아웃 가능한 자동화"라는 절충안이다**(§4, 신규 확인 — 레조넌스를 개별 장비·영웅 화면에서 켜고 끌 수 있다). 00_overview.md §5 표(#8)는 Resonance를 "자동화가 결정을 대신 가져가는 스펙트럼의 반대쪽 극단"으로만 기록했는데, 이번에 확인한 **토글 가능성**은 그 스펙트럼이 실은 이분법이 아니라 **"자동화를 켤지 끌지 자체는 플레이어가 고른다"는 3번째 지점**이 있다는 것을 보여준다. 본작이 §6-4(item_design.md) "자동 분해가 무엇을 보호하나" 미확정 과제를 풀 때, **자동 분해 규칙(ilvl 하한·점수 하한)을 전역이 아니라 개체 단위로 예외 지정할 수 있게 하는 안**의 참고 모델이 된다 — "규칙은 하나, 예외는 플레이어가 표시"라는 절충.
7. **Rowan 시그니처 아이템의 10레벨 마일스톤이 선형이 아니라 가속(60→120→200→400)**이라는 실측치(§5-2)는, 본작이 향후 무기 개체·전용 능력의 레벨 스케일링을 설계할 때 "마일스톤 배율은 등차가 아니라 등비에 가깝게 갈 수 있다"는 구체적 참고 수치가 된다 — battle_design.md §9-0 의 "성장 축(기하)·비율 축(선형)·곡선 밖" 3분류 중 **Signature Item 의 능력치는 성장 축에 더 가깝게 설계돼 있다**는 교차 확인이다.
