## 1. 습득 구조 — 레벨업 자동 + 고레벨 구매 관문

(기존 조사 §3-1 유지)

- **레벨업 시 스킬 마스터 NPC 방문**으로 대부분의 스킬을 습득한다(자동 또는 소액 비용으로 추정).
- **51레벨 이후 등 고레벨 구간은 스킬북을 NPC 상점에서 별도로 구매**해야 한다[검색합성] — "51레벨 이후 스킬북 어디서 구매하는가요?"라는 유저 질문이 반복적으로 발견될 만큼, 완전 자동이 아니라 레벨 구간마다 상점 방문(구매 관문)이 낀다.
- 40레벨대 일부 스킬북은 **선행 퀘스트 체인**을 완료해야 지급되는 경우도 있다[검색합성].
- → **"성장은 공짜로 흐르지 않는다"** — 초반은 자동, 중후반은 구매/퀘스트로 병목을 심는 흔한 MMORPG 문법. [dragoncliff/01_skills.md §3](dragoncliff/01_skills.md#3-school--스킬-강화의-병목-book-pages-정확한-비용표)의 Book Pages(탐험 전용 병목)와 독립적으로 같은 결론에 도달한 두 번째 사례.

## 2. 체인 스킬(연속기) 구조 — 5분류 원문 정의

기존 조사는 4분류(일반/발동/연속기/특수연속기/확률연속기 — 실질 5개 항목)를 서술했는데, 이번에 **연속기 시스템 가이드 원문**[인벤 idx90]으로 정의를 재확인·정밀화했다.

### 2-1. 스킬 5분류 원문

| 분류 | 원문 정의[인벤 idx90] |
|---|---|
| **일반 스킬** | 독립적으로 사용 가능 |
| **발동 스킬** | 연속기를 시전하기 위한 준비 단계 |
| **연속기** | 발동기 후에만 사용 가능하며, **단독으로 사용할 수 없다** |
| **특수연속기** | 발동기 후 연계되는 특별한 연속기(상태이상 등 추가 효과) |
| **확률연속기** | **"일정 확률로 사용이 가능한 연속기"**로, 발동 시 효과가 뛰어남 |

- **구조는 가로형 트리** — "A → B, C" 형태면 A가 발동기, B·C가 그 연속기[인벤]. 습득 여부는 스킬창(K)의 **연속기 목록** 탭에서 트리 형태로 확인(습득=활성 아이콘, 미습득=회색)[인벤 idx90].

### 2-2. UI가 콤보 입력을 강하게 유도한다

**두 가지 편의 기능**[인벤 idx90 원문]:
- **퀵바 자동 변경**: 발동기를 쓰면 퀵슬롯 아이콘이 자동으로 다음 연속기로 교체 — "1-1-1" 순차 연타가 가능
- **연속기 알리미**: 캐릭터 옆에 뜨는 다음 스킬 아이콘을 클릭해도 즉시 발동

→ 콤보를 외우지 않아도 UI가 절반을 대신 해준다는 기존 관찰이 원문으로 재확인됐다.

### 2-3. 실전 사례 — 마도성 PvE 딜사이클 (기존 조사 유지)

불꽃폭발 → 혹한의바람 → 불꽃화살 → 겨울의속박 → 냉기파동 → 집중의기원 순으로 발동기·연속기가 순서를 이루고, **평타 3회마다 확정으로 불꽃폭발 연계가 열리는 구간**도 있다[검색합성] — 순수 확률뿐 아니라 "몇 회마다 확정"이라는 **카운터 기반 확정 연계**도 섞여 있다.

## 3. 각성/전직 구조 — 1회성 분화 + 신규 직업의 옆으로 확장

### 3-1. 4원류 → 8확정 직업 매핑 — 원문으로 재확인

기존 조사가 서술만 했던 매핑을 **직업 선택 가이드 원문**[인벤 idx185]으로 표를 재구성했다:

| 원류 직업 | 각성 1 — 성격 | 각성 2 — 성격 |
|---|---|---|
| **전사** | **수호성** — 탱커("강인한 체력으로 꾸준한 사냥") | **검성** — 딜러(무기 다루기 능숙한 밸런스형 근접) |
| **정찰자** | **궁성** — "원거리 암살자"(거리 유지 견제) | **살성** — "솔로잉에 특화"(빠른 공속) |
| **마법사** | **마도성** — 누커("한방에 몰아치는 파괴력") | **정령성** — 펫 클래스(정령 활용 지속딜) |
| **사제** | **치유성** — 메인힐러(치유·버프·부활) | **호법성** — 하이브리드("딜/힐/버프 균형") |

- **"각성"은 10레벨의 데바(Deva) 각성 퀘스트, 단 1회다**[인벤] — 원칙적으로 되돌릴 수 없다. 예외는 "클래스 체인지"라는 **운영 이벤트**(아이온 클래식의 무료 클래스 체인지 이벤트 등[공식뉴스])뿐 — 상시 무료 리스펙이 아니라 비정기 이벤트다.

### 3-2. 신규 직업 — "옆으로" 확장, 성격 신규 정밀화

기존 조사는 신규 직업 이름만 나열했는데, 이번에 **집행자·사격성·기갑성·음유성의 실제 무기·전투 방식**을 확보했다:

| 직업 | 성격[검색합성] |
|---|---|
| **집행자** | 사슬검 중거리 딜러 |
| **사격성** | "화구"라는 무기로 원거리 물리 공격. **시전 시간이 아니라 공격 후 누적할수록 데미지가 커지는 방식** — 살성+궁성을 합친 듯한 조작 감각 |
| **기갑성** | 4.5 패치 신규. **"기갑"이라는 로봇을 타고 딜을 하는 유일한 마법계열 근접 직업** |
| **음유성** | 신규 무기 "현악기"로 **파티원 치유 + 적 약화**를 겸함. 방어(정화·이동불가 해제·물리방어)와 공격(넉백·강화효과 해제·마비·수면)을 함께 보유 |
| **권성·루미네스**(2024-11)**·화신**(2025-07) | 이름·업데이트 시점만 확인, 상세 스킬 미확보 |

- → **"사격성 = 시전이 아니라 누적으로 딜이 오른다"**는 처리는 기존 8직업 어디에도 없던 **새로운 파워 축**이다 — 원류 4직업 체계 확립 이후 신규 직업이 단순히 "다른 무기의 같은 문법"이 아니라 **문법 자체를 하나씩 새로 실험**하며 늘어났다는 뜻으로 읽을 수 있다(기존 §4-6 "깊이가 아니라 폭" 관찰에 대한 보강 근거).

### 3-3. "3차 전직" 없음 — 기존 결론 유지

세로 심화 층은 없고, 그 자리를 (1) 스킬 레벨 성장 (2) 스티그마 조합(§5) (3) 신규 직업의 옆으로 확장이 대신한다는 기존 조사의 결론은 이번 심화로 재확인만 됐다.

## 4. 클래스 8종별 실제 스킬 — 대표 스킬·초기 스탯·딜사이클 전수

### 4-9. 8클래스가 보여주는 것

1. **"주 능력치 1~2개 + 무기·방어구 고정 1쌍"이 클래스 정체성의 최소 단위다** — 8클래스 전부가 힘 또는 지력/의지 중심, 무기군 1~2개, 방어구 소재 1개로 고정된다. [dragoncliff/01_skills.md §5-8](dragoncliff/01_skills.md#5-8-대표-7종이-보여주는-것)의 "주능력치/원소 고정 1쌍" 관찰과 같은 결론에 **독립적으로 도달**한 두 번째 MMORPG 사례다.
2. **역할과 실제 스킬 구성이 어긋나는 사례가 이미 있다** — 치유성(메인힐러)이 근거리·원거리 공격 스킬을 함께 갖고, 호법성(버프 서포터)이 법봉 근접 공격을 병행하며, 살성(근접 딜러)이 §4-3 아이템 우선순위에서 회피(생존)를 치명타(공격)만큼 중시한다. **"역할 하나에 스킬 전부를 쏟지 않는다"**는 것이 8클래스 공통 패턴이다 — 실시간 조작 MMORPG라 플레이어가 상황을 판단해 스킬을 고를 수 있기 때문에 가능한 처리다.
3. **트레이드오프형 스티그마가 반복된다** — 호법성의 "격노의 주문"(공격력 +15%, 회복 시전시간 배로 증가)은 [dragoncliff/01_skills.md §2-1](dragoncliff/01_skills.md#2-1-rage-비용-감면-경로-4종--신규-확인)의 "스크롤 스타 효과"(쿨타임 0, Rage 비용 대폭 증가)와 같은 계열 — **한 축을 강하게 얻는 대신 다른 축을 명시적으로 깎는 노드**는 서로 다른 게임에서 반복 관찰되는 설계 문법이다.

## 5. 스티그마가 주는 스킬 — 클래스별 실제 예시

> 슬롯 메커니즘(해금 계단·등급 게이트·획득 경로)은 [02_items.md §5](02_items.md#5-스티그마stigma--장비도-스킬도-아닌-제3의-슬롯)에서 다룬다. 여기서는 **스티그마가 실제로 어떤 스킬을 주는지**를 클래스 횡단으로 모은다.

§4에서 확보한 스티그마 예시를 모으면 다음과 같다:

| 클래스 | 스티그마 이름 | 효과 성격 |
|---|---|---|
| 검성 | 체력 강화 | 수치업(생명력 20% 회복) |
| 검성 | 성문 파괴 | 조건부(성문 대상 한정 추가 타격) |
| 검성/수호성 | 균형의 갑옷 | 수치업(상태이상 저항) |
| 수호성 | 도발의 포효 | 반응형(탱킹 유틸) |
| 수호성 | 격앙 | 수치업(물리공격력 +30%) |
| 살성 | 연쇄 문양 각인 | 변형(콤보 구조 자체를 바꿈) |
| 살성 | 연막탄 | 유틸(광역 실명) |
| 살성 | 신속의 계약 | 수치업(공격속도) |
| 치유성 | 섬광 I | 유틸(실명 CC) |
| 치유성 | 주신의 은총 I | 자원(정신력 소모 면제) |
| 호법성 | 오드의 약속 | 반응형(공격 시 확률 자원 회복) |
| 호법성 | 흡수의 주문 | 반응형(피격 시 회복) |
| 호법성 | 격노의 주문 | **트레이드오프형**(공격력↑ / 회복시전시간↓) |

→ **등급(일반/상급)이 액티브·패시브를 가르는 규칙은 여전히 확인 못 했지만(02_items.md §5-3 N/F), 스티그마의 효과 성격 자체는 수치업·반응형·유틸·변형·트레이드오프까지 다양하게 흩어져 있다** — [diablo2/skills/01_amazon.md §3-1](diablo2/skills/01_amazon.md#3-1-각-패시브가-주는-축)의 "수치업/반응형" 2분류보다 아이온 스티그마 쪽이 분류가 더 풍부하다. 특히 **살성의 "연쇄 문양 각인"처럼 스킬의 작동 방식 자체를 바꾸는 변형 노드가 스티그마(파밍형 슬롯)에 들어 있다는 것**이 본작 마스터리 3분류(수치/반응/변형) 논의에 직접 참고가 된다 — 아마존 패시브에는 변형이 전무했던 것과 대비된다.

## 6. 역할별 스킬 배분 — 종합 관찰

(기존 §3-5의 결론을 §4의 8클래스 전수 데이터로 재확인·확장)

**공통 관찰**: 8클래스 전부 **역할 하나에 스킬 전부를 쏟지 않는다** — 딜러(검성·살성)도 생존 수단(회피 중시 아이템 우선순위, 은신)을 갖고, 힐러(치유성)·버퍼(호법성)도 딜/유틸 수단을 놓지 않는다. 이는 **실시간 조작 MMORPG라 플레이어가 상황을 판단해 스킬을 고를 수 있기 때문에 가능한 처리**다 — 자동전투인 본작에서 그대로 재현하면 "우선순위 슬롯 하나짜리 AI가 상황판단 못 하는 문제"([dragoncliff/00_overview.md §6-3](dragoncliff/00_overview.md#6-3-자동화-배급표)의 Auto-Tactics 불만 사례와 동일 계열)를 만날 공산이 크다.
