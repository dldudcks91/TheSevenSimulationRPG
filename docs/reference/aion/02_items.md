## 0. 조사 방법과 신뢰도

[00_overview.md §0](00_overview.md#0-조사-방법과-신뢰도)와 동일한 신뢰도 표기(**[인벤]·[공식]·[검색합성]·[위키경유]**)와 **아이온2 오염 배제 원칙**을 그대로 쓴다.

이번 심화의 방법론적 진전 — 기존 조사는 `aion.inven.co.kr` 가이드 페이지를 URL만 출처로 나열하고 본문은 WebSearch 요약에 의존한 경우가 많았는데, 이번엔 **아이템 관련 가이드 페이지(idx=88 마석·신석, idx=118 강화, idx=237 아이템 종류 개요)를 직접 WebFetch로 열어 원문을 확보**했다. 공식 가이드북(`aion.plaync.com/guidebook`)은 이번에도 대부분 SPA 껍데기만 반환됐으나, **`probability.plaync.com/aion`(공식 확률 정보 페이지, "[시엘] 강화형 아이템(강화석/마석) 강화 확률 정보" 등)의 존재 자체는 이번에 새로 확인**했다 — 접근은 확인했지만 원문 수치표 추출까지는 이번 세션에서 못 했다(§8 N/F).

## 1. 슬롯과 등급

### 1-1. 부위 구조 (기존 조사 유지)

- 방어구 — **무기 + 방어구 소재 4종**(§1-3) + **액세서리 5부위**: 목걸이·귀걸이·반지·허리띠·**모자**[인벤 idx237] — 모자가 방어구가 아니라 액세서리로 분류되는 것이 눈에 띄는 지점이다.

### 1-2. 무기 9종 — 신규 확정

기존 조사는 무기 종류를 "9종이라는 언급만 있고 목록 미확보"로 남겼는데, 이번에 **정확한 9종 목록**을 확보했다[인벤 idx237]:

| 무기 | 비고 |
|---|---|
| 단검 | 살성 |
| 장검 | 검성·수호성·궁성(보조) |
| 대검 | 검성(양손)·수호성(솔로잉 보조) |
| 미늘창 | 검성(양손, 4타) |
| 활 | 궁성 |
| 전곤 | 치유성·호법성 |
| 법봉 | 치유성·호법성 |
| 법서 | 마도성·정령성 |
| 보주 | 마도성·정령성(보조) |

무기는 **"1타~4타"로 공격 횟수가 표시**된다는 것이 이번에 새로 확인한 특징이다[인벤 idx237] — 예: 대검=3타, 미늘창=4타[인벤 idx149]. 검류(장검·대검·미늘창·단검)는 §1-1(부위 구조)에서 다루지 않았던 **무기 자체의 타수 속성**이 딜링 리듬을 정하는 축으로 작동한다는 뜻이다.

### 1-3. 방어구 4재질 — 직업 매핑 신규 정밀화

기존 조사는 "직업군이 소재를 결정한다"까지만 서술하고 세부 매핑을 미확인으로 남겼는데, 이번에 매핑 표를 확보했다[인벤 idx237]:

| 재질 | 특성 | 착용 직업군 |
|---|---|---|
| **로브**(천옷) | 마법저항 높음 | 마도성·정령성(마법사 계열) |
| **가죽** | 회피 수치 높음 | 궁성·살성(정찰자 계열) |
| **사슬** | 중간 방어력 | 호법성(사제 계열 하이브리드) |
| **판금** | 최고 방어력 | 검성·수호성(전사 계열) |

치유성(사제 메인힐러)의 소재는 이 표에 명시되지 않았으나, 직업 가이드 원문은 **"로브(파티, 정신력 확보) 또는 사슬(솔로, 방어력 확보)"** 둘 다 실전에서 쓴다고 서술한다[인벤 idx161] — 즉 사제 계열 내부에서도 치유성은 로브·사슬을 상황에 따라 갈아 끼우고, 호법성만 사슬 고정이다.

### 1-4. 등급 체계 — 4단계 + 특수 2범주로 정밀화

기존 조사(§5-2)는 "일반/희귀/전승/유일/영웅/신화 6단계 → 2018년 3단계 축소"라는 단일 출처 서술과 "일반/희귀/전승/유일 4단계"라는 서술이 공존해 미확인으로 남겼다. 이번에 **아이템 종류 개요 페이지 원문**에서 다음 구조를 확인했다[인벤 idx237]:

```
일반(회색) → 희귀(녹) → 전승(파랑) → 유일(주황)   ← 기본 4단계
       + 어비스 아이템   (어비스 지역에서 어비스포인트로 구매)
       + 드라코닉 아이템 (제작 숙련도 400 이상 달인만 제작 가능)
```

→ 이 발견은 **"6단계 → 3단계로 축소됐다"는 기존 단일 출처 서술과 다른 해석**을 제시한다 — 기본 등급은 **처음부터 4단계**였고, "영웅"·"신화"로 불리던 상위 개체는 **별도 축(어비스 재화 구매 / 제작 숙련도 게이트)의 특수 아이템 카테고리**였을 가능성이 있다. 다만 이 해석도 단일 출처 재확인이라 확정은 아니다 — **6단계설과 "4단계+특수 2범주"설 중 어느 쪽이 정확한 시기별 사실인지는 여전히 N/F**로 남긴다(§8).

## 2. 마석(Manastone) — 등급이 소켓 수를 직접 정한다

(기존 조사 §2-2 유지, 신규 확인 1건 추가)

| 아이템 등급 | 마석 소켓 수 |
|---|---|
| 일반 | 1 |
| 희귀 | 2 |
| 전승 | 3 |
| 유일 | 4 |

[인벤 idx88] — 무기·방어구에 장착해 "부가 옵션을 추가"하는 강화 시스템. **PvP(어비스) 아이템은 등급과 무관하게 전부 고정 6소켓**[검색합성].

- **옵션은 flat 수치** — "공격력+4", "명중+12" 같은 절대값[인벤 idx88]. % 옵션이 아니다.
- **합성 마석(복합 마석)** — 메인 옵션 + 서브 옵션을 하나의 마석에 담아 사실상 "마석 한 칸에 옵션 2개"[검색합성].
- **장착 실패 페널티가 이 시스템의 핵심 긴장이다**: "기존의 마석 장착이 성공했더라도 다음 시도에서의 마석 장착이 실패할 경우 최초로 장착한 마석까지 모두 사라지게 된다"[인벤 idx88 원문] — 뒤 칸으로 갈수록 판돈이 커지는 도박 구조.
- **신규 확인 — 제거 경로**: 마을의 **마석 제거사 NPC**를 통해 유료로 제거 가능하지만, **제거된 마석은 회수 불가능**하다[인벤 idx88]. 즉 "실패로 잃는 것"과 별개로 "의도적으로 빼는 것"도 대가(비용 + 마석 자체 소실)를 치른다 — 마석 슬롯은 **한 번 채우면 자유롭게 재배치할 수 없는 반영구 결정**에 가깝다.

## 3. 신석(Godstone) — 무기 전용, 확률 발동형

(기존 조사 §2-3 유지, CC 효과 확률·지속 관계 신규 확인)

| | 마석 | 신석 |
|---|---|---|
| 장착 대상 | 무기·방어구 | **무기만** |
| 효과 성격 | **상시** flat 스탯 | **확률 발동형** 추가 대미지/상태이상 |
| 획득 | 상점·드롭·합성 | **30레벨 이상 몬스터 저확률 드롭**, 고가 |
| 장착 | 마석 상점/직접 | **신석강화사 NPC 필수**, 높은 비용[인벤 idx88] |
| 효과 예 | 공격력+4 | 화/수/풍/지 속성 추가 대미지, 독·출혈 등 상태이상 |

- **신규 확인 — CC 효과 신석 간 확률·지속 트레이드오프**: "마비는 확률이 낮고 지속이 짧으며, 봉인(봉쇄)은 확률이 중간이고 지속이 길고, 침묵은 확률이 중간이고 지속이 중간"[검색합성] — **강한 CC(마비)일수록 발동 확률과 지속시간을 함께 깎는다**는 것이 신석 상태이상 효과 설계의 원칙으로 보인다. 정확한 %·초 수치표는 확보하지 못했다(N/F).

→ "상시 스탯"과 "확률 프록(proc) 효과"를 서로 다른 장착 슬롯으로 물리적으로 분리한 것이 이 이원화의 요점이라는 기존 결론은 유지된다.

## 4. 강화(Enchant) — 강화석 추출 메커니즘 + 2단 리스크 계단

### 4-1. 강화석 획득 — 추출(신규 확인)

기존 조사는 "강화석 레벨 vs 아이템 레벨 격차가 성공률을 정한다"는 결과만 서술했는데, 이번에 **강화석 자체의 획득 경로**를 확인했다[인벤 idx118 원문]:

- **추출 도구**(각 마을 잡화 상인, **242키나**)로 장비를 "추출"하면 강화석을 얻는다.
- 추출은 **성공/실패가 있다** — 실패하면 아무것도 안 나오고, 성공하면 **추출한 아이템 레벨보다 높은 레벨의 강화석이 무작위로** 나온다.
- **희귀도가 높은 아이템(희귀/전승/유일)일수록 추출 시 더 많은 개수·더 높은 레벨의 강화석**을 얻는다[인벤 idx118].

→ **강화석 자체가 "장비 하나를 갈아 넣어야 나오는 2차 파밍 산출물"**이라는 뜻이다. 마석(§2)이 몬스터 드롭·상점으로 직접 얻는 것과 달리, 강화석은 **"쓸모없어진 장비를 분해해서 재활용하는" 순환 구조**에 있다.

### 4-2. 강화 성공률 — 레벨 격차 원칙 (기존 조사 유지)

- **강화석 레벨이 아이템 레벨보다 낮으면 무조건 실패**[인벤 idx118 확인 — "강화석의 레벨은 반드시 자신의 장비 레벨과 같거나 높아야 한다"]. 10레벨 이상 낮은 강화석은 무조건 실패, 15레벨 강화석은 대략 5:5, 20레벨 강화석이면 성공 우세[검색합성].
- **공식 확률 페이지(`probability.plaync.com/aion`)의 존재는 확인했으나, 원문 수치표 추출은 못 했다** — 이번 세션의 N/F로 남긴다(§8).

### 4-3. 실패 페널티 — 2단 계단 (기존 조사 유지)

- **1~10강**: 실패해도 **-1강만 밀린다** (완만한 손해)
- **11~15강**: 실패하면 **10강까지 통째로 귀환**한다 (절벽)
- **아이템 자체는 파괴되지 않는다** — 마석과 달리 "장비가 사라지는" 일은 없고, 강화 수치만 오르내린다[검색합성].
- 강화 보조제(1.9패치 도입) — 마석 장착 성공률을 높여주는 소모 아이템[검색합성].

→ **"안전 구간"과 "하이리스크 구간"을 강화 수치 그 자체의 구간으로 가른 것**이 구조의 핵심. 마석(전부-아니면-전무)과 강화석(계단식, 절벽은 후반부에만)이 **같은 게임 안에서 서로 다른 리스크 곡선**을 쓴다는 기존 결론이 이번 심화로 재확인됐다.

## 5. 스티그마(Stigma) — 장비도 스킬도 아닌 제3의 슬롯

**"캐릭터에 장착하는 스킬석"**[인벤] — 장비창이 아니라 별도 슬롯에 꽂지만, 등급이 있고 거래·교환이 가능한 실물 아이템이라 아이템과 스킬 중간 지대에 있다. **스킬로서의 내용물(실제 스티그마 이름·효과)은 [01_skills.md §5](01_skills.md#5-스티그마가-주는-스킬--클래스별-실제-예시)에서 다룬다. 여기서는 슬롯 메커니즘만 다룬다.**

### 5-1. 슬롯 해금 계단 (기존 조사 유지)

- 20레벨 스티그마 입문 퀘스트 완료 → 2개. **10레벨 단위로 +1**. 50레벨에 **일반 슬롯 5개**[인벤].
- **상급 슬롯은 별도 계단**: 55레벨에 첫 상급 슬롯, 57레벨에 6번째 상급 슬롯을 여는 퀘스트 등[검색합성].
- **등급이 슬롯을 게이트한다** — 상급 슬롯엔 상급 이하만, 일반 슬롯엔 일반만 장착 가능(등급보다 낮은 스티그마는 아무 슬롯에나 가능하나 그 반대는 불가)[검색합성].

### 5-2. 최대 슬롯 수 — 2차 소스로 재확인

기존 조사는 "최대 11개"를 단일 출처 미확인으로 남겼는데, 이번 검색에서 **"레벨 업과 퀘스트를 통해 최대 11개까지 확장할 수 있다"는 두 번째 독립 서술**을 확인했다[검색합성] — 여전히 정확한 슬롯별 해금 레벨 전체표(6~11번째 슬롯이 몇 레벨인지)는 미확보(N/F)이지만, **"최대 11개"라는 총량 자체의 신뢰도는 이번 심화로 한 단계 올라갔다.**

### 5-3. 획득 경로 3갈래 (기존 조사 유지)

| 경로 | 특징 |
|---|---|
| **NPC 상점**(스티그마 명인/조율사, 천족·마족) | 비싸지만 확실. 귀속이라 거래 불가 |
| **몬스터 드롭**(어비스 사냥이 더 잘 나옴) | 싸지만 운. 거래 가능해 경매장 유통 |
| **퀘스트**(상급·최상급) | 노력이지만 확정 지급 |

- **등급별로 액티브를 주는지 패시브를 주는지의 명확한 구분 규칙**은 이번에도 미확인(N/F)이나, [01_skills.md §5](01_skills.md#5-스티그마가-주는-스킬--클래스별-실제-예시)에서 확보한 실제 예시들을 보면 **액티브(암습·연쇄 문양 각인·연막탄 등 전투 중 발동형)와 패시브(위기관리·격앙·오드의 약속 등 상시/조건부 발동형)가 뒤섞여 있다** — 등급이 아니라 개별 스티그마마다 정해지는 것으로 보인다.

## 6. 날개(Wing) — 등급 계단 + 기능·전투스탯 겸용 슬롯

### 6-1. 기본 구조 (기존 조사 유지)

- 장비(방어구) 취급이 아니라 **독립 슬롯**.
- **이동(활공/비행) 기능**과 **전투용 부가 스탯**(치명타·명중·추가 공격력)을 한 아이템이 함께 준다[검색합성] — 기능성 슬롯 하나가 전투력 축도 겸하는 이중 역할.

### 6-2. 등급 계단 — 신규 확인 (실제 이름·획득처)

기존 조사는 날개 등급을 "장비와 같은 색 체계를 공유한다"는 추정만 서술했는데, 이번에 **실제 등급명과 획득처**를 확보했다:

| 등급 | 이름 | 획득처 |
|---|---|---|
| (기본 계단) | **데바의 하급 → 중급 → 상급 → 최상급 날개** | 반복 퀘스트·징표 교환 등 단계적 진행[검색합성] |
| 전승 | **가우온의 날개**(천족) / **다리나의 날개**(마족) | 하우징 지역 반복 퀘스트 "사계절의 잎새" 완료[검색합성] |
| 유일 | **고대 정령의 날개** | 12인 인스턴스 던전 **도르겔 저택**의 마지막 보스 **쟈드라** 처치[검색합성] |

→ "데바"라는 명칭이 [01_skills.md §3](01_skills.md#3-각성전직-구조--1회성-분화--신규-직업의-옆으로-확장)의 10레벨 1회성 각성 퀘스트명과 같은 단어를 쓰지만, **날개 등급명의 "데바"는 각성 시스템과 직접 연결되는 근거는 확인하지 못했다**(동음이의어로 추정, N/F).

### 6-3. 강화 리듬 (기존 조사 유지)

- **20레벨부터 10레벨 단위로 반복되는 퀘스트**로 강화된다[공식뉴스][검색합성] — 스티그마(§5-1)와 같은 "레벨 게이트 + 반복 퀘스트" 리듬을 공유한다.

## 7. 세트효과·각인 — 정정: "세트" 명칭은 있으나 보너스 메커니즘은 미확인

기존 조사(§2-7)는 "원작에서 세트효과·각인을 확인 실패"로 결론 내렸는데, 이번 심화에서 **"세트"라는 이름이 붙은 제작 방어구 다수를 발견**했다 — 이 발견을 정정 사항으로 기록한다.

### 7-1. 신규 확인 — 이름 있는 제작 방어구군

- **바크론 세트**(76레벨, 던전 "바크론의 공중섬" 보상)[검색합성]
- **진룡왕·건룡왕 세트**(70레벨) / **백룡왕·흑룡왕 세트**(78레벨) — 제작 방어구[검색합성]

### 7-2. 그러나 "세트 보너스" 자체는 여전히 미확인

위 이름들은 **"이 아이템군을 부르는 명칭"**이라는 것만 확인됐고, 디아블로 2식 파츠 보너스(diablo2/02_items.md §4)나 Dragon Cliff식 2/4피스 보너스(dragoncliff/02_items.md §5-1)처럼 **"몇 개를 같이 착용하면 추가 효과가 켜지는가"를 뒷받침하는 원문은 이번 세션에서도 찾지 못했다** — 후속 검색("진룡왕 세트효과 2셋 4셋")도 구체 수치를 내놓지 못했다.

→ **"세트라는 이름"과 "세트 보너스라는 메커니즘"을 구분해야 한다.** 아이온 원작에 특정 던전·제작 계보를 공유하는 방어구 "묶음"은 존재하지만, 그 묶음을 갖춰 입었을 때 부가 효과가 발동한다는 증거는 아직 없다 — **"이름은 세트, 실질은 개별 아이템 묶음"**일 가능성이 여전히 남아 있다(N/F로 유지, 기존 결론보다 한 단계만 약화).

### 7-3. 각인 — 배제 유지

"각인"이라는 단어는 이번 조사에서도 전부 **아이온2**의 마석/영석 장착 시스템을 가리켰다[00_overview.md §0] — 원작에서는 확인되지 않아 배제를 유지한다.
