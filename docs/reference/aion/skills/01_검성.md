# 아이온: 영원의 탑 — 검성(Gladiator)

**컨셉/역할**: 전사(Warrior)의 2차 전직 중 하나, 영문 클래스명 Gladiator — 아이온에서 가장 많은 무기(창·대검·활·장검·단검·전곤·방패, 총 7종)를 갈아 끼우며 싸우는 공격형 근접 딜러. 페널티 없이 무한 유지되는 자기 버프와 흡혈 스킬로 화력과 생존을 동시에 챙기는 것이 정체성. 직업명은 "검성"이지만 실제로는 검보다 파동(장거리 충격파) 스킬 비중이 크다.

| 스킬 이름(분류) | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 돌진자세 | | 공격력을 크게 늘리고 공격속도도 올려주는 자기 버프, 재사용 대기시간이 30분으로 매우 길다 |
| 돌격자세 | | 공격력을 크게 늘려주는 대신 명중률과 방어력을 깎는 자기 버프 |
| 네자칸의 축복 / 지켈의 축복 | | 공격력과 공격속도를 늘려주는 버프, 돌진자세·돌격자세와 중첩해서 쓸 수 있다 — 재사용 대기시간이 1시간으로 매우 길다 |
| 공격준비 / 방어준비 / 전투준비 | | 켜 두면 페널티 없이 무한 지속되는 활성화형 버프, 기본 공격력·PVP 데미지·방어 관련 스탯을 큰 폭으로 올려준다 |
| 흡혈의 검(외 5종: 흡혈파동·흡혈찍기·흡수의반격·고갈의파동·흡수파동) | | 대상을 공격하며 자신의 체력을 함께 회복시키는 흡혈형 공격기 — 고갈의 파동을 뺀 나머지는 재사용 대기시간이 1분 내외로 짧아 자주 쓸 수 있다 |
| 광폭찍기 / 도약찍기 / 회전일격 | | 대상에게 접근하며 공격하는 근접기 3종 — 광폭찍기는 후딜레이가 길어 오히려 거리가 벌어지기 쉽고, 도약찍기는 대상이 「넘어짐」 상태일 때만 쓸 수 있으며, 회전일격은 인던(사냥터) 전용 스킬트리로 후딜레이가 가장 길다 |
