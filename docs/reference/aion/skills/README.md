# 아이온: 영원의 탑 — 검성 스킬 자료

나무위키 `검성(아이온: 영원의 탑)` 문서를 정리한 자료. 2026-09-23 세션에서 `curl.exe -L` 로 받았다.

**주의 — 다른 폴더 자료와 커버리지가 다르다**: 이 문서는 스킬 하나하나의 툴팁을 나열한 표가 아니라
직업 개요·PVP 특징·육성법 위주의 서술형 문서다. 스킬 이름과 효과가 함께 언급된 것만 골라 옮겼기 때문에
FF14 · 라그나로크 온라인 · D&D5e · 드래곤네스트 폴더만큼 촘촘하지 않다. 인벤(aion.inven.co.kr)의 스킬
DB(`/dataninfo2/skill/list.php`)에 검성 스킬 전체 목록(이름·습득레벨·소모 정신력)은 있으나 효과 설명이
목록에 없어(개별 스킬 상세 페이지가 필요) 이번엔 담지 않았다.

**기존 자료와의 관계**: `docs/reference/aion/01_skills.md` §4-1에 이미 인벤 소스로 검성의 대표 스킬(맹렬한
일격 · 분노의 일격 · 칼날 날리기 등)이 정리돼 있다. 이 파일은 그 자료를 고치지 않고, 거기 없던 버프·흡혈
스킬 계열만 새로 보탰다.

**라이선스**: 나무위키 문서는 CC BY-NC-SA 2.0 KR 로 배포된다. 원문서 표현을 그대로 옮기지 않고 스킬 이름
· 효과 요약(수치 제외) 만 발췌해 표로 재구성했다.
