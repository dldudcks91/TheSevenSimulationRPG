# 검은사막 — 워리어(Warrior)

**컨셉/역할**: 검+방패로 싸우는 비각성과, 각성 후 거대한 대검 하나로 전환해 싸우는 대검 워리어로 나뉘는 근접 전사. 비각성은 방패 가드·잡기·광역 CC로 안정적으로 싸우고, 각성은 낮은 방어 대신 전방위 대검 스윙으로 폭발적인 화력을 낸다.

## 비각성(검+방패)

| 스킬 이름 | 조작 | 무엇을 하는가 |
|---|---|---|
| 검술 수련 | 좌클릭 | 평타 연속 베기 |
| 강타 | 좌클릭+우클릭 | 최대 4연속으로 이어지는 콤보 공격 |
| 전진 검술 | ↑+좌클릭 | 전진하며 베는 공격, 이동기로도 쓰인다 |
| 방어 태세 | Q | 방패를 들어 공격을 막는다, 방어 중 전후 이동도 가능 |
| 좌우 베기 | ←/→+우클릭 | 좌우로 이동하며 베는 공격 |
| 찍어 차기 | ↓+F | 이단 앞차기, 맞은 적을 튕겨 올리고 투지를 채워준다 |
| 회전 가르기 | ↓+우클릭 | 투지를 소모해 회전하며 베는 주력기, 확정 치명타 |
| 잡아 메치기 | 근접 후 E | 적을 붙잡아 내리꽂는 잡기기, 잡을 수 없는 적에겐 몸통박치기로 경직을 건다 |
| 돌진 찌르기 | ↑+F | 일정 거리 돌진해 찌르고 발로 차는 접근기 |
| 깊게 찌르기 | Shift+좌클릭 | 깊게 찔러 공격, 맞힌 만큼 자신의 체력을 흡수한다 |
| 전장의 울림 | 기술슬롯 | 방패를 두드려 적의 방어력을 깎고 적대치를 끈다 |
| 방패 진공 | ↑+우클릭 (또는 가드 중 스페이스) | 가드 상태에서 앞으로 돌진하는 공격, 확정 치명타에 상대를 경직시킨다 |
| 방패 올려치기 | 기술슬롯 | 전진하며 방패로 적을 올려쳐 띄운다, 사용 중 가드 판정이 붙는다 |
| 방패 모아치기 | Shift+Q | 짧게 힘을 모았다 방패로 강타해 스턴을 건다 |
| 지면 울림 | Shift+우클릭 | 땅을 내려쳐 넓은 범위에 피해를 주고 상대의 방어력을 깎는다 |
| 지면 가르기 | ↓+E | 빠르게 두 번 올려베는 공격, 쓰러진 적에게 추가 피해(다운어택)가 들어간다 |
| 지면 강타 | ↓+F | 강하게 땅을 내려쳐 적을 띄우는 주력 광역 CC기 |
| 전장을 꿰뚫는 창 | 기술슬롯 | 창을 만들어 던지는 원거리 견제기, 상대를 경직시킨다 |
| 황혼의 상처 | 기술슬롯 | 검을 크게 휘둘러 넓은 범위에 강한 피해를 주는 주력 사냥기 |
| 광기 어린 돌진 | 기술슬롯 | 일정 거리를 돌격하며 피해를 주는 돌진기 |

## 각성(대검)

| 스킬 이름 | 조작 | 무엇을 하는가 |
|---|---|---|
| 각성: 고옌의 대검 | C | 검+방패와 대검 상태를 서로 전환한다 |
| 대검 장벽 | Q | 대검으로 전방을 가드한다, 막기에 성공하면 투지를 회복하고 오래 유지하면 버프가 붙는다 |
| 맹렬한 기세 | Shift+Space | 투지를 즉시 가득 채우고 잠시 방어력을 올려주는 버프 |
| 광전사 | E | 잠시 공격속도·이동속도를 크게 올리고 상태이상에 저항을 얻는 버프 |
| 대검 수련 | 좌클릭(가로)/우클릭(세로) | 평타, 가로베기는 공격력을, 세로베기는 치명타 확률을 올려주는 버프가 붙는다 |
| 작열 | ↑+좌클릭 | 대검으로 앞을 찌르는 확정 치명타 공격, 화상·출혈 피해가 붙고 명중해도 투지를 회복한다 |
| 선두 추격 | 방향키+Shift | 원하는 방향으로 빠르게 돌진하는 이동기 |
| 무자비 | ↓+우클릭 | 적을 올려친 뒤 다시 내려치는 확정 치명타 공격 |
| 균형 치기 | ↑+우클릭 | 어깨로 전방의 적을 쳐서 경직시킨다 |
| 무덤 가르기 | Shift+좌클릭 | 대검을 가로세로로 크게 휘두르는 각성 워리어의 주력기, 확정 치명타에 적을 띄워 쓰러뜨린다 |
| 분쇄 | ↓+좌클릭 | 회전하며 연속으로 베는 공격, 타격할 때마다 체력을 회복한다 |
| 흐름: 갑옷 부수기 | 특정 상황에서 Space | 대검의 면으로 적을 쳐서 경직시키고 투지를 크게 회복시킨다 |
| 흐름: 무릎 차기 | 특정 상황에서 F | 균형 치기를 다른 동작으로 바꿔주는 캔슬·디버프용 연계기 |
| 흐름: 자루 강타 | 균형 치기 후 우클릭 | 자루로 강하게 내려쳐 스턴을 건다 |
| 흐름: 압도 | 작열 후 Space | 대검을 올려쳐 적을 띄운다 |
| 흐름: 광기바람 | 분쇄 후 좌클릭 유지 | 한 번 더 회전해 공격하며 체력을 더 회복하는 흡혈 연계기 |
| 흐름: 무모한 일격 | 좌클릭+우클릭 | 힘을 모았다 강력한 일격을 날리는 확정 치명타 차징 공격 |
