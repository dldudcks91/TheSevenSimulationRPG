나무위키의 검은사막 클래스 스킬 문서를 정리한 자료. 2026-09-23 세션에서 `curl.exe -L` 로
`워리어(검은사막)/스킬` 문서를 받아, 비각성(검+방패)과 각성(대검) 스킬을 표로 옮겼다.

**라이선스**: 나무위키 문서는 CC BY-NC-SA 2.0 KR 로 배포된다. 이 폴더의 각 파일은 원문서 표현을 그대로
옮기지 않고 스킬 이름 · 조작키 · 효과 요약(수치 제외) 만 발췌해 표로 재구성했으며, 각 파일 첫 줄에 원문
출처를 남겼다.
