# 챕터 1-2 인간 몬스터 — 짧은 프롬프트 재시안 v7

최종 시트: `src/assets/art/faces/source/sheets/source_sheet_ch1_st2_human_3x3_short_prompt_v7.png`. 내장 `image_gen` 사용. 그림체 참조: 현행 `ready/hero/warrior_2.png`·`knight_4.png`·`warrior_4.png`, `ready/monster/1301.png`. 기존 `ready/monster/1201~1203.png`는 직업·장비 확인에만 사용했다.

```text
Match the attached current game portraits exactly in drawing style and SD bust proportions. Use them only as style references; draw new living human enemies, without copying their identities or distinctive gear.
One square 3×3 comparison sheet. In every row, left to right: footman, archer with a visible quiver, knight. Make all nine people distinct.
Keep the references' big heads, small cropped shoulders, generous headroom, dark irregular outlines, simple muted shading and dim lighting.
Separate equal square cells with straight black lines. Fill every cell with flat, opaque pure green #00FF00.
No scenery, lettering or watermark.
```
