# 신규 캐릭터·몬스터 초상 — 공통 구도 기준

> 확정: 2026-09-24 사용자 지시. 새 캐릭터를 그릴 때 반복해서 쓸 프롬프트의 **머리·몸 비율** 기준이다.
> 기존 초상을 일괄 수정하는 지시는 아니다. 그림체·캐릭터 외형·의상은 각 발주에서 별도로 정한다.

## 기존 아트 확인은 생성 전 필수 관문 [2026-09-24 사용자 지시]

**캐릭터·몬스터 초상은 프로젝트의 기존 그림을 실제로 열어 본 뒤에만 생성한다. 텍스트 설명만 읽고 그리는 것은 금지한다.**

1. 기존 대상을 다시 그리면 현재 그 대상의 `source/ready/` 원본을 반드시 열어 외형을 확인한다. 외형 보존이 목표면 생성 입력에도 넣는다. 사용자가 기존 얼굴이나 그림결을 버리고 전면 재설계를 요청했다면, 기존 원본은 직업·장비 확인에만 쓰고 생성 입력에서는 제외할 수 있다.
2. 새 대상이면 같은 종족을 최우선으로, 같은 챕터·진영·역할 순으로 가까운 기존 초상을 찾는다. 최소한 **외형 참조 1장 + 그림체 참조 1장**을 생성 입력에 함께 넣는다.
3. 참조 파일은 이름만 확인하지 않고 이미지 뷰어로 직접 열어 얼굴형·눈·머리·피부색·장비 실루엣·강조색을 확인한다.
4. 프롬프트에서 각 입력을 `외형 보존` 또는 `그림체·비율 기준`으로 구분한다. 외형 참조의 정체성은 유지하고, 사용자가 바꾸라고 한 부분만 바꾼다. 전면 재설계에서는 보존할 요소를 직업·장비처럼 좁혀 명시한다.
5. 적절한 기존 참조를 찾지 못하면 임의로 생성하지 않는다. 먼저 참조 부재를 보고하고 기준 대상을 정한다.
6. 생성 뒤에도 참조와 나란히 보며 종족·진영·얼굴 비율·실루엣이 이어지는지 확인한다. 이어지지 않으면 최종본으로 저장하지 않는다.

이 관문은 스케치·세부 작업, 단일 초상·비교 시트, 사용하는 생성 도구와 관계없이 모두 적용한다.

## 1-2 인간 몬스터 3종 — 현행 영웅 그림체 기준 [2026-09-25 사용자 지시]

`1201` 보병·`1202` 궁수·`1203` 기사를 다시 그릴 때는 현재 게임에 저장된 `source/ready/hero/` 초상화를 **그림체 기준**으로 삼는다. `archer_1.png`·`knight_5.png`·`warrior_3.png`·`priest_1.png` 등을 직접 열어 **외곽선의 굵기와 강약, 면 음영의 단순화, 색의 탁도, 디테일 생략 수준, 초상 여백**만 비교한다. 영웅의 얼굴형·머리 모양·흉터·후드·갑옷 디자인은 새 몬스터의 외형 지시가 아니다. `ready/monster/1201~1203`은 직업과 장비 역할을 확인하는 자료다. 옛 앵커의 실측값은 보조 기준이다.

**그림체 일치와 외형 복제는 별개다.** 새 인간 몬스터는 영웅과 같은 화가가 그린 듯해야 하지만, 어느 영웅과도 같은 사람이나 같은 의상으로 보이면 안 된다. 영웅 참조가 갖고 있는 고유한 헤어스타일, 얼굴 흉터, 문신, 플룸, 상징 문양, 망토 매듭 등을 그대로 옮기지 않는다. 직업이 요구하는 화살통·갑옷 같은 범용 장비는 새 형태로 설계한다.

- **여백과 크롭**: 현행 영웅의 실제 화면 여백을 우선한다. `archer_1.png`는 512px 높이에서 후드가 위로부터 약 96px(19%) 내려온 곳에서 시작한다. 이 세트의 3×3 시트에서는 궁수의 후드가 칸 위쪽에 4~6px만 남도록 붙으면 불합격이다. 아래 공통 5~10% 수치는 영웅 참조와 충돌할 때 강제하지 않는다.
- **얼굴**: 영웅처럼 눈을 어두운 덩어리와 적은 수의 면으로 그리되, 특정 영웅의 눈·코·광대·턱·입 모양은 복사하지 않는다. 아홉 명의 골격과 표정을 서로 다르게 설계한다. 흉터·머리카락·수염만 바꾼 같은 얼굴 아홉 개는 불합격이다.
- **선과 재질**: 영웅의 선 굵기 변화, 불규칙한 면 그림자, 절제된 손상 표현을 따른다. 일정한 벡터식 외곽선, 매끈한 둥근 갑옷 광택, 같은 위치의 하이라이트 반복은 피한다.
- **시트**: 3×3, 매 행 보병 → 화살통이 보이는 궁수 → 중장 기사. 직업 안에서도 얼굴형과 장비 실루엣을 달리하고, 영웅의 의상 실루엣을 재사용하지 않는다. 초록 배경은 누끼용이며 그림체 판단에서 제외한다.
- **검수**: 새 시트를 영웅 네 장과 나란히 열어 여백·선·음영·디테일 수준이 이어지는지 확인한다. 별도로 영웅의 고유 얼굴·의상이나 시트 내부의 얼굴 구조가 반복되는지 확인한다. 이전 `source_sheet_ch1_st2_human_3x3_hero_style_v3.png`는 상단 여백과 얼굴 반복 때문에 이 기준에 미달했다.

## 여러 시안의 기본 시트 [2026-09-24 사용자 지시]

- 사용자가 앞으로 같은 방식으로 캐릭터 시안 여러 개를 그려 달라고 하면, **8개를 가로로 긴 직사각형 시트 한 장**에 배치한다. 기본 배열은 **4열 × 2행**이다.
- 각 칸의 캐릭터가 서로 겹치지 않게 하고, 머리 크기·눈높이·여백을 통일한다. 아래 공통 구도 기준은 시트의 **각 칸**에 적용한다.
- 별도 지시가 없으면 개별 그림 8장을 따로 생성하지 않는다. 사용자가 다른 개수나 배열을 지정하면 그 지시를 따른다.

## 머리와 몸의 비율

- 작업 원본 512×512 초상 기준, **머리가 전체 캔버스 높이의 약 70%**를 차지한다. 허용 범위는 대략 **65~75%**다. 게임용 파일은 이후 WebP로 축소한다.
- 여기서 머리는 **뿔·머리카락·투구·두건의 맨 위부터 턱까지**다. 얼굴 피부만 재서 70%로 만들지 않는다.
- 맨 위에는 대략 **5~10% 여백**을 남긴다. 턱 아래에는 **어깨와 가슴 윗부분만** 보인다. 옷을 보여주려고 허리·벨트·팔 전체까지 내리지 않는다.
- 눈은 세로 중앙 부근에 두고, 소품은 얼굴 옆이나 아래에 일부만 넣는다. 소품 때문에 얼굴을 작게 그리지 않는다.
- 여러 안을 한 시트에 그릴 때도 **모든 칸의 머리 크기와 눈높이를 통일**한다. 의상 변주가 필요하면 몸통의 긴 길이가 아니라 두건·깃·견갑·소품의 형태로 구별한다.
