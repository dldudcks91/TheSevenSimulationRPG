## 1. 등급(희귀도) 체계 — 8단계 + 단종 등급

### 1-1. 현재 운영 중인 8단계 (2025-01-09 개편 기준)

| 등급 | 색상 | 동급 대비 능력치 | 비고 |
|---|---|---|---|
| 커먼(일반) | 흰색 | 기준 | **저레벨 구간 제외 단종**([나무위키]★★☆) |
| 언커먼(매직) | 하늘색 | 커먼+1레벨 상당 | **저레벨 구간 제외 단종**([나무위키]★★☆) |
| **레어** | 보라색 | 언커먼+5레벨 상당 | 밀봉 상태로 드롭, 착용 즉시 밀봉 해제(§1-3) |
| **유니크** | 분홍색 | 레어+6레벨 상당 | 레어엔 없는 고유 옵션 보유, 교환·재밀봉 가능 |
| **레전더리** | 주황색 | 유니크+3레벨 상당 | 대부분 교환 가능(일부 퀘스트 보상은 교환 불가) |
| **에픽** | 노랑/금색 | 레전더리+3레벨 상당 | 착용 즉시 교환 불가 귀속, "에픽 빔" 이펙트 |
| **신화** | 노랑-보라 그라데이션 | 舊 에픽 상위 | 2020-01-09 도입, **시즌 8 이후 신규 미추가** — 현재는 스토리 퀘스트/재료 위주로만 존재 |
| **태초** | 초록-청록 그라데이션 | 에픽+4.5레벨 상당 | 2024-04-25 도입, 신화를 대체한 현 최고 등급. 초기엔 목걸이/반지 융합석 전용 → 안개신 레이드 하드 이후 무기까지 확장(§8-1) |

([나무위키]★★☆ `던전앤파이터/아이템 등급`, 2025-01-09 기준 서술) — **"동레벨 커먼 아이템과 에픽 아이템의 독립공격력 차이는 거의 2배"**[검색합성]★★라는 것이 등급 축의 실질적 체감폭이다.

### 1-2. 단종된 역사적 등급 — 계보 확인용

현재는 8단계로 정리됐지만, 과거엔 더 세분화된 등급이 존재했다가 통폐합된 이력이 있다([나무위키]★★☆):

| 등급 | 성격 | 단종 시점/사유 |
|---|---|---|
| 진 레어 | 60레벨+ 히어로즈 로드 난이도 전용 상위 레어 | 시즌 개편으로 흡수 |
| 유물 | 레어 능력치 + 상위 옵션, 항아리 전용 | 시즌 개편으로 흡수 |
| 크로니클 | — | 2020-01 귀환 패치로 단종 |
| 보스 유니크 / 진 유니크 | 특정 보스 전용 / 고대 던전 전용 상위 유니크 | 2020년 단종 |
| 불가침의 영역(105Lv 레전더리) | 교환 가능, 레벨 재설정 시 +2~-1 변동 | 2025-01-09 시즌10 개편으로 단종 |
| 커스텀 에픽(105/110Lv) | 72개 옵션 풀 중 무작위 4개(확률 약 1/1,028,790) | 2025-01-09 시즌10 개편으로 단종 |
| 미스트 기어(세트 에픽) | 확정 4유효 커스텀 장비 | 2025-01 시즌10 개편으로 단종 |

→ **"등급 6단계 → 3단계로 축소"라는 통설**(dfo_reference.md의 이전 서술)은 이 표로 좀 더 구체화된다 — 정확히는 **여러 세대의 "상위 레어/상위 유니크" 파생 등급이 반복적으로 신설·단종되며 본선(레어~태초) 8단계로 수렴**해 온 것이지, 단일 시점의 6→3 축소가 아니다.

### 1-3. 등급 내부의 추가 축 — 밀봉과 % 롤

- **밀봉(레어 이상 드롭 시)** — 착용 전까지 거래 가능한 상태로 드롭되고, 착용하는 순간 밀봉 해제(귀속 전환). "황금밀랍초"로 **최대 7회 재밀봉**해 거래 유예를 늘릴 수 있다([나무위키]★★☆).
- **% 등급 롤** — 같은 등급 안에서도 "최상급(88%)"과 "최상급(98%)"처럼 **기본 능력치 자체가 다른 하위 롤**이 존재한다([나무위키]★★☆) — 등급(희귀도)과 독립적인 별도의 개체 품질 축이라는 점에서 diablo2의 Low/Normal/Superior(diablo2/02_items.md §2-1)와 구조적으로 유사하다.
- **해체 시 등급별 확정 재료** — 레어(무색 큐브 조각+하급 원소결정+레어 소울) / 유니크(+상급 원소결정+유니크 소울) / 레전더리(레전더리 소울) / 에픽(에픽 소울 1개 고정)([나무위키]★★☆) — 이 "등급별 소울"이 §8-3 승급 재료로 그대로 재사용된다.

## 3. 세트 아이템

### 3-1. 발동 메커니즘 — 레어만으로는 무효, 세트 포인트 누적제

레어 등급만 착용해서는 세트 효과가 발동하지 않는다. 장비 개체마다 내재된 **세트 포인트**가 있고, 착용한 장비 전체의 세트 포인트 합이 **등급별 임계값**을 넘으면 그 세트의 효과가 열린다([나무위키]★★☆). 서로 다른 세트를 섞어 입어도 혼합 발동은 안 되고, **가장 높은 세트 포인트를 가진 세트 하나만** 적용된다 — dfo_reference.md 원문 서술과 일치.

### 3-2. 임계값 — 시즌별로 다른 두 표기가 확인됨

이번 조사에서 **서로 다른 두 개의 세트 포인트 표**가 확인됐다. 어느 쪽도 오류는 아니고, **시즌(패치 시점)에 따라 세트 포인트 부여·임계값 산정 방식 자체가 개정**된 것으로 보이지만, 두 표를 정확히 어느 시점이 잇는지는 확인하지 못했다(N/F).

| 표 | 성격 | 값 |
|---|---|---|
| **115레벨 시즌**([나무위키]★★☆ `아이템/115레벨/세트 옵션`, dfo_reference.md 원문과 일치) | **누적 임계값**(총합이 이 값을 넘으면 발동) | 유니크 1,540pt / 레전더리 1,990pt / 에픽 2,440pt / 태초 2,550pt (레어 단독으론 미도달) |
| **중천 시즌**([Nexon 공식]★★★ 가이드 no=1492, [검색합성]★★ 교차확인) | **개체당 부여 포인트**(부위별로 이 값이 붙고 합산) | 레어 65 / 유니크 115 / 레전더리 165 / 에픽 215 / 태초 265 |

중천 시즌 쪽은 **태초 등급이 악세서리 부위에만 존재**하며, 악세서리를 "흑아(검은 아우라)"로 변경하면 에픽/태초 세트 포인트가 **50 하락**하는 부가 규칙도 확인됐다([검색합성]★★) — 즉 세트 포인트 시스템 자체가 등급 체계(§1)의 세부 개편과 맞물려 여러 세대를 거쳤다는 뜻이다.

### 3-3. 실제 세트 3종 — 115레벨 시즌 기준 전량 수치

115레벨 장비 세트는 총 13종이 존재한다. 등급이 오를수록(유니크→레전더리→에픽→태초) 같은 세트 안에서도 최종 데미지 배율이 계단식으로 뛴다는 것이 공통 패턴이다([나무위키]★★☆ `아이템/115레벨/세트 옵션`).

**① 고대 전장의 발키리** — 무적 이동기(발키리 융합 돌진) + 오브젝트 소환형
| 등급 | 최종데미지 배율 |
|---|---|
| 유니크 | +128.9% |
| 레전더리 | +264.3% |
| 에픽 | +377.9% |
| 태초 | +417.7% |

주요 옵션 예시 — 돌파(쿨8초): 11,220% 피해 / 심판(쿨15초): 20,900% 피해+추적 / 천벌(쿨20초): 에픽 224,400% · 태초 256,850% 피해.

**② 그림자에 숨은 죽음** — 스킬 캔슬(행동 중단) 특화, 깡딜형
| 등급 | 최종데미지 배율 |
|---|---|
| 유니크 | +130% |
| 레전더리 | +268% |
| 에픽 | +403% |
| 태초 | +453% |

**⑨ 영원히 이어지는 황금향** — 순수 깡딜 특화, 커뮤니티가 꼽는 1티어 세트
| 등급 | 최종데미지 배율 |
|---|---|
| 유니크 | +135.8% |
| 레전더리 | +263.5% |
| 에픽 | +394.5% |
| 태초 | +433.3% |

특징 — 강화 단계(§4)·증폭 단계(§5)에 비례해 추가 데미지가 붙는다. **강화·증폭이라는 별개 축의 투자가 세트 효과 자체의 값을 다시 끌어올리는 구조**라는 뜻으로, DFO의 강화·증폭·세트 세 시스템이 서로 완전히 독립적이지 않고 곱연산으로 겹친다는 것을 보여주는 사례다.

## 4. 강화 시스템

### 4-1. 성공 확률과 실패 페널티 — 3단 리스크 계단

| 강화 구간 | 성공확률 | 실패 페널티 |
|---|---|---|
| 0~4강 | 100% | 없음 |
| 5~10강 | 80%→30%(단계마다 감소) | 없음 |
| 11~12강 | 25%→15%(단계마다 감소) | **3단계 하락** |
| 13강 이상 | 14%→10%(단계마다 감소) | **장비 파괴** |

([나무위키]★★☆ `던전앤파이터/강화`, 2021-12-02 패치로 확률 전면 공개된 수치) — 최대 **+20강**까지 존재. 11~12강 구간은 **실패할 때마다 성공확률이 1%p씩 누적 상승하는 천장(pity) 보정**이 있어, dfo_reference.md 원문에 이미 있던 서술이 이번에도 재확인됐다.

### 4-2. 재료 — 무색 큐브 조각 + 골드, 강화 단계별 계단식 증가

| 강화 단계 | 무색 큐브 조각 | 골드(100Lv 무기 기준) |
|---|---|---|
| 0강 | 10개 | — |
| 1강 | — | 177,300 |
| 10강 | 100개 | — |
| 12강 | — | 2,836,800 |
| 17강 | 240개 | 10,638,000 |

([나무위키]★★☆) — 강화는 D2식 "룬/젬 소모"나 AION식 "강화석 레벨 격차"(aion/02_items.md §4)와 달리, **재료 종류가 하나(무색 큐브 조각)로 고정되고 개수와 골드가 함께 계단식으로 뛰는** 단순한 구조다.

### 4-3. 스탯 상승 계수

무기 강화는 "시드값 × 강화 계수"로 실제 공격력 상승치가 정해진다. 확인된 계수 — 10강 18.9 / 12강 37.13(구간 사이 상승폭이 크게 뜀) / 17강 68.59([나무위키]★★☆). 정확한 계수 곡선 전체(1~20강 전 구간)는 확보하지 못했다(N/F).

### 4-4. 안전 강화 — 무기 전용 무손실 경로

**+12강까지 수치 하락 없이** 강화할 수 있는 별도 트랙으로, 골드 대신 **라이언 코어**(던전에서 획득)를 소모한다. 초기 성공확률은 일반 강화보다 낮지만 **실패할 때마다 확률이 누적 보정**된다([나무위키]★★☆) — §4-1의 "11~12강 천장 보정"과 유사한 설계를 더 넓은 구간(0~12강)에 적용한 안전판 트랙.

### 4-5. 보호권

- **장비 보호권** — 13강 이상 강화 실패 시 파괴를 막는다. 단, 사용되면 **강화 수치가 초기화**된다.
- **증폭 보호권** — 10증폭 이상 증폭 실패 시 파괴를 막는다(§5).

## 5. 증폭 시스템

### 5-1. 대상 게이팅 — "이계의 기운이 서린 장비"만

강화(§4)의 상위 확장이지만, **모든 장비가 아니라 "이계의 기운이 서린 장비"만** 대상이다([검색합성]★★, dfo_reference.md 원문과 일치). **이계 기운의 정화서**를 사용해 정화하면 강화 전용 상태였던 장비가 **강화 불가·증폭 전용**으로 전환되고, 이때 **차원의 힘/지능/체력/정신력** 중 하나의 옵션이 함께 부여된다([검색합성]★★, 두 독립 출처 수렴). 즉 증폭은 "강화의 연장선"이 아니라 **장비의 성격 자체를 갈아 끼우는 별도 트랙 진입**이라는 점이 핵심이다.

### 5-2. 확률 구간과 실패 페널티

| 증폭 구간 | 성공확률 | 실패 페널티 |
|---|---|---|
| 0~4단계 | 100% | 없음 |
| 5~10단계 | 80%→50% | 수치 하락 |
| 11단계 이상 | 40%→20% | **장비 파괴** |

(dfo_reference.md 원문, 이번 세션에서 별도 1차 수치표는 재확보하지 못해 유지 — N/F: 공식 확률 페이지 자체의 원문 대조는 못 함) — 강화(§4-1)와 같은 "완만→절벽" 계단 문법을 공유하되, **파괴 임계선이 강화(13강)보다 이른 11단계**라는 점에서 증폭이 강화보다 더 이른 단계부터 하이리스크 구간에 들어간다.

### 5-3. 보호 증폭

일반 증폭보다 **초기 성공확률이 낮은 대신**, 실패할 때마다 보정 확률이 누적되는 별도 트랙([검색합성]★★) — §4-4의 안전 강화(라이언 코어)와 동일한 "낮은 시작 확률 + 실패 누적 보정" 설계 문법을 증폭에도 반복 적용한 사례.

## 6. 재련 — 강화·증폭과 별개인 세 번째 개조 축

### 6-1. 구조

- **무기 전용**(방어구·악세서리·특수장비는 재련 불가) — 다른 부위는 강화·증폭만 존재.
- 재련 시 **독립 공격력**이 상승한다([검색합성]★★, 복수 소스 수렴).
- 재료는 **강렬한 기운**뿐이며, 골드를 소모하지 않는다. **라이언 코어**를 마을 NPC(키리 더 레이디) 상점에서 "강렬한 기운 10개 상자"로 교환해 얻는다([검색합성]★★) — §4-4의 안전 강화와 **같은 라이언 코어를 원재료로 공유**한다는 뜻으로, 라이언 코어가 "무손실 성장 두 축(안전강화·재련)의 공용 화폐" 역할을 한다.
- **최대 8단계.**
- **실패해도 재료만 소모되고, 재련 단계·아이템 모두 그대로 유지**된다 — 강화(13강+ 파괴)·증폭(11단+ 파괴)과 달리 **파괴·수치하락 리스크가 아예 없는 유일한 개조 축**([검색합성]★★, dfo_reference.md 원문과 일치).

### 6-2. 재련과 강화의 상대적 비중

"8재련의 독립공격력을 초과하는 단계가 13강화"라는 커뮤니티 비교가 확인된다([검색합성]★★) — 즉 **재련 만렙(8단계, 무손실)이 강화 13강(파괴 리스크 진입 직전)과 맞먹는 화력**을 준다는 뜻으로, "리스크 없는 트랙을 먼저 만렙 찍고 나서 하이리스크 트랙에 들어가라"는 진행 순서를 자연히 유도하는 설계로 읽힌다.
