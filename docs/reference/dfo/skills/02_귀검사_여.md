### 2-2. 귀검사(여)

귀검사(여)는 마수에 깃든 마인의 힘을 다루는 방식에 따라 5개 전직으로 갈린다 — 소드마스터(4속성 마검 자유 전환) / 다크템플러(우시르의 힘을 쓰는 유일한 마법 원거리 딜러) / 데몬슬레이어(마검 프놈 순수 물리) / 베가본드(이도류+내공 무협풍) / 블레이드(납도술+와이어 액션). 블레이드는 출처 문서가 스킬을 "보조/전투/각성 후"로만 묶어 반환해 리벨리온·벤데타·진블레이드 중 어디 소속인지 세부 매핑이 불명확한 항목이 있다.

#### 소드마스터
**컨셉/역할**: 발검술과 마법을 접목한 마검사 — 4속성(화/수/명/암) 마검을 자유 전환하며 싸우는 물리 퍼센트 딜러. 무기 종류(대검/소검/도/둔기)마다 플레이 스타일이 달라짐.
**전직 계보**: 귀검사(여) → 소드마스터(2021-07-08부터 생성 시 자동 전직) → 1차 각성 **노블레스**(Lv50 자동) → 2차 각성 **마제스티**(Lv75 자동) → 진각성 **진(眞) 소드마스터**(Lv100 자동)

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 무기 숙련 | 패시브 | 모든 종류의 무기에 극도로 숙달된 소드마스터는, 각 무기가 지닌 특성을 극도로 이끌어낸다 |
| 속성의 소검 마스터리 | 패시브 | 소검 착용 시 물리 공격력 증가 및 마검발현·속성변환 강화 |
| 쾌속의 도 마스터리 | 패시브 | 도 착용 시 발검술 연계 강화, 제국검술·속성변환 공격력 증가 |
| 파쇄의 둔기 마스터리 | 패시브 | 둔기 착용 시 충격파 범위·공격력 증가, 특정 스킬에 충격파 추가 |
| 견고의 대검 마스터리 | 패시브 | 대검 착용 시 슈퍼아머 부여, 완충 스킬 범위·공격력 증가 |
| 마검일체 | 패시브 | 마검이 나의 의지대로 움직이게 되어 적을 향해 치명적인 공격을 가하게 된다 |
| 마검발현 | 패시브 | 스킬 사용 시 속성별 마검 발동, 추가 피해 및 상태이상 부여 |
| 신검합일 | 버프(액티브) | 크리티컬 확률·크리티컬 데미지 증가 |
| 방검술 | 버프(액티브) | 본능적으로 적의 공격을 막는다 — 일정확률로 적의 공격을 자동으로 막는 버프 |
| 제국검술 | 액티브(기본 타격) | 무기 종류에 따라 다른 기본 타격 |
| 반격 | 액티브 | 검막으로 적 공격 차단 후 반격 |
| 쾌속검 | 액티브 | 적이 눈치채지 못할만큼 빠른속도로 적을 베고 지나간다 |
| 환검 | 액티브 | 전방으로 환영을 보내서 적을 공격한다 |
| 승천 | 액티브 | 어깨로 적을 밀쳐낸 후 한손으로 강력한 올려베기를 하며 띄운다 |
| 비연참 | 액티브 | 강력한 올려베기로 적을 밀어낸 후 연속베기를 하고 마지막에 내려치며 바닥에 충격파를 생성한다 |
| 반월 | 액티브 | 한바퀴 회전하면서 발도를 한다. 모아서 사용시 이동거리와 공격력이 늘어난다 |
| 섬광 | 액티브 | 전방을 향해 거대한 검기를 빠르게 세번 날린다 |
| 폭명기검 | 액티브 | 마수의 힘을 이용해 고대의 검을 소환해서 공격한다 |
| 악즉참 | 액티브 | 전방으로 대시하면서 일정거리 이상 나아간 후에 빠르게 연속베기를 한다 |
| 참격혼 (1차) | 패시브 | 혼 마크가 생성된 적을 크리티컬 공격 시 스킬 공격력 증가 |
| 용성락 (1차) | 액티브 | 4속성의 검을 전방에 생성한 후 마법진을 그려 적을 묶고, 잊혀진 고대의 검을 소환하여 적을 공격한다 |
| 참마검 (1차) | 액티브 | 4속성 마법검으로 적을 베고 피니시 공격 |
| 고대의 맹약 (2차) | 패시브 | 무기 타입별 물리 무기 공격력 증가 |
| 마검방출 (2차) | 액티브 | 마검에 힘을 불어 넣어 강력한 마력 폭풍을 만들어 낸 후 전방으로 쏘아내 다단히트와 함께 큰 폭발을 일으킨다 |
| 극 귀검술: 파검무 (2차) | 액티브 | 고대의 마검이 잠든 대지를 현세에 만들어낸 후 마검을 집어들어 적들을 베어낸다 |
| 엑시던스 (진) | 패시브 | 전직 스킬 공격력 증가 및 일부 스킬 부가 효과 |
| 극 마검술: 창륜검 (진) | 액티브 | 원형 회전 참격 광범위 공격 |

**각성 스킬**
- 1차(노블레스): **극 귀검술: 시공섬** — 발도술을 극한으로 연마한 검사는 시간과 공간을 벨 수 있다
- 2차(마제스티): **궁극의 검: 레바테인** — 마검의 힘을 응축시켜 4대원소가 합쳐진 궁극의 검을 생성해낸 후 강력한 참격으로 차원을 가른다
- 진각성(진 소드마스터): **리전 오브 슈프림** — 강력한 검기 방출로 다수 적 공격

#### 다크템플러
**컨셉/역할**: 죽음의 신 우시르를 수호하는 비밀 기사단원. 그림자·우시르의 힘을 쓰는 암속성 마법 원거리 공격형 퍼센트 딜러 — 여귀검사 5전직 중 유일한 마법 공격력 기반.
**전직 계보**: 귀검사(여) → 다크템플러(2021-07 이후 생성 시 자동 전직) → 1차 각성 **암제(暗帝)**(Lv50) → 2차 각성 **네메시스**(Lv75) → 진각성 **진(眞) 다크템플러**(Lv100)

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 스티그마 | 패시브 | 다크템플러의 전직 계열 스킬 공격력이 증가하며, 일부 스킬은 적중한 대상에게 낙인을 부여 |
| 스파타 녹티스 | 패시브 | 고유의 기본 공격 동작을 가지며, 일부 스킬 간 후딜레이 캔슬이 가능 |
| 섀도 하이딩 | 액티브(회피/무적기) | 그림자 속에 숨어서 이동하며 적의 공격을 회피 (2초 이동, 상위 던전 즉사 패턴 회피용, 쿨타임은 스킬 종료 직후 적용) |
| 가이던스 | 패시브 | 전직 계열 스킬 공격력 증가, 암속성 부여 및 강화값 보정 |
| 컨제스트 | 액티브 | 자신을 고양시켜 기본 공격 및 스킬 공격력 증가 |

| 섀도 하베스트 | 액티브 | 지면에 어둠의 검을 투척하여 마법진으로 지속 피해 입힘 |
| 스카폴드 | 액티브 | 구속진으로 대상을 홀드하고 폭발 피해 입힘 |
| 리스레인트 | 액티브 | 전방 적들에게 금제술 발동 |
| 다크 트레이서 | 액티브 | 범위 내 적들을 추적하여 어둠의 검 파편 공격 |
| 섀도 스윕 | 액티브 | 어둠을 둘러 전방으로 참격을 날림 |
| 다크 코히즌 | 액티브 | 어둠의 구체를 소환하여 적을 끌어모았다 폭발 |
| 블랙 미러 | 액티브 | 어둠의 거울 소환하여 피해 감소 및 슈퍼아머 부여 |
| 다크 스플릿 | 액티브 | 검에 어둠을 둘러 전방을 벤 뒤 그림자로 숨어 추가 공격 |

| 베스퍼스 (2차) | 패시브 | 스킬 공격력 증가, 일부 스킬이 신의 기사단 보조 형태로 변경 |
| 데우스 엑스 레이 (2차) | 액티브 | 우시르의 힘을 일직선으로 발사하여 공격 |
| 지하드 (2차) | 액티브 | 원하는 위치에 신의 검을 소환하여 내려 꽂음 |
| 인카네이션 (진) | 패시브 | 스킬 공격력 증가, 일부 스킬 효과 강화 |
| 아포스타테 (진) | 액티브 | 우시르의 현신이 자신의 힘을 둘러 검을 휘두르며 공격 |

**각성 스킬**
- 1차(암제): **둠스데이** — 우시르의 힘으로 적을 구속한 뒤 수많은 어둠의 검으로 찔러 폭발
- 2차(네메시스): **퍼니쉬먼트** — 신의 기사단을 불러내어 어둠으로 물들인 뒤 우시르와 심판 집행
- 진각성(진 다크템플러): 구버전 **콰이터스 리뎀션** / 2026년 리뉴얼 버전 **디에스 이라에** — 신의 기사단의 힘을 돌려받은 뒤 분노의 검으로 속죄를 받아냄 (신구 명칭 병존, 교체 시점은 확인 안 됨)

#### 데몬슬레이어
**컨셉/역할**: 검마 다이무스와 계약해 마검 프놈(사복검 형태)을 다루는 순수 물리 딜러(퍼센트 데미지).
**전직 계보**: 귀검사(여) → 데몬슬레이어(생성 시 자동 전직) → 1차 각성 **검마(劍魔)**(Lv50) → 2차 각성 **디어사이드**(Lv75) → 진각성 **진(眞) 데몬슬레이어**(Lv100, "마인들의 여왕")

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 광폭화 | 버프(액티브) | 기본 공격력과 스킬 공격력, 캐릭터의 공/이속이 증가한다 |
| 마검 제어 | 패시브 | 마검을 제어할 수 있는 힘이 생겨, 무기 공격력과 물리 크리티컬 확률이 증가한다 |
| 사복검 - 발 | 액티브 | 검을 바닥으로 찍으면 일정 위치 앞 지면에서 검이 솟아오르며 다단히트 대미지를 준다 |

| 사형조수 | 액티브 | 검을 길게 늘려 전방을 찌른 뒤 회수하면서 적들을 끌어당긴다 |

| 혈화난무 | 액티브 | 검을 채찍처럼 길게 늘어트려서 전방으로 빠르게 휘두른다 |
