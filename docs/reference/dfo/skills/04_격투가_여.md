### 2-4. 격투가(여)

격투가(여) 4개 전직 문서는 모두 남성판과 별도 문서로 존재하며, 전직명(넨마스터/스트라이커/스트리트파이터/그래플러)은 같아도 스킬명·효과·각성 명칭은 완전히 별개다.

#### 격투가(여) 공용 스킬

**순수 공통 (전직 계열 무관)**

|---|---|---|---|
