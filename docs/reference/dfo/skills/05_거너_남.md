### 2-5. 거너(남)

거너(남)는 천계의 과학 기술로 만든 총기를 주무기로 원거리에서 적을 제압하는 천계인이며, 전직 전(=1차, 「거너」) 단계에서 5개 전직 공용 스킬과 각 전직으로 이어지는 계열별 예비 스킬을 함께 배운다. 2차/3차 전직 이후에는 잡별 전용 스킬만 있고 별도 "공용" 티어는 문서에 확인되지 않는다.
