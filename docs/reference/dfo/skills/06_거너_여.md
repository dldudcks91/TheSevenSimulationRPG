### 2-6. 거너(여)

거너(여)는 전직 이전 공용 스킬에 더해 전직 전부터 5개 전직별 "초반 계열 스킬"을 함께 배운다. 레인저의 전직 도입 순번은 문서 간 서술이 모순되어(레인저 문서 자체는 "5번째 전직", 패러메딕 문서 두 곳은 독립적으로 "여성 거너 5번째 전직(2018 추가)") 확인 안 됨으로 처리했고, 런처의 정확한 도입 순번도 확인 안 됨이다.
