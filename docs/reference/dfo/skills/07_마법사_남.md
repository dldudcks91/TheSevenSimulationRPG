### 2-7. 마법사(남)

#### 마법사(남) 공용 스킬

나무위키 문서 구조상 "완전 공용"과 "슬롯은 공용이지만 3차 전직별로 이름·효과가 갈라지는 스킬"이 한 문서 안에 같이 정리되어 있다.

**진짜 전 직업 공통(패시브)**

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 불사 | 패시브 | 캐릭터 사망 시 일정량의 HP를 가진 채로 부활 |
| 어비스 | 패시브 | MP MAX 증가, MP 10% 이하일 때 회복량 증가 |

**같은 슬롯, 3차 전직별로 이름/효과가 갈라지는 1차 전직 스킬** (◇ = 특정 전직 시 습득 제한)

| 전직 계열 | 스킬명 | 구분 | 효과 |
|---|---|---|---|
| 엘레멘탈바머 계열 | 연속발사 | 액티브 | 마법구 연속 발사 |
| 엘레멘탈바머 계열 | 화염방패 | 액티브 | 불의 방패를 발사해 공격/방어 |
| 빙결사 계열 | 물대포 | 액티브 | 물덩어리 발사 |
| 빙결사 계열 | 귀설화 | 버프 | 방어력 증가 |
| 빙결사 계열 | 빙백검 | 액티브 | 얼음 검으로 3타 공격 |
| 블러드메이지 계열 | 릴리악◇ | 액티브 | 박쥐를 보내 다단히트 피해 |
| 스위프트마스터 계열 | 윈드 스트라이크 | 액티브 | 회오리로 적을 띄움 |
| 스위프트마스터 계열 | 금나장 | 액티브 | 적을 잡아 던짐 |
| 디멘션워커 계열 | 텔레포트◇ | 액티브 | 일정 거리 순간이동 |
| 디멘션워커 계열 | 차원: 액시던트◇ | 액티브 | 박스를 떨어뜨려 기절 유발 |

비고: 블러드메이지는 텔레포트를 못 쓰고 대신 전용 이동기 "크리핑"을 받는다 — ◇표시가 실제로 배타적 습득 제한을 의미한다는 게 교차 확인됨.

#### 엘레멘탈바머
**컨셉/역할**: 어비스의 무한 마력으로 4대 원소 마법을 무차별로 퍼붓는 초공격형 광역 딜러.
**전직 계보**: 마법사 → 엘레멘탈바머 → (1차각성) 워록 → (2차각성) 오블리비언 → (진각성) 진 엘레멘탈바머

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 원소 융합 | 패시브 | 속성별 저항력·공격력 증가 |
| 속성 발동 | 버프 | 4속성 중 선택해 마법구 속성 변경 |
| 엘레멘탈 포스 | 패시브 | 스킬 적중 시 포스 충전, 캐넌 강화 |
| 엘레멘탈 실드 | 버프 | 방어력 증가 및 속성 공격력 강화 |
| 마나 폭주 | 버프 | 공격력 증가(마나소모 페널티) |
| 원소 폭격 | 패시브 | 캐스팅 속도·쿨타임 감소, 스킬 캔슬 가능 |
| 원소의 이해 | 패시브 | 공격력·적중률 증가 |
| 엘레멘탈 캐넌 | 액티브 | 강력한 속성 마법구 발사 |
| 크리스탈 어택 | 액티브 | 얼음 기둥으로 사선 공격 |
| 파이어 로드 | 액티브 | 불기둥 생성, 전방 공격 |
| 체인 라이트닝 | 액티브 | 전류 발사, 적 간 전이 공격 |
| 암전 | 액티브 | 암흑 에너지로 광역 암흑 상태이상 |
| 플레임 서클 | 액티브 | 화염 고리 회전, 주변 공격 |
| 아이스 크리스탈 샤워 | 액티브 | 마법진에서 얼음 기둥 낙하 |
| 다크니스 멘틀 | 액티브 | 암흑 구체로 적 홀딩 후 폭발 |
| 라이트닝 월 | 액티브 | 빛의 장막으로 전방 쓸어내기 |
| 엘레멘탈 레인 | 액티브 | 다중 속성 마법구로 공중 폭격 |

**각성 스킬**

| 각성 | 스킬명 | 구분 | 효과 |
|---|---|---|---|
| 1차(워록) | 페이탈 엘레멘트 | 패시브 | 크리티컬 확률·공격력 증가 |
| 1차(워록) | 엘레멘탈 버스터 | 액티브 | 속성별 폭발로 광역 고데미지(1차 각성기) |
| 1차(워록) | 컨센트레이트 | 액티브 | 압축 마법구 투척 후 폭발 |
| 1차(워록) | 엘레멘탈 스트라이크 | 액티브 | 5개 마법구 낙하 폭발 |
| 2차(오블리비언) | 검은 눈 | 패시브 | 모든 스킬 원소폭격 연계 + 공격력 증가 |
| 2차(오블리비언) | 엘레멘탈 필드 | 액티브 | 광역 필드 생성, 모속성 버프 |
| 2차(오블리비언) | 컨버전스 캐넌 | 액티브 | 4속성 융합 구체로 흡입 폭발 |
| 2차(오블리비언) | 아마겟돈 스트라이크 | 액티브 | 거대 원소 행성 낙하 폭발(2차 각성기) |
| 진각성 | 위키드 오드 아이 | 패시브 | 모든 스킬 캔슬 연계 + 중급 스킬 강화 |
| 진각성 | 컨버전스 리액트 | 액티브 | 소우주 구체로 레이저 방출 |
| 진각성 | 마이크로 유니버스 | 액티브 | 어비스 활성화로 빅뱅 폭발(진각성기) |

#### 빙결사
**컨셉/역할**: 수속성 마법을 극한까지 연구해 얼음으로 무기를 조형, 근접에서 직접 때리는 마법 딜러.
**전직 계보**: 마법사 → 빙결사 → (1차각성) 프로즌하트 → (2차각성) 이터널 → (진각성) 진 빙결사

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 수인체 | 패시브 | 기본 공격 전면 변경, 점프 공격·대시 공격 시 얼음 송곳 생성 |
| 프로즌웨폰 마스터리 | 패시브 | 빙백검·기본 공격·전직 스킬 공격력 증가, 설화연창/회전투창에 빙결 추가 |
| 아이스 로드 | 버프 | 속성 공격력 증가, 주위 적 빙결 내성 감소 |
| 발현 | 패시브 | 마법 공격력·크리티컬 확률·적중률 증가, MP 소모 감소 |
| 공명 | 버프 | 기본 공격·스킬 공격력 증가 |
| 크리스탈 블레이드 | 패시브 | 빙백검 2타 강화, 적을 앞으로 모으는 기능 추가 |

**각성 스킬**

| 각성 | 스킬명 | 구분 | 효과 |
|---|---|---|---|
| 1차(프로즌하트) | 툰드라의 가호 | 패시브 | 빙백검·기본 공격·전직 후 스킬 공격력 증가, 주변 적 일정시간 빙결 |
| 1차(프로즌하트) | 빙류환 | 액티브 | 얼음 고리로 적 주변 공격 후 거대 고리로 완성, 폭발 |
| 1차(프로즌하트) | 아이스 오브 | 액티브 | 가시 얼음 구슬 투척, 송곳 생성해 적 끌어모은 뒤 폭발 |
| 1차(프로즌하트) | 아이스 필드 | 액티브 | 전방 얼음 안개 생성, 얼음가시 3회 공격 + 빙결 부여 |
| 2차(이터널) | 아이스크래프트 | 패시브 | 스킬 공격력 증가, 얼음 무기 스킬 사용 후 얼음창 생성 |
| 2차(이터널) | 샤드 매그넘 | 액티브 | 얼음 기둥 생성 후 파괴, 파편·충격파로 공격 |
| 2차(이터널) | 오버프리즈 익스텐션 | 액티브 | 어비스 냉기 응축 후 주위로 뿜어 피해·경직 |
| 2차(이터널) | 쥬데카 디 이터널 | 액티브 | 영원의 얼음 화살로 얼음 감옥 생성, 적 가둠(2차 각성기) |
| 진각성 | 프로스트헌트 | 패시브 | 스킬 공격력 증가, 회전투창·브로큰 애로우 강화 |
| 진각성 | 글라키에스 | 액티브 | 거대 얼음 대검 2개로 광범위 단타 피해 |
| 진각성 | 영겁: 나스트론드 | 액티브 | 한파로 적을 얼린 뒤 얼음창 공격, 지면 파괴로 폭풍 생성, 거대 해머로 마무리(진각성기) |

#### 블러드메이지
**컨셉/역할**: 혈기(피) 자체를 힘의 근원으로 삼는 근접형 물리 딜러 마법사(창 사용, 마법사 계열 중 이례적으로 물리 퍼센트 딜러).
**전직 계보**: 마법사 → 블러드메이지 → (1차각성) 뱀파이어 → (2차각성) 뱀파이어로드 → (진각성) 진 블러드메이지

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 크리핑 | 액티브 | 전방으로 빠르게 이동(텔레포트 대체 이동기) |
| 데드 핸즈 | 패시브 | 무기를 혈기 장막에 흡수시켜 근접 공격으로 변경, 혈기 흡수 능력 부여 |
| 블러드 | 패시브 | 혈기 자원 생성, 적중률 증가, 고양 상태 유지 시 공격력·쿨감 제공 |
| 블러드 혼 | 패시브 | 기본·스킬 공격력 증가 |
| 블러드 번 | 버프 | 혈기를 태워 기본·스킬 공격력 강화 |
| 릴리악 | 액티브 | 박쥐 발사, 혈기 흡수 및 다단히트 피해 |
| 릴로이 | 액티브 | 박쥐떼로 범위 다단히트 및 혈기 흡수 |
| 헬베루즈 | 액티브 | 개 형상 사출, 적 고정 후 지속 피해 및 혈기 흡수 |
| 소울 스틸 | 액티브 | 혈기 장막으로 대상을 중앙으로 밀어내며 피해·혈기 흡수 |
| 블러드 윙 | 액티브 | 혈기 소모, 날개로 변형해 전방 돌진 및 다단히트 |
| 오퍼링 | 액티브 | 혈기 창으로 대상을 꿰뚫어 올렸다가 패대기(홀딩) |
| 쉬카리 | 액티브 | 혈기 가시로 대상을 정면에서 꿰뚫는 범위 공격 |
| 팽 | 액티브 | 혈기 이빨 형상으로 범위 내 적을 물어뜯음 |
| 토먼트 | 액티브 | 혈기 장막을 회전하듯 뿜어내는 범위 다단히트 |
| 커럽션 | 액티브 | 혈기 소모, 적에게 달려가 피를 빨아들이는 강력한 잡기 공격 |

**각성 스킬**

| 각성 | 스킬명 | 구분 | 효과 |
|---|---|---|---|
| 1차(뱀파이어) | 어밴던 | 패시브 | 상시 고양 상태 유지, 스킬 외형 변화, 공격력 증가 |
| 1차(뱀파이어) | 체페슈 | 액티브 | 혈기 호수로 변해 창으로 적을 꿰뚫고 혈기 흡수(1차 각성기) |
| 1차(뱀파이어) | 럼블독 | 액티브 | 개떼 형상으로 범위 내 적을 물어뜯으며 혈기 흡수 |
| 1차(뱀파이어) | 머로더 | 액티브 | 박쥐떼로 순간이동, 충격파로 적을 모으고 베기 |
| 2차(뱀파이어로드) | 트루 블러드 | 패시브 | 크리티컬 공격력·확률 증가, 혈기 흡수 시 체력 회복 |
| 2차(뱀파이어로드) | 팬텀 베일 | 액티브 | 개 형상으로 적을 물어뜯으며 홀딩 및 혈기 흡수 |
| 2차(뱀파이어로드) | 페이탈리티 | 액티브 | 혈기 회오리로 적을 끌어와 쐐기를 박아 정기를 뽑아냄 |
| 2차(뱀파이어로드) | 블러드 스트림 | 액티브 | 혈기의 흐름으로 다단히트 후 폭발, 장시간 채널링(2차 각성기) |
| 진각성 | 블러드비스 | 패시브 | 공격력 증가, 혈기 흡수량·지속시간 증가, 저레벨 스킬 강화 |
| 진각성 | 블러드 스틴저 | 액티브 | 혈기 날개로 회전하며 베는 전방 범위 공격 |
| 진각성 | 익스터미티 페리쉬 | 액티브 | 모든 혈기 소모, 적의 생명력을 뽑아내 구속 후 폭발(진각성기) |

#### 스위프트마스터
**컨셉/역할**: 바람을 자유자재로 다루는 고기동 물리 딜러(마법처럼 보이지만 순수 물리 공격, 봉 사용).
**전직 계보**: 마법사 → 스위프트마스터 → (1차각성) 스톰브링어 → (2차각성) 아이올로스 → (진각성) 진 스위프트마스터

| 스킬명 | 구분 | 효과 |

#### 디멘션워커
**컨셉/역할**: 차원 너머 이계 존재(크툴루 신화 모티브, 소환수 "니알리")를 탐구·활용하는 컨트롤형 마법 딜러. 스킬은 "차원계"와 "괴리계" 두 축으로 구성.
**전직 계보**: 마법사 → 디멘션워커 → (1차각성) 이레귤러 → (2차각성) 어센션 → (진각성) 진 디멘션워커
