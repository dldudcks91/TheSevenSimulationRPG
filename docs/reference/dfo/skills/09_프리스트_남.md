#### 인파이터(남)
**컨셉/역할**: 프리스트의 시조 미카엘라가 구사한 "신격권"에 특화된 물리 퍼센트 딜러 — 빠른 연타 공격과 카운터가 특징. **여성 인파이터와는 이름만 같고 설정·스킬 완전 별개** — 나무위키 원문상 "기존 남성 쪽의 성격은 이단심판관이 가져갔고, 여성 쪽은 남성 스트리트 파이터·블레이드와 유사하다"고 명시됨. 즉 과거 통합 직업이었던 인파이터가 개편되면서 옛 남성 인파이터의 컨셉은 별도 직업 "이단심판관"으로 넘어갔고, 현재의 남성 인파이터·여성 인파이터는 이름만 공유할 뿐 설정·스킬트리·모션이 완전히 별개인 직업이다.
**전직 계보**: 프리스트(남) → 인파이터(1차) → 갓핸드(1차 각성) → 저스티스(2차 각성) → 진 인파이터(진 각성)

| 스킬명 | 구분 | 효과 |
|---|---|---|
| 신체강화 | 패시브 | 기본 이동속도·공격속도·점프력 상승 |
| 윌 드라이버 | 버프 | 거병을 바닥에 꽂아 크리티컬 공격력·적중률 증가 |
| 테크니컬 마스터리 | 패시브 | 기본/스킬 공격력 증가, 일부 스킬 범위 확대 |
| 퀵 패리 | 패시브 | 신격 액티브 스킬 시작부 회피율 상승, 회피 시 크확 증가 |
| 섀도우 박서 | 버프 | 그림자 분신이 추가 타격 |

| 디바인 크러시 | 액티브 | 바닥 내려쳐 충격파 |

**각성 스킬**
- 1차(갓핸드): 드라이아웃(패시브, 신격 액티브 캔슬 가능+공증) · 빅뱅 펀치(액티브, 3연타+피니시, 충전형) · 개틀링 펀치(액티브, 10연타 후 내려찍기) · 데몰리션 펀치(액티브, 훅으로 띄움+충격파)
- 2차(저스티스): 데스블로우(패시브, 기본/스킬 공격력·적중률 증가) · 핵 펀치(액티브, 강력 펀치+충격파) · 아토믹 쵸퍼(액티브, 어퍼컷 후 내려찍기) · 신의 분노(액티브, 풋워크 연타 후 피니시)
- 진(진 인파이터): 하나의 정의(패시브, 공증+더킹 바디블로/초핑 해머 강화) · 어그레시브 저지먼트(액티브, 좌우연타 후 훅) · **정의 집행 : 레미디오스의 성좌**(액티브, 성역 선언+건틀렛 어퍼컷)

**컨셉/역할**: 악을 섬멸하기 위해 스스로 악마의 힘을 받아들인 프리스트 — 낫을 쓰는 마법 퍼센트 딜러, "악마화" 변신 메커니즘이 핵심.
**전직 계보**: 프리스트(남) → 어벤저(1차) → 둠스가디언(1차 각성, Lv.50) → 이모탈(2차 각성, Lv.75) → 진 어벤저(진 각성, Lv.100 — 각성무기명 "처형의 대가")
