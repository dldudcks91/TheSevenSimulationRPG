### 2-11. 도적 (여성 전용 기본형)

#### 도적 공용 스킬 (전직 전, 도적 시절 공통)

진짜 전 직업 공통은 "슬라이서" 하나뿐이고, 나머지는 "전직 전 도적이 배우는, 훗날 전직할 계열별 예비 스킬"로 문서가 4계열로 나눠 정리해 둔 구조.

| 스킬명 | 유형 | 효과 | 비고 |
|---|---|---|---|
| 슬라이서 | 액티브 | 대시 공격 중 공격키 입력 시 추가 베기를 시전한다 | 전 계열 공통 |
| 라이징 컷 | 액티브 | 아래에서부터 올려 베어 적을 띄운다. 공중에서도 사용 가능 | 로그 계열 예비 |
| 샤이닝컷 | 액티브 | 전방으로 섬광처럼 빠르게 나아가며 적을 베어버린다 | 로그 계열 예비 |
| 다이빙 애로우 | 액티브 | 공중에서 하강하여 연속차기를 한다 | 로그 계열 예비 |
| 다크 소울 | 액티브 | 암속성 구체를 사출한다. 구체는 적을 찾아 헤매며 폭발한다 | 사령술사 계열 예비 |
| 본 실드 | 버프 | 자신 주위에 뼈 조각을 소환하여 방어력을 증가시킨다 | 사령술사 계열 예비 |
| 커스 스피어 | 액티브 | 저주의 창을 소환하여 전방으로 발사한다 | 사령술사 계열 예비 |
| 쿠나이 던지기 | 액티브 | 쿠나이를 투척하여 원거리의 적에게 데미지를 입힌다 | 쿠노이치 계열 예비 |
| 염화참 | 액티브 | 불꽃의 힘을 모아 적을 강력하게 타격하여 날려보낸다 | 쿠노이치 계열 예비 |
| 인법: 허물벗기 | 액티브 | 지상에 분신을 남기고 공중으로 워프한다 | 쿠노이치 계열 예비 |
| 날다람쥐 | 액티브 | 적에게 빠르게 도약하여 폭발을 일으킨다 | 쿠노이치 계열 예비 |
| 섀도우 컷 | 액티브 | 적을 베어 경직을 시키며 적의 뒤로 이동한다 | 섀도우댄서 계열 예비 |
| 발목 타격 | 액티브 | 날카로운 하단 발차기로 적의 발목을 타격하여 둔화 상태로 만든다 | 섀도우댄서 계열 예비 |
| 이레이저 | 액티브 | 1명의 적을 붙잡고 베어서 큰 물리 대미지를 입힌다 | 섀도우댄서 계열 예비 |

#### 로그
**컨셉/역할**: "극한의 속도를 자랑하는 왕실 첩보 요원" — 흑요정 왕실 직속 첩보부대. 체술+단검술 기반 고속 근접 딜러.
**전직 계보**: 도적 → 로그(전직) → 실버문(1차 각성) → 알키오네(2차 각성) → 진 로그(진각성)

| 스킬명 | 유형 | 효과 |
|---|---|---|
| 스위프트 | 패시브 | 적중률, 회피율, 공격속도, 이동속도를 증가시킴 |
| 로그의 무기 마스터리 | 패시브 | 물리 공격력 증가 및 쿨타임 감소 |
| 샤인 스파크 | 패시브 | 샤이닝컷 발동 가능 횟수가 증가 |
| 에어리얼 점프 | 패시브 | 점프 중 한 번 더 점프할 수 있다 |
| 브레이킹 러시 | 액티브(이동기) | 전방을 향해 빠르게 돌진 |
| 사이드 스텝 | 액티브(이동기) | Y축으로 살짝 뛰어서 이동 |
| 셰이크 다운 | 버프 | 크리티컬 공격력이 증가 |
| 히트엔드 | 액티브 | 연계 점수를 소모하여 추가 공격을 가하는 로그 고유 메커니즘 |
| 소드 댄스 | 액티브 | 제자리에서 매우 빠르게 회전하며 주변 적을 공격 |
| 밴디트 컷 | 액티브 | 전진하면서 적을 베어 기절시킨다 |
| 더블 피어스 | 액티브 | 양손 찌르기로 칼을 꽂은 후 발로 차 대미지 |
| 체인소 | 액티브 | 회전 칼날로 적을 연속해서 벤다 |
| 허리케인 | 액티브 | 시전 위치를 축으로 회전하며 적들을 공격 |
| 라이트닝 애로우 | 액티브 | 대상을 잡아 연속으로 벤 후 킥을 내리꽂는다 |
| 버티컬 스파이럴 | 액티브 | 회전타격을 가하며 지면을 향해 내리꽂는다 |
| 소닉 어설트 | 액티브 | 빠르게 돌진하여 난무 공격을 가함 |
| 엑셀 스트라이크 | 액티브 | 대쉬하며 적들을 공격하여 띄운 후 연속 공격 |

**각성 스킬**
- 1차(실버문): 문아크 · 실버스트림 · 스트림 클로저 · 체인소 러시 · 어슬랜트 스파이럴
- 2차(알키오네): 히트 블리드 · 엑조틱 램펀트 · 디스트리뷰션 · 노바 램넌트
- 진각성: 모멘트 패닉 · 베니싱 일루젼 · **아데스 팬텀**(진각성기)

#### 사령술사
**컨셉/역할**: 죽은 자의 영혼을 강령시켜 부리는 도적 — 완드를 무기로 쓰는 마법 공격력 딜러. 니콜라스(원거리 소환수)와 발라크르(근접 강령체) 동시 운용.
**전직 계보**: 도적 → 사령술사(전직) → 데스브링어(1차 각성) → 타나토스(2차 각성) → 진 사령술사(진각성)

| 스킬명 | 유형 | 효과 |
|---|---|---|
| 완드 마스터리 | 패시브 | 완드 착용 시 캐스팅 속도 증가 및 쿨타임 감소 |
| 암흑의 의식 | 버프 | 스킬 공격력 증가 |
| 어둠의 고리 | 패시브 | 속성 공격력 증가 |
| 흑마법서: 망자의 혼 | 패시브 | 대부분 스킬 공격력 증가 |
| 발라크르의 맹약 | 버프/패시브 | 스킬 공격력 증가 및 발라크르의 야망·기요틴 자동 2타 |
| 어둠의 손톱 | 액티브 | 전방 손톱으로 적을 벰 |
| 망자의 원한 | 액티브 | 망자 소환으로 지속 피해 및 슬로우 |
| 야행혼 | 액티브 | 백귀사령으로 범위 내 적 공격 |
| 리빙데드 | 액티브 | 레디아 블랙옥스 소환하여 강력한 피해 |

| 복종하는 사령 | 액티브 | 니콜라스의 전투 방식을 근접/원거리/수호 태세로 변경 |
| 좀비 강령 | 액티브 | 니콜라스가 좀비 무리를 소환하여 적 공격 |
| 흑사진 | 액티브 | 니콜라스가 거미줄 장판을 설치하여 범위 내 적 공격 |
| 흡기암경파 | 액티브 | 니콜라스가 흡기선으로 적을 잡고 암속성 피해를 입힘 |
| 학살의 발라크르 강령 | 액티브(강령) | 발라크르를 강령하여 기본공격을 변경 |
| 암격권 | 액티브 | 발라크르가 주먹으로 잡기 공격 시전 |
| 살육난무 | 액티브 | 발라크르가 전방으로 전진하며 검을 휘두름 |
| 강격 | 액티브 | 발라크르가 앞쪽에 내려찍는 공격 시전 |
| 발라크르의 야망 | 액티브 | 손모양 기운으로 적을 끌어당기고 움켜쥠 |
| 기요틴 | 액티브 | 발라크르가 거대화된 검으로 일격 필살 공격 |

**각성 스킬**
- 1차(데스브링어): 학살자의 공포 · 팬텀스트롬 · 망자의 집념 · 헤이트풀

- 진각성: 아케론의 열쇠 · 코쿤 오브 언데드 · **태초의 공포: 모로스**(진각성기)

#### 쿠노이치
**컨셉/역할**: "차크라를 자유자재로 다루기 위한 인법을 수련한 도적" — 화(火)속성 마법 공격에 특화된 닌자형 딜러.
**전직 계보**: 도적 → 쿠노이치(전직) → 이즈나비(1차 각성) → 시라누이(2차 각성) → 진 쿠노이치(진각성)

| 스킬명 | 유형 | 효과 |
|---|---|---|
| 차크라 웨펀 착용 | 패시브 | 전용 무기 장착 시 기본 공격이 마법 공격력으로 전환 |
| 인술 | 패시브 | 스킬 사용 시 인을 맺어 추가 효과 발동 |
| 에어리얼 점프 | 액티브 | 공중에서 추가 점프 가능 |
| 인법: 통나무분신술 | 액티브 | 제자리에 통나무를 남기고 이동 |
| 화둔: 홍염 | 버프 | 공격력 및 방어력 증가 |
| 화염의 인 | 패시브 | 기본/스킬 공격력 증가 및 화상 피해 추가 |
| 화염구 | 액티브 | 입에서 화염을 방출 |
| 환영 다중 수리검 | 액티브 | 분신 소환 후 수리검 연속 투척 |
| 화염선풍 | 액티브 | 적을 끌어당기는 회오리를 발사 |
| 나선 대차륜 쿠나이 | 액티브 | 거대 쿠나이 투척 및 회전 공격 |
| 인법: 바꿔치기 | 액티브 | 적과 위치 교환 및 기폭찰 폭발 |
| 열화천도 | 액티브 | 지상 폭발 후 불덩어리 투척 |
| 두꺼비유염탄 | 액티브 | 불두꺼비를 소환하여 화염탄 발사 |
| 비기: 염무개화 | 액티브 | 고속 베기 후 화염 방출 |

**각성 스킬**
- 1차(이즈나비): 초열혼폭술 · 흉멸인법진 · 암기: 비연수리검 · 마환: 풍마수리검 (효과 상세 확인 안 됨, N/F)
- 2차(시라누이): 야타의 거울 · 광휘의 팔척곡옥 · 야마타오로치 · 아마테라스 · 쿠사나기의 검 (효과 상세 확인 안 됨, N/F)
- 진각성: 일기화삼청 · 구옥지화: 카마이타치 · **야타가라스**(진각성기) (효과 상세 확인 안 됨, N/F)

#### 섀도우댄서
**컨셉/역할**: "그림자 속에 숨어 적의 배후를 노리는 암살술을 연마한 도적" — 백어택(배후 공격) 특화 물리 딜러, 단검 사용.
**전직 계보**: 도적 → 섀도우댄서(전직) → 나이트메어(1차 각성) → 그림리퍼(2차 각성) → 진 섀도우댄서(진각성)

| 스킬명 | 유형 | 효과 |
|---|---|---|
| 암살기술 | 패시브 | 배후 공격에 특화, 백어택 판정 조건 완화, 크리티컬 공격력 증가 |
| 날카로운 단검 | 패시브 | 단검 사용 시 물리 무기 공격력 및 적중률 증가, 경직시간 상향 |
| 섀도우 댄싱 | 버프 | 백어택 성공 시 그림자 분신을 소환하여 주변 적 공격 |
| 그림자 유도분신 | 액티브 | 도발용 분신 소환 및 은신 상태 진입, 은신 중 크리티컬 확률 증가 |
| 암살자의 마음가짐 | 버프 | 크리티컬 확률 및 공격력 증가 |
| 그림자 이동 | 액티브(이동기) | 전방 돌진, 적 충돌 시 배후로 이동, 일부 스킬 캔슬 가능 |
| 넥 디바이더 | 액티브 | 백어택 시 추가타 발생 |
| 홀드업! | 액티브 | 누운/낮게 뜬 적을 기상시키며 강제 경직 |
| 심장 찌르기 | 액티브 | 백어택 시 급소를 도려내며 히트리커버리 조작 |
| 나락 떨구기 | 액티브 | 적을 투척 및 내려찍기, 슈퍼아머 무시 |
| 코버트 액션 | 액티브 | 연속 베기 후 배후로 이동 |
| 칼날돌풍 | 액티브 | 회전 공격으로 주변 적 공격 |
| 파이널 디스트럭션 | 액티브 | 직진 난무, 슈퍼홀드 판정 |
| 암살 | 액티브 | 은밀 접근 후 참격, 저체력 적 추가 피해, 후딜레이 김 |

**각성 스킬**
- 1차(나이트메어): 배후습격 · **절명의 그림자**(각성기) · 단검투척 · 섀도우 스팅
