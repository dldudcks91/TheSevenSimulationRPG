### 2-16. 제국기사 · 다크나이트 · 크리에이터 (독립/외전 캐릭터)

이 셋은 정규 전직 트리(귀검사/격투가/거너/마법사/나이트/마창사/총검사/아처)에 속하지 않는 독립·외전 캐릭터다.

#### 제국기사

제국기사는 귀검사(남) 계열의 하위 전직이 아니라, 귀검사·격투가·거너·마법사 등과 동급인 완전히 독립된 신규 캐릭터(18번째 신규 캐릭터)다. 세계관상 귀검사(여)와 대척점. 2025-11-22 공개, 첫 전직 브레이커 2026-06-04 출시. 무기 컨셉: 장병기 계열, 고유 무기 [앵커]. 데 로스 제국 출신, 히리아 황녀 산하 비밀 조직 "골든 니들" 소속.

##### 브레이커

**계보**: 제국기사 → 브레이커(1차 전직) → 1차 각성(블랙 쉽) → 2차 각성(세이렌) → 진각성(진 브레이커)
**컨셉/역할**: 해상 전투에 특화된 물리 퍼센트 데미지 딜러. 무기: 앵커(닻). 스킬 3계열: 앵커 스킬(광역)·체인 스킬(추적/캔슬)·철인 스킬(방어 겸비). 나머지 전직은 미공개(N/F).

**전직 스킬 — 패시브**: 덱 브레이커(쿨타임/MP소모 감소) · 노 쿼터(공증+물크확) · 어베스트(공증 버프) · 백병전 전문가(공증+적중)

**전직 스킬 — 액티브**: 훅 샷(강습 날아차기) · 앵커 킥(회전 날아차기) · 선체 파괴(도약 내려찍기 광역) · 스위핑 스트라이크(넓게 쓸어 적 모음) · 딥 워터 콜(강한 적 머리 위 낙하) · 타이드 피어서(강렬한 찌르기) · 게일 슬래시(십자 방향 휘두름) · 타이드 바운드(강습 날아차기) · 역조연격(2연격 후 올려베기) · 웨이브 브레이커(앵커 박아 충격파)

**1차 각성(블랙 쉽)**: 골칫거리(패시브 공증) · 개전의 팡파르(체인으로 선수 휘둘러 내려침) · 피어스 임팩트(강렬한 찌르기) · 마엘스트롬(소용돌이로 적 끌어모아 베기)

**2차 각성(세이렌)**: 철의 노래(패시브 공증) · 드레드폴 배러지(높이 발사 후 강습+앵커타격) · 교룡아(전진 회전베기) · 씨 베인(잠수 후 함선 박살 피니시 — 해신낙연과 연동 가능)

**진 각성**: 역조(패시브, 선체파괴·타이드피어서 강화) · 언바운드 템페스트(연속 베기로 광역 소탕) · 해신낙연(진각성기 — 씨 베인과 연동 시 딜레이 압축+데미지 합산)

#### 다크나이트

**컨셉/역할**: "모든 제약을 넘어서 자신이 가질 수 있는 모든 힘을 자유자재로 사용하여 싸우는 검사" — 카잔 증후군에서 해방된 귀검사. 2012-08-02 출시, 던전앤파이터 첫 번째 외전 캐릭터.

**해금 조건**: 2015년 8월 10주년 업데이트로 "계정 내 70레벨 이상 캐릭터 보유" 조건 신설(전직이 아니라 별도 캐릭터라 소급 적용). 크리에이터와 함께 "생성 레벨 제한이 생긴 첫 캐릭터".

**전직 계보 차이**: "전직"이 아니라 별도 생성하는 독립 캐릭터. 스킬은 웨펀마스터 계열/소울브링어 계열/버서커 계열/아수라 계열로 나뉘어(귀검사 남 4개 정식 전직명과 일치) — 귀검사 4개 전직의 스킬을 암속성으로 재해석해 통합한 컨셉.

**각성 대신 "자각"**: 1차 자각(Lv50 자동) → 2차 자각(Lv75 자동) → 진 자각(Lv100 자동).

**특수 조작**: A~H 8개 콤보슬롯에 각각 최대 5개 스킬을 자유 배치하는 전용 시스템.

**자각 스킬**

| 단계 | 스킬명 | 효과 |
|---|---|---|
| 1차 자각 | 자각(패시브) | 시간의 힘 사용 가능 |
| 1차 자각 | 타임 스톱(패시브) | 힘 극대화 순간의 시간을 멈췄다가 필요시 재생 |
| 1차 자각 | 팬텀 소드 | 검은 귀수로 형상화한 팬텀 소드 다수 소환 |
| 1차 자각 | 다크 웨이브 폴 | 어둠의 검 낙하 폭발 |
| 1차 자각 | 차지 익스플로전 | 전진하며 검을 휘둘러 적을 띄움 |
| 2차 자각 | 차원일치(패시브) | 검·마법 두 시간대 능력을 동시 구사 |
| 2차 자각 | 다크 버스트 | 암흑검 생성 후 에너지 폭발 |
| 2차 자각 | 타임 브레이크 | 여러 시간대로 나뉘어 광범위 참격 |
| 진 자각 | 타임로드(패시브) | 콤보슬롯 초기화 없이 다른 슬롯 사용 가능 |
| 진 자각 | 디아볼릭 슬래쉬 | 연속 베기 후 강력한 발도 |
| 진 자각 | 디 엔드 오브 타임 | 시간의 틈 소환, 자신 제외 모든 시간 정지(최상위 필살기) |

**자각 전 전체 스킬**: 어둠의 검사(패시브)·어둠의 무기 마스터리(무기별)·오버플로우·어퍼·브리프 컷·다크 슬래쉬·다크 크로스·웨이브·베인 슬래쉬·홉 스매쉬(공용) / 바운스 블로우·피어스 스트라이크·래피드 무브·다크 크래셔·드로우 소드·일루젼 슬래쉬(웨펀마스터 계열) / 스핀 어택·트리플 스탭·윕 어택·다크 폴·모멘터리 슬래쉬·다크 플레임 소드(소울브링어 계열) / 다크 익스플로젼·다크 레이브·다크 러스트·다크 소드·다크 브레이크(버서커 계열) / 그랜드 웨이브·다크 웨이브·다크 볼·쇼크 웨이브·웨이브 스핀(아수라 계열)

#### 크리에이터

**컨셉/역할**: "시간의 틈에서 새로운 힘을 얻게 된 마법사" — 시간의 퍼밀리어로 시간의 균열을 만들어 사물·마법을 소환해 공격. WASD 이동 + 마우스 좌/우클릭·드래그로 계열 스킬 2종을 각각 발동하는 독자적 컨트롤 방식.

**해금 조건**: 2012-08-16 최초 출시(여성 마법사 외전). 2015년 8월 업데이트로 "계정 내 70레벨 이상 캐릭터 보유" 조건 신설.

**전직 계보 차이**: 별도 외전 캐릭터, 전직/각성 과정 없음. 대신 **"자각"** 시스템(2016-05-19 도입)으로 성장 — "시간의 조각" 퀘스트 반복 수행. 전용 무기 빗자루.
