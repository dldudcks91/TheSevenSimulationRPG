# 던전 앤 드래곤 5판 — 팔라딘(Paladin) 핵심 클래스 기능

**컨셉/역할**: 서약(Oath)에 묶인 성기사 — 근접 전투 중에 주문 슬롯을 태워 순간적으로 큰 피해를 얹는 「신성한 강타」가 정체성. 4개 서약(헌신·고대·복수·정복) 중 하나를 골라 3레벨에 하위 클래스로 갈라진다.

| 기능 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 신성한 감각 | Divine Sense | 행동을 써서 주위에 있는 천상체·악마·언데드의 위치와 종류를 감지한다 |
| 치유의 손길 | Lay on Hands | 손을 대 대상의 HP를 회복시키거나, 대신 소모해 질병·중독을 치료한다 |
| 전투 유파 | Fighting Style | 전투 스타일(방어·결투·거대무기 등) 하나를 골라 영구적인 전투 보너스를 얻는다 |
| | Spellcasting | 성직자처럼 카리스마를 기반으로 팔라딘 주문 목록에서 주문을 준비해 쓸 수 있게 된다 |
| 신성한 강타 | Divine Smite | 근접 공격이 명중했을 때 주문 슬롯을 태워 추가 광휘 피해를 더한다, 언데드·악마 상대로는 더 세진다 |
| 신성한 체력 | Divine Health | 질병에 완전히 면역이 된다 |
| | Sacred Oath | 자신의 서약(헌신·고대·복수·정복 등)을 맹세하고, 그 서약의 전용 기능들을 얻기 시작한다 |
| 추가 공격 | Extra Attack | 자신의 턴에 공격 행동을 할 때 한 번 더 공격할 수 있게 된다 |
| 보호의 오라 | Aura of Protection | 자신과 근처 아군이 내성 굴림을 할 때 자신의 카리스마 보정치만큼 보너스를 준다 |
| 용기의 오라 | Aura of Courage | 자신과 근처 아군이 공포 상태에 걸리지 않게 막아준다 |
| 향상된 신성한 강타 | Improved Divine Smite | 별도로 슬롯을 안 써도 모든 근접 무기 공격에 추가 광휘 피해가 항상 붙는다 |
| 정화의 손길 | Cleansing Touch | 행동을 써서 자신이나 대상에게 걸린 주문 효과 하나를 끝낼 수 있다 |
