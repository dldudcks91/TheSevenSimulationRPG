# 던전 앤 드래곤 5판 — 팔라딘, 선조의 맹세(Oath of the Ancients)

**컨셉/역할**: 법이나 질서보다 「선함·생명·빛」 자체를 지키는 데 초점을 둔 자연 친화적 성기사. 규약은 빛의 전파·빛의 보호·자신만의 빛의 보존·빛과의 동화 네 가지.

| 기능 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| | Nature's Wrath(2014판 명칭) / 대자연의 분노(2024판) | 신성 변환을 써서 근처의 적 하나를 정령의 덩굴로 옭아맨다, 힘이나 민첩 내성에 실패하면 구속된다 |
| | Turn the Faithless | 신성 변환을 써서 요정·악마를 겁먹게 해 도망치게 만든다 |
| 방비의 오라 | Aura of Warding(2014판은 주문 피해 저항) | 자신과 근처 아군이 주문으로 인한 피해에 저항을 얻는다 |
| 불사의 파수꾼 | Undying Sentinel | HP가 0이 되어도 죽는 대신 1로 버틸 수 있다, 노화로 인한 불이익도 사라진다 |
| 장생의 용사 | Elder Champion | 행동을 써서 고대 생명의 화신으로 변신한다, 턴마다 HP를 회복하고 주문을 더 빠르게 쓸 수 있으며 근처의 적은 자신의 주문·신성 변환에 불리점을 받는다 |
