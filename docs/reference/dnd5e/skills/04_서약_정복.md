# 던전 앤 드래곤 5판 — 팔라딘, 정복의 맹세(Oath of Conquest)

**컨셉/역할**: 자비보다 「압도적인 승리로 적의 저항 의지 자체를 꺾는다」를 우선하는 가장 공격적인 서약. 공포로 적을 무력화시키는 군중 제어와 순수 화력에 특화됐다. 규약은 적의 희망 분쇄·철권 통치·힘에 대한 숭상.

| 기능 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| | Conquering Presence | 신성 변환을 써서 근처에 보이는 적들을 겁먹게 만든다 |
| | Guided Strike | 신성 변환을 써서 명중 굴림에 큰 보너스를 더한다, 명중 여부를 본 뒤에 쓸 수 있다 |
| | Aura of Conquest | 자신이 무력화되지 않은 한 항상 공포에 빠진 적의 이동속도를 근처에서 0으로 만들고, 매 턴 정신 피해를 준다 |
| | Scornful Rebuke | 자신을 공격해 명중시킨 적이 카리스마 보정치만큼 정신 피해를 되돌려받는다 |
| | Invincible Conqueror | 행동을 써서 정복의 화신으로 변신한다, 일정 시간 모든 피해에 저항을 얻고 공격을 한 번 더 할 수 있으며 근접 공격의 치명타 범위가 넓어진다 |
