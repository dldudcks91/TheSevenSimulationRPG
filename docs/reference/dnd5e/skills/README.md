# 던전 앤 드래곤 5판 — 팔라딘 자료

`dnd5e.wikidot.com` (영문 커뮤니티 위키, Player's Handbook 2014판 기준)에서 팔라딘 클래스의 핵심 기능과
4개 서약(Oath of Devotion · Oath of the Ancients · Oath of Vengeance · Oath of Conquest)을 받았다.
한국어 명칭은 나무위키의 "팔라딘(던전 앤 드래곤 시리즈)/5판" 문서 중 **2014판을 서술한 구간**(2024
개정판과 구분됨)에서 확인 가능한 것만 옮겼다 — 2024 개정판에서 이름이 바뀌었거나 구조가 달라진 기능은
각주로 표시했다.

**라이선스**: 두 출처 모두 팬 위키로 별도 라이선스 명시가 없다. 이 폴더의 각 파일은 원문 규칙 텍스트를
요약해(수치·주사위 공식 제외) 표로 재구성했으며, 각 파일 첫 줄에 원문 출처를 남겼다.

(Divine Smite)와 적의의 맹세(Vow of Enmity)를 포함해 4개 서약 전부를 담았다.

## 표 읽는 법

- **한글 칸이 빈 항목**: 나무위키 2014판 서술 구간에 해당 기능의 한국어 명칭이 명시적으로 나오지 않아
  비워뒀다(지어내지 않았다). 2024 개정판 명칭이 다르거나 구조가 바뀐 경우는 셀 안에 각주로 남겼다.
- **무엇을 하는가**: 원문 규칙 설명을 옮기되, 피해 주사위·내성 DC·레벨별 수치표는 빼고 효과의 모양만
  남겼다.
