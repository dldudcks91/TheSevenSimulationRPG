## 1. 구조 개관 — Active/Passive/Tactic 3층, 클래스 5분류

```
모험가 1인 = Active Skill  +  Passive Skill  +  Tactic
              (자동 발동)      (항시 — Star 등급만 보유)   (플레이어 수동, Rage 소비)
```

- 총 **약 100종**의 액티브·패시브 스킬 [상점], **25 클래스** [상점][위키]
- **클래스 5분류**: Assassin / Tank / Balanced / Healer / Support [위키] — 클래스가 어느 분류에 속하는지가 스킬·탤런트의 성격을 정한다
- 각 어드벤처러는 **주 능력치(힘 또는 지능) 1개 + 원소(피해 타입) 1개**를 고정으로 갖는다 [위키] — 예: Warrior=힘/물리, Missionary=지능/신성, Cube=지능/화염(+모든 액티브·택틱에 신성 피해 추가)
- **패시브(Star Skill)는 Ancient-Star 등급 개체만 보유** — 일반 개체는 액티브+택틱 2층뿐이고, 패시브가 붙는 순간 3층이 완성된다(§5 참조). 이는 [00_overview.md §2-3](00_overview.md#2-3-star-유닛--개체에-붙는-고유-패시브)의 "개체 등급이 스킬 슬롯 자체를 여는" 구조를 재확인한다

## 2. Tactic — 유일한 수동 개입, Rage 비용 감면 경로

- **Rage 0~100**을 전투 중 축적. 발동 비용 = **Rage + Energy Point 2 + 쿨타임**([00_overview.md §4-2](00_overview.md#4-2-energy-points--원정-전체의-행동-예산-최대-발견) 참조)
- 예시(Warrior "Sunder"): **Rage 50, 쿨타임 1** [위키] — 모든 적의 긍정 효과 1개 해제 + 전 저항 −25%(7초)

### 2-1. Rage 비용 감면 경로 4종 — 신규 확인

이전 조사는 "`Rage Efficiency` 속성이 최대 80% 감소"로만 서술했는데, 이번에 **실제 감면 경로 4개**가 확인됐다 [위키][커뮤니티]:

| 경로 | 감면량 | 비고 |
|---|---|---|
| **Efficiency 탤런트** | 5포인트 투자 시 **−40%** | "가장 이른 시점에 대부분의 유닛이 쓸 수 있는" 감면 수단이라는 설명 — 초반부터 접근 가능 |
| **아이템 속성** | **1~8%** | 일반 접사로 소량씩 붙는 감면 |
| **Bun Sister 스타 스킬** | **고정 −50** | 개체 고유 패시브가 비율이 아니라 **고정값**으로 Rage 비용을 깎는 사례 |
| **스크롤 스타 효과**(일부) | 모든 택틱 쿨타임 **0**, 대신 Rage 비용 **+30~90%** | 쿨타임을 지우는 대가로 Rage 소모를 늘리는 **트레이드오프형** 효과 — "쿨타임 축"과 "Rage 축"을 서로 맞바꾸는 장치 |

> **관전 시사점**: 스크롤 스타 효과(쿨타임 0 + Rage 대폭 증가)는 "택틱을 거의 매 턴 쓰되 Rage가 순식간에 바닥난다"는 새로운 리듬을 만든다 — 쿨타임 축과 자원(Rage) 축을 상호 교환 가능하게 설계한 사례로, 본작이 액티브 슬롯에 "쿨타임 대신 다른 자원을 태우는" 변형 노드를 넣을 때 참고가 된다.

## 3. School — 스킬 강화의 병목 (Book Pages 정확한 비용표)

> [00_overview.md §3](00_overview.md#3-스킬-구조-요약)이 요약한 "전투력의 최종 상한을 전투 밖(파견+탐험)이 쥔다"는 구조의 근거가 되는 정확한 수치표다. **본작의 `[balance.csv:rounds_per_stage]` 류 스킬 성장 병목 설계 시 직접 대입 가능한 표다.**

### 3-1. School 레벨업 비용 — Book Pages 정확한 장수

| 대상 | 레벨 | Book Pages |
|---|---|---|
| 액티브·패시브 스킬 | 7레벨 | **5장** |
| 액티브·패시브 스킬 | 8레벨 | **10장** |
| 액티브·패시브 스킬 | 9레벨 | **15장** |
| (합계) | 7~9레벨 | **총 30장** |
| 택틱 | 3레벨 | **15장** |

([위키] "At the schools, 5, 10 or 15 pages are needed to upgrade an active skill and passive skill to level seven, eight or nine respectively... Fifteen pages are needed to gain level three in all tactics.")

- **Book Pages는 오직 탐험(Pier)에서만 나온다** — "연구/문화" 스킬을 가진 주민을 배에 태워 학술 조우 성공률을 올려야 한다([00_overview.md §3](00_overview.md) 요약대로, 상세 근거는 [00_overview.md §11](00_overview.md#11-출처-미확인-오염) 원 출처)

### 3-2. Book Pages의 두 번째 쓰임 — Furnace 연계, 이전 조사보다 정밀화

이전 조사는 "Transfer(효과 전이)에 Book Pages 50"이라고만 적었는데, 이번에 **아이템 레벨에 따라 요구량이 3단으로 뛰는 계단식 비용**이 확인됐다 [위키]:

```
Transfer(효과 전이) 기본     : Book Pages 50
레벨 9 이상 아이템의 Transfer : Book Pages 200
레벨 11 이상 아이템의 Transfer: Book Pages 400
```

- 이 외에 **Reforge(레벨 8 이상 아이템)** 도 Book Pages 50을 요구 — [02_items.md §4](02_items.md#4-furnace--개조-5기능-정확한-비용표) 참조

> **재확인**: "School(스킬 성장) 하나만이 아니라, 아이템 강화(Furnace)의 고급 기능까지 Book Pages 하나의 재화가 병목을 쥔다." 스킬 성장과 장비 강화가 **서로 다른 시스템인데도 같은 재화(Book Pages)를 두고 경쟁**한다 — 이는 [00_overview.md §6-1](00_overview.md#6-1-재화-4종)의 "재화 4종이 각각 다른 활동에 묶여 있다"는 원칙에 **예외가 있다는 뜻**이다. 스킬 성장 후반과 장비 강화 후반이 **같은 파이프라인(탐험)을 두고 경합**하게 되는 지점 — 본작이 파견처 산출물을 여러 성장 축의 공통 병목으로 쓸 때 "몇 개 축까지 하나의 재화에 묶을 것인가"의 상한선 참고가 된다.

## 4. Talent — 4그룹 계단

### 4-1. 포인트 획득과 그룹 구조 — 신규 확인

- **5레벨마다 1포인트**, **레벨 85까지** 획득 가능 [위키] (레벨 상한 90보다 5 낮은 지점에서 탤런트 포인트 획득이 끝난다는 뜻 — 마지막 5레벨은 순수 스탯 성장 구간)
- **4그룹**, 이전 그룹에 정해진 수만큼 채워야 다음 그룹이 열린다(예: 1그룹 10점 → 2그룹 해금, [00_overview.md §3-3](00_overview.md) 요약대로)

### 4-2. 그룹별 성격 — 클래스 공통 패턴 [위키, 6개 클래스 페이지 교차 확인: Conjurer·Killer·Warrior·Fire Player·Duelist·Fashion Boy]

| 그룹 | 성격 |
|---|---|
| **1그룹** | 공격·방어 능력치 혼합 — "팀이 어느 한쪽이 부족하면 보완하거나, 전투에 작지만 유의미한 보탬을 준다" |
| **2그룹** | **스킬 전용** — 그 어드벤처러의 액티브 스킬에 피해 또는 유틸리티를 추가 |
| **3그룹** | 후반 전투 보조 — 명중률 상승(고레벨 Mystic Dungeon에서 적을 맞히기 어려워질 때 대비) + 원소 피해 증가 |
| **4그룹** | **택틱 전용** — 피해 상승 또는 공격형 유틸리티 |

> **패턴 확인**: 그룹 1(범용 스탯) → 그룹 2(액티브 강화) → 그룹 3(후반 대비, 명중·원소) → 그룹 4(택틱 강화) 순서가 **6개 클래스 페이지에서 동일하게 반복**된다 — 즉 탤런트 트리의 "무엇을 강화하는가" 배치는 클래스마다 다르지 않고, **트리의 뼈대(스탯→액티브→후반보정→택틱)가 전 클래스 공통 템플릿**이라는 뜻이다. 개별 노드 이름·수치만 클래스별로 다르다.

### 4-3. 포인트 배분 규칙 — 두 서술의 정합 시도

위키 두 곳에서 다음 서술이 확인됐다: "처음 10포인트는 능력치에, 그 다음 1포인트는 액티브 스킬 업그레이드에, 그 다음 5포인트는 능력치나 스킬 업그레이드에, 마지막 1포인트는 택틱 업그레이드에 쓸 수 있다"([위키], Warrior 페이지 문맥). 이는 §4-2의 "그룹당 성격"과 **완전히 일치하지는 않는다** — 그룹2가 "스킬 전용"이라는 서술과, 그룹2 구간(10+1번째~15번째 포인트)에 "능력치도 쓸 수 있다"는 서술이 부분적으로 겹친다. **정확한 포인트 수 대 그룹 경계의 1:1 매핑은 확정하지 못했다(N/F)** — 다만 큰 흐름(초반=스탯, 중반=스킬, 후반=명중/원소, 종반=택틱)은 두 서술 모두 일치한다.

### 4-4. 실전 사례 — Warrior "상시 도발" 조합

- **Taunt on Hit 탤런트 2포인트** + **Shift 탤런트(액티브 스킬 대상)** 조합 시, Warrior가 **팔라딘처럼 (거의) 항상 적을 도발**할 수 있게 된다 [위키] — 두 개의 서로 다른 탤런트(패시브형 확률 도발 + 액티브 스킬 변형)를 조합해 "역할군 고유 기능"(팔라딘의 상시 도발)을 **다른 클래스가 탤런트 투자로 따라잡는** 사례. 클래스 간 역할 경계가 탤런트로 부분적으로 무너질 수 있다는 뜻.

### 5-8. 대표 7종이 보여주는 것

1. **"주능력치/원소 고정 1쌍"이 클래스 정체성의 최소 단위다** — 25클래스 전부가 힘 또는 지능, 8원소 중 하나를 각각 정확히 1개씩만 고정으로 갖는다(Cube처럼 신성이 "추가"되는 예외는 있어도 "주 원소"는 여전히 1개). 본작 무기군×죄종 매트릭스보다 훨씬 **적은 자유도**로 클래스 정체성을 표현하는 방식.
2. **역할과 실제 효과가 어긋나는 사례가 이미 클래스 설계 단계에 있다** — Cube(Assassin으로 분류)가 힐러 대체 역할을 겸하는 것, Missionary(Healer인데 시작 시 공격 수단 zero)가 그 예. [01_skills.md의 Lootun 조사](../lootun/01_skills.md#5-4-warrior--barbarian-fire-arrow-dpssupport-빌드가이드)가 지적한 "이름표와 실제 최적 빌드가 어긋난다"는 관찰이 Dragon Cliff에도 **설계 단계부터 내장**돼 있다는 뜻.
3. **패시브(Star Skill)는 전부 "그 클래스만의 조건부 트리거"** — 워리어(피격 시 도발), 태티션(시전마다 반사 스택), 미셔너리(회복 시 실피해 반전) 전부 "특정 행동을 하면 부가 효과가 붙는" **반응형** 구조다. 아마존 패시브(diablo2/skills/01_amazon.md §3-1)의 "수치업/반응형" 2분류로 보면, Star Skill은 **100% 반응형**에 수렴한다 — 수치업 패시브가 없다.

## 6. 몬스터측 별도 축 — Combat Style 7종

> **신규 발견 — 기존 `dragoncliff_reference.md`에 없던 축.** 어드벤처러 5분류(Assassin/Tank/Balanced/Healer/Support)와 **완전히 별개로**, 몬스터에게는 **Combat Style 7종**이 있다 [위키]: **Assassin / Warrior / Defender / Protector / Supporter / Healer / Statue**.

- Combat Style은 **몬스터가 어떻게 공격하는가**를 정의하고, 몬스터 체력바 옆 "스타일 아이콘"에 마우스를 올리면 상세를 볼 수 있다
- 각 Combat Style은 **Easy / Normal / Hard** 3단계로 다시 세분되며, 이는 그 몬스터가 스폰된 던전의 난이도에 따라 갈린다

> **본작 시사점**: 어드벤처러(플레이어 유닛) 분류와 몬스터 분류가 **이름은 겹치지만(Assassin·Warrior·Healer·Supporter) 서로 다른 목적의 축**이라는 게 흥미롭다 — 플레이어 쪽은 "스킬·탤런트 성격"을, 몬스터 쪽은 "AI 행동 패턴 + 난이도 등급"을 가른다. 본작이 `monster.csv`의 몬스터 행동 패턴을 분류할 때, **영웅 직업 어휘를 그대로 재사용하되 의미는 완전히 다르게 붙이는** 이 처리는 "새 어휘를 안 늘리면서 두 축을 분리하는" 저비용 해법으로 참고할 만하다.

## 7. 본작 시사점

1. **Rage 비용 감면 경로 4종(§2-1)이 서로 다른 "축"에서 온다** — 탤런트(초반 접근)·아이템 접사(소량 누적)·개체 고유 패시브(고정값)·트레이드오프형 스크롤 효과(쿨타임↔Rage 교환). 본작이 액티브 3칸 중 하나에 "발동 비용"을 매긴다면, **감면 수단을 한 종류(예: 마스터리 노드)로만 몰지 않고 이렇게 4갈래로 분산**시키는 편이 각 시스템(스킬 트리·아이템·전직 고유·소모품)이 전부 그 자원과 맞물리게 만든다.
2. **School(§3)이 "재화 하나로 스킬 성장과 아이템 강화를 동시에 병목 잡는다"는 것은 이중 날의 설계다** — 장점은 [00_overview.md §3-2](00_overview.md)가 지적한 "거점을 필수로 만든다"이지만, 단점은 두 시스템이 같은 파이프라인 산출물을 두고 경쟁해 **어느 한쪽이 항상 병목이 된다**는 점이다(예: 스킬 9레벨을 미루고 아이템 Transfer에 Book Pages를 몰아준다는 선택이 강요됨). 본작이 파견처 산출물을 여러 축의 공통 재화로 쓰려 한다면, **"경쟁시킬 것인가, 완전히 분리할 것인가"를 미리 정할 것.**
3. **탤런트 4그룹의 "스탯→액티브→후반보정→택틱" 템플릿(§4-2)이 25클래스 전부에 반복된다** — 이는 "클래스마다 트리를 처음부터 새로 설계하지 않고, 뼈대는 고정한 채 노드 이름·수치만 바꾼다"는 뜻이다. 본작 skill_design.md의 마스터리 2탭(직업·죄종) 노드 배치를 짤 때, **"직업이 여러 개여도 트리의 그룹 순서·성격은 통일한다"**는 이 템플릿을 그대로 참고할 수 있다 — 신규 직업 추가 비용을 예측 가능하게 만드는 저비용 장치.
4. **Combat Style(§6)의 "같은 이름, 다른 축" 처리**는 본작이 새 분류가 필요할 때 새 어휘를 만들지 않고 기존 어휘를 다른 층에 재사용하는 선례로 남긴다.
5. **Missionary의 "시작 시 공격 수단 0"(§5-4)**은 극단적 역할 특화 사례다 — 본작이 서포트/힐러 역할에 "공격 수단을 아예 안 준다"는 선택지를 검토한다면, Dragon Cliff는 이게 **후반 해금으로 완화**된다는 점까지 함께 참고할 것(완전 배제가 아니라 "초반엔 없다가 나중에 생긴다"는 시간차 설계).
