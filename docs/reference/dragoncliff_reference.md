## 0. 조사 방법과 신뢰도

**Lootun과 달리 Fandom 위키가 실재한다** — 이게 이번 조사의 주 자료다.

| 표기 | 소스 | 신뢰도 |
|---|---|---|
| **[위키]** | Dragon Cliff Wiki (Fandom) — Adventurers / Talents / Tactics / Furnace / Gems / Scrolls / Devices / Energy Points / Damage Types and Effects / Growth potential / Mystic Dimension / Auto-Mechanics 등 | ★★★ |
| **[상점]** | Steam 상점 설명 | ★★★ 공식 카탈로그 |
| **[가이드B]** | Steam `Very Basic Guide` | ★★★ 마을·재화·수치 밀도 최고 |
| **[가이드E]** | Steam `Dragon Cliff: Guide, beginning to end.` | ★★ 엔드게임 실전, 수치 다수 |
| **[커뮤니티]** | 스팀 토론 | ★★ |

> **기술 메모**: Fandom은 WebFetch에 **HTTP 402**를 돌려줘 직접 크롤이 막혔다. 위키 내용은 전부 **검색 경유로 열람**한 것이라, 표 전체(효과 목록 등)는 확보하지 못하고 **정의·규칙 문장 위주**로 수집했다.

### 걸러낸 오염 — `mejoress.com` 진행 가이드는 **AI 생성 허구**다
검색 상위에 뜨는 "Dragon Cliff Beginner to Pro" 문서는 실제 게임과 어휘가 전면 불일치한다:

| mejoress 주장 | 실제 |
|---|---|
| 스탯 `Vigor / Tenacity / Spirit / Haste` | **`Vitality / Strength / Agility / Intellect`** |
| 건물 `Adventurer's Guild / Exploration Guild / Marketplace / Blacksmith / Training Ground` | **`Inn / School / Furnace / Weapon·Armor Factory / Pier / Shop`** |
| `Chronotraveler` 건물, `Rebirth`, `Ancient Tomes` 환생 시스템 | **게임에 없음** (환생 없음, 레벨 상한 90 고정) |
| "Divine-quality gear" | 등급 체계에 Divine 없음 |

→ **전량 배제.** Lootun 조사 때의 *Loot of Baal / Mind Over Magic* 오염과 같은 부류이며, 이번 것은 더 위험하다 — **게임 이름은 맞는데 내용이 통째로 지어낸 것**이라 걸러내기 어렵다.

## 1. 게임 구조 한 장

```
   플레이어 = 마을 시장(mayor)
   ┌────────────────────────────────────────────────────────┐
   │ 주민 30명 관리 → 마을 효과      Pier: 배 3척 → 탐험     │
   │        ↓                              ↓                 │
   │ Inn: 모험가 영입 ─→ 5인 파티 ─→ 던전 자동 진행          │
   │ School: 스킬 강화      ↑              ↓                 │
   │ Factory: 장비 대량생산 ┘        전리품 · PP · 재료      │
   │ Furnace: 개조 5기능 ←──────────────────┘                │
   └────────────────────────────────────────────────────────┘
```

- **파티 5인.** 전투는 ATB 자동 진행이고, 플레이어의 유일한 실시간 개입은 **Tactic 발동**(Rage 소비)뿐
- **오프라인 진행이 없다** [커뮤니티] — 서버도 과금도 없는 대신 **게임을 켜둬야 진행된다.** 여기서의 "semi-idle"은 *방치 누적*이 아니라 **자동전투 + 자동진행**을 뜻한다
  → **본작과 계약이 다르다.** 본작 방치형의 전제("자리 비워도 안전")는 Dragon Cliff에는 없다
- 무게중심이 Lootun과 다르다: Lootun은 **아이템 개조**에, Dragon Cliff는 **파티 시너지 + 전투 자원 관리**에 쏠려 있다

## 2. 캐릭터 축 — 성장 잠재력(Growth Potential)

### 2-1. 클래스와 역할

- **25 클래스** [상점][위키], 각각 고유 전투 능력과 탤런트 프로필
- 역할 5분류 [위키]: **Assassin / Tank / Balanced / Healer / Support**
  - Tank는 **단 2종**(Paladin=자기 방어 강화 / Warrior=적 약화)
  - Balanced 안에서도 성격이 갈림 (Fire Charger·Street Man=순딜, Tactician=공수 겸비, Iron Soldier=사실상 서포트)
- 클래스 해금 조건이 제각각 [가이드B]: 메인 퀘스트 / 보스 드롭 / 퀘스트 체인

### 2-2. 개체차 = 성장 잠재력 하나로 표현 — **가장 배울 지점**

| 희귀도 | 성장 잠재력 |
|---|---|
| Common | 0–37 |
| Rare | 39–73 |
| Epic | 74–122 |
| Legendary | 107–191 |
| Ancient | 194–282 |
| **Ancient-Star** | **333–404** |

- 잠재력은 **주 능력치·민첩·활력이 레벨업마다 오르는 양**을 정한다 [위키]
- **잠재력은 레벨 상한을 정하지 않는다. 상한은 전원 레벨 90 공통** [위키]
- 잠재력 20 차이 ≈ 성장 **약 20%** 차이 [위키] — 즉 개체차가 **완만한 곱셈**으로 들어온다
- 희귀도 구간이 **겹친다** (Legendary 107–191 ⊃ Epic 상단 107–122) → *낮은 등급의 상급 개체가 높은 등급의 하급 개체를 이긴다*

> **본작 hero_design.md의 "히든 성장률 / 상한선"이 정확히 이 자리다.** 다만 처리가 다르다:
> - Dragon Cliff: **상한은 공통(90), 잠재력은 속도만** → 시간을 부으면 누구나 만렙, 차이는 스탯 총량
> - 본작: `[balance.csv:hero_attr_max]` 아래에서 **개체별 상한선을 굴림** → 못 넘는 벽이 개체마다 있음
> → **본작 쪽이 더 가혹하고 더 수집욕을 자극한다.** 다만 Dragon Cliff의 **"등급 구간이 겹친다"**는 처리는 그대로 훔칠 만하다 — 등급이 기대값만 정하고 결정하지 않는다

### 2-3. Star 유닛 — 개체에 붙는 고유 패시브

- Ancient 모험가가 생성될 때 **소환 10% / 모험가 팩 20%** 확률로 Star가 된다 [커뮤니티]
- Star는 잠재력이 폭등할 뿐 아니라 **클래스별 고유 "스타 스킬"(패시브)** 을 갖고, **같은 클래스라도 개체마다 수치가 다르다**
  - 예: Warrior 스타 스킬 = 피격 시 도발, 그 도발이 **저항 불가**일 확률 (수치는 개체별)

> 본작 hero_design의 **유니크 영웅 15 + 레어 무한 생성** 2층 구조와 비교할 것. Dragon Cliff는 유니크를 **손으로 만들지 않고**, "고유 패시브가 붙은 최상급 굴림"으로 **절차 생성한다.** 본작이 유니크 15종을 수작업으로 채워야 하는 부채를 안고 있는 것과 대조적이다.

### 2-4. 획득과 레벨링

| 항목 | 값 |
|---|---|
| Inn 방문 | **20일마다** 새 모험가 도착. Legendary/Ancient는 **자동 영입** 설정 가능 |
| 즉시 소환 | **50,000 PP** |
| 레벨 1→70 | 약 **1.5M PP** |
| 레벨 86→90 | 누적 **87M PP** |

> 레벨 곡선이 **후반 4레벨에 전반 70레벨의 58배**를 요구한다. 만렙이 사실상 엔드게임 목표.

## 3. 스킬 구조 — 3층

```
모험가 1인 = Active Skill  +  Passive Skill  +  Tactic
              (자동 발동)      (항시)          (플레이어 수동, Rage 소비)
```

총 **약 100종**의 액티브·패시브 스킬 [상점].

### 3-1. Tactic — 유일한 수동 개입

- **Rage 0~100** 을 전투 중 축적. 택틱마다 요구 Rage가 다르다 [위키]
- 발동 비용: **Rage + Energy Point 2 + 쿨타임** (예외 2종)
- `Rage Efficiency` 속성이 택틱 Rage 비용을 깎으며 **최대 80% 감소** [위키]
- 효과는 유닛마다 다름 — 전체 피해 / 단일 / 피해 흡수 실드 / 자기·전체 버프
- 펫은 공격할 때마다 **Rage 20 생성** [위키]

> **본작 액티브 슬롯 3개 + 자동 발동**(skill_design.md §3, battle_design.md §3)과 대조: Dragon Cliff는 **자동(액티브) / 수동(택틱)을 분리**했다. 본작은 전부 자동이다. *플레이어가 개입할 자리를 하나 남길 것인가*가 결정 지점이며, 남긴다면 **비용을 두 개(Rage + 행동 예산) 물리는** 처리가 참고가 된다.

### 3-2. School — 스킬 강화의 병목이 전투 밖에 있다

| 대상 | 비용 |
|---|---|
| 액티브·패시브 7 / 8 / 9레벨 | **Book Pages 5 / 10 / 15** (마지막 3레벨에 총 30장) |
| 택틱 3레벨 | Book Pages **15** |
| 그 외 | Gold → 후반 Practice Points 추가 |

- **Book Pages는 오직 탐험(Pier)에서만 나온다** — 그것도 **"연구/문화" 스킬을 가진 주민을 배에 태워** 학술 조우 성공률을 올려야 한다 [위키]

> **주목**: 전투력의 최종 상한을 **전투와 무관한 축(주민 배치 + 탐험)** 이 쥐고 있다.
> 본작 base_expedition_design.md §2가 "시설이 곧 파견지이고 배치된 영웅이 효율을 민다"로 방향을 잡았는데, **Dragon Cliff는 그 파견 산출물을 스킬 성장의 유일한 병목으로 만들어** 거점을 필수로 만들었다. *거점을 선택 사항으로 두지 않는 가장 확실한 방법.*

### 3-3. Talent — 4그룹 계단

- 탤런트 포인트는 **5레벨마다 1점**
- **4그룹**으로 나뉘고, **이전 그룹에 정해진 수만큼 채워야 다음 그룹이 열린다** (예: 1그룹에 10점 → 2그룹 해금)
- **1그룹 = 6개 탤런트에 총 10점**, 전부 능력치 상승형

> D2식 시너지/선행 구조와 같다. 본작 skill_design.md §5의 "티어(선행조건) 구조" 미확정분에 대입 가능한 가장 단순한 형태 — **"앞 그룹 N점"이라는 단일 규칙**만으로 계단을 만든다.

## 4. 전투 모델 — 이 게임의 정수

### 4-1. Time Based Command (ATB)

- **Turn Progress**가 가득 차면 모험가가 **자동으로 행동**한다 [상점]
- **Agility**가 (a) 턴 진행 (b) 행동 순서 (c) 행동 빈도 를 전부 결정하고, 동시에 **명중·회피의 기반값**이 된다 [위키]
  - `민첩 × 명중/회피 보정(%) = 실제 명중/회피 수치`
- 턴 진행을 **아군은 올리고 적은 내리는** 탤런트·장비가 존재

> 본작 battle_design.md의 **행동 주기(action_period)** 와 같은 축이다. `agi → action_period`(hero_attribute.csv)로 이미 대응돼 있다.
> **차이 하나**: Dragon Cliff는 민첩이 **행동 속도와 명중·회피를 겸한다.** 본작은 이 둘이 분리돼 있다 — *하나의 능력치에 두 역할을 겹치면 그 능력치가 무조건 1순위가 된다*는 점은 경계할 것.

### 4-2. **Energy Points — 원정 전체의 행동 예산** ⭐ 최대 발견

```
원정 시작 시 파티에 EP 풀이 주어진다
   턴 행동 1회 = 1 EP 소모
   택틱 1회    = 2 EP 소모
EP가 0이 되면 → 전멸과 똑같이 원정 실패
```

- 즉 **"몇 대 맞고 버티느냐"(HP)와 별개로 "몇 번 행동할 수 있느냐"(EP)가 원정의 진짜 제한**이다
- **힐러는 파티 총 EP를 유닛당 +15%, 서포트는 +10% 늘린다** [위키] → *힐러의 가치가 회복량이 아니라 "원정 길이"로 환산된다*
- Mystic Dimension 700층 이상에서는 **던전 전체가 하나의 EP 풀**을 쓴다 (힐러 1 구성 시 약 **920 EP**)

> **이것이 Dragon Cliff에서 가장 훔칠 가치가 큰 장치다.**
> 방치형 자동전투의 고질병은 *"싸움이 길어져도 플레이어가 잃는 게 없다"* 는 것이다. HP는 회복되고 시간만 흐른다. EP는 **행동 1회마다 확정적으로 줄어드는 예산**이라, **효율 낮은 편성이 곧바로 "원정을 끝까지 못 돈다"로 처벌**된다.
> **본작 대입점**: 본작은 스테이지 9라운드 구조(`[balance.csv:rounds_per_stage]`)에 **부상/치료 모델**로 소모를 표현한다. EP는 그와 **다른 층위의 소모**다 — 부상은 *결과*고 EP는 *과정*이다. 둘은 배타적이지 않다.

### 4-3. 피해 타입 8종 — **각 타입이 고유 부가 효과를 갖는다**

| 타입 | 직격 시 부가 효과 [위키] |
|---|---|
| **Physical** | 대상 물리저항 감소 (최대 **50%**) |
| **Fire** | 대상의 모든 `fire seed`를 점화하고 새 seed 부착. 점화 시 **80%** 화염 피해 |
| **Ice** | 대상 민첩 감소 (최대 **60%**), **60%** 확률로 1초 빙결 |
| **Shadow** | `shadow spirit` 부착 — 3초간 총피해의 **25%/초**, 그중 **20%를 시전자에게 회복** |
| **Poison** | 3초 출혈 **20%/초** + 대상 **치유 효과 최대 50% 감소, 10초 지속** |
| **Divine** | 대상 **출력(output capacity) 최대 35% 감소** |
| **Lightning** | **30%** 확률로 인접 2체에 **100%** 번개 피해 |
| **Real** | **방어·회피·저항 전부 무시** |

> **원소가 "저항 뚫기 가위바위보"가 아니라 각각 다른 전술 도구다.**
> 얼음=행동 지연, 독=힐 차단, 신성=적 딜 감소, 번개=연쇄, 암흑=흡혈, 화염=중첩 폭발.
> 본작은 현재 물리/마법 2종(`monster.csv:attack_type`, battle_design.md §2-1)뿐이고 **죄종 7종이 정체성 축**을 맡고 있다. → **죄종에 이런 "고유 부가 효과"를 붙이면 sin_mapping.md가 단순 스탯 매핑을 넘어선다.** 실제로 본작 죄종 컨셉(색욕=흡혈, 시기=방무·디버프, 나태=저속, 폭식=흡수)은 **이미 이 표와 거의 같은 어휘**를 쓰고 있다.

### 4-4. Direct vs Non-direct — 효과 발동의 게이트

| 구분 | 정의 | 아이템·젬 특수효과 발동 |
|---|---|---|
| **Direct Damage** | 스킬·패시브·아이템이 낸 피해 (아군·적 공통) | **발동시킨다** |
| **Non-direct** | **DoT 전부 + 반사 피해** | **발동시키지 않는다** |

> **이 한 줄이 반사·도트 빌드가 무한 연쇄로 폭발하는 걸 구조적으로 막는다.**
> Lootun이 Thorns를 "일반 피해 속성 이득을 안 받는 별도 축"으로 격리한 것과 **같은 문제에 대한 다른 해법**이다. 두 게임 모두 반사/도트를 **주계보다 아래층에 묶어두는 장치**를 갖고 있다.
> **본작 대입**: 본작 나태 죄종의 "반격"과 폭식의 "흡수"가 정확히 이 위험 구간이다. **지금 규칙을 세워두지 않으면 나중에 못 막는다.**

### 4-5. Devices — 또 하나의 전투 자원

- 마을 칭호 **15~16** + 맵의 `Imperial Mausoleum` 1층 해금 시 등장하는 아이템 종류 [위키]
- **`energy adventure point`** 를 소모한다 — §4-2의 Energy Points와 **다른 자원** (혼동 주의)
  - 최대 **100**까지 쌓이고 **원정이 끝날 때마다 리셋**
- **2종이 쌍을 이룬다**: `charger`(조건 충족 시 포인트 생성) / `effect unleasher`(필요량 도달 시 소모하여 발동)
- → **같은 포인트 종류를 쓰는 charger + unleasher를 짝지어야** 의미가 있다

> 장비 하나가 아니라 **"장비 2개의 조합"이 하나의 기능**이 되는 구조. 본작 세트포인트(3/6/9)와 다른 종류의 조합 강제이며, **2개짜리 최소 조합**이라 훨씬 가볍다.

## 5. 아이템 구조

### 5-1. 슬롯 5 [가이드B][위키]

| 슬롯 | 해금 |
|---|---|
| **무기** | 처음부터 |
| **방어구** | 처음부터 — **타입 매칭 필요**: leather=근접 / plate=탱 / cloth=마법 [가이드E] |
| **반지(Ring)** | 처음부터 (Shop에서 구매, 자동 구매 가능) |
| **스크롤(Scroll)** | 노멀 클리어 후 · 마을 칭호 17 `Hesitated Hearts` 에서 School 제작 |
| **목걸이(Amulet)** | 엔드게임 (Mystic Dimension) |

> **본작 8부위 대비 5부위.** 파밍 게임치고 슬롯이 적고, 대신 **슬롯 하나당 붙는 것이 많다**(속성 + 오렌지 효과 + 스타 효과 + 젬 소켓 4개). *넓게 가느냐 깊게 가느냐*의 정반대 선택 — Lootun 16 vs Dragon Cliff 5.

### 5-2. 희귀도 5 + Star

```
White(Common) → Blue(Rare) → Purple(Epic) → Orange(Legendary) → Red(Ancient) → ★Star
```
- 아이템 레벨은 **1~10** (하드모드에서 10레벨 장비 / 9레벨 젬 드롭)
- **속성 수를 희귀도가 직접 정하지 않는다** — 대신:
  - Weapon Factory를 `Crystal Stone` 퀘스트로 업그레이드하면 **그 공장이 만드는 무기 전부에 속성 2개 추가**
  - **Enchant는 Ancient에 +1, Star에 +2 속성** [위키]
  - 스크롤은 **Ancient = 속성 5개 / Ancient-Star = 속성 8개**로 고정

> **Lootun과 정반대 처리다.** Lootun은 `희귀도 = 속성 칸 수`로 직결시켰고, Dragon Cliff는 **희귀도를 효과 등급(오렌지/스타 효과 접근권)에 쓰고, 속성 수는 제작 설비와 인챈트가 정한다.**
> → *"속성 칸을 늘리는 권한을 아이템이 갖느냐, 플레이어의 설비가 갖느냐"* 는 갈림길. Dragon Cliff는 후자라 **대량 생산 파밍이 성립한다.**

### 5-3. 효과 3층 — 색으로 구분

| 층 | 표기 | 성격 |
|---|---|---|
| 일반 속성 | 노랑 | 수치 (Vitality/STR/AGI/INT, 저항, HRA/DRA 등) |
| **Legendary 효과** | **오렌지** | Legendary 등급부터. **무기 종류·서브카테고리별로 거의 고정** (예: 해골 지팡이 = 90% 치명 성장) |
| **Star 효과** | **★ 접두** | general / **class 전용** / **모험가 전용** 3종. 특정 모험가의 성능을 통째로 바꿈 |

- 8레벨 장비를 공장에서 만들 수 있게 되면 **사실상 모든 아이템이 오렌지 효과를 갖는다** [위키]
- 효과 예시: "피격 시 **30% 확률로 Real Damage 반사** — 피해값 = 착용자 DMR × 공격자 저항", "팀원이 맞을 때 **50% 확률로 공격**"

> **핵심**: 오렌지 효과가 **베이스별로 거의 고정**이라 *"어떤 효과를 원하면 어떤 무기를 써야 한다"*가 성립한다.
> 본작 **무기군 Implicit**(item_design.md §1 — 창=선제타. 둔기=경직은 08-25 경직 폐지로 무효)과 **완전히 같은 사상**이다. 본작이 이미 옳은 방향에 있음을 확인해 주는 사례이고, **효과를 다른 아이템으로 옮기는 Transfer(§5-4)** 가 그 위에 얹힌 층이다.

### 5-4. Furnace — 개조 5기능 [위키][가이드B]

| 기능 | 하는 일 | 제약·비용 |
|---|---|---|
| **Combine** | **동일 등급 3개 → 상위 등급 1개** | 8레벨 미만 무료 / 8레벨↑ 회당 **50,000 G** |
| **Enchant** | 속성 추가 | **Ancient +1 / Star +2**. 그 이하 등급 불가 |
| **Reforge** | **속성 1개를 재굴림** | 레어 이상. 8레벨↑는 **Book Pages 50** |
| **Decompose** | 재료 추출 (고레벨 장비 → **Demon Shard**) | — |
| **Transfer** | **오렌지 효과를 다른 아이템으로 이전** | **Book Pages 50** + **원본 파괴** |

**Transfer 제약** [위키]:
- **반지의 효과는 어디로도 이전 불가**
- **스크롤의 효과는 무기·방어구로만** 이전 가능
- 오렌지(legendary)뿐 아니라 노란 접사도 이전 가능 [커뮤니티]

> **`3개 → 1개` 합성이 이 게임의 뼈대다.** 장비도, 젬도(§5-5), 전부 3:1. 그래서 **"양이 곧 질"** 이고, 공장 대량생산과 오토셀이 핵심 루프가 된다.
> Lootun의 개조 계단(Reroll→Lock→Transmute→Imbue→Imprint→Paragon, 10종)과 비교하면 **Dragon Cliff는 5종으로 훨씬 간결**하지만, **비용 통화를 나눠 각 기능의 병목을 다르게 만들었다** (골드 / Book Pages / 원본 파괴).

### 5-5. 젬 — 소켓 8, 세트 2/4, 3:1 합성

- **소켓 최대 8**: **무기 4 / 방어구 3 / 스크롤 1** [위키]
- **레벨 1~25.** **같은 종류·같은 레벨 3개 = 다음 레벨 1개**
  - → **레벨 19 젬 2,187개 = 레벨 25 젬 1개** (3⁷) [가이드E]
- **젬 세트 보너스**: **2개 = 1번째 효과 / 4개 = 2번째 효과** [위키]
  - 소켓 8개의 조합 = `4+4` / `4+2+2` / `2+2+2+2`

> **세트를 장비가 아니라 젬에 걸었다** — Lootun과 **같은 결론**이다(Lootun도 장비 세트 없음 / 젬 세트 있음).
> **두 참고작이 독립적으로 같은 곳에 도달했다는 건 신호다**: *세트 보너스를 장비 부위에 걸면 장비 교체 자유도를 죽인다.*
> **본작은 정반대로 간다** — 죄종 접사 = 세트포인트, 3/6/9(item_design.md §1). 본작 구조는 "세트포인트를 여러 부위에서 모은다"가 죄종 정체성과 직결돼 있어 **의도된 차이**지만, **두 참고작이 모두 피한 길**이라는 점은 기록해 둘 가치가 있다.

### 5-6. Set Amulet — 3개 전부 착용

- **Mystic Dimension 해금 후** 획득. **5개 세트** 존재 [위키]
- **한 세트의 목걸이 3개를 파티가 전부 착용해야 세트 보너스** → **동시에 1세트만 가능**
- 목걸이 개별 효과는 **단일 속성 %** 하나뿐. 자원을 부어 업그레이드하면 속성이 추가되거나 증가

> **세트가 "한 캐릭터"가 아니라 "파티 전체"에 걸린다.** 3개를 세 명이 나눠 껴야 한다.
> → **본작에 없는 축**: 본작 세트포인트는 전부 **개인 단위**다. *파티 단위 세트*는 편성(A안의 핵심 결정)에 직접 개입하는 장치이며, roster_cap 7 / party_size_max 3 구조에서 **3인 세트는 곧 "이 셋을 묶어라"** 가 된다.

## 8. Dragon Cliff가 반복하는 설계 원리 9가지

1. **행동 예산(EP)이 원정의 진짜 제한** — HP가 아니라 행동 횟수. 비효율이 즉시 처벌된다
2. **피해 타입 8종이 각각 다른 전술 도구** — 저항 가위바위보가 아니라 고유 부가 효과
3. **Direct / Non-direct 게이트** — 반사·도트가 아이템 효과를 못 굴리게 막아 연쇄 폭발 차단
4. **개체 희귀도 = 성장 속도이지 상한이 아니다** — 등급 구간이 서로 겹친다
5. **유니크를 손으로 안 만든다** — "고유 패시브가 붙은 최상급 굴림"(Star)으로 절차 생성
6. **3개 → 1개 합성이 전부의 뼈대** — 장비도 젬도. 양이 곧 질이라 대량생산이 성립
7. **재화를 활동별로 분리** — 던전만 돌면 스킬을 못 올린다. 특히 **스킬 성장의 병목을 전투 밖(탐험)에** 뒀다
8. **세트를 장비가 아니라 젬·목걸이에** — 장비 교체 자유도를 안 깎는다. **목걸이 세트는 파티 단위**
9. **자동화를 칭호 단계로 배급** — 편해지는 것 자체가 진행 보상

## 10. 검토 후보 (기획 판단 필요, **미반영**)

Lootun 조사분과 합쳐 우선순위를 다시 매긴다. **★는 두 참고작이 독립적으로 같은 결론에 도달한 것** — 신뢰도가 높다.

|---|---|---|---|
