# 드래곤네스트 — 크루세이더(Crusader)

**컨셉/역할**: 클레릭 → 팔라딘의 2차 전직 중 하나 — 같은 팔라딘 2차 전직인 가디언이 전문 탱커라면, 크루세이더는 방어보단 순간 폭딜에 특화된 딜러형 성기사. 아바타와 연계한 「저지스파워」로 순간적으로 물리·마법 공격력을 모두 끌어올리는 것이 정체성.

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 저지스파워 | Crusader's Zeal | 일정 시간 힘 수치의 일정 비율만큼 마법공격력을, 지능 수치의 일정 비율만큼 물리공격력을 올리는 버프 |
| 저지먼트 해머 | Judgement Hammer | 정면의 적을 관통하며 날아가는 동안 점점 커지는 망치를 던지는 빛속성 공격, 커질수록 공격력과 슈퍼아머 파괴력이 늘어난다 |
| 매지컬 브레스 | | 빛속성 공격이 적에게 명중하면 일정 시간 무기공격력이 오르고 스마이트 계열 스킬의 재사용 대기시간이 줄어드는 패시브 |
| 홀리 크로스 EX | Goddess Relic EX | (팔라딘의 홀리크로스를 강화) 공격 범위와 공격력을 올려주는 패시브 |
| 세크레드 해머링 EX | Sacred Hammering EX | (팔라딘의 세크레드 해머링을 강화) 망치 개수는 줄어드는 대신 망치를 전방으로 날려보내고 개당 공격력을 올려주는 패시브 |
| 라이트닝 차져 EX | Charitable Zap EX | (팔라딘의 라이트닝 차져를 강화) 공격 범위를 넓히고 맞힐 수 있는 적의 수·공격력을 올려주는 패시브 |
| 스마이트 EX | Electric Smite | (팔라딘의 스마이트를 강화) 공격 범위를 넓히고 번개가 사방으로 퍼져나가게 만드는 패시브 |
| 저지먼트 해머 EX | Judgement Hammer EX | 저지먼트 해머를 강화해, 적에게 날아간 망치가 다시 돌아오며 또 한 번 피해를 주게 만드는 패시브 |
