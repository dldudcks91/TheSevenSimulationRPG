# 드래곤네스트 — 가디언(Guardian)

**컨셉/역할**: 클레릭 → 팔라딘의 2차 전직 중 하나 — 크루세이더가 딜러형이라면, 가디언은 방어 행동을 쌓아 강력한 보호막과 반격으로 버티는 전문 탱커. 「가디언 버블」(방어 성공마다 쌓이는 버프)을 자원으로 쓰는 것이 정체성.

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 가디언 포스 | Divine Barrier | 가디언 버블 여러 개를 소비해 신성력을 터뜨려 주변에 피해를 주고, 근처 아군에게 피해를 흡수하는 보호막을 씌운다 |
| 저스티스 크래쉬 | Falling Angel | 공중에서 수직으로 내리꽂아 지면을 타격, 범위 내 적을 공격하고 기절시킨다 |
| 클래스 마스터리 I | | 방어 행동에 성공하면 일정 시간 물리공격력이 오르는 패시브 |
| 클래스 마스터리 II | | 가디언 포스를 쓰면 다른 스킬(윌 오브 아이언)의 재사용 대기시간이 줄어들고, 항상 받는 피해가 줄고 이동속도가 오르는 패시브 |
| 오토 블록 EX | Autoblock EX | 모든 방어 행동(오토 블록·블록·스탠스 오브 페이스)에 성공할 때마다 「가디언 버블」을 쌓는다, 버블은 힘·지능을 올려주고 일정 개수 이상 쌓이면 가디언 포스를 쓸 수 있게 해준다 |
| 스탠스 오브 페이스 EX | Stance of Faith EX | 방어 자세(스탠스 오브 페이스) 중에도 이동할 수 있게 하고 반격 범위를 넓히며, 방어에 성공하면 물리 피해도 추가로 준다 |
| 디바인 어센션 EX | Divine Ascension EX | 반격 피해가 빛속성으로 바뀌고, 반격 직후 추가타로 무적 상태에서 빛의 기운을 발사하는 공격이 붙는다 |
| 디바인 퍼니시먼트 EX | Divine Punishment EX | 디바인 퍼니시먼트가 지속되는 동안 주변에 가까이 온 적에게 지속 피해를 입힌다 |
| 저스티스 크래쉬 EX | Falling Angel EX | 공중으로 떠오르며 적을 끌어들인 뒤, 함께 바닥에 강하게 내리꽂는 강화판 |
