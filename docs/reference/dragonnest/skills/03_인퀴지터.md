# 드래곤네스트 — 인퀴지터(Inquisitor)

**컨셉/역할**: 클레릭 → 프리스트 → 세인트의 2차 전직 중 하나 — 성속성 번개(라이트닝)를 다루는 마법 딜러형 성기사. 감전 상태를 걸고 터뜨리는 연계, 그리고 각성 이후엔 「저지먼트 스피어」·「라이트닝 에너지」 같은 전용 자원을 굴리는 화력형 클래스.

## 기본 스킬

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 헤븐리 썬더스톰 | Heavenly Thunder Storm | 라이트닝 스톰이나 헤븐스 저지먼트를 쓰면 그 범위 안에 낙뢰 여러 발이 무작위로 떨어지는 추가 효과를 붙여주는 패시브 |
| 라이트닝 스톰 | Lightning Storm | 하늘로 번개를 쏘아 올려 번개구름을 소환한다, 구름이 완성되면 주기적으로 낙뢰가 떨어져 큰 피해와 감전을 준다 |
| 일렉트릭 블레스(클래스 마스터리 1) | | 감전 상태인 적을 공격하면 무속성 추가 피해를 더 주는 패시브 |
| 클래스 마스터리 2 | | 일렉트릭 데토네이션을 쓰면 빛공격력이 오르고, 헤븐스 저지먼트의 재사용 대기시간이 줄며 공격력이 크게 오르는 패시브 |
| 클래스 마스터리 3 | | 차지볼트를 강화해, 적중하면 저지먼트 스피어(각성기 자원)를 하나 채워주는 패시브 |

## 각성 스킬

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 저지먼트 스피어 | | 전방으로 심판의 창을 던져 강하게 타격하고 감전과 잔상을 남긴다, 잔상은 일렉트릭 데토네이션과 연계하면 추가 피해를 준다 |
| 익시드 라이트닝 | Exceed Lightning | 번개 기운을 모았다가 한 번에 방출, 주변 적을 추적하는 다수의 번개를 날린다 |
| 인투더 라이트닝 | Into the Lightning | 마인드 브레이커 EX의 전기 구체가 남아있을 때 퍼지나 폴링 썬더로 터뜨리면 추가 폭발 피해를 주는 연계기 |
| 퍼지 | Purge | 몸 앞에 응축된 번개를 쏘아내는 후속 연계 공격 |
| 슈퍼컨덕션 | Super Conduction | 일정 시간 빛공격력과 익시드 라이트닝의 피해를 올려주는 버프 |
| 각성 라이트닝볼트 | | 라이트닝 볼트의 공격력을 올리고, 명중 시 저지먼트 스피어의 재사용 대기시간을 채워주는 패시브 |
| 각성 일렉트릭 데토네이션 | | 일렉트릭 데토네이션 사용 시 일정 확률로 강화판이 발동하게 해주는 패시브, 감전되지 않은 적도 함께 공격한다 |
| 각성 홀리 웨이브 | | 홀리 웨이브의 공격력을 올리고 재사용 대기시간을 줄이며, 피격 상태가 아니어도 즉시 발동할 수 있게 해주는 패시브 |
| 각성 그랜드크로스 | | 그랜드크로스의 공격력을 올리고, 주력기를 쓸 때마다 쌓이는 「라이트닝 에너지」를 다 모으면 새로운 공격기(라이트닝 퓨리)로 바뀌게 해주는 패시브 |
