# 드래곤네스트 직업별 스킬 자료

나무위키의 드래곤네스트 직업 스킬 문서를 정리한 자료. 2026-09-23 세션에서 `curl.exe -L` 로 각 직업
문서(`크루세이더(드래곤네스트)` · `가디언(드래곤네스트)` · `인퀴지터(드래곤네스트)`)를 받아, 그 직업만의
전용 스킬 · EX 스킬(강화 패시브) · (인퀴지터는) 각성 스킬 · 영웅 스킬까지 표로 옮겼다.

**전직 계열**: 클레릭 → 팔라딘(1차) → 크루세이더 · 가디언(2차, 팔라딘의 갈림길) / 클레릭 → 프리스트 →
세인트(1차) → 인퀴지터 · 헤러틱(2차, 세인트의 갈림길). 세 직업 모두 1차 직업(팔라딘 · 세인트)의 기본기를
그대로 쓰고, 여기 담은 것은 2차 전직에서 새로 배우는 전용 스킬만이다 — EX 스킬 상당수는 1차 스킬을
강화하는 패시브라 설명에 원본 스킬을 괄호로 표시했다.

**라이선스**: 나무위키 문서는 CC BY-NC-SA 2.0 KR 로 배포된다. 이 폴더의 각 파일은 원문서 표현을 그대로
옮기지 않고 스킬 이름 · 영어 원본 · 효과 요약(수치 제외) 만 발췌해 표로 재구성했으며, 각 파일 첫 줄에 원문
출처를 남겼다.

## 표 읽는 법

- **영어 원본**: 나무위키 문서 제목에 병기된 스킬의 영문 명칭. 빈 칸은 위키에 영문 표기가 없던 경우다.
- **무엇을 하는가**: 나무위키의 스킬 툴팁·효과 설명 문장을 옮기되, 수치·%·재사용 대기시간 같은 기계적
  조건은 빼고 효과의 모양만 남겼다.
- 인퀴지터는 프리스트 리메이크 패치로 스킬이 여러 번 갈아엎어졌다 — 이 문서는 **현재 남아있는 스킬만**
  담았고, 패치로 삭제·대체된 구버전 스킬(쇼크 트랜지션 · 컨스크레이션 등)은 뺐다.
