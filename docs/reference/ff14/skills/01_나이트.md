# 파이널 판타지 14 — 나이트(Paladin)

**컨셉/역할**: 검·방패 콤보와 무속성 신성 마법(홀리 계열)을 섞어 쓰는 방어 역할 탱커 — 물리 콤보 사이사이 성령의 권능 등 마법 딜을 끼워 넣는 것이 이 직업의 정체성.

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 재빠른 검격 | Fast Blade | 물리 콤보의 시작 기술, 단순 공격 |
| 임전무퇴 | Fight or Flight | 일정 시간 자신의 데미지를 크게 늘리는 버프, 사용 시 꿰뚫는 검격을 쓸 수 있게 된다 |
| 폭도의 검격 | Riot Blade | 재빠른 검격에 이어지는 콤보 2타, 자신의 MP를 회복시킨다 |
| 개기식 | Total Eclipse | 자신 주위 범위 공격, 적개심을 크게 올린다 |
| 방패 가격 | Shield Bash | 공격과 동시에 대상을 기절시킨다 |
| 굳건한 의지 | Iron Will | 켜 두면 적개심 상승량이 크게 늘어나는 탱커 스탠스, 다시 쓰면 해제 |
| 방패 던지기 | Shield Lob | 원거리 공격, 적개심을 올린다 |
| 할로네의 분노 | Rage of Halone | 폭도의 검격에 이어지는 콤보 마무리 |
| 경계 | Sentinel | 일정 시간 받는 데미지를 감소시키는 생존기 |
| 파멸의 진 | Circle of Scorn | 주위 범위 공격 후 지속 피해를 남긴다 |
| 내면의 기개 | Spirits Within | 단일 대상 공격, 자신의 MP를 회복시킨다 |
| 방벽 | Sheltron | 자원(충의)을 소비해 짧은 시간 받는 데미지를 감소시킨다 |
| 홍염 | Prominence | 개기식에 이어지는 범위 공격 콤보, 성공 시 다음 홀리 계열 마법이 강화된다 |
| 감싸기 | Cover | 지정한 파티원이 받는 공격을 대신 받아준다 |
| 천하무적 | Hallowed Ground | 정해진 시간 동안 대부분의 피해를 완전히 무효화하는 궁극 생존기 |
| 방패 각성 | Bulwark | 일정 시간 방패 막기를 확정으로 발동시킨다 |
| 꿰뚫는 검격 | Goring Blade | 임전무퇴 상태에서 쓸 수 있는 강력한 단발 공격 |
| 신성한 보호막 | Divine Veil | 자신과 주위 파티원에게 피해를 흡수하는 보호막을 두른다 |
| 관용 | Clemency | 대상의 HP를 회복시키고, 파티원 대상이면 자신도 절반만큼 회복한다 |
| 제왕의 권위 | Royal Authority | 콤보 마무리 물리 공격, 성공 시 다음 홀리 스피릿/서클을 즉시 시전 가능하게 강화한다 |
| 중재 | Intervention | 파티원 1명이 받는 데미지를 줄이고 지속 회복을 걸어준다 |
| 성령의 권능 | Holy Spirit | 무속성 마법 공격, 사용 시 자신의 HP를 회복시킨다(원문: 홀리 스피릿) |
| 개입 | Intervene | 대상에게 빠르게 접근하며 공격하는 돌진기 |
| 안식 기도 | Requiescat | 일정 시간 마법을 시전 시간 없이 쓸 수 있게 하고, 홀리 계열·고백 기도 콤보의 위력을 올리는 버프(원문: 레퀴에스캇) |
| 결연한 수호자 | Passage of Arms | 이동을 멈추는 대신 방패 막기가 확정 발동되고 후방 파티원의 피해도 줄여준다 |
| 신성한 원 | Holy Circle | 자신 주위 범위 무속성 마법 공격, 사용 시 HP를 회복시킨다(원문: 홀리 서클) |
| 회한의 검 | Atonement | 콤보 조건 충족 시 쓸 수 있는 물리 공격, MP를 회복시킨다 |
| 염원의 검 | Supplication | 회한의 검에 이어지는 콤보 2타 |
| 장송의 검 | Sepulchre | 염원의 검에 이어지는 콤보 마무리 |
| 고백 기도 | Confiteor | 안식 기도 상태에서 쓸 수 있는 강력한 범위 무속성 마법 공격, HP를 회복시킨다(원문: 컨피테오르) |
| 신성한 방벽 | Holy Sheltron | 방벽의 상위 기술, 피해 감소와 지속 회복을 함께 건다 |
| 속죄 | Expiacion | 내면의 기개의 상위 기술, 범위 공격으로 확장되고 MP를 회복시킨다 |
| 신의의 검 | Blade of Faith | 고백 기도에 이어지는 콤보 2타, 범위 무속성 마법 공격 |
| 진실의 검 | Blade of Truth | 신의의 검에 이어지는 콤보 3타 |
| 용맹의 검 | Blade of Valor | 진실의 검에 이어지는 콤보 4타, 성공 시 명예의 검을 쓸 수 있다 |
| 극한 방어 | Guardian | 경계의 상위 기술, 피해 감소와 함께 보호막을 두른다 |
| 제왕의 명령 | Imperator | 안식 기도의 상위 기술, 범위 공격이 되고 사거리가 늘어난다 |
| 명예의 검 | Blade of Honor | 고백 기도 콤보의 최종 마무리, 글로벌 쿨다운 없이 즉시 발동하는 강력한 범위 마법 공격 |
