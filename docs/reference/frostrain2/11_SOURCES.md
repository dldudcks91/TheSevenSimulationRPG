새 패치가 나오면 최신 기준일만 바꾸지 말고 영향받은 규칙의 이전 값·변경 값·공식 링크를 추가한다. 직접 검증한 항목은 Q 번호와 빌드·난이도·재현 조건을 남긴다. 검증 없이 미확인 꼬리표를 지우지 않는다. 서부 기획에서 채택한 규칙은 이 연구 문서를 수정해 합의된 것처럼 만들지 말고 별도 기획 문서에 결정과 근거를 남긴다.
