## 문서의 표시 방법

- **공식 확인**: 상점 설명, 실제 공개된 패치 공지에 적힌 내용. 개발자 서신의 예정 사항은 별도로 표시한다.
- **화면 관찰**: 공식 스크린샷 또는 공개 플레이 영상의 특정 프레임에서 보인 내용. 영상 업로드 날짜와 게임 빌드는 구분한다.
- **해석**: 확인한 기능에서 도출한 설계 분석. 개발자의 발언처럼 쓰지 않는다.
- **제안**: 우리가 만들 게임에 적용할 수 있는 가설. 아직 사용자와 합의한 규칙이 아니다.
- **미확인**: 실행 파일·코드·직접 플레이로 검증하지 못한 규칙이나 수치.

**직접 게임을 실행하거나 조작하지 않았다.** 공개 영상은 일정 간격의 프레임과 필요한 장면을 추가 추출해 관찰했다. 연속 시청, 음향 청취, 모든 차장 클리어를 했다고 간주하면 안 된다. 특히 화면이 없는 내부 계산 순서와 확률 분포는 추정 공식으로 확정하지 않았다.

## 이 자료로 할 수 있는 일

먼저 01~06으로 원작의 규칙 관계를 이해하고, 10의 화면과 11의 공식 공지로 근거를 확인한다. 그 뒤 08의 제작 비용과 09의 실험안을 이용해 작은 프로토타입을 정할 수 있다. 개별 수치의 그대로 복제, 전체 콘텐츠 규모의 추산, 최신 빌드의 완전한 공략 작성에는 별도 직접 검증이 필요하다.
