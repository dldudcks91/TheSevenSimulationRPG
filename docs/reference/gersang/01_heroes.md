## 0. 조사 방법과 신뢰도

출처 표기와 신뢰도는 [00_overview.md §0](00_overview.md) 과 같다. 이 문서의 1차 출처는 **거상짱의 유닛별 페이지 원문**(스킬 · 전직 조건 · 재료)과 **나무위키 하위 문서 원문**(전투방식 · 주인공 캐릭터 · 전설 장수 · 환수계 몬스터 · 캐시 아이템)이고, 에펨코리아 2025~2026 가이드로 최신 규칙을 교차 확인했다. 스킬 개수(§7)는 검색 요약으로 판정하지 않고 **단계마다 대표 유닛 페이지를 열어 셌다**.

### 0-1. 「용병 최대 11명」 vs 「기본 3 → 최대 8」 — 서로 다른 한도였다

1차 조사에서 두 수치가 부딪혔다. 원문 확인 결과 **둘 다 맞고 가리키는 것이 다르다**:

- **12** — 전투에 동시에 세우는 절대 칸 수(주인공 포함, 불변). 주인공을 빼면 **11**[나무위키 전투방식][커뮤니티 에펨 「용병 최대 고용수 11? 12?」]
- **3 → 8** — 그중 **장수**(중복 불가 고유 인물)를 동시에 몇 명 두는가. 손자병법(유료)으로 늘린다[나무위키 캐시 아이템]
- 나머지 칸은 같은 종류를 여러 명 둘 수 있는 **일반 용병 · 몬스터**로 채운다

## 1. 구조 한 장

```
전투 칸 12 = 주인공 1 (1번 칸 고정) + 11
 ├─ 일반 용병 · 포획 몬스터 ── 같은 종류 중복 가능
 ├─ 장수 ── 고유 인물 · 1명씩만 · 동시 3명 → 손자병법으로 최대 8명
 │    용병 → 1차 장수 → 2차 장수(100레벨)
 │         → 개조 또는 각성 (총 능력치 +20%)
 │         → 전설 장수 (개조 · 각성 장수 4명 합성 · 1~3세대 × 5속성)
 └─ 특수 유닛 ── 장수 계보와 무관한 병렬 최상위 갈래
      환수(신용 95) ─ 서로 다른 환수 석상 3 ─→ 신수 4: 백호 · 주작 · 현무 · 청룡
      신수 석상 4종 ─→ 기린
      기린 + 신수 ─→ 사천왕 4: 지국 · 다문 · 증장 · 광목 (신용 100 · 260레벨)
      국가별 전직 몬스터 3종 합성 ─→ 흉수 4: 혼돈 · 궁기 · 도철 · 도올
```

## 2. 파티 편성 — 전투 칸 12 와 장수 한도

| 구분 | 수치 | 근거 |
|---|---|---|
| 전투 칸 | **12** (1번 주인공 고정 + 11) | [나무위키 전투방식] |
| 장수 동시 보유 · 동행 | 기본 **3** → 손자병법으로 최대 **8** (최대 5권 · 신용등급 100 요구) | [나무위키 캐시 아이템] |
| (옛 수치) | 손자병법 1개당 +1, 3개로 최대 6 | [커뮤니티 다음 카페 — 작성 시점 불명] |
| 보관 칸 (기본) | 일반 용병 5 · 1차 장수 3 · 2차 장수 2 · 몬스터 5 | [나무위키] |
| 보관 칸 확장 | 식객명부(유료)로 종류별 최대 **15** | [나무위키] |

**전투 방식** — 몬스터가 먼저 공격하지 않는다. 플레이어가 선공하면 5초 뒤 몬스터가 참전한다[나무위키 전투방식]. 스킬마다 「자동」 · 「수동」 발동이 따로 정해져 있다(§7-4).

## 3. 주인공 — 5개국 × 남녀

| 국가 | 남 | 여 |
|---|---|---|
| 조선 | 조철희 (사냥꾼) | 이명화 (대상인) |
| 일본 | 시마다 료 (사무라이) | 겐노 하나히네 (무녀) |
| 중국 | 당호엽 (무술가) | 노수연 (신녀) |
| 대만 | 왕소룡 (도인) | 왕미령 (야수소환사) |
| 인도 | 카르나 (무투가) | 라니아 (악사) |

[나무위키 주인공 캐릭터]

- **시작은 4개국만.** 인도는 유료 「직업서」로만 전환한다
- **인물별 고유 기능** — 조선 여자(이명화)는 「상재」(취급하지 않는 품목 판매가 최대 +30%) · 필드 전용 「순간이동」(좌표 3개 저장 · 100만 냥 수수료) → 무역용 부캐로 선호된다
- **레벨** — 전투 레벨(상한 260)과 교역 레벨이 따로 오른다. 전투 레벨 상한은 200 → 250 → 260 으로 올라왔고, 260 확장에는 2차 전직 + 250 달성 + 영웅의 영혼석 50 · 생명의 비약 1 · 각성석 조각 20 이 든다
- **전직** — 150레벨 1차 전직(국가별 직업 2개 중 택1) → 2021-01 부터 2차 전직(국가별 속성: 조선 불 · 일본 물 · 중국 바람 · 대만 번개 · 인도 땅)
- **특성 포인트** — 레벨 20마다 1, 200레벨까지 16. 기존 스킬 수치만 올린다(§7-4)

## 4. 국가 — 편성의 최상위 갈림길

| 국가 | 경향 |
|---|---|
| 조선 | 교역 친화 · 초보 추천이 많다 |
| 일본 | 음양사 · 낭인 계열 |
| 중국 | 저항 감소형이 많다 |
| 대만 | 광역 스킬(예: 각성 뇌공의 맵 전체 기절) |
| 인도 | 다른 4개국의 100레벨+ 용병을 인도 특정 지역에서 **변환**해 만든다 |

- **자국 전용** — 조선 · 일본 · 중국 · 대만 용병은 자기 나라에서만 고용 · 전직한다. **국가를 고르면 키울 수 있는 용병 목록이 정해진다**
- **귀화의 서약**(유료 · 약 1.5만 원) — 주인공 국적을 바꾸고, 그에 따라 키울 수 있는 용병 목록도 바뀐다
- **거래 예외** — 다른 나라 일반 용병을 유저 간 거래로 살 수는 있지만 전직시킬 수 없다

## 5. 장수 성장 단계 — 용병에서 전설 장수까지

| 단계 | 어디서 | 조건 |
|---|---|---|
| 용병 고용 | 각국 주막 | 신용등급 · 레벨 조건 + 고용비(수천~수만 냥) |
| 1차 장수 | 자국 전직 NPC | 직업별 레벨 조건(예: 염력사 80+) |
| 2차 장수 | 전직 NPC | 1차 최고 레벨 + 봉서 등 |
| **개조** | 기술공 용하 (조선 영광 「시간의 소용돌이」) | 2차 100레벨 + 개조 재료 20 |
| **각성** | 공동묘지 관리인 (한양 영혼의 숲) | 2차 100레벨 + 영웅의 영혼석 20 + 각성석 1 |
| **전설 장수** | 도사 박영감 (저잣거리 비밀 저택) | 개조 · 각성 장수 **4명** + 영혼이 봉인된 호리병(선조 영혼석 20 · 호리병 20 · 봉인의 서 1 · 3000만 냥) + 영웅의 영혼석(1세대 100 / 2~3세대 150) + 속성석 · 정기의 구슬 · 정령석 |

[나무위키 전설 장수][거상짱]

- **개조 · 각성 = 변화 전 총 능력치 +20%**, 국적 제한 없음. 확률 표기가 없어 **확정 성공**으로 보인다[추정]
- **합성하면 재료 장수 4명은 사라진다.** 합성 전 장비를 전부 벗겨야 한다
- 2026 1분기 **가호**(용병 강화 최대 30단계)가 추가됐다 — 상한을 더 올리지 않고 기존 유닛에 강화 층을 얹는 방향

### 5-1. 합성 예시

| 1세대 신궁 주몽 (번개) | 대장군 김유신 · 개량 화룡차 · 개량 불랑기포 · 각성 도라노스케 |

## 7. 스킬 구조 — 영웅마다 1개 고정인가

### 7-1. 판정

**아니다.** 스킬 수는 **단계마다 0~3개**이고 같은 단계 안에서도 유닛마다 다르다. 다만 **어떤 스킬을 갖는지는 유닛에 고정**이다 — 플레이어가 고르거나 바꾸지 않는다. 전직 · 각성 · 진화 때 그 묶음이 **교체**되거나 일부만 바뀐다. 「정확히 1개」에 가장 가까운 것은 **전차류 개조 장수 9종**(전부 1개)뿐이다.

### 7-2. 단계별 표

| 단계 | 액티브 | 패시브 | 전직 때 | 근거 |
|---|---|---|---|---|
| 일반 용병 | 0~1 | 0 | 장수 스킬로 완전 교체 | [거상짱 조선 용병] |
| 1차 장수 | 1~2 | 0~1 | 2차 전직 때 교체[추정] | [거상짱 제갈공명 · 축융 · 유성룡] |
| 2차 장수 (각성 전) | 1~2 | 0~1 | 각성 때 일부 교체 | [거상짱 서산대사] |
| 각성 장수 | 1~3 | — | 주 공격 스킬만 교체 · 나머지 유지 — 유닛마다 다름 | [거상짱 2차 장수 각성] |
| 전차류 개조 장수 | **1** | 0 | 개조하면 전용 스킬 1 | [거상짱 개조 장수 스킬] |
| 전설 장수 | 2 (고유 + 계승) | 1 (100레벨+) | 계승을 마치면 액티브 2번째가 **추가** | [나무위키 전설 장수] |
| 신수 · 사천왕 | 2 (마법 + 무기) | 0 | 환수 → 신수 → 사천왕 진화마다 **전부 교체** | [나무위키 환수계 몬스터] |
| 흉수 | 2 (고유 + 무기) | 0 | 각성 때 고유 스킬만 교체 · 무기 스킬 유지 | [거상짱 혼돈 · 사흉수] |
| 주인공 (전직 후) | 2 (고유 + 전용 무기) | 0 | 2차 전직 때 새 스킬 2개로 교체 | [거상짱 전직 본캐 스킬] |

### 7-3. 원문으로 센 예시

| 유닛 | 스킬 | 개수 |
|---|---|---|
| 조선 짐꾼 (일반 용병) | 무게(패시브 · 힘의 4배) | 1 |
| 창잡이 (일반 용병) | 스킬 없음 · 무기 기술만 | 0 |
| 제갈공명 (1차 장수) | 지혜(패시브 · 파티 마나 회복) · 번개술(마나 40) · 회복(마나 1당 체력 6) | 3 |
| 서산대사 (2차 → 각성) | 뇌격진 + 회복술 → **연뇌격** + 회복술 | 2 → 2 (1개 교체) |
| 각성 장수 24명 전체 | 동방은아 · 뇌공 1개 ~ 아즈미 3개 | 1~3 |
| 개조 거북차 · 개조 뇌전차 | 공중탄 / 강화굉뇌 | 1 |
| 신궁 주몽 (전설) | 뇌전탄(고유 · 마나 100) + 천뇌낙하(계승 · 마나 200) + 격려(패시브 · 100레벨+) | 3 |
| 백호 · 청룡 (신수) | 마법 스킬 1 + 무기 스킬 1 | 2 |
| 혼돈 (흉수) | 고통의 가시 + 혼돈의 광기 → 각성 후 **전격의 가시** + 혼돈의 광기 | 2 → 2 (1개 교체) |
| 조선 사냥꾼 (주인공) | 함정(고유) + 연사(전용 무기) | 2 |
| 중국 무술가 (주인공) | 진각(고유) + 무기막기(전용 무기) | 2 |

### 7-4. 스킬 개수에 넣지 않는 것 · 사용 방식

- **조합 스킬** — 유닛 고유 스킬과 완전히 별개. 특정 장수 둘을 함께 편성하면 생기고 **F1~F4 로 직접 쓴다**. 주인공과 같은 국적 장수끼리만 되고 전설 장수는 예외[거상짱 조합 스킬]
- **특성 포인트** — 주인공이 레벨 20마다 1(200레벨까지 16) 받아 **기존 스킬 수치만** 올린다. 새 스킬 선택은 없다
- **사용 방식** — 스킬마다 「자동」/「수동」이 따로 붙는다(축융 포박술 = 수동 · 마비 = 자동). 흔한 재사용 대기시간 대신 **마나 소모 + 발동 확률**(예: 일격필살 20%)로 조절하는 구조로 보인다[거상짱 용병 스킬]

### 7-5. 조합 스킬 예시

| 조합 | 필요한 짝 | 효과 |
|---|---|---|
| 정화 | 초선 + 각성 동방은아 | 총 능력치 비례 체력 회복 + 상태이상 제거 (15초) |
| 견고한 방패 | 주몽 + 각성 서산대사 | 아군 전체 물리 저항 상승 (30초) |
| 차단의 방패 | 맹획 + 각성 크라슈미 | 아군 전체 마법 저항 상승 (30초) |
| 불새 소환 | 뇌전차 + 거북차 외 | 광역 딜 (15초) |
| 휴전부 | 각성 시호 + 각성 오행기 | 적 전체 이동 불가 (30초) |

역할군은 공식 용어가 없다. 커뮤니티는 근접 광역 · 원거리 · 힐러(나라마다 1종) · 약화형으로 부른다.

### 7-6. 정리 (해석)

거상에서 **스킬 선택은 「어떤 영웅을 편성하느냐」로 이뤄진다.** 영웅은 정해진 스킬 0~3개의 묶음이고, 성장은 그 묶음을 전직으로 **바꾸거나** 수치를 올리는 것이다. 다양성은 편성과 조합 스킬 짝에서 나온다.

## 8. 능력치

| 축 | 연동 |
|---|---|
| 힘 | 소지 무게 · 공격력 |
| 민첩 | 치명타 (1000당 2%) |
| 생명력 | 체력 (1당 +4) |
| 지력 | 마나 (1당 +4) |

초기값 힘 15 · 민첩 15 · 생명 15 · 지력 5 + 보너스 포인트를 직접 나눈다. 개조 · 각성의 +20% 가 누적되므로 **상위 단계일수록 기본 능력치 자체가 오른다**.

## 9. 과금 지점 — 뽑기가 아니라 「한도 · 전환 · 재료」

| 지점 | 품목 | 가격 |
|---|---|---|
| 장수 동시 보유 한도 | 손자병법 (최대 5권) | 권당 24,000원 |
| 보관 칸 | 식객명부 | 6,000~12,000원 |
| 국적 전환 | 귀화의 서약 | 15,000원 |
| 인도 전직 | 직업서 | 15,000원 |
| 전직 초기화 | 환생의 서 | 20,000원 |
| 장수 동행 + 능력치 | 백의종군 (+ 손자병법 패키지) | 7,000원 / 패키지 28,000원 |
| 유료 신수 재료 | 봉인의 돌 · 봉인의 서 | 누적 약 55만 원 |

**장수 · 신수를 확률로 뽑는 상품은 확인되지 않았다.** 돈은 편성 폭(한도)과 제작 시간(재료)에 쓰인다.
