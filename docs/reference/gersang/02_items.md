## 0. 조사 방법과 신뢰도

출처 표기와 신뢰도는 [00_overview.md §0](00_overview.md) 과 같다. 1차 출처는 **나무위키 하위 문서 원문**(아이템 강화 · 캐시 아이템 · 레어방어구 · 전용장비 · 문제점) · **거상짱**(아이템 인덱스 · 세트 효과 · 좌판 · 마사무네 · 강화) · **에펨코리아**(225제 템세팅 · 2026 신규/복귀 가이드)다. 공식 홈페이지 캐시샵은 직접 열지 못했다. 세대표(§3)는 나무위키 「레어방어구」 단일 출처 기준이다.

## 1. 분류 한 장

```
아이템
├─ 장비
│   ├─ 무기 1 ─ 근거리 / 중거리 / 원거리 · 낡은 → 일반 → 고급 (+ 레어 라인)
│   ├─ 방어구 5 ─ 투구 · 갑옷 · 요대 · 신발 · 장갑
│   ├─ 반지 2 ─ 두 개를 같이 껴야 세트의 「1부위」
│   ├─ 장신구 ─ 목걸이 · 귀걸이 (세공사만 만듦)
│   ├─ 주인공 전용 ─ 수호부 · 신수부
│   └─ 2차 장수 전용 ─ 봉인 아이템
├─ 소모품 ─ 회복약 · 단약(기간제 자동 회복) · 능력치 버프(천하장사류) · 경험치 버프
├─ 교역품(상재 물품) ─ 마을 간 시세 차익용 · 일부는 제작 재료
├─ 생산품 ─ 농장 · 목장 · 공장 · 무기장 · 갑주장 산출물(환수 명패 · 무기 등)
├─ 퀘스트 · 기능성 ─ 거래 불가 225레벨 풀세트 · 장건상자 · 각종 비법책
└─ 유료 ─ 소모형(국적 · 성별 · 이름 변경) · 장착형(수호부 · 이동속도) · 기간제 버프
```

## 2. 장비 칸

| 칸 | 수 | 내용 |
|---|---|---|
| 무기 | 1 | 근거리(도검 · 도끼 · 창극 · 조도 · 차크람) / 중거리(인형 · 지팡이 · 표창 · 염주 · 부채) / 원거리(활 · 조총 · 석궁 · 화포). 직업별 착용 제한 |
| 방어구 | 5 | 투구 · 갑옷 · 요대 · 신발 · 장갑 |
| 반지 | 2 | 두 개를 같이 껴야 세트의 「1부위」로 인정 |
| 장신구 | — | 목걸이 · 귀걸이(반고의 시리즈 · 세공사 전용 제작) |
| 주인공 전용 | — | 수호부 · 신수부 |
| 2차 장수 전용 | — | 봉인 아이템 — 주인공과 칸 체계가 다르다 |

- 6부위 세트는 **방어구 5 + 반지 한 쌍 1** 로 보인다[추정]
- ⚠ 용병 · 장수의 칸 전체 목록(주인공과 몇 칸이 다른지)은 미확인

## 3. 등급 · 세대 — 레벨대마다 세트가 바뀐다

무기는 **낡은 → 일반 → 고급** 3단계(착용 레벨 3 간격)이고, 그 위에 레벨대별로 이름 붙은 「레어」 세트 라인이 얹힌다.

| 레벨 | 세트 | 특징 |
|---|---|---|
| 70 | 비호 | 2부위 세트 |
| 90 | 대흑천 | 주인공 전용 |
| 140 / 160 / 180 | 해왕 · 봉황 / 악령 · 두이 / 황금수은 | 레벨업 구간 |
| 200 | 태황 | 균형형 · 6부위 세트 효과 |
| 210 | 파멸자 · 수라 · 미트라 · 사령 | **능력치 특화 4계열** |
| 215~220 | 공명 · 신수 4세트(청룡 · 백호 · 주작 · 현무) | |
| 225 | 천라 · 치우천왕 · 아마테라스 · 황제 · 바투 | **능력치 특화 5계열** — 225레벨 구간의 핵심 |
| 235 | 사천왕(지국 · 광목 · 증장 · 다문천왕) | 6부위를 채우면 속성값도 상승 |
| 245 | 명왕(군다리 · 금강야차 · 항삼세 · 대위덕) | |
| 250 | 각성 사천왕 | 2026 최신 최종 장비 |

[나무위키 레어방어구]

- **같은 레벨대 안에 특화 계열 선택지가 있다**(210 · 225) — 수직 교체 안의 수평 선택
- **세트 효과는 부위 수에 따라 쌓인다** — 태황 예: 3부위 지력 +50 → 5부위 힘 +100 → 6부위 힘 +150
- **전용 장비** — 개조 장수 7종 · 각성 장수 3종 전용, 150레벨 고정. 진화한 뒤 +5 까지 더 강화한다[나무위키 전용장비]
- ⚠ 215~220 방어구 세트 「공명」과 2026 1분기 무기 강화 시스템 「공명」([01_heroes.md §11](01_heroes.md))은 이름이 겹친다 — 같은 것인지 미확정

## 5. 강화 체계 — 위험도 계단

| 단계 | 어디서 | 재료 | 결과 · 실패하면 |
|---|---|---|---|
| 무기 가공 (낡은 → 일반 → 고급) | 마사무네 (일본 다카야마) | 무기 자체 | **무기가 부서질 수 있다** |
| 재료 제련 | 마사무네 | 하위 재료 10~20 + 10만~200만 냥 | 정수 · 결정 · 각성석 · 속성석 등 **재료를 상위로** 바꾼다(장비 강화가 아니다) |
| **주술 강화** | 국가별 전용 NPC | 주술 비법책(1~4등급 · 청 → 녹 → 적 → 황) + 정기의 돌 등 | 대성공 / 성공 / 실패(「쓸모없는 이상한 아이템」으로 변함) / 대실패(아무것도 못 얻음). NPC 에 최대 1억 냥 기부 시 성공률 +5%p. 최근 「형상복원가루」로 아이템이 사라지는 것을 막을 수 있게 됐다 |
| **세공** (홈 뚫기 + 보석) | 대장장이(철제 죔쇄로 홈) → 세공사(보석 제작) | 주술을 마친 장비에만 | 실패해도 **장비는 남고** 재료만 잃는다 |
| 장신구 강화 | 세공사 | 시간의 가루(레벨 비례) | +5 까지 · +5 두 개를 끼면 세트 효과 |
| 전용 장비 진화 | 용하(개조) · 공동묘지 관리인(각성) | 64 · 73레벨 고급 무기 + 비호 갑옷 · 투구(+5) + 시간의 가루 5 + 전용 재료 20 | 진화 후 +5 까지 추가 강화 |

[나무위키 아이템 강화][거상짱 마사무네][나무위키 전용장비]

**위험도가 단계로 갈린다** — 가공은 **파괴**, 주술은 **변질**, 세공은 **재료만 손실**. 플레이어가 무엇을 걸고 있는지 단계 이름만으로 읽힌다.

## 7. 거래 · 귀속 — 6세트 규칙

- **착용하면 귀속되는 거래 불가 장비가 많다.** 225레벨 세트는 거래 불가판과 거래 가능판이 부위별로 섞여 있다
- **거래 불가 장비가 한 부위라도 섞이면 6세트 효과가 사라진다** — 실질적으로 4세트 이하로 운용된다[커뮤니티 에펨 225제 템세팅]
  - 해석: 규칙 하나로 **「노력으로 얻는 기본 세트(거래 불가) / 시장에서 사 오는 상위 세트(거래 가능)」** 이중 경제가 돈다

| 거래 수단 | 조건 · 규칙 |
|---|---|
| 개인 거래 | 신용등급 6+ |
| 좌판 | 신용등급 20+ · 최대 10억 판매 · 등록비 100만~500만(가격 연동) · 낙찰 수수료 1% · 경매 3분 · 입찰마다 최저가 10% 상승 · 즉시 구매 가능 |
| 경매소 | 폐지 — 좌판이 경매 기능을 대신하는 것으로 보인다[추정] |

[거상짱 좌판][나무위키]

유닛(용병 · 장수 · 신수) 거래 규칙은 [01_heroes.md §6](01_heroes.md).

## 8. 생산 경제와의 연결

- **생산 시설** — 마을마다 농장 · 목장 · 공장 · 무기장 · 갑주장이 있고 **시설 하나에 주인은 한 명**이다. 공장은 환수 명패 · 무기를 만든다
- **장인 기술 사슬** — 광부 → 대장장이(광물) · 약초꾼 → 연금술사(재료) → 세공사(보석 재료)
- **장날** — 마을 상점 재고가 초기화되고 가격이 바뀐다(날짜는 자료가 갈린다 — [00_overview.md §10](00_overview.md))
- ⚠ **교역품이 장비 제작 재료로 쓰이는 비중은 미확인** — 거상짱에 「교역품」 카테고리는 있으나 레시피 대조를 못 했다

## 10. 교체 주기 · 과금

### 10-1. 교체 주기 — 수직 교체형

- 레벨대별 세대가 뚜렷이 바뀐다. 새 장비(예: 뇌전구슬 · 호선인형) 출시로 **옛 장비 가치가 급락**하는 패턴과 엔드게임 필수 요소의 비용이 계속 오르는 인플레이션이 지적된다[나무위키 문제점]
- **옛 장비 재활용은 제한적** — 전용 장비 진화에 고급 무기를 넣는 정도. 대부분 버려지거나 거래 불가 세트의 하위 부품으로 밀린다[부분 추정]
- 개발사는 **장건상자**를 인플레이션 대책으로 도입했다 — 다만 이 상자가 유료성인지 게임 재화성인지 문서마다 서술이 갈린다

### 10-2. 과금 지점

| 지점 | 품목 | 가격 · 비고 |
|---|---|---|
| 편성 폭 | 손자병법(장수 한도) | 권당 24,000원 — [01_heroes.md §9](01_heroes.md) |
| 영구 능력치 누적 | 귀화의 서약 | 15,000원 × 최대 60장 = 누적 300 능력치 · 약 90만 원 — ⚠ 단일 출처 |
| 기간제 버프 | 경험치 · 이동속도 · 능력치 배율 | §9 |
| 확률 요소 | 변신주문서 꾸러미류 | 확률표 미확인 |
| 강화 보조 | 보호권류 | **유료 상점에 있는지 미확인** |

돈이 **장비 자체보다 「장비를 더 잘 쓰게 하는 구조」**(한도 · 버프 · 영구 능력치)에 걸린다.

## 11. 본작 대조

| # | 거상 | 본작과의 관계 |
|---|---|---|
| 1 | **위험도 계단** — 가공(파괴) · 주술(변질) · 세공(재료만) | 통제성 — 잃을 수 있는 크기를 단계로 읽는다. 참고 |
| 2 | **거래 불가 1부위가 섞이면 6세트 무효** | 규칙 하나로 이중 경제를 만든다. 참고 |
| 3 | **경험치 → 장비 교환** | 드랍 운과 별개로 플레이 시간이 확정 경로로 장비가 된다. 참고 |
| 4 | 레벨대 세트 통째 교체 | ⚠ **「무한 수직 스케일링은 만들지 않는다」(09-03 확정)와 충돌** — 같은 레벨대 특화 4~5계열(수평)이 참고 대상 |
| 5 | 옛 장비가 거의 재활용되지 않는다 | 버려지는 구조 — 본작 분해 · 재료 흐름과의 대조 재료. 줄 단위 대조는 하지 않았다 |
