# 메이플스토리 — 블래스터

**컨셉/역할**: 레지스탕스 소속 — 건틀렛으로 차지·폭발 데미지를 내는 콤보형 근접 전사

| 스킬 이름 | 구분(액티브/버프/패시브/하이퍼/5차) | 무엇을 하는가 |
|---|---|---|
| 매그넘 펀치 | 액티브 | 건틀렛 리볼버의 폭발력을 이용하여 전방에 강력한 스트레이트 펀치를 내지른다. 스킬 사용 시 리볼빙 캐논이 자동으로 발동된다. 더블 팡과 버닝 브레이커로 연계가 가능하다. |
| 리볼빙 캐논 | 액티브 | 건틀렛 리볼버에 내장된 캐논을 이용하여 추가 폭발을 일으켜 피해를 준다. 단독으로는 사용할 수 없으며 일부 공격 스킬 사용 시 자동으로 발동된다. 키다운을 통해 차지 시 불릿을 수동으로 리로드한다. |
| 릴리즈 파일 벙커 | 액티브 | 축적한 실린더를 한 번에 터뜨려 파일 벙커를 꽂아 넣는다. 파일 벙커는 폭발을 수반한 충격파를 발생시킨다. |
| 더블 점프 | 액티브 | 점프 중 한번 더 도약하여 먼 거리를 이동한다. |
| 익스플로젼 무브 | 액티브 | 전방을 향해 불릿을 폭발시켜 역추진력을 얻는다. 이에 따라 반동으로 후방으로 뛰어오른다. |
| 인듀어런스 실드 | 패시브 | 적에게 공격을 당하면 끈기를 발휘하여 받은 피해에 비례해 보호막을 생성한다. 단, 보호막과 현재 HP의 합이 최대 HP를 넘을 수 없고 초과한 실드는 소멸한다. 또한 블래스터의 스킬 사용 중에는 적에게 공격 받아도 밀려나지 않는다. |
| 리볼빙 캐논 마스터리 | 패시브 | 건틀렛 리볼버를 연구하여 리볼빙 캐논에 대한 기본 소양을 익힌다. 과열된 건틀렛 리볼버로 인한 직접 공격에 당하는 상대방은 그 열로 인한 추가 타격을 입는다. |
| 더블 팡 | 액티브 | 건틀렛 리볼버의 추진력을 이용하여 전방에 강력한 2단 콤비네이션을 가한다. 스킬을 배운 뒤 매그넘 펀치 버튼을 연타해도 사용할 수 있다. 스킬을 사용하면서 리볼빙 캐논을 사용할 수 있다. |
| 더킹 | 액티브 | 적의 공격을 회피하며 전방으로 이동한다. 점프 키를 입력하여 급정지 할 수 있다. |
| 건틀렛 부스터 | 버프 | MP를 소비하여 일정 시간 동안 무기의 공격 속도를 2단계 증가시킨다. 단, 반드시 건틀렛 리볼버 계열 무기를 들었을 경우에만 발동이 가능하다. |
| 익스플로젼 스퍼트 | 액티브 | 폭발적인 화력으로 돌진한다. 일부 스킬을 제외한 다른 스킬 사용 중 사용할 수 있다. |
| 건틀렛 마스터리 | 패시브 | 건틀렛 리볼버 숙련도, 크리티컬 확률, 공격력, 최종 데미지를 증가시킨다. |
| 피지컬 트레이닝 | 패시브 | 신체 단련을 통해 영구적으로 힘과 민첩성을 증가시킨다. |
| 차지 마스터리 | 패시브 | 힘의 완급 조절을 익혀 차지 스킬의 기능을 보완한다. 추가로 영구히 데미지가 증가한다. |

| 해머 스매시 | 액티브 | 지면을 내려찍듯 강타하여 중심을 지킨다. 매그넘 펀치, 버닝 브레이커로 연계 가능하다. |
| 스웨이 | 액티브 | 적의 공격을 회피하며 후방 이동한다. 점프 키를 입력하여 급정지 할 수 있다. |
| 리프트 프레스 | 액티브 | 근처의 적을 움켜쥔 후에 전방으로 밀어내면서 끌고 간다. 밀어내는 중에 마주치는 적이 있다면 충돌하여 데미지를 받는다. 근처에 잡을 수 없는 적이 없으면 발동되지 않는다. |
| 매그넘 캐논 | 액티브 | 건틀렛 리볼버에 내장된 캐논으로 불릿을 전방으로 발사해 순수한 폭발력으로 적을 공격한다. |
| 리볼빙 캐논 업그레이드Ⅱ | 패시브 | 건틀렛 리볼버에 내장된 리볼빙 캐논의 성능을 강화한다. 리볼빙 캐논 업그레이드의 증가량을 덮어 쓴다. |
| 인듀어런스 트레이닝 | 패시브 | 수련을 통해 인듀어런스 실드를 강화한다. 추가로 영구히 최종 데미지가 증가한다. |
| 콤비네이션 트레이닝 | 패시브 | 전투에서 가장 효율적인 동선과 타격 패턴을 연구하여 능력을 증가시킨다. |
| 쇼크 웨이브 펀치 | 액티브 | 스크류 블로를 내지른다. 더킹, 스웨이, 버닝 브레이커로 연계 가능하다. 추가로 영구히 더블 팡의 데미지가 증가한다. |
| 플래시 무브 | 액티브 | 스웨이 중 가까운 적에게 순간적으로 접근하여 일격을 날린다. |

| 용사의 의지 | 액티브 | 정신을 집중하여 상태 이상으로부터 벗어난다. 사용 후 3초 동안 상태 이상 면역. 단, 일부 상태 이상 효과에는 적용되지 않고 컴뱃 오더스가 적용되지 않는다. |
| 리볼빙 캐논 업그레이드Ⅲ | 패시브 | 건틀렛 리볼버에 내장된 캐논의 성능을 최종 강화한다. 리볼빙 캐논 업그레이드Ⅱ의 증가량을 덮어쓴다. |
| 인듀어런스 트레이닝Ⅱ | 패시브 | 혹독한 정신수양을 통해 궁극의 끈기를 길러 인듀어런스 실드를 강화한다. 추가로 영구히 리프트 프레스와 매그넘 캐논의 데미지가 증가한다. |

| 어드밴스드 차지 마스터리 | 패시브 | 힘의 완급 조절을 완벽히 익혀 차지 스킬의 기능을 최적화한다. 차지 마스터리의 수치를 덮어 쓴다. 추가로 영구히 공격 시 적의 방어율을 일정량 무시하고 피격 데미지가 감소한다. |
| 콤비네이션 트레이닝Ⅱ | 패시브 | 전투에서 가장 이상적인 동선과 타격 패턴을 연구한다. 스킬 연계 속도와 최종 데미지가 증가하는 능력은 콤비네이션 트레이닝의 수치를 덮어쓴다. 추가로 공격력이 증가한다. |
