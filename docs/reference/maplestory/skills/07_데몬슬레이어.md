# 메이플스토리 — 데몬슬레이어

**컨셉/역할**: 노바 소속 — HP를 소비해 데미지를 끌어올리는 데몬 포스 시스템의 근접 딜러

| 스킬 이름 | 구분(액티브/버프/패시브/하이퍼/5차) | 무엇을 하는가 |
|---|---|---|
| 데몬 점프 | 액티브 | 마족의 날개를 이용한 여러 가지 점프 스킬을 사용할 수 있다. 더블 점프 사용 시 일부 스킬을 제외한 다른 스킬 사용 중 사용할 수 있다. 글라이드 커맨드 잠금 : 마우스 우클릭, 글라이드 커맨드 잠금 중에는 점프 중 점프키를 사용 시 더블 점프 발동 |
| 데몬스 퓨리(링크 스킬) | 링크 | 대상이 보스 몬스터일 경우, 내면에 잠재된 분노를 이끌어 내 더욱 강력한 데미지를 입히고 데몬 슬래시 사용 시 추가 포스를 흡수한다. |
| 데모닉 블러드 | 패시브 | 마족은 선천적으로 강한 의지와 압도적인 카리스마를 갖고 태어난다. |
| 데스 커스 | 패시브 | 공격 시 일정 확률로 적에게 강력한 데미지를 줄 수 있으며, |
| 아스트라 인퓨젼 | 액티브 | 에리온의 힘으로 만들어낸 아스트라 포스 실드에 깃든 루인 포스실드의 힘을 발휘한다. 보스 전투맵에서는 아스트라 인퓨전을 활성화하거나 비활성화할 수 없다. 스킬 사용 시 효과가 활성화되고 재사용 시 비활성화되는 온오프 스킬 |
| 데몬 슬래시 | 액티브 | 공격키를 연타하여 전방의 적 다수를 4번 연속 공격한다. 공격 시 대상으로부터 일정량의 포스를 흡수할 수 있다. |
| 데빌 사이더 | 액티브 | 악마의 낫을 소환하여 전방의 적 다수를 동시에 공격한다. |
| 데몬 액셀레이션 | 패시브 | 공격 속도와 힘이 증가한다. |
| 다크 어질리티 | 패시브 | 영구적으로 이동속도, 점프력, 최대 이동 속도를 증가시킨다. |
| HP증가 | 패시브 | 최대 HP가 영구적으로 증가한다. |
| 데몬 슬래시 1차 강화 | 패시브 | 데몬 슬래시의 데미지를 증가시킨다. |
| 소울 이터 | 액티브 | 전방의 적 다수를 자신의 앞으로 끌어당기며 공격한다. |
| 다크 쓰러스트 | 액티브 | 전방으로 빠르게 돌진한다. 일부 스킬을 제외한 다른 스킬 사용 중 사용할 수 있다. 추가로 공격력이 영구적으로 증가한다. |
| 데몬 트레이스 | 액티브 | 자신의 주변, 가까운 위치의 적을 추적하여 공격하며 대상을 일정 확률로 기절시킬 수 있다. 공중에서 사용할 수 있고 한 개 또는 두 개의 방향키와 함께 사용하면 순간 이동하는 방향을 결정할 수 있다. |
| 다크 리벤지 | 버프 | 일정 시간 동안 적으로부터 받는 데미지가 감소한다. 재사용 대기시간 초기화, 버프 지속시간 증가의 효과를 받지 않는다. |
| 웨폰 마스터리 | 패시브 | 한손 둔기, 한손 도끼 숙련도와 최종 데미지를 증가시킨다. |
| 피지컬 트레이닝 | 패시브 | 영구적으로 힘과 민첩성을 증가시킨다. |
| 아웃레이지 | 패시브 | 영구적으로 공격력과 크리티컬 확률을 증가시킨다. |
| 데몬 슬래시 2차 강화 | 패시브 | 데몬 슬래시의 데미지를 증가시킨다. |
| 다크 저지먼트 | 액티브 | 사방의 적 다수를 동시에 공격하여 치명적인 데미지를 준다. 추가 크리티컬 확률이 적용된다. |
| 데스 드로우 | 액티브 | 사방의 적 다수를 자신의 근방으로 끌어 당기며 데미지를 준다. 끌려온 적은 일정 시간 동안 기절상태가 된다. 일부 몬스터는 저항하여 끌려오지 않고 기절하지 않는다. |
| 블러디 레이븐 | 액티브 | 붉은 까마귀 떼를 소환하여 전방의 적 다수를 공격한 후, 자신의 HP를 회복시킨다. |
| 데모닉 브레스 | 액티브 | 포이즌 데몬의 강력한 독으로 주변의 적 다수를 동시에 공격한다. 대상은 일정 시간 동안 지속 피해를 입는다. |
| 다크 인듀어 | 패시브 | 방어력, 상태 이상 내성, 모든 속성 내성 확률을 증가시킨다. |
| 이블 토쳐 | 패시브 | 기절, 암흑, 결빙, 슬로우, 행동 불가에 걸린 적을 공격할 경우, 데미지와 크리티컬 확률이 추가 증가한다. |
| 컨센트레이션 | 패시브 | 정신 집중을 통해 능력을 향상시킨다. |
| 포스 가드 | 패시브 | 일정 확률로 적의 공격을 포스 실드로 가드한다. 가드에 성공하면 포스 게이지와 HP가 소폭 회복된다. |
| 맥스 포스 | 패시브 | 데몬 슬래시 사용 시 일정 확률로 포스를 추가 획득할 수 있게 되며, 4초마다 일정량의 포스를 자동 회복한다. |
| 데몬 슬래시 최종 강화 | 패시브 | 데몬 슬래시의 데미지를 증가시킨다. |
| 데몬 익스플로젼 | 액티브 | 어두운 기운을 끌어올린 후 폭발시켜 치명적인 데미지를 준다. 폭발 데미지는 100% 크리티컬 공격으로 적용된다. |

| 데빌 크라이 | 액티브 | 순간적으로 잠재된 힘을 방출하여 사방의 적 다수를 위협하고 강한 데미지를 준다. 위협된 대상은 경험치 획득량과 아이템 드롭 확률이 증가한다. |
| 다크 바인드 | 액티브 | 일정 확률로 주변의 적 다수를 행동 불가 상태로 만든다. 추가로 몬스터의 방어율을 일정 수준만큼 무시하는 패시브 효과가 있으며 다크 바인드의 효과는 보스에게도 동일하게 적용된다. 공격을 받은 적은 81초 동안 행동 불가 상태 이상에 저항하여 다크 바인드 및 다른 스킬로 인한 행동 불가 상태 이상에 걸리지 않는다. |
| 메타모포시스 | 버프 | 일정 시간 동안 잠재능력을 개방하여 데미지를 증가시키고 자신의 주위로 암흑 투기 2개를 빠르게 회전시켜 공격 범위 내 다수의 적을 자동으로 공격한다. 메타모포시스는 공격 반사 상태의 적을 공격해도 피해를 입지 않는다. |

| 뱀피릭 터치 | 버프 | 일정 시간 동안 적들에게 입힌 데미지의 일부를 나와 파티원의 HP로 회복시킨다. |
| 메이플 용사 | 액티브 | 마스테리아의 여신의 가호로 인해 자신의 모든 능력치가 일정 퍼센트만큼 증가한다. 스킬을 사용하면 마스테리아의 여신이 잠시 현신한다. |

| 어드밴스드 웨폰 마스터리 | 패시브 | 한손 둔기, 한손 도끼 계열 무기 숙련도를 극한까지 증가시키며, 크리티컬 데미지와 물리 공격력을 증가시킨다. |
| 하드 스킨 | 패시브 | 영구적으로 신체를 강화하여 적에게 입는 피해를 감소 시킨다. |
