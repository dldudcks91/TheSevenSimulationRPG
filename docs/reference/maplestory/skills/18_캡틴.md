# 메이플스토리 — 캡틴

**컨셉/역할**: 해적(건) 4차 전직 — 총기 사격과 바인드 계열 제어기를 함께 쓰는 원거리 딜러

| 스킬 이름 | 구분(액티브/버프/패시브/하이퍼/5차) | 무엇을 하는가 |
|---|---|---|
| 수영의 달인 | 패시브 | 수영 속도를 증가시키며, 수영 시 HP저하를 막을 수 있다. |
| 수납의 달인 | 패시브 | 장비, 소비, 설치, 기타 인벤토리를 확장한다. |
| 파이렛 블레스(링크 스킬) | 링크 | 해적 특유의 강인함을 익혀 각종 스탯이 증가하고 피격 데미지가 감소된다. 월드 내 서로 다른 모험가 해적 직업군이 존재할 경우 한 캐릭터에 최대 3번 중복해서 링크 스킬 지급이 가능하다. 스킬을 사용하면 무기, 보조 무기, 아케인 심볼, 어센틱 심볼, 펫장비를 제외한 부위에 장착된 장비의 힘과 민첩이 바뀌어 적용된다. |
| 써머솔트 킥 | 액티브 | 점프 후 뒤로 한 바퀴 회전하며 다리로 근접한 적 다수를 공격한다. 건 착용 시 사용 불가능하다. |
| 더블 파이어 | 액티브 | 적중 시 쪼개져서 주변의 적에게 폭발을 일으키는 탄환을 연속 발사한다. 건 착용 시에만 사용 가능하다. |
| 파이렛 리프 | 액티브 | 점프 중 사용하면 진행 방향으로 한 번 더 점프한다. 스킬 레벨이 증가할수록 점프 거리가 증가한다. 점프 키 로도 사용할 수 있다. |
| 대쉬 | 액티브 | 좌우 방향키 중 하나를 두 번 연타한 후 키다운하여 사용한다. 사용 중 이동속도, 점프력, 스탠스 확률이 증가되며 해당 효과는 대쉬가 종료될 때 사라진다. 버프 지속시간 증가의 효과를 받지 않지만 공중에서도 발동 시킬 수 있다. |
| 크리티컬 로어 | 패시브 | 크리티컬 확률과 크리티컬 데미지를 증가시킨다. |
| 퀵모션 | 패시브 | 이동속도, 점프력, 최대 이동속도를 영구히 증가시킨다. |
| 매그넘 샷 | 액티브 | 적들에게 탄환을 매우 빠른 속도로 발사한다. |
| 스위프트 파이어 | 액티브 | 대상에게 세 발의 탄을 연속 발사한다. |
| 서먼 크루 | 버프 | 노틸러스의 용맹한 선원을 소환한다. 소환된 선원은 자유롭게 움직이며 적을 추적하는 탄환을 발사하고 공격반사 상태의 적을 공격해도 피해를 입지 않는다. 선원은 사정거리 내 최대 HP가 가장 높은 적을 우선하여 공격한다. |
| 백스텝샷 | 액티브 | 후방으로 긴급 회피하며 총을 쏜다. |
| 윙즈 | 액티브 | 발 밑으로 사격을 한 반동으로 높이 점프한다. 공중에서는 점프력이 감소하고 1번만 사용할 수 있으며 지상에서 윙즈를 사용해 점프했다면 공중에서 사용할 수 없다. 윙즈를 사용해 점프를 한 후 스킬키를 다시 누르고 있으면 천천히 하강하며 활공하고, 키를 떼면 정상 속도로 하강한다. |
| 인피닛 불릿 | 패시브 | 불릿 소비 없이 총을 쏠 수 있고 공격력이 증가한다. 인벤토리 내 불릿 중 가장 앞에 있는 불릿의 공격력이 적용되며 불릿을 하나라도 보유하지 않으면 스킬 사용이 불가능하다. |
| 건 액셀레이션 | 패시브 | 건의 공격 속도와 민첩성이 증가한다. |
| 건 마스터리 | 패시브 | 건 숙련도, 크리티컬 확률, 총알의 개수를 증가시킨다. |
| 피지컬 트레이닝 | 패시브 | 신체 단련을 통해 영구적으로 힘과 민첩성을 증가시키고 피해를 감소시킨다. |
| 더블 배럴 샷 | 액티브 | 강력한 화기를 발사해 전방의 적 다수에게 피해를 입힌다. |
| 불릿 스매시 | 액티브 | 거대한 탄환을 발사해 적들을 밀어내고 데미지를 준다. 일부 몬스터는 저항하여 밀리지 않는다. |
| 이스케이프 샷 | 액티브 | 화약을 흩뿌리며 위험 지점을 탈출한다. 키다운 스킬을 제외한 다른 스킬 사용 중 사용할 수 있다. |
| 시즈 봄버 | 버프 | 고정형 대포를 설치하여 일정 시간 동안 주위 적들에게 무차별 포격을 하게 한다. 공격 반사 상태의 적을 공격해도 피해를 입지 않는다. 시즈 봄버는 사정거리 내 최대 HP가 가장 높은 적을 우선하여 공격한다. |
| 럭키 다이스 | 버프 | 주사위를 던져 자신의 행운을 시험한다. 주사위의 결과에 따라 일정 시간 동안 랜덤 버프를 획득할 수 있지만, 1이 나올 경우에는 버프를 획득할 수 없고 럭키 다이스의 재사용 대기시간이 감소한다. |
| 할로포인트 불릿 | 패시브 | 불릿에 흠집을 내어 파괴력이 한층 강화된 불릿을 사용한다. |
| 발키리 페이션트 | 패시브 | 발키리 특유의 끈기로 상태 이상 내성 및 속성 내성과 방어력, 스탠스, 최대 HP, MP가 영구히 증가한다. |
| 풀메탈 자켓 | 패시브 | 불릿을 철갑으로 감싸는 기술을 익혀 최종 데미지, 크리티컬 확률을 증가시키고 몬스터 방어를 일부 무시할 수 있다. |
| 어셈블 크루 | 버프 | 서먼 크루를 강화하여 두 명의 강인한 선원을 소환한다. 소환된 선원은 자유롭게 적들을 공격하며, 치명적인 상태 이상 공격에 자신을 희생하여 보호한다. 선원들은 사정거리 내 최대 HP가 가장 높은 적을 우선하여 공격한다. |
| 래피드 파이어 | 액티브 | 아주 빠른 속도로 탄을 발사한다. 스킬 키를 누르고 있으면 지속적으로 탄이 나가며 좌우로 이동할 수 있다. |
| 헤드 샷 | 액티브 | 몬스터의 머리를 맞혀 강력한 데미지로 공격한다. |
| 퍼실레이드 | 액티브 | 전방에 일제 사격을 퍼붓는다. 캡틴이 아래 방향키를 누르면서 사용하면 공격범위가 감소하지만 시전하는 동안에는 적의 어떠한 공격에도 밀려나지 않는다. |
| 퀵 드로우 | 패시브 | 공격 시 일정 확률로 다음에 사용할 헤드 샷, 스트레인지 봄, 전함 노틸러스, 데드아이의 공격력을 대폭 강화해 주는 효과를 받을 수 있다. |
| 배틀쉽 봄버 | 버프 | 노틸러스 호의 배틀쉽을 소환한다. 배틀쉽의 포탄 공격은 공격 반사 상태의 적을 공격해도 피해를 입지 않는다. SP를 투자하지 않는 스킬이며 크루 커맨더십 스킬을 익히면 사용 할 수 있다. |
| 봄바드 템페스트 | 액티브 | 노틸러스 호의 배틀쉽이 원거리 지원 폭격을 실시한다. 봄바드 템페스트는 시즈 봄버, 배틀쉽 봄버와 동시에 사용할 수 없다. |
| 컨티뉴얼 에이밍 | 액티브 | 집중 사격을 위한 표식을 남길 특수 탄환을 적에게 날린다. 사정거리 내 보스 몬스터를 우선하여 공격한다. 이후 캡틴의 모든 공격은 표식이 새겨진 적에게 집중된다. |
| 전함 노틸러스 | 액티브 | 전함 노틸러스호에 공격 명령을 내려 적 다수를 동시에 공격한다. 노틸러스는 공격 반사 상태의 적을 공격해도 피해를 입지 않는다. 함장의 위엄으로 캡틴 디그니티의 최종 데미지를 증가시킨다. |
| 파이렛 스타일 | 버프 | 죽음을 두려워하지 않는 해적의 자세를 취해 공격력과 상태 이상, 모든 속성 내성을 증가시킨다. 단, 죽음이 두렵지 않기 때문에 회피율은 감소한다. 추가로 영구히 스탠스를 증가시킨다. |
| 메이플 용사 | 액티브 | 메이플 월드의 여신의 가호로 인해 자신의 모든 능력치가 일정 퍼센트만큼 증가한다. 스킬을 사용하면 메이플 월드의 여신이 잠시 현신한다. |
| 용사의 의지 | 액티브 | 정신을 집중하여 상태 이상으로부터 벗어난다. 사용 후 3초 동안 상태 이상 면역. 단, 일부 상태 이상 효과에는 적용되지 않고 컴뱃 오더스가 적용되지 않는다. |
| 오펜스 폼 | 패시브 | 공격 태세를 갖추어 자신의 공격 스킬 적중 시마다 데미지 증가 버프를 얻는다. 추가로, 영구적으로 받는 피해가 감소한다. |
| 더블 럭키 다이스 | 패시브 | 일정 확률로 주사위 2개를 동시에 던져 자신의 행운을 시험한다. 주사위의 눈이 같을 경우에는 보다 강력한 버프 효과가 적용된다. |
| 크루 커맨더십 | 패시브 | 특유의 통솔력으로 어셈블 크루로 소환되는 선원들의 능력을 강화한다. 캡틴의 위엄으로 최대 HP와 크리티컬 데미지가 증가하며 선원 소환 시 별도의 추가 패시브 효과를 받는다. 크루 커맨더십 스킬을 익히면 배틀쉽 봄버를 사용 할 수 있다. |
| 캡틴 디그니티 | 패시브 | 캡틴의 위엄으로 총기류 무기의 숙련도와 공격력 및 최종 데미지를 증가시키고 직접 공격하는 공격 스킬이 목표에 명중 시 폭발하는 탄환을 사용하여 추가 피해를 입힐 수 있다. |
| 더블 럭키 다이스-원모어찬스 | 하이퍼 | 더블 럭키 다이스 미발동 시 일정 확률로 재사용 대기시간이 적용되지 않으며 다음에는 반드시 4 이상의 더블 럭키 다이스가 발동된다. |
| 더블 럭키 다이스-엑스트라 넘버 | 하이퍼 | 더블 럭키 다이스에 행운의 숫자 7이 추가된다. |
| 더블 럭키 다이스-인핸스 | 하이퍼 | 럭키 다이스에서 4, 5, 6이 나올 확률을 증가시킨다. |
| 래피드 파이어-리인포스 | 하이퍼 | 래피드 파이어의 데미지를 증가시킨다. |
| 래피드 파이어-애드 레인지 | 하이퍼 | 래피드 파이어의 사거리를 증가시킨다. |
| 래피드 파이어-보스 킬러 | 하이퍼 | 래피드 파이어의 보스 몬스터 공격 시 데미지를 증가시킨다. |

| 헤드 샷-보스 킬러 | 하이퍼 | 헤드 샷의 보스 몬스터 공격 시 데미지를 증가시킨다. |

| 불릿 파티 | 5차 | 모든 방향으로 총을 난사한다. 스킬 사용 중 적의 어떠한 공격에도 밀려나지 않으며 치명적인 상태 이상에 걸리지 않는다. 스킬 재사용 시 난사가 즉시 취소된다. |

| 데스 트리거 | 5차 | 적을 관통하여 죽음으로 인도하는 탄환을 발사한다. 탄환은 목표를 향해 나아가며 관통 공격을 한 후 공격할 수 있는 적 수가 남아있다면 주변의 적에게 튕기며 경로의 적을 공격한다. |
