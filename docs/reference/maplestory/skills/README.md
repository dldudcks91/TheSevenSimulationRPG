# 메이플스토리 직업별 스킬 자료

나무위키의 메이플스토리 직업 스킬 문서를 정리한 자료. 2026-09-23 세션에서 `curl.exe -L` 로 각 직업의
`<직업명>(메이플스토리)/스킬` (또는 `<직업명>/스킬`) 하위 문서를 받아, 0차(링크 스킬) · 1~4차 · 하이퍼 스킬 ·
5차(V 매트릭스 — 직업 코어만, 공용 코어·강화 코어는 제외) 구간의 스킬을 표로 옮겼다. 6차(HEXA 매트릭스) ·
삭제된 스킬 · 공용 코어는 범위 밖이라 담지 않았다.

**라이선스**: 나무위키 문서는 CC BY-NC-SA 2.0 KR 로 배포된다. 이 폴더의 각 파일은 원문서 표현을 그대로
옮기지 않고 스킬 이름 · 구분 · 효과 요약(수치 제외) 만 발췌해 표로 재구성했으며, 각 파일 첫 줄에 원문
출처 링크를 남겼다.
