## 0. 조사 방법과 신뢰도

[../poe1/00_overview.md §0](../poe1/00_overview.md#0-조사-방법과-신뢰도)와 같은 신뢰도 표기(**[공식]·[가이드]·[가이드-DB]·[검색합성]·[커뮤니티]·[추정]·N/F**)를 쓴다. **[가이드-DB]**는 이 문서군에서 새로 쓰는 등급으로, `poe2db.tw`처럼 게임 클라이언트 데이터를 직접 추출해 노출하는 커뮤니티 데이터베이스를 가리킨다(해석·요약이 아니라 원자료 노출이라는 점에서 [가이드]보다 원출처에 가깝게 취급).

**이 문서군은 poe1 문서군보다 [공식] 소스 비중이 구조적으로 낮다.** 세 가지 이유가 확인됐다:
1. `pathofexile.com/path-of-exile-2` 공식 소개 페이지가 이번 조사에서 **404**로 직접 확보 실패([01_skills.md §6-1](01_skills.md#6-출처--미확인nf-총괄))
2. 공식 패치노트 포럼이 **PoE1·PoE2 패치노트를 한 게시판에 섞어** 올린다 — 실제로 [03_masteries.md §0](03_masteries.md#0-조사-방법과-신뢰도) 조사 중 이 포럼 최상단 글이 PoE2 가 아니라 PoE1 패치 3.29.3b 였다
3. `poe2db.tw`·`poewiki.net` 양쪽 다 Anubis 봇 차단에 걸려 구조화 데이터 직접 크롤이 대부분 실패했다([02_items.md §0](02_items.md#0-조사-방법과-신뢰도)) — 검색 엔진의 요약을 경유한 항목이 poe1 대비 많다

**세 짝 문서가 각각 실제로 잡아낸 오염 사례**(이 문서군의 신뢰도를 보여주는 근거로 요약):

| 문서 | 오염 사례 |
|---|---|
| [01_skills.md §0](01_skills.md#0-조사-방법과-신뢰도) | 원본 poe1 문서가 인용한 "PoE2 액티브 젬 소켓 9개 **고정**"이 낡은 정보였다 — 실제로는 어센던시(Gemling Legionnaire)·장비로 12개+ 까지 확장 가능. **얼리 액세스 초창기 스냅샷이 굳어 인용된 사례** |
| [02_items.md §0](02_items.md#0-조사-방법과-신뢰도) | 검색 결과가 제시한 "PoE2 원소 저항 최고 티어 +41~45%/ilvl82+"가 [../poe1/02_items.md §1-2](../poe1/02_items.md#1-2-아이템-레벨ilvl이-접사-티어를-가른다)의 **PoE1 수치와 완전히 동일** — PoE1 값이 PoE2 질의에 섞여 나온 것으로 판단해 채택 안 함 |
| [03_masteries.md §0](03_masteries.md#0-조사-방법과-신뢰도) | "Path of Exile"·"Mastery"로만 검색하면 결과 다수가 PoE1(마스터리 원조, 검색량 많음)로 쏠림 — 매 인용에 원작 어휘와 패치 시점을 명시해 재검증 |

**시점 기준 — 조사 시점(2026-09-10) 최신 패치**: **0.5.5 "Forbidden Rites"**(2026-09-04 출시). 직전 대형 패치는 **0.5.0 "Return of the Ascendants"**(리그명 "Runes of Aldur", 2026-05-29 — 룬·소울코어 체계 개편, 유니크 다수 신규/귀환). **1.0 정식 출시는 2026-12-11 예정**[검색합성, 3문서 공통]. 즉 이 문서군 전체가 **얼리 액세스 마지막 3개월** 시점의 스냅샷이다.

## 1. 게임 구조 한 장 — PoE1 대비 무엇이 바뀌었는가

```
   플레이어 = 각 클래스(8종)의 모험가
   ┌──────────────────────────────────────────────────────────┐
   │ 캠페인(6막) 클리어 → 엔드게임 Waystone(구 Atlas 맵)      │
   │        ↓                                                  │
   │ 몬스터·상자·퀘스트 → [장비 드롭] + [Uncut Gem 드롭]      │
   │        ↓                    ↓                             │
   │  장비 소켓엔 룬·소울코어만  전용 "젬 메뉴"에서 커팅→장착  │
   │  (스킬과 무관한 마이크로 튜닝) (액티브 9슬롯, 확장 가능)  │
   │        ↓                                                  │
   │  전투에서 젬 사용 → 젬 자체가 경험치로 레벨업(PoE1과 동일)│
   └──────────────────────────────────────────────────────────┘

   [별도 자원] Spirit — 오라·영구 소환수·메타 젬 전용 자원, 마나와 완전 분리
   [별도 층] 캐릭터 레벨업·퀘스트 → 패시브 포인트 → 거대 트리(마스터리 없음, §4)
   [별도 층] 트라이얼 2종(Sekhemas/Chaos) 중 선택 완주 → 어센던시(8클래스, 2~3갈래)

```

## 2. 아이템 구조 (요약 — 상세는 [02_items.md](02_items.md))

- **희귀도 4단은 그대로 유지**(Normal→Magic→Rare→Unique, 명칭·순서 동일)되지만 **"기본으로 몇 접사가 뜨는가"가 달라졌다** — Rare 이론상 상한은 PoE1과 같은 3+3=6이지만, Orb of Alchemy 는 4개만 확정 부여한다([02_items.md §2-1](02_items.md#2-1-희귀도-4단--접사-개수))
- **모디파이어 티어는 T1이 최강**이라는 것은 PoE1과 동일 — 다만 "아이템 티어"(미확인 아이템·Waystone 등급, 숫자가 클수록 상급)와 이름이 같아 검색 결과에서 자주 혼동된다([02_items.md §2-2](02_items.md#2-2-접사-티어--ilvl-게이팅))
- **화폐(오브) 목록이 재편됐다** — Orb of Alteration·Orb of Scouring·Chromatic Orb 는 **폐지**, Artificer's Orb(소켓 추가)·Greater/Perfect 등급 오브(최소 티어 보장)가 **신규**([02_items.md §3-4](02_items.md#3-4-화폐오브-목록과-poe1-대비-변경점))
- **Rune·Soul Core**가 PoE1에 없던 신규 소켓형 아이템으로, 장비 종류(근접/캐스터/방어구)에 따라 같은 룬도 효과가 3갈래로 갈린다([02_items.md §3-2·3-3](02_items.md#3-2-rune-실제-예시-장비-종류에-따라-효과가-3갈래로-갈린다))
- **유니크는 "PoE1 귀환"(Headhunter·Mageblood)과 "PoE2 전용 신규"(그레네이드 런처 베이스 Redemption, 액티브 스킬을 직접 주는 Nightfall)가 섞여 있다**([02_items.md §4](02_items.md#4-유니크-아이템-실제-예시))

## 4. 마스터리 (요약 — 상세는 [03_masteries.md](03_masteries.md), 결론: 없음)

**검증 결론(c): PoE2 패시브 트리에 PoE1 식 Mastery 노드(또는 개념적 동치물)가 존재하지 않는다.** 2025년 초부터 2026-09(조사 시점)까지 최소 세 독립 시점 스냅샷이 전부 "Mastery 없음"으로 일치한다([03_masteries.md §1](03_masteries.md#1-마스터리또는-대응-시스템-존재-여부--검증-결과)).

- PoE2 패시브 트리는 **Small · Notable · Keystone · Attribute · Jewel Socket** 5종으로 구성([03_masteries.md §2-1](03_masteries.md#2-1-노드-종류-45종))
- 비슷해 보이지만 다른 시스템 — **Dual Specialization**(무기 세트별로 같은 위치의 Small/Notable을 껐다 켰다 하는 것, Keystone 제외). "위치 고정 + 온오프"이지 PoE1 마스터리의 "위치 무관 + 전역 공유 풀"과 메커니즘이 다르다([03_masteries.md §2-4](03_masteries.md#2-4-weapon-set-이중-배분dual-specialization--마스터리와-혼동-주의))
- **왜 뺐는지 직접 근거는 없다(N/F)** — 디렉터 Jonathan Rogers 의 "의무형 노드를 없애 선택을 단순화한다"는 인터뷰가 정황상 방향은 같지만, 마스터리를 직접 언급하지는 않는다([03_masteries.md §3-3](03_masteries.md#3-3-원작사가-왜-뺐을-수-있는가--직접-근거-없음-정황만))
- **이 결론은 시한부다** — 1.0 정식 출시(2026-12-11) 전후로 재도입 가능성을 배제할 근거는 없다

## 5. 본작 대조 시사점 종합

**세 짝 문서 §5(또는 §4)의 관찰 중 「같은 스튜디오의 후속작 선택」이라는 이 문서군 고유의 무게를 가진 것만 추려 종합한다. 세부 논거는 각 문서를 참조.**

| # | 관찰 | 본작 접점 |
|---|---|---|
| 1 | ★ **"무엇을 얻는가"와 "얼마나 좋은가"의 도박을 분리한 것(Uncut Gem)이 PoE1 대비 가장 뚜렷한 개선이다.** PoE1 은 완전 확률형 드롭이었지만, PoE2 는 스킬 선택을 확정하고 등급만 확률로 남겼다 | `skill_design.md` §7 이 스킬 드롭형을 검토한다면 **PoE1 식(완성품 드롭)보다 PoE2 식(재료+확정 선택)이 좌절 없는 파밍에 더 가깝다** — "잘못 찍어 영웅 하나를 버리는 일이 없어야 한다"는 본작 원칙과 정확히 같은 방향 |
| 2 | ★ **Spirit 은 "상시효과가 즉발 스킬의 자원을 깎아먹는" 긴장을 아예 다른 자원 풀로 분리해 없앤 사례다** | 본작이 보호(오프라인 상시 자동전투)와 원정(실시간 액티브 운용)을 같은 자원으로 경쟁시키는 지점이 있다면, PoE2 처럼 상시효과 전용 자원을 분리하는 안을 검토할 근거가 된다 |
| 3 | **"PoE1 식 마스터리"가 검증된 정답은 아니었을 수 있다** — 원작사 스스로 후속작에서 재도입하지 않았다(이유는 미확인이지만, 소켓 색 강제·소켓-장비 결합 폐지와 같은 "20년 묵은 마찰 장치 걷어내기" 패턴과 궤를 같이할 가능성) | 본작이 "마스터리"라는 이름을 쓰면서 PoE1(전역 공유 풀)도 PoE2(부재)도 아닌 제3의 구조(수치/반응/변형 3분류)를 택한 것은, 원류를 그대로 따를 필요도 후속작의 단순화 방향을 따를 필요도 없다는 뜻으로 읽을 수 있다 — [../poe1/00_overview.md §4 관찰10](../poe1/00_overview.md#4-본작-대조-시사점) |
| 4 | **Chaos Orb 의 동작 변경(전체 재굴림→접사 1개 교체)은 확률형 크래프팅의 "폭"을 의도적으로 좁힌 사례다.** [../poe1/02_items.md §4-1](../poe1/02_items.md#4-1-기본-화폐-오브--확률형이-대부분)의 "확률/부분결정/완전결정 3계열 병존" 원리에서, PoE2 는 가장 거친 확률 수단을 없애고 더 통제 가능한 도구로 대체했다 | 본작이 강화·재굴림을 설계할 때, "한 번에 전부 리롤"보다 **"칸 하나씩 교체"** 쪽이 플레이어의 인과 감각(기획 조언 원칙 2 — 통제성 우선)을 더 지킨다는 근거 |
| 5 | **서포트 젬이 "물건 1개=적용 1곳" 원칙에서 이탈한 것은 [../poe1/01_skills.md §1-6](../poe1/01_skills.md#1-6-리롤해도-젬은-유지된다--스킬이-곧-자산)의 "스킬=자산" 철학과 반대 방향이다** — 물건화가 항상 정답은 아니라는 반증 | `skill_design.md` §5 참고 — "여러 곳에 동시에 쓰고 싶어지는 요소"는 물건화(1개=1곳)가 오히려 마찰일 수 있다. 액티브(물건화 유지)와 보조 효과(해금화가 나을 수도)를 다르게 설계하는 것도 옵션 |
| 6 | **레어 기본 접사를 4개로 줄이고 6까지는 추가 투자를 요구하는 것**은 "완제품처럼 바로 강한 아이템"과 "투자해서 완성하는 아이템"을 분리하는 처리다 | 본작 희귀도 4단(매직→레어→크래프트→유니크) 중 레어와 크래프트 단계 사이 간격을 어떻게 벌릴지 판단할 때 참고 |
| 7 | **유니크가 액티브 스킬을 직접 부여하는 사례(Nightfall)는 본작의 "액티브는 전직 3칸뿐" 원칙(GAME_DESIGN.md §9 08-28)에 대한 참고 반례다** — 다만 그 유니크는 특정 빌드에 캐릭터를 사실상 고정시키는 강한 트레이드오프를 동반한다 | 본작이 "유니크가 액티브를 준다"는 방향을 연다면, PoE2 식으로 강한 페널티를 동반해야 원칙과의 충돌이 정당화된다 |
| 8 | **어센던시 획득이 "양자택일→선택적 혼합"(트라이얼 2종)으로 바뀐 것**은 "같은 목표에 이르는 경로를 복수로 둔다"는 원리다 | 본작 전직 갈래 택1 구조에 관문 다양화를 검토한다면, 관문 자체를 이질적인 미니게임으로 쪼개고 아무거나 골라도 같은 총점에 도달하게 하는 처리가 참고가 된다 |
