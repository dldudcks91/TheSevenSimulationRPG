# 라그나로크 온라인 — 크루세이더(Crusader)

**컨셉/역할**: 방패와 한손무기·창을 쓰는 검사 계열 2-2차 전직 — 성전사(성기사) 컨셉의 방어형 스킬이 많고, 파티원을 대신 맞아주는 지원형 탱커.

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 창 수련 | Spear Mastery | 창 사용 시 공격력이 오르고, 페코페코에 탑승한 상태면 더 오른다 |
| 라이딩 | Riding | 페코페코를 탈 수 있게 해준다, 탑승 중에는 공격속도가 느려진다 |
| 기병 수련 | Cavalier Mastery | 페코페코 탑승 중 느려진 공격속도를 되돌려준다 |
| 힐 | Heal | 대상의 체력을 회복시킨다(언데드 상대로는 피해를 준다) |
| 큐어 | Cure | 침묵·혼란·암흑 상태이상을 치료한다 |
| 디바인 프로텍션 | Divine Protection | 악마형·불사형 몬스터의 공격에 대한 방어력을 올린다 |
| 데몬베인 | Demon Bane | 악마형·불사형 몬스터를 상대로 한 공격력을 올린다 |
| 믿음 | Faith | 최대 HP를 늘리고 성속성 공격에 대한 내성을 준다 |
| 오토 가드 | Auto Guard | 방패를 낀 상태로 근거리·원거리 물리 공격을 일정 확률로 막아낸다 |
| 쉴드 챠지 | Shield Charge | 방패로 적을 후려쳐 밀어내고, 확률로 기절시킨다 |
| 쉴드 부메랑 | Shield Boomerang | 방패를 던져 멀리 있는 적을 공격한다 |
| 리플렉트 쉴드 | Reflect Shield | 근접 공격을 받으면 일정 피해를 자동으로 되돌려준다 |
| 홀리 크로스 | Holy Cross | 성속성 2연타 공격, 확률로 적에게 암흑 상태를 건다 |
| 그랜드 크로스 | Grand Cross | 자신을 중심으로 거대한 십자가 모양의 신벌을 세 번 내리는 광역 공격, 자신도 HP를 대가로 소모한다 |
| 헌신 | Devotion | 지정한 파티원 1명이 입을 피해를 전부 자신이 대신 받는다 |
| 신의 뜻 | Providence | 아군에게 악마형·성속성 공격에 대한 내성을 준다 |
| 디펜더 | Defender | 원거리 물리 피해를 크게 줄이는 대신 이동·공격 속도가 느려진다 |
| 스피어 퀴큰 | Spear Quicken | 창 사용 시 공격속도·크리티컬·회피율을 올려준다 |
| 슈링크(퀘스트 스킬) | Shrink | 오토 가드로 막아낼 때 확률로 상대를 기절시킨다 |
