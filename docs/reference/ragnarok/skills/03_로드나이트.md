# 라그나로크 온라인 — 나이트(Knight) → 로드나이트(Lord Knight)

**컨셉/역할**: 검사 계열 2-1차(나이트)·전승 2-1차(로드나이트) — 페코페코를 타고 창·양손검으로 싸우는 공격형 탱커. 크루세이더 계열보다 공격적인 컨셉.

## 나이트(2-1차) — 로드나이트가 그대로 물려받는 스킬

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 창 수련 | Spear Mastery | 창 사용 시 공격력이 오른다(크루세이더와 공용 스킬) |
| 라이딩 | Riding | 페코페코를 탈 수 있게 해준다 |
| 기병 수련 | Cavalier Mastery | 페코페코 탑승 중 느려진 공격속도를 되돌려준다 |
| 차지 어택 | Charge Attack | 멀리 있는 적에게 단숨에 접근해 공격한다, 거리가 멀수록 위력이 세지지만 시전 시간도 길어진다 |
| 원핸드 퀴큰 | One-Hand Quicken | 한손검 사용 시 공격속도를 올린다 |
| 피어스 | Pierce | 창으로 찌르는 공격, 적의 크기가 클수록 연타 횟수가 늘어난다 |
| 브랜디쉬 스피어 | Brandish Spear | 페코페코를 탄 채 창을 크게 휘둘러 전방을 공격한다 |
| 스피어 스탭 | Spear Stab | 창으로 적을 멀리 쳐내며, 자신과 대상 사이에 있는 모든 적에게 피해를 준다 |
| 스피어 부메랑 | Spear Boomerang | 창을 던져 멀리 있는 적을 공격한다(창은 소모되지 않는다) |
| 투핸드 퀴큰 | Twohand Quicken | 양손검 사용 시 공격속도를 올린다 |
| 오토 카운터 | Auto Counter | 근접한 적의 공격을 자동으로 막아내고 확정 크리티컬로 반격한다 |
| 볼링 배쉬 | Bowling Bash | 적끼리 서로 부딪치게 만들어 주변 다수를 한 번에 공격한다 |

## 로드나이트(전승 2-1차) — 새로 배우는 스킬

| 스킬 이름 | 영어 원본 | 무엇을 하는가 |
|---|---|---|
| 오라 블레이드 | Aura Blade | 무기에 오러를 둘러 방어력을 무시하는 추가 피해를 더한다 |
| 패링 | Parrying | 양손검을 든 상태에서 적의 공격을 확률로 완전히 막아낸다, 막으면 상대의 공격이 취소된다 |
| 컨센트레이션 | Concentration | 명중률과 공격력이 오르는 대신 방어력이 낮아지고, 인듀어(경직 면역) 효과가 붙는다 |
| 텐션 릴렉스 | Tension Relax | 앉은 상태에서 HP 회복 속도를 크게 끌어올린다 |
| 버서크 | Berserk | HP가 늘고 이동·공격 속도가 오르지만 회피율이 떨어지고 아이템 사용·회복 등 다른 행동이 막히며, 시간이 지날수록 HP가 줄어든다 |
| 스파이럴 피어스 | Clashing Spiral | 무기를 내뻗어 회오리 모양으로 꿰뚫는 다중 연타 공격, 무기가 무거울수록 피해가 세지고 적의 이동을 잠깐 묶는다 |
| 헤드 크러쉬 | Traumatic Blow | 강하게 타격해 확률로 적에게 출혈 상태를 건다 |
| 조인트 비트 | Vital Strike | 창을 든 상태로 적의 관절을 노려 다양한 상태이상을 건다 |
