# 라그나로크 온라인 직업별 스킬 자료

그라비티/GNJOY 공식 사이트(ro.gnjoy.com)의 「룬미드가츠 도서관」 직업·스킬 정보를 정리한 자료.
2026-09-23 세션에서 `curl.exe -L` 로 각 직업의 `jobview.asp` 페이지와, 거기 걸린 스킬마다의
`skillview.asp` 페이지를 받아 한국어 공식 스킬명과 효과 설명을 표로 옮겼다. namu.wiki 의 검사계열
문서는 스킬 표가 아니라 서술형(빌드·평가 위주)이라 이번엔 원 출처로 쓰지 않았다.

**라이선스**: (주)그라비티의 공식 게임 정보 페이지. 이 폴더의 각 파일은 원문 문장을 그대로 옮기지 않고
스킬 이름(공식 한국어 명칭) · 영어 원본(그 한국어 이름이 음차/번역된 원 단어) · 효과 요약(수치 제외)만
발췌해 표로 재구성했으며, 각 파일 첫 줄에 원문 출처 URL을 남겼다.

## 받은 날짜 · 범위

| 번호 | 파일 | 직업 | 전직 단계 |
|---|---|---|---|
| 01 | 01_크루세이더.md | 크루세이더(Crusader) | 검사 계열 2-2차 |
| 02 | 02_팔라딘.md | 팔라딘(Paladin) | 전승 2-2차(크루세이더 전승) |
| 03 | 03_로드나이트.md | 나이트(Knight) → 로드나이트(Lord Knight) | 검사 계열 2-1차 → 전승 2-1차 |

2026-09-23 세션에서 「공격적인 성기사 · 마법검 기사」 조사의 2순위로 받았다. 성법 계열(그랜드 크로스 ·
홀리 크로스 · 프레셔 · 가스펠)과 오토 카운터 · 버서크 같은 로드나이트의 공격형 스킬을 포함한다.

## 표 읽는 법

- **영어 원본**: 라그나로크 온라인은 스킬명 대부분이 영어 단어를 그대로 한글 음차한 것이라(그랜드
  크로스 = Grand Cross), 공식 한국어 이름이 곧 원본 단어를 가리킨다. 한국 게임이라 별도의 "영문 공식
  명칭"이 명시된 소스는 못 찾아, 이 음차 원어를 영어 원본 칸에 적었다.
- **무엇을 하는가**: skillview.asp 의 스킬 설명 텍스트를 옮기되, 레벨별 수치표 · SP 소모 · 캐스팅 시간
  같은 기계적 수치는 빼고 효과의 모양만 남겼다.
- 크루세이더 → 팔라딘, 나이트 → 로드나이트는 전직 관계라 하위 스킬을 그대로 물려받는다. 02 · 03 파일은
  새로 배우는 스킬만 표로 담고, 물려받는 스킬은 01 파일(크루세이더) · 03 파일 내 나이트 표를 참조하도록
  적었다.
