## 0. 조사 방법과 신뢰도

- 도메인 4개를 병렬 조사. 항목당 2~4회 검증(위키피디아·공식 SRD/룰북 전사·팬덤 위키·나무위키 설정 문서·Coppermind·Tolkien Gateway). 팬덤 위키는 402 차단이 잦아 스니펫 교차로 대체.
- 신뢰도 ★★★(위키피디아·공식·룰북 원문) / ★★(팬덤·전문 블로그·종교기관) / ★(포럼·2차 정리). 검증 못 한 것은 **[미확인]** — 특히 웹소설은 설정 오기억이 흔해 "확인 범위"를 명시했다.
- **사실 정정 2건**(신화 조사): ① **빈드룬의 "마법적 사용"은 역사적으로 입증되지 않은 현대 해석** — 룬워드의 "원형"이라 부르기엔 근거가 약하다. ② Ars Magica는 "형상 15 × 기술 5"가 아니라 **기술 5 + 형상 10 = 15 아트, 조합 50**.

## 2. 본작 세계관과 직결된 발견 5가지

### 발견 1. 바알은 고에티아 72 악마의 **1번 왕(Bael)**이다 — 두 체계의 접합점
- 『솔로몬의 작은 열쇠』 Ars Goetia 72 영 중 **1번 = 바엘, 왕, 66군단**. 계급 왕 9·공작 23·대공 7·후작 15·백작 5·기사 1·대통령 12. ★★★
- 본작 7부하(Binsfeld 1589의 7군주: 루시퍼=오만, 맘몬=탐욕, 아스모데우스=색욕, 레비아탄=시기, 베엘제붑=폭식, 사탄=분노, 벨페고르=나태)는 **고에티아 72에 없다** — 예외는 **아스모데우스(32번 왕)** 하나. 즉 "지옥의 왕 바알이 7군주 위에 있다"는 본작 설정은 **고에티아 계급 체계 / 빈스펠트 7죄 체계의 접합**으로 자연스럽게 설명되고, 색욕 챕터만 "인장 원전이 있는 악마"가 된다.
- 고에티아의 규칙 — 악마마다 **고유 인장(sigil)**, 인장을 쥔 자가 명령, 계급 = 군단 수(전력), 솔로몬은 악마를 **놋쇠 그릇에 봉인**해 보관 — 이 본작 2차 층의 어휘 공급원(§3).

### 발견 2. 본작 낙인(Stigma)은 **성흔(Stigmata)과 같은 말**이다 — 그리고 전독시 성흔과는 방향이 반대
- 그리스어 στίγμα = 찍힌 표. 1224년 아시시의 프란치스코가 최초. 몸에 새겨져 **정체성·운명을 결정하고 본인이 고를 수 없다**(카인의 표식·짐승의 표도 같은 계통). ★★★
- 한국 웹소설 최대 히트작 **전지적 독자 시점의 "성흔"**은 **배후성(성좌)에게서 빌린 힘** — "연결이 끊어진 화신은 해당 성흔을 사용할 수 없게 된다", 1 후원 : n 성흔, 후원 계약을 하면 성좌 승격 경로가 닫힌다. ★★★ 본작 낙인은 **악마를 죽여 빼앗은 힘(흡수·누적, 대가는 저주)** — 같은 이름, 반대 방향. 한국 독자는 전독시 문법(배후성·계약 해지)을 기대하므로 UI 첫 문구에서 "낙인 = 흡수"를 못 박을 필요.
- Honkai Impact 3rd의 장비 이름도 Stigmata(상/중/하 3슬롯) — 이름 충돌 주의.

### 발견 3. 강철의 연금술사 호문쿨루스 = **7죄를 떼어 그릇에 담은 조각** — 본작 서사의 빈 칸을 채우는 접합안
- "플라스크 속 난쟁이"(아버지)는 **인간적 결점 7가지(7대 죄악)를 떼어내 각각 호문쿨루스로** 만들었고, 각 호문쿨루스는 현자의 돌을 핵으로 갖는다. 죄를 뗄수록 아버지는 **무미건조**해진다(힘은 남고 인간성이 빠진다). ★★★
- 본작 바알↔7부하와 **동형이되 방향이 반대**(FMA는 스스로 떼어 담았고, 본작은 배신해 가져갔다). 접합하면: **"7부하는 원래 바알이 떼어 맡겨 둔 7죄(자기 자신의 조각)였고, 그들이 그 조각을 들고 도망쳤다" → 악마를 죽여 힘을 흡수 = 자기 조각 회수** — "왜 그 악마의 죄종 힘만 흡수되는가"에 세계관 답이 생긴다. 대가의 방향도 온다: **죄를 되찾을수록 인간 몸이 무너진다**(낙인 확장 = 챕터 진행 = 상태이상 강화) — 이미 있는 "챕터 = 죄종 = 상태이상" 축으로 표현된다.
- 같은 계열: 스쿠나의 손가락 20개(각 5%, 20개 = 100%, 손가락이 숙주를 고르고 저주를 끌어모은다), 나르실 조각(자격자가 나타났을 때만 재련), 성유물 3등급(원본 > 소유물 > 접촉물).

### 발견 4. 샌더슨의 헤말러지는 **본작 죄종×부위 매트릭스와 동형**이다
- 금속 못을 사람의 **결합점(bind point)**에 박아 속성을 훔쳐 다른 사람의 결합점에 박는다. **금속 종류 × 결합점 위치 = 훔치는 속성**(철=힘, 주석=감각, 구리=기억, 아티움=아무 능력). 충전에는 **사람이 죽는다**. 못을 몸 밖에 두면 **충전이 새어 나간다**. 못 하나만 있어도 파멸의 속삭임, **수가 늘수록 조종당한다**(심문관 9~11개). 뽑으면 힘 상실. ★★★
- "악마를 죽이면 그 죄종의 힘을 흡수하는 낙인"은 문자 그대로 헤말러지다: 죄종(7) = 금속, 부위(8) = 결합점, 흡수한 힘이 몸을 갉아먹는 것 = 파멸의 조종. 슬롯 상한을 "인간성"으로 두면 통제성이 확보된다. 스톰라이트 파브리얼(보석 × 스프렌 × 금속 우리 = 증폭/감쇠/유인/경고 모드)은 여기에 "우리 금속" 축 3~4종을 얹는 확장.

### 발견 5. "아이템의 역사를 알아야 해금"(Earthdawn) — 본작 도감(처치 수)이 그대로 해금 게이지가 된다
- Earthdawn 스레드 아이템: 어뎁트가 아이템의 **Key Knowledge**(이름·제작자·재료·출처)를 알아내야 랭크가 열리고, 홀수 랭크마다 지식 또는 **Deed**(행위)가 필요하다. "아이템의 역사가 초라하면 힘도 작다." ★★★
- 본작은 이미 **도감 = 처치 수 모델**이다. "해당 죄종 몬스터 처치 누계 → 이름 해금 → 2랭크, 챕터 보스 처치(= 낙인 획득) → 출신 해금 → 3랭크"로 두면 **데이터 추가 0**으로 2차 층 성장이 생긴다. 같은 결론에 나혼렙 그림자 추출(처치한 존재를 3회 시도로 병력화), 라그나로크 카드, 전독시 설화("겪은 사건이 등급 있는 힘")가 있다.

## 3. 어휘 후보 — 2차 층의 이름

| 후보 | 원전 근거 | 적합도 | 비고 |
|---|---|---|---|

## 4. 규칙 원형 목록 — 출처별

### 4-1. 개수·배타 (Warhammer 드워프 룬 3원칙이 가장 검증된 조합)
- **Rule of Three** 아이템당 룬 최대 3 · **Rule of Form** 무기 룬은 무기에만 · **Rule of Pride** 군 전체에 같은 룬 조합은 하나 · **Rule of Jealousy** 마스터 룬은 군당 1회, 아이템당 1개 (WHFB 7판·The Old World 원문 ★★★). 본작은 "한 장비에 같은 죄종 중복 금지"를 이미 갖고 있다 — Rule of Duplication의 부정형. **Pride는 파티 편성 게임에서 특히 강력**(복붙 세팅 금지 = 영웅별 차별화 강제).
- D&D 5e 조율 **영웅당 3**(사람에 걸린 상한, 짧은 휴식 1시간). Pathfinder 2e **"potency 룬 값 = property 룬 슬롯 수"**(+1 무기는 슬롯 1, +2로 올리면 2), 룬스톤은 옮기면 깨지고 직접 이전은 가격의 10%.
- 40k 카오스 표식: **상호 배타, 유닛당 1, 편성 시 확정, Undivided도 선택지, 사이커는 코른 불가**(직업 금지 조합). 본작 영웅 메인 죄종이 이미 이것 — 새로 정할 것은 "바꿀 수 있는가"뿐 → 바알만 예외적으로 누적/교체.
- 악마의 열매 1인 1개(둘째 = 사망), **능력자가 죽으면 열매가 세계에 재생성** → 유니크 영웅 소실 시 선술집 재등장 규칙. 블랙 클로버 마도서 1인 1속성, **주인이 죽으면 평생 쌓은 주문을 싣고 탑으로 돌아간다** → 영웅 소실 시 스킬 카드 공용 풀 반환. SAO 유니크 스킬 1스킬 1인·총 10.

### 4-2. 페널티·중독 (방치형 안전 순위: 효과 소멸형 > 상한 초과형 > 누적 침식형)
- **JJK 자기 속박**: 어기면 **이익만 사라지고 끝**(페널티 없음), 속박 위에 속박을 겹쳐 단점을 지울 수 있다 → 방치형에 가장 안전한 제약 접사. **HxH 제약과 서약**: 제약이 가혹할수록 강하고 어기면 죽음(크라피카) 또는 **선불**(곤: 미래를 통째로) → 사망형은 배제, "죄종 X 챕터에서만 발동, 대신 배율↑"은 본작 낙인 크래프트의 죄종 지정에 접사 하나로 얹힌다.
- Shadowrun 포커스: 개수 ≤ Magic, 총 Force ≤ Magic×5, 초과 시 **중독**. Weapons of Legacy: 힘을 여는 대가로 **HP·내성 영구 감소**, 포기하면 회복. → 본작이라면 새 수치가 아니라 **`fhr`(상태이상 회복 속도)**로 받는 것이 단순화 원칙("저주의 힘을 많이 쥘수록 죄의 상태이상을 오래 앓는다").
- 팔문둔갑(단계 n = 출력 f(n), 대가 g(n), 8문 = 사망)·광전사 갑주(감각 영구 상실 누적)·헤말러지(못 수↑ = 조종)·힘의 반지(착용 누적 유령화) → 출발 전 다이얼로만, 기본값 0, 자동 상승 금지.
- 희생의 낙인: **악에 반응해 피를 흘린다**(사도 근처 방울, 갓핸드 근처 분출) = 위험 센서 + 야간 조우율↑ 영구 디버프 → **"출혈 강도 = 근처 악마의 격"**은 스테이지 진입 전 위험도 UI로 바로 쓸 수 있다.

### 4-3. 소모·만료
- 부적 3형: 태워 마심(즉시) / 오마모리 1년 반납·소각(기한) / 스카라브 무덤 동봉(영구). **기한형은 방치형 계약과 충돌**("비운 사이 손해") → 넣지 말 것, 소모형은 원정 1회 즉시형만.
- Fate 영주 3획: 계약 시 자동 생성, 쓸 때마다 한 획, **재충전 불가, 늘리려면 남의 것을 빼앗는 것뿐** → 반복 원정과 상성 나쁨, 유니크 영웅 고용 시 1회성 보험 3획 정도가 한계. 브로큰 판타즘(보구를 부수며 한 랭크 위 일격) → "전투 중 분해"를 액티브로.
- PF2e 룬스톤(1회용 그릇)·룬석(부숴서 습득)·프리렌 마도서(읽으면 소모, 직업 제한 무시).

### 4-4. 조각 수집·회수
- FMA 호문쿨루스 7(발견 3) · 스쿠나 손가락 20 = 100%, 첫 조각은 **삼켜**(영구 소켓) 나머지는 크래프트로 **소모** — "지닐지 쓸지"의 D2 룬식 선택 · 나르실(조각 보관 → 자격자 → 재련 시 새 이름·문양) · 결속의 룬(2조각 결합 시 **접사 1개가 새로 생성** — 합이 아님) · 성유물 3등급(접촉 크래프트는 원본을 소모하지 않고 하위 사본) · 호크룩스(살인 = 조각, 조각이 대신 파괴되는 **부활 토큰**, 조각 수만큼 인간성 감소).
- 그리드 아일랜드 북: **지정 포켓 100 + 자유 45**, 카드마다 **월드 존재 한도**(랭크 높을수록 적음) → 싱글에서는 **세이브 내 유니크 보유 상한**, 몬스터 도감과 아이템 도감(지정 포켓)을 한 화면으로.

### 4-5. 문법·조합
- 아온: 기본 문자 + 수식 선(범위·지속·조건) + 연결(사슬) + 증폭(도시). **지형이 바뀌자 선 하나가 부족해 마법 전체 붕괴** → 챕터 이동 시 낙인에 지역 선을 추가해야 그 지역에서 효력 = 파워 인플레 억제 + "챕터 = 죄종 = 지역" 활용.
- ESO 글리프 = Potency(강도) + Essence(효과) + Aspect(품질) 룬 3개 → 확정 1개(랜덤 없음). 위처 3 룬워드 = **3소켓 전부 소모 → 규칙 변경 효과 1개**(작은 접사 3 vs 큰 효과 1의 배타 선택) → 세트 보류의 대안("세트"가 아니라 "단어", 8부위 안 맞춰도 3조합으로 성립). Tyranny 인장 3층 = **레시피 비소모**, 예산은 요구치 합.
- 아그리파 마방진: 행성 × 금속 × 시간 **3중 정합**, 행성마다 **격자 크기가 다르다**(토성 3×3 ~ 달 9×9), 인장은 **이름에서 산출** → 죄종별 인장 용량 차등, 정합 시 풀 성능, 레어 영웅 이름 → 인장 도형 절차 생성(데이터 추가 없이 개체 식별감).
- 파브리얼 3축(보석 × 스프렌 × 금속 우리 = 증폭/감쇠/유인/경고), **쪼갠 보석 페어는 한 보석처럼 움직인다** → 두 영웅에게 나눠 끼우면 버프 공유(파티 3인 편성 결정).

### 4-6. 해금·조건·그릇
- Earthdawn(발견 5) · 달문자(달·계절에만 판독 = 조건부 감정, 판독 성공이 열쇠) · 실마릴(자격 없는 자는 손이 탄다 = 게이트 대신 "장착은 되지만 손이 탄다", 본작 게이트 폐지와 호환; 세트를 모으려는 행위 자체가 저주 = 역세트) · 죽음의 성물(소유권은 승리로만 이동 → 그 유니크를 든 영웅이 사망하면 적이 회수) · 도굴왕(미계약 70% 출력 = 귀속 플래그 1비트, 3단계 변신 = 봉인 해제 문법).
- 힘의 반지 3/7/9/1: 마스터 1개가 하위 전체를 덮고(파괴 시 연동 소멸), **같은 아이템이 그릇(난쟁이)에 따라 다른 축으로 발현** → "같은 죄종 접사도 영웅 메인 죄종과 맞으면 증폭, 아니면 부작용" 그릇 규칙. 브레스(하이트닝 50/200/600/1,000/2,000): **부위 안 따지고 개수만 세는 임계값 세트** = 본작 세트포인트와 동형.
- Exalted 허스스톤: 돌의 힘은 **원격지(맨스)**에서 온다 → 거점 시설 등급 = 인장 상한(방치 계약상 하한은 보장). 페루케미 메탈마인드: 속성을 **저장했다가 인출**(저장 중 약해짐) → 부재 시간 동안 충전하는 배터리 장신구. Ars Magica 비스: 동사×명사 매트릭스의 **한 칸에만** 귀속, 그릇 용량, 3용도 경쟁 → **인장은 죄종(명사)만 갖고 부위(동사) 축은 장비가 결정**(매트릭스 중복 방지).
- 전독시 후원 구조: 1 후원원 : n 능력 묶음, 갈아타면 이전 것 잠김, **후원을 받으면 자립 승격 경로가 닫힌다** → 죄종 계약 1개(배타) ↔ 그 죄종 패시브 묶음. 튜토리얼(층 = 신 1명 = 후원자) → 챕터 = 후원자(죄종 악마). SSS급 자살헌터 "**나를 죽인** 몬스터의 스킬 카드 1장(뒷면 랜덤), 같은 대상 1회" → 패배를 자원으로 바꾸는 방치형 안전망(패배 리포트에 카드 1장).

## 6. 조사자 제안 종합 — 세 조사가 독립적으로 수렴한 것 (**제안이지 결정 아님**)

신화·서양 소설·일본 만화 조사자가 서로 모른 채 같은 지점에 도달했다. ★는 셋 이상이 독립적으로 낸 것.

| # | 제안 | 원형 | 수렴 |
|---|---|---|---|
| 1 | **인장 = 죄종 1 + 등급 1, 부위 축 없음** — 효과는 그 죄종의 **상태이상 부여**(story_chapter_design §3의 빈 칸) + 등급별 강도, **수치 보너스는 주지 않는다**(접사 중복 방지) | 고에티아 · Ars Magica(인장은 명사만) · 헤말러지 | ★ |
| 2 | **아이템당 3 · 로스터 내 같은 조합 금지 · 챕터보스급은 아이템당 1** | WHFB Three/Pride/Jealousy | 신화 |
| 3 | **랭크 해금 = 도감 처치 수 + 챕터 클리어** — 데이터 추가 0 | Earthdawn · 나혼렙 · Fate 성배 | ★ |
| 4 | **7부하 = 바알이 떼어 맡긴 자기 조각** 서사 접합, 챕터 보스 조각의 첫 1개는 **삼켜(영구, 일곱 상처)** 나머지는 크래프트 **소모** | FMA · 스쿠나 · 헤말러지 | ★ |
| 5 | **자기 페널티는 기존 축(`fhr`)으로**, 상한 안에서 0, 위반 시 **효과 소멸만** | Shadowrun · Legacy · JJK 속박 | ★ |
| 6 | **바알만 인장을 몸에 직접 박고 교체 가능**, 다른 영웅은 메인 죄종 1개 고정 | 40k 표식 · 일곱 상처 | 신화·만화 |
| 7 | **슬롯 수 = 강화 단계**, 이송은 봉인 그릇(1회용), 직접 이전은 세금 | PF2e | 신화 |
| 8 | **죄종 X 챕터 전용 제약 접사 → 배율↑, 위반 시 효과 소멸** | HxH · JJK | 만화 |
| 9 | **세트 = 7죄종 보스 처치 기록**(장비 슬롯 소비 0) 또는 **3조합 단어**(위처) | Fate · 위처 | 만화·소설 |
| 10 | **기한 소모형(오마모리)·영웅 제물(베헬리트)·자동 발동 페널티는 넣지 말 것** | 부적 · 베르세르크 · 팔문 | ★ |

**반대 근거(조사자 스스로 적은 것)**: 인장이 상태이상 부여를 맡으면 보류 중인 **"세트 3포인트 = 부여" 안**(item_design §4)과 **경로가 충돌**한다 — 세트를 부활시킬 계획이면 인장은 부여가 아니라 **강도/지속 증폭**으로 한 칸 물러서야 하며, 어느 쪽이든 **부여 경로는 하나**여야 한다. 슬롯 = 강화 단계면 강화 안 한 매직 장비는 인장 0 → 초반 체험 지연. 헤말러지형 "자율성 손실"은 본작이 미탑재한 폭주 레이어를 되살리는 것이라 방치 계약과 긴장.

## 7. 톤·계약 주의 — 본작과 충돌하는 원형

| 원형 | 충돌 | 처리 |
|---|---|---|
| 베헬리트(소중한 사람 제물)·MiA 카트리지(아이를 소모)·흰 피리(유해) | 레어 영웅 무한 생성이라 경제적으론 성립하는 드문 세계관이지만 **톤이 어둡고**, 자동 발동은 방치 계약 위반 | 넣더라도 명시 선택만. 톤은 별도 확인 |
| 이식(라크리마·사륜안·인주력·나노머신) | 영웅 = 빌드 슬롯, 장비 재배분이 본체 → 이식은 **재배치 자유를 깎는다**. 사륜안형 상시 누수는 기본 능력치 불변식(`attr_equip_bonus=0`) 위반 | 1영웅 1결정·상위로 덮어쓰기만, 불변식 수정은 별도 확인 |
| 소켓 용량(오버로드 데이터 크리스탈) | 영웅 단위면 **코스트 폐지(08-21) 번복** | 아이템 단위(희귀도 계단 = 용량)면 별개 — 경계는 결정 사항 |
| 기한 만료(오마모리)·재충전 불가(영주)·투자 소멸(Rise 백룡) | "비운 사이 손해" = 방치 계약 위반 | 만료는 손실 없는 "반납 대기"로, 소모형은 원정 1회 즉시형만 |
| 통제 이탈(주인·헤말러지 조종·나이트블러드) | 방치 계약 + 사기·폭주 미탑재 결정 | 침식은 **회복 가능한 부상**으로 치환 |
| 이중 처벌(광전사 흉터 + 낙인 디버프, 팔문 부상 + 부상 모델) | 구조적 완성도 원칙(이중 처벌 금지) | 페널티 축은 하나(`fhr` 또는 부상)만 |
| 전독시 "성흔" 어휘 | 빌린 힘 vs 빼앗은 힘 — 독자 기대 충돌 | 낙인 = 흡수를 UI 초반 문구로 |
| 랜덤 이득/손해 이벤트(SMT 마가타마 난동, FFVI 마석 후회 압박) | 통제성 우선 | 내성 세트 교체·상한 성장 방향만 |
