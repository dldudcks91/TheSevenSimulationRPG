## L1. 신화 · 종교 · 오컬트 · 테이블탑 RPG

> 조사: 항목당 웹 검색/원문 2~3회 대조(위키피디아·공식 SRD·룰북 전사 우선). 검증 못 한 진술은 **[미확인]**.

### L1-0. 한 장 요약

- 원형은 네 계통: **① 문자가 곧 힘**(북유럽 룬, 골렘 emet, 부적, 72신명) **② 존재의 조각이 힘**(성유물, 허스스톤, 비스) **③ 계약·구속이 힘**(고에티아 인장, 솔로몬의 반지, Shadowrun 포커스, Weapons of Legacy) **④ 소속의 표식이 힘**(카오스 표식, 카인의 표식, 짐승의 표)
- 제약 규칙의 원형도 넷: **개수 상한**(Rule of Three, D&D 조율 3, PF2e 포텐시=슬롯) / **상호 배타**(카오스 표식, Rule of Pride) / **페널티·중독**(Focus Addiction, Weapons of Legacy) / **소모·만료**(오마모리 1년 반납, 부적 태워 마심, PF2e 룬스톤 파괴)
- 사실 정정 2건: (a) **빈드룬의 "마법적 사용"은 역사적으로 입증되지 않은 현대 해석** — 룬워드의 "원형"이라 부르기엔 근거가 약하다. (b) Ars Magica는 "형상 15 × 기술 5"가 아니라 **기술 5 + 형상 10 = 15 아트, 조합 50**.

### L1-1. 북유럽 룬 (Elder Futhark 24자)

- 24자 = 8자씩 **3 ætt**. 의미: Fehu=가축·재산, Uruz=오록스, Thurisaz=거인, Ansuz=신, Raido=여정, Gebo=선물 … Isaz=얼음, Sowilo=태양, Tiwaz=티르, Othala=상속. ★★★
- **하바말 Rúnatal**: 오딘이 나무에 아홉 밤 매달려, 창에 찔린 채, "나 자신을 나 자신에게" 바쳐 룬을 집어 올렸다. ★★★
- **Ljóðatal**: 오딘의 **주문 18개** — 3번 적의 칼날 무디게, 4번 족쇄 풀림, 5번 화살 멈춤, 9번 바다 잠재움, **18번은 "누구에게도 말하지 않음"**. ★★★(범위)/★★(개별)
- **Sigrdrífumál 6연**: "승리를 원하면 승리 룬을 새겨라, **칼자루에**, 칼날 홈에, 그리고 **티르의 이름을 두 번 불러라**". ★★★
- **빈드룬**: 획을 공유한 합자. **위키피디아는 마법적 용도를 전혀 언급하지 않는다** — 현대 오컬트 해석. ★★★

**규칙**: 힘의 대가 = **자기희생**. 룬은 **새기는 위치 규정** + **신의 이름 발성** = "문자 + 위치 + 발화" 3요소. 주문은 유한 목록(18), 마지막은 **비밀(양도 불가)**.
**번역**: 룬 = 유한 사전, 각 룬은 **하나의 의미 축** → 접사가 아니라 **카테고리 태그**. "칼자루에" = **부위 지정**(Rule of Form의 뿌리). "티르 두 번" = 같은 룬 2개 중첩 허용의 원형. 18번 = **계정 귀속 룬 한 종**.
**본작 접점**: 24자 사전은 7죄종 축보다 넓다. 가져올 것은 **"희생으로 얻는다"**(바알이 몸을 잃고 낙인을 얻은 구조와 동형)와 **"위치 + 이름 부르기"** 문법.

### L1-2. 카발라 · 골렘

- **emet/met**: 이마의 אמת(진리)에서 알레프를 지우면 מת(죽음) → 정지. **헬름 골렘 전승**(16세기), 문헌 최초 **1674년**. **프라하 마하랄 골렘은 19세기 독일 문학의 창작**. ★★★
- 변형: **입 속 신명(shem) 종이**를 넣어 살리고 빼서 멈춤(안식일 전 제거). ★★★
- 『세페르 예치라』: **22 문자 + 10 세피로트 = 32 지혜의 길**. **게마트리아**: 문자=숫자 → 같은 수치의 단어는 같은 본질. ★★
- **72 신명**: 출애굽기 14:19~21 세 절 각 72자 → 우경으로 읽어 3글자 이름 72개. 러드 계열에서 **72 천사가 고에티아 72 악마를 각각 구속**. ★★★

**규칙**: **글자 하나 = 활성/비활성 스위치** — 총량이 아니라 **완전성**이 작동 조건. 이름은 **자리에 있어야 작동**(입 속 종이) — 빼면 정지, 재삽입 가능(**비파괴**). 문자=숫자 → 이름의 **합산값 = 등급**. 72:72 **1:1 카운터 쌍**.
**번역**: 인장을 뽑으면 아이템이 잠든다(비파괴 착탈, 빼는 동안 비활성). 게마트리아 = **인장 이름의 문자 합 = 등급 점수**. 72:72 = 악마 인장 ↔ 성흔(천사) 카운터.
**본작 접점**: **바알이 악마를 죽여 흡수** = 72:72 구속 관계를 **주인공이 천사 대신 수행**. 진범이 대천사 티리엘인 반전과 맞물린다 — 천사 측 "성흔"과 악마 측 "인장"을 대립 층으로 둘 근거.

### L1-3. 솔로몬의 열쇠 / 고에티아 72 악마의 인장

- **Ars Goetia** 72 영. **1번 = 바엘(Bael), 왕, 66군단**. **아스모데우스 = 32번 "아스모다이", 왕**. ★★★
- 등급: 왕 9 · 공작 23 · 대공 7 · 후작 15 · 백작 5 · 기사 1 · 대통령 12 = 72. ★★★
- **72에 없는 자**: 베엘제붑, 벨페고르, 레비아탄, 맘몬, 루시퍼, 사탄 → **빈스펠트 7군주는 고에티아와 별개**, 겹치는 것은 아스모데우스뿐. ★★★
- 각 악마 **고유 인장(sigil)** — 인장으로 소환·구속·명령. **솔로몬의 반지**(『솔로몬의 유언』): 악마를 하나씩 소환·심문·구속해 **성전 건설에 부린다**. 악마를 **놋쇠 그릇에 봉인**해 바다에 던진 것이 "램프의 지니" 기원. ★★★
- [미확인] 인장을 계급별 금속(왕=금, 후작=은…)에 새긴다는 규정 · 바엘 능력 "투명화" 통설.

**규칙**: 인장은 **개체 고유 식별자**(악마 1 = 인장 1). **계급이 군단 수(전력)를 결정**. 구속의 목적은 **노동** — 힘을 빌리는 것. 봉인(그릇) = **격리 = 보관**, 깨면 풀려난다.
**번역**: **인장 = 네임드 몬스터 1:1 드롭**, 등급 = 원본 계급 고정. 인장을 **그릇(봉인함)**에 넣으면 보관, 꺼내면 소모(PF2e 룬스톤과 같은 이송 매체). 심문 = **도감 정보 해금**이 인장 성능을 연다.
**본작 접점**: **가장 직접적인 어휘 공급원.** 바알이 고에티아 1번 왕이라는 점은 "지옥의 왕이 7군주 위에 있다"는 설정과 **두 체계의 접합**으로 설명된다. "인장 = 계급 고정"은 스폰 등급(일반<정예<스테이지보스<챕터보스)과 1:1.

### L1-4. 7대 죄악 ↔ 7 지옥 군주 (Binsfeld 1589)

- 빈스펠트(1589): **루시퍼=오만, 맘몬=탐욕, 아스모데우스=색욕, 레비아탄=시기, 베엘제붑=폭식, 사탄=분노, 벨페고르=나태**. ★★★
- 변형 1 — 『Lanterne of Light』(1409~10): **베엘제붑=시기, 아바돈=나태, 벨페고르=폭식**, 레비아탄 없음. ★★★
- 변형 2 — 미카엘리스(1613): 천사 위계 분류. ★★★

**규칙**: 매핑은 **저자마다 다르다**. 루시퍼와 사탄이 **별개**(오만/분노). 본작의 "루시퍼 불참·사탄 기추방" 트릭은 이 분리를 활용.
**본작 접점**: 이미 채택된 판. 추가 발견: **아스모데우스만 고에티아(32번 왕)에도 등장** → 색욕 챕터를 인장 시스템의 기원 챕터로 두는 서사 근거. 변형표는 "이단 판본" 이벤트 재료.

### L1-5. 성유물 · 성흔 · 카인의 표식 · 일곱 봉인 · 짐승의 표

- **성흔(Stigmata)**: 1224년 **아시시의 프란치스코**가 최초. ★★★ / **카인의 표식**(창 4:15): 아무도 죽이지 못하게 하는 **보호 표식** — 형벌이 아니라 보호. ★★★ / **짐승의 표**(계 13:16~18): **표 없이는 사고팔 수 없다**, 666. ★★★ / **일곱 봉인**(계 5~8): 순서 고정 단계 해금. ★★★
- **성유물 3등급**: 1급 = 성인의 몸 일부, 2급 = 소유·사용한 물건, 3급 = 1·2급에 **닿은** 물건. **성유물함(reliquary)** = 그릇. ★★★

**규칙**: 표식은 **몸에 새겨져 정체성·운명을 결정**, 본인이 고를 수 없다. 짐승의 표 = **경제 접근권 게이트**. 봉인 = **순서 고정·비가역**. 성유물은 **접촉으로 등급 전이**되지만 내려간다.
**번역**: 영웅 몸 층 = **선택 불가·양도 불가·1개**. 3등급 = **원본(보스 유골) → 소유물(보스 드롭) → 접촉물(원본에 닿게 만든 크래프트)** — 접촉 크래프트는 원본을 소모하지 않고 하위 사본을 만든다.
**본작 접점**: 본작 **낙인(Stigma)은 어원상 성흔(Stigmata)과 같은 말**(στίγμα = 찍힌 표). "바알의 몸의 낙인" = 성흔의 어두운 판본 → **영웅 측 표식 층**은 낙인/성흔 계열, **아이템 측 표식 층**은 인장 계열로 분리하면 어휘 충돌 없음.

### L1-6. 부적 전통 3종

- **동아시아 부적(符籙)**: 노란 종이 + **주사 붉은 글씨**. **태워 재를 물에 타 마시는 부수(符水)**. ★★★
- **오후다·오마모리**: **1년 후 반납**, 오타키아게로 소각 — 신이 머물다 돌아간다. ★★★
- **타위즈**: 꾸란 구절 부적, 힘의 출처를 신 외에 두면 shirk. ★★ / **메주자**: 쉐마 양피지, 문설주 오른쪽. ★★★ / **하트 스카라브**: 『사자의 서』 **주문 30B** — 심장이 불리한 증언을 못 하게 묶는다. **우제트**: "온전한 것". ★★★

**규칙**: "글자 자체가 힘" vs "물건에 신이 깃듦"(머물다 돌아감) vs "형상이 힘". **소모 방식 셋**: 태워 마심(즉시), 1년 만료 반납(시간), 무덤 동봉(영구). 오마모리는 **버리면 안 되고 반납** — 소모에 **의례 절차**. 타위즈는 **믿음의 방향**이 합법 경계.
**번역**: **소모형 인장 3형**: 즉시형(원정 1회), 기한형(N회 후 반납·재발급), 동봉형(영구 봉인). 방치 계약상 **기한형 만료는 손해 없이 "반납 대기"**로만. "힘의 출처" = 인장(악마)과 성흔(천사)을 같은 몸에 두면 상쇄.
**본작 접점**: 상태이상 7종의 대응 축이 **회복 속도(`fhr`) 하나**뿐이므로 "부적 = 상태이상을 털어내는 소모품"은 기존 축 위에 바로 올라간다. 접사 풀 희석 금지 → **별도 소모품 카테고리**여야.

### L1-7. 연금술 — 현자의 돌 · 기호 · 호문쿨루스

- **7행성 = 7금속**: 태양=금, 달=은, 수성=수은, 금성=구리, 화성=철, 목성=주석, 토성=납 (요일 대응 포함). ★★★
- **현자의 돌**: 변성 + 불사. 플라멜 1382 전설은 후대 창작. ★★★
- **호문쿨루스**(파라켈수스 1537): 밀봉 유리 + **말똥 속 40일** → **인간 피로 40주** 양육. ★★★

**규칙**: **7축 대응표가 금속·행성·요일·장기까지 관통**. 변성은 **단계**(니그레도→알베도→루베도), **시간이 재료**. 호문쿨루스 = 재료 + 시간 + 지속 급식.
**번역**: 7죄종 × {금속, 요일, 챕터, 상태이상, 색} 단일 대응표 = 본작이 이미 하는 일. **금속 1종**을 더하면 인장 재료 이름이 저절로 생긴다(탐욕=금, 분노=철, 나태=납). "시간이 재료" = 제련소 공정이 **원정 횟수를 소모**.
**본작 접점**: 제련소 세계관 어휘. "현자의 돌" = **유니크 크래프트 재료 최상위 이름 후보**.

### L1-8. 행성 탈리스만(Agrippa) · 마방진(Kamea)

- 『오컬트 철학 3서』(1533) **제2서 22장**: **토성 3×3, 목성 4×4, 화성 5×5, 태양 6×6, 금성 7×7, 수성 8×8, 달 9×9**. ★★★
- 이름의 문자를 숫자로 바꿔 표 위를 선으로 이으면 **인장(sigil)**이 나온다. 새길 금속 = 행성의 금속, **행성의 요일·행성시**에 제작·축성. ★★★

**규칙**: **행성 × 금속 × 시간 3중 정합**. 마방진 크기가 행성마다 다르다 = **행성마다 칸 수가 다르다**(9~81). 인장은 **이름에서 산출** — 이름이 다르면 인장이 다르다(Rule of Pride의 오컬트 판).
**번역**: **죄종별 인장 용량 차등**(나태=토성 3×3 소형, 오만=태양 6×6 대형). 3중 정합 = 인장(죄종) × 아이템(죄종) × 제작 시점(챕터)이 일치할 때 풀 성능. **이름 → 인장 도형 절차 생성**.
**본작 접점**: 레어 영웅 무한 생성의 개성 부족을 **데이터 추가 없이** "이름→인장 도형"으로 보강 가능.

### L1-9. Warhammer Fantasy — 드워프 룬(Runesmith) ★★★ (7판 아미북 · The Old World "Rules of the Runes" 전사 확인)

### L1-11. Pathfinder 2e — 룬 ★★★ (Archives of Nethys)

|---|---|---|---|
| **인장(Sigil)** | 고에티아 — 악마마다 고유 인장, 쥔 자가 명령. 바알 = 1번 왕 | **최고**. "악마를 죽여 인장을 빼앗아 새긴다" = 흡수 서사와 1:1. 낙인·접사와 충돌 없음 | 영문 Sigil 권장(Seal은 "봉인"과 혼동) |

### L1-19. 조사자 제안 — 규칙 골격 (원전 이식, 새 게이지 0) — **제안이지 결정 아님**

1. **인장 = 죄종 1 + 등급 1**(부위 축 없음 — Ars Magica). 효과 = **그 죄종의 상태이상 부여**(story_chapter_design §3의 빈 칸 "영웅→몬스터 부여 경로 미정"을 채움) + 등급별 강도. **수치 보너스는 주지 않는다**(접사 중복 방지)
2. **슬롯 수 = 강화 단계**(PF2e). 골드 최종 소모처가 곧 인장 자리 — 손잡이 하나
3. **아이템당 최대 3 · 로스터 내 같은 조합 금지 · 챕터보스급 인장은 아이템당 1**(WHFB Three/Pride/Jealousy)
4. **인장 랭크 해금 = 도감 처치 수 + 챕터 클리어**(Earthdawn) — 데이터 추가 0
5. **이송은 봉인(그릇)을 통해서만, 그릇은 1회용, 직접 이전은 세금**(PF2e)
6. **영웅당 활성 인장 총등급 상한 = f(레벨)**, 초과분은 **`fhr` 감소**(Shadowrun 중독 + D&D Legacy 페널티를 기존 축으로). 상한 안에서는 페널티 0 → 방치 계약 준수
7. **바알만 인장을 몸(일곱 상처)에 직접 박고 교체 가능**, 다른 영웅은 메인죄종 1개 고정(40k)
8. **오마모리형 기한 소모 인장은 넣지 말 것** — "비운 사이 손해". 소모형은 **원정 1회 즉시형**만

**반대 근거**: 인장이 상태이상 부여를 맡으면 보류 중인 **"세트 3포인트 = 부여" 안과 경로 충돌** — 세트 부활 시 인장은 **부여 강도/지속 증폭**으로 한 칸 물러서야. 어느 쪽이든 **부여 경로는 하나**. 슬롯 = 강화 단계면 강화 안 한 매직 장비는 인장 0 → 초반 체험이 늦어짐(레어 이상 기본 슬롯 1 보정 필요 가능).
