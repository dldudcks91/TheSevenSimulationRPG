## L2. 서양 판타지 소설

> 조사: Wikipedia 직접 열람 + Tolkien Gateway / Coppermind / 팬덤 위키 스니펫 교차. 검증 못 한 부분은 **[미확인]**.

### L2-1. 톨킨 — 힘의 반지 3/7/9/1

- 엘프 3 / 난쟁이 7 / 인간 9 / 지배자 1 = 20. 절대반지는 나머지를 지배·탐지·구속. **절대반지 파괴 → 셋의 힘도 사라짐**(연동 페널티). 절대반지·아홉은 착용자를 투명화하고 수명을 "얇게 늘여" 유령계로 끌어들인다 → 나즈굴.
- **같은 아이템·다른 그릇**: 난쟁이는 유령화·지배되지 않았고 대신 "황금 갈망"만 증폭. 사우론 스스로 "실패한 계획". ★★★

**번역**: 등급 피라미드에 마스터 1개가 하위 전체를 덮는 "지배 슬롯" — 마스터를 잃으면 하위 보너스도 소멸. 동일 아이템의 효과가 **그릇(영웅의 메인 죄종)에 따라 다른 축으로 발현** — "그릇 × 아이템" 2차원 표. 강한 보너스에는 **사용 누적형 페널티**.
**본작 접점**: 바알의 낙인이 곧 "1", 7부하의 힘이 "7". 난쟁이 반지 규칙은 "같은 죄종 접사도 영웅 메인 죄종과 맞으면 증폭, 아니면 부작용" 식의 그릇 규칙에 바로 쓸 수 있다.

### L2-2. 톨킨 — 달문자 · 모리아 문 · 나르실 · 실마릴

- **달문자**: 은펜으로 쓴 룬, 달빛이 뒤에서 비출 때만 드러나며 정교한 것은 **쓴 날과 같은 달·같은 계절**에만 읽힌다(스로르의 지도 — 한여름 전야 초승달). 모리아 서문 "친구라 말하고 들어가라" — 답 "멜론"이 곧 열쇠. ★★★ → **감정 조건형 아이템**(특정 챕터/라운드에서만 판독), 판독 성공이 열쇠.
- **나르실→안두릴**: 조각은 버려지지 않고 보관, **자격자(후계자)가 나타났을 때만** 재련. 재련 = 새 이름 + 새 문양(일곱 별 = 혈통 표식). ★★★ → **조각 수집 → 자격 조건 → 합성 시 문양(고정 접사) 각인**. 부서진 검은 "쓸모없지만 버릴 수 없는" 별도 보관.
- **실마릴 3개**: 바르다의 축성으로 **악한 자·부당한 목적의 필멸자가 만지면 손이 탄다**. 페아노르의 맹세는 파기도 완수도 불가능한 양방향 저주. 세트 3개는 **한 번도 합쳐지지 않았고** 그것이 서사의 핵심. ★★★ → **자격 없는 착용 = 지속 피해**(게이트 대신 "장착은 되지만 손이 탄다" — 본작 게이트 폐지와 호환). **"세트를 모으려는 행위 자체가 페널티"인 역세트** — 소유 개수에 따라 그 죄종 악마가 파티를 찾아온다(탐욕 챕터 직결).
- [미확인] 달문자가 이실딘으로 쓰였다는 서술(팬덤만).

### L2-3. 어스시 — 진명 · 에레스 아크베의 반지

- 진명을 태고어로 부르면 지배. 게드는 펜도르의 용을 진명으로 섬에 영구히 묶었다. 반지 안쪽에 **아홉 힘의 룬**, 반으로 부러지자 **결속의 룬(Bond-Rune, 평화의 룬)이 균열로 파괴되어 읽을 수 없게** 됨 → 이후 어느 왕도 군도를 평화롭게 통치하지 못했다. 『아투안의 무덤』에서 두 조각을 잇는다. ★★★
- **룬은 그 자체로 뜻을 갖는다** — 문자가 부서지면 **뜻(평화)이 세계에서 사라진다**.

**번역**: **분할 아이템** — 2조각 드롭, 각 조각에 "읽을 수 없는 접사", 결합 시 접사 1개가 **새로 생성**(합이 아님). **이름 지정 = 지배**: 악마의 진명을 판독하면 그 종 관통·제압 보너스.
**본작 접점**: 낙인의 "죄종 지정"을 "그 죄종의 진명을 읽었다"로 서사화. 챕터 보스(7부하)의 진명 = 크래프트 재료. [미확인] 결합 방식 "Patterning" 표현.

### L2-4. 해리 포터 — 호크룩스 · 죽음의 성물

- **호크룩스**: 살인으로 영혼이 찢어진 상태에서 조각을 물건에 담는다. 물건이 존재하는 한 본체는 죽지 않는다. 볼드모트는 6개(+해리 8번째)로 7조각 의도. 파괴는 **바실리스크 독·악마의 불** 등 회복 불능 파손만(화이트리스트). 되돌리기는 **진정한 후회**뿐(본인을 죽일 수 있음). 부작용: 외형 변형, 인간성 감소. ★★★
  - **번역**: **부활 토큰형 소켓** — 영웅 사망 시 조각이 대신 파괴. 조각은 **보스 처치로만** 생성. 조각 수만큼 **인간성 스탯 영구 감소**.
  - **본작 접점**: 방치형 계약 "자리 비워도 안전"과 정면 대응. "죽인 악마의 죄종 힘 흡수" = 살인으로 얻는 조각. 부상/치료 모델과 붙이면 "조각이 대신 부상을 먹는다".
- **죽음의 성물 3**: 각 아이템은 **단독 완결**, 세트 보너스는 "칭호"뿐. 딱총나무 지팡이의 소유권은 **거래·상속이 아니라 승리로만 이동**(소유자를 죽이거나·이기거나·무장해제). ★★★ → **승리 이전형 유니크**: 그 유니크를 든 엘리트를 죽여야 드롭 + 그 유니크를 든 영웅이 사망하면 **적이 회수**. 3종 동시 보유 = 스탯이 아니라 **규칙 변경**(사망 판정 1회 면제).
- 고대 룬 = **해독** 학문(헤르미온느가 에와즈↔에이와즈 혼동) → 판독 실패 시 오답 접사가 붙는 "오독 크래프트".

### L2-5. 샌더슨 — 헤말러지(미스트본) ★★★ (Coppermind/17th Shard 표)

- 금속 못을 사람의 **결합점(bind point)**에 박아 속성을 훔쳐 다른 사람의 결합점에 박아 이식하는 **파멸(Ruin)의 기술**. 결합점 200~300개, 위치마다 효과가 다르다. 이식은 항상 손실 동반(end-negative).
- **금속 × 훔치는 속성**: 철=힘 / 강철=알로만시 물리계(**박는 위치**로 결정) / 주석=감각 / 백랍=페루케미 물리계 / 아연=감정 강인함 / 황동=페루케미 정신계 / 구리=정신·기억·지성 / 청동=알로만시 정신계 / 금=페루케미 혼합계 / 아티움=**아무 능력이나**.
- 대가: 충전에는 **사람이 죽는다**. 못을 몸 밖에 두면 **충전이 시간에 따라 새어 나간다**. 못 하나만 있어도 파멸의 속삭임에 노출, 수가 늘수록 **조종**당함(심문관 9~11개 = 자율 거의 없음, 콜로스 4, 칸드라 2). 뽑으면 힘 상실. [미확인] 핵심 못(linchpin) 제거 시 사망, 감쇠의 전 금속 공통 여부.

**번역**: **금속(소재) × 결합점(부위) = 효과 매트릭스** — 본작 7죄종 × 8부위와 **동형**. 못은 **처치한 적에게서만**(살해=충전), 뽑아 둔 채 시간이 지나면 **감쇠**(부재 정산 감쇠로 번역). 못 개수 누적 → **자율성 손실**(본작이 미탑재한 폭주를 아이템 축으로만 표현 가능).
**본작 접점**: **가장 직접적인 참고.** "악마를 죽이면 그 죄종의 힘을 흡수하는 낙인"은 문자 그대로 헤말러지. 죄종(7) = 금속, 부위(8) = 결합점, 흡수한 힘이 몸을 갉아먹는 것 = 파멸의 조종. 슬롯 상한을 "인간성"으로 두면 통제성 확보.

### L2-6. 샌더슨 — 페루케미 · 아온 · 파브리얼 · 브레스

- **페루케미 메탈마인드**: 속성을 금속에 **저장했다가 인출**(저장 중 그만큼 약해짐, net-zero). 기본 **저장한 본인만** 사용(Identity 키), 알루미늄으로 정체성을 저장해 만든 **unkeyed** 메탈마인드는 누구나. 금속별: 철=무게/강철=속도/주석=감각/백랍=힘/아연=사고속도/황동=온기/구리=기억/청동=각성/금=건강/아티움=나이/크롬=행운/알루미늄=정체성… ★★★ → **배터리형 장신구**: 원정 A에서 깎아 충전, 원정 B에서 몰아 쓴다. 방치형 "부재 시간 동안 충전"과 자연 결합. 귀속 vs 비귀속(상위 크래프트 = 연구/제련 공정).
- **엘란트리스 아온**: 기본 아온 **아온(Aon Aon)의 형상 = 아렐론 국토 지도**(선=해안, 점=산맥·호수). 기본 아온에 **수식 선을 덧붙여** 지속·목적지 지정, **아온 오미**로 연결(사슬), **아온 라오**는 증폭기(도시 전체가 거대한 아온). 지진으로 **협곡(Chasm)**이 생기자 모든 아온에 선 하나가 부족해져 마법 전체 붕괴(Reod) → 라오덴이 협곡 선을 추가해 복원. ★★★ → **문자 조합 크래프트**: 기본 룬(효과) + 수식 룬(범위/지속/조건) + 연결 룬. **챕터(지형) 진행에 따라 이전 룬이 "선 하나 부족"해 무효화** → 새 챕터에서 수식 선 하나를 추가해야 재활성 = 파워 인플레 억제. 본작 "챕터 = 죄종 = 지역"이므로 "지역 문자" = 죄종 문자.
- **스톰라이트 파브리얼**: 보석에 스프렌을 가두고 금속 우리로 감싼 장치. **보석(그릇) × 스프렌(내용) × 금속(제어)** 3축 — 아연=강화/황동=약화(강도), 백랍=증폭기/주석=감쇠기/청동=경고기/철=유인기(방향), 알루미늄=절연. 결합형은 충전된 루비를 반으로 쪼개 만들고 **두 조각은 한 보석처럼 움직인다**. 스톰라이트는 **새어 나가(dun)** 재충전 필요. 윤리 문제(스프렌 감금). ★★★ → 3축 소켓: 소켓 × 잡아넣은 존재(악마 죄종) × 우리 금속(증폭/감쇠/유인/경고 모드) — "같은 악마를 주석 우리에 넣으면 그 죄종 피해 감쇠"처럼 **한 재료가 방어·공격 양쪽으로 전환**. **쪼갠 보석 페어**: 두 영웅에게 나눠 끼우면 버프 공유(파티 3인 편성 결정).
- **워브레이커 브레스·나이트블러드**: 모두 브레스 1개를 갖고 태어나 "My life to yours" 말로만 양도(강탈 불가). 모으면 **하이트닝** — 1단 ~50 / 2단 200 / 3단 600 / 4단 1,000 / 5단 2,000(**불로**) / 6단 3,500 (공식 Ars Arcanum). **나이트블러드** = 천 개의 브레스 + "악을 파괴하라" 명령. 뽑으면 닿는 것의 인베스티처를 무차별로 먹으며 **든 사람의 브레스·영혼까지 갉아먹는다**. 선한 자는 구역질, 악한 자는 매혹. ★★★ → **누적 카운트형 세트**: 부위를 안 따지고 같은 죄종 접사 개수만 세어 3/6/9 임계 = 본작 세트포인트와 동형(브레스는 어느 부위에 있든 개수만 센다). **자해형 유니크** + 칼집 = 별도 아이템(**아이템 쌍 조건**). 소지 조건이 **죄종 성향 판정**. [미확인] 칼집 소재(은 vs 알루미늄).

### L2-7. 기타

- **휠 오브 타임 앙그리알/사앙그리알/터앙그리알**: 앙그리알은 증폭 + **과인출을 막는 완충**. 사앙그리알은 더 강하나 **번아웃·사망** 위험, 칼란도르·보라의 사앙그리알은 **완충 없음**(칼란도르는 오염까지 증폭). 초에단 칼은 **접근 열쇠(터앙그리알)** 없이 제어 불가. 터앙그리알 = 기능 고정. 미감정 아이템 연구 중 번아웃(마틴 자나타 40년 연구 후 사고). ★★★ → 증폭 아이템에 **완충 플래그**: 완충 없는 고성능은 상한 초과 시 영구 부상(히든 상한선 감소). **감정 실패 페널티**: 연구 시설에서 열면 확률로 파괴 또는 연구 영웅 부상 — 연구 시설(비전투)에 리스크를 넣는 근거.
- **에라곤 고대어·검 이름**: 고대어로 **거짓말 불가**, 진명을 알면 지배. 마법 비용 = **같은 일을 손으로 했을 때 잃을 에너지와 동일**(계산 가능), 과용하면 죽는다. 보석에 에너지 저장(벨로스의 띠 다이아몬드 12). 브리싱거는 이름을 말할 때마다 **불타오른다**. ★★★ → 스킬 비용 HP 직접 차감, **보석 저장량이 먼저 소모**되는 순서 규칙. 유니크 검 "이름 호출" = 액티브.
- **엘릭 스톰브링어**: 룬이 새겨진 검이자 검의 형상을 한 악마. 스치기만 해도 **영혼을 마셔** 활력을 엘릭에게 넘긴다. 엘릭은 검 없이 살 수 없다(의존). 검은 **자기 의지**로 연인·아내·엘릭을 죽이고 웃으며 사라진다. ★★★ → **흡혈형 유니크**: 처치 시 회복 대신 일정 확률로 **아군 공격**(3인이라 통제 가능한 리스크). 해제 시 영구 디버프(중독). **바알 자체가 엘릭형 주인공**(전 지옥왕, 약해진 몸, 저주 무기).
- **말라잔 오타타랄**: 워렌(마법 차원) 접근을 차단하는 광석 — **마법 무효 구역**(아군 마법 포함). 장기 노출 시 오염·광기. 후반에 **용 코라바스에 결속된 힘**임이 드러남. ★★★ → **죄종 무효 아이템**: 해당 죄종 접사·세트 전부 OFF, 대신 그 죄종 몬스터의 특수능력도 OFF — 편성 트레이드오프. 방치 안전장치로도.
- **드레스덴 / 바르티메우스**: Name을 뜻을 담아 말하면 효과 천 배, 이름을 **주는 것**이 화폐(해리가 악마에게 자기 Name 하나를 넘김). 요정은 **세 번 말한 것을 반드시 지킨다**. 펜타클 안에서만 지배 유효, 선 밖으로 나가면 무방비. 마법사의 **출생명**을 영이 알면 지렛대. 명령의 부주의한 표현이 파멸. ★★ → **계약형 소환 소켓**: 펜타클 역할 아이템이 없으면 역습 확률. 대가로 영웅의 이름을 내주면 특정 죄종 몬스터에게 항상 표적. 본작 7부하와의 배신 서사에 "계약"이 원래 있다 — 낙인 = 계약의 흔적.
- **위처 3 룬워드·글리프워드**(게임 고유, 소설엔 없음): 룬장인 5,000→10,000→15,000 크라운 3단계. **소켓 3개짜리에만**, **3슬롯을 전부 소모**해 특수 효과 1개(기존 룬석 자동 제거). 예: Severance(휠·렌드 사거리), Invigoration(만피 시 회복량→피해), Levity(모든 갑옷을 경갑 취급). 개조 시 인챈트 파괴. ★★★ → **3소켓 = 1워드**: 작은 접사 3개(가산) vs 큰 규칙 변경 1개(질적)의 **배타 선택**. 단어 레시피 = 죄종 3조합 → 죄종 세트효과 보류의 대안("세트"가 아니라 "단어"로, 8부위 다 맞출 필요 없이 3개 조합만으로 빌드 성립).

### L2-9. 조사자 종합 — 본작에 맞는 후보 규칙 (**제안이지 결정 아님**)

1. **헤말러지형 낙인 소켓(가장 세계관 적합)** — 처치한 악마에게서 "못"을 얻고, 죄종(7) × 결합점(부위 8)로 효과 결정. 못 수가 늘수록 영웅의 자율성(파견 판정·편성 준수)이 떨어진다. 부재 정산 중 미장착 못은 감쇠. 통제성: 못 수 상한을 화면에 드러낸다.
2. **브레스형 개수 세트** — 부위를 안 따지고 같은 죄종 접사 개수만 세어 3/6/9. 현행 세트포인트와 동형이라 추가 시스템 없이 "룬 층"을 흡수.
3. **위처형 단어 봉인** — 한 부위 접사 슬롯 3개를 봉인해 죄종 3조합 "단어" 1개. 세트효과 보류를 대체하는 가장 싼 안.
4. **아온형 지역 각인** — 챕터 이동 시 낙인에 지역 선을 추가해야 그 지역에서 효력. 파워 인플레 억제 + 챕터=죄종 활용.
5. **호크룩스형 부활 조각** — 보스 재료를 "영혼 조각"으로, 사망 대신 파괴. 방치형 계약을 아이템으로 구현.

권고: 1개만 고르라면 **1(헤말러지)**, 최소 비용이면 **3(단어 봉인)**. 파브리얼의 "우리 금속" 축은 1에 3~4종 모드로 얹으면 되고 별도 시스템 불필요.
