## L3. 일본 만화 · 애니 · 라이트노벨

> 조사: 항목마다 팬덤 위키·나무위키 2~3개 대조. 확인 못 한 세부는 **[미확인]**.

### L3-1. 베르세르크 — 베헬리트 / 희생의 낙인 / 광전사의 갑주

- **베헬리트**: 인면 알. 인과율이 소유자를 고른다. 소유자가 절망의 극한(죽음 직전)에 몰리면 갓핸드가 강림해 "강마의 의식". **대가 = 생전 가장 소중히 여긴 사람(들)을 제물** — 제물에게 희생의 낙인. 전생하면 사도(영생), **적색 베헬리트**로는 갓핸드. 잃어버려도 인과율로 **되돌아온다**. [미확인] 재사용·양도. ★★★
  - **번역**: 파티 전멸 직전(HP 임계)에만 발동하는 소모품, 대가 = **파티원 1명 영구 소실**, 소유자 승격. 인과율 = 트리거가 조작이 아니라 상태 판정. **본작**: 레어 영웅 무한 생성이라 "영웅 제물"이 경제적으로 성립하는 드문 세계관 — 단 방치 계약과 정면충돌 → **자동 발동 금지, 명시 선택만**.
- **희생의 낙인**: 제물에게 새겨지는 인장. **악에 반응해 피를 흘린다** — 사도 근처 방울, 갓핸드 근처 분출 = **위험 감지기이자 거리·등급 센서**. 낙인자는 "틈"에 살며 **밤마다 망령이 몰려든다**. 낙인자 둘 동행 시 통과 마을마다 재앙. 마녀의 임시 봉인으로 완화, 영구 해제 없음. ★★★
  - **번역**: 영구 디버프(원정 중 조우율↑) + 패시브 센서(보스 근접 경고). **본작**: 바알의 낙인과 거의 1:1. **"출혈 강도 = 근처 악마의 격"**은 스테이지 진입 전 위험도 UI로 바로 쓸 수 있다. "동행자가 재앙을 부른다" = 파티 3인 전원이 낙인 페널티 공유.
- **광전사의 갑주**: **고통 인식 차단** → 한계 초과 전투, 부상 부위 강제 고정. 대가: 반복 사용 시 **감각 상실(시력·미각), 손 떨림, 정신 침식 누적**. 외부(시르케)가 눌러 회수. ★★★
  - **번역**: 사망 판정을 '부상'으로 치환하되 **영구 능력치 감소 누적**, 외부 힐러 필요. **본작**: 부상/치료 모델과 결합 — "부상 대신 싸운다, 대신 치료로 안 지워지는 흉터". 이중 처벌(낙인 디버프 + 흉터) 주의.

### L3-2. 강철의 연금술사 — 호문쿨루스 7 / 현자의 돌 / 등가교환 ★★★

- "플라스크 속 난쟁이"(아버지)는 크세르크세스 국민 절반의 영혼으로 만든 현자의 돌을 몸으로 삼은 존재. **인간적 결점 7가지(7대 죄악)를 떼어내 각각 호문쿨루스로** 만들었다. 각 호문쿨루스는 **현자의 돌을 핵**으로, 몸 어딘가에 **우로보로스 문양**(러스트 가슴, 글러트니 혀, 엔비 허벅지).
- 재생 = 핵의 영혼이 소모될 때까지 → **유한 스택**. 죄를 떼어낸 뒤 아버지는 **무미건조** — 힘은 남고 인간성이 빠진다. [미확인] 아버지의 재흡수(글러트니·초대 그리드).
- **등가교환**: 현자의 돌은 이를 **우회하는 화폐**(영혼 = 재료). **인체연성 통행료**: 진리가 "욕망과 관련된 부위"를 가져간다 — 에드 왼다리(+오른팔), 알 몸 전체, 이즈미 내장, 머스탱 시력. 문을 통과하면 연성진 없이 연성 가능.

**번역**: ① 보스 = 본체에서 떼어낸 죄 1개 + 핵 1개, 죽이면 핵이 드롭되고 본체(플레이어)가 그 죄를 **다시 삼켜** 복구 — **조각 회수형 성장**. ② 인체연성 = 강력한 크래프트인데 **성공해도 부위(슬롯) 하나를 잃는다**. ③ 현자의 돌 = 등가교환을 건너뛰는 화폐, 재료가 영혼(도감 처치 수).
**본작 접점 — 핵심**: 아버지↔7호문쿨루스는 **바알↔7부하와 동형**, 방향만 반대(FMA는 스스로 떼어 담았고, 본작은 배신해 가져갔다). 접합하면 **"7부하는 원래 바알이 떼어 맡겨 둔 7죄(자기 자신의 조각)였고 그들이 그 조각을 들고 도망쳤다" → 악마를 죽여 힘을 흡수 = 자기 조각 회수** — "왜 그 악마의 죄종 힘만 흡수되는가"에 세계관 답이 생긴다. 대가 방향도 가져올 수 있다: 아버지는 죄를 뗄수록 인간성을 잃었다 → 바알은 **죄를 되찾을수록 인간 몸이 무너진다**(낙인 확장 = 챕터 진행 = 디버프 강화) — 이미 있는 "챕터 = 상태이상" 축으로 표현 가능. 우로보로스 = 챕터 보스의 낙인 드롭 위치·문양.

### L3-3. 나루토 — 주인 / 팔문둔갑 / 인주력 / 사륜안 이식 ★★★

- **주인(呪印)**: 쥬고의 효소 + 선술 차크라 + **오로치마루의 의식 일부**. 새길 때 **생존율 10%**. 상태 1(출력 폭증, 이성 상실) → 상태 2(형태 변이). 인장이 몸과 정신을 **침식**, 신체 탈취 후보. 술자가 죽어도 안 사라짐. [미확인] 제거 수단. → 이식 성공률 낮은 영구 버프, 켤 때마다 '침식 게이지', 임계 시 **플레이어 통제 이탈**. **본작**: 통제 이탈은 방치 계약 위반 → 침식은 **회복 가능한 부상**으로 치환해야 안전.
- **팔문둔갑**: 8개 경혈을 순서대로 개방. 제1문 = 근육 제한 해제(100% 출력). 4~7문부터 근육 파열·골절(치료 가능). **제8문 사문은 반드시 죽는다**. → **단계 다이얼**: 단계 n = 출력 ×f(n), 대가 = 전투 후 부상 g(n), 마지막 = 영구 사망. 문 개수가 UI 자체(8칸 바). **본작**: 원정 출발 전 "낙인 개방 단계" 위험 다이얼. 방치 중 자동 상승 금지, 기본값 0.
- **인주력**: 그릇 1명당 미수 1체. **뽑아내면 숙주는 죽는다**(예외: 우즈마키 생명력). → 영웅에 1개만 박히는 최상위 소켓, **빼면 영웅이 죽는다** = 이전 불가, 영웅 소실로만 회수 → 내용물은 세계로 돌아와 재드롭. **본작**: 유니크의 "귀속"을 서사화. 레어 영웅에게 유니크급 정체성을 주는 수단.
- **사륜안 이식**: 비우치하는 **눈을 끌 수 없어 차크라가 계속 새어나간다**(이마 보호대로 덮음). 외과 수술 = 비가역. → 타 직업 능력을 통째로 이식, 대가 = **상시 자원 누수**(최대 HP/기본 능력치 감소), 제거 불가. **본작**: 기본 능력치 불변식(`attr_equip_bonus=0`)과 충돌 → 넣으려면 불변식 수정 확인 선행.

### L3-4. 헌터×헌터 — 제약과 서약 / 그리드 아일랜드 ★★★

- **제약과 서약**: 스스로 제약을 걸고 서약(어길 시 페널티)을 맹세하면 출력↑. **제약이 가혹할수록, 페널티가 클수록 강하다**. 크라피카: 속박 사슬은 "환영여단에게만" — 어기면 죽음; 심판 사슬은 **상대에게 규칙을 거는 계약**. 곤: "모든 넨·재능·미래를 통째로" = **선불 거래**. 절대시간: **1초당 수명 1시간**(지속형 코스트, ★). → ① 장비/스킬에 **제약 접사**("대상이 죄종 X일 때만") → 배율↑, 어기면 효과 소멸 또는 부상. ② 선불형: 히든 상한선을 영구히 깎아 지금 출력을 산다. ③ 지속형: 켜 두는 동안 자원이 빠진다. **본작**: "챕터 = 죄종"이라 **"죄종 X 전용" 제약**이 자연스럽다 — 낙인 크래프트의 죄종 지정에 "그 챕터에서만 발동, 대신 배율↑"을 얹으면 D2 룬워드처럼 "어디에 들고 갈지"가 결정. 페널티는 **효과 소멸형**(JJK 자기 속박)이 방치 계약에 맞다.
- **그리드 아일랜드 카드**: 북 = **지정 포켓 100(000~099, 같은 번호만) + 자유 포켓 45**. 스펠 카드 40종. 카드마다 **랭크와 변환 한도 수**(세계에 동시에 존재할 수 있는 개수, 3~100장 이상) — **랭크가 높을수록 한도가 적다**. 한도가 차면 누가 되돌리기 전까지 새로 변환 불가. 획득 후 **1분 안에 북에 넣지 않으면** 되돌아가고 다시 카드화 불가. [미확인] 100장 완성 보상 3장 반출. → "도감이 곧 인벤토리: **번호 고정 슬롯**(유니크 1종 = 1슬롯) + 자유 슬롯. 유니크마다 **월드 존재 한도**". **본작**: 싱글이라 "월드 한도" = **세이브 내 보유 상한**("유니크 A는 세이브에 최대 1개, 분해하면 다시 드롭 가능"). 몬스터 도감과 **아이템 도감(지정 포켓)**을 한 화면으로 합칠 근거.

### L3-5. 주술회전 — 속박 / 주구·주물 / 스쿠나의 손가락 / 흑섬·영역 ★★★

- **속박(縛り)**: **자기 속박**은 어기면 **이익만 사라지고 끝**(페널티 없음). 속박 위에 속박을 겹쳐 앞선 속박의 단점을 지우고 이익만 취한 뒤 깨는 것도 가능(스쿠나 영역 99초 → 범위 축소 속박으로 시간 제한 해제 → 나중에 파기). **상대와의 속박**은 어기면 페널티 강제. **천여주박**: 태어날 때 걸린 속박 — 주력 0 대신 초인적 육체(토지), 몸을 잃은 대신 막대한 주력(메카마루). [미확인] 술식 공개 = 출력↑. → 자기 속박 = **어겨도 손해는 버프 소멸뿐**인 조건부 접사(**방치형에 가장 안전한 제약 모델**). 천여주박 = 영웅 생성 시 **한 축 0 ↔ 다른 축 폭증**. **본작**: 영웅 생성이 "합 고정·주력 축"이라 절반 구현 — **극단값 롤(한 축 0)** 허용하면 레어 영웅에게 유니크급 개성.
- **주구·주물·스쿠나의 손가락**: 특급 주물은 **파괴 불가**(속박이 보증). 손가락 **20개**(팔 4·다리 4 신체), 각 = 전성기의 **5%**, 20개 = 100%. 손가락이 **숙주를 고르고**, 천 년이 지나도 저주를 끌어모은다. 삼키면 그릇. → 보스의 조각 N개 = 완전체 100%, 조각은 **드롭이자 적 유인**(조우율↑), 삼키면 그릇 판정 실패 시 폭주. **본작**: 낙인 = 챕터 보스 재료를 "**보스 1체 = 그 죄종 힘의 조각**"으로 읽으면 스쿠나 손가락. 첫 조각은 바알의 낙인에 **삼켜**(영구 소켓) 나머지는 크래프트로 **소모** — "지닐지 쓸지"의 D2 룬식 선택. 손가락이 저주를 부른다 = 희생의 낙인과 겹쳐 **낙인 = 조우율 디버프**를 두 번 정당화.
- **흑섬**: 시차 **0.000001초 이내**, 위력 **2.5제곱**, **의도적 발동 불가**. **영역전개**: 필중 + **주력 대부분 소모 + 이후 술식 제한**, 동급 영역 겹치면 상쇄. → 흑섬 = 플레이어가 못 고르는 상위 크리 티어. 영역 = **필중 + 자원 전량 소모 + 쿨 동안 스킬 봉인** 궁극기. **본작**: 액티브 슬롯 3 중 하나를 "영역형(자원 전량)"으로 두면 자동전투에서도 발동 조건 규칙이 된다.

### L3-6. Fate — 영주 3획 / 보구 / 성배 7 ★★★

- **영주**: 마스터 손등의 3획 문양 = **절대 명령 3회**. 계약 시 대성배가 **자동 생성**. **쓸 때마다 한 획씩 꺼진다**. 3획 소진 = 강제권 상실. **획수를 늘리는 방법은 남의 것을 빼앗는 것뿐**(이전 약 1시간). 1획으로 "위신의 서" = 서번트 **일시 양도**. [미확인] 명령의 격. → **3충전 소모형 슬롯**: 계약(고용) 시 1회 지급, 재충전 불가, 타 영웅 것 탈취로 이전. **본작**: 액티브 슬롯 3과 숫자상 겹치지만 영주의 본질은 "재충전 안 됨"이라 반복 원정과 상성 나쁨 → **유니크 영웅 고용 시 1회성 3획**(부상 무시 1회·탈출 1회·확정 크리 1회) 같은 **일회성 보험**으로.

### L3-10. 조사자 종합 — 본작 세계관에 충돌 없이 붙는 규칙 넷 (**제안이지 결정 아님**)

1. **조각 수집(FMA 호문쿨루스 + 스쿠나 손가락)** — 가장 세계관에 맞는다. "7부하 = 바알이 떼어 맡긴 자기 죄의 조각"으로 서사를 잡으면 챕터 보스 처치 = 자기 회수. 낙인의 첫 1개는 바알의 낙인에 **삼켜**(7소켓, 죄종당 1, 영구) 나머지는 크래프트로 **소모** — "지닐지 쓸지". 회수의 대가는 FMA 역방향: 죄를 되찾을수록 인간 몸이 무너진다(= 낙인 디버프 = 챕터 상태이상 강화) — 이미 있는 "챕터 = 상태이상" 축으로 표현.
2. **자기 속박형 제약 접사(HxH + JJK)** — "죄종 X 챕터에서만 발동, 대신 배율↑". 위반 시 **효과 소멸만**. 낙인 크래프트가 이미 "죄종 지정"이라 접사 하나 추가로 끝.
3. **처치 기록형 세트(Fate 성배 7)** — 보류 중인 죄종 세트효과를 "장비 맞추기"가 아니라 **"7죄종 보스 처치 기록"**으로 열면 도감과 하나가 되고 장비 슬롯을 소비하지 않는다.
4. **월드 프로텍션(오버로드)** — 죄종 보스는 자기 죄종 상태이상 면역.
