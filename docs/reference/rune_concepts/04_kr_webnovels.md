## L4. 한국 웹소설 (게임 판타지 · 헌터물 · 회귀물)

> 검증: 항목당 나무위키 해당 작품 설정/인물 문서 직접 열람(★★★), 미러·팬위키·검색 요약(★★), 단일 요약(★). 팬덤 위키는 402 차단 → 스니펫만. 확인 못 한 세부는 **[미확인]**.

### L4-1. 전지적 독자 시점 — 성흔(星痕) · 설화 · 성좌 후원 ★★★

- **성흔**: "화신 본인의 스킬과 다른, **배후성으로부터 부여받는** 힘." 성좌의 근간 설화와 관련된 능력. "**오직 성좌들로부터만**" — 도깨비 보따리 구매·직접 전수 불가.
- **설화**: "특성·스킬·성흔이 도구라면 설화는 **존재의 근간을 이루는 힘 자체**." 역사급 → 전설급 → 준신화급 → 신화급 → **거대설화**. "자신을 구성하는 설화를 잃어버리면 소멸." 거래 화폐로도 쓰이며, 거대설화 **지분**만으로도 막대한 개연성.

| 규칙 | 내용 |
|---|---|
| 의존성(대가) | "성흔을 내린 성좌와의 **연결이 끊어진 화신은 해당 성흔을 사용할 수 없게** 된다" — 빌린 힘 |
| 성장 | 배후성과의 **동조율**이 높을수록 성흔 성장↑ |
| 개수 | 한 배후성에게서 **복수 성흔**: 이현성(강철의 주인) 4종, 이지혜(해상전신 이순신) 4종(유령함대 12척 소환 등) |
| 배후성:화신 | 성좌 역량에 따라 2명 이상과 계약 가능 |
| 화신:배후성 | 여러 배후성 동시 — **[미확인]** |
| 자유 제약 | 계약 화신은 배후성 의사에 따라 자유 일정 부분 제약, 계약서는 성좌가 일방적으로 |
| 자립 경로 | "배후성이 없을 것" + "**스스로 5개 설화를 쌓으면 성좌**". **배후 계약을 하면 성좌 가능성이 사라진다** |
| 코인 | 능력치 강화 비용 = (⌊레벨÷10⌋+3)×100; 도깨비 보따리 = 캐시샵+거래소+경매(회원 등급제) |
| 스킬/특성 | 스킬 D~SSS, 레벨 최대 10; 특성 일반→희귀→영웅→전설→신화, "특성 전용 스킬 패키지" |

**번역**: **후원자 = 계약 슬롯, 성흔 = 계약에 딸려오는 능력 묶음(1 계약 : n 능력)**. 계약이 끊기면 즉시 잠김 → "빌린 힘" 모델. **자립 경로가 상위 승격 조건** — 후원을 받는 순간 승격 경로가 닫히는 강력한 배타. **설화 = 이력 기반 장비**(겪은 사건이 등급 있는 장비/버프, 잃으면 존재 소멸 = 벗을 수 없는 장비).
**본작 접점**: 어휘가 같지만 **방향이 반대** — 전독시 성흔은 *빌려온 힘(계약 의존·회수 가능)*, 본작 낙인은 *빼앗은 힘(악마 처치로 흡수·누적, 대가는 저주)*. 같은 이름을 쓰면 독자가 전독시 문법을 기대하므로 UI 문구로 초반에 못 박을 것. 가져갈 것은 이름이 아니라 **"1 후원원 : n 능력 묶음" + "자립하면 상위 티어"** 구조 — 예: 낙인의 죄종 계약 1개(배타) ↔ 그 죄종의 성흔형 패시브 여러 개, 갈아타면 이전 죄종 성흔 잠김. 설화의 "이야기가 곧 장비"는 **도감 처치 수 모델**과 결합 — "챕터 보스 처치 이력" 자체를 등급 있는 설화 슬롯으로.

### L4-2. 나 혼자만 레벨업 — 룬석 · 그림자 추출 ★★★/★★

- **룬석**: 스킬이 담긴 돌. 강태식 사망 후 '은신' 룬석 습득; 전직 보상 '지배자의 손길' **부숴 습득**; 카미쉬의 룬석(드래곤 피어)은 국가 단위 보상급. 사용 = 파괴 → 소모형 1회. [미확인] 상점 판매·스킬 개수 상한.
- **그림자 추출**: "죽은 존재의 그림자를 통해 동일한 개체를 소환."

| 규칙 | 내용 | 신뢰 |
|---|---|---|
| 시도 횟수 | **3회** 제한(이그리트 2회 거부 후 3회째 성공) | ★★★/★★ |
| 실패 확률 | 대상 능력치·사망 후 경과 시간에 비례 | ★★ |
| 하향 보정 | 성진우보다 강하면 차이에 비례해 하향 | ★★ |
| 불가 대상 | 무생물 · 오염된 마나 · 영체 군주 · 오래된 시체(카미쉬 **8년** 경과 자동 해제) | ★★★ |
| 보관 상한 | 초기 "20명" → 최종 1천만. 초과 시 기존 병사 **해제하고 자리 확보** | ★★★/★★ |
| 해제 = 영구 | "추출이 해제된 병사들은 무의 세계로 돌아가기에 불러들이는 것이 불가능" | ★★★ |
| 등급·성장 | 졸병/일반/정예/기사/정예기사/장군/원수/총군단장. 경험치로 성장, 생전보다 강해질 수 있음 | ★★★ |

**번역**: **도감 → 병력 파이프라인**: "3회 굴림 상한 + 강할수록·오래될수록 실패↑ + 실패해도 시체(재료)는 소모 안 됨" — 확률 크래프트인데 재료 파괴 대신 **기회 소진**으로 페널티. **보관 상한은 레벨/칭호로만 확장, 초과 시 방출(영구 소실)** → "무엇을 버릴까" 결정. **등급 계승 + 하향 보정 + 이후 성장**. 룬석 = "몬스터 스킬 1개를 담은 소모형 카드", 가치가 몬스터 등급에 비례.
**본작 접점**: 도감 = 처치 수 모델과 직결. "**처치 수 N 달성 → 해당 몬스터의 '그림자 결정' 추출 시도권(3회)**"로 도감을 소켓템 공급원으로. 결정에는 몬스터 스킬 1개(룬석)와 등급, 소켓 상한은 영웅 레벨/챕터로만. 불가 조건은 "보스/유니크 몬스터는 추출 불가, 죄종 보스는 낙인 크래프트 전용"처럼 **채널 분리**.

### L4-3. 템빨 — 아이템 등급 · 개조 총량제 · 성장형 · 1인 1클래스 ★★★

- 그리드 = 전설적 대장장이. 클래스 등급 신화/레전드리/유니크/에픽/레어/노멀 + 고대. 아이템 등급 노멀~레전드리~신화 + **유일·성장형·비화**.

| 규칙 | 내용 |
|---|---|
| 1인 1클래스 | "일부 상위 클래스는 한 사람이 전직 시 타인은 전직 불가능" |
| **개조 횟수** | "이해도 100%인 아이템을 개조. 마스터 레벨까지 올려도 **10번까지만**, **아이템당 1번**" |
| 성장형 부여 | "설계도를 뛰어넘는 실력으로 제작할 때 **낮은 확률**로 획득, 등급 상승 시마다 사용자에게 맞춘 스탯·스킬 자동 부여" |
| 강화 | 성공/실패/**파괴** 3결과, 축복받은 강화석은 성공률↑ |
| 이해도 | 개조·강화 전제, 감정으로 숨은 옵션 발견 |
| 귀속 스킬 | "신화 등급이 아닌 아이템 귀속 스킬은 레벨업 안 됨" |
| 스킬북 | [미확인] |

- **옵션 서술 방식**: "깨달음을 주는 불타는 열망의 무아지경의 칼날" — 고정 3500 공격력 / 물리·마법 20%↑, 화염·암흑 30%↑ / 패시브 "불의 화신"(스태미나 5 이하 불가) / 액티브 "날아오르라!"(조건부). 형식 = **이름(수식어 누적 = 제작 이력) → 등급/유일 → 고정 수치 → % 옵션 → 귀속 패시브/액티브(조건 명기) → 성장 여지**.

**번역**: **개조는 총량 10회, 아이템당 1회, 이해도 100%** = "크래프트 자원은 재료가 아니라 *횟수*" — 어떤 아이템에 쓸지가 결정. 성장형 = 랜덤 리롤 대신 "사용 이력 → 옵션 확정". 1인 1클래스 → 싱글에서 "유니크 영웅 1회 스폰".
**본작 접점**: 본작 크래프트 = 통제의 계단인데, **개조 횟수 총량제**는 낙인 크래프트에 붙일 만한 제약(챕터 보스 재료 + 회당 1회 + 총량 캡). 이름에 이력을 누적하는 서술은 본작 `nm()`/`eliteName()` 조립 규칙과 같은 층.

### L4-4. 달빛조각사 — 조각술 · 파괴술 · 생명 부여 · 감정/수리 ★★★/★★

| 규칙 | 내용 |
|---|---|
| 스킬 티어 | 초급/중급/고급/마스터 × 각 9레벨. 사망 시 숙련도 하락. **비생산직은 생산 스킬 중급 이상 불가** |
| 조각품 등급 | 평작/걸작/명작/대작 + 역사적·불가사의 |
| **조각 파괴술** | 예술 스탯을 일시적으로 전투 스탯으로 전환. 배율 **평작 1:2, 걸작 1:4, 명작 1:6, 대작 1:20** (★★) |
| 생명 부여 | 대가 "**레벨 2 하락 + 예술 10**". 생명체 레벨 = 조각사 예술 수치, 걸작 +10%/명작 +15%/대작 +20%. "같은 종류 10마리 이상 무리" |
| 아이템 구조 | 이름·내구도·해설·옵션. **감정 스킬 수준에 따라 보이는 정보가 다름** |
| 수리 | 최대 내구 감소, 중급 수리 이상이면 회복. "수리불가" 옵션 |
| 착용 제한 | 절대적이지 않음 — 대장장이 스킬로 감소 |

**번역**: **별도 축(예술)을 파괴(소모)로 전투 스탯에 등급 배율 환전** — 소모형 버프의 원형. **생명 부여 = 영구 스탯 지불 소환**. **감정 수준 = 정보 노출 수준**(미감정 아이템의 스킬화).
**본작 접점**: 예술 축은 없지만 **"등급 × 배율" 소모형 버프 공식**은 낙인/차암 설계에 그대로. "동일 종 10마리 상한"은 소환 도입 시 참고.

### L4-5. 튜토리얼이 너무 어렵다 · SSS급 자살헌터 · 나노마신 · 책 먹는 마법사 · 지오

- **튜토리얼**: 난이도 4종, 100층 — "**백신회의 신들이 한 층씩** 만들었기에 100층". 신들이 관전하며 **권능 선물**로 개입. 스킬 3경로: 층 보상 / 권능 / 각성. 화폐 2종: 포인트(구매) + **정보값**(관리자에게 정보·조언 구매). [미확인] 유물 등급·사망 규칙. ★★★ → **층 = 후원자 1명**: 스테이지별 후원 성좌 모델. **화폐 2종 분리(구매 vs 정보)**. **본작**: "챕터 = 죄종 = 지역"에 "챕터 = 후원자(죄종 악마) 1명"을 겹치면 같은 구조.
- **SSS급 자살헌터**: S+급 스킬 "**너처럼 되고 싶다**": "적에게 죽으면 자동 발동. 당신을 죽인 적의 스킬 중 1개를 복사. ※단, 죽습니다!" **동일 대상 재복사 불가**. 사망 시 **뒷면만 보이는 카드** 중 선택(랜덤). 부활 없음 → 회귀 스킬과 결합해야 실용. 스킬 등급 F~EX, 카드 색 황금(S↑)/은/동. **보유 개수 F급 4, 등급 1단계마다 +1**. 카드 파괴로 삭제 가능하나 **성좌가 준 것은 포기 불가**. ★★★ → **"패배가 획득 조건"**: 전멸 전투에서 자신을 죽인 몬스터의 스킬 카드 1장(뒷면 랜덤), 같은 몬스터에게서 두 번 못 얻음 — **패배를 자원으로 바꾸는 방치형 안전망**. **스킬 슬롯 = 등급 종속(4+등급)**, 후원자 카드 = 잠금 슬롯. **본작**: 액티브 슬롯 3 + 스킬 카드 합성과 바로 맞물린다. "**나를 죽인 몬스터**" 기준이라는 역발상이 방치 계약과 궁합 — 패배 리포트에 카드 1장.
- **나노마신**: 제7세대 나노머신 주입, 약 65억 개 전신 배치, **사망 시 배출**. 초재생·항상성·**스캔**(비급 655개 습득)·튜토리얼 모드. "기록상 30% 이상 사용 사례 없음", **단독으로는 강해지지 않음**(재능 곱). 무공 사본은 얻어도 **수련은 본인 몫**. ★★★ → **소켓 대신 몸 = 영구 이식, 1인 귀속, 사망 시만 회수**, 기능은 "증폭기". 본작 유니크 15의 고유 패시브와 같은 층.

### L4-9. 조사자 종합

1. **낙인(Stigma) 어휘 충돌** — 전독시 성흔은 "빌린 힘", 본작 낙인은 "빼앗은 힘". 같은 이름을 쓰면 독자가 전독시 문법(배후성·계약 해지)을 기대 → 본작은 **낙인 = 흡수 누적 / 대가 = 저주**임을 UI 문구로 초반에 못 박는다. 가져갈 것은 "1 후원원 : n 능력" 묶음과 "갈아타면 이전 것 잠김" 배타 규칙뿐.
2. **도감 ↔ 소켓템(나혼렙)** — "처치 수 임계 → 추출 시도권 3회 → 결정(몬스터 스킬 1 + 등급 계승)". 보관 상한은 레벨/챕터로만, 초과 시 방출. 죄종 보스는 낙인 크래프트 전용으로 **채널 분리**.
3. **2차 층 제약 후보(확인된 원전 규칙만)** — 시도 횟수 총량(템빨 10·나혼렙 3), 미계약 70%(도굴왕), 등급별 소모 배율(달조 1:2~1:20), 종류별 슬롯 상한(소엑 1/3/2/1), 등급 종속 슬롯 수(SSS급 4+등급), 동일 대상 1회(SSS급).
4. **단순화 관점** — 새 게이지 없이 기존 축(도감 처치 수·희귀도·레벨)만으로 표현 가능한 것: 나혼렙 추출(도감), SSS급 패배 카드(리포트), 도굴왕 70%(귀속 플래그 1비트). 예술 스탯·동조율·개연성처럼 **새 수치 축이 필요한 것은 후순위**.
