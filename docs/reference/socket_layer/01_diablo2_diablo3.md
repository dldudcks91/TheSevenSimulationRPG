### G1-8. 트레이드오프·제약

- 인벤 격자 vs 차암 파워 · **회색 베이스의 가치**(소켓 수·ilvl·에테리얼이 맞는 흰 템이 유니크급) · 큐브 소켓 **랜덤 개수**가 베이스를 망칠 확률(Enigma용 3소켓 노리다 4 뜨면 폐기)
- **소켓 = 1회성 결정**: 유니크 1소켓에 주얼/룬/젬 중 하나, 되돌릴 수 없음. 룬워드 순서 실수 = 룬 소실
- **룬 승급의 손실 산술**: 2:1이라 승급마다 가치 절반이 증발 — 낮은 룬을 태워 높은 룬을 사는 싱크
- 타겟 파밍의 **천장 명시**: 1인 1유니크 차암, 파티 Hellforge 1개, Countess 상한 Ist

### G1-10. 설계 원리

1. **한 아이템·다중 문맥** — 같은 룬/젬이 무기·방어구·방패에서 다른 효과 → 68종으로 200+ 효과 후보, 접사 풀은 안 건드림
2. **결정론적 레시피 + 확률적 재료** — 룬워드 결과는 100% 예측(통제성), 재료만 확률 → "무엇을 모으면 무엇이 되는지" 안다 = 장기 목표
3. **회색 아이템에 생명** — 희귀도 최하단이 최상단 재료 → 드롭 테이블 전체가 유의미
4. **지수 승급 = 자연 환율** — 어떤 룬도 쓰레기가 아니다
5. **소켓 = 1회성 의사결정** — 파괴성이 결정을 진짜로 만든다
6. **차암 = 장비 슬롯 밖의 연속 자원** — 부위 고정 게임에서 "n칸"으로 미세 조정

**가져올 것**
1. **"한 아이템·부위별 다른 효과" 매트릭스** — 본작 7죄종×8부위 접사 매트릭스와 같은 모양. "죄종 룬 7종(×등급 2~3)" 하나로 부위마다 다른 고정 효과 → **접사 풀 희석 없이** 2차 층. 효과는 combat_stat 27종의 **동일 키** 참조
2. **결정론적 레시피 = 통제 계단의 최상단** — 룬워드의 본질은 "재료를 알면 결과를 아는 아이템". 본작은 크래프트(낙인)가 이미 그 자리 → 별도 층보다 **낙인 크래프트의 레시피 표현**으로 흡수 가능한지 먼저 검증
3. **3:1 / 2:1 승급 = 저급 드롭의 싱크** — 방치 파밍의 산더미 저급 드롭에 "버릴 게 없다"는 감각. 단 D2 확률 이식 금지, 사다리 길이는 7죄종×3등급=21 정도로 압축
4. **Sunder식 "강력 효과 + 자기 페널티 1아이템"** — 파티 단위 부적 슬롯 1~2개로 두면 인벤 격자 없이 차암의 의사결정만 가져온다. "1개만 소지" 규칙도 그대로
5. **Hel 레시피 = 베이스 구제·내용물 파괴** — 회수 불가를 택해도 "베이스는 산다"는 최소 통제성

**피할 것**
1. **인벤 격자 = 파워** — 방치형 계약·리포트 루프에 격자 테트리스는 마찰만. 본작에 격자 인벤 자체가 없으니 도입 금지
2. **룬워드가 유니크를 무력화** — 긴 체이스 원칙 위반. 레시피형은 유니크 미만·사이드그레이드로 캡
3. **소켓 수 RNG 3중 구조** — 소켓은 **부위별 고정 개수**로
4. **거래 전제 희소성** — 싱글에서는 벽. 타겟 파밍처(Countess 상한형) 필수
5. **아이템 종류 폭발**(젬 35+룬 33+주얼 무한+차암 3크기) — 층 1개, 종류는 죄종 축 1개

### G2-2. 상세

**일반 젬** (공식 가이드 ★★★, icy-veins ★★★) — 19단계(Chipped … Marquise → Imperial → Flawless Imperial → Royal → Flawless Royal). **Flawless Royal 1개 = Marquise 81 + DB 4 + 골드 9.8M**. 최상급: Emerald 무기 **치명 피해 +130%** / Diamond 투구 쿨감 12.5%·기타 모든 저항 +78 / Ruby 기타 힘 +280 등. 제거 = Jeweler 골드(등급 비례).

**전설 젬** (Blizzard 포럼 가이드 ★★★, maxroll ★★★) — 2.1.0(2014) 도입. 반지·목걸이 소켓만 → 캐릭터당 **3개**. 같은 젬 2개 불가, 계정 귀속. 가디언은 **미보유 젬만** 드롭. **Urshi 승급** GR당 최대 5회, 성공률 = (GR 단계 − 젬 랭크): ≥+10 → 100% / +7 → 70% / **+6~0 → 60%** / −1 → 30% / −5 → 2% / ≤−16 → 0%. 최대 150. **랭크 25**에서 2차 효과. 대표: **Bane of the Trapped**(CC 적 +15%, 랭크당 +0.3%) / **Stricken**(타격마다 누적) / **Powerful** / Taeguk / Gogok / **Legacy of Dreams**(세트 없는 전설마다 +3.75%, 13개 최대 9,750%) / Boon of the Hoarder.

**카나이 큐브** (2.3.0 패치노트 ★★★) — 추출: 현상금 재료 5 + **DB 5**, 아이템 **파괴**. 슬롯 3. 규칙: **항상 최대 롤**(150-200% 롤 반지도 200%), 착용+큐브 중복 불가, 스탯은 안 오고 오렌지 파워만. 기타 레시피: Law of Kulle 리포지(FS 50), Hope of Cain 레어→전설, Skill of Nilfur 세트 부위 변환, Work of Cathan 레벨 요구 제거, Curiosity of Lorath Nahr 원시 승급. 효과: "저롤 전설도 추출로 시즌 내내 가치 유지" — 슬롯 3 = **장비 슬롯 +3**.

**미스틱** (공식 ★★★) — **아이템당 1접사만** 영원히 리롤("한 번 고르면 다른 접사는 잠김"), 매 시도 새 후보 2개 vs 유지, 골드 누진. 접사를 소켓으로 리롤 가능. 인챈트 즉시 계정 귀속.

**Ramaladni's Gift** (★★) — 소켓 없는 무기에 **추가 접사로** 소켓 부여(접사 상한 초과). 배경: "무기 = 소켓 필수"라 소켓 없이 나온 무기는 폐기 → 다른 접사 1개를 포기해야 했던 문제 해소.

**Augment** (maxroll ★★★) — 고대/원시 + 전설 젬(무기 30+/장신구 40+/방어구 50+) + Flawless Royal 3 → 주 능력치 **랭크×5** 영구(150=750). **전설 젬 파괴**. 13부위×750 = 9,750. 역할: 전설 젬(3개면 충분)의 **잉여 수요 창출** = 젬 싱크 + 장기 목표.

### G2-3. D2 대비 삭제·단순화 — 개발자 발언

- **차암/Talisman 삭제** (2011-05-25 Bashiok ★★): "**입고 있는 방어구·무기에서 못 얻는 걸 아무것도 주지 않는다**… 스탯을 더하기 위해 또 다른 아이템 종류를 찾고 저장하게 만드는 건 지루한 일". 개발팀은 D2 차암의 인벤 트레이드오프를 싫어했고, 2010 BlizzCon 전용 차암 인벤(Talisman)으로 해결하려다 통째로 컷.
- **아이템 룬(Runestone) → 스킬 룬** (2012-02 Jay Wilson ★★): 스킬 120×룬 5×등급 5 ≈ **3,000종 아이템**이 될 예정 → "심각하고 지루한 인벤 테트리스" → 아이템에서 떼어 스킬 시스템에 내장. D2 룬의 "빌드 변형" 기능은 D3에서 아이템 층을 떠났다.
- 룬워드 삭제(대체 없음 — "전설 파워"가 고유 효과 담당). 젬 파괴성·인벤 차암·소켓 파괴성 전부 삭제.

### G2-4. 트레이드오프

- 전설 젬 **슬롯 3**: 24종 중 3 → 실제로는 Trapped/Stricken/Powerful(+Taeguk/Zei)로 수렴
- 승급 = **GR 난이도 vs 랭크** 저울: "클리어 가능한 최고 단계 +0~+10"이 최적
- Augment는 젬을 **태운다** → 다시 키울 시간 vs 지금 +500
- 미스틱 1접사 고정 → "어느 접사를 포기하고 리롤할지" 1회성 결정
- 카나이 추출 = 아이템 파괴 + DB 5 → 저롤 사본을 태우는 게 정석
- 젬 제작 9.8M × 10소켓 ≈ 1억 골드 — RoS 골드 싱크의 큰 축

### G2-5. 경제 — 거래 없음, 전부 **싱크·시간 통화**

골드(젬·인챈트) / Death's Breath(젬 상위·큐브 전 레시피) / Forgotten Soul(리포지·인챈트) / 현상금 재료(추출·리포지) / GR 시도(=젬 랭크) / 전설 젬 자체(Augment). 전설 젬 랭크 = "시간의 저장", 계정 공유.

### G2-6. 설계 원리

1. **비파괴 = 재배분 마찰 0** — 빌드 실험 비용이 골드뿐. "통제성 우선"의 극단
2. **성장형 소켓템** — 장비 드롭이 끝나도 젬 랭크가 오름. GR 도전 = 승급 확률로 위험/보상 연결
3. **파워를 아이템에서 분리(큐브)** — 슬롯 안 늘리고 빌드 폭 +3, 저롤 전설에 용도, 스탯은 안 주니 착용 장비 가치 유지
4. **소켓 = 접사 1칸** — 새 게이지 없이 "이 접사 자리를 소켓으로 쓸래?"
5. **문맥별 3효과**(무기/투구/기타)로 젬 5종 = 15역할
6. **싱크 사슬** — 젬→Augment, 전설→추출, 저급→고급, 전부 상위 목표에 흡수

### G2-7. 알려진 문제

- 전설 젬 **3개 고정 메타**(24종 중 실질 5~6) · **수치 인플레**(랭크 150·Augment 9,750·LoD 9,750%) · **젬 19등급의 공허**("70 이전 젬 제작은 무의미") · 카나이 "항상 최대 롤"이 롤 가치 소멸 + 전설 소모품화 · **재료 종류 폭발**(현상금 5 + DB + FS + Ashes + 일반 3) · 차암/룬 삭제로 초기 D3 아이템 심도가 얕다는 비판 → RoS 전설 젬 도입의 배경

### G2-8. 본작 관점 메모

**가져올 것**
1. **비파괴 소켓(골드 회수)** — 본작 핵심 루프가 "3인 파티 장비 **재배분**"이므로 소켓 내용물이 파괴되면 재배분마다 손실 = 루프 자체를 처벌. 회수 비용을 골드로 두면 강화와 같은 싱크 축 재사용
2. **소켓 = 접사 1칸** — 새 게이지 없이 기존 접사 슬롯 하나가 "소켓" 값을 갖는다. 크래프트(낙인)에서 "죄종 지정 + 소켓 여부"를 고르게 하면 통제 계단과 정합
3. **성장형 젬을 원정 난이도와 결합** — Urshi 표는 "스테이지 dlvl vs 젬 랭크"로 직역 가능. 단 **새 게이지**이므로 강화 축으로 표현 불가함을 먼저 증명한 뒤에만
4. **파워 추출(큐브)의 축소판** — 유니크 고유 효과를 영웅에 **1개** 이식(아이템 파괴). 단 "항상 최대 롤"은 채택 금지(장비가 주인공 위반)
5. **Augment식 "성장템을 태워 영구 스탯"** — 긴 체이스 끝의 싱크. 낙인과 경합하므로 하나만

**피할 것**
1. **전설 젬 3개 고정 메타** — 3인 파티면 9슬롯이 같은 젬으로 찬다. 효과가 죄종/부위 문맥 없이 범용이면 반드시 수렴 → 문맥 종속(죄종×부위)으로만
2. **랭크 150·배율 스택 인플레** — 상한 낮게(3~5단계)·선형
3. **19등급·재료 8종** — 등급 3~4, 재료는 골드 + 죄종 재료 1축
4. **파워 항상 최대 롤 + 아이템 소모품화** — 유니크의 롤 체이스를 없앤다
5. **차암 완전 삭제의 교훈** — Bashiok의 논거("장비가 주는 것과 다르지 않으면 존재 이유 없음")는 본작에도 적용: 2차 층은 **장비 접사가 표현할 수 없는 것**(파티 전체 효과, 죄종 전환, 페널티 동반 효과)만 담아야 정당화된다
