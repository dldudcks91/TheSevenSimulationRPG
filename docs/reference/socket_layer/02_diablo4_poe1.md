## 2. 각 개조 아이템 상세

### 2-1. 젬 (Gem)
- **종류 7**: 자수정(Amethyst)·다이아몬드·에메랄드·루비·사파이어·해골(Skull)·토파즈. [maxroll 젬 2026-07-14]
- **등급 8**: Crude(Lv1) → Chipped(Lv1) → 일반(Lv15) → Flawless(Lv20) → Royal(Lv25) → **Grand**(Lv30, VoH 2.0 추가) → **Horadric**(Lv30, LoH 추가) → **Flawless Horadric**(Lv30, LoH 추가). [fextralife Gems] icy-veins는 Crude를 표에서 제외(S4에서 삭제됐다가 재등장한 것으로 보임 — 미확인).
- **부위별 효과 (LoH 3.0.1 개편 후)** — 무기 소켓은 **곱연산 속성 배율**:

| 젬 | 무기 | 방어구 | 장신구 |
|---|---|---|---|
| 자수정 | ×% 암흑 피해 | 방벽 생성 % | 암흑 저항 |
| 다이아몬드 | ×% 모든 피해 | 모든 능력치 | 모든 저항 |
| 에메랄드 | ×% 독 피해 | 민첩 | 독 저항 |
| 루비 | ×% 화염+신성 피해 | 힘 | 화염 저항 |
| 사파이어 | ×% 냉기 피해 | 의지 | 냉기 저항 |
| 해골 | ×% 물리 피해 | 치유 획득 % | 물리 저항 |
| 토파즈 | ×% 번개 피해 | 지능 | 번개 저항 |

  Grand 기준 실수치: 무기 ×24%(다이아 ×20%), 방어구 +90 주스탯(다이아 +30 전능력치, 자수정 방벽생성 18%, 해골 치유 22.5%), 장신구 +2,625 단일저항(다이아 +375 전저항). Horadric 루비 ×28% / +120 / +3,500, Flawless Horadric 루비 **×32% / +150 / +4,375**. [Blizzard 포럼 BlizzPlanet 포스터, fextralife Gems]
  개편 전(S4~S12)은 무기 젬이 "치명타 피해 %·취약 피해 %·제압 피해 %·기본 스킬 피해·궁극기 피해·DoT·처치 시 생명력"이었고 가산이라 **"빌드를 정의하지 못하는 부가물"**로 무시됐음. [Blizzard 3.0 패치노트, gamerant]
- **제작 비용** (icy-veins S14 / VoH 2.0 패치노트): Chipped 10파편 → 일반 100 → Flawless 1,000 → Royal 10,000 → **Grand 100,000 파편 + 30 Forgotten Soul + 골드 1,000만**(Royal 대비 +50%). fextralife는 10배 큰 표(Grand 1,000,000 + 300 FS)를 싣고 있어 **불일치 — 공식 패치노트 수치(100,000/30 FS)를 채택**.
- **Horadric 승급은 보석세공사가 아니라 큐브**: Grand 5개(동일 종) → Horadric 1개, Horadric 5개 → Flawless Horadric 1개 (Amalgamation 레시피). [maxroll 호라드릭 큐브 2026-07-16]
- **젬 파편(Gem Fragments) 개편** — 패치 1.2.0(2023-10-17, 시즌 2 Season of Blood): 젬이 드롭에서 제거되고 **파편이 재료 탭에 쌓임**, 보석세공사에서 제작, 분해 시 파편으로 환원. 명시된 이유: **인벤토리 압박**(젬 1개=1칸 × 등급 7 × 종류). 젬 탭/가방 대신 재료화를 택함. [Wowhead 2023-10-04, sportskeeda] 이후 VoH 2.0에서 파편 드롭 Lv5부터, 보석세공사 Lv1 개방. 3.1.0(S14): 파편 상한 999,999 → 999,999,999, Torment X+ 파편 드롭 대폭 증가, 파편 교환 레시피를 **2종 입력**으로 단순화, 남는 파편으로 **전설 장신구 상자** 제작. [Blizzard 3.1.0]
- **제거**: 2.0부터 무료. 교체 시 이전 젬 반환(FIFO), 장비 분해 시 젬 반환. 젬↔룬은 상호 배타(하나 넣으면 다른 쪽 자동 제거). [fextralife Gems, icy-veins]

### 2-2. 위상 / 전설의 서 (Aspect / Codex of Power)
- **개념**: 전설 파워를 아이템에서 분리해 코덱스(도서관)에 보관하고 임의 레어/전설에 **각인**. 장비 = 스탯 그릇, 빌드 정체성 = 코덱스. 
- **카테고리 5 × 부위 제한** [maxroll 코덱스 wiki 2023-10 / icy-veins S14]:
  - 공격(Offensive): 1H·2H·장갑·반지·목걸이
  - 방어(Defensive): 투구·갑옷·바지·목걸이(+방패)
  - 자원(Resource): 반지(+목걸이)
  - 유틸(Utility): 투구·갑옷·장화·장갑·목걸이(+방패·바지)
  - 이동(Mobility): 장화·목걸이
  - **배율**: 2H 무기 +100%, 목걸이 +50%.
- **연혁**: 1.0(2023-06) — 코덱스 각인은 **최저 롤 고정**, 추출은 아이템 파괴 + "위상 아이템"이 인벤 차지. → S4 Loot Reborn(1.4.0, 2024-05-14) — **모든 위상이 코덱스에 존재, 분해하면 최고 롤 영구 저장**, 기존 위상 아이템은 로그인 시 자동 변환, 검색/필터/즐겨찾기, 장착 표시. [Blizzard S4 블로그] → VoH 2.0 — 위상 최대치는 **조상(Ancestral) 아이템에서만** 나오도록 상한 분리("아이템 진행감 부족" 명시). [maxroll VoH 패치노트] → **LoH(2026-04)** — 던전 완료 보상 위상 **폐지**, 드롭 전용. 복귀 유저 혼란("던전 왜 도냐") 보고. [icy-veins 뉴스] 코덱스 업그레이드 상한 16회. [icy-veins S14]

### 2-3. 룬워드 (Runeword, VoH 2.0 2024-10-08~)
- **구조**: Rune of Ritual(원인: 조건 충족 시 Offering 생성) + Rune of Invocation(결과: Offering 임계치 도달 시 발동, 초과분 **Overflow**로 효과 강화). 2소켓 아이템에 **위 Ritual / 아래 Invocation**. [maxroll 룬워드 2026-07-16]
- **제약**: 캐릭당 **룬워드 2개**, 동일 룬 중복 불가, 젬과 공존 불가, VoH 필수. [icy-veins 룬워드 S14]
- **풀**: Ritual 15종(Magic 5 / Rare 3 / Legendary 7), Invocation 19종. 예:
  - Ritual — Cem(회피 시 75) · Yax(물약 200) · Zan(궁극기 150) · Neo(2초 무피해 후 200) · Poc(자원 5% 소모당 5) · Bac(5m 이동 50) · Igni(0.3초마다 25, 최대 500) · Tam(핵심 스킬 25) · Xol(타 클래스 파워 150) · Yul(쿨다운 스킬 50)
  - Invocation — Gar(25: 치명타 +2.5%, 최대 25%) · Qua(50: 이속 +10%) · Ceh(100: 정령 늑대) · Eom(100: 쿨다운 -0.1s) · **Vex(300: 전 스킬 +1, 10초, 최대 +3 — 3.1.0에서 100→300 상향)** · Jah(350: 회피→순간이동) · Ohm(600: 전쟁의 함성) · Yom(500: 석화) · 타 클래스 스킬 차용(Thul 프로스트 노바, Que 대지 방벽 등)
- **획득**: 쿠라스트 지하도시(Tribute of Harmony), 소굴 보스, 월드보스, 헬타이드 상자, 속삭임 보상. **룬 제작**: 동일 룬 3개 → 다른 랜덤 룬, Magic/Rare는 희귀도 상승 가능. [icy-veins, maxroll]
- **미식 제작 재료**: 보석세공사 — Resplendent Spark 2 + 전설 룬 6종×3(18개) + 골드 5,000 → 해당 부위 랜덤 미식. [nexttier S14 / icy-veins]
- **D2와의 차이**: D2는 **룬 순서 고정 + 소켓 수 정확 일치 + 특정 베이스 + 비마법 아이템만**(Enigma = Jah·Ith·Ber 3소켓 갑옷). 순서 틀리면 실패. [D2 fextralife Runewords] D4는 **자유 2종 조합**(15×19 = 285 조합), 어떤 2소켓 전설/유니크에도, 무료 교체. 즉 D2 = "레시피 발견", D4 = "조건→효과 배선".

### 2-4. 정복자 글리프 (Paragon Glyph)
- 보드당 소켓 1, 최대 5보드(시작 보드 포함), 정복자 Lv300, 총 342포인트. [maxroll 글리프 2026-07-09]
- **반경 성장**: 시작 3 → 4 → 5. 임계 레벨은 자료 불일치: maxroll "Lv25 / Lv51", icy-veins "Lv15 / Lv50, Lv51 전설". **미확인**으로 표기.
- **전설 승급**: 레어→전설 시 반경 +1 및 추가 보너스. maxroll은 "Lv50, 젬 파편 15,000 소모", icy-veins는 "Lv51 자동". 불일치.
- **최대 Lv150**(S14 기준; VoH 2.0 시점 100). 성장은 **구덩이(Pit) 전용**(3.1.0): 클리어당 시도 3 + 무사망 +1 + 시즌 축복 +1. 구덩이 단계가 글리프보다 80+ 높으면 100%(+5), 글리프가 구덩이보다 50+ 높으면 업그레이드 불가. [maxroll]
- VoH 2.0에서 글리프 계수 -50%, 대신 레어/매직 노드 가산 피해 +100%. [maxroll VoH 패치노트]

### 2-5. 템퍼링 / 마스터워킹
**템퍼링 연혁**
- S4(1.4.0): 매뉴얼로 레시피 학습(6 카테고리: 무기·공격·방어·이동·유틸·자원), 일반 아이템 1개 / 조상 2개(서로 다른 카테고리), 접사는 **레시피 내 랜덤**, 재굴림마다 **내구도 감소 → 소진 시 브릭**. [Blizzard S4 블로그] 커뮤니티 반발("무기 5개 브릭하고 렉퀏"), Kotaku 기사화. [Blizzard 포럼, Kotaku]

## 4. 트레이드오프·제약
- **젬 vs 룬**: 같은 소켓을 두고 상호 배타. 무기 젬(×24~32% 배율)과 룬워드(조건부 발동)의 저울질이 2소켓 부위에서 발생.
- **룬워드 2개 상한 + 동일 룬 금지**: 285조합 중 2개를 고르되, 좋은 Ritual 룬(Igni, Tam)은 하나만.
- **위상 부위 제한 + 배율**: 공격 위상은 무기·장갑·반지·목걸이에만 → 2H(+100%)에 핵심 배율 위상, 목걸이(+50%)에 두 번째. 슬롯 경쟁으로 빌드마다 6~8개 위상만 실제 사용.
- **템퍼링**: 과거 브릭 리스크가 가장 큰 트레이드오프였으나 S11 이후 사실상 제거. 남은 제약은 재료·카테고리 슬롯 제한.
- **변용**: 대부분 수정 불가로 잠김 → "완성 후 마지막 도박". 결과 랜덤이나 전부 상향(하향 없음).
- **인벤/재료**: 젬은 파편 카운트, 룬은 아이템(칸 차지), 매뉴얼은 학습형(칸 안 차지), 위상은 코덱스(칸 안 차지), 차암은 아이템. 층마다 "인벤 오브젝트냐 재료 카운트냐"가 다르고, 오브젝트였던 것은 순차적으로 재료화·도감화됨.
- **골드 싱크**: Grand 젬 1,000만, 미식 대장장이 5,000만, 캡스톤 리롤 100만~1,000만.

## 5. 경제
- 거래 가능 범위가 좁음(전설/유니크 일부·룬·재료 일부). 층 대부분은 **자기 재료 경제**: 파편(젬), 오브두사이트/Neathiron(마워), Forgotten Soul(젬 Grand·템퍼·소켓), Scattered Prism(소켓), Resplendent Spark·판데모니움 파편(미식), Primordial Dust(큐브), 룬(룬워드·미식).
- 싱크 구조: 젬 파편은 등급 제작 + 장신구 상자 + 글리프 전설 승급(15,000) + 파편 종 교환에 소비. Torment X+에서 파편 드롭 증폭(3.1.0) = 상위 난이도 보상 축.
- 룬 3→1 제작 = 저가 룬 싱크 + 희귀도 상승 도박. 미식 제작 = 룬 18개 싱크.
- 전체 흐름: 활동(구덩이·지하도시·소굴 보스·헬타이드) → 층별 전용 재료 → 상인(보석세공사/대장장이/오컬티스트/큐브). **층마다 재료 1~2종 + 상인 1명 + UI 탭 1개**가 붙는다.

## 6. 설계 원리 (왜 작동하는가)
- **파워의 위치 분리**: 스탯(접사) / 빌드 정체성(위상) / 조건 배선(룬워드) / 성장(마워·글리프) / 시너지(차암 세트)를 서로 다른 그릇에 담아 드롭 1개를 "어느 층의 업그레이드인가"로 읽게 함.
- **한 번 얻으면 영구**(코덱스): 위상 파밍이 재고 관리가 아니라 도감 완성이 됨. 장비 교체 비용이 낮아져 "장비 = 소모품, 빌드 = 자산".
- **소켓 층은 재료 카운트**: 젬을 아이템에서 파편으로 바꾼 뒤에야 등급 8단계·종류 7이 인벤 없이 굴러감.
- **조합 폭발을 작은 풀로**: 룬 34종으로 285 조합, 차암 세트 2/3/5로 부위 수 대비 보너스 다중화.
- **결정론으로 수렴**: 템퍼링(랜덤→선택), 마워(랜덤 크릿→품질+캡스톤), 미식(6종 고정→모든 유니크 품질화) — 도박은 변용 한 곳으로 몰아넣음.
- **상한이 곧 결정**: 룬워드 2, 글리프 5, 차암 6, 템퍼 1, 위상 1 — 상한이 있어서 "무엇을 넣을까"가 성립.

## 8. 본작 관점 메모 (Diablo IV)
**가져올 만한 것**
1. **"위상=코덱스" 원리를 스킬 카드에**: 본작은 스킬 카드 합성이 후속 예정. D4가 위상을 "장비에서 분리한 영구 도감"으로 만든 것처럼, 본작의 **2차 층은 새 아이템군이 아니라 스킬 카드 도감**으로 수렴시키면 층을 늘리지 않고 "들고 다니며 빌드 조립"이 성립한다. 장비는 27종 전투 능력치 그릇, 카드는 빌드 정체성.
2. **룬워드 = 조건→효과 2피스**: 3인 자동전투에서 플레이어가 유일하게 못 하는 것이 "행동 규칙 지정"이다. D4 룬워드는 정확히 그 빈칸("체력 물약 시 → 방벽", "쿨다운 스킬 시 → +1 스킬")을 채우는 선언형 배선. 영웅당 1개, 풀은 죄종 7 × 조건 소수로 제한하면 죄종 단일 축을 관통하면서 접사 풀을 건드리지 않는다.
3. **세트를 장비에서 떼어 별도 판으로**(탈리스만): 본작이 보류한 "접사 죄종 = 세트포인트"의 대안 사례. 세트 보너스를 장비 접사 매트릭스와 분리한 슬롯판에 두면 접사 풀 희석 없이 세트 체이스를 살릴 수 있다. 단, 층 하나 추가라는 비용은 그대로.
4. **소켓 층은 처음부터 재료 카운트**: 젬 파편 교훈. 본작에 어떤 소켓형 층이든 들어가면 "아이템 오브젝트"가 아니라 **CSV 카운트**로 시작한다(인벤 9슬롯×3인 관리에 오브젝트를 더하지 않음).
5. **결정론 우선**: 템퍼링·마워가 5시즌 만에 랜덤→선택으로 이동. 본작 "강화 = 골드로 접사 증폭"은 이미 결정적. 유지.
6. **성장형 장착물**(글리프): 원정 반복이 장비가 아니라 "성장 아이템"의 레벨을 올리는 축은 방치형 리텐션과 맞는다. 다만 보드(반경) 없이도 되는가 검증 필요 — 단순화 원칙.

**피해야 할 것**
1. **접사와 같은 스탯을 주는 젬**: D4가 12시즌 동안 "무의미" 소리를 들은 이유. 본작은 이미 죄종×부위 접사 매트릭스가 전투 능력치 27종을 덮는다. 젬이 같은 축이면 숫자 노이즈 + 접사 풀 희석. 젬을 넣으려면 접사가 **못** 주는 것(발동 조건, 세트, 성장)이어야 한다.
2. **층의 누적**: D4는 9겹이 됐고 각 겹이 재료 탭·상인·UI를 요구한다. 서버 없는 싱글 + 3인 × 9슬롯 = 27 장비에 층 하나 = 27×N 결정. **2차 층은 1개만**, 그것도 기존 슬롯 재사용이 우선.
3. **파괴 RNG**(구 템퍼링 브릭, 변용 잠금): 거래 없는 본작에서 체이스 아이템이 RNG로 죽으면 대체 수단이 없다. 하향/파괴/영구 잠금 결과는 넣지 않는다.
4. **위상식 부위 배율(2H +100%)**: "숫자로 읽히는 최적화" 원칙에는 맞지만, 본작 8부위 구조에서 특정 부위에 배율을 주면 부위 간 가치가 접사 매트릭스와 이중으로 왜곡된다. 부위 가치는 접사 매트릭스 한 곳에서만 정한다.
5. **던전→위상 보상 폐지 같은 "노림 불가" 전환**: LoH가 위상을 드롭 전용으로 바꾸자 "던전 왜 도냐" 불만. 본작의 지역 죄종 드롭 편향·낙인은 "노릴 수 있음"이 핵심 — 2차 층도 챕터/지역과 결합해 노림이 가능해야 한다.

## 4. 트레이드오프·제약
- **트리 포인트 vs 주얼**: 주얼 소켓 할당에 1포인트, 클러스터는 8~12포인트 소모 → "포인트당 효율"이 모든 주얼의 비교 단위.
- **소켓/링크 수 vs 아이템 접사**: 좋은 접사 6소켓 몸통에 6링크를 뚫는 비용(평균 1,000~1,500 Fusing) vs 벤치 1,500 보장. 3.28까지는 오프컬러 비용 추가.
- **부패의 비가역**: 젬 21/23 도박, 아이템 임플리시트/흰 소켓/브릭. "부패된 아이템은 일반 화폐로 수정 불가" — 리스크&리워드의 핵심 레버. [maxroll 부패]
- **인챈트 덮어쓰기**: 원하는 투구 인챈트를 얻기 위해 라비린스 반복, 성공 시 이전 것 소실.
- **팅크처의 마나 번**: 버프 대가로 자원 고갈 → 동시 1개.
- **주얼 4모드 상한 + "limited to"**: 유니크 주얼 중복 제한.
- **인벤**: 젬 1칸, 주얼 1칸, 플라스크 1×2. 스택 불가라 스탠다드에선 젬/주얼 보관함 탭이 상품.

## 5. 경제 — 화폐 = 크래프팅 오브
- PoE는 골드 없이(3.25 전) **소켓·접사·부패를 조작하는 소모품이 화폐**. Chaos/Divine이 기준 단위, Fusing/Jeweller's/Chromatic/Vaal은 소켓 층의 통화. 소켓 굴리기는 곧 화폐 싱크 → 화폐 가치가 유지되는 구조.
- 벤치 보장(350 J / 1,500 F)은 **기대값의 상한 가격**을 고정하는 장치 = RNG 싱크에 결정론적 천장.
- 3.25 Currency Exchange가 상인 환율을 시장가로 대체(골드 세금 = 신규 싱크). 3.29 Chromatic 희귀화는 소켓 색 층의 수요 붕괴에 대한 공급 조정.
- 주얼·클러스터·엘드리치·Timeless는 **거래로 완성**하는 층(완품 클러스터 100+ Div, 특정 시드 Timeless). 이 층의 가치는 트레이드 리그 전제.

## 6. 설계 원리
- **트리가 소켓판**: 주얼/클러스터/룬그라프트/타투가 전부 "패시브 트리의 특정 위치에 끼우는 아이템" — 장비 소켓을 늘리지 않고 트리를 소켓판으로 재활용. 위치(반경)가 동일 아이템의 가치를 바꿔 "어디에 끼우나"가 결정이 됨.
- **스킬=아이템**: 스킬을 드롭·거래·성장·부패 가능한 오브젝트로 만들어 루팅 게임의 문법에 스킬을 편입. 대가로 장비 비교가 소켓/링크로 오염 → 3.29에서 색 제약 제거로 마찰 조정.
- **시드 결정론**(Timeless): 같은 시드=같은 결과라 "롤"이 아니라 "탐색"이 되고, 접사 풀을 안 늘리면서 체이스가 무한.
- **한 슬롯에 두 종류**(팅크처=플라스크 자리, 어비스 주얼=트리 or 벨트): 새 슬롯 대신 기존 슬롯의 선택지를 늘림.
- **비가역 도박을 한 곳에**(Vaal Orb): 나머지 층은 되돌릴 수 있게, 부패만 잠근다.
- **보장 경로 병존**: 확률(Fusing)과 결정(벤치)을 같은 자원으로 연결.

## 8. 본작 관점 메모 (Path of Exile)
**가져올 만한 것**
1. **시드 결정론 유니크(Timeless형)**: 본작은 RNG를 시드로 주입한다. "시드 N의 낙인/유니크가 스킬 트리 반경 노드를 결정적으로 변환"하는 아이템은 접사 풀을 한 줄도 안 늘리고 긴 체이스를 만들며, 엔진 이식 후 같은 시드로 대조 검증도 된다. 본작 기술 조건과 가장 궁합이 좋은 2차 층 후보.
2. **트리를 소켓판으로**: 새 장비 슬롯 없이 스킬 트리 3탭(죄종/마스터리/전직)에 "주얼 소켓 노드"를 두면, 스킬 카드가 곧 주얼이 된다. "룬·차암·주얼"을 따로 만들 필요 없이 **스킬 카드 = 트리에 끼우는 아이템** 하나로 통합 가능. 위치(반경)로 같은 카드의 가치가 달라지면 "숫자로 읽히는 최적화"도 유지.
3. **한 슬롯에 두 종류**(팅크처): 새 슬롯 추가 대신 기존 슬롯(예: 액티브 슬롯 3 중 하나를 "패시브 카드" 자리로 전환 가능)에 선택지를 넣는 방식이 단순화 원칙에 맞다.
4. **Instilling Orb식 조건 배선**: "체력 50% 이하일 때 사용" 같은 발동 조건을 접사가 아닌 **소모품/카드의 인챈트**로 두면 자동전투 행동 규칙을 플레이어가 조립한다. 본작 액티브 슬롯 3의 발동 조건 정의와 결합 가능.
5. **보장 경로 병존**: 어떤 확률 크래프트든 결정적 천장(벤치 1,500 Fusing)을 같은 재화로 제공. 본작 강화/크래프트가 확률을 갖는다면 "N회 실패 시 확정" 또는 골드 확정 경로를 처음부터 CSV 키로.
6. **비가역은 한 곳**: 부패(Vaal)만 잠금. 본작에서 "돌이킬 수 없는 결정"을 넣는다면 유니크 낙인 1곳으로 국한.

**피해야 할 것**
1. **스킬=소켓템 전환**: 장비가 주인공인 본작에서 장비가 스킬 그릇이 되면 장비 비교가 소켓/링크로 오염되고, 접사 매트릭스의 "숫자로 읽히는 최적화"가 무너진다. GGG도 3.29에서 이 층의 마찰을 줄였다.
2. **소켓 수·링크·색 굴리기 경제**: 화폐 싱크로 작동하는 건 거래가 있을 때다. 거래 없는 싱글에서 Fusing 스팸은 순수 시간 낭비 RNG. 소켓이 필요하면 **부위별 고정 수, 굴림 없음**.
3. **주얼 접사 풀의 별도 확장**: PoE 주얼은 장비 접사와 겹치는 풀(생명·저항·피해)을 트리에서 다시 준다. 본작 "접사 풀 희석 금지" 원칙과 정면 충돌 — 트리 아이템은 접사가 아니라 **노드 변환/행동 규칙/죄종 축 이동**처럼 접사가 표현 못 하는 것만 준다.
4. **아센던시 노터블의 아이템화**(Affliction 차암): 클래스 정체성을 아이템으로 팔면 정체성이 사라지고 파워 인플레 — GGG가 1리그 만에 삭제. 본작 전직 탭의 고유 노드를 카드로 뽑아 쓰게 하지 않는다.
5. **덮어쓰기 도박 인챈트**(라비린스): 방치형 계약("자리 비워도 안전")과 맞지 않는 "얻으려다 잃는" 구조.
6. **층 10겹의 관리 부담**: 젬 1칸·주얼 1칸·플라스크 5·팅크처·인챈트·엘드리치…는 하드코어 커뮤니티와 트레이드 사이트가 받쳐준다. 서버 없는 싱글은 이 규모의 층을 버틸 UI·경제가 없다.

# 종합 — "본작에 2차 층이 필요한가"에 대한 판단 재료

1. **두 게임 모두 2차 층은 "접사가 표현 못 하는 것"을 담을 때만 살아남았다**: 조건→효과 배선(D4 룬워드, PoE Instilling), 빌드 정체성의 영구화(D4 코덱스), 세트 시너지(D4 탈리스만), 트리 변형(PoE 주얼/룬그라프트), 결정론 체이스(Timeless). 접사와 같은 스탯을 주는 층(D4 구 젬, PoE 주얼 IIR)은 무시되거나 삭제됐다.
2. **층 수는 곧 재료 탭·상인·UI 수**다. D4 9겹, PoE 10겹은 각각 트레이드/커뮤니티 도구가 받친다. 본작(3인×9슬롯, 거래 없음, 단순화 원칙)은 **2차 층 1개**가 상한.
3. **후보 우선순위**(본작 맥락): (a) **스킬 카드 = 트리 소켓 아이템** — 이미 예정된 개념을 2차 층으로 승격, 새 아이템군 없음. (b) **룬워드형 "조건→효과" 1슬롯/영웅** — 자동전투 행동 규칙 표현, 풀 = 죄종 7 × 조건 소수. (c) **세트를 장비에서 뗀 부적판** — 보류 중인 세트효과의 대안이지만 층 추가 비용 최대. (a)와 (b)는 하나로 합칠 수 있다("카드에 발동 조건 인챈트").
4. **어떤 형태든**: 재료 카운트(젬 파편 교훈), 결정론(템퍼링 교훈), 파괴·하향 없음(거래 없음), 지역/챕터와 결합해 노림 가능(LoH 위상 교훈), 새 슬롯보다 기존 슬롯 재사용(팅크처 교훈).
