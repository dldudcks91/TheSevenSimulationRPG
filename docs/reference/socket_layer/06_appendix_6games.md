- 카드: 덱 6, 세트 2/3/4/6/7장, 각성 5, 전설 완각 = XP 90만 + 실버 152.5만 [maxroll]

**가르치는 것**: 빌드 정체성(각인)을 장비 밖 층에 두면 장비 교체가 빌드를 깨지 않는다 — T4는 장신구에서 각인을 완전히 떼냈다. 보석 = "스킬을 지정하는 소켓", 슬롯 예산(11) 안의 피해/쿨감 배분이 빌드 미세조정. 반면 팔찌·엘릭서·초월처럼 층마다 독립 RNG를 붙이면 층 수가 진입 장벽.
**문제**: 층 과다 → "숙제 벽" · 3종의 별개 도박 미니게임 · T3→T4 개편으로 장신구 각인 자산 통째 재편.
**본작 한 줄**: 가져올 것 — "각인 = 장비 밖 정체성 층" + "보석 = 스킬 지정 소켓"(액티브 슬롯 3에 붙이는 스킬 룬으로 번역 가능). 피할 것 — 층 6~7겹, 층마다 독립 RNG.
**출처**: maxroll engraving/gem/card/bracelet ★★★ · namu 각인/엘릭서/초월 ★★ · playlostark 2024 로드맵 part 3 ★★★. 미확인: T4 유물 각인서 1권당 증가폭, 팔찌 T4 옵션 풀.

- 스타포스: **15성부터 파괴**. 15성 성공 31.5%/파괴 2.055%, **22성 15.75%/16.85%** — 22성이 종착지인 이유: 그 위부터 파괴 > 성공. 2024 개편으로 15~21성 하락 폐지 [namu]

**가르치는 것**: 한 장비 본체에 독립 RNG 층을 4~5겹 쌓으면 완성 기대비용이 층 수의 곱으로 폭증하고, 파괴는 "장비 자체가 판돈". 정반대로 심볼은 장비 밖 확정 성장 층이라 통제성 100% — 같은 게임 안에 두 극단.
**문제**: 큐브 확률 미고지 → 2024-01 공정위 과징금 116억 · "완성품 구매가 직작보다 효율적"이라는 위키 서술 자체가 실패 증거 · 실패/교체 시 소멸 규칙이 많아 실험 비용 高.
**본작 한 줄**: 피할 것 — 파괴, 본체 독립 RNG 중첩, 교체 시 소멸. 가져올 것 — 심볼형 "파밍량 = 확정 성장"(장비 밖), 스타포스의 "안전 구간·종착점 가시화".
**출처**: namu 잠재능력/스타포스/주문서/소울웨폰/아케인심볼/큐브 삭제 ★★ · maplestory.nexon.com 공식 확률 ★★★(미fetch). 미확인: 어센틱심볼 수치, 재설정 단가표.

### A-3. Terraria — 액세서리 슬롯 5~7 · 접두사 Reforge · 조합 (2겹)

- 기본 슬롯 5, 데몬 하트 +1, 마스터 +1 → **최대 7**. **동일 액세서리 중복 불가** [wiki.gg]
- 액세서리 접두사 19종, **전부 이득**: 방어 +1~4(Warding), 크리 +2/4%(Lucky), 피해 +1~4%(Menacing), 이속(Quick), 근공속(Violent), 마나 +20(Arcane). 생성 시 75% 확률로 접두사 [wiki.gg]
- 리포지 비용 = **현재 구매가의 1/3**. 나쁜 접두사일수록 싸고 좋은 걸 다시 굴리면 비쌈. 후보 균등 확률
- 무기 접두사는 83종 — 액세서리와 풀 분리
- **팅커러 워크숍**(10골드): 두 액세서리 → 한 슬롯에 두 효과(로켓+헤르메스 → 스펙터 부츠). 결과물은 새 랜덤 접두사
- 7슬롯 × 4% = 최대 +28% — 슬롯마다 접두사 선택이 빌드 성향

**가르치는 것**: 슬롯 상한을 고정한 채 **합성으로 압박을 푼다** — 슬롯 안 늘리고 파워가 오르고 조합 자체가 후반 체이스. 접두사는 "손해 없는 소폭 랜덤"이라 리롤이 스트레스가 아니라 골드 싱크.
**문제**: 리포지 RNG(1/19) 피로 · 조합 트리 위키 의존 · 조합마다 접두사 재굴림.
**본작 한 줄**: 가져올 것 — "합성으로 슬롯 압박 해소" + "이득만·소폭·골드 리롤"(본작 강화=골드와 결이 같다). 피할 것 — 인게임 안내 없는 조합 트리.
**출처**: terraria.wiki.gg Modifiers / Accessories / Tinkerer's Workshop / Goblin Tinkerer ★★★.

|---|---|---|---|---|
| 모드(카드) | 워프레임 8+오라+엑실러스 / 총기 8+엑실러스 / 근접 8+엑실러스+스탠스 | 고정 + 랭크 성장 | **무손실 탈착**, 공유 라이브러리 | 엔도+크레딧 랭크 0~10 |

- 오라·스탠스 모드는 용량을 소모하지 않고 **더해준다** [wiki]
- 포르마: 최대 랭크에서만 적용, **랭크 0 리셋** → 재육성 (반복 플레이 동기)
- 리븐: 소티 드롭 근접 8.14%/소총 6.79%/샷건 1.36%. 성향 0.5~1.55, 프라임 액세스마다 재조정 → 기존 리븐 값 자동 변동. 보유 15 기본, 최대 180 [wiki]

**가르치는 것**: 슬롯 수는 고정하고 **용량 예산 + 극성**으로 최적화를 "비용 절감 퍼즐"로 만든다 — 극성 변경(포르마)이 장비 랭크를 리셋하므로 장비 자체에 시간이 쌓인다. 모드는 장비에 종속되지 않는 공유 라이브러리라 장비 교체 비용 0.
**문제**: 포르마 반복 그라인드 · 용량 예산이 신규에게 불투명 · 리븐 성향 조정이 자산 가치를 흔듦.
**본작 한 줄**: 본작은 코스트(용량)를 폐지했으므로 **용량 예산 재도입은 결정 번복** — 가져올 것은 "모드 = 장비 밖 공유 라이브러리 + 슬롯 고정"과 "극성 일치 = 이득"(죄종 일치 룬 슬롯으로 번역 가능). 피할 것 — 리븐형 랜덤 롤 + 사후 성향 조정.
**출처**: wiki.warframe.com Mods / Riven_Mods / Arcane_Enhancement ★★★ · warframe.fandom Orokin_Reactor ★★.

### A-5. Elden Ring — 탈리스만 · 전회 기억 · 전성 · 결정 눈물 · 대룬

- 탈리스만 슬롯 1 + 파우치 3 = **4**. 무게 없음. 총 154종(기본 115 + DLC 39) [fextralife]
- 예: 라다곤의 상흔 각인 생명·지구·근·기 +5, **받는 피해 +15%**(트레이드오프형); 알렉산더의 파편 전회 피해 +15%
- **전회 기억**: 그레이스에서 숫돌 나이프로 **무비용** 부착, **소모되지 않음**, 1 전회 = 1 무기(빼면 재사용). 잃어버린 전회 기억으로 복제, 회차당 15개. 총 ~116종. 특수 무기(고유 스킬) 불가 [fextralife]
- **전성** 13종이 **스케일링을 바꾼다**: 중량 = 근력↑ 기량 삭제; 냉기/독/출혈은 기본 스케일↓ 강화 배율↑. 전회 종류에 따라 가능한 전성이 제한되고 숫돌칼로 확장 [fextralife]
- 결정 눈물: 성수병에 **2개** 조합, 32종 + DLC 8
- **모든 소켓 조작이 무료·가역·즉시 → 실험 비용 0**

**가르치는 것**: 소켓을 **스킬(전회)**과 **패시브(탈리스만)**로 분리하고 둘 다 무손실 가역으로 두면 빌드 다양성이 자연히 생긴다. 전회가 무기의 스케일링(전성)까지 바꾸므로 "무기 = 뼈대, 전회 = 성격". 희소성은 소켓 조작이 아니라 **획득(탐험)**에만.
**문제**: 4슬롯에 필수 탈리스만 쏠림(황금수·알렉산더·용문장 + 빌드 1개) → 실질 선택지 1 · 전회 116종 중 실사용 소수 · 전성 최적화는 스프레드시트.
**본작 한 줄**: 가져올 것 — 무손실 가역 소켓(통제성) + "스킬 소켓 vs 패시브 소켓" 분리: 액티브 슬롯 3 = 전회 기억(스킬 카드), 탈리스만 = 영웅 단위 소수 슬롯 후보. 피할 것 — 필수 슬롯 고정화(슬롯 대비 후보가 좁으면 선택이 사라짐).
**출처**: eldenring.wiki.fextralife.com Talismans / Ashes_of_War / Lost_Ashes_of_War / Affinities / Crystal_Tears ★★★. 미확인: 동계열 탈리스만 동시 장착 불가 원문.

### A-6. Torchlight II — 젬 · 소켓 추가 · 인챈트
