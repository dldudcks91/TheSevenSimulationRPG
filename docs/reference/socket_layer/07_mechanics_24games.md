### 1. Bloodborne — 카릴 룬 + 혈석(Blood Gem)
캐릭터 "룬" 4슬롯(패시브) + 무기 소켓 "혈석"(랜덤 드롭·형태 매칭·저주 젬) 두 층 분리.
- 카릴 룬: 슬롯 4 = 일반 3 + **서약(Oath) 1**. 서약 룬 = 코버넌트 소속(유일 판정). 기억 제단에서만 교체 ☆
- 혈석 소켓: 무기 강화 **+1 / +3 / +6에서 1개씩 개방(최대 3)**. 총기 0~1 ★
- 형태 매칭: 방사·삼각·초승달 → 오른손, 원형 → 왼손(총). **Droplet은 형태 무관** ★. 형태 ↔ 출처: Pthumeru → Radial, Loran → Waning, Isz → Triangular ☆
- 등급 1~20. 성배 깊이 5 → 17~20 ★
- **저주(Cursed) 젬**: 주옵션이 더 강한 대신 네거티브(내구도 감소·스태미너 소모 증가·HP 지속 감소)가 붙고 **중첩됨**. 총기는 내구·스태미너를 안 쓰므로 그 두 저주는 "사실상 무결점" ★
- 탈착 자유·비용 0·파괴 없음 ★

**메커니즘**: 소켓 형태 = 슬롯별 접사 풀 분리. 저주 = "강한 롤에 붙은 세금"인데 세금을 안 내는 자리에 놓으면 무료 → **페널티 회피가 곧 최적화 퍼즐**.
**본작 한 줄**: 저주 젬(강한 주옵 + 네거티브 1줄)은 크래프트 등급의 "대가"로 쓸 만하다. 형태-소켓 매칭은 접사 풀 희석과 같은 마찰이니 피할 것.
출처: ★ bloodborne.wiki.fextralife Blood+Gems · ☆ Caryll+Runes · ☆ bloodborne.fandom Caryll_Runes

### 2. Hollow Knight — 참(Charm) / 노치
- 참 45종, 동시 보유 최대 40(5종 교환형: Fragile→Unbreakable 3, Kingsoul→Void Heart, Grimmchild→Carefree Melody) ★
- 노치 비용 **1~5**. 노치 시작 3, 최대 **11** ★. 벤치에서만 장착/해제 ★
- **오버참**: 노치가 모자라는 참을 5회 클릭하면 장착됨. **받는 피해 2배**. 노치가 정확히 꽉 차 있으면 오버참 불가 ★
- Fragile 3종(Heart +2 마스크 / Strength 네일 +50% / Greed): **사망 시 파괴** → 수리 → Divine에게 **9,000 / 12,000 / 15,000 Geo**로 Unbreakable(합 36,000) ★☆
- 시너지 16개 문서화: Dashmaster+Sprintmaster 이속 30→39%, Grubsong+Grubberfly SOUL 15→25, Quick Focus+Shape of Unn 속도 6→12 ★

**메커니즘**: **예산 + 오버플로 1개 허용 + 그 대가가 숫자로 명확(×2)**. Fragile→Unbreakable = "위험한 힘을 큰 골드로 안정화"하는 골드 싱크.
**본작 한 줄**: 오버참(초과 1개, 피해 ×2)은 리포트에서 인과가 읽히는 **가장 깨끗한 예산형 페널티**. Fragile의 "사망 시 파괴"는 방치형 계약 위반 → 부상 모델로 치환.
출처: ★ hollowknight.wiki Charms · ★ Charm_Synergies · ☆ Divine

### 3. Hollow Knight: Silksong — 크레스트 + 툴
- 크레스트가 무기 모션과 **툴 슬롯의 색 구성**을 결정. Hunter = 실크 스킬 1, 빨 2(1 잠금), 파 2(1 잠금), 노 2(1 잠금) / Architect = 빨 3, 파 2, 노 2, **실크 스킬 슬롯 없음** / Shaman = 실크 스킬 3, 파 2 ★
- 잠긴 슬롯은 **메모리 로켓(총 20)**으로 개방. 12슬롯 개방 시 Vesticrest(상시 슬롯) ★☆
- 툴 색: 빨강 = 횟수 소모형 공격, 파랑 = 전투/생존 패시브, 노랑 = 탐험/자원 패시브 ☆

**메커니즘**: **프레임이 슬롯 색 구성을 정하고, 색이 예산을 분리**(공격/방어/유틸이 서로 자리를 못 뺏음). 빌드 정체성은 프레임에, 세부는 툴에.
**본작 한 줄**: 직업 7종을 크레스트로 보고 **직업별 2차 층 슬롯 색 구성(공/방/유틸 비율)을 다르게** 주면 접사 풀을 안 늘리면서 직업 차별화. 소모형(빨강)은 방치형과 상성 나쁨.
출처: ★ hollowknight.wiki Crests · ☆ silksong fextralife Tools

### 4. Hades / Hades II — 은총·망치·기념품 / 아르카나
- Hades: 은총은 신별, 슬롯(공격/특수/캐스트/대시/콜)당 1 ☆. **듀오 은총** = 두 신의 특정 은총 선행 보유(교집합 세트) ☆. 기념품 1슬롯 ☆. 다이달로스 망치 **런당 최대 2** ☆
- **Hades II 아르카나**: **5×5 = 25장**. Grasp 비용 **0~5**. 시작 Grasp **10**, Psyche로 상한↑ ★. **0-Grasp 카드는 각성 조건**으로만 켜짐: Messenger "같은 Grasp 카드 3장 이상", Centaur "1~5 Grasp 각 1장 이상", Queen "같은 Grasp 카드 2장 이하", Seer "주변 카드 전부 활성", Judgment "활성 카드 3장 이하" ★☆. 업그레이드 2회, **Grasp 비용 불변** ★

**메커니즘**: 예산을 안 쓰는 대신 **"구성의 모양"**을 요구하는 세트 효과. 듀오 은총 = 두 출처의 교집합이 곧 세트.
**본작 한 줄**: 죄종 세트효과 보류 중이라면, 아르카나 각성식 **"분포 조건이 맞으면 켜지는 무료 층"**이 세트의 대안("죄종 5종 이상 착용 시", "같은 죄종 3개 이하일 때"). 그리드 인접은 과함.
출처: ★ hades2.wiki.fextralife Arcana+Cards / The+Queen / The+Centaur / The+Seer · ☆ Judgment · ☆ hades.fandom Daedalus_Hammer / Keepsakes

### 5. Transistor — Function() 3역할
- 슬롯: 액티브 4 × 업그레이드 각 2 + 패시브 4 ☆★. MEM 최대 **32**. 기능 비용 예: Crash 1, Breach·Jaunt 3 ★☆. 기능 수 16(통설) vs 20 — 상충
- 3역할: Crash() 액티브 = 근접 타격+취약 / 업그레이드 = 다른 기능에 스턴 부여 / 패시브 = 피해·둔화 저항 ★. 패시브 중복 불가 ☆
- **과부하**: HP 0 → MEM 최대 기능이 과부하(사용 불가). 마지막까지 과부하되면 사망 ☆. 리미터 10개: 적 강화 대가로 XP 최대 **+32%** ☆

**메커니즘**: **한 아이템이 붙는 곳에 따라 다른 문법** → 아이템 수 안 늘리고 조합 공간 3배. 죽음 = 장비의 임시 상실.
**본작 한 줄**: 스킬 지정형의 정답에 가깝다 — 낙인/룬 하나가 **무기 소켓·스킬 슬롯·영웅 슬롯 3곳에서 다른 효과**면 접사 풀 희석 없이 깊이. 과부하는 부상으로 치환.
출처: ★ gamesbeat Function 가이드 · ★ gamingbolt 메가 가이드 · ☆ transistor.fandom Functions / Limiters

### 6. Noita — 완드 + 주문 순서
- 완드 베이스: 셔플 여부 / 회당 주문 수 1~26 / 캐스트 딜레이 / 재충전 / 마나 최대(160~250) / **용량 1~26** / 분산 ★
- 수식(modifier)은 **다음 투사체 주문 1개에만** → 순서가 전부. **Always Cast**: 완드 생성 시 랜덤 고정, 제거 불가 ★. 편집은 Holy Mountain에서만 ★

**메커니즘**: 베이스 = "문법의 그릇", 주문 = "단어", 순서 = "문장". Always Cast = 그릇의 Implicit.
**본작 한 줄**: 액티브 슬롯 3 + 스킬 카드 합성이 있으니 **순서 문법은 과함**. 무기군 Implicit이 이미 Always Cast. 가져올 건 "그릇의 슬롯 수가 희귀도와 무관하게 롤링된다"는 축 하나.
출처: ★ noita.wiki.gg Wands · ☆ Guide:_Wand_Mechanics

### 7. Tyranny — 인장(Sigil) 3층 주문 제작
- 코어 **11**(Fire·Frost·Lightning·Life·Force·Illusion·Vigor·Terratus·Atrophy·Emotions·Stone) ★ + 표현 **9**(Lore 요구 +15 ~ +100) ★ + 악센트(범위/명중/강도/AoE/지속/회복 + 강화 1개, 악센트는 **개수 제한 없음**, Lore 요구치 합산이 실제 제한) ☆
- 주문 = 코어 1 + 표현 1 필수. **인장은 소모되지 않음** — 같은 인장으로 여러 주문, 동료 여럿에 동시 배정 ★

**메커니즘**: 3층 문법에서 예산을 "슬롯 수" 대신 "요구치 합"으로 두면 슬롯 개념 없이 상한이 생긴다. 재료 비소모 = 라이브러리형.
**본작 한 줄**: 본작 크래프트(낙인=코어 죄종, 부위=표현, 등급=악센트)는 이미 3층. 가져올 건 **"낙인은 소모되지 않는 레시피"**로 두어 파티 3인 재배분 마찰을 줄이는 것 — 긴 체이스와 충돌하니 상위 낙인만.
출처: ★ tyranny.wiki.fextralife Spell+Creation · ★ gamepressure · ☆ tyranny.fandom

### 8. Bastion — 아이돌(자기 페널티 다이얼) + 증류주
- 아이돌 10: Pyth(적 이속·공속↑, +10%), Acobi(사망 시 폭탄, +5%), Micia(재생, +5%), Garmuth(공격 튕김, +10%), Roathus(회복 미드롭, +10%), Olak(빗나감, +10%), Hense(피해↑, +10%), Jevel(저항, +5%), Yudrig(접촉 피해, +5%), Lemaign(둔화, +5%) ★. 합산 최대 **+75%** XP·파편 ★. 사원에서 자유 토글 ★
- 증류주 20종, 선반 = 레벨(1 → 10) ☆

**메커니즘**: 페널티를 **플레이어가 켜고**, 보상은 **산술 합** — 인과가 완전히 읽힌다.
**본작 한 줄**: 예산형 페널티 후보 중 방치형에 가장 안전. **원정 출발 전 "아이돌" 토글 = 몬스터 강화 + 드롭 배율**로 스테이지 변형자화. 아이템 층이 아니라 원정 층에.
출처: ★ guidestrats bastion-all-idols · ☆ bastion.fandom Idols / Spirits

### 9. Vampire Survivors — 진화 레시피
- 무기 6 + 패시브 6 ★. 진화: 무기 최대 레벨(8) + 대응 패시브 **아무 레벨** → 10분 이후 보스 상자에서 **확정** ★. 예: Whip + Hollow Heart = Bloody Tear ★. Union: 두 무기(만렙) 합체 → **슬롯 1개 해방** ★

**메커니즘**: **결정론 레시피** — 도감이 곧 빌드 가이드, 랜덤은 "언제 드롭되나"에만.
**본작 한 줄**: "특정 접사 조합 + 낙인 = 유니크 승격" 결정론 레시피는 **숫자로 읽히는 최적화**와 가장 잘 맞는다. 접사 풀은 늘리지 말고 기존 축(죄종×부위) 조합으로만.
출처: ★ vampire.survivors.wiki Evolution · ☆ fandom Weapons

### 10. The Binding of Isaac — 트링킷 1슬롯(+1)
- 트링킷 1슬롯, Mom's Purse 또는 Belly Button으로 2(중첩 X) ★. 188종. 골든 트링킷 2%, 효과 2배 ★. Smelter / Gulp! = 트링킷 **영구 흡수**(슬롯 안 씀) ★. 네거티브: Tick(버릴 수 없음), Cursed Skull ★
- **7대 죄악 미니보스**: Pride/Envy/Greed/Wrath/Gluttony/Lust/Sloth, 미니보스 방, Super 변종, Ultra Pride/Greed ☆

**메커니즘**: 1슬롯 트링킷 + "삼켜서 영구화" = 아이템이 캐릭터 성장으로 승화되는 회수 규칙.
**본작 한 줄**: 7대 죄악 미니보스 = 본작 **낙인 드롭 보스**와 같은 자리. 트링킷 영구 흡수 = "룬을 영웅에 각인(슬롯 해방, 회수 불가)" 후보 — 긴 체이스와 정합.
출처: ★ bindingofisaacrebirth.wiki.gg Trinkets · ☆ Seven_Deadly_Sins

### 11. Dead Cells — 뮤테이션 3 / 저주
- 뮤테이션 최대 **3**(바이옴마다 +1), 56종 = Brutality 12 / Tactics 12 / Survival 12 / Colorless 20 ★. 리셋 골드 1,000 → 2배 → 8,000 상한 ★
- **저주**: 저주 중 거의 모든 피해 = 즉사. **킬 1당 −1 스택**. 저주 상자 10, 골든 도어 10/50, Cursed Flask 20 ★. Demonic Strength: 저주 중 피해 +30% ★

**메커니즘**: 저주 = **"먼저 받고 나중에 갚는" 페널티**, 상환 단위가 킬 수라 인과가 명확.
**본작 한 줄**: 도감이 처치 수 모델이니 **"저주 아이템은 N킬 후 저주 해제"**가 자연스럽다. 즉사 대신 부상 확률/피해 증가로.
출처: ★ deadcells.wiki.gg Mutations · ★ Curse

### 12. Loop Hero — 카드로 월드 편집
- 장비가 아니라 **루프 도로와 지형이 소켓**. 카드 유형: 도로 / 도로변 / 지형 / 특수 / 골든 ★. 인접 시너지: Rock/Mountain 3×3 = Mountain Peak(HP +48%, 하피) / Village+Vampire Mansion → Ransacked → Count's Lands / Treasury 8방 포위 → Empty Treasury ☆★. 모든 타일이 **보상과 위험을 동시에** ★

**메커니즘**: 소켓이 월드에 있으면 "무엇을 켜느냐 = 무엇과 싸우느냐"가 하나의 결정.
**본작 한 줄**: 원정 전 "스테이지 카드"로 조건(드롭↑ / 위험↑ / 특정 몬스터 종 추가)을 편집하는 **스테이지 변형자**로만 차용. 인접·격자는 과함.

### 13. FF VI — 마석(Magicite)
- 27종, 1인 1개, 자유 교체 ★. 마법 습득률 ×1~×20 ★. **레벨업 보너스**: STR+1 Ifrit / +2 Bismarck·Alexander · MAG+2 Zona Seeker·Valigarmanda · SPD+2 Odin·Raiden · HP+50% Bahamut · MP+50% Crusader · 없음 Shiva·Phoenix·Ragnarok ★. HP/MP 외 스탯 영구 상승의 **유일한 수단** ☆ → 저레벨 최적화 압박

**메커니즘**: 장착물이 **성장 방향**을 정하고 영구 흔적을 남긴다 — 후회 압박이 부작용.
**본작 한 줄**: 히든 성장률/상한에 **"장착 중 레벨업 시 상한 성장 방향"**을 마석식으로 붙일 수 있다. 후회 없는 형태(상한만 밀고 되돌릴 수 있게)로.

### 14. FF Tactics — 크리스탈
- KO 후 카운터 3 → 0이면 **크리스탈 또는 보물상자**, 이후 부활 불가 ★. 크리스탈(인간): 습득자가 전직 가능한 잡의 어빌리티 중 일부 습득 또는 HP/MP 회복 ★☆. 몬스터 → 상자 ★. 람자 결정화 = 게임오버 ★

**메커니즘**: **존재 → 아이템**. 영구 손실이 대가.
**본작 한 줄**: 레어 영웅 무한 생성과 결합해 **"영웅 은퇴 → 결정 → 스킬 카드 계승"** 루프 후보. 퍼머데스는 방치 계약과 충돌 → 자발적 은퇴로.

### 15. Chrono Cross — 엘리먼트 그리드
- 그리드 최대 8레벨. 엘리먼트마다 배정 레벨 + 오프셋 — **낮은 칸이면 약화, 높은 칸이면 강화** ★. 6색 대립(적↔청, 녹↔황, 흑↔백), 고유색 배율, 필드 효과 = 최근 3색 ★

**메커니즘**: 슬롯 레벨 = 아이템 등급 게이트인데, 오프셋으로 게이트를 부드럽게.
**본작 한 줄**: 슬롯 레벨은 본작이 폐지한 게이트의 부활 → **피할 것**. 오프셋 발상만 "같은 접사가 부위 가중치에 따라 강/약"으로 부위 계수에 흡수 가능.

### 16. Vagrant Story — 젬 + 성장형 친화도

**메커니즘**: 장비가 **경험을 기억**한다(도감 처치 수 = 장비 성장). 제로섬은 전문화 강제.

### 17. Golden Sun — 진(Djinn)

## 본작 고민 4축에 대한 판단

- **(a) 몬스터 도감 ↔ 소켓템**: WuWa 에코 / DFO 카드 / FFT 크리스탈 / Vagrant Story. 본작 도감이 처치 수 모델이므로 **"N킬 → 그 몬스터의 룬 해금, 옵션 고정(결정론)"**이 접사 풀을 안 늘리면서 긴 체이스. 코스트 상한은 폐지한 코스트의 부활이니 슬롯 수만.
- **(b) 스킬 지정형 소켓**: DFO 탈리스만(스킬 1 + 룬 3)과 Transistor(자리 따라 3역할). 액티브 슬롯 3에 **"탈리스만 1 + 룬 3"**이 스킬 카드 합성 후속과 정합. DFO가 2024년 소켓 색 랜덤을 걷어낸 것을 반면교사로.
- **(c) 예산형 페널티**: HK 오버참(초과 1개 = ×2, 가장 읽기 쉬움) / WoW 타락(합산 → 임계 4단계) / Bastion 아이돌(자발 다이얼, 산술 합). 방치 계약상 **Bastion형(원정 층, 자발) > HK형(장비 층, 대가 명확) > WoW형(누적 임계, 리포트 인과 추적 어려움)** 순으로 안전. Dead Cells 저주(N킬 상환)는 도감과 결합 가능.
- **(d) 룬워드 문법**: Noita(순서) / Tyranny(3층 + 요구치 합) / ESO(3룬 = 1글리프). 본작 크래프트가 이미 3층이므로 새 문법 불필요. 가져올 건 Tyranny **"레시피 비소모"**와 ESO **"3개 합쳐 1개로 확정(랜덤 없음)"**.
- **공통 회수 교훈**: XC2(융합·불가) ↔ XC3(전원 공유) ↔ SW(마나 지불) — 파티 3인 재배분이 본체인 본작에는 **"룬 층은 공유 라이브러리(XC3), 장비 층은 개별(체이스)"**로 층별 회수 규칙을 다르게.
