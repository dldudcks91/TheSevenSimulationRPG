## 0. 조사 방법과 신뢰도

- 게임 2종씩 병렬 조사 5묶음 + 부록 1묶음 + 메커니즘 압축 1묶음, 총 **웹 검색 약 200회 · 원문 fetch 약 350회**. 1차 자료(공식 패치노트·개발자 발언·공식 위키·데이터마이닝 DB) 우선, 수치는 1차 자료로 교차 확인된 것만 채택.
- 신뢰도 표기는 상세 문서에 항목별로 있다(★★★ 공식 / ★★ 준공식 위키·편집 가이드 / ★ 커뮤니티·스니펫). **미확인 항목**은 각 문서 말미에 나열 — 추측을 확정처럼 쓰지 않았다.
- **걸러낸 오염**: 재화 판매·부스팅 사이트 가이드(aoeah, iggm, u4gm, mmogah 등 30여 곳), AI 생성 SEO 기사(grokipedia, eathealthy365, mejoress 류), 사설 서버 커스텀 규칙(rAthena 스크립트), 타 게임 혼입(shapes.inc). 검색 상위에 뜨지만 수치 근거로 쓰지 않았다.
- 접근 차단(402/403)으로 원문을 못 연 위키: poewiki.net, poe2wiki.net, fandom 계열 다수, lastepochtools, monsterhunterwiki, finalfantasy.fandom → 공식 패치노트·poedb·maxroll·fextralife·game8·archive.org 사본으로 대체. 대체 불가분은 **[미확인]**.
- **조사 원칙으로 남길 것**(Lootun·Dragon Cliff 조사와 동일): 게임 이름이 일치해도 어휘(아이템·슬롯 이름)를 1차 자료로 먼저 확정하고 2차 자료를 그 어휘로 검증할 것. 이번 조사에서도 "PoE2 차암은 반지 슬롯" 같은 오류가 판매 사이트에 널려 있었다.

## 1. 용어 — "2차 층"의 정의와 분류 축

**2차 층** = 장비 자체의 접사(1차 층) 밖에서, 플레이어가 **끼우거나(소켓) 지니거나(슬롯·인벤) 배치해(트리·월드)** 빌드를 조립하는 부가 층. 40종을 아래 6축으로 읽었다.

| 축 | 값 | 예 |
|---|---|---|
| ① **붙는 곳** | 장비 소켓 / 캐릭터 슬롯 / 스킬 / 인벤 격자 / 패시브 트리 / 월드 | D2 룬(장비) · Elden Ring 탈리스만(캐릭터) · Lost Ark 보석(스킬) · D2 차암(인벤) · PoE 주얼(트리) · Loop Hero(월드) |
| ② **효과 성격** | 고정 / 랜덤 / 성장 / 조건→효과 배선 | D2 젬 · D2 주얼 · D3 전설 젬 · D4 룬워드 |
| ③ **예산** | 슬롯 수 / 코스트 / 인벤 격자 / 요구치 합 / 없음 | RO 슬롯 `[n]` · Warframe 용량 · D2 차암 · Tyranny Lore · Bastion |
| ④ **페널티 동반** | 없음 / 자기 페널티 / 예산 초과 페널티 / 누적 임계 | — · D2 Sunder · HK 오버참 · WoW 타락 |

## 2. 한 장 요약 — 40종이 수렴한 발견 12가지

> 아래는 참고작이 **실제로 겪고 고친** 것에서 뽑았다. 본작 판단은 §5·§6에서 한다.

### 발견 1. 2차 층은 "접사가 못 하는 일"을 할 때만 살아남는다
- D3 개발진이 차암을 컷한 이유(2011, Bashiok): "**입고 있는 방어구·무기에서 못 얻는 걸 아무것도 주지 않는다**". D4 젬은 12시즌 동안 "빌드를 정의 못하는 부가물"이었고 2026 LoH에서 무기 젬을 **곱연산 속성 배율**로 바꿔서야 의미를 얻었다. PoE는 3.25에서 주얼의 IIR 롤을 삭제(풀 희석).
- 살아남은 2차 층이 하는 일은 여섯 가지로 압축된다: **조건→효과 배선**(D4 룬워드, PoE Instilling Orb, PoE2 차암) · **빌드 정체성의 영구화**(D4 코덱스, Lost Ark 각인) · **세트**(D4 탈리스만, Lootun/DC 젬 세트) · **드롭 종료 후 성장**(D3 전설 젬, D4 글리프) · **결핍 패치**(PoE2 룬, Grim Dawn 컴포넌트 = 저항 보충) · **스킬 그릇**(FF7 마테리아, Lost Ark 보석, DFO 탈리스만).

### 발견 2. 본체(장비 접사)는 랜덤, 부품(2차 층)은 고정
- Grim Dawn은 Titan Quest에서 물려받은 **완성 보너스(랜덤)를 커뮤니티 투표 후 폐지**(Build 29, "스택 1000")하고 **부분 조각까지 폐지**(1.1.6.0, "부분이 있을 이유가 없어졌다")했다. 라그나로크 카드는 효과 고정, 랜덤은 **장비의 슬롯 수**에만. Last Epoch 아이돌은 접사 T1 고정·크래프트 불가.
- 몬스터 헌터는 랜덤을 **한 층에만** 둔다: World = 장식품 랜덤/호석 확정 → Rise = 장식품 확정/호석 랜덤 → Sunbreak가 둘 다 랜덤(기이 방어구 + 랜덤 호석)으로 가장 비판받음 → Wilds "단일 스킬은 확정 제작, 복합만 랜덤" + 총감독 Tokuda "특정 스킬을 영영 못 얻는 상황을 없앤다".

### 발견 3. 확률 크래프트에는 결정론 천장을 나란히 둔다
- PoE 벤치 "6소켓 350 Jeweller's / 6링크 1,500 Fusing" 보장. D4 템퍼링은 S4 랜덤+브릭 → S6 복원 두루마리 → **S11 원하는 접사 직접 선택**으로 5시즌 만에 결정론화. PoE2 0.2.0은 "룬 3개 → 랜덤 룬" 도박을 폐지하고 **3:1 확정 승급**으로. D2 큐브 룬 승급(3:1·2:1)은 33단계 전체를 하나의 가치 축으로 묶는 장치.

### 발견 4. 파괴·비가역은 한 곳으로 몰아넣는다
- PoE는 Vaal Orb(부패)에만 비가역을 두고 나머지는 되돌릴 수 있다. D4는 변용 1곳. PoE2는 "룬 영구"(0.1.0)를 **10일 만에 덮어쓰기 허용**(0.1.1)으로 완화. 라그나로크는 2016-08 카드 분리 개편에서 **파괴 확률 삭제 + 가격 1/8**("언제 파괴될지 모른다는 불안감은 발걸음을 돌리게 했다" — 공식 공지). Torchlight 1의 "인챈트 실패 시 전소"를 T2가 버렸다. 메이플의 스타포스 파괴는 "장비 자체가 판돈"이라는 비판.

### 발견 5. 층 수 = 재료 탭 · 상인 · UI 탭 수
- D4 9겹, PoE1 10겹, Lost Ark 7겹("숙제 벽"), 메이플 5+1겹, 라그나로크는 20년간 캐시 접점을 위해 층을 덧대다 **"인챈트가 카드 슬롯을 점유"하는 규칙 충돌**을 남겼다. 각 층은 트레이드·커뮤니티 도구·시즌 리셋이 받친다. 거래 없는 싱글(D3·MH·GD)은 층이 적고 재료 경제가 폐쇄 루프다.

### 발견 6. 소켓템은 인벤 오브젝트가 아니라 재료 카운트로
- D4 1.2.0 젬 파편화(명시 이유: 인벤 압박), Grim Dawn 스택 1000, D2R 2026 젬·룬 스택 탭. D2 차암의 인벤 격자는 개발사가 25페이지 스레드에도 불구하고 전용 인벤을 **미도입**한 채 남아 있고, D3는 Talisman(전용 차암 인벤)을 만들려다 통째로 컷했다. Last Epoch은 인벤 격자를 **전용 아이돌 그리드로 격리**해 파밍 공간과의 경쟁만 제거.

### 발견 7. 세트는 장비 밖으로 옮겨지는 중이다 ★ (Lootun·Dragon Cliff 조사의 발견을 재확인)
- Lootun·Dragon Cliff(장비 세트 없음 / 젬 세트 있음)에 더해 — D4는 S13까지 세트 아이템이 없었고 2026 LoH에서 **장비와 별개인 탈리스만 판(인장 1 + 차암 6)에 2/3/5피스 세트**를 얹었다. GW2는 2023년 **6피스 룬 특수효과를 유물 슬롯 1개로 분리**. Summoners War 룬 세트, Hades II 아르카나("같은 코스트 카드 3장 이상"이면 켜지는 구성 조건), MH Wilds 그룹 스킬(세트 불문 태그 3부위), Fate 성배(7클래스 전원 처치 = 세트).
- → 본작 **죄종 세트효과 보류**(item_design.md §4)의 대안 후보가 여기서 나온다(§6-4).

### 발견 8. 스킬을 장비 소켓에 묶지 않는다 — 다만 "스킬 지정형" 소켓은 살아남는다
- PoE1 장비 링크 → PoE2 "젬 자체에 서포트 소켓"으로 이전(GGG: "incidental complexity"), PoE1 3.29는 13년 된 소켓 색 제약을 "차단"에서 "일치 보너스"로 전환. D3 룬스톤(아이템 3,000종 예정)을 스킬 룬으로 내장. FF7 마테리아는 캐릭터 동질화를 리미트 브레이크로 보완, Rebirth는 슬롯을 무기 레벨로 자동 확장. DFO는 2024-06 탈리스만 룬 소켓 색 제약 폐지.
- 살아남은 형태: **스킬 1개를 지정하는 소켓** — Lost Ark 보석(11슬롯, 피해/쿨감 2종), DFO 탈리스만(스킬 1 지정 + 룬 3), Transistor(같은 기능이 액티브/업그레이드/패시브 자리에서 다른 효과), Elden Ring 전회 기억(무기당 1, 무손실).

### 발견 9. 몬스터 도감 ↔ 소켓템
- 라그나로크 카드(거의 모든 몬스터가 자기 카드를 **0.01%**로 드롭 — 사냥터 선택 = 빌드 재료 선택), Wuthering Waves 에코(처치한 몬스터가 곧 장비, 1번 슬롯은 액티브, 코스트 12), FF Tactics 크리스탈(유닛 → 아이템), Vagrant Story(무기가 때린 종을 기억), Grim Dawn 컴포넌트(몬스터별 드롭 편향). 소설에서는 Earthdawn(아이템 역사를 알아야 해금)·나혼렙 그림자 추출(3회 시도).
- 0.01%는 봇·거래·MVP 경쟁이 있는 MMO에서만 정당화된다. 싱글에서는 **처치 수 임계 → 확정 지급**이 같은 감각을 준다.

### 발견 10. 슬롯 수는 굴리지 않는다 — "강화 단계 = 슬롯 수" 또는 "소켓 = 접사 1칸"
- Pathfinder 2e "potency 값 = property 룬 슬롯 수", D3 "소켓 = 접사 1칸"(Ramaladni's Gift는 그 규칙의 예외 소모품), Bloodborne 무기 +1/+3/+6에서 소켓 개방, Grim Dawn은 소켓 뚫기 개념 자체가 없다(모든 장비 컴포넌트 1 + 오그먼트 1). 반대편: D2 소켓 RNG 3중(ilvl × 난이도 × 큐브 랜덤), PoE Jeweller's/Fusing 경제, 라그나로크 슬롯 부여(실패 시 장비+카드 파괴) — 전부 거래 경제가 흡수하는 구조.

### 발견 11. 자기 페널티는 세 형태가 있고 방치형 안전 순위가 있다
- **자발 다이얼**(Bastion 아이돌: 켤 때마다 적 강화 + 보상 산술 합, 최대 +75%) > **예산 초과 1개 허용 + 명확한 대가**(Hollow Knight 오버참: 피해 ×2) > **누적 임계**(WoW 8.3 타락: 아이템별 수치 합산 → 20/40/60/80 단계 페널티, 리포트에서 인과 추적이 어려움). 아이템 단위: D2 Sunder(면역을 95% 저항으로 강등 + 자기 저항 -70~90%), Bloodborne 저주 젬(강한 주옵 + 네거티브 1줄, 안 쓰는 자리에 두면 무료), Dead Cells 저주(N킬로 상환).

### 발견 12. 회수 규칙은 셋이고, 재배분이 본체인 게임은 파괴형을 못 쓴다
- **자유/골드**(Elden Ring, D3, D4, Summoners War, Xenoblade 3 공유 젬) / **양자택일**(Torchlight 2 "젬 파괴+장비 보존 or 장비 파괴+젬 회수", Grim Dawn Salvage, Titan Quest Enchanter) / **덮어쓰기=파괴·회수 불가**(D2, PoE2 0.1.1, ESO, WoW 젬). Xenoblade 2(융합·회수 불가) → 3(파티 전원 공유)로 정반대 실험. D3 비파괴는 "빌드 실험 비용 = 골드뿐"이라는 통제성의 극단.
