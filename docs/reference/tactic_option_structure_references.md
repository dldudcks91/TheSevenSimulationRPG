## 0. 요약

- **카드 게임과 보드게임은 옵션 값을 다시 굴리지 않는다.** 옵션은 값이 고정이고, 플레이어가 고르거나 붙인다.
  - 등급 + 범위 + 재굴림 구조는 장비 게임에만 있다: 서머너즈 워 · 니케 · 세븐나이츠 리버스 · 에픽세븐 · 라스트 에포크 · PoE.
- **규칙형 옵션은 값이 고정이고, 골라 붙인다.**
  - 규칙형 옵션의 예: 분담 · 반사 · 조건부 회복 · 위치 참조.
  - 이런 게임에 있다: 삼국지 전략판 병서 · 랑그릿사 인챈트 · 와일드프로스트 부적 · 하데스 은총.
  - 다시 굴리는 옵션은 거의 다 스탯 %다.
- **보드게임은 두 갈래로 나뉜다.**
  - 캠페인형: 붙이면 못 뗀다. 글룸헤이븐 · 프로스트헤이븐 · 팬데믹 레거시 · 아컴 커스터마이즈가 있다.
  - 대전형: 판마다 점수 예산 안에서 다시 조립한다. X-Wing · 레기온 · 언더월드가 있다.
- **우리 구조와 가장 가까운 짝은 둘이다.**
  - 카드 본체(규칙 고정)는 병서 · 랑그릿사 인챈트와 같은 방식이다.
  - 옵션 줄(등급 · 범위 · 잠금 재굴림)은 니케 오버로드와 같은 방식이다.

## 4. 옵션을 넣는 방식 — 유형

| 유형 | 어떻게 돌아가나 | 게임 |
|---|---|---|
| 주옵 + 부옵, 강화하면 줄이 열림 | 드랍 때 몇 줄이 정해지고, 강화 단계마다 새 줄이 생기거나 기존 줄이 오른다 | 서머너즈 워 · 에픽세븐 · 세븐나이츠 리버스 · 원신 · 스타레일 |
| 등급 = 줄 수 | 등급이 부옵 개수 상한을 정한다 | 에픽세븐 **(약)** · 세븐나이츠 리버스 |
| 확률로 줄 수가 정해짐 | 줄마다 등장 확률이 다르다 | 니케(100 / 50 / 30%) · 원신(3줄 vs 4줄 시작) |
| 줄 잠금 재굴림 | 한 줄을 잠그고 나머지를 굴린다. 잠글수록 비싸진다 | 니케(영구 잠금 · 1회용 잠금) · 세븐나이츠 리버스 |
| 값 바꾸기와 종류 바꾸기를 분리 | 값만 올리는 도구와 종류만 바꾸는 도구가 따로다 | 서머너즈 워(연마석 · 보석) · 에픽세븐(강화 · 개조) · Outerplane(재련 · 트랜지스톤) |
| 한 줄만 바꿀 수 있음 | 종류 교체는 1줄만, 횟수에 상한이 있다 | 서머너즈 워 보석 · 에픽세븐 개조 |
| 소모되는 총량 | 바꿀 때마다 줄어드는 예산이 있어 끝이 있다 | 라스트 에포크 FP · 로스트아크 세공 칸 |
| 확률 세공 | 성공할수록 다음 성공률이 내려간다 | 로스트아크 스톤 |
| 칸 모양이 받는 종류를 정함 | 칸 아이콘 · 모양에 맞는 옵션만 붙는다 | 프로스트헤이븐(□ ○ ◇ ◈) · 글룸헤이븐(줄마다) · X-Wing · 레기온 · 몬스터 헌터(칸 크기) |
| 층마다 한 자리 | 옵션 종류(층)마다 한 칸씩 있고, 같은 층은 덮어쓴다 | 발라트로(강화 · 에디션 · 봉인) |
| 규칙 효과를 골라 붙임 | 고정 값 규칙 효과를 목록에서 고르거나 붙인다 | 삼국지 전략판 병서 · 랑그릿사 인챈트 · 와일드프로스트 · 몬스터 트레인 · 하데스 |
| 효과 + 대가 한 쌍 | 이로운 줄에 나쁜 줄이나 위험이 같이 붙는다 | 로스트아크 각인 · 스톤 감소 줄 · 병서 「유인의 책」 · 슬레이 더 스파이어 2 Corrupted · 어크로스 디 오벨리스크 타락 |
| 강한 옵션이 칸을 더 먹음 | 두 칸을 차지하는 옵션이 있다 | X-Wing(Missile 2칸) · Too Many Bones(Heavy = 3칸) |
| 붙일수록 비싸짐 | 레벨 · 이미 붙은 수에 따라 값이 오른다 | 프로스트헤이븐(레벨 +25 · 기존 강화 +75) · 니케(잠금 수) |
| 칸 수 = 옵션 값 | 강한 옵션은 체크 칸을 더 채워야 켜진다 | 아컴 커스터마이즈 · 프로스트헤이븐 퍽 |
| 갈래 선택 · 전환 | 정해진 A/B 중 하나를 고르고, 비용을 내면 바꾼다 | 어크로스 디 오벨리스크 |
| 세트 · 조합 | 같은 것을 모으면 추가 효과 | 서머너즈 워 세트 · 랑그릿사 인챈트 쌍 · AFK 저니 참 3개 |
| 조건이 맞아야 세짐 | 주인이 맞으면 옵션이 커진다 | 라이즈 오브 킹덤즈(특성 일치 +30%) |
| 영구 vs 판마다 재조립 | 캠페인은 못 뗀다. 대전은 예산 안에서 자유 | 글룸헤이븐 · 팬데믹 레거시 / X-Wing · 레기온 · 언더월드 |
| 좋은 · 나쁜 스티커가 칸을 나눠 씀 | 흉터가 같은 칸 풀을 차지하고, 빼는 데 비용이 든다 | 팬데믹 레거시 · 40K 크루세이드 |
