# TERA — 창기사(Lancer)

**컨셉/역할**: 창과 방패를 쓰는 TERA의 순수 탱커 — 오픈 초기부터 지금까지 유지되는 유일한 정통 탱커로, 전방 아군까지 지켜주는 방패 막기와 공대 버프·수호 스킬이 정체성. 개인 딜량은 셋 중 가장 낮지만 공대 버프 효율이 가장 좋다.

| 방패 방어 | | 방패로 전방의 공격을 막고 방패 뒤 아군도 지켜주는 방어기, 대부분의 다른 스킬을 캔슬하고 즉시 전환할 수 있다 |

| 도약 공격 | | 창을 강하게 내질러 공격하는 주력기, 다른 공격기 뒤에 이어 쓰면 더 빠르게 나간다 |

| 기상 공격 | | 다운된 상태에서 일어나며 주변을 공격하고, 잠시 다운·경직·스턴·밀림에 면역이 되는 기상기 |

| 맹렬한 돌진 | | 창과 방패를 앞세워 전방 방어 효과를 두른 채 돌진하는 주력 공격기, 타격 시 적대치도 추가로 얻는다 |
| 신뢰의 오라 | | 일정 시간 주위 파티원과 자신의 맷집·힘을 늘려주는 오라형 공대 버프 |
| 반격 찌르기 | | 방어에 성공한 직후 쓸 수 있는 반격기, 반격 중엔 다운·경직에 저항하고 받는 피해가 줄어든다 |
| 포획 | | 멀리 있는 대상에게 갈고리를 던져 앞으로 끌어당기는 원거리 스턴기 |
| 압도 | | 뛰어올라 방패로 내려찍는 강공격, 적을 다운시키고 사용 중엔 전방 방어 효과가 붙는다 |
| 방어구 부수기 | | 방패로 대상의 방어구를 가격해 맷집(방어력)을 낮추는 디버프기 |
| 철갑의 의지 | | 일정 시간 MP를 소모해 피해를 흡수하는 보호막을 두르는 생존기 |
| 연쇄 포획 | | 포획을 쓴 직후 한 번 더 대상을 끌어당길 수 있는 후속 스턴기 |
| 충격의 맹타 | | 창으로 강하게 후려쳐 큰 피해를 주고 이동속도를 늦추는 주력기 |
| 분노 유발 | | 주위 몬스터의 분노를 강제로 유발해 적대치를 최대로 끌어올리는 2번째 도발기 |
| 수호의 맹세 | | 일정 시간 주위 파티원이 받는 피해를 줄이고, 그 피해 일부를 자신에게 전이시키는 수호 버프 |
| 전투의 의지 | | 일정 시간 파티원과 자신의 공격속도·스킬 위력을 늘려주는 공대 버프 |
| 작살 사슬 | | 작살을 던져 대상을 기절시키고, 주위의 다른 적까지 사슬로 끌어당겨 한곳에 모으는 광역 스턴기 |
| 전선 유지 | | 고함으로 주위 아군에게 다운·경직 면역을 걸어주고, 몬스터의 적대치도 함께 획득하는 수호형 버프 |
