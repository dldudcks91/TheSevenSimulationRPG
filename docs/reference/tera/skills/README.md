# TERA 직업별 스킬 자료

나무위키의 TERA 직업 스킬 문서를 정리한 자료. 2026-09-23 세션에서 `curl.exe -L` 로 `창기사/스킬` 문서를
받았다. 사용자가 「TERA 랜서」로 지칭한 직업은 한국 서비스명 「창기사」(영문 원 클래스명 Lancer)다 —
한국 클라이언트에서 "검투사"로 번역된 클래스는 영문으로는 "Warrior"이며 랜서와는 다른 직업이니 착오
주의.

**라이선스**: 나무위키 문서는 CC BY-NC-SA 2.0 KR 로 배포된다. 이 폴더의 각 파일은 원문서 표현을 그대로
옮기지 않고 스킬 이름 · 효과 요약(수치 제외) 만 발췌해 표로 재구성했으며, 각 파일 첫 줄에 원문 출처를
남겼다. 삭제된 스킬(위협의 파동)은 현재 게임에 없어 빼고 담지 않았다.
