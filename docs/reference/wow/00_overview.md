## 0. 조사 방법과 신뢰도

WoW는 위키·공식 발표·커뮤니티 가이드가 압도적으로 많은 게임이라 Dragon Cliff·Lootun 조사와 반대로 **자료 과잉**이 문제였다. Blizzard 공식 발표와 Wowhead/Warcraft Wiki/Icy Veins 같은 검증된 위키·공략 사이트를 1차로 삼고, 부스팅 사이트·SEO 가이드(Overgear·Koroboost·Skycoach·Method.gg·Nexttier·Timesaver·Conquestcapped·Boostmatch·ExpCarry·WowCarry·AccountShark·misti.services 등)는 **서로 교차 확인된 수치만** 채택했다.

| 표기 | 소스 | 신뢰도 |
|---|---|---|
| **[공식]** | `worldofwarcraft.blizzard.com/news`, `news.blizzard.com` — 개발자 발표문 원문 | ★★★ |
| **[위키]** | Wowhead(가이드·아이템 DB·탤런트 계산기), Warcraft Wiki(warcraft.wiki.gg), Wowpedia | ★★★ 커뮤니티가 즉시 정정하는 대형 위키 — 오래 검증됨. 단 **탤런트 계산기 페이지는 JS 렌더링이라 WebFetch로 본문 추출이 안 됨**(§0-1) |
| **[가이드]** | Icy Veins·Method.gg(전문 공략 사이트, 레이드 팀들이 실제로 참고) | ★★★ |
| **[부스팅]** | Overgear·Koroboost·Skycoach·Method.gg·Nexttier·Timesaver·Conquestcapped·Boostmatch·ExpCarry·WowCarry·AccountShark·misti.services·mmoexp 등 골드/부스팅 판매 사이트의 공략 블로그 | ★★ — 개별 사이트 하나만으로는 안 믿었고, **2개 이상이 같은 수치로 수렴할 때만** 인용 |
| **[커뮤니티]** | Blizzard 공식 포럼 스레드, WoWUtils(시뮬레이션 기반 손비타 계산 사이트) | ★★ |
| **N/F** | 확인 못 함 | — |

### 0-1. 이번 심화의 방법론적 한계 — Wowhead 탤런트 계산기는 못 열었다

이번 심화(2026-08-31)에서 Wowhead의 인터랙티브 탤런트 계산기(`wowhead.com/talent-calc/*`)를 WebFetch로 여러 차례 시도했으나, **SPA(JS 렌더링) 페이지라 헤더·네비게이션만 반환되고 실제 탤런트 노드 데이터는 확보되지 않았다** — 아이온 조사(`aion/00_overview.md §0`)에서 겪은 것과 같은 유형의 기술적 한계다. 대신 **Icy Veins의 정적 렌더링 공략 페이지**(빌드 요약·핵심 탤런트 서술)와 **WebSearch가 여러 결과를 종합한 요약**으로 대체했다 — 이 때문에 [01_skills.md](01_skills.md)의 실제 탤런트 수치는 "노드 전량표"가 아니라 **핵심 탤런트·Apex 탤런트·티어세트 발동 효과** 같은 "실제로 확인된 스킬 텍스트" 위주로 채워졌다. 노드 총량표 확보는 diablo2 조사(Arreat Summit 정적 표)만큼의 밀도에 못 미친다 — 이 갭은 각 절에서 N/F로 명시한다.

### 0-2. 시점 문제 — "Midnight"과 "패치 12.1"은 다른 정밀도의 시점이다

- **Midnight**(2026-03 출시, 11번째 확장팩)은 큰 틀(레벨 90·탤런트 재편·5트랙 강화)을 정한 시점
- **패치 12.1 "Curse of Ula'tek"**(2026-08-11/12 라이브, 시즌 2는 08-18 개시)이 이 조사 시점(08-31)의 실제 현재 패치다 — 시즌 2 신규 레이드 **볼트 오브 아탈'우텍(The Venomous Abyss, 8보스)**, 신규 최종보스 **울라'텍**을 포함한다[가이드]
- 이 문서군은 **"Midnight 공통 구조"와 "시즌 2(12.1) 전용 수치"를 구분해 표기**한다 — 시즌 1 수치가 섞여 인용된 경우 어느 시즌인지 각주로 명시(자세한 수치는 [02_items.md §5](02_items.md#5-강화업그레이드-시스템--크레스트--트랙))

## 1. 게임 구조 한 장

```
   레벨 1~90 (Midnight, 2026-03 출시 — 11번째 확장팩 · 현재 패치 12.1 "Curse of Ula'tek", 2026-08)
   ┌──────────────────────────────────────────────────┐
   │ 클래스 13종 선택 → 전문화 3~4(총 40종) 중 1택         │
   │        ↓                                          │
   │ 던전/레이드/오픈필드 자동 전투 아님 — 100% 수동 조작   │
   │ 파티(던전 5인) / 레이드(10~20인) 실시간 협동 전투     │
   │        ↓                                          │
   │ 전리품 = 장비(ilvl) + 재화(크레스트·골드) + 세트 토큰  │
   │        ↓                                          │
   │ 강화(크레스트 소모) · 제작(전문기술) · 인챈트/젬       │
   └──────────────────────────────────────────────────┘
```

- **본작과 가장 다른 전제** — WoW는 **전투가 100% 수동 조작**이고 파밍은 그 부산물이다. 본작은 반대로 **전투가 자동이고 파밍이 목적**이다. 그래서 이 조사는 "전투 설계"가 아니라 **"장비·스킬이 무엇으로 구성되는가"라는 구조 껍데기만** 참고 대상으로 삼는다 — 전투 페이싱(로테이션·자원)까지 옮겨올 근거는 약하다는 점을 먼저 못박는다
- **시즌제 라이브 서비스** — 하나의 확장팩(Midnight) 안에서도 시즌(현재 시즌 2)마다 아이템 레벨 상한·크레스트 이름·레이드가 통째로 갈린다. "확장팩"이 아니라 **"시즌"이 본작의 "챕터"에 가장 가까운 단위**다
- **클래스 13종은 그대로, 전문화 총수는 39→40으로 늘었다** — 이번 조사에서 새로 확인한 것: 패치 12.1에서 악마사냥꾼(Demon Hunter)에게 3번째 전문화 **디바우러(Devourer)**가 신설됐다(기존 황폐화Havoc·복수Vengeance 2개뿐이던 유일한 2전문화 클래스였음). 상세는 [01_skills.md §5](01_skills.md#5-새로운-파워-축-실험--디바우러devourer-악마사냥꾼)

## 2. 아이템 구조 (요약 — 상세는 [02_items.md](02_items.md))

- **슬롯 체계** — 16부위(방어구 8 + 장신구 6 + 무기 2). 본작 9착용위치의 거의 두 배([02_items.md §1](02_items.md#1-슬롯-체계--16부위))
- **아이템 등급** — 6단계(회색~주황). 등급이 접사 슬롯 수를 정하고, **ilvl 스탯 스케일링은 지수 곡선**(`B(x) = a × 1.15^(x/15)`) — 본작의 지수 성장 방식과 형태가 동일([02_items.md §2](02_items.md#2-아이템-등급--ilvl-스케일링))
- **소켓·인챈트·젬** — 반지·목걸이는 소켓 1개 고정, **헬름·팔찌·벨트는 소모품으로 소켓 추가 가능**(이번 심화 신규 확인). 인챈트 가능 슬롯은 시즌마다 바뀌며 **12.1 시점 정확히 6부위**(투구·어깨·반지·부츠·가슴·무기)로 확정([02_items.md §3](02_items.md#3-소켓--인챈트--젬))
- **티어세트(Tier Set)** — 5부위 중 4부위만 채워도 2/4피스 보너스가 전부 발동하는 계단형 구조, 카탈리스트로 "안 뜨는 부위" 문제를 보정([02_items.md §4](02_items.md#4-티어세트tier-set))
- **강화(업그레이드)** — 5개 트랙(Adventurer~Myth) × 각 6단계, 트랙마다 크레스트 종류가 다르고 랭크당 비용은 고정([02_items.md §5](02_items.md#5-강화업그레이드-시스템--크레스트--트랙))
- **전설·임벨리시먼트·3차스탯** — 체계적 전설 시스템(룬각인)을 도입했다가 후퇴시킨 전례, 임벨리시먼트 동시 장착 상한 2개, 3차 스탯이 접사 풀 순도를 별도 계층으로 격리([02_items.md §6](02_items.md#6-전설-장비--부가효과임벨리시먼트--3차-스탯))
- **제작 품질** — 12.1에서 소모품·재료 품질이 청동 폐지, **은/금 2단으로 단순화**(장비 자체는 5랭크 유지)([02_items.md §7](02_items.md#7-제작-품질--12.1-단순화))

## 4. 본작 대조 시사점

**설계 원리 관찰 — 그대로 옮기라는 게 아니라 "이런 축이 있다"는 기록이다.**

1. **다층 정체성은 "공유 폭"으로도 가를 수 있다** — 본작은 지금 "공식의 자리"(직업/죄종)로만 층을 나눴다. WoW의 클래스→전문화→히어로특성→Apex 4단은 **"몇 명이 이 노드를 같이 쓰는가"**라는 완전히 다른 축이다. 본작 전직 3갈래(§4-1)가 "무기군 축은 폐기하고 성격 축으로 갔다"는 결정을 내릴 때 실제로 쓴 판단 기준("전직이 상황별 스위치가 되면 안 된다")이 WoW의 히어로특성 설계 원칙(전문화당 하나만 고정 선택, 무료지만 전투 중 스위치는 불가)과 **정확히 같은 문제의식**이라는 걸 이번 조사로 재확인했다 — 이미 옳은 방향에 있다는 교차검증

2. **노드를 도형으로 액티브/패시브/선택 구분** — 본작 skill_design.md §1의 텍스트 정의(행동주기 소모 여부)를 화면에서 **즉시 식별 가능한 시각 기호**로 옮기는 건 검토할 만하다. 관전이 유일한 인과 창구인 본작에서 특히 값이 크다(SCREEN_DESIGN.md 소관)

3. **키스톤/캡스톤 — 트리에 "입구"와 "출구"를 명시** — 본작 마스터리의 "얕은 노드=수치 패시브, 깊은 노드=반응 패시브"(skill_design.md §1-3)는 깊이로 방향을 주지만 **트리 맨 위(입구)가 뭘 여는지, 맨 아래(출구)가 뭘 완성하는지의 이름**은 아직 없다. WoW식 "첫 노드=핵심 메커니즘을 여는 키스톤, 마지막 노드=완성하는 캡스톤"이라는 **위치별 역할 이름**은 §7 "노드 규모"를 정할 때 훔칠 만한 최소 어휘다

4. **자원 시스템은 실시간 조작의 장치다 — 본작에 옮길 근거가 약하다** — WoW의 빌더/스펜더 자원 순환이 화려해 보이지만, 이건 **플레이어가 매 순간 "지금 스펜더를 쓸까"를 판단하는 게임에서만 의미가 있다.** 본작은 자동전투라 그 판단을 AI가 대신 내려야 하는데, 그러면 결국 "규칙으로 정해진 우선순위"(battle_design.md §3)로 수렴해 WoW식 자원의 재미(플레이어의 실시간 타이밍 감각)를 못 가져온다. **탐낼 게 아니라 "안 맞는 장치"로 기록해 두는 편이 낫다** — 다만 "무언가가 다른 무언가의 발동 빈도를 조절한다"는 상호 종속 사고방식 자체는 §7 "반응 패시브의 예산 자" 미확정 과제에 참고 가치가 있다

5. **티어세트의 카탈리스트(전환) 시스템과 "4/5피스로 완전체"라는 완충 — "안 뜨는 부위" 문제의 별도 해법** — 본작은 세트효과 자체를 폐기하고 전술카드로 이관했다(item_design.md §4). 그런데 "특정 부위·특정 옵션이 하필 안 뜬다"는 좌절 자체는 세트가 없어도 남는다. WoW가 이 문제를 **"세트를 지키되 획득 난이도를 화폐(카탈리스트)로 보정"**하고, 나아가 **"5부위 중 4부위만 채워도 최종 보너스가 전부 켜지게"**([02_items.md §4](02_items.md#4-티어세트tier-set)) 아예 마지노선을 낮춘 것은, 본작이 나중에 "특정 옵션 지정 크래프트"(item_design.md §5-3 "지정재가 두 일을 겸한다")를 설계할 때 참고할 만한 **다른 해법 계열**이다

6. **3차 스탯(Avoidance/Leech/Speed) — 접사 풀 순도 문제를 20년째 같은 방식으로 푼다** — 본작 item_design.md "접사 풀 순도"(§2 변경점 표)가 이미 WoW의 3차 스탯과 같은 결론(주력 판단축과 덤 판단축을 분리한다)에 도달해 있다는 교차검증

7. **소켓·전설 시스템은 확장팩마다 스스로 뒤집었다 — 다만 "완전 폐지"는 과장이었다** — War Within→Midnight에서 반지·목걸이 소켓 추가 소모품이 사라진 것은 맞지만, 이번 심화로 **헬름·팔찌·벨트는 여전히 소켓 추가 소모품(Radiant Jewelbinder 등)이 살아있다**는 것을 새로 확인했다([02_items.md §3](02_items.md#3-소켓--인챈트--젬)) — "파밍 목표를 슬롯 단위로 켜고 끈다"는 것이 부위별로 정밀하게 조율된다는 뜻이다. Shadowlands 룬각인(체계적 전설)→이후 확장팩(희소 이벤트 전설)으로의 후퇴는 여전히 유효한 관찰 — 본작이 "치명 배수를 유니크·낙인으로 아낀다"(item_design.md §3)는 절제형 결정을 이미 내린 것과 같은 방향이다

8. **콘텐츠 난이도 = ilvl 트랙이라는 WoW식 단순화 대비, 본작은 레벨과 희귀도를 이미 한 단계 더 떼어 놨다** — item_design.md의 드롭 파이프라인(§1)이 "레벨(ilvl)은 대역만, 희귀도는 몬스터+매직찬스가 정한다"고 명시적으로 분리한 것은, WoW가 "난이도 하나가 트랙과 등급을 같이 미는" 것보다 **한 겹 더 분해한 설계**다

9. **새 전문화(디바우러)는 "옆으로 폭을 넓히는" 확장이 여전히 새 문법 실험의 자리로 쓰인다는 재확인** — 20년 차 게임이 신규 전문화 하나를 추가하면서 **"WoW 역사상 최초의 지능 스케일링 근접 인접 클래스"**([01_skills.md §5](01_skills.md#5-새로운-파워-축-실험--디바우러devourer-악마사냥꾼))라는, 기존 13클래스·39전문화 어디에도 없던 파워 축을 실험했다는 것은 `aion/00_overview.md §4-6`("클래스 확장은 깊이가 아니라 폭")이 관찰한 패턴을 **완전히 다른 장르(수동조작 하드코어 MMORPG)에서 독립적으로 재확인**하는 세 번째 사례다(Dragon Cliff·Aion에 이어)
