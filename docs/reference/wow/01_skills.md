## 0. 조사 방법과 신뢰도

[00_overview.md §0](00_overview.md#0-조사-방법과-신뢰도)와 동일한 신뢰도 표기(**[공식]·[위키]·[가이드]·[부스팅]·[커뮤니티]**)를 그대로 쓴다.

**이번 심화의 방법론적 한계** — Wowhead의 인터랙티브 탤런트 계산기(`talent-calc`)는 SPA(JS 렌더링)라 WebFetch로 실제 노드 데이터를 못 가져왔다(헤더만 반환됨, [00_overview.md §0-1](00_overview.md#0-1-이번-심화의-방법론적-한계--wowhead-탤런트-계산기는-못-열었다)). 대신 **Icy Veins의 정적 빌드 가이드 페이지**(WebFetch 성공)와 **WebSearch 종합 요약**으로 대체했다 — 이 문서의 "실제 수치"는 diablo2 조사(Arreat Summit 레벨별 표 전량)만큼의 밀도가 아니라, **핵심 탤런트·Apex 탤런트·티어세트 발동 효과**처럼 실제로 원문 확인된 텍스트 위주다.

## 1. 탤런트 트리 구조 — 클래스 트리 + 전문화 트리 2단

### 1-1. 포인트 배분 [위키][공식]

- 레벨업마다 **클래스 포인트**와 **전문화 포인트**를 번갈아 획득한다(API 상으로는 하나의 트리지만 화면엔 둘로 나뉘어 보인다)
- **레벨 70(War Within 기준) 시점 포인트 총량 — 클래스 31 + 전문화 30 = 61**[커뮤니티 집계, 위키 교차확인]
- **Midnight(레벨 90)에서 +10 재분배**[공식] — **클래스 +3 · 전문화 +4 · 히어로 탤런트 +3**. 즉 레벨 90 기준 대략 **클래스 34 + 전문화 34 + 히어로 13**

### 1-2. 게이트(선행조건) 규칙 [위키]

- 트리는 행(row) 단위로 나뉘고, **"앞 행에 일정 포인트를 썼어야 다음 행을 살 수 있다"**는 문턱이 있다(예: 5행부터는 누적 8포인트, 8행부터는 누적 20포인트를 요구)
- Dragon Cliff의 "4그룹, 앞 그룹 N점 채우면 다음 그룹 해금"과 **동일한 원리**다 — "이전 구간에 누적 포인트 요구"라는 계단형 게이트가 서로 다른 두 게임에서 같은 해법으로 반복된다

### 1-3. 노드 형태 — 도형으로 액티브/패시브/선택을 구분 [위키]

| 도형 | 뜻 |
|---|---|
| ▢ 사각형 | **액티브 스킬** — 새 스킬을 배우거나 기존 스킬을 바꾼다 |
| ● 원형 | **패시브 효과** — 수치 상승 · 상시 효과 |
| ⬡ 팔각형 | **선택 노드** — 2개 중 1개를 고른다(둘 다는 불가) |

- **본작의 "액티브/패시브 2층"(skill_design.md §1) 구분 기준과 그대로 대응한다.** 본작이 문서 텍스트로 "행동 주기를 먹는가"로 가르는 것을, WoW는 **화면 도형 하나로 즉시 식별**되게 만들었다 — 조작이 없어 "관전 화면이 유일한 인과 창구"인 본작일수록 이 시각 구분 원칙이 마스터리 트리 UI에 직접 참고될 만하다(SCREEN_DESIGN.md 소관)

### 1-4. 클래스 트리 vs 전문화 트리의 내용 분담 [공식][위키]

- **클래스 트리** — 그 클래스의 **모든 전문화가 공유**하는 유틸리티(이동기·해제기·방어 쿨다운 등). "무엇을 고르든 기본 생존기는 유지"하기 위한 층
- **전문화 트리** — **주 역할(딜/힐/탱)을 강화**하는 로테이션 핵심 능력
- → **"모두가 공유하는 것"과 "역할이 갈리는 것"을 트리 레벨에서 물리적으로 분리**했다. 본작 마스터리의 "직업 마스터리 = 내 숫자를 키운다 / 죄종 마스터리 = 그 숫자가 상대에게 닿는 방식을 바꾼다"(skill_design.md §3)는 **공식의 자리**로 가르는 것과는 다른 축(WoW는 "공유 범위"로 가름)

## 2. 전문화(Specialization) — 클래스 정체성을 가르는 단위

### 2-1. 13클래스 × 전문화 — 39 → **40**으로 갱신 [위키][부스팅×3 교차확인]

| 클래스 | 전문화 (12.1 기준) |
|---|---|
| 죽음의기사(Death Knight) | 혈기(Blood)·냉기(Frost)·부정(Unholy) — 3 |
| **악마사냥꾼(Demon Hunter)** | 파괴(Havoc)·복수(Vengeance)·**디바우러(Devourer, 신규)** — **2→3 (12.1 신설, §5)** |
| 드루이드(Druid) | 조화(Balance)·야성(Feral)·수호(Guardian)·회복(Restoration) — 4 |
| 기원사(Evoker) | 증강(Augmentation)·황폐(Devastation)·보존(Preservation) — 3 |
| 사냥꾼(Hunter) | 야수(Beast Mastery)·사격(Marksmanship)·생존(Survival) — 3 |
| 마법사(Mage) | 비전(Arcane)·화염(Fire)·냉기(Frost) — 3 |
| 수도사(Monk) | 양조(Brewmaster)·운무(Mistweaver)·풍운(Windwalker) — 3 |
| 성기사(Paladin) | 신성(Holy)·보호(Protection)·징벌(Retribution) — 3 |
| 사제(Priest) | 수양(Discipline)·신성(Holy)·암흑(Shadow) — 3 |
| 도적(Rogue) | 암살(Assassination)·무법(Outlaw)·잠행(Subtlety) — 3 |
| 주술사(Shaman) | 정기(Elemental)·고양(Enhancement)·복원(Restoration) — 3 |
| 흑마법사(Warlock) | 고통(Affliction)·악마학(Demonology)·파괴(Destruction) — 3 |
| 전사(Warrior) | 무기(Arms)·분노(Fury)·방어(Protection) — 3 |
| **합계** | **13클래스 · 40전문화**(디바우러 신설로 +1) |

- **"13클래스 대부분 3전문화(드루이드 4)"라는 기존 조사의 결론에, 이번 심화로 "악마사냥꾼도 이제 3전문화"라는 갱신이 붙는다.** 공식 발표문 제목("Reveals Midnight Apex Talents For All 40 Class Specializations")이 40이라는 총량을 직접 확인해 준다[부스팅, 공식 발표 제목 교차확인]

### 2-2. 전사 사례 — 역할이 갈리는 전문화 [공식][가이드]

| 전문화 | 역할 | 정체성 |
|---|---|---|
| 무기(Arms) | 딜러 | 양손무기로 강력한 일격 · 폭딜과 제어 |
| 분노(Fury) | 딜러 | 양손 무기 두 자루 난타 · 분노 자원을 빠르게 쌓고 푼다 |
| 방어(Protection) | 탱커 | 한손무기+방패 · 어그로를 끌고 버틴다 |

- 클래스 하나(전사)가 **딜러 2종 + 탱커 1종**으로 갈린다 — 무기군(양손 vs 한손+방패)이 역할과 함께 바뀌는 구조는 **본작의 "전사 = 무엇으로 싸우는가(자기 강화·무기·목소리)" 갈래축**(skill_design.md §4-1)과 표면적으로 유사해 보이지만, WoW는 **역할(딜/탱)이 갈리고** 본작은 **셋 다 같은 역할(딜) 안에서 성격만 갈린다** — 본작이 이미 "전사=무기군 3종" 안을 폐기하고 "무엇으로 싸우는가"로 바꾼 이유(§4-1의 무기 드롭 종속 문제)가 WoW식 "전문화=무기+역할 동시 결정" 모델의 함정과 같은 자리라는 걸 보여준다

## 3. 히어로 탤런트 + Apex 탤런트 — War Within(2024)와 Midnight(2026)의 2단 신설

### 3-1. 히어로 탤런트 도입 배경 [공식]

> Blizzard 공식 발표: 히어로 탤런트는 "각 전문화를 위한 상록수 형태의 캐릭터 진행 수단"이며, **기존 트리로는 못 담던 새로운 클래스 판타지**를 제공하기 위해 War Within(2024)에서 도입했다.

### 3-2. 구조 [공식][위키]

| 항목 | 값 |
|---|---|
| 트리 수 | 클래스당 **3개**(드루이드 4개) — **전문화 2개가 트리 1개를 공유하는 겹침 구조**(§3-3) |
| 노드 수 | 트리당 **11개**(Midnight +3으로 14개, §3-4) |
| 잠금 해제 | **71레벨**부터, 71~80레벨까지 매 레벨 1포인트(레벨 80이면 전부 습득) |
| 선택권 | **전문화당 2개 트리 중 1개**를 고른다. 언제든 무료로 재선택 가능(클래스 탤런트 리스펙과 동일한 방식) |
| 구조 | **키스톤(맨 위)** — 트리의 핵심 메커니즘을 여는 노드 / **선택 노드 3~4개** — 둘 중 하나 / **캡스톤(맨 아래)** — 테마를 완성하거나 새 파워를 더한다 |

### 3-3. 전 클래스 히어로 탤런트 명단 — 이번 심화 신규 확보 [가이드][부스팅×2 교차확인]

| 클래스 | 히어로 탤런트 트리(전문화별 2택1) |
|---|---|
| 죽음의기사 | Deathbringer · Rider of the Apocalypse · San'layn |
| 악마사냥꾼 | 파괴/복수: Aldrachi Reaver · Fel-Scarred / **디바우러(신규): Annihilator · Void-Scarred**(§5) |
| 드루이드 | Druid of the Claw · Elune's Chosen · Keeper of the Grove · Wildstalker(4전문화 각 1개씩으로 추정, 짝지음 세부는 N/F) |
| 기원사 | Chronowarden · Flameshaper · Scalecommander |
| 사냥꾼 | Dark Ranger · Pack Leader · Sentinel — **전문화별 2택1이 삼각형으로 겹친다**: 야수=Dark Ranger+Pack Leader / 사격=Dark Ranger+Sentinel / 생존=Pack Leader+Sentinel[가이드×3 교차확인] |
| 마법사 | Sunfury · Frostfire · Spellslinger |
| 수도사 | Master of Harmony · Conduit of the Celestials · Shado-Pan |
| 성기사 | Lightsmith · Herald of the Sun · Templar |
| 사제 | Voidweaver · Oracle · Archon |
| 도적 | Deathstalker · Trickster · Fatebound |
| 주술사 | Stormbringer · Farseer · Totemic |
| 흑마법사 | Soul Harvester · Hellcaller · Diabolist |
| 전사 | Colossus · Slayer · Mountain Thane |

- **헌터의 "삼각형 겹침"이 이 표에서 가장 흥미로운 구조다** — 트리 3개 중 각 전문화가 정확히 2개씩을 나눠 갖되, 어느 두 전문화도 같은 페어를 공유하지 않는다(3택2 조합 3가지가 3전문화에 정확히 1:1 대응). 이는 [00_overview.md §4-1](00_overview.md#4-본작-대조-시사점)의 "공유 폭으로 층을 가른다"는 관찰에 **구체적 조합 패턴**을 하나 더한다 — 본작이 전직 갈래 사이에 "일부 노드를 공유시킬지"를 검토할 때, 트리 수보다 전문화 수가 적은 경우(여기선 3트리·3전문화가 같지만, 만약 4클래스 6조합이 4트리로 압축된다면) 겹침 방식의 참고가 될 수 있다
- **Apex 탤런트는 히어로 탤런트가 아니라 전문화 트리 자체의 신규 캡스톤이다** — 명칭이 비슷해 혼동하기 쉽지만 별개 층이다(§00_overview §1-3 갱신, §3-4)

### 3-4. Midnight(2026)의 확장 — 히어로 탤런트 +3 & Apex 탤런트 신설 [공식]

- 레벨 81~90 구간에서 **히어로 탤런트에 +3포인트**(새 열 하나 추가) — 트리가 11 → 14노드 규모로 커졌다
- **Apex 탤런트** — 히어로 탤런트가 아니라 **전문화 트리 맨 밑에 신설된 새 캡스톤**. "히어로 탤런트가 안 다뤄본 테마를 팠다면, Apex는 그 전문화의 **기본 게임플레이 메커니즘 자체를 한 단계 더 강화**한다"[공식]는 위상 차이가 있다
- **구조 3단**[공식, 이번 심화로 원문 재확인] — **키스톤 티어(1포인트)**: 큰 파워 증가와 새 플레이 방식을 연다 / **중간 노드(2포인트)**: Apex 능력이나 전문화 핵심 스킬 몇 개를 강화 / **캡스톤(1포인트)**: 키스톤과 중간 노드를 하나의 완결된 패키지로 묶는다. 레벨 81/84/87/90에 걸쳐 총 4포인트를 배치
- **레벨 81부터 잠금 해제**, 트리 맨 아래 위치

## 4. 대표 클래스 실제 탤런트·수치 — 격노 전사 + 시즌2 티어세트 7종

### 4-1. 격노 전사(Fury Warrior) — Apex 탤런트 "Rampaging Berserker" 전량 [가이드, Icy Veins 원문 WebFetch]

패치 12.1 기준 격노 전사의 Apex 탤런트는 4포인트 모두 하나의 테마(Rampage·Recklessness 강화)로 수렴한다:

| 포인트 | 효과 |
|---|---|
| 1번째(키스톤) | 격노(Rampage) 시전 시 Berserk 버프 발동 |
| 2~3번째(중간) | Rampage의 피해량 상승 + Recklessness 중 Rampage의 격노(Rage) 비용 감소 — "강력한 일격을 훨씬 자주 쓰고, Recklessness 창 안에서 Berserk 스택을 더 높이 쌓게" 만든다 |

## 5. 새로운 파워 축 실험 — 디바우러(Devourer, 악마사냥꾼)

패치 12.1에서 악마사냥꾼(원래 2전문화만 있던 유일한 클래스)에 3번째 전문화 **디바우러**가 신설됐다[공식 포럼 발표][부스팅×3 교차확인].

| 항목 | 내용 |
|---|---|
| 정체성 | **공허(Void) 테마 원거리 시전형 딜러** — 사거리 25야드, 가죽 방어구 |
| 역사적 의의 | [부스팅] **"WoW 사상 최초의 지능(Intellect) 스케일링 근접-인접 클래스"** — 근접(5야드)도 순수 원거리(30~40야드)도 아닌 중간 사거리(기원사 적룡 시전과 유사한 포지션)로 규정됨 |
| 핵심 순환 | 흡수(Consume)로 영혼 파편(Soul Fragment) 생성 → 격노(Fury)를 공허 광선(Void Ray)에 소비 → 공허 변신(Void Metamorphosis, 쿨다운·고정 지속시간 없음) 상태에서 영혼을 태워 붕괴하는 별(Collapsing Star) 시전 |
| 핵심 프록 | Moment of Craving — Void Ray 완전 채널링 후 Reap 쿨다운 초기화 + 다음 Reap이 영혼 파편 최대 6개 추가 수집 |
| 히어로 탤런트 | Annihilator · Void-Scarred(§3-3) — 디바우러 전용 2택1 |

**본작에 던지는 시사점** — 파괴(근접 격투)·복수(탱커) 2전문화만 갖고 20년 가까이 버틴 클래스에 **"기존 전문화 어디에도 없던 완전히 새로운 스탯 축(지능)과 사거리 대역(중거리)"**을 통째로 얹은 사례다. `aion/01_skills.md §3-2`가 관찰한 "사격성 = 시전이 아니라 누적 딜로 오르는 완전히 새 파워 축"과 **독립적으로 같은 패턴**에 도달했다 — 대형 라이브 서비스 MMORPG가 신규 클래스/전문화를 추가할 때 "기존 문법의 재탕"이 아니라 **"이 게임에 없던 자원·스탯·사거리 조합을 실험하는 자리"**로 쓴다는 것이 장르를 가리지 않고 반복된다는 뜻이다. 본작이 새 직업이나 전직 갈래를 추가할 때도 "기존 5직업 문법의 변주"에 그치지 않고 **한 번쯤 완전히 새로운 축(예: 기존에 없던 자원 소비 방식)을 실험하는 슬롯**을 의도적으로 남겨 둘 근거가 된다.

## 6. 로테이션 · 쿨다운 · 자원 설계 원리

### 6-1. GCD(전역 쿨다운) [위키]

- **기본 1.5초** — 대부분의 스킬 사용마다 이 시간만큼 다른 액티브를 못 쓴다. 일부 클래스/폼(도적, 냥꾼폼 드루이드, 수도사)은 **1.0초**로 더 빠르다
- **개별 쿨다운은 GCD 위에 얹힌다** — 스킬 고유 쿨다운이 GCD보다 항상 크므로, "이 스킬을 몇 번째 GCD에 쓸 수 있는가"가 로테이션 설계의 기본 단위가 된다

### 6-2. GCD 밖(Off-GCD) 스킬 [위키][커뮤니티]

- 자동공격, 일부 즉발기·해제기·방어 쿨다운은 **GCD를 소모하지 않는다** — GCD로 묶인 메인 로테이션 사이 틈에 "끼워 쓸 수 있는" 별도 층
- → **GCD 스킬 = 결정, Off-GCD 스킬 = 반응**이라는 역할 분담이 자연히 생긴다. 본작의 "액티브 = 행동 주기를 먹는다 / 패시브(반응 패시브 포함) = 안 먹는다"(skill_design.md §1-1)는 구분과 **개념적으로 같은 자리**를 차지한다

### 6-3. 자원 시스템 — 빌더/스펜더가 사용 빈도를 조절 [커뮤니티×3 교차확인]

| 자원 | 대표 전문화 |
|---|---|
| 마나 | 대부분의 힐러·일부 마법 딜러 |
| 분노(Rage) | 전사 |
| 기력(Energy) | 도적, 냥꾼폼 드루이드 |
| 집중(Focus) | 사냥꾼 |
| 룬 마력(Runic Power) | 죽음의기사 |
| 광기(Insanity) | 암흑사제 |
| 천체력(Astral Power) | 조화 드루이드 |
| 마엘스트롬(Maelstrom) | 정기 주술사 |
| 격노(Fury) → 소울 파편(Soul Fragment) | **디바우러(§5, 신규)** |
| 연계·신성한힘·기·영혼조각 등 | 도적/성기사/수도사/흑마법사 계열의 2차 자원 |

- 대부분의 딜러 전문화가 **"자원을 만드는 스킬(빌더)"과 "자원을 쓰는 스킬(스펜더)"의 순환**으로 설계된다 — 빌더는 GCD를 채우는 저위력 반복 스킬, 스펜더는 자원이 찼을 때 터뜨리는 고위력 스킬
- **본작과의 가장 뚜렷한 차이점** — 본작은 "마나가 없고 비용이 행동 1회뿐"(skill_design.md §9-1 규칙 1)이라 **페이스를 정하는 축이 쿨다운 하나**다. WoW는 쿨다운(개별기) + GCD(전역) + 자원(마나/분노 등) **셋**이 동시에 페이스를 조율한다. 본작이 자동전투라 "빌더/스펜더 판단"을 플레이어가 못 내리는 게 이 차이의 근본 원인 — **자원 시스템은 실시간 조작 게임의 장치이지, 자동전투 게임에 그대로 옮길 축이 아니다**

## 7. 클래스 정체성 다층 분담 — 종합

```
클래스(13종)         "이 클래스는 무엇을 하는가"           — 전체가 공유 (판타지의 뼈대)
  └ 전문화(40종/13클래스) "이 클래스가 어떤 역할로 싸우는가"   — 딜/탱/힐 분기 (역할 정체성)
      └ 히어로탤런트(2특성 공유, 71~) "같은 역할 안에서 어떤 하위 판타지인가" — War Within 신설
          └ Apex탤런트(전문화 전용, 81~) "그 전문화의 정점을 얼마나 세게 미는가" — Midnight 신설
```

- **새 층을 넣을 때마다 "무엇을 공유하고 무엇을 안 하는가"의 폭을 계속 좁혀 왔다.** 클래스 트리(13분의 1이 공유) → 전문화 트리(3~4분의 1) → 히어로특성(대개 3분의 2, 그마저 2개가 공유) → Apex(전문화 전용, 공유 없음). **가장 최근에 추가된 층일수록 공유 폭이 좁다**는 게 일관된 패턴이다
- 본작 skill_design.md의 "마스터리 2탭(직업/죄종) + 전직 3갈래" 구조와 **층 수는 비슷하지만(2~3층) 가르는 기준이 다르다.** WoW는 "누구와 공유하는가"로 층을 쌓았고, 본작은 "공식의 어느 자리에 들어가는가"([1]기본공격력/[2]타격피해/[3]최종피해 — skill_design.md §3)로 층을 쌓았다. **본작 쪽이 더 원리적**(공식에서 연역)이고 WoW 쪽이 **더 체험적**(플레이어가 느끼는 소유 감각으로 연역)이다
