## 0. 조사 방법과 신뢰도

[00_overview.md §0](00_overview.md#0-조사-방법과-신뢰도)와 동일한 신뢰도 표기(**[공식]·[위키]·[가이드]·[부스팅]·[커뮤니티]**)를 그대로 쓴다.

이번 심화의 진전 — 기존 조사가 N/F로 남겼던 **"인챈트 가능 슬롯의 정확한 표"**를 Method.gg의 12.1 전용 정리 페이지(WebFetch 원문)로 해소했고, **"소켓 추가 소모품이 완전히 사라졌다"**는 기존 서술이 **반지·목걸이에 한정된 것이며 헬름·팔찌·벨트는 여전히 소켓 추가 소모품이 있다**는 것을 새로 확인했다(§3).

## 1. 슬롯 체계 — 16부위 [위키]

| 구분 | 슬롯 |
|---|---|
| 방어구 | 머리·어깨·가슴·손목·장갑·허리·다리·발 (8) |
| 장신구 | 목·등(망토)·반지×2·장신구(트린켓)×2 (6) |
| 무기 | 주무기·보조무기(양손 무기 시 잠김) (2) |

- 원거리 무기(활·총·마법도구) 슬롯은 **패치 5.0.4(2012)에서 폐지**돼 주무기 슬롯으로 통합됐다 [위키] — "슬롯을 줄이는" 개편이 실제로 일어난 전례
- 셔츠·문장(tabard)은 코스메틱 전용이라 전투 슬롯 수엔 안 들어간다
- **본작 9착용위치(8부위, 반지 2)와 비교** — WoW 16부위는 본작의 거의 두 배. 다만 본작은 이미 계승 원본 5부위에서 확장한 것이라(item_design.md §1) "얼마나 넓게 갈 것인가"는 정답이 없고 두 게임 모두 자기 파밍 밀도에 맞춰 슬롯 수를 조정했다는 사실 자체가 시사점이다

## 2. 아이템 등급 · ilvl 스케일링

### 2-1. 등급 6단계 [위키][가이드]

회색(불량) → 흰색(일반) → 초록(고급) → **파랑(레어)** → **보라(에픽)** → **주황(전설)**

- 등급이 오르면 **같은 ilvl 이라도 붙는 옵션 개수가 늘어난다** — "고급은 접사 1~2개, 레어 이상은 최대 4개" [위키]. 등급이 **접사 슬롯 수를 정한다**는 점에서 Lootun과 같은 처리이고, Dragon Cliff(등급=효과 접근권, 접사 수는 설비가 정함)와는 다른 처리다

### 2-2. ilvl 스탯 스케일링 — 지수 곡선 [부스팅×2 교차확인, WoWUtils 시뮬레이션 계산 사이트 역산]

스탯 예산 함수가 `B(x) = a × 1.15^(x/15)` 형태를 띤다. 즉 **ilvl 15당 스탯이 약 15% 성장**하며, 이 지수 하나가 주스탯·2차스탯·무기 위력 전부의 성장 배율로 공유된다. 이번 심화에서 같은 공식을 다루는 **WoWUtils(wowutils.com/loot/slot-strength)** — "매 아이템 레벨마다 대략 1%씩 예산이 늘고, 이것이 지수적으로 복리 성장한다(100레벨 높은 아이템은 시작 아이템의 약 2.70배 예산 = 약 170% 증가)"는 독립 서술로 재확인했다.

- **본작 `power_growth_per_level` 지수 성장 방식과 형태가 동일하다.** 본작이 "굴림 × 계수^(ilvl−1)"로 설계한 것(item_design.md §2-1)과 WoW의 `1.15^(ilvl/15)`는 같은 계열의 해법 — **지수 성장이 MMO 아이템 스케일링의 업계 표준형**이라는 근거가 하나 늘었다
- 차이는 **WoW엔 접사 "굴림"이 사실상 없다** — 같은 ilvl·같은 등급의 아이템은 옵션 종류만 랜덤이고, 본작처럼 "같은 슬롯도 개체마다 세기가 다르게 뜬다"는 축이 약하다. **본작의 개체 굴림(무기 편차·방어구 고유값)은 WoW엔 없는 축**이라 그대로 참고할 대상이 아니라 **차별점으로 기록**해 둔다

## 3. 소켓 · 인챈트 · 젬

### 3-1. 젬(소켓) — 색상 4종 + 유니크 장착 다이아몬드 [가이드, Method.gg 원문 WebFetch]

| 젬 계열 | 색상/이름 | 효과 |
|---|---|---|
| 2차스탯 젬 4종(일반/Flawless 2등급) | 가넷(Garnet, 빨강) | 치명타(Critical Strike) |
| | 자수정(Amethyst, 보라) | 특화(Mastery) |
| | 라피스(Lapis, 파랑) | 유연성(Versatility) |
| | 페리도트(Peridot, 초록) | 가속(Haste) |
| 주스탯 젬 | **에버송 다이아몬드(Eversong Diamond)** | 힘/민첩/지능 겸용, **캐릭터당 1개만 장착 가능**(유니크 이큅) |
| PvP 전용 | 헬리오트로프(Heliotrope) | 전투 효과 부여 |

- 구세대(War Within 이전)의 "색상별 소켓 규칙"(젬 색상이 소켓 색과 일치해야 보너스)이 없어졌다는 것이 기존 조사의 결론이었는데, 이번 심화로도 **"소켓이 색상을 가리지 않고 어떤 젬이든 낀다"**는 최근 세대의 처리가 유지되고 있음을 재확인했다(간접 확인 — 젬 자체가 "무슨 색 소켓에" 라는 제약 서술이 이번 검색에서도 발견되지 않음, N/F로 완전 확정은 아님)

### 3-2. 소켓이 붙는 슬롯 — 반지·목걸이는 고정 1개, **헬름·팔찌·벨트는 소모품으로 추가 가능** [가이드][위키][부스팅]

| 슬롯 | 소켓 규칙 |
|---|---|
| 반지·목걸이 | **1개 고정 보장**, 추가 소켓을 부여하는 소모품은 **War Within 시절엔 있었으나 Midnight에서 폐지**([위키] 12.1 시점까지 유지) |
| 헬름·팔찌·벨트 | **소켓 추가 소모품이 여전히 존재**(이번 심화 신규 확인) — PvE는 **라디언트 주얼바인더(Radiant Jewelbinder)**, PvP는 **갤럭틱 주얼러스 세팅(Galactic Jeweler's Setting)**을 상점 재화로 구매해 사용[가이드, Method.gg 원문] |

> **정정 사항** — 기존 `wow_reference.md`는 "War Within→Midnight에서 소켓 추가 소모품 자체가 사라졌다"고 서술했는데, 이는 **반지·목걸이에 한정된 사실**이었다. 헬름·팔찌·벨트의 소켓 추가 경로는 살아있다는 것을 이번 심화로 확인했다 — "파밍 목표를 슬롯 단위로 켜고 끈다"는 조정이 부위별로 정밀하게 갈린다는 뜻이다. [00_overview.md §4-7](00_overview.md#4-본작-대조-시사점) 참조

### 3-3. 인챈트 — 정확히 6부위로 확정 [가이드, Method.gg 원문 WebFetch, 기존 N/F 해소]

**12.1(Midnight 현행) 인챈트 가능 슬롯 — 투구·어깨·반지·부츠·가슴·무기**

- 이전 확장팩(War Within 이전) 대비 **망토·팔찌 인챈트가 제거**되고 **어깨·투구 인챈트가 복귀**했다[가이드] — "이 슬롯엔 이 종류의 파워만 추가로 얹을 수 있다"는 슬롯별 차등 자체는 유지하되, **어느 슬롯이 인챈트 대상인지는 확장팩마다 바뀐다**는 것을 새로 확인
- **본작 대조**: 본작은 강화가 "접사 증폭"(골드 소모, item_design.md §5-1) 하나뿐이고 슬롯 구분이 없다. WoW는 슬롯마다 인챈트 가능 여부 자체를 스위치처럼 켜고 끄며, 그 스위치가 시즌마다 바뀌는 손잡이로 쓰인다

## 4. 티어세트(Tier Set)

### 4-1. 구조 — 클래스·전문화별 2피스/4피스 세트 효과 [위키][가이드×3 교차확인]

- 헬멧·어깨·가슴·장갑·다리 **5부위**가 전통적으로 세트 부위다(Midnight도 동일 구조 유지)
- **2피스**: 기존 스킬에 소소한 %강화 또는 자원 생성 추가. **4피스**: 2피스 효과를 더 키우거나, 스킬 간 상호작용(쿨감·자원 전환)을 새로 만든다 — 시즌2(12.1) 실제 텍스트 7종은 [01_skills.md §4-2](01_skills.md#4-2-시즌2패치-121-티어세트-24피스-실제-텍스트--7개-클래스-표본)에 정리
- **핵심 확인 — "5피스 중 4피스만 채워도 2/4피스 보너스가 전부 발동한다"**[가이드] — 슬롯 하나(예: 다리)를 세트 밖 유니크·크래프트로 자유롭게 교체해도 세트 보너스 유지에 지장이 없다는 뜻. 완전체(5/5)에는 별도의 "풀세트 전용" 초과 보너스가 없는 것으로 보인다(이전 확장팩의 5피스 전용 보너스 유무는 시즌마다 다름, N/F)
- **레이드 보스 처치 시 "세트 토큰"이 드롭** → 토큰은 **현재 전문화에 맞는 부위로 자동 귀속**[부스팅×2] — "5부위 각각을 따로 굴리는" 게 아니라 **부위 랜덤을 토큰이라는 중간 계층으로 흡수**한다
- **카탈리스트(Catalyst) 시스템**[위키][부스팅×2] — 세트가 아닌 일반 장비(던전·필드드롭·제작)를 **주 1회 충전되는 화폐(시즌 전용)로 세트 부위로 전환**할 수 있다. "하필 그 부위만 안 뜬다"는 좌절을 시스템으로 우회하는 장치

> **세트가 장비 부위에 걸리는 정공법이면서, 동시에 "그 부위가 안 뜨는 문제"를 카탈리스트로 보정하고, 나아가 완전체 요구치 자체를 5/5에서 4/5로 낮춘다.** Dragon Cliff·Lootun 둘 다 "세트를 장비 밖(젬·목걸이)에 둬서 교체 자유도를 안 죽인다"는 정반대 해법을 썼는데, WoW는 **세트를 장비 부위에 그대로 두고 획득 난이도와 완성 문턱 둘 다를 인위적으로 낮춘다** — 세 번째 해법 계열이다.

## 5. 강화(업그레이드) 시스템 — 크레스트 · 트랙

### 5-1. 5개 장비 트랙 × 각 6단계 [부스팅×3 교차확인]

```
Adventurer → Veteran → Champion → Hero → Myth   (트랙 5개, 각 1/6~6/6)
```

**시즌2(패치 12.1, 2026-08-18 개시) 기준 실제 ilvl 구간** — 이번 심화로 정확한 상·하한을 새로 확인:

| 트랙 | 시즌2 ilvl 구간 |
|---|---|
| Adventurer | 263 ~ 276 |
| Veteran | 276 ~ 289 |
| Champion | 289 ~ 302 |
| Hero | 302 ~ 315 |
| **Myth(표준 6/6)** | **334** |
| Myth(시즌 막바지 보스 특별 드롭, Very Rare) | **344** |

- 시즌2는 시즌1 대비 **베이스 아이템 레벨 자체가 46 상승**한 시점에서 출발했다[부스팅] — 시즌 전환마다 트랙 전체가 위로 밀리는 것이 WoW 시즌제의 기본 리듬
- **같은 트랙 안에서 랭크 하나 올리는 비용은 랭크에 관계없이 동일**(시즌2: 랭크당 크레스트 20개, 1/6→6/6 풀강 = 100개) [부스팅×2] — "뒤로 갈수록 비싸지는" 계단형이 아니라 **트랙 하나를 다 밀 때까지 단가가 고정**
- **크레스트 종류가 트랙마다 다르다**(시즌2는 통칭 "미스트크레스트Mistcrest" 계열이 트랙별로 이름이 갈린다) — 하위 트랙 크레스트는 상위 트랙에 못 쓴다(정확히는 상위 크레스트가 하위로는 호환되지만 역은 안 됨인 구조가 일반적) [부스팅]

### 5-2. 콘텐츠 다각화 압력 [부스팅]

- 획득처가 **필드·던전·레이드·PvP 전부**에 걸쳐 있어, 어떤 콘텐츠를 하든 같은 통화(크레스트)로 수렴한다 — **콘텐츠 다각화 압력을 재화 하나로 만든다는 점**은 Dragon Cliff의 "재화를 활동별로 분리해 다변화를 강제한다"와 **반대 방향**의 해법이다

## 6. 전설 장비 · 부가효과(임벨리시먼트) · 3차 스탯

### 6-1. 전설(주황 등급) — 시스템이 아니라 "희소 이벤트"로 후퇴 [위키][부스팅]

- 과거 확장팩(Shadowlands)엔 **룬각인(Runecarving)**이라는 체계적 "전설 제작 시스템"이 있었으나, 이후 확장팩(Dragonflight·War Within·Midnight)에서는 **전설이 긴 퀘스트체인 보상 1~2개**로 축소됐다
- → **"체계화된 전설 시스템을 시도했다가 되돌린 전례"** — 본작이 item_design.md §3에서 "치명 배수의 출처를 유니크·낙인으로 아낀다"고 결정한 것과 같은 방향의 절제다

### 6-2. 임벨리시먼트(Embellishment) — 동시 장착 상한 2개 [가이드×3 교차확인, 이번 심화 재확인]

- **제작 장비 전용**의 특수 부가효과(예: 처치 시 광역 힐 등). "옵션 재료(Optional Reagent)"로 일반 제작 장비에 붙일 수 있다
- **동시 장착 상한 2개**[가이드] — 아무리 좋아도 셋째부터는 효과가 안 붙는다는 **명시적 캡**. 파워 하나(제작 부가효과)가 무한정 쌓이는 걸 막는 장치. 12.1 시점에도 상한 2개가 그대로 유지되고 있음을 확인

### 6-3. 3차 스탯(Tertiary Stat) [위키][커뮤니티]

| 스탯 | 효과 |
|---|---|
| **가뭄내성(Avoidance)** | 광역 피해 최대 20% 추가 감소 |
| **흡수(Leech)** | 자신이 가한 피해·치유의 일부를 자기 회복으로 전환 |
| **속도(Speed)** | 이동속도 증가 |
| **파괴불가(Indestructible)** | 내구도 개념 자체를 없앰(전투 무관 편의 스탯) |

- 3차 스탯은 **접사 풀과 별도 층**에서 굴러 어떤 아이템에는 "덤"으로 붙는다 — 주스탯/2차스탯 외에 **전투에 영향은 있으나 "선택 기준"의 주축은 아닌 스탯을 따로 격리**한 것. 본작 item_design.md의 "유틸 접사(드랍률/골드)를 접사 풀과 분리해 순도를 지킨다"는 결정과 **정확히 같은 문제의식**이다

## 7. 제작 품질 — 12.1 단순화

### 7-1. 재료 품질 2단으로 축소 [부스팅×2 교차확인, 이번 심화 신규]

- **패치 12.1에서 소모품·제작 재료의 "청동(Bronze)" 품질이 폐지**되고, **은(Silver)·금(Gold) 2단계만 남았다**[부스팅] — 이전(War Within 시절)엔 재료 자체가 청동/은/금 3단계로 나뉘어 있었다
- **완제 장비·전문기술 도구 자체는 여전히 5랭크**를 유지한다[부스팅] — "재료 품질"과 "완성품 랭크"가 서로 다른 축이고, 이번 개편은 **재료 쪽 축만 단순화**한 것
- 재료 대부분에 **품질(Quality) 속성**이 있고, 제작 시 자동으로 최고 품질 재료를 선택하는 옵션이 있다[부스팅]

### 7-2. 제작 지식(Knowledge) · 제작 주문서(Crafting Orders) [부스팅]

- **첫 제작(First Craft)** — 특정 아이템을 처음 만들 때 "장인의 패기(Artisan's Moxie)"를 얻어 레시피 구매·전문기술 지식 해금에 쓴다
- **제작 주문서**는 숙련도 15에 해금되며, 12.1엔 **지식·옵션 재료·증폭 룬(Augment Rune)까지 보상으로 준다**[부스팅] — 제작 주문서가 단순 대행 시스템을 넘어 성장 루프의 일부로 편입됐다는 뜻

> **본작 대조** — item_design.md §5-3 "크래프트 가드 — 원정 없이 제작이 성립하는가"가 미확정인 상태에서, WoW가 **"재료 자체의 품질 축"과 "완성품 랭크 축"을 분리**하고, 나아가 재료 품질 가짓수를 3→2로 줄인 것은 "가짓수는 필요할 때만 늘리고, 필요 없어지면 되돌린다"는 원칙의 실제 사례다 — [00_overview.md §4-7](00_overview.md#4-본작-대조-시사점)이 관찰한 "확장팩마다 스스로 뒤집는" 패턴이 스킬(§소켓)뿐 아니라 제작 시스템에도 반복된다.

## 8. 콘텐츠별 등급 분리 — 난이도가 곧 아이템 등급

### 8-1. 던전·레이드 난이도 4단계 [위키][가이드]

```
공격대 찾기(LFR) < 일반(Normal) < 영웅(Heroic) < 신화(Mythic, 20인 고정)
```

- **던전은 별도로 신화+(Mythic+)** — 무한 단계(키 레벨)로 난이도가 오르고, **키 레벨 구간마다 드롭 트랙이 바뀐다**(§5-1 표와 매핑)
- **PvP는 별도 파워 스탯 체계** [위키] — 정복(Conquest) 장비는 같은 ilvl 이라도 PvP 전용 파워를 더 갖고, PvP 구역에선 PvE 장비가 **아이템 레벨 상한/하한으로 강제 보정**된다. "PvE 최강 장비가 PvP도 최강"이 안 되도록 **콘텐츠별 파워를 분리 계산**한다
- **난이도 자체가 등급 분리축이다** — 같은 보스, 같은 드롭 목록이라도 **난이도가 트랙을 결정**하고(§5-1), 트랙이 ilvl 대역을 결정한다. 본작의 "몬스터 등급 + 매직찬스가 희귀도를 정하고 ilvl은 별개로 스테이지가 정한다"(item_design.md §1 드롭 파이프라인)는 구조와 **절단면이 다르다** — WoW는 "콘텐츠 난이도 = ilvl 트랙" 하나로 등급과 레벨을 사실상 같이 미는데, 본작은 이미 **"레벨과 희귀도를 서로에게서 뗀 것이 파이프라인의 핵심"**이라고 명시적으로 결정했다. 즉 본작이 WoW보다 한 단계 더 분리한 설계를 택한 셈이다
