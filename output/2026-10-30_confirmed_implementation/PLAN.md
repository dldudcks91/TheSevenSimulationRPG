# 확정 기획 구현 — 2026-10-30

대상은 TheSevenSimulationRPG다. 확정 기획의 실제 미반영 기능을 구현한다. 6·7장은 제외한다.

## 구현 목록

- R389: 직업 주력·보조와 죄종 보정의 중복 곱 제거. 분노는 운, 나태는 건강.
- R399: 연구소 도서관 줄, 등록, 도안 생산, 연구, 오프라인 정산, 한영 화면.
- R309: 새 목걸이 베이스를 특정 기본 스킬 +n으로 교체. 기존 장비 보존.
- R321: 반지 베이스 태그·효과 굴림과 전투 적용. 미발행 범위는 CSV 임시값으로 명시.
- 부채 93: 강화·물약·책 제작·전직 비용과 분해 산출 표시.
- R301: 난이도 배율 표시. 오래된 미구현 기록을 실제 구현과 대조.

## 검증

구현 전 Edge 회귀 테스트 PASS 732/732. 기능별 단정, 세이브 왕복, 한영 화면, 전체 회귀를 확인한다. 의도대로 바뀐 능력치·장비 굴림만 골든을 갱신한다.

## 규칙이 남은 기획

탐험 개편(R312), 제작 개편(R237), 전직 가지 ②③④, 나머지 마스터리 T3, 유니크 옵션 저작, 부족 재소환 담당 스킬은 규칙이 미정이다. 확정 기능과 구분해서 남은 결정과 근거를 기록한다.
