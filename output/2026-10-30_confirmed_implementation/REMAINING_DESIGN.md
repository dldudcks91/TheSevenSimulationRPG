# 구현 전에 규칙이 더 필요한 기획

확정 미반영 R309·R321·R389·R399는 구현했다. 아래는 기존 문서가 미확정 또는 코드 보류로 구분한 기능이다. 구현 완료로 표시하지 않는다.

| 항목 | 필요한 결정 | 근거 |
|---|---|---|
| 탐험의 전투 판 개편 | 표의 드롭 출처·보상·중도 회수·오프라인 판 종료·관전 배치 | DEV_PLAN R312 · GAME_DESIGN §10 「탐험 상세」 |
| 제작·크래프트 개편 | 도안 효과·바탕 장비 계승 범위·재료별 효과·죄종 수·비용 | DEV_PLAN R237 · item_design §7 |
| 전직 가지 ②③④ | 설명을 실제 효과로 옮기는 기계 규칙·상태이상·전투불능 후 복귀 | DEV_PLAN R150 · skill_design §7·§10 |
| 마스터리 T3 잔여 | 탐욕 외 죄종의 실제 노드·효과·상한 | DEV_PLAN R15 · skill_design §7 |
| 유니크 아이템·영웅 | 개별 고유 효과·값·출현 규칙 | DEV_PLAN R292 · unique_item_draft |
| 부족 재소환 | 재소환을 맡는 스킬과 몬스터 스킬 칸의 관계 | DEV_PLAN R388 · PLAN_monster_race_family Q4 |
| 반지 베이스 후속 | 임시 범위 밸런스·값 없는 강화 효과의 의미·장신구 자동 분해 문턱의 비교 방식 | item_design 「반지 베이스 옵션」·§6-5 |

상단 교역소·특수상단의 실제 거래 목록, 물약 종류 확장, 나머지 수치 조정도 GAME_DESIGN §10의 미확정 목록을 따른다. 6·7장은 현재 기획에서 제외한다.
