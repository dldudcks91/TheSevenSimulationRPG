# 패배 정체 안내 QA

최종 브라우저 검사 **46/46**, 전체 회귀 단정 **721/721** 통과. 브라우저 예외·로컬 HTTP 오류·최종 실행 도중 소스 변경은 모두 0개다.

## 사용자 흐름 확인

- 기존 관리 플레이 60분의 실제 사탄 패배 기록을 바탕으로 연속 미클리어 5회 fixture를 만들었다. 횟수만 인공 반복했으므로 진행 속도의 측정 자료로 사용하지 않는다.
- 첫 의뢰 완료 뒤에도 안내가 나온다. 4회에서는 나오지 않는다. 실제 진행 중 원정 핸들을 둔 상태에서 확인했다.
- 임무 폴더의 안내에 부대·스테이지·5회 미클리어와 장비·마스터리·물약 점검 및 이전 구간 파밍 권고가 표시된다.
- 바로가기가 실제 출정 영웅의 캐릭터 화면과 해당 부대 인벤토리로 이동한다. 선택한 게임 편성 번호는 바꾸지 않으며 원정·자동 재도전·전투 번호·자원·물약·편성·기록·활성 핸들도 바꾸지 않는다.
- 접기·펼치기·Esc·바로가기 후 닫기가 정상이다. 안내가 무효가 된 뒤 남아 있던 옛 버튼을 누르면 이동을 거절한다.
- 기존 리포트의 기여 표·남은 적·선택한 패배 기록과 상세 내부 스크롤을 유지한다.

## 말풍선과 시각 검증

한글 1600×900, 영문 1280×720에서 실제 클릭과 스크린샷을 확인했다. 안내가 이미 있는 판을 처음 불러올 때는 과거 말풍선을 재생하지 않고, 같은 판에서 처음 조건을 충족하면 한 번 표시한다. 횟수가 늘어도 반복하지 않는다. 독립 알림 컴포넌트에 A5→B6→A7을 적용한 누적 말풍선 횟수는 1→2→2이며, 다시 자격이 생기거나 판을 갈아도 과거 안내를 재생하지 않는다.

시각 검토에서 초기 안내 설명의 한 줄 말줄임이 실제 권고 문장을 숨기는 문제를 발견해 메인 담당에게 전달했다. 최종 `.notification-retry` 전용 줄바꿈 수정 뒤 다시 검사했다. 양 언어 모두 `white-space: normal`, `scrollWidth <= clientWidth`, `scrollHeight <= clientHeight`이고 설명 영역은 카드 안에 들어간다. 안내 버튼도 고정 알림 패널 안에 온전히 표시된다. 최종 화면: `ko_1600_advice.png`, `en_1280_advice.png`.
