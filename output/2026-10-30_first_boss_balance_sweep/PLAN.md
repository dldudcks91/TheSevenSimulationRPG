# 첫 보스 시간 단축 조합 전수 검증

목표: 적극 관리 기준 첫 보스 격파 중앙30~40분,40분 안80~90%, 느린 조건도45분 근처.20분 이전 과도한 완주가 많아지는 후보도 따로 표시한다. 모든 가능한 실수·설계 변경은 무한하므로 아래 유한한 탐색 공간을 먼저 전수 검사하고, 좋은 영역을 더 촘촘하게 검사한다. ‘전수’는 명시한 공간에 한정한다.

제품 코드·CSV·골든은 건드리지 않는다. 현재 소스를 고정하고 후보별 주입 데이터와 메모리상의 소스 오버레이로만 실행한다. 변경 축별 단독 효과와 상호작용, 비용과 후반 영향 범위를 함께 기록한다. 영웅이나 자원·승리를 주입하지 않는다.

## 1차 전수 공간 —8축576조합

| 축 | 값 |
|---|---|
| 노말1장 일반·정예·장소보스 HP 배수 | 1.0 / 0.9 / 0.8 |
| 같은 적 데미지 배수 | 1.0 / 0.9 |
| 노말1장 처치 XP 배수 | 1.0 / 1.25 / 1.5 |
| 1장 일반 칸 라운드 수 | 9 / 7 |
| 첫 책 학습·지급 레벨 | 10 / 9 |
| 노말1장 챕터보스 HP 배수 | 1.0 / 0.8 |
| 같은 챕터보스 데미지 배수 | 1.0 / 0.85 |
| 시작 무기 고정 데미지 옵션 | +100% / +125% |

전체3×2×3×2×2×2×2×2=576조합. 같은 최초 굴림 시드1~20, ×1/FocusOff의 제품 박자, 정기2분 관리+관측한 실패·상자 대응, 실제 받은 책 우선 학습 정책으로 검사한다. 첫 보스 승리 또는60분에 종료한다. 후보별 파티와 게임 시드는 짝을 유지한다.

HP·데미지·XP·라운드 변경은 노말1장에만 적용한다. 시작 무기 옵션과 책 레벨은 전역 설계 축이므로 범위가 넓다는 비용을 표시한다. 기존9라운드를7라운드로 바꿀 때 마지막 정예/보스와 중간 정예를 유지한다. 몬스터 종류·장비·드롭 RNG를 직접 조작하지 않으며 라운드가 줄면 XP와 드롭도 실제로 줄어든다.

## 후속 검사

1. 현재 제품과 기존 Edge 검증의 시드별 결과, 관측 유무를 대조해 빠른 실행기의 동등성을 먼저 확인한다.
2.576조합을 모두 끝내고 누락·오류·제외를 집계한다. 목표율·분위수·너무 빠른 완주·변경 축 수를 함께 비교한다.
3. 유망 영역의 수치를 더 촘촘히 바꿔 재검사한다. 선택에 사용한 시드와 별도의 검증 시드를 구분한다.
4. 변경이 적은 후보·목표 충족 후보·설계 축을 유지한 후보를 더 많은 새 시드와5분 관리 정책에서 확인한다. 느린 조합·첫 보스 전 지연·보스 재도전 지연을 나누어 기록한다.
5. 최종 후보는 실제 브라우저 원본 엔진과 재대조하고, 재화·장비·책·시간·재현성·2장 이후 범위 검사를 한다. 적용 가능한 변경 명세와 결과를 저장하되 제품 적용은 별도 판단으로 남긴다.

보고 시 시간은 가상 접속 경과이며 사람의 읽기·클릭 시간은 제외한다. 미완료 조건을 버려서 중앙값을 낮추지 않는다. 자동 정책의 한계와 표본 선택 편향을 명시한다.

추가 사전 정의: 제품 수치를 유지한 관리 방식도4축81조합을 전수 검사한다. 정기 관리60/120/300초×파밍 전환2/3/6패×파밍1/3/5승×초기 배분 균형/공격/생존이다. 정상 무료 초기화·실패 관측·파밍만 사용한다. 수치 조정이 필요한지와 정책의 영향도 분리한다.

촘촘한 수치 검사는 기존 책Lv10·시작 무기+100%·9라운드·챕터보스 수치를 유지한 채 일반 구간HP6값×데미지3값×XP5값=90조합을 전수 검사한다(`refinement/design.json`). 최종 검증은 선택에 쓰지 않은 자연 시작 시드와, 가능한9개 직업 구성·등급 배치까지54개 순서 각각4시드(총216)를 별도로 사용한다.

시작 조건의 편차 대안도54조합으로 검사한다. 기존 등급 배치/마법사 우선 딜러에게 높은 등급/궁수 우선 딜러에게 높은 등급×일반 등급 유지/매직 하한×1장HP3값×XP3값이다. 영웅 생성 함수가 등급에 맞춰 정상 능력치를 굴리며 생성 후 스탯을 고치지 않는다. 초기 등급 구성·배치의 설계 변경이라는 비용을 분명히 표시한다. 이 후보군은 현재 시작 규칙 그대로의 후보와 별도로 비교한다.

공격력 증가와 구별할 방어 대안도36조합으로 검사한다. 기존 직업HP 바탕값에 전열0/15/30·후열0/15/30을 더하고,XP1/1.25·일반 구간HP1/0.9를 결합한다. 실제 `class.csv:hp_base`에 해당하는 입력 변경이며 자원·레벨을 주입하지 않는다. 몬스터는 별도HP 입력을 쓰지만 영웅은 모든 레벨에서 바탕값이 바뀌므로 최종 후보의 범위·만렙 영향도 따로 확인한다.

후보 선별에는 시드1~20만,독립 중간 검증에는21~100을 쓴다. 그 결과로 추천 후보를 먼저 고정한 뒤 자연 시작201~400의200시드×정기2분/5분 정책을 검사한다. 최종 테스트를 보고 추천 입력을 몰래 바꾸지 않는다. 추가 조정이 필요하면 그 사실을 밝히고 새 테스트 시드 범위를 사용한다.54개 직업·등급 순서의216개 균형 표본은 별도 검사이며 자연 시작 분포의 평균으로 부르지 않는다.
