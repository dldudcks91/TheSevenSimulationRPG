# 브라우저 QA 결과

실제 Edge 헤드리스 브라우저에서 기존 회귀 단정 707/707, 일반 신규 게임 흐름 검사 29/29를 통과했다. 확인한 범위에서 JavaScript 예외와 로컬 HTTP 오류는 없었다. 제품 소스는 수정하지 않았다.

## 확인한 흐름

- 빈 브라우저의 메뉴 → 시작 영웅 후보 3명 → 파티 확정 → 프롤로그 5씬 → 게임 진입. 프롤로그 전에 세이브가 생성된다. 전체 로스터 4명에는 시작 NPC가 포함된다.
- 초기 내비게이션 15개: 열린 탭 진입과 잠긴 탭 거절 모두 정상. 연구소 자원 줄은 창고 미건설을 표시하며 연구 시작 버튼을 열지 않는다.
- 첫 출정 창 열기·Esc 닫기·보내기, 전투 중 캐릭터 탭 이동.
- 설정 닉네임의 공백 제거·Enter 확정, 저장 후 새로고침과 불러오기에서 영웅 UID·생성 시각·골드·닉네임 보존.

## 실제 시뮬레이션 세이브 렌더링

| 시점 | 정책 | 영웅 레벨(전투 3명/NPC) | 골드 | 불러오기 보존 |
|---|---|---|---:|---|
| 10분 | 주기적 관리 | 4/4/4/1 | 267 | 정상 |
| 60분 | 주기적 관리 | 11/10/9/1 | 321 | 정상 |
| 24시간 | 주기적 관리 | 34/33/29/1 | 12,180 | 정상 |
| 24시간 | 무관리 접속 | 19/18/16/1 | 119,165 | 정상 |

각 세이브를 일반 불러오기 버튼으로 열고 원정·캐릭터·연구소·리포트를 그렸다. `Date.now`는 각 세이브의 `savedAt + 1ms`로 고정했으며, 추가 하루가 정산되는 방식이 아니다. 불러오기가 진행 중 원정을 끊고 대기 상태로 만드는 것은 기존 제품 동작이다.

60분 패배 리포트는 전원 전투불능, 사탄 잔여 HP 34%, 레벨 차 4에 따른 명중 −12%, 영웅별 사망 시각·원인을 보여 준다. 원인 정보가 누락된 오류는 확인되지 않았다. 화면 증거: `managed_3600_defeat.png`.

무관리 24시간 인벤토리 42칸이 모두 찬 화면을 확인했다. 캐릭터 화면에는 숫자로 된 점유량이나 만석 경고가 없으며, 넘친 전리품은 해당 리포트에만 빨간 글씨 `가방이 가득 차 2개 분해`로 표시된다. 손실 위험의 사전 인지가 약한 UX 관찰이며 자동 분해 자체는 구현된 규칙이다. 화면 증거: `passive_86400_character.png`, `passive_86400_overflow.png`.

## 재현 자료와 범위

- 회귀 결과: `regression.json`; 실행기: `run_browser_qa.py`.
- 일반 클릭 결과: `ui_results.json`; 실행기: `run_ui_qa.py`; 스크린샷: `01_menu.png`~`07_reloaded.png`.
- 체크포인트 결과: `snapshot_ui_results.json`, `passive_snapshot_ui_results.json`; 실행기: `render_snapshots.py`와 `render_snapshots.py --passive`.
- 체크포인트 렌더링은 UI·로직 JavaScript, CSV, CSS를 메모리에 동결해 같은 소스로 진행했다. 정확한 원문은 `source_snapshot/`, SHA-256과 원본 수정 시각은 `snapshot_source_manifest.json`에 있다. 동결 시각: 2026-10-30 02:15:57 KST. app.js SHA-256: `e5ed6423030b1bfdff69b28a9acf94c91944c6df7c977ebc4f8f0cbabea722bf`.
- 앞선 회귀·일반 클릭은 당시 작업 트리로 실행했고, 이후 다른 세션이 UI를 수정했다. 따라서 앞선 클릭 검사와 후속 고정 렌더링의 소스 버전을 동일하다고 주장하지 않는다. 게임 진행 수치는 별도 simulation 결과를 따른다.
- 독립 임시 포트, 새 브라우저 컨텍스트를 사용했다. 기존 서버·프로필·세이브는 건드리지 않았다. 프로덕션 클라우드 함수는 응답에서 스텁 처리했다. 실제 계정 가입·배포 서버·Firebase 수집은 이번 검증 범위 밖이다.
- 외부 웹 폰트 두 곳은 환경 네트워크 제한 때문에 로드되지 않아 시스템 대체 글꼴로 확인했다. 이 요청 실패는 로컬 게임 오류와 분리했다. 초기 `failure.png`는 HTTP 검사 서버의 작은 연결 대기열 때문에 발생했던 하네스 실패 증거이며 제품 오류가 아니다. 최종 실행기는 대기열 128을 사용한다.
