# 연구소 오프라인 정산 오류 수정 결과

연구 완료 전후로 정산을 나누더라도 각 생산 시계가 기존 공백의 상한을 한 번만 적용하도록 수정했다. 기존 시계의 시작부터 허용된 구간 안에서 연구 완료 전후 속도를 적용하고, 실제 복귀 시각까지 시계를 이동해 버린 공백을 다음 정산에서 다시 지급하지 않는다.

- 자원: 기존 합법적 진행 재현 5개 모두 연구군 210개 → 180개, 연구 없는 대조군과 일치.
- 골드: 별도 상태 fixture에서 210 → 180, 훈련 경험치는 71 → 61로 대조군과 일치.
- 연구가 생산 상한 안에 끝나면 그 경계를 기준으로 옛 속도와 새 속도를 계산한다. 상한 뒤에 끝나면 해당 공백은 옛 속도로만 생산하고 연구 완료는 실제 시각에 반영한다.
- 서로 다른 시계의 시작 시각, 저장·불러오기, 같은 시각 재정산, 복귀 후 다음 생산, 온라인 생산, 상한을 받지 않는 수색을 검증했다.
- 공개 API·세이브 스키마·CSV 값은 유지했다. 기존 지급분을 회수하는 소급 처리는 추가하지 않았다.

수정 파일: `src/game_logic/state.js`, `src/dev/test.js`, `docs/client/INTERFACE.md`. 기존 파일들의 병렬 변경은 보존하고, 수정 시작 때 복사한 파일과 비교해 이번 엔진 변경 범위를 검수했다. 회귀 단정 6개를 추가했다.

검증: 전체 브라우저 회귀 **714/714**, 독립 정산 검사 **28/28** 통과. 브라우저 예외와 검증 중 소스 변경은 0건이다. [원시 검증 결과](verification.json), [검증 소스 해시](source_manifest.json), [기존 재현의 수정 후 결과](../2026-10-30_new_player_qa/audit/state_results_after_fix.json).
