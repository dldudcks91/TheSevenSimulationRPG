# 공용 스킬 포인트 정정 — 2026-11-01

사용자 정정에 따라 기존의 전직 전용 포인트 계산을 폐기했다.

- 레벨업마다 기존 공용 스킬 포인트를 받는다. 기존 저장 필드 `masteryPoints`와 지급량 키 `mastery_point_per_level`은 호환성을 위해 유지한다.
- 죄종·직업 마스터리와 전직 메인·꼬리가 같은 포인트 지갑을 사용한다. 전직 완료 자체의 포인트 지급은 없다.
- `advance_skill_level_interval = 5`는 메인 단계 해금 전용이다. 영웅 Lv30·35·40·45·50에 메인 Lv1·2·3·4·5를 찍을 수 있다. 포인트가 충분해도 레벨을 우회하지 못한다. 늦게 배울 때는 이미 열린 단계까지 연속 투자할 수 있다.
- 메인의 학습·강화는 단계마다 1포인트이며 되돌리면 공용 지갑으로 환급된다. 마스터리의 소비·환급도 같은 지갑에 반영된다.
- 꼬리에 메인의 5레벨 간격을 적용하지 않는다. 꼬리 효과와 선행 구조는 아직 논의·미구현 상태다.
- AI 생성·친선전 팀 검증도 마스터리와 전직 투자를 합친 공용 예산을 사용한다. 기존 AI 생성의 마스터리/스킬 선택 RNG 순서는 새 배분 순서로 변경된다.
- 전투 중 같은 메인 스킬의 레벨만 올려도 다음 갈아입기에 반영하도록 슬롯 서명에 `up`을 포함했다. 쿨 잇기 키는 유지한다.
