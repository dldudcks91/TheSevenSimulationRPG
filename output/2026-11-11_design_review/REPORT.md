## 5. 먼저 닫을 순서 — 막고 있는 순서

1. **결투 기준** — 결투 길이 / 첫 시전 규칙 + 성장한 파티 결투 하네스. 전직 값 · 자동 발동 · 기본 스킬 값이 여기 매달려 있다(`sim.html` 에 결투 모드 없음)
2. **골드 · 가루 장부** — 처치 골드 삭제 뒤 재측정 + 분해 반환량. 건설 · 강화 · 제작 · 리롤 비용이 기다린다
3. **속도 축** — 분노 속도 모순 + 공속 · 쿨감 합 상한. 무기 재측정 전에 닫아야 두 번 안 잰다 (무기 · 마스터리 세션과 겹침)
4. **전직 꼬리 방식**(셋 다 / 하나) — 노드 135 · 죄종 T4 가 기다린다 (§10 기존)

⚠ 「데모 범위는 만들며 굳힌다」(09-03)는 그대로 — 다만 데모(2027-02)까지 3개월이고 편성 3 · 로스터 +4 가 나이트메어 클리어에 묶여 있어, 위 넷의 순서를 가르려면 범위 선이 필요해진다.

## 7. 사제 · 회복 — 따로 본 것 (사용자 「일단 패스」)

**사제가 약한 이유 — 3인 파티 한 칸이 데미지를 거의 안 낸다.** 결투 승패를 가른 것은 파티 평타 세기 · 앞줄 수였고, 영웅 몫이 사제만 마이너스(−0.05 ~ −0.12)다(11-03).

| 이유 | 근거 |
|---|---|
| 평타가 없다 | 시작 고유가 힐링 라이트 · 힐이면 데미지 0 |
| 심판 배율이 두 번 깎였다 | 2.2 → 0.88(10-06) → 0.7(10-30 R396) · 같은 쿨 라이트닝 2.5 |
| 깎은 기준이 높은 레벨 | R396 = Lv15 · 25 · 45 결투 · Lv1 은 방어가 낮아 고정 피해 이득 없음 → 초당 1.0 (마법사 3.5 ~ 5.5) |
| 값 하나로 못 맞춘다 | 심판 0.8 은 Lv45 에서 튄다(10-30) — 고정 피해는 상대 방어가 오를수록 세진다 |
