## 절차

1. **스냅숏** — 작업 폴더 `src/` 를 이 폴더 `snap/` 으로 복사(그림 파일 제외 · `output/2026-11-17_res_penalty/harness/snap.py` 참고) · 시각과 `git status` 를 `SNAP_AT.txt` 에. 병렬 세션이 작업 폴더를 계속 고친다 — 측정은 스냅숏만 쓴다
2. **하네스** — `harness/` 에 페이지(`snap/src/dev/obt.html` + `obt.js`) · 구동(`drive.py` · `run_page.py` — 저항 페널티 것을 고쳐 쓴다) · 분석(`analyze.py`). 페이지는 결과를 `<pre id="sim">` JSON 으로, 제목은 `OBT ok` / `OBT FAIL`
3. **도구 검증 먼저** — ①옵션을 안 넣은 판 둘이 같은 씨앗에서 같은 결과(결정론) ②데미지 +20% 판이 +0% 보다 결투장 승률 · 원정 처치 시간이 확실히 나아진다 ③한 줄을 넣은 영웅의 `heroCombat` 에 그 stat 이 실제로 들어갔다(넣은 값 그대로) — 셋 중 하나라도 어긋나면 측정을 멈추고 원인부터
4. **본 측정** — 노말 끝부터. 시간이 모자라면 나이트메어 끝 → 헬 순으로 줄이고 **줄인 것을 적는다**
5. **분석 · 보고** — 이 폴더 `README.md`(한국어 · 표는 칸마다 짧은 한 마디)

## 지킬 것

- **게임 파일 무수정** — `src/` · `docs/` · 루트 파일을 고치지 않는다. 커밋 · 푸시 금지
- **서버** — 포트 8777 은 사용자 것이라 절대 끄지 않는다. 하네스 서버는 빈 포트(8860 ~ 8869 중 · 쓰기 전 `Get-NetTCPConnection` 으로 확인)에 `serve_snap.py` 를 `Start-Process` 로 띄우고, 끌 때는 **그 PID 하나만**. 이름으로 뭉뚱그려 죽이는 명령 금지
- **브라우저** — Edge 헤드리스는 PowerShell 도구에서만 뜬다(Git Bash 에선 안 뜬다). Playwright 는 anaconda python + `channel='msedge'`
- **결정론** — 난수는 `makeRng(seed)` 류로만 · 같은 씨앗 묶음을 옵션 사이에 공유한다
- 오래 걸리면 시드 수를 줄이되 앞 / 뒤 절반이 각 둘 이상 남게 하고, 줄인 것을 README 「한계」에 적는다
