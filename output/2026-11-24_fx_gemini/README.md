# 스킬 이펙트 Gemini 다시 그리기 (2026-11-24)

지금 게임이 쓰는 이펙트 106장(다크 카툰 105 + 모으기 기운 금속박 1)을 Gemini 웹(4 Neon · `/images` 채팅)으로 다시 그린 후보. **설치 안 함** — `src/` 는 그대로다.

| 단계 | 파일 |
|---|---|
| 묶음 12장(3×3) | `fx_map.json` — `s08` 의 마지막 두 칸은 배시 · 파이어볼 한 판 더 |
| 참조 시트 | `build_refs.py` → `refs/<묶음>.png` (설치본을 자홍 바탕 3×3 로 — 칸 = 그림 한 장 전체라 구도가 그대로 간다) |
| 발주 | `gemini_web_fx24_batch.py <묶음…>` · 프롬프트 `prompts/_head.txt`(1차 — 같은 모양 그대로) · `_head_free.txt`(2차 — 생각 · 자리 · 방향만 지키고 자유롭게, `FX_HEAD` 로 고른다) · 기록 `sheets/log.txt` |
| 키잉 · 자르기 | `fx_cut.py sheets/<묶음>_<k>.png` → `cut/<묶음>_<k>/<file>.png`(384 RGBA · 칸 전체) |
| 비교판 | `fx_board.py` → `board/<묶음>.png` · `board/index.html` — 초상 140px(게임 90px 의 1.56배) 위에 `SKILL_ART.size` 비율로 |

열 이름: `current` = 설치본 · `gemini 0` = 시험판(s01 만 · 빛 번짐 금지 문구 전) · `gemini 1` = 1차 · `gemini 2` = 2차.

- `/images` 채팅의 4 Neon 은 **첨부 + 긴 지시문(칸마다 한 줄 아홉 줄)이면 「이미지 도구가 없다」 글로 답한다** — 한두 문장으로 줄이면 10~20초에 그린다. 첨부가 모양 · 색을 거의 그대로 나른다
