# PC 모바일 고정 미리보기

설정 → 화면 → 화면 배치 → 모바일을 선택한다.

- 마우스 환경의 PC는 **390×844 세로 규격**으로 중앙에 표시한다.
- 큰 창에서도 확대하지 않는다. 작은 창에서는 배치를 고정한 채 전체가 보이도록 비율을 유지해 축소한다.
- 창의 폭·높이에 관계없이 메뉴·전장·카드·글자·팝업의 논리 크기를 유지한다.
- 게임 인스턴스를 교체하지 않으며 설정은 브라우저에 저장한다.
- 자동 배치와 실제 터치 모바일은 실제 뷰포트를 따른다.

## 검증

| 검사 | 결과 |
|---|---|
| preview | 74/74 |
| fixed | 703/703 |
| minigames | 61/61 |

Edge에서 PC 창 1600×1000, 2560×1440, 1280×720, 800×600, 350×950, 568×320, 300×400을 검사했다. 크기·비율·배치 동일성, 마우스 메뉴/패널/설정 조작, 안내 카드 경계, PC 복귀, 새로고침 후 유지, 게임 진행 연속성을 확인했다. 터치 모바일 에뮬레이션의 세로·가로 및 핀치 확대도 확인했다. 물리 휴대폰/Safari 검증은 포함하지 않는다. 미리보기의 안내 카드 검사는 실제 안내 모듈에 별도 검사 문구를 전달해 수행했다.

[1600×1000 전장](preview-1600x1000-battle.png) · [1280×720 전장](preview-1280x720-battle.png) · [좁은 PC 창](preview-350x950-battle.png) · [설정](preview-1600x1000-settings.png)

CSS의 화면 크기 조건은 미리보기의 논리 규격을 따르도록 통일했고, `:where()`로 기존 선택자 우선순위를 유지했다. 배포용 JS·CSS 주석 제거 후 토큰 보존 검사와 변경 파일 공백 검사를 통과했다. 배포·커밋은 하지 않았다.
