게임을 실제로 실행해 찍은 화면이다. 개발 환경의 Admin은 기존 개발 도구다. 새 그림을 만들거나 기존 게임 아트를 바꾸지 않았다.

## 자동 검사

Windows의 Microsoft Edge + Python Playwright, 독립 브라우저 저장소에서 검사했다. 실제 사용자의 세이브와 8777 서버는 건드리지 않았다.

| 검사 | 결과 | 근거 |
|---|---|---|
| 모바일 화면·조작 통합 | 546/546 통과 | [전체 결과](all-results.json)의 게임 로직 검사 항목을 제외한 결과 |
| 소형·가로 배치 보완 | 49/49 통과 | [배치 결과](layout-results.json) |
| 데스크톱 최대화·모바일 왕복 | 9/9 통과 | [데스크톱 결과](desktop-results.json) · [일반](desktop-normal.png) · [최대화](desktop-maximized.png) |
| 실시간 전투·이동·회전·재접속 | 11분 · 43주기 · 재접속 2회 통과 | [실시간 결과](soak-results.json) · 브라우저 예외 0 |
| 게임 로직 회귀 | 869/870 통과 | [최신 회귀 결과](core-results.json) |

통합 검사는 320×568, 390×844, 844×390, 768×1024, 1024×768, 1366×600에서 한국어·영어와 D2 Min·Now 스킨을 조합했다. 모든 메뉴 이동, 전장·가방 전환, 로그·누적 피해, 팝업, 스킬 습득, 장비 설명·세부·범위·잠금·착용, 진형 터치 드래그, 잠긴 메뉴, 도감·제작 하위 탭, 새 게임·프롤로그·저장·이어하기를 검사했다. 추가 배치 검사는 568×320도 포함하며 물약과 카드의 겹침, 설명창 조작, 설정의 전체 하위 탭을 확인했다.

게임 회귀의 남은 1건은 변경된 CSV·밸런스와 `golden.json` 기준 스냅샷의 불일치다. 모바일 구현에서는 게임 로직·CSV·골든을 수정하지 않았다. 전체 결과 파일에는 앞선 회귀 868/870도 남아 있으며, 뒤에 실행한 `core-results.json`이 최신 회귀 결과다.

실시간 검사는 재접속 시 원정이 종료되는 기존 규칙을 따른다. 대기 부대를 눌러 열리는 출정 창에서 실제 [보내기]로 다시 출정하고, 원정 시간과 골드 증가·영웅 ID 보존을 확인했다. 게임 상태를 직접 써서 전투를 이어 붙이지 않았다.

초기 검사 중 병행 작업의 게임 규칙 오류 때문에 새 실행이 막힌 구간이 있었다. 그때의 HEAD 규칙 분리 검사는 진단용이며, 이 폴더의 결과는 모두 최신 작업 폴더에서 수행한 검사다.

## 재현

```powershell
python serve.py 8854
python scripts/verify_mobile_ui.py --port 8854
python scripts/soak_mobile_ui.py --port 8854 --minutes 11
```

첫 명령은 별도 터미널에서 실행한다. 이미 사용하는 포트가 있다면 다른 포트를 지정한다. 모든 검사는 실제 버튼을 누르며, 주입된 상태 접근자는 읽기 전용이다.

브라우저 에뮬레이션 검증이며 실물 iPhone·Android의 Safari·Chrome 검증은 아직 하지 않았다. 검사 환경에서 외부 웹폰트 요청이 차단되어 대체 글꼴로 검사했다. 온라인 상대 조회·업로드와 배포는 수행하지 않았다.
