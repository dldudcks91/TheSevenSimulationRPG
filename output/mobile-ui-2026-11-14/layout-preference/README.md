# 화면 배치 선택 검증

설정 → 화면 → 화면 배치에서 자동·PC·모바일을 선택한다. 수동 선택은 창 크기보다 우선하고 이 브라우저에 저장된다. 세로 휴대폰에서 PC를 골라도 회전 안내막은 표시하지 않는다.

Edge 터치 에뮬레이션에서 43/43 통과, 브라우저 예외 0건. 390×844 한국어와 1600×900 영어에서 세 배치 왕복, 설정창 유지, 영웅 보존, 새로고침 후 선택 유지, 자동 모드의 창 크기 추적을 확인했다. 잘못된 저장값은 자동으로 돌아가며, 저장소 접근이 차단되어도 현재 실행에서는 배치를 바꿀 수 있다.
