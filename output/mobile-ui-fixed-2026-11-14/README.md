검사는 Windows Edge의 모바일 에뮬레이션으로 수행했다. 물리 휴대폰과 iOS Safari 검증은 포함하지 않는다. 단기 검사는 외부 웹폰트를 차단하고 로컬 대체 글꼴을 사용한다. 각 결과에는 검사 시각과 소스 해시가 있다. 연속 실행 중에는 이 작업과 공유 작업공간의 변경이 있었으며 재접속 때 소스 해시를 기록했다. 변경한 화면은 이후 관련 검사로 다시 확인했다. 이 결과는 UI 검증이며 게임 규칙 전체 회귀검사 결과를 뜻하지 않는다.

배포 준비 목록에 모바일 모듈 네 파일이 포함되고, 배포용 주석 제거 뒤 JS·CSS 토큰이 보존되는 것을 확인했다. 배포·커밋·사용자 브라우저 세이브 변경은 수행하지 않았다.
