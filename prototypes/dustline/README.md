# DUSTLINE · 더스트라인

정류장에서 물건을 싣고, 카우보이를 태우고, 만든 객차로 서부를 달리는 2D 열차 운영 프로토타입.

**실행:** [start.bat](start.bat)을 더블클릭하거나 [index.html](index.html)을 Edge·Chrome·Firefox에서 연다. 설치·빌드·인터넷 연결이 필요 없다. 첫 실행에서는 에이다와 서부 횡단을 고르고 출발하면 된다.

## 첫 여정

1. **화물·계약**에서 보리평원 곡물 납품을 수락하고, 곡물 3개를 추가 매입한다. 처음 가진 2개와 합쳐 5개가 된다. 식당의 식사에 쓰일 여유분이다.
2. 원하면 **객차 편성**에서 보관 중인 보안관칸을 연결하고, **정류장**에서 카우보이를 고용한다.
3. **결단**에서 공동 식탁을 준비하면 이동하면서 사기가 더 잘 회복된다.
4. 왼쪽에서 보리평원행을 골라 출발한다. 주행 중 사건의 비용과 결과를 읽고 선택한다.
5. 보리평원에 도착하면 **화물·계약 → 납품·완료**를 누른다. 도착 보급과 랜드마크를 방문한다.
6. 소나무 분기점 → 큰강나루 → 새벽항으로 달려도 되고, 협곡과 은광을 거쳐도 된다. 새벽항에서 납품을 끝내고 **여정 완주·정산**을 누른다.

처음에는 1×로 선택과 생산을 읽어 보고, 익숙해지면 2×·5×·10×를 사용할 수 있다. 게임 속 주행 시간만 기준으로 보면 하루는 32초다. 거래·사건·설명을 비교하는 동안은 멈춘다.

## 들어 있는 시스템

| 영역 | 실제 구현 |
|---|---|
| 여행 | 정류장 7곳, 노선 12개, 갈림길, 예약 운행, 반복 방문 |
| 화물 | 곡물·의약품·부품, 정류장별 가격·재고, 거래에 따른 시세 변화, 적재 한도 |
| 계약 | 화물 납품, 수상한 여행자 동행, 도적 현상금, 목적지·기한·보상·실패 |
| 열차 | 객차 9종, 배치·보관·순서 변경, 3층 강화, 합성, 재활용 |
| 생산 | 승객 순환 탑승, 현금·사기·부품, 누적 훈련·준비 시간, 초과 성과·반복 생산 |
| 조합 | 태그 6종, 각 2·3칸 단계의 시너지 |

| 결단 | 12개, 4개 분야, 선행 조건, 상호 배타적 개조, 준비·완료·취소 |
| 인물 | 기관사 3명, 카우보이 호위자 3명, 여행자 로언, 각 역할의 비용과 보상 |
| 사건 | 도적·철로 고장·부상자·승객 반발, 조건·확률·지속 후유증 |
| 장소 | 7개 고유 랜드마크, 물자·사람·기록 선택, 5종 지역 풍경 |
| 위험 | 석탄 소비, 감속, 사기·내구도, 변질, 혼잡, 긴장, 경제·신뢰·치안 |
| 반복 성장 | 보라색 동전, 기관사·유물 해금, 페이지 특전, 유물 후보 제외·복구 |
| 유산 | 클라라 완주로 개방, 장점 3개·단점 1개, 재설정·효과 고정·사용 설정 |
| 기록 | 실제 경로, 보상 내역, 객차별 기여, 숨은 동행 결말, 최근 20회 기록, 도감 |
| 편의 | 일시정지·배속, 도착/결단 정지 설정, 단축키 변경, 소리·음량, 움직임 줄이기 |
| 저장 | 자동 저장, 이어 하기, JSON 내보내기·가져오기, 잘못된 파일 거부, 선택형 오프라인 운행 |
| 게임 모드 | 서부 횡단·순환 철도·철도 상단, 혹독함 4단계 |

이전 연구에서 보류 대상으로 분류했던 유물·복수 기관사·영구 성장·유산도 이번 요청에 맞춰 작동하는 규모로 포함했다. 원작 분석에서 확인하지 못한 공식이나 콘텐츠는 [이 프로토타입의 명시적 규칙](docs/RULES.md)으로 정했다. 원작의 수백 개 콘텐츠를 복제했다는 의미는 아니다.

## 조작과 저장

| 키 | 기본 기능 |
|---|---|
| Space | 주행 중 일시정지·재개 |
| M | 노선 보기 |
| C | 객차 편성 |
| T | 화물·계약 |
| D | 결단 |

키는 설정에서 변경할 수 있다. 객차 순서는 드래그 또는 좌우 버튼으로 바꾼다. 시너지의 접힌 설명을 열면 조건과 효과를 계속 비교할 수 있다. 유물을 누르면 현재 효과와 사용 시간을 읽을 수 있다.

브라우저에 현재 여정 하나와 영구 기록을 저장한다. 같은 파일·주소·브라우저에서 다시 열면 **이어서 운행**이 나타난다. 브라우저가 파일 주소의 저장을 제한하면 아래 로컬 서버 방식으로 실행하거나 설정에서 파일을 내보내면 된다. 파일 실행과 서버 실행은 저장 공간이 서로 다르므로, 이동할 때 저장 파일을 가져온다.

오프라인 운행은 기본적으로 꺼져 있다. 켜면 종료 직전 주행 중이었던 열차를 최대 15분까지 계산한다. 사건·완주 지점·예약 없는 정류장에서는 선택을 기다리며 멈춘다. 종료 당시 배속은 오프라인 시간을 증폭하지 않는다. 창을 다시 열면 일시정지 상태로 돌아온다.

## 그림과 소리

차량·인물·아이콘은 SVG, 배경과 주행 장면은 Canvas로 직접 그렸다. 선명한 외곽선, 제한된 색, 작은 풀바디 인물, 다층 객차를 사용한다. 외부 이미지·폰트·음원·원작 에셋을 다운로드하지 않는다. 해상도와 객차 층수에 맞춰 그림이 바뀐다.

기적·증기 리듬·선택음은 브라우저에서 합성한다. 소리는 기본 꺼짐이며 상단 스피커나 설정으로 켤 수 있다. 음악은 포함하지 않는다.

## 선택 실행: 로컬 서버

Python 3이 있을 때 이 폴더에서:

```powershell
python serve.py
```

`http://127.0.0.1:8844/`를 열며, Ctrl+C로 종료한다. 다른 포트는 `python serve.py --port 8850`, 브라우저 자동 열기를 끄려면 `--no-browser`를 사용한다. 서버는 이 프로토타입 폴더만 제공한다.

이 폴더는 TheSevenSimulationRPG 및 별도 northward-idle의 구현과 독립적이다. 게임 코드에는 의존성 설치가 필요 없다. 개발 검사에는 Node와 Python Playwright가 쓰인다.

실행 가능성과 시스템 연결을 확인한 프로토타입이다. 상업용 분량의 이야기·음악·장기 운영 밸런스, 여러 사람이 평가한 재미는 아직 검증하지 않았다. 첫 플레이에서는 **다음 역과 적재를 왜 골랐는지**, **다음 판에서 무엇을 바꾸고 싶은지**를 기록하는 것이 유용하다.
