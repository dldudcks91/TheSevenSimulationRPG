# 구현 대응표

작성일: 2026-10-09. 현재 구현: DUSTLINE 0.1.

사용자의 “니가 적은 내용이 모두 구현되도록”은 이전 연구에서 분석한 플레이 시스템과 서부 적용 제안을 실제로 연결하는 범위로 해석했다. 당시 A/B 실험과 보류 목록도 이번에는 함께 포함했다. 연구의 모든 문장이 기능 요구는 아니다. 리뷰·가격·개발 연표·미확인 원작 수치는 분석 자료로 유지하고, 작동하는 규칙은 RULES.md에 별도로 명시했다.

## 서부 적용 제안 09의 대응

| 제안 | 실제 구현과 선택의 결과 |
|---|---|
| 화물 A + 객차 B 비교 | 같은 게임에서 거래·납품과 생산 빌드를 함께 운용. 화물칸·냉장칸·공방칸은 두 축을 연결하고 적재/배치 제한을 공유 |
| 정류장에서 물건 싣기 | 개별 1/3개 매입·매각. 화물 HUD와 차량 위 상자가 바뀜. 공간이 부족하면 행동 거부 |
| 가까운 곡물 / 먼 약품 비교 | 노을역에서 보리평원 곡물 / 붉은협곡 약품 계약이 서로 다른 경로·수량·매입가를 요구 |
| 호위의 기회비용 | 카우보이는 비용 + 보안관칸 배치 공간을 사용. 안전을 택하면 생산·화물 칸 기회를 사용 |
| 보안관 의뢰 | 협곡/은광에서 도적 현상금. 단순 운송과 다르게 방어 승리가 필요 |
| 수상한 승객 | 로언 동행은 화물 공간 1칸, 기한, 도착 완료, 나침반과 완주 결말 |
| 도적 | 위험 3노선에서 예고된 사건. 지불·호위 확률·화물 포기 선택 |
| 한 번의 여정 / 순환 / 장기 운영 | 세 모드 모두 작동. 상단 목표는 4계약+$500이며 달성 뒤에도 수동으로 운영 가능 |
| 반복 방문 시 고정 거래 방지 | 재방문 시장 갱신, 매입·판매 수요 변화, 매각가가 같은 역 매입가보다 낮도록 제한 |
| 실패 후 복구 | 정비·휴식·한정 긴급 지원. 실패 시 생존/계약/탐험 보상은 정산, 영구 기록은 유지 |
| 오프라인 선택 처리 | 선택형으로 포함. 사건에서 자동 선택하지 않고 멈춤. 예약 없는 역·완주도 정지 |

원작 미확인 규칙을 “동일 구현”이라고 표시하지 않는다. 예를 들어 승객 배분은 순환식, 초과 성과와 추가 반복은 독립 판정 후 곱셈, 결단 취소는 진행 중 50% 환급, 지도는 손으로 만든 고정 노선이다. 이 결정은 현재 코드와 RULES.md가 기준이다.

## 콘텐츠 규모와 현재 한계

모든 주요 시스템 영역이 실제 플레이와 저장에 연결돼 있다. 대규모 무작위 지도·수백 개 유물·전면적인 실시간 총격·원작 시나리오·원작 이미지와 음악은 구현 범위가 아니다. 정류장 사건은 4개 유형의 짧은 대표 장면이며, 숨은 결말은 로언의 동행 완수 1종이다. 오프라인은 선택 보류 방식으로 구현해 완전 자동 방치 수익으로 삼지 않았다.

재미와 장기 경제는 자동 테스트만으로 확정할 수 없다. 실제 플레이에서 정류장 선택 이유, 화물과 편성의 기회비용, 반복 거래의 지배 전략, 사기 과잉 회복을 확인해야 한다.
