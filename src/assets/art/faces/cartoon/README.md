## hero_*.png 는 이름이 고른다

`mock.js:heroFace` 가 **영웅 이름의 안정 해시**로 `hero_1..5.png` 중 하나를 준다 — uid 가 아니라 이름인
이유는 시작 화면·선술집의 후보가 아직 uid 가 없어서다(뽑을 때 본 얼굴과 고용 뒤 얼굴이 갈리면 안 된다).
직업과는 무관하다. 여기 든 다섯은 기사 5종이라 마법사·궁수가 기사 얼굴을 쓸 수 있다 — 임시다.

## 규격

- 512×512 RGBA · 투명 배경 · 장당 150~260KB (합계 약 3.1MB)
- 용량은 최적화 전이다. 플랫 카툰이라 256색 양자화가 잘 먹을 것으로 보이나 **화질 확인이 먼저**라 원본 그대로 뒀다
  (참고: `pixel16` 은 8장 합계 250KB)
