## hero_*.png 는 아직 안 보인다

`mock.js:heroFace` 가 전부 `null` 을 돌려주고, 인자가 `uid`(런타임 생성값)라 **직업 단위 파일명과 연결되지 않는다.**
`hero_1..5.png` 는 기사 5종을 넣어 둔 것으로, 영웅 초상을 켜려면 `heroFace` 와 호출부
(`app.js:125` · `battle.js:200`)를 직업 키로 바꿔야 한다 — 화면 변경이라 `/ui` 쪽 일이다.

## 규격

- 512×512 RGBA · 투명 배경 · 장당 150~260KB (합계 약 3.1MB)
- 용량은 최적화 전이다. 플랫 카툰이라 256색 양자화가 잘 먹을 것으로 보이나 **화질 확인이 먼저**라 원본 그대로 뒀다
  (참고: `pixel16` 은 8장 합계 250KB)
