# 스타일 앵커 (faces/example/)

몬스터·영웅 초상 아트의 **스타일 기준 이미지**. 게임에서 로드하지 않는다 — 생성 시 레퍼런스로 첨부하는 용도.

`_source_sheet.png` 는 Gemini 가 한 번에 뽑은 원본 시트(2752×1536, 불투명 스크린샷).
나머지 9장은 거기서 타일별로 잘라 **체커보드 배경을 알파로 되돌리고 512×512 정사각으로 맞춘** 것이다.

## 이 시트가 정의하는 스타일

- 클린 카툰 흉상 · SD 비율(두상이 전체의 약 절반) · 굵고 균일한 어두운 외곽선
- 플랫 베이스 + 부드러운 그림자 1단 + 둥근 면의 작은 광택 하이라이트
- **거의 정면**, 아주 살짝 틀어짐
- **머리 + 어깨 + 가슴 일부 + 한 손** — 무기가 프레임에 들어와 직업을 읽게 한다
- 배경 투명 · 저채도 팔레트(뼈 아이보리 · 회갈 천 · 나무 · 무딘 철)

## 파일 — 전부 512×512 RGBA

원본 시트의 타일 프레이밍을 그대로 두고 정사각 캔버스에 중앙 배치했다.
**타일 안에서의 위치를 보존했으므로 9장의 눈높이·머리 크기를 나란히 놓고 비교할 수 있다.**

| 파일 | 내용 | 규격 |
|---|---|---|
| `skeleton_plain.png` | 장비 없는 순수 두상 | ◎ **두상 비율·팔레트의 기준** |
| `skeleton_soldier.png` | 투구 + 한손검 | ◎ **장비 있는 표준 앵커** |
| `skeleton_archer.png` | 화살통 + 활 | ◎ `monster.csv:1302` 스켈레톤 궁수 |
| `skeleton_mage.png` | 후드 + 지팡이 | ◎ |
| `skeleton_rogue.png` | 후드 + 단검 2 | ◎ |
| `skeleton_king.png` | 왕관 | ◎ 보스급 표현 참고 |
| `skeleton_pirate.png` | 삼각모 · 안대 · 붉은 두건 | ○ 시트에서 유일하게 채도 있는 색(두건) — 강조색 분량 참고 |
| `skeleton_bard.png` | 바이올린 | ○ 톤 이탈 (본작 서사와 무관) |
| `skeleton_chef.png` | 요리사 모자 + 국자 | ✕ 톤 이탈 — 앵커로 쓰지 않는다 |

원본 시트에는 사제(전신)가 한 장 더 있었으나 **혼자 전신이라 크기·눈높이가 안 맞아 삭제**했다.
같은 사고를 막는 장치가 프롬프트의 `LAYOUT — all the same size, all the same framing and eye line`
과 네거티브의 `full body, legs, inconsistent sizes` 다.

## 쓰는 법

1. 새 초상을 뽑을 때 `skeleton_plain` + `skeleton_soldier` 두 장만 첨부하고
   `match this exact style, outline weight, proportions, shading, and framing` 을 덧붙인다
   — `chef` · `bard` 를 붙이면 생성기가 그쪽 소품을 끌고 온다
2. 시트로 여러 장을 한 번에 뽑을 때는 **같은 시트 안에서 눈높이·머리 크기가 흔들리는지** 먼저 본다
3. 한 명만 튀면 그 한 명만 다시 뽑는다

## 누끼 작업 메모

원본이 투명 PNG 가 아니라 UI 스크린샷이라 체커보드가 픽셀로 구워져 있었다.
**중성 회색 판정(채널 편차 ≤ 12 · 밝기 18~145) + 테두리에서 flood fill** 로 배경만 지웠다 —
이 스타일의 외곽선(약 `#0B060C`)이 배경 회색보다 훨씬 어두워서 경계가 깨끗하게 잘리고
활시위 같은 얇은 선도 살아남는다. 픽셀아트나 회화체였으면 같은 방법이 안 통한다.
