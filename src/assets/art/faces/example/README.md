# 스타일 앵커 (faces/example/)

몬스터·영웅 초상 아트의 **스타일 기준 이미지**. 게임이 로드하지 않는다 — 생성 시 레퍼런스로 첨부하는 용도.
게임에서 보려면 이름을 바꿔 넣은 [`../cartoon/`](../cartoon/) 을 `?face=cartoon` 으로 켠다.

`_source_sheet_*.png` 는 Gemini 가 한 번에 뽑은 원본 시트(2752×1536, 불투명 스크린샷).
나머지는 거기서 잘라 **배경을 알파로 되돌리고 512×512 정사각으로 맞춘** 것이다.

## 이 세트가 정의하는 스타일

- 클린 카툰 흉상 · SD 비율(두상이 전체의 약 절반) · 굵고 균일한 어두운 외곽선
- 플랫 베이스 + 부드러운 그림자 1단 + 둥근 면의 작은 광택 하이라이트
- **거의 정면**, 아주 살짝 틀어짐
- **머리 + 어깨 + 가슴 일부 + 한 손** — 무기가 프레임에 들어와 직업을 읽게 한다
- 배경 투명 · 저채도 팔레트

## 몬스터 — 해골 9종 (`_source_sheet_skeleton.png`)

| 파일 | 내용 | 규격 |
|---|---|---|
| `skeleton_plain.png` | 장비 없는 순수 두상 | ◎ **두상 비율·팔레트의 기준** |
| `skeleton_soldier.png` | 투구 + 한손검 | ◎ **장비 있는 표준 앵커** |
| `skeleton_archer.png` | 화살통 + 활 | ◎ `monster.csv:1302` 스켈레톤 궁수 |
| `skeleton_mage.png` | 후드 + 지팡이 | ◎ |
| `skeleton_rogue.png` | 후드 + 단검 2 | ◎ |
| `skeleton_king.png` | 왕관 | ◎ 보스급 표현 참고 |
| `skeleton_pirate.png` | 삼각모 · 안대 · 붉은 두건 | ○ 세트에서 유일하게 채도 있는 색 — 강조색 분량 참고 |
| `skeleton_bard.png` | 바이올린 | ○ 톤 이탈 (본작 서사와 무관) |
| `skeleton_chef.png` | 요리사 모자 + 국자 | ✕ 톤 이탈 — 앵커로 쓰지 않는다 |

원본 시트에는 사제(전신)가 한 장 더 있었으나 **혼자 전신이라 크기·눈높이가 안 맞아 삭제**했다.

## 영웅 — 인간 기사 5종 (`_source_sheet_knight.png`)

| 파일 | 내용 |
|---|---|
| `knight_1_young_blond.png` | 젊은 남성 · 투구 없음 · 금발 · 한손검 · 판금 견갑 |
| `knight_2_veteran_helm.png` | 중년 남성 · 얼굴 열린 투구 · 사슬 목가리개 |
| `knight_3_scarred_woman.png` | 여성 · 묶은 검은 머리 · 눈썹 흉터 · 목가리개 |
| `knight_4_old_greybeard.png` | 노년 남성 · 백발백염 · 낡은 견갑 · 낡은 검 |
| `knight_5_helmed_shield.png` | 젊은 인물 · 투구 착용 · 카이트 실드 |

**이 시트는 같은 5명을 두 줄로 두 번 그렸고, 아래 줄이 `y=1025` 에서 잘려 있다.** 위 줄만 썼다.
그리고 배경이 투명이 아니라 **회색 단색**으로 나왔다 — 프롬프트의 투명 배경 지시가 안 먹은 것이다.

## 쓰는 법

1. 새 초상을 뽑을 때 `skeleton_plain` + `skeleton_soldier` 두 장만 첨부하고
   `match this exact style, outline weight, proportions, shading, and framing` 을 덧붙인다
   — `chef` · `bard` 를 붙이면 생성기가 그쪽 소품을 끌고 온다
2. 인간을 뽑을 때는 `knight_1` 을 함께 붙인다
3. 시트로 여러 장을 뽑으면 **같은 시트 안에서 눈높이·머리 크기가 흔들리는지** 먼저 본다
4. 한 명만 튀면 그 한 명만 다시 뽑는다

## 누끼 작업 메모

원본이 투명 PNG 가 아니라 UI 스크린샷이라 배경이 픽셀로 구워져 있었다.
**중성 회색 판정(채널 편차 ≤ 12 · 밝기 18~150) + 테두리에서 flood fill** 로 배경만 지운다.

⚠ **색 판정만으로는 갑옷이 뚫린다.** 기사 시트의 배경 회색(밝기 65)과 판금 갑옷의 중간톤이
사실상 같은 값이라, 외곽선에 틈이 있으면 flood fill 이 갑옷 안으로 새어 들어간다
(1차 시도에서 노년 기사의 견갑이 통째로 파였다). 그래서 **flood 전에 그림 쪽(barrier)을 7px 팽창시켜
외곽선 틈을 막고, flood 후 같은 크기로 배경을 되돌린다.** 이 순서를 지켜야 갑옷이 남는다.

이 스타일의 굵고 어두운 외곽선(약 `#0B060C`)이 자동 누끼를 가능하게 한다 — 픽셀아트나 회화체면 같은 방법이 안 통한다.
