# 스타일 앵커 (faces/example/)

몬스터·영웅 초상 아트의 **스타일 기준 이미지**. 게임이 로드하지 않는다 — 생성 시 레퍼런스로 첨부하는 용도.
게임에서 보려면 이름을 바꿔 넣은 [`../cartoon/`](../cartoon/) 을 `?face=cartoon` 으로 켠다.

`_source_sheet_*.png` · `source_sheet_*.png` 는 Gemini 가 한 번에 뽑은 원본 시트(해골·기사는 2752×1536, 검투사는 2048×2048 — 전부 불투명 스크린샷).
나머지는 거기서 잘라 **배경을 알파로 되돌리고 512×512 정사각으로 맞춘** 것이다 —
⚠ `gladiator_helm.png` 만 예외다(누끼 없음 · 1013×1013 원본 해상도 · 아래 참조).

## 이 세트가 정의하는 스타일

- 클린 카툰 흉상 · SD 비율(두상이 전체의 약 절반) · 굵고 균일한 어두운 외곽선
- 플랫 베이스 + 부드러운 그림자 1단 + 둥근 면의 작은 광택 하이라이트
- **거의 정면**, 아주 살짝 틀어짐
- **머리 + 어깨 + 가슴 일부 + 한 손** — 무기가 프레임에 들어와 직업을 읽게 한다
- 배경 투명 · 저채도 팔레트

## 영웅 — Gem 바바리안 (`barbarian.png`) [2026-09-04 · 같은 날 3판]

Gem 재발주 산출물(2048² · 불투명 **초록 `#00FF00` 배경**). 초록 배경은 「transparent」 지시가 두 번 안 먹은 뒤의
우회다: 인물이 전 층 채도 ≤ 0.25 라 `g − max(r,b)` 판정 하나로 기계 키잉이 된다(절차는
[`../cartoon/README.md`](../cartoon/README.md)). 게임용 사본은 `cartoon/hero_2.png`(키잉 투명 512²).

구판 변주 3장(`barbarian_1..3.png`)은 **스타일 불합격으로 삭제**(미커밋 — 복구 불가): 밝기 중앙 116 · 밝은 영역
35~38% 로 글레디에이터 기준(81 · 13%)을 크게 벗어났다. 신판(맨몸 문신판)은 97 · 41% — 맨살 면적이 넓어 수치상은 밝지만 화면 판단으로 채택. 발주 방법도 바뀌었다:
**장문 규칙서 대신 매 채팅에 `gladiator_helm.png` 첨부 + 「match the attached portrait's exact style」 단문**
(Gem Knowledge 의 이미지는 생성기에 전달되지 않는 것으로 판명 — 첨부만 믿는다).

## 영웅 — 검투사 1종 (`source_sheet_gradiator.png`) [2026-09-04 · 교체됨]

| 파일 | 내용 | `cartoon/` 사본 |
|---|---|---|
| `gladiator_helm.png` | 닫힌 코린트식 투구 · 상처 난 판금 · 맨 어깨 + 가죽 벨트 | `hero_1.png` |

원본 시트는 **2048×2048 · 2×2 · 검정 격자선**(`x = 1016~1031` / `y = 1016~1031`, 폭 16px)이고
쓴 것은 **오른쪽 위 타일** — `(1035, 0) ~ (2048, 1013)` 로 잘랐다(격자 쪽만 3px 안쪽으로 깎아 정사각 유지).
나머지 3종(머리띠 맨얼굴 · 독수리 투구 · 볏 투구)은 아직 안 땄다.

### ⚠ 이 시트는 누끼를 안 했다 — 배경이 외곽선보다 밝다

`gladiator_helm.png` 도 `cartoon/hero_1.png` 도 **배경이 불투명**이라 초상 칸에 네모 박스로 보인다(사용자 지시로 보류).

이 시트는 앞의 둘과 조건이 반대다: 배경이 회색이 아니라 **어두운 텍스처(밝기 17~30)** 이고,
그게 **외곽선(밝기 8~11)보다 밝다.** 기사·해골 시트의 「중성 회색 판정(채널 편차 ≤ 12 · 밝기 18~150)」을
그대로 걸면 **외곽선이 배경보다 어두워서 판정 밖으로 빠지고** 씨앗이 그림 안으로 샌다.
누끼를 하려면 판정식을 새로 잡아야 한다 — 아래 「누끼 작업 메모」의 절차는 이 시트에 그대로 안 통한다.

## 쓰는 법

1. 새 초상을 뽑을 때 `skeleton_plain` + `skeleton_soldier` 두 장만 첨부하고
   `match this exact style, outline weight, proportions, shading, and framing` 을 덧붙인다
   — `chef` · `bard` 를 붙이면 생성기가 그쪽 소품을 끌고 온다
2. 인간을 뽑을 때는 `knight_1` 을 함께 붙인다 (갑옷 인물이면 `gladiator_helm` 도 같이 — 닫힌 투구의 눈높이 기준이다)
3. 시트로 여러 장을 뽑으면 **같은 시트 안에서 눈높이·머리 크기가 흔들리는지** 먼저 본다
4. 한 명만 튀면 그 한 명만 다시 뽑는다

## 누끼 작업 메모

원본이 투명 PNG 가 아니라 UI 스크린샷이라 배경이 픽셀로 구워져 있었다.
**중성 회색 판정(채널 편차 ≤ 12 · 밝기 18~150) + 테두리에서 flood fill** 로 배경만 지운다.

⚠ **색 판정만으로는 갑옷이 뚫린다.** 기사 시트의 배경 회색(밝기 65)과 판금 갑옷의 중간톤이
사실상 같은 값이라, 외곽선에 틈이 있으면 flood fill 이 갑옷 안으로 새어 들어간다
(1차 시도에서 노년 기사의 견갑이 통째로 파였다). 그래서 **flood 전에 그림 쪽(barrier)을 7px 팽창시켜
외곽선 틈을 막고, flood 후 같은 크기로 배경을 되돌린다.** 이 순서를 지켜야 갑옷이 남는다.

이 스타일의 굵고 어두운 외곽선(약 `#0B060C`)이 자동 누끼를 가능하게 한다 — 픽셀아트나 회화체면 같은 방법이 안 통한다.
