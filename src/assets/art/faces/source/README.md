# 스타일 앵커 (faces/source/)

몬스터·영웅 초상 아트의 **PNG 원본과 스타일 기준 이미지**. 게임이 이 폴더를 로드하지 않는다.
게임에서 보려면 축소한 [`../cartoon/`](../cartoon/)(`monster/<idx>.webp` · `hero/<직업id>_<k>.webp`) 을 `?face=cartoon` 으로 켠다.
**이 폴더의 자리** [2026-09-14 구 `example/`] — 게임이 읽는 그림 = 묶음 폴더/id · 원본 시트·앵커 = `source/`(여기) · id 없는 여분 = `unused/`. `icons/` 도 같은 모양이다([`../../README.md`](../../README.md)).

`_source_sheet_*.png` · `source_sheet_*.png` 는 여러 초상을 한 번에 뽑은 원본 시트다(해골은 2752×1536, 검투사·로마군·기사·고블린은 2048×2048). `source_sheet_ch1_st4_flame_zealot_refinement_v2.png` 는 투명 배경의 예외다.
나머지는 거기서 잘라 **배경을 알파로 되돌리고 512×512 정사각으로 맞춘** 것이다 —
⚠ `gladiator_helm.png` 만 예외다(누끼 없음 · 1013×1013 원본 해상도 · 아래 참조).

## 게임 초상 내보내기 [2026-09-24]

`ready/monster/` 42장과 `ready/hero/` 19장은 게임 초상의 작업 원본이다. 더 큰 원본 시트가 남아 있는 그림은 시트도 따로 보관한다. 게임 폴더에는 PNG를 두지 않고, 몬스터 256×256 · 영웅 320×320의 투명 WebP(품질 90)를 둔다.

새 초상이 확정되면 해당 id의 PNG를 `ready/monster/` 또는 `ready/hero/`에 저장하고, 저장소 루트에서 아래 명령으로 내보낸다. 미확정 시안은 `_scratch/`에 둔다.

```powershell
python -m pip install Pillow
python scripts/export_face_portraits.py
```

첫 이관에는 `--migrate`를 사용했다. 이 옵션은 구 게임 PNG를 `ready/`에 복사해 일치 여부를 검사하고 WebP를 만든 다음, 게임 폴더의 PNG를 제거한다.

## 영웅을 얼굴로 앉힌다 [2026-09-16]

영웅은 화면에서 **네모 칸 `object-fit: contain`** 이라 칸을 채우는 것이 어깨가 아니라 **얼굴**이다.
어깨 74% 규칙(postprocess §3)은 `hd/sh` 가 앵커 대역(70~73)에 든 그림에서만 얼굴 크기를 맞춰 준다 —
어깨가 넓은 그림은 74% 에 앉히면 얼굴이 그만큼 작아져 같은 줄의 다른 영웅보다 **혼자 뒤로 물러나 보인다.**

**기준은 눈이다.** 설치본 중 눈이 잡히는 일곱 장(`knight_4`·`knight_5`·`priest_1`·`priest_2`·`priest_3`·`warrior_2`·`warrior_3`)의
중앙값으로 잡았다 — **눈 사이 89px · 눈높이 y 235 · 눈 중점 x 315**(512² 기준).
눈은 **검은 덩어리**라 침식(3px)으로 선화를 지우면 두 덩이만 남아 자동으로 잡힌다(머리카락·후드에 붙어 버리는 것을 침식이 끊는다).
어깨는 그 결과로 정해지고 **아래가 프레임 밖으로 잘리는 것이 정상**이다 — 흉상은 어깨가 바닥에 닿는 것이 문법이라 잘려도 빈칸이 안 생긴다.

⚠ **`74%` 를 버릴 때만 쓴다.** `hd/sh` 가 대역 안이면 74% 가 이미 같은 답을 낸다.
지금 이 기준으로 앉은 것은 `mage_poseidon` · `mage_nostradamus` · `warrior_leonidas` · `warrior_samson` 넷이고, `mage_orb_eyepatch`(0.84) ·
`priest_wimple_cross`(0.68) 은 09-07 사용자 지시로 정한 target 을 그대로 유지한다.
⚠ 격자에서 **3px 여유**를 두고 자른다 — 안 두면 격자 모서리의 안티에일리어싱이 키잉 뒤 티끌로 남는다(`mage_poseidon` 에서 4px 실측).

## 누끼 작업 메모

원본이 투명 PNG 가 아니라 UI 스크린샷이라 배경이 픽셀로 구워져 있었다.
**중성 회색 판정(채널 편차 ≤ 12 · 밝기 18~150) + 테두리에서 flood fill** 로 배경만 지운다.

⚠ **색 판정만으로는 갑옷이 뚫린다.** 기사 시트의 배경 회색(밝기 65)과 판금 갑옷의 중간톤이
사실상 같은 값이라, 외곽선에 틈이 있으면 flood fill 이 갑옷 안으로 새어 들어간다
(1차 시도에서 노년 기사의 견갑이 통째로 파였다). 그래서 **flood 전에 그림 쪽(barrier)을 7px 팽창시켜
외곽선 틈을 막고, flood 후 같은 크기로 배경을 되돌린다.** 이 순서를 지켜야 갑옷이 남는다.

이 스타일의 굵고 어두운 외곽선(약 `#0B060C`)이 자동 누끼를 가능하게 한다 — 픽셀아트나 회화체면 같은 방법이 안 통한다.
