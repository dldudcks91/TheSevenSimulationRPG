# 1-2 인간 3종 — Codex 로 Gemini 결 찾기

**생김새가 다양한 인간을 Gemini 설치본(`ready/hero` · `ready/monster`)과 같은 하나의 스타일로** Codex 에서 뽑는 프롬프트를 찾은 기록이다. 찾은 프롬프트는 [art-prompt prompt_template §7](../../../../../../.claude/skills/art-prompt/prompt_template.md) 에 옮겼다. **게임 초상은 교체하지 않았다.**

r1~r4 는 인물 묘사가 같고(보병 · 궁수 · 기사), 버전(v1~v3)은 붙인 Gemini 참조 묶음이다 — v1 영웅 넷 · v2 챕터 몬스터 셋 + priest_1 · v3 인물마다 차림이 가까운 영웅 셋. r5 는 인물 9명을 `rounds/r5.json` 에 따로 적었다.

| 판 | 방식 | grain (Gemini 0.5~1.8) | 판정 |
|---|---|---|---|
| r1 | 참조만 붙이고 「같은 그림체로 새 인물」 | 2.0~6.7 | 녹 · 긁힘 결, 넓은 어깨, v3 는 흰자 · 홍채 |
| r2a | r1 + 매끈한 평면 채색 · 검은 눈 · 큰 머리를 글로 | 1.7~1.9 | 매끈하지만 젊은 벡터 얼굴 · 머리 작다 |
| r2b | Gemini 원본 한 장을 바탕으로 사람만 교체(편집) | 2.0~2.8 | 구도 · 여백 · 눈 · 연기가 Gemini |
| **r3** | r2b + 매끈한 평면 채색 한 줄 | **1.4~2.0** | **채택** — 세 묶음이 같은 결로 수렴 |
| r4 | r3 그대로 · 버전마다 바탕을 다른 영웅으로 | 1.5~2.4 | 결은 유지 · 바탕의 어깨폭과 의상 재질(사슬)이 샌다 |
| **r5** | r3 프롬프트(인물 줄만 일반화) · **생김새가 전부 다른 인간 9명** | 1.3~2.1 | **목표 확인** — 나이 · 성별 · 피부색 · 머리 · 체형이 갈리고 스타일은 하나. 바탕의 소품(화살통 · 붉은 망토)이 샌다 |

- `rounds/<판>.txt` · `<판>.json` — 판마다 보낸 프롬프트와 바탕(lead)
- `run_codex.py <판>` — 발주 · `out/<판>/<버전>_<id>.png`(1254² 투명)
- `score.py` — grain · 채도 · 어깨폭 · 머리 위 여백 (`--gemini` 는 기준 묶음)
- `compare.py <판> ...` — `compare_<이름>.png` (첫 행 Gemini 기준)
