# 누락된 스킬을 다크 카툰으로 보완

생성 방식은 **Codex 내장 imagegen**이다. 기존 다크 카툰 시트는 굵은 검은 윤곽선·각진 실루엣·두 단계 명암·색감만 참조하고 새로운 스킬 동작을 그렸다. 원본은 실제 투명 알파를 가진 3×3 시트 두 장이다.

- [원본 01](sheet_01.png) · [최종 프롬프트 01](prompt_01.txt): 리커버리·프렌지·워 크라이·배틀 크라이·레지스탕스 실드·스윕·홀리 파이어·애로우 레인·이베이드.
- [원본 02](sheet_02.png) · [최종 프롬프트 02](prompt_02.txt): 오버드로우·이그나이트·딥 프리즈·서지·에코·둠·자폭·헬파이어. 마지막 칸은 비어 있다.

[게임 크기 모음](compare.png) · [스킬·셀·사건 대응](manifest.json) · [생성 위치](generation_paths.json) · [내보내기 검사](export_report.json) · [파일 검사](asset_verification.json) · [브라우저 검사](verification.json) · [삭제 목록](cleanup_report.json) · [기존 그림 보존 해시](preserved_sha256.json)

`python scripts/build_darktoon_completion_fx.py`로 투명 원본을 자르고 알파를 보존해 `../../fx/skills/<skill>_darktoon.webp`에 256×256으로 저장한다. `--compare`는 모음, `--verify`는 현재 CSV 스킬의 전체 다크 카툰 대응·삭제된 스타일 부재·기존 파일 보존을 검사한다. 로컬 서버를 실행한 뒤 `python scripts/verify_darktoon_completion_fx.py`로 새 그림 재생·금속박 코드 대체·그림체 선택 저장을 검사한다.

새 17장을 더해 현재 96개 스킬 모두 다크 카툰 이미지가 있다. 이어지는 착탄 그림을 포함한 활성 파일은 106장이다. 기존 금속박은 보존하며 추가 그림이 없는 17개 스킬은 코드 조합을 쓴다. `SKILL_ART`의 `styles`와 `artFile`이 파일이 없는 조합의 요청을 막는다. 오오라는 기존처럼 도감에서 미리 본다.

수채화·스테인드글라스·네온 플라즈마·로우폴리·자수의 이전 설치본·원본·프롬프트·비교와 전용 스크립트는 삭제했다. 결정 근거는 [ADR-0754](../../../../../docs/client/adr/0754-새-이펙트-시안은-삭제하고-누락-스킬은-다크카툰으로-채운다.md)다.

검증 결과: 새 17장 모두 투명 알파·이미지 경계 검사 통과, 기존 204개 아트 파일의 SHA-256 일치. 브라우저에서 다크 카툰 활성 106장과 금속박 89장 디코딩, 새 17종의 다크 카툰 이미지 재생과 금속박 코드 대체, 전체 재생·한영 탭·설정 저장·삭제된 선택값의 기본값 복귀를 확인했다. 페이지 오류와 이펙트 파일 요청 오류는 없었다. 이전 시안과 관련 데이터 492개 파일을 삭제했다.
