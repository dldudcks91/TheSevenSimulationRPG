# 서로 다른 재료로 그린 스킬 이펙트 다섯

클린 도트·다크 카툰·수묵을 보존하고, 같은 스킬 형태를 다섯 재료 표현으로 새로 그렸다. 생성 방식은 **Codex 내장 imagegen**이다. 각 그림체 88장, 총 440장의 투명 WebP를 `../../fx/skills/<file>_<style>.webp`에 저장했다. 설정 → 이펙트 그림체와 도감 → 이펙트에서 보존 셋과 새 다섯을 고른다.

각 스타일의 원본은 `sheet_<style>_01.png` ~ `sheet_<style>_03.png`이며, 총 15장이다. 첫 참조는 보존한 클린 도트의 해당 시트로 형태와 셀 대응만 참조했다. 후속 시트의 둘째 참조는 같은 새 그림체의 첫 시트로 재료 표현만 참조했다. 생성된 원본의 위치도 [기록](generation_paths.json)했다.

`python scripts/build_material_fx.py`로 내보내고 `--compare`로 비교표를 만든다. 내보내기는 원본의 투명 알파를 유지하고, 각 행의 셀 사이 간격을 찾아 자른 뒤 256×256 WebP로 저장한다. 낙하·착탄 위치를 보존하며 그림을 알파 경계로 재중앙 정렬하지 않는다. 마지막 시트의 빈 행 때문에 생기는 간격 변화도 대응표에 기록했다. 과거 스킬 일곱 칸은 원본 대응을 위해 남지만 설치하지 않는다.

게임에서는 같은 스킬의 위치·크기·움직임·시간을 공통으로 사용한다. 기본값은 다크 카툰이다. 삭제된 스타일 환경설정은 기본값으로 돌아가며 코드 모양 선택은 걷었다. 그림이 없는 스킬의 기존 코드 대체 연출은 유지한다. 결정 근거는 [ADR-0655](../../../../../docs/client/adr/0655-이펙트는-클린도트-다크카툰-수묵과-서로-다른-재료의-다섯-그림체다.md)다.

검증 결과: 보존 대상 353개 파일의 SHA-256 일치, 새 440장 모두 투명 알파와 셀 경계 검사 통과, 브라우저에서 여덟 그림체의 활성 이미지 704개 디코딩·전체 재생·한영 탭·새 다섯 설정 저장·삭제된 다섯 선택값의 기본값 복귀를 확인했다. 페이지 오류와 이펙트 파일 요청 오류는 없었다. 이전 데이터 615개 파일의 삭제 목록은 위 삭제 기록에 있다.
