# 스킬 이펙트 그림체 — 2026-10-12

이 후보 셋은 사용자의 「그 그림체에 맞추지말고 우리 게임 캐릭터와 분위기에 어울리는걸로」 정정으로 교체했다. [캐릭터·세계관 기준 후보](../world_styles_20261012/README.md)를 사용한다. 이 폴더는 앞 비교 자료이며 설치본은 `previous/installed/`에 보관한다.

기존 초상·수묵·고딕 펜화·목탄·유화와 비교할 세 가지 후보를 **Codex 내장 imagegen**으로 생성했다. 각 그림체는 기본·전직 스킬 이펙트 **95장**을 갖는다. [비교 시트](compare.png)에는 기존 다섯 그림체와 새 셋을 같은 크기로 나란히 놓았다.

| 그림체 | 파일 접미 | 선택한 질감 |
|---|---|---|
| 과슈 | `_gouache` | 불투명한 무광 물감 면, 둔한 붓 자국, 마른 가장자리 |
| 동판화 | `_etching` | 오래된 마도서의 새김선, 굵은 빗금, 채도를 낮춘 손 채색 |
| 프레스코 | `_fresco` | 광물 안료의 얼룩, 닳고 벗겨진 가장자리, 오래된 벽화의 칠 |

## 원본과 프롬프트

- `sheet_<그림체>_01.png` ~ `_03.png`: 그림체마다 원본 아틀라스 세 장. 각 장은 검정 격자와 자홍 배경의 6×6 칸이다. 마지막 장의 남는 칸은 비워 둔다.
- `prompt_<그림체>_01.txt` ~ `_03.txt`: 생성에 사용한 프롬프트 전문. 첫 장을 그림체 기준으로 삼고, 둘째·셋째 장에는 첫 장을 참조 이미지로 첨부했다.
- `manifest.json`: 그림체 정의와 아틀라스 칸별 설치 파일·구도. 수묵의 `../ink_20261009/picks.py` 및 칸별 프롬프트에서 가져왔다.

```powershell
python scripts/prepare_painterly_fx.py
python scripts/build_painterly_fx.py
python scripts/build_painterly_fx.py --compare
```

첫 명령은 프롬프트와 칸 표만 작성한다. 이미지 생성 호출은 하지 않는다. 둘째 명령은 원본 아홉 장을 검증한 다음 `src/assets/art/fx/skills/<기존 이름>_<그림체>.webp`로 설치한다. 지정한 그림체만 다시 자르려면 `python scripts/build_painterly_fx.py gouache`처럼 실행한다.

설치본은 **384×384 RGBA WebP**, 품질 90, 알파 품질 100이다. 기존 키잉과 알파를 곱한 Lanczos 축소를 사용하고, 전직 설치 스크립트와 같은 바깥 5% 알파 처리를 한다. 칸 좌표를 유지해 낙하·착탄 위치와 강화·회복의 빈 중앙이 움직이지 않는다.

이 후보 셋의 게임 탭은 교체했다. 그림체 등록과 파일명 조합은 `src/ui/skill_art.js`가 관리한다.
