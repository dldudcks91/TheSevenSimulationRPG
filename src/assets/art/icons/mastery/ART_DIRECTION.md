# 마스터리 아이콘 제작표

확정 범위는 `src/data/mastery_node.csv`의 46개 노드다. 노드별 제작 지시는 [icon_plan.csv](icon_plan.csv)에 한 행씩 저장한다. `node_id`가 데이터와 그림을 잇는 키이며, `asset_path`는 게임에서 읽는 개별 PNG 경로다. 표시 이름은 `mastery_node.csv:name_kr/name_en`이 기준이다. 직업 공통 무기 노드의 `{group}`은 직업에 맞는 `weapon_group.csv` 이름으로 바뀌며, 한 칸씩만 그리는 비교표에는 `무기군 마스터리`로 적는다. 새 마스터리가 확정되면 데이터와 이 표에 함께 추가한다.

스킬창과 도감의 마스터리 탭은 모두 노드 ID로 아이콘을 읽는다. 고유 노드는 `nodes/<node_id>.png`, 죄종 공통 노드는 `nodes/variants/<죄종>/<node_id>.png`, 직업 공통 노드는 `nodes/variants/class/<직업>/<node_id>.png`를 쓴다. 특정 PNG 하나를 바꾸면 두 화면에 함께 반영된다.

| 항목 | 공통 제작 기준 |
|---|---|
| 그림 언어 | 어두운 판타지 RPG의 오래된 금속 마스터리 문장. 액티브 스킬의 장면 그림과 구분되는 정면의 단일 기호. |
| 외곽 | 지름 약 72%의 **완전히 매끈하고 끊기지 않는 원**. 톱니, 끊어진 고리, 광선, 사각 프레임 없음. |
| 중심 | 효과를 읽을 수 있는 굵은 실루엣 1개와 새김선 1~3개. 48px에서도 식별되어야 함. |
| 색과 질감 | 죄종·직업의 고유 노드와 그 판에 표시되는 공통 노드는 해당 죄종색·직업색을 쓴다. 원형 겉테두리·중심 문양·칸 테두리·판 테두리도 같은 색에 맞춘다. 어두운 홈과 작은 모서리 하이라이트는 유지한다. |
| 출력 | 투명 배경 256×256 PNG. 문자와 랭크 수치는 그림에 포함하지 않음. 칸의 사각 테두리, 잠금, 랭크 표시는 UI가 그린다. |
| 반복 효과 | 같은 `glyph`는 같은 기본 문양. 같은 효과라도 장비 조건이 핵심인 노드는 별도 `glyph`로 구분한다. |

## 제작 및 교체

`icon_plan.csv`의 `prompt`는 **공통 기준 뒤에 붙는 노드별 시각 지시**다. 현재 46개 기본 PNG는 [generate.ps1](generate.ps1)과 [IconRenderer.cs](IconRenderer.cs)가 `glyph`와 `palette` 열을 해석해 재현 가능하게 그린다. `palette`가 비어 있으면 청동, 죄종 ID이면 [mock.js](../../../ui/mock.js)의 `SINS` 색, 직업 ID이면 [class.csv](../../../data/class.csv)의 `color_hex`를 쓴다. `prompt` 문장은 생성기의 코드 입력이 아니라 그림을 다시 그리거나 이미지 생성 도구로 교체할 때 쓰는 아트 명세다. 따라서 문장만 고치면 PNG가 자동으로 바뀌지는 않는다.

| 죄종 | 색 | 죄종 | 색 |
|---|---|---|---|
| 분노 `wrath` | `#e03030` | 시기 `envy` | `#30b050` |
| 탐욕 `greed` | `#d0a020` | 나태 `sloth` | `#808898` |
| 폭식 `gluttony` | `#e07020` | 색욕 `lust` | `#e03080` |
| 오만 `pride` | `#8040e0` | | |

| 직업 | 색 | 직업 | 색 |
|---|---|---|---|
| 전사 `warrior` | `#7895A9` | 기사 `knight` | `#C6CDD6` |
| 마법사 `mage` | `#7878D9` | 궁수 `archer` | `#93A861` |
| 사제 `priest` | `#E1CE98` | | |

죄종 공통 노드 3개와 직업 공통 노드 2개는 원본을 공유하므로, 각 판에 쓰는 색 변형 PNG를 별도로 생성한다. 생성기는 `mastery_node.csv`의 소유자를 읽어 죄종 변형 21개와 직업 변형 10개를 관리한다. 확장 직업 두 종류는 아직 마스터리 노드와 직업색이 없다.

비어 있는 아이콘만 생성: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File src/assets/art/icons/mastery/generate.ps1`

한 개 다시 생성: 위 명령 뒤에 `-NodeId sin_t1_atkspeed` 추가. 전체를 강제로 다시 생성하려면 `-Force`를 추가한다. 기본 전체 실행은 이미 존재하는 PNG를 건너뛰므로 개별 교체본이 보존된다. 특정 마스터리만 교체할 때는 표의 해당 행을 수정하고 `asset_path`의 PNG 하나만 갈아 끼우면 된다. 게임 코드는 노드 ID로 파일을 읽으므로 다른 아이콘에 영향이 없다.

죄종 고유 아이콘 21개와 공통 노드의 죄종별 변형 21개만 다시 생성: 위 명령 뒤에 `-RecolorSins` 추가. 직업 아이콘과 공통 원본은 건드리지 않는다.

직업 고유 아이콘 20개와 공통 노드의 직업별 변형 10개만 다시 생성: 위 명령 뒤에 `-RecolorClasses` 추가. 죄종 아이콘과 공통 원본은 건드리지 않는다.

전체 비교 미리보기는 `preview.ps1`로 다시 만들 수 있으며 결과는 `output/mastery_icons_all.png`에 저장된다.
