# src/ui — DOM 렌더러

**Phase 2(엔진 이식)에서 버려질 레이어.** 계산·난수 없음 — 상태(G)를 읽고 `game_logic` 시스템(SYS)을 부르고 `save()` 한다.

## 파일별 역할

| 파일 | 역할 |
|---|---|
| `app.js` | 화면 렌더링. 계산·난수 없음 |
| `battle.js` | 전투 관전 = `game_logic/battle.js` 타임라인 **재생기** (계산하지 않는다) |
| `data.js` | CSV fetch → `game_logic` 시스템 조립(주입). 수치 미러 없음. `D.csvText` 에 **원문**도 남긴다 — 읽는 곳은 `dev/golden.js` 의 CSV 해시 하나뿐이고 게임 로직은 안 본다 (2026-08-31) |
| `storage.js` | localStorage 어댑터 — 저장소를 만지는 **유일한** 파일 |
| `tip.js` | 툴팁 — **기계장치 한 곳**(표시 · 따라다니기 · 넘침 보정 · 겹친 툴팁 복귀). 두 렌더러가 함께 쓰는 **영웅 카드 · 스킬 카드**도 여기. 아이템 비교 카드는 `app.js` (app 헬퍼를 많이 탄다) |
| `i18n.js` | 한/영 사전 `STRINGS` + 언어 상태 |
| `mock.js` | 화면 전용 사전 — 죄종·희귀도 색 · 접사 **표기**(`AFFIX_LABELS` — ⚠ 19개 중 12개가 `combat_stat.csv` 와 이름·단위 중복이다. 08-31 에 `reflect_damage` 가 갈려 한 탭에서 다르게 찍히는 사고가 났다) · 페이퍼돌 배치(`PAPERDOLL`) · 마스터리 판 프레임(`MASTERY_GRID` — 티어 3 × 노드 3) · 자산 경로(`faceDir()`·`BG_DIR`·`stageBg`) · **얼굴 아트 스타일 전환**(`FACE_STYLES`·`setFaceStyle`·`applyDocumentFace` — 폴더 하나 = 스타일 하나. 고른 스타일은 `<html data-face>` 로도 나간다 — CSS 가 **초상 축소 보간**을 가르는 신호다, 아래 「초상 보간」) · 액티브 표시 사전(`SKILL_DISPLAY` — 아이콘·설명만. 이름·쿨은 `skill.csv`). **직업·슬롯·아이템 베이스·접사 정의·영웅 이름/특성 풀은 2026-08-31 로 CSV 로 나갔다**(`class`·`equip_slot`·`item_base`·`affix`·`hero_name`·`hero_trait` → `data.js` 의 `D.classes`·`D.slots`/`D.equipSlots`·`D.itemBases`·`D.affixDefs`·`D.heroNamePool`·`D.heroTraitPool`). 이름 ko/en·얼굴 유무·기본 능력치 7·전투 능력치 25·도감 보정은 08-28 로 나갔다 — 헬퍼는 `data.js` (`monsterName`·`monsterFace`·`monsterSin`·`stageName`·`stageBgOf`·`chapterOf`·`eliteName`). **남은 게임 데이터는 죄종(`SINS`)·정예 특성(`SIN_TRAITS`·`COMMON_TRAITS`) 셋뿐** — 죄종 매핑 확정을 기다린다 |
| `style.css` | 스타일 |

- **공통 영웅 띠** (`app.js heroStrip`) — 캐릭터 탭 상단(스킬은 탭을 잃고 **창**이 됐고, 창은 띠를 다시 그리지 않는다 — SCREEN_DESIGN §7), 원정은 **편성 패널 안**(`formPanel` — 스테이지를 골라야 열린다, `{flat:true}` 로 패널 껍데기를 벗는다)에 같은 띠: 초상(`.hero-face` — 관전 유닛 카드와 같은 네모 박스 · 그림은 `mock.js heroFace` 가 **이름**으로 고르고 없으면 밑에 깔린 직업 글리프 `mock.js classGlyph` 가 드러난다, [SCREEN_DESIGN §5](../../docs/client/SCREEN_DESIGN.md))이 카드 전체, 그 위 위칸(`.hs-band`)에 지금 하는 일(치료 중 / 전투 파티 / 대기) + 이름. 직업·레벨·죄종·등급은 툴팁

## 다국어 (한/영) — 필수

화면에 나가는 모든 문자열은 한 곳에 ko/en 이 **나란히** 있어야 한다.

| 종류 | 위치 | 사용 |
|---|---|---|
| UI 문구 | `i18n.js` 의 `STRINGS` — 키 하나에 `{ko, en}` | `t('key')` |
| 데이터 문자열 | CSV 의 `_kr`/`_en` 컬럼 쌍 → `{ko, en}` (로더·헬퍼가 조립) · 아직 CSV 로 안 간 것은 `mock.js` | `L(value)` |

- **렌더러(`app.js` / `battle.js` / `tip.js`)에 한국어 리터럴 금지** — 주석 제외. 이게 누락 검증 기준이다
- 이름 조립 규칙(어순·조사)은 렌더러에 두지 않는다 — **`game_logic/naming.js`** 가 든다 (`composeName` · `eliteName`, 2026-08-31 이관). `data.js:eliteName(sin, monsterId)` 은 id → 이름 조회만 하고 조립은 넘긴다
- **설명 문구는 도움말 탭 전용** — 인게임 패널에 안내 문장 금지 (2026-08-26 사용자 지시). 패널에는 숫자·상태·오류·버튼·툴팁만 남기고, 규칙 문구는 `app.js` 의 `helpSections()` 에 **기존 키를 재사용해** 넣는다 ([SCREEN_DESIGN §12](../../docs/client/SCREEN_DESIGN.md))

## 화면 폭 정책

- 상한 **1600px** / 하한 **1280px**, 세로 예산 **700px** (1366×768 노트북 기준)
- 해외 배율 125% 환경에서 CSS 뷰포트가 1536/1280 으로 잡힌다. 영어는 같은 내용이 1.3~1.5배 길다
- 라벨이 들어가는 칸은 **고정 px 금지** — `minmax()` / `clamp()` 로 최소만 보장한다
- **초상 보간** [2026-09-01] — 초상은 어디서나 원본보다 작게 그려진다(구성 칩 26px ~ 시작 후보 카드 152px). **줄이는 방법은 스타일이 정한다**: 토큰 `--face-render` 가 `:root` 에서 `auto`(손그림 — 기본값이자 안전한 쪽), `:root[data-face="pixel16"]` 에서 `pixelated`(도트). 초상 `<img>` 셋(`.face` · `.hero-face` · `.sprite.has-face`)이 그 토큰만 읽으므로 **스타일을 늘리면 손댈 곳은 토큰 한 줄**이다 ([SCREEN_DESIGN §5](../../docs/client/SCREEN_DESIGN.md))
  - ⚠ 배경 아트(`body::before` · `.arena.has-bg` · `.panel.town-bg` · `.zone.has-bg`)의 `pixelated` 는 **이 토큰과 무관**하다 — 그쪽은 스타일과 상관없이 늘 픽셀아트다. 걷어내지 말 것
  - **예외 1건 — 관전 유닛 카드**(폭 고정은 카드를 감싼 칸 `.unit-slot` 이 든다 — 카드 밑에 창 뱃지 줄이 붙기 때문, 2026-08-27 사용자 지시): 몬스터·영웅·보스가 전부 같은 고정 크기다. 한 진영 최대 3장(`balance.csv:party_size_max` · `wave_monster_max`)이라 하한 폭에서 접히지 않는다. 긴 이름은 위칸에서 말줄임 ([SCREEN_DESIGN §4-2](../../docs/client/SCREEN_DESIGN.md))
